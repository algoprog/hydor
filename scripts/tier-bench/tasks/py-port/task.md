We are retiring the Python version of our reporting helpers. Please port legacy/report_utils.py to src/report_utils.mjs: one exported function for each public Python function, with the same name (snake_case, as in Python) and the same parameters in the same order (Python's default values become JavaScript default values). The Node.js service will call them with the inputs the Python gets today, decoded from JSON: strings, numbers, booleans, null, arrays for lists, plain objects for dicts. Each function must give exactly the same result as the Python one for every such input: the same strings character for character, the same numbers, the same arrays and objects. Where the Python raises an exception, the JavaScript must throw (any Error will do). legacy/test_report_utils.py shows how they are used. Add tests under test/ (node:test, so that `node --test` passes). Plain Node.js 22 ES module, no packages.
