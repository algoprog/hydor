Our old metrics collector saved its data in .mlog files, and the only program that could read them, mlog-dump, is gone, along with any description of the format. What we have is samples/: forty .mlog files and, for each, the JSON that mlog-dump printed for it (a .json file of the same name), or, for the few files it refused, its error message (a .err file). Please write src/mlog.mjs exporting `decode(buffer)`, which takes the bytes of an .mlog file and returns what mlog-dump printed for it (the parsed JSON), and throws an Error for any file mlog-dump would have refused. We have thousands of these files, written by the same collector over the years, so it has to work for all of them, not only the samples. Plain Node.js 22, no packages.
