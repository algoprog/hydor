# 用量、限额和费用

Claude Code 和 Codex 运行在有使用限额的套餐上，每次调用模型也都有价格。本主题介绍在哪里查看每个套餐用了多少、何时重置，达到限额时会发生什么（以及如何让会话自动继续），智能体一段时间以来做了什么，以及应用如何估算费用，包括你自己设置的价格。

![用量：每个套餐用了多少，以及什么时候重置](images/usage.webp)

## 打开用量页面

点击侧边栏中的 **用量**（在手机上，先打开侧边栏）。“用量”图标下方的细条让你一眼看到 Claude Code 和 Codex 中用得最多的那个限额；任何一个用完时它会变红。把鼠标悬停在上面，可以看到每个限额的百分比。

[用量页面](/usage) 有三个标签页：

- **限制**（`/usage`）：每个套餐还剩多少，以及何时重置。
- **活动**（`/stats`）：一段时间以来更改的行数、token 和会话。
- **竞技场**（`/arena`）：哪些模型在你自己的任务上胜出。

应用会在你打开这个页面时读取你的用量，并在应用打开期间每五分钟读取一次；在“限制”标签页上，**刷新** 会立即重新读取。

## 查看套餐的限额

**限制** 标签页为 Claude Code 显示一张卡片，为 Codex 显示一张，并为你在 [设置 → 智能体 → 账户](/settings?s=accounts) 中添加的每个账户各显示一张。在宽屏幕上每行两张；在手机上一张接一张往下排。

每张卡片显示账户的电子邮件和套餐、这些数字是多久以前读取的，以及每个限额一行（限额指一段时间窗口内的使用上限）：

- Claude Code：**当前会话（5 小时）**、**每周 · 所有模型**，以及针对单个模型的每周限额，比如 **每周 · 仅 Sonnet**。
- Codex：**5 小时窗口**、**每周**，或者其他时长的窗口。当 Codex 有多个限额时，每一行以限额的名称开头。

每一行给出已用的百分比、一个进度条、剩余的百分比，以及何时重置（“重置：2 小时 15 分钟后”；悬停可以看到确切时间）。达到 90% 或更多时会出现警告标志。

根据套餐不同，卡片还会显示：

- **额外用量**（Claude）：是否开启了超出套餐限额的付费使用，以及它的月度上限已经花掉了多少。
- **额度**（Codex）：你的额度余额，或“无限制”。
- **限额重置**：你现在就可以使用的重置（见[使用限额重置](#use-a-limit-reset)）。
- **本周按使用端**（Claude）：本周的用量在你使用 Claude 的各个地方之间是如何分配的。
- **每日 Token**（Codex）：最近 30 天的图表，以及你的累计总量。token 是一个词的一小部分；模型按 token 计算它们读和写的量。

出问题时，卡片会说明：

- “未登录”，并提供 **在设置中登录**；
- “此套餐没有报告用量限制”；
- 一条错误信息，并提供 **请在设置中检查登录**；
- 最近一次读取失败时，显示“显示最后已知的数据：……”。

## 达到限额时会怎样

套餐的用量用完时，智能体的这一轮会停止。会出现一条通知，说“你已达到 Claude Code 的使用限额”（或 Codex），以及是哪个限额、何时重置。它会显示在：

- 开始页的消息框上方，针对你选择的智能体（和账户）；
- 会话中的消息框上方；
- 用量页面上该套餐的卡片上。

通知会提供你可以做的事：

- **重置时继续**（在会话中）：会话会在限额重置一分钟后自动继续，并发送消息“Continue where you left off.”。通知随后会显示“此会话会在以下时间自动继续：重置时”，并带有 **取消**。
- **使用一次重置**，当账户持有一个现在就能用的限额重置时出现（“有 2 次重置可用”）。

用量已经恢复、但还有会话等着继续时，通知会显示“将自动继续……”，并带有 **取消**。

## 达到限额后让会话自动继续

要让每个达到限额的会话都自动继续，打开 [设置 → 应用 → 通用](/settings?s=general&find=Resume%20after%20usage%20limits)，开启 **用量限制解除后继续**（“当某一轮因套餐用量耗尽而停止时，会话会在限额重置一分钟后自动继续”）。在你开启之前它是关闭的。即使没有打开任何浏览器，它也能工作。

无论是用这个开关，还是用 **重置时继续**，时间都是这样安排的：

- 会话会在限额重置一分钟后继续，重置时间以服务商最近一次报告的为准。会话等待期间，应用会不时读取用量，越接近重置读得越频繁；如果服务商调整了重置时间，应用也会相应调整继续的时间。
- 如果限额提前解除（你使用了一次重置，或者换了另一个账户登录），会话会立即继续。如果它在过去 15 分钟内提前继续过，又再次达到了限额，它就会改为等待重置。
- 通知上的 **取消** 会取消已计划的继续。

如果这个智能体有不止一个账户，[**达到限额时切换账户**](/settings?s=accounts&find=Switch%20accounts%20at%20a%20limit)会立即让会话换另一个账户继续，只有在每个账户都达到限额时才会等待（见[智能体、账户和模型](/guide/agents-models#use-all-your-accounts-switch-at-a-limit)）。

## 使用限额重置

有些套餐会给你限额重置：Codex 的重置额度和 Claude 的重置授权。使用一次，就能立即清除套餐的使用限额，而不用等它们自行重置。

每张卡片都在 **限额重置** 下列出它们，并显示你有多少个。每个重置都显示它的名称（以及它还剩几次可用）、“到期：……”（不到一天时以警示色显示）或“不会过期”，以及诸如“达到限额后才能使用”或“暂时还不能使用”之类的说明。一个都没有时显示“目前没有可用的限额重置”，如果套餐有说明，还会显示下一个何时到来。

1. 点击某个重置旁边的 **使用**，或者点击限额通知上的 **使用一次重置**（它会使用列表中第一个现在就能用的重置）。
2. 阅读确认信息。它会说明要使用哪个重置、它何时到期，以及还会剩下几个。如果你没有达到限额，它会提醒你（“你目前没有达到限额”）。
3. 点击 **使用重置**。

应用会告诉你结果，例如“Codex 的使用限额已重置。”“Claude 目前没有达到使用限额，所以没有重置任何东西。”“重置正在冷却中，请稍后再试。”或“这次重置已经用过了。”成功时，正在等待限额的会话会立即继续。

Claude 的重置需要 Claude Code 用 Claude 订阅登录（而不是 API 计费）。

## 查看智能体一段时间以来做了什么

**活动** 标签页（`/stats`）统计智能体做过的事，数据来自应用在这台电脑上掌握的会话。

顶部有：

- **每日**（最近 30 天）、**每周**（26 周）、**按月**（12 个月，或从你的历史记录开始时算起）或 **每年**（按年）。页面会记住你的选择。
- **全部**，或某一个智能体：**Claude**、**Codex**、**Custom**，以及在这里做过事的任何其他智能体（Gemini CLI、OpenCode……）。
- 一个模型的标签：当你在下面的 **按模型** 中选择了一个模型时出现，页面随后只统计这个模型。点击这个标签（它的 **✕**）可以重新查看所有模型。
- **图表** 或 **表格**。

它们旁边的一行文字说明时间范围和你的时区。天、周和月都按你的时区计算。

各个方块显示该时间范围内的总数：

- **新增行数** 和 **删除行数**
- **输入 token**（模型读入的内容：新的和缓存的）和 **输出 token**（模型写出的内容）
- **输出速度**：写回复期间每秒输出的 token 数
- **API 费用（估算）**：同样的 token 通过 API 使用要花多少钱
- **提示词**（以及轮数）、**会话**、**命令**（以及工具调用次数）和 **文件编辑**

方块上的小箭头是与紧挨着的前一段同样长的时间相比（“箭头表示与此前 30 天相比”）。它是中性的：多并不代表更好，也不代表更差。

**图表** 显示更改的行数（新增朝上，删除朝下）、输入 token（新的和缓存的）、输出 token、输出速度，以及提示词、会话、命令和文件编辑的小图表，每天、每周、每月或每年一根柱子。**表格** 按时间段列出同样的数字，最新的在前，并附有合计。

两种视图的下方都有：

- **按智能体**：按名称列出每个智能体（Claude Code、Codex、Custom、Gemini CLI 以及其他做过事的智能体），包括会话、提示词、行数、输入和输出。
- **使用最多的项目**：更改行数最多的文件夹。
- **按模型**：每个模型的会话、提示词、输入、缓存输入、输出和 API 费用；Custom 的模型（OpenRouter、Ollama、vLLM……）和 Claude、Codex 的模型一样都会列出。点击一个模型，整个页面就只显示它的数据。价格未知的模型会改为显示 **设置价格**。把鼠标悬停在模型上，可以看到它每百万 token 的价格和价格来源（“你的价格”或“公开价格表”）。

在手机上，方块每行两个，表格的部分列会被省略。

今天智能体做过事之后，开始页会在消息框下方显示今天的数字：新增和删除的行数、输入和输出 token、提示词和会话。点击它们可以打开“活动”。

## 费用是怎么估算的

Claude 和 ChatGPT 的套餐是固定费用，所以应用会显示同样的工作按 API 价格（按用量付费的价格）要花多少钱。这能让你知道你从套餐中得到了多少使用量，以及通过 API 使用某个模型要花多少钱。

- 价格来自一份公开价格表（LiteLLM 的），应用每天最多获取一次，并保存下来，以便离线时使用。
- 你自己设置的价格优先于价格表。
- 每个会话的 token 按它的模型计价；中途换过模型的会话，按它最后使用的模型计价。
- 缓存输入（模型之前读过、从它的缓存中提供的文字）按缓存价格计价，没有缓存价格时按输入价格计价。
- 价格未知的模型（只有一个系列名，比如“opus”，或者价格表里没有的模型）在总数中按零计算，并在“按模型”中显示 **设置价格**。

花费上限使用同样的价格，但如果智能体自己报告了花费，就采用它自己的数字：Claude Code 的费用，或者 OpenRouter 给出的每次 Custom 调用的费用。在这台电脑上运行的模型在这里不计费用。

## 为模型设置你自己的价格

1. 在 **活动** 标签页上，点击 **按模型** 顶部的 **模型价格**，或者点击某个模型旁边的 **设置价格**。
2. **模型价格** 对话框列出当前视图中的模型，以及你之前设置过价格的模型。每个都有 **输入**、**缓存** 和 **输出**，单位为美元/百万 token。留空的字段使用公开价格表中的价格，以灰色显示。
3. 输入你的价格。输入和输出都必须填写；缓存是可选的（不填时按输入价格计算）。
4. 要给没有列出的模型定价，在 **其他模型 ID** 中输入它的 ID，然后点击 **添加**。
5. 点击 **保存价格**。

某一行上的垃圾桶图标（**使用价格表中的价格**）会清除你为该模型设置的价格。要把这台电脑上运行的某个模型算作免费，给它的输入和输出都填 0。

## 每个会话都会保留

无论智能体自己的程序怎么做，应用都会保留每个会话及其数字。Claude Code 默认会在 30 天后删除它的对话，所以应用会告诉它保留这些对话（在每个设置里没有指定保留多久的 Claude Code 账户中），而且应用会为 Claude Code 和 Codex 的每个对话文件保留它自己的一个链接：被智能体的程序（或任何人）删除的对话会回来，像以前一样列出、可以打开。这个链接就是同一个文件的另一个名字，所以不会额外占用磁盘空间。

会被删除的只有没人用的：不活跃满一年的会话会被删除，除非你在 [设置 → 通用 → 删除不活跃的会话](/settings?s=general&find=Delete%20inactive%20sessions) 中更改（见[删除不活跃的会话](/guide/app#delete-inactive-sessions)）。它们的数字会保留在“活动”中。

在此之前、应用还没有保留它们时被 Claude Code 删除的对话，无法再找回；“活动”的历史记录从应用第一次统计它们时开始。

## 限制会话的花费

花费上限会在会话按 API 价格花到设定的金额时让它停止，无论你用哪种套餐付费。它启动的子会话也计算在内。

- 对于新会话：在开始页上，**选项** → **花费上限**。选择 $1、$5、$10 或 $25，或者输入一个金额并点击 **设置**。**无上限** 会取消上限。
- 对于正在运行的会话：会话的菜单（⋯）→ **会话设置** → **花费上限**。对话框会显示它到目前为止花了多少。输入一个上限（最低 $0.01），然后点击 **设置上限** 或 **修改**；**取消上限** 会取消它。

设置了上限后，消息框上方的横条会显示“$1.20 / $5.00”，并带有 **修改**。达到上限时，智能体会在达到上限的那次模型调用之后立即停止，这一轮下方的说明会显示“已在花费上限处停止”，新消息会一直等待，直到你提高上限（**提高上限…**）或者取消它。更多内容见[会话](/guide/sessions)。

## 竞技场标签页

**竞技场** 标签页（`/arena`）显示哪些模型在你自己的任务上胜出。在开始页上，**选项** → **竞技场** 会把你的提示词同时发给另外一两个模型；你保留最好的回答。这个标签页根据你已经判定的比赛，按评分（Elo 评分，从 1000 开始）给模型排名，显示每个模型被保留的频率和胜率，并列出最近的比赛，包括已判定的和尚未判定的。见[深度研究、第二意见和多个智能体](/guide/research)。

## 能把这些数字清零吗？

没有清空“活动”的按钮。你自己删除会话（它的菜单 → **删除会话**）也会把它的数字从“活动”中去掉；因为不活跃而被删除的会话会保留它们的数字。“限制”标签页上的限额是你的套餐本身的：它们按服务商的时间表重置，或者通过[限额重置](#use-a-limit-reset)来重置。

## 问问智能体

- “我的 Claude 套餐这周还剩多少？什么时候重置？”
- “打开用量限制解除后自动继续会话的功能。”
- “Codex 的限额重置后，继续我的会话‘重构认证’。”
- “按 API 价格算，上个月的工作要花多少钱？按模型分别列出。”
- “在费用估算中把我的 Ollama 模型算作免费。”
- “Custom 这个月做了多少事？用了哪些模型？”
- “把不活跃会话的删除期限从一年改成两年。”
