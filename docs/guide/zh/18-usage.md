# 用量、限制与费用

Claude Code、Codex 和 Grok Build 都按带有用量限制的套餐运行，Antigravity CLI 则使用你的 Google AI 套餐（它自己的终端会显示剩余额度），而每一次模型调用都有价格。本主题介绍：在哪里查看每个套餐已用了多少、何时重置；达到限制时会发生什么（以及如何让会话自动继续）；智能体随时间做了哪些事；以及应用如何估算费用，包括你自己设置的价格。

![用量：每个套餐已用了多少，以及何时重置](images/usage.webp)

## 打开用量页面

在侧栏的导航条上打开 **用量**（在手机上，先打开侧边栏）。**用量**图标下方有一条细条，让你一眼看出所有付费的 Claude Code、Codex 和 Grok Build 订阅还剩多少，每个订阅按最接近上限的那项限制计算；如果你只有免费订阅，就按免费订阅计算；一个订阅都没有时则不显示。当额度全部用完时，它会变红。把鼠标悬停在上面，可以看到每个订阅还剩多少。Antigravity CLI 不计入这条细条：应用不会读取它的额度。

[用量页面](/usage)有三个标签页：

- **限制**（`/usage`）：每个套餐还剩多少，以及何时重置。
- **活动**（`/stats`）：随时间变化的修改行数、token 和会话。
- **竞技场**（`/arena`）：哪些模型在你自己的任务上表现最好。

应用会在你打开页面时读取用量，并在应用打开期间每五分钟读取一次；在**限制**标签页上，点击**刷新**会立即再读取一次。Grok Build 的用量是每隔几分钟从它的智能体读取的，点击**刷新**也会立即读取。

## 查看套餐的限制

**限制**标签页为 Claude Code、Codex、Grok Build 各有一张卡片，Antigravity CLI 也有一张（在你于[设置 → 智能体 → 更多智能体](/settings?s=agents)中添加之后），你在[设置 → 智能体 → 账户](/settings?s=accounts)中添加的每个账户也各有一张。在宽屏上每行放两张；在手机上则一张接一张地竖排。

每张卡片显示账户的邮箱和套餐、数字是多久前读取的，以及每项限制一行（一段时间窗口加上用量上限）：

- Claude Code：**Current session (5 h)**、**Weekly · all models**，以及针对某一个模型的每周限制，例如 **Weekly · Sonnet only**。
- Codex：**5-hour window**、**每周**，或其他时长的窗口。当 Codex 有多项限制时，每一行都以该限制的名称开头。
- Grok Build：**每周**，并显示何时重置。卡片还会注明套餐名称（SuperGrok、SuperGrok Plus 或 SuperGrok Heavy）。Grok 自己的登录有一张卡片，你添加的每个 Grok 账户也各有一张。
- Antigravity CLI：没有任何行。添加之后，它的 **Antigravity CLI** 卡片会显示邮箱和套餐，并说明“Antigravity CLI shows how much of your plan is left with /usage in its own terminal.”应用不会读取它的额度，因为 Google 的指引不允许在后台发起调用。它的 Google AI Pro 和 Ultra 套餐每五小时刷新一次，直至达到每周上限；Free 和 Plus 套餐只有每周上限。

每一行会给出已用百分比、一条进度条、剩余百分比，以及何时重置（“resets in 2 h 15 min”；悬停可看到确切时间）。达到 90% 或以上时会出现警告标志。

根据套餐不同，卡片还会显示：

- **额外用量**（Claude）：超出套餐限制的付费使用是否已开启，以及已花掉月度上限的多少。
- **额度**（Codex、Grok Build）：你的额度余额，或“Unlimited”。
- **按用量付费**（Grok Build）：套餐支持时，显示你本月在其上的花费与上限的对比（“$12.00 of $50.00 this month”）。
- **限额重置**：你现在可以使用的重置（见[使用限额重置](#use-a-limit-reset)）。
- **本周按使用端**（Claude）：本周的用量在你使用 Claude 的各个地方之间如何分布。
- **每日 Token**（Codex）：最近 30 天的图表，以及你的累计总数。token 是一个词的片段；模型用 token 来计算它们的阅读量和写作量。

出现问题时，卡片会告诉你：

- “Not signed in”，并附有**在设置中登录**（对于 Grok Build：“Sign in to see Grok's plan usage.”）；
- 对于由团队管理的套餐，Grok Build 的卡片会显示“Usage limits are managed by your team.”，因为它没有自己的限制可显示；
- “No usage limits reported for this plan”；
- 一条错误，附有**请在设置中检查登录**；
- 当最近一次读取失败时，显示“Showing the last known numbers: …”。

## 达到限制时会发生什么

当套餐的用量用完时，智能体的当前轮次会停止。对于 Grok Build，这指的是它的每周限制、额度限制或按用量付费的花费上限；短暂的速率限制（一阵密集的请求）不算，它会自行过去。系统会弹出通知，说明是谁的限制被触发、是哪一项限制以及何时重置：“You've hit the Claude Code usage limit”（或 Codex、Grok Build、Antigravity CLI），即该智能体只有一个账户时；“All your Claude Code accounts have hit their usage limit”，即你有多个账户而且都没有剩余用量时；或者以账户名称显示（“Work has hit its usage limit”），即另一个账户仍有剩余时。通知会出现在：

- 起始页上，消息框的上方，针对你选择的智能体（和账户）；
- 会话中，消息框的上方；
- 用量页面上该套餐的卡片中。

通知会提供你可以采取的操作：

- **重置时继续**（在会话中，且**用量限制解除后继续**处于关闭状态时）：会话会在限制重置一分钟后自动继续，并带上消息“Continue where you left off.”。此时通知会显示“This session continues by itself when it resets”，并带有**取消**。
- **使用一次重置**，当账户持有你现在可以使用的限额重置时（“2 resets available”）。

用量恢复后，如果某个会话仍待继续，通知会显示“Continues by itself in …”，并带有**取消**。

Antigravity CLI 是个例外。当它的额度用完时（“Individual quota reached… Resets in 2h39m52s”），该轮次会停止，通知会说明它已达到用量限制以及何时重置，并附上这句话：“Antigravity CLI 不会自行继续（Google 的套餐条款只允许由你发起的轮次），所以请在重置后发送一条消息。”它没有**重置时继续**按钮，**用量限制解除后继续**也不适用于它。当 Google AI 额度过低时（“AI credits”），通知也会告诉你。

## 达到限制后自动继续会话

若想让每个达到限制的会话都自动继续，请打开[设置 → 应用 → 通用](/settings?s=general&find=Resume%20after%20usage%20limits)，并开启**用量限制解除后继续**（当某一轮因套餐用量用完而停止时，会话会在限制重置一分钟后自动继续）。它默认是关闭的，直到你开启。它在没有打开任何浏览器时也能工作。它绝不适用于 Antigravity CLI 会话：Google 对其套餐的条款只允许由你自己发起的轮次，所以请在它的限制重置后发送一条消息。开启后，会话在被限制停止时不会显示警告：消息框上方的一行会说明是谁的限制被触发了（与通知一样）、是哪一项限制，以及“Continues by itself in …”，当账户持有重置时附带**使用一次重置**，另外还有**取消**。

无论使用该开关还是**重置时继续**，时间是这样安排的：

- 会话在限制重置一分钟后到期，以提供方最近一次报告的时间为准。会话等待期间，应用会不时读取用量，重置临近时更频繁，并且如果提供方改动了重置时间，应用也会随之调整。
- 如果限制提前解除（你使用了一次重置，或用另一个账户登录了），会话会立即继续。如果它在最近 15 分钟内已被提前继续、又再次触及限制，它就会改为等待重置。
- 只有真正被限制中断的轮次才会被继续，刚好在套餐用量达到 100% 时完成的轮次不会。当会话不靠它继续下去时，已计划的继续会被取消：你发送了消息或点击了**停止**，或者某一轮正常完成了。智能体在等待期间自己发起的轮次（当它自己的后台任务或子智能体在同一限制下停止时）不会取消它。用**停止**停下的会话绝不会自动继续，即使限制的错误先出现也一样，直到你给它发送消息。

当该智能体（Claude Code、Codex 或 Grok Build）有多个账户时，[**达到限额时切换账户**](/settings?s=accounts&find=Switch%20accounts%20at%20a%20limit)会让会话立即改用另一个账户继续，而不是等待，只有当所有账户都达到限制时才会等待（见[智能体、账户和模型](/guide/agents-models#use-all-your-accounts-switch-at-a-limit)）。对于 Claude Code，[**达到限额时使用 API 额度**](/settings?s=accounts&find=Use%20API%20credit%20at%20a%20limit)可以在那时让它继续，改为记在你保存的 Anthropic API 密钥上计费，而不是等待（见[当所有账户都达到限额时使用 API 额度](/guide/agents-models#use-api-credit-when-every-account-is-at-its-limit)）。

## 使用限额重置

有些套餐会给你限额重置：Codex 的重置额度和 Claude 的重置授权（Grok Build 没有）。使用一次重置，会立即清除套餐的用量限制，而不必等它们自行重置。

每张卡片都在**限额重置**下列出它们，并标明你有多少个。每个重置会显示它的名称（以及它还剩几次使用）、“Expires in …”（不到一天时用警告色）或“Does not expire”，以及诸如“Works once you hit a limit”或“Not usable yet”的说明。被另一项限制挡住的重置会说明是哪一项以及何时解除：“Blocked while your weekly limit is used up (usable in …)”。有些 Claude 重置只清除你部分额度，所以在你的每周限制用完时无法使用；它们会在重置后变得可用。没有重置时会显示：“No limit resets right now”，如果套餐提供了信息，还会说明下一个何时到来。应用大约每十分钟检查一次 Claude 账户的重置，因为 Anthropic 会拒绝更频繁的检查，并且在两次检查之间（即使应用重启后）显示它最近读取的列表。所以一个重置可能要过几分钟才显示为可用。你使用过的重置会立刻从列表中消失。

1. 点击某个重置旁边的**使用**，或点击限制通知上的**使用一次重置**（它会取列表中第一个现在可用的重置）。
2. 阅读确认信息。它会说明将使用哪个重置、它何时到期，以及还会剩下多少个。如果你并未达到限制，它会警告你（“You are not at a limit right now”）。
3. 点击**使用重置**。

应用会告诉你结果如何，例如“Codex usage limits are reset.”、“Claude is not at a usage limit right now, so nothing was reset.”、“Resets are cooling down. Try again later.”或“That reset was already used.”。成功后，正在等待限制的会话会立即继续。

Claude 的重置需要 Claude Code 使用 Claude 订阅登录（而不是 API 计费）。

## 查看智能体随时间做了什么

**活动**标签页（`/stats`）统计智能体做了什么，数据来自应用在这台电脑上已知的会话。

顶部有：

- **每日**、**每周**、**按月**或**每年**：数字统计的时间段，以及图表中每天、每周、每月或每年一根柱。页面会记住你的选择。
- **全部**，或某一个智能体：**Claude**、**Codex**、**Custom**，以及在这里做过事的其他智能体（Gemini CLI、OpenCode……）。
- 一个模型的标签，当你在下方的**按模型**中选了某个模型时：页面此时只统计该模型。点击该标签（它的 **✕**）可再次查看所有模型。
- **图表**或**表格**。

它们旁边的一行会写明图表和表格涵盖的范围（最近 30 天、最近 26 周、最近 12 个月或从你的历史开始，或每一年）以及你的时区。天、周和月都按你的时区计算，一周从周一开始。

它们下方是到目前为止的时间段，即**今天**、**本周**、**本月**或**今年**，并附有日期。各个磁贴显示它的总计：

- **新增行数**和**删除行数**
- **输入 token**（模型读取的内容：新的和缓存的）和**输出 token**（它们写出的内容）
- **输出速度**：回复被写出时每秒的 token 数
- **API 费用（估算）**：同样的 token 通过 API 会花多少钱
- **提示词**（附轮次数）、**会话**、**命令**（附工具调用次数）和**文件编辑**

磁贴上的小箭头会与前一个时间段比较，比到同一时间点为止：比如在周三 15:00，将本周与上周从周一到周三 15:00 比较；将今天与昨天截至同一小时比较。时间段名称旁边的那一行会这样说明（“compared with last week up to the same day and hour”）。它是中性的：更多并不意味着更好或更差。

**图表**显示修改的行数（新增向上、删除向下）、输入 token（新的和缓存的）、输出 token、输出速度，以及提示词、会话、命令和文件编辑的小图表，在整个范围内每天、每周、每月或每年一根柱；最后一根柱是到目前为止的时间段。**表格**按时间段列出同样的数字，最新的在最前，并附有整个范围的总计。

在下方，两种视图中都会再次显示到目前为止的时间段，按磁贴的统计口径：

- **按智能体**：按名称列出每个智能体（Claude Code、Codex、Custom、Gemini CLI 以及其他做过事的智能体），附会话、提示词、行数、输入和输出。
- **使用最多的项目**：修改行数最多的文件夹。
- **按模型**：每个模型的会话、提示词、输入、缓存输入、输出和 API 费用，Custom 的模型（OpenRouter、Ollama、vLLM……）与 Claude 和 Codex 的一样都会列出。点击某个模型，可查看只针对它的整个页面。没有已知价格的模型会显示**设置价格**。把鼠标悬停在某个模型上，可看到它每百万 token 的价格以及来源（“your price”或“public price table”）。

在手机上，磁贴每行放两个，表格中的一些列会被省略。

当智能体今天做过事之后，起始页会在消息框下方用一行总结今天：“Today · 7 sessions · 12 file edits · $0.84”，数值为零的部分会省略。其中的金额是当天的 **API 费用（估算）**：在套餐上（Claude Code、Codex）你支付的是套餐的费用，悬停提示中也这样说明。把鼠标悬停在这一行上，可看到新增和删除的行数、输入和输出 token，以及提示词；点击它可打开活动页面。

## 费用是如何估算的

Claude 和 ChatGPT 的套餐是固定费率的，因此应用会显示同样的工作按 API 价格（按用量付费的价格）需要花多少钱。这能让你了解套餐用得值不值，以及通过 API 使用某个模型要花多少钱。会话中每个完成的回合那一行也会显示同样的估算（“≈ $0.12”，其明细在**时间和费用**下），起始页的**今天**一行同样如此；如果你使用的是套餐，把鼠标指向它们时会有相应说明。

- 价格来自一份公开的价格表（LiteLLM 的），应用最多每天获取一次，并保存下来供离线时使用。
- 你自己设置的价格优先于价格表。
- 每个会话的 token 按其所用的模型计价；中途换过模型的会话，按最后使用的那个模型计价。
- 缓存的输入（模型之前读过、从缓存中提供的文本）按缓存价格计价；没有缓存价格时，按输入价格计价。
- 没有已知价格的模型（只有系列名称，例如“opus”，或价格表中未列出的模型）在总计中按 0 计算，并在“按模型”中显示 **set a price**。

OpenRouter 的模型使用从 OpenRouter 自动获取的价格，包括缓存输入价格，你无需自己填写。如果 OpenRouter 没有提供价格，**按模型**会显示一个短横线，而不是让你去设置价格。

花费上限使用同样的价格，但如果智能体自己报告了费用，就以它的数字为准：Claude Code 的费用，或 OpenRouter 给出的每次 Custom 调用的费用。本机上的模型在这里不计费用。

## 为模型设置你自己的价格

1. 在**活动**标签页中，点击**按模型**顶部的**模型价格**，或点击某个模型旁边的**设置价格**。
2. **模型价格**对话框会列出当前显示的模型，以及你之前设置过价格的模型。每个模型都有**输入**、**缓存**和**输出**三项，单位为每百万 token 的美元数。留空的字段会使用公开价格表中的价格，以灰色显示。
3. 输入你的价格。输入价格和输出价格都需要填写；缓存价格可以不填（此时按输入价格计费）。
4. 如果要为列表中没有的模型定价，请在**其他模型 ID**中输入它的 ID，然后点击**添加**。
5. 点击**保存价格**。

某一行上的垃圾桶图标（**使用价格表中的价格**）会清除你为该模型设置的价格。若要让本机上的模型按免费计算，请把它的输入价格和输出价格都设为 0。

## 每个会话都会保留

无论智能体自己的程序怎么做，应用都会保留每个会话及其数据。Claude Code 默认会在 30 天后删除它的对话，因此应用会告诉它保留这些对话（适用于每个设置中没有指定保留时长的 Claude Code 账户）；同时，应用会为 Claude Code 和 Codex 的每个对话文件保留自己的一个链接：如果智能体的程序（或任何人）删除了某个对话，它会恢复回来，照常列出并可以打开。这个链接就是同一个文件的另一个名字，因此不会占用额外的磁盘空间。

会被清理的是没人使用的内容：闲置一年的会话会被删除，除非你在[设置 → 通用 → 删除闲置会话](/settings?s=general&find=Delete%20inactive%20sessions)中更改这一设定（参见[删除闲置会话](/guide/app#delete-inactive-sessions)）。它们的数据仍保留在“活动”中。

在此之前、应用尚未保留时被 Claude Code 删除的对话无法恢复；“活动”的历史从应用第一次统计它们的时候开始。

## 限制会话的花费

花费上限会在会话按 API 价格花掉设定的金额后停止它，无论你使用哪种套餐。它启动的子智能体也会计入。

- 对于新会话：在起始页上，依次点击**选项** → **花费上限**。选择 $1、$5、$10 或 $25，或者输入一个金额并点击**设置**。**无上限**会取消上限。
- 对于正在运行的会话：会话的菜单（⋯）→ **会话设置** → **花费上限**。对话框会显示它目前已花的金额。输入上限（最低 $0.01），然后点击**设置上限**或**修改**；**取消上限**会将其取消。

设置了上限后，消息框上方会有一个条，显示“$1.20 of $5.00”，旁边有**修改**。达到上限时，智能体会在达到上限的那次模型调用之后立即停止，该回合下方会出现一条备注“Stopped at the spending cap”，新消息会等待，直到你提高上限（**提高上限…**）或取消上限。了解更多请参见[会话](/guide/sessions)。

## 竞技场标签页

**竞技场**标签页（`/arena`）会显示哪些模型在你自己的任务上表现最好。在起始页上，依次点击**选项** → **竞技场**，会把你的提示同时发送给另外一两个模型；你保留最好的回答。该标签页会根据你已裁定的对战，按评分（Elo 评分，起始为 1000）对模型排名，并显示每个模型被保留的频率和胜率，还会列出最近的对战，无论已裁定还是仍未结束。参见[深度研究、第二意见与多个智能体](/guide/research)。

## 我可以重置这些数据吗？

没有清除“活动”的按钮。你自己删除某个会话（其菜单 → **删除会话**）也会把它的数据从“活动”中移除；因闲置而被删除的会话则保留其数据。“限额”标签页上的限额是你的套餐自己的限额：它们按提供商的时间表重置，或通过[限额重置](#use-a-limit-reset)来重置。
