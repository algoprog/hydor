# 会话

会话就是你在一个文件夹里与一个智能体进行的一场对话：你说出想做的事，智能体去做，你在一旁跟进、批准它想做的操作，并引导它的方向。本主题涵盖会话的方方面面：开始页及其选项、智能体工作时你能看到的内容、在一轮进行中给它发消息，以及会话菜单里的所有功能，从分叉、目标到工作树和分享。

![一个正在工作的会话：智能体的步骤和回复，以及一张请求运行命令的卡片](images/sessions.webp)

## 开始一个会话

侧边栏顶部的**新建会话**会打开开始页。在消息框里写下你想做的事，看一眼它下面那一排选项，然后按 Enter（或点**开始**；在手机上点圆形箭头）。会话页面会立刻打开，显示你的消息和正在处理它的智能体（**工作中**）。如果会话无法开始，页面会说明原因，**返回开始页**会把你的消息（以及你附加的内容）放回消息框。

如果在应用回复之前连接断开了（比如手机进入了睡眠，或者网络切换了），页面会显示**正在重新连接…**，并在能连上时向应用询问你的消息结果：如果会话已经开始，就直接打开它；同一个会话不会开始两次。如果大约一分钟后仍然连不上应用，页面会显示**无法连接到应用**；点**重试**会再问一次。

会话开始后不久，它就会得到一个标题：用几个词概括你的请求（例如“周末去里斯本”“修复结账测试”），由辅助模型（[设置 → 智能体 → 模型](/settings?s=models&find=Helper%20model)）在一旁写出，对话里不会出现任何东西。侧边栏、会话的页头和搜索框都会显示这个标题（在侧边栏里，它的词会一个接一个地出现，取代你消息的开头），Claude Code 和 Codex 也会收到它，用在它们自己的列表里。在标题出来之前，或者辅助模型无法回答时，会先用你消息的开头代替。你自己用**重命名**给会话起的标题永远不会被替换。从你发送的那一刻起，侧边栏就会列出这个会话，放在**活跃**的最上面（**正在启动**）。

消息框下面那一排依次是**运行于**、**模型**、**文件夹**（或**项目**）、**智能体**，最后是**选项**。在手机上，它们都会以从屏幕底部弹出的面板打开。

### 选择智能体和模型

**运行于**会并排列出你能用的所有程序：

- **Claude Code**：Anthropic 的智能体，使用 Claude 套餐或 API 密钥。
- **Codex**：OpenAI 的智能体，使用 ChatGPT 套餐或 API 密钥。
- **Custom**：应用自带的智能体，可以使用任何模型：来自 OpenRouter、Ollama 或 vLLM 的都行。参见 [Custom，应用自己的智能体](/guide/custom)。
- 你添加的其他任何支持 ACP 的智能体（Gemini CLI、OpenCode、Qwen Code、Goose…），名称下方显示它的命令。

列表底部，**Custom 的模型**会打开[设置 → 模型](/settings?s=models)，**添加或管理智能体**会打开[设置 → 更多智能体](/settings?s=agents)。参见[智能体、账户和模型](/guide/agents-models)。

**模型**一开始是**自动**：会话从最佳档位的模型开始；如果你的请求看起来是个难题，则从最高档位的模型开始，它的主智能体会把明确的部分交给更便宜档位上的子智能体（见[档位：按任务类型选模型](/guide/agents-models#tiers-a-model-for-each-kind-of-job)）。在它下面，菜单只列出所选智能体自己的模型。智能体的默认模型标有“默认”。较旧的模型版本收在“2 个旧版模型”后面；列表较长时会有一个**搜索模型**输入框（按 Enter 选中第一个匹配项）。Custom 列出你在设置 → 模型中添加的模型；其他 ACP 智能体列出它上次运行时提供的模型，而且要等它运行过一次，这个按钮才会出现。

### 选择文件夹、项目或新建任务文件夹

**文件夹**按钮显示智能体在哪里工作。它的菜单（“工作所在的项目或文件夹”）顶部有一个输入框**查找文件夹，或输入它的路径**，下面是一个简短的列表：

- 你的项目，按名称列出（最近用过的三个，以及当前选中的那个）。选择一个项目后，会话会使用该项目自己的文件夹、智能体和准则；按钮随即显示为**项目**，并显示项目的名称。项目组也是一样，会带上组里所有的项目。参见[项目和知识库](/guide/projects)和[智能体准则](/guide/guidelines)。
- 当前使用的文件夹，以及你最近选过的三个文件夹；
- **新建任务文件夹**：为这个任务新建一个文件夹，用日期和你消息中的几个词命名（例如 `2026-11-01-plan-trip-lisbon`），放在 `~/Hydor` 中，除非你在[任务文件夹](/settings?s=assistants&find=Task%20folders)（设置 → 功能 → 你的智能体）里设了别的位置；
- **新建项目**：创建一个项目（把会话、文件和记忆放在一起）并选中它。

在输入框中输入，可以找到更多：

- 输入名称，会找到匹配的项目，以及在你最近用过的文件夹、当前文件夹和你的主文件夹中匹配的文件夹。
- 输入路径（`~/code/`，或从主文件夹算起的 `code/`）会列出那里的文件夹。
- 用 ↑ ↓ 和 Enter 选择。按 Tab，或点一行末尾的箭头，会列出它里面的文件夹。

当文件夹位于 git 仓库中（并且你没有选择新建任务文件夹）时，菜单最后有一个开关：**新建工作树 基于 main**（或当前检出的其他分支）。打开它后，会话会在一个新分支上的独立副本中工作；按钮上会显示“· 新建工作树”。参见[在工作树中工作](#work-in-a-worktree)。

会话是否默认使用新建任务文件夹，取决于智能体：大多数智能体会在新任务文件夹中开始，除非你选了一个文件夹；程序员则在你选择的文件夹中工作，只属于一个项目的智能体在那个项目中工作。

### 选择智能体

**智能体**决定会话以谁的身份工作：**通用**（第一次时）、**研究员**、**撰稿人**、**程序员**、**辅导老师**、**规划师**、**分析师**、**应用搭建师**，或者**你的**分组下你自己的某个智能体（在所有地方工作的，以及所选项目的）。把鼠标指向某个智能体，可以看到它做什么、用哪个程序和模型。选择它还可能同时设置它建议的程序、模型和权限（如果它用某个档位思考，则为该档位的模型），并打开它的已连接账户。**创建或修改智能体**会打开[智能体页面](/agents)。参见[智能体](/guide/agents)。

### 选项：思考强度、权限及更多

其余的都在**选项**里。它的按钮显示“选项”，或者列出你改动过的非默认设置，例如“高思考强度 · 计划 · $5.00 花费上限”。在电脑上，它的菜单最后有一行提示：在消息框中按 Shift+Tab 可以切换权限。

- **思考强度**：模型思考得有多深入。**默认**使用模型自己的默认值，后面是模型提供的各个级别：**低**（快速、轻量的推理）、**中等**（均衡）、**高**（更深入的推理）、**超高**（超深度推理）、**最高**（最强推理），某些模型还有**极低**、**无**或**极致**。Custom 和其他 ACP 智能体没有这一项，没有级别的模型也没有。
- **权限**：智能体不必先问你就能做哪些事。每个智能体都有自己的模式；参见[各权限模式的含义](#what-each-permissions-mode-means)。在消息框中按 Shift+Tab 会切换到下一个模式。
- **账户**：只有在你于[设置 → 智能体 → 账户](/settings?s=accounts&find=Accounts)中为 Claude Code 或 Codex 添加了其他账户后才会出现。**你的登录**是智能体自己的账户；选另一个账户，就会以它的身份运行这个会话。**管理账户**会打开设置。
- **保密**：一个带锁的开关（“只用这台电脑上的模型。任何内容都不会离开这台电脑。”），适合你要审的论文、患者数据或客户的代码。打开后，**运行于**会变成 **Custom**，**模型**会变成这里装好的最好的模型。参见[让会话保密](#keep-a-session-confidential)。
- **记忆**：只有在设置中开启了记忆时才会出现。**开启**会使用并补充智能体记住的内容；**本会话已关闭**则从零开始，也不会从这个会话中保留任何内容。参见[记忆](/guide/memory)。
- **花费上限**：这个会话按 API 价格计算最多能花多少钱。输入金额后按**设置**，或者选 $1、$5、$10 或 $25；**无上限**会取消上限。会话达到上限时会停下，直到你提高上限。参见[用量、限额和费用](/guide/usage)。
- **集群**：**关闭**；**集群**：由一个主导智能体把任务拆成几个切入角度，为每个角度启动一个成员，同时工作的成员数量以**集群规模**为上限（[设置 → 功能 → 子智能体](/settings?s=children&find=Swarm%20size)）。成员们在一块公告板上分享各自的发现，并互相发消息。适合难题；花费是单个智能体的好几倍。或者**战役**（“把一项大改动拆成几部分，各在一个工作树中完成”）：主导智能体把一项大改动拆成几个部分，每个成员在自己的分支上完成其中一部分并运行它的测试，再由主导智能体把它们合并；文件夹必须是 git 仓库（参见[战役](/guide/engineering#campaigns-a-big-change-in-many-parts)）。
- **研究**：**关闭**，或**深度研究**：智能体规划要做的搜索，为每个部分派出研究员，用两个来源核对关键说法，最后交付一份附有引用的报告。可以设置**同时进行的研究员数**（1 到 8）、**轮数**（1 到 5）、**总搜索次数**（10 到 500）和**报告**（**网页**或 **Word**）。
- **竞技场**：**关闭**，或**比较模型**：同一条消息还会发给你勾选的另外一两个模型（列表较长时可以用**查找模型**输入框），每个模型在同一文件夹里各开一个会话。你比较这些回答，留下最好的；其余的会被归档。在 git 仓库中，请打开文件夹菜单里的**新建工作树**，让每个模型在自己的副本上工作。

集群（或战役）和深度研究都会带领 Hydor 子智能体，所以打开其中一个会关闭另一个。**保密**会关闭集群、深度研究和竞技场，而打开它们中的任何一个也会关闭保密。集群、深度研究和竞技场花费更高，因此不会保留到下一个会话；你选的研究参数和竞技场模型会保存在这个浏览器里，下次再打开时沿用。参见[深度研究、第二意见和多个智能体](/guide/research)。

### 各权限模式的含义

**Claude Code**

| 模式 | 智能体可以做什么 |
| --- | --- |
| 询问（默认） | 进行编辑、运行其设置中未允许的命令之前先询问 |
| 接受编辑 | 可以随意编辑文件，运行其他命令前先询问 |
| 自动 | 由安全检查批准常规操作，遇到有风险的操作再问你 |
| 计划 | 只读取和规划，然后提出计划供你批准 |
| 绕过 | 从不询问（完全访问） |

**Codex**

| 模式 | 智能体可以做什么 |
| --- | --- |
| 计划 | 先讨论和规划；可以向你提出澄清问题 |
| 只读 | 读取文件并回答；更改任何内容前先询问 |
| 自动（默认） | 在自己的文件夹中编辑文件和运行命令；要超出这个范围时先询问 |
| 自动审查 | 与自动相同，但由一个审查智能体来回答它的批准请求 |
| 完全访问 | 没有沙盒，也无需批准 |

在 Docker 中，Codex 自己的沙盒无法启动，所以那里默认使用**完全访问**，菜单中也会说明原因。

**Custom**

| 模式 | 智能体可以做什么 |
| --- | --- |
| 询问（默认） | 编辑文件和运行命令前先询问；四处查看则不受限制 |
| 接受编辑 | 可以随意编辑文件夹中的文件，运行命令前先询问 |
| 自动 | 常规步骤直接进行；快速检查会就有风险的步骤询问你 |
| 完全访问 | 工具和命令无需批准或命令沙盒，使用你的电脑账户权限 |
| 计划 | 只读取和规划：不编辑，不运行命令 |

除完全访问外，Custom 会在运行有风险的命令前询问你。在询问、接受编辑和计划模式下，它在读取或更改文件夹以外的文件、或含有密钥或密码的文件之前也会询问；在自动模式下，则先由快速检查来判断这些情况。参见 [Custom，应用自己的智能体](/guide/custom)。

**其他 ACP 智能体**提供它们自己的模式，在智能体运行过一次后列出。

### 让会话保密

有些工作绝不能离开你的电脑：别人请你审的论文（大多数会议和期刊都禁止把投稿交给在线 AI）、患者或客户的记录，或者你按协议为某家公司处理的代码。保密会话使用这台电脑上的模型运行，它的任何内容都不会被发送到任何地方。

1. 在开始页上打开**选项**，开启**保密**（“只用这台电脑上的模型。任何内容都不会离开这台电脑。”）。之后选项按钮上会显示“保密”。
2. **运行于**会变成 **Custom**，**模型**会变成这里装好的最好的模型；保密开启期间，它们的菜单只提供这些选项。如果这里还没有模型，它会告诉你：[设置 → 智能体 → 模型](/settings?s=models)可以一键安装推荐给这台电脑的模型。
3. 写下你想做的事，附上论文或选择它所在的文件夹，然后按 Enter。例如：“以 NeurIPS 审稿人的身份审阅附件中的投稿：摘要、优点、缺点、给作者的问题，以及评分。”

“这台电脑上的模型”是指这里的 Ollama 和 vLLM 的模型，以及地址在这台电脑或你的私有网络中的端点：`localhost`、`127.0.0.1`、`::1`、`10.…`、`192.168.…`、`172.16.…` 到 `172.31.…`，或者以 `.local` 结尾的名称（参见[连接 Ollama、vLLM 或其他端点](/guide/agents-models#connect-ollama-vllm-or-another-endpoint)）。Ollama 的云端模型（名称以“cloud”结尾）在 ollama.com 上运行，不算在内。开始页会为你之后的会话保持这个开关开启，直到你把它关掉。

保密会话的标题旁边有一把锁，在页头和侧边栏中都有；它的消息框带一圈柔和的绿色边框；消息框上方有一行文字说明这意味着什么，直到你把它关掉。点击这把锁，可以看到哪些功能开启、哪些关闭。

- **关闭**：网页搜索和网页、浏览器和你的屏幕、已连接的应用和你的密钥、应用、发布、定时任务、生成、查找或编辑图片、绘图、数据图、视频或声音、其他地方的模型（深度研究、集群和竞技场；[第二意见](/guide/research)只能来自这台电脑上另一家公司的模型）、把对话交给另一个智能体、往记忆里保存任何内容，以及把页面导出为文件（请自己从资料库导出）。
- **命令断网运行**：在每种权限模式下，智能体的命令都在与网络隔绝的状态下运行，所以无法下载、从网上安装、推送或发送任何东西。在做不到这一点的地方（Mac、Windows、某些容器），无论什么模式，每条命令都会先征求你的同意，锁的说明里也会写明。
- **仍然开启**：文件夹中的文件、文档（在这台电脑上读取）、资料库、共享知识、你的记忆笔记和档案（只读，从不添加）、Hydor 子智能体（它们同样是保密的），以及回答卡片（不含来自网络的图片和地图）。
- **不对外发送任何相关内容**：辅助模型在这台电脑上运行时，标题由它生成，否则取自你消息开头的几个字；通知只写“一个保密会话”，以及它已完成、需要你处理还是失败了；它没有只读链接，不能从它的菜单创建拉取请求，也不能用它做成自动化或应用；其他会话中的智能体和别处的智能体都读不到它；它的回复不显示来自网络的图片，它展示的页面也不会从任何地方加载内容（所以需要从网上加载库的图表画不出来）；听写只能使用这台电脑上的语音识别（[设置 → 功能 → 语音](/settings?s=voice)），朗读回复也只能使用你设备上的语音。
- **它会一直保密**：分叉和**从这里编辑**得到的会话同样是保密的，而且保密无法关闭，所以说过的内容会留在原处。如果工作内容可以离开这台电脑，请开始一个新会话。

它无法保证的事：Hydor 检查的是模型的服务器在哪里，而不是那台服务器做什么，所以你在自己网络上设置的、会把请求转发给在线服务的端点，照样算是在线的。你从会话里复制出去的内容，或者你自己从别处打开或发送的东西（回复中的链接、从资料库打开的它生成的页面、从 Git 页面进行的推送），要由你自己留意；你在另一台设备上阅读它时也是如此：应用的页面会像往常一样传到那台设备上（如果你使用隧道，就经过你的隧道）。

### 附加文件、引用文件、使用命令

- 用**附加文件**（消息框底部一行最左边的 **+**）、把文件拖到消息框上，或者把图片和文件粘贴进去。一条消息最多可带 25 MB 的文件。图片（PNG、JPEG、GIF、WebP）会作为图像发给模型，每条消息最多 8 张；其他文件（最多 20 个）会保存在这台电脑上，并列在你消息的末尾，供智能体打开。发送前可以点某个文件的 × 把它移除。已附加的文件会一直留在消息框里，直到你发送为止，即使你去了别的页面也一样（重新加载页面会清除它们）。
- **附加截图**（在同一个 **+** 菜单里，仅限电脑；浏览器不能截图时，**+** 就是一个回形针，用来附加文件）：浏览器会问你要截哪个屏幕、窗口或标签页，然后附上一张它的截图。
- **@**：输入 @ 和文件名的一部分，会列出文件夹中匹配的文件；用 ↑ ↓ 移动，按 Enter 或 Tab 插入，按 Esc 关闭。
- **/**：在消息的最开头输入 /，会列出智能体的命令和技能（Claude Code 的），并说明各自的作用。
- 当你的浏览器或这台电脑能够识别语音时，发送按钮旁边会有麦克风（听写你的消息）和耳机（免手动语音模式）。参见[文档、图片、视频和语音](/guide/documents-voice)。

### 开始页会记住什么

开始页打开时会沿用你上次的选择，在每台设备上都一样：程序；每个程序各自的模型、思考强度、权限和账户；文件夹、新建任务文件夹或项目；工作树开关；智能体；关闭记忆；花费上限；以及保密。选择一个程序时，会恢复你上次用它时的设置。

指向开始页的链接可以预先填好内容，例如 `/?prompt=Summarize%20my%20notes&agent=codex`；还可以加上 `model=`、`cwd=`（文件夹路径）和 `confidential=1`（开启保密）。它只会填写消息框和各项选择，绝不会自己启动任何东西。通过链接带来的消息中如有不可见字符，会被移除，并给出提示。

你在消息框里写的内容，在你去别的页面时会一直留在那里：消息、附加的文件、仅针对这个任务的选项（**集群**、**深度研究**、**竞技场**、仅本会话的**准则**），以及链接或**在这里新建智能体会话**打开它时带来的文件夹。会话开始后，消息框就会清空：在智能体启动期间，**开始**上的箭头会不断向上移动；随后开始页变成会话，消息框移到底部它的位置，你写的内容向上移动，成为你的第一条消息。消息和这些选项保存在这个浏览器中，所以重新加载页面后也还在；附加的文件则不会保留。

## 跟进会话中的工作

### 页头

会话顶部有：

- 智能体的图标和标题（双击可重命名），[保密会话](#keep-a-session-confidential)还有一把锁；
- 状态：**工作中**、**需要你处理**、**就绪**、**正在启动**、**正在停止**、**已停止**，在别处运行的会话则显示“已在 VS Code 中打开”；
- 文件夹（点击可在“文件”中浏览）、拉取请求标记、以添加的账户运行时显示该账户，在较宽的屏幕上还有 git 分支和模型；
- 一个按钮，对应你此刻能做的事：一轮正在进行时是**停止**，智能体已停止时是**继续**，Claude Code 会话在 VS Code 或终端中打开时是**在这里继续**；
- **详情**（文件有改动后会显示新增和删除的行数），它会打开[详情面板](#the-details-panel-changes-commands-and-info)；
- 会话菜单（⋯）：参见[会话菜单中的所有选项](#everything-in-the-sessions-menu)。

### 轮次、步骤和回复

对话读起来就像聊天。每一轮包括你的消息、智能体的工作，以及它最后给出的回复：

- **你的消息**显示在右侧，连同其中的图片和附件。较长的消息会折叠到只显示前几行；点**显示更多**可以展开。
- **工作过程**放在一行概括文字下面：“工作了 2m 10s · 3 条命令”、“已思考”、“40s 后停止”或“5s 后失败”，右侧是用掉的 token 数：点它可以查看这一轮的[时间和费用](/guide/sessions#a-turns-time-and-cost)。这一轮进行时，这行会显示“工作中 · 1m 2s”（或“等你处理”），工作大纲会随着进展实时增长；如果之前已有几轮，还会加上这个会话所有轮次合计工作了多久：“工作中 · 1m 2s (47m)”。一轮结束后，工作过程会折叠起来；点这一行可以展开。
- **工作大纲**：智能体在步骤之间写下的每条说明（它发现了什么、接下来做什么）都会开始一个部分，之后它做的步骤都归在这个部分里。完成的部分只占一行，带一个勾：用几个词概括那条说明（“先运行结账测试，看看哪里失败”、“先打折，最后统一四舍五入”），以及用了几个步骤、改动了多少行。点击它可以看到完整的说明和每个步骤。正在进行的部分会完整显示智能体的说明，下面是正在执行的步骤，比如“正在编辑 total.ts · 4 s”；点那一行可以看到这个部分到目前为止的步骤。智能体写第一条说明之前做的步骤会成为一个部分，以它们做了什么命名（“运行了 3 条命令，读了 2 个文件”）。很长的一轮只显示最新的几个部分；点**显示更早的 12 个部分**可以看到其余的。
- **步骤**用平实的话命名：“运行测试”、“读取 index.ts”、“已搜索网络”，命令本身用较淡的字体显示。点击一个步骤可以看到它做了什么。
- **思考**显示为“思考了 12s”，并附上它的第一个标题；点击即可阅读。
- **回复**是智能体在最后一个步骤之后写的内容。智能体展示的页面也和回复放在一起。智能体工作时，它在最后一个步骤之后写的简短说明会作为正在进行的部分显示在大纲里；如果这一轮就此结束，它就成为回复。
- **改动的文件**：回复下方有一张卡片，列出这一轮改动的每个文件，以及新增和删除的行数。点击文件可查看它的差异；**打开文件**会打开它。超过五个时，多出的会折叠在“再显示 3 个文件”后面。
- **提交**：智能体在这一轮里做了提交时，回复下方会有一个小标签：**已提交** · 提交的标题，或“3 个提交”和所在分支，以及新增和删除的行数。点击它（有多个时再点一个提交），可以看到完整的提交说明、提交人和时间、哈希（点击可复制），以及它改动的每个文件和差异。**在 Git 中打开**会在 [Git 页面](/git)上打开会话所在仓库里的这个提交。智能体在同一轮里修改（amend）或变基掉的提交不会列出。

智能体还可能维护一份清单（**计划**或**待办事项**，并显示完成了几项），随着工作推进逐项勾掉。应用给出的说明会跟在相关的那一轮后面：记忆保存了什么、第二意见、达到花费上限、Hydor 子智能体的卡片。来自其他会话的消息显示为“来自 …”，Hydor 子智能体的回复显示为“回复来自 …”（点击即可阅读回复），定时任务的每次运行都以一行写有任务名称的文字开头。

日期分隔线（“昨天”、“今天”）把不同的日子隔开；全部在今天的对话没有分隔线。向上滚动时，或点**显示更早的消息**，会加载更早的消息。新的消息和回复出现在对话末尾，下方不会留出空白。回复长到能占满屏幕时，视图会停在它的第一行，并在它变长时保持在那里，让你从开头读长回复；短回复则直接接在前面的内容下方。智能体工作时如果你向上滚动，视图会停在你所在的位置；点**最新**可以回到末尾，回复延伸到屏幕下方时也会显示这个按钮。

把鼠标悬停在回复上，会出现**从这条回复分叉**（Claude Code 和 Custom）、**朗读**和**复制消息**。悬停在你自己的消息上，会出现**从这里编辑**和发送时间。

### 一轮的时间和费用

已结束的一轮，概括行右侧的 token 数可以打开**时间和费用**，看看一轮为什么用了很久或花了很多钱：

- **时长**：一条显示这一轮时间花在哪里的条，每一部分都有占比和时长：**模型**（阅读收到的内容、思考和写作）、**命令**、**读取和编辑文件**、**网页**、**其他步骤**（子智能体、已连接应用的工具）、**等你处理**（批准、问题和表单，从每张卡片出现到你回答为止）和**其余**（启动，以及步骤之间）。同时进行的步骤只算一次。下面是“3 s 后给出第一个回复或步骤”：智能体多快开始工作。
- **Token**：**新读取**；**写入缓存**（新读取并由模型的提供方保存下来，下一次请求读取时更便宜）；**从缓存读取**，以及它在全部读取中所占的比例；还有**写出**（回复、思考和步骤）。
- **费用**：这一轮的费用；知道模型价格时，还有每一类的费用，并显示“缓存大约节省了 $0.80。”。不知道模型的价格时，会说明不计算它的费用。

Claude Code 的轮次会给出模型自己的时间和第一个回复；对于其他智能体，模型这一部分是它的思考。token 数和这个面板在较宽的屏幕上显示。

### 回复中的数学公式、示意图、插图和图片

智能体是为这个应用写回复的，而不是为终端写的，所以一条回复里可以不只有文字。每个智能体都知道怎么做，并会在能让回答更清楚的地方自己用上：

- **排版**：标题、列表、表格、粗体和代码，排得便于阅读。
- **数学公式**：公式像教科书里那样画出来，可以嵌在句子里，也可以单独占一行；化学方程式也一样（2H₂ + O₂ → 2H₂O）。成对美元符号之间的数字（`$1$`、`$0$`）也按数学公式显示；$4.70 这样的普通价格仍然表示金额。
- **示意图**：流程图、时序图和状态图、时间线、思维导图、甘特图和饼图，用应用自己的颜色画出来，浅色或深色都跟着应用。示意图上方的工具栏有**显示代码**（智能体写的内容；同一个按钮可以切回示意图）、**另存为图片（SVG）**、**全屏**，以及一个复制代码的按钮。画不出来的示意图会显示它的代码和原因。
- **插图和小工具**：图表、带标注的插图、计算器、带滑块的模拟或简短的小测验，会直接在回复里运行，和智能体展示的页面一样与应用和你的文件隔开。它使用应用的外观，并随内容调整高度（很高的可以点**查看全部**打开）；它的工具栏有**显示代码**（**显示效果**可以切回）、**另存为文件**和**全屏**。你在上面点选的选项会进入你的消息框。回复还在写的时候，它会在原处逐步出现（在有内容可显示之前显示“正在撰写…”），写完后才开始运行。
- **图片**：来自网络的照片（一个地方、一件商品、一种植物、一件艺术品）和这台电脑上的图片，按回复的宽度显示；点击可以放大查看，那里的**编辑**会在图片编辑器中打开它（[编辑图片和视频](/guide/library#edit-pictures-and-videos)）。网络上的图片经由这个应用的服务器取来，所以存放图片的网站看不到你的浏览器。加载不了的图片会显示为指向它的链接。

如果你只想要纯文字，可以在[智能体准则](/guide/guidelines)里写明（“只用纯文字回答，不要示意图或图片”），或者在消息里说。你也可以用平常的话要求这些：“把步骤画成流程图”、“给我看一张它的图片”、“给我一个滑块，试试别的数值”。

### 回答卡片：回复中的卡片、图表和地图

当一个回答更适合去看、去比较或去使用，而不是去读时，智能体可以用应用的一种回答卡片来展示它：一百多种现成的卡片、表格、图表、地图、图库、时间线和小工具，填入回答本身的内容。要比较的选项会变成一张表，每行的最佳值都有标记；菜谱会变成一张卡片，改变份数时用量随之变化；天气预报显示接下来的几小时和几天；地点显示在带编号图钉的地图上；测验则是可以当场作答的题目。每一种都随着回复的到来逐步呈现，采用应用的外观，浅色或深色皆可。

- **可以做什么**：给表格排序和筛选，把图表切换成数字，勾选清单，启动菜谱的计时器，翻转抽认卡，配对或填空，回答排障向导的问题，转动转盘替你做选择，拖动计算器或函数图像的滑块，播放视频。在这台设备上回到对话时，你勾选或回答的内容仍然保留。有些卡片会把文字放进你的消息框，由你来发送：你选中的选项、你的测验得分。
- **悬停时**：**显示数据**会显示智能体写下的内容（**显示效果**可以返回），**复制为文本**会把它复制为纯文本。
- **智能体何时使用**：只在能让回答更清楚的地方使用；聊天、简短回答、解释和代码修改仍然是文字。每个回答，无论是第一个还是之后的任何一个，都可以有多张卡片，每个部分一张（一次旅行的行程、天气和行李清单），因此一段对话中的卡片数量按回答所需而定；之后的回答可以用更新后的数据再次展示某一张。智能体用几个词描述它的回答要展示什么，以此查找合适的卡片（按词语，并且在[设置 → 记忆](/settings?s=memory)中开启**按含义搜索**时也按含义），所以永远不会把所有卡片都交给它。
- **查看全部**：[回答卡片](/answers)页面按分组展示每一种卡片及其示例：摘要、比较、购物、地点和旅行、饮食、计划、工作与商务、数字和图表、金钱、学习、科学、媒体、人物和体育、写作，以及代码。**播放生成过程**会展示一张卡片像在回复中那样逐步出现。

也可以用平常的话要求使用：“把它们放进表格里比较”“把它们标在地图上”“就这个内容考考我”。你的[智能体准则](/guide/guidelines)可以要求改用纯文本。

### 打开步骤查看输出

点击任意步骤即可打开：

- 命令：命令本身、运行所在的文件夹、退出码和耗时、一个复制按钮，以及它的输出（输出被截断时有**加载完整输出**）；
- 文件编辑：差异（被截断时有**加载完整差异**）；
- 文件读取：指向该文件的链接，以及读取的内容；
- 网页：它的地址，以及从中读到的内容；
- 交给子智能体的任务：**布置的任务**，以及返回的结果；
- 其他任何步骤：智能体发出了什么、返回了什么。

步骤可能带有**后台**标记（它会继续运行）、**自动**标记（由 Custom 的自动模式做出决定，悬停可看到原因），或显示红色的退出码。后台任务（仍在运行的命令、监控、工作流）会和会话的子智能体一起列在消息框上方的一行里；打开某个任务可查看它的输出（Claude Code），也可以**停止**它，停止前会先确认。参见[子智能体](/guide/sessions#subagents)。

## 批准或拒绝智能体想做的事

当智能体想做一件它的权限不允许它独自完成的事时，它会停下来，在对话末尾用一张卡片询问你：它想运行什么、某个文件改动及其差异，或者其他工具及其详情，并显示它已经等了多久。会话的圆点会变成琥珀色，收件箱会把它计入，如果你开启了通知，还会收到通知。你可以在卡片上、在[收件箱](/guide/inbox)里回答；如果只是简单的是或否，在浏览器显示按钮的情况下，也可以直接在通知上回答。

按钮由智能体提供：

- **Claude Code**：**允许**、**拒绝**，通常还有一条规则，例如“始终允许 Bash npm test”或“本会话中允许所有编辑”。
- **Codex**：**允许**、**在此会话中允许**、**始终允许此命令**、**拒绝**、**拒绝并停止**；文件改动时有**本会话中允许编辑**；需要更大权限时有**本轮允许**和**在此会话中允许**。
- **Custom**：**允许**、**始终允许**（后面写明它具体涵盖什么：只限你批准的那条命令，不会有别的东西夹带在后面），以及**驳回**。
- 其他智能体：它们自己提供的选项。

**拒绝**会先打开一个输入框“可选：告诉智能体改做什么”；再按一次**拒绝**即可发送，写不写说明都可以。（Custom 的**驳回**和 Codex 的**拒绝并停止**会立即生效。）

在 Claude Code 的**自动**模式下，安全检查可能会直接拒绝一条命令，而不是询问你。这时消息框上方会出现一张卡片，写着“Claude 拦截了一条命令”以及原因。**批准并重试**会把会话切换到询问模式并让智能体再运行一次，于是它会作为普通的批准请求回到你这里；**关闭**则不做处理。

## 回答问题和批准计划

当智能体问你问题时，会出现一张琥珀色边框的卡片，列出问题和可选项：

- 选一个选项；标有“可多选”的可以选多个。**其他——输入你自己的答案**可以用你自己的话回答。
- **附加文件**可以在回答中附上文件。
- 按键 1 到 9 会为第一个尚未回答的问题选择对应的选项。
- **发送回答**会把答案作为你的下一条消息发出。如果会话在提问时停止了，**继续并回答**会带着你的回答重新启动它。对于在 VS Code 或终端中等待的 Claude Code 会话，**在此回答**会在那边结束它，并带着你的回答在这里继续；而在那边的 Codex 会话只能在那边回答。

如果问题以批准卡片的形式出现，它的按钮是**发送回答**，Claude Code 还有**跳过**。

**计划**。在 Claude Code 的**计划**模式下，智能体先读取和规划，然后在卡片中展示它的计划：**批准，自动接受编辑**（直接开始，编辑时不再询问）、**批准，编辑前询问**，或**继续规划**（它会留在计划模式；告诉它要改什么）。在 Codex 的计划模式下，Codex 会先讨论和规划，并可能向你提出澄清问题。Custom 的计划模式最后会给出一份编号的计划；切换权限（Shift+Tab）并回复，它就会去执行。

## 填写服务要求的表单

当你连接的某个服务在任务进行到一半时需要你提供一些东西（一个日期、一个选择、一个需要你去批准的页面），无论是哪个智能体在工作，它的表单都会以卡片形式出现：“Linear 请你填写一个表单”、“… 请你打开一个页面”或“… 请求继续”。填好字段后按**发送**（或按**打开**来打开那个页面，或按**允许**），也可以按**拒绝**或**暂不**。Codex 自己的工具服务器也用同样的方式询问。参见[已连接的应用、密钥和工具](/guide/connections)。

## 在智能体工作时给它发消息

一轮进行时你也可以打字。这时按 Enter 会怎样，由[设置 → 应用 → 通用](/settings?s=general&find=Sending%20while%20an%20agent%20works)中的**智能体工作时发送**决定，每个浏览器分别设置：

- **加入本轮**（默认）：按 Enter 会把你的消息加入正在进行的这一轮，智能体会马上考虑它。按 Ctrl+Enter（Mac 上是 ⌘Enter）则会把它放进队列。
- **等它结束**：按 Enter 会把你的消息放进队列，等这一轮结束时再发出。按 Ctrl+Enter 则会把它加入这一轮。

消息框会提示是哪一种：“在进行中的这一轮里追加一条消息”或“把消息排进队列，等这一轮结束时发送”。在触摸屏上，发送按钮的作用与 Enter 相同。Custom 会在正在运行的工具完成后，于下一次模型调用时接收追加消息；排队消息的**立即发送**也同样生效。如果 Custom 会话在应用更新前就已运行，尚不支持实时追加消息，你的消息会留在队列中，等本轮结束后发送。其他 ACP 智能体一次只接收一条消息，所以在它们工作时发出的消息总会在队列中等待。在 Claude Code 中，智能体工作期间发进去的消息下方会显示“工作期间发送”。

## 管理队列

排队的消息在消息框上方等待，按发出的顺序编号。每当一轮结束，就会自动发出一条。

- 拖动消息的把手可以调整顺序。
- **立即发送**（箭头）：马上把它发出，插入进行中的这一轮。
- **编辑**（铅笔）：修改文字、去掉附件或添加更多附件（用**附加**，或粘贴、拖入文件）。按 Enter 保存，按 Esc 取消。
- **移除**（垃圾桶）：把它移出队列；它的附件会被删除。
- 当你停止智能体，或应用重启时，队列会暂停：“队列已暂停（智能体被停止了，或服务器重启了）。”点**继续**后，等智能体空闲下来，消息就会继续发出。达到花费上限也会让队列暂停；提高上限后队列就会继续。

## 更改智能体、模型、思考强度或权限

会话的消息框里有开始页的**智能体**，以及和开始页一样的三个选择：**模型**、**思考强度**和**权限**，合在 **+** 旁边的一个按钮里（点开是**选项**，在手机上从底部弹出）。按钮上写着智能体和模型，以及与平常不同的思考强度和权限；当智能体可以不经询问做任何事时（**绕过**，或 Codex 的**完全访问**），它会变成琥珀色。换成另一个智能体会从你的下一条消息起生效（见[在会话中切换智能体](/guide/agents#switch-agents-in-a-session)）。更改模型、思考强度或权限会立即作用于正在运行的智能体，并一直保留在这个会话中。按 Shift+Tab 会切换到下一个权限模式。模型菜单只列出这个智能体的模型；要把对话转给另一个智能体，请使用[转到另一个智能体继续](#continue-in-another-agent)。

## 引用回复的一部分

在智能体的某条回复或你自己的某条消息中选中文字：上方会出现一个**引用**按钮（在触摸屏上则在下方）。它会把这段文字作为引用放进消息框，光标停在引用之后，方便你针对这部分作答，或重提你之前说过的话。

## 在会话中查找文字

在会话中按 Ctrl+F（⌘F）。**在此会话中查找**会搜索你和智能体的消息，包括尚未加载的部分（不包括命令输出）。输入至少两个字符；它会跳到最新的匹配处并高亮这些文字，同时显示“3 / 12”。按 Enter 跳到更早的匹配，按 Shift+Enter 跳到更新的匹配（也可以用箭头），按 Esc 关闭。折叠起来的长消息会在找到的位置展开。在搜索框（Ctrl+K）中选中一条消息时，会打开它所在的会话，并且这个查找栏已经填好。

## 消息框的更多用法

- 在空的消息框中按 ↑，会调出你在这个会话中发过的消息，从最新的开始；按 ↓ 往回翻。
- 你输入的内容会按会话分别保存为草稿（保存在这个浏览器中），所以你回来时它还在。
- 按 Ctrl+S（⌘S）会把草稿暂存起来并清空消息框；在空的消息框中再按 Ctrl+S 会把它恢复。
- 粘贴非常长的内容（32,000 个字符或更多）时，它会作为文本文件附加，而不是填满消息框。
- 占位文字会告诉你发送后会发生什么：“给 Claude 发消息…”，或在智能体停止时显示“发消息以继续这个会话…”。

## 详情面板：更改、命令和信息

页头中的**详情**会打开一个有三个标签页的面板。在宽屏上，它位于对话旁边，你在会话之间切换时它会一直开着；在较窄的屏幕上，它会滑出覆盖在页面上；在手机上，只有你要求时才会打开。

- **更改**：这个会话改动过的每个文件，改动最多的排在前面，并显示新增和删除的行数。点击文件可查看每次编辑的差异；**打开**会打开该文件。
- **命令**：智能体运行过的每条 shell 命令，最新的在前，可按**全部**、**失败**和**后台**筛选。点击某条命令可查看它的输出。
- **信息**：智能体、状态、文件夹、分支、模型和思考强度、上下文用了多少、开始时间和最后活跃时间、它的活动（提示、轮次、工具调用、命令）、token 数（输入、缓存、输出）、API 费用（同样的工作按 API 价格要花多少）、输出速度，它是从哪里启动的（Hydor、VS Code、终端、Claude 桌面版…），以及智能体运行时的**它的程序**：它们此刻的使用情况（CPU、内存和数量），以及它运行时受的[上限](/guide/app#limit-each-session)。下方是它的后台任务（打开某个任务可查看它做了什么，或**停止**它），以及**在终端中继续**：在终端中恢复这个会话的命令和会话 ID，各带一个复制按钮（Claude Code 和 Codex）。

## 看懂指标：上下文、缓存和速度

麦克风旁边有一个带百分比的小圆环，随着对话占用模型的上下文窗口而填满；其余指标在“选项”按钮菜单的底部：

- **上下文**：那个圆环，以及“选项”里的**上下文**一行（“已使用 42%”）。把指针移到圆环上可以看到确切的 token 数。超过 85% 时会变成琥珀色。点击圆环或“选项”里的**压缩**可以压缩对话（一轮进行时不行）。
- **缓存 4m**（Claude Code）：提示缓存会让对话在一段时间内（5 分钟或 1 小时）保持就绪，这样下一条消息更便宜、更快。你不发消息时它会倒计时；在此之前发出的消息会重用缓存，并重新开始计时。**缓存已过期**表示下一条消息会重新建立缓存。
- **85 tok/s**：上一条回复的生成速度，单位是每秒 token 数。

## 停止一轮、停止智能体或继续

智能体启动或工作时，消息框旁的停止按钮会显示旋转圆环。需要你处理时圆环暂停；设备设置为减少动态效果时，圆环保持静止。这一轮结束后，只要智能体启动的后台任务或子智能体仍在运行（例如 Hydor 子智能体、Claude Code 子智能体、仍在运行的命令或监控），停止按钮就会带着圆环继续显示，发送按钮在它旁边；消息框照常接收你的消息。把指针移到停止按钮上，可以看到它会停止什么：“会停止当前这一轮、2 个子智能体和 1 个后台任务”，或“会停止 2 个子智能体”。它会一次停止所有这些：这一轮、每个仍在运行的子智能体、每个仍在运行的后台任务，以及它们各自启动的会话。这样停止的 Hydor 子智能体不会向父会话回报；已经在路上的回报会留在父会话暂停的队列里，不会唤醒它；按**继续**即可让队列继续。

- **停止一轮**：按页头中的**停止**，或消息框旁的圆形方块按钮，它也会停止这个会话启动的内容（见上）。（Esc 不会停止它：它只关闭打开着的东西，比如查找栏或列表。）智能体会停下正在做的事；这一轮会显示“…后停止”。智能体仍然随时可以接收你的下一条消息，而队列会暂停，直到你让它继续。
- **停止智能体进程**：在没有一轮正在进行时，选择会话菜单（⋯）→ **更多** → **停止智能体进程**。智能体的程序会结束；会话及其历史记录都会保留，并显示**已停止**。
- **继续**：页头中的**继续**会带着完整的对话重新启动智能体，你也可以直接发一条消息（“发消息以继续这个会话…”）。如果这个会话在几秒钟前刚被写入过（可能来自 VS Code 或终端），应用会先询问你，因为两个程序同时写一个会话可能会损坏它的历史记录。
- 闲置的智能体在三小时后会自行停止（前提是没有等你处理的事，也没有正在运行的后台任务）；你的下一条消息会再次启动它。

## 给会话设定目标

目标会让智能体一轮接一轮地工作下去，直到你设定的条件成立。打开会话菜单（⋯）→ **设定目标**，或者在 Claude Code 或 Codex 会话中输入 `/goal` 再加上条件。说清楚“完成”是什么样子，例如“npm test 通过，并且上传页面能处理 2 GB 的文件”，然后按**开始处理**（或 Ctrl+Enter）。

- **Claude Code** 会持续工作；每一轮结束后，由一次快速检查判断目标是否已经达成。
- **Codex** 会一直工作，直到它判断目标已完成。
- **Custom** 会持续工作；每一轮结束后，辅助模型会检查证据并给出下一步。当它不再取得进展时会暂停，运行的轮数最多不超过[设置 → Custom → 目标 → 目标暂停前的轮数](/settings?s=custom&find=Rounds%20before%20a%20goal%20pauses)中设定的值。

设定目标后，消息框上方会有一条栏显示目标及其状态（正在处理、已暂停、卡住了：需要你介入，或因用量或 token 限额而停止）、检查了多少次、花费的时间和 token，以及最近一次检查的理由。**暂停**和**继续**适用于 Codex 和 Custom；**清除**会停止朝这个目标努力。侧边栏中的靶心标记表示哪些会话有目标。

## 分叉会话

分叉是一个新会话：它以当前对话开头，然后去尝试别的做法；当前会话保持不变。

1. 打开会话菜单（⋯）→ **分叉**；或者把鼠标悬停在某条回复上，按**从这条回复分叉**（Claude Code 和 Custom），只保留到那里为止的对话。
2. 写下分叉会话要做什么（“分支会话应该改为尝试什么？”）。
3. 按**分叉**（或 Ctrl+Enter）。

分叉会话随即打开，标题为“… · fork”，使用相同的智能体、模型、思考强度、权限和账户。它顶部有一行“分叉自 …”，旁边有**打开**（Codex 的分叉会话只显示分叉之后的内容；之前的对话在原会话中）。分叉适用于 Claude Code、Codex 和 Custom，但不适用于在其他应用中打开的会话。压缩对话之前的 Claude Code 回复也可以分叉：分叉会话以到那条回复为止的完整对话开头，即压缩之前的样子。

## 从这里编辑

回到你的某条消息，换一种说法：

1. 把鼠标悬停在你的消息上，按**从这里编辑**。
2. 修改文字。
3. 如果智能体在那之后做的改动也要撤销，勾选**把文件恢复到这条消息之前的样子**。
4. 按**从这里发送**（Enter），或**取消**（Esc）。

对话会在一个副本中继续，副本包含那条消息之前的全部内容，并沿用这个会话的标题；当前会话会被归档。恢复文件适用于 Claude Code（依据它为从本应用发出的消息所做的检查点）、Custom（它自己编辑改动过的文件；命令所做的改动会保留），以及任何在工作树中的会话（每次你发消息时都会拍一个快照）。Codex 会话只有在工作树中才能恢复文件。如果一轮正在进行，请先停止智能体。从这里编辑适用于 Claude Code、Codex 和 Custom。

## 转到另一个智能体继续

把对话交给另一个智能体，在那里继续：

1. 打开会话菜单（⋯）→ **转到 Codex 继续**（或**转到 Claude Code 继续**，或在 Custom 有了模型之后选**转到 Custom 智能体 继续**）。
2. 消息框上方会出现一条提示，说明你的下一条消息会发到那里；模型、思考强度和权限的选择现在都作用于新的智能体。按 ×（“留在这里”）可以取消。
3. 写一条消息，或者直接发送以继续。

一个新会话会在同一个文件夹中打开，带着目前为止的对话：你最初的请求，接着是能装进大约 15,000 个 token 的最近消息，以及改动过的文件。新的智能体会被告知完整对话保存在哪里，以便它读取被省略的部分。它的第一条消息显示“接续自 Claude Code”，旁边有**打开那个会话**和一个可以查看带过来的消息的按钮；旧会话则显示“此对话已转到 Codex 继续”，旁边有**打开**。这适用于从 Claude Code 和 Codex 会话转出。

## 压缩对话

压缩会用一份摘要替换目前为止的历史记录，从而在模型的上下文中为接下来的内容腾出空间。使用会话菜单（⋯）→ **更多** → **压缩对话**，或者点击消息框中的上下文指标，然后按**压缩**确认。它适用于 Claude Code 和 Codex，在两轮之间进行。Custom 会自己压缩较长的对话。

## 重命名、置顶、延后、告一段落、归档或删除

这些操作大多在会话菜单（⋯）中，也在侧边栏里它那一行的菜单中：指向这一行并点击末尾的 **⋯**，或者右键单击它（在手机上，轻点它的 **⋯**）。

- **重命名**：输入新标题（最多 200 个字符）；按 Enter 保存，按 Esc 取消。双击页头或侧边栏中的标题，或在选中的行上按 F2，效果相同。
- **重命名文件夹**（在侧边栏中，针对不在项目中的会话）：为它工作的文件夹起一个你自己的名称，侧边栏、会话行和文件夹菜单在所有设备上都显示这个名称；文件夹在磁盘上的名称不变。留空则恢复文件夹本来的名称。
- **置顶** / **取消置顶**：置顶的会话会留在**已置顶**分组中，按你拖动排列的顺序显示。你也可以把会话从下面的各组（项目或文件夹的分组、今天、昨天…）拖到“已置顶”上；还没有置顶任何会话时，拖到“拖到这里即可置顶”上。
- **延后**：把会话收进底部的**已延后**分组，直到你选的时间：**1 小时**、**3 小时**、**今晚**（下午 5 点前可选）、**明天早上**、**下周**（周一早上），或**选择日期和时间**。到时它会自己回来并附带提示；如果它需要你处理，会提前回来。**取消延后**会让它立刻回来。
- **告一段落：先到这里**：用于已完成的工作。智能体会停止（一轮进行时不提供此项），会话会被视为已读；它的历史记录和工作树（如有）都会保留。对于在工作树中的会话，会打开工作树对话框，方便你移除它。
- **归档** / **取消归档**：把会话从列表中移走；不会删除任何东西。已归档的会话可以通过侧边栏中的**搜索会话**找到；打开它，在菜单中选择**取消归档**。
- **删除会话**：你确认后，会话的历史记录会从磁盘上删除，所以它也会从智能体自己的命令行和 VS Code 中消失。此操作无法撤销。侧边栏中这一行菜单里的**删除**作用相同。

在你删除之前，应用会保留每一个会话，即使智能体自己的程序删除了它的对话（除非另行设置，Claude Code 会在 30 天后删除）：它会回来，仍在列表中，也仍能打开。一年没人用过的会话会自动删除，除非你把它置顶，或在设置 → 通用中更改这一设置（参见[删除不活跃的会话](/guide/app#delete-inactive-sessions)）。

置顶、取消置顶、归档、取消归档和延后都会显示一条带**撤销**的提示，8 秒内按 Ctrl+Z 也可以撤销。

## 分享只读链接

会话菜单（⋯）→ **分享只读链接**会生成一个链接，任何人不需要你的密码就能打开（[保密会话](#keep-a-session-confidential)不能这样分享）。他们能实时看到对话（消息、步骤名称、文件改动和智能体展示的页面），但看不到命令输出或智能体的思考过程，也不能输入或更改任何内容。选择链接的有效期（**一天**、**一周**、**一个月**、**直到关闭**），然后按**创建链接**；链接只显示一次。同一个对话框还会列出当前有效的链接、每个链接被打开的次数，并可以关闭某个链接。参见[手机、其他机器和分享](/guide/devices)。

## 在工作树中工作

工作树是仓库文件在一个新分支上的独立副本，这样智能体可以修改东西而不碰到你自己的副本，多个智能体也可以同时在一个仓库上工作。

- **创建**：在开始页上打开**文件夹**，打开**新建工作树 基于 …**（文件夹必须位于 git 仓库中）。应用会从当前检出的分支创建一个名为 `agent/` 加上几个任务关键词的分支，并在应用的数据文件夹中为它建一个文件夹。这个开关会保留到下一次。
- **快照**：在工作树中，每次你发消息时，应用都会保存一份文件快照，这样[从这里编辑](#edit-from-here)就能把文件恢复。
- **查看**：会话菜单（⋯）→ **文件夹与代码** → **工作树：agent/…**，会显示该分支及其来源分支、它的文件夹、领先或落后多少个提交，以及未提交的更改，并提供**查看它的改动**和**在 Git 中打开**。
- 工作完成后**移除**它：在同一个对话框中点**移除工作树**。文件夹会被删除；会话保留它的历史记录。分支会保留，所以已提交的内容不会丢失，除非你勾选**同时删除分支 …**（没有任何新内容的分支无论如何都会被删除）。如果有未提交的更改，要先勾选**放弃这 … 处未提交的更改**。如果智能体正在运行，它会停止；共用这个工作树的分叉会话和“从这里编辑”产生的会话也会失去它。

## 创建拉取请求

从会话所在的分支出发，选择会话菜单（⋯）→ **文件夹与代码** → **创建拉取请求**，即可在 GitHub 或 Gitea 上创建拉取请求。**帮我写**会根据提交和差异起草标题与描述；一个勾选框可以先提交未提交的更改；**草稿**会把它标为草稿；按下**创建拉取请求**时会推送分支。你需要在[设置 → 源代码管理](/settings?s=scm)中有一个账户。**关联一个已有的拉取请求…**，可以关联在别处创建的拉取请求。

关联之后，它的状态和检查结果会以标记的形式显示在侧边栏和页头中，每隔几分钟更新一次；合并后或检查完成时会有提示。同一个菜单项此时变成**拉取请求 #12**，其中有**在 GitHub 上打开**（或 Gitea）、**查看改动**、**立即检查**和**取消关联**。子菜单中的**查看改动**会逐个文件地查看这个分支改了什么。参见[系统：文件、Git、终端和预览](/guide/files-git)。

## 当使用限额让会话停下时

当 Claude Code 或 Codex 套餐的用量用完时，消息框上方会出现一条横幅，说明达到的是谁的限额、是哪一项限额、何时重置：你只有这个智能体的一个账户时写着“你已达到 Claude Code 的使用限额”；你有好几个账户且都没有用量时写着“你所有的 Claude Code 账户都已达到使用限额”；另一个账户还有用量时，则说出达到限额的那个账户的名称（“Work 已达到使用限额”）。

如果这个智能体的另一个账户还有用量，并且**达到限额时切换账户**已开启，就不会出现横幅：会话会转到那个账户继续（新会话也会从那里开始）。如果该设置已关闭，横幅会说出那个账户，并提供**开启**。

- **重置时继续**会在限额重置一分钟后自动继续会话，发送的消息是“Continue where you left off.”。横幅随后会显示继续的时间，并提供**取消**。
- **使用一次重置**：如果你的账户有可用的限额重置次数，横幅会显示还有几次，点这个会立即用掉一次。
- 设置 → 应用 → 通用中的[用量限制解除后继续](/settings?s=general&find=Resume%20after%20usage%20limits)会对每个因限额而停下的会话这样做。开启后，会话里不会出现警告：消息框上方有一行，说明达到的是谁的限额（和横幅一样）、是哪一项限额以及何时继续（“你所有的 Claude Code 账户都已达到使用限额”，下面是“当前会话（5 小时）· 将自动继续 3 小时 15 分钟后”），有可用的重置时带 **使用一次重置**，以及 **取消**。你自己按 **停止** 停下的会话不会自动继续。

继续的时间跟随限额：如果重置时间变了，或者用量提前恢复，会话就在那时继续。参见[用量、限额和费用](/guide/usage)。

## 在 VS Code 或终端中运行的会话

这台电脑上的每个 Claude Code 和 Codex 会话都会列出来，包括你在 VS Code、终端或 Claude 桌面应用中运行的会话。它们在那边运行时，列表会显示“正在 VS Code 中工作”、“需要你在终端中处理”或“已在 VS Code 中打开”（灰色圆点），你可以在它们工作时同步阅读。如果某个会话在那边等你，应用只会在它一分钟后仍在等待时才通知你。

- **接管 Claude Code 会话**：按它页头中的**在这里继续**，或者直接发一条消息（“已在 VS Code 中打开——发送消息会把它移到这里”）。应用会先询问你：它会在那个应用中结束这个会话，停下正在做的事，然后带着完整的历史记录在这里继续。那个应用会显示它已结束；之后你可以在那边重新打开它。
- 在别处打开的 **Codex 会话**在这里是只读的，因为那边的一个 Codex 进程服务于它的所有线程。请在那边继续，或者在那边关闭后再到这里继续。
- 会话在其他应用中打开时，不提供分叉。

## 子智能体

智能体可以把一项工作的部分内容交给子智能体，并取回它们的结果。子智能体有两种，应用会说明是哪一种：

- **Hydor 子智能体**是由 Hydor 启动的、自成一体的会话，可使用任何智能体和模型。它在父会话的对话中有一张卡片，在侧边栏里排在父会话下面，你可以打开它并与它对话。它有自己的花费，也分到父会话花费上限的一份，它的回复会作为一条消息发回父会话。
- **Claude Code 子智能体**（用 Codex 时是“Codex 子智能体”：即会话自己所用程序的名称）是那个程序在会话内部为完成一小部分工作而运行的。它是消息框上方托盘里的一行，会在面板中打开并显示它的各个步骤，也可以停止，但你不能与它对话。它花的钱算作会话自己的花费。

在侧边栏中，Hydor 子智能体折叠在父会话下面（“3 个子智能体 · 1 个需要你 · 2 个工作中”）；点这一行即可看到它们。你查看其中某个时，这一组会保持展开。集群的成员显示为“集群成员”，战役的成员显示为“战役成员”。在父会话的对话中，每个 Hydor 子智能体都有一张卡片，显示它在做什么，并提供进入的入口。在其中一个里面，消息框上方的横条写着“子智能体，来自”和父会话的标题（“它的回复会发回那里”），旁边有**打开父会话**。父会话自己的这一轮已经结束、但它的子智能体仍在运行时，它并没有完成：它的圆点继续蓝色呼吸，消息框中停止按钮上的圆环继续旋转，状态显示“工作中 · 2 个子智能体正在运行”，不显示“已完成”标记，并留在“活跃”中，你仍然可以给它发消息。依赖自己的子智能体的 Hydor 子智能体也算在运行。父会话的花费上限也涵盖它的 Hydor 子智能体。参见[深度研究、第二意见和多个智能体](/guide/research)。

消息框上方有一行，概括这个会话启动的所有内容：它的子智能体和后台任务（命令、监控、工作流）。它会写成“2 个子智能体和 1 个后台任务正在运行”，有 Hydor 子智能体在等你时，会用琥珀色加上“1 个需要你”；没有东西在运行时则写成“3 个子智能体 · 2 个后台任务 · 全部完成”。每次打开会话时它都是折叠的。点它即可列出每一项：需要你处理的在最上面，然后是正在运行的，再是已结束的（最新的在前），超过大约五行后在里面滚动。每一行的样子都相同：带状态圆点的图标、标题、它是什么（“Hydor 子智能体 · Claude Code · Sonnet 5.5”、“Claude Code 子智能体”、“命令”、“监控”、“工作流”）、它的状态（“工作中 · 2m 10s”、“需要你处理”、“已完成 · 3 分钟前”、“已停止”、“失败”）、Hydor 子智能体的花费、**打开**，以及运行时的停止按钮。把指针移到“它是什么”上，可以看到谁在运行它：“Hydor 把它作为独立的会话启动：打开它可以观看它工作或与它对话”，或“Claude Code 在这个会话内部运行它：打开它可以查看它的步骤”。**打开** Hydor 子智能体会进入它的会话；Claude Code 子智能体或后台任务则在页面右侧的面板中打开（手机上占满整个屏幕），面板里有它的标题、类型和状态、运行时的**停止**，下面是它做过的事：子智能体的各个步骤，或命令、监控的输出。它每两秒刷新一次，除非你向上滚动，否则一直停在最新的几行。Hydor 子智能体的停止按钮写着“停止这个子智能体”，任务的则写着“停止这个任务”。这一行右侧的**全部停止**会停止所有正在运行的内容，和消息框旁的停止按钮一样。集群或战役的成员不会列在这里：它们的看板会显示。已结束的任务会一直列着，直到智能体的程序停止；在 VS Code 或终端中打开的会话会列出它的任务，但无法从这里停止。

一个会话同时运行多少个 Hydor 子智能体，在[设置 → 功能 → 子智能体](/settings?s=children)中设置：这些设置针对 Hydor 子智能体，因为 Claude Code 和 Codex 自己的子智能体在它们的会话内部运行。在设置 → 模型 → 档位中打开[主智能体带领子智能体](/settings?s=models&find=Lead%20with%20subagents)后，会话的主智能体会做规划，把明确的部分交给更便宜档位上的子智能体，并检查它们的工作。

## 会话菜单中的所有选项

会话右上角的 ⋯ 按钮会打开它的菜单。有些项目只在适用时才显示；[保密会话](#keep-a-session-confidential)的菜单里没有**分享只读链接**、**创建拉取请求**、**打开浏览器**、**已连接的账户**、**把它设为自动化**和**另存为应用**，它的记忆也始终关闭。

- **重命名**：就地编辑标题。
- **置顶** / **取消置顶**。
- **延后**（一个时间子菜单），延后期间则显示**取消延后（返回时间：…）**。
- **告一段落：先到这里**：停止智能体并把会话标为已读（一轮进行时不可用）。
- **分叉**：从这段对话新建一个会话（Claude Code、Codex、Custom）。
- **转到 Codex 继续**、**转到 Claude Code 继续**、**转到 Custom 智能体 继续**：把对话带到另一个智能体（从 Claude Code 和 Codex 转出）。
- **设定目标**：一直工作到某个条件成立（Claude Code、Codex、Custom；尚未设定目标时）。
- **第二意见**：由另一家公司的模型对照你的要求检查某一轮的工作，结论显示在那一轮下方。参见[深度研究、第二意见和多个智能体](/guide/research)。
- **分享只读链接**。
- **文件夹与代码**（子菜单，适用于有文件夹的会话）：
  - **查看改动**：逐个文件查看这个分支改了什么。
  - **创建拉取请求**，有了拉取请求后则显示**拉取请求 #12**。
  - **工作树：agent/…**：工作树的对话框（在工作树中的会话）。
  - **浏览文件夹**：在“文件”中打开会话的文件夹。
  - **在此处打开终端**：在该文件夹中新开一个终端（在电脑上位于底部的面板中，在手机上位于“终端”页面）。
- **会话设置**（子菜单）：
  - **记忆**，旁边显示**开启**或**关闭**：为这个会话开启或关闭记忆（设置中关闭了记忆时显示“已全局关闭”）。参见[记忆](/guide/memory)。
  - **花费上限**，旁边显示上限金额：设置、更改或提高它。参见[用量、限额和费用](/guide/usage)。
  - **已连接的账户**：只为这个会话开启或关闭每个已连接的账户。参见[已连接的应用、密钥和工具](/guide/connections)。
  - **智能体**，旁边显示它的名称：打开这个智能体的页面（有智能体的会话）。在消息框里可以切换智能体。
- **更多**（子菜单）：
  - **打开浏览器** / **显示浏览器**：这个会话的智能体浏览器，你可以观看，也可以接手操作。参见[搜索和浏览器](/guide/web)。
  - **把它设为自动化**：辅助模型会读取这个会话，并据此起草一个定时任务；你可以修改任何内容，试运行一次，然后保存。参见[定时任务](/guide/tasks)。
  - **另存为应用**：以这个会话为基础新建一个应用。参见[应用](/guide/apps)。
  - **压缩对话**（Claude Code 和 Codex）。
  - **复制 CLI 恢复命令**：在终端中继续这个会话的命令。
  - **停止智能体进程**（智能体在运行且没有一轮正在进行时）。
- **归档** / **取消归档**。
- **删除会话**：确认后把它的历史记录从磁盘上删除。
