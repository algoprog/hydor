# 会话

**会话**是你与智能体在某个文件夹中进行的一次对话：你说出想要什么，智能体开始工作，你则全程跟进、批准它想执行的操作，并随时引导它。本主题涵盖会话的方方面面：起始页及其选项、智能体工作时你能看到的内容、在智能体处理过程中向它发消息，以及会话菜单中的所有功能，从分叉、目标到工作树和分享。

## 开始会话

侧边栏顶部的 **新建会话** 会打开开始页。在消息框里写下你想完成的事，看一眼下方那一行选项，然后按 Enter（或点 **开始**；手机上是圆形箭头）。会话页面会立刻打开，显示你的消息，以及正在处理它的智能体（**工作中**）。如果会话无法启动，页面会说明原因，点 **返回开始页** 会把你的消息（和附加的内容）放回消息框。

如果在应用回应之前连接断了（手机休眠了，或网络变了），页面会显示 **正在重新连接…**，连上后会向应用询问你的消息结果如何：已经启动的话会话就会打开，而且同一个会话绝不会启动两次。如果应用约一分钟仍然连不上，页面会显示 **无法连接到应用**；点 **重试** 会再问一次。

会话启动片刻后会得到标题：用几个词概括你的请求（“里斯本周末行”“修复结账测试”）。标题由辅助模型（[设置 → 智能体 → 模型](/settings?s=models&find=Helper%20model)）在后台写出，不会在对话中显示任何内容。侧边栏、会话页眉和搜索框都会显示它（在侧边栏里，标题的文字会逐字出现，取代你消息的开头），Claude Code 和 Codex 也会收到它，用于各自的列表。标题生成之前，以及辅助模型无法回答时，会用你消息的开头代替。你用 **重命名** 给会话起的标题不会被替换。侧边栏从你发送的那一刻起就会列出这个会话，位于 **活跃** 的最上方（**正在启动**）。

消息框下方的一行包含 **运行于**、**模型**、**文件夹**（或 **项目**）、**智能体**，末尾是 **选项**。在手机上，它们各自从屏幕底部以面板形式打开。

### 选择智能体及其模型

**运行于** 并排列出你能使用的每个程序：

- **Claude Code**：Anthropic 的智能体，使用 Claude 套餐或 API 密钥。
- **Codex**：OpenAI 的智能体，使用 ChatGPT 套餐或 API 密钥。
- **Custom**：应用自带的智能体，可用于任何模型：来自 OpenRouter、Ollama 或 vLLM 的模型。参见 [Custom，应用自带的智能体](/guide/custom)。
- 你添加的其他支持 ACP 的智能体（Gemini CLI、OpenCode、Qwen Code、Goose……），名称下方会显示它的命令。

底部的 **Custom 的模型** 会打开 [设置 → 模型](/settings?s=models)，**添加或管理智能体** 会打开 [设置 → 更多智能体](/settings?s=agents)。参见 [智能体、账户和模型](/guide/agents-models)。

**模型** 默认是 **自动**：会话从最佳档位的模型开始，它的主智能体会把清晰的部分交给较低档位的子智能体，遇到太难的问题时，它还可能自行切换到最大值档位的模型（参见 [档位：为每类工作选择模型](/guide/agents-models#tiers-a-model-for-each-kind-of-job)）。其下的菜单只列出所选智能体自己的模型。智能体的默认模型会标注“默认”。较旧版本的模型收在“2 个较旧的模型”后面；列表很长时会有 **搜索模型** 字段（按 Enter 选中第一个匹配项）。Custom 列出你在“设置 → 模型”中添加的模型；其他 ACP 智能体列出它上次运行时提供的模型，运行过之后才会出现这个标签。

### 选择文件夹、项目或新的任务文件夹

**文件夹** 标签说明智能体在哪里工作。它的菜单（“要在其中工作的项目或文件夹”）有一个 **查找项目或文件夹，或输入路径** 字段，下面是两个简短的列表，每一行都标明了所在位置：

- **项目**：按名称列出你的项目，包括最近工作过的五个（以及当前选中的那个），各自附带它的文件夹。选中其中一个，会把文件夹设为该项目自己的文件夹，同时采用它的智能体和它在本会话中的准则；此时标签显示 **项目** 并带上项目名称。一组项目的用法相同，包含其中的所有项目。标题末尾的 **新增** 会创建一个项目（会话、文件和记忆合在一起）并选中它。参见 [项目与知识](/guide/projects) 和 [智能体准则](/guide/guidelines)。
- **文件夹**：当前使用的文件夹，以及你最近选过的三个文件夹，每个都带有它所在的文件夹。标题末尾的 **浏览** 会列出你主文件夹中的文件夹。
- **新建任务文件夹**（“在 ~/Hydor 中新建一个”）：为这个任务创建一个全新的文件夹，以日期加你消息中的几个词命名（例如 `2026-11-01-plan-trip-lisbon`），放在 `~/Hydor` 中，除非你在 [任务文件夹](/settings?s=assistants&find=Task%20folders)（设置 → 功能 → 你的智能体）里另设了位置。

项目自己的文件夹就是这个项目：菜单只会把它列为项目，在它里面启动的会话会在项目中工作，即使开始页选的是文件夹而不是项目。

菜单会在标签的上方或下方打开，取空间更大的一侧，并且无需滚动即可完整显示：窗口较小时，会先少显示一些文件夹，再少显示一些项目，项目下方会出现类似“还有 2 个”的一行，点开可以看到其余的。

在字段中输入可以找到更多：

- 输入名称会找到匹配的项目，以及你最近用过的文件夹、当前文件夹和你主文件夹中的文件夹。按名称找到的项目文件夹会显示为项目。
- 输入路径（`~/code/`，或从你主文件夹算起的 `code/`）会列出那里的文件夹，和 **浏览** 一样。字段末尾的箭头会返回上一级文件夹；叉号或 Escape 会回到原来的列表。
- ↑ ↓ 和 Enter 用来选择。Tab，或一行末尾的箭头，会列出其中的文件夹。

当文件夹位于 git 仓库中（并且你没有选择新的任务文件夹）时，菜单末尾会有一个开关：**新建工作树**，基于 main（或当前检出的其他分支），“在仓库的副本中新建分支”。打开后，会话会在自己的副本中、一个新分支上工作；标签显示“· 新建工作树”。参见 [在工作树中工作](#work-in-a-worktree)。

新会话默认是否得到新的任务文件夹，取决于智能体：大多数智能体会在新文件夹中启动，除非你选了文件夹；程序员在你选的文件夹中工作，属于某个项目的智能体则在该项目中工作。

### 选择智能体

**智能体** 设定会话以谁的身份工作：**通用**（在你选择其他智能体之前；在拥有自己智能体的项目里，则是该项目的智能体）、**研究员**、**撰稿人**、**程序员**、**辅导老师**、**规划师**、**分析师**、**应用搭建师**，或是 **你的** 下面你自己的智能体（既包括在所有地方都能用的，也包括所选项目的）。将鼠标指向某一个，可以看到它做什么，以及使用哪个程序和模型。选中它还可以一并设置它建议的程序、模型和权限（如果它用档位思考，则是该档位的模型），并开启它所连接的账户。**创建或修改智能体** 会打开 [智能体页面](/agents)。参见 [智能体](/guide/agents)。

### 选项：思考强度、权限等

**选项** 包含其余的设置。它的标签显示“选项”，或者列出你调整过的、不同于常规的设置，例如“最高思考强度 · 计划 · 上限 $5.00”。在电脑上，它的菜单末尾有一条提示：在消息框中按 Shift+Tab 可以切换权限。

- **思考强度**：模型思考的深度。**默认** 使用模型自己的设置，之后是模型提供的各个级别：**最低**（快速、轻度推理）、**中等**（均衡）、**最高**（更深入的推理）、**超高**（特别深入的推理）、**最大值**（最大程度的推理），部分模型还有 **极简**、**无** 或 **极限**。Custom 和其他 ACP 智能体，以及没有级别的模型，不提供此项。
- **权限**：智能体无需先问你就可以做的事。每个智能体有各自的模式；参见 [各权限模式的含义](#what-each-permissions-mode-means)。在消息框中按 Shift+Tab 会切换到下一个。
- **账户**：只有当你在 [设置 → 智能体 → 账户](/settings?s=accounts&find=Accounts) 中为 Claude Code 或 Codex 添加了其他账户后才会出现。**你的登录** 是智能体自己的账户；选择另一个，就以它的身份运行这个会话。**管理账户** 会打开设置。
- **保密**，带锁的开关（“仅使用本机上的模型。任何内容都不会离开本机。”）：适用于你评审的论文、患者数据或客户的代码。**运行于** 会变为 **Custom**，**模型** 变为本机上安装的最佳模型。参见 [保持会话保密](#keep-a-session-confidential)。
- **记忆**：仅在设置中开启了记忆时才会出现。**开启** 会使用并补充智能体记住的内容；**本会话已关闭** 则从零开始，也不会留下任何内容。参见 [记忆](/guide/memory)。
- **花费上限**：这个会话最多可以花多少，按 API 价格计算。输入金额后点 **设置**，或者选 $1、$5、$10 或 $25；**无上限** 会取消上限。会话到达上限后就会停止，直到你提高上限。参见 [用量、限额和费用](/guide/usage)。
- **集群**：**关闭**；**集群**：由一个主导智能体把任务拆分成多个切入角度，并为每个角度启动一个成员，同时工作的数量由 **集群规模** 决定（[设置 → 功能 → 子智能体](/settings?s=children&find=Swarm%20size)）。成员们把发现的内容共享在看板上，并互相发消息。适用于困难的问题；费用是单个智能体的数倍。或者 **战役**（“一项大改动分成多个部分，每部分放在一个工作树中”）：主导智能体把一项大改动拆成多个部分，成员们各自在自己的分支上完成一个部分及其测试，最后由主导智能体合并；文件夹必须是 git 仓库（参见 [战役](/guide/engineering#campaigns-a-big-change-in-many-parts)）。
- **研究**：**关闭**，或 **深度研究**：智能体规划搜索，派研究员去处理每个部分，用两个来源核对关键论断，并交付一份带引用的报告。可以设置 **同时进行的研究员数**（1 到 8）、**轮数**（1 到 5）、**总搜索次数**（10 到 500）和 **报告**（**网页** 或 **Word**）。
- **目标**：**关闭**（“智能体一直工作，直到它认为完成了”），或 **直到完成**（此时选项标签显示“目标模式”）（“它一轮接一轮地工作，直到你认可的检查项都满足”）：你的第一条消息就是目标，智能体先想出如何检查它并展示给你，在你同意之前不会开始任何工作。在 **向你询问的频率** 下，选择它多久问你一次该往哪个方向走。它适用于所有智能体，会消耗很多轮对话，并在你同意的限制（轮数、金额、时间）处停止。参见 [为会话设定目标](#give-the-session-a-goal)。
- **竞技场**：**关闭**，或 **比较模型**：同一条消息还会发给你勾选的一到两个其他模型（列表很长时，**查找模型** 字段会有帮助），每个模型在同一文件夹中各有一个自己的会话。你比较各个回答，保留最好的，其余的会被归档。在 git 仓库中，请打开文件夹菜单里的 **新建工作树**，让每个模型在自己的副本上工作。

集群（或战役）和深度研究都会带领 Hydor 子智能体，所以打开其中一个会关闭另一个。**目标** 可以与集群同时使用（目标属于它的主导智能体：[为集群设定目标](#a-goal-for-a-swarm)），但不能与战役、深度研究或竞技场同时使用：打开 **目标** 会关闭这些，打开其中任何一个会关闭目标，而带领着其中任何一个的会话不能设定目标（它的菜单里没有 **设定目标**）。**保密** 会关闭集群、深度研究和竞技场，打开其中任何一个也会关闭保密（目标可以在保密会话中运行）。集群、深度研究、竞技场和目标不会保留到下一个会话，因为它们花费更高；你选的研究数值和竞技场模型会保存在这个浏览器里，等你再次打开它们时使用。参见 [深度研究、第二意见与多个智能体](/guide/research)。

### 各权限模式的含义

**Claude Code**

| 模式 | 智能体可以做什么 |
| --- | --- |
| 询问（默认） | 在编辑和未被其设置允许的命令之前先询问 |
| 接受编辑 | 可以自由编辑文件，运行其他命令前先询问 |
| 自动 | 由安全检查批准常规操作，遇到有风险的操作则询问你 |
| 计划 | 只读取和规划，然后提出计划供你批准 |
| 绕过 | 从不询问（完全访问） |

**Codex**

| 模式 | 智能体可以做什么 |
| --- | --- |
| 计划 | 先讨论和规划；可以向你提出澄清问题 |
| 只读 | 读取文件并回答；改动任何内容前先询问 |
| 自动（默认） | 在其文件夹内编辑文件和运行命令；超出该范围时先询问 |
| 自动审查 | 与自动类似，但由一个审查智能体来回应它的批准请求 |
| 完全访问 | 没有沙盒，也没有批准 |

在 Docker 内，Codex 自己的沙盒无法启动，所以那里默认是 **完全访问**，菜单会说明原因。

**Custom**

| 模式 | 智能体可以做什么 |
| --- | --- |
| 询问（默认） | 编辑文件和运行命令前先询问；查看周围的内容则可自由进行 |
| 接受编辑 | 可以自由编辑文件夹中的文件，运行命令前先询问 |
| 自动 | 常规步骤直接进行；有风险的步骤由一次快速检查来询问你 |
| 完全访问 | 无需批准提示，也没有命令沙盒，直接运行工具和命令，使用你电脑账户的权限 |
| 计划 | 只读取和规划：不编辑，不运行命令 |

在完全访问之外，Custom 在运行有风险的命令前会询问你。在询问、接受编辑和计划模式下，读取或更改文件夹之外的文件，或存放密钥或密码的文件之前，它也会询问；在自动模式下，则由快速检查先判断这些情况。参见 [Custom，应用自带的智能体](/guide/custom)。

**其他 ACP 智能体** 提供它们自己的模式，在智能体运行过之后列出。

### 保持会话保密

有些工作不能离开你的电脑：别人发给你评审的论文（大多数会议和期刊禁止把投稿交给在线 AI）、患者或客户的记录，或是你根据协议处理的公司代码。保密会话在这台电脑上的模型上运行，它的任何内容都不会被发送到别处。

1. 在开始页打开 **选项**，打开 **保密**（“仅使用本机上的模型。任何内容都不会离开本机。”）。它的标签随后显示“保密”。
2. **运行于** 变为 **Custom**，**模型** 变为本机上安装的最佳模型；开启期间，它们的菜单只提供这些。如果还没有，菜单会这样说明：[设置 → 智能体 → 模型](/settings?s=models) 可以一键安装为这台电脑推荐的模型。
3. 写下你想做的事，附上论文或选好它的文件夹，然后按 Enter。例如：“以 NeurIPS 审查者的身份评审附件中的投稿：摘要、优点、缺点、给作者的问题和评分。”

本机上的模型指这里的 Ollama 和 vLLM 的模型，以及地址属于这台电脑或你私有网络的端点：`localhost`、`127.0.0.1`、`::1`、`10.…`、`192.168.…`、`172.16.…` 到 `172.31.…`，或以 `.local` 结尾的名称（参见 [连接 Ollama、vLLM 或其他端点](/guide/agents-models#connect-ollama-vllm-or-another-endpoint)）。Ollama 的云端模型（名称以“cloud”结尾）在 ollama.com 上运行，不算在内。开始页会为你之后的会话保持这个开关处于开启状态，直到你把它关掉。

保密会话的标题旁边有一把锁，在页眉和侧边栏中都有，它的消息框带有柔和的绿色边框；框上方有一行说明这意味着什么，直到你关闭它。点击锁可以查看哪些已开启、哪些已关闭。

- **已关闭**：网络搜索和网页、浏览器和你的屏幕、已连接的应用和你的密钥、应用、发布、定时任务、制作、查找或编辑图片、绘图、图表、视频或声音、其他地方的模型（深度研究、集群和竞技场；[第二意见](/guide/research) 只能来自本机上另一家厂商的模型）、把对话交给另一个智能体、向记忆中保存任何内容，以及把网页导出为文件（请自行从网页导出）。
- **命令不联网**：智能体的命令在断开网络的状态下运行，在每种权限模式下都是如此，因此无法下载、从互联网安装、推送或发送任何内容。在做不到这一点的地方（Windows、某些容器），无论处于哪种模式，每条命令都会先询问你，锁的说明中也会这样写明。
- **仍然开启**：文件夹中的文件、文档（在这台电脑上读取）、你保留的网页、图片和文件、共享知识、你的记忆备注和个人资料（只读取，从不添加）、同样保密的 Hydor 子智能体，以及回答卡片（不含来自网络的图片或地图）。
- **不会向外发送任何相关内容**：它的标题在辅助模型于这台电脑上运行时由辅助模型生成，否则取自你消息的开头几个词；通知只会写“一个保密会话”，以及它是已完成、需要你处理还是失败了；没有只读链接，它的菜单中没有拉取请求，也不能由它生成自动化或应用；其他会话中的智能体和别处的智能体都无法读取它；它的回复不显示来自网络的图片，它显示的网页也不会从任何地方加载内容（所以需要网络库的图表无法绘制）；听写只有在使用这台电脑上的语音识别时才可用（[设置 → 功能 → 语音](/settings?s=voice)），回复也只会用你设备上的声音朗读。
- **它始终保密**：分叉和 **从这里编辑** 同样是保密的，并且无法关闭，所以说过的内容会留在原处。对于可能离开这台电脑的工作，请新建一个会话。

它无法保证的事：Hydor 检查的是模型服务器在哪里，而不是该服务器做什么，所以你在网络上搭建的、会把请求转发给在线服务的端点，仍然是在线的。你从会话中复制出去的内容，或是你自己从别处打开或发送的内容（回复中的链接、从项目文件中打开的它生成的网页、从 Git 页面进行的推送），需要你自己留意，你在另一台设备上读到的内容也一样：应用的页面会像往常一样传到那台设备（如果你使用隧道，则经由你的隧道）。

### 附加文件、指向文件、使用命令

- **附加文件**（消息框底部一行左侧的 **+**）、把文件拖到消息框上，或把图片和文件粘贴进去。一条消息最多可携带 25 MB 的文件。图片（PNG、JPEG、GIF、WebP）会作为图像发送给模型，每条消息最多 8 张；其他文件（最多 20 个）会保存在这台电脑上，并列在你消息的末尾，供智能体打开。发送前可以用文件旁的 × 移除它。你附加的文件会留在消息框中，直到你发送，即使你切换到其他页面也一样（重新加载页面会清除它们）。
- **附加截图**（在同一个 **+** 菜单里，仅限电脑；浏览器无法截图时，**+** 会是一个只用来附加文件的回形针）：浏览器会询问要选哪个屏幕、窗口或标签页，然后附加它的一张图片。
- **@**：输入 @ 和文件名的一部分，会列出文件夹中匹配的文件；用 ↑ ↓ 移动，按 Enter 或 Tab 插入，按 Esc 关闭。
- **/**：在消息最开头输入 /，会列出智能体的命令和技能（Claude Code 的），并说明每一项的作用。
- 当你的浏览器或这台电脑能识别语音时，发送按钮旁会有麦克风（听写你的消息）和耳机（免提语音模式）。参见 [文档、图片、视频和语音](/guide/documents-voice)。

### 开始页会记住什么

开始页会为你工作的每个地方记住你的选择：每个项目、每个文件夹和 **新建任务文件夹**，在所有设备上都一样。每个地方会记住它的 **运行于**（程序）、每个程序的 **模型**，以及在 **选项** 下的 **思考强度** 和 **权限**、**智能体**、**记忆**、**花费上限**、**保密** 和 **新建工作树** 开关。账户（**选项 → 账户**）不按地方记忆：它保持为你选的那个，在任何地方都一样。在某个地方选择一个程序，会带回你上次在那里用它时的设置。

某个地方只有在你于那里更改了其中某项设置或启动了会话之后，才会保留你的选择；仅仅看一眼不会保留任何内容。在 **文件夹** 标签中选一个地方（项目、文件夹或 **新建任务文件夹**），消息框就会带着那个地方的选择打开，而你已写下和已附加的内容仍留在其中。从项目启动（项目卡片或页面上的 **新建会话**，或侧边栏里的项目）会带着该项目的选择打开开始页，在某个文件夹上（在文件或侧边栏中）点 **在此文件夹中新建会话**，则带着该文件夹的选择打开。页面会在你上次选的地方打开。

还没有选择过或启动过任何内容的地方，会按默认值打开：智能体是 **通用**，或者在项目有自己的智能体时是该项目的智能体（它的建议也会生效，和你选择它时一样：它的程序、其档位的模型和它的权限）；**模型** 在提供 **自动** 的地方是 **自动**，否则是该程序的默认模型；**思考强度** 和 **权限** 是该程序通常的设置；记忆为开启；没有花费上限；**保密** 和 **新建工作树** 为关闭。**运行于** 保持为你上次用的程序。在加入这一功能之前你上次选的那个地方，会保留你当时的选择。

指向开始页的链接可以预先填好它，例如 `/?prompt=Summarize%20my%20notes&agent=codex`；还可以加上 `model=`、`cwd=`（文件夹的路径）和 `confidential=1`（开启保密）。它只会填入消息框和各项选择，绝不会自行启动任何事情。链接中的消息里的不可见字符会被移除，并给出提示。

你在消息框中写的内容在你切换到其他页面时会保留：消息、你附加的文件、仅针对这个任务的选项（**集群**、**深度研究**、**竞技场**、本会话的 **准则**），以及链接或 **在此新建智能体会话** 打开它时所在的文件夹。会话启动时消息框会清空：智能体启动期间，**开始** 上的箭头会不断向上；随后开始页变成会话，消息框向下移到页面底部它的位置，你写的内容上移成为你的第一条消息。消息和这些选项保存在这个浏览器里，所以重新加载后仍然在；附加的文件则不会保留。

## 跟进会话中的工作

### 标题栏

会话顶部有：

- 智能体的图标和标题（双击标题可重命名），以及[保密会话](#keep-a-session-confidential)的锁图标；
- 状态：**工作中**、**需要你处理**、**就绪**、**正在启动**、**正在构建记忆**、**正在停止**，或者在其他地方运行的会话显示“在 VS Code 中打开”；智能体不再运行后，则显示工作是如何结束的：最后一轮顺利结束时为**完成**（如果创建或改动了文件，会加上“· 创建了 2 个文件”或“· 改动了 3 个文件”），你停止了它或它在完成前被中断时为**已停止**，因出错而结束时为**失败**。把鼠标指向状态可以看到下一步该做什么；
- 文件夹（点击可在文件中浏览）、拉取请求标记、以添加的账户运行时显示的账户，以及在较宽的屏幕上显示的 git 分支和模型；
- 一个对应你此刻能做的事的按钮：一轮正在运行时是**停止**；智能体没有运行时是**继续**（在**已停止**或**失败**之后；在**完成**之后则更低调，因为在输入框中发一条消息本来就会继续会话）；对于在 VS Code 或终端中打开的 Claude Code 会话，则是**在这里继续**；
- **详情**（文件有改动后会显示增加和删除的行数），点击会打开[详情面板](#the-details-panel-changes-commands-and-info)；
- 会话的菜单（⋯）：参见[会话菜单中的全部功能](#everything-in-the-sessions-menu)。

### 轮次、步骤和回复

对话读起来像聊天。每一轮包括你的消息、智能体的工作，以及它最后给出的回复：

- **你的消息**会在你发送的那一刻显示在右侧，连同其中的图片和附加文件，此时智能体还没收到：智能体会在它下方显示为工作中，而消息框可以继续写下一条。如果没能发出去（没有网络连接，或达到了花费上限），它会被撤下并放回消息框，同时附上说明原因的提示。较长的消息会折叠为前几行；点击**显示更多**可展开。
- **工作**位于一行概括它的文字下方：“工作了 2m 10s · 3 条命令”“思考了一会儿”“40s 后已停止”或“5s 后失败”，右侧是这一轮的花费（“≈ $0.12”）：点击它可查看这一轮的[时间和费用](/guide/sessions#a-turns-time-and-cost)。对于订阅套餐（Claude Code、Codex），这是按 API 价格计算的 Token 费用，而不是你实际支付的金额；如果不知道该模型的价格，这里会显示 Token 数量。这一轮运行时，这一行显示“工作中 · 1m 2s”（或“等你处理”），工作大纲会随进展不断增长；在之前已有若干轮的情况下，它还会加上会话总共工作了多久，即所有轮次加在一起：“工作中 · 1m 2s (47m)”。完成的一轮会把工作折叠起来；点击这一行可展开。
- **工作大纲**：智能体在步骤之间写下的每条简短说明（它发现了什么、接下来要做什么）开启一个部分，随后它执行的步骤归入其中。已完成的部分是带对勾的一行：用几个词概括的说明（“先运行结账测试，看看哪里失败”“先应用折扣，再统一取整一次”）、执行了多少步，以及改动了多少行。点击它可查看完整说明和每一步。正在进行的部分会完整显示智能体的说明，其下是当前正在执行的步骤，例如“正在编辑 total.ts · 4 s”；点击这一行可查看该部分到目前为止的步骤。智能体第一条说明之前执行的步骤会组成一个以它们的操作命名的部分（“运行了 3 条命令，读取了 2 个文件”）。较长的一轮会显示最新的几个部分；点击**显示 12 个更早的部分**可显示其余部分。
- **步骤**用通俗的话命名：“运行测试”“读取 index.ts”“搜索了网页”，命令本身以较淡的字体显示。点击某一步可查看它做了什么。Claude Code 会自行运行命令或其他会产生改动的步骤；而智能体在同一条消息中随后请求的 Hydor 自身的步骤（网页搜索、页面读取等）要等它结束后才会执行。这样的步骤会低调地显示**等待中**来代替计时，直到真正开始；之后计时才从那一刻开始，完成的步骤会显示它实际花费的时间。大纲中对应正在进行步骤的那一行，写的是真正在运行的步骤。
- **思考**显示为“思考了 12s”，并带有第一个标题；点击可阅读。
- **回复**是智能体在最后一步之后写下的内容。智能体展示的网页会与它放在一起。智能体工作期间，它在最后一步之后写下的简短说明会显示在大纲中，作为正在进行的部分；如果这一轮到此结束，它就成为回复。
- **步骤之间的回复**：智能体在步骤之间写下的、读起来像回复的内容（对你在它工作时发送的消息的回答，或者它在继续之前的发现，包含若干段落、列表或表格）也会显示为回复，位于原来的位置，而不会折叠进工作里。它前后的工作各自位于单独的一行下方，例如“工作了 20s · 2 条命令”。
- **改动的文件**：回复下方有一张卡片，列出这一轮改动的每个文件，以及增加和删除的行数。点击某个文件可查看它的差异；**打开文件**会打开该文件。超过五个的会折叠在“显示另外 3 个文件”后面。
- **生成的文档**：回复下方会以标有**新增**或**已更新**的卡片显示智能体在这一轮创建或改动的文档（PDF、Word、Excel、PowerPoint、LaTeX、笔记本、Markdown 等），无论它是否交给了你；回复中的文件名和路径是链接，会在对话上方的窗口中打开该文件（[它创建或改动的文档](/guide/documents-voice#documents-it-made-or-changed-and-file-names-in-its-reply)）。
- **提交**：如果智能体在这一轮做了提交，回复下方会有一个标签说明这一点：**已提交** · 提交的标题，或者“3 次提交”及其分支，还有增加和删除的行数。点击它（有多个提交时，再点击某个提交）可阅读完整的提交信息、作者和时间、哈希值（点击可复制），以及它改动的每个文件和差异。**在 Git 中打开**会在 [Git 页面](/git)中，于该会话的仓库里打开它。智能体在同一轮中修改过或通过变基抹掉的提交不会列出。

智能体也可能维护一份清单（**计划**或**待办事项**，并显示已完成的数量），随着工作推进逐项打勾。来自应用的通知会跟在它们所涉及的那一轮之后：记忆保存了什么、第二意见、达到了花费上限、某一轮启动的子智能体卡片。来自其他会话的消息显示为“来自 …”，子智能体的回复（Hydor、Claude Code 或 Codex 子智能体）显示为“来自 … 的回复”（点击可阅读该回复），定时任务的运行则以一行说明任务名称开头。

日期行（“昨天”“今天”）把不同的日子隔开；全部发生在今天的对话没有日期行。向上滚动时会加载更早的消息，也可以点击**显示更早的消息**。新的消息和回复会出现在对话末尾，下方不会留下空白。当一条回复长到足以占满屏幕时，视图会停在它的第一行并随着回复变长保持不动，这样你可以从头开始阅读长回复；较短的回复则直接显示在之前内容的下方。在智能体工作时向上滚动，视图会停留在你所在的位置；**最新**会带你回到末尾，当回复在屏幕下方继续生成时也会显示它。

每条完成的回复下方有**复制消息**、**从这条回复分叉**和**朗读**。**从这条回复分叉**适用于 Claude Code 的任何一条回复；对于 Codex 和 Custom，只适用于已完成一轮的最后一条回复，因为它们是对整轮分叉。在你自己的每条消息下方，**复制消息**、**从这里编辑**和发送时间始终显示，而不只是在鼠标悬停时显示。

### 一轮的时间和费用

已完成一轮那一行右侧的费用（“≈ $0.12”，或者在不知道该模型价格时显示 Token 数）会打开**时间和费用**，帮你了解一轮为什么耗时长或花费多：

- **时长**：一条显示这一轮时间花在哪里的条形图，每个部分都标有占比和时长：**模型**（读取给它的内容、思考和写作）、**命令**、**读取和编辑文件**、**网页**、**其他步骤**（子智能体、已连接的应用的工具）、**等你处理**（批准、问题和表单，从每张卡片出现到你回答为止）以及**其余**（启动，以及步骤之间）。同时进行的步骤只计一次。条形图下方是“首次回复或步骤用时 3 s”：智能体多快开始工作。
- **Token**：**新读取**；**写入缓存**（由模型提供方新读取并保存，这样下一次请求读取时更省钱）；**从缓存读取**，并显示它占全部读取量的比例；以及**写出**（回复、思考和步骤）。
- **费用**：这一轮的费用，并且在知道模型价格时给出每一类的费用，还有“缓存大约节省了 $0.80。”。对于订阅套餐（Claude Code 和 Codex，除非会话使用 API 额度运行），会显示“按 API 价格：使用套餐时你支付的是套餐费用”。如果不知道该模型的价格，则显示不计算它的费用。

Claude Code 的轮次会给出模型自身的用时和首次回复；对于其他智能体，模型这一部分是它的思考时间。费用和这个面板在较宽的屏幕上显示。

### 回复中的数学公式、示意图、图表和图片

智能体是为这个应用而不是为终端来撰写回复的，所以回复里可以有文字以外的内容。每个智能体都会用，并在这些能让回答更清楚时自行使用：

- **格式**：标题、列表、表格、粗体和代码，排版得便于阅读。
- **数学**：像教科书那样排版的公式，可以在句子中，也可以单独占一行，还有化学方程式（2H₂ + O₂ → 2H₂O）。成对美元符号之间的数字（`$1$`、`$0$`）也属于数学公式；像 $4.70 这样的普通价格仍然是金额。
- **示意图**：流程图、时序图和状态图、时间线、思维导图、甘特图和饼图，使用应用的颜色绘制，浅色或深色均可。示意图上方的栏里有**显示代码**（智能体写的内容；同一个按钮会再次显示示意图）、**另存为图片（SVG）**、**全屏**，以及一个复制其代码的按钮。无法绘制的示意图会显示它的代码和原因。
- **图表和小工具**：图表、带批注的图、计算器、带滑块的模拟或简短的测验会在回复内部运行，与应用和你的文件隔离，就像智能体展示的网页一样。它沿用应用的外观并自动调整大小（较高的可用**查看全部**打开）；它的栏里有**显示代码**（**显示效果**可返回）、**另存为文件**和**全屏**。你在上面点选的内容会进入你的消息框。回复还在撰写时，它会就地逐步构建（在有内容可显示之前显示“正在撰写…”），完整后才会活起来。
- **图片**：来自网络的照片（某个地点、产品、植物、艺术品）以及这台电脑上的图片，会适配回复的版面；点击一张可查看大图，其中**编辑**会在图片编辑器中打开它（[编辑图片和视频](/guide/library#edit-pictures-and-videos)）。来自网络的图片经由本应用的服务器传来，所以提供图片的网站永远看不到你的浏览器。无法加载的图片会显示为指向它的链接。

如果想要纯文本，可以在你的[智能体准则](/guide/guidelines)中说明（“用纯文本回答，不要使用示意图或图片”），或者在消息里说明。你也可以用平常的话要求其中任何一种：“把这些步骤画成流程图”“给我看看它的图片”“给我一个滑块，让我试试其他数值”。

### 回答卡片：回复中的卡片、图表和地图

当回答的某一部分是需要查看、比较、选择、跟随、尝试或练习而不是阅读的内容时，智能体会用应用的某种回答卡片来展示：近 150 种现成的卡片、表格、图表、地图、图库、时间线和小工具，里面填入的是这个回答自己的内容。多于几行的回答大多都有这样的部分，所以你在大多数回答中都会看到它们。要比较的选项会变成一张表格，每一行中的最佳值会被标出；食谱会变成一张卡片，份数可以调整用量；天气预报会显示接下来的几小时和几天；地点会显示在带编号图钉的地图上；测验或练习题则是你可以就地作答的题目。每一种都会随着回复的生成逐步构建，采用应用的外观，浅色或深色均可。

- **你可以在其中做什么**：对表格排序和筛选，把图表切换为数字，勾选清单，启动食谱的计时器，翻转闪卡，配对或填空，回答排障向导的问题，转动转盘替你做选择，拖动计算器或函数图像的滑块，播放视频。你勾选或回答的内容，在你回到这个设备上的对话时仍然保留（练习题的答案也一样）。标有**发送**字样的按钮（**发送我的选择**、**发送我的得分**、**发送我的结果**、**发送**等）会立即把它所指的内容作为你的下一条消息发出，就像你亲自输入并按下回车一样：你选的选项、你的测验得分、转盘停下的位置。旁边的**已发送**表示已经发出。你正在写的内容仍留在消息框中；如果会话此刻无法接收消息（另一条还在发送途中），这些文字会改为进入消息框，由你自己发送。有些功能更进一步：
  - 你用自己的话或数字作答的**练习题**会当场检查（数字在容差范围内即可，文字不区分大小写；正确答案如果唯一的失误是重音符号，会指出来）。**显示提示**会一次给出一条提示；做过尝试后，或者所有提示都显示完后，会显示详细解答。你会得到一个得分，**发送我的结果**会把它发给智能体。你对开放性问题的回答用**发送以供检查**发出，由智能体来检查。
  - **可以运行和修改的代码**：演练场可以就地运行 JavaScript、Python 或小型网页，与应用隔离，输出（以及 Python 的图表）显示在下方。上面有**运行**、**重置**、**复制**和**发送我的代码**（发给智能体查看），还可能布置一些任务让你尝试。Python 在第一次使用时需要从网络加载，所以它无法在[保密会话](/guide/sessions#keep-a-session-confidential)中运行。
  - **代码讲解**以导览的方式解释代码：编号的步骤位于代码旁边，每一步会点亮它所讲解的行，其余部分变淡。用箭头（或 **←** 和 **→** 键）逐步浏览，或者点击某一行打开讲解它的那一步。**询问这一步**会把一个关于它的问题放进你的消息框。
  - **逐步运行的程序**会显示程序在每一步所处的位置：当前所在的行、它的变量（刚变化的会被标出）、正在进行的调用，以及到目前为止的输出。可以前后步进、拖动滑块或按播放键。当它要求你先预测输出时，输入你的猜测并按**检查**。**询问这一步**在这里同样可用。
  - **关系图**显示事物之间如何关联（概念图、小说中的人物、什么依赖什么）：点击一个节点可点亮它的连线并阅读它的备注，可以拖动节点，查看图例，或者切换到**列表**视图。
  - **带批注的文字**会标出文本中的段落：点击其中一处可阅读它的备注（更正、评论、含义）以及它建议的修改，或点击**问问这个**。可以按类别筛选备注，在**原始比例**和**已更正**之间切换，使用**复制更正后的文字**，也可以听这段文字。
  - **事实核查**会逐条检查论断，每条都有结论、原因、智能体的把握程度，以及支持和反对的证据与来源。顶部的结论统计在你点击时会筛选论断。
  - **追问**是回答末尾的两到五个按钮，给出接下来的问题或步骤：当你的消息框为空时，点击一个会把它作为你的下一条消息发出，否则会把它添加到你正在写的内容中。用过的按钮会打上对勾。
- **图片**：没有图片或图片无法加载的条目会不带图片显示，文字占据其空间，所以不会留下空框。
- **来自电子表格或文件的数字**：表格、图表、关键数字、排名、直方图或地图上的数值，可以从你的某个电子表格（参见[电子表格](/guide/library#spreadsheets)），或者对话所在文件夹或其项目文件夹中的 CSV、TSV、JSON 或 JSONL 文件读取数字，而不是自己存放这些数字。当数字本来就在那里、行数超过几十行，或者是你可能想保留的卡片时，智能体会这样做：卡片自己进行求和、计数、分组、筛选和排序，所以不需要重新输入任何内容，并且每次显示时都展示最新的数字（之后添加的行也一样，除非它指定了固定的单元格范围）。卡片下方有一行说明数字来自哪里（**数据来自** *Shop numbers · Sales*，这是一个会打开该电子表格或文件的链接）、读取的时间，以及只显示了一部分时显示了多少（“显示 12,400 行中的 1,000 行”）；**重新读取**会再读取一次，保存电子表格时卡片会自动重绘。如果电子表格、它的标签页、某一列或文件已不存在，卡片会用通俗的话说明，并附上**重试**。卡片只读取其对话所在文件夹中的文件，不会读取你电脑上的其他位置，文件最大 50 MB（JSON 文件为 20 MB），并且只读取前 1,000,000 行；在[保密会话](/guide/sessions#keep-a-session-confidential)中创建的电子表格只有该会话中的卡片才能读取。
- **鼠标悬停时**（或用键盘到达它时），卡片右上角会出现一个小栏：**显示数据**会显示智能体写的内容（对于读取电子表格或文件的卡片，则显示它从哪里读取以及显示了其中的什么；**显示效果**可返回），**复制为文本**会把它复制为纯文本，**全屏**会把卡片单独显示在页面上方，宽度与你的窗口相同（在手机上是整个屏幕），较高时可滚动；**Esc**、**关闭**或点击卡片旁边都可以返回。在**更多**（…）下：**固定到看板**会在你的某个看板上保留一份卡片副本，可以选一个现有的，也可以在那里命名一个**新建看板…**，以便日后与其他卡片放在一起查看（参见[看板](/guide/library#boards)）；**另存为图片**会把卡片保存为 PNG，保持你所看到的主题外观，尺寸为两倍大以保持清晰，并以它的标题命名，**复制为图片**会把同样的图片放到剪贴板上，便于粘贴到消息或文档中（前提是你的浏览器允许网页这样做）。全屏时顶部也有这两项。内含地图、由图表库绘制的图形、视频播放器或代码演练场输出的卡片没有图片按钮（但仍然可以固定）：这些部分无法绘制到图片中。
- **智能体何时使用它们**：智能体被告知，回答中凡是需要查看、比较、选择、跟随、尝试、练习或保留的部分都要使用一种，这在多于几行的回答中大多数时候都适用：需要权衡的选项、带图片和细节的事物（地点、产品、电影、书籍、人物、论文、新闻）、数字、时间和计划、要做的事、要学的东西、要检查的文字、要核实的论断，以及你可能想采取的后续步骤。它们会填入图片，并在观看比照片更有帮助时播放视频。卡片无法表达的内容（推理、建议、注意事项）仍留在智能体自己的话里。普通对话、对简短问题的简短回答以及代码改动仍然是文本。每一个回答，无论是第一个还是之后的，都可以包含若干张卡片，每个部分一张（旅行的行程、天气和打包清单），所以一段对话会累积回答所需的任意多张；之后的回答可以再次展示某一张，并更新其数据。智能体通过一次查找来找到合适的卡片：对已经知道的按名称查找，对其他部分则用几个词描述每一部分展示的内容（按词查找，并且当在[设置 → 记忆](/settings?s=memory)中开启了**按含义搜索**时，也按含义查找），所以不会把全部卡片都交给它。[内置智能体](/guide/agents#the-built-in-agents)各自会偏向使用适合其工作的那些。
- **查看全部**：[回答卡片](/answers)会按分组展示每一种及其示例：摘要、比较、购物、地点和旅行、食物、计划、工作和商务、数字和图表、金钱、学习、科学、媒体、人物和体育、写作以及代码。**播放生成过程**会展示某一张像回复那样逐步呈现的样子。

也可以用平常的话要求使用：“用表格比较一下”“把它们放到地图上”“就这个考考我”“给我出一些这方面的练习题”“在我的文章上标出需要修改的地方”。你的[智能体准则](/guide/guidelines)（“用纯文本回答，不要使用卡片或图表”）或你的消息也可以要求改用纯文本。

### 打开一个步骤查看它的输出

点击任意一个步骤即可打开：

- 命令：命令本身、它运行所在的文件夹、退出代码和耗时、一个复制按钮，以及它的输出（输出被截断时有**加载完整输出**）；
- 文件编辑：差异（被截断时有**加载完整差异**）；
- 文件读取：指向该文件的链接和读取的内容；
- 网页：它的地址和从中读取的内容；
- 交给子智能体的任务：**布置的任务**，以及返回的结果；
- 其他任何步骤：智能体发送的内容和返回的内容。

步骤可能被标为**后台**（它会继续运行）、**自动**（Custom 的自动模式做出了决定，悬停可看原因），或者显示红色的退出代码。后台任务（留着运行的命令、监视器、工作流）会与会话的子智能体一起列在消息框上方的一行中；打开某个任务可查看它的输出（Claude Code）并**停止**它，停止前会先询问；子智能体则作为一个独立的会话打开。参见[子智能体](/guide/sessions#subagents)。

## 在智能体启动前构建项目的记忆

当你在起始页的某个项目中新建会话，而该项目的 [Wiki 记忆](/guide/wiki-memory)还很新（少于 10 篇文章，也还没有运行过根据历史记录的构建），并且项目里有可用来构建记忆的内容（对话、提交信息、文档、备注、README 或 docs/ 文件夹）时，会话会先询问你。你的消息下方会出现一张卡片，写着 **要先构建 <项目> 的记忆吗？**，说明将读取哪些内容，以及智能体启动前大约需要多长时间。在你做出选择之前，会话会显示 **需要你处理**（你也会收到通知）：

- **构建记忆，然后开始**：开始构建记忆，卡片变为构建进度，会话显示 **正在构建记忆**。你的消息会先等着（“记忆就绪后发送给智能体”），一旦最重要的部分写好，就会发给智能体：包括根据项目文件生成的项目概览、项目的备注，以及内容最丰富的那些对话。其余部分会在后台继续构建，写好一篇，智能体就能找到一篇。**立即开始** 会马上发送你的消息，并让构建继续进行；**停止构建** 会停止构建（已写好的内容会保留）并启动智能体。你可以关闭应用：智能体会自动启动。如果在那之前构建失败，卡片会告诉你，并提供 **重试** 和 **仍然开始**。如果智能体在收到你的消息之前就已结束（它崩溃了，或者等待期间电脑重启了），并且无法再次启动，卡片会提供 **在新会话中开始**：使用相同设置的新会话会收到你的消息，接手你在此期间发送的内容，而那个空会话会被归档。
- **不用记忆直接开始**：智能体立即启动，并且这个项目一周内不会再询问。
- **不再为此项目询问**：以后不会再为这个项目询问。**根据历史记录构建 Wiki…** 仍然保留在项目详情的 **记忆** 标签页的 **⋯** 菜单中。

在等待期间你发送的任何内容，都会排在第一条消息之后发给智能体。只有当你自己在起始页新建会话时才会询问；定时运行、应用、子智能体或由智能体启动的会话从不询问，已经构建过的项目也不会询问。

## 批准或拒绝智能体想做的事

当智能体想做的事超出了它的权限、无法自行完成时，它会等待，并在对话末尾用一张卡片向你询问：它想运行什么、带有差异对比的文件更改，或者其他工具及其详情，同时显示已等待多久。会话的圆点会变成琥珀色，收件箱会计入这一项，如果你开启了通知，还会收到通知。你可以在卡片上回答，也可以在[收件箱](/guide/inbox)中回答；如果只是简单的“是”或“否”，在浏览器显示按钮的情况下，还可以直接在通知上回答。

按钮由智能体决定：

- **Claude Code**：**允许**、**拒绝**，通常还有一条规则，例如“始终允许 Bash npm test”或“在此会话中允许所有编辑”。
- **Codex**：**允许**、**在此会话中允许**、**始终允许此命令**、**拒绝**、**拒绝并停止**；文件更改有 **在此会话中允许编辑**；更广的权限有 **在这一轮中允许** 和 **在此会话中允许**。
- **Custom**：**允许**、**始终允许**（后面跟着它所涵盖的确切内容，只包括你批准的那条命令，因此后面不会夹带其他内容）以及 **拒绝**。
- 其他智能体：它们提供的选项。

**拒绝** 会先打开一个输入框，“可选：告诉智能体改做什么”；再按一次 **拒绝** 即可发送，可以附带备注，也可以不附带。（Custom 的 **拒绝** 和 Codex 的 **拒绝并停止** 会立即回答。）

已连接账户中你设为 **先问我** 的工具不会在会话中询问：这次调用会被保留在发件箱中，智能体继续工作。对话中会出现一行 **在发件箱中等你确认**，之后会显示它是已发送还是已丢弃（[发件箱](/guide/inbox#the-outbox-calls-held-for-your-ok)）。

在 Claude Code 的 **自动** 模式下，安全检查可能直接拒绝某条命令，而不是询问。此时消息框上方会出现一张卡片，写着“Claude 拦截了一条命令”并说明原因。**批准并重试** 会把会话切换为询问，并让智能体再次运行该命令，这样它会作为一次普通批准回到你面前；**关闭** 则保持现状。

## 回答问题并批准计划

当智能体向你提问时，会出现一张带琥珀色边框的卡片，显示问题及其选项：

- 选择一个选项；如果写着“任选”，则可以选择多个。**其他——输入你自己的答案** 可以输入你自己的话。
- **附加文件** 可以为回答添加文件。
- 按数字键 1 到 9 可以选择第一个尚未回答的问题的对应选项。
- **发送回答** 会把它作为你的下一条消息发送。如果会话在提问时已停止，**继续并回答** 会带着你的回答重新启动它。对于在 VS Code 或终端中等待的 Claude Code 会话，**在此回答** 会在那边结束它，并在这里带着你的回答继续；在那边等待的 Codex 会话则必须在那边回答。

当问题以审批卡片的形式出现时，它的按钮是 **发送回答**，对于 Claude Code 还有 **跳过**。

**计划.** 在 Claude Code 的 **计划** 模式下，智能体先阅读和规划，然后在一张卡片中展示它的计划：**批准，自动接受编辑**（继续执行，编辑时不再询问）、**批准，编辑前先询问**，或 **继续规划**（它仍停留在计划模式；告诉它要改什么）。在 Codex 的计划模式下，Codex 会先讨论和规划，并且可以向你提出澄清问题。Custom 的计划模式以一份带编号的计划结束；切换权限（Shift+Tab）并回复，即可让它执行。

## 填写服务请求的表单

当你连接的某个服务在任务进行到一半时需要你提供信息（日期、选择，或需要批准的页面），它的表单会以卡片形式显示，无论是哪个智能体在工作：“Linear 请你填写表单”“……请你打开一个页面”或“……请求继续”。填写各字段后按 **发送**（或 **打开**，它会打开该页面，或 **允许**），也可以按 **拒绝** 或 **暂不**。Codex 自己的工具服务器也以同样的方式询问。参见[已连接的应用、密钥和工具](/guide/connections)。

## 智能体工作时给它发消息

一轮运行期间你也可以输入。此时按 Enter 会怎样，取决于每个浏览器各自在[设置 → 应用 → 通用](/settings?s=general&find=Sending%20while%20an%20agent%20works)中的 **智能体工作时发送**：

- **加入本轮**（默认）：按 Enter 会把你的消息加入正在进行的这一轮，智能体会立即考虑它。Ctrl+Enter（Mac 上为 ⌘Enter）则把它放入队列。
- **等它结束**：按 Enter 会把你的消息放入队列，在这一轮结束时发出。Ctrl+Enter 则把它加入本轮。

消息框会说明是哪一种：“将后续消息发送到正在运行的这一轮”或“将消息排队，等这一轮结束后发送”。在触摸屏上，发送按钮的作用与按 Enter 相同。Custom 会在下一个模型步骤拾取后续消息，即在正在运行的工具完成之后；对排队的消息，**立即发送** 的效果相同。如果你的 Custom 会话在应用更新之前就已在运行，还无法接收实时后续消息，那么你的消息会留在队列中，直到这一轮结束。其他 ACP 智能体一次只接收一条消息，所以在它们工作时发送的消息总会在队列中等待。在 Claude Code 中，智能体工作期间发出的消息下方会显示“工作时发送”。智能体对它的回答会显示为你消息下方的一条回复，即使智能体随后继续做它的工作。

## 管理队列

排队的消息在消息框上方等待，按发出的顺序编号；你刚发送的排队消息会立即显示在那里。每当一轮结束，就会自动发出一条。

- 拖动消息的手柄可以调整顺序。
- **立即发送**（箭头）：立即发送，进入正在运行的这一轮。
- **编辑**（铅笔）：修改文本、移除附件，或添加更多附件（**附加**，或粘贴、拖入文件）。按 Enter 保存，按 Esc 取消。
- **移除**（垃圾桶）：把它从队列中移除；它的附件会被删除。
- 当你停止智能体，或应用重启时，队列会暂停：“队列已暂停（智能体已停止，或服务器已重启）。”**继续** 会让消息在智能体空闲后重新发出。智能体之间互相发送的消息（会话发给其 Hydor 子智能体的消息及其回复）不会因重启而暂停：如果它们等待的智能体仍在工作，就会在其这一轮结束时发出。达到花费上限也会让队列暂停；提高上限后即可继续。

## 更改智能体、模型、思考强度或权限

会话的消息框带有起始页的 **智能体**，以及它的三个选项 **模型**、**思考强度** 和 **权限**，它们在 **+** 旁边的一个标签里（它会打开 **选项**，在手机上是从底部弹出的面板）。其下是起始页上适用于本会话的其余选项，顺序相同：**账户**（从你的下一条消息起由另一个账户接管会话；智能体有多个账户时才显示）、**保密** 和 **竞技场**（按原样显示：两者都在会话开始时选定，点击会说明如何获得另一个）、**记忆**、**花费上限**、**集群**、**研究** 和 **准则**（选项和对话框与会话菜单中的[会话设置](/guide/research#turn-it-on)相同；集群和研究从你的下一条消息起生效）。这个标签会显示智能体和模型，在思考强度和权限不是常规设置时也会显示它们；当智能体可以不经询问做任何事时（**绕过**，或 Codex 的 **完全访问**），它会变成琥珀色。更换智能体会从你的下一条消息起生效（参见[在会话中切换智能体](/guide/agents#switch-agents-in-a-session)）。模型、思考强度或权限的更改会立即应用于正在运行的智能体，并保留在该会话中。Shift+Tab 会切换到下一个权限模式。模型菜单只列出这个智能体的模型；要把对话转到另一个智能体，请使用[在另一个智能体中继续](#continue-in-another-agent)。

## 引用回复的一部分

选中智能体某条回复或你自己某条消息中的文字：文字上方会出现 **引用** 按钮（在触摸屏上则出现在下方）。它会把这段文字作为引用放入消息框，光标位于其后，这样你就可以回应那一部分，或者重提你之前说过的内容。

## 在会话中查找文字

在会话中按 Ctrl+F（⌘F）。**在此会话中查找** 会搜索你的消息和智能体的消息，包括尚未加载的部分（不含命令输出）。输入两个或更多字母；它会跳到最新的匹配项并高亮这些词，同时显示“第 3 项，共 12 项”。按 Enter 跳到较旧的匹配项，按 Shift+Enter 跳到较新的匹配项（也可以使用箭头），按 Esc 关闭。折叠的长消息会在找到的位置展开。在搜索框（Ctrl+K）中选中某条消息，会打开它所在的会话，并且此栏已填好内容。

## 消息框中的更多功能

- 在空消息框中按 ↑ 会调出你在本会话中之前的消息，最新的在前；按 ↓ 则向后翻。
- 你输入的内容会按会话在此浏览器中保存为草稿，所以你回来时它还在。
- Ctrl+S（⌘S）会把草稿放到一边并清空消息框；在空消息框中按 Ctrl+S 可以把它找回来。
- 很长的粘贴内容（32,000 个字符或更多）会作为文本文件附加，而不是塞满消息框。
- 占位文字会告诉你发送会发生什么：“给 Claude 发消息…”，或者在智能体未运行时显示“发消息以继续…”：发送会带着整个对话重新启动它。

## 详情面板：更改、命令和信息

页眉中的 **详情** 会打开一个带有三个标签页的面板。在宽屏上，它位于对话旁边，在你切换会话时保持打开；在较窄的屏幕上，它会滑出并覆盖页面；在手机上，只有当你要求时才会打开。

- **更改**：会话更改过的每个文件，更改最多的排在前面，并显示新增和删除的行数。点击某个文件可查看每次编辑的差异对比；**打开** 会打开该文件。
- **命令**：智能体运行过的每条 shell 命令，最新的在前，带有 **全部**、**失败** 和 **背景** 筛选。点击其中一条可查看其输出。
- **信息**：智能体、状态（与页眉相同：**完成**、**已停止**、**失败**，或它当前正在做的事）、文件夹、分支、模型和思考强度、已使用多少上下文、开始时间和最近活动时间、它的活动（提示、轮次、工具调用、命令）、令牌（输入、缓存、输出）、API 费用（同样的工作按 API 价格计算所需的费用）、输出速度、会话的启动位置（Hydor、VS Code、终端、Claude 桌面应用……），以及在其智能体运行期间的 **它的程序**：它们当前的占用（CPU、内存和数量），以及它所受的[限制](/guide/app#limit-each-session)。下方是它的后台任务（打开一项可查看它做了什么，或 **停止** 它），以及 **在终端中继续**：在终端中恢复该会话的命令，和会话 ID，各带一个复制按钮（Claude Code 和 Codex）。

## 读懂指示器：上下文、缓存和速度

麦克风旁边有一个带百分比的小圆环，随着对话用掉模型的上下文窗口而逐渐填满；其余信息在选项标签菜单的底部：

- **上下文**：圆环，以及选项中的 **上下文** 一行（“已用 42%”）。把指针移到圆环上可查看确切的令牌数。超过 85% 时它会变成琥珀色。点击圆环，或点击选项中的 **压缩**，即可压缩对话（一轮运行期间不可用）。在 Custom 会话中，把指针移到圆环上可查看令牌数及其去向的明细，明细位于 **上下文** 一行的箭头下方；Custom 会自动精简，所以没有 **压缩**，点击圆环也没有任何作用（参见[长对话与长输出](/guide/custom#long-conversations-and-long-output)）。
- **cache 4m**（Claude Code）：提示缓存会让对话保持就绪一段时间（5 分钟或一小时），这样下一条消息更便宜、更快。在你不发送任何内容时它会倒计时；在那之前发送消息会复用它，并重新开始计时。**缓存已过期** 表示下一条消息会重新构建它。
- **85 tok/s**：上一条回复的写出速度，单位为每秒令牌数。

## 停止一轮、停止智能体或继续

消息框旁的“停止”按钮在智能体启动或工作时带有一圈旋转的圆环。智能体需要你操作时，圆环会暂停；如果你的设备设置了减少动态效果，圆环则保持静止。一轮结束后，只要智能体启动的后台任务或子智能体仍在运行，例如 Hydor 子智能体、Claude Code 子智能体、一直运行的命令或监视器，“停止”按钮就会连同圆环一直保留；发送按钮就在它旁边，消息框也照常接收你的消息。把鼠标指向“停止”，就能看到它会停止什么：“停止本轮、2 个子智能体和 1 个后台任务”，或“停止 2 个子智能体”。它会一次性全部停止：本轮、每个正在运行的子智能体、每个正在运行的后台任务，以及它们各自接着启动的那些。以这种方式停止的 Hydor 子智能体不会再向其父级汇报；已经在路上的汇报会留在父级已暂停的队列中等待，而不会唤醒父级；按下 **继续** 即可放行队列。

- **停止一轮**：按下标题栏中的 **停止**，或消息框旁的圆角方形按钮，它同时也会停止本会话启动的其他内容（见上文）。（Esc 不能停止：它只会关闭已打开的内容，例如查找栏或列表。）智能体会停下手头的工作，这一轮会显示“已停止于…”。你一按下 **停止**，会话就会显示已停止，即使智能体还要几秒钟才能完全结束（例如结束它正在运行的命令）；如果 20 秒后智能体仍在工作，会话会重新显示为工作中。智能体仍可接收你的下一条消息，队列则会暂停，直到你继续它。
- **停止智能体进程**：会话菜单（⋯）→ **更多** → **停止智能体进程**，仅在没有正在进行的一轮时可用。智能体的程序会结束；会话及其历史记录保留，并显示它上一轮的结束方式（**完成**、**已停止** 或 **失败**）。
- **继续**：标题栏中的 **继续** 会带着完整的对话重新启动智能体；你也可以直接发送一条消息（“发送消息以继续…”），同样会重新启动它，Claude Code、Codex 和 Custom 都一样。在 **完成** 之后，**继续** 会变成一个更低调的按钮，因为你只需发送下一条消息即可。如果会话在几秒前刚被写入，比如来自 VS Code 或终端，应用会先询问你，因为两个程序同时写入一个会话可能会损坏它的历史记录。
- 空闲的智能体会在三小时后自行停止（前提是没有等你处理的事项，也没有后台任务在运行）；你的下一条消息会让它重新启动。

## 为会话设定目标

目标会让智能体一轮接一轮地持续工作，直到你认可的检查项全部成立。你和智能体先把“完成”的含义商定为一份简短的检查项清单。之后应用自己会在每一轮结束后运行这些检查项，并判断这一轮是否让事情更接近目标。所以智能体说“完成了”不起任何作用：只有检查项才能结束目标。它适用于所有智能体（Claude Code、Codex、Custom 以及你添加的其他智能体），因为驱动它的是应用自己的循环。

设定目标的方法：打开会话的菜单（⋯）→ **设定目标**，写下工作完成时应当成立的事（“npm test 通过，并且上传页面能处理 2 GB 的文件”），选择 **向你询问的频率**，然后点击 **起草检查项**（或按 Ctrl+Enter）。你也可以在开始会话时就设定：在起始页打开 **选项** → **目标** → **直到完成**，你的第一条消息就是目标。以下情况无法设定目标：由其他会话启动的会话（Hydor 子智能体：它的菜单里没有 **设定目标**）；在 VS Code 或终端中运行的会话（请先在应用中继续该会话）；处于计划模式的会话（智能体不会更改任何内容）；领导战役、深度研究或竞技场对战的会话（“这个会话带领着一场战役：目标可以与集群配合使用，暂不支持战役。”，其他情况类似）；以及已有所用程序自带 `/goal` 的会话（请先用 `/goal clear` 清除）。如果你用 **目标** 启动的会话无法设定目标，它会作为普通会话继续，并有通知说明原因（“未能设定目标：……”）。一个会话同一时间只能有一个目标，而目标会消耗很多轮对话：下面商定的限制可以控制它的消耗。会话被归档时，或被 **从这里编辑** 替换时，目标会自动停止。

侧边栏中的靶心标记显示哪些会话有目标；将鼠标指向它可以看到当前是第几轮以及有多少检查项成立，会话自己的 **选项** 标签上会显示“目标模式”。你第一次从起始页开启目标时，会有一条简短的提示说明它的作用和成本。

### 商定“完成”的含义

智能体会阅读项目，并提出检查项、不得更改的路径和限制。你会在消息框上方的一张卡片 **“完成”是这个意思吗？** 上看到它们。**完成条件** 列出各项检查，每项都有一个标签表示它的类型：

- **命令**：必须通过的命令（“npm test”）。
- **已测量**：打印出一个数字的命令，并带有目标值：至少或至多（“搜索 p95 低于 200 ms”）。某一轮可以比目前最佳值稍微落后一点（最佳值的十分之一）而仍然算数。
- **审查者**：一句需要审查者判断为真的话。审查者是一个没有参与任何工作的模型：它会阅读改动的内容、检查项指明的文件或输出，并说明这句话是否成立及理由。它用于命令无法证明的事情，例如“设置页面有深色模式”。
- **你**：只有你才能确认的事。当其他检查项都成立后，它会等你确认。

**已妥善保存** 显示智能体不能更改的路径（测试、测试数据、检查项自带的脚本）以及它工作的位置。**限制** 是它最多可以使用的轮数、费用（按 API 价格计算）和时间；轮数来自 [目标暂停前的轮数](/settings?s=custom&find=Rounds%20before%20a%20goal%20pauses)（默认 30，除非你修改），费用和时间在你设置之前不设限。在 **向你询问的频率** 下，你仍然可以更改它询问的频率。如果会话的花费没有价格（使用的模型没有定价），卡片会说明费用限制无法让它停下，轮数和时间限制仍然有效。

应用会在任何一轮开始前测量当前进展，所以卡片上会显示“3 分钟前已测量 · 5 项中 3 项成立”。只有当会话的权限本来就允许智能体无需询问即可运行命令（Claude Code 的 **绕过**、Codex 和 Custom 的 **完全访问**），并且会话不是保密会话时，应用才会在提出方案后立即测量。否则暂时什么都不会运行，卡片会显示“尚未测量”和“你点击 **开始** 时，检查项会首次运行”：这些命令是智能体提出的方案，需要你先同意。无法运行的检查项视为不成立；卡片会说明这一点，按钮则显示 **仍然开始**。

检查项的运行方式与会话自己的命令相同，绝不会更宽松，并使用智能体获得的环境。在保密会话中，它们始终在应用的沙盒中运行且不联网；在没有沙盒的电脑上则完全无法运行（检查项会显示“这台电脑上没有可运行它的沙盒”）。在处于自动模式且开启了沙盒的 Custom 会话中，它们也在沙盒中运行，并限制在该文件夹内；在权限低于 **完全访问** 的 Codex 会话中，它们在沙盒中运行，限制在该文件夹内，并且不联网，除非 Codex 自己的沙盒策略允许联网；其他情况下则直接运行。

- **开始**：同意这些检查项。如果它们已经全部成立，目标立即达成；否则第 1 轮开始。
- **修改…**：把各行变成可编辑的字段。你可以删除某个检查项，编辑它的标签、命令、目标值或句子，**添加检查** 的某种类型，编辑受保护的路径（每行一个）和限制，然后点击 **开始**。**取消更改** 会让卡片恢复原样。
- **暂不**：停止该目标。

如果智能体被要求两次后仍未提出任何检查项，应用会替它提出一项：由审查者对照你的目标阅读这些改动。

### 各轮：保留或撤销

在每一轮中，智能体会得到要处理的内容：每个检查项的现状、上一轮做了什么、你对它提出的要求以及哪些内容不能更改。它的工作方式与处理任何消息时一样，使用会话已有的权限，并在告知应用它做了什么、还剩什么之后结束这一轮的回合。你自己的消息仍然优先：它们是这一轮之内的普通回合。

回合结束时（并且智能体启动的任何内容，例如 Hydor 子智能体，都已不再工作），应用会运行所有检查项。对于仍在运行的命令，例如开发服务器，应用会在回合结束后等待 10 分钟，然后无论如何都会运行检查项。你在两轮之间对文件所做的更改，绝不会被算作这一轮的改动，也绝不会随这一轮一起被撤销。当事情更接近目标且没有任何东西被破坏时，这一轮为 **已保留**。出现以下情况时，这一轮为 **已撤销**：

- 它更改了不允许更改的路径；
- 它违反了你的某条规则（参见 [随时引导它](#steer-it-whenever-you-want)）；
- 某个原本成立的检查项不再成立；
- 某个测量值远远落后于它的最佳值；或
- 没有任何东西更接近目标。

被撤销的一轮会让文件恢复到这一轮开始时的样子（即目前最好的一轮，列表中标有 **目前最佳**，除非你在两轮之间改动过什么）。这要求会话在工作树中工作（起始页的 **新建工作树**）；卡片会告诉你属于哪种情况，“它在自己的分支上工作”或“它在你的文件夹中工作，其中无法撤销某一轮”。在你自己的文件夹中，更差的一轮会被标为 **保持原样**，并且会告诉下一轮哪里变差了，以便它加以纠正。

只有在这一轮开始后没有其他人在该文件夹中工作过（例如同一文件夹中的另一个会话，比如一个分叉），并且本会话自这一轮结束后一直保持安静时，应用才会自行恢复文件。在此之前，它会把文件夹里的所有内容，包括检查项自己的输出和你所做的任何编辑，保存为这一轮自己的文件，所以对该轮点击 **仍然保留…** 就能把一切找回来。如果另一个会话在该文件夹中工作过，或者有过提交，这一轮就 **不会被撤销**：它会保留下来，标为 **保持原样** 并给出原因（“它没有被撤销：另一个会话（“…”）正在该文件夹中工作”），目标继续进行，并且会告诉下一轮文件没有被恢复。如果是你自己的消息在检查项运行期间到达，则会在会话安静下来后重新检查这一轮（三次之后目标会暂停：“第 4 轮无法检查：检查项运行期间，会话仍在该文件夹中继续工作。点击继续可重新检查。”）。应用绝不会尝试第二次：如果恢复文件没有完成（失败，或应用在中途重启），目标会暂停一次并显示“恢复第 4 轮的文件没有完成，所以文件可能只恢复了一部分。该文件夹中的所有内容都已保存：对第 4 轮点击 **仍然保留…** 即可找回。点击继续会从文件当前的样子接着进行。”被某个已保留的轮次删除的文件，在之后的撤销后仍然保持已删除。

消息框上方的一个栏会显示目标、它正在做什么（“第 7 轮，共 12 轮 · 工作中”、“正在运行检查项”、“正在询问你”、“已暂停”）、每个检查项的一个标记（成立时是对勾；数字类的显示“0.73 / 0.80”并带一个小进度条；尚未成立的是空心圆点；无法运行的是琥珀色标记）、相对于限制的费用和时间，以及 **轮次 · 3 已保留 · 2 已撤销**。点击它会打开各轮的列表：每一轮做了什么、什么发生了变化（“相关性 0.61 → 0.68”）、它是 **已保留** 还是 **已撤销**、花费多少、用了多长时间。打开某一轮可以看到智能体的报告、每个检查项的结果，以及这一轮为何如此收场。循环发给智能体的消息在对话中显示为安静的一行，“目标 · 第 5 轮，共 12 轮”；点击它即可阅读该消息。

对于一个原本成立、现在却无法运行的检查项（审查者不可用、超时、缺少工具），并不算它不再成立：它会再运行一次，如果仍然无法运行，目标就会暂停（“‘测试通过’无法运行：……点击继续可重新检查这一轮”），这一轮既不保留也不撤销。如果审查者无法读取你的规则，这一轮会继续，并且它那一行会显示“这一轮无法检查你的规则”。

当所有检查项都成立时，应用不会立刻相信：它会把命令和数字再运行一遍，并由审查者阅读整个改动，确认没有测试被削弱或跳过、没有把答案写进代码，并且目标确实已经达成。只有这时目标才算达成。如果这一步未通过，下一轮会被告知最终检查发现了什么，从那时起，当没有任何东西被破坏且文件有变化时这一轮就被保留，而文件没有变化时则以“无变化”为由被撤销。此时 **你** 检查项会来询问你：**成立** 或 **还没有**，可以附上备注，而“还没有”的处理方式与上述相同。

### 向你询问的频率

**向你询问的频率** 有三种设置，位于起始页、**设定目标** 对话框、卡片以及栏上的标签中：

- **自行进行**（标签显示“自行工作”）：只有在没有你就无法继续时才询问（需要只有你能提供的东西，或需要只有你能确认的检查项）。
- **在转折点**（默认；标签显示“在转折点询问”）：当它即将改变做法时询问，这发生在连续两轮没有进展之后。
- **每一轮**（“每轮询问”）：每一轮结束后，它会展示自己的发现以及对下一轮的选择。

询问时，会出现一张问题卡片，列出两到四种继续的方式，每种都有理由、应带来什么、需要付出什么代价，智能体自己的选择上标有 **它的选择**。你可以勾选一种或多种方式，它们会按你勾选的顺序依次执行。**其他：请说明哪种方式** 可以填入你自己的方式，**给智能体的备注（可选）** 会放进下一轮。主按钮显示为 **走这条路**，或“按此顺序执行这 2 项”；**仅限它的选择** 采用智能体的选择。按键 1 到 4 可勾选对应的方式。

如果没有回答，它会在 10 分钟后按自己的选择继续（分钟数为整数，0 到 1,440，其中 0 表示一直等待），或者等你：**如果你不回答** 中有这两个选项。卡片会倒计时（“9 分钟后按它的选择继续”），**等我** 会停止倒计时。只有你能确认的检查项，或只有你能提供的东西，始终会等你。

### 随时引导它

你可以随时引导目标。

- 像往常一样 **给智能体发消息**：你的消息优先，这一轮从那里继续。
- 栏中的 **暂停** 和 **继续**。正在运行的一轮会先完成，并像任何一轮一样接受检查（栏上会显示“本轮结束后暂停”，此时点击 **继续** 会取消暂停）；之后目标会等待，在你继续之前不会再发送任何内容。这时正是对某一轮给出你的意见的时机（见下文）。如果想让智能体立即停下，请在会话中停止它：目标会在这一轮尚未检查的情况下暂停，**继续** 会检查它做了什么。**停止** 会结束目标（见下文）。
- 栏上 ⋯ 菜单中的 **添加规则…** 会把某件事固定下来，从现在起每一轮都适用（“不得新增依赖”）。审查者会按你的规则检查每一轮；违反规则的一轮会被撤销。规则显示在 **来自你** 下，每条都有一个 × 用于移除。
- 同一菜单中的 **更改检查项…** 可以在目标运行期间编辑检查项、路径和限制；你添加或更改的检查项会重新测量。只更改了目标值（或单位、容差、时限、名称）的检查项会保留它的值：它会按新的目标值重新判定，而不会重新测量。对限制的更改立即生效。在某一轮运行期间对检查项或路径所做的更改，要等这一轮按它开始时的检查项判定完毕后才生效（栏上会显示“你对检查项的更改将在这一轮之后生效。”），否则从下一轮起生效。
- 某一轮上的 **你的意见**，适用于会话在工作树中工作且目标不在某一轮中途时（请暂停它，或等待）。以下情况会被拒绝，并附一句说明阻碍原因的话：本会话的智能体正在工作时（“这个会话的智能体正在工作：请等它的回合结束后再试。”）、另一个会话正在该文件夹中工作时、自目标上次留下文件以来文件夹中做过提交之后（请先把它移到自己的分支上），以及自目标上次留下文件以来有文件在目标之外被更改时：消息会列出这些文件（最多五个），并给出要在工作树顶层文件夹中运行的命令：它们把你对这些文件的更改搁置到 stash 中，并恢复目标自己的版本（`git stash push --include-untracked -- <files>`，然后 `git restore --source=<checkpoint> --worktree -- <files>`；超过十个文件时，对整个文件夹做同样的事），这样你自己的更改绝不会丢失。在某一轮运行时被暂停的目标，其文件夹中留有该轮尚未检查的工作：此时消息会这样说明，按 **继续** 后应用会先检查这一轮：
  - 对已撤销的一轮点击 **仍然保留…**，会保留它的文件并使它成为最佳。对于每个未达标的已测量检查项，你可以保留目标值，或把它改为这一轮达到的值，并说明理由。
  - 对已保留的一轮点击 **撤销**，会让文件恢复到它之前保留的那一轮，并且它所尝试的做法不会再被尝试。
  - **从这里换一种方式** 会保留这一轮的文件，并让下一轮从那里起采用另一种方式；如果你愿意，可以说明改为尝试什么。

### 为集群设定目标

带领 [集群](/guide/research#set-a-swarm-on-a-hard-problem) 的会话也可以有目标：在开始页的 **选项** 中同时打开 **目标** 和 **集群**，在已经带领集群的会话中设定目标，或者在目标运行期间打开它的集群。战役、深度研究和竞技场不能与目标同时使用。

- **一轮就是整个集群的工作。** 应用把这一轮的消息发给主导智能体，由它让成员去处理尚未成立的部分：每人一个角度或一个检查项。它们都在主导智能体的文件夹中工作。
- **所有成员都完成时，这一轮才结束**：主导智能体的回合已经结束，没有成员还在工作，它们之间也没有任何内容在传递途中。在此之前，栏上会显示“正在等待 2 名成员”。之后应用会像对单个智能体一样，对主导智能体的文件夹运行检查项，这一轮或被保留，或被撤销。被撤销的一轮会连同成员所做的更改一起撤销。
- **成员在各轮之间会保留**，并记得自己的工作：主导智能体给它们下一步，为新的角度启动新的成员，并停止角度已经用尽的成员。每一轮的那一行会说明有多少成员在这一轮中工作过。
- **限制针对整个团队。** 费用统计主导智能体和每个成员花掉的钱，时间是团队在工作的时间，在一轮中途达到限制时，成员和主导智能体都会被停止。
- **暂停** 照常等待这一轮结束，在这里意味着等待每一个成员。集群看板上的 **全部停止** 会同时停止主导智能体和它的成员，目标随之暂停。
- 只有主导智能体会向你提问；有问题要问的成员会把它发布到看板上。

集群的一轮要花掉它所有成员花费的总和：是单个智能体一轮的好几倍。请给目标设一个合适的费用限制。

### 何时停止，以及给它更多

目标在达成时、你点击 **停止** 时，或达到上限（轮数、费用或时间）时会自动停止。以下情况它还会暂停并告诉你原因：你停止了智能体、某个回合失败、应用无法保存文件、恢复某一轮的文件没有完成（如上所述）、某个检查项无法运行、某一轮因会话一直在工作而无法检查、它的消息无法发送、应用重启第二次打断了智能体的回合（第一次时应用会重新发送这一轮的消息并说明情况）、应用恰好在循环的一条消息发出时重启（两分钟内没有任何启动，它会再发送一次消息，然后暂停并说明），或智能体因达到其套餐的用量上限而停止，并且应用不会自行让它继续。当会话的队列处于搁置状态时，目标会请你在那里点击 **继续**。应用重启后，目标会立即查看自己所处的状态，不必等待。随后一张卡片会显示报告：**达成目标**、**在上限处停止** 或 **由你停止**，包含轮数、费用和时间、一份摘要、一张表格（列出每个检查项在开始时、现在以及所需的状态；在目标运行期间添加或更改的检查项在开始列显示“—”，并以它首次被测量的那一轮之后作为标题），以及最终审查的理由。**查看改动** 会打开会话的改动。**关闭** 会移除报告，以便你设定新的目标。

在上限处停止的目标会显示 **给它更多…**：提高用完的那一项（轮数、费用或时间）并点击 **继续**；它会从文件当前的状态接着进行，就像任何一轮之后一样。在上限处等待期间，你仍然可以添加或删除规则，并更改向你询问的频率：它们会在它继续时生效。如果仍然触及上限，对话框会说明目标已经用了多少（“它已经运行了 4 轮：请给它比这更多。”，费用和时间同理），并且不会有任何改变。达到上限后不会恢复任何东西：因费用或时间上限而被中途停止的一轮，会保持智能体留下的样子留在文件夹里。它会被记录为独立的一轮（**保持原样**，“在上限处中途停止”）并附上它的文件，报告会写道：“第 4 轮被中途停止，它的工作成果仍在该文件夹中。对第 3 轮点击 **仍然保留…** 会让文件恢复到最佳的一轮。”**给它更多…** 会从文件当前的样子接着进行。已达成或被你停止的目标则就此结束。

通知：目标工作期间，你会在检查项准备好等你处理时、某个检查项无法运行时、它询问你或需要你时、它暂停时、它在上限处停止时，以及目标达成时（“目标已达成：……”）收到通知，而不是每一轮都收到一条“已完成”；当它在等你时，“已完成”通知不会被压下。参见 [各类通知的含义](/guide/inbox#what-each-notification-says)。

### 在 Claude Code 或 Codex 中输入的 /goal

在 Claude Code 或 Codex 的聊天中输入 `/goal` 并加上一个条件，是该程序自带的、更简单的目标：程序会一直进行，直到它判断目标已达成（Claude Code 在每个回合后检查；Codex 自行决定）。它没有商定的检查项、轮次或撤销，并显示在消息框上方较早的小栏中，带有 **暂停** 和 **继续**（Codex）以及 **清除**。会话菜单中的 **设定目标** 是应用自己的目标，适用于所有智能体。在 Custom 会话或其他智能体中，`/goal` 只是普通文本。一个会话不能同时拥有两者：在程序自带的目标已设定时，**设定目标** 会被拒绝；而在应用的目标运行时输入的 `/goal` 会像任何消息一样交给程序，没有任何东西会注意到它。

## 分叉会话

分叉是一个新会话：它从当前对话开始，然后尝试别的做法；当前这个会话保持原样。

1. 打开会话的菜单（⋯）→ **分叉**，或者在某条回复下方点击 **从这条回复分叉**（Claude Code 可用于任意一条回复；Codex 和 Custom 只能用于已结束的一轮中的最后一条回复），只保留到那里为止的对话。
2. 写下分叉要做什么（“分叉应该改为尝试什么？”）。
3. 点击 **分叉**（或按 Ctrl+Enter）。

分叉会话会打开，标题为“… · fork”，使用相同的智能体、模型、思考强度、权限和账户。它顶部有一行“Forked from …”，旁边是 **打开**（Codex 的分叉只显示之后的内容；之前的对话在原会话中）。分叉适用于 Claude Code、Codex 和 Custom，不适用于在其他应用中打开的会话。对话被压缩之前的 Claude Code 回复也可以分叉：分叉会从压缩之前的完整对话开始，直到那条回复为止。

## 从这里编辑

回到你的某条消息，换一种说法：

1. 点击你的消息下方的 **从这里编辑**。
2. 修改文字。
3. 如果也要撤销智能体此后所做的改动，请勾选 **把文件恢复到这条消息之前的样子**。
4. 点击 **从这里发送**（Enter），或点击 **取消**（Esc）。

对话会在一个副本中继续，副本只保留那条消息之前的内容，并沿用当前会话的标题；当前会话会被归档。恢复文件适用于：Claude Code（使用它为从本应用发送的消息所建立的检查点）、Custom（恢复它自己的编辑所改动的文件；命令造成的改动不会恢复），以及任何在工作树中的会话（每次你发送消息时都会生成一份快照）。Codex 会话只能在工作树中恢复文件。如果某一轮正在运行，请先停止智能体。如果会话的[目标](#give-the-session-a-goal)正在检查它的文件或正在恢复文件，恢复文件会被拒绝（“This session’s goal is checking its files right now: wait for it to finish, or pause the goal first”）；会话被替换时，目标本身也会停止。从这里编辑适用于 Claude Code、Codex 和 Custom。

## 在另一个智能体中继续

把对话交给另一个智能体，在那里继续：

1. 打开会话的菜单（⋯）→ **在 Codex 中继续**（或 **在 Claude Code 中继续**，或在 Custom 有了模型之后选择 **在 Custom 智能体中继续**）。
2. 消息框上方的一条提示会说明你的下一条消息将发送到那里；模型、思考强度和权限的选择现在作用于新的智能体。点击 ×（“留在这里”）可取消。
3. 写一条消息，或者直接发送以继续。

新会话会在同一个文件夹中打开，带有到目前为止的对话：你的第一条请求，然后是能放进约 15,000 个 token 的最近消息，以及改动过的文件。新的智能体会被告知完整对话保存在哪里，因此可以读取被省略的内容。它的第一条消息显示“Continued from Claude Code”，旁边有 **打开那个会话** 和一个可以显示被带过去的消息的按钮；旧会话则显示“This conversation continued in Codex”，旁边有 **打开**。这适用于 Claude Code 和 Codex 会话。

## 压缩对话

压缩会用一份摘要替换到目前为止的历史，从而为接下来的内容腾出模型上下文的空间。使用会话的菜单（⋯）→ **更多** → **压缩对话**，或者点击消息框中的上下文计量器，然后点击 **压缩** 确认。它适用于 Claude Code 和 Codex，且只能在两轮之间进行。Custom 会自行精简过长的对话。

## 重命名、置顶、延后、告一段落、归档或删除

其中大多数操作都在会话的菜单（⋯）中，也在侧边栏里该会话所在行的菜单中：将鼠标指向该行并点击行尾的 **⋯**，或者右键点击它（在手机上，点按它的 **⋯**）。

- **重命名**：输入新标题（最多 200 个字符）；按 Enter 保存，按 Esc 取消。双击标题栏或侧边栏中的标题，或在选中某一行后按 F2，效果相同。
- **重命名文件夹**（在侧边栏中，针对不属于项目的会话）：为它工作所在的文件夹起一个你自己的名字，侧边栏、会话行和文件夹菜单会在所有设备上显示这个名字；文件夹在磁盘上仍然保持它自己的名字。留空则使用文件夹原本的名字。
- **置顶** / **取消置顶**：置顶的会话会留在 **已置顶** 分组中，顺序就是你拖放的顺序。你也可以把会话从下方的分组（某个项目或文件夹的分组、今天、昨天……）拖到“已置顶”上，或者在还没有任何置顶会话时拖到“拖到这里置顶”上。
- **延后**：把会话隐藏到底部的 **已延后** 分组中，直到 **1 小时**、**3 小时**、**今晚**（在下午 5 点之前可选）、**明天早上**、**下周**（周一早上）或 **选择日期和时间**。它会自动回来并给出提示，如果需要你处理，则会更早回来。**取消延后** 会让它立即回来。
- **告一段落：先到这里**：用于已完成的工作。智能体会停止（某一轮正在运行时不提供此项），会话会被视为已读；它的历史和任何工作树都会保留。对于在工作树中的会话，会打开工作树的对话框，方便你移除它。
- **归档** / **取消归档**：把会话从列表中移走；不会删除任何内容。已归档的会话可以用搜索框（Ctrl+K）找到，并标有 **已归档**；打开其中一个，然后在它的菜单中选择 **取消归档**。
- **删除会话**：你确认之后，会话的历史会从磁盘上移除，因此它也会从智能体自己的命令行和 VS Code 中消失。此操作无法撤销。侧边栏中该会话所在行菜单里的 **删除** 效果相同。

在你删除之前，应用会保留每一个会话，即使智能体自己的程序删除了它的对话（除非另行设置，Claude Code 会在 30 天后删除）：它会回来，列出并可以打开。一年没有人使用的会话会被自动删除，除非你把它们置顶，或在设置 → 通用中更改这一行为（参见[删除不活跃的会话](/guide/app#delete-inactive-sessions)）。

置顶、取消置顶、归档、取消归档和延后都会显示带有 **撤销** 的提示，并且 Ctrl+Z 可以在 8 秒内撤销它们。

## 分享只读链接

会话的菜单（⋯）→ **分享只读链接** 会生成一个任何人都无需你的密码就能打开的链接（[保密会话](#keep-a-session-confidential)不可用）。他们可以实时看到对话的进展（消息、按名称列出的步骤、文件改动以及智能体展示的网页），但看不到命令输出或智能体的思考过程，也不能输入或更改任何内容。选择链接的有效期（**一天**、**一周**、**一个月**、**直到关闭**），然后点击 **创建链接**；链接只显示一次。同一个对话框还会列出当前有效的链接、每个链接被打开的次数，并可以关闭其中一个。参见[手机、其他机器与分享](/guide/devices)。

## 导出对话

会话的菜单（⋯）→ **导出** 可以把对话从聊天中取出来：

- **导出为 Markdown** 会把它下载为一个以会话标题命名的 Markdown 文件，可以保存、发送，或在任何笔记应用中打开。
- **复制为 Markdown** 会把同样的文本放到剪贴板上，方便粘贴到备注、电子邮件或其他应用中。
- **保留为文档** 会把它做成一份文档，保存在会话所属的项目中（它会显示在项目的 **文件** 中；没有项目时，它会跟这个对话放在一起），你可以在那里阅读、编辑、评论、打印，并导出为 Word 或 PDF。准备好时会有消息提示；点击 **打开** 即可前往。

导出的内容包括：标题和日期，然后按顺序列出你的每条消息和智能体的每条回复，并附上时间。一轮中的步骤会被省略，取而代之的是一行类似“Worked for 2 min · 5 steps”的文字。智能体交付的文件按名称列出。回答卡片会变成可读的文本，表格仍然是表格（比较表、数据表、图表的数字）。示意图保留为它们的 Mermaid 代码，数学公式保留为 LaTeX，与智能体写下的一致。在文档中，你附在消息里的图片以及智能体交付的图片也会包含在内。

[保密会话](#keep-a-session-confidential)同样可以导出，它的文档和它的其他工作一样留在这台电脑上：来自网络的图片会保留为链接，而不会被抓取。在终端中，`hydor sessions export` 可以做同样的事（[终端中的 Hydor](/guide/terminal)）。

## 在工作树中工作

工作树是代码仓库文件在新分支上的一份独立副本，这样智能体可以做改动而不会碰到你自己的副本，多个智能体也可以同时在同一个仓库上工作。

- **创建**：在起始页上，打开 **文件夹** 并开启 **从 … 新建工作树**（该文件夹必须在 git 仓库中）。应用会基于当前检出的分支创建一个名为 `agent/` 加上你任务中几个词的分支，并在应用的数据文件夹中为它创建一个文件夹。这个开关会为下次保留。
- **快照**：在工作树中，每次你发送消息时，应用都会保留一份文件快照，这样[从这里编辑](#edit-from-here)就能把它们恢复回来。
- **查看**：会话的菜单（⋯）→ **文件夹与代码** → **工作树：agent/…** 会显示该分支以及它的来源分支、它的文件夹、领先或落后多少个提交，以及未提交的改动，并提供 **查看它的改动** 和 **在 Git 中打开**。
- 工作完成后 **移除它**：在同一个对话框中点击 **移除工作树**。文件夹会被删除；会话保留它的历史。分支会保留，因此已提交的内容不会丢失，除非你勾选 **同时删除分支 …**（没有任何新内容的分支无论如何都会被删除）。如果有未提交的改动，请先勾选 **丢弃 … 个未提交的改动**。如果智能体正在运行，它会停止；共用该工作树的分叉或编辑也会失去它。

## 创建拉取请求

在会话的分支上，使用会话的菜单（⋯）→ **文件夹与代码** → **创建拉取请求**，即可在 GitHub 或 Gitea 上创建拉取请求。**帮我写** 会根据提交和差异起草标题与描述；有一个复选框可以先提交未提交的改动；**草稿** 会把它标记为草稿；点击 **创建拉取请求** 时才会推送分支。你需要在[设置 → 源代码管理](/settings?s=scm)中有一个账户。**关联一个已有的拉取请求…** 用来关联在别处创建的拉取请求。

关联之后，它的状态和检查项会以徽章的形式显示在侧边栏和标题栏中，每隔几分钟更新一次，并在它被合并或检查项完成时给出提示。同一个菜单项现在是 **拉取请求 #12**，其中有 **在 GitHub 上打开**（或 Gitea）、**查看改动**、**立即检查** 和 **取消关联**。子菜单中的 **查看改动** 会逐个文件地查看分支改动了什么。参见[系统：文件、Git、终端和预览](/guide/files-git)。

## 用量限额使会话停止时

当 Claude Code 或 Codex 的套餐用量用完时，消息框上方的横幅会说明是谁的限额、哪一种限额，以及何时重置：只有该智能体的一个账户时显示“You've hit the Claude Code usage limit”；有多个账户且都没有剩余用量时显示“All your Claude Code accounts have hit their usage limit”；另一个账户仍有用量时，则显示该账户的名称（“Work has hit its usage limit”）。

当该智能体的另一个账户仍有剩余用量时，只要 **达到限额时切换账户** 处于开启状态，你就不会看到横幅：会话会切换到那个账户并继续（新会话也会从那里开始）。关闭时，横幅会指出那个账户，并提供 **开启**。

- **重置时继续** 会在限额重置一分钟后自动继续会话，并发送消息“Continue where you left off.”。随后横幅会说明时间，并提供 **取消**。
- **使用一次重置**：当你的账户有可用的限额重置次数时，横幅会说明有多少次，点击它会立即使用一次。
- 设置 → 应用 → 通用中的[限额后继续](/settings?s=general&find=Resume%20after%20usage%20limits)会对每个因限额而停止的会话执行这一操作。开启后，会话中不会出现警告：消息框上方的一行文字会说明是谁的限额（与横幅一样）、哪一种限额以及何时继续（“All your Claude Code accounts have hit their usage limit”，然后是“Current session (5 h) · Continues by itself in 3 h 15 min.”），如果你有可用的重置次数，还会有 **使用一次重置**，以及 **取消**。你自己用 **停止** 停下的会话不会自动继续。

时间会随限额而变：如果重置时间推迟，或用量提前恢复，会话就会在那时继续。参见[用量、限额与费用](/guide/usage)。

## 在 VS Code 或终端中运行的会话

这台电脑上的每一个 Claude Code 和 Codex 会话都会被列出，包括你在 VS Code、终端或 Claude 桌面应用中运行的会话。当它们在那里运行时，列表会显示“Working in VS Code”“Needs you in terminal”或“Open in VS Code”（灰色圆点），你可以在它们工作时同步查看。如果某个会话在那里等待你，只有在一分钟后它仍在等待时，应用才会通知你。

- **接管 Claude Code 会话**：点击它标题栏中的 **在这里继续**，或者直接发送一条消息（“Open in VS Code — sending moves it here”）。应用会先询问：它会结束该应用中的会话，停止其正在做的事，并在这里连同完整历史恢复它。那个应用会把它显示为已结束；你之后可以在那里重新打开它。
- 在别处打开的 **Codex 会话** 在这里是只读的，因为那里的一个 Codex 进程为它的所有线程提供服务。请在那里继续它，或者在那里关闭它，然后在这里恢复。
- 当会话在另一个应用中打开时，不提供分叉。

## 子智能体

智能体可以把工作的一部分交给子智能体，再取回它们的结果。子智能体分为两种，应用会标明是哪一种：

- **Hydor 子智能体**是由 Hydor 启动的独立会话，可以使用任意智能体和模型。它在父会话对话中的子智能体卡片里占一行，在侧边栏中位于父会话之下，你可以打开它并与它交谈。它有自己的费用，也有从父会话的花费上限中分得的一份，它的回复会以消息的形式回到父会话。
- **Claude Code 子智能体**（在 Codex 中称为“Codex 子智能体”：以会话自身所用程序的名称命名）由该程序在会话内部运行，负责工作中的一小段。它的显示和打开方式与 Hydor 子智能体相同：在对话的卡片中占一行，在侧边栏和托盘中占一行，并有一个展示完整对话的专属页面。但你无法与它交谈（它的上级可以），它的花费计入上级自己的花费，也没有花费上限的份额。

在侧边栏中，子智能体在工作或等待你处理时，会折叠在其父会话之下，Hydor 子智能体和程序自带的子智能体合在一行显示（“3 个子智能体 · 1 个需要你”“2 个子智能体”）；点击这一行即可看到每个子智能体各占一行。已完成的子智能体会从侧边栏消失，除非你正在查看它，而且当你查看其中一个时，这一行会保持展开。集群的成员显示为“集群成员”，战役的成员显示为“战役成员”。在父会话的对话中，某一轮启动的子智能体会合并为该轮之下的一张卡片：Hydor 子智能体在一张卡片中，程序自带的子智能体（Claude Code 或 Codex 的）在另一张卡片中。卡片的顶行会说明数量和类型，以及它们共有的信息（“6 个 Claude Code 子智能体 · Sonnet 5.5”“3 个 Hydor 子智能体 · Claude Code · Sonnet 5.5”，深度研究中则是“4 位研究员”），以及它们的进展（“5 个工作中 · 1 个已完成”，还有“1 个需要你”“1 个已停止”“1 个失败”）。点击这一行可折叠或展开卡片：只要有任何一个在工作或需要你，它就保持展开；全部结束后，它会折叠为这一行。

在其下，每个子智能体各占一行：一个状态颜色的圆点（工作时为蓝色并轻轻闪动；需要你时为琥珀色；完成时为绿色；停止时为灰色；失败时为红色）、它的标题，在宽屏上还有它与其他子智能体不同的信息（类型或模型、它所扮演的你的智能体、它的档位），以及它的进展：到目前为止已工作多久、“需要你”、完成时间（“3 分钟前”）、“已停止”或“失败”。Hydor 子智能体的这一行还会显示它的花费，指向已升档的子智能体时，会显示“升档自”它最初的档位及原因。点击某一行即可打开该子智能体。当其他子智能体仍在工作时，已完成的会折叠为一行，例如“4 个已完成：”加上它们的标题：点击即可查看。失败的会各自保留一行。工作中的超过六个时，会显示五个，并带有 **显示另外 3 个**。

只启动了一个子智能体的一轮，会把它显示为单行卡片：带状态圆点的图标、它的标题、它的类型（“Claude Code 子智能体 · Explore · Sonnet 5.5”，或“Hydor 子智能体 · Claude Code · Sonnet 5.5”，有智能体和档位时会一并显示），以及它的进展。

要停止某个子智能体，把指针移到它的那一行（或用 Tab 键移到它），**停止**会取代时间显示出来；在触屏上，始终有一个小的停止按钮。Claude Code 子智能体会先询问（“停止此子智能体？”），Hydor 子智能体会立即停止，而 Codex 子智能体无法在这里逐个停止。卡片的 **⋯** 菜单中有 **停止 5 个子智能体**（数字为可以停止的数量），它会不经询问地全部停止。启动子智能体的那次调用，仍然是该轮已折叠工作中的一个步骤。

当一个在后台工作的子智能体回来时，父会话的对话中会显示一行：“来自”加它的标题的回复，或“……已停止”，或“……因错误而停止”，并附上它所写内容的开头。点击即可阅读回复，点击 **打开它的会话** 可前往该会话。Codex 子智能体的回复会在你打开这一行时，从它自己的对话中取回。父会话仍在工作时到来的回复，会就地显示在前后步骤之间。

在 Hydor 子智能体内部，消息框上方有一个栏，写着“子智能体，所属：”以及父会话的标题（“它的回复会回到那里”），并带有 **打开父会话**。Claude Code 或 Codex 子智能体也会作为会话打开，但是只读的：它显示所收到的任务、它的步骤和它的回复，工作时实时更新，没有消息框，也没有 **继续** 或会话菜单。在消息框的位置，有一个栏写着“Claude Code 子智能体，所属：”以及父会话的标题（“它的回复会回到那里”），并带有 **打开父会话**。Claude Code 子智能体工作时，它标题栏中的 **停止** 会停止它，并会先询问。向它发送消息、继续、分叉、移交或删除它都会被拒绝：它的程序在父会话内部运行它，所以请与父会话交谈。

父会话自己的这一轮结束了，而它的子智能体仍在运行，此时它并未结束：它的圆点继续呈蓝色呼吸状，消息框停止按钮上的圆环继续转动，状态显示为“工作中 · 2 个子智能体运行中”，不显示“完成”标记，并停留在“进行中”，你仍可以向它发送消息。Claude Code 会话和 Codex 会话都是如此。Hydor 子智能体也一样：在它自己的一轮结束后，只要它启动的子智能体或后台任务（命令、监视器）仍在运行，就算作运行中，因此它的父会话显示为工作中，而不是完成。父会话上的花费上限涵盖它的 Hydor 子智能体，而 Claude Code 或 Codex 子智能体的花费本来就是父会话自己的。参见[深度研究、第二意见与多个智能体](/guide/research)。

消息框上方有一行汇总会话启动的所有内容：它的子智能体和后台任务（命令、监视器、工作流）。它显示为“2 个子智能体和 1 个后台任务运行中”；当有 Hydor 子智能体在等你时，会用琥珀色显示“1 个需要你”；当没有任何东西在运行时，显示为“3 个子智能体 · 2 个后台任务 · 全部完成”。每次打开会话时，它都是折叠的。点击它可列出每一项：需要你的在最上面，然后是运行中的，再然后是已结束的，最新的在前，约五项之后在其中滚动。每一行看起来都一样：带状态圆点的图标、标题、它是什么（“Hydor 子智能体 · Claude Code · Sonnet 5.5”“Claude Code 子智能体 · Explore · Haiku 5.5”“命令”“监视器”“工作流”）、它的进展（“工作中 · 2 分 10 秒”“需要你”“完成 · 3 分钟前”“已停止”“失败”）、Hydor 子智能体的花费（程序子智能体不显示：它的花费算在父会话上）、**打开**，以及运行时的停止按钮（圆圈中的方块）。把指针移到它是什么上，可以看到由谁运行它：“Hydor 将它作为独立会话启动：打开它可以观看或与它交谈”，或“Claude Code 在此会话内部运行它：打开它可以观看”。**打开**会带你前往 Hydor 子智能体或 Claude Code、Codex 子智能体的会话；命令、监视器或工作流则会在页面右侧的面板中打开（在手机上占满整个屏幕），其中有它的标题、类型和状态，运行时有 **停止**，其下是它的输出。它每两秒刷新一次，除非你向上滚动，否则会停留在最新的几行。子智能体的停止按钮写着“停止此子智能体”，任务的则写着“停止此任务”。这一行右侧的 **全部停止** 会停止所有正在运行的内容，与消息框旁的停止按钮作用相同。集群或战役的成员不在这里列出：它的看板会显示它们。已结束的任务会一直列出，直到智能体的程序停止；在 VS Code 或终端中打开的会话会列出它的任务，但无法停止它们。

一个会话可以同时运行多少个 Hydor 子智能体，在[设置 → 功能 → 子智能体](/settings?s=children)中设定：这些设置针对的是 Hydor 子智能体，因为 Claude Code 和 Codex 自带的子智能体在它们的会话内部运行。在设置 → 模型 → 档位中开启[以子智能体为主导](/settings?s=models&find=Lead%20with%20subagents)后，会话的主智能体会负责规划，把明确的部分交给较低档位的子智能体，并检查它们的工作。

## 会话菜单中的全部内容

会话右上角的 ⋯ 按钮会打开它的菜单。有些项目只在适用时才显示；[保密会话](#keep-a-session-confidential)的菜单中没有 **分享只读链接**、**创建拉取请求**、**打开浏览器**、**已连接的账户**、**把它设为自动化** 或 **另存为应用**，并且它的记忆保持关闭。

- **重命名**：就地编辑标题。
- **置顶** / **取消置顶**。
- **延后**（一个时间子菜单），或在延后期间显示 **取消延后（于……恢复）**。
- **告一段落：先到这里**：停止智能体，并把会话标为已读（某一轮运行时不可用）。
- **分叉**：从这段对话新建一个会话（Claude Code、Codex、Custom）。
- **在 Codex 中继续**、**在 Claude Code 中继续**、**在 Custom 智能体中继续**：把对话带到另一个智能体（从 Claude Code 和 Codex 出发）。
- **设定目标**：智能体和你商定检查项，它会一轮接一轮地工作，直到这些检查项都满足；适用于所有智能体；仅在尚未设定目标时可用。参见[为会话设定目标](#give-the-session-a-goal)。
- **第二意见**：另一家公司的模型对照你的要求检查某一轮的工作，它的发现会显示在该轮之下。参见[深度研究、第二意见与多个智能体](/guide/research)。
- **分享只读链接**。
- **导出**（一个子菜单）：**导出为 Markdown**、**复制为 Markdown** 和 **保留为文档**。参见[导出对话](#export-a-conversation)。
- **文件夹与代码**（一个子菜单，适用于有文件夹的会话）：
  - **查看改动**：分支所做的改动，逐个文件显示。
  - **创建拉取请求**，或在已有拉取请求时显示 **拉取请求 #12**。
  - **工作树：agent/…**：工作树的对话框（适用于位于工作树中的会话）。
  - **浏览文件夹**：在会话的文件夹处打开文件。
  - **在访达中显示**、**在文件资源管理器中显示** 或 **在文件夹中显示**：在桌面应用中，在系统的文件管理器里选中会话的文件夹（参见[处理文件和文件夹](/guide/files-git#work-with-files-and-folders)）。
  - **在此处打开终端**：在该文件夹中新建一个终端（在电脑上位于底部面板中，在手机上位于终端页面）。
- **会话设置**（一个子菜单）：
  - **记忆**，旁边显示 **开启** 或 **关闭**：为此会话开启或关闭记忆（在设置中记忆关闭时显示“全部关闭”）。参见[记忆](/guide/memory)。
  - **花费上限**，旁边显示上限数值：设置、更改或提高它。参见[用量、限制与费用](/guide/usage)。
  - **已连接的账户**：仅为此会话开启或关闭每个已连接的账户。参见[已连接的应用、密钥与工具](/guide/connections)。
  - **集群**，旁边显示 **关闭**、**开启** 或 **战役**：打开一个对话框，从你的下一条消息起开启或关闭集群或战役。参见[深度研究、第二意见与多个智能体](/guide/research#set-a-swarm-on-a-hard-problem)。
  - **深度研究**，旁边显示 **关闭** 或搜索次数：打开一个对话框，从你的下一条消息起开启、关闭或更改深度研究。参见[深度研究、第二意见与多个智能体](/guide/research#turn-it-on)。（保密会话以及由其他会话启动的会话不显示集群和深度研究。）
  - **智能体**，旁边显示它的名称：打开该智能体的页面（适用于有智能体的会话）。消息框可以切换它。
- **更多**（一个子菜单）：
  - **打开浏览器** / **显示浏览器**：此会话中智能体使用的浏览器，你可以观看并接管。参见[搜索与浏览器](/guide/web)。
  - **把它设为自动化**：辅助模型会阅读会话，并据此起草一个定时任务；你可以修改任何内容，先试运行一次，再保存。参见[定时任务](/guide/tasks)。
  - **另存为应用**：从此会话开始创建一个新应用。参见[应用](/guide/apps)。
  - **压缩对话**（Claude Code 和 Codex）。
  - **复制 CLI 恢复命令**：在终端中继续此会话所用的命令。
  - **停止智能体进程**（在智能体运行且没有进行中的一轮时可用）。
- **归档** / **取消归档**。
- **删除会话**：从磁盘上删除它的历史记录，需先经你确认。
