# 会话

会话是你与智能体在某个文件夹中进行的一次对话：你说明想要什么，智能体开始工作，你可以随时跟进、批准它想执行的操作，并随时调整方向。本主题涵盖会话的方方面面：起始页及其选项、智能体工作时你能看到的内容、在智能体运行中途给它发消息，以及会话菜单中的所有功能，从分叉、目标到工作树和分享。

## 开始一次会话

侧边栏顶部的 **新建会话** 会打开开始页。在消息框中写下你想完成的事，查看下方的一排选项，然后按 Enter（或点击 **开始**；在手机上是圆形箭头）。会话页面会立即打开，显示你的消息和正在处理它的智能体（**工作中**）。如果会话无法启动，页面会说明原因，点击 **返回开始页** 会把你的消息（以及你附加的内容）放回消息框。

如果在应用回应之前连接中断（比如手机进入了睡眠，或网络发生了变化），页面会显示 **正在重新连接…**，并在可以连接时向应用询问你的消息结果如何：如果会话已启动，就会打开它，而且同一个会话绝不会启动两次。如果应用约一分钟都无法连接，页面会显示 **无法连接到应用**；点击 **重试** 会再询问一次。

会话启动片刻后，就会有自己的标题：用几个词概括你的请求（例如“里斯本周末之旅”“修复结账测试”），由辅助模型（[设置 → 智能体 → 模型](/settings?s=models&find=Helper%20model)）在后台写出，对话中不会显示任何内容。侧边栏、会话的页眉和搜索框都会显示它（在侧边栏中，标题的文字会逐个出现，替换你消息中的文字），Claude Code 和 Codex 也会得到它，用于它们各自的列表。在标题生成之前，以及辅助模型无法回答时，会用你消息的开头来代替。你用 **重命名** 给会话起的标题永远不会被替换。从你发送的那一刻起，侧边栏就会把这个会话列在 **活跃** 的顶部（**正在启动**）。

消息框下方的一排包含 **运行于**、**模型**、**文件夹**（或 **项目**）、**智能体**，末尾是 **选项**。在手机上，它们各自都会从屏幕底部以面板形式打开。

### 选择智能体及其模型

**运行于** 并列列出你可以使用的每个程序：

- **Claude Code**：Anthropic 的智能体，使用 Claude 套餐或 API 密钥。
- **Codex**：OpenAI 的智能体，使用 ChatGPT 套餐或 API 密钥。
- **Custom**：应用自带的智能体，可用于任何模型：来自 OpenRouter、Ollama 或 vLLM 的模型。参见 [Custom，应用自带的智能体](/guide/custom)。
- 你添加的任何其他支持 ACP 的智能体（Gemini CLI、OpenCode、Qwen Code、Goose……），其名称下方会显示它的命令。

在底部，**Custom 的模型** 会打开 [设置 → 模型](/settings?s=models)，**添加或管理智能体** 会打开 [设置 → 更多智能体](/settings?s=agents)。参见 [智能体、账户和模型](/guide/agents-models)。

**模型** 默认为 **自动**：会话从最佳档位的模型开始，它的主智能体会把清晰的部分交给较便宜档位的子智能体，当问题被证明太难时，它还可能自行切换到“最大值”档位的模型（参见 [档位：为每类工作选择模型](/guide/agents-models#tiers-a-model-for-each-kind-of-job)）。在它下方，菜单只列出所选智能体自己的模型。智能体的默认模型会标注为“默认”。较旧版本的模型收在“2 个较旧的模型”后面；较长的列表中有一个 **搜索模型** 字段（按 Enter 会选中第一个匹配项）。Custom 会列出你在“设置 → 模型”中添加的模型；其他 ACP 智能体会列出它上次运行时提供的模型，运行过之后才会出现这个选项。

### 选择文件夹、项目或新建任务文件夹

**文件夹** 选项说明智能体在哪里工作。它的菜单（“要在其中工作的项目或文件夹”）有一个 **查找项目或文件夹，或输入路径** 字段，下面是两个简短的列表，每一行都标明了所在位置：

- **项目**：按名称列出你的项目，即最近处理过的五个项目（以及当前选中的那个），每个都附有它的文件夹。选择其中一个，会把文件夹设为该项目自己的文件夹，并在本会话中使用它的智能体和准则；此时该选项会显示 **项目**，并显示项目的名称。一组项目的用法相同，包含其中所有项目。标题末尾的 **新增** 会创建一个项目（会话、文件和记忆合在一起）并选中它。参见 [项目与知识](/guide/projects) 和 [智能体准则](/guide/guidelines)。
- **文件夹**：当前使用的文件夹和你最近选择的三个文件夹，每个都附有它所在的文件夹。标题末尾的 **浏览** 会列出你的主文件夹中的文件夹。
- **新建任务文件夹**（“在 ~/Hydor 中新建一个”）：为这项任务新建一个文件夹，以日期和你消息中的几个词命名（例如 `2026-11-01-plan-trip-lisbon`），位于 `~/Hydor` 中，除非你在 [任务文件夹](/settings?s=assistants&find=Task%20folders)（设置 → 功能 → 你的智能体）中设置了其他位置。

项目自己的文件夹就是项目本身：菜单只把它列为项目，在其中启动的会话会在该项目中工作，即使开始页上选的是文件夹而不是项目。

菜单会在选项的上方或下方打开，取空间更大的一侧，并且无需滚动即可完整显示：在较小的窗口中，它会先显示较少的文件夹，再显示较少的项目，项目下方的“还有 2 个”之类的一行可以把其余的找回来。

在字段中输入可以找到更多：

- 输入名称会找到匹配的项目，以及你最近用过的文件夹、当前使用的文件夹和你的主文件夹中的文件夹。按名称找到的项目文件夹会显示为项目。
- 输入路径（`~/code/`，或从你的主文件夹起的 `code/`）会列出那里的文件夹，与 **浏览** 相同。字段末尾的箭头会上移一级文件夹；叉号或 Escape 会回到列表。
- ↑ ↓ 和 Enter 用于选择。Tab 或一行末尾的箭头会列出其中的文件夹。

当文件夹位于 git 仓库中（并且你没有选择新建任务文件夹）时，菜单末尾会有一个开关：**从 main 新建工作树**（或当前检出的任一分支），“在仓库的副本中创建新分支”。开启后，会话会在自己的副本中、在新分支上工作；此时该选项显示“· 新工作树”。参见 [在工作树中工作](#work-in-a-worktree)。

新会话默认是否使用新建任务文件夹，取决于智能体：多数智能体会在新文件夹中启动，除非你选择了文件夹；程序员会在你选择的文件夹中工作，某个项目的智能体则在该项目中工作。

### 选择智能体

**智能体** 决定会话以谁的身份工作：**通用**（直到你选择其他智能体；在有自己智能体的项目中，则是那个智能体）、**研究员**、**撰稿人**、**程序员**、**辅导老师**、**规划师**、**分析师**、**应用搭建师**，或 **你的** 下的某个自建智能体（在所有地方都能用的，以及所选项目的）。把鼠标指向其中一个，可以了解它做什么，以及它使用哪个程序和模型。选择一个智能体，还可以设置它建议的程序、模型和权限（如果它用某个档位思考，则是该档位的模型），并开启它所连接的账户。**创建或修改智能体** 会打开 [智能体页面](/agents)。参见 [智能体](/guide/agents)。

### 选项：思考强度、权限等

**选项** 包含其余设置。它的选项会显示“选项”，或者列出你设置得与通常不同的内容，例如“最高思考强度 · 计划 · $5.00 上限”。在电脑上，它的菜单末尾有一条提示：在消息框中按 Shift+Tab 可以切换权限。

- **思考强度**：模型思考的深入程度。**默认** 使用模型自己的设置，之后是该模型提供的各个级别：**最低**（快速、轻量的推理）、**中等**（均衡）、**最高**（更深入的推理）、**Xhigh**（超深入的推理）、**最大值**（最大程度的推理），某些模型上还有 **极简**、**无** 或 **Ultra**。Custom 只为会推理的端点模型提供此项（低、中、高）；其他 ACP 智能体在列出级别时提供，没有级别的模型则没有。
- **权限**：智能体无需先询问你就可以做什么。每个智能体有自己的模式；参见 [各权限模式的含义](#what-each-permissions-mode-means)。在消息框中按 Shift+Tab 会切换到下一个。
- **账户**：只有在 [设置 → 智能体 → 账户](/settings?s=accounts&find=Accounts) 中为 Claude Code 或 Codex 添加了其他账户后才会出现。**你的登录** 是智能体自己的账户；选择另一个账户，就以它运行本会话。**管理账户** 会打开设置。
- **保密**，一个带锁的开关（“仅限本机上的模型。任何内容都不会离开本机。”）：适用于你评审的论文、患者数据或客户的代码。**运行于** 会变为 **Custom**，**模型** 会变为本机上安装的最佳模型。参见 [让会话保持保密](#keep-a-session-confidential)。
- **记忆**：仅在设置中开启了记忆时才会出现。**开启** 会使用并补充智能体记住的内容；**本会话已关闭** 则从头开始，不保留其中的任何内容。参见 [记忆](/guide/memory)。
- **花费上限**：本会话最多可以花费的金额，按 API 价格计算。输入金额后按 **设置**，或选择 $1、$5、$10 或 $25；**无上限** 会取消上限。会话会在达到上限时停止，直到你提高上限。参见 [用量、限额和费用](/guide/usage)。
- **集群**：**关闭**；**集群**：由一个主导智能体把任务拆分成若干切入角度，并为每个角度启动一个成员，同时工作的成员数量以 **集群规模** 允许的为限（[设置 → 功能 → 子智能体](/settings?s=children&find=Swarm%20size)）。成员们把发现的内容分享到看板上，并互相发消息。适用于难题；费用是单个智能体的数倍。或者 **战役**（“一项大改动分成若干部分，每部分在一个工作树中”）：主导智能体把一项大改动拆成若干部分，成员各自在自己的分支上完成一部分及其测试，再由主导智能体合并；文件夹必须是 git 仓库（参见 [战役](/guide/engineering#campaigns-a-big-change-in-many-parts)）。
- **研究**：**关闭**，或 **深度研究**：智能体规划搜索，派研究员去处理每个部分，用两个来源核对关键论断，并交付一份附有引用的报告。可设置 **同时进行的研究员数**（1 到 8）、**轮数**（1 到 5）、**总搜索次数**（10 到 500）和 **报告**（**网页** 或 **Word**）。
- **目标**：**关闭**（“智能体会一直工作到它认为完成为止”），或 **直到完成**（此时“选项”选项会显示“目标模式”）（“它会一轮接一轮地工作，直到你认可的检查项都满足”）：你的第一条消息就是目标，智能体先想好如何检查它并展示给你，在你同意之前不会开始任何工作。在 **向你询问的频率** 下，选择它多久询问一次该往哪个方向走。它适用于每个智能体，会消耗很多轮次，并在你认可的限制（轮数、金额、时间）处停止。参见 [目标](/guide/goals)。
- **竞技场**：**关闭**，或 **比较模型**：同一条消息还会发给你勾选的一两个其他模型，每个都在同一文件夹里各自的会话中。你比较答案并保留最好的；其余的会被归档。在 git 仓库中，请开启文件夹菜单中的 **新建工作树**，让每个模型在自己的副本上工作。**查找模型** 字段可在较长的列表中帮到你。

集群（或战役）和深度研究都会带领 Hydor 子智能体，所以开启其中一个会关闭另一个。**目标** 可以与集群同时使用（目标属于它的主导智能体：[为集群设定目标](/guide/goals#a-goal-for-a-swarm)），但不能与战役、深度研究或竞技场同时使用：打开 **目标** 会关闭这些，打开其中任何一个会关闭目标，而带领着其中任何一个的会话不能设定目标（它的菜单里没有 **设定目标**）。**保密** 会关闭集群、深度研究和竞技场，开启其中任何一个又会关闭保密（目标可以在保密会话中运行）。集群、深度研究、竞技场和目标不会保留到下一次会话，因为它们花费更多；你选的研究数值和竞技场模型会保存在此浏览器中，待你再次开启时使用。参见 [深度研究、第二意见和多个智能体](/guide/research)。

### 各权限模式的含义

**Claude Code**

| 模式 | 智能体可以做什么 |
| --- | --- |
| 询问（默认） | 在进行编辑以及执行其设置中未允许的命令之前先询问 |
| 接受编辑 | 可自由编辑文件，执行其他命令前先询问 |
| 自动 | 由安全检查批准常规操作，有风险的操作则询问你 |
| 计划 | 只读取和规划，然后提出计划供你批准 |
| 绕过 | 从不询问（完全访问） |

**Codex**

| 模式 | 智能体可以做什么 |
| --- | --- |
| 计划 | 先讨论和规划；可以向你提出澄清问题 |
| 只读 | 读取文件并回答；更改任何内容之前先询问 |
| 自动（默认） | 在其文件夹内编辑文件并运行命令；超出该范围时先询问 |
| 自动审查 | 与“自动”类似，但由一个审查智能体回应它的批准请求 |
| 完全访问 | 无沙盒，无需批准 |

在 Docker 内，Codex 自己的沙盒无法启动，因此那里默认是 **完全访问**，菜单中也会说明原因。

**Custom**

| 模式 | 智能体可以做什么 |
| --- | --- |
| 询问（默认） | 编辑文件和运行命令之前先询问；查看周围环境则可自由进行 |
| 接受编辑 | 可自由编辑文件夹中的文件，运行命令之前先询问 |
| 自动 | 常规步骤直接进行；有风险的操作会由一次快速检查来询问你 |
| 完全访问 | 无需批准提示，也不使用命令沙盒，直接运行工具和命令，使用你电脑账户的权限 |
| 计划 | 只读取和规划：不编辑，不运行命令 |

在“完全访问”之外，Custom 会在执行有风险的命令之前询问你。在“询问”“接受编辑”和“计划”中，它在读取或更改文件夹之外的文件，或存有密钥或密码的文件之前也会询问；在“自动”中，则由快速检查先对这些进行判断。参见 [Custom，应用自带的智能体](/guide/custom)。

**其他 ACP 智能体** 提供它们自己的模式，在智能体运行过之后列出。

### 让会话保持保密

有些工作不能离开你的电脑：别人发给你评审的论文（多数会议和期刊禁止把投稿交给在线 AI）、患者或客户的记录，或是你按协议处理的公司代码。保密会话在本机的模型上运行，它的任何内容都不会被发送到别处。

1. 在开始页上，打开 **选项** 并开启 **保密**（“仅限本机上的模型。任何内容都不会离开本机。”）。此时它的选项会显示“保密”。
2. **运行于** 会变为 **Custom**，**模型** 会变为本机上安装的最佳模型；开启期间，它们的菜单只提供这些。如果还没有，它会这样说明：[设置 → 智能体 → 模型](/settings?s=models) 可以一键安装为这台电脑推荐的模型。
3. 写下你想要的内容，附上论文或选择它所在的文件夹，然后按 Enter。例如：“以 NeurIPS 评审人的身份评审所附的投稿：摘要、优点、缺点、给作者的问题和一个评分。”

本机上的模型指这里的 Ollama 和 vLLM 的模型，以及地址为本机或你的私有网络的端点：`localhost`、`127.0.0.1`、`::1`、`10.…`、`192.168.…`、`172.16.…` 到 `172.31.…`，或以 `.local` 结尾的名称（参见 [连接 Ollama、vLLM 或其他端点](/guide/agents-models#connect-ollama-vllm-or-another-endpoint)）。Ollama 的云端模型（名称以“cloud”结尾）运行在 ollama.com 上，不算在内。开始页会为你之后的会话保持该开关开启，直到你把它关闭。

保密会话在页眉和侧边栏中的标题旁有一把锁，它的消息框有一圈平和的绿色边框；框上方有一行说明这意味着什么，直到你把它关闭。点击锁可以查看哪些已开启、哪些已关闭。

- **关闭的功能**：网络搜索和网页、浏览器和你的屏幕、已连接的应用和你的密钥、应用、发布、定时任务、制作、查找或编辑图片、绘图、图表、视频或声音、别处的模型（深度研究、集群和竞技场；[第二意见](/guide/research)只会来自本机上另一家厂商的模型）、把对话交给另一个智能体、向记忆中保存任何内容，以及把网页导出为文件（请自行从网页中导出）。
- **无网络的命令**：智能体的命令在断开网络的状态下运行，在每种权限模式下都是如此，因此不能下载、从互联网安装、推送或发送任何内容。在无法做到这一点的地方（Windows、某些容器），无论处于什么模式，每条命令都会先询问你，锁的说明中也会这样写。
- **仍然开启**：文件夹中的文件、文档（在本机上读取）、你保存的页面、图片和文件、它用文件展示给你的截图、共享知识、你的记忆备注和个人资料（只读，不会添加内容）、同样保密的 Hydor 子智能体，以及回答卡片（不含来自网络的图片或地图）。
- **不会向外发送任何相关内容**：它的标题在辅助模型运行于本机时由其生成，否则取自你消息的开头几个词；通知只会说“一个保密会话”以及它已完成、需要你处理还是失败；它的菜单中没有只读链接和拉取请求，也不能由它创建自动化或应用；其他会话中的智能体和别处的智能体都无法读取它；它的回复不显示来自网络的图片，它所显示的网页也不会从任何地方加载内容（因此需要来自网络的库的图表将无法绘制）；听写只有在使用本机上的语音识别时才可用（[设置 → 功能 → 语音](/settings?s=voice)），回复只会用你设备上的语音朗读。
- **它始终保密**：分支和 **从这里编辑** 同样保密，而且无法关闭，因此说过的内容会留在原处。对于可能离开这台电脑的工作，请新建一个会话。

它不能保证的是：Hydor 检查的是模型的服务器在哪里，而不是该服务器做什么，所以你在网络中搭建的、会把请求转发给在线服务的端点，依然是在线的。你从会话中复制出去的内容，或你自己从别处打开或发送的内容（回复中的链接、从项目文件中打开的它所生成的网页、从 Git 页面推送），需要你自己留意；你在另一台设备上读到的内容也是如此：应用的页面会像往常一样传到那台设备上（如果你使用隧道，则通过你的隧道）。

### 附加文件、指向文件、使用命令

- **附加文件**（消息框底部一行左侧的 **+**）、把文件拖放到消息框上，或把图片和文件粘贴进去。一条消息最多可携带 25 MB 的文件。图片（PNG、JPEG、GIF、WebP）会作为图像发送给模型，每条消息最多 8 张；其他文件（最多 20 个）会保存在这台电脑上，并列在你消息的末尾，供智能体打开。发送前可以用文件旁的 × 移除它。你附加的文件会留在消息框中等你发送，即使你转到其他页面也是如此（重新加载页面会清除它们）。
- **附加截图**（在同一个 **+** 菜单中，仅限电脑；在浏览器无法截图的地方，**+** 是一个回形针，只能附加文件）：浏览器会询问要截取哪个屏幕、窗口或标签页，然后附加它的一张图片。
- **@**：输入 @ 和文件名的一部分，会列出文件夹中匹配的文件；用 ↑ ↓ 移动，按 Enter 或 Tab 插入，按 Esc 关闭。
- **/**：在消息的最开头，输入 / 会列出智能体的命令和技能（Claude Code 的），以及每个的作用。
- 当你的浏览器或这台电脑能识别语音时，发送按钮旁会有麦克风（听写你的消息）和耳机（免提语音模式）。参见 [文档、图片、视频和语音](/guide/documents-voice)。

### 开始页会记住什么

开始页会为你工作的每个地方分别记住你的选择：每个项目、每个文件夹和 **新建任务文件夹**，在所有设备上都是如此。一个地方会记住它的 **运行于**（程序）、每个程序的 **模型**，以及在 **选项** 下的 **思考强度** 和 **权限**、**智能体**、**记忆**、**花费上限**、**保密** 和 **新建工作树** 开关。账户（**选项 → 账户**）不按地方记忆：它始终是你选的那个，在所有地方都一样。在某个地方选择一个程序，会带回你上次在那里用它时的设置。

一个地方在你于那里更改了其中某项，或在那里启动了会话之后，才会保留它的选择；只是看一眼某个地方不会保留任何内容。在 **文件夹** 选项中选择一个地方（项目、文件夹或 **新建任务文件夹**），消息框就会带着那个地方的选择打开，而你写下的和附加的内容仍留在其中。从项目开始（在项目卡片或页面上点 **新建会话**，或点侧边栏中的项目），会以该项目的选择打开开始页；在某个文件夹上（在文件或侧边栏中）点 **在此文件夹中新建会话**，会以该文件夹的选择打开它。页面会在你上次选择的地方打开。

对于你还没有在其中选择或启动过任何内容的地方，会以默认值打开：智能体是 **通用**，或者在项目有自己的智能体时是该项目的智能体（并且该智能体的建议也会生效，就像你选择它时一样：它的程序、其档位的模型和它的权限）；**模型** 在提供该选项的地方是 **自动**，否则是程序的默认模型；**思考强度** 和 **权限** 是程序通常的设置；记忆开启；没有花费上限；**保密** 和 **新建工作树** 关闭。**运行于** 仍是你上次使用的程序。在加入这项功能之前你上次选择的地方，会保留你当时的选择。

指向开始页的链接可以预先填好内容，例如 `/?prompt=Summarize%20my%20notes&agent=codex`；还可以加上 `model=`、`cwd=`（文件夹的路径）、`assistant=`（智能体的 id，如 `app-builder`，除非链接指定了程序或模型，否则它还会选择该智能体建议的程序、模型和权限）以及 `confidential=1`（开启保密）。它只会填好消息框和各项选择，绝不会自行启动任何内容。链接中消息里的不可见字符会被移除，并给出提示。

你在消息框中写的内容会在你转到其他页面时留在那里：消息、你附加的文件、仅限这项任务的选项（**集群**、**深度研究**、**竞技场**、本会话的 **准则**），以及链接或 **新建智能体会话** 在其中打开它的文件夹。会话开始时消息框会清空：在智能体启动期间，**开始** 上的箭头会不断上升；然后开始页变成会话，消息框下移到底部它的位置，你写的内容上移成为你的第一条消息。消息和这些选项保存在此浏览器中，因此重新加载后仍然在；附加的文件则不会保留。

## 跟进会话中的工作

### 标题栏

会话顶部有：

- 智能体的图标和标题（双击标题可重命名），以及[保密会话](#keep-a-session-confidential)的锁图标；
- 状态：**工作中**、**需要你处理**、**就绪**、**正在启动**、**正在构建记忆**、**正在停止**，或者对在其他地方运行的会话显示“在 VS Code 中打开”；智能体不再运行后，则显示工作的结束方式：上一轮完成时为**完成**（如果创建或改动了文件，会附上“· 创建了 2 个文件”或“· 改动了 3 个文件”），你停止它或它在完成前被中断时为**已停止**，因错误而结束时为**失败**。将鼠标指向状态，可以看到下一步该做什么；
- 文件夹（点击可在文件中浏览）、拉取请求标记、以添加的账户运行时显示的账户，以及在较宽的屏幕上显示的 git 分支和模型；
- 一个对应当前可做操作的按钮：一轮运行时为**停止**；智能体未运行时为**继续**（在**已停止**或**失败**之后；在**完成**之后则更淡，因为在输入框里发一条消息同样会继续会话）；对于在 VS Code 或终端中打开的 Claude Code 会话，则为**在这里继续**；
- **详情**（文件有改动后会显示增加和删除的行数），用来打开[详情面板](#the-details-panel-changes-commands-and-info)；
- 对话处于[缩放](#zoom-in-and-full-screen)状态时，会显示 **− 125% +** 和当前的缩放级别；
- 会话的菜单（⋯）：参见[会话菜单中的全部内容](#everything-in-the-sessions-menu)。

### 轮次、步骤和回复

对话读起来就像聊天。每一轮包括你的消息、智能体的工作，以及它最后给出的回复：

- **你的消息**会在你发送的那一刻显示在右侧，附带其中的图片和附件，此时智能体还没收到：智能体会显示在它下方开始工作，而输入框可以接着写下一条。如果消息没能发出（没有网络连接、达到花费上限），它会被撤回并放回输入框，同时有一条说明原因的提示。较长的消息会折叠成开头几行；点击**显示更多**可展开。
- **工作**位于一行概括它的文字之下：“工作了 2 分 10 秒 · 3 条命令”“思考”“40 秒后已停止”或“5 秒后失败”，右侧是这一轮的花费（“≈ $0.12”）：点击它可查看这一轮的[时间和费用](/guide/sessions#a-turns-time-and-cost)。在套餐（Claude Code、Codex）下，这是按 API 价格计算它的 Token 所需的费用，并非你实际支付的金额；如果不知道该模型的价格，这里会改为显示 Token 数。一轮运行期间，这一行显示“工作中 · 1 分 2 秒”（或“等你处理”），工作大纲会随进展不断增长；在之前已有若干轮时，它还会加上会话总共工作了多久（所有轮次加在一起）：“工作中 · 1 分 2 秒（47 分）”。完成的一轮会把工作折叠起来；点击这一行可展开。
- **工作大纲**：智能体在各步骤之间写下的每条简短说明（它发现了什么、接下来做什么）开启一个部分，随后它执行的步骤归入其中。已完成的部分是带一个对勾的一行：用几个字概括的说明（“先运行结账测试，看看哪里出错”“先应用折扣，再一次性取整”）、它执行了多少步，以及改动了多少行。点击它可查看完整说明和每一步。正在进行的部分会完整显示智能体的说明，其下是当前正在执行的步骤，例如“正在编辑 total.ts · 4 秒”；点击该行可查看这一部分到目前为止的步骤。在智能体写下第一条说明之前执行的步骤，会组成一个以其所做之事命名的部分（“运行了 3 条命令，读取了 2 个文件”）。较长的一轮会显示最近的部分；点击**显示更早的 12 个部分**可查看其余部分。
- **步骤**用通俗的话命名：“运行测试”“读取 index.ts”“搜索了网络”，命令本身以较淡的字体显示。点击某一步可查看它做了什么。Claude Code 会自行运行命令或其他会产生改动的步骤；而智能体在同一条消息中、排在它之后请求的 Hydor 自带步骤（网络搜索、网页读取等）要等它结束后才执行。这样的步骤会以淡淡的样式显示**等待中**，代替计时，直到真正开始；然后它的计时从那一刻起算，完成的步骤显示它实际花费的时间。大纲中对正在进行的步骤的那一行，写的是真正在运行的步骤。
- **思考**显示为“思考了 12 秒”，并带有第一个标题；点击可阅读。
- **回复**是智能体在最后一步之后写下的内容。智能体展示的网页会和它放在一起。智能体工作期间，它在最后一步之后写下的简短说明会显示在大纲中，作为正在进行的部分；如果这一轮到此结束，它就成为回复。
- **步骤之间的回复**：智能体在步骤之间写下的、读起来像回复的内容（对你在它工作时发送的消息的答复，或它继续之前的发现，包含多个段落、列表或表格）也会作为回复显示在原位，不会折叠进工作里。它前后的工作各自位于单独的一行之下，例如“工作了 20 秒 · 2 条命令”。
- **改动的文件**：回复下方有一个标签，显示这一轮改动了多少个文件，以及增加和删除的行数。点击它可查看列表，再点击某个文件可查看它的差异（只有一个文件时，会直接打开它的差异）；**打开文件**可打开它。超过五个的会折叠在“显示另外 3 个文件”之后。这一轮的提交和记忆标签在同一行，位于它旁边，各自在这一行下方展开。
- **生成的文档**：回复下方，智能体在这一轮中创建或改动的文档（PDF、Word、Excel、PowerPoint、LaTeX、笔记本、Markdown 等）会显示为标有**新增**或**已更新**的卡片，无论它是否交给了你；回复中的文件名和路径是链接，会在对话上方的窗口中打开该文件（[它创建或改动的文档](/guide/documents-voice#documents-it-made-or-changed-and-file-names-in-its-reply)）。在宽屏上，当这一轮只制作或改动了一份时，它还会在对话旁边打开。
- **提交**：智能体在这一轮中做了提交时，回复下方会有一个标签说明这一点：**已提交** · 提交的标题，或“3 次提交”及其分支，还有增加和删除的行数。点击它（有多个提交时，再点某个提交）可阅读完整的提交信息、作者和时间、它的哈希值（点击可复制），以及它改动的每个文件和差异。**在 Git 中打开**会在 [Git 页面](/git)中、该会话所在的仓库里打开它。智能体在同一轮中修改过或通过变基去掉的提交不会列出。

智能体还可能维护一份清单（**计划**或**待办事项**，并显示已完成多少项），它会在工作时逐项打勾。来自应用的通知会跟在它们所涉及的那一轮之后：记忆保存了什么、第二意见、达到花费上限、这一轮启动的子智能体的卡片。来自其他会话的消息显示为“来自 …”，子智能体的回复（Hydor、Claude Code 或 Codex 子智能体的）显示为“来自 … 的回复”（点击可阅读该回复），定时任务的运行则以一行说明任务名称的文字开头。

日期行（“昨天”“今天”）把各天分隔开；全部来自今天的对话没有日期行。向上滚动时会加载更早的消息，也可以点击**显示更早的消息**。新的消息和回复出现在对话末尾，其下不会留下空白。当回复长到足以占满屏幕时，视图会停在它的第一行并随着回复变长保持不动，这样你可以从头阅读长回复；较短的回复则直接位于前面内容的下方。智能体工作时如果你向上滚动，视图会停留在原处；**最新**会带你回到末尾，在回复在屏幕下方继续生成时也会显示。

每条完成的回复下方有**复制消息**、**从这条回复分叉**和**朗读**。**从这条回复分叉**适用于 Claude Code 的任何回复；对于 Codex 和 Custom，则只适用于已完成一轮的最后一条回复，因为它们是按整轮来分叉的。在智能体使用过工具或展示过卡片的一轮的最后一条回复下方，**再做一次…**（循环箭头）可以让这些工作重做一遍，无需再次提出要求：**做成应用**会根据这一轮起草一个应用，期间你做出的更正保留在它的任务中，它的卡片则作为它的回答（[来自一次顺利的会话](/guide/apps#make-your-own-app)）；**每隔…运行一次**会用你所问的内容打开一个新的[定时任务](/guide/tasks)。保密会话中没有这些。在你自己的每条消息下方，**复制消息**、**从这里编辑**和发送时间会一直显示，而不只是在鼠标悬停时。

### 一轮的时间和费用

已完成一轮那一行右侧的费用（“≈ $0.12”，或在不知道该模型价格时显示 Token 数）会打开**时间和费用**，帮你了解一轮为什么耗时长或花费多：

- **时长**：一条显示这一轮时间花在哪里的条形图，每一部分都有占比和时长：**模型**（读取给它的内容、思考和写作）、**命令**、**读取和编辑文件**、**网页**、**其他步骤**（子智能体、已连接的应用的工具）、**等你处理**（批准、问题和表单，从每张卡片出现到你回答为止）和**其余**（启动，以及步骤之间）。并行运行的步骤只计一次。其下是“3 秒后首次回复或步骤”：智能体多快开始行动。
- **Token**：**新读取**；**写入缓存**（新读取后由模型提供方保留，因此下一次请求读取它的花费更低）；**从缓存读取**，以及它占全部读取量的比例；还有**写出**（回复、思考和步骤）。
- **费用**：这一轮的费用，以及在知道模型价格时每一类的费用，并附有“缓存节省了约 $0.80。”。在套餐下（Claude Code 和 Codex，除非会话使用 API 额度运行），它会显示“按 API 价格：使用套餐时你支付的是套餐费用”。在不知道该模型价格时，它会显示不计算其费用。

Claude Code 的各轮会给出模型自身的耗时和首次回复；对其他智能体，模型这一部分就是它的思考。费用和这个面板在较宽的屏幕上显示。

### 回复中的数学公式、示意图、图表和图片

智能体是为这个应用而不是为终端来写回复的，所以回复里可以有文字之外的内容。每个智能体都会这些，并在能让回答更清楚时自行使用：

- **格式**：标题、列表、表格、粗体和代码，排版得便于阅读。
- **数学**：像教科书一样绘制的公式，可以在句子中，也可以单独成行；还有化学方程式（2H₂ + O₂ → 2H₂O）。成对美元符号之间的数字（`$1$`、`$0$`）也算数学公式；像 $4.70 这样的普通价格仍然是金额。
- **示意图**：流程图、时序图和状态图、时间线、思维导图、甘特图和饼图，使用应用的颜色绘制，浅色或深色均可。示意图上方的栏里有**显示代码**（智能体写的内容；同一个按钮会再次显示示意图）、**另存为图片（SVG）**、**全屏**，以及一个复制其代码的按钮。无法绘制的示意图会显示它的代码和原因。
- **图表和小工具**：图表、带批注的图示、计算器、带滑块的模拟或简短的测验会在回复内运行，与应用和你的文件隔离开，就像智能体展示的网页一样。它沿用应用的外观并自动调整大小（较高的可用**查看全部**打开）；它的栏里有**显示代码**（**显示效果**可返回）、**另存为文件**和**全屏**。你在上面点选的内容会进入你的输入框。回复仍在编写时，它会就地逐步生成（在有内容可显示之前显示“正在写…”），完成后才会活起来。
- **图片**：来自网络的照片（地点、产品、植物、艺术品）和这台电脑上的图片，会适配回复；点击一张可查看大图，其中**编辑**会在图片编辑器中打开它（[编辑图片和视频](/guide/library#edit-pictures-and-videos)）。连续的几张图片会显示为网格，每张下面有它的说明：两张并排，四张两行两列，更多则每行三张（手机上两张）。点击一次回复里的任意一张图片，查看器里会包含这次回复的所有图片，用箭头可以在它们之间切换。应用或页面的截图则会改为一张卡片，你可以在对话旁边审阅它（[审阅智能体对网页应用的修改](/guide/files-git#review-an-agents-changes-to-a-web-app)）。来自网络的图片经由这个应用的服务器传来，所以存放它们的网站永远看不到你的浏览器。无法加载的图片会显示为指向它的链接。

如果想要纯文本，可以在你的[智能体准则](/guide/guidelines)中说明（“用纯文本回答，不要示意图或图片”），或者在消息里说明。你也可以用平常的话要求其中任何一种：“把这些步骤画成流程图”“给我看一张它的图片”“给我一个滑块，让我试试其他数值”。

### 回答卡片：回复中的卡片、图表和地图

当回答中的某一部分是用来看、比较、选择、跟随、尝试或练习而不是阅读时，智能体会用应用的某个回答卡片来展示它：近 150 种现成的卡片、表格、图表、地图、图库、时间线和小工具，填入回答本身的内容。多数超过几行的回答都有这样的部分，所以你在大多数回答中都会看到它们。要比较的选项会变成一张表格，每行的最优值会被标出；食谱变成一张卡片，份数可以调整用量；天气预报显示未来几小时和几天；地点变成带编号标记的地图；测验或练习题则是让你就地作答的问题。每一个都随回复逐步生成，采用应用的外观，浅色或深色。

- **你可以在其中做什么**：对表格排序和筛选，把图表切换为数字，勾选清单，启动食谱的计时器，翻转闪卡，配对或填空，回答故障排查的问题，转动转盘替你做选择，拖动计算器或函数图的滑块，播放视频。你勾选或回答的内容，在你回到对话时仍会在这台设备上（练习题的答案也是）。写着**发送**的按钮（**发送我的选择**、**发送我的得分**、**发送我的结果**、**发送**等）会立即把它所指的内容作为你的下一条消息发送，就像你自己输入并按下了回车键：你选的选项、你的测验得分、转盘停下的位置。旁边的**已发送**表示已发出。你正在写的内容会留在输入框中；当会话此刻无法接收消息（上一条还在发送途中）时，这些文字会改为放进输入框，由你自己发送。有些还能做更多：
  - 你用自己的话或数字作答的**练习题**会当场检查（数字允许一定误差，文字不区分大小写；如果答案正确、只是重音符号有误，会指出这一点）。**显示提示**会一次给出一条提示；在尝试之后，或在所有提示都显示完之后，会显示详细解答。你会得到一个得分，**发送我的结果**会把它发给智能体。你对开放性问题的回答用**发送以供检查**发出，由智能体来检查。
  - **可以运行和修改的代码**：演练场会就地运行 JavaScript、Python 或一个小网页，与应用隔离开，其输出（以及 Python 的图表）显示在下方。上面有**运行**、**重置**、**复制**和**发送我的代码**（会发给智能体查看），它还可能布置一些任务让你尝试。Python 第一次使用时从网络加载，所以在[保密会话](/guide/sessions#keep-a-session-confidential)中无法运行。
  - **代码讲解**以导览的方式解释代码：编号的步骤位于代码旁边，每一步会点亮它所解释的行，其余部分变淡。用箭头（或 **←** 和 **→** 键）逐步浏览，或者点按某一行来打开解释它的那一步。**询问这一步**会把一个关于它的问题放进你的输入框。
  - **逐步运行的程序**会显示程序在每一步所处的位置：它所在的行、它的变量（刚刚变化的会被标出）、正在进行的调用，以及到目前为止打印的内容。可以前后单步移动、拖动滑块或按播放。当它要求你先预测输出时，输入你的猜测并按**检查**。**询问这一步**在这里同样可用。
  - **关系图**显示事物之间如何关联（概念图、小说的人物、什么依赖什么）：点按一个节点可点亮它的连线并阅读它的备注，拖动节点调整位置，查看图例，或切换到**列表**视图。
  - **带批注的文字**会标出文本中的段落：点按一处可阅读它的备注（更正、评论、含义）和它建议的修改，或者**问问这个**。可以按类别筛选备注，在**原始比例**和**已更正**之间切换，使用**复制更正后的文字**，或者收听这段文字。
  - **事实核查**会逐条检查各项说法，每条都有它的结论、原因、智能体的把握程度以及支持和反对的证据，并附有来源。顶部的结论统计在你点按时会筛选这些说法。
  - **追问**是回答末尾的两到五个按钮，内含接下来的问题或步骤：当你的输入框为空时，点按一个即可把它作为你的下一条消息发送；否则会把它添加到你正在写的内容中。用过的按钮会出现一个对勾。
- **图片**：没有图片或图片无法加载的条目会不带图片显示，文字占据其位置，因此不会留下空框。
- **链接**：回答中提到的、你可能想打开的东西（地点、商品、论文、书、电影、活动、网页），都会链接到它自己的页面，无论是在智能体的话里还是在它的卡片中，这样你就不必再去查找。在卡片上，带链接的名称会加下划线，后面还有一个小小的 ↗，即使在手机上你也能看出它是链接：点按或点击即可在新标签页中打开该页面（在你选择用的卡片上，只会打开页面，不会选中该选项）。地点的地址会在 Google Maps 中打开，表格还可以把一列名称变成链接。
- **来自电子表格或文件的数字**：表格、图表、关键数字、排行榜、直方图或地图上的数值，可以从你的某个电子表格中读取数字（参见[电子表格](/guide/library#spreadsheets)），也可以从对话文件夹或其项目文件夹中的 CSV、TSV、JSON 或 JSONL 文件读取，而不是自己存放这些数字。当数字就存放在那里、行数超过几十行，或者是你可能想保留的卡片时，智能体会这样做：卡片自己完成求和、计数、分组、筛选和排序，所以不必再把任何内容重新输入一遍，而且每次显示时都是最新的数字（之后新增的行也包括在内，除非它指定了固定的单元格范围）。其下一行说明它们的来源（**数据来自** *店铺数据 · 销售*，一个会打开该电子表格或文件的链接）、读取的时间，以及在只显示一部分时显示了多少（“显示 12,400 行中的 1,000 行”）；**重新读取**会再读一次，而当你保存电子表格时，卡片会自动重绘。如果电子表格、它的标签页、某一列或该文件已不存在，卡片会用平实的话说明，并附有**重试**。卡片只读取其对话的文件夹中的文件，不会读取你电脑上的其他位置，大小不超过 50 MB（JSON 文件为 20 MB），并且只读取前 1,000,000 行；在[保密会话](/guide/sessions#keep-a-session-confidential)中创建的电子表格只会被该会话中的卡片读取。
- **悬停时**（或用键盘选中它时），右上角会出现一个小栏：**显示数据**会显示智能体写的内容（对于读取电子表格或文件的卡片，则显示它从哪里读取以及显示了其中的哪些内容；**显示效果**可返回），**复制为文本**会把它复制为纯文本，**全屏**会在页面上单独显示这张卡片，宽度与你的窗口一样（在手机上是整个屏幕），内容较高时可以滚动；按 **Esc**、**关闭**或点击它旁边即可返回。在**更多**（…）下：**固定到看板**会在你的某个看板上保留这张卡片的副本，可以是你选的一个，也可以是你在那里命名的**新建看板…**，以便之后与其他卡片放在一起查看（参见[看板](/guide/library#boards)）；**另存为图片**会把卡片保存为一张 PNG，外观与你所见一致，使用你当前看到的主题，并放大到两倍大小以保持清晰，以它的标题命名；**复制为图片**会把同样的图片放到剪贴板上，以便粘贴到消息或文档中（在你的浏览器允许网页这样做时）。全屏时，顶部也有同样的这两项。内含地图、由图表库绘制的图、视频播放器或代码演练场输出的卡片没有图片按钮（仍然可以固定）：这些部分无法绘制成图片。
- **智能体何时使用它们**：智能体被告知，回答中凡是用来看、比较、选择、跟随、尝试、练习或保留的部分，都要使用一张卡片，这在超过几行的回答中大多数时候都适用：需要权衡的选项、带图片和详情的事物（地点、产品、电影、书籍、人物、论文、新闻）、数字、时间和计划、要做的事、要学的东西、要检查的文字、要核实的说法，以及你可能想采取的后续步骤。它们会填入图片，并在观看比看照片更有帮助时播放视频。卡片无法表达的内容（推理、建议、注意事项）仍用智能体自己的话说。普通对话、对简短问题的简短回答和代码改动仍然是文字。每一个回答，无论是第一个还是之后的，都可以包含多张卡片，各对应它的一个部分（行程、天气和打包清单），所以一段对话会按回答的需要积累任意多张；之后的回答可以再次显示某张卡片，并把它的数据更新到最新。智能体通过一次查找找到合适的卡片：对已经知道的按名称查找，对其余各部分则用几个词描述每一部分展示什么（按词语查找，并且在[设置 → 记忆](/settings?s=memory)中开启了**按含义搜索**时也按含义查找），因此不会把所有卡片都交给它。[内置智能体](/guide/agents#the-built-in-agents)各自偏好适合它们工作的那些卡片。
- **在你的应用中**：应用的回答也可以是这样的一张卡片，由应用的智能体在每次运行时填入（参见[回答](/guide/apps#the-answer)），而展示过卡片的回复下方的**再做一次…**会做出一个以这些卡片作为回答的应用。
- **查看全部**：[回答卡片](/answers)按分组展示每一种及其示例：摘要、比较、购物、地点和旅行、美食、计划、工作和商务、数字和图表、金钱、学习、科学、媒体、人物和体育、写作以及代码。**播放生成过程**会展示一张卡片如何像回复那样逐步出现。

也可以用平常的话要求使用：“用表格比较它们”“把它们放在地图上”“就这个考考我”“给我这方面的练习题”“在我的文章上标出要改的地方”。你的[智能体准则](/guide/guidelines)（“用纯文本回答，不要卡片或图表”）或你的消息可以要求改用纯文本。

### 缩放和全屏

对话内容可以单独放大或缩小显示，而侧边栏、顶栏和消息框保持原样。对话里的所有内容（文字、代码、卡片和图片）都会一起放大或缩小，文字行会重新换行以适应宽度。缩放级别有 67、80、90、100、110、125、150、175 和 200%；每台设备分别记住自己的级别，适用于它的所有会话。

- **键盘**：**Ctrl**（Mac 上为 **⌘**）加 **+** 或 **=** 放大，加 **−** 缩小，加 **0** 恢复到 100%。在桌面应用中，也可以用 **View → Zoom In**、**Zoom Out** 和 **Actual Size**；不在会话页面时，它们缩放整个窗口。对话已是 100% 时再按 **0**，则重置浏览器或窗口自身的缩放。
- **鼠标和触控板**：按住 **Ctrl** 滚动，或在触控板上双指捏合。在 Safari 中，捏合手势同样有效。
- **顶栏**：当级别不是 100% 时，**详情**旁边会显示 **− 125% +**；点击百分比即可恢复到 100%。
- **菜单**：会话的 ⋯ 菜单里始终有**缩放**一行，手机上也有。

改变级别时，你在屏幕顶部正在阅读的内容会保持在原处。终端和代码编辑器会自己处理这些按键。

缩放与[设置 → 应用 → 通用 → 外观 → 文字大小](/settings?s=general&find=Text%20size)不是一回事。**文字大小**会放大整个应用中供阅读的文字（消息、帮助页面和你输入内容的框），卡片和图片保持不变；缩放则放大会话对话区的全部内容，对话区以外的内容不受影响。

**全屏查看表格、代码和示意图**：表格右上角有一个小按钮，代码块在**复制**旁边有一个，示意图的工具栏里有**全屏**。它们都会覆盖在页面上打开，在其中：

- 顶部的 **− 100% +** 缩放显示的内容，点击百分比恢复到 100%；
- **Ctrl** 或 **⌘** 加 **+**、**−** 和 **0** 效果相同，按住 **Ctrl** 滚动或双指捏合则以指针位置为中心缩放；
- 放大后，可以用鼠标拖动来移动画面（滚动也可以）；
- 按 **Esc**、点**关闭**或点击旁边即可返回。

图片本来点击后就会放大打开。

### 打开一个步骤查看它的输出

点击任意一个步骤即可打开：

- 命令：命令本身、它运行所在的文件夹、它的退出码和耗时、一个复制按钮，以及它的输出（输出被截断时有**加载完整输出**）；
- 文件编辑：差异（被截断时有**加载完整差异**）；
- 文件读取：指向该文件的链接和读取的内容；
- 网页：它的地址和从中读取的内容；
- 交给子智能体的任务：**布置的任务**，以及返回的结果；
- 其他任何内容：智能体发送了什么以及返回了什么。

步骤可以标为**后台**（它继续运行）、**自动**（Custom 的自动模式做出了决定，悬停可看原因），或者显示红色的退出码。后台任务（留着运行的命令、监视器、工作流）会列在输入框上方的一行中，与会话的子智能体放在一起；打开某个任务可查看它的输出（Claude Code），并可**停止**它，停止前会先询问；子智能体会作为独立的会话打开。参见[子智能体](/guide/sessions#subagents)。

## 在智能体开始前构建项目的记忆

当你在起始页的某个项目中开始会话，而该项目的 [Wiki 记忆](/guide/wiki-memory)还很新（文章不足 10 篇，也没有运行过根据历史记录的构建），并且项目里有可用来构建的内容（对话、提交信息、文档、备注、README 或 docs/ 文件夹）时，会话会先询问你。你的消息下方会出现一张卡片，标题是**要先构建 <项目> 的记忆吗？**，卡片上写明它会读取什么内容，以及在智能体开始之前大约需要多长时间。在你做出选择之前，会话会显示**需要你处理**（你也会收到通知）：

- **构建记忆，然后开始**：开始构建记忆，卡片变为构建进度，会话显示**正在构建记忆**。你的消息会先等待（“记忆就绪后发送给智能体”），一旦最重要的部分写好，就会发送给智能体：这部分包括根据项目文件生成的项目概览、项目的备注，以及内容最丰富的那些对话。其余部分会在后台继续构建，写好一部分，智能体就能找到一部分。**立即开始**会马上发送你的消息，并让构建继续进行；**停止构建**会停止构建（已写好的内容会保留）并启动智能体。你可以关闭应用：智能体会自动启动。如果构建在那之前失败，卡片会告知你，并提供**重试**和**仍然开始**。如果智能体在收到你的消息之前就已结束（它崩溃了，或者等待期间电脑重启了），并且无法再次启动，卡片会提供**在新会话中开始**：使用相同设置的新会话会收到你的消息，接手这期间你发送的内容，而那个空会话会被归档。
- **不用记忆直接开始**：智能体立即启动，并且这个项目在一周内不会再询问。
- **不再为此项目询问**：之后不会再为这个项目询问。**根据历史记录构建 Wiki…** 仍保留在项目详情的**记忆**标签页的 **⋯** 菜单中。

等待期间你发送的任何内容，都会排在第一条消息之后发送给智能体。只有当你自己在起始页开始会话时才会询问；定时运行、应用、子智能体或由智能体启动的会话从不询问，已经构建过的项目也不会询问。

## 批准或拒绝智能体想做的事

当智能体想做的事超出了它的权限、不能自行完成时，它会等待，并在对话末尾用一张卡片询问你：它想运行什么、带有差异对比的文件更改，或者其他工具及其详情，同时显示它已等待了多久。会话的圆点会变成琥珀色，收件箱会计入这一项，如果你开启了通知，还会收到通知。你可以在卡片上回答，也可以在[收件箱](/guide/inbox)中回答；如果只是简单的“是”或“否”，在浏览器显示按钮的地方，还可以直接在通知里回答。

按钮由智能体决定：

- **Claude Code**：**允许**、**拒绝**，通常还有一条规则，例如“始终允许 Bash npm test”或“在此会话中允许所有编辑”。
- **Codex**：**允许**、**在此会话中允许**、**始终允许此命令**、**拒绝**、**拒绝并停止**；对于文件更改，有**在此会话中允许编辑**；对于更广的权限，有**在这一轮中允许**和**在此会话中允许**。
- **Custom**：**允许**、**始终允许**（后面跟着它涵盖的确切内容，只包括你批准的那条命令，因此不会有任何内容附带在其后），以及**拒绝**。
- 其他智能体：它们提供的选项。

**拒绝**会先打开一个输入框，“可选：告诉智能体改做什么”；再按一次**拒绝**即可发送，可以附带说明，也可以不带。（Custom 的**拒绝**和 Codex 的**拒绝并停止**会立即回答。）

已连接账户中你设为**先问我**的工具不会在会话里询问：这次调用会被保留在发件箱中，智能体继续工作。对话中会出现一行**在发件箱中等你确认**，之后会显示它是已发送还是已丢弃（[发件箱](/guide/inbox#the-outbox-calls-held-for-your-ok)）。

在 Claude Code 的**自动**模式下，安全检查可能会直接拒绝某条命令而不是询问。此时消息框上方会出现一张卡片，写着“Claude 拦截了一条命令”以及原因。**批准并重试**会把会话切换为询问，并让智能体再次运行该命令，于是它会作为一次普通的批准请求回到你这里；**关闭**则不做处理。

## 回答问题与批准计划

当智能体向你提问时，会出现一张带琥珀色边框的卡片，显示问题及其选项：

- 选择一个选项，或者在写有“可多选”的地方选择多个。**其他——输入你自己的答案**可以让你写下自己的话。
- **附加文件**可以为回答添加文件。
- 数字键 1 到 9 可以选择第一个尚未回答的问题的对应选项。
- **发送回答**会把它作为你的下一条消息发送。如果会话在提问时已停止，**继续并回答**会带着你的回答重新启动它。对于在 VS Code 或终端中等待的 Claude Code 会话，**在此回答**会在那里结束它，并在这里带着你的回答继续；在那边等待的 Codex 会话则必须在那边回答。

如果问题改以批准卡片的形式出现，它的按钮是**发送回答**，对于 Claude Code 还有**跳过**。

**计划.** 在 Claude Code 的**计划**模式下，智能体会先阅读并制定计划，然后在卡片中展示它的计划：**批准，自动接受编辑**（继续进行，编辑时不再询问）、**批准，编辑前先询问**，或者**继续规划**（它会停留在计划模式；告诉它要修改什么）。在 Codex 的计划模式下，Codex 会先讨论并制定计划，还可能向你提出澄清性问题。Custom 的计划模式会以一份编号的计划结束；切换权限（Shift+Tab）并回复，即可让它执行。

## 填写服务请求的表单

当你连接的某个服务在任务进行到一半时需要你提供一些内容（日期、选项，或需要批准的页面）时，无论是哪个智能体在工作，它的表单都会以卡片形式显示：“Linear 请你填写表单”“……请你打开一个页面”或“……请求继续”。填写字段后按**发送**（或者按**打开**，它会打开该页面，或者按**允许**），也可以按**拒绝**或**暂不**。Codex 自带的工具服务器也以同样的方式询问。参见[已连接的应用、密钥和工具](/guide/connections)。

## 智能体工作时向它发消息

一轮运行期间你也可以输入。此时按 Enter 会怎样，取决于[设置 → 应用 → 通用](/settings?s=general&find=Sending%20while%20an%20agent%20works)中的**智能体工作时发送**，每个浏览器分别设置：

- **加入本轮**（默认）：按 Enter 会把你的消息加入正在进行的这一轮，智能体会立即把它考虑在内。Ctrl+Enter（Mac 上为 ⌘Enter）则改为把它放入队列。
- **等它结束**：按 Enter 会把你的消息放入队列，在这一轮结束时发出。Ctrl+Enter 则改为把它加入本轮。

消息框会说明当前是哪种方式：“向正在运行的这一轮发送追加消息”或“排队等待这一轮结束后发送”。在触摸屏上，发送按钮的作用与 Enter 相同。Custom 会在下一个模型步骤、即正在运行的工具完成之后接收追加消息；对排队的消息，**立即发送**的效果相同。如果你的 Custom 会话在应用更新之前就已在运行，还无法接收实时的追加消息，那么你的消息会留在队列中，直到这一轮结束。其他 ACP 智能体一次只接收一条消息，所以在它们工作时发送的消息总是在队列中等待。在 Claude Code 中，智能体工作期间发送的消息，下方会显示“工作中发送”。智能体对它的回答会作为回复显示在你的消息下方，即使智能体随后继续它的工作也是如此。

## 管理队列

排队的消息在消息框上方等待，按发出的顺序编号；你排队的消息在发送的那一刻就会显示在那里。每当一轮结束时，会自动发出一条。

- 拖动消息的手柄可以更改顺序。
- **立即发送**（箭头）：立刻把它发送到正在运行的这一轮中。
- **编辑**（铅笔）：修改它的文字、移除附件，或添加更多附件（**附加**，或粘贴、拖入文件）。按 Enter 保存，按 Esc 取消。
- **移除**（垃圾桶）：把它从队列中移除；它的附件会被删除。
- 当你停止智能体或应用重启时，队列会暂停：“队列已暂停（智能体已停止，或服务器已重启）。”**继续**会让消息在智能体空闲后重新发出。智能体之间互相发送的消息（会话发给它的 Hydor 子智能体的消息及其回复）不会因重启而暂停：如果它们等待的智能体仍在工作，会在其这一轮结束时发出。达到花费上限也会暂停队列；调高上限后队列会继续。

## 更改智能体、模型、思考强度或权限

会话的消息框中有起始页的**智能体**及其三项选择**模型**、**思考强度**和**权限**，它们合在一个标签中，位于 **+** 旁边（它会打开**选项**，在手机上是从底部弹出的面板）。其下是起始页上适用于该会话的其余选项，顺序相同：**账户**（从你的下一条消息起由另一个账户接管会话；当智能体有多个账户时显示）、**保密**和**竞技场**（按原样显示：两者都在会话开始时选定，点击会告诉你如何换成另一个）、**记忆**、**花费上限**、**集群**、**研究**和**准则**（选项和对话框与会话菜单中的[会话设置](/guide/research#turn-it-on)相同；集群和研究从你的下一条消息起生效）。该标签显示智能体和模型的名称，当思考强度和权限不是常规设置时也会显示它们；当智能体可以不经询问做任何事时（**绕过**，或 Codex 的**完全访问**），它会变成琥珀色。更换智能体从你的下一条消息起生效（参见[在会话中切换智能体](/guide/agents#switch-agents-in-a-session)）。模型、思考强度或权限的更改会立即应用于正在运行的智能体，并保留在该会话中。Shift+Tab 会切换到下一个权限模式。模型菜单只列出这个智能体的模型；要把对话转到另一个智能体，请使用[在另一个智能体中继续](#continue-in-another-agent)。

## 引用回复的一部分

在智能体的某条回复或你自己的某条消息中选中文字：上方会出现一个**引用**按钮（在触摸屏上出现在下方）。它会把这段文字作为引用放入消息框，光标位于其后，这样你就可以回应那一部分，或者重提你之前说过的内容。

## 在会话中查找文字

在会话中按 Ctrl+F（⌘F）。**在此会话中查找**会搜索你的消息和智能体的消息，包括尚未加载的部分（不含命令输出）。输入两个或更多字符；它会跳到最新的匹配项并高亮这些词，同时显示“第 3 个，共 12 个”。按 Enter 跳到较早的匹配项，按 Shift+Enter 跳到较新的匹配项（也可以使用箭头），按 Esc 关闭。被折叠的长消息会展开到找到的位置。在搜索框（Ctrl+K）中选择某条消息，会打开它所在的会话，并且这个栏已经填好内容。

## 消息框中的更多功能

- 在空的消息框中按 ↑ 会调出你在此会话中之前的消息，从最新的开始；按 ↓ 则往回前进。
- 你输入的内容会按会话作为草稿保存在此浏览器中，所以你回来时它仍然在。
- Ctrl+S（⌘S）会把草稿搁置起来并清空消息框；在空的消息框中按 Ctrl+S 会把它找回来。
- 很长的粘贴内容（32,000 个字符或更多）会作为文本文件附加，而不是塞满消息框。
- 占位文字会告诉你发送会发生什么：“给 Claude 发消息…”，或者在智能体未运行时显示“发消息以继续…”：发送会带着整个对话重新启动它。

## 详情面板：更改、命令和信息

标题栏中的**详情**会打开一个有三个标签页的面板。在宽屏上，它位于对话旁边，在你切换会话时保持打开；在较窄的屏幕上，它会滑动覆盖在页面上；在手机上，只有当你要求时才会打开。

- **更改**：会话更改过的每个文件，更改最多的排在前面，并显示新增和删除的行数。点击文件可以查看每次编辑的差异对比；**打开**会打开该文件。
- **命令**：智能体运行过的每条 shell 命令，最新的在前，带有**全部**、**失败**和**背景**筛选。点击某一条可以查看它的输出。
- **信息**：智能体、状态（与标题栏相同：**完成**、**已停止**、**失败**，或它当前正在做的事）、文件夹、分支、模型和思考强度、上下文已使用多少、开始时间和最近活动时间、它的活动（提示、轮次、工具调用、命令）、令牌（输入、缓存、输出）、API 费用（同样的工作按 API 价格计算的费用）、输出速度、它是从哪里启动的（Hydor、VS Code、终端、Claude 桌面应用……），以及在它的智能体运行期间的**它的程序**：它们当前的占用（CPU、内存以及数量），还有它所受的[限制](/guide/app#limit-each-session)。下面是：它的后台任务（打开一个可以查看它做了什么，或者**停止**它），以及**在终端中继续**：在终端中恢复该会话的命令和会话 ID，各带一个复制按钮（Claude Code 和 Codex）。

## 读懂指示器：上下文、缓存和速度

麦克风旁边有一个带百分比的小圆环，随着对话用掉模型的上下文窗口而逐渐填满；其余内容位于“选项”标签菜单的底部：

- **上下文**：圆环，以及“选项”中的**上下文**一行（“已使用 42%”）。指向圆环可以看到确切的令牌数。超过 85% 时它会变成琥珀色。点击圆环，或点击“选项”中的**压缩**，可以压缩对话（一轮运行期间不可用）。在 Custom 会话中，指向圆环可以看到令牌数及其去向的明细，明细位于**上下文**一行的箭头下方；Custom 会自行精简，所以没有**压缩**，点击圆环也没有作用（参见[长对话和长输出](/guide/custom#long-conversations-and-long-output)）。
- **缓存 4 分钟**（Claude Code）：提示缓存会让对话保持待命一段时间（5 分钟或一小时），因此下一条消息更便宜也更快。在你不发送任何内容时它会倒计时；在此之前发送消息会重用它，并重新开始计时。**缓存已过期**表示下一条消息会重新构建它。
- **85 tok/s**：最近一条回复的撰写速度，单位为每秒令牌数。

## 停止一轮、停止智能体或继续

智能体启动或工作时，消息框旁的“停止”按钮上有一圈旋转的环。当智能体需要你处理时，这圈环会暂停转动；如果你的设备要求减少动态效果，它则保持静止。一轮结束后，只要智能体启动的后台任务或子智能体仍在运行，例如 Hydor 子智能体、Claude Code 子智能体、一条仍在运行的命令或一个监视器，“停止”按钮就会连同它的环一直保留；发送按钮在它旁边，消息框也照常接收你的消息。将鼠标指向“停止”，可以看到它会停止什么：“停止本轮、2 个子智能体和 1 个后台任务”，或“停止 2 个子智能体”。它会一次性全部停止：这一轮、每个正在运行的子智能体、每个正在运行的后台任务，以及它们各自接着启动的那些。以这种方式停止的 Hydor 子智能体不会再向其上级汇报；已经在途中的汇报会留在上级暂停的队列里，不会唤醒上级；按 **继续** 即可放行队列。会话启动的作业（用 `job` 命令运行的，或实验的运行）在结束前，会让会话保持“工作中 · 1 个在后台”的状态。但“停止”按钮不会停止它们，因此只有这些作业时不会显示“停止”按钮：请在 **作业** 中停止它们。

- **停止一轮**：按标题栏中的 **停止**，或消息框旁的圆角方形按钮，后者同时会停止该会话启动的其他内容（见上文）。（Esc 不能停止它：它只会关闭已打开的内容，例如查找栏或列表。）智能体会停下手头的工作；这一轮会显示“已停止，用时……”。你按下 **停止** 的那一刻，会话就显示为已停止，即使智能体还要几秒才能完全收尾（比如结束它正在运行的命令）；如果 20 秒后智能体仍在工作，会话会再次显示为工作中。智能体仍会随时待命，等你发送下一条消息，队列则会暂停，直到你继续。
- **停止智能体进程**：会话的菜单（⋯）→ **更多** → **停止智能体进程**，仅在没有正在进行的轮次时可用。智能体的程序会结束；会话及其历史记录保留，并显示它上一轮的结束方式（**完成**、**已停止** 或 **失败**）。
- **继续**：标题栏中的 **继续** 会带着整段对话重新启动智能体，你也可以直接发送一条消息（“发消息继续……”），这同样会重新启动它，Claude Code、Codex 和 Custom 都一样。在 **完成** 之后，**继续** 是一个更低调的按钮，因为你只需发送下一条消息即可。如果会话在几秒前刚被写入，比如来自 VS Code 或终端，应用会先询问你，因为两个程序同时写入同一个会话可能会损坏它的历史记录。
- 智能体闲置三小时后会自行停止（前提是没有任何事项在等你处理，也没有后台任务在运行）；你发送下一条消息时，它会再次启动。

## 为会话设定目标

目标会让智能体一轮接一轮地持续工作，直到你们商定的检查项全部成立。可以从会话的菜单（⋯）→ **设定目标** 设定，也可以在起始页的 **选项** 中带着目标开始会话。目标如何运作，从商定检查项到在运行时掌控目标，请见[目标](/guide/goals)。

## 分叉会话

分叉是一个新会话：它从当前对话开始，然后尝试别的做法；当前会话保持原样。

1. 打开会话的菜单（⋯）→ **分叉**，或者在某条回复下方点击 **从这条回复分叉**（Claude Code 的任意一条回复均可；Codex 和 Custom 则只能用已完成一轮的最后一条回复），只保留到那里为止的对话。
2. 写下分叉要做什么（“分叉要改为尝试什么？”）。
3. 点击 **分叉**（或按 Ctrl+Enter）。

分叉会打开，标题为“… · fork”，使用相同的智能体、模型、思考强度、权限和账户。它顶部有一行“Forked from …”，旁边是 **打开**（Codex 的分叉只显示之后的内容；之前的对话在原会话中）。Claude Code、Codex 和 Custom 都支持分叉，但在其他应用中打开的会话不支持。对话被压缩之前的 Claude Code 回复也可以分叉：分叉会从压缩前的完整对话开始，一直到那条回复。

## 从这里编辑

回到你的某条消息，改成说别的内容：

1. 点击消息下方的 **从这里编辑**。
2. 修改文字。
3. 如果也要撤销智能体在那之后所做的改动，请勾选 **把文件恢复到这条消息之前的样子**。
4. 点击 **从这里发送**（Enter），或 **取消**（Esc）。

对话会在一个副本中继续，副本只保留到那条消息之前的内容，并沿用本会话的标题；本会话则会被归档。恢复文件适用于 Claude Code（使用它自己为从本应用发送的消息所做的检查点）、Custom（恢复它自己的编辑所改动的文件；命令改动的内容不会恢复），以及任何在工作树中的会话（每次你发送消息时都会拍一份快照）。Codex 会话只有在工作树中才能恢复文件。如果某一轮正在运行，请先停止智能体。当会话的[目标](/guide/goals)正在检查文件或恢复文件时，恢复文件会被拒绝（“This session’s goal is checking its files right now: wait for it to finish, or pause the goal first”）；会话被替换时，目标本身也会停止。从这里编辑适用于 Claude Code、Codex 和 Custom。

## 在另一个智能体中继续

把对话交给另一个智能体，在那边继续：

1. 打开会话的菜单（⋯）→ **Continue in Codex**（或 **Continue in Claude Code**，或在 Custom 有了模型之后选择 **Continue in Custom Agent**）。
2. 消息框上方会出现一条提示，说明你的下一条消息将发送到那里；模型、思考强度和权限的选择现在适用于新的智能体。点击 ×（“Stay here”）可以取消。
3. 写一条消息，或者直接发送以继续。

新会话会在同一个文件夹中打开，并带有到目前为止的对话：你的第一个请求，然后是能放进约 15,000 个 token 的最近几条消息，以及已改动的文件。新的智能体会被告知完整对话保存在哪里，因此可以读取被省略的部分。它的第一条消息显示“Continued from Claude Code”，并带有 **打开那个会话** 和一个可以显示所带入消息的按钮；旧会话则显示“This conversation continued in Codex”，并带有 **打开**。这适用于 Claude Code 和 Codex 会话。

## 压缩对话

压缩会用一份摘要替换到目前为止的历史记录，为接下来的内容腾出模型上下文的空间。使用会话的菜单（⋯）→ **更多** → **压缩对话**，或点击消息框中的上下文计量表，然后点击 **压缩** 确认。它适用于 Claude Code 和 Codex，且只能在两轮之间进行。Custom 会自行压缩过长的对话。

## 重命名、置顶、延后、告一段落、归档或删除

其中大多数操作都在会话的菜单（⋯）里，也在侧边栏中该会话所在行的菜单里：指向该行并点击行末的 **⋯**，或右键点击它（在手机上，点按它的 **⋯**）。

- **重命名**：输入新标题（最多 200 个字符）；按 Enter 保存，按 Esc 取消。双击页眉或侧边栏中的标题，或在选中某行后按 F2，效果相同。
- **重命名文件夹**（在侧边栏中，针对不在项目里的会话）：为它工作所在的文件夹取一个你自己的名称，侧边栏、会话行和文件夹菜单会在所有设备上显示这个名称；文件夹在磁盘上仍保留它自己的名称。留空则使用文件夹本身的名称。
- **移到文件夹**（在侧边栏中）：把会话放进你为会话建立的某个文件夹，或从中移出，或为它新建一个文件夹。你也可以把会话拖到文件夹的标题上。参见[把会话归入文件夹](/guide/start#sort-sessions-into-folders)。
- **置顶** / **取消置顶**：置顶的会话保留在 **已置顶** 分组中，顺序按你拖动的次序。你也可以把会话从它下面的分组（某个项目或文件夹的分组、今天、昨天……）拖到“已置顶”上，或者在还没有置顶会话时拖到“Drop here to pin”上。
- **延后**：把会话隐藏到底部的 **已延后** 分组中，直到 **1 小时**、**3 小时**、**今晚**（仅当现在早于下午 5 点时提供）、**明天早上**、**下周**（周一早上）或 **选择日期和时间**。它会自动回来并给出提示，如果需要你处理，也会更早回来。**Unsnooze** 会立即把它带回来。
- **告一段落：先到这里**：用于已完成的工作。智能体会停止（某一轮运行时不提供此选项），会话算作已读；它的历史记录和工作树都会保留。对于在工作树中的会话，会打开工作树的对话框，让你可以移除它。
- **归档** / **取消归档**：把会话从列表中移除；不会删除任何内容。已归档的会话可以通过搜索框（Ctrl+K）找到，并标有 **已归档**；打开其中一个，在它的菜单中选择 **取消归档**。
- **删除会话**：你确认之后，会话的历史记录会从磁盘上移除，因此它也会从智能体自己的命令行和 VS Code 中消失。此操作无法撤销。侧边栏中该行菜单里的 **删除** 效果相同。

在你删除它之前，应用会保留每一个会话，即使智能体自己的程序删除了它的对话（Claude Code 在 30 天后会这样做，除非另行设置）：它会回来，被列出并可以打开。一年无人使用的会话会被自动删除，除非你把它们置顶，或在 设置 → 通用 中更改这一点（参见[删除不活跃的会话](/guide/app#delete-inactive-sessions)）。

置顶、取消置顶、归档、取消归档和延后都会显示带有 **撤销** 的提示，Ctrl+Z 可以在 8 秒内撤销它们。

## 分享只读链接

会话的菜单（⋯）→ **分享只读链接** 会创建一个任何人无需你的密码就能打开的链接（[保密会话](#keep-a-session-confidential)不可用）。他们可以实时看到对话（消息、按名称列出的步骤、文件改动以及智能体展示的网页），但看不到命令输出或智能体的思考过程，也不能输入或更改任何内容。选择链接的有效期（**一天**、**一周**、**一个月**、**直到关闭**），然后点击 **创建链接**；链接只显示一次。同一个对话框会列出当前有效的链接、每个链接被打开的次数，并可以关闭某个链接。参见[手机、其他机器与分享](/guide/devices)。

## 导出对话

会话的菜单（⋯）→ **导出** 可以把对话从聊天中取出：

- **导出为 Markdown** 会把它下载为一个 Markdown 文件，文件名取自会话标题，便于保存、发送或在任何笔记应用中打开。
- **复制为 Markdown** 会把同样的文本放到剪贴板上，方便粘贴到笔记、电子邮件或其他应用中。
- **保留为文档** 会把它做成一份文档，保存在会话所属的项目中（它会显示在项目的 **文件** 里；没有项目时则与这段对话放在一起），你可以在那里阅读、编辑、评论、打印，并导出为 Word 或 PDF。准备好时会有消息提示；点击 **打开** 即可前往。

包含的内容：标题和日期，然后按顺序列出你的每条消息和智能体的每条回复，并带有时间。一轮中的步骤会被省略，用一行文字代替，例如“Worked for 2 min · 5 steps”。智能体交付的文件会按名称列出。回答卡片会变成可阅读的文本，表格仍是表格（比较表、数据表、图表的数字）。示意图保留为它们的 Mermaid 代码，数学公式保留为 LaTeX，与智能体写的一致。在文档中，你附在消息里的图片和智能体交付的图片也都会包含在内。

[保密会话](#keep-a-session-confidential)也可以导出，它的文档和它的其他工作一样保留在这台电脑上：来自网络的图片只保留为链接，不会被抓取。在终端中，`hydor sessions export` 可以做同样的事（[终端中的 Hydor](/guide/terminal)）。

## 在工作树中工作

工作树是仓库文件在新分支上的一份独立副本，因此智能体可以在不触碰你自己那份副本的情况下做改动，多个智能体也可以同时在同一个仓库上工作。

- **开始一个**：在起始页面中，打开 **文件夹** 并开启 **New worktree from …**（该文件夹必须位于 git 仓库中）。应用会用 `agent/` 加上你任务中的几个词来命名一个分支，基于当前检出的分支创建，并在应用的数据文件夹中为它建一个文件夹。这个开关会为下次保留。
- **快照**：在工作树中，每次你发送消息时，应用都会保留一份文件快照，这样[从这里编辑](#edit-from-here)就可以把它们恢复。
- **查看它**：会话的菜单（⋯）→ **文件夹与代码** → **Worktree: agent/…**，会显示该分支和它的来源分支、它的文件夹、领先或落后多少个提交，以及未提交的更改，并带有 **查看它的改动** 和 **在 Git 中打开**。
- 工作完成后 **移除它**：在同一个对话框中点击 **移除工作树**。文件夹会被删除；会话保留它的历史记录。分支会保留，因此已提交的内容不会丢失，除非你勾选 **Delete branch … too**（没有任何新内容的分支无论如何都会被删除）。如果有未提交的更改，请先勾选 **Discard the … uncommitted changes**。如果智能体正在运行，它会停止，共用该工作树的分叉或编辑也会失去它。

## 创建拉取请求

在会话的分支上，会话的菜单（⋯）→ **文件夹与代码** → **创建拉取请求**，会在 GitHub 或 Gitea 上创建一个拉取请求。**帮我写** 会根据提交和差异起草标题与说明；有一个选项可以先提交未提交的更改；**草稿** 会把它标记为草稿；当你点击 **创建拉取请求** 时，分支会被推送。你需要在 [设置 → Source control](/settings?s=scm) 中有一个账户。**关联一个已有的拉取请求…** 可以关联在别处创建的拉取请求。

关联之后，它的状态和检查项会以徽章形式显示在侧边栏和页眉中，每隔几分钟更新一次，并在它被合并或检查项完成时给出提示。同一个菜单项现在变成 **Pull request #12**，其中有 **Open on GitHub**（或 Gitea）、**查看改动**、**立即检查** 和 **取消关联**。子菜单中的 **查看改动** 会逐个文件地查看该分支改动了什么。参见[文件、Git、终端和预览](/guide/files-git)。

## 用量限额让会话停下时

当 Claude Code 或 Codex 的套餐用量用完时，消息框上方的横幅会说明是谁的限额、哪一种限额以及何时重置：当该智能体只有一个账户时显示“You've hit the Claude Code usage limit”；当你有多个账户而且都没有剩余用量时显示“All your Claude Code accounts have hit their usage limit”；当另一个账户仍有用量时，则显示该账户的名称（“Work has hit its usage limit”）。

当该智能体的另一个账户仍有剩余用量时，只要 **达到限额时切换账户** 处于开启状态，你就不会看到横幅：会话会转到那个账户并继续（新会话也从那里开始）。关闭时，横幅会指出那个账户，并提供 **开启**。

- **重置时继续** 会在限额重置一分钟后自动继续会话，发送的消息是“Continue where you left off.”。之后横幅会说明时间，并带有 **取消**。
- **使用一次重置**：当你的账户有可用的限额重置次数时，横幅会说明有多少次，点击它会立即使用一次。
- [限额后继续](/settings?s=general&find=Resume%20after%20usage%20limits)（位于 设置 → App → 通用）会对每一个被限额停下的会话这样做。开启后，会话中不会出现警告：消息框上方会有一行文字，说明是谁的限额（和横幅一样）、哪一种限额以及何时继续（“All your Claude Code accounts have hit their usage limit”，然后是“Current session (5 h) · Continues by itself in 3 h 15 min.”），如果你有可用的重置，还会带有 **使用一次重置**，以及 **取消**。你自己用 **停止** 停下的会话不会自动继续。

时间会跟随限额变化：如果重置时间推后，或用量提前恢复，会话就在那时继续。参见[用量、限额与费用](/guide/usage)。

## 在 VS Code 或终端中运行的会话

这台电脑上的每一个 Claude Code 和 Codex 会话都会被列出，包括你在 VS Code、终端或 Claude 桌面应用中运行的会话。当它们在那里运行时，列表会显示“Working in VS Code”、“Needs you in terminal”或“Open in VS Code”（灰点），你可以边看边跟着它们工作。如果某个会话在那边等你，应用只有在它一分钟后仍在等待时才会通知你。

- **接管 Claude Code 会话**：点击页眉中的 **在这里继续**，或者直接发送一条消息（“Open in VS Code — sending moves it here”）。应用会先询问：它会结束那个应用中的会话，停止它正在做的事，并在这里带着完整历史记录恢复它。那个应用会把它显示为已结束；你之后可以在那里重新打开它。
- 在别处打开的 **Codex 会话** 在这里是只读的，因为那边的一个 Codex 进程为它的所有线程提供服务。请在那里继续它，或者在那里关闭它，然后在这里恢复。
- 当会话在另一个应用中打开时，不提供分叉。

## 子智能体

智能体可以把工作的一部分交给子智能体，再取回它们的结果。子智能体有两种，应用会标明是哪一种：

- **Hydor 子智能体**是由 Hydor 启动的独立会话，可以使用任意智能体和模型。它在父会话对话中的子智能体卡片里占一行，在侧边栏中位于它的父会话之下，你可以打开它并与它交谈。它有自己的费用，也占父会话花费上限中的一份，它的回复会作为一条消息回到父会话。
- **Claude Code 子智能体**（在 Codex 中叫“Codex 子智能体”：以会话自身程序的名称命名）是该程序在会话内部为完成工作的一小段而运行的子智能体。Hydor 在它运行的会话中会关闭这类子智能体，所以你只会在 VS Code 或终端中运行的会话以及较早的会话里看到它们。它的显示和打开方式与 Hydor 子智能体相同：在对话的卡片中占一行，在侧边栏和托盘中占一行，并有一个显示完整对话的独立页面。但你无法与它交谈（它的主导者可以），它的花费算在主导者自己名下，也不占花费上限中的份额。

在侧边栏中，子智能体在工作或等待你时，会折叠在它们的父会话之下，Hydor 子智能体和程序自带的子智能体合在一行显示（“3 个子智能体 · 1 个需要你”“2 个子智能体”）；点击这一行即可看到每个子智能体各占一行。已完成的子智能体会离开侧边栏，除非你正在查看它，而且在你查看其中某一个时，这一行会保持展开。集群的成员显示为“集群成员”，战役的成员显示为“战役成员”。在父会话的对话中，某一轮启动的子智能体会合并为该轮下方的一张卡片：Hydor 子智能体在一张卡片中，程序自带的子智能体（Claude Code 的或 Codex 的）在另一张卡片中。卡片的顶行会说明有多少个、是哪一种，以及它们共有的信息（“6 个 Claude Code 子智能体 · Sonnet 5.5”“3 个 Hydor 子智能体 · Claude Code · Sonnet 5.5”，深度研究中则是“4 名研究员”），还有它们的进展（“5 个工作中 · 1 个已完成”，也可能是“1 个需要你”“1 个已停止”“1 个失败”）。点击这一行可折叠或展开卡片：只要有任何一个在工作或需要你，卡片就是展开的；全部完成后，则折叠为这一行。

在它下面，每个子智能体占一行：一个状态颜色的圆点（工作时为蓝色并轻轻闪动；需要你时为琥珀色；完成时为绿色；停止时为灰色；失败时为红色）、它的标题，在宽屏上还有它与其他子智能体不同的信息（它的类型或模型、它所担任的你的智能体、它的档位），以及它的进展：到目前为止已工作多久、“需要你”、完成的时间（“3 分钟前”）、“已停止”或“失败”。Hydor 子智能体的这一行还会显示它的费用，将鼠标指向一个已升级的子智能体时，会显示“升级自”它最初的档位及原因。点击某一行即可打开该子智能体。当其他子智能体仍在工作时，已完成的会折叠为一行，例如“4 个已完成：”加上它们的标题：点击即可查看。失败的会保持单独一行。工作中的超过六个时，会显示五个，并带有**显示另外 3 个**。

如果某一轮只启动了一个子智能体，它会显示为单行卡片：带状态圆点的图标、它的标题、它是什么（“Claude Code 子智能体 · Explore · Sonnet 5.5”，或“Hydor 子智能体 · Claude Code · Sonnet 5.5”，如有则带上它所担任的智能体和它的档位），以及它的进展。

要停止某个子智能体，请将鼠标指向它的那一行（或用 Tab 键选中它），**停止**会代替时间显示出来；在触摸屏上，始终有一个小的停止按钮。Claude Code 子智能体会先询问（“停止这个子智能体？”），Hydor 子智能体会立即停止，而 Codex 子智能体无法在这里逐个停止。卡片的 **⋯** 菜单中有**停止 5 个子智能体**（数字为可停止的个数），它会不经询问地全部停止。启动子智能体的那次调用，仍作为该轮已折叠工作中的一个步骤保留。

当在后台工作的子智能体回来时，父会话的对话中会显示一行：“来自”加上它的标题的回复，或“……已停止”，或“……因错误而停止”，并附上它所写内容的开头。点击它即可阅读回复，点击**打开它的会话**可前往该会话。Codex 子智能体的回复会在你打开这一行时，从它自己的对话中获取。在父会话仍在工作时到达的回复，会就地显示在前后步骤之间。

在 Hydor 子智能体内部，消息框上方有一个栏，写着“子智能体，所属：”加上父会话的标题（“它的回复会回到那里”），并带有**打开父会话**。Claude Code 或 Codex 子智能体也会作为会话打开，但是只读的：它显示所收到的任务、它的步骤和它的回复，在工作时实时更新，没有消息框，也没有**继续**或会话菜单。在消息框的位置上，有一个栏写着“Claude Code 子智能体，所属：”加上父会话的标题（“它的回复会回到那里”），并带有**打开父会话**。Claude Code 子智能体工作时，它标题栏中的**停止**会停止它，并会先询问。向它发送消息、继续、分叉、交接或删除它都会被拒绝：它的程序在父会话内部运行它，所以请与父会话交谈。

如果父会话自己的一轮已经结束，而它的子智能体仍在运行，那么它并未完成：它的圆点会继续呼吸般地闪动蓝色，消息框上停止按钮的圆环会继续转动，它的状态显示为“工作中 · 2 个子智能体运行中”，不显示“已完成”标记，并仍留在“活跃”中，你还可以给它发送消息。Claude Code 会话和 Codex 会话都是如此。如果 Hydor 子智能体自己的一轮结束后，它启动的子智能体或后台任务（命令、监视器）仍在运行，它也算作正在运行，所以它的父会话显示为工作中，而不是已完成。父会话上的花费上限涵盖它的 Hydor 子智能体，而 Claude Code 或 Codex 子智能体的花费本来就算在父会话名下。参见[深度研究、第二意见与多个智能体](/guide/research)。

在消息框上方，有一行汇总该会话启动的所有内容：它的子智能体和它的后台任务（命令、监视器、工作流）。它显示为“2 个子智能体和 1 个后台任务运行中”；当有 Hydor 子智能体在等你时，会用琥珀色显示“1 个需要你”；当没有任何东西在运行时，则显示“3 个子智能体 · 2 个后台任务 · 全部完成”。每次打开会话时，它都是折叠的。点击它可列出每一项：需要你的在最上面，然后是运行中的，再然后是已结束的，最新的在前，超过大约五项后在内部滚动。每一行的样子都相同：带状态圆点的图标、标题、它是什么（“Hydor 子智能体 · Claude Code · Sonnet 5.5”“Claude Code 子智能体 · Explore · Haiku 5.5”“命令”“监视器”“工作流”）、它的进展（“工作中 · 2 分 10 秒”“需要你”“已完成 · 3 分钟前”“已停止”“失败”）、Hydor 子智能体的费用（程序自带的子智能体不显示：它的花费算在父会话名下）、**打开**，以及运行时的停止按钮（圆圈中的方块）。将鼠标指向它是什么，可以看到由谁来运行它：“Hydor 将它作为独立会话启动：打开它即可查看或与它交谈”，或“Claude Code 在这个会话内部运行它：打开它即可查看”。**打开**会带你到 Hydor 子智能体或 Claude Code、Codex 子智能体的会话；命令、监视器或工作流则会在页面右侧的面板中打开（在手机上是整个屏幕），其中有它的标题、类型和状态，运行时有**停止**，下方是它的输出。它每两秒刷新一次，并保持在最新的几行，除非你向上滚动。子智能体的停止按钮写着“停止这个子智能体”，任务的则写着“停止这个任务”。这一行右侧的**全部停止**会停止所有正在运行的内容，作用与消息框旁的停止按钮相同。集群或战役的成员不在这里列出：它的看板会显示它们。已结束的任务会一直列出，直到智能体的程序停止；在 VS Code 或终端中打开的会话会列出它的任务，但无法停止它们。

一个会话同时运行多少个 Hydor 子智能体，在[设置 → 功能 → 子智能体](/settings?s=children)中设定：这些设置针对的是 Hydor 子智能体，因为 Claude Code 和 Codex 自带的子智能体在它们自己的会话内部运行。在设置 → 模型 → 档位中开启[由子智能体协助主导](/settings?s=models&find=Lead%20with%20subagents)后，会话的主智能体会做规划，把明确的部分交给较便宜档位上的子智能体，并检查它们的工作。

## 会话菜单中的全部内容

会话右上角的 ⋯ 按钮会打开它的菜单。有些项目只在适用时才显示；[保密会话](#keep-a-session-confidential)的菜单中没有**分享只读链接**、**创建拉取请求**、**打开浏览器**、**已连接的账户**、**把它设为自动化**或**另存为应用**，它的记忆也保持关闭。

- **重命名**：就地编辑标题。
- **缩放**：包括 **−**、当前比例和 **+**，用于在这台设备上缩放[对话](#zoom-in-and-full-screen)；点按比例数字可恢复到 100%。
- **置顶** / **取消置顶**。
- **延后**（一个时间子菜单），在延后期间则为**取消延后（在……回来）**。
- **告一段落：先到这里**：停止智能体，并把会话标为已读（某一轮运行时不可用）。
- **分叉**：基于这段对话新建一个会话（Claude Code、Codex、Custom）。
- **在 Codex 中继续**、**在 Claude Code 中继续**、**在 Custom 智能体中继续**：把对话带到另一个智能体（从 Claude Code 和 Codex 出发）。
- **设定目标**：智能体和你商定检查项，它会一轮接一轮地工作，直到这些检查项都满足；适用于所有智能体；在尚未设定目标时可用。参见[目标](/guide/goals)。
- **第二意见**：另一家公司的模型会对照你的要求检查某一轮的工作，它的发现会显示在该轮下方。参见[深度研究、第二意见与多个智能体](/guide/research)。
- **分享只读链接**。
- **导出**（子菜单）：**导出为 Markdown**、**复制为 Markdown** 和**保留为文档**。参见[导出对话](#export-a-conversation)。
- **文件夹与代码**（子菜单，适用于有文件夹的会话）：
  - **查看改动**：这个分支改了什么，逐个文件显示。
  - **创建拉取请求**，已有拉取请求时则为**拉取请求 #12**。
  - **工作树：agent/…**：工作树的对话框（适用于位于工作树中的会话）。
  - **浏览文件夹**：在会话的文件夹处打开文件。
  - **在访达中显示**、**在文件资源管理器中显示**或**在文件夹中显示**：在桌面应用中，在系统的文件管理器里选中会话的文件夹（参见[处理文件和文件夹](/guide/files-git#work-with-files-and-folders)）。
  - **在此处打开终端**：在该文件夹中新建一个终端（在电脑上位于底部的面板中，在手机上位于终端页面）。
- **会话设置**（子菜单）：
  - **记忆**，旁边显示**开启**或**关闭**：为这个会话开启或关闭记忆（当设置中记忆已关闭时显示“对所有会话关闭”）。参见[记忆](/guide/memory)。
  - **花费上限**，旁边显示上限：设定、更改或提高它。参见[用量、限额与费用](/guide/usage)。
  - **已连接的账户**：仅为这个会话开启或关闭每个已连接的账户。参见[已连接的应用、密钥与工具](/guide/connections)。
  - **集群**，旁边显示**关闭**、**开启**或**战役**：打开一个对话框，从你的下一条消息起开启或关闭集群或战役。参见[深度研究、第二意见与多个智能体](/guide/research#set-a-swarm-on-a-hard-problem)。
  - **深度研究**，旁边显示**关闭**或搜索次数：打开一个对话框，从你的下一条消息起开启、关闭或更改深度研究。参见[深度研究、第二意见与多个智能体](/guide/research#turn-it-on)。（保密会话以及由其他会话启动的会话不显示集群和深度研究。）
  - **智能体**，旁边显示它的名称：打开该智能体的页面（适用于有智能体的会话）。在消息框中可以切换它。
- **更多**（子菜单）：
  - **打开浏览器** / **显示浏览器**：智能体在这个会话中使用的浏览器，你可以观看并接管。参见[搜索与浏览器](/guide/web)。
  - **把它设为自动化**：辅助模型会读取这个会话，并据此起草一个定时任务；你可以修改任何内容，用一次测试运行试试看，然后保存。参见[定时任务](/guide/tasks)。
  - **另存为应用**：基于这个会话开始一个新应用。参见[应用](/guide/apps)。
  - **压缩对话**（Claude Code 和 Codex）。
  - **复制 CLI 恢复命令**：在终端中继续这个会话所用的命令。
  - **停止智能体进程**（在智能体运行且没有进行中的一轮时可用）。
- **归档** / **取消归档**。
- **删除会话**：从磁盘上移除它的历史记录，需要你先确认。
