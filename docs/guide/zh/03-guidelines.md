# 智能体准则

智能体准则是你希望这里每个智能体都遵循的内容：你喜欢怎样工作，什么事一定要做、什么事绝对不能做，以及怎样跟你说话。同一段文字适用于每个智能体（Claude Code、Codex、Custom，以及支持 ACP 的智能体），你可以为所有会话、为某个空间，或为单个会话来写。

## 什么是准则

准则就是会话开始时、在你发出第一条消息之前，应用交给智能体的一些平常话：“用通俗易懂的中文回答，并解释所有术语”“删除任何东西之前先问我”“你做的东西都放在 ~/Work 里”“使用英式拼写”。智能体在整个会话中都会遵循它们。

你不需要知道每个智能体是怎样读取指令的。Claude Code 和 Codex 各有自己专用的文件（CLAUDE.md 和 AGENTS.md），其他智能体也各有各的方式；应用会亲自把你的准则交给它们每一个，所以写一段文字就够它们全部使用了。

你在对话中提出的要求永远优先：如果你的准则写着“简短回答”，而你要一份详细的报告，你得到的就是报告。

## 三个层级

准则分为三个层级，从最通用到最具体：

1. **适用于所有会话**：每个会话中的每个智能体。在[设置 → 智能体 → 智能体准则](/settings?s=guidelines)中设置。
2. **适用于某个空间**：那个[空间](/guide/spaces)中的每个会话。在空间的页面上，于它的**智能体准则**字段中设置。
3. **适用于单个会话**：只有那一个会话。会话开始前在开始页上设置（**选项 → 准则**），或者之后从会话的菜单（⋯）→ **会话设置 → 准则**中设置。

智能体会按这个顺序得到适用于它会话的所有层级。两个层级说法不一致时，更具体的那个优先：会话的准则优先于它所在空间的准则，空间的准则优先于适用于所有会话的准则。

## 为所有会话写准则

1. 打开[设置 → 智能体 → 智能体准则](/settings?s=guidelines)。
2. 在**适用于所有会话**下面，写下每个智能体都应该知道的关于你的情况，以及你的工作方式。
3. 点击**保存**。

输入框下方有几种现成的、让智能体跟你说话的方式（**通俗易懂，回答简短，解释术语**、**温和、多鼓励：我是新手**、**简洁、偏技术**）。点一下就会把它作为一行加进去（“How to talk to me: …”），保存前你可以修改。

每个层级最多可以写 20,000 个字符。能短就尽量短：每个会话都会读完全部内容，几行清楚的话比好几页更管用。

## 给空间写准则

每个空间都有自己的准则，用于你放在其中的工作：它是为谁做的、用什么风格来写、项目有哪些规则。

1. 在侧边栏中打开**空间**，选择那个空间。
2. 在**智能体准则：其中每个智能体都遵循的内容**字段中写下准则。
3. 保存这个空间。

你也可以在新建空间时就写好，就在新空间表单的同一个字段里。**设置 → 智能体 → 智能体准则 → 适用于某个空间**会列出每个有准则的空间；点击其中一个即可打开它。

在组（把几个空间组合在一起的空间）中，会话遵循组自己的准则；在使用组里的某个空间时，也会读取那个空间的要求，作为使用它的一部分。

## 单个会话的准则

### 开始之前

1. 在开始页上，打开**选项**（在消息框旁边）。
2. 点击**准则**。会打开一个对话框，停在**此会话**标签页上。
3. 写下只有这个会话要遵循的内容，然后点击**保存**。之后选项按钮上会显示**仅本会话**。

同一个对话框还会在各自的标签页上显示空间的准则（如果你选了空间）和适用于所有会话的准则，这样你就能看到智能体将会遵循的全部内容，也能修改它们。标签页上有圆点，表示那个层级已经写了准则。

### 在运行中的会话里

1. 打开会话的菜单（⋯）→ **会话设置 → 准则**。
2. 修改**此会话**的准则（或空间的、或所有会话的），然后点击**保存**。

修改从你的下一条消息起生效。Claude Code 和 Codex 在启动时读取指令，所以当你发送下一条消息时，应用会悄悄地带着新准则重新启动智能体；对话会从原处接着进行。如果智能体正处在一轮对话中间、正在朝某个目标工作，或者有工作在后台运行，这一步会等待：等它空闲下来才进行。Custom 本来就会在每一轮之前读取准则。其他智能体（Gemini CLI、OpenCode 等）要从下一个会话开始才会采用修改后的准则。

## 怎样写出好的准则

- **想要什么就直说**：“安装任何东西之前先问我”比“小心点”清楚。
- **长期不变的放在这里，具体任务写在消息里**：准则是用来写每次都成立的事情的。
- **用对层级**：你喜欢别人怎样跟你说话，属于所有会话的准则；项目的规则放在它的空间里；一次性的限制放在会话的准则里。
- **及时更新**：智能体老是做你不想要的事时，就加一行。

一些例子：

- 适用于所有会话：“用通俗易懂的中文回答。术语第一次出现时要解释。删除文件或向这台电脑以外发送任何东西之前，先问我。”
- 适用于空间“Thesis”：“按 APA 格式引用。这篇论文是关于希腊乳业的。草稿放在 drafts 文件夹里。”
- 适用于单个会话：“只使用 Python 的标准库。”

## 智能体与你交流的方式

以前的**智能体与你交流的方式**设置（在设置 → 功能 → 助手中）现在已经并入适用于所有会话的准则：你在那里写过的内容都已移到准则里，成为以“How to talk to me:”开头的一行。要修改或删除，就去那里改。

## CLAUDE.md 和 AGENTS.md

Claude Code 和 Codex 还会读取它们自己的指令文件：CLAUDE.md（Claude Code）和 AGENTS.md（Codex）。放在你的主文件夹里的，对每个会话都生效；放在项目文件夹里的，对在那里工作的会话生效。它们照常起作用。有些人把这类文件放在代码仓库里，好和参与这个仓库的所有人共享，他们仍然可以在这里编辑：

1. 打开[设置 → 智能体 → 智能体准则](/settings?s=guidelines)。
2. 打开底部的 **Claude Code 和 Codex 也会读取的文件**。
3. 选择文件夹，然后选择 **Claude Code** 或 **Codex**，再选择要编辑的文件（或**创建**它）。

列表会显示智能体在那个文件夹的会话中读取的每个文件，按它读取的顺序排列。对大多数人来说，准则更简单：它们对每个智能体都有效，也不需要任何文件。

## 问问智能体

- “在我的准则里加一条：始终用中文回答。”
- “这个会话遵循哪些准则？”
- “给我的 Thesis 空间加一条准则：按 APA 格式引用。”
- “把关于英式拼写的那一行从我的准则里删掉。”
- “仅限这个会话：不要使用标准库以外的任何库。”
