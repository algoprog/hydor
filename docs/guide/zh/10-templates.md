# 模板

模板是一项你会反复运行的任务：填一张简短的表单，按下“运行”，智能体就会独立完成工作，并把结果以卡片或表格的形式交还给你。本主题介绍现成模板、如何运行模板并完善结果、如何创建你自己的模板（也包括带步骤、数据、记忆和自己的界面的模板）、如何通过 API 密钥、其他智能体、公开页面或电子表格中的多行数据来共享模板，以及如何把模板作为文件传给别人。

![模板：你自己的模板，以及可以直接拿来用的现成模板](images/templates.webp)

## 什么是模板

模板保存了一项任务所需的一切，只有每次都会变的细节除外：

- **表单**：每次运行前要回答的问题（“去哪里？”“天数”）。
- **任务**：要智能体做的事，其中会填入这些回答。
- **答案**：结果中的各个字段（一段摘要、一个列表、一张表格），由智能体在完成时填写。没有回答字段的模板，则以智能体的回复作为结果。
- **由谁来做**：智能体、它的模型、它的模式，以及它可以使用的工具。

每次运行模板时，应用都会用填好的任务启动一个会话。智能体会从头到尾一口气做完，中途不会停下来问你：它会做出合理的假设，并说明做了哪些假设。这样完整的一次就叫作一次**运行**。之后你还可以对结果提出修改，智能体会交回更新后的结果。

点击侧边栏底部的**模板**图块打开模板页面，或前往 [/apps](/apps)。在手机上，侧边栏是一个抽屉：先把它打开。你也可以在搜索框中输入模板名称来找到任意模板，无论是你自己的还是现成的（Ctrl+K，Mac 上为 ⌘K）。

## 认识模板页面

页面标题是**模板**，顶部有一个**新建模板**按钮。下面是：

- **你的模板**：你创建的每个模板都有一张卡片，显示它的图标、名称和描述、运行它的智能体，公开页面开放时还有一个**公开**标记，以及它今天运行了几次。还没有模板时，页面会建议你从现成模板开始、从零创建一个，或在会话菜单中使用**更多 → 另存为模板**。
- **最近的运行**：你最近的六次运行，显示每次收到的回答、当前状态和结束时间。来自 CSV 各行和公开页面的运行不在这里显示，而是留在各自的模板下。点击一项即可打开。
- **现成**：应用自带的模板。可以用标签按类别筛选：**全部**、**研究**、**规划**、**购物**、**工作**、**写作**、**学习**和**构建**。每张卡片会显示它的类别以及要问几个问题。

运行的状态以标记显示：**等待中**（在排队）、**正在启动**、**工作中**、**需要你处理**（它在等你批准或回答）、**完成**、**失败**或**已停止**。

在手机上，卡片排成一列，类别标签可以左右滑动。

## 使用现成模板

这些模板随应用提供。除非你在模板页面上选了别的智能体，否则它们都用 Claude Code 运行。

- **深度研究报告**：就任何问题写一份有出处的报告：搜索网络、交叉核对事实，每个说法都注明来源。你只需给出主题、重点、深度和读者对象。
- **旅行规划**：按天安排的行程，并对照你的日期核实过（开放时间、活动、路上要花的时间），附带预算和需要提前预订的事项。
- **比较产品**：当前价格、独立评测和已知问题，按你看重的方面逐一权衡，并给出明确的推荐。
- **文档问答**：根据你附上的文档回答问题，每个回答都附上原文段落及其位置。
- **会议记录转行动项**：从原始笔记或会议转录中整理出决定、带负责人和日期的待办事项、未决问题，以及一封跟进邮件。
- **求职信**：针对某个职位的求职信，以你经历中的真实例证为依据，并坦诚指出不足之处。
- **教案**：从教学目标倒推、带时间安排的一节课，包括课堂活动、理解程度检查、辅助支持和拓展提高。
- **每周新闻摘要**：你关注的主题在过去一周的动态，取材于原始报道，合并重复内容，并说明每条新闻为什么重要。
- **解读合同**：用浅白的话讲清协议的内容：关键条款、日期、不寻常之处，以及签字前该问的问题。附上文件或粘贴文本即可。
- **做一个小型网页应用**：根据描述做出一个能用的应用，使用纯 HTML、CSS 和 JavaScript，直接打开文件就能运行，交付前会先测试。

现成模板本身不能修改。要调整它，打开后按**改成我自己的**（在手机上是**编辑**）：编辑器会打开一份副本，你创建后它就成为你自己的模板。

## 运行模板

1. 从模板页面或搜索框打开模板。
2. 填写表单。标有红色 **\*** 的问题是必填的。
3. 如果是现成模板，选择由谁来做（见下文）。你自己的模板则会显示一行说明，例如“Claude Code · Sonnet · 高思考强度 · 自动”：可以用**编辑**来更改。
4. 按**运行**。运行页面会打开，并实时跟进工作进度。

如果有遗漏，应用会提示“请先填写标记的问题”，并在每个问题下方指出问题所在（“必填”“请输入数字”“选择文件”）。

### 问题的类型

- **短文本**和**长文本**：一行输入框，或一个随输入内容变高的文本框。
- **数字**：普通数字；“$1,250.50”会被读作 1250.5。
- **日期**：一个日期选择器。
- **选项**：选项少而短时显示为一排标签；多时显示为列表。对于非必填的问题，再次点击已选中的标签即可清除。
- **是 / 否**：一个开关。
- **文件**：需要附上的文件。

问题下方可以有一行帮助说明，输入框里可以有示例答案，也可以预先填入一个值。

### 选择智能体、模型、思考强度和模式

在现成模板上，**运行**旁边有几个选择器：

- **智能体**：Claude Code、Codex、Custom（应用自带、可搭配任意模型的智能体），或你添加的其他智能体。
- **模型**：该智能体的模型。
- **思考强度**：模型思考得有多用力，仅适用于提供不同档位的模型（Custom 和其他添加的智能体没有）。
- **模式**：智能体不经询问就可以做哪些事。默认是**自动**，因为运行时没有人在旁边看着。如果选了每一步都要先询问的模式，运行就会停下来等你。

这个浏览器会记住你上次的选择，用于你下次运行的现成模板。

### 附加文件

文件类问题会显示**选择文件**，你也可以把文件拖放到上面（在电脑上）。每个文件最大 25 MB。文件会保存在这次运行的文件夹中，智能体会拿到它的路径，因此可以像读取任何文件一样读取 PDF、Word 文档、电子表格和其他文件。点击已选文件旁边的 **×** 可以移除它。

### 运行在哪里进行

每次运行都有一个属于自己的新文件夹，位于你主文件夹下的 `naget-apps` 文件夹中，以模板名称和时间命名。模板也可以改为指定一个文件夹（见[由谁来做](#who-does-it)）；这样每次运行都在那里进行。

你从表单启动的运行，其会话会和其他会话一样显示在侧边栏的会话列表中，标题是模板名称加上你最前面的几个回答。来自 API、其他智能体、公开页面或 CSV 各行的运行会被归档，所以不会出现在列表中，而是显示在各自的模板下。

## 跟进运行并查看结果

运行页面会显示模板名称、这次运行的来源（“来自表单”“试运行”“来自 API”“来自另一个智能体”“公开页面”“第 3 行”）以及开始时间。

顶部的状态卡片会说明它进行到了哪一步：

- **排队中**、**正在启动…**，或**工作中**并显示已用时间。工作期间，你能看到它最近的几个步骤（“已搜索网络”“已读取页面”“已更新计划”），以及智能体最后所说内容的开头。
- **它需要你在会话中批准**或**它在会话中有个问题要问你**：智能体在等你。打开会话去回答；需要批准的请求也会显示在[收件箱](/inbox)中。
- **已完成，用时**后面跟着所花的时间，并附上花费。
- **已停止**，或**它没有完成**并附上原因。

下面是结果：

- 简短的回答字段（文本、数字、日期、链接、是或否）放在同一张卡片里。
- 长文本、列表和表格各自在标题下占一张卡片。长文本有**复制**按钮；表格有**复制**和 **CSV**（下载）。
- 在手机上，太宽放不下的表格会改为每行一张卡片。

接着是智能体自己的回复。模板没有回答字段时，它展开显示在**回答**下；否则折叠在**智能体的回复**下。**提出的请求**（折叠）列出了这次运行收到的回答。

如果智能体结束时没有提交回答字段，会被提醒一次。既没有回复也没有结果就结束的运行算作失败（“智能体结束了，但没有给出答案”）。

底部的**用这些回答再运行一次**会打开按同样方式填好的表单，可以修改后再运行。文件不会带过去：需要重新选择。

顶部的**打开会话**（在手机上是**会话**）会打开这次运行的完整对话。

## 对结果提出修改

运行结果并不是定稿。运行页面底部有一个输入框，提示**对结果提出修改…**（模板没有回答字段时则是**提出修改…**）。

1. 输入要改的地方：“第 2 天别排得那么满”“加一列营业时间”“再短一点，语气再亲切些”。
2. 按 Enter，或点击箭头按钮。Shift+Enter 换行。在手机上 Enter 是换行：点箭头发送。

追问会发送到这次运行的会话中。智能体完成修改后，会交回完整的更新结果，替换页面上原来的结果。每条追问都显示在**追问**下，附有智能体的答复；结果有变化时还会显示**已更新结果**。之后状态卡片会显示**已更新，用时 …**；如果追问只需要回答（比如一个问题、一句感谢），则显示**已回答，用时 …**。

如果你在智能体还在工作时发送追问，它会标注“排队中”并等待，等当前这一轮结束后再交给智能体。一条追问最多 20,000 个字符。

来自公开页面的运行不接受追问。会话已被删除的运行，或会话正在另一个程序中打开的运行（请在那个程序里继续），也不接受。

## 在运行的会话中操作

从侧边栏打开时，运行的会话会先显示**结果**，和运行页面的视图一样，顶部有一个切换到**对话**的开关。（运行页面上的**打开会话**会直接进入对话。）这时会话的消息框会提示**对结果提出修改…**：你在那里发送的任何内容都是追问，和在运行页面上一样；在一处开始写的草稿也会带到另一处。

在**结果**视图中，智能体的批准卡片会显示在结果下方，你可以直接在那里批准或拒绝。如果它是有问题要问，就会出现一张卡片，写着 **它有个问题要问你。** 并带有**去回答**按钮，点击后会切换到对话。

在对话中，智能体提交结果的那一刻会显示为**结果已提交**，并带有**打开结果**。如果它提交的内容不符合回答字段，会显示**结果暂时还不符合答案字段**以及哪里不对；智能体会修正后重新提交。

## 停止或移除运行

- **停止**（运行进行时位于顶部）：还在排队的运行会立即结束；正在工作的运行会被中断，并显示**已停止**。
- 运行结束后，垃圾桶按钮（**从列表中移除**）会询问“移除这次运行？”，然后把它从模板的运行列表中移除。会话会保留：如果也想删掉，请从会话菜单中删除。

## 查看模板的所有运行

你自己的模板页面有四个标签页：**运行**、**运行记录**、**逐行运行**和 **API 与分享**。**运行记录**显示今天运行了几次，并按从新到旧列出每次运行：收到的回答、来源、多久以前、花费和状态。**显示更早的运行**会加载更多，每次 50 条。

现成模板没有“运行记录”标签页：可以在模板页面的**最近的运行**下找到它们的运行，或在侧边栏中作为会话找到。

## 创建你自己的模板

有四种开始方式：

- **从零开始**：模板页面上的**新建模板**，或前往 [/apps/new](/apps/new)。
- **描述它**：在新建模板页面上，在**或者描述一下这个模板，让智能体来做**下面写出它该做什么，然后按**询问**。会话会以**应用搭建师**（[助手](/guide/assistants)）开始，由它制作模板、试运行并交给你。
- **从现成模板开始**：打开它并按**改成我自己的**（在手机上是**编辑**）。
- **从一个顺利的会话开始**：在会话菜单（⋯）中选择**更多** → **另存为模板**。页面会显示“正在根据会话起草模板…”，同时辅助模型会根据你的请求和智能体的回复，把会话的第一个请求变成表单、任务和回答字段。每次使用都会变化的部分会变成问题。草稿会沿用会话的智能体、模型、思考强度、模式和助手。如果智能体调用过步骤自己就能调用的工具（读取了网页、搜索了网络），草稿还会带上步骤：这些调用变成工具步骤，表单的回答填在相应位置，其余部分交给一个模型步骤或智能体步骤。检查不通过的步骤会被去掉，保留交给一个智能体的任务；保存前请检查这些步骤并试一试。如果辅助模型起草不了，你会得到原样的请求，放在一个**请求**问题中，并附上一条说明原因的备注；辅助模型在[设置 → 智能体 → 模型](/settings?s=models&find=Helper%20model)中设置。

你也可以在任何会话中让智能体帮你创建模板（见[问问智能体](#ask-an-agent)）。

编辑器打开时标题为**新建模板**。填好各部分，用**试运行**试一试，然后按**创建**。模板页面随即打开，可以运行了。

### 名称、描述和图标

- 点击图标可以选择它的颜色（11 种颜色）和图案（32 个图标）。
- **名称**（必填，最多 60 个字符），例如“旅行规划”。
- 描述：用一句话说明它做什么（最多 300 个字符）。

模板的地址在创建时由名称生成（“Trip planner”变成 `trip-planner`）。之后改名时地址保持不变，所以链接、密钥和其他智能体调用的工具都能继续使用。

### 表单

每次运行前要回答的问题。**添加问题**会添加一行，其中包括：

- 问题本身，也就是填写的人看到的文字（“去哪里？”）。
- 它的类型：**短文本**、**长文本**、**数字**、**日期**、**选项**、**是 / 否**或**文件**。
- **必填**：没有它，运行就无法开始。
- 对于**选项**：各个选项，每行一个（留空时提供“是”和“否”）。
- **帮助文字、示例、默认值…** 会再打开三个输入框：**问题下方的帮助说明**、**示例答案**（在空输入框中以灰色显示）和**初始填入的值**。

箭头可以把问题上移或下移，垃圾桶可以删除它。每个问题下方会显示它的占位符，例如 `{{destination}}`：任务就是用它来引用这个问题的回答，程序也用这个名字。新问题的占位符会随问题文字自动变化，直到任务用到它为止。一个模板最多可以有 30 个问题。

### 任务

要智能体做的事，其中会填入各个回答（最多 30,000 个字符；必填）。像你亲自向智能体提要求那样来写，不只说要做出什么，还要说明怎么做。

- **插入**后面的标签会把问题的占位符插入光标所在位置。任务还没用到的问题会突出显示。**今天**会插入今天的日期。
- `{{question}}` 会被替换为该问题的回答。
- `{{#question}}` 和 `{{/question}}` 之间的文字，仅在问题已作答（且回答不是“否”）时保留。`{{^question}}` 和 `{{/question}}` 之间的文字，仅在问题留空时保留。
- **预览**会显示填入了各问题默认值（或方括号中的问题名）的任务。**编辑**返回编辑状态。

输入框下方的警告会在两种情况下提醒你：某个占位符对应不到任何问题（它会原样保留），或者某个必填问题在任务中从未被用到。

### 答案

智能体完成时要填写的字段。它们显示为卡片或表格，程序则以 JSON 形式拿到它们。没有回答字段时，智能体的回复就是答案。

**添加回答字段**会添加一行，其中包括：

- 一个标题（“推荐”）。
- 它的类型：**文本**、**长文本**（带格式的文本）、**数字**、**是 / 否**、**日期**、**链接**、**列表**或**表格**。
- **必填**：智能体必须填写它。
- **这里填什么，供智能体参考（可选）**：给智能体的提示。
- 对于**表格**：它的**列**，每列都有名称和类型（**文本**、**数字**、**是 / 否**、**日期**或**链接**）。**添加一列**会添加一列；表格至少保留一列。

应用会检查智能体提交的内容：数字必须是数字，日期必须是真实的日期，链接必须是完整的网址。有不符合的地方，会告诉智能体要修正什么。一个模板最多可以有 30 个回答字段，一张表格最多 12 列。新回答字段在保存时会根据标题生成供程序使用的名称；之后这个名称保持不变，所以读取它的程序能继续正常工作。

### 示例

示例是用来试运行模板的回答，以及对运行结果的检查：这样你可以试一试改动，并在模板变差时及时发现。**添加示例**会添加一个：愿意的话给它起个名字，填好它的回答，再为一次好的运行应给出的每样东西**添加检查**。检查是对运行中的值的规则，和步骤的规则一样：`{{answer.unread}} > 0`、`{{find.count}} = 3`、`{{reply}} contains Lisbon`。**{ }** 按钮会插入一个值：表单的回答、步骤给出的结果、**它的答案**（`{{answer.field}}`）和**它的回复**。

**全部试一试**会把每个示例作为一次试运行来运行，用的是屏幕上的模板，不管保存了没有；示例旁的烧瓶按钮只试那一个。每个示例都会显示它上次试运行的结果：**通过**、有几项检查未通过，或者**未完成**，以及用了多长时间、花了多少钱；打开的示例会说明每项未通过的检查看到了什么（"answer.unread is 2"）。

### 由谁来做

这一部分写着：“运行时没有人看着，所以请选择一个不会停下来询问的模式（Auto，或允许编辑的模式）。”

- **智能体**、**模型**、**思考强度**和**模式**选择器，和现成模板上的一样。模式默认是**自动**。
- **助手**：**无**，或每次运行开始时使用的助手（研究员、撰稿人……或你自己的助手），连同它的指令。见[助手](/guide/assistants)。
- **文件夹**：默认是**每次运行使用新文件夹**。**选择一项**会让每次运行都在你选定的文件夹中进行（运行开始时它必须存在）；**每次都用新的**则恢复默认。选定文件夹后，附加的文件会放在一个单独的上传文件夹里，不会混进你的文件。

### 工具

运行可以使用应用自带的哪些工具：网络搜索、浏览器、页面、记忆等等。**全部**默认是开启的。把它关掉就会看到一个列表，列出每个工具的名称和作用，勾选运行可以使用的那些。智能体自己的文件和命令工具由它的模式决定，不受这个列表控制。

### 限制

- **每天运行次数（来自任何地方）**：这个模板一天内最多可以运行几次，从午夜起算，来自表单、API、其他智能体、CSV 各行和公开页面的运行都计算在内。超过之后，运行会被拒绝，并提示“此模板今天已运行 … 次，已达上限”。留空：不限制。
- **单次运行最多可花费（US$）**：每次运行的花费上限。达到上限时运行会停止。留空：没有上限。见[用量、限额和费用](/guide/usage)。

### 保存前先测试

**试运行**（在手机上是烧瓶按钮）会打开一个对话框，里面是屏幕上当前的表单，无论是否已保存。填好后按**运行测试**：运行过程会在对话框中展开。**打开会话**会显示它的对话，**再测一次**会回到表单。已保存模板的试运行会以“试运行”显示在它的**运行记录**标签页中。**保存为示例**会把一次已完成试运行的回答保存为新的示例，再到**示例**下给它加上检查。

## 修改、复制或删除模板

在你的模板页面上：

- **编辑**会打开编辑器，标题是**编辑**加上模板名称。改完后按**保存**。更改只对之后的运行生效；正在进行的运行会继续使用开始时的版本。
- **更多**（⋯）→ **创建副本**会复制出一份，名称末尾加上“副本”，并有自己的地址。它的界面会作为副本自己的页面一起复制；副本的公开页面一开始是关闭的，密钥和它保存的记录不会被复制。
- **更多**（⋯）→ **删除**会先询问“删除 …？”：它的运行、密钥和公开页面会一并删除，仍在进行的运行会被停止。它启动过的会话会保留。

## 从你自己的程序调用模板

脚本、快捷指令和其他程序可以用密钥运行你的模板并拿回答案。打开你的模板 → **API 与分享** → **API**。

1. 按**新建密钥**，写明谁会使用它（用来区分不同的密钥），然后按**生成密钥**。
2. 立即复制密钥：“这是你的新密钥。现在就复制：它不会再显示。”

一个密钥只能用于这个模板，不能访问应用里的其他任何东西。列表会显示每个密钥的名称、开头和结尾的几个字符，以及上次使用的时间。**撤销**会让密钥失效：使用它的程序会立即停止工作。

这个标签页会显示一个调用示例，其中包含你模板的地址和示例回答。如果你有一个名为 Trip planner 的模板，示例大致如下：

```bash
curl -X POST https://your-address/api/apps/trip-planner/run \
  -H "Authorization: Bearer napp_…" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"destination": "Lisbon", "start": "2026-11-20", "days": 4}, "wait": 300}'
```

- 把表单的回答放在 `inputs` 下，按占位符名称填写。对于文件类问题，可以给出这台电脑上某个文件的路径，或者把文件放在 `files` 下发送，带上它的 `name`，并把 base64 编码的内容作为 `data`。
- `wait` 是等待答案的秒数，最多 900。
- 响应中包含这次运行的 `status`、`result`（回答字段）、`reply`（智能体最后说的话）和 `session`（指向会话的链接），有的话还会附上 `error` 和 `costUsd`。
- 对于仍在进行的运行，可以用 `GET …/run/<run>?wait=60` 查询它的情况。
- 如果前面有会切断长请求的代理（Cloudflare 的代理在 100 秒时切断），就把等待时间设短一些，然后再查询。

每个密钥每分钟最多调用 30 次，并且受模板每日上限的约束。关于应用 API 的更多内容，见[应用的 API](/guide/api)。

## 让其他智能体把模板当作工具运行

Claude Code、Cursor 或其他连接到本应用自带 MCP 服务器（智能体使用工具的一种标准方式）的智能体，都可以把你的模板当作工具来运行。在 **API 与分享** → **其他智能体**下，**提供给其他智能体**开关会把模板作为一个以其地址命名的工具提供出去，例如 `app_trip_planner`。新模板默认开启这个开关。智能体会把表单当作工具的输入来填写，然后等待答案；运行时间较长时，会先返回运行的 id，智能体再用第二个工具 `app_run_status` 查询。这类智能体需要的地址和令牌在[设置 → 应用 → 连接其他智能体](/settings?s=connect)中。

## 开放一个人人可用的公开页面

公开页面让任何拿到链接的人都能填写表单并查看答案，无需登录，也无法访问这里的其他任何东西。它在 **API 与分享** → **公开页面**下。

公开运行始终使用 Custom，所以请先在[设置 → 智能体 → 模型](/settings?s=models)中为 Custom 添加一个模型。然后：

1. 打开开关。状态会从**已关闭**变为**对所有拿到链接的人开放**，并自动选用 Custom 的第一个模型（可在下方更改）。
2. 复制链接（你的应用地址后面接 `/a/` 和模板的地址），或点击**打开**。
3. 设置其余各项：
   - **模型（Custom 的模型之一）**：公开运行使用的模型。
   - **搜索和阅读网页**：默认开启。关闭后，智能体只凭自己已知的内容回答。
   - **每位访客每小时运行次数**（默认 5）、**每天公开运行次数**（50）和**每天最多可花费**（$2）。有一行会显示今天的公开运行次数和花费。

访客能看到的：模板的名称、图标、描述和表单，他们这次运行的进展，以及他们自己之前的运行（最近 10 次，靠他们浏览器中的 cookie 来区分）。他们永远看不到任务、设置、其他人的运行、会话或花费，出错时也只会看到笼统的说明。他们附上的文件最大 3 MB，他们的回答长度限制也比你的更短。页面底部会提醒他们答案可能有误。

公开运行能做的：使用 Custom 和所选模型，不能执行命令，不能使用文件，记忆和连接都关闭，在一个运行结束就删除的临时文件夹中进行。它们只能提交回答字段，以及在你允许时搜索网络和阅读公开网页。附上的文件会以文本形式交给智能体。每次运行的花费上限是当天预算的剩余部分。

为了避免负载过大：同一个模板最多同时进行 3 个公开运行（所有模板合计 8 个），访客要等上一次运行结束才能开始下一次，同一个网络地址在所有页面上每小时最多运行 60 次。公开运行计入模板的每日上限，并且不接受追问。关掉开关即可关闭页面；访客随后会看到“此页面未开放”。

## 对 CSV 的每一行各运行一次模板

一次性对整个列表运行模板：把电子表格另存为 CSV，每一行运行一次。打开你的模板 → **逐行运行**。（现成模板需要先按**改成我自己的**。）

1. 点击**选择 CSV 文件**，或把文件拖到框里。第一行是列名。逗号、分号和制表符分隔都可以，最多 500 行。
2. 在**哪一列回答哪个问题**下，为每个问题指定一列（应用会按名称猜测），或选择**每一行都一样…** 并填一个值。必填问题需要指定一列或一个值。
3. 检查**前几行，按表单将收到的形式呈现**。
4. 看一下费用估算（见[一次运行的费用](#what-a-run-costs)），并选择**同时运行**几个：1、2、3、4 或 6（默认 2）。
5. 按**运行**（按钮上会写明行数）。

文件类问题会把单元格内容当作文本：这台电脑上的路径，或一个网址。某一行的值不符合表单要求时，会立即失败，原因显示在表格中，让你知道要改什么。如果这些行会让模板超出每日上限，应用会在开始前就拒绝。

各行运行时，会逐步填出一张表格：行号、前两个问题、状态、最多四个回答字段（或回复），以及每次运行的链接。表格上方显示：已完成多少、有多少没完成、目前的花费、同时运行几个，以及一个进度条。

- **停止**会结束仍在等待的行，并中断正在运行的行。
- **CSV** 会下载结果：每一行的回答、所有回答字段、状态、错误（如有）、花费和会话链接。电子表格会当作公式处理的单元格，开头会加一个撇号。
- **×** 会关闭表格。

即使应用重启，各行也会继续运行。**之前的表格**列出你过去的逐行运行（最近 30 次），显示进度以及状态是**正在运行**、**已停止**还是**已完成**；点击一项可以重新打开它的表格。

## 让模板自行运行

模板可以自行运行：在每天的某个时间、每隔一段时间、只运行一次、在另一个服务调用 webhook 时，或者在监测器发现变化时（订阅源、网页、某个值、文件夹）。每次运行都像从它的表单运行一样，使用你设定的回答，运行记录和其他运行一起显示在**运行记录**下。

- **设置方法**：打开模板，然后点**运行记录** → **何时自行运行** → **添加定时运行**。起个名字，填好每次运行要用的回答，再选择运行时间，和任何[定时任务](/guide/tasks#when-it-runs)一样。**试运行**会不保存地试运行一次。
- **来自外部的回答**：webhook 的回答可以取用调用中的部分（`{{body.title}}`、`{{headers.name}}`、`{{query.name}}`），监测器的回答可以用 `{{change}}`，也就是它看到的变化。运行会把它们当作数据，绝不当作指令。
- 每次运行结束都会通知你它返回了什么，或者为什么没能完成，点通知会打开那次运行。**何时自行运行**下它的那一行可以暂停、立即运行、查看历史或删除它；这个任务也在[设置 → 定时任务](/settings?s=tasks)中。

## 一次运行的费用

每次运行结束后，花费会显示在它的页面上和**运行记录**列表中。这个数字是智能体报告的金额，或者按 API 价格计算的用量（对 Custom，是根据它读写的内容估算的）；在这台电脑上运行的模型花费为 $0。

运行 CSV 之前，应用会估算整批的花费：“… 行约 $…”，依据是该模板最近已完成运行（最多 30 次）花费的中位数。设置了单次上限时，它还会加上这些行最多可能花掉多少。如果模板从未完成过一次运行，它会提示“先运行一次模板，看看每次运行要花多少钱。”

要控制花费，可以在模板的**限制**下设置 **单次运行最多可花费（US$）** 和 **每天运行次数（来自任何地方）**，如果有公开页面，还可以设置它的每日预算。所有会话的花费见[用量、限额和费用](/guide/usage)。

## 按步骤工作的模板

模板也可以按**步骤**来完成工作：由一个智能体做其中一部分，向模型快速提个问题来理清某件事，用工具获取一个网页，按规则决定走哪条路，对列表中的每一项执行同样的步骤。每个步骤把它的发现交给下一步，运行结束时交回答案字段。与让一个智能体包揽一切相比，步骤让模板更省钱、更快、更可靠，也能做更多事：在多次运行之间保存数据，调用你的其他模板，让几部分并排运行。

你可以在模板的**编辑**中创建按步骤工作的模板，也可以问智能体。在**编辑**中，**任务**旁边的**分步骤工作**会把任务变成第一个步骤：一个完成它的智能体；之后**它做什么**会按顺序列出各个步骤。**添加步骤**用来选择步骤的类型；点击一个步骤会打开它的设置，它的 **⋯** 菜单可以移动、复制或删除它。**判断**、**重复**或**同时进行**里面的步骤显示在它下面，每个列表都有自己的**添加步骤**。文本框旁的 **{ }** 按钮（**插入一个值**）会插入一个值：表单中的一个回答，或前面某个步骤给出的结果（`{{find.records}}`）。**它的答案从哪里来**说明每个答案字段由哪个值填入（留空：由最后一个给出同名值的步骤填入）。需要修改的地方会随时显示在对应步骤下面，**试运行**会试一试屏幕上的内容，**回到单个任务**会把只有第一个步骤的模板变回一个任务。步骤上方**列表**旁边的**图**会把它们显示为节点和连线：灰色的线是顺序（判断的各条路径和并排的分支、框在一起的重复步骤、步骤失败时运行的红线），彩色的线表示哪一步用了哪一步的值。

你也可以直接在图中搭建（在电脑上；手机上仍用列表）。点击节点会在图旁边打开它的设置，**更多**（⋯）可以移动、复制或删除它；连线上的 **+** 会在那里放一个新步骤，空路径里的**添加步骤**会开始这条路径。把节点右侧的圆点拖到另一个步骤上，就能把它的某个值放进那一步（它的指示、工具的输入、规则……），拖到空白处则会新建一个用这个值的步骤。拖动节点可以摆放位置（判断或重复里面的步骤会跟着移动），**整理：重新排布全部**会让它们自动排好；按住 Shift 点选几个节点，可以**把它们编成一组并加备注**。拖动背景可以移动画布，按住 Ctrl 滚动滚轮可以缩放，**全屏**会让它占满整个窗口。

或者问智能体：“创建一个模板，读取我给的每个链接，用一个快速模型总结它，并把它保存到阅读清单里。”智能体会写好步骤、检查并试运行，之后你也可以在**编辑**中修改它们。智能体在任何会话中都有为此准备的工具：读取你的模板，保存模板（先检查，错误用文字说明；可以是整个模板、其中几部分或某一步），试运行它的示例并等待结果，给它一个界面，以及读取它保存的记录或添加记录（修改或删除记录由你决定：在它的界面上做，或者先征得你的同意）；把模板交给你之前，它们会说明一次运行要花多少钱。

在对话中，智能体保存的每个模板都会显示为一张卡片；屏幕够宽时，模板会在搭建的同时在对话旁边打开（卡片上的**在旁边打开**会再次打开它，**打开它的页面**打开它自己的页面）。你在那里修改并保存的内容，会在你发下一条消息时传给智能体，让它在你的版本上继续：你改过之后，智能体再保存时会先读取你的版本。如果智能体在你有未保存的修改时保存了，会出现一条提示，让你选择**载入它**或**保留我的**。在那里，步骤的 **⋯** 菜单中的**就此问智能体**会在对话的消息框里写好关于这一步的开头。

步骤的类型：

- **问智能体**：由一个会话用它的工具处理自己那一部分，并交回它的发现。每个这样的步骤都有自己的会话，你可以从运行页面打开它。
- **问模型**：让模型快速给出一个回答，不用工具：分类、提取、总结。花费很少，用这台电脑上的模型则不花钱。
- **使用工具**：用设定好的输入调用应用自己的一个工具：搜索网络、读取网页、用保存的密钥调用一个地址、读取文档、生成图片，或者给你发一条通知。
- **判断**：走这条路或那条路，依据一条规则（“价格低于 100”）或一个用文字写的问题，由辅助模型回答。
- **重复**：对列表中的每一项各执行一遍它里面的步骤（愿意的话可以几项同时进行），或者一遍遍执行，直到某个条件成立。
- **同时进行**：几个分支并排运行；全部结束后流程再继续。
- **调用应用**：把你的另一个模板当作一个步骤。
- **保存数据**：添加、查找、修改或删除模板保存的记录（见下文）。
- **问一个人**：运行会等待你的回答，是或否，或者一个简短的表单：通知会打开这次运行，那里有一张卡片向你提问，收件箱也会列出它。除非你另设期限，它会等一周，之后就会失败。
- **运行代码**：你写的一段 JavaScript 或 Python 小程序，拿到你给它的值，返回这一步的值。它在沙盒中运行：没有网络，除了模板安装的包，看不到这台电脑上的任何文件。带有代码步骤的模板文件会在安装卡片上说明这一点。

一个步骤可以只在某条规则成立时运行，也可以说明失败时怎么办：改为运行其他步骤，不用它继续，或者（工具、模型、代码、数据或应用步骤）选**由智能体代为完成它的工作**：智能体会拿到这一步的输入和失败原因，交回后面步骤要用的值，运行继续进行。之后，运行的页面会在这一步旁边显示**由智能体代为完成**，并写明失败原因。

运行进行时，页面会随着进度列出各个步骤。运行结束后，**步骤**会列出每一步的结果、用时和花费；会话按钮可以打开某个智能体步骤的对话。按步骤工作的运行不接受后续追问：修改答案后重新运行即可。

按步骤工作的运行结束后，它的每个步骤都有**从这里再次运行**（↺）：用同样的回答开始一次新的运行，这一步之前的步骤沿用这次给出的结果（标为**沿用上次运行**，不花钱），其余步骤按模板现在的样子运行。**编辑**中的**试运行**也有这个按钮，用的是屏幕上的内容：修改后面的某一步，不必重新运行前面的步骤就能再试一次。

### 固化它

在**编辑**里的步骤上方，模板最近的运行会告诉你两件事。某个步骤失败、由智能体代为完成时，会说明这发生在几次运行中，以及上一次失败的原因；**请智能体修复它**会去问旁边的智能体（模板在对话旁边打开时），或者以**应用搭建师**开始一个会话。某个智能体步骤在最近每次运行中都做了同样的事（比如读取给它的网页，然后回答），就会出现**固化它**：花费更少就能完成它的固定步骤——智能体每调用一次工具就对应一个工具步骤，用的是它当时用的值，然后是一个模型步骤，带着它的指示和工具给出的结果。**用它的示例试一试**（没有示例时是**全部试一试**，用那几次运行的回答）会先运行这些步骤，并显示用它的智能体和用这些步骤时，一次运行各要多久、花多少钱；**使用这些步骤**会在屏幕上替换它，按**保存**才会保留。它生成的工具步骤失败时会由智能体代为完成，所以以前能成功的运行仍然能成功。

搭建模板的智能体也能看到这些，连同可以试的步骤。

### 模板保存的内容

模板可以在多次运行之间保存数据：一组组记录，比如阅读清单里的链接，或小型客户管理中的客户。它的步骤会添加、查找和修改这些记录，它的智能体也可以，用的是它们自己的一个工具。一组记录可以说明每条记录包含什么（标题、评分、日期……），应用会据此检查写入的内容。在**编辑**中，**它保存的内容**会列出它们：点**添加列表**，给它起个名字，愿意的话再写出记录包含的字段（没有字段时，任何记录都可以放进去）。

步骤和智能体也可以像搜索你的知识库那样，为一个问题搜索这些记录：按其中的字词，并在开启[按含义搜索](/settings?s=memory&find=Search%20by%20meaning)时按含义，最相关的排在最前。步骤也可以用 knowledge_search 和 recall 工具搜索你的知识库和记忆笔记。

模板保存的内容会一直跟着它，直到你删除这个模板。来自它的公开页面的运行永远碰不到这些数据。

### 会记住内容的模板

模板可以跨运行记住内容：它的智能体会把以后的运行应该知道的事（你表现出的偏好、一个好用的来源、一个要避免的错误）保存在模板自己的记忆中，每次运行都从这些记忆开始。[设置 → 记忆](/settings?s=memory)会把它列为一个项目，名字就是模板的名字。在它的**编辑**中，打开**它保存的内容**下的**跨运行记忆**即可。

### 模板在这台电脑上需要的东西

模板可能需要这台电脑上的一些东西：它的智能体要用的 Node 或 Python 包，以及 ffmpeg 之类的命令。这些包会在你安装或修改模板时立即装到模板自己的文件夹里，不影响整台电脑；它的第一次运行会等它们装好。模板页面上会有一行提示正在安装或没能装上，并附有**显示输出**和**重新安装**。它要用但这台电脑上没有的命令也会在那里列出：这类命令需要你自己安装。

## 给模板一个界面

模板可以有一个自己的界面：一个代替表单的页面，用来运行模板并显示它保存的内容。阅读清单可以把链接放在一张能搜索和整理的表格里，小型客户管理可以列出客户并配一个起草跟进邮件的按钮，记录器可以显示它记了多少条。界面是实时的：你在它的表单里提交的内容会运行模板，答案准备好就会显示出来，它的步骤和智能体修改记录时，表格也会随之变化。

- **添加界面**：打开你的模板，然后选择**更多**（⋯）→ **给它一个界面**。界面由模板自己的部件组成：它的表单、它的答案、它保存的每组记录各一张表格，以及它之前的运行。之后它的页面会打开在这个界面上。
- **修改界面**：**更多**（⋯）→ **编辑界面**会在“页面”的编辑器中打开它，你可以像修改任何页面一样修改它（[自己修改页面](/guide/pages#change-a-page-yourself)）：移动部件、改变样式，或者问智能体。**添加**中有一个**应用**标签页，里面是模板自己的部件：**它的表单**、**它的答案**、**它的运行**，它的每个其他流程各有一个表单和一个按钮，它保存的每组记录各有一张表格和一个计数。
- **或者问智能体**：“给我的阅读清单做一个界面，未读链接放在最上面，再加一个按钮生成本周摘要。”智能体会用同样的部件编写界面，也可以给模板添加更多流程，供界面上的按钮启动。

界面是模板自己的页面：它不会出现在你的“页面”库中，删除模板时会一并删除，并且会随模板文件一起传递。要用之前的答案通过表单再次运行模板，请在某次运行的页面上使用**用这些回答再运行一次**。

## 把模板作为文件分享

模板可以打包成一个文件，用来留存，或安装到另一个 Naget Agent 上。

- **下载**：打开你的模板，然后选择**更多**（⋯）→ **下载为文件**。这个文件（`.naget-app`）包含它所做和所需的一切，以及它的步骤调用的模板。如果它保存了数据，打开**包含它保存的记录**就会把记录也放进去。它的文件夹、密钥和公开页面留在这里。
- **安装**：在模板页面按**新建模板**，然后选择**从文件安装模板**，再选一个 `.naget-app`、`.zip` 或 `.json` 文件。在创建任何东西之前，会有一张卡片说明它在这里会做什么：由谁来做、它的步骤、它可以使用的工具、它使用的模型、随附的模板、它会安装的东西和用到的命令、它保存的内容、是否会记住内容，以及它的限制。每个模型都会标明是已在这里设置好、在这里用了别的名字，还是这里没有设置：对于这里没有的，请从你的模型中挑一个代替，或者交给智能体的默认模型。按**安装**。

有些东西会在安装时改变，卡片会说明是哪些：它在别处使用的文件夹不会带过来（每次运行都会有自己的文件夹），允许每一步都不经询问的模式会改为从**自动**开始，这台电脑上没有的助手会被去掉。随附的模板如果和你已有的一模一样，就沿用你已有的；否则会装在你的那个旁边。它的公开页面一开始是关闭的，也没有 API 密钥。

## 问问智能体

应用里的智能体可以通过应用的 API 帮你创建和运行模板，只需你在卡片上同意即可。例如：

- “创建一个叫‘周报’的模板，询问项目和日期范围，回答包括一段摘要和一张变更表格。”
- “把这个会话变成一个我可以反复运行的模板。”
- “用‘旅行规划’模板安排去里斯本的行程，从 11 月 20 日开始玩四天，做好后把结果给我看。”
- “用我的‘公司调研’模板把这 20 家公司各跑一遍，然后把表格给我。”
- “每周五 18:00 运行我的‘旅行规划’，目的地里斯本，玩三天。”
- “给我的‘求职信’模板开放一个公开页面，每天最多花 $1。”
- “停止我的‘比价’模板的所有运行，并撤销它的 API 密钥。”
- “创建一个按步骤工作的模板，读取我发来的每个链接，用一个快速模型总结它，并把它保存到阅读清单里。”
- “给我的‘竞品观察’模板加一个步骤，只在有变化时通知我。”
- “安装我‘下载’文件夹里的 reading-list.naget-app 模板。”
- “给我的阅读清单做一个界面，未读链接放在最上面，再加一个按钮生成本周摘要。”
- “固化我的‘链接摘要’模板，先用它的示例试一试。”
- “让我的‘链接摘要’里‘查找标题’这一步在失败时把工作交给智能体。”
