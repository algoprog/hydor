# 页面和已发布的网站

智能体可以用页面代替纯文字来回答：一份报告、一张图表、一个比较各个选项的表格，或者一个小工具，比如跟踪表、计算器或清单。本主题介绍如何在智能体编写页面时观看它，如何自己修改页面（直接在页面上点击，或者改它的代码），让智能体在你的版本上继续，如何把页面保留在你的“页面”库中（包括它的图片、它的版本、它保存的数据，以及供手机使用的独立地址），如何自己制作页面，以及如何把页面或构建好的网站发布到别人能打开的链接上。

![编辑器中的一个页面：选中了它的标题，旁边是标题的文字和外观设置](images/pages.webp)

## 对话中的页面

当一张图比文字更能说明问题时，智能体会显示一个页面：一份报告、一张图表、一个表格、一张示意图、一份设计稿，或者一些可供选择的选项。应用里的任何智能体都能做到；用平常的话提出要求就行（“把这个做成图表给我看”“用表格比较这三台笔记本电脑”）。

在宽屏上，智能体一开始编写页面，页面就会在对话旁边打开（见[观看页面的编写过程](#watch-a-page-as-it-is-written)），对话里则为它留一张小卡片：它的标题、它是什么（“页面 · 24 KB”“已保存到‘页面’ · 版本 2”），以及 **打开**；正在旁边显示的那一个则显示 **在旁边**。点击一张卡片，就会在对话旁边显示它的页面。

在较窄的窗口中、在手机上，或者关闭了对话旁边的面板时，页面位于回复中，和对话一样宽，并会随内容增高。非常高的页面会在一定高度处停住，并在底部边缘显示 **查看整个页面**。页面上方的横条包含：

- 页面的标题；
- **保留**：把页面放进你的“页面”库（见[保留页面](#keep-a-page)）；
- **编辑**（铅笔图标）：打开它进行修改（见[自己修改页面](#change-a-page-yourself)）；
- **另存为文件**（下载图标）：把页面保存为 `.html` 文件，带着它的现成外观，可以在任何浏览器中打开；
- **全屏**（展开图标）：在应用上方打开页面。按 Escape 键、轻点关闭按钮（✕）或点击页面旁边的区域即可关闭。

页面运行在它自己的框架中，与应用隔离：它无法访问应用、你的文件或你的登录信息。它可以从网上加载图表库和其他库。

页面看起来就像应用的一部分：智能体按应用的主题来做页面，应用是浅色就是浅色，是深色就是深色，用你的主题颜色（包括你自己的主题）和应用的字体；你切换主题时，打开着的页面也会跟着变。自带浅色和深色两种外观的页面，会显示应用当前的那一种，不管你的设备设成什么。想要别的外观时直接说：“用我们品牌的颜色”“做一个带霓虹强调色的深色页面”。

如果你用只读链接分享会话，对方也能看到其中的页面，但不能保留或修改它们，他们在页面上做的选择也不会发送到任何地方（[分享只读链接](/guide/sessions#share-a-read-only-link)）。

## 观看页面的编写过程

智能体编写页面时，你会看到它一点点长出来：先是标题，然后是文字、表格和卡片，写到哪里就显示到哪里。在宽屏上（1100 像素或更宽），对于屏幕上正在显示的会话，页面会自动在对话旁边的面板中打开。面板顶部那一行显示 **正在编写**，以及目前已经写了多少；旁边的代码按钮会改为显示正在写入的页面 HTML，眼睛按钮则回到页面。在较窄的窗口中或手机上，页面会在对话里它的卡片中逐渐长出来。页面的脚本会等到页面完整之后才运行。

智能体完整写出一个 HTML 文件时（比如静态网站的 `index.html`），面板也会打开它，并从文件所在的文件夹加载它的图片和样式。

- 拖动面板的左边缘可以让它变宽或变窄；应用会在这台设备上记住这个宽度。
- 一个对话中有多个页面时，点击面板中的页面标题，可以切换到另一个页面。
- 面板中的 **更多**（⋯）包含 **在“页面”中打开**（已保存的页面）、**在“文件”中显示**（HTML 文件）、**另存为文件**，以及 **页面一开始编写就在这里打开**：关闭它后，页面会等你从它们的卡片中打开。
- ✕ 关闭面板。会话标题栏中的 **详情** 会在同一位置打开会话的详情。

## 自己修改页面

智能体显示或保存的任何页面、你库中的任何页面，以及智能体写出的任何 HTML 文件，都可以用三种方式修改。用页面顶部的按钮选择一种（在对话旁边的面板中，它们是图标：眼睛、铅笔和代码符号）：

- **使用**：页面本身，可以正常使用：在它的输入框中输入、勾选它的方框、选择它的选项。
- **编辑**：直接在页面上点击来修改它。修改期间，页面的脚本会暂停运行，所以页面保持不动。
- **代码**：它的 HTML，旁边是页面（在较窄的面板中则在下方），你输入后片刻就会显示你的更改。

在它们旁边，屏幕按钮可以按 **电脑**、**平板** 或 **手机** 的尺寸显示页面（在面板中和较窄的窗口里是一个带菜单的按钮）。页面打开时有多宽的空间就显示多宽；选了平板或手机的宽度后，在页面关闭前会一直保持。在 **编辑** 中，选着平板或手机时做的修改只用于那种尺寸的屏幕（[为手机和平板修改](#change-it-for-phones-and-tablets)）。

### 点击编辑

1. 点击页面的某个部分：一个标题、一个段落、一张图片、一张卡片、一个表格。它会出现一个带有名称的边框（“标题 2”“图片”“卡片”），旁边还有一个小工具条。
2. 再点一次（或者双击）就可以就地修改它的文字。文字上方的工具条有 **粗体**、**斜体**、**下划线**、**删除线**、**设为链接**（Ctrl+K）、**取消链接**、**清除格式** 和 **完成**。在段落里按 Enter 会另起一行，在标题里按 Enter 会结束编辑；按 Esc 结束编辑。
3. 选中部分旁边的工具条：拖动手柄（⠿）可以把这个部分移到页面的其他位置；**选择外层部分**（按 Esc 也一样）；**修改文字**；**上移** 和 **下移**；**创建副本**（Ctrl+D）；**删除**（Delete 键）。拖动它右边、下边和右下角的小手柄，可以把它拉宽或拉高。

按键和其他编辑器一样：Ctrl+C、Ctrl+X 和 Ctrl+V 可以复制、剪切和粘贴选中的部分（在应用打开期间，也能粘贴到另一个页面里）；Ctrl+G 把它包进一个块里，Ctrl+Shift+G 取出里面的内容；方向键选中上面、下面、外层或里面的部分；Alt+↑ 和 Alt+↓ 移动它。

在手机上，点一下某个部分就能选中它，再点一下就能修改它的文字。页面下方的标签（**部分**、**图层**、**网页**）会打开一个抽屉，里面是可以修改的内容；箭头可以收起它，你输入文字时它也会自动收起。

**添加** 会把一个新部分放在选中的部分之后、它里面，或者页面末尾（用 **放在** 选择位置）：**基础**（标题、文本、按钮、链接、图片、列表、引用、分隔线、一段空白）、**布局**（区块、两栏或三栏、卡片、一组卡片、表格、数字、折叠区、输入框）以及 **现成区块**（开场介绍、功能特点、价格、步骤、常见问题、用户评价、行动号召、联系表单、页脚）。在合适的地方，它的文字可以直接输入。

**撤销**（Ctrl+Z）和 **重做**（Ctrl+Shift+Z）可以一步步撤回或重做你的更改。

### 部分、图层和网页

页面旁边（在较窄的面板中或在手机上则在页面下方）有三个标签，显示你可以修改的内容。

**部分** 是选中的部分，上方是它外层的各个部分（点击其中一个即可选中它）。最上面是：**问智能体**（在对话中：它会在你的消息框里写下你指的是哪个部分，你只需说要改什么；还没保存的修改会先保存，好让智能体看到）、**复制**、**粘贴**，以及 **更多**（⋯），里面有 **剪切**、**粘贴到它里面**、**包进一个块里**、**取出里面的内容**、**创建副本**、**在页面里找到它** 和 **删除**。下面选择修改用于哪些部分：**仅这个部分**、所有同类的部分（“所有标题 2”），或者所有带它某个 class 的部分（“所有 .card”）；还有 **正常** 或 **悬停**，即鼠标指针停在上面时的样子（你修改时页面会显示这个样子）。然后是它的几组设置，可以收起：

- **内容**：它的文字；对于标题或文本，它的 **类型**（H1、H2、H3、文本、引用）；对于链接，它 **链接到** 哪里，以及是否在 **新标签页** 中打开；对于图片，它的地址或 **来自这台设备的图片**（会缩小到足以放进页面里），以及它的 **描述**。
- **文本**：**字体**、大小和粗细、**行距和字距**（行的高度、字母之间的距离）、**颜色**、**对齐** 和 **样式**（斜体、下划线、删除线、大写）。
- **填充和边框**：**填充**、放在后面的 **图片**、**透明度**、**圆角**、**边框** 和 **阴影**。
- **空间**：边框 **外** 和边框 **内** 的空间，按这个部分本身的样子并排显示。输入数字，或者上下拖动数字。
- **大小**：它的 **宽度** 和最多能有多宽，它的 **高度** 和至少要有多高，以及图片如何 **适配** 它的尺寸。
- **布局**：里面的部分如何 **显示**（上下排列、并排、竖向排列、网格排列，或者隐藏），它们怎么对齐和分布、彼此的间距，以及它的 **位置**：默认位置、从原位置偏移、相对所在的块、固定在屏幕上，或者在页面滚动时固定。
- **类名、名称和 CSS**：它的 class、它的 id，以及给它设置的 CSS。

某项设置有内容时，它的名称会变成金色；旁边的 ✕ 可以清除它。左右拖动数字前面的字母可以修改数字，也可以用方向键（按住 Shift 则每次改 10）。色块是页面自己的颜色；彩虹色的那个可以选择任何其他颜色。

**图层** 把页面的各个部分显示成一棵树，按它们互相包含的样子排列。指向其中一个，就能在页面里看到它；点击它就能选中它，即使它太小或被挡住，在页面里点不到。

**网页** 是整个页面：

- **页面**：它的 **标题**（浏览器标签页上的名称）、**背景**、**宽度**（在大屏幕上居中显示的内容有多宽：**全宽**、**宽**、**中等** 或 **窄**）、**内部留白** 和 **语言**。
- **颜色**：页面自己命名的颜色（它的 CSS 变量；用应用自带外观做的页面，有 **背景**、**卡片**、**文本**、**强调色** 等）。它们一开始就是你主题的颜色。改一个，用到它的地方都会一起变，而且在任何主题下都保持这样。
- **字体**：它的 **文本** 和 **标题** 用的字体：设备自带的字体，或者 Google 的字体，页面会自动加载。
- **文字样式**：**文本**、**标题 1** 到 **标题 3**、**链接** 和 **按钮** 在整个页面里的样子。你单独改过的部分会保留它自己的修改。
- **你的 CSS**：你为整个页面写的规则，会原样保存在页面里。

### 为手机和平板修改

在顶部选 **平板** 或 **手机**，页面就会按那个宽度显示，上方的工具条会出现 **平板专用** 或 **手机专用**。这时做的修改只用于那么宽或更窄的屏幕（平板 900 像素，手机 600 像素），页面在电脑上的样子不变：比如手机上的标题小一点、两栏在手机上变成上下排列、某个部分在手机上隐藏（**布局** → **显示** → **隐藏**）。再选 **电脑**，修改就又用于所有屏幕。

悬停时的样子、某种屏幕尺寸的修改，以及对所有同类部分的修改，会放进编辑器保存在页面里的样式表；对单个部分本身的修改则放在它自己的样式里。无论哪种，都是你保存的页面的一部分，以后修改这个页面的智能体也能看到。

### 保存或放弃

一旦你改了什么，底部就会出现一个横条，显示 **尚未保存**，以及 **放弃** 和 **保存**（Ctrl+S，在页面里面按也可以）。在 **使用**、**编辑** 和 **代码** 之间切换不会丢失你的更改。

- 已保存的页面（在你的库中）会得到一个新版本：智能体的版本都会保留，你可以回到其中任何一个（[回到早先的版本](#go-back-to-an-earlier-version)）。如果在你修改期间页面又被保存了一次（比如被某个智能体保存），应用会先问你，再把你的版本放在最上面；另一个版本会留在版本列表中。
- 对话中显示、还没有保留的页面，按钮会显示 **连同更改一起保留**：它会被放进“页面”，智能体的页面作为版本 1，你的作为版本 2。
- HTML 文件会保存在原处。如果在你打开它之后它在磁盘上被改过，应用会告诉你，而不会覆盖它。

### 智能体会知道你的更改

显示这个页面的智能体（对于已保存的页面，还有创建它的那个会话的智能体）会在你下次给它发消息时知道你的更改：哪个页面、它的版本，以及你改了什么，这样它会在你的版本上继续，而不是用它自己的版本覆盖你的。对话中会显示一条提示：“你修改了‘旅行计划’（版本 3） · 智能体会在你发下一条消息时看到”，消息发出后，它会变成“智能体已看到”。点击这条提示可以再次打开页面。

## 在页面上选择选项或填写表单

有些页面会问你一些问题：三个方案中你更喜欢哪一个、旅行的日期、要保留哪些物品。你的回答会进入消息框，而不会直接发给智能体：

- **点击一个选项**，消息框中就会出现一行，比如 `Chose: B` 或 `Color: Blue`。如果页面允许多选，它们会一起放进去（`Color: Blue, Green`）。在同一组中选择另一个选项，它的那一行会替换第一行；不会越积越多。
- **填写表单并提交**，它的回答会以一个简短的列表放进去，标题是表单的名称，每个字段一行。

在消息中添加你想说的任何内容，然后像平常一样发送。智能体会把你的选择当作你消息的一部分来读。

页面全屏显示时，你的选择会先等着，在你关闭全屏时放进消息框（消息框在页面下方）。

## 保留页面

对话中显示的页面与对话共存。要以后再回来用它，就保留它：

1. 点击页面上方横条中的 **保留**。
2. 提示“已保存到‘页面’”表示成功。按钮现在显示为 **已保留**；点击它可以在“页面”中打开这个页面。

修改一个显示中的页面并保存，也会保留它（**连同更改一起保留**，见[保存或放弃](#save-or-discard)）。

页面还在对话中时你在上面输入的内容会随它一起保留。保留之前，页面只在显示在屏幕上时记住你输入的内容；一旦保留，它就会永久保存它的数据（见[页面保存的数据](#the-data-a-page-keeps)）。

你也可以一开始就请智能体做一个要保留的东西：“给我做一个能在手机上用的习惯打卡表”“一份搬家清单”。智能体会自己把它保存到“页面”中，对话中会显示一张卡片，上面有：

- 页面的标题和 **已保存到页面 · 版本 2**（这条回复保存的版本）；
- **打开**（在“页面”中打开它）、**编辑**（铅笔图标）和 **全屏**；
- 页面本身，可以直接使用，带有它的数据，就在卡片中。

在宽屏上，当页面显示在对话旁边时，卡片会保持小尺寸，它的页面则在旁边打开。

之后保存了更新的版本时，较早的卡片会显示 **已有更新的版本**。它仍然显示自己的那个版本，并读取页面的数据，但你在那里做的更改不会保存。如果那个版本已经不再保留，卡片会显示“这个版本已不再保留；‘打开’会显示最新版本”。如果页面被删除了，卡片也会说明。

智能体也可以修改你保留的页面：说“给我的习惯打卡表加一列备注”，智能体就会保存它的一个新版本。你的数据会保留，较早的版本也保持原样。

## 找到你的页面

侧边栏中的 **页面**（[/pages](/pages)）存放着你保留、制作和发布的所有内容。在手机上，先用 **菜单**（≡）打开侧边栏。你也可以在搜索框（Ctrl+K，Mac 上为 ⌘K）中按标题查找页面。

这个页面有两个标签页，每个都带有数量：

- **已保存**：你的页面，每个都是一张卡片，上面有它的图片（页面打开时的样子，带着它的数据；在图片生成之前，显示它的首字母）、标题、上次更改的时间和版本；已发布的页面会显示一个地球图标，保存了数据的页面会显示一个圆柱图标。点击卡片即可打开页面。卡片的 **更多**（⋯）中有 **编辑**、**重命名**、**创建副本**（不带数据的副本）、**下载**（下载为 `.html` 文件）和 **删除**。
- **已发布**：你发布的页面和文件夹，以及它们的链接（见[查看和取消发布你发布的内容](#see-and-unpublish-what-you-published)）。[打开“已发布”标签页](/pages?tab=published)。

页面超过四个时，卡片上方的 **查找页面** 可以按标题筛选它们，旁边的按钮可以按 **最近更改**、**名称** 或 **最新创建** 排序。应用会在这台设备上记住排序方式。

还没有保留任何页面时，“已保存”标签页会显示“还没有页面”，以及 **新建页面**。

## 制作页面

“已保存”标签页右上角的 **新建页面**（[也可以从搜索框打开](/pages?new=1)）可以制作一个你自己的页面：

1. 选择从哪里开始：**空白页**（一个标题和几句话，可以在此基础上继续完善）、**备注**（一个用来写东西的页面，边写边保存）、**清单**（要做的事，做完一件勾掉一件）或 **跟踪表**（每天一个数字，并画出最近 30 天的数据）。
2. 如果愿意，可以修改 **名称**，然后点击 **创建**。空白页会在 **编辑** 中打开；其他的打开后就可以直接使用。

或者在 **或者描述一下，让智能体来做** 下面描述你想要的东西（“一周徒步的行李清单”），然后点击 **询问**：开始页会带着你的话打开，由智能体来制作这个页面并把它保存到“页面”中。

## 打开页面

页面会在应用内全屏打开，在“页面”中有它自己的位置。顶部的横条包含：

- 返回箭头（**所有页面**），回到列表；
- 页面的标题，下方是它的版本、上次更改的时间和它保存了多少数据。点击标题可以重命名页面；
- **使用**、**编辑** 和 **代码**，以及 **电脑**、**平板** 和 **手机** 尺寸（见[自己修改页面](#change-a-page-yourself)）；
- **版本**（时钟图标）：它较早的版本（见[回到早先的版本](#go-back-to-an-earlier-version)）；
- **分享**：供你的手机使用的独立地址，以及把它发布到一个链接（见[在手机上使用页面](#use-a-page-on-your-phone)和[发布页面](#publish-a-page)）；
- **更多**（⋯）：**它保存的内容**（见[页面保存的数据](#the-data-a-page-keeps)）、**重命名**、**创建副本**、**下载**、**在新标签页中打开**（在它的独立地址打开页面）和 **删除**。

在手机上，**使用**、**编辑** 和 **代码** 显示为图标，**分享** 显示为分享图标，尺寸按钮则不显示（手机本身就是那个尺寸）。

用应用现成的外观做的页面会跟随应用的浅色或深色主题。

## 重命名页面

点击顶部的页面标题，或者在页面中或列表中使用 **更多**（⋯）→ **重命名**。输入新名称（最多 120 个字符），然后点击 **重命名**。页面的名称也是你把它添加到手机主屏幕时使用的名称。

## 回到早先的版本

页面的每次保存都是一个独立的版本：第一个版本（由你保留或制作，或由智能体保存）、智能体保存的每次更改、你在编辑器中保存的每次更改，以及你恢复的每个旧版本。页面更改时不会丢失任何东西。

1. 打开页面，点击 **版本**。
2. 列表显示每个版本（`v3`）、它的标题（当前版本标为 **最新**）、创建时间、创建者（**由智能体生成**、**由你保留**、**由你修改**、**由你创建** 或 **已恢复**）以及大小。
3. 点击一个版本查看它。页面上方的横幅会显示“旧版本，来自 2 天前。它在这里所做的更改不会保存。”旧版本可以使用页面的数据，但你在其中做的任何更改都会被丢弃。
4. 点击 **恢复此版本** 让它成为当前版本，或者点击 **回到最新版本** 离开它。

恢复某个版本会把它作为一个新版本加在最上面（“版本 3 已恢复，成为版本 6”），所以它之后的版本也会保留。页面的数据不受影响。

页面保留它最新的 40 个版本。较旧的版本先被删除，所有版本加起来超过 24 MB 时也是如此；当前版本始终保留。

## 页面保存的数据

小工具需要记住一些东西：你记录的锻炼、你勾选的方框、你的预算条目。保留的页面会把这些数据存放在应用里，也就是应用运行的那台电脑上，而不是某一个浏览器里。所以无论你在哪里打开，它显示的数据都一样：在“页面”中、在对话里它的卡片中，以及在你手机上它的独立地址。

- 列表和页面的顶部横条会显示它保存了多少数据（`keeps 14 KB`）。
- 一个页面总共可以保存约 2 MB，单个条目最多 512 KB，最多 1000 个条目。超过这些限制后，就无法再保存更多。
- 新版本和恢复的版本使用相同的数据。
- 智能体可以读取页面的数据，用来回答关于它的问题（“这个月我记录了几次跑步？”），或者修改页面以适应这些数据。
- 页面的已发布副本不会保存数据（见[发布页面](#publish-a-page)）。

要查看页面保存了什么，打开它，然后使用 **更多**（⋯）→ **它保存的内容**。每个值按名称列出，并显示它的大小和更改时间；点击一个值就可以读取它。值旁边的垃圾桶会删除这一个值；**下载** 会把所有值保存为一个 `.json` 文件，**全部清除** 会清空页面的数据（页面本身会保留）。这两种删除都会先问你，而且无法撤销。

## 在手机上使用页面

每个保留的页面都有它自己的独立地址。这个地址只打开这个页面，带着它的数据，在任何设备上都能打开，而且不需要登录 Naget Agent：很适合你在手机上填写的跟踪表。

1. 打开页面，点击 **分享**。
2. **在你的手机上** 下面会显示地址。点击复制按钮，或者点击旁边的打开按钮试一下。
3. 在手机上打开这个地址。要把它添加到主屏幕：
   - **iPhone**：在 Safari 中打开，然后点 **共享** → **添加到主屏幕**。
   - **Android**：在 Chrome 中打开，然后点 **⋮** → **添加到主屏幕**。

从主屏幕打开时，页面会像应用一样全屏显示，并使用它自己的名称。在独立地址打开时，它会跟随手机的浅色或深色设置。

任何拿到这个地址的人都可以打开这个页面，并更改它保存的内容，所以只把它分享给你在这方面信任的人。你的手机也必须能访问应用的地址（[从其他设备访问应用](/guide/devices#reach-the-app-from-another-device)）。

### 给页面换一个新地址

如果某个地址被发到了不该去的地方，就替换它：

1. 打开页面，点击 **分享**，然后点击 **给它换一个新地址（旧地址会失效）**。
2. 确认 **新地址**。旧地址会立即失效，已添加到主屏幕上的也一样。“页面有了新地址”表示已完成。

在你需要的地方，把新地址重新添加到主屏幕。

## 删除页面

在页面的卡片上或打开的页面中使用 **更多**（⋯）→ **删除**，并确认。页面会连同它的所有版本、它保存的数据以及它的任何已发布副本一起删除。它的地址也会失效。

“页面”最多可容纳 1000 个页面，单个页面的 HTML 最大 2 MB。

## 发布页面

发布会把页面放到一个链接上，别人不需要应用的密码就能打开。用它来给别人看你做的报告或小工具。

1. 打开页面，点击 **分享**，然后点击 **发布到别人能打开的链接**。
2. 检查 **名称**（最多 60 个字符）。
3. 选择链接类型：
   - **私密链接**：一个无法猜到的链接，只有你把链接给了的人才能打开。
   - **公开链接**：一个由名称生成的可读链接（比如 `/site/trip-plan/`），任何人都可能找到并打开它。
4. 点击 **发布**。框中会显示链接，以及复制和打开它的按钮。点击 **完成**。

已发布的副本显示的是页面现在的样子，之后的版本也会显示在那里。它不会保存数据：别人输入的内容在重新加载后就没了。要自己在手机上使用页面并保存数据，请改用它的独立地址打开（[在手机上使用页面](#use-a-page-on-your-phone)）。

链接以你访问应用时用的地址开头，所以只有能访问那个地址的人才能打开它。如果只有你自己的设备能访问应用（比如通过 Tailscale），那么也只有它们能打开这个链接（[从其他设备访问应用](/guide/devices#reach-the-app-from-another-device)）。

## 从文件夹发布网站

你也可以发布项目构建出来的网站，比如用 Vite 或静态网站生成器做的应用：也就是构建输出的那个文件夹，里面要有一个 `index.html`。

1. 打开 [页面 → 已发布](/pages?tab=published)，点击 **发布文件夹**。
2. 选择 **文件夹**：一个包含 `index.html` 的已构建网站（构建后的 `dist/`、`build/` 或 `out/`）。
3. **名称** 会根据文件夹的名称自动填写；你可以修改它。
4. 选择 **私密链接** 或 **公开链接**，然后点击 **发布**。

网站直接从磁盘上的文件夹提供，所以新的构建会立即显示，不需要重新发布。可以发布的内容：

- 文件夹必须包含 `index.html`；
- 不能是你的主文件夹、主文件夹的上一级、磁盘的根目录、应用自己的数据，或者隐藏文件夹（名称以点开头的文件夹）里的文件夹；
- 最多 5000 个文件、300 MB；
- 名称以点开头的文件和文件夹（`.env`、`.git`）永远不会被提供。

网站内没有对应文件、也没有文件扩展名的地址（`/site/…/about`）会得到网站的 `index.html`，这样自己切换页面的应用也能正常工作。如果文件夹被移动或删除，链接会显示它已不存在：请重新发布。

### 已发布的网站能做什么

已发布的网站运行在它自己的一个封闭空间中，与应用隔离：没有 cookie，没有应用的任何登录信息或数据，它在浏览器中保存的内容在重新加载后就会被忘掉。它没有自己的服务器代码。它可以从自己的文件以及三个公共脚本托管站点（jsDelivr、unpkg 和 cdnjs）加载脚本，并通过 HTTPS 调用外部服务。私密链接不会被搜索引擎收录。

从地址根路径（`/assets/…`）加载文件的已构建网站，在网站的链接下找不到这些文件。请用相对路径构建它们（在 Vite 中是 `base: './'`）。智能体请求发布这样的文件夹时，会被提醒先重新构建。

## 当智能体请求发布时

智能体也可以发布，但必须得到你的同意。说“发布我的网站”或“把旅行计划放到网上”，智能体会在对话中显示一张卡片：

- **发布“旅行计划”？**，以及它要发布的内容：保存的页面，或者文件夹及其文件数量和大小；
- 可供选择的 **私密链接** 或 **公开链接**，以及各自的含义：“它会在沙盒中打开，与本应用相互隔离；你可以随时在‘页面’中取消发布。”；
- **发布** 和 **暂不**。

在你点击 **发布** 之前，什么都不会发布。然后智能体会收到一条消息，告知结果和链接。卡片会变成 **已发布“旅行计划”**，并附上可复制或打开的链接；如果你点击了 **暂不**，会变成 **未发布：“旅行计划”**；如果发布失败，会变成 **“旅行计划”发布失败**，并附上原因。

一个会话中，智能体最多可以有五个等待中的发布请求。

## 查看和取消发布你发布的内容

[页面 → 已发布](/pages?tab=published) 列出所有已发布的内容，最新的排在前面。每一项显示它的名称、**私密链接** 或 **公开链接**、它提供的内容（页面的标题或文件夹的路径）和发布时间，以及可复制或打开的链接。

要撤下其中一项：

1. 点击它旁边的 **取消发布**。
2. 确认 **取消发布**。“它的链接会立即失效。”“已取消发布”表示已完成。

你以后可以再次发布它；届时私密链接会是一个新的链接。删除保留的页面也会取消发布它。同一时间最多可以发布 200 个网站。

没有发布任何内容时，标签页会显示“没有已发布的内容”。**发布文件夹** 位于这个标签页的右上角。

## 问问智能体

智能体可以为你读取和修改你的页面，你在卡片上同意即可。可以试试这些：

- “给我做一个能在手机上用的健身记录，保存到‘页面’里。”
- “我改了旅行页面上的标题；现在在它们下面加一张地图。”
- “我的预算跟踪表昨天看起来更好：把你上次修改之前的版本恢复回来。”
- “这周我在习惯打卡表里记了什么？帮我总结一下。”
- “把页面‘未命名清单’改名为‘搬家’。”
- “我把行李清单的地址发给了不该发的人：给它换一个新地址。”
- “用私密链接发布旅行计划”，或者“取消发布我们上周做的网站。”
- “把我的落地页上的标题在手机上改小一点，按钮改得更圆一些。”
