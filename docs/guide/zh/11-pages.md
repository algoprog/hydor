# 页面和已发布的网站

智能体可以用页面代替纯文字来回答：一份报告、一张图表、一个比较各个选项的表格，或者一个小工具，比如跟踪表、计算器或清单。本主题介绍智能体在对话中显示的页面以及你如何回应它们，如何把页面保留在你的“页面”库中（包括它的版本、它保存的数据，以及供手机使用的独立地址），以及如何把页面或构建好的网站发布到别人能打开的链接上。

![智能体做的一个页面：可以反复使用的贷款计算器](images/pages.webp)

## 对话中的页面

当一张图比文字更能说明问题时，智能体会直接在对话中显示一个页面：一份报告、一张图表、一个表格、一张示意图、一份设计稿，或者一些可供选择的选项。应用里的任何智能体都能做到；用平常的话提出要求就行（“把这个做成图表给我看”“用表格比较这三台笔记本电脑”）。

页面位于回复中，和对话一样宽，并会随内容增高。非常高的页面会在一定高度处停住，并在底部边缘显示 **查看整个页面**。页面上方的横条包含：

- 页面的标题；
- **保留**：把页面放进你的“页面”库（见[保留页面](#keep-a-page)）；
- **另存为文件**（下载图标）：把页面保存为 `.html` 文件，可以在任何浏览器中打开；
- **全屏**（展开图标）：在应用上方打开页面。按 Escape 键、轻点关闭按钮（✕）或点击页面旁边的区域即可关闭。

页面运行在它自己的框架中，与应用隔离：它无法访问应用、你的文件或你的登录信息。它可以从网上加载图表库和其他库。

如果你用只读链接分享会话，对方也能看到其中的页面，但不能保留它们，他们在页面上做的选择也不会发送到任何地方（[分享只读链接](/guide/sessions#share-a-read-only-link)）。

## 在页面上选择选项或填写表单

有些页面会问你一些问题：三个方案中你更喜欢哪一个、旅行的日期、要保留哪些物品。你的回答会进入消息框，而不会直接发给智能体：

- **点击一个选项**，消息框中就会出现一行，比如 `Chose: B` 或 `Color: Blue`。如果页面允许多选，它们会一起放进去（`Color: Blue, Green`）。在同一组中选择另一个选项，它的那一行会替换第一行；不会越积越多。
- **填写表单并提交**，它的回答会以一个简短的列表放进去，标题是表单的名称，每个字段一行。

在消息中添加你想说的任何内容，然后像平常一样发送。智能体会把你的选择当作你消息的一部分来读。

页面全屏显示时，你的选择会先等着，在你关闭全屏时放进消息框（消息框在页面下方）。

## 保留页面

对话中显示的页面与对话共存。要以后再回来用它，就保留它：

1. 点击页面上方横条中的 **保留**。
2. 提示“已保存到‘页面’”表示成功。按钮现在显示为 **已保留**；点击它可以在“页面”中打开这个页面。

页面还在对话中时你在上面输入的内容会随它一起保留。保留之前，页面只在显示在屏幕上时记住你输入的内容；一旦保留，它就会永久保存它的数据（见[页面保存的数据](#the-data-a-page-keeps)）。

你也可以一开始就请智能体做一个要保留的东西：“给我做一个能在手机上用的习惯打卡表”“一份搬家清单”。智能体会自己把它保存到“页面”中，对话中会显示一张卡片，上面有：

- 页面的标题和 **已保存到页面 · 版本 2**（这条回复保存的版本）；
- **打开**（在“页面”中打开它）和 **全屏**；
- 页面本身，可以直接使用，带有它的数据，就在卡片中。

之后保存了更新的版本时，较早的卡片会显示 **已有更新的版本**。它仍然显示自己的那个版本，并读取页面的数据，但你在那里做的更改不会保存。如果那个版本已经不再保留，卡片会显示“这个版本已不再保留；‘打开’会显示最新版本”。如果页面被删除了，卡片也会说明。

智能体也可以修改你保留的页面：说“给我的习惯打卡表加一列备注”，智能体就会保存它的一个新版本。你的数据会保留，较早的版本也保持原样。

## 找到你的页面

侧边栏中的 **页面**（[/pages](/pages)）存放着你保留和发布的所有内容。在手机上，先用 **菜单**（≡）打开侧边栏。你也可以在搜索框（Ctrl+K，Mac 上为 ⌘K）中按标题查找页面。

这个页面有两个标签页，每个都带有数量：

- **已保存**：你的页面，最近更改的排在前面。每个页面显示一个彩色方块中的首字母、标题、上次更改的时间、版本，以及它存有数据时的数据量（`keeps 14 KB`）。**打开** 会打开它；**更多**（⋯）中有 **重命名**、**发布** 和 **删除**。
- **已发布**：你发布的页面和文件夹，以及它们的链接（见[查看和取消发布你发布的内容](#see-and-unpublish-what-you-published)）。[打开“已发布”标签页](/pages?tab=published)。

还没有保留任何页面时，“已保存”标签页会显示“还没有保存的页面”，并建议你保留一个页面，或者请智能体做一个小工具。

## 打开页面

页面会在应用内全屏打开，在“页面”中有它自己的位置。顶部的横条包含：

- 返回箭头（**所有页面**），回到列表；
- 页面的标题，下方是它的版本、上次更改的时间和它保存了多少数据。点击标题可以重命名页面；
- **版本**：它较早的版本（见[回到早先的版本](#go-back-to-an-earlier-version)）；
- **在手机上**：它的独立地址，供你的手机使用（见[在手机上使用页面](#use-a-page-on-your-phone)）；
- **发布**：把它放到别人能打开的链接上（见[发布页面](#publish-a-page)）；
- **更多**（⋯）：**重命名**、**在新标签页中打开**（在它的独立地址打开页面）和 **删除**。

在手机上，**版本**、**在手机上** 和 **发布** 只显示为图标，没有文字。

用应用现成的外观做的页面会跟随应用的浅色或深色主题。

## 重命名页面

点击顶部的页面标题，或者在页面中或列表中使用 **更多**（⋯）→ **重命名**。输入新名称（最多 120 个字符），然后点击 **重命名**。页面的名称也是你把它添加到手机主屏幕时使用的名称。

## 回到早先的版本

页面的每次保存都是一个独立的版本：第一个版本（由你保留，或由智能体保存）、智能体保存的每次更改，以及你恢复的每个旧版本。页面更改时不会丢失任何东西。

1. 打开页面，点击 **版本**。
2. 列表显示每个版本（`v3`）、它的标题（当前版本标为 **最新**）、创建时间、创建者（**由智能体生成**、**由你保留** 或 **已恢复**）以及大小。
3. 点击一个版本查看它。页面上方的横幅会显示“旧版本，来自 2 天前。它在这里所做的更改不会保存。”旧版本可以使用页面的数据，但你在其中做的任何更改都会被丢弃。
4. 点击 **恢复此版本** 让它成为当前版本，或者点击 **回到最新版本** 离开它。

恢复某个版本会把它作为一个新版本加在最上面（“版本 3 已恢复，成为版本 6”），所以它之后的版本也会保留。页面的数据不受影响。

页面保留它最新的 40 个版本。较旧的版本先被删除，所有版本加起来超过 24 MB 时也是如此；当前版本始终保留。

## 页面保存的数据

小工具需要记住一些东西：你记录的锻炼、你勾选的方框、你的预算条目。保留的页面会把这些数据存放在应用里，也就是应用运行的那台电脑上，而不是某一个浏览器里。所以无论你在哪里打开，它显示的数据都一样：在“页面”中、在对话里它的卡片中，以及在你手机上它的独立地址。

- 列表和页面的顶部横条会显示它保存了多少数据（`keeps 14 KB`）。
- 一个页面总共可以保存约 2 MB，单个条目最多 512 KB，最多 1000 个条目。超过这些限制后，就无法再保存更多。
- 新版本和恢复的版本使用相同的数据。
- 智能体可以读取页面的数据，用来回答关于它的问题（“这个月我记录了几次跑步？”），或者修改页面以适应这些数据。
- 页面的已发布副本不会保存数据（见[发布页面](#publish-a-page)）。

没有清除页面数据的按钮；请智能体删除你想去掉的内容，或者删除这个页面。

## 在手机上使用页面

每个保留的页面都有它自己的独立地址。这个地址只打开这个页面，带着它的数据，在任何设备上都能打开，而且不需要登录 Naget Agent：很适合你在手机上填写的跟踪表。

1. 打开页面，点击 **在手机上**。
2. **独立地址** 框中会显示地址。点击复制按钮，或者点击 **打开** 试一下。
3. 在手机上打开这个地址。要把它添加到主屏幕：
   - **iPhone**：在 Safari 中打开，然后点 **共享** → **添加到主屏幕**。
   - **Android**：在 Chrome 中打开，然后点 **⋮** → **添加到主屏幕**。

从主屏幕打开时，页面会像应用一样全屏显示，并使用它自己的名称。在独立地址打开时，它会跟随手机的浅色或深色设置。

任何拿到这个地址的人都可以打开这个页面，并更改它保存的内容，所以只把它分享给你在这方面信任的人。你的手机也必须能访问应用的地址（[从其他设备访问应用](/guide/devices#reach-the-app-from-another-device)）。

### 给页面换一个新地址

如果某个地址被发到了不该去的地方，就替换它：

1. 打开页面，点击 **在手机上**，然后点击 **新地址**。
2. 确认 **新地址**。旧地址会立即失效，已添加到主屏幕上的也一样。“页面有了新地址”表示已完成。

在你需要的地方，把新地址重新添加到主屏幕。

## 删除页面

在列表中或打开的页面中使用 **更多**（⋯）→ **删除**，并确认。页面会连同它的所有版本、它保存的数据以及它的任何已发布副本一起删除。它的地址也会失效。

“页面”最多可容纳 1000 个页面，单个页面的 HTML 最大 2 MB。

## 发布页面

发布会把页面放到一个链接上，别人不需要应用的密码就能打开。用它来给别人看你做的报告或小工具。

1. 打开页面并点击 **发布**，或者在列表中使用 **更多**（⋯）→ **发布**。
2. 检查 **名称**（最多 60 个字符）。
3. 选择链接类型：
   - **私密链接**：一个无法猜到的链接，只有你把链接给了的人才能打开。
   - **公开链接**：一个由名称生成的可读链接（比如 `/site/trip-plan/`），任何人都可能找到并打开它。
4. 点击 **发布**。框中会显示链接，以及复制和打开它的按钮。点击 **完成**。

已发布的副本显示的是页面现在的样子，之后的版本也会显示在那里。它不会保存数据：别人输入的内容在重新加载后就没了。要自己在手机上使用页面并保存数据，请改用它的独立地址打开（[在手机上使用页面](#use-a-page-on-your-phone)）。

链接以你访问应用时用的地址开头，所以只有能访问那个地址的人才能打开它。如果只有你自己的设备能访问应用（比如通过 Tailscale），那么也只有它们能打开这个链接（[从其他设备访问应用](/guide/devices#reach-the-app-from-another-device)）。

## 从文件夹发布网站

你也可以发布项目构建出来的网站，比如用 Vite 或静态网站生成器做的应用：也就是构建输出的那个文件夹，里面要有一个 `index.html`。

1. 打开 [页面 → 已发布](/pages?tab=published)，点击 **发布文件夹**。
2. 选择 **文件夹**：一个包含 `index.html` 的已构建网站（构建后的 `dist/`、`build/` 或 `out/`）。
3. **名称** 会根据文件夹的名称自动填写；你可以修改它。
4. 选择 **私密链接** 或 **公开链接**，然后点击 **发布**。

网站直接从磁盘上的文件夹提供，所以新的构建会立即显示，不需要重新发布。可以发布的内容：

- 文件夹必须包含 `index.html`；
- 不能是你的主文件夹、主文件夹的上一级、磁盘的根目录、应用自己的数据，或者隐藏文件夹（名称以点开头的文件夹）里的文件夹；
- 最多 5000 个文件、300 MB；
- 名称以点开头的文件和文件夹（`.env`、`.git`）永远不会被提供。

网站内没有对应文件、也没有文件扩展名的地址（`/site/…/about`）会得到网站的 `index.html`，这样自己切换页面的应用也能正常工作。如果文件夹被移动或删除，链接会显示它已不存在：请重新发布。

### 已发布的网站能做什么

已发布的网站运行在它自己的一个封闭空间中，与应用隔离：没有 cookie，没有应用的任何登录信息或数据，它在浏览器中保存的内容在重新加载后就会被忘掉。它没有自己的服务器代码。它可以从自己的文件以及三个公共脚本托管站点（jsDelivr、unpkg 和 cdnjs）加载脚本，并通过 HTTPS 调用外部服务。私密链接不会被搜索引擎收录。

从地址根路径（`/assets/…`）加载文件的已构建网站，在网站的链接下找不到这些文件。请用相对路径构建它们（在 Vite 中是 `base: './'`）。智能体请求发布这样的文件夹时，会被提醒先重新构建。

## 当智能体请求发布时

智能体也可以发布，但必须得到你的同意。说“发布我的网站”或“把旅行计划放到网上”，智能体会在对话中显示一张卡片：

- **发布“旅行计划”？**，以及它要发布的内容：保存的页面，或者文件夹及其文件数量和大小；
- 可供选择的 **私密链接** 或 **公开链接**，以及各自的含义：“它会在沙盒中打开，与本应用相互隔离；你可以随时在‘页面’中取消发布。”；
- **发布** 和 **暂不**。

在你点击 **发布** 之前，什么都不会发布。然后智能体会收到一条消息，告知结果和链接。卡片会变成 **已发布“旅行计划”**，并附上可复制或打开的链接；如果你点击了 **暂不**，会变成 **未发布：“旅行计划”**；如果发布失败，会变成 **“旅行计划”发布失败**，并附上原因。

一个会话中，智能体最多可以有五个等待中的发布请求。

## 查看和取消发布你发布的内容

[页面 → 已发布](/pages?tab=published) 列出所有已发布的内容，最新的排在前面。每一项显示它的名称、**私密链接** 或 **公开链接**、它提供的内容（页面的标题或文件夹的路径）和发布时间，以及可复制或打开的链接。

要撤下其中一项：

1. 点击它旁边的 **取消发布**。
2. 确认 **取消发布**。“它的链接会立即失效。”“已取消发布”表示已完成。

你以后可以再次发布它；届时私密链接会是一个新的链接。删除保留的页面也会取消发布它。同一时间最多可以发布 200 个网站。

没有发布任何内容时，标签页会显示“没有已发布的内容”。**发布文件夹** 位于这个标签页的右上角。

## 问问智能体

智能体可以为你读取和修改你的页面，你在卡片上同意即可。可以试试这些：

- “给我做一个能在手机上用的健身记录，保存到‘页面’里。”
- “我的预算跟踪表昨天看起来更好：把你上次修改之前的版本恢复回来。”
- “这周我在习惯打卡表里记了什么？帮我总结一下。”
- “把页面‘未命名清单’改名为‘搬家’。”
- “我把行李清单的地址发给了不该发的人：给它换一个新地址。”
- “用私密链接发布旅行计划”，或者“取消发布我们上周做的网站。”
