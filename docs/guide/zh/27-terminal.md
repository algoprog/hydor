# 终端里的 Hydor

`hydor` 命令在终端里完成你在应用页面上做的事，只要是没有页面也说得通的：与智能体对话并实时跟进它的工作、批准它的请求并回答它的问题、在脚本里发出一次请求并取回答案，以及管理你的会话、模型、档位、智能体、定时任务和用量。它和应用用的是同一个 Hydor，所以在终端里开始的会话会显示在应用里，在应用里开始的会话也能在终端里继续。

![hydor 命令：在终端里与智能体对话](images/terminal.webp)

## 获取这个命令

- **用安装程序安装**（`./install.sh`）：当 `~/.local/bin` 在你的 PATH 中时，安装程序会把 `hydor` 链接到那里，并告诉你。否则它会告诉你命令在哪里：Hydor 文件夹里的 `bin/hydor.mjs`，你可以直接运行它，也可以把它链接到你存放命令的地方。
- **用 Docker**：镜像里已经有它。运行 `docker exec -it hydor hydor`，就可以在容器内与智能体对话。
- **桌面应用**不会把这个命令放进你的 PATH。如果你在另一台电脑上有一份 Hydor，仍然可以使用那一份的：参见[使用另一台电脑上的 Hydor](#use-another-computers-hydor)。

`hydor help` 会列出它能做的一切。维护命令用的是同一个名称：`hydor service status`、`hydor setup-token`、`hydor update` 等等（`node dist/server/cli.js …` 也仍然可用）。

你不必先启动 Hydor。当这台电脑上没有任何响应时，命令会在后台启动它，显示 **Starting Hydor…**（正在启动 Hydor…），并在命令结束后让它继续运行，所以你的会话不会中断。`hydor status` 会告诉你它用的是哪个 Hydor、它的版本、它是否作为服务运行，以及现在有什么在工作。

## 与智能体对话

在一个文件夹里运行 `hydor`，或者在 `hydor` 后面跟上你的消息（`hydor fix the failing test`）。第一条消息会在该文件夹里开始一个会话。对话的开头会写出文件夹，以及由谁来回答你：程序（**Claude Code**、**Codex** 或 **Custom**）、模型（在有档位的 Hydor 上，如果模型按任务来定，则显示为**自动**）以及权限模式。

你看到的内容都留在终端自己的历史记录里，所以你可以向上滚动并从中复制，通过 SSH 和在 tmux 里也一样：

- **你的消息**，前面有一个 `›`。
- **智能体的文字**，随写随显示，包括标题、列表、引用、表格、链接（地址跟在文字后面）和代码（绝不会重新换行，所以复制出来的内容可以直接运行）。
- **每一步**占一行：它读了什么、搜索了什么、编辑了什么（附带增加和删除的行数）、运行了什么（附带所用时间；失败时还有退出码，错误的第一行显示在它下面）。
- **思考**显示为暗淡的一行，例如“Thought for 8 s”（思考了 8 秒）。用 `--thinking` 启动可以看到完整的思考内容，用 `-v` 可以看到每一步输出的前几行。
- **助手**：当智能体把一部分工作交给[子会话](/guide/research#let-an-agent-hand-work-to-child-sessions)时，会显示“Helper started”（助手已启动）；它的回复回来时，会显示“Helper finished”（助手已完成；或已停止、已失败）。Claude Code 还可以在后台运行它自己的助手，并在它们工作时结束这一轮：底部几行会说明哪些助手正在后台工作，每个助手结束时会显示“Finished in the background”（已在后台完成），智能体则自行继续。它留在后台运行的命令（例如开发服务器）不会拖住任何东西。`/helpers` 会列出所有助手，以及每个助手正在做什么（和一个助手花了多少钱）。
- **每一轮的结尾**：用了多长时间、花了多少钱、用的是哪个模型，以及有多少个助手参与了工作。

在底部，智能体工作时有几行会不断变化：正在写的文字、正在进行的步骤、正在工作的助手、带有已用时间的旋转指示符，以及你的输入行。按 Esc 或 Ctrl+C 可以停止这一轮。

### 回答智能体的询问

当智能体需要你批准时，请求会连同它的内容一起显示（命令、对文件的修改、计划），选项列在下面：

- 按 **y** 选第一个允许它的选项，按 **n** 拒绝，或者按任一选项的**数字**（例如“Always allow”，即始终允许）。
- 要拒绝并告诉智能体改做什么，输入你的话然后按 Enter。

问题的选项带有编号：按数字选一个（对于可多选的问题，选几个，然后按 Enter），或者输入你自己的答案并按 Enter。按 Esc 跳过。表单会逐个询问它的字段：输入每个答案并按 Enter，或者直接按 Enter 保留它显示的内容。要提供文件，就输入它在这台电脑上的路径。

有些请求需要用到应用：比如与签名有关的，或者你某个应用所需的密钥。终端会这样说明，并给出该会话在应用中的地址。

### 智能体工作时

你的输入行始终归你使用。智能体工作时你发送的消息会在会话的队列里等待（显示为 **queued**，即已排队），并在这一轮结束时发出，和在应用里一样。

### 按键

- **Enter** 发送。**Alt+Enter**、**Ctrl+J**，或者在行尾加一个 `\` 再按 Enter，可以换行。粘贴的内容会连同换行一起整体进入。
- **↑** 和 **↓** 在你之前的消息中翻查（保留最近 500 条）；在有多行的消息里，它们先在各行之间移动。
- **←**、**→**、**Home**、**End**、**Ctrl+A** 和 **Ctrl+E** 移动光标；**Alt+←** 和 **Alt+→** 一次移动一个词；**Ctrl+W** 删除光标前的一个词，**Ctrl+U** 和 **Ctrl+K** 分别删除光标之前和之后的其余部分。
- **Tab** 补全命令、`@` 后面的文件和文件夹（从会话的文件夹算起），以及 `/model` 后面的模型名称。
- **Esc** 停止这一轮。**Ctrl+C** 在有一轮正在运行时停止这一轮，有文字时清空这一行，否则连按两次就退出。**Ctrl+D** 在空行上退出。**Ctrl+L** 清屏。

你退出时，会话会继续：终端会告诉你怎样回到它。

### 命令

在输入行中输入：

- `/help`：命令和按键。
- `/new`（再加一条消息）：在同一个文件夹里开始一个新会话。
- `/sessions`：选另一个会话继续。
- `/model`、`/effort`、`/mode`：更改模型、思考的深入程度，以及不用询问就可以做哪些事。不带名称时，每个都会显示一个带编号的列表供你选择。
- `/agent`：从下一条消息起，以[你的某个智能体](/guide/agents)的身份工作。
- `/helpers`：所有助手（包括后台的）、每个助手正在做什么（以及一个助手花了多少钱）；`/helpers 2` 显示第二个助手的对话。
- `/tiers`、`/usage`、`/cost`：每个档位对应哪个模型、你的套餐的用量和限额，以及这个会话和它的助手花了多少钱。
- `/stop`、`/rename`、`/open`、`/quit`：停止这一轮和后台的助手、给会话重命名、显示它在应用中的地址、退出。

其他任何 `/命令` 都会原样交给智能体，用于该程序自己的命令和技能。

## 继续一个会话

- `hydor -c` 继续你所在文件夹里最近的一个会话。
- `hydor resume` 列出你最近的会话供你挑选；`hydor resume 6f1e2a3b` 继续指定的那个。

最近的几轮会先显示出来，每一轮的工作折叠成一行（“Ran 3 commands, read 4 files”，即运行了 3 条命令，读了 4 个文件）；`hydor show` 会打印全部内容。

## 选择会话如何开始

这些选项可以和 `hydor`、`hydor run` 和 `hydor resume` 一起使用：

- `--agent claude`、`codex`、`custom`，或者[另一个智能体程序](/guide/agents-models)的名称：由哪个程序来回答。
- `--model`（模型的名称，或者用 `auto` 表示自动）、`--effort`，以及 `--mode ask`、`edits`、`plan` 或 `full`（也可以用该程序自己的模式名称）。
- `--as Researcher`：以[你的某个智能体](/guide/agents)的身份开始。
- `--cwd`（一个文件夹；省略时是你当前所在的文件夹）、`--worktree`（有自己的分支和文件夹）、`--cap 2`（最多花 $2）、`--no-memory`、`--title`。

你省略的部分，取自应用开始页上最近一次的选择，再取自应用的默认值。

## 在脚本里发出一次请求

`hydor run "…"`（或 `hydor -p "…"`）用你的消息开始一个会话，一直跟进到工作完成，打印智能体的最后一条回复，然后结束。完成的意思是：这一轮结束了，没有任何助手还在工作或还欠着回复（包括 Claude Code 在后台的助手，无论是智能体的还是助手的助手），队列里也没有在等待的内容：结束一轮来等候助手的智能体，会被助手的回复或结束唤醒，而这次运行也会等候那一轮。留在后台运行的命令（例如开发服务器）不会拖住它。遇到 `--timeout` 或 Ctrl+C 时，后台的助手会随这一轮一起停止。后面不带任何内容时，它会从管道输入的内容读取消息：`git diff | hydor run "review this change"`。

- 在终端里，旁边的短行会说明发生了什么（每一步、助手的启动和完成）；`-q` 把它们关掉。
- 没有人可以回答，所以批准请求或问题会让这次运行停下，并说明被问了什么，会话则在应用里或通过 `hydor resume` 等你。使用 `--mode full`（或 `-y`）时，智能体什么都不会问。
- `--json` 在结束时打印一个对象：`key`、`url`、`status`、`reply`、`model`、`costUsd`（含它的助手的）、`tokens`、`durationMs`、`turns`、`children`（每个助手的 `title`、`label`、`tier`、`costUsd`、`status`），失败时还有 `error`。`--stream-json` 在每次变化发生时各打印一行（`item`、`live`、`note`），最后一行是上面那个对象。
- `--timeout 300` 在 300 秒后停止这一轮。

它结束时带有一个脚本可以检查的退出码：

| 退出码 | 发生了什么 |
| --- | --- |
| 0 | 完成 |
| 1 | 会话失败（出错，或者套餐的用量限额，它会指明），或者 Hydor 拒绝了 |
| 2 | 命令用法不对 |
| 3 | 需要你给出答案 |
| 124 | 用时超过了 `--timeout` |
| 130 | 你按了 Ctrl+C（先停止了这一轮） |

## 管理各项内容

- `hydor sessions`：你最近的会话、每个会话正在做什么（**工作中**、**需要你处理**、**已完成**）、它们的程序和模型、文件夹和时间。第一列是其他命令用来指代某个会话的名称；`--all` 也会列出助手。
- `hydor show 6f1e2a3b`：某个会话的对话。
- `hydor send 6f1e2a3b "…"`：给某个会话发一条消息，如果它正在工作就排队。`hydor stop 6f1e2a3b` 停止它的这一轮。
- `hydor models`（或 `hydor models claude`）：每个程序提供的模型、它们的思考强度，以及它的模式。
- `hydor tiers`：每个程序的每个[档位](/guide/agents-models#tiers-a-model-for-each-kind-of-job)对应哪个模型，以及会话如何使用它们。`hydor tiers set claude best opus --effort high` 更改其中一个，`hydor tiers reset` 把它们恢复原样；`hydor tiers team off` 和 `hydor tiers hard off` 分别关闭**主智能体带领助手**和**难题用最高档位**（`on` 再把它们打开）。
- `hydor agents`：你的智能体，内置的排在前面。
- `hydor tasks`：你的[定时任务](/guide/tasks)；`hydor tasks run <id>` 立即运行其中一个。
- `hydor usage`：每个套餐的用量和限额，以及它们何时重置。
- `hydor open` 打印应用的地址（`hydor open 6f1e2a3b` 打印某个会话的地址）；`--browser` 会把它打开。
- `hydor serve` 在这里于前台运行 Hydor，直到按 Ctrl+C。

它们每一个都接受 `--json`，会打印应用的 API 给出的内容，供脚本使用。

## 使用另一台电脑上的 Hydor

在那台电脑上创建一个访问令牌（在它的[设置 → 应用 → 机器](/settings?s=machines&find=Access%20from%20other%20machines)中点**新建令牌**，或者在那里运行 `hydor access-token "my laptop"`），然后连同它的地址一起指定：

```bash
hydor --server https://hydor.example.com --token acm_… sessions
```

或者一次性设置 `HYDOR_URL` 和 `HYDOR_TOKEN`。文件夹是那台电脑的：会话会在它的默认文件夹里开始，除非你用 `--cwd` 给出那里的一个文件夹（这台电脑自己的地址，例如 `http://localhost:8790`，则保留你当前所在的文件夹）。在这台电脑上，命令第一次运行时会为自己创建一个令牌，它在[设置 → 应用 → 机器](/settings?s=machines&find=Access%20from%20other%20machines)中列为“This computer's command line”。

## 颜色和管道

终端里颜色是开启的；当输出到文件或另一个程序、设置了 `NO_COLOR` 或使用 `--no-color` 时，颜色是关闭的；`FORCE_COLOR` 会把它们打开。当你输入的内容通过管道传入时（`echo "…" | hydor`），它的工作方式和 `hydor run` 一样。当只有输出被管道接走时，对话会不带颜色和不断变化的行来打印，你输入的每一行都会被发送。
