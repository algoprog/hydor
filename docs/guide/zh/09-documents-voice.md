# 文档、图片、视频和语音

Hydor 里的智能体能读 PDF、Word、Excel、PowerPoint 等文档，也能为你制作新文档，并以卡片的形式交给你，你可以打开或下载；它们还能生成图片、绘图、数据图和短视频，查找免费照片，修改你的图片和视频（裁剪、抠图、擦除、修剪），以及制作歌曲、配音和声音，用的是图像、视频和音频模型以及这台电脑上的工具，它们做出来的东西你可以保存到你的资料库。你也可以用说话代替打字，让回复朗读出来，或者边走路边用免提方式和应用对话。

![一个读了报告、做了一页 Word 摘要和一份带图表的电子表格的智能体](images/documents-voice.webp)

## 让智能体读文档

应用运行的每个智能体都能读文档：Claude Code、Codex、Custom，以及支持 ACP 并能接入 MCP 服务器的智能体。你不需要先做任何转换。用下面任意一种方式把文档交给它：

1. **附加到消息中**：点消息框里的回形针（**附加文件**），或者把文件拖到消息框上，或者直接粘贴。图片会以图片的形式发给模型；其他文件会保存在运行 Hydor 的电脑上，并把路径加到你的消息里，好让智能体打开它。一条消息最多可以带 25 MB 的文件。
2. **指明这台电脑上的某个文件**：“总结一下 ~/Documents/lease.pdf”。不以 `/` 或 `~` 开头的路径从会话的文件夹算起。
3. **把文档放在项目或共享知识中**，这样会话就能搜索它们，并注明出自哪一页：见[项目和知识库](/guide/projects)。

智能体读取时，它的工作过程会显示 **正在读取 lease.pdf**，读完后显示 **已读取 lease.pdf**。在较宽的屏幕上，这一行还会说明这是什么文档（类型，以及页数、工作表数或幻灯片数）和读了哪几行。点击这一行可以看到智能体拿到的文字，点击 **打开 lease.pdf** 可以查看文件本身。

长文档会分段读取，每次约 1200 行，还有更多内容时智能体会被告知。智能体会被要求把文档里写的内容当作信息，而不是指令。文档里的任何东西都不会运行：宏永远不会执行，链接也只保留网页链接和邮件链接。

Custom 用它普通的文件读取功能也能读 PDF、Office 文档和图片：见 [Custom，应用自己的智能体](/guide/custom)。

## 智能体能从文档中读到什么

### PDF

- 每一页的文字，按它在页面上的排版排列。
- 装有 pdftotext 程序（在 poppler-utils 中）时效果最好。没有它时，应用会下载一次 pdf.js（约 35 MB，第一次需要联网），排版也只是大致还原。
- 扫描的页面没有文字，智能体会被告知是哪几页（“第 3、5–7 页没有文字”）。借助 **pdf** 技能，它会把这些页面当作图片来看、自己读出内容，或者在装有 tesseract 时对它们做 OCR。
- 设有密码的 PDF 无法读取。把密码告诉智能体，**pdf** 技能就会做一份解除密码的副本。不用密码就能打开、只是限制修改的 PDF（很多官方表格都是这样），和其他 PDF 一样可以读取。
- **表单**：智能体会列出 PDF 的表单字段，每个字段都附上印在它旁边的文字（这些文字说明了名为“f1_02”的字段是做什么用的），还会把页面当作图片来看，图片上的字段都标有编号，并带有以点（pt）为单位的标尺。
- **你的高亮和笔记**：你在“文件”的阅读器里标出的高亮，逐页列出，附上你的笔记，以及你选中的图和公式的图片（[阅读 PDF 并标出高亮](/guide/files-git#read-and-highlight-a-pdf)），可以用来总结它们，或者对照论文核对。你要求的话，它也会替你高亮文字，这些高亮随后会显示在阅读器里。

### Word、Excel 和 PowerPoint

- **Word**（.docx，以及它的启用宏格式和模板格式）：标题、段落、编号列表和项目符号列表、表格、链接、文本框、图片（以其描述呈现）、脚注、尾注和批注。
- **Excel**（.xlsx，以及它的启用宏格式和模板格式）：每个工作表都呈现为带行号和列字母的表格，数字大致按其格式显示（日期、百分比、金额），每个工作表最多附带 40 个公式。隐藏的工作表会被标出。每个工作表给出前 2000 行和前 60 列，还有更多时会告诉智能体；要读取更大工作表的全部内容，**spreadsheets** 技能会用另一种方式加载它。
- **PowerPoint**（.pptx，以及它的启用宏格式、模板格式和放映格式）：每张幻灯片的标题、文字、表格、图片（以其描述呈现）、图表（标题和数据系列）和演讲者备注。隐藏的幻灯片会被标出。最多 1000 张幻灯片。

### OpenDocument、EPUB、CSV 和 RTF

- **OpenDocument**（LibreOffice 自己的 .odt、.ods 和 .odp，它们的模板，以及 .odg）：带标题、列表、表格、链接和脚注的文字；按显示效果呈现的工作表；带标题、文字和备注的幻灯片。
- **EPUB** 电子书：按阅读顺序排列的各章，带标题、列表、表格和引文。
- **CSV** 和 **TSV** 表格，以及 **RTF** 文本。

### 旧版 Office 文件、加密文件和超大文件

- 旧的 .doc、.xls 和 .ppt 文件通过 LibreOffice 读取，它会先把它们转换成现在的格式。没有 LibreOffice 就无法读取，这时智能体会被告知：请你提供另存为 .docx、.xlsx 或 .pptx 的文件，或者安装 LibreOffice。
- 设有密码的 Word、Excel 和 PowerPoint 文件无法读取。
- 最大可以读取 300 MB 的文件。一份文档最多提供约 100 万个字符的文字（约 25 万个 token）；超出的部分会被截掉，并告知智能体。

## 让智能体制作文档

应用自带四个文档技能，每个智能体都能加载：**word-documents**、**spreadsheets**、**presentations** 和 **pdf**。它们在[设置 → 技能](/settings?s=skills&find=Built%20in)的**文档**分组下（见[技能](/guide/skills)）。你不用自己挑选：用平常的话提出要求就行（“根据我的笔记做一份一页的 Word 简历”“把这些开支做成电子表格，加上每月合计和一张图表”“为我关于蜜蜂的演讲做 8 张幻灯片”“把这三个 PDF 合并成一个”），任务需要时，智能体会加载合适的技能。

每个技能的做法都一样：

1. 智能体先规划文档：它的大纲、工作表或幻灯片。
2. 它在会话的文件夹里用一小段脚本写出文件。
3. 它把结果渲染成页面图片来查看，检查有没有文字超出页面、表格放不下、幻灯片太挤，并修正不对的地方。
4. 它把文件做成卡片放在回复下方交给你，并附上一句简短的说明（见[打开或下载智能体制作的文件](/guide/documents-voice#open-or-download-the-files-an-agent-made)）。

修改你的文件时，它会用新的文件名保存结果，除非你要求它覆盖原文件。

### Word 文档

报告、信件、简历、备忘录、合同、表单、讲义和笔记，可以在 Word、Google Docs 或 Pages 中打开。

- 真正的文档结构：标题（可用于 Word 的导航窗格和屏幕阅读器）、项目符号列表和编号列表、带标题行的表格、图片和分页符。
- 目录（文件打开时由 Word 填好）、页码（“第 1 页，共 3 页”）、链接和带底纹的表格单元格。
- A4 或 US Letter 纸张，以及在任何电脑上看起来都一样的字体（Calibri、Arial、Cambria、Times New Roman）。
- 直接修改你自己的文档，保留原有的样式、页眉和版式；替换文字而不丢失格式；添加批注。
- 用你保存的签名签署：放在 {{signature}} 的位置、紧跟在“Signature:”这样的文字之后、放进表格的单元格，或者放在文档末尾，每次都要等你在卡片上允许（[签名](/guide/library#signatures)）。
- 还可以通过 LibreOffice 生成一份 PDF。

### 电子表格

预算、跟踪表、日程表、发票和数据表（.xlsx）。

- 你的数字作为数值填入，计算结果用公式表示，这样你改一个数字，其余的就会跟着变。
- 金额、百分比和日期的数字格式；滚动时始终可见的粗体标题行；列宽；列表上的筛选。
- 放在数据旁边的条形图、折线图和饼图。
- 检查每一个公式。装有 LibreOffice 时，检查会把公式实际算一遍，并列出所有错误（#REF!、#DIV/0!、#NAME?），然后由智能体修正。
- 修改你自己的工作簿，保留其中的公式、样式和大部分版式（数据透视表不会保留，图表只有在智能体重新创建时才会保留）。你要求时，也可以改为生成 CSV 文件。

### 演示文稿

推介材料、演讲、课程和总结（.pptx），可以在 PowerPoint、Keynote 或 Google Slides 中放映。

- 简洁的 16:9 幻灯片，风格前后统一，并使用你的品牌色：标题页、分级的要点、两栏、适应幻灯片大小的图片、表格、图表（柱形图、条形图、折线图、饼图、堆积图）、章节页，以及写着你要讲什么的演讲者备注。
- 每张幻灯片一个观点，标题直接点明要点（“销售额增长了 12%”），一次演讲通常 6 到 12 张幻灯片。
- 图片可以由你提供、来自网络，或者用图像模型生成（见[让智能体生成图片](/guide/documents-voice#let-agents-make-images)）。
- 用你自己的模板做一份新的演示文稿，或者修改你的演示文稿，保留它的主题和版式。
- 还可以通过 LibreOffice 把幻灯片导出为 PDF。

### PDF 文件

报告、发票、证书、传单、信件和表单。

- 以文字为主，或者你以后还想编辑的：智能体先做一份 Word 文档，再用 LibreOffice 把它转成 PDF。
- 需要精确排版的（发票、证书、门票、表单）：它直接绘制 PDF。
- 把幻灯片或工作表做成 PDF：先用对应的技能制作，再转成 PDF。
- **填写表单**：按名称填写它的字段（文字、勾选、选项，希腊文、中文或任何文字都可以），这样任何查看器都能显示它们，之后也仍然可以在那里修改；对于只有印刷的横线和方框的表单，则把文字写在页面上印着的文字（“Date of birth:”）旁边，并在方框里打勾；对于扫描的表单，因为里面没有可查找的文字，就写在智能体从页面图片中看到的空白处。智能体会向你询问它不知道的内容，并在填写前后查看页面。带数字签名的表单只填写字段时，签名仍然有效。XFA 表单（Adobe LiveCycle）只能在 Adobe 自己的应用中填写：智能体会说明这一点，但仍然可以在它们的页面上书写。
- **在页面上书写**：文字、勾号和叉号、图片、盖在原有内容上的白色方框（它们只是让文字看不见：文字仍然留在文件里，所以这不是真正的涂黑删除）、轮廓框和线条，以及作为 PDF 自身注释的高亮和批注，其他查看器会列出它们，也可以把它们去掉。
- **修改页面**：旋转、删除、移动页面，插入空白页，合并 PDF，把其中一些页面单独存成一个文件，或者把一个文件拆成几个。这样修改过的文件无法保留数字签名，智能体会说明这一点。
- 智能体写的内容会放进原文件旁边的一份副本（“name (filled).pdf”），除非你要求直接修改文件本身；那样的话，文件的旧版本会进入废纸篓。你也可以自己填写和签署 PDF：[填写和签署 PDF](/guide/files-git#fill-in-and-sign-a-pdf)。
- 用 **pdf** 技能在每一页上盖上大号的浅色字样（比如“草稿”），以及做一份去掉密码的副本（由你提供密码）。
- 用你保存的签名签署：放在页面上某些文字旁边，或者先给你看过的某个位置，每次都要等你在卡片上允许；签名会添加到 PDF 中，不改变原有的内容（[签名](/guide/library#signatures)）。
- 把 Office 文件转换成 PDF。

### 电脑需要准备什么

这里说的是运行 Hydor 的那台电脑，而不是你用来访问它的设备。

- **Python 3** 及其 venv 模块：制作文档需要它。第一次使用时，技能会把几个处理 Office 文件和 PDF 的 Python 库安装到应用的一个私有文件夹里（约 30 MB，只需一次，从网上下载）；不会在系统范围内安装任何东西。如果缺少 Python，智能体会告诉你需要运行的那一条命令（在 Debian 或 Ubuntu 上是 `sudo apt install python3 python3-venv`；在 Mac 上是 `brew install python`）。
- **LibreOffice**（可选）：用于在文件查看器中按排版后的页面预览、读取旧的 .doc、.xls 和 .ppt 文件、让智能体以页面形式查看 Office 文档、检查公式，以及把 Office 文件转成 PDF。在 Debian 或 Ubuntu 上：`sudo apt install libreoffice-writer-nogui libreoffice-calc-nogui libreoffice-impress-nogui`；在 Mac 上：`brew install --cask libreoffice`。
- **poppler-utils**（可选）：效果最好的 PDF 读取，以及为智能体和 **填写和签名** 生成 PDF 页面的图片。没有它时，应用会用这台电脑现有的方式来绘制（Mac 或 Windows 自带的 PDF 绘制方式），或者用 **设置 → 浏览器** 中的浏览器。在 Debian 或 Ubuntu 上：`sudo apt install poppler-utils`；在 Mac 上：`brew install poppler`。
- **tesseract**（可选）：对扫描的 PDF 做 OCR。

没有 LibreOffice 或 poppler-utils 时，智能体会把文件读回成文字来检查，并让版式保持简单。

## 打开或下载智能体制作的文件

智能体为你制作了文件（文档、电子表格、幻灯片、PDF、图片、压缩包）后，会以卡片的形式放在回复下方交给你，一次最多 12 个。每张卡片包含：

- 按文件类型显示的图标，带有对应的颜色（Word 蓝色、Excel 绿色、PowerPoint 橙色、PDF 红色），如果是图片，则显示一张小缩略图；
- 文件名、文件类型和大小（“Word 文档 · 24 KB”）；
- 智能体写的说明（“预算，每个季度一张工作表”）；
- **打开**、一个下载按钮，以及 **更多**（⋯）。

**打开** 会在文件查看器中显示文件：它是盖在对话上方的一个窗口，对话停留在原来的位置（在手机上，窗口从屏幕底部升起）。窗口顶部的 **在“文件”中打开** 会把文件带到“文件”页面；叉号或 Escape 键会关闭窗口。下载按钮会把文件保存到你的设备上。

卡片上和窗口顶部的 **更多**（⋯）里有 **用它开始会话**（打开开始页，文件已放在消息框里）、**添加到项目**（把它复制到某个项目的文件夹中）、**保存到资料库**（Jupyter 笔记本、PowerPoint 演示文稿、Word 或 Markdown 文档、电子表格或 LaTeX 文件：在你的资料库里保存一份副本，用对应的编辑器打开；有项目时会放进你选的项目，会话所在的项目排在最前）、**在“文件”中显示**（卡片上）和 **复制路径**。见[用文件开始会话](/guide/files-git#start-a-session-with-files)和[把文件添加到项目](/guide/files-git#add-files-to-a-project)。

之后被删除或移动的文件会显示为 **已不存在**。如果智能体给出了一个不存在的文件，你会看到“无法显示文件”和原因，智能体也会被告知去修正。

## 在文件查看器中预览文档

文件查看器可以显示来自卡片、“文件”页面或回复中链接的文档（见[系统：文件、Git、终端和预览](/guide/files-git)）。

- **PDF** 按原样显示，使用浏览器自带的 PDF 查看器，并带有 **填写和签名**，可以填写和签署它们（[填写和签署 PDF](/guide/files-git#fill-in-and-sign-a-pdf)）。
- **Word、Excel、PowerPoint、OpenDocument、EPUB 和 RTF** 文件（包括旧的 .doc、.xls 和 .ppt）会以预览形式显示。装有 LibreOffice 时，顶部的切换开关提供两种视图：
  - **页面**：“按 LibreOffice 的排版显示”，每一页都和打印出来的样子一样。第一次需要一点时间（“正在排版页面…”）；之后在文件改动之前，页面都会立刻打开。
  - **文本**：“它的文字、工作表和幻灯片”，也就是应用读到的内容。文本文档显示为一页纸；工作簿显示为一个网格，带列字母、行号，底部每个工作表一个标签（隐藏的工作表标有一只划掉的眼睛）；幻灯片显示为卡片，每张都带编号，下方是它的演讲者备注。图片显示为一个写着其描述的方框。有内容被省略时，顶部会有一行说明（“显示前 1000 行”）。
- 没有 LibreOffice 时，只有 **文本** 视图。EPUB 电子书总是在这个视图中打开。
- 在手机上，预览默认打开 **文本** 视图，它在小屏幕上滚动和缩放都更方便；用切换开关可以查看页面。

如果 LibreOffice 无法为某个文件排版，查看器会说明，文件的文字仍然可以在 **文本** 下查看。没有预览的文件会显示“此文件无法预览”：把它下载下来，在你的设备上打开。查看器的下载按钮始终都在。

## 让智能体生成图片

让任何一个智能体画张图（“给我的面包店做个标志”“把这张照片变成水彩画”），它会通过 OpenRouter 用图像模型生成图片，保存到会话的文件夹里，并和回复一起显示出来。在 **[设置 → 功能 → 图片、视频和音频](/settings?s=images)** 中设置（在手机上：打开设置，然后点 **图片、视频和音频**）。

- **[图片生成](/settings?s=images&find=Making%20images)**：开关 **允许智能体生成图片** 会给每个智能体提供处理图片的工具：生成图片、绘图和数据图，以及去掉图片的背景或擦除它的一部分。除非你把它关掉，否则它是开启的；关闭后，智能体就不会得到这些工具。
- **OpenRouter 密钥**：图像、视频和音频模型通过 OpenRouter 调用，每张图片、每段视频或每段声音都用你的 OpenRouter 密钥付费。没有密钥时，这一部分会说明，并提供 **在 openrouter.ai 获取** 和 **添加密钥**，后者会打开 [设置 → 智能体 → 模型 → OpenRouter](/settings?s=models&find=OpenRouter)，密钥就填在那里（见[智能体、账户和模型](/guide/agents-models)）。需要密钥的智能体则会改为用一张卡片向你要它（[智能体需要 OpenRouter 密钥时](#when-an-agent-needs-the-openrouter-key)）。
- **[用于大多数图片（最佳）](/settings?s=images&find=For%20most%20pictures%20%28Best%29)**：用来生成场景、照片、人物、图中文字和示意图，以及对图片做任何修改的模型。它会显示开发者、生成一张图片的大致费用（按约一百万像素的图片计）、OpenRouter 上架的月份和它的 ID，以及标签：**新增**（最近 30 天内上架）、**图片编辑**（它可以接收图片来修改或参照）和 **也输出文字**（它会在图片之外输出文字）。在你选择之前，由应用来选（“由应用选择，直到你选定一个”）：从 OpenRouter 仍在提供的一小批模型中取第一个：先是 ByteDance 的 Seedream 5.0 Pro 和 Flash，然后是 Google Gemini、OpenAI 和 FLUX 的图像模型。
- **[用于简单图片（快速）](/settings?s=images&find=For%20simple%20pictures%20%28Quick%29)**：一个更便宜、更快的模型，用于图标、背景、纹理和简单的图片，显示方式相同。在你选择之前，由应用来选：从 OpenRouter 仍在提供的一小批快速模型中取第一个，先是 ByteDance 的 Seedream 5.0 Flash，然后是 Google、Recraft、FLUX 和 OpenAI 的快速模型（OpenRouter 一个都不提供时，简单图片也由“最佳”模型来生成）。
- **[这台电脑上的图片工具](/settings?s=images&find=Picture%20tools%20on%20this%20computer)**：在这台电脑上去掉图片的背景、擦除图片的一部分，而不通过 OpenRouter：免费，你的图片也留在这里。**配置** 会把它们下载一次，下方的一行字会说明它们正在做什么，**移除** 会再把它们从这台电脑上删掉（见[这台电脑上的图片工具](/guide/library#the-picture-tools-on-this-computer)）。

要选择“最佳”或“快速”模型：

1. 点击它旁边的 **修改**：会打开 OpenRouter 的图像模型列表（**大多数图片使用的图像模型（最佳）** 或 **简单图片使用的图像模型（快速）**）。
2. 按名称搜索（“seedream”“flux”“gemini”），并按 **推荐**（应用推荐的排在前面）、**最新** 或 **最便宜** 排序。
3. 点击某一行即可使用该模型。**改为让应用来选择** 会回到由应用选择。

这些列表来自 OpenRouter，不需要密钥；无法访问时，列表里会说明。

## 让智能体生成视频

智能体也能制作短视频（“十秒钟的黄昏海浪”“让这张照片里的狗在田野上奔跑”），用的是 OpenRouter 上的视频模型，设置在同一个部分 **[设置 → 功能 → 图片、视频和音频](/settings?s=images)** 中：

- **[视频生成](/settings?s=images&find=Making%20videos)**：开关 **允许智能体生成视频** 会给每个智能体提供生成视频的工具。除非你把它关掉，否则它是开启的。
- **[视频模型](/settings?s=images&find=Video%20model)**：用来生成视频的模型，会显示它的开发者、每秒视频的费用（从不带声音的最低分辨率到带声音的最高分辨率，比如“每秒 $0.03 到 $0.08”）、它能生成的时长（“4 到 8 s”）、它的最高分辨率（“最高 1080p”）和 OpenRouter 上架的月份，以及标签：**声音**（随画面一起生成声音）、**从图片开始**（它可以从你提供的图片开始）和 **视频编辑**（它修改你提供的视频，而不是根据文字生成新视频）。在你选择之前，由应用来选：从 OpenRouter 仍在提供的一小批带声音的模型中取第一个：先是 ByteDance 的 Seedance 2.5，然后是更便宜、更快的模型，比如 Google Veo 3.1 Lite。**修改** 会打开列表，可以搜索（“seedance”“veo”“kling”），并按 **推荐**、**最新** 或 **最便宜** 排序。

视频比图片贵得多：每秒从几美分到几美元不等，用顶级模型生成一段 8 秒、带声音的视频，可能要花好几美元。每段视频都用你的 OpenRouter 密钥付费，在生成任何东西之前，你都会在一张表单上看到它的价格。

## 让智能体生成音频

智能体也能生成声音：歌曲和广告短曲（“为我的播客做一段 30 秒的片头曲”），用你描述的声音（“用温暖、缓慢的声音读这段欢迎词”）或从你手头的录音中复制的声音来配音和旁白，以及音效和环境声（“雨打在铁皮屋顶上”）。设置在同一个部分 **[设置 → 功能 → 图片、视频和音频](/settings?s=images)** 中：

- **[音频生成](/settings?s=images&find=Making%20audio)**：开关 **允许智能体生成音频** 会给每个智能体提供生成音频的工具。除非你把它关掉，否则它是开启的。
- **[音乐模型](/settings?s=images&find=Music%20model)**：用来生成歌曲和音乐的模型，会显示它的开发者、价格（“每首 $0.08”）、能生成的最长时长（“最高 3:00”）和 OpenRouter 上架的月份，以及标签 **音乐**。在你选择之前，由应用来选：Google 的 Lyria 3 Pro，能生成最长约 3 分钟的完整歌曲，有演唱或没有演唱都可以；没有它时用 Lyria 3 Clip，生成 30 秒的片段。
- **[语音和声音模型](/settings?s=images&find=Voice%20and%20sound%20model)**：用来说话和生成其他声音的模型，会显示它的价格（“每秒 $0.0025”“每 1,000 个字符 $0.08”“每分钟约 $0.014”）、能生成的最长时长和它有多少种声音，以及标签：**也能做音效**（根据描述生成音效和环境声，也能生成人声）、**复制声音**（用从你给的简短录音中复制的声音说话）、**对话**（为几个说话人配音，每个人用自己的声音）和 **可指导**（接受表达方式的指导：语气、语速、情感）。在你选择之前，由应用来选：ByteDance 的 Seed Audio 1.0，它能根据描述做到以上所有事情，每次最长 2 分钟；没有它时用 Google 的 Gemini 3.8 Flash TTS，再没有就用 ElevenLabs v3。

**修改** 会打开各自的模型列表，可以搜索（“lyria”；“seed”“elevenlabs”“gemini”），并按 **推荐**、**最新** 或 **最便宜** 排序（语音模型按一分钟语音的大致费用排序）；**改为让应用来选择** 会回到由应用选择。如果你选的语音模型只会把文字读出来，音效或复制的声音就会改用应用选择中能做到的模型来生成，表单上会说明这一点。

语音模型大多按读出的字符数计费，Seed Audio 按生成声音的秒数计费，Lyria 按首计费。每一项都用你的 OpenRouter 密钥付费，在生成任何东西之前，你都会在一张表单上看到它的价格。

## 生成之前先确认设置

智能体生成图片、精细绘图、视频或声音之前，对话中会显示一张简短的表单，列出这个模型可调的设置和成品的费用，并已按你的要求和应用的默认值填好：

- 图片：**形状**（正方形、横幅、竖幅……模型支持几种就列出几种）、**分辨率**（1K、2K、4K……）、**质量**、**图片数量**（适用于一次能生成多张的模型）和 **透明背景**（用于标志或图标）；
- 精细绘图（由 Recraft 的矢量模型绘制）：它的 **形状**；
- 视频：**视频时长**（模型能生成的几种时长，或者 **时长（秒）**）、**形状**、**分辨率** 和 **声音**；
- 声音：歌曲有 **纯音乐，不要演唱**，能生成长歌曲的模型还有 **时长（秒）**（留空则让歌曲按需要的长度生成）；音效有它的 **时长（秒）**（Seed Audio 按秒计费）；语音有 **语音**（适用于有自带声音的模型）；还有 **文件**（**MP3，更小** 或 **WAV，无压缩**，适用于两种都能生成的模型）。

这些设置项上方是模型的名称、它的价格（“每张图片约 $0.08”“每秒 $0.03 到 $0.08，视分辨率和声音而定”“每首歌 $0.08”“每秒声音 $0.0025”；对于视频或声音，还有按显示的设置算出的总价），以及智能体要提的完整要求（用它自己的话写）。改你想改的，然后点击 **创建**；**暂不** 会关闭表单，什么都不会生成，也不会花钱。表单只显示这个模型提供的设置。

在一个会话中，每个模型只会出现一次表单：这个会话里之后的图片、视频和声音都沿用你选的设置（声音沿用它的语音和文件格式），除非你另有要求（“这次做张竖的”）。说“再给我看看设置”就会再出现表单，说“直接做吧，你帮我选”智能体就会不经表单直接生成。定时任务和应用的运行不经表单，直接用应用的默认值生成，因为没有人在那里回答。

## 智能体需要 OpenRouter 密钥时

图片、精细绘图、视频、音乐和语音都由模型通过 OpenRouter 生成，用你的 OpenRouter 密钥付费。智能体要生成其中一样、却还没有设置密钥时，对话中会先出现一张卡片 **这需要 OpenRouter 密钥**，说明会由哪个模型来生成、大概要花多少钱，以及生成的东西由你付费给 OpenRouter，卡片上还有一个填写密钥的输入框：

- 粘贴密钥，然后点击 **保存密钥**（或按 Enter）。OpenRouter 会先检查它；密钥会直接存进 [设置 → 智能体 → 模型 → OpenRouter](/settings?s=models&find=OpenRouter)，永远不会进入对话，智能体也会接着做下去（和平常一样，接下来是带设置的表单）。之后卡片会显示“你的 OpenRouter 密钥已保存在‘设置 → 模型’中。”
- **获取密钥** 会打开 OpenRouter 上创建密钥的页面。
- **跳过**：这个模型不会运行，什么都不会生成，也不会花钱，智能体会不用它接着做下去：有不需要密钥的办法时就换个办法（它自己写出的简单绘图、[这台电脑上的图片工具](/guide/library#the-picture-tools-on-this-computer)），没有就不做。这个会话在六小时内不会再问。

卡片最多等九分钟；之后智能体会在没有密钥的情况下继续，如果你之后添加了密钥，它也会得知。定时任务和应用的运行不会显示卡片，因为没有人在那里回答：它们会说明缺少密钥（“生成图片需要 OpenRouter 密钥”，以及 **添加 OpenRouter 密钥**）。编辑器自带的 AI 工具则会在它们的对话框中向你要密钥（[用 AI 生成图片、绘图、数据图和视频](/guide/library#make-pictures-drawings-plots-and-videos-with-ai)）。

## 请智能体生成图片或修改图片

描述你想要的：主体、场景、风格（照片、插画、水彩画）、颜色、光线，以及图中应该出现的文字。智能体还可以：

- **修改或合成你的图片**：这台电脑上的图片文件（PNG、JPEG、WebP 或 GIF，每个最大 20 MB；大多数模型最多 4 个，有些更多），放在会话的文件夹里，或者给出它们的路径，也可以是你资料库里某套幻灯片、某份文档或某个页面中已有的图片；说清楚要改什么。（附加在消息里的图片是发给模型看的；要让图像模型以它为基础来生成，它必须是一个文件：在“文件”页面上传它。）这需要带有 **图片编辑** 标签的模型；用其他模型时，智能体会被告知改用文字描述要做的修改，或者请你选一个能编辑图片的模型；
- **使用“快速”或“最佳”模型**：智能体用“快速”模型生成简单的图片（背景、纹理、图标），用“最佳”模型生成场景、照片、图中文字和示意图，以及做任何修改，或者根据你的要求来决定；想用另一个就直说（“快速的就行”“用最佳模型”）；
- **让背景透明**（标志、图标）：做不到的模型会把它交给能做到的模型；或者，在配置好[图片工具](/guide/library#the-picture-tools-on-this-computer)时，先在纯色背景上生成图片，再在这台电脑上去掉它的背景；
- **换一个模型** 来生成某一张图片：说出它的名字就行（“用 FLUX 2 Pro 来做”），不用改设置。

图片会保存在会话文件夹里的 **images** 文件夹中，按图片的内容命名，绝不会覆盖已有的文件。

在对话中：

- 模型工作时，会有一个按所要求形状显示的占位框，写着“正在生成图片”和已用的时间，下方是图片描述。
- 然后图片会和回复一起显示，下方是描述、模型名称和 **保存到资料库**（见[保存智能体做的东西](#keep-what-an-agent-made)）。点击一张图片可以放大查看：再点一次看原始尺寸，用箭头（或方向键）在多张图片之间切换，**在新标签页中打开** 会单独打开它，**编辑** 会在图片编辑器中打开它（你在那里保存的东西会作为一张新图片放进你的资料库：[编辑图片和视频](/guide/library#edit-pictures-and-videos)），按 Escape 键关闭。鼠标指向每张图片时，上面会出现 **在文件中显示**、**下载** 和 **更多**（⋯，其中有 **用它开始会话**、**添加到项目** 和 **复制路径**）；在手机上它们一直显示。有多张图片时，那里也有 **保存到资料库**。
- 没有设置 OpenRouter 密钥时，会先有一张卡片向你要密钥（[智能体需要 OpenRouter 密钥时](#when-an-agent-needs-the-openrouter-key)）；在没有人看着的运行中（定时任务的、应用的），你会改为看到“生成图片需要 OpenRouter 密钥”，以及 **添加 OpenRouter 密钥**。什么都没生成时（你跳过了密钥或关闭了表单，或者模型拒绝了），你会看到“这次没有生成图片”和原因。

## 请智能体绘图或制作数据图

有些图片与其让图像模型画出来，不如用形状来绘制，或者根据数字算出来：

- **绘图**（SVG：由形状而不是像素组成，任何大小下都清晰）：图标、标志、示意图、可以重复的图案、形状或扁平插画，用你给的颜色（比如某套幻灯片或某份文档自己的颜色）。简单的由 Claude（或你选的[辅助模型](/settings?s=models&find=Helper%20model)）写出来，不用为图像模型付钱，不到一分钟就好；精细的（插画，或者你要求最好的效果时）由 Recraft 的矢量模型通过 OpenRouter 绘制，每张约 $0.08，会先显示带价格的表单。每张绘图在保存之前，都会去掉其中的脚本、链接以及任何要从别处加载的东西。
- **数据图**：画出你的数据或数学内容，用于幻灯片的图表画不了的东西：散点图、直方图、箱线图、误差线、多个坐标轴或多个子图、热力图、函数、拟合曲线，以及对关键数据点的标注。Claude（或辅助模型）用 Python 和 matplotlib 写出它，它在这台电脑上运行，出了问题就交回去修正（最多试三次）；大约需要半分钟，花费只有那一次回答。把数字写在消息里，或者以文件的形式给出（CSV、TSV 或 JSON，最大 20 MB），并说明它要表达的重点（“显示春季翻了一番”）。它以绘图的形式交给你（SVG；数据点非常多时为 PNG），除非你要求别的尺寸，否则是 960×540 像素，旁边附有它的 Python 代码，所以说“现在改用对数刻度”就会修改这张数据图；对于面向网页的幻灯片，它还可以做成一张会动、会响应指针的数据图。它需要应用所在的电脑上有带 matplotlib 的 Python：配置好图片工具后用它们自带的那个（[这台电脑上的图片工具](/guide/library#the-picture-tools-on-this-computer)），或者电脑上已有的。

两者都保存在会话文件夹里的 **images** 文件夹中，并像图片一样和回复一起显示；制作期间，占位框会显示“正在制作绘图”或“正在绘制数据图”。

## 查找免费照片

如果你要的是照片，而不是模型生成的图片（“给我的标题幻灯片找两张里斯本电车的照片”），智能体会搜索采用开放许可的照片，可以免费使用和修改，商业用途也可以：Openverse 的图库（Flickr、Wikimedia Commons、博物馆等），Openverse 无法回应时则用 Wikimedia Commons 自己的搜索。它会把最好的几张（除非你另有要求，否则是 4 张，最多 10 张）保存到会话的 **images** 文件夹中，并在旁边的一个文件里记下每一张的署名信息（标题、作者、许可协议和链接），使用之前会先看一看，并按许可协议的要求署名：写在幻灯片的演讲者备注中，或者写在文档或页面中图片的下方；对于 CC0 和公有领域以外的许可协议，还会在照片旁边加一行小小的说明文字（例如：Photo: “Title” by Author, CC BY 2.0）。这是免费的，只需几秒钟；搜索期间，占位框会显示“正在查找免费照片”。

## 抠图、擦除和编辑

智能体还能直接修改你的图片和视频，而不用重新生成：

- **去掉图片的背景**：把它的主体（一个人、一件商品、一只动物、一个标志）放在透明背景上，存为 PNG。配置好[图片工具](/guide/library#the-picture-tools-on-this-computer)后，在这台电脑上做是免费且私密的，会保留主体原本的像素，只需几秒钟；抠得不好的，会交给图像模型重新做。没有这些工具时，由图像模型通过 OpenRouter 来做（约 $0.01 到 $0.04），它会把去掉背景的图片重新画一遍，所以细小的地方可能会有出入。
- **从图片中擦除某样东西**（背景里的一个人、一块招牌、水印、污渍、一根线缆）：它会被去掉，并按周围的样子延续着填补上。智能体会标出它在哪里，或者描述它，让图像模型去找。小的区域在这台电脑上免费擦除；大的区域、横跨图片的区域，以及位于文字等精细内容之间的区域，会交给图像模型（约 $0.01 到 $0.04）。
- **编辑图片**：裁剪、旋转或翻转、调整大小，修改光线和颜色（曝光、对比度、色温等），加上滤镜（**复古**、**黑白**……），在上面写字，画箭头和方框，以及把某些部分模糊或打上马赛克（一张脸、一块车牌、一个名字）。免费，在这台电脑上完成；JPEG、WebP 或 GIF 图片，或者要在这类图片上写字，需要那里有 ffmpeg 或图片工具。
- **编辑视频**：修剪、剪掉其中几段、按比例裁剪（16:9、9:16、正方形、4:5）、旋转或镜像、加快或放慢，修改亮度、对比度和颜色，淡入淡出，去掉声音或调整音量，在上面加文字（标题、字幕）并配上背景音乐；或者把它做成 GIF，或把某一帧存为图片。免费，需要这台电脑上有 ffmpeg（图片工具会带一个），并且 **允许智能体生成视频** 处于开启状态。

每一项都可以从会话文件夹里的文件开始，也可以从某套幻灯片、某份文档或某个页面中已有的图片或视频开始，做出的东西保存在会话的 **images** 文件夹中（编辑过的视频保存在 **videos** 中），绝不会覆盖原件。你资料库里的图片也可以编辑，并放回原处，或者作为一张新图片放在它旁边，就像图片编辑器的 **保存** 和 **另存副本** 那样（“把我资料库里那张港口的照片调亮一点”）。它会像智能体生成的图片一样和回复一起显示，处理期间占位框会显示“正在去掉背景”“正在擦除”“正在编辑图片”或“正在编辑视频”。对于抠图或擦除，回复会说明它是用哪种方式做的，以及为什么：如果效果不对，说“用 AI 来做”，智能体就会交给图像模型。要自己动手，就在编辑器中打开这张图片或这段视频（[编辑图片和视频](/guide/library#edit-pictures-and-videos)）。

## 请智能体生成视频

描述场景、什么在动以及怎么动、镜头（“缓慢推近”“跟着骑车的人走”）、风格和光线，以及任何声音或说出的话。智能体还可以：

- **从图片开始**：用一个图片文件作为视频的第一帧（“让这张照片动起来”），有些模型还可以再给一张作为结尾；适用于带 **从图片开始** 标签的模型；
- **参照图片**：最多 4 张人物、产品或风格的图片，让视频与它们保持一致，但它们不会成为视频的画面；
- **修改视频**：一个视频文件（MP4、WebM 或 MOV，最大 40 MB），交给带 **视频编辑** 标签的模型来编辑、延长或让画面更清晰。

生成一段视频需要不到一分钟到几分钟。智能体会等它，最多约九分钟；用时更长时，应用会继续跟进，等视频做好就保存下来，智能体再次查看时就会把它显示出来。等待不会多花钱。

视频会保存在会话文件夹里的 **videos** 文件夹中，按视频的内容命名。

在对话中：

- 模型工作时，会有一个按视频形状显示的占位框，写着“正在生成视频”和已用的时间。
- 然后视频会和回复一起显示，可以直接播放（也可以用它的控制按钮全屏播放），下方是描述、模型名称和 **保存到资料库**。鼠标指向视频时，上面会出现 **编辑**（视频编辑器：你保存的东西会放进你的资料库）、**在文件中显示**、**下载** 和 **更多**（⋯）。
- “仍在生成中”表示智能体在视频做好之前就不再等了：智能体再次查看时它就会显示（如果智能体没有去查看，就请它去看看）。“这次没有生成视频”会给出原因：你关闭了表单，或者模型拒绝了（它的话会说明原因）。

## 请智能体生成音乐、语音或声音

告诉智能体你想听到什么：

- **音乐**：曲风和情绪、乐器、节奏、演唱的声音以及歌曲的结构（“一首 2 分钟的欢快合成器流行歌，讲星期一早上，女声演唱，副歌朗朗上口”）。可以给出你自己的歌词，也可以让模型来写；不想要演唱时，就要一首纯音乐。Lyria 3 Clip 总是生成 30 秒；Lyria 3 Pro 最长约 3 分钟，你要多长就多长。一首歌需要一两分钟。
- **配音**：要说的原话，以及它应该怎么说（“用平静、低沉的声音慢慢读”）。如果模型有自带的声音，你可以在表单上选一个；Seed Audio 会生成你描述的声音。几个人之间的对话也可以（“一段由两位主持人主持的简短播客开场”），适用于能为多个说话人配音的模型。
- **从录音复制的声音**：给智能体 1 到 3 段这个声音的录音，即这台电脑上的文件（WAV、MP3、M4A、OGG 或 FLAC，每个最大 30 MB；每段只用前 30 秒），交给带 **复制声音** 标签的模型（Seed Audio）。只使用你有权使用的声音：你自己的，或者声音的主人同意过的。电脑上有 ffmpeg 时，以上任何一种文件都可以；没有时，只能用 WAV 和 MP3。
- **音效或环境声**：它是什么、发生了什么以及什么时候发生（“大雨打在铁皮屋顶上，最后雷声滚滚而来，没有人声”），以及要多长。
- **换一个模型** 来生成某一段声音：说出它的名字就行（“用 ElevenLabs v3 来读”），不用改设置。

声音会保存在会话文件夹里的 **audio** 文件夹中，按声音的内容命名，格式是 MP3（你要求时为 WAV）。

在对话中：

- 模型工作时，会有一张卡片写着“正在生成音乐”“正在生成配音”或“正在生成声音”，以及已用的时间。
- 然后声音会和回复一起显示在一个播放器里：圆形按钮用来播放和暂停（同一时间只播放一段声音），它的波形就是进度条，可以点击或拖动，然后是时间和语速（**1×**、**1.25×**、**1.5×**、**2×** 或 **0.75×**）。播放器有焦点时，空格键或 K 键播放和暂停，← → 前后移动 5 秒。它的标题来自文件名，旁边是 **在文件中显示**、**下载** 和 **更多**（⋯）。下方是生成它所用的描述、模型名称和 **保存到资料库**（见[保存智能体做的东西](#keep-what-an-agent-made)）；歌曲的 **歌词** 可以在下面展开。
- 没有 OpenRouter 密钥时，你会看到“生成音频需要 OpenRouter 密钥”，以及 **添加 OpenRouter 密钥**。“这次没有生成声音”会给出原因：你关闭了表单，或者模型拒绝了（它的话会说明原因）。

智能体听不到它做出来的东西：它只知道自己要求的是什么。如果听起来不对，说说要改什么，它会再做一个。

## 智能体所做内容中的图片

智能体为你制作或修改幻灯片、文档或页面时，会像设计师那样，在图片能增色的地方（标题幻灯片、某一节、某个想法；并不是每张幻灯片都配）自己配上插图，用它们的颜色和风格：背景、纹理或图标用“快速”图片，场景、照片或示意图用“最佳”图片，必须保持清晰的图标、标志或示意图用绘图，数字用数据图，真实的地方和东西用免费照片，并对用到的图片做抠图、擦除或编辑，让它们放得合适。它既能用你打开的内容中已有的图片，也能用文件；你要求时，它还会为一套幻灯片中每张没有描述的图片写上描述，给看不到图片的人（由为你资料库图片撰写说明的那个模型来写）。要花钱的东西，在生成之前都会在表单上标出价格（[生成之前先确认设置](#check-the-settings-before-anything-is-made)）；你不想这样时，就说“不要图片”或“只用免费照片”。

当你按名称要一种常见的东西时（SWOT 分析幻灯片、融资路演、求职信、执行摘要、习惯打卡、价格表、预算），智能体会先读一读应用是怎样把这类东西做好的：里面放什么、按什么顺序、看起来什么样、哪里配图有帮助，和类型库中各种类型的做法一样（[按类型用 AI 制作](/guide/library#made-with-ai-from-a-kind)）。这不花任何钱。

在[保密会话](/guide/sessions#keep-a-session-confidential)中，这些都没有：它的智能体不会生成、查找或编辑任何图片或视频。

## 保存智能体做的东西

智能体生成的图片、视频或声音下方的 **保存到资料库**，会把它的一份副本保存到你的[资料库](/guide/library#images-and-videos-in-the-library)：模型会在那里为它撰写标题和说明（声音没有模型能听，就根据生成它所用的内容来写），即使会话的文件夹被清理了，它也会留在那里。之后按钮会显示 **已在你的资料库中**，点击它就会在资料库中打开它。

## 用听写输入消息

消息框里的麦克风（在开始页和每个会话中都有）会把你说的话转成文字，放进你的消息里。不会自动发送任何东西：你检查一遍后，像平常一样发送。

1. 点击或轻点麦克风。
2. 说话。消息框上方的面板会显示时间、目前听到的话（如果由服务器识别语音，则显示“正在录音…”和随你的声音起伏的音量条），以及它正在听的语言。
3. 点击 **完成**，或者再点一次麦克风。这些话会接在你已经写好的内容后面（如果由服务器识别，会先短暂显示“正在把你的话转成文字…”）。

面板上的语言标签（“DE”“PT-BR”）可以在你说话时切换语言；它会接着用新的语言识别。由服务器识别语音时，录音会在 10 分钟后自动停止。

麦克风只在听写能用的地方显示：浏览器自己能识别语音时（Chrome、Edge、Safari），或者服务器能识别时（见[服务器端语音识别](/guide/documents-voice#speech-recognition-on-the-server)）。无法开始时，它会说明原因和该怎么做：

- **麦克风需要安全连接**：浏览器只允许在 HTTPS 地址上使用麦克风，或者在电脑本机上通过 localhost 使用。请通过 HTTPS 地址打开 Hydor（见[手机、其他机器和分享](/guide/devices)）。
- **此网站的麦克风权限已被阻止**：在浏览器的网站设置中允许它（在 iPhone 上：轻点地址栏中的 **aA**，然后选择 **网站设置 → 麦克风**），然后重试。
- **未找到麦克风**，或者 **麦克风正被占用**（另一个应用正在使用它）。
- **此处的语音识别已关闭**：在 iPhone 上，到“设置 → 通用 → 键盘”中开启“听写”；或者让服务器来识别语音。
- **此浏览器无法录音**：请使用新版的 Chrome、Edge、Firefox 或 Safari。

每条提示都有一个 **语音设置** 按钮，会打开“设置 → 语音”。

## 设置语音

所有与语音有关的设置都在 **[设置 → 功能 → 语音](/settings?s=voice)** 中（在手机上：打开设置，然后点 **语音**）。它分为三部分。

### 听写

**[听写](/settings?s=voice&find=Dictation)** 首先说明这个浏览器能做什么：

- 自己能识别语音的浏览器会在你说话时显示你的话。为此它可能会把你的语音发送给它的开发商（Chrome 发给 Google，Safari 发给 Apple）。要让你的语音留在自己的机器上，请在下面开启 whisper.cpp，并选择服务器。
- 自己不能识别语音的浏览器，会在服务器端语音识别开启后，通过服务器来听写。

然后：

- **[你说的语言](/settings?s=voice&find=Language%20you%20speak)**：**与此浏览器相同**，或者 56 种语言和地区中的一种。听写会按这个语言来听，免提模式也用它来说和听。
- **识别方式**：**此浏览器**（边说边显示文字）或 **服务器**（用 whisper.cpp 时不外传语音；停下来后文字才出现）。只有两者都可用时才会显示。

语言和 **识别方式** 保存在这个浏览器中，所以你的每台设备各有各的设置。

### 服务器端语音识别

**[服务器端语音识别](/settings?s=voice&find=Speech%20recognition%20on%20the%20server)** 适用于自己不能识别语音的浏览器，或者用来让你的语音留在自己的机器上。在你开启之前它是关闭的，开启之前也不会下载任何东西。它对整个应用只设置一次，在每台设备上都生效。三选一：

- **关闭**。
- **在本机**：whisper.cpp 在运行 Hydor 的电脑上、用它的处理器运行，你的语音留在那里。
  - **模型**：**极小**（74 MB；最快，偶尔会听错一个词）、**基础**（141 MB；速度快，对大多数听写来说足够好，默认选项）、**小**（465 MB；听得更准，在 CPU 上每句话需要几秒钟）或 **中等**（1.4 GB；听得最准，没有快速的 CPU 会很慢）。
  - **语言**：**任意语言**（跟随你说的语言）或 **仅英语**（英语会更准确一点）。
  - **开启 · 下载 …** 会说明要下载多少：模型，以及第一次时的 whisper.cpp 本身（如果所有东西都已经就位，选择 **在本机** 会立即开启）。进度条显示下载进度；**取消** 会停止下载，并关闭服务器端语音识别。在 Linux 上，应用会下载现成的 whisper.cpp；在它无法运行的地方，应用会在这台电脑上编译 whisper.cpp，这需要 C++ 编译器（在 Debian 或 Ubuntu 上：`sudo apt install build-essential cmake`）。如果这台电脑上已经有你自己的 whisper.cpp（比如为你的 GPU 编译的版本），会直接使用它。
  - 准备好后：“就绪：whisper.cpp …，使用基础模型，在这台机器的处理器上运行。你的语音只留在这里。” **测试** 会检查它是否响应，以及速度如何。如果出了问题，会显示原因和 **重试**。
  - 开启状态下选择另一个模型，会下载那个模型。
- **外部服务**：任何提供 OpenAI 语音转文字地址（`/audio/transcriptions`）的服务：OpenAI 本身，或者你网络上的服务器（Speaches、LocalAI、whisper.cpp 的服务器、运行在 GPU 上的服务器）。录音会发送给它。
  - **地址**（例如 `https://api.openai.com/v1`）、**API 密钥**（你网络上的大多数服务器都不需要）和 **模型**（除非你另行指定，否则为 `whisper-1`）。
  - **保存并开启**（之后变为 **保存**）、**测试**，以及保存密钥后出现的 **移除密钥**。服务保存过之后，再次选择 **外部服务** 会立即切换过去。

在 **本机 · …** 下方，这一部分会列出 whisper.cpp 在这台电脑上留下的东西：whisper.cpp 本身，以及每个模型和它的大小，正在用的那个标着“使用中”。模型旁边的垃圾桶图标会删除它（删除正在用的那个，会在你确认后关闭服务器端语音识别）。**全部移除** 会删除 whisper.cpp 及其模型；它在服务器端语音识别关闭或使用外部服务时显示。

### 朗读

**[朗读](/settings?s=voice&find=Read%20aloud)**：“回复上的扬声器会把它读给你听，跳过其中的代码。每个浏览器各自保存自己的语音和语速。”

- **语音**：**自动**（浏览器为你所说语言提供的语音），或者这个浏览器拥有的任何语音，你的语言的语音排在前面。每个语音都会注明它的语言，需要联网的会标注“在线”。
- **语速**：从 0.5× 到 2×。
- **试一试**：**播放示例** 会用该语音和语速读一句话。

如果浏览器不能朗读文字，这一部分会说明。

## 让回复朗读出来

1. 指向一条回复：它的右上角、复制按钮旁边会出现一个扬声器。
2. 点击它。消息框上方的横条会显示 **正在朗读**、读到第几部分（共几部分）以及回复开头的几个字。
3. 在横条上暂停和继续，或者在那里停止，也可以用扬声器停止。

它会把回复当作普通文字来读：跳过代码，链接读它的文字，网址读它的网站名，表格逐行读。开始朗读另一条回复会停止前一条，离开对话也会停止。用鼠标指向时才会显示扬声器；在手机上，免提模式会把回复读给你听（“把回答读给我听”）。

## 免提与应用对话

免提模式适合你没法看屏幕的时候，比如走路时：你说话，应用去做，然后告诉你它做了什么，再接着听。它可以开始会话、把你的话转给会话、告诉你它们进展如何、回答它们的批准请求，并把结果读给你听。

### 开始和结束

- 在会话中，消息框里的耳机按钮（**免提**，在麦克风旁边）会打开它，并跟随这个会话。
- 在开始页，同一个按钮会打开它，此时不特别跟随哪个会话。
- 在搜索框（Ctrl+K，Mac 上为 ⌘K）中，**免提对话** 操作也能打开它。

它会占满屏幕，说“我在听”，并在打开期间请求设备保持屏幕常亮。顶部显示它跟随的会话（或“和 Hydor 对话”）。大圆形按钮显示它正在做什么：**正在聆听…**、**正在处理…**、**正在说话** 或 **已暂停：轻点开始聆听**。按钮下方是它听到的话（加引号显示）和它的回答。

- 它说话时轻点圆形按钮可以打断它；其他时候轻点可以暂停或继续聆听。
- 要结束，说“再见”（或“拜拜”“结束”“结束免提”，也可以用英文说“Goodbye”“Bye”“That's all”“Stop listening”“End hands-free”“Exit”），或者轻点右上角的叉号。

### 你可以说什么

- **开始会话**：“开一个会话，帮我规划在克里特岛的周末”。它会像开始页那样开始会话：使用你上次在那里选的智能体、模型、思考强度、权限、助手和项目，放在一个新的任务文件夹里（或你上次在那里选的文件夹里）。从那以后它就跟随这个会话。
- **告诉会话一些事**：“让它用公制单位”。这些话会作为你的消息，发给它跟随的会话。
- **询问进展**：“我的会话进展如何？”它会告诉你哪些正在工作、哪些需要你以及它们在问什么，还有最近完成了什么。
- **听结果**：“把回答读给我听”。它会说出它跟随的会话的最新回复（如果没有跟随任何会话，则是最忙或最近的会话的回复）。长回复会以要点的形式说出，三到五句话；当应用以英语以外的语言显示时，每条回复都会用那种语言说出要点。
- **回答批准请求**：“批准”或“拒绝”，前提是它跟随的会话（如果没有跟随任何会话，则是任意一个会话）正在等一个简单的是或否。问题、计划或表单必须在屏幕上回答，它会这样告诉你。
- **停止工作**：“停下”会停止它跟随的会话正在做的事（不会结束免提模式）。
- **切换**：说出另一个会话（“我们聊聊克里特岛之行吧”），它就会改为跟随那个会话。
- 询问关于应用的问题，或者其他任何事：它会简短回答，不确定时会反问你。

### 它会主动告诉你什么

- 它跟随的会话完成时：“…… 已完成。说‘读给我听’就能听到回答。”
- 任何会话需要你时：“……需要你：……”，然后对简单的是或否说“请说批准或拒绝”，否则说“请在屏幕上回答”。之后它会跟随那个会话，所以说“批准”就能回答它。
- 任何会话因出错而停止时：“…… 因出错而停止。”

它会停止聆听来说这些话，然后再接着听。你其他机器上的会话不会播报。

### 须知

- 由辅助模型来理解你说的话（[设置 → 智能体 → 模型 → 辅助模型](/settings?s=models&find=Helper%20model)）。如果连不上它，一些简单的英文词仍然管用：“status”、“approve”或“yes”、“deny”或“no”、“stop”、“read”、“start …”；其他任何话都会发给它跟随的会话，如果它没有跟随任何会话，就会开始一个新会话。
- 它用应用显示的语言回答（设置 → 通用 → 语言），用你说的语言聆听（设置 → 语音），没有设置时则用应用的语言。
- 它用[朗读](/guide/documents-voice#read-aloud)中设置的语音和语速说话。
- 它需要一个能朗读的浏览器，以及一种聆听方式：浏览器自带的语音识别（Chrome、Edge、Safari），或者服务器端语音识别。耳机按钮只在它能工作的地方显示。使用服务器识别时，你说的每句话在安静一秒半后结束（最长半分钟），沉默 15 秒后它会重新开始聆听。
- 如果麦克风没有被允许，或者根本没有麦克风，它会说一次并暂停：在浏览器中允许麦克风，然后轻点开始聆听。
