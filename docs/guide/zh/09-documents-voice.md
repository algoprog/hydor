# 文档、图片、视频和语音

Hydor 中的智能体可以读取 PDF、Word、Excel、PowerPoint 和其他文档，为你生成新的文档，并以卡片的形式交给你，供你打开或下载；它们还可以生成图片、绘图、统计图和短视频，查找免费照片，修改你的图片和视频（裁剪、抠图、擦除、剪辑），还能借助图像、视频和音频模型以及这台电脑上的工具创作歌曲、配音和音效，你也可以把它们的成果保存在项目的文件中。此外，你可以用说话代替打字，让智能体把回复朗读出来，或者在走路时免提地与应用对话。

![一个智能体读完一份报告后，生成了一页的 Word 摘要和一个带图表的电子表格](images/documents-voice.webp)

## 给智能体一份文档来读

应用运行的每个智能体都能读取文档：Claude Code、Codex、Custom，以及支持 ACP 并接入 MCP 服务器的智能体。你无需事先转换任何格式。可以用下面几种方式把文档交给它：

1. **附加到消息中**：点击消息框里的回形针（**附加文件**），或者把文件拖到消息框上，或者直接粘贴。图片会以图片的形式发给模型；其他文件会保存在运行 Hydor 的那台电脑上，并把它的路径添加到你的消息中，这样智能体就能打开它。每条消息最多可携带 25 MB 的文件。
2. **指明这台电脑上的某个文件**：“总结一下 ~/Documents/lease.pdf”。不以 `/` 或 `~` 开头的路径，从会话所在的文件夹开始算起。
3. **把文档放在项目或共享知识中**，这样会话就能搜索它们并引用具体页码：参见 [项目与知识](/guide/projects)。

智能体读取时，它的工作记录会先显示 **Reading lease.pdf**，随后显示 **Read lease.pdf**。在较宽的屏幕上，这一行还会说明文档是什么（类型、页数、工作表数或幻灯片数）以及读取了哪些行。点击这一行可以查看智能体拿到的文本，点击 **Open lease.pdf** 可以查看文件本身。

较长的文档会分段读取，每次约 1,200 行，还有更多内容时会告知智能体。智能体会被告知，要把文档里的话当作信息，而不是指令。文档中的任何内容都不会被执行：宏永远不会运行，只会保留网页链接和邮件链接。

Custom 也可以通过普通的文件读取功能来读取 PDF、Office 文档和图片：参见 [Custom，应用自带的智能体](/guide/custom)。

## 智能体能读取文档中的哪些内容

### PDF

- 每一页的文本，排版与页面上一致。
- 配合 pdftotext 程序（属于 poppler-utils）效果最好。没有它时，应用会下载一次 pdf.js（约 35 MB，第一次需要联网），此时排版只是大致还原。
- 扫描页没有文本，智能体会被告知是哪几页（“Pages 3, 5–7 have no text”）。借助 **pdf** 技能，它会把这些页面当作图片来查看并自行阅读，如果装有 tesseract，也可以对它们运行 OCR。
- 用密码锁定的 PDF 无法读取。把密码告诉智能体，**pdf** 技能就会生成一份解除锁定的副本。无需密码即可打开、但限制修改的 PDF（许多官方表格）可以像其他 PDF 一样正常读取。
- **表单**：智能体会列出 PDF 的表单字段，并附上字段旁边印着的文字（这些文字能说明名为“f1_02”的字段是做什么用的），还会把页面当作图片来查看，图片上标有字段编号和以点为单位的标尺。
- **你的高亮和备注**：你在文件阅读器中标出的高亮，按页整理，附有你的备注，以及你所选的图表和公式的图片（[阅读并高亮 PDF](/guide/files-git#read-and-highlight-a-pdf)），可用来总结它们，或对照论文核对。你提出要求时，它也能替你高亮文字，这些高亮随后会显示在阅读器中。

### Word、Excel 和 PowerPoint

- **Word**（.docx，以及它的宏和模板类型）：标题、段落、编号列表和项目符号列表、表格、链接、文本框、按描述读取的图片、脚注、尾注和批注。
- **Excel**（.xlsx，以及它的宏和模板类型）：每个工作表都以表格形式呈现，带有行号和列字母，数字大致按设定的格式显示（日期、百分比、金额），每个工作表最多读取 40 个公式。隐藏的工作表会有标记。每个工作表读取前 2,000 行和 60 列，还有更多内容时会告知智能体；要读取更大工作表的全部内容，**电子表格**技能会用另一种方式加载它。
- **PowerPoint**（.pptx，以及它的宏、模板和放映类型）：每张幻灯片的标题、文本、表格、图片（按描述）、图表（标题和数据系列）以及演讲者备注。隐藏的幻灯片会有标记。最多 1,000 张幻灯片。

### OpenDocument、EPUB、CSV 和 RTF

- **OpenDocument**（LibreOffice 自有的 .odt、.ods 和 .odp，它们的模板，以及 .odg）：带标题、列表、表格、链接和脚注的文本；按显示效果读取的工作表；带标题、文本和备注的幻灯片。
- **EPUB** 图书：按阅读顺序排列的章节，带标题、列表、表格和引文。
- **CSV** 和 **TSV** 表格，以及 **RTF** 文本。

### 旧版 Office 文件、加锁文件和超大文件

- 旧版 .doc、.xls 和 .ppt 文件通过 LibreOffice 读取，LibreOffice 会先把它们转换成当前的格式。没有 LibreOffice 就无法读取，智能体会被告知请你提供另存为 .docx、.xlsx 或 .pptx 的文件，或者请你安装 LibreOffice。
- 用密码锁定的 Word、Excel 和 PowerPoint 文件无法读取。
- 最大 300 MB 的文件都可以读取。一份文档最多提供约 1,000,000 个字符的文本（约 250,000 个 token）；超出部分会被截断，并告知智能体。

## 让智能体制作文档

应用自带四个文档技能，每个智能体都可以加载：**word-documents**、**spreadsheets**、**presentations** 和 **pdf**。你可以在 [设置 → 技能](/settings?s=skills&find=Built%20in) 的 **文档** 下找到它们（参见 [技能](/guide/skills)）。你不需要自己挑选：直接用平常的话提要求就行（“根据我的笔记，用 Word 文档做一份一页的简历”“把这些开支放进电子表格，附上每月合计和一个图表”“为我关于蜜蜂的演讲做 8 张幻灯片”“把这三个 PDF 合并起来”），智能体会在任务需要时加载合适的技能。

每个技能的工作方式都一样：

1. 智能体先规划文档：它的大纲、工作表或幻灯片。
2. 它在会话所在的文件夹中用一段简短的脚本写出文件。
3. 它把结果当作页面图片来查看，检查有没有文字超出页面、表格放不下、幻灯片过于拥挤，并修正有问题的地方。
4. 它把文件以卡片的形式放在回复下方交给你，并附上一句简短的说明（参见 [打开或下载智能体生成的文件](/guide/documents-voice#open-or-download-the-files-an-agent-made)）。

当它修改你的文件时，会把结果保存为新的文件名，除非你要求它覆盖原文件。

### Word 文档

报告、信函、简历、备忘录、合同、表格、讲义和笔记，可在 Word、Google 文档或 Pages 中打开。

- 真实的结构：标题（可用于 Word 的导航窗格和屏幕阅读器）、项目符号列表和编号列表、带表头行的表格、图片和分页符。
- 目录（文件打开时由 Word 自动填充）、页码（“第 1 页，共 3 页”）、链接和带底纹的表格单元格。
- A4 或 US Letter 纸张，以及在任何电脑上看起来都一样的字体（Calibri、Arial、Cambria、Times New Roman）。
- 直接修改你自己的文档，保留其样式、页眉和版式；替换文字时不丢失格式；可以添加批注。
- 使用你保存的签名签署：替换 {{signature}}，或紧跟在“签名：”之类的文字后面，放在表格的单元格中或文末，需要你先在卡片上允许（[签名](/guide/library#signatures)）。
- 也可以通过 LibreOffice 生成它的 PDF。

### 电子表格

预算表、跟踪表、日程表、发票和数据表（.xlsx）。

- 你的数字作为数值，结果作为公式，这样你改动一个数字，其余部分就会随之更新。
- 金额、百分比和日期的数字格式；始终保持可见的加粗表头行；列宽；列表筛选。
- 数据旁边的柱状图、折线图和饼图。
- 对每个公式进行检查。装有 LibreOffice 时，检查会计算这些公式并列出所有错误（#REF!、#DIV/0!、#NAME?），随后由智能体修正。
- 修改你自己的工作簿时，会保留其中的公式、样式和大部分版式（数据透视表不会保留，图表只有在智能体重新构建时才会保留）。如果你要求，也可以改为生成 CSV 文件。

### 演示文稿

路演材料、演讲、课程和总结（.pptx），可在 PowerPoint、Keynote 或 Google 幻灯片中放映。

- 整洁的 16:9 幻灯片，整体风格统一，并采用你的品牌色：标题页、带层级的要点、双栏、适配幻灯片大小的图片、表格、图表（柱形、条形、折线、饼图、堆叠）、章节页，以及供你演讲时参考的演讲者备注。
- 每张幻灯片只讲一个观点，标题直接点明要点（“销售额增长了 12%”），一场演讲通常 6 到 12 张幻灯片。
- 图片可以来自你、来自网络，或由图像模型生成（参见 [让智能体生成图片](/guide/documents-voice#let-agents-make-images)）。
- 基于你自己的模板制作新的演示文稿，或修改你的演示文稿并保留其主题和版式。
- 通过 LibreOffice 生成幻灯片的 PDF。

### PDF

报告、发票、证书、传单、信函和表格。

- 以文字为主，或者你之后还想编辑的内容：智能体先制作 Word 文档，再用 LibreOffice 把它转成 PDF。
- 需要精确排版的内容（发票、证书、票券、表格）：它直接绘制 PDF。
- 把幻灯片或电子表格做成 PDF：先用对应的技能制作，再转成 PDF。
- **填写表单**：按名称填写表单字段（文本、勾选、选项，支持希腊文、中文或任何文字），因此任何阅读器都能显示，并且仍可在其中修改；或者，对于只有印刷线条和方框的表单，把文字写在页面上印刷文字（“出生日期：”）的旁边，并在方框中打勾；对于扫描件，由于没有文字可供查找，智能体会在页面图片中找出空白处。智能体会向你询问它不知道的信息，并查看前后的页面。只填写字段的话，经过数字签名的表单仍然有效。XFA 表单（Adobe LiveCycle）只能在 Adobe 自己的应用中填写：智能体会这样告知你，但仍然可以在它们的页面上书写。
- **在页面上书写**：文字、对勾和叉号、图片、盖在原有内容上的白色方框（它们只是在视觉上遮住文字：文字仍留在文件里，所以这不算涂黑删除）、轮廓和线条，以及作为 PDF 自身内容的高亮和批注，其他阅读器会列出这些内容，也可以将其移除。
- **修改页面**：旋转、删除、移动、插入空白页、合并 PDF、把部分页面提取成单独的文件，或把一个文件拆分成多个。这样修改过的文件无法保留数字签名，智能体会告知你这一点。
- 智能体写入的内容会放在文件旁边的一份副本中（“name (filled).pdf”），除非你要求直接修改原文件；这时它的旧版本会进入废纸篓。你也可以自己填写并签署 PDF：[填写并签署 PDF](/guide/files-git#fill-in-and-sign-a-pdf)。
- 借助 **pdf** 技能，可以在每一页上加上 DRAFT 之类的大号淡色文字，也可以生成一份去掉密码的副本（密码由你提供）。
- 使用你保存的签名签署，放在页面上某些文字旁边，或放在它事先给你看的位置，需要你先在卡片上允许；添加后不会改变 PDF 原有的内容（[签名](/guide/library#signatures)）。
- 把 Office 文件转成 PDF。

### 电脑需要具备什么

这些要求针对的是运行 Hydor 的那台电脑，而不是你用来访问它的设备。

- **Python 3**，并带有 venv 模块：制作文档时需要。第一次使用时，这些技能会把几个处理 Office 文件和 PDF 的 Python 库安装到应用的专用文件夹中（约 30 MB，只需一次，需要联网）；不会安装任何系统级的内容。如果缺少 Python，智能体会告诉你只需运行的那一条命令（在 Debian 或 Ubuntu 上是 `sudo apt install python3 python3-venv`；在 Mac 上是 `brew install python`）。
- **LibreOffice**（可选）：在文件查看器中以排好版的页面预览、读取旧版 .doc、.xls 和 .ppt 文件、让智能体以页面形式查看 Office 文档、检查公式，以及把 Office 文件转成 PDF。在 Debian 或 Ubuntu 上：`sudo apt install libreoffice-writer-nogui libreoffice-calc-nogui libreoffice-impress-nogui`；在 Mac 上：`brew install --cask libreoffice`。
- **poppler-utils**（可选）：最佳的 PDF 读取效果，并为智能体和 **填写和签名** 提供 PDF 页面的图片。没有它时，应用会用这台电脑自带的功能来绘制（Mac 或 Windows 自带的 PDF 绘制方式），或者使用 **设置 → 浏览器** 中的浏览器。在 Debian 或 Ubuntu 上：`sudo apt install poppler-utils`；在 Mac 上：`brew install poppler`。
- **tesseract**（可选）：用于扫描版 PDF 的 OCR。

没有 LibreOffice 或 poppler-utils 时，智能体会把文件当作文本重新读取来检查，并保持简单的版式。

## 打开或下载智能体生成的文件

当智能体为你生成了文件（文档、电子表格、幻灯片、PDF、图片、压缩包）时，会把它们以卡片的形式放在回复下方，一次最多 12 个。每张卡片包含：

- 按类型显示的图标及其颜色（Word 为蓝色，Excel 为绿色，PowerPoint 为橙色，PDF 为红色），图片则显示为小图；
- 文件名、文件类型和大小（“Word 文档 · 24 KB”）；
- 智能体写的说明（“预算表，每个季度一张工作表”）；
- **打开**、下载按钮和**更多**（⋯）。

**打开**会在对话上方的窗口中用文件查看器显示该文件，对话仍停留在原处（在手机上，窗口会从屏幕底部升起）。窗口顶部的**在“文件”中打开**会把文件带到“文件”页面；点击叉号或按 Escape 可关闭窗口。文件上方会显示它的路径，与“文件”页面一样（[打开和编辑文件](/guide/files-git#open-and-edit-a-file)）；点击路径中的文件夹会在同一窗口中打开该文件夹，并选中这个文件（如果有未保存的更改，会先询问你），窗口顶部的 **‹** 可返回到文件。下载按钮会把文件保存到你的设备上。

卡片上和窗口顶部的**更多**（⋯）中有：**用它开始会话**（打开开始页面，文件已放在消息框里）、**添加到项目**（把文件复制到某个项目的文件夹中）、**保留一份副本**（针对 Jupyter 笔记本、PowerPoint 演示文稿、Word 或 Markdown 文档、电子表格或 LaTeX 文件：副本会作为独立的文档保存，用它自己的编辑器打开；如果你有项目，则保存在你所选项目的文件中，否则保存在会话的首个位置）、**在“文件”中显示**（在卡片上）、**在访达中显示**、**在文件资源管理器中显示**或**在文件夹中显示**（在桌面应用中；参见[处理文件和文件夹](/guide/files-git#work-with-files-and-folders)），以及**复制路径**。参见[用文件开始会话](/guide/files-git#start-a-session-with-files)和[向项目添加文件](/guide/files-git#add-files-to-a-project)。

之后被删除或移动的文件会显示为**已不存在**。如果智能体提到的文件并不存在，你会看到“Could not show the files”及原因，同时智能体会被告知去修正。

### 智能体生成或修改的文档，以及回复中的文件名

在智能体回复的下方，它在该轮中生成或修改的文档每次都会显示为卡片，无论它是否已将其交给你：PDF、Word、Excel、PowerPoint 和 OpenDocument 文件，CSV 和 TSV 表格，LaTeX，Jupyter 笔记本，EPUB 和 Markdown。这些文件包括它的编辑所写入的文件，以及它的命令在该轮运行期间于会话文件夹中生成的文件（即该轮中提到的文件，或位于它修改过的文件旁边的文件：在同一文件夹中工作的其他会话所生成的文件不会计入）。

- 每张卡片都标有**新增**或**已更新**，并显示其类型和大小，还有**打开**、下载按钮和 **⋯**，与上面的卡片相同。
- 成品文档（PDF、Word 文件等）排在其源文件（LaTeX、Markdown、表格）之前。前四个会直接显示；**Show N more documents** 会显示其余的，**收起**则再次折叠。
- 智能体已交给你的文件保留它自己的卡片和说明，不会重复显示。已不存在的文件会被省略。图片、代码和数据文件不会以这种方式显示（智能体仍会把图片交给你）。

回复中的文件名和路径都是链接。代码中的文件名或路径（`report.tex`、`docs/report.pdf`、`src/app.ts:42`，后者会在该行打开）、文本中的绝对路径或 `~/` 路径，以及指向文件的链接，都会像卡片上的**打开**一样，在对话上方的窗口中打开文件。单独的文件名会打开该对话中同名的文件；不是从顶层开始的路径则相对于会话的文件夹。

## 在文件查看器中预览文档

文件查看器可以显示来自卡片、“文件”页面或回复中链接的文档（参见[系统：文件、Git、终端和预览](/guide/files-git)）。

- **PDF** 按原样显示，使用浏览器自带的 PDF 视图，并有**填写和签名**，可用来填写并签署文件（[填写并签署 PDF](/guide/files-git#fill-in-and-sign-a-pdf)）。
- **PowerPoint** 文件（.pptx，以及它的宏、放映和模板类型）会在**幻灯片**中打开：“应用绘制出的幻灯片”。每张幻灯片都按其本来的样子显示，就像已保留的演示文稿那样（图片、形状、表格、图表、背景和页脚都在原位），一张接一张地向下排列，并带有编号和演讲者备注，手机上也是如此。如果演示文稿用到的某种字体在这台电脑上没有，会用另一种字体代替；如果代替的字体需要更多空间，文本框中的文字会稍微缩小以适应，因此不会被截断。**文本**（“它的文字和演讲者备注”）显示幻灯片中的文字，**页面**则在已安装 LibreOffice 时显示由它排版后的幻灯片。如果无法绘制幻灯片，查看器会在**文本**中打开并说明原因。
- **Word、Excel、PowerPoint、OpenDocument、EPUB 和 RTF** 文件（旧的 .doc、.xls 和 .ppt 也一样）会显示为预览。安装了 LibreOffice 后，顶部的开关提供两种视图：
  - **页面**：“按 LibreOffice 的排版”，每一页都如同打印出来的样子。第一次需要稍等片刻（“Laying out the pages…”）；之后在文件改动之前，页面都会立即打开。
  - **文本**：“它的文本、工作表和幻灯片”，即应用所读取到的内容。文本文档显示为一页纸；工作簿显示为带有列字母、行号的网格，底部为每个工作表设一个标签（隐藏的工作表用带斜线的眼睛标记）；幻灯片显示为卡片，每张带有编号，下方是演讲者备注。图片显示为带有其描述的方框。当有内容被省略时，顶部会有一行提示（“Shows the first 1000 rows”）。
- 未安装 LibreOffice 时，只有**文本**视图。EPUB 图书始终在其中打开。
- 在手机上，预览会在**文本**中打开（PowerPoint 文件则在**幻灯片**中），这在小屏幕上滚动和缩放都更方便；开关可切换到页面视图。

如果 LibreOffice 无法排版某个文件，查看器会告知，而它的文字仍可在**文本**中查看。没有预览的文件会显示“No preview for this file”：请下载后在你的设备上打开。查看器的下载按钮始终可用。

## 允许智能体生成图片

向任何智能体要一张图片（“给我的面包店做个标志”“把这张照片变成水彩画”），它会通过 OpenRouter 使用图像模型生成，保存在会话的文件夹中，并随回复一起显示。在 **[设置 → 功能 → 图片、视频和音频](/settings?s=images)** 中进行配置（在手机上：设置，然后是**图片、视频和音频**）。

- **[生成图片](/settings?s=images&find=Making%20images)**：位于该分组标题旁的开关**允许智能体生成图片**，会为每个智能体提供图片相关的工具：生成图片、绘图和图表，以及去除图片背景或擦除图片的一部分。除非你关闭，否则它默认开启；关闭后，不会再向智能体提供这些工具。
- **OpenRouter 密钥**：图像、视频和音频模型都通过 OpenRouter 调用，每张图片、每段视频或每段声音都用你的 OpenRouter 密钥付费。没有密钥时，这一部分会提示，并给出**在 openrouter.ai 获取**和**添加密钥**，后者会打开 [设置 → 智能体 → 模型 → OpenRouter](/settings?s=models&find=OpenRouter)，密钥就填在那里（参见[智能体、账户和模型](/guide/agents-models)）。需要密钥的智能体会改为在卡片上向你索取（[当智能体需要 OpenRouter 密钥时](#when-an-agent-needs-the-openrouter-key)）。
- **[大多数图片使用的图像模型（最佳）](/settings?s=images&find=For%20most%20pictures%20%28Best%29)**：用来生成场景、照片、人物、图片中的文字和示意图，以及对图片所做的每一次修改的模型。它会显示名称、开发者、一张图片大约的费用（按约一百万像素的图片计）以及 OpenRouter 上架它的月份（它的 id 在 (i) 中），并带有标签：**新增**（最近 30 天内上架）、**图片编辑**（它可以接收图片来修改或参照）和**也输出文字**（它在输出图片的同时也输出文字）。在你选择之前，由应用来选择（“The app’s choice, until you pick one”）：从 OpenRouter 仍在提供的一份简短清单中取第一个：字节跳动的 Seedream 5.0 Pro 和 Flash，然后是 Google Gemini、OpenAI 和 FLUX 的图像模型。
- **[简单图片使用的图像模型（快速）](/settings?s=images&find=For%20simple%20pictures%20%28Quick%29)**：一个更便宜、更快的模型，用于图标、背景、纹理和简单图片，显示方式相同。在你选择之前，由应用来选择：从 OpenRouter 仍在提供的一份快速模型简短清单中取第一个，首选字节跳动的 Seedream 5.0 Flash，然后是 Google、Recraft、FLUX 和 OpenAI 的快速模型（如果 OpenRouter 一个都没有提供，则由“最佳”模型一并生成简单图片）。
- **[本机上的图片工具](/settings?s=images&find=Picture%20tools%20on%20this%20computer)**：在这台电脑上去除图片背景、擦除图片的一部分以及放大图片，而不通过 OpenRouter：免费，图片也留在本机。**配置**会一次性下载这些工具，其下方的一行会说明它们正在做什么，**⋯ → 移除**则会把它们再次从这台电脑上移除（参见[本机上的图片工具](/guide/library#the-picture-tools-on-this-computer)）。

要选择“最佳”或“快速”模型：

1. 点击它旁边的**修改**：会打开 OpenRouter 图像模型的列表（**大多数图片使用的图像模型（最佳）**或**简单图片使用的图像模型（快速）**）。
2. 按名称搜索（“seedream”“flux”“gemini”），并按**推荐**（应用的推荐在前）、**最新**或**最便宜**排序。
3. 点击某一行即可使用该模型。选好之后，该行的 **⋯** 菜单中会有**改为让应用来选择**，可恢复为应用的选择。

这些列表来自 OpenRouter，无需密钥；无法连接时，列表会提示。

## 允许智能体生成视频

智能体也可以生成短视频（“十秒钟黄昏的海浪”“让我这张狗狗的照片跑过一片田野”），通过 OpenRouter 使用视频模型，位于同一部分，即 **[设置 → 功能 → 图片、视频和音频](/settings?s=images)**：

- **[生成视频](/settings?s=images&find=Making%20videos)**：位于该分组标题旁的开关**允许智能体生成视频**，会为每个智能体提供相应的工具。除非你关闭，否则它默认开启。
- **[视频模型](/settings?s=images&find=Video%20model)**：用来生成视频的模型，显示其开发者、每秒视频的费用（从最低分辨率无声到最高分辨率有声，如“$0.03 to $0.08 a second”）、它能生成的时长（“4 to 8 s”）、最高分辨率（“up to 1080p”）以及 OpenRouter 上架它的月份，并带有标签：**声音**（它会随画面生成声音）、**从图片开始**（它可以从你提供的图片开始）和**视频编辑**（它修改你提供的视频，而不是根据文字生成视频）。在你选择之前，由应用来选择：从 OpenRouter 仍在提供的一份带声音的模型简短清单中取第一个：字节跳动的 Seedance 2.5，然后是更便宜、更快的模型，如 Google Veo 3.1 Lite。**修改**会打开列表，可搜索（“seedance”“veo”“kling”），并按**推荐**、**最新**或**最便宜**排序。

- **[视频使用显卡](/settings?s=images&find=Use%20the%20graphics%20card%20for%20videos)**（在**视频编辑**中）：**自动**会在有可用显卡（NVIDIA、Intel、AMD 或 Apple）时，用显卡来处理你编辑的视频以及智能体所做的编辑：速度快得多，处理器也能空出来。第一次生成视频时会尝试使用，其下方的一行会说明检测到了什么（“NVIDIA GeForce RTX 4090 · NVENC”）；**立即检查**会重新尝试。如果显卡在某次编辑中失败，处理器会立刻重新处理。**关闭**则用处理器来处理。

视频的费用远高于图片：每秒从几美分到几美元不等，用顶级模型生成一段 8 秒带声音的视频可能要花好几美元。每一段都用你的 OpenRouter 密钥付费，并且在生成任何内容之前，你会在表单上看到它的价格。

## 允许智能体生成音频

智能体也可以生成声音：歌曲和广告短曲（“给我的播客做一段 30 秒的广告曲”）、用你描述的声音来配音和旁白（“用温暖、缓慢的声音读这段欢迎词”），或用从你已有的录音中复制的声音，以及音效和环境音（“雨点落在铁皮屋顶上”）。在同一部分配置，即 **[设置 → 功能 → 图片、视频和音频](/settings?s=images)**：

- **[生成音频](/settings?s=images&find=Making%20audio)**：位于该分组标题旁的开关**允许智能体生成音频**，会为每个智能体提供相应的工具。除非你关闭，否则它默认开启。
- **[音乐模型](/settings?s=images&find=Music%20model)**：用来生成歌曲和音乐的模型，显示其开发者、价格（“$0.08 a song”）、最长时长（“up to 3:00”）以及 OpenRouter 上架它的月份，并带有标签**音乐**。在你选择之前，由应用来选择：Google 的 Lyria 3 Pro，它能生成最长约 3 分钟的完整歌曲，可以有歌声，也可以没有；否则是 Lyria 3 Clip，它生成 30 秒的片段。
- **[语音和声音模型](/settings?s=images&find=Voice%20and%20sound%20model)**：用来朗读和生成其他声音的模型，显示其价格（“$0.0025 a second”“$0.08 per 1,000 characters”“about $0.014 a minute”）、最长时长以及它有多少种声音，并带有标签：**也能做音效**（除了声音之外，它还能根据描述生成音效和环境音）、**复制声音**（它能用从你提供的简短录音中复制的声音来说话）、**对话**（它能为多位说话者配音，各用各自的声音）和**可指导**（它接受对表达方式的指示：语气、节奏、情绪）。在你选择之前，由应用来选择：字节跳动的 Seed Audio 1.0，它能根据描述完成以上所有这些，一次最长 2 分钟；否则是 Google 的 Gemini 3.8 Flash TTS，再否则是 ElevenLabs v3。

**修改**会打开各个模型的列表，可搜索（“lyria”；“seed”“elevenlabs”“gemini”），并按**推荐**、**最新**或**最便宜**排序（声音按大约一分钟语音的费用排序）；已选定模型的那一行有 **⋯ → 改为让应用来选择**，可恢复为应用的选择。如果你选的语音模型只会朗读文字，那么音效或复制的声音会用应用选择的、能做到这些的模型来生成，表单上会说明这一点。

语音模型大多按朗读的字符数收费，Seed Audio 按生成的声音秒数收费，Lyria 按每首歌收费。每一项都用你的 OpenRouter 密钥付费，并且在生成任何内容之前，你会在表单上看到它的价格。

## 在生成之前检查设置

智能体在生成图片、精细绘图、视频或声音之前，会先在对话中显示一个简短的表单，列出该模型支持的设置以及生成结果的费用，并按你的要求和应用的默认值填好：

- 图片：**形状**（方形、横向、纵向……，取决于模型支持哪些）、**分辨率**（1K、2K、4K……）、**质量**、**图片数量**（适用于一次能生成多张的模型）和**透明背景**（适用于标志或图标）；
- 精细绘图（由 Recraft 的矢量模型生成）：其**形状**；
- 视频：**视频时长**（模型支持的时长，或**时长（秒）**）、**形状**、**分辨率**和**声音**；
- 声音：歌曲有**纯音乐，不要演唱**，如果模型能生成较长的歌曲，还有**时长（秒）**（留空则由歌曲按需要的长度生成）；音效有其**时长（秒）**（Seed Audio 按秒计费）；语音有**语音**（适用于自带声音的模型）和**文件**（**MP3，更小**或**WAV，无压缩**），前提是模型两种格式都能生成。

表单上方是模型的名称、价格（“约 $0.08 每张图片”“$0.03 至 $0.08 每秒，取决于分辨率和声音”“$0.08 每首歌”“$0.0025 每秒声音”；视频或声音则显示按当前设置计算的总价），以及智能体将提出的请求，完整且保持它自己的措辞。你可以随意修改，然后点击**创建**；点击**暂不**会关闭表单，不会生成任何内容，也不会产生花费。表单只显示该模型提供的设置。

在一个会话中，每个模型只会出现一次表单：该会话中之后的图片、视频和声音会沿用你选择的设置（声音则沿用其语音和文件格式），除非你要求换用别的设置（“这次来张纵向的”）。说“再给我看看设置”可以重新显示表单，说“直接做吧，你来选”则让智能体不经表单直接生成。定时任务和应用的运行不使用表单，直接按应用的默认值生成，因为没有人在场回答。

## 当智能体需要 OpenRouter 密钥时

图片、精细绘图、视频、音乐和语音都由模型通过 OpenRouter 生成，费用用你的 OpenRouter 密钥支付。当智能体要生成这些内容而尚未设置密钥时，对话中会先出现一张卡片，标题为**这需要 OpenRouter 密钥**，说明哪个模型会负责生成、大约要花多少钱，以及你需要向 OpenRouter 支付生成内容的费用，卡片上有一个填写密钥的输入框：

- 粘贴密钥，然后点击**保存密钥**（或按回车键）。OpenRouter 会先检查密钥；密钥会直接进入[设置 → 智能体 → 模型 → OpenRouter](/settings?s=models&find=OpenRouter)，绝不会出现在对话中，之后智能体会继续（照常进入设置表单）。随后卡片会显示“你的 OpenRouter 密钥已保存在设置 → 模型中。”
- **获取密钥**会打开 OpenRouter 的页面，你可以在那里创建密钥。
- **跳过**：该模型不会运行，不会生成任何内容，也不会产生花费，智能体会不用它继续：能不用密钥的话就换一种方式（它自己编写的简单绘图、[这台电脑上的图片工具](/guide/library#the-picture-tools-on-this-computer)），否则就不生成。该会话在六小时内不会再次询问。

卡片最多等待九分钟，之后智能体会在没有密钥的情况下继续，如果你之后添加了密钥，它也会得知。定时任务和应用的运行不会出现卡片，因为没有人在场回答：它们会提示缺少密钥（“图片需要 OpenRouter 密钥”，并附有**添加 OpenRouter 密钥**）。编辑器自带的 AI 工具则在各自的对话框中请求密钥（[用 AI 生成图片、绘图、数据图和视频](/guide/library#make-pictures-drawings-plots-and-videos-with-ai)）。

## 要一张图片，或让它修改

描述你想要的内容：主体、场景、风格（照片、插画、水彩）、颜色、光线，以及图中需要出现的文字。智能体还可以：

- **修改或合并你的图片**：这台电脑上的图片文件（PNG、JPEG、WebP 或 GIF，每张最大 20 MB；大多数模型最多接受 4 张，有些更多），可以在会话的文件夹中，也可以通过路径指定；也可以是已保留的幻灯片、文档或网页中的图片；说明要改什么即可。（附在消息中的图片只会交给模型查看；要让图片模型以它为基础生成，它必须是文件：请在文件页面上传。）这需要带有**图片编辑**标签的模型；换成其他模型时，智能体会被告知用文字描述修改，或请你选择一个能编辑图片的模型；
- **使用快速模型或最佳模型**：简单的图片（背景、纹理、图标）智能体会用快速模型，场景、照片、图中的文字、示意图以及所有修改则用最佳模型，也可以根据你的要求来决定；说出来即可换用另一个（“快速的就行”“用最佳模型”）；
- **让背景透明**（标志、图标）：不能生成透明背景的模型会交给能生成的模型处理；如果已设置好[图片工具](/guide/library#the-picture-tools-on-this-computer)，则会先在纯色背景上生成图片，再在这台电脑上抠掉背景；
- **为某一张图片使用其他模型**：只要你指明模型（“用 FLUX 2 Pro 来做”），无需更改设置。

图片会保存在会话文件夹内的 **images** 文件夹中，以图片内容命名，绝不会覆盖已有的文件。

在对话中：

- 模型工作时，会出现一个与所要求形状相同的占位图，显示“正在生成图片”和已用时间，下方是描述。
- 然后图片会与回复一起显示，下方有描述和模型名称，以及**保留**（参见[保留智能体生成的内容](#keep-what-an-agent-made)）。点击一张可查看大图：再次点击可查看原始尺寸，用箭头（或方向键）可在多张之间切换，**在新标签页中打开**会单独打开它，**编辑**会在图片编辑器中打开它（在那里保存的内容会作为新图片保留：[编辑图片和视频](/guide/library#edit-pictures-and-videos)），按 Esc 键关闭。把鼠标指向每张图片时，上面会出现**在文件中显示**、**下载**和**更多**（⋯：**用它开始会话**、**添加到项目**、**复制路径**，以及在桌面应用中的**在访达中显示**、**在文件资源管理器中显示**或**在文件夹中显示**）（在手机上这些按钮始终显示）；如果有多张图片，还会有**保留**。
- 如果没有设置 OpenRouter 密钥，会先出现一张卡片向你索要（[当智能体需要 OpenRouter 密钥时](#when-an-agent-needs-the-openrouter-key)）；在无人看管的运行中（定时任务或应用的运行），你会看到“图片需要 OpenRouter 密钥”，并附有**添加 OpenRouter 密钥**。如果没有生成任何内容（你跳过了密钥、关闭了表单，或模型拒绝了请求），你会看到“这次没有图片”及原因。

## 要一幅绘图或一张数据图

有些图片更适合用形状绘制或由数字计算得出，而不是由图片模型来画：

- **绘图**（SVG：由形状而非像素组成，任何尺寸下都清晰锐利）：图标、标志、示意图、重复的图案、形状或扁平插画，使用你指定的颜色（比如某个幻灯片或文档自己的配色）。简单的绘图由 Claude（或你选择的[辅助模型](/settings?s=models&find=Helper%20model)）编写，无需为图片模型付费，不到一分钟即可完成；精细的绘图（插画，或你要求最佳效果时）则由 Recraft 的矢量模型通过 OpenRouter 绘制，每幅约 $0.08，并在显示价格的表单之后进行。每幅绘图在保留之前，都会去除其中的脚本、链接以及任何从别处加载的内容。
- **数据图**：用于你的数据或数学公式，适合幻灯片图表画不出来的内容：散点图、直方图、箱线图、误差线、多个坐标轴或多个面板、热力图、函数、拟合曲线，以及对关键点的标注。Claude（或辅助模型）用 Python 和 matplotlib 编写，在这台电脑上运行，出错时会把问题反馈给它去修复（最多尝试三次）；大约需要半分钟，只会计入那一次回答的费用。你可以在消息中给出数字，或提供文件（CSV、TSV 或 JSON，最大 20 MB），并说明它要表达的重点（“显示春季翻了一番”）。结果是一幅绘图（SVG；点数非常多时为 PNG），除非你要求其他尺寸，否则为 960 × 540 像素，旁边附有它的 Python 代码，因此说“现在改用对数坐标”就会修改那张图；对于网页版幻灯片，它也可以是会动并能响应鼠标指针的数据图。它需要运行本应用的那台电脑上装有带 matplotlib 的 Python：设置好之后可用图片工具自带的那个（[这台电脑上的图片工具](/guide/library#the-picture-tools-on-this-computer)），或者使用已有的。

两者都保存在会话文件夹内的 **images** 文件夹中，并像图片一样与回复一起显示；生成过程中，占位图会显示“正在绘图”或“正在绘制数据图”。

## 查找免费照片

如果你要的是照片而不是模型生成的图片（“为我的标题幻灯片找两张里斯本有轨电车的照片”），智能体会搜索开放授权的照片，这些照片可以免费使用和修改，商用也可以：先搜索 Openverse 的目录（Flickr、Wikimedia Commons、博物馆等），Openverse 无法回应时则使用 Wikimedia Commons 自己的搜索。它会把最好的几张（除非你另有说明，默认 4 张，最多 10 张）保存到会话的 **images** 文件夹中，每张的署名信息（标题、作者、许可协议和链接）放在旁边的一个文件里；它会先查看这些照片再决定用哪一张，并按许可协议的要求署名：在幻灯片的演讲者备注中，或在文档或网页的图片下方；对于 CC0 和公有领域之外的许可协议，则在照片旁加一行小字说明（“照片：“标题”，作者 Author，CC BY 2.0”）。这是免费的，只需几秒钟；搜索期间，占位图会显示“正在查找免费照片”。

## 剪裁、擦除与编辑

智能体也可以直接修改你的图片和视频，而无需重新生成：

- **抠掉背景**：把图片中的主体（人物、产品、动物、标志）抠出来，放在透明背景上，保存为 PNG。在这台电脑上，只要设置好了[图片工具](/guide/library#the-picture-tools-on-this-computer)，这一步就免费、私密，会保留主体原有的像素，只需几秒钟；如果抠出来的效果不好，会改由图像模型重做。没有图片工具时，则通过 OpenRouter 使用图像模型来完成（约 $0.01 到 $0.04），它会把图片去掉背景后重新画一遍，所以一些细节可能会有出入。
- **擦除某样东西**：从图片中擦掉某样东西（背景里的人、招牌、水印、污渍、电线），擦掉后会顺着周围的内容把空缺补上。智能体会标出它的位置，或者用文字描述，让图像模型去找。小块区域在这台电脑上擦除，不花钱；大块区域、横跨整张图片的区域，以及夹在文字等细节之中的区域，则交给图像模型处理（约 $0.01 到 $0.04）。
- **放大图片**：每边放大到两倍或四倍，细节被清晰地重新画出来，而不是变得模糊（用于打印或幻灯片的小照片、旧图片）。免费且私密，只要设置好了[图片工具](/guide/library#the-picture-tools-on-this-computer)，就在这台电脑上完成（第一次会下载它的模型，约 5 MB）；较大的图片需要一两分钟。
- **编辑图片**：裁剪、旋转或翻转、调整尺寸，调整光线和色彩（曝光、对比度、色温等，或曲线、色阶、某一种颜色的色相和饱和度、色彩平衡、清晰度、去雾、降噪、颗粒，或者用“自动增强”一次全部调好），加上滤镜（**复古**、**黑白**…），在上面写字，画箭头和方框，以及对其中的部分进行模糊或像素化（人脸、车牌、姓名）。免费，在这台电脑上完成；JPEG、WebP 或 GIF 图片，或者在这些图片上写字，需要这台电脑上有 ffmpeg 或图片工具。
- **编辑视频**：裁剪时长、剪掉其中的部分、裁成某种画幅（16:9、9:16、正方形、4:5），旋转或镜像，加速或减速（或倒放、并做防抖），用转场（溶解、渐入渐出黑场、擦除、滑动）把多段视频和图片拼接起来，给图片加上缓慢的缩放，调色（曝光、色温、对比度，电影感或黑白等风格，暗角，颗粒），淡入淡出，去掉声音或调整音量，选择听到哪些声道（一侧的领夹麦克风两边都能听到），让部分声音静音，给音乐设置音量曲线，在上面叠加标志、水印或绿幕，加上文字（标题、字幕，或根据说话内容生成的字幕，并在旁边生成一个 .srt 文件），在下面铺上音乐和旁白，同时清理人声、在说话时压低音乐、并让响度保持均衡；也可以把它做成 GIF，或者截取一帧保存为图片。免费，使用这台电脑上的 ffmpeg（图片工具自带一个），电脑有显卡时会用显卡加速，前提是已开启 **允许智能体生成视频**。
- **编辑声音**（声音文件、视频中的声音，或你保留的声音）：保留一段、剪掉或静音其中的部分，缩短过长的停顿，去掉口头禅（“嗯”“呃”：需要这台电脑上的语音识别，见[服务器上的语音识别](#speech-recognition-on-the-server)），在保持音高的前提下加快或放慢，改变音高，调大或调小音量或淡入淡出，设定最大峰值或响度（播客、流媒体、广播），降噪，改变音色（更清晰的人声、电话声、电台声），压缩或限幅，添加回声或混响，倒放或转为单声道，并在某个位置叠加其他声音（人声下的音乐、音效）。免费，使用这台电脑上的 ffmpeg，前提是已开启 **允许智能体生成音频**。

每一种操作都基于会话文件夹中的某个文件，或者基于已经在幻灯片、文档或网页中的图片或视频，并把结果保存在会话的 **图片** 文件夹中（编辑后的视频放在 **视频**，编辑后的声音放在 **音频**），绝不会覆盖原件。你保留的图片或声音也可以编辑，并作为新的一份放回原处或放在它旁边，就像编辑器里的 **保存** 和 **另存副本** 一样（“把我保留的海港照片调亮一些”“把我那段‘Interview’声音的响度调到像播客一样”）。结果会像智能体生成的图片一样随回复显示，处理期间它的占位符会显示“正在抠掉背景”“正在擦除”“正在放大”“正在编辑图片”“正在编辑视频”或“正在编辑声音”。对于抠图或擦除，回复会说明采用了哪种方式以及原因：如果效果不对，就说“用 AI 来做”，智能体会去请图像模型处理。如果想自己动手，请在编辑器中打开这张图片、这段视频或这段声音（[编辑图片和视频](/guide/library#edit-pictures-and-videos)、[声音编辑器](/guide/library#the-sound-editor)）。

## 请求生成视频

描述场景、什么在动以及怎么动、镜头（“缓缓推近”“跟随骑车的人”）、风格和光线，以及任何声音或台词。智能体还可以：

- **从图片开始**：用一个图片文件作为视频的第一帧（“让这张照片动起来”），部分模型还支持再指定一张作为结尾，适用于带有 **从图片开始** 标签的模型；
- **参考图片**：最多 4 张角色、产品或风格的图片，让视频保持一致，但这些图片不会成为视频的画面；
- **修改视频**：提供一个视频文件（MP4、WebM 或 MOV，最大 40 MB），让带有 **视频编辑** 标签的模型来编辑、延长或锐化。

一个视频需要不到一分钟到几分钟不等。智能体最多会等待约九分钟；如果耗时更长，应用会继续等它生成，并在准备好后保存，智能体再次查看时就会把它显示出来。等待不会产生额外费用。

视频会保存在会话文件夹内的 **视频** 文件夹中，并以其内容命名。

在对话中：

- 模型工作期间，会出现一个与视频形状相同的占位符，显示“正在生成视频”以及已用时间。
- 然后视频会随回复显示，可直接播放（也可以通过播放控件全屏），下方是描述和模型名称，还有 **保留**。把鼠标指向它时，上方会出现 **编辑**（视频编辑器：你保存的内容会被保留）、**在文件中显示**、**下载** 和 **更多**（⋯：与图片下方的相同，在桌面应用中包括 **在访达中显示**、**在文件资源管理器中显示** 或 **在文件夹中显示**）。
- “仍在生成中”表示智能体在视频准备好之前就停止了等待：它再次查看时就会显示（如果没有，请让它去查看）。“这次没有视频”会给出原因：你关闭了表单，或者模型拒绝了（它的回复会说明原因）。

## 请求生成音乐、声音或音效

告诉智能体你想听到什么：

- **音乐**：曲风和情绪、乐器、节奏、演唱的声音以及它的编排方式（“一首 2 分钟的欢快合成器流行歌曲，关于周一早晨，由女声演唱，副歌朗朗上口”）。可以提供你自己的歌词，也可以让模型来写；如果不想要演唱，就要求纯器乐。Lyria 3 Clip 总是生成 30 秒；Lyria 3 Pro 最长可生成约 3 分钟，取决于你的要求。一首歌需要一两分钟。
- **旁白**：要说的话（一字不差），以及听起来应该是什么样（“用平静、低沉的声音慢慢读出来”）。使用自带声音的模型时，你在表单上选择一个声音；Seed Audio 则会生成你描述的声音。多位说话者之间的对话也可以（“一段有两位主持人的简短播客开场”），前提是模型支持为他们配音。
- **复制录音中的声音**：给智能体 1 到 3 段这个声音的录音，是这台电脑上的文件（WAV、MP3、M4A、OGG 或 FLAC，每个最大 30 MB；每段只使用前 30 秒），用于能 **复制声音** 的模型（Seed Audio）。请只使用你有权使用的声音：你自己的，或者声音主人同意的。电脑上装有 ffmpeg 时，以上任何格式的文件都可以；没有 ffmpeg 时，只能用 WAV 和 MP3。
- **音效或环境音**：它是什么、发生了什么以及何时发生（“大雨打在铁皮屋顶上，结尾处雷声滚滚而来，没有人声”），以及时长。
- 为某一段声音**换一个模型**，只要你说出模型名称（“用 ElevenLabs v3 来读”），无需更改设置。

声音会保存在会话文件夹内的 **音频** 文件夹中，并以其内容命名，格式为 MP3（如果你要求，也可以是 WAV）。

在对话中：

- 模型工作期间，会出现一张卡片，显示“正在生成音乐”“正在生成旁白”或“正在生成声音”，以及已用时间。
- 然后声音会随回复显示在播放器中：圆形按钮用来播放和暂停（同一时间只播放一个声音），它的波形就是进度条（点击或拖动），接着是时间和播放速度（**1×**、**1.25×**、**1.5×**、**2×** 或 **0.75×**）。播放器获得焦点时，空格键或 K 可播放和暂停，← → 可前进或后退 5 秒。标题来自文件名，旁边有 **编辑**（[声音编辑器](/guide/library#the-sound-editor)：你保存的内容会被保留）、**在文件中显示**、**下载** 和 **更多**（⋯：与图片下方的相同，在桌面应用中包括 **在访达中显示**、**在文件资源管理器中显示** 或 **在文件夹中显示**）。下方是生成它所依据的文字、模型名称和 **保留**（见[保留智能体生成的内容](#keep-what-an-agent-made)）；歌曲的 **歌词** 会在它们下方展开。
- 没有 OpenRouter 密钥时，你会看到“音频需要 OpenRouter 密钥”，旁边有 **添加 OpenRouter 密钥**。“这次没有声音”会给出原因：你关闭了表单，或者模型拒绝了（它的回复会说明原因）。

智能体听不到自己生成的内容：它只是根据自己提出的要求来了解这段声音。如果听起来不对，告诉它要改什么，它会再生成一个；也可以让它去编辑（“把这段广告曲的最后两秒淡出”“把它放在我的旁白下面，从 0:05 开始”），由智能体或在声音编辑器中完成。

## 智能体制作内容中的图片

当智能体为你制作或修改幻灯片、文档或网页时，它会在图片能增色的地方自行配图（标题幻灯片、某个章节、某个想法；并非每张幻灯片都配），使用与内容一致的色彩和风格，就像设计师那样：背景、纹理或图标用一张 快速 图片，场景、照片或示意图用一张 最佳 图片，必须保持清晰的图标、标志或示意图用绘制的图形，数据用图表，真实地点和事物用免费照片，并把它的图片抠图、擦除或编辑以适配内容。它既会使用你已打开内容中的图片，也会使用文件；如果你要求，还会为一份幻灯片中没有描述的每张图片写上描述，方便看不到图片的人（由为你保留的图片写描述的那个模型来完成）。需要花钱的部分会在生成之前在表单上标明价格（[在生成之前检查设置](#check-the-settings-before-anything-is-made)）；如果你想换个方式，就说“不要图片”或“只用免费照片”。

当你按名称要求某种常见的内容（SWOT 幻灯片、融资演示文稿、求职信、执行摘要、习惯追踪表、定价表、预算），智能体会先读取应用是如何把这类内容做好的：里面放什么、按什么顺序、外观如何、图片在哪里有帮助，就像资料库图库中各种类型的制作方式一样（[用 AI 按类型制作](/guide/library#made-with-ai-from-a-kind)）。这一步不花钱。

在[保密会话](/guide/sessions#keep-a-session-confidential)中，以上这些都不会出现：它的智能体不会制作、查找或编辑任何图片或视频。

## 保留智能体生成的内容

在智能体生成的图片、视频或声音下方点击 **保留**，会在某个项目的文件中保留一份副本，由模型为它写一个标题和描述（对于声音，根据生成它所依据的文字来写，因为没有模型能听到它；所用的模型在[设置 → 功能 → 图片、视频和音频 → 为你保留的内容生成说明](/settings?s=images&find=Captions%20for%20what%20you%20keep)中选择），并且在会话文件夹被清理之后它仍会留在那里。当你有项目时，会弹出一个简短的菜单询问放到哪里（**保留到**）：先是会话自己的项目，然后是你的其他项目，以及 **不放在项目中**，这会把它和对话放在一起，用搜索框（Ctrl+K）可以找到它。随后按钮会变成 **已保留**，点击即可打开它。你保留的图片会出现在它所属项目的文件中（项目详情 → **文件**，显示为带有图片的方块），而在编辑器中，**保留** 会把编辑后的图片保留为一张新图片，**保存** 会把它放回原来的位置，**另存副本** 则在它旁边另保留一份。

## 输入时的词语建议

输入时，Hydor 可以在光标后面用灰色显示你正在输入的这个词的其余部分，并用更淡的灰色显示下一个词。消息框、文档、备注和其他文本框中都有这个功能，无论你使用哪种语言书写。

- **Tab** 接受灰色的词。再按一次，接受下一个词。
- 光标在文本末尾时，按 **→**（右箭头）可以一次接受这两个词。
- **Esc** 会把它们隐藏起来，直到下一个词。继续输入，它们会自行消失；如果你输入的字母与它们显示的一致，它们会保留，只是变短。
- 在消息框中，打开的 `@` 或 `/` 菜单会优先使用 Tab 和 Esc，而 **Shift+Tab** 仍然用来切换权限模式。没有灰色建议显示时，所有按键都照常工作。

你输入的任何内容都不会离开你的电脑：这些猜测由在电脑上运行的模型给出。它从一开始就是开启的，并会在你第一次输入时自行完成设置。

### 第一次使用，以及如何关闭

词语建议从一开始就是开启的，但在你使用之前不会下载任何内容：你第一次在消息框或文档中输入时，它会安装并下载所需的内容，总共约 1.3 GB。下载内容包括：它运行所依赖的 Python 库（来自 PyPI 和 PyTorch 自己的下载地址）、llama.cpp（来自 GitHub）、语言模型和小模型（来自 Hugging Face）。在那之前，**[设置 → 功能 → 词语建议](/settings?s=suggest)** 中开关下方会显示 **尚未设置**；设置期间，那一行会显示进度，之后不会再次下载任何内容。当这一行显示 **已就绪：输入时会显示建议** 时，说明功能已经可用；在长时间停顿后的第一条建议会稍慢一些，因为模型需要加载，而模型在你一段时间不输入后会被再次释放。一切都在处理器上运行，因此不需要显卡。

如果不想用，请在那里关闭 **[词语建议](/settings?s=suggest&find=Word%20suggestions)**：它会停止工作；如果在第一次使用之前就关闭，则完全不会下载任何内容；已下载的内容会保留。如果设置失败（例如没有网络连接），那一行会说明原因，之后会再次尝试，每次失败后等待的时间会更长；把开关关闭再开启，则会立即重试。

### 两个模型，以及它们需要的内存

两个模型协同工作，都在你的电脑上运行：

- **小模型**是应用自带的模型，小到任何电脑都能运行，并用 200 种语言的文本训练而成。它还会从你写的内容中学习（见[下文](#learn-from-what-you-write)）。
- **语言模型**是 Qwen3.5-0.8B，一个更大的模型，猜得更准，尤其是在文档中。它要求电脑至少有 8 GB 内存，并且此时有 2.5 GB 可用。

**[语言模型](/settings?s=suggest&find=Language%20model)** 有三个选项。**自动**表示电脑内存足够时使用它，不够时只用小模型；开关下方的文字会说明当前是哪种情况以及原因。**开启**表示即使内存不够也使用它（可能会拖慢电脑）。**关闭**表示从不使用。没有它，建议仍然可用，只是稍差一些。**[语言模型大小](/settings?s=suggest&find=Language%20model%20size)** 可选 **8-bit**（猜得稍准）或 **4-bit**（占用内存更少，下载也更小，约 560 MB，而不是 830 MB）。

更改大小时，第一次会下载另一个文件。**[按语言选择](/settings?s=suggest&find=Choose%20by%20language)** 默认开启，它会让应用在两个模型中，选用在你正在书写的语言上表现更好的那一个。

### 在哪里显示

在同一部分的 **位置** 下，每个位置都有各自的开关：

- **[在消息框中](/settings?s=suggest&find=In%20message%20boxes)**：你给智能体写消息的地方，包括起始页和会话中。
- **[在文档中](/settings?s=suggest&find=In%20documents)**：在文档中书写时。文档里 **视图** 中的“边输入边给出建议”会请辅助模型猜测一句话如何继续；当有词语建议显示时，它会先等待。
- **[在备注中](/settings?s=suggest&find=In%20notes)**：记忆笔记和你的档案。
- **[在其他文本框中](/settings?s=suggest&find=In%20other%20text%20boxes)**：追问、队列、你正在编辑的早先提示词、询问面板和其他小文本框。

这些选项对整个应用只设置一次。**[在此浏览器中显示](/settings?s=suggest&find=Show%20in%20this%20browser)** 是例外：它按浏览器分别保存，因此你可以在一台设备上关闭灰色词语，而在另一台设备上保持开启。智能体也可以为显示其会话的浏览器更改这一项。

### 需要多确定才显示

每个猜测都有一定的正确概率，只有概率足够高时才会显示。**[显示前的把握程度](/settings?s=suggest&find=How%20sure%20before%20showing)** 用来设定这个门槛：**更多**（默认）会显示更多猜测，其中错误的也更多；**均衡**介于两者之间，目标是显示的猜测中约十个有四个正确；**更确定**显示的更少，但其中正确的更多。智能体还可以把门槛设得更高，只显示最有把握的建议。**[显示下一个词](/settings?s=suggest&find=Show%20the%20next%20word)** 可以关闭更淡的第二个词，这样只会显示你正在输入的这个词的其余部分。

### 它会读取什么

为了做出猜测，它会读取光标前你输入的词，以及你正在回应的内容：消息中是智能体的上一条回复，文档中是该段落上方的文字。

- **[你输入的词数](/settings?s=suggest&find=Words%20of%20what%20you%20typed)**：它读取你最近多少个词，范围从 20 到 200（初始为 100）。越多越慢。
- **[回复或文档的词数](/settings?s=suggest&find=Words%20of%20the%20reply%20or%20document)**：它读取回复或文档中的多少个词，范围从 0 到 200；0 表示不读取。
- **[从对话中学习](/settings?s=suggest&find=Learn%20from%20the%20conversation)**：在你输入消息时，记住对话前面用到的词和名称。它与下文的学习是分开的。
- **[Threads](/settings?s=suggest&find=Threads)**：词语建议使用多少个处理器线程。**自动**会根据电脑的核心数来选择。

### 从你写的内容中学习

默认情况下，小模型还会学习你自己的用词：你使用的名称、术语和写作方式，让它的猜测更贴合你。这一切都在你的电脑上进行，你写的内容不会离开电脑。学习得到的模型保存在应用的数据文件夹中，不会与任何人分享。

- **[从我写的内容中学习](/settings?s=suggest&find=Learn%20from%20what%20I%20write)** 用来开启或关闭学习。
- 它会从你保持开启的来源中学习：**[来自我的消息](/settings?s=suggest&find=From%20my%20messages)**（你对智能体输入的内容，但不包括已关闭记忆的会话或[保密会话](/guide/sessions#keep-a-session-confidential)，也不包括应用、定时任务或其他会话替你写的内容）、**[来自智能体的回复](/settings?s=suggest&find=From%20agents'%20replies)**、**[来自我的备注](/settings?s=suggest&find=From%20my%20notes)**（你亲自写的记忆笔记）和 **[来自我的文档](/settings?s=suggest&find=From%20my%20documents)**（你写的页面和文档）。例如，关闭智能体的回复，可以让它的猜测只贴合你自己的风格。
- **[我自己输入的词的权重](/settings?s=suggest&find=Weight%20of%20my%20own%20words)** 表示你输入的内容比其余内容重要多少，范围从 1（相同）到 16；初始为 4。
- **[学习时间](/settings?s=suggest&find=When%20it%20learns)**：**每晚**（大约每天一次，在你十分钟没有输入且电脑内存足够时）、**每周**，或 **仅在我需要时**。它以最低优先级在后台运行，不会拖慢你的工作；如果电脑被关闭，它会从中断的地方继续。第一次会读取你写过的所有内容，在没有显卡的电脑上可能需要数小时；之后只读取新增的内容，只需几分钟。**[用于学习的线程数](/settings?s=suggest&find=Threads%20for%20learning)** 限制它可以使用的处理器资源。
- **[在显卡上学习](/settings?s=suggest&find=Learn%20on%20the%20graphics%20card)**（默认开启）让一次学习运行在电脑有显卡时使用显卡，比处理器快很多倍：可以是空闲内存至少 4 GB、忙碌程度不到一半的 NVIDIA 显卡（有多块时选空闲内存最多的；被其他程序占用的显卡不会动），也可以是搭载 Apple 芯片的 Mac。第一次在 NVIDIA 显卡上学习时，应用会把适用于它的 PyTorch（约 2.5 GB）下载到自己的文件夹里，这次运行会等它下载完，开关下方的文字会这样说明。如果显卡无法准备好，或在某次运行中出错，这次运行会立刻改在处理器上继续，并且这块显卡一天内不再使用；设置里会说明原因。关闭它则始终在处理器上学习。
- **[立即重新训练](/settings?s=suggest&find=Retrain%20now)** 会立刻从你上次之后写的内容中学习。
- **[忘记已学内容](/settings?s=suggest&find=Forget%20what%20it%20learned)** 在你确认后，会删除由你的写作生成的模型，并回到应用自带的那个模型。除非你关闭了学习，否则它会在下一次学习时间再次学习。

开关下方的文字会说明当前使用的是哪个小模型、上次学习的时间、一次学习运行进行到哪里了，以及它在哪里学习（**在显卡上：…** 或 **用处理器**）。

运行进行时，这一行有**暂停**和**停止**。**暂停**会让这次运行停在当前位置，并保留它到目前为止学到的内容；这一行随后显示**已暂停，进度 45%**，并带有**继续**和**停止**。在你按下**继续**之前（**立即重新训练**的效果相同），什么都不会再自行启动它，计划也不会，重启应用后同样如此。**继续**会从停下的位置接着学习，读取的还是之前那些文字。**停止**会先让你确认，然后丢弃这次运行到目前为止学到的内容（你现在使用的模型保持不变），下一次运行等到平常的时间再开始。关闭学习，或选择**忘记已学内容**，也会结束已暂停的运行。

### 它帮了多少忙

在同一部分的 **帮助情况** 下，有两行显示建议到目前为止为你做了什么：**节省的按键**（以及它占你输入量的比例），以及在已判定的建议中有多少条是 **正确** 的，还有你用 Tab 采纳了多少条。当你采纳了建议（按 Tab，或按 → 采纳两个单词），或者自己输入了整个灰色单词时，这条建议就是正确的；当建议显示时你输入了别的内容，就是错误的。用 Esc 隐藏的建议，或者因为你点击别处、发送了消息或移动了光标而消失的建议，两者都不算。每次按 Tab 或 → 节省的是它补上的字母数，再减去你按的那一下键。

**显示详情** 会加上今天、本周以及从开始统计以来的总数，**[重置数字](/settings?s=suggest&find=Reset%20the%20numbers)** 会在你确认后让这些数字从零开始。只保存计数，绝不保存你输入的内容，而且它们不会改变建议的工作方式。

## 语音输入消息

消息框中的麦克风（在起始页和每个会话中）会把你说的话转成消息中的文字。不会自动发送任何内容：你先检查一遍，然后照常发送。

1. 点击或轻点麦克风。
2. 开始说话。消息框上方的面板会显示时间、目前听到的词（如果由服务器识别语音，则显示“正在录音…”以及随你声音起伏的条形），还有它正在听取的语言。
3. 点击 **完成**，或再次点击麦克风。这些词会接在你已经写好的内容后面（使用服务器时，会先短暂显示“正在把你的话转成文字…”）。

面板上的语言标签（“DE”“PT-BR”）可以在你说话时切换语言；它会接着用新的语言继续。由服务器识别语音时，录音会在 10 分钟后自动停止。

只有在语音输入能够使用的地方才会显示麦克风：浏览器自己能识别语音时（Chrome、Edge、Safari），或服务器能识别时（见[服务器上的语音识别](/guide/documents-voice#speech-recognition-on-the-server)）。当它无法启动时，会说明原因和该怎么做：

- **麦克风需要安全连接**：浏览器只允许在 HTTPS 地址上，或在电脑本机的 localhost 上使用。请通过 HTTPS 地址打开 Hydor（见[手机、其他机器和分享](/guide/devices)）。
- **此网站的麦克风权限已被阻止**：请在浏览器的网站设置中允许，然后再试一次（在 iPhone 上：地址栏中的 **aA**，然后 **网站设置 → 麦克风**）。
- **未找到麦克风**，或 **麦克风正被占用**（另一个应用正在使用它）。
- **此处的语音识别已关闭**：在 iPhone 上，请在“设置 → 通用 → 键盘”中开启听写；或者让服务器来识别语音。
- **此浏览器无法录音**：请使用最新版本的 Chrome、Edge、Firefox 或 Safari。

这些提示每一条都有一个 **语音设置** 按钮，它会打开“设置 → 语音”。

## 设置语音

语音的所有设置都在 **[设置 → 功能 → 语音](/settings?s=voice)**（在手机上：设置，然后选择 **语音**）。它分为三个部分。

### 听写

**[听写](/settings?s=voice&find=Dictation)** 首先会说明此浏览器能做什么：

- 能自行识别语音的浏览器会在你说话时显示你的话。它可能会把你的声音发送给浏览器的开发商来完成识别（Chrome 发给 Google，Safari 发给 Apple）。如果想让你的声音留在你的机器上，请在下方开启 whisper.cpp，并选择服务器。
- 不能自行识别语音的浏览器，在服务器上的语音识别开启后，会通过服务器进行听写。

然后是：

- **[你说的语言](/settings?s=voice&find=Language%20you%20speak)**：**与此浏览器相同**，或 56 种语言和地区之一。听写会按它来聆听，免提模式也会用它来说话和聆听。
- **识别方式**：**此浏览器**（你说话时文字就会显示）或 **服务器**（使用 whisper.cpp 时是私密的；停止说话后文字才会出现）。只有两种方式都可用时才会显示。

语言和 **识别方式** 保存在此浏览器中，因此你的每台设备各有自己的设置。

### 服务器上的语音识别

**[服务器上的语音识别](/settings?s=voice&find=Speech%20recognition%20on%20the%20server)** 适用于不能自行识别语音的浏览器，或者想让你的声音留在你的机器上的情况。它在你开启之前是关闭的，之前不会下载任何内容。它是为整个应用统一设置的，对所有设备都有效。在 **运行位置** 下，从三项中选择一项：

- **关闭**。
- **在本机**：whisper.cpp 在运行 Hydor 的电脑上运行；如果这台电脑有 whisper.cpp 能用的 GPU（Mac 的 GPU 或 NVIDIA GPU），就用 GPU，否则用处理器，你的声音只会留在这台电脑上。
  - **模型**：**极小**（74 MB；最快，偶尔会听错个别词）、**基础**（141 MB；速度快，对大多数听写已经足够好，为默认选项）、**小**（465 MB；听得更准，在 CPU 上每句话需要几秒）或 **中等**（1.4 GB；听得最准，没有快速 CPU 时会很慢）。
  - **语言**：**任意语言**（跟随你所说的语言）或 **仅英语**（对英语稍微更准确）。
  - **开启 · 下载 …** 会说明要下载多少内容：模型，以及首次使用时的 whisper.cpp 本身（当所有内容都已就绪时，选择 **在本机** 会立即开启）。进度条会显示下载进度；**取消** 会停止下载，并关闭服务器上的语音识别。在 Linux 上，应用会下载现成的 whisper.cpp，它在处理器上运行；在 Mac 上，以及现成版本无法运行的地方，应用会在这台电脑上编译 whisper.cpp，这需要 C++ 编译器和 CMake（在 Debian 或 Ubuntu 上：`sudo apt install build-essential cmake`；在 Mac 上：`xcode-select --install`，然后 `brew install cmake`）。在 Mac 上，它会针对 Mac 的 GPU（Metal）进行编译。电脑上你自己安装的 whisper.cpp（比如针对你的 GPU 编译的版本）会按原样使用。
  - **NVIDIA GPU**（Linux 上）：whisper.cpp 没有适用于它的现成版本，所以在听写能用处理器工作之后，应用会在后台用 NVIDIA 的 CUDA 工具包（`nvcc`）为 GPU 编译一个版本。进度条会显示进展（需要 5 到 20 分钟）；在此期间听写在处理器上工作，完成后改用 GPU。如果没有该工具包，会有提示说明，并带有 **重新检查** 按钮，供你安装后使用；如果编译失败，会显示原因和 **重试** 按钮，听写仍然在处理器上运行。
  - 就绪后会显示：“Ready: whisper.cpp … with the Base model. Your voice stays here.”，其下是它运行所用的设备，内容取自 whisper.cpp 上一次运行时的报告（就绪后它会立即试听一秒静音）：“It runs on the GPU: Apple M2 Pro (Metal).” 或 “It runs on this machine's processor.” 如果 GPU 出错（比如显存不足），该次录音会改用处理器完成，提示会说明原因，几分钟后会再次尝试使用 GPU。**测试** 会检查它是否有响应以及速度如何。如果出现了问题，会显示原因和 **重试** 按钮。
  - 在开启状态下选择另一个模型，会下载该模型。
- **外部服务**：任何提供 OpenAI 语音转文字地址（`/audio/transcriptions`）的服务：OpenAI 本身，或你网络上的服务器（Speaches、LocalAI、whisper.cpp 的服务器、GPU 上的服务器）。录音会发送给它。
  - 服务所在行上的 **配置**（之后是 **编辑**）会打开一个表单：**地址**（例如 `https://api.openai.com/v1`）、**API 密钥**（你网络上的大多数服务器不需要）和 **模型**（除非你指定其他模型，否则为 `whisper-1`）。
  - **保存并开启**（之后是 **保存**）；服务开启后，可在它所在的行上点 **测试**；保存了密钥之后，可在它的 **⋯** 菜单中选择 **移除密钥**。服务保存之后，再次选择 **外部服务** 会立即切换到它。

名为 **在本机** 的分组会显示其总大小，并列出 whisper.cpp 留在这台电脑上的内容：whisper.cpp 本身（当应用为 GPU 编译时，会标注 “built here for Metal” 或 “for CUDA”），以及每个模型和它的大小，正在使用的那个标有 “in use”。模型的 **⋯** 菜单中有 **移除**（移除正在使用的模型，在你确认后会关闭服务器上的语音识别）。分组自己的 **⋯** 菜单中的 **全部移除** 会移除 whisper.cpp 及其模型；它在服务器上的语音识别关闭或使用外部服务时显示。

### 朗读

**[朗读](/settings?s=voice&find=Read%20aloud)**：回复上的喇叭会把回复读给你听，并跳过其中的代码。每个浏览器各自保存自己的声音和语速（该分组的 (i) 里有说明）。

- **语音**：**自动**（浏览器针对你所说语言的声音），或此浏览器拥有的任何声音，适合你的语言的排在前面。每个声音都会标明它的语言，需要联网时会标注 “online”。
- **语速**：从 0.5× 到 2×。
- **试一试**：**播放示例** 会用该声音和语速读一句话。

如果浏览器不能朗读文本，该部分会说明这一点。

## 让回复被朗读出来

1. 将指针移到一条回复上：它的右上角、复制按钮旁边会出现一个喇叭。
2. 点击它。消息框上方的栏会显示 **正在朗读**、读到共几段中的第几段，以及回复的开头几个字。
3. 你可以在这个栏里暂停和继续朗读，也可以在这里或用喇叭停止朗读。

它会把回复当作普通文字来读：代码会被跳过，链接按其文字来读，网址按其网站名来读，表格逐行来读。开始朗读另一条回复会停止前一条，离开对话也会停止朗读。用鼠标指向时才会显示喇叭；在手机上，免提模式会把回复读给你听（“把答案读给我听”）。

## 免提与应用对话

免提模式适用于你无法看屏幕的时候，比如走路时：你说话，应用去执行并说出它做了什么，然后再次聆听。它可以开始会话，把你的话转给会话，说明会话进展如何，回应会话的批准请求，并把结果读给你听。

### 开启和结束

- 在会话中，消息框里的耳机按钮（**免提**，在麦克风旁边）会打开它，并跟随该会话。
- 在起始页上，同一个按钮会打开它，但不跟随任何特定的会话。
- 在搜索框中（Ctrl+K，Mac 上为 ⌘K），操作 **免提对话** 也会打开它。

它会占满屏幕，说 “I'm listening”，并请求设备在它打开期间保持屏幕常亮。顶部会显示它跟随的会话（或 “Talk to Hydor”）。中间的大圆按钮显示它正在做什么：**正在聆听…**、**正在处理…**、**正在说话** 或 **已暂停：轻点开始聆听**。其下会用引号显示它听到的内容，以及它的回答。

- 它说话时轻点圆按钮可以打断它；其他时候轻点可以暂停或继续聆听。
- 要结束它，请说 “Goodbye”（或 “Bye”、“That's all”、“Stop listening”、“End hands-free”、“Exit”），或点右上角的叉号。

### 你可以说什么

- **开始会话**：“开始一个会话，规划我在克里特岛的周末”。它会像起始页那样开始：使用你上次在那里选择的程序、模型、思考强度、权限、智能体和项目，在新的任务文件夹中（或在你上次在那里选择的文件夹中）。从那以后，它会跟随该会话。
- **对会话说点什么**：“告诉它使用公制单位”。这些话会作为你的消息发送给它所跟随的会话。
- **询问情况**：“我的会话进展如何？”它会说明哪些在工作、哪些需要你以及它们问了什么，还有最近完成了哪些。
- **听取结果**：“把答案读给我听”。它会说出它所跟随的会话的最新回复（如果没有跟随任何会话，则是最忙碌或最近的会话的回复）。较长的回复会以要点形式给出，三到五句话；当应用显示的语言不是英语时，每条回复都会用该语言以要点形式给出。
- **回应批准请求**：“批准”或“拒绝”，适用于它所跟随的会话（如果没有跟随任何会话，则是任何会话）在等待简单的是或否的时候。问题、计划或表单必须在屏幕上回答，它会告诉你这一点。
- **停止工作**：“停止”会停止它所跟随的会话正在做的事（不会结束免提模式）。
- **切换**：说出另一个会话的名称（“我们聊聊克里特岛之行”），它就会跟随那个会话。
- 询问应用或其他任何事情：它会简短地回答，不确定时会反过来问你。

### 它会主动告诉你什么

- 当它所跟随的会话完成时：“… is done. Say “read it” to hear the answer.”
- 当任何会话需要你时：“… needs you: …”，然后对于简单的是或否会说 “Say approve or deny”，否则说 “Answer it on the screen”。之后它会跟随那个会话，所以说“批准”就会回应它。
- 当任何会话因错误而停止时：“… stopped with an error.”

它会先停止聆听来说这些话，然后再次聆听。你其他机器上的会话不会被播报。

### 须知

- 辅助模型负责理解你说的话（[设置 → 智能体 → 模型 → 辅助模型](/settings?s=models&find=Helper%20model)）。如果无法连接到它，简单的词语仍然有效：“status”、“approve” 或 “yes”、“deny” 或 “no”、“stop”、“read”、“start …”；其他任何话都会发送给它所跟随的会话，如果没有跟随任何会话，则会开始一个新会话。
- 它用应用显示的语言回答，用你所说的语言聆听（设置 → 通用 → 语言 里的语言；你所说的语言在 设置 → 语音），否则使用应用的语言。
- 它使用[朗读](/guide/documents-voice#read-aloud)中设置的声音和语速。
- 它需要一个能朗读的浏览器，以及一种聆听方式：浏览器自带的语音识别（Chrome、Edge、Safari），或服务器上的语音识别。只有在能够工作的地方才会显示耳机。使用服务器时，你说的每句话在安静一秒半后结束（最长半分钟），并在静音 15 秒后重新开始聆听。
- 如果麦克风未被允许或没有麦克风，它会说明一次并暂停：请在浏览器中允许使用，然后轻点开始聆听。
