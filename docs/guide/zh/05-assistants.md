# 助手

助手是会话所使用的一种预设：它告诉智能体在这次会话中扮演什么角色、该怎样开展工作，还可以限制智能体能用什么、优先使用某些技能、开启已连接的账户，并建议使用某个智能体、模型和权限。本主题介绍应用自带的七个助手、如何在开始页上选择助手、如何把会话切换到另一个助手、如何创建、修改、删除和导入你自己的助手、没有选择文件夹时会话得到的任务文件夹，以及如何让智能体在任务完成后清理。

![在开始页面选助手：通用、研究员、撰稿人、程序员、辅导老师、规划师或分析师](images/assistants.webp)

## 什么是助手

开始会话时，你在开始页上选择一个助手，之后也可以在会话的消息框里换成另一个。它的指令会叠加在智能体自身的指令之上，所以同一个智能体在这次会话里是严谨的研究员，到下一次会话就可以是耐心的辅导老师。助手适用于所有智能体：Claude Code、Codex、Custom（应用自带的智能体），以及使用 ACP（Agent Client Protocol，智能体客户端协议）的智能体，例如 Gemini CLI 或 OpenCode。

一个助手可以包含：

- **指令**：智能体在这次会话中是谁、怎样工作。智能体会被要求始终按这种方式工作，但你在对话中提出的要求优先。
- **它可以使用什么**：读取文件、创建和修改文件、运行命令、使用网络，以及其他工具。可以全部开着，也可以关掉其中一些。
- **优先使用的技能**：当这些技能适合任务时，智能体会在开始前先加载它们（见[技能](/guide/skills)）。
- **连接**：在它的会话中要开启的已连接账户（见[已连接的应用、密钥和工具](/guide/connections)）。
- **建议的智能体、模型和权限模式**：在开始页上选中这个助手时会一起选上，开始之前你仍然可以更改。
- **它的会话从哪里开始**（没有选择文件夹时）：一个属于会话自己的新任务文件夹，或开始页上显示的文件夹。

助手是一次会话中扮演的角色。至于所有智能体都应该遵守的文字，比如你希望它们怎样和你说话，无论是适用于所有会话、某个项目还是某一个会话，都应该写进[智能体准则](/guide/guidelines)。

## 内置助手

应用自带七个助手。它们都不会建议智能体、模型或权限模式，所以会沿用你在开始页上的选择；它们也都不限制智能体能用什么。除程序员外，其他助手在没有指定文件夹时，都会让会话在一个新的任务文件夹中开始（见[任务文件夹](#task-folders-where-a-task-without-a-folder-works)）。你不能修改或删除它们，但可以复制一个，再修改副本（见[修改、复制或删除助手](#change-duplicate-or-delete-an-assistant)）。

### 通用

“什么都能帮：问题、写作、规划、文件。”在你选别的助手之前，开始页默认选的是通用。它是为不一定懂编程的人写的。

- 它会弄清你想要什么，然后去做。只有当请求不清楚、而且会影响结果时，它才会问一个简短的问题；否则它会做出合理的选择，并说明选了什么。
- 遇到有时效性的内容或它没把握的事，它会上网搜索；它会阅读你指给它的文件，并把你会想保留的成果存成会话文件夹中的文件；如果是你会反复使用的页面，比如追踪表或计算器，就存到你的[资料库](/guide/library)中。
- 它先给出答案，再讲重要的细节，用浅白的话，遇到避不开的专业术语会加以解释。
- 如果创建或修改了文件，它最后会说明是哪些文件、放在哪里。

### 研究员

“查找并核实来源，并注明出处。”

1. 它会用一句话复述你的问题，把宽泛的问题拆成几个需要回答的子问题。
2. 下结论之前，它会广泛搜索：换不同的说法做多次网络搜索，在合适的搜索类别中查找（论文、新闻、专利、公司公告、数据集），需要全面覆盖一个主题时会获取更多结果。
3. 它会阅读重要的来源，而不是只凭摘要片段回答，并优先采用一手和权威的来源：原始论文和数据、官方网站、公认的专家和媒体。它会记下每个来源的日期；如果事实会随时间变化，它会说明答案的时效。
4. 来源之间有分歧时，它会指出来，并按质量和新旧加以权衡，同时把已有定论的、有争议的和未知的内容区分开。
5. 它边写边注明出处：每个说法后面加一个编号标记，如 [1]，并在末尾列出来源，包括标题、作者或出版方、日期和链接。它从不编造来源、引文、数字或链接；有无法核实的内容时，它会如实说明。
6. 它先用简短的摘要给出结论，然后是细节，最后是仍不确定的地方。长篇报告还会另存为会话文件夹中的 Markdown 文件。

对于需要大量搜索的大问题，请参阅[深度研究、第二意见和多个智能体](/guide/research)中的深度研究。

### 撰稿人

“起草、编辑并润色你的文字”：电子邮件、信件、帖子、文章、报告、故事和演讲稿。

- 写长篇之前，它会先确认读者、目的、语气和篇幅。其中某一项不清楚又很重要时，它会简短地问一下；否则就用一句话说明它的假设，然后动笔。
- 它写得平实而具体：用词具体，要点先行，句式有变化，不说空话套话。
- 它会采用你要求的风格；如果你分享过以前写的东西，它会贴合你自己的风格。
- 修改你的文字时，它会保留你的意思和风格：改正错误，收紧松散之处，保留写得好的部分，并简要列出主要改动。
- 超过几段的内容都会存成会话文件夹中的文件（默认是 Markdown，除非你想要别的格式），并告诉你存在哪里。
- 遇到重要的选择（邮件主题、标题、开头），它会提供两三个选项。

### 程序员

“构建、修复和讲解软件。”程序员是在你的项目里工作的软件工程师，所以和其他内置助手不同，它在你于开始页上选择的文件夹中工作，而不是在新的任务文件夹中。

- 改动之前，它会先阅读相关的代码，并遵循项目的惯例和工具。
- 它只改你要求的部分；发现的其他问题会告诉你，而不是擅自去修。
- 改完代码后，如果项目有测试、构建或代码检查工具（linter），它会运行它们，并修复失败的地方。
- 如果你看起来是编程新手，它会用浅白的话解释它做了什么、怎么运行。
- 最后它会给出简短的总结：改了什么、怎么验证的，以及还有什么没做。

### 辅导老师

“一步步讲解，并确认你跟得上。”目标是让你真正理解，而不只是得到一个答案。

- 如果不清楚你的水平或目标，它会先快速问一个问题。
- 它一次讲一步，用浅白的话，每个新概念都配一个具体的例子，由浅入深。
- 每讲完一步，它会用一个简短的问题或小练习检查你是否掌握，等你回答后再继续。
- 你回答后，它会指出哪里对了，并和善而具体地纠正不对的地方，还会随时调整：你卡住时换一种讲法或例子，你学得快时加快进度。
- 遇到作业或练习题，它会用提示和提问引导你，只有在你要求、或者你尝试后仍然卡住时，才给出完整解答。
- 当图比文字讲得更清楚时，它会在会话中展示一张示意图或一个小型互动页面；每讲完一个主题，会做一个简短的回顾。

### 规划师

“规划旅行、活动和项目”，搬家和日常安排也可以。

- 首先，它会确定影响计划的要素：目标、日期和截止时间、预算、涉及的人以及硬性限制。对缺少且重要的少数几项，它会询问你；其余的则采用合理的默认值，并说明它做了哪些假设。
- 它会上网核实计划所依赖的事实（营业时间、路程时间、价格、是否有空位、相关规定），并指出哪些无法核实或可能变化。
- 它会把计划做得很具体：一条时间线或按天的日程，写明时间、地点、费用和分工，为可能延误的事情留出余地，并列出需要先预订或先决定的事项。
- 遇到重要的选择，它会给出两三个选项并说明各自的利弊。涉及花钱时，它会附上一份带总额的预算。
- 它会把计划存成会话文件夹中的文件（Markdown；适合放进电子表格的预算和日程则用 CSV），并主动提出可以再调整。

### 分析师

“用图表帮你看懂数据和电子表格”：电子表格、CSV 文件、导出的数据和各种数字。

- 分析之前，它会先查看数据（列、规模、类型和缺口），在下结论之前报告缺失值、重复项或奇怪的格式等问题。
- 它用代码计算（一段简短的 Python 或 JavaScript 脚本，或一个公式），从不靠目测估算，并把脚本保存在会话文件夹中，方便重复这项工作。
- 它先用浅白的话和关键数字回答问题，再展示这些数字是怎么得出的。它会说明假设和局限，不会声称数据无法证明的因果关系。
- 有帮助时，它会在会话中的页面上用图表和表格展示结果：选用最简单的合适图表（比较用柱状图，随时间变化用折线图），坐标轴标注清楚、带单位，在手机上也看得清。
- 如果你会需要，它会把清理后的数据和结果存成文件（CSV；你要求时也可以是 XLSX）。

### 应用搭建师

“制作你自己的应用：表单、步骤、数据和界面”（见[应用](/guide/apps)）。

- 它先弄清楚输入什么、输出什么、一次好的运行是什么样子，只问会影响设计的问题，并说明它做了哪些假设。
- 它用自己的工具搭建应用，为每个部分选最省的步骤（一个工具、一次快速的模型回答、一条规则、代码），需要判断的地方才用智能体。
- 它给应用配上两到四个带检查的示例，试运行它们，把没通过的修好之后再交给你，并说明一次运行要花多少钱、用多长时间。
- 你自己修改了应用时，它会在你的修改之上继续。
- 它使用 app-builder 技能。

## 以某个助手开始会话

1. 打开[开始页](/)。消息框下方有一行显示由谁来做：智能体、模型、文件夹，以及**助手**标签，上面写着当前选中的助手。
2. 点击**助手**。在**以以下身份开始**下，先列出内置助手，然后是**你的**下面你自己的助手。
   - 在电脑上，助手名称排成网格，每行两个。把鼠标指向其中一个，就会在网格下方看到它的说明：它的描述；如果它建议了智能体，还会显示“使用”加上那个智能体及其模型。
   - 在手机上，菜单会以面板形式从屏幕底部弹出，列出每个助手及其说明。
3. 选择一个。然后输入你的任务，按 Enter 或点击**开始**。

菜单末尾的**创建或修改助手**会打开[设置 → 助手](/settings?s=assistants)。

在开始页上选择一个助手会带来这些变化：

- **智能体、模型和权限**：如果助手建议了某个智能体，开始页会切换到它；如果助手指定了模型，也会一并换上。如果助手设了权限模式，开始页的**权限**（在**选项**下）会换成该智能体对应的模式。开始之前，这些你都还可以更改。
- **连接**：助手开启的已连接账户，在新会话中都会开启。
- **文件夹**：除非你自己选了文件夹，否则由助手决定。大多数助手从**新建任务文件夹**开始；程序员，以及设置为“开始页上的文件夹”的助手，则使用显示的那个文件夹。

无论你在哪台设备上，开始页打开时都会选中你上次选择的助手；第一次使用时是通用。开始页这样打开时，你的其他选择（智能体、模型、权限）保持你离开时的样子；只有选择助手才会改变它们。如果你上次选的助手已被删除，则改为选中通用。

在文件夹菜单中选择一个项目时，如果该项目设定了会话开始时使用的助手，也会同时选中那个助手（见[项目](/guide/spaces)）。

## 在会话中切换助手

会话的消息框会显示它当前使用的助手，你随时可以换成另一个：比如资料查齐之后，从**研究员**换成**撰稿人**。

1. 它是消息框下方那个打开**选项**的按钮里的第一行，而那个按钮也会先写出它的名称，例如“研究员 · Opus 5.5”。
2. 点击它。在**切换到**下面选另一个助手：和开始页上的菜单一样，在电脑上是网格，在手机上是从屏幕底部弹出的面板。
3. 应用会提示“从你的下一条消息起，智能体将以 *名称* 的身份工作”。

从你的下一条消息起，智能体就以新的助手工作，对话照常继续：

- 智能体会随你的消息得知这次切换（对话中不会显示这一点）。
- **Claude Code 和 Codex** 在启动时读取指令，所以会话空闲时，它的智能体会在你的消息之前重新启动，带上新助手的指令和限制；这条消息会稍慢一点。如果正在一轮工作之中，或者智能体正朝着目标工作、有后台任务，它会随你的消息收到新的指令，等之后空闲时，再在某条消息之前重新启动。
- **Custom** 在每一轮之前读取指令。其他智能体（Gemini CLI、OpenCode……）会随你的消息收到新助手的指令。
- 新助手开启的已连接账户会在这个会话中开启，取代上一个助手开启的；你自己为这个会话开启或关闭的保持不变。如果它设定了权限模式，会话会换成对应的模式；如果它建议的正是这个会话的智能体，还会换成它的模型。智能体本身不变：要把对话转给另一个智能体，见[转到另一个智能体继续](/guide/sessions#continue-in-another-agent)。

不是以助手开始的会话（在 VS Code 或终端里开始的，或在应用有助手之前开始的）在那里显示**无助手**：选一个就能给它配上助手。会话菜单（⋯）→ **会话设置** → **助手** 也会显示它的名称；点击它会打开[设置 → 助手](/settings?s=assistants)。

## 创建你自己的助手

1. 打开[设置 → 功能 → 助手](/settings?s=assistants&find=New%20assistant)，点击**新建助手**（或在开始页上点击**助手**标签 → **创建或修改助手**）。
2. 填写下面的各项。只有名称是必填的。
3. 点击**保存**。应用会提示“现在可以在开始页面选择 *名称* 了”，它也会出现在开始页助手菜单的**你的**下面。

在手机上，编辑器会以面板形式从屏幕底部弹出。你最多可以保存 200 个自己的助手。

各个字段，从上到下：

- **图标**：名称左边的图标。点击它可以从 30 个中选一个（望远镜、钢笔、厨师帽、飞机、钱包等等）。
- **名称**：最多 60 个字符，例如“记账员”或“旅行顾问”。
- **一句话介绍**：最多 160 个字符，显示在开始页的菜单中，例如“把家庭账目打理得井井有条”。
- **指令**：它是谁、怎样工作，最多 20,000 个字符。每次以它开始会话时，智能体都会先读这段文字。可以照内置助手的写法来写：“在本次会话中，你是用户的记账员”，然后用几行说明它怎样工作（“需要哪些对账单就向用户要”“把各项合计记在工作文件夹里的电子表格中”）。
- **它的会话从哪里开始**（开始页上没有选择文件夹时）：
  - **新的任务文件夹**（默认）：每个会话都有一个属于自己的全新文件夹（见[任务文件夹](#task-folders-where-a-task-without-a-folder-works)）。
  - **开始页上的文件夹**：会话在开始页显示的文件夹中工作，和程序员一样。在项目中工作的助手请选这一项。
- **智能体和模型**：它建议使用的智能体，在开始页上选中这个助手时会一起选上。
  - **任意智能体**（默认）：沿用开始页上选中的智能体。
  - **Claude Code**、**Codex**、**Custom**（“任意模型”），或你在[设置 → 智能体 → 更多智能体](/settings?s=agents)中添加的任何智能体。
  - 选定智能体后，旁边会出现一个模型菜单，列出该智能体的模型（适用于提供多个模型的智能体）；不去动它，就使用该智能体的默认模型。
- **权限模式**：智能体在什么情况下要先问你。
  - **沿用所选**（默认）：沿用开始页上选中的模式。
  - **询问**：修改文件和运行命令之前都会先问。
  - **接受编辑**：可以随意修改文件，运行命令前会先问。
  - **完全访问**：从不询问。
  - **计划**：在你批准之前，只阅读和制定计划。

  Claude Code、Codex 和 Custom 都有与这些对应的模式。其他智能体（Gemini CLI、OpenCode…）则保留它们自己的模式。
- **它可以使用什么**：五个开关，新助手全部开启（见下文）。
- **优先使用的技能**：技能名称，一次添加一个（见下文）。
- **连接**：有已连接的账户时才显示（见下文）。

**取消**会关闭编辑器，不保存。

### 它可以使用什么

每个开关对应一类工具：

- **读取文件**：打开、列出和搜索文件与文件夹。
- **创建和修改文件**：写入新文件，编辑已有文件。
- **运行命令**：在这台电脑上运行程序和脚本。
- **使用网络**：搜索和阅读网页。
- **其他工具**：为智能体设置的 MCP 服务器（工具服务器）和插件。

关掉的开关会产生什么效果，取决于智能体：

- **Claude Code 和 Custom**：这些工具会被直接关闭。关闭**其他工具**后，Claude Code 只能使用应用自带的工具和你已连接的账户，你自己设置的 MCP 服务器一个都用不了。
- **Codex**：会被告知不要使用它们。关闭**使用网络**后，它自带的网络搜索也会关闭。如果关闭**运行命令**但开着**读取文件**，Codex 会被告知只能用 shell 读取和搜索文件，因为它是通过 shell 来读文件的。
- **其他智能体**：会被告知不要使用它们。

应用自带的工具（页面、记忆之类）会保持开启，除非它们属于你关掉的某个开关：关闭**使用网络**后，应用的网络搜索、网页阅读和浏览器也会一并关闭；关闭**读取文件**后，它的文档阅读器也会关闭。已连接的账户不算“其他工具”：它们由下面的**连接**决定。当任务需要助手无法使用的东西时，智能体会被告知直接说明，而不是想办法绕过去。

### 优先使用的技能

输入技能名称后按 Enter（或输入逗号）即可添加。输入框会建议 Claude Code 和 Codex 自己的技能，也就是[设置 → 智能体 → 技能](/settings?s=skills)针对“文件”中打开的文件夹所列出的那些；你也可以输入技能库中某个技能的名称，例如 research。点击名称旁边的垃圾桶可以去掉它。最多 30 个。当其中某个技能适合任务时，智能体会在开始前加载并遵循它。应用自带哪些技能、如何添加更多技能，见[技能](/guide/skills)。

### 连接

只有当你有已连接的账户（在[应用 → 已连接的应用](/apps/connected)中设置）时，才会显示这一部分。每个账户都有一个开关：开启表示在这个助手的会话中开启它。已经对所有会话开启的账户会显示“对所有会话开启”。如果助手指定的某个账户已不再连接，它会显示为“（未连接）”，并带有一个移除按钮。见[已连接的应用、密钥和工具](/guide/connections)。

## 修改、复制或删除助手

在[设置 → 助手](/settings?s=assistants)中，每个助手所在的行上都有它的按钮。内置助手带有**内置**标记；导入的助手带有**已导入**标记。

- **编辑**（铅笔图标，仅限你自己的助手）：打开同一个编辑器。**保存**会保留更改（“*名称* 已保存”）。之后你开始的会话会使用新版本；已经在进行中、使用这个助手的会话，也会从你的下一条消息起采用：Custom 在每一轮之前读取它，Claude Code 和 Codex 会在空闲时重新启动（对话照常继续）。
- **创建副本**（两个方块图标，每个助手都有）：以新助手的形式打开编辑器，所有内容都已填好，名称为“*名称* (copy)”。改你想改的，然后**保存**。要做一个属于你自己的内置助手版本，就用这个方法。
- **删除**（垃圾桶图标，仅限你自己的助手）：会先询问“删除 *名称*？”。以它开始的会话会继续进行，只是不再带有它的指令。

搜索框（Ctrl+K，Mac 上为 ⌘K）也能按名称和描述找到助手；选中一个会打开“设置 → 助手”并定位到它。

## 导入 Claude Code 的智能体文件

Claude Code 可以把它自己的智能体保存为 `.claude/agents` 文件夹中的 Markdown 文件：开头是一小段文件头，写着智能体的名称、描述、模型和工具，下面是它的指令。应用会把这些文件转换成助手，这样这里的每个智能体都能按那种方式工作。

1. 打开[设置 → 助手](/settings?s=assistants)，点击**导入**。
2. **导入 Claude Code 智能体**会列出它找到的智能体文件：你自己的在 `~/.claude/agents` 中（标记为**你的**），以及在[文件](/files)中打开的文件夹里 `.claude/agents` 文件夹中的那些（标记为**此文件夹**）。要查看某个项目自己的智能体，请先在“文件”中打开该项目。
3. 点击文件旁边的**导入**。它对应的助手随即就可以在开始页上选用了。
4. 如果文件在别的地方，点击**选择文件**（“或此设备上的智能体文件”），然后选择那个 `.md` 文件。

文件必须是 Markdown（`.md`），最大 256 KB。应用会从中提取以下内容：

| 智能体文件中 | 助手中 |
|---|---|
| `name`（没有时用文件名） | **名称**：“code-reviewer”变成“Code reviewer” |
| `description` | **一句话介绍**：取它的第一句，不含示例 |
| `model` | **智能体和模型**：Claude Code 加上该模型（“inherit”表示沿用开始页上的模型） |
| `tools` | **它可以使用什么**，按类别对应；没有 tools 这一行的文件可以使用全部工具 |
| `permissionMode` | **权限模式**：default → 询问，acceptEdits → 接受编辑，bypassPermissions → 完全访问，plan → 计划 |
| `skills` | **优先使用的技能** |
| 文件头下方的文字 | **指令** |

图标会根据智能体的名称和描述来选（研究用望远镜，写作用钢笔，审查和测试用代码图标，等等）。导入的助手在开始页上的文件夹中工作，就像 Claude Code 的智能体在项目中工作一样。

已导入的文件在列表中显示的是**更新**，而不是**导入**。**更新**会重新读取文件，写入同一个助手：它的各个字段会重新变成文件中的内容，只有你选的图标保持不变。从你的设备选择文件，则总是会新建一个助手。

## 任务文件夹：没有指定文件夹的任务在哪里进行

很多任务并不属于哪个文件夹：一份旅行计划、一封信、一个问题。对于这些任务，开始页上的文件夹标签会显示**新建任务文件夹**；当你按下**开始**时，应用会为会话新建一个文件夹，以日期和你消息中的几个词命名，例如 `~/Hydor/2026-10-31-plan-trip-lisbon`。智能体会把成果保存在那里，你之后可以在[文件](/files)中再找到它。

名称是这样生成的：

- 日期，按你所在的时区。
- 你消息中的最多五个词，略去虚词（a、the、please、help、me…）、链接和开头的 `/command`，并去掉重音符号，最多 40 个字符。如果一个词都不剩，就用 `task`。
- 如果这个名称已被占用，会加上 `-2`、`-3` 等后缀。

### 选择任务文件夹或你自己的文件夹

打开开始页上的文件夹标签：

- **新建任务文件夹**（“位于 ~/Hydor”）会为每个会话新建一个文件夹。
- 选择一个项目、一个最近用过的文件夹，或输入名称或路径找到的任意文件夹，会话就会改在那里进行（见[项目](/guide/spaces)和[会话](/guide/sessions)）。

在你做出选择之前，由助手决定：除程序员以外的内置助手，以及你自己设置为“新的任务文件夹”的助手，会使用任务文件夹；程序员和设置为“开始页上的文件夹”的助手，会使用显示的文件夹。开始页会记住你的选择。选择另一个助手会把决定权交还给助手，除非你在页面打开后选过文件夹。

任务文件夹不会挤满文件夹菜单：菜单中列出的最近用过的文件夹不包括它们。在免提模式下用语音开始的会话也会得到一个任务文件夹，除非开始页上次设置的是某个文件夹或项目（见[文档、图片、视频和语音](/guide/documents-voice)）。

### 移动任务文件夹

1. 在[设置 → 功能 → 助手](/settings?s=assistants&find=Task%20folders)中找到**任务文件夹**（“未指定文件夹就启动的会话，会在这里获得一个新文件夹，以日期和任务命名”）。
2. 点击文件夹的名称。在**工作文件夹**下输入一个路径（输入时会建议文件夹，也会列出你最近用过的文件夹），然后点击**使用此文件夹**。请填写完整路径，或以 `~` 开头表示你的主文件夹。

从此以后，新的任务文件夹都会放在那里；已经建好的文件夹留在原处。改过位置后会出现**改回 ~/Hydor**，用来恢复默认。下方的一行会显示新文件夹的样子。获得自己文件夹的新项目，也会把文件夹建在这里，放在其中的 **Spaces** 文件夹里（见[项目](/guide/spaces)）。

## 任务完成后清理

[设置 → 功能 → 助手](/settings?s=assistants&find=Clean%20up%20after%20a%20task)中的**任务完成时**有一个开关：**任务完成后清理**。除非你关掉它，否则它一直开启，并且适用于所有智能体，不管用的是哪个助手。

开启后，智能体在任务中的最后一步，是清理它在过程中创建、已不再需要的东西：

- 草稿和测试文件、临时文件夹和数据、调试输出和截图；
- 它创建的、已合并或已放弃的 git 分支、工作树（仓库的额外副本，每个都在自己的分支上）和储藏（stash）；
- 它启动的进程、服务器或容器，除非你希望它们继续运行。

它会保留你要的成果，以及还需要有人审查或合并的工作（比如有未合并提交的分支），绝不删除不是它创建的东西；遇到大的或不确定的内容（比如一个很大的下载、任何共享的东西），会先问你。它会逐一点名要删除的东西，而不是按通配模式批量删除，并用一句话说明删了什么、留下了什么。应用自带的 clean-up 技能里写有具体做法（见[技能](/guide/skills)）。

关掉它，智能体就会把创建的东西留在原处。无论开还是关，智能体都会从下一个会话起按新设置执行（Custom 从下一条消息起）。

## 助手还会在哪些地方用到

- **项目**：项目可以指定它的会话以哪个助手开始（“它的会话开始时使用”）；在开始页上选中该项目时，就会选中那个助手。见[项目](/guide/spaces)。
- **应用**：应用可以指定一个**助手**，它的运行就会以该助手开始（来自公开页面的运行除外）。见[应用](/guide/apps)。
- **定时任务**：智能体在会话中为你设置的任务，会像那个会话一样运行，使用同一个助手。见[定时任务](/guide/tasks)。
- **免提语音**：你用语音开始的会话，会以开始页上最后选中的助手开始。
