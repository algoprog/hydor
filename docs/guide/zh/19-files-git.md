# 系统：文件、Git、终端和预览

侧边栏中的**系统**就是这台电脑：浏览、查找、打开和编辑它的文件，把它们添加到项目和新会话中，在文件内容中搜索，运行 Jupyter 笔记本，用 Git 提交和推送，创建拉取请求，以及审查一个分支改了什么。终端、这里运行的网页应用的预览、智能体修改某个网页应用前后的截图，以及这台电脑运行状况的实时视图（监控）也都在这里，所以你不用离开应用，就能检查并完成智能体的工作。

![系统 → Git：仓库的更改、其中一个文件的改动、提交框，以及“同步”](images/files-git.webp)

## 打开系统

点击侧边栏工具中的**系统**，或前往[系统](/system)。标题下方有一排标签页，分别带你前往各个部分，每个部分都有自己的地址：

- **概览**（[打开](/system)）：这台电脑的概况，以及每个工具现在有什么（参见[概览](#the-overview)）。
- **文件**（[打开](/files)）：这台电脑上的文件（参见[打开文件页面](#open-the-files-page)）。
- **Git**（[打开](/git)）：你的仓库（参见[在 Git 页面查看你的仓库](#see-your-repositories-on-the-git-page)）。
- **终端**（[打开](/terminal)）：这台电脑上的 shell（参见[使用终端](#use-the-terminal)）。
- **预览**（[打开](/preview)）：这里运行的网页应用（参见[用预览查看开发服务器](#look-at-a-dev-server-with-preview)）。它只出现在这台机器自己的页面上，你在查看另一台机器时不会出现。
- **监控**（[打开](/system/monitor)）：这台电脑有多忙（参见[在监控中查看这台电脑](#watch-this-computer-in-monitor)）。
- **实验**（[打开](/system/experiments)）：等待空闲 GPU、自行运行并作为记录保存下来的作业（参见[实验](/guide/experiments)）。

在手机上，标题显示你所在的部分（**系统 / 监控**）：点按它即可看到系统的所有部分，每行四个，点按其中一个即可前往。标签页自己的按钮（Git 的**添加**、预览的刷新按钮）位于标题右侧。

## 概览

**概览**的顶部显示电脑的名称、它的系统和已经运行了多久，以及四个仪表：**处理器**、**记忆**（即内存）、**磁盘**（主磁盘，以及它的可用空间）和**显卡**（有 NVIDIA 显卡时）。仪表快满时会变成红色。点击它们可以打开**监控**。

下面是每个工具各一张卡片；点击卡片的标题或**打开**，就会打开它的标签页：

- **文件**：一个搜索框，可以搜索文件名和文件里的文字（从你的主文件夹开始搜索），你最近打开的文件，以及**主文件夹**、**最近的文件**和**废纸篓**。
- **Git**：你的仓库，有更改或有待推送提交的排在前面，每个都显示它的分支和改了多少个文件。点击一个，就会在 Git 标签页中打开它。
- **终端**：正在运行的 shell，以及用来再开一个的**新增**。
- **预览**：这里运行的网页应用，每个都显示它的端口。点击一个即可查看它。
- **实验**：正在进行的运行，每个都显示它的状态和指标。点击一个即可打开它。

## 打开文件页面

点击**系统**，然后点**文件**，或前往[文件](/files)。在电脑上，这个页面分为两部分：

- 左边是**位置**：你最近打开的文件、你的主文件夹、你置顶的文件夹、各个项目的文件夹、会话工作过的文件夹，以及废纸篓（见[位置](/guide/files-git#places)）。
- 右边是你所在的文件夹及其中的内容（见[浏览文件夹](/guide/files-git#browse-a-folder)）。你打开的文件也显示在那里，每个文件一个标签页：第一个标签页会回到文件夹。

在较小的窗口中，位置会收进标题右侧的一个按钮里：它显示你所在的文件夹，点击它就会列出各个位置。

在手机上，文件夹占满整个屏幕。轻点右上角的文件夹名称，位置会从屏幕底部升起；标题下方带有上一级文件夹名称的 **‹** 会回到上一级文件夹，手机的返回键则回到你之前所在的文件夹。文件会在单独的页面上打开，带有**返回**。

其他打开方式：

- 点击会话标题下方的文件夹，或使用会话的菜单（⋯）→ **文件夹与代码** → **浏览文件夹**：“文件”会在那个文件夹打开。
- 智能体改过或交给你的文件，或它回复中指向某个文件的链接，会在对话上方的窗口中打开，这样你不会丢失当前的位置。**在“文件”中打开**会把它移到文件页面；✕ 或 Esc 会关闭它（如果你改了却没保存，它会先问“放弃你的更改？”）。文件的路径显示在它上方，和“文件”页面一样；从这里前往某个文件夹时，窗口会先关闭，并询问是否保存未保存的更改。见[它制作或修改的文档](/guide/documents-voice#documents-it-made-or-changed-and-file-names-in-its-reply)。
- 项目的**文件**标签页显示项目自己的文件夹（见[项目和知识库](/guide/projects)）。

## 位置

- **前往文件夹**：按名称查找文件夹，或输入它的路径（`~/code/shop`）；项目和置顶的文件夹排在最前。按 Tab，或点击一行末尾的箭头，会列出其中的文件夹。
- **最近的文件**：你最近在这个浏览器中打开的文件，最近打开的排在最前，每个都显示它所在的文件夹。已经不存在的会标明这一点；**清除已不存在的**会把它们从列表中去掉。
- **主文件夹**：你自己的文件夹，你的文件都在这里。新会话开始时所在的文件夹如果不是你的主文件夹，会显示在它下面。
- **已置顶**：你置顶的文件夹，在每台设备上都一样。要置顶一个文件夹，使用它的菜单或文件夹的 ⋯ → **在“位置”中置顶**；要取消置顶，把鼠标指向它并点击 ✕，或使用**从“位置”中取消置顶**。
- **项目**：每个项目自己的文件夹。
- **会话工作过的文件夹**：会话最近工作过的文件夹。
- **废纸篓**：你删除的东西（见[删除和放回](/guide/files-git#delete-and-put-back)）。

在电脑上，把文件或行拖到位置中的某个文件夹上，就能把它们放到那里。

## 浏览文件夹

文件夹上方的工具栏从左到右依次是：

- **上一级文件夹**（向上的箭头）。
- 文件夹的路径，一级一级显示：主文件夹显示为一个房子图标，后面是 **code › shop**；主文件夹之外的文件夹从**电脑**（`/`）开始。点击某一级即可前往那里，把行拖到它上面则会移到那里。路径太长时，中间部分会收进 **…**，点击它会列出中间的文件夹。最后一级，或它旁边的小箭头，会打开**前往文件夹**。
- **在 *文件夹* 中查找**：随着你的输入，把列表缩小到名称中包含所输入内容的项。按 Enter，或点击列表顶部的**搜索整个 … 中的“…”，包括文件内容**这一行，会搜索这个文件夹下的每个文件夹，包括文件名和文件里的内容（见[搜索文件](/guide/files-git#search-files)）。
- **新增**：**新建文件夹**、**新建文件**、**新建笔记本**、**上传文件**和**上传文件夹**。
- **以列表显示**或**以图块显示，带缩略图**：图块会直接显示图片本身，很适合用来浏览照片。
- **更多**（⋯）：**排序方式**（**名称**、**修改日期**、**大小**或**类型**，以及**反向排序**）、**显示隐藏文件**、**在“位置”中置顶**、**在此文件夹中新建会话**、**在此处打开终端**、**复制路径**、**下载为 .zip** 和**刷新**。

列表中文件夹排在前面。每一项都显示名称、修改时间（“刚刚”、“5 分钟前”、当天的时间、“昨天”或日期）和大小。点击某一列的标题即可按它排序，再点一次则反向排序。在较窄的窗口中，工具栏会把查找字段收到一个搜索按钮后面，**以列表显示**和**以图块显示，带缩略图**会移到**更多**里；日期和大小两列会让位给名称。

- 点击文件夹即可进入它，点击它的箭头则会像文件树那样就地展开；文件夹会记住其中哪些文件夹是展开的。
- 点击文件即可打开它。
- 底部的一行会统计文件夹和文件的数量，并合计它们的大小。
- 你查看列表时，它每 5 秒自动刷新一次，所以智能体新建的文件会自己出现。

在手机上，每一行会在名称下面显示大小和日期；搜索按钮会打开查找字段，**更多**里还有**以列表显示**、**以图块显示，带缩略图**和**多选**，右下角的 **+** 按钮可以添加文件夹、文件或上传。

每个文件夹都有自己的地址，所以浏览器的返回会回到你之前所在的文件夹。显示的这个文件夹，也就是应用其他地方所说的“‘文件’中打开的文件夹”。它保存在这个浏览器里，你用的每台机器各自分开保存（见[其他机器](/guide/devices#use-other-machines-from-one-app)）。

### 文件旁边的字母是什么意思

在 git 仓库（由 git 保存历史记录的文件夹）里，自上次提交以来有改动的文件会带有一个字母和一种颜色：

- **M**：已修改。
- **A**：新文件，已经添加到 git。
- **U**：新文件，还没有加入 git。
- **D**：已删除。
- **R**：已重命名。
- **C**：有待解决的冲突。
- **•** 出现在文件夹上：里面有东西改动了。

## 处理文件和文件夹

每一行都有一个菜单。把鼠标指向这一行并点击行末的**更多**（⋯），或右键点击它；在手机上，轻点它的 ⋯。菜单里有：

- **打开**。
- **编辑图片**或**编辑视频**（图片或视频）：在图片或视频编辑器中打开它，在那里**保存**会覆盖这个文件（它的旧版本会进入废纸篓），**另存副本**则会在它旁边放一个“名称 (edited)”（见[编辑图片和视频](/guide/library#edit-pictures-and-videos)）。
- **用它开始会话**（文件；见[用文件开始会话](/guide/files-git#start-a-session-with-files)），或**在此文件夹中新建会话**（文件夹：打开开始页，并已选好那个文件夹）。
- **添加到项目**（见[把文件添加到项目](/guide/files-git#add-files-to-a-project)）。
- **在“位置”中置顶**或**从“位置”中取消置顶**（文件夹）。
- **重命名**（F2）、**创建副本**、**移到**和**复制到**。
- **在此处打开终端**（文件夹）：在那个文件夹中打开一个新的 shell，电脑上在底部面板中，手机上在终端页面上。
- **复制路径**：完整路径，可以粘贴到任何地方。
- **下载**；文件夹则是**下载为 .zip**。
- **删除**（Delete 键）。

### 多选

要一次处理多样东西，先把它们选中：

- 在电脑上，点击行首的方框（把鼠标指向这一行时才会出现），按住 Ctrl 点击（Mac 上是 ⌘+点击）可以再加选一项，按住 Shift 点击会选中从上一次选中的那一项到这一项之间的全部，按 Ctrl+A 则全选。
- 在手机上，长按一行，再轻点其他行；或者用**更多** → **多选**。

这时工具栏会显示选中了多少项，并提供**开始会话**、**添加到项目**、**移到**、**删除**，以及放着菜单其余各项的**更多**（⋯）：**复制到**、**复制路径**、**下载为 .zip** 等。✕（或 Esc）会全部取消选择。

### 使用键盘

在电脑上，列表处于使用状态时（先点击一下列表）：

| 按键 | 作用 |
| --- | --- |
| ↑ ↓ | 移到上一行或下一行（按住 Shift 会边移边选） |
| → ← | 就地展开或收起文件夹；在图块视图中，移到旁边的图块 |
| Enter | 打开 |
| 空格键 | 选择或取消选择 |
| Backspace | 上一级文件夹 |
| Delete | 删除 |
| F2 | 重命名 |
| Ctrl+A | 全选 |
| Esc | 全部取消选择，然后清空查找字段 |

直接输入一个字母，就会在查找字段（**在 *文件夹* 中查找**）里以它开始查找。

### 新建文件或文件夹

1. 点击**新增** → **新建文件夹**、**新建文件**或**新建笔记本**（在手机上，用 **+** 按钮）。
2. 在列表中出现的字段里输入名称，然后按 Enter。按 Esc 取消。

新文件是空的，会立即在编辑器中打开。新笔记本叫 `Untitled.ipynb`（这个名字已被占用时叫 `Untitled 2.ipynb`），除非你输入别的名字；它从一个空的代码单元格开始，并以笔记本的形式打开。名称以 `.ipynb` 结尾的新文件，同样以空笔记本开始。如果名称已被占用，应用会告诉你，并且不会新建任何东西。

### 重命名或移动

- **重命名**会把名称变成一个输入字段。按 Enter 保留新名称，按 Esc 则保持原样。
- **移到**会先列出你的项目和置顶的文件夹，然后是最近用过的文件夹，还有一个字段，可以按名称查找任何文件夹，或输入它的路径。选一个，文件或文件夹就会移到那里。一条消息会告诉你它去了哪里，并带有**撤销**。
- 在电脑上，把行拖到某个文件夹上（列表中的文件夹、路径中的某一级，或位置中的文件夹）即可移到那里；一起选中的文件会一起移动。放下时按住 Alt（Mac 上是 Option）则改为复制。

文件夹不能移进它自己，移动也不会替换任何东西：如果目标位置已经有同名的东西，移动就会停止。

### 创建副本和复制

- **创建副本**会在旁边做一份副本，名称后面加上“copy”（`report copy.pdf`，然后是 `report copy 2.pdf`）。
- **复制到**会复制到另一个文件夹，选择方式和**移到**一样。如果那里的名称已被占用，副本也会按同样的方式命名。消息上的**显示**会打开那个文件夹。

### 删除和放回

**删除**会立即把文件，或者文件夹连同里面的所有东西，移到废纸篓，并显示一条带有**撤销**的消息。在你清空废纸篓之前，什么都不会丢失。

位置中的**废纸篓**会列出你删除的东西，最近删除的排在最前：每一项都显示它原来在哪里、什么时候删除的以及大小。

- **放回原处**会把它放回原来的位置。如果之后有别的东西占了它的位置，它会回到旁边，名称后面加上“copy”。在应用开始记录原位置之前删除的东西，则会让你选择一个文件夹。
- 它的**更多**（⋯）里有**放到其他文件夹**和**永久删除**。
- **清空废纸篓**会在你确认后永久删除其中的所有东西。

废纸篓是应用数据文件夹中的一个文件夹（例如 `~/.hydor/trash`）；它的页面会写明在哪里。你的主文件夹和顶层文件夹（`/`）不能删除。与应用数据文件夹不在同一块磁盘上的东西无法进入废纸篓：应用会先询问“永久删除 …？”。

### 下载

文件会按原样下载。文件夹，或一起选中的多样东西，会下载为一个 .zip 文件，边下载边打包。.zip 会略过 `.git` 和 `node_modules` 文件夹，最多容纳 4 GB 和 65,000 个文件。

## 把文件添加到项目

项目把一个项目的文件放在它的文件夹里，也可以就地使用你的其他文件夹（见[项目和知识库](/guide/projects)）。要添加到项目：

1. 打开文件或文件夹的菜单（或者选中多项），点击**添加到项目**。
2. 选择项目，或点击**新建项目**先为它们创建一个。

文件会被复制到项目的文件夹中。文件夹不会被复制：它会留在原处，加入项目使用的文件夹。一条消息会说明添加了什么，并带有**显示**，点击它会打开项目的**文件**标签页。已经在项目里的东西保持不变。

编辑器中文件的**更多**（⋯）、文件在会话上方打开的窗口、智能体交给你的文件卡片，以及智能体生成的图片上，也都有**添加到项目**。

之后你在这个项目里启动的会话就能在那里找到这些文件：每个会话都会被告知项目的文件夹里有什么，以及项目还使用哪些其他文件夹。

## 用文件开始会话

要让一个新会话带着一些文件开始：

1. 打开文件的菜单（或者选中多项），点击**用它开始会话**（或者选中项工具栏上的**开始会话**）。
2. 开始页会打开，这些文件已经放在消息框里，每个都标着“在这台电脑上”。用 ✕ 可以去掉某个文件，用回形针可以从你的设备添加文件，智能体和文件夹照常选择。
3. 输入要用它们做什么，然后按**开始**。

什么都不会上传：消息会按路径写明每个文件，智能体就在原处打开它；图片（PNG、JPEG、GIF 和 WebP，最大 5 MB）还会发给模型查看。一条消息最多带 20 个文件。

对于文件夹，**在此文件夹中新建会话**会打开开始页，并把会话设为在其中工作。

编辑器中文件的**更多**（⋯）、文件在会话上方打开的窗口、智能体交给你的文件卡片，以及智能体生成的图片上，也都有**用它开始会话**。

## 上传文件和文件夹

- **新增** → **上传文件**或**上传文件夹**会上传到你所在的文件夹。在手机上，**+** 按钮 → **上传文件**可以从手机中选择文件或照片。
- 在电脑上，把文件或整个文件夹从桌面拖到当前文件夹、其中的某个文件夹，或某个位置上（“把文件拖到这里即可上传”）。空文件夹也会一起上传。

上传情况显示在右下角的**上传**面板中：逐个文件显示已上传了多少。**取消**会停止某个上传，✕ 会把已完成的上传从面板中清除。大文件会分成 32 MB 的块上传。

在发送任何东西之前，应用会检查那个文件夹里有没有同名的文件。如果有，面板会列出它们（“3 个已存在”），并给出三个选择：

- **替换**：上传并覆盖已有的文件。
- **跳过已存在的**：只上传新的文件。
- **取消**：什么都不上传。

## 打开和编辑文件

在文件夹中点击一个文件。它会在编辑器中、在单独的标签页里打开。第一个标签页会回到你打开它时所在的文件夹（或搜索、最近的文件、废纸篓）。你最近打开的 12 个文件会保留为标签页：点击一个即可回到它，用它的 ✕ 或鼠标中键点击可以关闭它。位置中的**最近的文件**会列出你最近打开的文件。

文件上方会显示它的路径：一个房子图标代表你的主文件夹（主文件夹之外的文件则是 **电脑**），然后是各级文件夹，最后是文件名。每个文件夹都会前往“文件”页面中的那个文件夹，并在那里选中路径的下一步；路径很长时，“…”会列出中间的文件夹（**中间的文件夹**）；文件名会在它所在的文件夹中显示它，并选中它（**在所在文件夹中显示**）。在手机上，文件名下面的文件夹一行会打开 **前往文件夹**：路径上的每个文件夹，然后是 **在所在文件夹中显示**。[Word、Excel、CSV 和 LaTeX 文件](#edit-word-excel-csv-and-latex-files)的编辑器上方也显示同样的路径。

编辑器会给行编号，按文件的语言给文字着色，匹配括号；在电脑上，还能折叠代码块，并在你输入时提示补全。按 Tab 缩进。

要保存，点击**保存**（你改动了什么之后它就会亮起），或按 Ctrl+S（Mac 上是 ⌘S）。文件名旁边的圆点表示有未保存的更改。应用开着的时候会替你保管它们：切到别的文件的标签页再回来，文件还是你离开时的样子，撤销记录、光标和位置都在。有未保存更改的文件，它的标签页上会有一个圆点；关闭这样的标签页（点它的 ✕ 或鼠标中键），或在手机上用**返回**离开这个文件时，会问**是否保存更改？**：**保存**、**不保存**或**取消**。刷新或关闭页面会丢掉未保存的内容，浏览器会先询问。行尾是 Windows 样式（CRLF）的文件，保存后仍是这种样式，不会被换成另一种。

### 编辑器的工具

在电脑上，文件上方的工具栏显示它的路径和这些按钮：

- **预览**（Markdown 文件）：按阅读效果显示文件，包括标题、表格、它自己的图片（来自文件旁边）和指向其他文件的链接。再点一次即可编辑。Markdown 文件会先以预览方式打开。
- **以页面显示**（HTML 文件）：在一个与应用隔离的框架中运行这个页面，它可以加载旁边的文件。HTML 文件会先以页面方式打开。页面的链接有效期为一小时；过期后，重新打开文件即可。
- **自上次提交以来的更改**：文件与它上次提交时的差异，新增的行显示为绿色，删除的行显示为红色。如果文件与上次提交时一致，或者不在 git 仓库中，它会显示“没有更改”。切到**预览**或**更改**再切回来，文字保持原样，撤销记录、光标和位置都还在。
- **自动换行**：把长行折行显示，而不是横向滚动。这个选择会被记住。
- **询问**：请智能体修改这个文件，或问它关于文件的问题（见[下文](#ask-an-agent-about-the-file)）。
- **在此文件夹中打开终端**：在文件所在的文件夹中打开一个新的 shell。
- **下载**。
- **更多**（⋯）：**查找**、**替换**、**转到行**、**就所选内容提问**和**键盘快捷键**，然后是**用它开始会话**、**添加到项目**、**在所在文件夹中显示**和**复制路径**。
- **保存**。

要在文件中查找文字，在光标位于文件中时按 Ctrl+F（Mac 上是 ⌘F）：顶部会打开一个查找栏，也可以替换（Ctrl+H，Mac 上是 ⌘⌥F）。按 Ctrl+G（Mac 上是 ⌘⌥G）可转到某一行。

在文字上点右键（或按菜单键，或按 Shift+F10 在光标处打开菜单），可以**剪切**、**复制**、**粘贴**、**全选**、**查找**、**替换**、**转到行**和**就所选内容提问**；最后一项会打开[询问](#ask-an-agent-about-the-file)，并把你选中的行引用在里面。**更多** → **键盘快捷键**列出所有按键。

文字下方的状态条显示光标的位置（**Ln 12, Col 5**，以及选中了多少个字符；点击它可转到某一行）、文件的语言、缩进方式（**Spaces: 2**、**Spaces: 4**、**Tabs**：从文件中读出；点击可为你接下来输入的内容选另一种）、**LF** 或 **CRLF**（文件的行尾；点击可改用另一种来保存）以及**自动换行**或**不换行**（点击切换）。

在手机上，工具栏显示**返回**、文件名（下面是它所在的文件夹）、**预览**或**以页面显示**、**问智能体**（✨）、**保存**（你改动了什么之后才出现）以及**更多**（⋯），其中有**查找**、**转到行**、**就所选内容提问**、**自动换行**、**自上次提交以来的更改**、**在此文件夹中打开终端**、**下载**、**用它开始会话**、**添加到项目**、**在所在文件夹中显示**和**复制路径**。手机上会自动换行，除非你关闭**自动换行**。

### 就这个文件问智能体

点击编辑器工具栏中的**询问**（手机上是 ✨），说出要改什么（“找出并修复错误”“在开头加一段摘要”），或者问一个关于这个文件的问题。面板会在文件旁边打开（屏幕较窄时盖在文件上面），里面有可以直接用的例子，并显示你上次在开始页选的智能体和模型。

- 未保存的更改会先保存，这样智能体就在你改过的内容上工作。
- 智能体在文件所在的文件夹中启动，知道你说的是哪个文件，并直接修改这个文件。每一处改动一写入，你就会在编辑器里看到，改动的行会短暂着色，而你正在看的位置保持不变。
- 对话在面板中继续：回复它就能提出更多要求。**新请求**会重新开始，**作为会话打开**会以完整会话打开它；它也会出现在你的会话列表中。在手机上，**查看文件**会把面板收起来，好让你看着文件变化，底部的按钮可以把它叫回来。
- 在不同文件的标签之间切换时，面板保持打开，每个文件有自己的对话。在 Word、Excel、CSV 和 LaTeX 编辑器中也一样可用，在笔记本中也是：智能体修改单元格，并保留其他单元格的输出。在 PDF 上，智能体会读取它并回答，你还可以就你在其中选中的一段文字、一个公式或一张图提问（[询问 PDF 的某个部分](#ask-about-a-part-of-a-pdf)）。和[在资料库中提问](/guide/library#change-it-by-asking-an-agent)一样，智能体记住的模型和权限保持不变。

### 文件在你打开期间发生变化时

智能体和终端随时都在改动文件。编辑器每隔几秒（智能体工作时每秒一次）就会检查一次文件：

- 如果没有未保存的内容，它会自己在你正在看的位置放入新版本：只有改动的行会变，并短暂着色。
- 如果你有未保存的更改，会出现一个提示栏：“自你打开后，该文件已在磁盘上被更改。”要采用新版本，选择**重新加载（丢弃我的修改）**；要用你的版本覆盖它，选择**用我的版本覆盖**。

不经过这个询问，保存永远不会覆盖更新的版本。

### 编辑器不能编辑的文件

- 超过 10 MB 的文件：“文件太大，无法在这里编辑”。下载它，或在终端中打开它。（笔记本最大可以到 40 MB。）
- 二进制文件（任何不是文本的文件）：“二进制文件”。下载后在你的设备上打开。
- Word、Excel、CSV 和 LaTeX 文件会在各自的编辑器中打开（下一节）；图片、PDF、视频、音频和其他 Office 文档会显示为预览（再下一节）。

## 编辑 Word、Excel、CSV 和 LaTeX 文件

这些文件会在[资料库](/guide/library#documents)为它们准备的编辑器中打开，保存时会按文件本来的格式重新写入同一个文件：

- **Word 文档**（.docx）在文档编辑器中打开，就像在 Word 或 Google 文档中一样，显示在一张与它的纸张大小相同的页面上。
- **Excel 文件**（.xlsx）、**CSV** 和 **TSV** 文件在电子表格编辑器中打开，带着它们的工作表和能计算的公式（Excel 文件还带着它的筛选、条件格式、下拉列表和复选框、合并的单元格、备注和图表）。
- **LaTeX 文件**（.tex）在 LaTeX 编辑器中打开，源码旁边是排好版的页面。文档读取的文件（用 `\input` 放进来的章节、参考文献）会一起打开；排版时会用到它所在文件夹里的其他文件（图片、样式和数据），TeX 只读取它们，从不更改。打开一个章节，会打开它所属的文档（它用 `% !TEX root = …` 指明的文档，或者它作为 subfile 所属的文档；否则是它所在文件夹中、或往上一两层的文件夹中读取它的那个文档），并打开这个章节，文档的文件显示在[文件树](/guide/library#the-files-tree)中：它读取的文件放在各自的文件夹里，TeX 从文件夹中原样取用的东西（它的图片、样式和文档类、数据）则以灰色显示，供你查看；要修改这些，请在“文件”中修改。在窄屏上，源码上方的 **文件** 会打开文件树。评论的用法和在[资料库](/guide/library#latex-documents)中一样：文件只保存它的文本，所以应用会按文件的路径把它的评论保存在文件旁边，点 **保存** 时一起保存；你在这里重命名或移动这个文件（或它所在的文件夹）时，评论也会跟着走；[被问到这个文件](#ask-an-agent-about-the-file)的智能体会读这些评论，回复并解决它们，它的回复一写出就会显示出来。**用 AI 解决**（在一条评论上，或者在 **评论** 顶部）会立即把评论交给这个智能体（[用 AI 解决评论](/guide/library#resolve-comments-with-ai)）。**比较版本** 只用于保存在资料库中的 LaTeX 文档。

像在[资料库](/guide/library#documents)中一样修改它，然后点击底部栏中的 **保存**，或按 Ctrl+S（Mac 上为 ⌘S）；**放弃** 会回到文件原来的样子。上方的栏显示文件的路径、**询问**（[问智能体](#ask-an-agent-about-the-file)）、**下载** 和 **更多**（⋯）：**以文本编辑**（CSV、TSV 和 LaTeX 文件）或 **以预览显示**（Word 和 Excel 文件）会像以前一样显示文件，栏中有一个按钮可以回到编辑器；还有“文件”页面的 **用它开始会话**、**添加到项目**、**在所在文件夹中显示** 和 **复制路径**。从搜索结果中在某一行打开的文件会以文本打开。

保存会保留文件的哪些内容：

- **CSV 和 TSV**：你没有改动的行和单元格会保持原来的文本，文件也保持它的分隔符、引号和换行符。CSV 文件只能容纳一个工作表的值：如果你添加了公式、工作表或格式，第一次保存前会先询问，公式会保存为它们算出的值。
- **LaTeX**：只写入你改过的文件，每个文件保持自己的换行符。在编辑器中添加的文件会放进文件夹；删除的文件会进入[废纸篓](#delete-and-put-back)。
- **Word 和 Excel** 文件会根据编辑器中的内容重新写入：Word 文件的批注、修订、公式、目录、页眉和页脚会保留下来，Excel 文件的筛选、条件格式、下拉列表和复选框、合并的单元格、备注、评论和图表也一样。如果文件中有编辑器不保留的内容（Word 文件的脚注、图表，或者带图片或表格的页眉；Excel 文件的图片、形状、数据透视表、套用了表格格式的表、超链接、命名区域、宏或分组的行），上方会有一栏说明：“保存会替换这个文件，不再包含这个编辑器不保留的内容”，并列出是哪些。第一次保存会先询问再替换文件；那一栏中的 **另存为副本** 会改为把你的修改写入旁边的一个新文件（“report (edited).docx”）。第一次保存 Word 或 Excel 文件时，原来的文件会进入[废纸篓](#delete-and-put-back)，在那里用 **放回原处** 可以把它放回新文件旁边。
- 对编辑器来说太长的文件只显示开头部分，且只能阅读：**以文本编辑** 或 **以预览显示** 可以看到全部内容。

当智能体或终端在文件打开期间更改了它：如果你什么都没改，编辑器会自动载入新版本；否则会像文本编辑器一样询问：**重新加载（丢弃我的修改）** 或 **用我的版本覆盖**。

PowerPoint 文件、较旧的 Office 文件（.doc、.xls、.ppt）、OpenDocument 文件、RTF 和 EPUB 会显示为预览，下一节会介绍。

## 查看图片、PDF、文档和网页

文件查看器按文件本来的样子显示它们：

- **图片**（PNG、JPEG、GIF、WebP、SVG、ICO、BMP、AVIF）：完整显示，透明的部分衬着棋盘格。顶部的 **编辑** 会在图片编辑器中打开它（[编辑图片和视频](/guide/library#edit-pictures-and-videos)）。
- **PDF**：在浏览器自带的 PDF 查看器中显示，顶部有 **突出显示**，可以在应用自己的阅读器中阅读它们、高亮它们，并在旁边记备注（见[阅读和高亮 PDF](#read-and-highlight-a-pdf)），还有 **填写和签名**，可以填写和签署它们（见[填写和签署 PDF](#fill-in-and-sign-a-pdf)）。你高亮过的 PDF 会在阅读器中打开。
- **视频**（MP4、WebM、MOV 和 M4V；浏览器支持时还有 MKV 和 OGV）：在应用自带的播放器中播放（见下文的[观看视频](#watch-a-video)）；对于 MP4、MOV、M4V 或 WebM 视频，顶部的 **编辑** 会在视频编辑器中打开它。**音频**（MP3、WAV、OGG）就地播放。
- **Office 文档**：PowerPoint（.pptx、.ppt）、较旧的 Word 和 Excel 文件（.doc、.xls 等）、OpenDocument（.odt、.ods、.odp）、RTF 和 EPUB；Word（.docx）和 Excel（.xlsx）文件则在它们的编辑器中通过 **更多**（⋯）→ **以预览显示** 查看。顶部的切换开关用来选择视图：
  - **页面**：LibreOffice 排版后的文档，一页一页显示（第一次会显示“正在排版页面…”）。只有这台电脑上安装了 LibreOffice 时才有这个视图，EPUB 电子书也没有。
  - **文本**：应用读出的文字、工作表和幻灯片。

  手机上默认是**文本**，因为它在手机上滚动和缩放都更顺畅。如果文档无法读取，会显示“此文件无法预览”：那就下载它。
- **Markdown** 和 **HTML**：见上文的**预览**和**以页面显示**。

**下载**始终在工具栏里。

### 观看视频

视频会在应用自带的播放器中打开，播放器占满整个查看区域：

- **播放和暂停**：中间的圆形按钮、左下角的按钮、点一下画面，或按空格键（K 键也可以）。双击画面会全屏。
- **前后跳转**：沿底部的进度条拖动，或点击条上的某一点；把指针停在进度条上会显示该处的时间，条上颜色较浅的部分是已经加载的内容。← 和 → 移动 5 秒，J 和 L 移动 10 秒，Home 和 End 跳到开头和结尾，0 到 9 跳到视频相应的十分之一处，暂停时 , 和 . 逐帧前后移动。
- **声音**：喇叭按钮切换静音（M）。在电脑上，把指针停在喇叭上会出现音量滑块；↑ 和 ↓ 也能调节音量。
- **速度**：**1×** 按钮可在 0.5× 到 2× 之间选择（**正常**即 1×）。
- **循环**会在每次播放结束时从头再放；**画中画**让视频在一个浮于其他内容之上的小窗口里继续播放（浏览器支持时）；**下载**保存文件；**全屏**（F）占满屏幕，再按同一个按钮或按 Esc 即可返回。
- 播放时控件会淡出，移动指针时重新出现。播放器会为下一个视频记住你的音量和速度。
- **在手机上**：点一下画面显示或隐藏控件，在画面左侧或右侧双击可后退或前进 10 秒。在 iPhone 上，全屏使用手机自带的视频播放器。
- 浏览器无法播放的视频（MKV 和 AVI 文件常用浏览器不支持的编码）会显示“这个视频无法在这里播放”，并提供**下载**，以便用视频应用观看。

## 填写和签署 PDF

打开一个 PDF，按顶部的 **填写和签名**（在手机上，是它名称旁边的笔）。它的页面会像纸张一样显示，表单的字段以浅蓝色叠在上面：

- **字段**：在文本框里输入，勾选复选框，选择单选按钮、下拉列表中的一项或列表中的几项。表单锁定的字段（只读的，或者被文件里已有的数字签名锁定的）无法更改。
- **在页面上点击**，就会把工具栏上选中的东西放在那里：**文本**（一个可以输入的框，这是默认的）、**勾号**、**叉号** 或 **日期**（今天的日期，可以修改）。一个空白接一个空白地点击：每次点击都会开始下一项。只有印刷的横线和方框的表单，或者扫描的表单，就是这样填写的。
- **签名** 只要轻点一下，就能把你保存的某个签名放到页面上，也可以在那里画、输入或上传一个（勾选 **保留以后再用** 就会保存它；见[签名](/guide/library#signatures)）。表单自己的签名字段会显示 **在此签名**：轻点它，签名就会放进它的框里。
- **移动和调整大小**：拖动勾号、叉号或签名可以移动它，拖动它的蓝色角可以调整大小。文本框用它左边的手柄移动，它上方的 **A−** 和 **A+** 可以把文字变小或变大。每样东西上方的垃圾桶，或者按 Delete，可以把它去掉。
- **缩放**：在手机或平板上用双指捏合；在电脑上，按住 Ctrl 滚动鼠标滚轮，或者按 Ctrl+= 和 Ctrl+−。**适应宽度**（或 Ctrl+0）会恢复原来的大小。

**保存** 会在文件旁边写入一份副本“name (filled).pdf”，并打开它。它旁边的箭头里有 **在旁边另存一份副本** 和 **替换文件**，替换时文件的旧版本会进入[废纸篓](#delete-and-put-back)。**关闭** 会不保存就离开，如果你改过什么，会先询问。

字段会把你填的值作为表单自己的字段保存，所以任何 PDF 查看器都能显示它们，之后也仍然可以在那里修改，所用的字体能显示你写的文字（包括希腊文和中文）。你放置的东西会画到页面上。文件原有的字节保持不变，改动附加在它们后面，所以：

- **带数字签名** 的 PDF，在你只填写字段时，签名仍然有效。放在它页面上的文字、勾号或签名，在其他查看器中会显示为签名之后所做的更改；
- 所有者 **设置了保护** 的 PDF（不用密码就能打开，但限制修改），只能在它允许的范围内填写。需要密码才能打开的 PDF 无法在这里填写。

它做不到的：

- **XFA 表单**（用 Adobe LiveCycle Designer 制作，常见于政府部门）：它们的字段只能在 Adobe Acrobat 或 Reader 中填写。你仍然可以在它们的页面上输入文字和签名。
- **扫描的表单** 没有字段，也没有可查找的文字：你的文字和勾号会放在你点击的位置。
- 画出来的签名是你签名的图片，不是能证明签署人身份的数字签名。
- 这里没有任何功能能把文字从 PDF 中彻底删除。白色方框（智能体可以把它们盖在文字上）只是让文字看不见：文字仍然留在文件里。

智能体也能用它们自己的工具填写 PDF、在上面书写和修改 PDF：见[文档、图片、视频和语音](/guide/documents-voice#pdfs)。

## 阅读和高亮 PDF

打开一个 PDF，按顶部的 **突出显示**（在手机上，是它名称旁边的马克笔图标）。它的页面会像纸张一样显示，由应用绘制，页面上覆盖着它的文字，可以像在任何阅读器中那样选择。你高亮过的 PDF 会自动以这种方式打开，所以你回来时备注都还在；**关闭** 会回到浏览器自带的查看器。

- **高亮文字**：用鼠标选中它们，在手机上则按住一个词再拖动两端的手柄。会出现一个小工具条：它的四种颜色之一（黄色、绿色、蓝色或粉色）会高亮这些文字，**备注** 会高亮它们并打开一条备注供你书写，**询问** 会就它们去问智能体（[见下文](#ask-about-a-part-of-a-pdf)），**复制** 会复制它们，在行尾被断开的单词会重新拼合。选择会按你阅读的顺序，从论文的一栏延续到下一栏。
- **高亮图或公式**：按 **框选区域**，在它周围拖出一个方框；在电脑上，也可以不按这个按钮，直接按住 Alt 拖动。同样的工具条会为页面的这一部分出现，这一部分会保存为它的图片（**复制** 会复制这张图片；浏览器不允许页面复制图片时，则复制其中的文字）。
- **修改高亮**：点击它，打开它的工具条，可以换一种颜色、**编辑备注**、**询问**、**复制** 或删除它（垃圾桶图标，或者按 Delete；随后提示中的 **撤销** 可以把它找回来）。把指针停在高亮上会显示它的备注，有备注的高亮会带一个小圆点。再次高亮同样的文字会改变它们的颜色。
- **缩放**：在手机或平板上用两指缩放；在电脑上按住 Ctrl 滚动鼠标滚轮，或者按 Ctrl+= 和 Ctrl+−。**适应宽度**（或 Ctrl+0）会恢复原样。无论放大多少，高亮都会留在它们的文字上。

只有图片的页面（扫描件）没有可以选择的文字：用 **框选区域** 高亮它的各个部分。在页面上竖向排列的文字（页面被横过来时）也无法选择。其他应用保存在 PDF 中的高亮会显示在它的页面上，但不会出现在 **备注** 中。

### 你的备注

**备注** 会在页面旁边（在手机上是从底部升起的面板）逐页列出你的高亮：每条的文字或它所框区域的图片、它的备注（你可以直接在那里书写或修改），以及它的颜色。点击一条即可跳到它所在的页面；垃圾桶图标会删除它，✨ 会就它去问智能体。

应用会按文件的路径把你的高亮和备注保存在文件旁边：PDF 本身不会改变。你在这里重命名或移动这个文件（或它所在的文件夹）时，它们会跟着走；用其他方式移动的文件（在终端中、由智能体移动），在你打开它时会根据它的内容重新找到它的备注。文件本身发生变化时（比如你重新排版的一篇论文），每条高亮都会按它的文字重新找到，即使到了另一页也一样；如果它的文字已经不在文件里了，它会留在原处，并标上“文件已更改，现在找不到这些文字了”。

**备注** 中的 **更多**（⋯）里有：

- **保存到项目**：你的高亮和备注会作为一份以论文命名的文档（比如“Sparse Retrieval with Learned Term Weights (notes).md”）放进项目的[知识库](/guide/projects#knowledge)：先是论文的标题，然后逐页列出每条高亮的文字（区域则用一行表示）和你的备注，这样项目的会话在搜索它的文档时就能找到它们。PDF 所在文件夹所属的项目排在最前。这份文档会随你对备注的每次修改而更新；**打开项目的知识库** 会在那里显示它，**不再保存到该项目** 会把它移除。
- **保存到 PDF**：把高亮作为文件自己的高亮写进文件，每条备注作为对应高亮的批注，这样其他 PDF 应用也能显示它们。**在旁边另存一份副本** 会写出“name (highlighted).pdf”，它也会保留你的备注；**替换文件** 会覆盖原文件，旧版本会放进[废纸篓](#delete-and-put-back)。再次保存时，会按当时的样子写入，替换之前保存的那些。如果文件的所有者禁止添加批注，或者文件经过认证、不允许批注，就无法写入：它们仍然保存在文件旁边。
- **全部复制**：把备注作为文本复制，可以粘贴到别处。

### 询问 PDF 的某个部分

工具条上的 **询问** 会在 PDF 旁边（窄屏上则盖在上面）打开[就这个文件问智能体](#ask-an-agent-about-the-file)，并带上你选中的内容：文字或区域的图片，以及它所在的页。选一个示例（“解释这段文字”“这个公式表达的是什么？”“这和我的方法相比怎么样？”“概括这一节”），或者写下你自己的问题；智能体也可以读取整个 PDF。当关于这个文件的对话正在进行时，**询问** 会把这部分内容放进对话的消息框，这样你接下来就可以问它。你请智能体读取一个 PDF 的高亮和备注时，它们也会去读（“总结我在这篇论文里的高亮”）。

## 按名称查找文件

在任何页面上按 Ctrl+P（Mac 上是 ⌘P）。“转到 … 中的文件”会按名称搜索“文件”中打开的文件夹：按顺序输入名称中的几个字母即可（`invq3` 能找到 `invoices/q3-report.xlsx`）。文件名本身包含你所输入内容的文件排在前面。用 ↑ 和 ↓ 移动，按 Enter 或点击即可打开。它最多列出 60 个文件，包括隐藏文件。

搜索框（Ctrl+K，Mac 上是 ⌘K）也能按名称查找同一文件夹中的文件，只要你输入两个字母。

## 搜索文件

一次搜索就能在一个文件夹下的所有位置，按名称和文件里的文字查找文件。在文件夹的**在 *文件夹* 中查找**字段中输入并按 Enter，或前往[在文件中搜索](/search)。

1. 在“搜索文件名和文件里的文字”中输入要查找的内容。结果会随着你的输入出现。
2. 字段下方的**范围**说明在哪里搜索：起初是你来时所在的文件夹。点击它可以换到别处搜索：某个项目的文件夹、某个置顶的文件夹、某个会话工作过的文件夹、你的**主文件夹**，或任何你按名称找到或输入路径的文件夹。
3. 如果需要，可以缩小范围：
   - **所有类型的文件**用来选择文件类型：**文本和笔记**、**代码**、**数据和设置**、**网页**或**笔记本**。也可以在同一个菜单里输入这样的名称，用逗号分隔（`*.md, *.py`）；前面加 `!` 则排除这些文件（`!dist/**`）。
   - **包括隐藏文件**会搜索名称以点开头的文件和文件夹。
   - 字段里的**区分大小写**会严格匹配大小写（不开启时，全是小写的搜索会忽略大小写，含有大写字母的搜索则区分大小写），**正则表达式**则把你输入的内容当作模式（`colou?r`），而不是普通文本。

结果分为两部分：

- **名称匹配的文件**：名称中包含你所输入内容的文件，最多 30 个，每个都显示它所在的文件夹。
- **文件内容**：匹配的行，按文件分组，每个文件都显示匹配的数量。点击某一行，即可在那一行打开文件；点击文件名则打开该文件。

每个结果的**更多**（⋯）里有**在所在文件夹中显示**、**用它开始会话**、**添加到项目**，以及文件菜单中的其他各项。

搜索内容记在页面地址里，所以返回和刷新页面都会保留它。它会跳过文件夹的 `.gitignore` 排除的文件，以及超过 4 MB 的文件。每个文件最多 50 个匹配、总共最多 1,000 个匹配，或者满 15 秒，搜索就会停止；每个文件显示前 30 行匹配的内容。PDF、Word 等文档只按名称查找，不按其中的文字查找；要让智能体搜索它们的内容，请把它们添加到[知识库](/guide/projects#shared-knowledge-documents-every-session-can-search)。

## 运行 Jupyter 笔记本

笔记本（`.ipynb`）会以笔记本的形式打开：显示它的各个单元格，每个都带着输出。顶部的工具栏有内核按钮、**运行所有单元格**、**中断（I, I）**、**重启内核 (0, 0)**、**清除所有输出**、**查看笔记本文件（JSON）**、**下载**、**询问**（见[就这个文件问智能体](#ask-an-agent-about-the-file)）和**保存**。在手机上，不常用的那些放在**更多**里：**重启内核**、**重启并全部运行**、**清除所有输出**、**查看文件（JSON）**，还有**下载**。

在文件夹里用**新增** → **新建笔记本**新建一个（见[新建文件或文件夹](/guide/files-git#make-a-file-or-folder)），或者请智能体帮你做一个：它会写好笔记本，从头运行一遍让输出都在里面，在没有合适的环境时准备一个运行它的环境，再作为卡片交给你，点开就在这里打开。

### 选择代码在哪里运行

内核按钮（一个圆点加一个名称，或“没有内核”）会打开**用以下环境运行此笔记本**：这台电脑上的 Python 环境。它列出笔记本所在文件夹或其上级文件夹中名为 `.venv`、`venv` 或 `env` 的虚拟环境、conda 环境、系统 Python，以及在这里注册的 Jupyter 内核（也包括其他语言的）。每个都显示它的版本，笔记本要求的那个（或它旁边的虚拟环境）会标为**推荐**。

- 标有“需要 ipykernel”的环境有一个**安装**按钮：你确认后，它会在那个环境中运行 `pip install ipykernel`，环境里的其他东西都不会改变。
- 还没有内核时运行单元格，会在推荐的环境中启动一个内核。如果失败，列表会打开，让你选另一个。
- 内核运行时，按钮的菜单会显示它的状态（正在启动、空闲、正在运行、正在重启或已停止）、启动时间，以及**中断**、**重启**和**关闭**。选择另一个环境前会先询问，因为正在运行的内核里的变量会丢失。

关闭笔记本后，内核仍会继续运行，应用重启时也不会中断：再次打开笔记本，期间运行的输出都在那里。要关闭内核，可以从它的菜单操作，或者到列出了正在运行的内核的[系统](/system)页面。

### 编写和运行单元格

单元格分为**代码**、**文本**（Markdown）和**原始**三种。点击代码单元格即可编辑它，文本单元格则要双击。单元格运行时会显示 `[*]` 和一个计时器；运行结束后显示它的运行编号，如 `[3]`。

- 把鼠标指向代码单元格，它的编号位置会变成一个运行按钮（“运行 (Shift+Enter)”：运行这个单元格并转到下一个；单元格运行时，它会中断内核）。它的工具显示在角落里：**编辑**（文本单元格）、单元格类型、**上移**、**下移**、**在下方添加单元格**、**删除此单元格**和**此单元格的更多操作**（⋯，单元格的菜单，见下）。在手机上，轻点一个单元格：它的工具会显示在它上方，包括**运行**。
- 在电脑上，把鼠标指向两个单元格之间，会显示 **+ 代码** 和 **+ 文本**。最后一个单元格下方也有这两个按钮。
- **单元格的菜单**：在单元格上点右键（或点角落里的 ⋯，手机上就用它打开）。里面有**运行此单元格**、**运行上方所有单元格**、**运行此单元格及以下的单元格**和**运行下方所有单元格**（只有代码单元格会运行）、**剪切**、**复制**、**粘贴到下方**、**粘贴到上方**、**制作副本**、**在光标处拆分**（编辑单元格时，光标放在要拆分的地方）、**与下一个单元格合并**、**在上方添加单元格**和**在下方添加单元格**、**上移**和**下移**、**单元格类型**、**清除输出**、**折叠输出**或**显示输出**，以及**删除此单元格**，每一项都标着它的按键。剪切、复制和制作副本的单元格会保留输出；应用开着的时候，粘贴也可以粘到另一个笔记本里。拆分或合并会清除它所产生的单元格的输出。
- **同时选中几个单元格**：Shift+↑ / Shift+↓（或 Shift+点击）会选中你开始的位置和当前位置之间的单元格，并给它们着色；菜单、**复制**、**剪切**、**制作副本**、**合并**和 D, D 就会对它们全部起作用。按 Esc 取消。
- **折叠输出**：单元格编号旁边的小箭头（或菜单里的**折叠输出**）会把输出收起来，显示“输出已隐藏”；点击它就再次显示。这个状态保存在笔记本文件里（和 Jupyter 一样），所以下次打开时仍是折叠的。
- 当代码请求输入时（Python 的 `input()`），单元格下方会出现一个字段：“输入后按 Enter”。密码会保持隐藏。
- 编辑代码时，在一个名称后按 Tab，会向正在运行的内核请求补全。

输出可以显示文字、带颜色的错误信息、图片和图表、表格、HTML（在隔离的框架中）、Markdown 和公式。“交互式小组件无法在这里运行”，JavaScript 输出也不行。进度条显示为它最后的样子，一个单元格一点一点打印出的文字合成一整块显示，和在 Jupyter 中一样。

### 快捷键

编辑单元格时：

- Shift+Enter：运行它并转到下一个单元格（在最后一个之后则新建一个）。
- Ctrl+Enter（Mac 上是 ⌘Enter）：运行它并留在原处。
- Alt+Enter：运行它并在下方添加一个单元格。
- Ctrl+Shift+Enter：运行它以及它下面的单元格。
- Ctrl+Shift+-（⌘⇧-）：在光标处拆分单元格。
- Esc：停止编辑。

没有在编辑单元格时：

- Enter：编辑选中的单元格。↑ / ↓（或 K / J）：在单元格之间移动。Shift+↑ / ↓：同时选中几个。
- A / B：在上方 / 下方添加单元格。D, D：删除单元格（或选中的几个）。Z：恢复最后删除的单元格；再按一次恢复更早的。
- C / X：复制 / 剪切单元格（或选中的几个）。V / Shift+V：粘贴到下方 / 上方。Shift+M：把单元格与下一个合并（或合并同时选中的几个）。Ctrl+Shift+Enter：运行此单元格及以下的单元格。
- M, Y, R：把单元格设为文本、代码或原始。
- I, I：中断内核。0, 0：重启内核。

笔记本上方栏里的**更多**（⋯）有**运行所有单元格**、**运行上方所有单元格**、**运行此单元格及以下的单元格**和**运行下方所有单元格**（后三项针对选中的单元格）、**重启内核**、**重启并全部运行**、**清除所有输出**、**大纲**和**键盘快捷键**。**大纲**会在单元格旁边的列表里（手机上是一张面板）列出文本单元格的标题（以 # 开头的行）：点击一个就转到它的单元格。**键盘快捷键**列出所有按键。内核还在启动时运行的单元格会等它启动好，然后再运行。

按 Ctrl+S（Mac 上是 ⌘S）保存。和其他文件一样，如果你有未保存的更改时笔记本在磁盘上被改动，会出现一个提示栏，提供两个选择：**重新加载（丢弃我的修改）**，或**用我的版本覆盖**。**查看笔记本文件（JSON）**：在编辑器中以文本形式显示文件；**以笔记本方式打开**则返回笔记本视图。

## 在 Git 页面查看你的仓库

点击**系统**，然后点 **Git**，或前往 [Git](/git)。左边列出你的 git 仓库，最近用过的排在前面：包括你的会话工作过的仓库（某个会话的文件夹，或某个会话编辑过的文件所在的仓库；`/tmp` 之类的临时位置不算在内），以及你自己添加的仓库。仓库超过六个时，顶部会出现一个查找框，可以按名称找到仓库。

每个仓库都显示它的名称和分支，有事要做时还会带上小标记：

- **● 3**：有三个文件改动过，还没有提交。
- **↑ 2**：有两个提交待推送。**↓ 1**：有一个提交待拉取。
- **合并中**或**变基中**：一次合并因文件冲突而停止（见[合并因冲突而停止时](/guide/files-git#when-a-merge-stops-on-conflicts)）。
- 右边是最后一次提交距今多久。

在页面顶部，**获取每个仓库的远程更新**（云朵图标）会向每个远程仓库询问有什么新内容，**刷新**会重新读取列表。

点击一个仓库，它会在列表旁边打开。顶部是它的名称和文件夹、你所在的分支、一行说明它相对远程仓库的状况、**同步**按钮和一个 ⋯ 菜单。下面是四个标签页：**更改**、**历史**、**分支**和**储藏**。在电脑上，进入这个页面时会打开你上次用过的仓库。在较小的窗口中，列表会收进页面标题里（点击仓库名称可以换一个）；在手机上，列表单独占一页，仓库在它上面打开，并带有返回箭头。

### 添加仓库

页面顶部的**添加**提供两种方式：

- **添加这台电脑上的文件夹**：输入或选择一个项目的文件夹，然后点击**添加**。位于某个仓库里面的文件夹会添加那个仓库。git 还没有管理的文件夹可以新建自己的仓库：**在这里新建仓库**（即 git 的 `git init`）。
- **从链接克隆**：粘贴 GitHub、GitLab 或其他 git 服务器上某个仓库的地址（`https://…`、`ssh://…` 或 `git@host:owner/project`）。**放在哪里**会建议一个单独的文件夹（如果你有 `~/code`，就放在那里）；这个文件夹必须还不存在，或者是空的。**克隆**会显示进度；你可以关闭对话框，克隆会继续。完成后仓库会打开。

你添加的仓库会一直留在列表中，直到你把它拿掉：⋯ → **从列表中移除**。它的文件夹保持不变。

## 与远程仓库同步

远程仓库是共享这个仓库的地方，例如 GitHub。分支下面的一行说明你的分支的状况：“2 待推送 · 1 待拉取 · 获取于 5m 前”、**已是最新**、**尚未推送到远程仓库**或**没有远程仓库**。

**同步**一键完成需要做的事：向远程仓库询问有什么新内容，把那些提交拉取进来，再把你的提交推送上去。它上面的箭头显示每个方向各有多少（**同步 ↑2 ↓1**）。如果远程仓库还没有这个分支，这里显示的是**发布分支**：它会把分支放到远程仓库上，并从此让两边保持同步。

当你的分支和远程分支都有了新的提交时，“同步”先不做任何改动，而是问你怎样把它们合到一起：

- **把我的提交放在最上面**：你的提交排在远程仓库的提交之后，就像是你后来才做的，历史保持为一条直线（git 把这叫作变基，rebase）。
- **合并**：用一个合并提交把两条线连起来；每个提交都保持原样。

然后“同步”会把你的提交推送上去。如果双方改了相同的行，它会停下来，让你解决冲突（见[合并因冲突而停止时](/guide/files-git#when-a-merge-stops-on-conflicts)）。如果你未提交的更改涉及远程仓库上也改过的文件，它会告诉你：先提交这些更改，或用储藏把它们放到一边。

⋯ 菜单里有逐步的操作，以及其他功能：

- **获取**会向远程仓库询问有什么新内容，不改动这里的任何东西。**拉取**会把新内容拉进来（如果两边都有新的提交，它会问同样的问题）。**推送**会把你的提交发送上去。
- **在此处打开终端**、**在“文件”中显示**和**复制路径**。
- **远程仓库**：这个仓库的远程仓库及其地址。没有远程仓库的仓库会显示**没有远程仓库 · 添加一个**：粘贴一个地址，点击**添加远程仓库**（它的名字是 origin），然后点击**发布分支**。
- **推送标签**：仓库有标签时显示。

当某项操作没有完成时，会出现一个红框，尽量用通俗的话说明发生了什么，**git 的输出**里是 git 自己的消息。应用里的 git 从不询问密码：推送和拉取使用这台电脑的 SSH 密钥或保存的 git 凭据；如果它们不能在没有提示的情况下工作，红框会说明。

## 提交更改

**更改**列出上次提交以来改动过的每个文件，带有“文件”页面使用的字母（见[文件旁边的字母是什么意思](/guide/files-git#what-the-letters-beside-files-mean)）、加粗的文件名及其后面的文件夹，以及增删的行数。点击一个文件，可以在列表旁边看到它的改动（在手机上是单独的一页）。项目足够时，**单栏**和**并排**会把旧行和新行上下排列或左右并排显示。

没有单独的暂存步骤：每个文件都有一个框，勾选后会纳入下一次提交（一开始全部勾选），顶部的框可以全部勾选或全部取消（“3 / 4 纳入提交”）。

- **放弃这一部分**位于文件每一部分改动的顶部，只会把这几行恢复到上次提交时的样子（会先询问）。
- 文件的 ⋯ 菜单：**打开文件**、**在“文件”中显示**、**放弃更改**（对于新文件是**删除新文件**；两者都会先询问，而且无法撤销），以及**忽略它**（新文件）或**停止跟踪并忽略**（git 管理的文件：下一次提交会把它移出仓库，文件仍留在这台电脑上）。两者都会把它加入 `.gitignore`。
- 列表顶部的盒子图标会用储藏把所有更改放到一边（见[用储藏把更改先放到一边](/guide/files-git#put-changes-aside-with-a-stash)）。

要提交，在列表底部：

1. 写下这次更改的摘要，需要的话再写一段描述。或者点击**撰写信息**：一个模型会读取你勾选的更改，按照仓库最近几次提交的风格起草两者（Claude Code 已登录时用 Claude，否则用 Codex）。
2. 点击**提交**，或点击**提交并推送**直接把它发送到远程仓库（如果远程仓库还没有这个分支，它会发布分支）。按 Ctrl+Enter 也可以提交。

只有勾选的文件会被纳入，即使其他文件在别处已被暂存。

当还没有远程仓库拥有上一个提交时，会显示**修订上一个提交**：勾选它，就会修改那个提交，而不是新建一个。它的信息会填进来供你编辑，你勾选的文件会并入它，按钮会变成**修订**和**修订并推送**。

当所有更改都已提交时，“更改”会显示**没有可提交的内容**，并显示上一个提交：点击它可以在“历史”中打开。

## 合并因冲突而停止时

当双方改了相同的行时（“同步”拉取提交、合并一个分支、还原一个提交），git 会中途停下，仓库会在标签页上方说明：“把 origin/main 合并到 main 已停止：1 个文件冲突”。冲突的文件会列在那里，并在“更改”中标记为 **C**；点击一个文件就能查看。

在每个这样的文件里，git 把两边的版本放在标记之间：`<<<<<<<` 和你的版本，`=======`，然后是对方的版本，直到 `>>>>>>>`。打开文件，保留应该留下的内容，删除这些标记。文件里不再有标记时，它会显示为已解决，带有一个勾。然后：

- **让智能体解决它们**会打开开始页，并填好针对这个仓库的提示：一个智能体会解决这些文件，检查它们仍然能正常工作，并告诉你它是怎么选择的。在你发送之前，什么都不会开始。
- **继续**：在每个文件都解决后，完成被停下的操作（合并的提交，或者把你剩下的提交放到最上面）。
- **停止合并**（或**停止放到最上面**、**停止还原**）会在询问之后，把一切恢复到开始之前的样子。你为解决冲突所做的修改会丢失。

在此之前，“同步”和提交框会等待：“继续”会完成这次提交。

## 浏览历史记录

**历史**列出提交，最新的排在前面，左边是一幅图，显示分支如何分开和汇合：每条线是一个分支，每个点是一个提交；空心圆圈表示远程仓库还没有的提交。标签显示每个提交上的分支（你所在的分支带边框）、远程仓库的分支（带云朵图标）和标签，然后是它的信息、作者和时间。

- **这个分支**显示通向你所在分支的历史；**所有分支**显示每个分支的历史，包括远程仓库的分支。
- **查找提交**可以按提交信息中的文字、作者的名字或邮箱，或者哈希来查找提交。
- 它旁边的**找出是哪个提交弄坏了它**按钮会让一个智能体找出把某样东西弄坏的那个提交（见[找出是哪个提交弄坏了它](#find-what-broke-it)）。
- 列表末尾的**加载更多**会显示更早的提交。

点击一个提交，它会在列表旁边打开（在手机上是单独的一页）：它的完整信息、作者、日期和哈希（点击哈希可以复制），它上面的分支和标签，以及它改动的文件，每个文件都可以展开查看改动。合并提交会说明它合并了哪些提交。

- **解释**会打开开始页，并填好提示，请一个智能体用通俗的话解释这个提交。
- 当还没有远程仓库拥有最后一个提交时，它上面会显示**撤销这个提交**：这个提交会被移除，它所做的更改回到“更改”中，可以重新提交。
- ⋯ 菜单里还有**复制哈希**、**找出是哪个提交弄坏了它**（以这个提交作为最后正常工作的地方）、**从这里新建分支**（一个从这个提交开始的分支；你会切换到它）、**给这个提交打标签**（一个名称，例如 `v1.2.0`，以及可选的说明；仓库 ⋯ 菜单中的**推送标签**会把标签发送到远程仓库），以及**还原这个提交**：会在询问之后新建一个提交，撤销这个提交所做的更改。这个提交本身仍保留在历史中。

### 找出是哪个提交弄坏了它

当某样东西在早先的版本中正常、现在却坏了时，打开它最后正常工作的那个提交，在它的 ⋯ 菜单中选择**找出是哪个提交弄坏了它**，或者选择**查找提交**旁边的**找出是哪个提交弄坏了它**按钮。它的表单会问：

- **正常工作的版本**：那个提交（有标签时显示它的标签），否则是最新的标签；任何标签、分支或提交都可以，它所代表的提交会显示在下面。
- **出问题的版本**：一开始是 `HEAD`。
- **出了什么问题**，用你自己的话说，以及**如何检查（可选）**：一条在出问题时会失败的命令。
- **执行者**：由哪个智能体来做。

**开始**会在仓库的一个工作树中打开一个新会话，所以你自己的副本保持不变。它的智能体会写一个检查，在两端各试一次，运行 git bisect 找出第一个出问题的提交，并解释那个提交中是什么弄坏了它、为什么，附上建议的修复。见[找出是哪个提交弄坏了它](/guide/engineering#find-what-broke-it)。

## 使用分支

点击仓库名称下面的分支名称即可切换：先列出这里的分支，最新的排在前面，并带有相对远程分支的 ↑↓，然后是**仅在远程仓库上**的分支。输入文字可以查找；如果输入的名称还不是分支，会出现**从这里新建分支“…”**。如果有未提交的更改，应用会先询问：这些更改会一起带过去；如果它们与那个分支冲突，git 会拒绝，什么都不会改变。只在远程仓库上的分支会变成这里的一个分支，并跟踪远程的那个分支。

**分支**先显示你所在的分支，然后是其他分支，每个都带有它的最后一个提交和标记：**已合并**（它的工作已经在你的分支里了）、**仅在本地**（不在远程仓库上）、**已从远程仓库删除**，以及相对远程分支的 ↑↓。**新建分支**会从你当前的位置新建一个分支并切换过去。每个分支都有**切换**和一个 ⋯ 菜单：

- **合并到** *你的分支*：它的工作会并入你的分支。如果双方改了相同的行，合并会停下来，让你解决冲突。
- **与** *你的分支* **比较**：两边各有哪些对方没有的提交。点击一个提交即可打开它。
- **发布**会把只在这里的分支放到远程仓库上。
- **重命名**：它在远程仓库上的分支保持原名。
- **删除**：已合并的分支会直接删除，因为不会丢失任何内容。对于未合并的分支，询问中会列出其他分支都没有的提交，点击**仍然删除**会连同它们一起删除。

收在**仅在远程仓库上**下面的是远程仓库上有、这里没有的分支：**检出**会在这里新建一个跟踪它的分支，并切换过去。

## 用储藏把更改先放到一边

储藏会把你未提交的更改先放到一边，这样你可以去做别的事，以后再把它们取回来。**储藏更改**（在**储藏**标签页中，或“更改”顶部的盒子图标）会询问这些更改是什么，以及是否**连新文件一起**；然后这些文件会恢复到上次提交时的样子。

**储藏**列出它们，附有信息、创建时所在的分支、时间和文件数。点击一个储藏，可以逐个文件查看它保存的内容：

- **应用并移除**会取回这些更改，并把储藏从列表中移除。
- **应用**会取回这些更改，并保留储藏。
- 垃圾桶图标会在询问之后丢弃它。此操作无法撤销。

如果这些更改与文件现在的内容冲突，冲突的文件会在“更改”中标记为 **C**：像合并之后那样解决它们，然后提交。

## 从会话创建拉取请求

拉取请求是请仓库的维护者把一个分支的改动合并进去。你可以直接从做出这些改动的会话，在 GitHub 或 Gitea 上创建拉取请求。

需要满足的条件：

- 在[设置 → 应用 → 源代码管理](/settings?s=scm)中，有一个用于该仓库所在服务器的 GitHub 或 Gitea 账户（见[添加 GitHub 或 Gitea 账户](/guide/devices#add-a-github-or-gitea-account)）。
- 会话的文件夹位于一个有远程仓库的 git 仓库中，并且在它自己的分支上。直接在主分支上工作的会话无法创建拉取请求：请在工作树（仓库在一个新分支上的单独副本）中启动会话，或者先切换到一个新分支。

创建方法：

1. 在会话的菜单（⋯）中，选择**文件夹与代码** → **创建拉取请求**。
2. 对话框会显示分支以及它要合并到哪里（`my-branch → main on owner/repo`）、它包含多少个提交和文件，以及分支是否已推送（如果没有，会显示“打开时会推送分支”）。
3. 如果有未提交的更改，勾选**先提交这 … 项未提交的更改，以标题作为提交信息**即可把它们包括进去。不勾选的话，它们就不会包含在内。（如果分支还没有任何提交，会自动为你勾选。）
4. 写一个标题和一段描述（Markdown），或点击**帮我写**：一个模型会读取提交、改动以及交给这个会话的任务，然后把两者都写好。这至少需要一个提交。
5. 勾选**草稿**即可将它创建为草稿。（Gitea 会在草稿的标题前加上“WIP:”。）
6. 点击**创建拉取请求**。应用会推送分支、创建拉取请求、把它关联到会话，并在新标签页中打开它。

如果这个分支已经有一个打开的拉取请求，对话框会说明这一点，并提供**将它关联到此会话**。要关联其他任何一个，点击**关联一个已有的拉取请求…**，粘贴它的地址，然后点击**链接**。

### 跟踪拉取请求

关联之后，拉取请求的编号会显示在侧边栏中会话的旁边和会话的标题栏中，附带一个表示其状态的图标（打开、草稿、已合并或已关闭），以及一个表示其检查情况的圆点（服务器对它运行的测试：运行中、已通过或失败）。应用每隔几分钟检查一次，并在它被合并或检查完成时告诉你。

点击标题栏中的编号（或会话菜单 → **文件夹与代码**中的**拉取请求 #12**）即可打开它的对话框：

- **在 GitHub 上打开**（或 Gitea）。
- **查看改动**：审查页面，见下文。
- **立即检查**：立即查询它的状态和检查情况。
- **取消关联**：把它从会话上取下（拉取请求本身仍然保留）。

## 审查分支的改动

审查页面显示会话的分支自从离开它的基础分支以来改动的一切，无论是否已提交，也包括新文件。可以从会话的菜单（⋯）→ **文件夹与代码** → **查看改动**打开它，也可以从拉取请求的对话框，或从工作树的对话框（**查看它的改动**）打开。

顶部是：“审查：”和会话的标题、分支及其基础分支、有多少个文件以及其中多少个“未提交”、拉取请求的链接（如果有的话），以及用来返回的**会话**。

每个改动过的文件都显示它的状态字母（A 新增，M 修改，D 删除，R 重命名）、路径、适用时的“未提交”标签、增删的行数，下面是它的改动。

- 在你看过的文件上勾选**已查看**：它会收起，并计入“已查看 … / …”。这个标记会一直保留到文件再次改动，并保存在这个浏览器里。
- 在宽屏上，左边有一个文件列表和一个进度条：点击一个文件即可跳到它。
- **带我逐步查看**：一个模型会读取这些改动，写出一段简短的总结、一个容易跟上的阅读顺序（先是核心思路，再是用到它的部分，测试和文档放在最后），并为每个文件写一条说明，讲清改了什么、哪里要仔细看。然后用**引导顺序**和**按路径**在这个顺序和按名称排列的文件之间切换。这份引导只对应这些改动保存，所以下次打开时它还在，直到分支再有改动。
- **重新加载**会重新读取改动。

git 尚未跟踪的新文件，如果是小的文本文件就会显示出来。二进制文件会显示“二进制文件：没有可显示的文本更改。”

## 使用终端

点击**系统**，然后点**终端**，或前往[终端](/terminal)：这台电脑上真正的 shell。如果还没有打开的终端，会在你的主文件夹中启动一个。

- 每个终端是一个标签页，以它的文件夹和其中运行的程序命名。**新建终端**（+）会再打开一个，同样在你的主文件夹中。
- 双击标签页即可重命名它。
- ✕ 会关闭终端。如果其中还有程序在运行，应用会先询问，因为关闭会结束这个 shell 以及它运行的一切。
- 输出中的链接会在新标签页中打开。

终端运行在应用自己私有的 tmux 服务器中，所以当你离开页面、重新加载页面或关闭浏览器时，它们都会继续运行，应用重启时也一样：回来时，它们还是你离开时的样子。

要在别的文件夹中打开终端，就从那里打开：文件页面上某个文件夹的菜单，或你所在文件夹的**更多**（⋯）（**在此处打开终端**）、编辑器（**在此文件夹中打开终端**）、Git 页面上的仓库（**在此处打开终端**），以及会话的菜单 → **文件夹与代码** → **在此处打开终端**。

### 终端面板

在电脑上，`` Ctrl+` ``（Mac 上也是）会在任何页面的底部显示或隐藏一个终端面板，里面的终端与终端页面上的相同。拖动它的上边缘可以调高或调低，点击**隐藏面板**可以关闭它。搜索框里的**显示或隐藏终端面板**也能做到同样的事。从其他页面打开的终端会出现在这个面板中。

### 灰色建议

当 shell 等待命令时，你正在输入的内容最可能的后半部分会以灰色显示在光标后面：

- 按 → 或 End 采用全部；按 Ctrl+→（或 Alt+→）采用下一个单词。
- 建议来自你以前输入过的命令（在同一文件夹中运行过的优先，最近的和常用的排在旧的前面）、你的 shell 自己的历史记录，以及智能体最近运行过的命令。

按 Ctrl+Space（Mac 上也是），或点击标签栏中的**建议**，会打开一个列表，里面有更多内容：

- 以你输入的内容开头的以前的命令；
- 适合你正在输入的单词的内容：git 命令和分支、项目的脚本（`npm run …`）、make 目标、SSH 主机、文件夹和文件；
- 当你输入了几个字母后，还有**编写命令：“…”**，见下文。

↑ 和 ↓ 用来选择，按 Enter 或点击会把命令填入命令行，按 Esc 关闭列表。任何命令都不会自己运行：你仍然要在 shell 中按 Enter。

建议只在 shell 的提示符处起作用，在编辑器或 Python 之类的程序里不起作用。以空格开头的命令，以及看起来含有密码或密钥的命令，都不会被记住。可以在[设置 → 应用 → 通用 → 终端建议](/settings?s=general&find=Terminal%20suggestions)中关闭灰色文字；无论开关如何，Ctrl+Space 列表都能用。

### 用文字要一条命令

在提示符处用普通的话输入你想要的，例如 `find the biggest files here`（找出这里最大的文件），按 Ctrl+Space，然后选择**编写命令：“find the biggest files here”**。一个模型（Claude Code 已登录时用 Claude，否则用 Codex）会写出最多三条适合你的 shell 和文件夹的命令，每条都附一句简短的说明，讲它做什么。选一条把它填入命令行，读一读，然后自己按 Enter 运行它。

### 在手机上

终端页面会多出一排手机上没有的按键：**Ctrl** 和 **Alt**（作用于你输入的下一个键）、**建议**、^C、^D、^Z、^L、^R、Esc、Tab、方向键、`|`、`/`、`-`、`~`、Home 和 End。手机上没有底部面板：从其他页面打开的终端会在终端页面上打开。

## 用预览查看开发服务器

当你或智能体在这里运行某个网页应用的开发服务器时（`npm run dev`、一个 Python 服务器），预览可以显示它，无论是在这台电脑上，还是在任何能访问应用的其他设备上。点击**系统**，然后点**预览**，或前往[预览](/preview)。

左边的**网页应用**列出这台电脑上用网页来响应的服务器：每个都显示它的项目名称（取自它的软件包，没有的话取自它的文件夹）、端口、页面标题、提供它的是什么（如果应用能判断出来：Vite、Next.js、Python……）以及它的文件夹。折叠起来的**其他服务器**列出其余的服务器：API、数据库之类。**其他端口**可以打开没有列出的服务器。列表每 5 秒刷新一次；刷新按钮会立即重新读取。

点击一个网页应用，就会在右边显示它。在电脑上，第一个会立即显示；在手机上，它会占满屏幕，用**所有服务器**返回。它的上方有：

- **返回**、**前进**和**重新加载**，以及显示端口和页面路径的地址栏。地址栏会跟着你在应用里点击的链接变化；输入另一个路径并按 Enter 就可以前往。
- **电脑**、**平板**和**手机**：按那种屏幕的宽度显示应用（手机是 390 像素），并缩小到能放下。
- **更多**（⋯）：**在单独的标签页中打开**、**就这个画面问问智能体**（开始页会打开，附上这个画面的图片，设为在该应用的文件夹中工作，并写好开头“About this screen of …”让你接着写）、**保存截图**，以及**以图片显示**或**实时显示**。

### 实时显示，或者显示为图片

预览通过应用的预览端口（端口为 8791，除非你的安装设置了别的端口）实时显示开发服务器，这样开发服务器就和应用隔离开：你的登录信息永远不会传到它那里，并且支持热重载。一个浏览器一次只预览一个服务器：显示另一个时，预览端口就会转到那个服务器。

当你的浏览器访问不到预览端口时（比如你通过只有一个主机名的隧道或代理访问应用），页面会改为在这台电脑上的一个浏览器中按你选择的尺寸打开，并实时传到预览里：你可以像在任何网页中一样在里面点击、输入、滚动和粘贴，热重载也会显示出来。在手机上，用手指点按和拖动；页面下方的**输入**会调出键盘，旁边还有手机缺少的按键（Tab、Enter、Esc、方向键）。页面只能访问那个开发服务器，访问不到这台电脑上的其他服务器。回到预览时，页面还停在你离开的地方；15 分钟没人查看后它会关闭，等你再看时重新打开。**保存截图**和**就这个画面问问智能体**用的是页面在屏幕上的当前样子。

如果想让页面本身在你的浏览器中打开，而不是传过来的画面：

- 在同一个网络中，或通过 Tailscale、WireGuard 之类的 VPN，用这台电脑自己的地址打开应用：这个端口可以直接使用；
- 在隧道或代理后面时，给预览端口单独分配一个主机名（preview.example.com → localhost:8791），并在启动应用时把 `PREVIEW_ORIGIN` 设为它。

**更多**（⋯）里的**以图片显示**会改为显示在这台电脑上截取的静态图片；这时**重新加载**会重新截一张图。实时画面和图片都需要这台电脑上有一个 Chromium：也就是浏览器功能使用的那个（[设置 → 功能 → 浏览器](/settings?s=browser)可以下载一个）。“预览已关闭”表示应用是用 `PREVIEW_PORT=0` 启动的。预览只适用于你打开应用的那台机器，不适用于你切换到的其他机器。

## 审阅智能体对网页应用的修改

当智能体修改一个网页应用的外观或功能时（一个带开发服务器的网站或应用，或者一些 HTML 文件），它会给你看截图供你审阅：在第一次修改之前，给每个要修改的画面截一张图；完成之后，再把同样的画面截一次。如果应用的开发服务器没有在运行，它会先启动它。

- **修改前**卡片用小图显示画面原来的样子：同一次回复里的截图会放在一起，显示在一张卡片里。在**修改前后**卡片里，一个画面的一对截图标着**修改前 → 修改后**，修改前和修改后从中间分开。如果智能体也截了手机尺寸，这个画面会有一个手机标志。一次回复的画面多到一行放不下时，卡片只显示第一行，下面有**全部显示**（**收起**会再把它们折起来）。
- 点击一张图来审阅它：在宽屏上，它会像页面一样在对话旁边打开；在较窄的窗口或手机上，则在应用上方打开。顶部的箭头可以前往这次回复的其他画面。
- 一个画面的修改前和修改后会叠在一起显示：拖动滑块（或按 ← 和 →）可以在两者之间来回对比，也可以选择**并排**。如果智能体两种尺寸都截了，电脑和手机按钮可以在两者之间切换。**查看大图**会在应用上方打开这些图片。**看起来不错**和**需要修改**会在消息框中放入一行关于这个画面的话，由你补充完再发送。
- 在宽屏上，一个画面的修改后截图到达时，会自动在对话旁边打开。
- 没有修改前图片的修改后图片会单独显示，并附上“没有可对比的修改前图片。”；智能体会被告知下次先截修改前的图。

你也可以随时要一张截图：“给我看看设置页面在手机上的样子”，或者“用深色主题”（跟随电脑浅色或深色的网站会按你说的那种显示，否则按浅色显示）。智能体为对话或资料库做的页面（设计稿、报告）会按应用显示它的样子截图，除非要求浅色主题，否则用深色主题，这样在你看到之前，智能体就能发现看不清的地方。这些图片由这台电脑上的 Chromium 截取（[设置 → 功能 → 浏览器](/settings?s=browser)），并随它们的会话一起保存：会话删除时它们也会删除，总量超过 500 MB 时，最旧的先删除。

## 在监控中查看这台电脑

点击**系统**，然后点**监控**，或前往[监控](/system/monitor)。顶部是：电脑的名称、处理器、它有多少个线程、已经运行了多久，以及它的操作系统。

顶部的小方块显示以下内容，并附有最近两分钟的小图表：

- **CPU**：处理器有多忙，以及平均负载。
- **记忆**（即内存）：用了多少，总共多少。
- **GPU × n**（有 NVIDIA GPU 时）：平均使用率，以及已用的显存。
- **网络**：每秒接收和发送的数据量。
- **磁盘 I/O**：每秒读取和写入的数据量。

下面是更详细的内容：

- **CPU**：一张图表、每个核心的负载，以及温度（如果能读到的话）。
- **记忆**（即内存）：一张图表、已用的 RAM（包括缓存和缓冲区）、交换空间，以及还有多少可用。
- 每个 **GPU** 一张卡片：使用率、显存、功耗与其上限、温度、风扇、性能状态和时钟频率（在手机上不显示图表）。
- **网络**：下载和上传，以及每个网络连接。
- **存储**：读取和写入，以及每块磁盘的可用空间、文件系统和已用比例。
- **传感器**：各项温度，从 85 °C 起显示为红色。
- **笔记本内核**（有内核在运行时）：每个都显示它的环境、状态、内存和**关闭**。
- **会话**（有会话在运行时，在 Linux 和 Mac 上）：每个运行中的会话的程序（它的智能体的程序、它运行的命令、它启动的服务器），内存用得最多的排在前面，显示数量、CPU 和内存。右侧是会话运行时受的上限：点击即可修改（[限制每个会话](/guide/app#limit-each-session)）。点击会话即可打开它。
- **进程**：最忙的 12 个程序，可以按 **CPU** 或**记忆**排序（使用 GPU 的程序还可以按 **GPU** 排序），显示进程 ID、用户、CPU 和内存。把鼠标指向一行可以看到它的完整命令。

页面打开期间，它每 2 秒读取一次数据，并保留最近 10 分钟的记录。
