# 文件、Git、终端和预览

围绕智能体的各种工具：浏览、打开和编辑这台电脑上的文件，在文件内容中搜索，运行 Jupyter 笔记本，用 Git 提交和推送，创建拉取请求，以及审查一个分支改了什么。终端、这里运行的开发服务器的预览，以及这台电脑的实时状态（系统）也都在这里，所以你不用离开应用，就能检查并完成智能体的工作。

## 打开文件页面

点击侧边栏工具中的**文件**，或前往[文件](/files)。在电脑上，这个页面分为两部分：

- 左边是一个切换开关，在**文件**（文件夹树）和**搜索**（在文件内容中搜索，见[在文件内容中搜索](/guide/files-git#search-inside-files)）之间切换。
- 右边是你打开的文件，每个文件一个标签页。没有打开任何文件时，它会显示“没有打开的文件”，并提醒你可以用 Ctrl+P（Mac 上是 ⌘P）。

在手机上，文件树占满整个屏幕。文件会在单独的页面上打开，用**返回**回到文件树。

其他打开方式：

- 点击会话标题下方的文件夹，或使用会话的菜单（⋯）→ **文件夹与代码** → **浏览文件夹**：文件树会在那个文件夹打开。
- 智能体改过或交给你的文件，或它回复中指向某个文件的链接，会在对话上方的窗口中打开，这样你不会丢失当前的位置。**在“文件”中打开**会把它移到文件页面；✕ 或 Esc 会关闭它（如果你改了却没保存，它会先问“放弃你的更改？”）。

## 在文件树中浏览文件夹

文件树从一个根文件夹开始，起初是新会话开始时所在的文件夹。它的路径显示在顶部，用 `~` 表示你的主文件夹。

- **更改根目录**：点击路径，输入另一个路径。输入时会提示子文件夹，以及你的会话工作过的文件夹（标有“最近”）；按 Tab 采用一条提示并进入其中。然后按**打开**，或按**取消**。
- **上一级文件夹**（箭头按钮）把根目录移到上一级文件夹。
- 文件夹的菜单 → **作为根目录打开**会把它设为根目录。
- 点击文件夹即可展开或收起它。文件树会为每个根目录记住哪些文件夹是展开的。
- 你查看文件树时，它每 5 秒自动刷新一次，所以智能体新建的文件会自己出现。**刷新**会立即刷新。
- **显示隐藏文件** / **隐藏点文件**（眼睛按钮）显示或隐藏名称以点开头的文件和文件夹。`.github` 文件夹总是显示。

根文件夹和你打开的标签页保存在这个浏览器里，你用的每台机器各自分开保存（见[其他机器](/guide/devices#use-other-machines-from-one-app)）。

### 文件旁边的字母是什么意思

在 git 仓库（由 git 保存历史记录的文件夹）里，自上次提交以来有改动的文件会带有一个字母和一种颜色：

- **M**：已修改。
- **A**：新文件，已经添加到 git。
- **U**：新文件，还没有加入 git。
- **D**：已删除。
- **R**：已重命名。
- **C**：有待解决的冲突。
- **•** 出现在文件夹上：里面有东西改动了。

## 处理文件和文件夹

文件树中的每一行都有一个菜单。把鼠标指向这一行并点击**更多**（⋯），或右键点击它，在手机上则长按它。菜单里有：

- **打开**（文件）或**作为根目录打开**（文件夹）。
- **在这里新建文件**和**在这里新建文件夹**。
- **将文件上传到这里**和**将文件夹上传到这里**。
- **在此处打开终端**：在那个文件夹中打开一个新的 shell，电脑上在底部面板中，手机上在终端页面上。
- **在这里新建智能体会话**：打开开始页，并已选好那个文件夹。
- **重命名**。
- **复制路径**：完整路径，可以粘贴到任何地方。
- **下载**（文件）。
- **删除**。

文件树顶部的按钮对根文件夹做同样的事：**新建文件**、**新建文件夹**和**上传文件**。

### 新建文件或文件夹

1. 点击**新建文件**或**新建文件夹**（或者行菜单里的**在这里新建文件** / **在这里新建文件夹**）。
2. 在文件树中出现的字段里输入名称，然后按 Enter。按 Esc 取消。

新文件是空的，会立即在编辑器中打开。如果名称已被占用，应用会告诉你，并且不会新建任何东西。

### 重命名或移动

- **重命名**会把名称变成一个输入字段。按 Enter 保留新名称，按 Esc 则保持原样。
- 在电脑上，把一行拖到另一个文件夹上即可移到那里，拖到文件树的空白处则移到根文件夹。文件夹不能移进它自己，也不会替换任何东西：如果目标位置已经有同名的东西，移动就会停止。

### 删除

**删除**会先询问，然后把文件，或者文件夹连同里面的所有东西，移到应用数据文件夹中的回收站文件夹。询问中会说明它在哪里（例如 `~/.naget-agent/trash`）。要找回某样东西，先显示隐藏文件，在文件树中打开那个文件夹，再把它移出来：它的名称以删除时的日期和时间开头。

- 你的主文件夹和顶层文件夹（`/`）不能删除。
- 与应用数据文件夹不在同一块磁盘上的东西无法移到回收站，所以会被永久删除。

## 上传文件和文件夹

- 文件树顶部的**上传文件**会上传到根文件夹。行菜单里有**将文件上传到这里**和**将文件夹上传到这里**。
- 在电脑上，把文件或整个文件夹从桌面拖到文件树中的某个文件夹上，或者拖到文件树的空白处以上传到根目录（“将文件或文件夹拖到某个文件夹上即可上传”）。空文件夹也会一起上传。

上传情况显示在右下角的**上传**面板中：逐个文件显示已上传了多少。**取消**会停止某个上传，✕ 会把已完成的上传从面板中清除。大文件会分成 32 MB 的块上传。

在发送任何东西之前，应用会检查那个文件夹里有没有同名的文件。如果有，面板会列出它们（“3 个已存在”），并给出三个选择：

- **替换**：上传并覆盖已有的文件。
- **跳过已存在的**：只上传新的文件。
- **取消**：什么都不上传。

## 打开和编辑文件

在文件树中点击一个文件。它会在编辑器中、在单独的标签页里打开。你最近打开的 12 个文件会保留为标签页：点击一个即可回到它，用它的 ✕ 或鼠标中键点击可以关闭它。

编辑器会给行编号，按文件的语言给文字着色，匹配括号；在电脑上，还能折叠代码块，并在你输入时提示补全。按 Tab 缩进。

要保存，点击**保存**（你改动了什么之后它就会亮起），或按 Ctrl+S（Mac 上是 ⌘S）。文件名旁边的圆点表示有未保存的更改；带着未保存的更改离开页面时，浏览器会先询问。

### 编辑器的工具

在电脑上，文件上方的工具栏显示它的路径和这些按钮：

- **预览**（Markdown 文件）：按阅读效果显示文件，包括标题、表格、它自己的图片（来自文件旁边）和指向其他文件的链接。再点一次即可编辑。Markdown 文件会先以预览方式打开。
- **以页面显示**（HTML 文件）：在一个与应用隔离的框架中运行这个页面，它可以加载旁边的文件。HTML 文件会先以页面方式打开。页面的链接有效期为一小时；过期后，重新打开文件即可。
- **自上次提交以来的更改**：文件与它上次提交时的差异，新增的行显示为绿色，删除的行显示为红色。如果文件与上次提交时一致，或者不在 git 仓库中，它会显示“没有更改”。
- **自动换行**：把长行折行显示，而不是横向滚动。这个选择会被记住。
- **在此文件夹中打开终端**：在文件所在的文件夹中打开一个新的 shell。
- **下载**。
- **保存**。

要在文件中查找文字，在光标位于文件中时按 Ctrl+F（Mac 上是 ⌘F）：顶部会打开一个查找栏，也可以替换。

在手机上，工具栏显示**返回**、文件名（下面是它所在的文件夹）、**预览**或**以页面显示**、**保存**（你改动了什么之后才出现）以及**更多**（⋯），其中有**查找**、**自动换行**、**自上次提交以来的更改**、**在此文件夹中打开终端**和**下载**。手机上会自动换行，除非你关闭**自动换行**。

### 文件在你打开期间发生变化时

智能体和终端随时都在改动文件。编辑器每隔几秒就会检查一次文件：

- 如果没有未保存的内容，它会自己载入新版本。
- 如果你有未保存的更改，会出现一个提示栏：“自你打开后，该文件已在磁盘上被更改。”要采用新版本，选择**重新加载（丢弃我的修改）**；要用你的版本覆盖它，选择**用我的版本覆盖**。

不经过这个询问，保存永远不会覆盖更新的版本。

### 编辑器不能编辑的文件

- 超过 10 MB 的文件：“文件太大，无法在这里编辑”。下载它，或在终端中打开它。（笔记本最大可以到 40 MB。）
- 二进制文件（任何不是文本的文件）：“二进制文件”。下载后在你的设备上打开。
- 图片、PDF、视频、音频和 Office 文档会改为显示预览，下一节会介绍。

## 查看图片、PDF、文档和网页

文件查看器按文件本来的样子显示它们：

- **图片**（PNG、JPEG、GIF、WebP、SVG、ICO、BMP、AVIF）：完整显示，透明的部分衬着棋盘格。
- **PDF**：在浏览器自带的 PDF 查看器中显示。
- **视频**（MP4、WebM、MOV 和 M4V；浏览器支持时还有 MKV 和 OGV）：在应用自带的播放器中播放（见下文的[观看视频](#watch-a-video)）。**音频**（MP3、WAV、OGG）就地播放。
- **Office 文档**：Word（.docx、.doc 等）、Excel（.xlsx、.xls）、PowerPoint（.pptx、.ppt）、OpenDocument（.odt、.ods、.odp）、RTF 和 EPUB。顶部的切换开关用来选择视图：
  - **页面**：LibreOffice 排版后的文档，一页一页显示（第一次会显示“正在排版页面…”）。只有这台电脑上安装了 LibreOffice 时才有这个视图，EPUB 电子书也没有。
  - **文本**：应用读出的文字、工作表和幻灯片。

  手机上默认是**文本**，因为它在手机上滚动和缩放都更顺畅。如果文档无法读取，会显示“此文件无法预览”：那就下载它。
- **Markdown** 和 **HTML**：见上文的**预览**和**以页面显示**。

**下载**始终在工具栏里。

### 观看视频

视频会在应用自带的播放器中打开，播放器占满整个查看区域：

- **播放和暂停**：中间的圆形按钮、左下角的按钮、点一下画面，或按空格键（K 键也可以）。双击画面会全屏。
- **前后跳转**：沿底部的进度条拖动，或点击条上的某一点；把指针停在进度条上会显示该处的时间，条上颜色较浅的部分是已经加载的内容。← 和 → 移动 5 秒，J 和 L 移动 10 秒，Home 和 End 跳到开头和结尾，0 到 9 跳到视频相应的十分之一处，暂停时 , 和 . 逐帧前后移动。
- **声音**：喇叭按钮切换静音（M）。在电脑上，把指针停在喇叭上会出现音量滑块；↑ 和 ↓ 也能调节音量。
- **速度**：**1×** 按钮可在 0.5× 到 2× 之间选择（**正常**即 1×）。
- **循环**会在每次播放结束时从头再放；**画中画**让视频在一个浮于其他内容之上的小窗口里继续播放（浏览器支持时）；**下载**保存文件；**全屏**（F）占满屏幕，再按同一个按钮或按 Esc 即可返回。
- 播放时控件会淡出，移动指针时重新出现。播放器会为下一个视频记住你的音量和速度。
- **在手机上**：点一下画面显示或隐藏控件，在画面左侧或右侧双击可后退或前进 10 秒。在 iPhone 上，全屏使用手机自带的视频播放器。
- 浏览器无法播放的视频（MKV 和 AVI 文件常用浏览器不支持的编码）会显示“这个视频无法在这里播放”，并提供**下载**，以便用视频应用观看。

## 按名称查找文件

在任何页面上按 Ctrl+P（Mac 上是 ⌘P）。“转到 … 中的文件”会按名称搜索文件页面的根文件夹：按顺序输入名称中的几个字母即可（`invq3` 能找到 `invoices/q3-report.xlsx`）。文件名本身包含你所输入内容的文件排在前面。用 ↑ 和 ↓ 移动，按 Enter 或点击即可打开。它最多列出 60 个文件，包括隐藏文件。

搜索框（Ctrl+K，Mac 上是 ⌘K）也能按名称查找同一文件夹中的文件，只要你输入两个字母。

## 在文件内容中搜索

点击文件树上方的**搜索**，或前往[在文件中搜索](/search)。

1. 在“在文件中搜索”中输入要查找的内容。结果会随着你的输入出现，按文件分组，每个文件都显示匹配的数量。
2. 点击某一行，即可在那一行打开文件；点击文件名则打开该文件。

字段旁边有：

- **区分大小写**：严格匹配大小写。不开启时，全是小写的搜索会忽略大小写，含有大写字母的搜索则区分大小写。
- **正则表达式**：把你输入的内容当作模式（`colou?r`），而不是普通文本。

它下面的“要包含的文件，例如 *.ts, !dist/**”可以缩小搜索范围：用逗号分隔多个模式，前面加 `!` 则排除这些文件。

搜索范围是文件树的根文件夹（“位于 …”这一行会写出它）；要搜索别处，就更改根目录。它会跳过隐藏文件、文件夹的 `.gitignore` 排除的文件，以及超过 4 MB 的文件。每个文件最多 50 个匹配、总共最多 1,000 个匹配（“显示前 1000 个匹配项。”），或者满 15 秒，搜索就会停止；每个文件列出前 30 行匹配的内容。

## 运行 Jupyter 笔记本

笔记本（`.ipynb`）会以笔记本的形式打开：显示它的各个单元格，每个都带着输出。顶部的工具栏有内核按钮、**运行所有单元格**、**中断（I, I）**、**重启内核 (0, 0)**、**清除所有输出**、**查看笔记本文件（JSON）**、**下载**和**保存**。在手机上，不常用的那些放在**更多**里：**重启内核**、**重启并全部运行**、**清除所有输出**、**查看文件（JSON）**，还有**下载**。

### 选择代码在哪里运行

内核按钮（一个圆点加一个名称，或“没有内核”）会打开**用以下环境运行此笔记本**：这台电脑上的 Python 环境。它列出笔记本所在文件夹或其上级文件夹中名为 `.venv`、`venv` 或 `env` 的虚拟环境、conda 环境、系统 Python，以及在这里注册的 Jupyter 内核（也包括其他语言的）。每个都显示它的版本，笔记本要求的那个（或它旁边的虚拟环境）会标为**推荐**。

- 标有“需要 ipykernel”的环境有一个**安装**按钮：你确认后，它会在那个环境中运行 `pip install ipykernel`，环境里的其他东西都不会改变。
- 还没有内核时运行单元格，会在推荐的环境中启动一个内核。如果失败，列表会打开，让你选另一个。
- 内核运行时，按钮的菜单会显示它的状态（正在启动、空闲、正在运行、正在重启或已停止）、启动时间，以及**中断**、**重启**和**关闭**。选择另一个环境前会先询问，因为正在运行的内核里的变量会丢失。

关闭笔记本后，内核仍会继续运行，应用重启时也不会中断：再次打开笔记本，期间运行的输出都在那里。要关闭内核，可以从它的菜单操作，或者到列出了正在运行的内核的[系统](/system)页面。

### 编写和运行单元格

单元格分为**代码**、**文本**（Markdown）和**原始**三种。点击代码单元格即可编辑它，文本单元格则要双击。单元格运行时会显示 `[*]` 和一个计时器；运行结束后显示它的运行编号，如 `[3]`。

- 把鼠标指向代码单元格，它的编号位置会变成一个运行按钮（“运行 (Ctrl+Enter)”；单元格运行时，它会中断内核）。它的工具显示在角落里：**编辑**（文本单元格）、单元格类型、**上移**、**下移**、**在下方添加单元格**和**删除此单元格**。在手机上，轻点一个单元格：它的工具会显示在它上方，包括**运行**。
- 在电脑上，把鼠标指向两个单元格之间，会显示 **+ 代码** 和 **+ 文本**。最后一个单元格下方也有这两个按钮。
- 当代码请求输入时（Python 的 `input()`），单元格下方会出现一个字段：“输入后按 Enter”。密码会保持隐藏。
- 编辑代码时，在一个名称后按 Tab，会向正在运行的内核请求补全。

输出可以显示文字、带颜色的错误信息、图片和图表、表格、HTML（在隔离的框架中）、Markdown 和公式。“交互式小组件无法在这里运行”，JavaScript 输出也不行。

### 快捷键

编辑单元格时：

- Shift+Enter：运行它并转到下一个单元格（在最后一个之后则新建一个）。
- Ctrl+Enter（Mac 上是 ⌘Enter）：运行它并留在原处。
- Alt+Enter：运行它并在下方添加一个单元格。
- Esc：停止编辑。

没有在编辑单元格时：

- Enter：编辑选中的单元格。↑ / ↓（或 K / J）：在单元格之间移动。
- A / B：在上方 / 下方添加单元格。D, D：删除单元格。Z：恢复最后删除的单元格。
- M, Y, R：把单元格设为文本、代码或原始。
- I, I：中断内核。0, 0：重启内核。

按 Ctrl+S（Mac 上是 ⌘S）保存。和其他文件一样，如果你有未保存的更改时笔记本在磁盘上被改动，会出现一个提示栏，提供两个选择：**重新加载（丢弃我的修改）**，或**用我的版本覆盖**。**查看笔记本文件（JSON）**：在编辑器中以文本形式显示文件；**以笔记本方式打开**则返回笔记本视图。

## 在 Git 页面查看你的仓库

点击侧边栏中的 **Git**，或前往 [Git](/git)。它列出你的会话工作过的 git 仓库，最近用过的排在前面：包括含有某个会话文件夹的仓库，以及含有某个会话编辑过的文件的仓库（`/tmp` 之类的临时位置不算在内）。要让某个仓库出现在这里，就在其中启动一个会话。

每个仓库都显示它的名称、分支、改动了多少个文件以及最后一次提交的时间，并带有一个标记：

- **↑ 3**：有三个提交待推送。**↓ 2**：有两个提交待拉取。
- **已是最新**：分支与远程仓库（用来共享仓库的服务器，例如 GitHub）上的副本一致。
- **仅本地**：分支还不在远程仓库上。**已分离**：不在任何分支上。

在顶部，**全部获取**会向每个仓库的远程仓库询问有什么新内容，**刷新**会重新读取列表。

点击一个仓库即可打开它。在电脑上，它会在列表旁边打开；在手机上，它会占满屏幕，并带有返回列表的箭头。它的页面显示名称和文件夹、**在此处打开终端**、分支菜单、分支跟踪的对象（“跟踪 origin/main”、“尚未推送到远程仓库”或“无远程仓库”），以及从上到下这几个部分：**待推送**、**待拉取**、**更改**、**储藏**和**最近的提交**，然后是各个远程仓库的地址。

## 获取、拉取和推送

- **获取**会向远程仓库询问有什么新内容，而不改动你的文件。它旁边的一行说明上次获取是什么时候（起初是“从未获取”）。然后**待拉取**会列出在那里等待的提交。
- **拉取**（它会显示数量：**拉取 2**）把那些提交拉进来，只做快进：它从不产生合并提交。如果你的分支和远程分支都有了新的提交，它会失败，并提示你在终端中合并或变基。
- **推送**（**推送 3**）会先询问并列出你的提交，然后把它们推送上去。分支上远程仓库没有的所有内容都会推送上去，包括其他会话做的提交。
- 当分支还不在远程仓库上时，会出现**发布分支**，代替**推送**：它会在远程仓库上创建这个分支，并把它设为该分支的上游（它所跟踪的远程分支）。

其中某项失败时，会出现一个红框，显示“… 失败”以及 git 自己的消息；✕ 可以关闭它。没有远程仓库的仓库会注明这一点：在终端中添加一个（`git remote add origin <address>`），然后在这里发布分支。

应用里的 git 从不询问密码。推送和拉取使用这台电脑的 SSH 密钥或保存的 git 凭据；如果它们不能在没有提示的情况下工作，就会失败并显示 git 的消息。

## 提交更改

**更改**列出每个改动过的文件，以及它发生了什么（新增、已添加、已修改、已删除、已重命名、已复制、冲突）。没有单独的暂存步骤：你勾选要纳入提交的文件即可。

- 每个文件都有一个可以勾选的框；顶部的框可以全部勾选或全部取消，并说明有多少个纳入了提交（“4 / 6 纳入提交”）。长列表只显示前 60 个文件，以及**显示全部 … 个文件**。
- 点击一个文件可以查看它的改动。**打开文件**会在编辑器中打开它。
- **放弃更改**会把文件恢复到上次提交时的样子；对于新文件，则是**删除新文件**。两者都会先询问，而且无法撤销。

要提交：

1. 勾选文件。
2. 在“提交信息”中写下提交信息，或点击**撰写信息**：一个模型会读取所勾选文件的改动，并按照仓库最近几条提交信息的风格起草一条（Claude Code 已登录时用 Claude，否则用 Codex）。你可以随意修改。
3. 点击**提交**，或点击**提交并推送**直接把它发送到远程仓库（后者只在仓库有远程仓库时才显示；如果分支还不在那里，它会发布这个分支）。

只有勾选的文件会被纳入，即使其他文件在别处已被暂存。

## 切换、创建和删除分支

点击分支名称（带分支图标的按钮）即可打开分支菜单：

- **从这里新建分支**：输入名称，然后点击**创建**。新分支从你当前所在的位置开始，并且你会切换到它。
- 各个分支，最新的排在前面，每个都显示它最后一次改动的时间、它与远程分支相比的状况，以及当它的工作已经在当前分支中时显示的“已合并”。点击一个即可切换过去。如果有未提交的更改，应用会先询问：这些更改会一起带过去；如果它们与那个分支冲突，git 会拒绝操作，什么都不会改变。
- 已合并的分支有一个删除按钮。这里只能删除已合并的分支，所以不会丢失任何提交。

## 用储藏把更改先放到一边

**储藏**（在**更改**旁边）会把所有更改先放到一边，包括新文件，并让文件夹恢复到上次提交时的样子。随后这个储藏会显示在**储藏**下面，附有它的信息和创建时间：

- **应用**会把这些更改带回来，并把这个储藏从列表中移除。
- **丢弃**会在询问之后删除这个储藏。这无法撤销。

## 浏览历史记录

- **待推送**：你的分支上有、而远程仓库没有的提交（最多显示最近的 100 个）。
- **待拉取**：远程仓库上有、而你没有的提交，以上次获取时为准。
- **最近的提交**：最后 15 个提交。

只有当分支跟踪着远程仓库上的某个分支时，才会显示**待推送**和**待拉取**。

点击一个提交即可打开它：它的完整信息、作者、日期，以及它改动的文件和增删的行数。点击一个文件即可查看它的改动。

## 从会话创建拉取请求

拉取请求是请仓库的维护者把一个分支的改动合并进去。你可以直接从做出这些改动的会话，在 GitHub 或 Gitea 上创建拉取请求。

需要满足的条件：

- 在[设置 → 应用 → 源代码管理](/settings?s=scm)中，有一个用于该仓库所在服务器的 GitHub 或 Gitea 账户（见[添加 GitHub 或 Gitea 账户](/guide/devices#add-a-github-or-gitea-account)）。
- 会话的文件夹位于一个有远程仓库的 git 仓库中，并且在它自己的分支上。直接在主分支上工作的会话无法创建拉取请求：请在工作树（仓库在一个新分支上的单独副本）中启动会话，或者先切换到一个新分支。

创建方法：

1. 在会话的菜单（⋯）中，选择**文件夹与代码** → **创建拉取请求**。
2. 对话框会显示分支以及它要合并到哪里（`my-branch → main on owner/repo`）、它包含多少个提交和文件，以及分支是否已推送（如果没有，会显示“打开时会推送分支”）。
3. 如果有未提交的更改，勾选**先提交这 … 项未提交的更改，以标题作为提交信息**即可把它们包括进去。不勾选的话，它们就不会包含在内。（如果分支还没有任何提交，会自动为你勾选。）
4. 写一个标题和一段描述（Markdown），或点击**帮我写**：一个模型会读取提交、改动以及交给这个会话的任务，然后把两者都写好。这至少需要一个提交。
5. 勾选**草稿**即可将它创建为草稿。（Gitea 会在草稿的标题前加上“WIP:”。）
6. 点击**创建拉取请求**。应用会推送分支、创建拉取请求、把它关联到会话，并在新标签页中打开它。

如果这个分支已经有一个打开的拉取请求，对话框会说明这一点，并提供**将它关联到此会话**。要关联其他任何一个，点击**关联一个已有的拉取请求…**，粘贴它的地址，然后点击**链接**。

### 跟踪拉取请求

关联之后，拉取请求的编号会显示在侧边栏中会话的旁边和会话的标题栏中，附带一个表示其状态的图标（打开、草稿、已合并或已关闭），以及一个表示其检查情况的圆点（服务器对它运行的测试：运行中、已通过或失败）。应用每隔几分钟检查一次，并在它被合并或检查完成时告诉你。

点击标题栏中的编号（或会话菜单 → **文件夹与代码**中的**拉取请求 #12**）即可打开它的对话框：

- **在 GitHub 上打开**（或 Gitea）。
- **查看改动**：审查页面，见下文。
- **立即检查**：立即查询它的状态和检查情况。
- **取消关联**：把它从会话上取下（拉取请求本身仍然保留）。

## 审查分支的改动

审查页面显示会话的分支自从离开它的基础分支以来改动的一切，无论是否已提交，也包括新文件。可以从会话的菜单（⋯）→ **文件夹与代码** → **查看改动**打开它，也可以从拉取请求的对话框，或从工作树的对话框（**查看它的改动**）打开。

顶部是：“审查：”和会话的标题、分支及其基础分支、有多少个文件以及其中多少个“未提交”、拉取请求的链接（如果有的话），以及用来返回的**会话**。

每个改动过的文件都显示它的状态字母（A 新增，M 修改，D 删除，R 重命名）、路径、适用时的“未提交”标签、增删的行数，下面是它的改动。

- 在你看过的文件上勾选**已查看**：它会收起，并计入“已查看 … / …”。这个标记会一直保留到文件再次改动，并保存在这个浏览器里。
- 在宽屏上，左边有一个文件列表和一个进度条：点击一个文件即可跳到它。
- **带我逐步查看**：一个模型会读取这些改动，写出一段简短的总结、一个容易跟上的阅读顺序（先是核心思路，再是用到它的部分，测试和文档放在最后），并为每个文件写一条说明，讲清改了什么、哪里要仔细看。然后用**引导顺序**和**按路径**在这个顺序和按名称排列的文件之间切换。这份引导只对应这些改动保存，所以下次打开时它还在，直到分支再有改动。
- **重新加载**会重新读取改动。

git 尚未跟踪的新文件，如果是小的文本文件就会显示出来。二进制文件会显示“二进制文件：没有可显示的文本更改。”

## 使用终端

点击侧边栏中的**终端**，或前往[终端](/terminal)：这台电脑上真正的 shell。如果还没有打开的终端，会启动一个。

- 每个终端是一个标签页，以它的文件夹和其中运行的程序命名。**新建终端**（+）会在文件页面的根文件夹中再打开一个。
- 双击标签页即可重命名它。
- ✕ 会关闭终端。如果其中还有程序在运行，应用会先询问，因为关闭会结束这个 shell 以及它运行的一切。
- 输出中的链接会在新标签页中打开。

终端运行在应用自己私有的 tmux 服务器中，所以当你离开页面、重新加载页面或关闭浏览器时，它们都会继续运行，应用重启时也一样：回来时，它们还是你离开时的样子。

还有其他地方可以在某个文件夹中打开新终端：文件页面上的行菜单（**在此处打开终端**）、编辑器（**在此文件夹中打开终端**）、Git 页面上的仓库（**在此处打开终端**），以及会话的菜单 → **文件夹与代码** → **在此处打开终端**。

### 终端面板

在电脑上，`` Ctrl+` ``（Mac 上也是）会在任何页面的底部显示或隐藏一个终端面板，里面的终端与终端页面上的相同。拖动它的上边缘可以调高或调低，点击**隐藏面板**可以关闭它。搜索框里的**显示或隐藏终端面板**也能做到同样的事。从其他页面打开的终端会出现在这个面板中。

### 灰色建议

当 shell 等待命令时，你正在输入的内容最可能的后半部分会以灰色显示在光标后面：

- 按 → 或 End 采用全部；按 Ctrl+→（或 Alt+→）采用下一个单词。
- 建议来自你以前输入过的命令（在同一文件夹中运行过的优先，最近的和常用的排在旧的前面）、你的 shell 自己的历史记录，以及智能体最近运行过的命令。

按 Ctrl+Space（Mac 上也是），或点击标签栏中的**建议**，会打开一个列表，里面有更多内容：

- 以你输入的内容开头的以前的命令；
- 适合你正在输入的单词的内容：git 命令和分支、项目的脚本（`npm run …`）、make 目标、SSH 主机、文件夹和文件；
- 当你输入了几个字母后，还有**编写命令：“…”**，见下文。

↑ 和 ↓ 用来选择，按 Enter 或点击会把命令填入命令行，按 Esc 关闭列表。任何命令都不会自己运行：你仍然要在 shell 中按 Enter。

建议只在 shell 的提示符处起作用，在编辑器或 Python 之类的程序里不起作用。以空格开头的命令，以及看起来含有密码或密钥的命令，都不会被记住。可以在[设置 → 应用 → 通用 → 终端建议](/settings?s=general&find=Terminal%20suggestions)中关闭灰色文字；无论开关如何，Ctrl+Space 列表都能用。

### 用文字要一条命令

在提示符处用普通的话输入你想要的，例如 `find the biggest files here`（找出这里最大的文件），按 Ctrl+Space，然后选择**编写命令：“find the biggest files here”**。一个模型（Claude Code 已登录时用 Claude，否则用 Codex）会写出最多三条适合你的 shell 和文件夹的命令，每条都附一句简短的说明，讲它做什么。选一条把它填入命令行，读一读，然后自己按 Enter 运行它。

### 在手机上

终端页面会多出一排手机上没有的按键：**Ctrl** 和 **Alt**（作用于你输入的下一个键）、**建议**、^C、^D、^Z、^L、^R、Esc、Tab、方向键、`|`、`/`、`-`、`~`、Home 和 End。手机上没有底部面板：从其他页面打开的终端会在终端页面上打开。

## 用预览查看开发服务器

当你或智能体在这里运行某个网页应用的开发服务器时（`npm run dev`、一个 Python 服务器），预览可以在你的浏览器中打开它，无论是在这台电脑上，还是在任何能访问应用的其他设备上。点击侧边栏中的**预览**，或前往[预览](/preview)。

- **在这里运行**列出这台电脑上正在监听的服务器，每个都显示它的端口、程序、文件夹和命令。点击**打开**。
- 对于没有列出的服务器，在**其他端口**下输入它的端口，然后点击**打开**。

预览会在单独的标签页中、在应用的预览地址上打开（端口为 8791，除非你的安装设置了别的端口）。那个浏览器会在 12 小时内保持预览的登录状态，并且支持热重载。你在应用中的登录信息永远不会传到开发服务器。一个浏览器一次只预览一个服务器：打开另一个时，预览地址就会转到那个服务器。每次点击**打开**都会生成一个新的一次性链接，所以要在手机上查看，就在手机上打开预览并点击**打开**。列表每 5 秒刷新一次；**刷新**会立即重新读取。

- 如果你的浏览器访问不到预览端口，页面会说明这一点：在同一个网络中，或通过 Tailscale、WireGuard 之类的 VPN，这个端口可以直接使用；在隧道或代理后面时，给这个端口单独分配一个主机名，并在启动应用时把 `PREVIEW_ORIGIN` 设为它。
- “预览已关闭”表示应用是用 `PREVIEW_PORT=0` 启动的。
- 预览只适用于你打开应用的那台机器，不适用于你切换到的其他机器。

## 在系统页面查看这台电脑

点击侧边栏中的**系统**，或前往[系统](/system)。标题下面是：电脑的名称、处理器、它有多少个线程、已经运行了多久，然后是操作系统。

顶部的小方块显示以下内容，并附有最近两分钟的小图表：

- **CPU**：处理器有多忙，以及平均负载。
- **记忆**（即内存）：用了多少，总共多少。
- **GPU × n**（有 NVIDIA GPU 时）：平均使用率，以及已用的显存。
- **网络**：每秒接收和发送的数据量。
- **磁盘 I/O**：每秒读取和写入的数据量。

下面是更详细的内容：

- **CPU**：一张图表、每个核心的负载，以及温度（如果能读到的话）。
- **记忆**（即内存）：一张图表、已用的 RAM（包括缓存和缓冲区）、交换空间，以及还有多少可用。
- 每个 **GPU** 一张卡片：使用率、显存、功耗与其上限、温度、风扇、性能状态和时钟频率。
- **网络**：下载和上传，以及每个网络连接。
- **存储**：读取和写入，以及每块磁盘的可用空间、文件系统和已用比例。
- **传感器**：各项温度，从 85 °C 起显示为红色。
- **笔记本内核**（有内核在运行时）：每个都显示它的环境、状态、内存和**关闭**。
- **进程**：最忙的 12 个程序，可以按 **CPU** 或**记忆**排序（使用 GPU 的程序还可以按 **GPU** 排序），显示进程 ID、用户、CPU 和内存。把鼠标指向一行可以看到它的完整命令。

页面打开期间，它每 2 秒读取一次数据，并保留最近 10 分钟的记录。

- “这台电脑上现在运行着哪些开发服务器？”
- “这台电脑上什么最占内存？”
