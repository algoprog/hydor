# 已连接的应用、密钥和工具

在应用页面的**已连接的应用**中，把你使用的服务（Notion、Gmail、GitHub、Stripe、这台电脑上的某个文件夹……）连接一次，每个智能体和应用就都能使用它们。把 API 密钥和登录信息存放在加密的保险库里，智能体可以使用它们，却永远看不到；为 Claude Code 和 Codex 添加工具服务器，为 Claude Code 添加插件。当你希望智能体在你自己的账户里操作、用你的密钥调用某个服务，或者使用它们本身没有的工具时，就用这些功能。

![应用 → 已连接的应用：你已连接的服务、市场和你的密钥](images/connections.webp)

## 什么是连接、密钥和工具

给智能体工具，它们就能做更多事。有三个地方可以做到这一点：

- **已连接的应用**（[应用 → 已连接的应用](/apps/connected)）：来自市场的服务，连接一次就供所有智能体使用：Claude Code、Codex、Custom 和支持 ACP 的智能体，以及它们运行的应用。每个已连接的账户都会把它的工具提供给智能体。
- **保险库**（同一页面的 **密钥** 标签页）：API 密钥、令牌和登录用的密码。API 密钥是服务给你的一种密码，让程序可以使用你的账户。智能体用它们调用服务、登录网站或运行程序，但永远看不到它们。
- **MCP 服务器和插件**（[设置 → MCP 服务器](/settings?s=mcp) 和 [设置 → 插件](/settings?s=plugins)）：你自己在 Claude Code 和 Codex 的设置中配置的工具服务器，以及为每个智能体带来技能和工具的插件（参见[插件](/guide/plugins)）。

MCP（Model Context Protocol，模型上下文协议）是服务向智能体提供工具的通用方式。一个已连接的账户就是一个 MCP 服务器，由 Hydor 为每个智能体配置好并登录。“设置 → 智能体”中的 MCP 服务器则是你用一条命令或一个地址手动配置的。

## 打开“已连接的应用”

从侧边栏打开 **应用**，选择它的 **已连接的应用** 标签页，或者前往[应用 → 已连接的应用](/apps/connected)。（它们以前在“设置”中：指向那里的旧链接现在会来到这里。）在一行说明它们用途的文字和 **连接服务** 下面，它有三个标签页：

- **已连接**：你已连接的账户，以及每个账户的状态。标签上的数字是它们的数量；**已连接的应用** 标签页上也会显示这个数量。
- **市场**：所有可以连接的服务。
- **密钥**：保险库。标签上的数字是你的密钥数量。

你已经连接过服务时，页面会打开 **已连接**；还没有连接时，会打开 **市场**；每个标签页都有自己的地址（`/apps/connected?tab=market`、`?tab=keys`）。在手机上，标签页可以横向滚动，对话框从屏幕底部升起。

## 在市场中查找服务

打开[市场标签页](/apps/connected?tab=market)。

- 搜索框（“搜索 … 个服务：邮件、Notion、发票…”）会在名称、描述、关键词和类别中查找。你输入的每个词都必须匹配。
- 各个类别一次显示一个，每个都带有它的服务数量：**全部服务**（标签上是**全部**）、**笔记与文档**、**任务与项目**、**邮件、聊天与会议**、**日历与日程安排**、**文件与存储**、**设计与媒体**、**开发者工具**、**云与托管**、**数据库与数据**、**分析与监控**、**销售、营销与客服**、**支付与财务**、**网站与商店**、**搜索与网络**、**AI 与自动化**、**旅行与日常** 和 **在这台电脑上**。在电脑上，它们是服务旁边的一个列表；在较窄的屏幕上，它们是搜索框下方可以横向滚动的标签。
- **精选**：一排较大的卡片，展示知名服务（Notion、Linear、GitHub、Figma、Stripe、Zapier……）。在你还没有搜索或选择类别时显示；在电脑上，可以用它的箭头滚动。后面是各个服务，标题是 **全部服务**（或所选的类别，搜索时是 **搜索结果**），并显示数量。在手机上，它们是同一个列表里的一行行。

每张卡片都显示服务的名称、智能体能用它做什么，以及它的连接方式：

- **浏览器登录**：你在浏览器中登录你的账户。
- **API 密钥**：你粘贴服务给你的密钥。
- **无需登录**：没有需要填写的内容。
- **在这台电脑上运行**：一个程序，智能体需要时由 Hydor 在这里启动。
- **在本机运行，需要密钥**：同上，但需要你提供一个密钥。

名称旁边的对勾表示有人检查过，确认该服务的服务器的响应与它的条目描述一致。**未验证** 表示还没有人检查过。你已连接的服务会显示 **已连接**（或 **重新登录**），其他服务则显示 **连接**。

其中的一部分：

- **邮件、聊天和日历**：Gmail、Slack、Fireflies、Granola、Google Calendar、Calendly。
- **文件和设计**：Google Drive、Dropbox、Box、Figma、Canva、Miro、Gamma、Cloudinary。
- **开发者工具和托管**：GitHub、GitLab、Sentry、CircleCI、Postman、Cloudflare、Vercel、Netlify、Railway、Context7、DeepWiki。
- **数据和分析**：Airtable、Supabase、Neon、PostgreSQL、MongoDB、SQLite、PostHog、Mixpanel、Amplitude、Datadog。
- **商业**：Stripe、PayPal、Plaid、Square、HubSpot、Intercom、Attio、Klaviyo、Webflow、Wix、WordPress.com。
- **搜索和网络**：Exa、Perplexity、Tavily、Brave Search、Firecrawl、Wolfram，以及一个 Playwright 浏览器。
- **AI 和日常生活**：Hugging Face、Zapier、AllTrails、Kiwi.com、trivago、Strava。
- **在这台电脑上**：这台电脑上的文件（Files on this computer，只限你选择的文件夹）、Git、时间（Time）和记忆图谱（Memory graph）。

没有服务匹配时，页面会显示 **没有匹配的服务**。你可以自己添加这个服务：见[向市场添加服务](/guide/connections#add-a-service-to-the-marketplace)。新的服务会随本应用的更新一起到来。

## 连接服务

1. 点击服务的卡片。对话框会显示它能做什么、它的类别、连接方式，以及带日期的 **已核验**（或 **地址尚未检查**）。**网站** 和 **文档** 链接到该服务。一个方框显示它在哪里运行：服务器的地址，或者它在这里运行的命令。对话框还会说明，每个智能体都会以服务的简称获得它的工具（Notion 的工具在“notion”下），并且你可以按会话关闭它。
2. 如果有黄色方框里的提示，请先阅读。它会说明需要先了解的事，比如“这台电脑上需要 uv（uvx）。”，或者某个服务需要你自己的登录客户端。
3. 填写对话框要求的内容，然后点击 **连接**，或者点击 **登录** 加服务名称的按钮（如“登录 Notion”）。

连接成功后，服务会移到 **已连接** 标签页，并在后台进行测试。对话框要求填写什么，取决于服务。

### 无需填写任何内容的服务

点击 **连接**。有些服务会先要求一项设置。GitLab 会要求填写它的地址（gitlab.com，除非你自己架设了 GitLab）。“这台电脑上的文件”（Files on this computer）会要求填写它可以使用的文件夹，用完整路径，每行一个；它只能读取和修改这些文件夹里的文件。SQLite 会要求填写数据库文件。标有 **可选** 的字段可以留空。字段旁边的 **获取** 链接到获取该值的地方。

### 需要密钥的服务

互联网上的服务有一个 **密钥** 字段，旁边的 **获取密钥** 链接到该服务生成密钥的页面。在这里运行的服务会在它自己的一个或多个字段中要求填写密钥（令牌、连接字符串）。粘贴密钥，然后点击 **连接**。

密钥会加密存入保险库。从那以后，你只能看到它的最后几个字符。比如 GitHub 使用细粒度个人访问令牌：一种你可以限定到你希望智能体拥有的仓库和权限范围的密钥。

### 在浏览器中登录的服务

1. 点击 **登录** 加服务名称的按钮。
2. 在电脑上，会打开一个小窗口。在手机上，则会在同一个标签页中打开该服务的登录页面。
3. 登录并允许访问。在此期间，对话框会显示“等你完成登录…”。
4. 完成后，会有通知说账户已连接。在手机上，你会回到“应用 → 已连接的应用”。

令牌加密保存在这台电脑上，会自动续期；智能体永远看不到它们。登录必须在 15 分钟内完成；超时后请重新开始。如果你拒绝访问，会提示“你没有允许访问”。

有些服务只允许通过你自己的登录客户端（OAuth 应用）登录：例如 Asana、Box、HubSpot、Slack 和 Google 的应用。它们的对话框会展开 **你自己的客户端 ID（此服务需要）**，并说明要做什么。其他浏览器登录则以 **使用你自己的客户端 ID（可选）** 的形式提供同样的选项；如果发现某个服务不允许应用自行注册，它也会自动展开。

1. 在该服务的开发者设置中创建客户端。
2. 把 **需要提供给它的回调地址** 下的地址填给它（旁边有复制按钮）。
3. 粘贴它的 **客户端 ID**，如果有 **客户端密钥**，也一并粘贴。
4. 点击 **登录** 加服务名称的按钮。

### 在这台电脑上运行的服务

这类服务会为每个会话的智能体在这里启动一个程序（用 npx 或 uvx）。如果程序需要先下载，第一次测试可能要花一些时间。这类服务需要的密钥会在它启动时从保险库放进它的环境变量里。密钥永远不会出现在命令行上，因为其他程序可能读取命令行。

## 检查已连接的账户是否可用

在 **已连接** 标签页上，每个账户都会显示它的状态：

- **工作中**，上次检查的时间，以及开启了多少个工具（“已开启 12 / 14 个工具”）。
- **尚未测试**。
- **需要重新登录**：它的登录已过期，并且无法续期。
- **无法使用**，并附上原因。

**测试** 会像智能体那样连接到服务，并列出它的工具。通知会告诉你账户可以使用以及它有多少个工具，或者出了什么问题：“密钥被拒绝”，或“登录被拒绝：请重新连接”（账户随后会显示 **需要重新登录**）。账户在你连接后会立即自动测试。

## 关闭账户或它的部分工具

- **所有会话**（在手机上只有开关）：开启时，每个会话的智能体都会获得这个账户，除非某个会话关闭了它。关闭时，没有会话会获得它，除非某个会话自己开启它。新连接的账户默认开启。
- **工具**：测试列出账户的工具后，这个按钮会打开工具列表，每个工具都带有开关和说明。关掉智能体不该用的工具，比如删除或发送类的工具。智能体尝试使用你关掉的工具时，会被告知它已关闭。

## 修改连接或重新登录

- **修改**（适用于需要密钥或设置的账户）会再次打开对话框，里面是你之前填写的内容。设置会保留原值。密钥和客户端密钥字段会显示“已保存：留空则保留原值”：输入新的值即可替换，然后点击 **保存**。
- **重新登录**（适用于浏览器登录）会重新登录一次。当账户显示 **需要重新登录** 时，在你重新登录之前，智能体都不会获得它。

如果你连接之后，市场更改了服务的地址或登录方式，账户会显示“目录中有它的新地址或新的登录方式。它会一直沿用旧的，直到你重新连接。”在你亲自重新连接之前，你的密钥或登录信息绝不会发送到新地址。

## 断开账户

点击 **断开连接**（在手机上是一个拔掉插头的图标）并确认。账户的登录信息或密钥会在这里被删除，智能体也不再获得它的工具。对于浏览器登录，如果服务提供了相应的方式，Hydor 还会告诉服务这些令牌不再需要。

## 选择某个会话使用的账户

每个会话都会获得 **所有会话** 开关处于开启状态的已连接账户。要为某一个会话更改：

1. 打开会话的菜单（⋯）→ **会话设置** → **已连接的账户**。
2. 为这个会话开启或关闭账户。每个账户都会显示它的状态：“开启，与所有会话相同”“关闭，与所有会话相同”“仅在此处开启”或“仅在此处关闭”。
3. 点击 **完成**。

互联网上的服务会立即生效。在这台电脑上运行的服务会在智能体下次启动时生效。如果还没有已连接的账户，对话框会提供 **打开“已连接的应用”**。

智能体也可以为以它的身份开始的会话开启账户：见[智能体](/guide/agents)。

## 智能体如何使用已连接的账户

- 每种智能体获得已连接账户的方式都一样：Claude Code、Codex、Custom 和 ACP 智能体都会以服务的简称获得它的工具。
- 会话开始时，智能体会被告知你的哪些账户已连接，并在任务涉及它们时使用。它还可以列出已连接的账户和已保存的密钥，但只能看到名称。
- 智能体只会获得在它的会话中开启并且已登录的账户。登录会在后台续期，即使是没有会话在用的账户也一样，所以长时间运行的会话能一直正常工作。
- 密钥和令牌永远不会进入智能体的设置或命令行。在服务的工具返回的任何内容中，已知的密钥值都会被遮盖。
- 搜索框（Ctrl+K，Mac 上为 ⌘K）也能找到你已连接的账户。

## 向市场添加服务

任何人都可以向 GitHub 上 Hydor 的仓库提交拉取请求（pull request），为市场添加服务，或修正已有的服务。市场标签页底部的 **如何添加** 会打开相应的指南。

1. 按照那里的指南，在仓库的 `catalog/` 文件夹中为服务写一个小 JSON 文件。它包含服务的名称、一句通俗地说明智能体能用它做什么的话、类别、图标和颜色、主页和文档、它的服务器（一个地址，或一条在这里运行的命令）、登录方式（无需登录、浏览器登录或密钥），以及用户需要填写的字段。
2. 如果服务有自己的 MCP 服务器，就使用它文档中给出的地址。在没有这种服务器时，或者对于只有本地程序才能做到的事（比如这台电脑上的文件），也欢迎使用在这里运行的程序。
3. 文件里不要放任何密钥或令牌。用户会把自己的密钥填进保险库。
4. 运行指南中描述的检查。它会按规则检查文件，还可以询问服务器，看它如何响应。
5. 发送拉取请求。合并之后，服务会随下一次更新出现在所有人的市场中。

## 把密钥存放在保险库中

打开[密钥标签页](/apps/connected?tab=keys)。保险库存放智能体使用但看不到的 API 密钥、令牌和登录用的密码。它们在这台电脑上加密保存，之后再也不会显示出来，无论是在这里还是给智能体：只显示最后几个字符。

智能体通过 Hydor 自带的工具使用它们：它的网络请求工具、它的浏览器，以及在你允许时这台电脑上的命令。应用会自己把密钥放进去，并且只在你允许的地方这样做。

列表中的每个密钥都显示：

- 它的名称和值的遮盖提示（例如“…f3a9”）；
- 它的备注；
- 它可以发送到的主机，以及当这台电脑上的命令可以使用它时显示的 **可用于命令**（两者都没有时显示 **尚未允许任何主机**）；
- 上次使用的时间（在此之前显示“尚未使用”），以及添加的时间或值最后一次更改的时间。

还没有密钥时，标签页会说明你可以在这里添加，或者让智能体来请求。

应用也可能需要密钥（天气服务的、地图服务商的）：应用会写明它需要哪些密钥，你可以在它的页面上、在安装它的卡片上，或在会话中它的卡片上逐一提供（[提供它需要的密钥](/guide/apps#give-it-the-keys-it-needs)）。它们会保存在这里，使用应用给它们起的名称和应用指定的主机，备注里会写明是哪个应用。

### 添加密钥

1. 点击 **添加密钥**。
2. **名称**：智能体称呼它的名字，比如 WEATHER_API_KEY：由大写字母、数字和下划线组成，2 到 64 个字符，以字母开头。你输入的内容会被转换成这样的名称（“github token”会变成 GITHUB_TOKEN），字段中会有提示。
3. **值**：粘贴密钥。它必须是一行，除非是以 -----BEGIN 开头的一段内容（证书或私钥）。
4. **允许发送到的主机**：服务的地址，用逗号分隔，比如 api.example.com（最多 20 个）。密钥只会通过 https 发送到这些主机及其子域名。在你添加主机之前，智能体无法使用这个密钥。
5. **允许这台电脑上的命令使用它**（一开始是关闭的）：为这里的某个程序需要的密钥开启它，比如数据库的密码或 git 用的令牌。见[使用密钥的命令](/guide/connections#commands-that-use-a-key)。
6. **备注**：这个密钥的用途。智能体能看到这条备注。
7. **发送方式**（可选）：默认情况下，密钥放在 Authorization 请求头中，前面加上“Bearer ”。你可以更改 **请求头**（比如 X-Api-Key）和 **密钥前缀**（用于其他请求头时留空），或者用 **或作为查询参数** 改成以查询参数发送（比如 api_key）。
8. 点击 **保存**。

保险库中已有的名称会被拒绝：请改为给那个密钥设置新值。

### 为密钥设置新值

点击密钥旁边的圆形箭头（**新值**），把新值粘贴到 **新值** 中，然后点击 **替换**。主机、备注和发送方式保持不变。

### 修改密钥可以发送到的地方

点击铅笔图标（**主机、备注和发送方式**），修改主机、命令是否可以使用它、备注或发送方式，然后点击 **保存**。值保持不变。

### 删除密钥

点击垃圾桶图标（**删除**）并确认。智能体将无法再使用这个密钥，它的值也会被永久删除。

### 智能体能用密钥做什么、不能做什么

- 按名称用它调用服务。应用会把密钥放进请求中：放在为它设置好的位置；或者放在智能体在地址、请求头或请求体中用双花括号写下它名称的地方（比如 {{GITHUB_TOKEN}}）；或者作为基本认证（Basic）登录的用户名和密码。
- 在它的浏览器中，按名称把它输入到网站的登录页面：只能输入到单行输入框中，只能在这个密钥的某个主机的网页上，并且要通过 https（或者在这台电脑上）。输入框随后会显示圆点，智能体只能看到它已从保险库中填好。
- 在你开启了 **允许这台电脑上的命令使用它** 时，把它交给这台电脑上的命令，并且只在你允许这条命令之后（见[使用密钥的命令](/guide/connections#commands-that-use-a-key)）。
- 在网上，只能发送到你允许的主机及其子域名，只能通过 https，并且绝不会发送到这台电脑或它所在的本地网络。重定向到不允许发送该密钥的主机时，不会跟随。
- 在单次调用中更改密钥放在哪个请求头或查询参数中。
- 查看密钥的名称、主机和备注。永远看不到它们的值：返回的结果、网页和命令输出的内容中，密钥都会被遮盖。

## 当智能体请求密钥时

智能体被告知永远不要让你在聊天中输入密码、令牌或密钥。当任务需要一个还没保存的密钥时，智能体会改为在对话中显示一张卡片：**智能体请求一个密钥**，附上密钥的名称和它为什么需要（通常还有在哪里获取）。

1. 把密钥粘贴到字段中。
2. 检查 **仅发送到**：智能体建议的主机。需要的话可以修改。没有主机时，智能体无法使用这个密钥。
3. 点击 **保存到保险库**。

密钥会直接进入加密的保险库，绝不会进入对话。卡片会变成一条说明密钥已保存的提示，智能体会收到一条消息，告诉它密钥已经在那里（但绝不会告诉它密钥是什么），这样它就可以继续工作。

- **暂不** 表示拒绝。智能体会被告知你现在不想提供，让它不用密钥继续，或者说明还有什么别的办法。卡片随后会显示你没有提供，并带有 **仍要输入**，以防你改变主意。
- 卡片等待期间，它也会以“请求密钥”出现在[收件箱](/guide/inbox)中，并附上密钥的名称。**打开** 会带你进入该会话。
- 如果保险库里已经有同名的密钥，智能体会被告知使用它，卡片只会说明它已在保险库中。如果已保存的密钥失效了，智能体可以再次请求：这时字段会说明它将替换已保存的那个。
- 当智能体需要在这台电脑上的命令中使用这个密钥时，卡片上还会有 **允许这台电脑上的命令使用它**，一开始是开启的。如果你不想这样，就把它关掉；智能体仍然可以在它的主机上使用这个密钥。对于已经保存的密钥，卡片上写的是 **智能体请求在命令中使用一个密钥**：字段留空即可保留原值，然后点击 **保存到保险库**。

### 由多个字段组成的登录信息

要登录某个网站或服务时，智能体会一次把所需的内容都要齐：**智能体请求一组登录信息**，每一部分各有一个字段，比如电子邮件和密码，或者数据库的地址、用户名和密码。密码和其他机密内容在你输入时会隐藏；点击眼睛图标可以显示它们。

1. 填写这些字段。标有 **可选** 的字段可以留空。
2. 检查 **仅发送到**：这组登录信息适用的主机。
3. 点击 **保存到保险库**。

每一项机密内容都会作为一个单独的密钥存入保险库，以这组登录信息命名（Voltaro 的密码会变成 VOLTARO_PASSWORD）。标有 **智能体能看到这一项** 的字段是不需要保密的细节，比如服务器的地址：智能体会得到你在那里输入的内容，它也不会存入保险库。保险库中已有的字段会注明这一点：留空即可保留已保存的内容。保存之后，卡片会列出这些密钥，智能体就可以在它的浏览器中用它们登录，只限那些主机，而且看不到它们。

## 使用密钥的命令

有些工作需要在这台电脑上的某个程序中用到密码或令牌：用令牌推送到 GitHub，用密码读取数据库，或者运行一个调用某个服务的脚本。为此，智能体有一个工具，它运行一条命令，并把保险库中的密钥放进这条命令的环境变量里，每个密钥用它自己的名称。命令输出的内容会返回给智能体，其中的密钥都会被遮盖。

- 只有开启了 **允许这台电脑上的命令使用它** 的密钥才能交给命令。你可以在密钥的铅笔图标对话框中开启它，或者在智能体请求时在卡片上开启。
- 这样的命令运行之前，会有一张卡片显示它：**Run a command with** 加上密钥的名称，然后是这条命令，以及它的用途。**允许** 会运行它一次。**在此会话中允许** 还会让这个会话之后使用同样密钥的命令无需询问就能运行，直到应用重启。**不要** 会阻止它，你也可以告诉智能体改做什么。
- 拥有完全访问权限的会话会直接运行这些命令，不会询问，和它运行其他命令时一样。在计划模式下，这些命令都不会运行。
- 命令能做程序能做的任何事，包括把密钥发送到别处：只允许你看得懂的命令，并且只为这里的程序确实需要的密钥开启此项。
- 命令在两分钟后停止，除非智能体给它更长的时间（最多十分钟）。

## 填写服务要求的表单

有些服务会在任务进行到一半时需要你提供一些东西：一个日期、一个选择、一个是或否，或者打开一个页面。无论是哪个智能体在工作，这个请求都会以卡片形式显示在会话中（和智能体自己的批准请求在一起），也会显示在[收件箱](/guide/inbox)中。卡片的标题说明服务想要什么：

- **……请你填写表单**：服务的消息，然后是它的字段，以表单形式显示。有文本框、长文本、数字、日期、表示是或否的开关，以及可供选择的标签或列表（服务允许多选时，标签可以选多个）。点击 **发送**。在发送任何内容之前，为空的必填字段（“必填”）和不是数字的数字会被标出。服务无法接受的回答（太长、不是电子邮件地址、选得太少）会被拒绝，并说明需要修正什么，卡片会保留。
- **……请你打开一个页面**：一个链接。**打开** 会在新标签页中打开该页面（以便在那里批准某件事或登录），并告诉服务你已经打开了。
- **……请求继续**：一个简单的是或否。**允许** 表示同意。

**拒绝** 表示不同意。**暂不** 会取消这一次。服务的卡片最多等待一小时；如果智能体的这一轮先结束了，请求就会被取消。你为 Codex 配置的 MCP 服务器也会用同样的卡片来询问。

## 为 Claude Code 和 Codex 设置 MCP 服务器

打开 [设置 → 智能体 → MCP 服务器](/settings?s=mcp)。这些是 Claude Code 和 Codex 自己设置中的工具服务器，用于市场里没有的工具，或者你自己运行的服务器。新会话会加载它们；已经在运行的会话会在重启时应用更改。Custom（本应用自带的智能体）也会使用它们，SSE 类型的除外（见 [Custom](/guide/custom)）。

页面分两部分列出 Claude Code 和 Codex 的服务器。顶部的 **文件夹** 标签用来选择要查看哪个文件夹的服务器，因为 Claude Code 既可以为所有文件夹保存服务器，也可以只为某一个文件夹保存。

每个服务器显示：

- 它的名称和类型：**命令**（这台机器运行的程序），或者 **HTTP** 或 **SSE**（某个地址上的服务器；SSE 是较旧的一种）；
- 对 Claude Code 来说，它的适用范围：**所有文件夹**、**此文件夹，仅限你自己** 或 **此文件夹，共享**；
- **关闭**，表示这个 Codex 服务器在 Codex 自己的设置中被关闭了；
- 它的命令或地址，以及它的环境变量、请求头或 bearer 令牌变量的名称。它们的值保留在服务器上，永远不会显示；
- 检查之后，服务器的状态。

### 添加服务器

点击[添加服务器](/settings?s=mcp&find=Add%20server)。**添加 MCP 服务器** 对话框会询问：

- **添加到**：Claude Code、Codex，或者两者（默认两者都选）。
- **名称**：字母、数字、点、短横线或下划线，最多 64 个字符，以字母或数字开头。智能体会把它的工具显示为名称、斜杠和工具名。
- **输入**（服务器类型）：**命令**、**HTTP** 或 **SSE**。Codex 不支持 SSE，所以选择 SSE 会把 Codex 排除在外。
- 对于命令：
  - **命令**：完整的命令行，比如 `npx -y @modelcontextprotocol/server-github`。会话启动时它在这台机器上运行。包含空格的参数要加引号。参数开头的 ~ 表示你的主文件夹。
  - **环境**：每行一个 KEY=value（以 # 开头的行会被跳过）。这些值会写入智能体的配置文件，之后在这里不会再显示。
- 对于 HTTP 或 SSE：
  - **URL**：服务器的地址，以 http:// 或 https:// 开头。
  - **请求头**（用于 Claude Code）：每行一个“Name: value”，用于需要 API 密钥的服务器。使用浏览器登录（OAuth）的服务器不需要：添加后从列表中登录即可。
  - **Bearer 令牌变量**（用于 Codex，可选）：一个环境变量的名称，Codex 会把它的值作为 bearer 令牌发送。
- **Claude Code 在哪里使用它**（只选了 Claude Code 时显示为 **使用位置**）：
  - **所有文件夹**：这台机器上的每个 Claude Code 会话。这是默认选项。
  - **此文件夹**：只用于顶部所选文件夹中的会话，保存在你自己的 Claude Code 设置中。
  - **共享的 .mcp.json**：保存到该文件夹中的 .mcp.json 文件，这样在这个仓库里工作的每个人都能用上。

  Codex 服务器总是适用于所有文件夹。

点击 **添加服务器**。Hydor 会通过每个智能体自己的命令来添加它，这样它们的设置会保持它们期望的样子。如果某个智能体拒绝了，对话框会显示它没有添加该服务器，并附上智能体给出的信息。修正问题后再次点击 **添加服务器**：只会重试失败的那些智能体。

### 检查哪些服务器能连上

Claude Code 或 Codex 旁边的[检查连接](/settings?s=mcp&find=Check%20connections)会像新会话那样启动每个服务器，并显示每个服务器的结果：

- **已连接**，以及它的工具数量；
- **需要登录**；
- **仍在连接**；
- **失败**，并附上原因（没有原因时显示“服务器没有启动，或没有响应。”）；
- **关闭**。

不会用到任何模型。可能需要一两分钟。对 Claude Code 来说，检查会在顶部所选的文件夹中运行，所以该文件夹自己的服务器也会算进去。

### 登录服务器

位于某个地址、使用 OAuth 登录的服务器需要登录一次。点击 **登录**（检查结果显示需要登录时会出现），或者点击它所在行的登录图标。应用中会打开一个终端，运行该智能体为这个服务器提供的登录流程：按照那里的步骤操作。

### 移除服务器

点击服务器旁边的垃圾桶图标，并用 **移除** 确认。智能体将不再加载它。已经在运行的会话会一直保留它，直到重启。

## 为 Claude Code 添加插件

Claude Code 有它自己的插件：打包了技能、命令、智能体、钩子和 MCP 服务器的扩展组件，来自市场（也就是插件目录，保存在 GitHub 仓库、其他 git 仓库或某个文件夹中）。它们只适用于 Claude Code。它们在[设置 → 智能体 → 插件](/settings?s=plugins&find=Claude%20Code)的 **Claude Code** 标签页上；Codex 自己的插件在它的 **Codex** 标签页上。适用于所有智能体的插件在**所有智能体**标签页上：参见[插件](/guide/plugins)。

### 已安装的插件

**已安装** 列出这台机器上 Claude Code 的插件。新的 Claude Code 会话会加载它们。每个插件显示它的名称、所属市场、版本和用途。

- 开关可以关闭或开启插件，而不移除它。
- 垃圾桶图标会在你确认后卸载它。新的 Claude Code 会话将不再加载它的技能、命令和服务器。

### 查找并安装插件

**浏览** 列出你可以从你的市场中安装的所有插件，安装最多的排在前面，并显示每个插件的安装次数。**搜索插件** 可以缩小列表范围。它一次显示 40 个：**显示更多** 会再多显示 40 个。

点击 **安装** 并确认。插件会为每个 Claude Code 会话安装。插件可以添加在这台机器上运行命令的钩子和服务器，所以只安装你信任的插件。

Hydor 最多每 10 分钟向 Claude Code 获取一次插件列表，每次更改后也会重新获取。第一次可能需要一些时间。

### 插件市场

**市场** 列出 Claude Code 安装插件所用的目录。

- 要添加一个，在列表下方的输入框中输入 GitHub 的 owner/repo、git URL 或文件夹，然后点击 **添加**。
- 要移除一个，点击它的垃圾桶图标并确认。从它安装的插件也会被卸载。

## 问问智能体

智能体可以为你做这些事，你在卡片上同意即可。它们从不在应用中输入密钥的值：需要密钥或登录信息时，它们会显示卡片，让你在那里输入。

- “哪些账户已经连接了？测试一下 Notion，告诉我它能不能用。”
- “连接 Context7，让智能体可以查阅库的文档。”
- “在所有会话中关闭 Gmail，但在这个会话里保留它。”
- “给我看看 Notion 的工具，把会删除页面的那些关掉。”
- “为 Claude Code 和 Codex 添加一个运行 npx -y @modelcontextprotocol/server-memory 的 MCP 服务器，然后检查它能不能连上。”
- “给我看看安装最多的 Claude Code 插件，然后安装我选的那个。”
- “登录我的 Voltaro 账户，把今年的账单下载到这个文件夹里。”（第一次时，它会用卡片向你要登录信息。）
- “用保险库里的令牌把这个分支推送到 GitHub。”
