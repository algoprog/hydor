# 搜索和浏览器

无论用的是什么模型，应用中的智能体都能搜索网络、阅读网页，并使用真正的浏览器。本主题介绍它们使用的搜索提供方以及怎样设置这些提供方、搜索显示什么及其来源，还有浏览器：实时观看它，接管它来登录、完成验证或付款，以及它的设置。它还介绍“浏览器”页面（桌面应用里属于你自己的浏览器，有标签页、无痕标签页、智能地址栏、书签、历史记录、广告拦截器、翻译、阅读视图和扩展程序），以及怎样把其中的一个页面交给智能体。在桌面应用中（Mac、Windows、Linux），浏览器就运行在应用里面，智能体还能使用电脑本身：它的屏幕、鼠标和键盘。

## 智能体怎样搜索网络

你在这里运行的每个智能体（Claude Code、Codex、Custom，以及支持 ACP 的智能体）都会从应用获得三个工具：网络搜索、阅读网页的方法，以及为事物找图片和视频的方法。无论用什么模型，它们的效果都一样，所以在你自己电脑上运行的小模型，搜索起来也和大模型一样好。

- 搜索会按顺序交给**设置 → 功能 → 搜索**中的提供方。第一个已开启的提供方来回答。它回答不了时（需要密钥、额度用完了、无法连接，或者要求证明搜索不是机器人发起的），就由下一个来回答。回答会告诉智能体是哪个提供方回答的。
- 智能体最多可以要求 100 条结果，还可以把搜索限定在某些网站（或排除某些网站）、某些日期、某些语言、PDF，或网站自己的主页（个人主页、官方网站）。Naget Search 还可以只搜某些类型的网页，比如学术论文、预印本、生物医学论文、美国专利、公司申报文件、新闻、文档或讨论。如果提供方无法遵守某个筛选条件，智能体会得到通知。当智能体自己没有设置任何筛选条件，但搜索的文字里已经说明了一些（比如“nasa.gov 上个月的气候报告”“2024 年以来关于检索增强生成的论文”）时，辅助模型会先把它们读出来（见[选择辅助模型](/guide/agents-models#choose-the-helper-model)），Naget Search 再带着这些筛选条件去搜剩下的文字。这只发生在文字看起来说明了筛选条件的搜索上，一次只处理少数几个，并且大约在 8 秒内完成。当辅助模型来不及回答，或连续两次读取失败（之后读取会暂停 10 分钟）时，搜索就按智能体写的原样进行；SearXNG、Brave Search 和 DuckDuckGo，以及智能体自己设置了任何筛选条件时，也是如此。如果读出的筛选条件什么都没搜到，Naget Search 会改为按原样搜索这些文字。
- Naget Search 还能为每条结果带回其网页中回答这次搜索的句子，而不是普通的摘要。这样会慢一些，所以智能体只在需要从网页中获取事实时才会这样要求。没有密钥也可以这样做。
- 对于要展示的一组事物（游戏、电影、地点、菜肴、产品、球队），智能体可以为每一个找一张图片：它自己的维基百科条目里的图片（游戏的封面、地点的照片、球队的队徽），没有的话就用介绍它的网页在分享时显示的图片；需要时还可以找一段标题写着它名字的 YouTube 视频（预告片、菜谱、精彩片段）。只有明确是这个事物的才算数，所以有些可能找不到。应用用它在答案里显示图片和视频（见[应用](/guide/apps)）。
- 智能体被要求这样引用它们用到的网页：在每个网页所支持的内容后面加上方括号里的编号，并在回复末尾列出这些网页，且只列这些。应用会把它们显示为链接和卡片（见[查看回复下方的来源](/guide/web#see-the-sources-under-a-reply)）。智能体把结果和网页里的内容当作信息，绝不当作指令。

失败的提供方会休息一段时间（比如直到它的额度恢复），这样后面的搜索就不必等它。10 分钟内再次提出同样的搜索，会直接得到之前的结果，不会重新搜索。

Claude Code 和 Codex 也有自己的网络工具。回复引用它们找到的网页时，也会这样显示。

## 选择你的搜索提供方

打开[设置 → 功能 → 搜索](/settings?s=search)。在手机上，设置是一个列表：轻点“功能”下的**搜索**。

在[提供方](/settings?s=search&find=Providers)（“从上往下依次尝试：第一个开启的会作答”）下面，每个提供方各占一行：

- 它的名称，第一个已开启的提供方会带有**默认**；当它按目前的设置无法回答时，会显示**需要密钥**或**需要你的实例地址**之类的警告；
- 一行说明它是什么；名称旁的 (i) 还会补充它能把搜索限定在什么范围，比如“最多 100 条结果 · 分类 · 日期 · 主页 · 页面中给出回答的部分”；
- 如果保存过密钥，会显示密钥的提示（比如“sk-ab…12cd”：绝不会显示密钥本身）；
- 它最近一次的错误，用红色显示，并注明是多久以前；
- 右边的开关，用来开启或关闭它，以及一个 **⋯** 菜单，里面有**添加密钥**（或**更换密钥**）、**设置地址**（或**更改地址**）、**测试**、**设为默认**（在已开启但不在第一位的提供方上出现），以及用来改变它在顺序中位置的**上移**和**下移**。

**提供方**旁的 (i) 说明：无论用的是什么模型，智能体都能搜索网络、阅读网页；搜索结果和网页是外部数据，智能体只把它们当作信息使用，绝不当作指令。

**设为默认**会把这个提供方移到列表顶部。默认的顺序是 Naget Search、SearXNG、Brave Search、DuckDuckGo。Naget Search 和 DuckDuckGo 一开始就是开启的；SearXNG 和 Brave Search 一开始是关闭的，直到你提供它们所需的东西。

### Naget Search

[Naget Search](/settings?s=search&find=Naget%20Search) 是默认的提供方：Naget 自己的网络、论文、专利和申报文件索引。它不需要密钥：没有密钥的搜索会使用每日免费额度。它回答过之后，这一行会显示**今日剩余免费额度**（当天的额度还剩多少）、一个进度条，以及额度何时恢复。额度用完时，这一行会说明这一点，并由下一个提供方回答，直到额度恢复。

来自 naget.com 的密钥能提供更多的搜索次数；有了密钥，这一行会改为显示**剩余额度**。有了密钥，Naget Search 还能在智能体阅读网页时挑出网页中回答问题的部分（见[阅读整个网页，或只读回答问题的部分](/guide/web#read-whole-pages-or-only-the-parts-that-answer-a-question)）；没有密钥时，由应用按词语挑选。搜索结果中回答搜索的句子，没有密钥也能得到。如果这一行显示“Naget Search 目前需要密钥”，说明没有密钥的搜索正被拒绝；在你添加密钥之前，由下一个提供方回答。

它的表单里还有一个**地址**：除非你另行设置，否则是 <https://naget.com>。除非有人给了你另一个地址，否则保持原样即可。

### SearXNG

[SearXNG](/settings?s=search&find=SearXNG) 是一个你自己运行的搜索引擎，它会同时询问许多搜索引擎，并且不保留任何关于你的记录。它不需要密钥，只需要你的实例地址：打开它的 **⋯** 菜单，选**设置地址**，输入地址（比如 <https://searx.example.org>），然后按**保存**。给它设置地址就会开启它。它最多返回 100 条结果。

### Brave Search

[Brave Search](/settings?s=search&find=Brave%20Search) 通过 Brave 的 Search API 搜索 Brave 自己的独立索引。它需要密钥；Brave 有免费套餐。**⋯ → 添加密钥**会打开一个带链接的表单：**在 api-dashboard.search.brave.com 获取**。添加密钥就会开启它。它最多返回 100 条结果。

### DuckDuckGo

[DuckDuckGo](/settings?s=search&find=DuckDuckGo) 不需要密钥，一开始就是开启的，排在列表最后，作为最后的备选。它每页大约返回 10 条结果（最多 30 条），而且可能会要求证明搜索不是机器人发起的；这时如果还有下一个提供方，就由它来回答。

### 添加或更改密钥或地址

1. 在提供方那一行，打开 **⋯** 菜单，选**添加密钥**（或**更换密钥**、**设置地址**、**更改地址**）。
2. 把密钥粘贴到**密钥**下面（它会显示为圆点），或者输入**地址**。对于 Naget Search，密钥会标注“可选，用于更多搜索”。
3. 按**保存**。**取消**会关闭表单，一切保持原样。

给提供方提供它所需的密钥或地址，就会开启它。密钥保存在服务器上：页面上只会显示密钥的提示。要删除已保存的密钥，打开表单并按**移除已保存的密钥**。

### 测试提供方

打开某一行的 **⋯** 菜单，选**测试**。应用会只用这个提供方做一次小搜索，不会退回到下一个提供方，而且即使你还没保存，也会用你在它表单里输入的内容。你会看到“可用：”、结果数量和用时，以及前三条结果的链接，或者失败的原因。测试已保存的提供方时，一旦它恢复正常，也会清除它之前的错误。

### 每次搜索的结果数

[每次搜索的结果数](/settings?s=search&find=Results%20per%20search)设置智能体没有指定数量时一次搜索返回多少条结果：**10**、**20**（默认）、**50** 或 **100**。智能体仍然可以要求更多，最多 100 条，用于更深入的搜索，比如查找论文。结果越多，智能体要读的内容就越多。

页面底部有一条说明，附有链接，介绍开发者如何添加其他提供方。

### 没有提供方能回答时

如果每个已开启的提供方都失败了，或者你把它们全都关闭了，智能体会得知每个提供方失败的原因。这时 Claude Code 和 Codex 会改用它们自己内置的网络搜索（Claude Code 的 WebSearch、Codex 的网络搜索）来完成这次搜索以及这项任务剩下的搜索，并照常引用网页：只有当它们自己的搜索也失败时，才会告诉你去设置 → 搜索。其他智能体，比如 Custom，没有自己的网络搜索：它们会被要求告诉你，可以在设置 → 搜索中添加密钥，或开启另一个提供方。在[深度研究](/guide/research)中，智能体自己的网络搜索是关闭的，这样每次搜索都计入预算：在那里同样会告诉你需要修正什么。

## 查看搜索找到了什么

智能体的步骤会折叠成它消息之间的一行，比如“已搜索 4 次”（在这里，网络搜索和读过的网页都算作搜索）。展开它就能看到每一步。一次搜索显示为“已搜索网络‘2000 欧元以下的电动自行车’”，右边是回答它的提供方和结果数量（在手机上只显示数量）。搜索进行时显示“正在搜索网络”，并带有计时器；失败的搜索显示“网络搜索失败”。

点击一次搜索即可展开：

- 它用到的筛选条件（某个网站、日期、某个类别……），以小标签显示，从搜索文字中读出的也在其中，并附一条说明，写明搜索了哪些文字；当智能体要求获取回答问题的句子时，会显示“能回答它的部分”；
- 说明，比如某个提供方无法回答、改由哪个提供方回答了，或者提供方无法遵守的某个筛选条件；
- 结果，按智能体看到的顺序编号：标题（一个链接）、网站、日期、表示网页类型的标签（论文、arXiv、PubMed、专利、SEC 申报文件、文档……）、PDF 标签，以及摘要或回答这次搜索的句子。每条都有一个打开按钮（↗）。

前 8 条结果会显示出来；**显示全部 N 个结果**会显示其余的。

## 查看回复下方的来源

智能体引用它用到的网页时，回复会在两个地方显示它们，而不是在末尾放一个编号列表：

- **正文中**：在引用网页的地方，有一个带网站图标和名称的小标签，比如 **ign**。代表多个网页的标签会写出还有几个（**ign +1**）。在电脑上，把指针放在标签上就能看到它的网页，以及它们的标题和网站；点击标签会打开它的网页（有多个网页时从卡片中打开）。在手机上，轻点标签查看它们，再轻点其中一个打开。
- **回复下方**：一行**来源**，显示前几个网站的图标，以及这条回复引用了多少个网页。点击它会为每个网页打开一张卡片：标题、网站和链接。

只显示回复引用的网页，按智能体给它们的编号，而不是它做过的每一次搜索：它搜索和阅读了什么，都在它的步骤里（打开回复上方的**工作了…**）。**复制消息**（在回复下面）会按智能体写的样子复制回复，包括它的来源列表；朗读时会略去编号和列表。网站图标在第一次显示时从网站本身获取并保存下来；没有图标的网站显示它的首字母。

## 阅读整个网页，或只读回答问题的部分

摘要不够用时，智能体会阅读网页。它可以读整个网页：长网页会分成每部分大约 3,000 词，智能体需要时再要下一部分。它也可以向网页提一个问题，只取回能回答这个问题的部分，这样要短得多。

- 开启 Naget Search 并添加了它的密钥后，由 Naget Search 挑出网页中回答问题的句子。这一步会说明保留了网页中的多少词。与回答搜索的句子不同，这需要密钥。
- 否则，由应用挑出与问题共有词语最多的段落，并告诉智能体：如果这些段落没有包含答案，就阅读整个网页。

PDF 也会当作文字来读。只有公开的网页能这样读：这台电脑或其所在网络上的地址不行（经你允许后，[浏览器](/guide/web#the-browser-agents-use)可以打开它们）。网页只获取一次，并保留 10 分钟，所以它的下一部分会立即送到。

在对话中，一次阅读显示为“已读取”加上网页标题，在较宽的屏幕上还会显示对它提出的问题。点击它可以看到地址、读的是哪一部分（“第 1 部分，共 3 部分”）或是“能回答问题的部分”，以及智能体得到的文字。

## 智能体使用的浏览器

有些网站需要点击、填表、登录或运行脚本，普通的读取无法通过。对于这些网站，智能体有一个浏览器，与你自己的浏览器分开：你日常使用的 Chrome、Edge、Firefox 或 Safari 里的登录状态，它一概没有。你可以实时观看它，并随时接管。它是哪个浏览器，取决于应用运行在哪里：

- **在桌面应用中**（Mac、Windows、Linux），它是应用自己的浏览器，基于 Chromium（Chrome 所基于的开源浏览器），运行在应用里面。什么都不用安装，除非你另选一个，应用就会用它（见 [Chromium](/guide/web#chromium)）。它的页面在应用的窗口里绘制得很快，点一下页面就能自己操作，关闭窗口后它也照常工作。
- **在其他地方**（Docker 或服务器上的应用，以及用手机或任何网页访问它时），它是应用在运行它的那台电脑上启动的真正的 Chromium，你看到的是一幅实时画面。

开启浏览器后，每个智能体都可以：

- 在当前标签页或新标签页中打开网页，并运行网页的脚本；
- 以大纲的形式查看网页：它的文字，以及编了号的链接、按钮和输入框；
- 点击、双击、指向、在输入框中输入（替换其中的内容，或在后面追加，并按 Enter）、从列表中选择、滚动、按键、后退和等待：一次最多 10 步，网页一有变化就提前停下；
- 用你保存在保险库中的登录信息登录：它按名称把密码（或其他密钥）输入到网页中，自己却看不到，而且只在你为它允许的主机的网页上这样做（见[把密钥存放在保险库中](/guide/connections#keep-keys-in-the-vault)）；
- 当它的模型能看图片并且开启了截图时，查看画上了编号的截图；
- 在网页上查找文字、分段阅读它的文字，或者让辅助模型根据长网页回答问题（见[智能体、账户和模型](/guide/agents-models)）；
- 列出、切换和关闭标签页；
- 把会话文件夹中的文件附加到网页的上传栏（其他地方的文件都不行）；
- 把浏览器交给你。

有些事情始终由你来做，或者要等你点头：

- **没有保存登录信息的登录、验证，以及智能体没有把握的任何事。** 智能体被要求把这些交给你，而不是自己尝试，验证码（确认你是真人的检查）和发给你的验证码也包括在内。如果一项任务以后还要在你不在时再次登录，比如定时任务，智能体可能会改为用卡片向你要这组登录信息，存进保险库。
- **付款和下单。** 智能体绝不会按下会付款或下单的按钮（Pay、Buy now、Place order、Subscribe now、Donate、Book now、带有银行卡字段的表单的提交按钮……）。它会停下来，请你自己完成。
- **在浏览器已登录的网站上，发送、发布、删除或转账的按钮。** 智能体按下之前，会先请你允许（见[发送、发布或删除的按钮](/guide/web#buttons-that-send-post-or-delete)）。你可以在设置中把它关掉。
- **你输入的内容。** 密码、卡号、安全码和一次性验证码的值永远不会显示给智能体，你在操控浏览器时输入的任何内容也不会。地址中类似密码的部分也会对它隐藏。智能体用保险库中的内容填写的输入框会显示圆点，智能体只会得知它已填好。
- 网页提出的**弹窗问题**（见[回答网页的弹窗问题](/guide/web#answer-a-pages-pop-up-questions)）。

每个会话都有自己的浏览器。没有个人资料时，它从全新状态开始，没有登录任何网站，关闭后什么都不保留。有个人资料时，个人资料登录过的网站它都是已登录状态（见[用个人资料保持登录](/guide/web#keep-sign-ins-with-profiles)）。你自己的浏览器（在“浏览器”页面里）是另一个，智能体永远不会用到，除非你把它的一个页面交给它（见[把页面交给智能体](/guide/web#hand-a-page-to-an-agent)）。

## 实时观看浏览器

会话的浏览器打开时，消息框正上方会有一个面板。它显示网页的标题（或“空白页”），下面是智能体正在做什么（“正在点击‘Sign in’”“正在向‘Search’中输入”）、它使用的个人资料，以及打开了多少个标签页。有事等你处理时，它会显示“等你处理”；你在使用浏览器时，它显示“由你操控：智能体在等待”。

在电脑上：

- 折叠时，面板左侧会显示网页的实时小画面。点击它、标题或箭头（**显示实时画面**）即可展开实时画面；**隐藏实时画面**会再次把它折叠起来。
- **全屏**会让浏览器覆盖整个应用；**退出全屏**会带你回来。
- **接管**让你自己使用浏览器（见下文），**浏览器选项**（⋯）会打开它的菜单。

在手机上，轻点面板即可全屏打开浏览器；× 会关闭它。

在桌面应用中，实时画面就是网页本身，由应用绘制，网页一变化就同步更新，所以滚动和输入都和任何浏览器一样顺手。在其他地方，它是网页的图片，你观看时每秒会发送好几次；在第一张图片到来之前，它会显示“正在连接浏览器…”。

### 看清智能体指向哪里

浏览器在你看不见的地方运行，所以实时画面会替你画出智能体的指针：一个应用强调色的大箭头，带着柔和的光晕，旁边有一个 **智能体** 标签。

- 智能体点击、输入或滚动之前，它的指针会从原来的位置滑到那个地方，大约用三分之一秒，好让你的眼睛跟得上。你在看的时候，智能体会等指针到位；没人看浏览器时，它就不等。
- 它点击的地方会扩散出一圈波纹（双击是两圈）。它输入的输入框，或它从中选择的列表，会短暂地显示一个轮廓。滚动时，指针旁边会用箭头显示滚动的方向；它按的键（Enter、Tab、Ctrl+A）会显示在标签旁边。
- 指针会停在智能体最后操作的地方。在折叠起来的面板的小画面上，它显示为一个小箭头。
- 你在操控时，智能体的指针会从实时画面中消失：只剩你自己的指针。你把浏览器交还给它时，它会再出现。

智能体在浏览器中的每一步也会显示在对话中，和它的其他步骤排在一起，显示为一行（“已打开 github.com”“已点击 [12] 按钮‘Sign in’”“向你提问：登录 GitHub”），后面附有一张这一步之后网页的小图。点击这一行可以看到大图和智能体的完整回答。在大图上，一个圆圈标出这一步点击的位置，一个虚线框标出它输入的输入框；如果这一步做了几件事，还会标上编号。应用会保留每个会话最近 400 步的图片；一个月没动过的会话，其图片会被删除。

## 接管浏览器来登录、完成验证或付款

当智能体需要你在浏览器中操作时，你会同时在好几个地方得到通知：

- 浏览器面板顶部的一行提示，带有相应的按钮；
- 对话中的一张卡片，比如“需要你在浏览器中操作：登录 GitHub”，带有**显示**（在手机上是**打开**）；
- 一条通知（就像会话需要你回答时那样），以及[收件箱](/inbox)中的一项（见[收件箱和通知](/guide/inbox)）。

在电脑上，遇到登录、付款或弹窗问题时，实时画面会自动展开，处理完后再次折叠（除非是你自己打开的）。

### 在电脑上

1. 按那一行（或面板）上的**接管**。面板会显示“由你操控：智能体在等待”，实时画面会加上彩色边框。
2. 像在任何浏览器中一样使用网页：点击、用滚轮滚动、输入。先在网页里点一下；之后你的按键都会发送到网页（应用自己的快捷键暂停使用），粘贴的内容会作为文字输入。在桌面应用中，在网页里点击或输入就足以接管：面板会自动变成“由你操控：智能体在等待”；智能体操控时，地址下面有一行写着“点一下页面即可自己操作”。
3. 你操控时，网页上方会有一个栏，里面有**返回**、**重新加载**和地址：输入一个地址并按 Enter 即可前往。
4. 完成后，按那一行上的**完成**。应用会告诉智能体你已经完成，并附上浏览器现在显示的网页，智能体就会继续。

### 在手机上

1. 轻点**接管**。浏览器会全屏打开，在你操控期间，网页会按手机屏幕排版。带有**返回**、**重新加载**和地址的栏在它上方。
2. 轻点即点击，拖动即滚动。**输入**会打开手机键盘；旁边那一行有 Tab、Enter、Esc、⌫ 和方向键。
3. 完成后轻点**完成**。网页会恢复正常大小，智能体会继续。

### 付款和下单

当智能体遇到会付款或下单的按钮时，它会停下来：“在付款或下单前停下了：shop.example.com 上的 Place order。这一步要由你来完成。”接管浏览器，检查订单，自己付款，然后按**完成**。如果你不打算继续，就按**暂不**。无论哪种情况，智能体都会知道你选了哪个。

### 其他回答，以及主动接管

- **做不到**会告诉智能体，你没能完成它请求的事。
- 你随时都可以接管，不必等它请求：按面板上的**接管**。智能体会等待；如果它在此期间试图使用浏览器，会被告知浏览器在你手上，等你用完时它会收到通知。按**交还**把浏览器还给它；如果智能体正在等浏览器，它会收到一条消息，里面有浏览器当前显示的网页。

应用替你发给智能体的消息会显示在对话中。如果智能体正处在一轮对话中间，这些消息会等到这一轮结束。

## 发送、发布或删除的按钮

在浏览器已登录的网站上，智能体在按下会发送、发布、公开、分享、回复、删除、移除、转账或提现的按钮之前，会先询问你。这适用于使用个人资料的浏览器（见[用个人资料保持登录](/guide/web#keep-sign-ins-with-profiles)），以及你交给智能体的页面（见[把页面交给智能体](/guide/web#hand-a-page-to-an-agent)）。从全新状态开始、没有登录任何网站的浏览器没有什么需要保护的，也不会询问。付款和下单仍然只由你来做（见上文）。

智能体靠按钮上的字来认出它们，支持英语、德语、希腊语、中文、法语和西班牙语：Send、Post、Publish、Delete、Transfer 之类，以及当页面说的是其中某件事时单独一个“Confirm”或“Yes”（比如一个询问“Delete this post?”的弹窗）。“Sign in”“Next”“Save draft”“Cancel”、搜索按钮，以及给你自己发验证码（Resend code）不会被拦下。

遇到这样的按钮时，它会停下来，结束这一轮并等待。你会在和其他提问相同的地方（浏览器面板上的那一行和对话中的一张卡片）看到“想要在 mail.example.com 上点按“Delete””，带有**不允许**和**允许**两个按钮。实时画面不会自动展开。

- **允许**告诉智能体现在可以按下这个按钮。它只放行接下来两分钟内、在那个网站上、文字相同的按钮的一次按下；之后智能体会再次询问。
- **不允许**告诉智能体不要按。它会不按而继续，或者告诉你它没能做成什么。这张卡片随后显示“已允许”或“未允许”。

它一开始是开启的。要把它关掉，见[在已登录的网站上发送前先询问](/guide/web#ask-before-sending-on-signed-in-sites)。

## 回答网页的弹窗问题

当网页弹出一个对话框（一条提示、一个是或否的问题、一个要求输入文字的提示框，或“要离开此页面吗？”）时，它会显示在实时画面上方：网站、“说”（或“询问是否离开”），以及那条消息。只有你能回答它：**确定**或**取消**（要求输入文字时会带一个输入框），或者**离开**或**留下**。如果是智能体的某一步打开了它，你会收到通知，智能体也会知道你是怎样回答的。

## 让会话打开这台电脑或你所在网络上的网站

开启[禁止网页访问本机及其所在网络](/settings?s=browser&find=Keep%20pages%20off%20this%20machine%20and%20its%20network)时（一开始就是开启的），网页无法访问这台电脑或其所在网络中的其他设备。当智能体想打开其中某个地址时，比如在这台电脑上运行的、你正在搭建的网站（开发服务器），它会先询问：“想要打开本机或其网络中的 localhost:3000”，并提供**不允许**和**在此会话中允许**两个选项。允许之后，这个会话的浏览器从此就可以打开那个地址，智能体也会被告知再打开一次。

你在操控时自己输入的、这台电脑或其所在网络上的地址，也会以同样的方式在这个会话中获得允许。浏览器菜单中的**此会话的网站**会在“允许访问本机或其所在网络”下面列出你允许过的地址；点旁边的 × 即可撤销。Hydor 本身永远无法从浏览器中打开。

## 浏览器的菜单

面板上的**浏览器选项**（⋯）会打开一个菜单：

- **标签页**（打开了不止一个时）：选择一个即可显示它。当网页在新标签页中打开链接时，智能体会在那里继续。
- **已保存在会话的文件夹中**：浏览器最近下载的文件；选择一个即可打开。
- **个人资料（换成其他个人资料会重启浏览器）**：**全新，未登录任何账号**，或你的某个个人资料。你创建过个人资料后才会有这一项。选择另一个会关闭浏览器；下次使用时，它会以新的个人资料打开。
- **此会话的网站**：这个会话的浏览器只能访问的网站（**仅限这些网站**，留空表示任何网站都可以）和它绝不访问的网站（**禁止访问这些网站**），每行一个。它们是在设置 → 浏览器中的列表之外另加的。按**保存**来保留它们。
- **关闭浏览器**。

## 自己打开浏览器

你可以在智能体之前先打开会话的浏览器，比如在让它去某个网站工作之前，先登录那个网站。打开会话的菜单（⋯）→ **更多** → **打开浏览器**。面板会出现在消息框上方：按**接管**即可使用。如果浏览器已经打开，同一项会显示为**显示浏览器**。如果浏览器在设置中被关闭了，你会收到提示。想要一个不属于任何会话、只属于你自己的浏览器，见[你自己的浏览器](/guide/web#your-own-browser)。

## 下载和上传

网页下载的文件会保存在会话文件夹中一个名为 downloads 的文件夹里，智能体会被告知它们的位置。浏览器菜单会在**已保存在会话的文件夹中**下面列出最新的文件。

智能体只能把会话文件夹中的文件附加到网页的上传栏。要让它上传别的文件，先把文件复制到那个文件夹（见[系统：文件、Git、终端和预览](/guide/files-git)）。

## 浏览器何时关闭

会话的浏览器会在以下情况下自动关闭：

- 15 分钟内没有人使用或观看它时；如果它在等你，或者正由你操控，则是两小时；
- 它的最后一个标签页关闭时；
- 会话的智能体停止运行，或会话被删除时；
- 你为它选择了另一个个人资料，或删除了它正在使用的个人资料时。

仍在等你处理的事情也会随之结束。智能体下次需要时会再次打开浏览器。

在桌面应用中，智能体的浏览器不需要应用的窗口：只要应用还在运行（它留在菜单栏、通知区域或托盘里），窗口关闭或隐藏时它也照常工作。打开窗口，就能看到它的页面。

## 你自己的浏览器

**浏览器**页面是桌面应用（Mac、Windows、Linux）里属于你自己的浏览器，与智能体使用的那个并存：在工具栏里打开**浏览器**，或前往[浏览器](/browser)。它只在桌面应用中有：在浏览器里打开的 Web 应用和手机上都没有**浏览器**按钮，那里的[浏览器](/browser)地址会这样告诉你。智能体的浏览器在任何地方都能用，你可以在它们的会话中观看。

它顶部有一条栏，里面的输入框可以搜索、打开，也可以就页面向智能体提问，或告诉它要在页面里做什么；页面左边是一列标签页，带着你固定的网站和工作中的智能体；右边是一列（宽度由你拖动），用来就页面向智能体提问或告诉它要在页面里做什么、查看智能体的对话，以及历史记录、下载、书签、扩展程序和设置。它有后退、前进和重新加载、书签、历史记录、Chrome 扩展程序、会同时隐藏 Cookie 横幅的广告和跟踪器拦截器、在页面中查找、缩放、打印和下载。它还有关闭时会忘掉一切的[无痕标签页](/guide/web#private-tabs)、把页面翻译成你的语言的[网页翻译](/guide/web#translate-a-page)、适合文章的[阅读视图](/guide/web#reader-view)、[深色页面](/guide/web#dark-pages)、[截图和把页面保存为 PDF](/guide/web#screenshots-and-pdfs)，以及不能自己播放声音的网站。指向一个链接时，它会去往哪里会显示在页面左下角的小框里（鼠标正在那里时则显示在右下角），和 Chrome 一样。它的标签页是显示在应用窗口里的真正网页，速度和按键都和任何浏览器一样，并像任何浏览器一样直接连接网站。应用中弹出的菜单或对话框盖住网页时，网页会暂时让开（在它关闭之前显示一张它的图片）。它会在两次访问之间保留你的登录状态，放在它自己的个人资料里，没有智能体能选用；再次打开时，它会恢复你原来的标签页（最多 30 个；空白的和无痕的不算）。你的标签页也可以打开这台电脑及其所在网络上的地址（比如你正在搭建的网站）。如果浏览器无法启动，页面会说明原因，并带有**重试**和**浏览器设置**，后者会打开[设置 → 浏览器](/settings?s=browser)。

### 栏和输入框

页面顶部有一条栏。它的左边在标签页列的上方，有 **HYDΩR** 标志、**新标签页**（+）和**隐藏标签页**（和 Ctrl+B 一样），后者会把标签页列收起，直到用**显示标签页**把它带回来。栏的其余部分属于你正在看的页面：

- **后退**、**前进**、**重新加载**和 **Home** 在输入框的左边。页面加载时，重新加载会变成**停止**。**Home** 会在当前标签页打开你的主页，**新标签页**则在新的标签页里打开它。
- 中间的输入框就是地址栏。平时它把网页的地址显示为网站名，地址的其余部分颜色较浅，还有一个提示 **Ctrl+L**。点一下它，或按 Ctrl+L，它就显示完整的地址供你修改。你在里面输入的内容在你切到别的应用时会保留；在网页里点一下，它就恢复显示地址。输入一个地址，带不带 https:// 都行（`example.com`、`localhost:3000`、`192.168.1.5`、`file://` 地址），按 Enter 打开它。你输入的其他内容会用你的搜索引擎搜索（一开始是 Google；见[浏览器设置](/guide/web#browser-settings)），而像 `yt` 这样的快捷词加一个空格再加你的字词，则改为搜索那个网站（见[建议](/guide/web#suggestions)）。**Alt+Enter**，或 Ctrl+Enter（Mac 上是 ⌘+Enter），会改在新标签页中打开（在无痕标签页里时，打开的是无痕标签页）。你输入时它提供什么，见[建议](/guide/web#suggestions)。它的挂锁在左边（在无痕标签页里，挂锁前面先是一个紫色的**私密**标记：见[无痕标签页](/guide/web#private-tabs)）。右边是：一个按钮，在页面的语言与你的不同时翻译这个页面（见[翻译网页](/guide/web#translate-a-page)）；一个书本按钮，在页面有文章时进入阅读视图，开启时旁边还有 **Aa**（见[阅读视图](/guide/web#reader-view)）；还有它的星标。
- 输入框末尾的星标会把这个页面加到书签栏；实心表示已加书签，再按一次就取消书签。书签栏上的网站会显示为标签页列顶部的小方块。
- **保存**会在一个项目中保存页面的一份可读副本，就像阅读视图显示的那样：文章的正文连同其中的图片和视频，没有网站的菜单、广告、评论和脚本。会有提示说“已保存到”加上项目的名称（“已保存到 Thesis 的文件中”），带有**打开**：这份副本是项目文件中的一个网页，在它的**文件**标签页里（见[文件](/guide/projects#files)）。**保存**旁边的 **▾**（**选择要保存到的项目**）列出可以保存到哪里：**不放在项目中**和你的每个项目。保存所用的位置会在这个菜单里打上标记：就是你上次在这台电脑上选的位置（一开始是**不放在项目中**）。没有项目时，提示会说“已保存。在“保存”旁边选一个项目，就能把副本保留到它的文件中。”：副本不属于任何项目，搜索框（Ctrl+K）能找到它。你的列表（书签、稍后阅读的页面、下载、历史记录和高亮）是这个页面的面板，在**菜单**（⋯）里（见[页面旁边的列](/guide/web#the-column-beside-the-page)）。
- **询问**会在页面旁边打开一列，你可以在里面就页面向智能体提问，或选**执行**让智能体在页面里工作（见[在页面旁提问](/guide/web#ask-beside-the-page)）；那一列在时，它会亮着。
- 接下来是你固定的扩展程序的按钮，然后是**扩展程序**（拼图块），它列出每个已开启的扩展程序，然后，当打开的标签页是某个扩展程序的 Chrome 应用商店页面时，还有**添加到 Hydor**（见 [Chrome 扩展程序](/guide/web#chrome-extensions)）。
- **菜单**（⋯）有**新建无痕标签页**（见[无痕标签页](/guide/web#private-tabs)），然后是**在页面中查找**、**翻译网页…**（页面已翻译时是**显示原文**；见[翻译网页](/guide/web#translate-a-page)）、**阅读视图**和**深色页面**（开启时打上勾；见[阅读视图](/guide/web#reader-view)和[深色页面](/guide/web#dark-pages)），然后是**缩放**，中间是 − 和 + 以及用百分比表示的缩放（见[缩放、打印和全屏](/guide/web#zoom-print-and-full-screen)），然后是**打印…**、**当前可见内容的截图**、**整个网页的截图**和**另存为 PDF…**（见[截图和 PDF](/guide/web#screenshots-and-pdfs)），然后是**稍后阅读此页面**（见[稍后阅读](/guide/web#read-later)）和**用 AI 为我的标签页分组**（见[用 AI 为我的标签页分组](/guide/web#group-my-tabs-with-ai)），然后是**历史**、**下载**、**书签**、**稍后阅读**、**导入书签和历史记录…**、**高亮**（带有这个页面有多少条）、**扩展程序**、**网站权限**和**设置**，再然后是**键盘快捷键**，它们会在页面右边的那一列中打开（见[页面旁边的列](/guide/web#the-column-beside-the-page)）。你按缩放的 − 和 + 时，菜单会一直开着。在无痕标签页里，**询问**是灰色的：智能体永远得不到无痕标签页。

指向 `/browser?url=https://example.com` 的链接会打开浏览器页面，并在新标签页中打开该地址；[/browser?private=1](/browser?private=1) 会打开一个新的无痕标签页（加上 `&url=https://example.com` 就在其中打开那个地址）。

### 建议

你在地址栏中输入时，它下面的列表会给出以下内容，你输入的字词以粗体显示：

- 你打开的标签页（“切换到标签页”：选中它就会跳转过去，而不是再打开一次这个页面；你的无痕标签页在开着时也在其中，关闭之后不会留下关于它们的任何内容），
- 标题和地址中含有这些字词的书签和历史页面，你常去的和最近去过的排在前面（你亲手输入过的地址权重最高，一个书签算作二十次访问）。当有书签与你输入的字词匹配时，提供的页面中始终至少有两个书签，它们取代历史记录中排在最后的页面，所以庞大的历史记录，比如从其他浏览器导入的，永远不会把它们挤掉，
- [按含义搜索](/settings?s=memory&find=Search%20by%20meaning)开启时，还有那些内容与你输入的相关、但标题和地址里没有这些字词的书签和历史页面，排在含有这些字词的之后（它们不显示粗体字词）。找到它们的模型运行在这台电脑上，依据的是用每个页面的标题和地址（不含查询字符串）生成的向量，应用把它与其他一切分开存放在自己的数据库里；页面一删，它也随之删除，
- 当你输入的内容以你的某个搜索快捷词和一个空格开头（`yt lofi`）时，最先出现一行，用来在那个网站上搜索后面的字词（“在 YouTube 中搜索 ‘lofi’”），按 **Enter** 就会这样做（见[浏览器设置](/guide/web#browser-settings)），
- 你输入的内容，作为一次搜索（“使用 Google 搜索”），或者当它看起来像一个地址时，作为这个地址；前面有快捷词时，这一行仍会用你的搜索引擎搜索你输入的所有字词，
- 搜索引擎自己的建议，在[搜索建议](/guide/web#browser-settings)开启时，
- 再往下，当打开的标签页是网页（而且不是无痕标签页，智能体永远得不到它）时，有**就这个页面提问：“…”**，它会在页面旁边打开“询问”，把你输入的内容当作问题。在“询问”里选了**执行**时，这一行改为**在这个页面上执行：“…”**，把你输入的内容交给一个智能体，让它在那里去做（见[在页面上执行](/guide/web#do-it-on-the-page)），
- 最后是**问智能体：“…”**，它会以你输入的内容作为第一条消息，用开始页上次使用的智能体和模型开启一个会话，并带你过去。

列表显示的数量以屏幕放得下为限，其中至少有两个你自己的页面和两个搜索引擎的建议（只要有这么多）。当列表要为了适应较矮的窗口而削减时，先去掉的是你的历史页面，再是你的书签和打开的标签页。方向键在其中移动，**Enter** 打开选中的那一项（没有选中时打开你输入的内容）；**Alt+Enter**，或 Ctrl+Enter（Mac 上是 ⌘+Enter），在新标签页中打开（在无痕标签页里时，打开的是无痕标签页）。地址栏还会原地补全：当你去过的某个地址以你输入的内容开头时，其余部分会在光标后以选中状态显示（按你输入的字词找到，绝不按含义），按 **Tab** 或 **→** 即可采用。删掉你输入的内容会关闭补全。在某条历史建议上按 **Shift+Delete** 会忘掉那个页面，**Esc** 关闭列表。

### 标签页列

页面左边的这一列从上到下列出（**隐藏标签页**，或 Ctrl+B，会把它收起）：

- **固定的网站**：书签栏上的项目，显示为小方块，每行五个，最多两行（一个 **…** 方块会列出其余的）。点一个，会在当前标签页中打开；Ctrl+点击（Mac 上是 ⌘+点击）或中键点击，会在新标签页中打开。文件夹会打开一个列表，列出里面的内容。右键点一个方块，有**打开**、**在新标签页中打开**、**编辑**（文件夹是**重命名**）和**删除**。书签栏上什么都没有时就没有方块；星标会把页面放到那里（见[书签](/guide/web#bookmarks)）。
- **工作中的智能体**：只要有智能体开着浏览器，每个一行，带着它的图标和一个圆点（工作时是蓝色，等你处理或由你操控时是琥珀色）、会话的标题和它正在做的事。点一行就能看它（见[工作中的智能体](/guide/web#agents-at-work)）。它的箭头会把这个列表收起。
- **无痕**，在你开着无痕标签页时：一个紫色的区块，带着一个面具和有几个无痕标签页，每个无痕标签页一行（底色带点颜色，图标上有一个小面具）。点它的标签可以把这个区块折叠起来；**关闭无痕标签页**（指向标签时出现 ×）会把它们全部关闭，区块末尾的**新建无痕标签页**会再开一个（见[无痕标签页](/guide/web#private-tabs)）。无痕标签页不在任何分组里，也不能拖进分组。
- **标签页**：每个标签页一行，有图标、标题、**⋯** 和 **×**（打开的标签页上有，你指着的那个上也有）。标题太长、这一栏放不下时，结尾会渐隐；指着这一行时，它会滚动显示其余部分。打开的标签页是被标出的那一行；点一行会显示那个标签页，中键点击会关闭它。右键点一行，或按它的 **⋯**，会打开这个标签页的菜单（见[标签页分组和标签页菜单](/guide/web#tab-groups-and-the-tab-menu)）。你放进分组的标签页会排在分组标题下面，**标签页**标签末尾的闪光按钮会用 AI 为你的标签页分组。播放声音的标签页会显示一个扬声器：点它会让标签页静音，再点一次就能听到。静音的标签页会一直显示它的扬声器。末尾的**新标签页**会打开你的主页。关闭最后一个标签页会留下一个空白页。
- **稍后阅读**，在标签页下方：你留待稍后阅读的页面（见[稍后阅读](/guide/web#read-later)），最新的在前，每个都有图标和标题，并显示正在等待的数量。没有等待阅读的内容时它是折叠的；点它的箭头即可展开。点一行会在新标签页中打开那个页面。指着一行会出现**标为已读**（它会离开列表）和**移除**。末尾的**显示已读**会把你读过的页面带回来（**隐藏已读**再把它们收起）。

### 标签页分组和标签页菜单

右键点一个标签页（或按你指着的那一行上的 **⋯**，或在已聚焦的一行上按菜单键），会打开它的菜单：

- **关闭标签页**、**关闭其他标签页**和**关闭下方的标签页**（栏里列在它下面的标签页，按列出的顺序）。你的浏览器总会留着一个标签页。
- **创建副本**会在它旁边的新标签页里打开同一个地址，放在同一个分组里，并显示出来（无痕标签页的副本也是无痕的）。**重新加载**只重新加载这个标签页，而不只是你打开的那个。
- **复制地址**、**复制为 Markdown 链接**（把指向页面的链接按 Markdown 格式复制下来，标题作为链接文字，方便放进文档或消息；提示会说“已复制 Markdown 链接”）和**书签**（已加书签时是**删除书签**），后者会把页面放到书签栏。
- **添加到分组**，列出你的分组（标签页所在的那个打上勾）和**新建分组…**，后者用这个标签页建一个分组，并打开它的名称让你输入；还有**从分组中移除**。无痕标签页的菜单里两者都没有：无痕标签页不能分组。

分组把属于一起的标签页放在一起。它有名称、七种颜色之一（灰色、蓝色、绿色、琥珀色、橙色、红色或紫色），并且是展开或折叠的。在栏里，它是一个标题，带着它的颜色、名称（你起名之前叫“未命名分组”）和它有几个标签页；它的标签页排在下面，旁边有一条它颜色的线，不在任何分组里的标签页排在分组之后。点标题会把分组折叠起来，或再次展开；折叠的分组会隐藏它的标签页，只留下你打开的那个。双击名称（或按 F2）可以重命名。你可以把标签页拖到分组上放进去，拖到不在分组里的标签页上就能取出来。右键点标题，或按它的 **⋯**，会打开分组的菜单：

- **重命名**和**颜色**。
- **在分组中新建标签页**会在其中用新标签页打开你的主页。
- **取消分组**会拆开分组，让它的标签页留在原处。
- **关闭分组**会关闭分组和它所有的标签页。

没有标签页的分组就消失了。分组会和你的标签页一起保存，浏览器再次打开时一起回来。在手机上，标签页是栏里的一个列表，没有分组。

### 用 AI 为我的标签页分组

标签页很多时，**标签页**标签末尾的闪光按钮（指着这个标签时才出现），或**菜单**（⋯）→**用 AI 为我的标签页分组**，会按用途把不在任何分组里的标签页分类。至少需要三个这样的标签页；已经在分组里的标签页保持原样，无痕标签页也不算在内：它们从不被计数、从不被分组，也从不被发送到任何地方。

**会发送什么，发给哪个模型。**只有在你按下按钮时，这些标签页（最多 60 个）每个的标题和地址会发给应用的辅助模型，也就是写会话标题和记忆笔记的那个模型（[设置 → 智能体 → 模型 → 辅助模型](/settings?s=models&find=Helper%20model)）。选“自动”时它是通过 Claude Code 的 Claude Haiku，否则是 Codex，两者都在线；你电脑上自己的模型则把它们留在本机。地址发送时不带 **?** 或 **#** 后面的任何内容，文件的地址只发它的名称。页面的文字和图片从不发送，其他任何时候也不会发送任何东西。如果某个标题是私密的，就不要按它（或把你电脑上的模型设为辅助模型）。

模型回答的是一组组标签页，每组有简短的名称和颜色，应用会立即建好它们。一条消息会说建了几个分组，并带有**撤销**，它会把分组恢复成原来的样子。如果没有标签页放在一起合适，它会这样说，不做任何更改。智能体从不会看到你的标签页，应用也不允许它们使用这个功能。

### 页面旁边的列

页面右边有一列，只有里面有东西时才显示，一次只显示下面其中之一：就页面**询问**，或让智能体在页面里做点什么（见[在页面旁提问](/guide/web#ask-beside-the-page)）；你在看某个智能体的标签页时，它的对话（见[工作中的智能体](/guide/web#agents-at-work)）；或者**历史**、**下载**、**书签**、**稍后阅读**、**导入书签和历史记录**、**高亮**、**扩展程序**、**网站权限**、**设置**或**键盘快捷键**的面板。每个都有一个 **×** 来关闭，选另一个会替换它。页面上不会盖着任何东西：它会变窄来腾出地方，那一列关闭后再变宽。地址[历史](/browser?panel=history)、[下载](/browser?panel=downloads)、[书签](/browser?panel=bookmarks)、[稍后阅读](/browser?panel=later)、[导入书签和历史记录](/browser?panel=import)、[高亮](/browser?panel=highlights)、[扩展程序](/browser?panel=extensions)、[网站权限](/browser?panel=permissions)、[设置](/browser?panel=settings)和[键盘快捷键](/browser?panel=shortcuts)会打开浏览器页面，并让对应的面板出现在那里。

拖动这一列的左边缘可以让它变宽或变窄（或让边缘获得焦点后按 **←** 或 **→**）；双击会恢复它通常的宽度，400 px。它对这一列显示的所有内容是同一个宽度，保存在这台设备上，不会窄于 340 px，并且总给页面留下至少 360 px。在窄窗口里，标签页是栏里的一个列表，那一列则是盖在页面上的一块面板，宽度另有规定。

### 在页面旁提问

栏里的**询问**（或输入框列表里的**就这个页面提问：“…”**，或右键菜单里的**就“…”问智能体**）会为你所在的标签页打开这一列。它顶部有一个开关，**询问**或**执行**；你选的会保存在这台设备上。

选**询问**时，写下你想了解的，或按**总结**、**要点**或**简单解释**，然后按**询问**（**Ctrl+Enter**，Mac 上是 ⌘+Enter）。输入框下面的一行会说是哪个智能体和模型来回答：开始页上次用的那个。会开始一个新会话，基于页面此刻的一份副本（见[就这个页面提问](/guide/web#ask-about-this-page)），它的对话会占满这一列，所以你可以在那里接着问。它的提示以“选择“执行”，可让智能体在页面中工作。”结尾。

选**执行**时，写下智能体应该在这个页面上做什么（“用我的信息填写这份表单”），然后按**开始执行**（**Ctrl+Enter**，Mac 上是 ⌘+Enter）。输入框下面的智能体一行是一个按钮，用来选 **Claude Code** 或 **Custom**（只有这两个能被限制在一个标签页内；开始页上次用的那个，一开始是 Claude Code），模型则是开始页上次为它用的。提示会说明智能体会得到什么：属于它自己的一个标签页，带着你在这个网站上的登录状态，只有浏览器，并且在发送、发布、删除或付款之前会先询问（见[在页面上执行](/guide/web#do-it-on-the-page)）。它一开始，智能体的标签页就会显示在网页的位置，它的对话占满这一列，和[工作中的智能体](/guide/web#agents-at-work)里一样。

两种方式里，你在页面中选中并用**就“…”问智能体**发送的、显示在输入框上方的字词，都会随你的请求一起发出（最多 4,000 个字符）；用**就这张图片提问**发送的图片也一样（见[右键菜单](/guide/web#right-click-menu)），它同样显示在输入框上方，在“询问”里还带有**描述这张图片**之类的快捷问题。

每个标签页有自己的对话：切换标签页，这一列就显示那个标签页的对话。**作为会话打开**会带你到会话列表中的它。**新问题**（“执行”之后是**新请求**）会在这里忘掉这个标签页的对话（会话本身还在），这样你可以重新提问。执行之后回到你的标签页，这个标签页的“询问”会显示那段对话，带有**看它工作**，它会把智能体的标签页再次显示在网页的位置。它适用于网站的网页（“询问”也适用于文件）。地址栏中页面那一行会跟随这个开关（见[建议](/guide/web#suggestions)）。

### 键盘快捷键

在“浏览器”页面上，网页内部也一样，Windows 和 Linux 上用 Ctrl，Mac 上用 ⌘：

- **Ctrl+T** 打开新标签页，**Ctrl+W** 关闭当前的标签页。
- **Ctrl+Shift+T** 重新打开你最后关闭的标签页；再按一次，打开再之前的那个（无痕标签页不在这个列表里）。
- **Ctrl+Shift+N** 打开新的无痕标签页（Mac 上是 **⇧⌘N**）。
- **Ctrl+Tab** 前往下一个标签页，**Ctrl+Shift+Tab** 前往上一个。**Ctrl+1** 到 **Ctrl+8** 前往对应的标签页，**Ctrl+9** 前往最后一个。
- **Ctrl+L** 跳到地址栏。
- **Ctrl+R**（**F5** 也行）重新加载。
- **Alt+←** 和 **Alt+→** 后退和前进（Mac 上 **⌘[** 和 **⌘]** 也行）。
- **Ctrl+F** 打开在页面中查找，**Esc** 关闭它。
- **Ctrl+D** 为这个页面添加书签。
- **Ctrl+H** 打开历史记录，**Ctrl+J** 打开下载。
- **Ctrl+B** 会收起标签页列，再按一次就带回来。拖动它的边缘可以把它调宽或调窄：它和应用里所有栏共用同一个宽度。
- **Ctrl+P** 打印这个页面。
- **菜单**（⋯）→ **键盘快捷键**会在页面右边的那一列里按组列出这些按键：标签页、页面、地址栏、你的列表和智能体（[键盘快捷键](/browser?panel=shortcuts)）。
- **Ctrl+Shift+Delete** 打开设置中的**清除浏览数据**。
- **Ctrl** 加 **+**、**−** 和 **0** 分别放大、缩小并重置缩放（见[缩放、打印和全屏](/guide/web#zoom-print-and-full-screen)）。

### 在页面中查找

**Ctrl+F**，或菜单里的**在页面中查找**，会在地址栏下面打开一个栏。输入，你一停顿，就会找到第一处匹配并滚动到它。**Enter** 前往下一处匹配，**Shift+Enter** 前往上一处（箭头也行），栏里会显示你在第几处（“3 of 12”，超过一千处显示“1000+”）或“No matches”。默认不区分大小写，除非你按下**区分大小写**，并且会循环。**Esc** 或 **×** 会关闭这个栏，并清除找到的标记。

### 缩放、打印和全屏

- **缩放**：**Ctrl** 加 **+** 放大，**−** 缩小，档位与 Chrome 相同（25 % 到 500 %）。Ctrl 加鼠标滚轮也能缩放，**菜单**（⋯）里**缩放**一行的 − 和 + 也行，你按它们时菜单会一直开着。**Ctrl+0**、那一行里的百分比，或下面说的小标签，会把缩放重置为[浏览器设置](/guide/web#browser-settings)里的**页面缩放**（一开始是 100 %）。你自己缩放过的网站，在应用运行期间会保持它的缩放。与页面缩放不同的缩放会在地址栏末尾显示为一个小标签，比如“125%”：点击它即可恢复（它的提示写着“恢复到 100 %”，或你的页面缩放）。
- **打印**：**Ctrl+P**，或菜单或右键菜单里的**打印…**，会为这个页面打开你电脑的打印对话框，并带上它的背景。
- **全屏**：当视频或网页要求铺满屏幕时，应用的窗口会进入全屏，网页铺满整个窗口。用网页自己的退出方式（Esc）就能让窗口恢复。

### 截图和 PDF

**菜单**（⋯）里有三项，把你正在看的页面保存为文件，适用于网站的网页或标签页中显示的文件：

- **当前可见内容的截图**：标签页里显示出来的那部分页面的一张图片。
- **整个网页的截图**：从上到下整个页面的一张图片，不论它要滚动多远（最高 16,384 像素；无法截取时，你得到的是当前可见的内容）。
- **另存为 PDF…**：把页面保存为带着背景的 PDF，就像你把它打印出来一样。

截图是 PNG。它会保存在你的“下载”文件夹里，以页面的标题加日期和时间命名（“Example 2026-11-18 at 14.30.05.png”），同时放到剪贴板上，所以你可以直接把它粘贴到消息或文档里。会有提示说“截图已保存到“下载”并已复制”，带有**在文件夹中显示**。PDF 保存在“下载”里，以页面的标题命名，提示是“已以 PDF 格式保存到“下载””，也带有**在文件夹中显示**。重名时会在名称后加一个数字，不会覆盖任何文件。它们在无痕标签页里也能用。

### 右键菜单

在网页中右键点击会打开一个菜单，内容取决于你点击的位置，外观和语言与应用自己的其他菜单一致（按 **Esc** 或点击菜单外部即可关闭）：

- 在文本框中：对拼错的词给出拼写建议，并带有**添加到词典**；然后是**撤销**、**重做**、**剪切**、**复制**、**粘贴**和**全选**。
- 在链接上：**在新标签页中打开链接**、**在无痕标签页中打开链接**（见[无痕标签页](/guide/web#private-tabs)）、**在默认浏览器中打开链接**、**复制链接地址**和**稍后阅读链接**（见[稍后阅读](/guide/web#read-later)）。
- 在图片上：**在新标签页中打开图片**、**图片另存为…**（保存到你的“下载”文件夹）、**将图片保存到**（保存所用的项目）（还没有选项目时只是**保存图片**）、**就这张图片提问**、**复制图片**和**复制图片地址**。
- 在视频上：**播放**或**暂停**、**静音**或**取消静音**、**循环**和**显示控件**（开启时打上勾）、**画中画**（显示时打上勾）、**在新标签页中打开视频**、**视频另存为…**（保存到你的“下载”文件夹）和**复制视频地址**。声音也一样，是**在新标签页中打开音频**、**音频另存为…**和**复制音频地址**，没有画中画。只有那个视频或声音能做的项目才会显示。
- 选中了文字时：**复制**、**用…搜索“…”**（用你的搜索引擎搜索它，在新标签页中打开），以及**就“…”问智能体**，它会在页面旁边打开**询问**，并把选中的字词（最多 4,000 个字符）和网页的地址准备好，等你写下问题（见[在页面旁提问](/guide/web#ask-beside-the-page)）；**翻译“…”**，它会在一个框里显示这些字词翻译成你的语言的结果（见[翻译网页](/guide/web#translate-a-page)）；还有**高亮**，它会把这些字词在页面上标出并保存下来（见[高亮](/guide/web#highlights)）。
- 在你自己的某条高亮上：**移除高亮**。
- 在网页本身上，不在文本框或选中的文字上时：**返回**、**前进**和**重新加载**，以及**翻译为德语**（你翻译成的语言；页面已翻译时是**显示原文**）。
- 始终有：**为此页面添加书签**、**稍后阅读此页面**（在网页上）、**打印…** 和 **检查**，后者会打开这个页面的开发者工具。

在无痕标签页里，菜单里没有**在无痕标签页中打开链接**，**在新标签页中打开链接**和其他“在新标签页中打开”的项目打开的是无痕标签页，而且所有**询问**项目（**就“…”问智能体**、**就这张图片提问**）都不在，因为智能体永远得不到无痕标签页。

**将图片保存到**（一个项目）会用这个标签页自己的登录状态读取图片，所以登录后才能看到的图片也行，并把它保存到**保存**旁边选的项目中（在它的**文件**里，以这个页面作为它的来源），或者不放进任何项目。会有提示说“已保存到 Thesis 的文件中”（或“图片已保存”），带有**打开**（如果你之前已保存过，则是“那张图片已经保存过了”）。它保存最大 50 MB 的 PNG、JPEG、WebP、GIF 和 AVIF 图片；位图或图标会变成 PNG，SVG 等其他类型会被拒绝。图片需要有 http、https、data 或 blob 地址。智能体可以读取项目保留的内容，所以只有在你对此没问题时才把图片保存到那里。**就这张图片提问**用同样的方式读取图片，并在页面旁边打开**询问**，把它和你的问题一起准备好，同时附上页面的一份副本。

扩展程序自己的菜单项永远不会显示（见[哪些可能无法使用](/guide/web#what-may-not-work)）。

### 无痕标签页

无痕标签页是会忘掉一切的标签页。打开它可以用 **Ctrl+Shift+N**（Mac 上是 **⇧⌘N**）、**菜单**（⋯）→ **新建无痕标签页**、标签页列里**无痕**区块末尾的**新建无痕标签页**，或 [/browser?private=1](/browser?private=1)（加上 `&url=https://example.com` 就在其中打开那个地址）。在链接上右键 → **在无痕标签页中打开链接**；在无痕标签页本身里没有这一项，**在新标签页中打开链接**打开的就是无痕标签页（其他“在新标签页中打开”的项目、为选中的字词**搜索**，以及地址栏里的 **Alt+Enter** 也一样）。

无痕标签页看起来是这样的：

- 它的那一行在标签页列紫色的**无痕**区块里，区块会说有几个无痕标签页。**关闭无痕标签页**（标签末尾的 ×）会把它们全部关闭。
- 地址栏开头有一个紫色的**私密**标记。点它可以看到无痕标签页是什么、保留什么，并带有**关闭无痕标签页**。

无痕标签页把什么单独分开、又忘掉什么：

- **登录状态、Cookie、网站数据和缓存文件**保存在内存里，与你的其他标签页相互隔离：你在普通标签页里登录的网站，在无痕标签页里不认识你，反过来也一样。最后一个无痕标签页关闭时，或应用退出时，它们全部被忘掉。
- **它的页面不会保存**到你的[历史](/guide/web#history)里、**最近关闭**列表里（**Ctrl+Shift+T** 会跳过它们），也不会出现在下次启动浏览器时重新打开的标签页中。你关闭的标签页就彻底没有了。
- **扩展程序不会在其中运行。**广告拦截器和 Cookie 横幅隐藏和在任何标签页里一样工作。
- 网站请求的**权限**（摄像头、位置等）每次都会重新询问，你的回答在标签页关闭时就被忘掉。你在普通标签页里阻止过的网站仍然被阻止。
- **下载的文件会保存**在你的“下载”文件夹里，但不会加入搜索框（Ctrl+K）能找到的下载列表。
- 你主动要求的仍会保留：**书签**、**稍后阅读**、**高亮**，以及**保存**（到项目）。无痕标签页关闭后，它们依然存在，并显示那个页面，所以只有在你对此没问题时才这样做。
- **翻译**在无痕标签页里和在任何标签页里一样工作，所以页面的文字会发给辅助模型（见[翻译网页](/guide/web#translate-a-page)）；如果这点很重要，就不要翻译无痕页面。
- 无痕标签页不能放进分组，**用 AI 为我的标签页分组**也从不计入或发送它。
- **智能体永远得不到无痕标签页。****询问**是灰色的，地址栏的**就这个页面提问**（或**在这个页面上执行**）一行以及右键菜单里的**就“…”问智能体**和**就这张图片提问**都不在，服务器也会拒绝把它的页面复制给智能体（见[把页面交给智能体](/guide/web#hand-a-page-to-an-agent)）。

在开着无痕标签页时关闭最后一个普通标签页，只会留下那些无痕标签页；否则你的浏览器总会留着一个标签页。无痕标签页只管这台电脑自己的记录：你访问的网站、你的网络服务商和你的网络仍然能看到你去了哪里，你登录的网站也知道你是谁。

### 翻译网页

当页面的语言与你阅读的语言不同时，地址栏右边会出现一个翻译按钮（一个小小的**语言**图标）。页面已翻译时它亮着，正在翻译途中会闪动。按它：

- 它会说页面被检测为哪种语言（“检测到：德语”），这是应用在这台电脑上根据页面的字词和它自己的语言标签判断出来的。
- **翻译成**是要翻译成的语言。起初是应用自己的语言；选另一种就会把它记为你的选择（它也是[浏览器设置](/guide/web#browser-settings)里的**翻译成**），已经翻译过的页面会再次翻译成它。
- **翻译**开始翻译。它工作时，下面一行会说“正在翻译…已完成 12/40 个部分”，按钮变成**显示原文**，它会把页面的每个字词恢复成原样。完成后，这一行会说它是从哪种语言、用哪个模型翻译的。如果没能翻译，这一行会说明原因，按钮则变成**重试**。
- **始终翻译德语**（针对检测到的语言）会从此在这种语言的页面一加载就翻译它们。**从不翻译德语**会让按钮不再为它显示。**从不翻译example.com**（页面的网站）对那个网站也一样，不论它是什么语言。
- **翻译设置**会打开[浏览器设置](/guide/web#browser-settings)里的**翻译**。

屏幕上显示的内容先翻译，然后是页面的其余部分，再然后是之后出现的内容，比如你滚动时，或页面自己变化时，所以它一直保持在你的语言里。页面的版式、链接和图片保持原样：只有它的字词被原地改变。文本框、代码，以及网站标明不要翻译的部分都不会动。很长的页面最多翻译到屏幕所显示内容之后大约 150,000 个字符。

你也可以用**菜单**（⋯）→ **翻译网页…**（页面已翻译时是**显示原文**），在按钮不显示时（比如页面已经是你的语言）它会在菜单下面打开同一个框。在页面上右键点击，不要点在链接、图片或选中的字词上，选择**翻译为德语**（你翻译成的语言），或者在页面已翻译时选择**显示原文**。选中一些字词，右键点击，选择**翻译“…”**，只翻译这些字词（最多 5,000 个字符）：一个**翻译**框会显示它们和它们的译文，还有一个**翻译成**的选项可以试另一种语言，以及**复制**。

按钮和列表里的语言名称使用应用的语言，旁边是每种语言自己的名称。

**会发送什么，发给哪个模型。**翻译会把页面的文字分成小块发给应用的辅助模型，也就是写会话标题和记忆笔记的那个模型（[设置 → 智能体 → 模型 → 辅助模型](/settings?s=models&find=Helper%20model)）；你选中要翻译的字词也会发到那里。选“自动”时它是通过 Claude Code 的 Claude Haiku，否则是 Codex，两者都在线；你电脑上自己的模型则把文字留在本机。图片和登录状态从不发送。它发生在你按下**翻译**或菜单项时，以及对你设为**始终翻译**的语言，在每个页面加载时自动进行：如果页面里有你想保密的文字，就不要翻译它（或把你电脑上的模型设为辅助模型）。智能体看不到其中任何内容，它的接口也会拒绝智能体。

翻译过的页面在[阅读视图](/guide/web#reader-view)里也显示为翻译后的样子。

### 阅读视图

在有文章的页面上，比如新闻报道、博客文章或食谱，地址栏右边会出现一个书本按钮（**阅读视图**）。按它，文章就会单独显示在页面上方一个干净的栏里：网站、标题、作者、阅读需要多长时间（“5分钟”）和日期，然后是带着图片的正文，没有网站的菜单、广告和评论。再按一次按钮（**退出阅读视图**）就回到页面，或者选择**菜单**（⋯）→ **阅读视图**，开启时它打着勾。在其中打开链接会退出它，就像前往其他页面一样。没有文章可显示的页面没有这个按钮（菜单项也是灰色的；如果一个页面其实没有文章，会有提示说“此网页没有可在阅读视图中显示的文章”）。

阅读视图开启时，**Aa**（**阅读视图样式**）会打开文章的外观：

- **文字大小**，带有**缩小文字**和**放大文字**：从 14 到 28（起初是 19）。
- **颜色**：**自动**（跟随应用的浅色或深色外观）、**深色**、**浅色**或**棕褐色**。
- **字体**：**衬线**或**无衬线**。

更改会立即生效，并对每篇文章都保留。方向键、**Page Down** 和**空格**键会滚动文章。制作它时没有任何东西离开这个标签页：页面就在原地被阅读，不涉及任何智能体或模型。

### 深色页面

**菜单**（⋯）→ **深色页面**（开启时打上勾），或[浏览器设置](/guide/web#browser-settings)里的**深色页面**，会让网页以深色显示。自带深色外观的网站会使用它，就像你的电脑设为深色时那样；没有的页面则由浏览器自己的自动深色模式变暗，所以它浅色的背景变深、文字变浅。起初它是关闭的，同时作用于所有标签页，并且不影响智能体的浏览器。

有些页面变暗后看起来很怪（图片、图表、本来有含义的颜色）。要让某个网站保持原样，点它的挂锁，关掉**此网站使用深色页面**（深色页面开启时才有这个开关）。这样的网站会列在浏览器设置的**保持原样显示的网站**下，点其中某一个旁边的 × 就会让那个网站再次变暗。

### 稍后阅读

把页面留到有空时再读：右键点页面选**稍后阅读此页面**，或右键点链接选**稍后阅读链接**，也可以用**菜单**（⋯）里的**稍后阅读此页面**。会有提示说“已添加到“稍后阅读””；已经在列表里的页面会重新变成等待阅读，并排到最上面。只有网页（http 和 https）可以留待稍后阅读。

这个列表显示在两个地方：标签页列里的**稍后阅读**（见[标签页列](/guide/web#the-tab-column)），以及页面旁那一列里它自己的面板：**菜单**（⋯）→ **稍后阅读**，或前往[稍后阅读](/browser?panel=later)。面板标题下有一个框，**搜索你的“稍后阅读”列表**，它会把列表缩小到标题或地址里有你输入的字词的页面。最新的在前，每一行有网站的图标、页面的标题，下面是网站和你添加它（“添加于今天”）或把它标为已读的时间。点一行，或点**打开**，会在新标签页中打开那个页面。**标为已读**会把它从列表中去掉；**显示已读**（读过一个之后才显示）会把你读过的页面带回来，用**标为未读**可以让其中一个重新等待阅读，**隐藏已读**会再把它们收起来。**移除**会忘掉它。没有搁置的页面时，面板会说“没有留待稍后阅读的内容”。

和你的书签一样，这个列表只属于你：智能体永远看不到它，也无法访问提供它的接口。

### 历史

按 **Ctrl+H**，或**菜单**（⋯）→ **历史**，或前往[历史](/browser?panel=history)。这个面板按日期（“今天”“昨天”，然后是具体日期）从新到旧列出你在自己的浏览器中访问过的页面，每个都带有时间、网站图标、标题和地址。

- 搜索框**搜索历史记录**按标题和地址中的字词查找页面。
- 点击一个页面会在当前标签页中打开它，或按住 Ctrl 点击（Mac 上按住 ⌘ 点击）在新标签页中打开。旁边的 **×** 会把它从历史中去掉。**显示更早的**会加载更多。
- **最近关闭**（不在搜索时）列出你最近关闭的标签页：点击一个即可重新打开。**Ctrl+Shift+T** 打开最新的那个。
- **清除浏览数据…**会打开设置中的那一部分。

你的历史记录留在这台电脑上，放在应用自己的数据库里，并且只有你自己的浏览才会添加：网页和文件、每个标签页最终停留的页面，以及它稳定下来的标题。[无痕标签页](/guide/web#private-tabs)里的页面从不会添加，你关闭的无痕标签页也不在**最近关闭**里。它会保留最近的 20,000 个页面；最旧的先被删除。智能体永远看不到它。地址栏的[建议](/guide/web#suggestions)就是从它取材的。

要导入你其他浏览器的历史记录，用面板底部的**导入**（不在搜索时才会显示），和书签面板里的一样。它会列出这台电脑上有历史记录的浏览器，和[书签](/guide/web#bring-in-bookmarks)那里列出的是同一批；一个浏览器有多个个人资料时，每个个人资料一行，每行附有会导入的页面数（“8,931 个网页”）。按**导入**，它最近的 20,000 个页面就会进来：每个页面都保留标题、你上次访问的时间、访问次数，以及你输入它地址的次数，所以地址栏的[建议](/guide/web#suggestions)会像那个浏览器一样给它们排序。你已经有的页面保留较晚的那次访问和较大的计数，因此再导入一次不会重复添加任何东西。你的历史记录仍然只保留最近的 20,000 个页面，最旧的先被删除，而且一切都留在这台电脑上：智能体永远看不到它。完成后会有一条提示写着“已导入 8,931 个网页”（或“你的历史记录里已经有全部内容”）；没有可导入的来源时，面板会写“在这台电脑上没有找到其他有历史记录的浏览器。”

会在打开期间锁住历史记录的浏览器会说“请先关闭 Google Chrome，然后重试：它在打开时会锁住历史记录。”；把它关掉，再按一次**导入**。Firefox 可以保持打开。Safari 把它的历史记录放在 macOS 看守的地方，和它的书签一样：在你允许之前，它那一行会写着“Hydor may not read Safari’s history: allow it in System Settings → Privacy & Security → Full Disk Access”。它那一行会显示**打开系统设置**，代替**导入**：它会打开系统设置 → 隐私与安全性 → 完全磁盘访问权限，你在那里打开 Hydor（没有列出时，用 **+** 添加）。你回到 Hydor 时它会再检查一次，然后显示 Safari 的数量和**导入**。如果仍然读不了 Safari，那一行会加上一句“已经允许了？macOS 可能要求先重新打开 Hydor：退出 Hydor，再重新打开。”

你的浏览器下载的文件也保存在一份列表里：每个文件的名称、保存位置和它来自的地址，保留最近的 5,000 个。在勾选**浏览历史记录**的情况下使用**清除浏览数据**，也会清空这份列表，时间范围相同（文件仍留在它们保存的位置）；被删除的页面、书签或下载，也会同时从按含义搜索中消失。搜索框（Ctrl+K）会在**搜索范围**的**浏览器**下，按字词以及按内容大意查找你的历史、书签和下载（见[用 Ctrl+K 搜索一切](/guide/start#search-everything-with-ctrlk)）。智能体看不到其中任何内容。

### 高亮

在页面上标出字词，它们就会一直保持标出。选中一些字词，点右键，选择**高亮**：它们会立刻以柔和的黄色标出（在深色页面上同样清晰），并被保存下来。每次你再次打开那个页面，这些字词都会被找到并标出；如果页面在加载之后才生成内容，稍等片刻还会再标一次。在某处高亮里点右键，选择**移除高亮**就能把它去掉。页面自己的文字不会被改动，只是被包了一层，所以从页面复制文字得到的还是同样的字词。

- 无论地址后面跟着什么，同一个页面都是同一个页面：`#片段` 或跟踪参数（`utm_…`、`fbclid` 之类）都不要紧，`http`、`https` 和 `www.` 算作一个。每条高亮会保留它的字词、它前后的一小段文字（同样的字词出现两次时用来找到正确的位置）、页面的标题、你标出它的时间，以及你添加的备注（如果有的话）。
- 有高亮的页面，**菜单**（⋯）上会显示一个小小的黄色标记，**菜单**（⋯）→ **高亮** 会告诉你有多少条。它会在页面旁边的那一列里打开这个页面的高亮，也可以前往[高亮](/browser?panel=highlights)。**在页面上显示** 会滚动到某一条，**复制** 复制它的字词，**添加笔记**（或 **编辑笔记**）写下一条备注，在页面上用指针指向这条高亮时会显示出来，**删除** 会把它去掉。**就这些询问智能体** 会启动一个会话，其中引用了页面的地址和它的高亮，并带上你的备注。
- 再也找不到的字词（页面变了）会留在列表里，只是不再标出。一条高亮最多容纳 5,000 个字符，一个页面最多 500 条高亮。文本框里的字词，以及页面上隐藏的部分，不会被标出。页面内嵌框架（其中显示的另一个页面）里的字词也不会被标出：在那里菜单中没有**高亮**。页面自己组件里的字词与其他字词一样会被标出。

你的高亮保存在这台电脑上、应用自己的数据库里，智能体永远看不到它们：相关的接口会拒绝智能体。只有当你按下 **就这些询问智能体** 时，它们才会到达智能体，而且送出的只有那个页面的地址和它的高亮。

### 浏览器设置

**菜单**（⋯）→ **设置**，或[设置 → 浏览器 → 你自己的浏览 → 浏览器设置](/settings?s=browser&find=Browser%20settings)，或[浏览器设置](/browser?panel=settings)，会打开一个面板，里面有：

- **主页**：“主页”按钮和新标签页打开的网址（起初是 https://www.google.com/）。**使用当前页面**会把它设为你正在看的页面。
- **搜索引擎**：地址栏用什么来搜索：Google（起初）、DuckDuckGo、Bing、Brave、Ecosia、Startpage，或 **Custom**，即你自己的网址，用 %s 代表你输入的词所在的位置，比如 `https://example.com/search?q=%s`。
- **搜索快捷词**：在地址栏中输入一个快捷词、一个空格和你的字词，就能搜索那个网站。常用的有 `yt`（YouTube）、`wiki`（Wikipedia）、`gh`（GitHub）、`scholar`（Google 学术）、`arxiv`（arXiv）和 `hf`（Hugging Face）。点某一个的 × 会删除它。**添加快捷词**会要你填**快捷词**（一个词）、**名称**和**地址，用 %s 代表你输入的词所在位置**，然后按**添加**（或**取消**）；最多可以有 50 个。你改过列表之后，会出现**恢复常用的**。在地址栏里，`yt lofi` 会最先给出“在 YouTube 中搜索 ‘lofi’”，按 **Enter** 就会这样做；你输入内容的那一行（“使用 Google 搜索”）仍会用你的搜索引擎搜索所有字词。
- **搜索建议**（起初开启）：你在地址栏中输入的内容会边输入边发送给你的搜索引擎，和任何浏览器一样，这样它才能给出搜索建议。Startpage 和自定义网址不提供建议。关闭它，你输入的内容就只留在这台电脑上；你打开的标签页、书签和历史仍会显示。
- **拦截广告和跟踪器**（起初开启），见下文。
- **隐藏 Cookie 横幅**（起初开启；它需要**拦截广告和跟踪器**开着，没有它时是灰色的），见下文。
- **翻译**，用于[翻译网页](/guide/web#translate-a-page)：
  - **翻译成**：页面翻译成的语言。在你选一种之前，它就是应用自己的语言。
  - **为其他语言的网页提供翻译**（起初开启）：在其他语言的页面上，在地址栏里显示翻译按钮。关闭后，按钮只在已经翻译的页面上显示；**菜单**（⋯）→ **翻译网页…**仍然可用。
  - **始终翻译**：这些语言的页面一加载就会被翻译。**添加语言**可以挑选一种；语言上的 × 会把它去掉。
  - **从不翻译**：从不为这些语言显示按钮。一种语言最多在这两个列表之一里。
  - **从不翻译这些网站**：从不为这些网站显示按钮，也从不自动翻译它们（在你用翻译框里的**从不翻译**添加之前是“没有网站”）；网站上的 × 会把它去掉。
  - 一条说明会告诉你翻译会发送什么、发给哪个模型。
- **页面**：
  - **页面缩放**（起初 100 %；50 % 到 200 %）：页面显示多大，除非你自己缩放某个网站。你自己缩放过的网站（Ctrl 加 + 或 −、Ctrl 加滚轮、菜单里的**缩放**），在应用运行期间会保持它的缩放；**重置**（Ctrl+0、菜单里的百分比、地址栏的小标签）会把它恢复为页面缩放（见[缩放、打印和全屏](/guide/web#zoom-print-and-full-screen)）。
  - **检查拼写**（起初开启）：输入时给拼错的词加下划线，并在右键菜单中给出建议。
  - **深色页面**（起初关闭）：没有自带深色外观的页面会以深色显示（见[深色页面](/guide/web#dark-pages)）。
  - **保持原样显示的网站**：你为其关掉**此网站使用深色页面**的网站，带有 ×，可以让某个网站再次显示为深色。
  - **允许网站自动播放声音**（起初关闭）：关闭时，页面的声音要等你在其中点击或输入后才会播放，没有声音的视频仍会播放；开启时，页面可以立即开始播放声音，就像在较旧的浏览器里那样。更改后新打开的标签页才会生效。
- **清除浏览数据**：勾选**浏览历史记录**、**Cookie 和网站数据**（你会退出网站的登录）和**缓存的文件**，选一个时间范围（**过去 1 小时**、**过去 24 小时**、**过去 7 天**或**所有时间**），再按**清除数据**。时间范围只对历史记录（以及随它一起保存的下载列表）有效：Cookie、网站数据和缓存的文件始终会清除所有时间的。

### 拦截广告和跟踪器

你自己的浏览器会像广告拦截器那样拦截广告和跟踪器：它不让已知的广告和跟踪服务器的请求发出去，并隐藏留下的空位。它使用 Ghostery 的广告和跟踪器列表（EasyList、EasyPrivacy 等），应用会在你的浏览器第一次启动时从 GitHub 下载，之后每周更新一次（无法更新时，就沿用已有的列表）；发送这些请求时不会带上任何关于你的信息。它不会拦截智能体的浏览器里的任何内容，在无痕标签页里则会工作。在[浏览器的设置](/guide/web#browser-settings)里关闭**拦截广告和跟踪器**即可把它关掉。

开启时，你的 Chrome 扩展程序仍能看到页面的请求，但拦截或修改请求的扩展程序（你自己的广告拦截器）不会拦截它们；把拦截器关掉，就能让它接手这个页面。

要让某个网站显示它的广告，点击地址栏里的挂锁，再按**允许此网站显示广告**（它的子域名也包括在内）；页面会重新加载。**拦截此网站的广告**会恢复拦截。

**隐藏 Cookie 横幅**（起初开启，在浏览器的设置里，且只在拦截器开着时有效）还会隐藏许多网站显示的 Cookie 提示，用的是加到上述列表里的 EasyList 的相应列表。它隐藏提示，但不替你作答，所以等待你回应的网站可能会扣留部分内容：通过那个网站的挂锁允许它显示广告，就能再次看到它的提示。

### 挂锁

地址栏开头的挂锁显示与网站的连接是否安全（http 页面显示“不安全”，并带一把打开的挂锁）。点击它可以看到这个网站、它的连接是否安全、你为它允许或阻止了什么（每项都带**忘记**，让它再次询问），以及在拦截器开启时，这个页面上拦截了多少广告和跟踪器，并带有**允许此网站显示广告**或**拦截此网站的广告**。在网页上它还有：

- **此网站使用深色页面**，一个在[深色页面](/guide/web#dark-pages)开启时显示的开关：关掉它，就让这个网站保持原样。
- **Cookie 和网站数据**，带有**删除**。它会先询问（“要删除 example.com 的 Cookie 和网站数据吗？其子域名的也会一并删除。你会退出它的登录。”）；按**删除**会删除这个网站的 Cookie 和已存储的网站数据，它的子域名也包括在内（对 `mail.example.com` 来说，是 example.com 的），作用于这个标签页自己的登录状态（无痕标签页的是它自己的），并重新加载页面。会有提示说删除了什么。缓存文件会保留：浏览器设置里的**清除浏览数据**会清除它们，以及每个网站的一切。

### 下载

网页下载的文件会保存在应用所在电脑的“下载”文件夹里，并列在**菜单**（⋯）→ **下载**下面，显示为“正在下载…”“完成”或“失败”，附有它的路径。来自无痕标签页的下载以同样的方式保存，也显示在这里，但不会加入搜索框（Ctrl+K）能找到的列表。点击一个已完成的文件，可以在它的文件夹中查看：桌面应用会打开系统的文件管理器并选中这个文件（**在访达中显示**、**在文件资源管理器中显示**或**在文件夹中显示**；见[处理文件和文件夹](/guide/files-git#work-with-files-and-folders)）。

### 网站请求权限时

当你自己浏览器里的网页请求使用你的摄像头、麦克风、位置、通知、剪贴板之类时，网页上方的一个栏会告诉你（“example.com 想要使用你的摄像头”），带有**不允许**和**允许**。你的回答会为这个网站记住，所以它只会问一次；要查看你允许或阻止了什么，或者想让它再问一次，打开挂锁，或**菜单**（⋯）→ **网站权限**，在某个回答旁按**忘记**。那里智能体的浏览器会自己拒绝所有这类请求，只有铺满屏幕和复制到你的剪贴板除外。在无痕标签页里，这个栏每次都会询问：你的回答在标签页关闭时就被忘掉，你在普通标签页里给过的允许不会带过来（你阻止过的网站仍然被阻止）。网页的弹窗问题（一条提示、一个是或否的问题或一个要求输入文字的提示框）会显示在网页上方，和智能体的浏览器里一样（见[回答网页的弹窗问题](/guide/web#answer-a-pages-pop-up-questions)）。

## 书签

只要书签栏上有书签，那些网站就会固定在标签页列的顶部（手机上没有标签页列；你的书签在菜单里）。点一个，会在当前标签页中打开它；Ctrl+点击（Mac 上是 ⌘+点击）或中键点击，会在新标签页中打开。文件夹会打开一个列表，列出里面的内容，最多显示十个方块（一个 **…** 方块会列出其余的）。右键点一个方块，有**打开**、**在新标签页中打开**、**编辑**（文件夹是**重命名**）和**删除**。

要看全部书签，按**菜单**（⋯）→ **书签**，或前往[书签](/browser?panel=bookmarks)。面板有两处，**书签栏**和**其他书签**，其中的文件夹可以展开和收起。

- **搜索你的书签**（最上面的框）会按字词找到书签（见[搜索你的书签](/guide/web#search-your-bookmarks)）。
- **新建文件夹**（在最上面）会在书签栏中添加一个文件夹，并询问它的名称。
- **用 AI 整理**（最上面的闪光按钮，在**新建文件夹**旁边）会按主题把你的书签整理进文件夹（见[用 AI 整理](/guide/web#organize-with-ai)）。
- 指向一行，会出现**上移**、**下移**、**编辑**（文件夹是**重命名**）和**删除**。你也可以拖动一行：拖到文件夹中间就放进去，拖到行与行之间就放在那里。文件夹不能放进它自己里面。删除文件夹会先询问，并连同里面的内容一起删除。
- 书签的地址以 http://、https://、file:// 或 chrome-extension:// 开头。最多可以保留 20,000 个。

### 搜索你的书签

面板最上面的**搜索你的书签**框，会按你输入的每一个字词，在书签的名称和地址中查找书签（大小写和重音符号都不影响），并按名称查找文件夹。框里有字词时，面板会显示**文件夹**（最多 20 个）和**书签**（最多 200 个），而不是文件夹树，每个书签都会显示它的网站和它所在的位置，比如“书签栏 › Imported from Chrome › Research”。

- 点一个文件夹，就能在你的文件夹中看到它：搜索会清空，文件夹会展开。
- 点一个书签就会打开它；Ctrl+点击（Mac 上是 ⌘+点击）会在新标签页中打开。
- 指向一个书签，会出现**在文件夹中显示**、**编辑**和**删除**。
- **Enter** 打开找到的第一个书签，**Esc** 清空搜索。

### 用 AI 整理

书签很多时，面板最上面、**新建文件夹**旁边的闪光按钮**用 AI 整理**，会按主题把它们整理进文件夹。你也可以在搜索框（Ctrl+K）里搜“用 AI 整理书签”，或前往[用 AI 整理](/browser?panel=bookmarks&organize=1)。它会打开**用 AI 整理你的书签**，你在其中选择方式：

- **保留我的文件夹**（一开始选中的）：你的文件夹和里面的书签保持原样。零散的书签会放进合适的文件夹：你自己的，或一个新的。零散指的是直接在**其他书签**里，或在一个只用来收集书签的文件夹里，比如一次导入产生的“Imported from Chrome”，以及它里面的“Other bookmarks”或“Mobile bookmarks”文件夹（辅助模型会把它们和你自己的文件夹区分开，不论哪种语言）。这样的收集文件夹被整理清空后会被删除（原本就是空的会保留）；其他任何文件夹都不会被删除、重命名或移动。新文件夹放在**其他书签**的末尾，或放在你的某个文件夹里面。
- **重新开始**：每个书签都按主题放进新的文件夹，在**其他书签**里，而你原来的文件夹会被删除。新文件夹在**其他书签**中排在最前面，按名称排序，最多有一层子文件夹；如果某个文件夹里留着模型没能归类的书签，它会保留。

无论哪种方式，固定在你书签栏上的网站（书签栏自己的链接）都留在原处。

**会发送什么，发给哪个模型。**只有在你按下**整理**时，你书签的标题和地址（不带 **?** 或 **#** 后面的内容）以及你文件夹的名称，才会发给应用的辅助模型，也就是写会话标题和记忆笔记的那个模型（[设置 → 智能体 → 模型 → 辅助模型](/settings?s=models&find=Helper%20model)）。选“自动”时它是通过 Claude Code 的 Claude Haiku；你电脑上自己的模型则把它们留在本机。其他任何时候都不会发送任何东西。如果某个书签的标题是私密的，就不要按它（或把你电脑上的模型设为辅助模型）。

它分两步进行：先想出文件夹，再把书签分进去，每次 150 个；几百个书签需要一两分钟。工作时，面板最上面会写“正在规划文件夹…”，然后是“正在整理书签… 150 / 412”，带一个进度条，还有**停止**，它不会改变任何东西。完成后，它会说明做了什么，比如“已将 412 个书签归入 14 个新文件夹。已删除 3 个空文件夹。”，文件夹显示为收起状态，这样新文件夹一眼就能看出来。**撤销**会把每个书签恢复成原来的样子，前提是这之后你没有改动过书签；X 会关闭这条提示。如果失败了，什么都不会改变，**重试**会再次打开它。

智能体不能替你整理书签：你自己的浏览只属于你。问智能体的话，它会告诉你按钮在哪里。

### 导入书签

在面板的**导入**下面，应用会列出这台电脑上有书签的浏览器，每个都附有书签数量：Chrome（和 Chrome Beta）、Chromium、Edge、Brave、Vivaldi、Opera、Firefox，以及仅在 Mac 上的 Arc 和 Safari。有多个个人资料的浏览器，每个个人资料各列一次，以个人资料的名称区分。在其中一个上按**导入**，它的书签会进入书签栏末尾的一个新文件夹，名为“Imported from Chrome”（浏览器有多个个人资料时是“Imported from Chrome (Work)”）。它会保留浏览器自己的文件夹：先是它书签栏上的内容，然后是它的其他书签、移动设备书签和 Firefox 的菜单，作为文件夹，名称与那个浏览器的叫法相同。不是网页的链接（比如 javascript: 链接）和空文件夹会被略去。Firefox 可以保持打开。 在桌面应用中，当 Hydor 在这台电脑上找到其他浏览器时，欢迎导览也会在单独的一页**导入书签和历史记录？**里提供这个功能（参见[开始导览](/guide/app#take-the-tour)）。

你第一次打开“浏览器”页面时，如果 Hydor 在这台电脑上找到其他浏览器，而且还没有向你提供过导入（导览里的那一页也算），页面上方会出现一条横栏，问“从 Google Chrome 和 Firefox 导入书签和历史记录？”，并写出它找到的浏览器。**不用了**会把它关掉，**导入…**会打开**导入书签和历史记录**面板（[导入书签和历史记录](/browser?panel=import)）。这条横栏只在那一次访问时出现；面板则随时都在，位于**菜单**（⋯）→**导入书签和历史记录…**。面板里有一句说明，“书签会进入书签栏末尾的一个新文件夹，历史记录会并入你已有的历史记录。这一切都只留在这台电脑上。”，然后是**书签**和**历史**两个开关（都已打开），以及每个浏览器（和每个个人资料）一行，附有它的书签数和历史记录的页面数，还有**导入**，它会导入已打开的内容，和导览里的那一页一样。已经导入的内容，在这两处都会显示**已导入**。一个也没找到时，会写“在这台电脑上没有找到其他浏览器。”

Safari 把它的书签放在 macOS 看守的地方。在你允许之前，它那一行会写着“Hydor may not read Safari’s bookmarks: allow it in System Settings → Privacy & Security → Full Disk Access”。它那一行会显示**打开系统设置**，代替**导入**：它会打开系统设置 → 隐私与安全性 → 完全磁盘访问权限，你在那里打开 Hydor（没有列出时，用 **+** 添加）。你回到 Hydor 时它会再检查一次，然后显示 Safari 的数量和**导入**。如果仍然读不了 Safari，那一行会加上一句“已经允许了？macOS 可能要求先重新打开 Hydor：退出 Hydor，再重新打开。”

要改为导入一个文件，按**来自文件**，选择从任何浏览器导出的书签文件（一个 .html 文件，最大 20 MB）。它会进入一个名为“Imported bookmarks”的文件夹。

### 导出你的书签

**导入**下面的**导出**会把你所有的书签保存为 `bookmarks.html`，Chrome、Firefox 和 Safari 都可以导入它。

## Chrome 扩展程序

你自己的浏览器可以运行 Chrome 扩展程序：密码管理器、深色模式、翻译工具。按**菜单**（⋯）→ **扩展程序**，或前往[扩展程序](/browser?panel=extensions)。扩展程序在桌面应用自带的浏览器中运行。在其他地方，面板会保存它们并这样说明（“扩展程序在桌面应用自带的浏览器中运行。它们保存在这里，在那边运行。”）。扩展程序带着你的登录状态运行，并能读取它所请求的网站，所以只添加你信任的。

### 添加扩展程序

- **来自 Chrome 应用商店**：在**来自 Chrome 应用商店**下面粘贴扩展程序的链接（一个 chromewebstore.google.com 或 chrome.google.com/webstore 的地址）或它的 ID（32 个 a 到 p 的字母），然后按**添加**。或者在你自己的浏览器中打开这个扩展程序的页面，按顶部栏里的**添加到 Hydor**。应用会从 Chrome 应用商店下载它（向 Google 发出一次请求），并记下它的应用商店 ID。
- **来自文件夹**：按**选择文件夹**（在桌面应用中），或输入文件夹的路径（在其他地方：应用所在电脑上的一个文件夹），用于带有 manifest.json 的未打包扩展程序。它就在原处使用，不会被复制，所以开发者的修改会直接生效。
- **来自你的其他浏览器**：这台电脑上 Chrome、Edge、Brave 和其他基于 Chromium 的浏览器中已安装的扩展程序会列出来，每个带一个复选框。勾选你想要的，按**导入**。已经在这里的会写“已有”，在原浏览器中已关闭的会写“在那边已关闭”。

扩展程序不会自动更新。要获得最新版本，就再从 Chrome 应用商店添加一次；它会替换旧的。

### 关闭或移除扩展程序

面板中的每个扩展程序都显示它的图标、名称和版本，以及一个开关，用来开启或关闭它。**移除**会删除它（文件夹本身的文件会保留）。**选项**会在一个标签页中打开它的选项页面。

扩展程序在工具栏上有按钮时，只要它开着并且已固定，就会显示在地址栏右侧：点击它，会在按钮下面打开它的弹出窗口，按钮上的角标（一个数字或几个字母）显示扩展程序报告的内容。没有固定的扩展程序没有自己的按钮，它们在其他按钮之后的**扩展程序**按钮（拼图块）里。只要至少有一个扩展程序开着，这个按钮就会显示。

- **从菜单里使用扩展程序**：按**扩展程序**，点击某个扩展程序的名称就能使用它，就像点击它的按钮一样。没有自己工具栏按钮的扩展程序也会列出：如果它有选项页面，点击它的名称会打开该页面。
- **固定或取消固定**：这个菜单里扩展程序旁边的图钉（**固定到工具栏**，已固定时是**从工具栏取消固定**）会在工具栏上显示或隐藏它的按钮。已固定时图钉是亮的。固定只改变工具栏：扩展程序无论哪种情况都在运行。
- **扩展程序的更多操作**：它旁边的 **⋮** 有**选项**（有选项页面时）、**关闭**和**移除**（会先询问）。
- 菜单底部的**管理扩展程序**会打开这个面板。
- **在工具栏的按钮上右键**，会出现一个带有它名称的小菜单，然后是**选项**（有选项页面时）、**取消置顶**、**移除**和**管理扩展程序**。
- **固定到工具栏**在面板里也是一个开关，位于每个已开启且有按钮的扩展程序下面。

新的扩展程序一开始是固定的。从 Chrome 导入的扩展程序会保留它们在 Chrome 里的固定状态：你在 Chrome 里固定的，在这里也是固定的，其余的在**扩展程序**菜单里。点击一个没有在此浏览器中运行的扩展程序时，会提示（“… 没有在此浏览器中运行”）。

**也用于智能体的浏览器**一开始是关闭的。开启后，这个扩展程序也会在智能体的、保留登录状态的浏览器中运行，也就是使用个人资料的那些（见[用个人资料保持登录](/guide/web#keep-sign-ins-with-profiles)），而且只有这些。从全新状态开始的浏览器永远不会得到扩展程序。（在服务器上，Chromium 或 Chrome for Testing 会加载它们；Google Chrome 已经不会了。）

### 哪些可能无法使用

桌面应用的浏览器具备 Chrome 提供给扩展程序的大部分功能。扩展程序添加到网页里的内容、弹出窗口、选项页面、保存的设置、消息、角标、通知（显示为系统通知）和闹钟都可以使用；扩展程序对你的标签页所做的事也可以：它能看到你所在的标签页，以及它有权读取的页面的地址和标题；它能打开标签页（像在 Chrome 中一样显示在最前面）、切换到这些标签页、关闭它们，并在它们加载或变化时得到通知。它的下载会像你的下载一样保存，它能读取和设置它有权使用的网站的 Cookie，它为自己创建的后台页面（offscreen）可以运行，它的侧边栏会像弹出窗口一样在它的按钮下面打开。可能无法使用的有：拦截或修改请求（许多广告拦截器靠它）、用账号登录、浏览器的历史记录和书签、标签页分组、扩展程序的键盘快捷键，以及扩展程序添加到右键菜单中的项目（会接受，但从不显示）。扩展程序那一行会说明它请求了哪些，写成类似“有些部分在这里可能无法使用：拦截或修改请求、用账号登录”的一行。这是按扩展程序所请求的来判断的，所以它仍然可能运行良好。

## 把页面交给智能体

智能体永远得不到你自己的浏览器。你可以把其中的一个页面交给它，有两种方式（[无痕标签页](/guide/web#private-tabs)不能交出去：那里的**询问**是灰色的，应用也会拒绝复制它的页面）：**询问**给它一份副本去读，**执行**则给它一个标签页去工作。两者都在栏里的**询问**中，它会在页面旁边打开一列，上面有一个开关，**询问**或**执行**（见[在页面旁提问](/guide/web#ask-beside-the-page)）。它们作用于网站的网页。栏里的输入框按开关所选，用你输入的内容两样都能做：选了**执行**时，它的**就这个页面提问：“…”**一行会变成**在这个页面上执行：“…”**。

### 就这个页面提问

智能体会拿到页面的一份副本，一个包含它的标题、地址、你在上面选中的内容和可读文字（最多 200,000 个字符）的文件，然后开始一个新会话，以你的问题开头，用的是开始页上次用的智能体和模型。回答会显示在页面旁边的那一列，**作为会话打开**会带你过去。智能体碰不到页面，也看不到你的登录状态：它读的是那份副本。先让页面加载完，因为副本就是此刻标签页显示的样子。

### 在页面上执行

在“询问”里选了**执行**时，这一列会问“智能体应该在这个页面上做什么？”，并说明智能体会得到什么。用智能体按钮选 **Claude Code** 或 **Custom**（只有这两个能被限制在浏览器中；应用会拒绝其他的），然后按**开始执行**。你在页面中用**就“…”问智能体**选中的字词，或来自**就这张图片提问**的图片，会随请求一起发出。智能体会得到：

- **属于它自己的一个标签页**，在保留你登录状态的浏览器里，打开在你那个页面的地址：它在那个网站上以你的身份登录。你自己的标签页留在原处。
- **只有那个网站**：别处的网页它打不开。对于这台电脑上的页面，就只有那一个地址。
- **只有浏览器**：没有命令、没有文件、没有网络搜索、没有其他应用、没有记忆，也没有子智能体。这样的会话不能换到另一个智能体上继续，它的分叉仍然被限制在浏览器里。
- **发送前的一次停顿**：和上文一样，在它按下会发送、发布、删除或转账的按钮之前，它会先询问，并且被告知没把握时要问你（见[发送、发布或删除的按钮](/guide/web#buttons-that-send-post-or-delete)）。付款一如既往地由你来做。

智能体的第一条消息会告诉它，你的页面在它的浏览器里打开着，而且它只在那里工作。设置中的浏览器（**供智能体使用的浏览器**）必须是开着的。你按下**开始执行**之后，智能体的标签页会显示在网页的位置，它的对话在旁边（见[工作中的智能体](/guide/web#agents-at-work)）。回到你的标签页后，这个标签页的“询问”会显示那段对话，带有**看它工作**（智能体的标签页再次显示）、**作为会话打开**和**新请求**。

### 收回页面

在拿到你页面的智能体浏览器上，它消息框上方的面板会写着“你的标签页，来自 example.com”，带有**收回**，你看着它时，栏里也有。按它，就会关闭智能体的标签页，并把这个页面作为你的一个新标签页打开在最前面。智能体会被告知“I took the page back: it is mine again”。它的浏览器会随它的最后一个标签页一起关闭，其他情况下则和任何会话的一样，在会话结束时关闭（见[浏览器何时关闭](/guide/web#when-the-browser-closes)）。

## 工作中的智能体

只要有智能体开着浏览器，标签页列就会把它列在**工作中的智能体**下面，每个一行，带着会话的标题和它正在做的事（“正在点击‘Sign in’”“等你处理”“由你操控：智能体在等待”）。这个列表会保持更新，没有智能体开着浏览器时，就没有这一部分。点一行，就会在网页的位置看到那个浏览器：

- 页面显示在那里，上方是智能体的提问，如[接管浏览器来登录、完成验证或付款](/guide/web#take-over-to-log-in-solve-a-check-or-pay)中所述，周围有一圈：它在等你时是琥珀色，由你操控时是蓝色。输入框里显示一个小标签，写着智能体和会话的标题（它的 **×**，**回到你的标签页**，会回去），后面是智能体标签页的地址。
- 智能体工作时，栏里有**停止**，还有**接管**（由你操控时是**交还**）、对你交给它的页面显示的**收回**，以及**打开会话**。在桌面应用中，点一下它的页面就能自己操作；智能体会等待。
- 右边的那一列实时显示会话的对话，带着它的消息框：看它工作、回答它，或给它发消息。**打开会话**和 **×** 在它的顶部。

**Esc**、小标签上的 **×**、**回到你的标签页**，或点一下你的某个标签页，就会回到你自己的标签页；右边的那一列会显示它之前显示的内容，或者关闭。

## 设置浏览器

打开[设置 → 功能 → 浏览器](/settings?s=browser)（“智能体使用的网页浏览器，你可以观看并接管”）。

### 供智能体使用的浏览器

[供智能体使用的浏览器](/settings?s=browser&find=A%20browser%20for%20agents)是该部分标题旁的开关。它为所有智能体开启或关闭浏览器。一旦找到 Chromium，它就会自动开启；找到之前无法开启。关闭时，智能体就得不到浏览器的工具。每个智能体还有自己的**使用浏览器**开关（在[它可以使用什么](/guide/agents#what-it-may-use)下）：关掉它的智能体得不到浏览器的工具，无论这里如何设置。

### Chromium

[Chromium](/settings?s=browser&find=Chromium) 显示正在使用的那个，以及它的版本；它在哪里，看它的 (i)。应用按以下顺序挑选：在桌面应用中，是**桌面应用自带的浏览器**；这台电脑上安装的 Chrome 或 Chromium；应用自己下载的；然后是 Playwright（一个浏览器测试工具）安装的。找到不止一个时，会有一个选择器让你挑选：**找到的最佳选项**，或某个特定的。

桌面应用自带的浏览器不需要下载，也没有路径可显示。它正在使用时，这一行会写“页面显示在应用的窗口中。”，**下载 Chrome**和**显示窗口**不会显示，因为它们对它没有意义。选择另一个 Chromium，它们就会回来。“浏览器”页面（你自己的浏览器）用的是同一个引擎。

一个都没找到时，这一行会说明，并提供把 Chrome for Testing（约 170 MB）下载到应用的数据文件夹的选项：按**下载 Chrome**；进度条会显示进度，如果失败，这一行会说明原因。只要还没有下载的副本，这个按钮就会一直在，即使已经找到了别的 Chromium。

如果 Chrome 自己的沙盒（隔开网页和电脑其余部分的那堵墙）无法在这台电脑上运行，会有一条说明。网页仍然无法访问这台机器的网络，但个人资料最好只用于你需要的网站。

### 显示窗口

[显示窗口](/settings?s=browser&find=Show%20a%20window)一开始是关闭的：浏览器在看不见的地方运行，你在应用里观看它。开启后，它还会在这台电脑的屏幕上打开一个窗口。Playwright 的 headless shell（没有窗口的 Chromium）无法显示窗口，所以用它时这个开关会保持关闭。更改会在浏览器下次启动时生效。正在使用桌面应用自带的浏览器时，没有这一项。

### 禁止网页访问本机及其所在网络

[禁止网页访问本机及其所在网络](/settings?s=browser&find=Keep%20pages%20off%20this%20machine%20and%20its%20network)一开始是开启的。网页无法访问这台电脑或其所在网络中的私有地址（路由器、打印机、本应用），无论是通过实时连接，还是通过之后会指向这类地址的网站名称：每个连接都要经过应用的检查点。经你允许后，会话仍然可以打开它自己的开发服务器（见[让会话打开这台电脑或你所在网络上的网站](/guide/web#let-a-session-open-a-site-on-this-computer-or-your-network)）。关闭后，网页可以访问你的网络，但 Hydor 本身仍然禁止访问。

### 为能看图片的模型提供截图

[为能看图片的模型提供截图](/settings?s=browser&find=Screenshots%20for%20models%20that%20see%20images)一开始是开启的：模型能看图片的智能体，可以查看画上了编号方框的网页。只能读文字的模型总是以文字形式获取网页；关闭这一项后，所有模型都是如此。

### 在已登录的网站上发送前先询问

[在已登录的网站上发送前先询问](/settings?s=browser&find=Ask%20before%20sending%20on%20signed-in%20sites)一开始是开启的。在智能体于它已登录的网站上发送、发布、删除或转账任何东西之前，会先询问你（见[发送、发布或删除的按钮](/guide/web#buttons-that-send-post-or-delete)）。关闭后，智能体在个人资料已登录的网站上，以及在你交给它的页面上，按这类按钮时不再询问。无论哪种情况，付款仍然会停下。

### 网站：仅限这些，禁止这些

在[网站](/settings?s=browser&find=Sites)下面，有两个列表适用于每个会话的浏览器，每行一个网站，比如 example.com（它的子域名也算在内）：

- **仅限这些网站**：只要列表中有网站，浏览器就只打开这些网站上的网页。留空表示任何网站都可以。
- **禁止访问这些网站**：这些网站的任何内容都不会加载。

修改后，该组标题旁会出现**保存网站列表**：按它。你可以粘贴完整的地址：应用只保留网站部分（“<https://www.example.com/page>”会变成 example.com）。每个会话都可以在它浏览器的菜单（**此会话的网站**）中添加自己的网站。

### 用个人资料保持登录

个人资料是一个独立的浏览器文件夹，会在不同会话之间保留登录状态，这样智能体就能在你已登录的网站上工作，而你的密码永远不会到它们手里。你自己的 Chrome 个人资料永远不会被使用。在[个人资料](/settings?s=browser&find=Profiles)下面：

1. 按**新建个人资料**，给它起个名字（比如“工作”或“购物”），然后按**添加**。
2. 会打开一个窗口：“登录网站 · 工作”。输入要登录的网站，比如 github.com/login，然后按**打开**。
3. 像在任何浏览器中一样在网页上点击和输入（在手机上，**键盘**会打开你的键盘），然后登录。用同样的方法打开更多网站。
4. 完成后关闭窗口。登录状态会保留在这个个人资料中。

要使用它，先打开会话的浏览器，然后在**浏览器选项**（⋯）→ **个人资料**下面选择这个个人资料。选择后浏览器会关闭；下次智能体或你打开它时，它会以已登录的状态重新打开，面板上会显示这个个人资料的名称。使用同一个个人资料的会话共享它的登录状态。

列表中的每个个人资料都有**登录网站**（用来登录更多网站），以及一个 **⋯** 菜单，里面有**重命名**和**删除**；删除也会删掉它的登录状态以及浏览器为它保存的一切，并关闭正在使用它的浏览器。还没有任何个人资料时，列表会说明每个会话的浏览器都从全新状态开始，没有登录任何网站。

### 你自己的浏览

在桌面应用中，[设置 → 浏览器](/settings?s=browser)里还有一个**你自己的浏览**组（“‘浏览器’页面：你自己使用的页面，智能体永远拿不到”），有三行，用来打开“浏览器”页面的面板：[书签](/settings?s=browser&find=Bookmarks)（“你自己的，加上这台电脑上其他浏览器的”）、[扩展程序](/settings?s=browser&find=Extensions)（“Chrome 扩展程序，在桌面应用中使用”）和[浏览器设置](/settings?s=browser&find=Browser%20settings)（“主页、搜索引擎、翻译、深色网页、广告拦截器、历史记录，以及清除它保存的内容”）。在其他地方不显示这个组。见[书签](/guide/web#bookmarks)、[Chrome 扩展程序](/guide/web#chrome-extensions)和[浏览器设置](/guide/web#browser-settings)。

## 让智能体使用你的电脑

在桌面应用中（Mac、Windows 和 Linux），智能体还能像坐在电脑前的人一样使用电脑本身：看它的屏幕，在任何应用里使用它的鼠标和键盘（Mac 上的备忘录或日历，Windows 上的记事本或 Excel，Linux 上的“文件”，浏览器够不到的应用）。网站的事它们仍交给浏览器，那样更快也更安全。电脑操控初始为关闭。每个智能体还有自己的**使用电脑**开关（在[它可以使用什么](/guide/agents#what-it-may-use)下）：关掉它的智能体即使在这里已开启，也不能使用电脑。

### 开启电脑操控

打开[设置 → 功能 → 电脑操控](/settings?s=computer)（“智能体能看到你的屏幕，并使用鼠标和键盘，仅限桌面应用”），开启该部分标题旁的[**电脑操控**](/settings?s=computer&find=Computer%20use)开关。然后按你的系统需要：

- **在 Mac 上**，给 Hydor macOS 的两项权限。在[**辅助功能**](/settings?s=computer&find=Accessibility)（macOS 允许使用鼠标和键盘的权限）旁按**允许…**。macOS 会询问是否允许 Hydor 控制这台电脑，然后它的系统设置会打开到**隐私与安全性 → 辅助功能**：在那里开启 **Hydor**。在[**屏幕录制**](/settings?s=computer&find=Screen%20Recording)（macOS 允许查看屏幕的权限）旁按**允许…**，然后在**屏幕录制**（macOS 15 上是**录屏与系统录音**）中开启 **Hydor**。如果 macOS 要求退出并重新打开 Hydor，照做即可：正在运行的智能体会继续工作。macOS 已经给出的权限会显示**已允许**，应用更新后也会保留。如果系统设置里 **Hydor** 是开着的，但设置里仍然显示**允许…**，那个开关属于之前的版本（0.28.1 之前，每次更新后都需要重新给出这些权限）：按**允许…**，它会清除那个开关，然后再次开启 **Hydor**。
- **在 Windows 上**没有需要允许的。以管理员身份运行的程序智能体够不到，屏幕锁定时也一样。
- **在 Linux 上**，它在 X11（Xorg）桌面上工作，需要 Python 3，几乎所有系统都有。Wayland 桌面（如今大多数系统上的 GNOME 和 KDE 都是）不让任何应用查看屏幕或使用其他应用的鼠标和键盘：这个部分会这样说明，并告诉你怎样改为登录 X11 会话（在 Ubuntu 上，登录屏幕上的齿轮 → **Ubuntu on Xorg**）。

如果有什么让电脑操控在这台电脑上无法工作，这个部分顶部的黄色方框会说明是什么（开关关闭时，会有一条说明告诉你智能体无法使用这台电脑）。这个部分在哪里的设置中都有，但只有桌面应用能做到：在别处它会这样说明。

### 智能体在你的电脑上做什么

会话中的智能体第一次想用电脑时，对话中会出现一张卡片询问：“让智能体使用你的 Mac 吗？”（在 Windows 和 Linux 上是“你的电脑”），带有**在此会话中允许**和**暂不**。会话会等你回答，你也会收到通知。允许之后，智能体可以：

- 看屏幕（主显示器，缩小后的画面；其他显示器不会显示）；
- 单击、双击、右键点按、拖移、滚动和移动指针；
- 输入任何语言的文字，按下按键和快捷键，比如 Mac 上的 ⌘C，Windows 和 Linux 上的 Ctrl+C；
- 按名称打开应用，即“开始”菜单或应用菜单中显示的名称。

智能体工作时，屏幕边缘（每个显示器）会亮起一圈光晕，底部的提示写着“有智能体正在使用你的 Mac”（你的电脑）和“按 Esc 停止”。点按会穿过它，它也从不占用键盘。它只给你看：智能体的截图里从来没有它（截图的那一刻它会隐藏，然后回来）。在 Linux 上，它需要一个会合成窗口的桌面，GNOME、KDE、Xfce、Cinnamon 和 MATE 都是；没有的话就没有光晕，托盘图标仍会说明有智能体在工作。

### 看清智能体在你屏幕上指向哪里

智能体移动的是你自己的鼠标指针，它很小，很容易看丢。所以在智能体工作时，会有一个带柔和光晕的大圆环围着指针，颜色和光晕一样，旁边还有一个 **智能体** 标签：

- 指针会用四分之一秒滑到每个位置，而不是直接跳过去，圆环也跟着它走，好让你的眼睛跟得上；
- 它点按的地方会扩散出一圈波纹（右键点按是虚线的一圈，双击是两圈）；它按住按钮（拖移）时，圆环会收紧并跟着拖移走；
- 它输入的文字和按下的键（Ctrl+S、Enter）会在标签旁边短暂显示，滚动时会用箭头显示方向。

圆环是光晕的一部分：点按会穿过它，它从不占用键盘，智能体的截图里从来没有它；在 Linux 上，它也需要一个会合成窗口的桌面。

每一步都会作为一行显示在对话中，附带之后屏幕的小图：点按图片可以放大查看，点按那一行可以看到智能体的完整回答。打开后，图片上会标出这一步操作的位置：点按的地方有一个圆圈（双击是两圈，右键点按是虚线），拖移的路线有一条线，滚动的地方有一个箭头；如果这一步做了几件事，还会标上编号。应用会保留每个会话最近 200 步的图片；一个月没有动过的会话的图片会被删除。

智能体被告知要先看再做，网站交给浏览器，并且绝不输入密码、卡号或验证码，绝不付款、购买或转账：遇到这些，它们会停下来请你自己完成。同一时间只有一个会话使用电脑。

### 让智能体停止使用你的电脑

智能体使用电脑时，光晕和它的提示会显示，应用图标也会说明（在 Mac 上，菜单栏中图标旁会显示 “Agent using your Mac”），它的会话会在消息框上方显示“智能体正在使用你的 Mac”（你的电脑）。要立即停止它：

- 在任何应用中按 **Esc**（在 Mac 上，**⌘⇧Esc** 也可以）。只有智能体在工作时 Esc 才会让它停下，而智能体自己按 Escape（比如关闭一个对话框）不会让它停下；
- 在应用图标的菜单中选择 **Stop**：Mac 上在菜单栏，Windows 上在通知区域，Linux 上在系统托盘（这些菜单是英文的）；
- 或者按会话消息框上方的**停止**，或设置 → 电脑操控中的**停止**。

停止会结束智能体正在做的事，并收回所有会话的许可：想再次使用电脑的智能体会再次用卡片询问你（“你让智能体停止使用你的 Mac。要让它继续吗？”）。关闭**电脑操控**也是一样。

## 问问智能体

- “开启 SearXNG，地址是 <https://searx.example.org>，把它排在搜索提供方的第一位，然后测试一下。”
- “网络搜索不要再用 DuckDuckGo，把它关掉。”
- “让智能体默认获取 50 条搜索结果。”
- “永远不要让浏览器打开 facebook.com 或 tiktok.com。”
- “在这台电脑上用一个窗口显示浏览器，并关闭它的截图。”
- “新建一个名为‘购物’的浏览器个人资料。”（在其中登录网站要由你自己来做，在设置 → 浏览器中。）
- “别再在智能体按下发送或删除之前问我了，在它们已登录的网站上也一样。”（这是设置 → 浏览器 → 在已登录的网站上发送前先询问；要再开启，也用同样的办法）
- “我智能体的浏览器是桌面应用自带的，还是一个 Chromium？”
- “我怎样把我在‘浏览器’页面里正看着的页面交给智能体？”（**就这个页面提问**给它一份副本；**询问**里的**执行**给它一个位于该页面的、属于它自己的标签页）

- “我怎样直接从地址栏搜索 YouTube 或 Wikipedia？”（搜索快捷词：输入 `yt` 或 `wiki`、一个空格和你的字词；**浏览器设置** → **搜索快捷词**里可以添加你自己的）
- “让网页默认显示得大一些，并关掉拼写检查。”（**浏览器设置** → **页面** → **页面缩放**和**检查拼写**）
- “把页面旁边的那一列拉宽一点。”（拖它的左边缘；双击会恢复它的宽度）
- “我的浏览器响应哪些按键？”（**菜单** → **键盘快捷键**）
- “把 example.org/reports 添加到我的书签栏里一个名为‘工作’的文件夹中。”
- “我怎样更改浏览器的搜索引擎或主页？”（在“浏览器”页面的**菜单** → **设置**里：由你来改，智能体改不了）
- “我怎样允许某个网站在我的浏览器里显示广告？”（挂锁里的**允许此网站显示广告**）
- “我怎样清除浏览历史记录和 Cookie？”（**浏览器设置** → **清除浏览数据**；时间范围只对历史记录和随它保存的下载列表有效）
- “为什么地址栏会建议一个我访问过、但里面没有我输入的任何字词的页面？”（开启按含义搜索时，它也会给出内容与你输入的相关的页面）
- “我怎样把标签页放进分组，用 AI 为我的标签页分组会发送什么？”（右键点标签页→**添加到分组**；AI 按钮只在你按下时，把标签页的标题和地址（不含 ? 或 # 之后的内容）发给辅助模型）
- “我怎样重新打开关闭了的标签页？”（**Ctrl+Shift+T**，或历史记录里的**最近关闭**）
- “我怎样在页面上标出字词，之后再找到它们？”（选中，点右键，**高亮**；**菜单** → **高亮** 里有它们）
- “我的浏览器会拦截广告吗？它的列表来自哪里？”
- “无痕标签页会保留什么，又会忘掉什么？”（登录状态、Cookie 和网站数据单独保存，最后一个无痕标签页关闭时被忘掉；它的页面不在历史记录里；下载、书签和你保存的内容仍会保留）
- “把这个页面翻译成英语，并且总是翻译日语页面。”（地址栏里的翻译按钮；**始终翻译**在**浏览器设置** → **翻译**里；页面的文字会发给辅助模型）
- “我怎样不受杂乱内容干扰地读一篇文章，并且用更大的字体？”（地址栏里的书本按钮，然后是 **Aa**）
- “让网页以深色显示，只有一个网站除外。”（**菜单** → **深色页面**，然后是那个网站的挂锁 → **此网站使用深色页面**）
- “我怎样把整个网页保存为图片或 PDF？”（**菜单** → **整个网页的截图**或**另存为 PDF…**；都会保存到“下载”）
- “怎样用 AI 把我的书签整理进文件夹，它会发送什么？”（书签面板里的**用 AI 整理**；你书签的标题和地址（不带 ? 或 # 后面的内容）以及文件夹的名称，只有在你按下**整理**时才会发给辅助模型；**撤销**会把它们恢复原样）
- “怎样找到一个书签？”（书签面板最上面的**搜索你的书签**）
- “我怎样把一个页面留到以后再读，在哪里找到这个列表？”（**稍后阅读此页面**；**菜单** → **稍后阅读**，或标签页下面的“稍后阅读”列表）
- “把这个页面保存到我的 Thesis 项目里。”（**保存**，并在它旁边的 **▾** 中选好 **Thesis**；副本在项目的**文件**里）

- “把我 Chrome 的历史记录导入‘浏览器’页面。”（或者：“为什么我导入不了 Safari 的历史记录？”）
- “我的浏览器里有哪些 Chrome 扩展程序，其中哪些在智能体的浏览器里也会运行？”
- “把 https://chromewebstore.google.com/detail/… 上的扩展程序添加到我的浏览器。”（应用每次都会先问你）
- “工具栏上只留我的密码管理器，其他扩展程序放在扩展程序菜单里。”（**扩展程序**按钮菜单里每个扩展程序旁边的图钉）
- “帮我在 riverside.example.org 上填写借书证申请表，我在旁边看着。”（实时画面中会显示它的指针点击和输入的位置）
- “在我的 Mac 上打开备忘录，新建一条备忘录写下今天的购物清单。”
- “打开记事本，写下今天的购物清单。”（在 Windows 上；它工作时屏幕周围会亮起光晕，它的圆环会显示它指向哪里，按 Esc 就能让它停下）
