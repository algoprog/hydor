# 搜索和浏览器

无论用的是什么模型，应用中的智能体都能搜索网络、阅读网页，并使用真正的浏览器。本主题介绍它们使用的搜索提供方以及怎样设置这些提供方、搜索在对话中显示什么、每条回复下方的来源，还有浏览器：实时观看它，接管它来登录、完成验证或付款，以及它的设置。

## 智能体怎样搜索网络

你在这里运行的每个智能体（Claude Code、Codex、Custom，以及支持 ACP 的智能体）都会从应用获得两个工具：网络搜索，以及阅读网页的方法。无论用什么模型，它们的效果都一样，所以在你自己电脑上运行的小模型，搜索起来也和大模型一样好。

- 搜索会按顺序交给**设置 → 功能 → 搜索**中的提供方。第一个已开启的提供方来回答。它回答不了时（需要密钥、额度用完了、无法连接，或者要求证明搜索不是机器人发起的），就由下一个来回答。回答会告诉智能体是哪个提供方回答的。
- 智能体最多可以要求 100 条结果，还可以把搜索限定在某些网站（或排除某些网站）、某些日期、某些语言、PDF，或网站自己的主页（个人主页、官方网站）。Naget Search 还可以只搜某些类型的网页，比如学术论文、预印本、生物医学论文、美国专利、公司申报文件、新闻、文档或讨论。如果提供方无法遵守某个筛选条件，智能体会得到通知。
- Naget Search 还能为每条结果带回其网页中回答这次搜索的句子，而不是普通的摘要。这样会慢一些，所以智能体只在需要从网页中获取事实时才会这样要求。没有密钥也可以这样做。
- 智能体被要求引用它们用到的网页并附上链接，并把结果和网页里的内容当作信息，绝不当作指令。

失败的提供方会休息一段时间（比如直到它的额度恢复），这样后面的搜索就不必等它。10 分钟内再次提出同样的搜索，会直接得到之前的结果，不会重新搜索。

Claude Code 和 Codex 也有自己的网络工具。它们找到的内容也会列在回复下方（见[查看回复下方的来源](/guide/web#see-the-sources-under-a-reply)）。

## 选择你的搜索提供方

打开[设置 → 功能 → 搜索](/settings?s=search)。在手机上，设置是一个列表：轻点“功能”下的**搜索**。

在[提供方](/settings?s=search&find=Providers)（“从上往下依次尝试。第一个已开启的就是默认项。”）下面，每个提供方各占一行：

- 左边的两个箭头**提前尝试**和**延后尝试**，用来把它在顺序中上移或下移；
- 它的名称，第一个已开启的提供方会带有**默认**；当它按目前的设置无法回答时，会显示**需要密钥**或**需要你的实例地址**之类的警告；
- 一行说明它是什么，以及它能把搜索限定在什么范围，比如“最多 100 条结果 · 分类 · 日期 · 主页 · 页面中给出回答的部分”；
- 如果保存过密钥，会显示密钥的提示（比如“sk-ab…12cd”：绝不会显示密钥本身）；
- 它最近一次的错误，用红色显示，并注明是多久以前；
- 按钮：**添加密钥**（或**更换密钥**）、**设置地址**（或**更改地址**）、**测试**，以及在已开启但不在第一位的提供方上出现的**设为默认**；
- 右边的开关，用来开启或关闭它。

**设为默认**会把这个提供方移到列表顶部。默认的顺序是 Naget Search、SearXNG、Brave Search、DuckDuckGo。Naget Search 和 DuckDuckGo 一开始就是开启的；SearXNG 和 Brave Search 一开始是关闭的，直到你提供它们所需的东西。

### Naget Search

[Naget Search](/settings?s=search&find=Naget%20Search) 是默认的提供方：Naget 自己的网络、论文、专利和申报文件索引。它不需要密钥：没有密钥的搜索会使用每日免费额度。它回答过之后，这一行会显示**今日剩余免费额度**（当天的额度还剩多少）、一个进度条，以及额度何时恢复。额度用完时，这一行会说明这一点，并由下一个提供方回答，直到额度恢复。

来自 naget.com 的密钥能提供更多的搜索次数；有了密钥，这一行会改为显示**剩余额度**。有了密钥，Naget Search 还能在智能体阅读网页时挑出网页中回答问题的部分（见[阅读整个网页，或只读回答问题的部分](/guide/web#read-whole-pages-or-only-the-parts-that-answer-a-question)）；没有密钥时，由应用按词语挑选。搜索结果中回答搜索的句子，没有密钥也能得到。如果这一行显示“Naget Search 目前需要密钥”，说明没有密钥的搜索正被拒绝；在你添加密钥之前，由下一个提供方回答。

它的表单里还有一个**地址**：除非你另行设置，否则是 <https://naget.com>。除非有人给了你另一个地址，否则保持原样即可。

### SearXNG

[SearXNG](/settings?s=search&find=SearXNG) 是一个你自己运行的搜索引擎，它会同时询问许多搜索引擎，并且不保留任何关于你的记录。它不需要密钥，只需要你的实例地址：按**设置地址**，输入地址（比如 <https://searx.example.org>），然后按**保存**。给它设置地址就会开启它。它最多返回 100 条结果。

### Brave Search

[Brave Search](/settings?s=search&find=Brave%20Search) 通过 Brave 的 Search API 搜索 Brave 自己的独立索引。它需要密钥；Brave 有免费套餐。**添加密钥**会显示一个链接：**在 api-dashboard.search.brave.com 获取**。添加密钥就会开启它。它最多返回 100 条结果。

### DuckDuckGo

[DuckDuckGo](/settings?s=search&find=DuckDuckGo) 不需要密钥，一开始就是开启的，排在列表最后，作为最后的备选。它每页大约返回 10 条结果（最多 30 条），而且可能会要求证明搜索不是机器人发起的；这时如果还有下一个提供方，就由它来回答。

### 添加或更改密钥或地址

1. 在提供方那一行，按**添加密钥**（或**更换密钥**、**设置地址**、**更改地址**）。
2. 把密钥粘贴到**密钥**下面（它会显示为圆点），或者输入**地址**。对于 Naget Search，密钥会标注“可选，用于更多搜索”。
3. 按**保存**。**取消**会关闭表单，一切保持原样。

给提供方提供它所需的密钥或地址，就会开启它。密钥保存在服务器上：页面上只会显示密钥的提示。要删除已保存的密钥，打开表单并按**移除已保存的密钥**。

### 测试提供方

在某一行上按**测试**。应用会只用这个提供方做一次小搜索，不会退回到下一个提供方，而且即使你还没保存，也会用你在它表单里输入的内容。你会看到“可用：”、结果数量和用时，以及前三条结果的链接，或者失败的原因。测试已保存的提供方时，一旦它恢复正常，也会清除它之前的错误。

### 每次搜索的结果数

[每次搜索的结果数](/settings?s=search&find=Results%20per%20search)设置智能体没有指定数量时一次搜索返回多少条结果：**10**、**20**（默认）、**50** 或 **100**。智能体仍然可以要求更多，最多 100 条，用于更深入的搜索，比如查找论文。结果越多，智能体要读的内容就越多。

页面底部有一条说明，提醒你搜索结果和网页都是外部数据，并附有链接，介绍开发者如何添加其他提供方。

### 没有提供方能回答时

如果每个已开启的提供方都失败了，智能体会得知每个提供方失败的原因，并被要求告诉你：可以在设置 → 搜索中添加密钥，或开启另一个提供方。如果你关闭了所有提供方，智能体就完全无法用应用的搜索来搜索网络了。

## 查看搜索找到了什么

智能体的步骤会折叠成它消息之间的一行，比如“已搜索 4 次”（在这里，网络搜索和读过的网页都算作搜索）。展开它就能看到每一步。一次搜索显示为“已搜索网络‘2000 欧元以下的电动自行车’”，右边是回答它的提供方和结果数量（在手机上只显示数量）。搜索进行时显示“正在搜索网络”，并带有计时器；失败的搜索显示“网络搜索失败”。

点击一次搜索即可展开：

- 它用到的筛选条件（某个网站、日期、某个类别……），以小标签显示；当智能体要求获取回答问题的句子时，会显示“能回答它的部分”；
- 说明，比如某个提供方无法回答、改由哪个提供方回答了，或者提供方无法遵守的某个筛选条件；
- 结果，按智能体看到的顺序编号：标题（一个链接）、网站、日期、表示网页类型的标签（论文、arXiv、PubMed、专利、SEC 申报文件、文档……）、PDF 标签，以及摘要或回答这次搜索的句子。每条都有一个打开按钮（↗）。

前 8 条结果会显示出来；**显示全部 N 个结果**会显示其余的。

## 查看回复下方的来源

如果智能体在给出回复的过程中搜索了网络或阅读了网页，回复下方会有一个小小的**来源**标签：“来源 · 已读 3 个网页 · 2 次搜索”，在较宽的屏幕上还会写出前几个网站的名称。点击它会打开两个列表：

- **已读网页**：每个网页的标题（或地址）作为链接、它所在的网站，以及智能体对它提出的问题（如果有）。
- **搜索记录**：每次搜索的词语、提供方和它返回了多少条结果，以及排名靠前的结果所在网站的链接。

它列出智能体用应用的搜索和网页阅读找到的内容，也包括用 Claude Code 和 Codex 自己的网络工具找到的内容：每条回复最多 12 次搜索和 20 个网页。

## 阅读整个网页，或只读回答问题的部分

摘要不够用时，智能体会阅读网页。它可以读整个网页：长网页会分成每部分大约 3,000 词，智能体需要时再要下一部分。它也可以向网页提一个问题，只取回能回答这个问题的部分，这样要短得多。

- 开启 Naget Search 并添加了它的密钥后，由 Naget Search 挑出网页中回答问题的句子。这一步会说明保留了网页中的多少词。与回答搜索的句子不同，这需要密钥。
- 否则，由应用挑出与问题共有词语最多的段落，并告诉智能体：如果这些段落没有包含答案，就阅读整个网页。

PDF 也会当作文字来读。只有公开的网页能这样读：这台电脑或其所在网络上的地址不行（经你允许后，[浏览器](/guide/web#the-browser-agents-use)可以打开它们）。网页只获取一次，并保留 10 分钟，所以它的下一部分会立即送到。

在对话中，一次阅读显示为“已读取”加上网页标题，在较宽的屏幕上还会显示对它提出的问题。点击它可以看到地址、读的是哪一部分（“第 1 部分，共 3 部分”）或是“能回答问题的部分”，以及智能体得到的文字。

## 智能体使用的浏览器

有些网站需要点击、填表、登录或运行脚本，普通的读取无法通过。对于这些网站，智能体有一个浏览器：一个真正的 Chromium（Chrome 所基于的开源浏览器），运行在应用所在的电脑上，与你自己的浏览器分开。你可以实时观看它，并随时接管。

开启浏览器后，每个智能体都可以：

- 在当前标签页或新标签页中打开网页，并运行网页的脚本；
- 以大纲的形式查看网页：它的文字，以及编了号的链接、按钮和输入框；
- 点击、双击、指向、在输入框中输入（替换其中的内容，或在后面追加，并按 Enter）、从列表中选择、滚动、按键、后退和等待：一次最多 10 步，网页一有变化就提前停下；
- 用你保存在保险库中的登录信息登录：它按名称把密码（或其他密钥）输入到网页中，自己却看不到，而且只在你为它允许的主机的网页上这样做（见[把密钥存放在保险库中](/guide/connections#keep-keys-in-the-vault)）；
- 当它的模型能看图片并且开启了截图时，查看画上了编号的截图；
- 在网页上查找文字、分段阅读它的文字，或者让辅助模型根据长网页回答问题（见[智能体、账户和模型](/guide/agents-models)）；
- 列出、切换和关闭标签页；
- 把会话文件夹中的文件附加到网页的上传栏（其他地方的文件都不行）；
- 把浏览器交给你。

有些事情始终由你来做：

- **没有保存登录信息的登录、验证，以及智能体没有把握的任何事。** 智能体被要求把这些交给你，而不是自己尝试，验证码（确认你是真人的检查）和发给你的验证码也包括在内。如果一项任务以后还要在你不在时再次登录，比如定时任务，智能体可能会改为用卡片向你要这组登录信息，存进保险库。
- **付款和下单。** 智能体绝不会按下会付款或下单的按钮（Pay、Buy now、Place order、Subscribe now、Donate、Book now、带有银行卡字段的表单的提交按钮……）。它会停下来，请你自己完成。
- **你输入的内容。** 密码、卡号、安全码和一次性验证码的值永远不会显示给智能体，你在操控浏览器时输入的任何内容也不会。地址中类似密码的部分也会对它隐藏。智能体用保险库中的内容填写的输入框会显示圆点，智能体只会得知它已填好。
- 网页提出的**弹窗问题**（见[回答网页的弹窗问题](/guide/web#answer-a-pages-pop-up-questions)）。

每个会话都有自己的浏览器。没有个人资料时，它从全新状态开始，没有登录任何网站，关闭后什么都不保留。有个人资料时，个人资料登录过的网站它都是已登录状态（见[用个人资料保持登录](/guide/web#keep-sign-ins-with-profiles)）。

## 实时观看浏览器

会话的浏览器打开时，消息框正上方会有一个面板。它显示网页的标题（或“空白页”），下面是智能体正在做什么（“正在点击‘Sign in’”“正在向‘Search’中输入”）、它使用的个人资料，以及打开了多少个标签页。有事等你处理时，它会显示“等你处理”；你在使用浏览器时，它显示“由你操控：智能体在等待”。

在电脑上：

- 折叠时，面板左侧会显示网页的实时小画面。点击它、标题或箭头（**显示实时画面**）即可展开实时画面；**隐藏实时画面**会再次把它折叠起来。
- **全屏**会让浏览器覆盖整个应用；**退出全屏**会带你回来。
- **接管**让你自己使用浏览器（见下文），**浏览器选项**（⋯）会打开它的菜单。

在手机上，轻点面板即可全屏打开浏览器；× 会关闭它。

实时画面是网页的图片，你观看时每秒会发送好几次。在第一张图片到来之前，它会显示“正在连接浏览器…”。

智能体在浏览器中的每一步也会显示在对话中，和它的其他步骤排在一起，显示为一行（“已打开 github.com”“已点击 [12] 按钮‘Sign in’”“向你提问：登录 GitHub”），后面附有一张这一步之后网页的小图。点击这一行可以看到大图和智能体的完整回答。应用会保留每个会话最近 400 步的图片；一个月没动过的会话，其图片会被删除。

## 接管浏览器来登录、完成验证或付款

当智能体需要你在浏览器中操作时，你会同时在好几个地方得到通知：

- 浏览器面板顶部的一行提示，带有相应的按钮；
- 对话中的一张卡片，比如“需要你在浏览器中操作：登录 GitHub”，带有**显示**（在手机上是**打开**）；
- 一条通知（就像会话需要你回答时那样），以及[收件箱](/inbox)中的一项（见[收件箱和通知](/guide/inbox)）。

在电脑上，遇到登录、付款或弹窗问题时，实时画面会自动展开，处理完后再次折叠（除非是你自己打开的）。

### 在电脑上

1. 按那一行（或面板）上的**接管**。面板会显示“由你操控：智能体在等待”，实时画面会加上彩色边框。
2. 像在任何浏览器中一样使用网页：点击、用滚轮滚动、输入。先在网页里点一下；之后你的按键都会发送到网页（应用自己的快捷键暂停使用），粘贴的内容会作为文字输入。
3. 你操控时，网页上方会有一个栏，里面有**返回**、**重新加载**和地址：输入一个地址并按 Enter 即可前往。
4. 完成后，按那一行上的**完成**。应用会告诉智能体你已经完成，并附上浏览器现在显示的网页，智能体就会继续。

### 在手机上

1. 轻点**接管**。浏览器会全屏打开，在你操控期间，网页会按手机屏幕排版。带有**返回**、**重新加载**和地址的栏在它上方。
2. 轻点即点击，拖动即滚动。**输入**会打开手机键盘；旁边那一行有 Tab、Enter、Esc、⌫ 和方向键。
3. 完成后轻点**完成**。网页会恢复正常大小，智能体会继续。

### 付款和下单

当智能体遇到会付款或下单的按钮时，它会停下来：“在付款或下单前停下了：shop.example.com 上的 Place order。这一步要由你来完成。”接管浏览器，检查订单，自己付款，然后按**完成**。如果你不打算继续，就按**暂不**。无论哪种情况，智能体都会知道你选了哪个。

### 其他回答，以及主动接管

- **做不到**会告诉智能体，你没能完成它请求的事。
- 你随时都可以接管，不必等它请求：按面板上的**接管**。智能体会等待；如果它在此期间试图使用浏览器，会被告知浏览器在你手上，等你用完时它会收到通知。按**交还**把浏览器还给它；如果智能体正在等浏览器，它会收到一条消息，里面有浏览器当前显示的网页。

应用替你发给智能体的消息会显示在对话中。如果智能体正处在一轮对话中间，这些消息会等到这一轮结束。

## 回答网页的弹窗问题

当网页弹出一个对话框（一条提示、一个是或否的问题、一个要求输入文字的提示框，或“要离开此页面吗？”）时，它会显示在实时画面上方：网站、“说”（或“询问是否离开”），以及那条消息。只有你能回答它：**确定**或**取消**（要求输入文字时会带一个输入框），或者**离开**或**留下**。如果是智能体的某一步打开了它，你会收到通知，智能体也会知道你是怎样回答的。

## 让会话打开这台电脑或你所在网络上的网站

开启[禁止网页访问本机及其所在网络](/settings?s=browser&find=Keep%20pages%20off%20this%20machine%20and%20its%20network)时（一开始就是开启的），网页无法访问这台电脑或其所在网络中的其他设备。当智能体想打开其中某个地址时，比如在这台电脑上运行的、你正在搭建的网站（开发服务器），它会先询问：“想要打开本机或其网络中的 localhost:3000”，并提供**不允许**和**在此会话中允许**两个选项。允许之后，这个会话的浏览器从此就可以打开那个地址，智能体也会被告知再打开一次。

你在操控时自己输入的、这台电脑或其所在网络上的地址，也会以同样的方式在这个会话中获得允许。浏览器菜单中的**此会话的网站**会在“允许访问本机或其所在网络”下面列出你允许过的地址；点旁边的 × 即可撤销。Naget Agent 本身永远无法从浏览器中打开。

## 浏览器的菜单

面板上的**浏览器选项**（⋯）会打开一个菜单：

- **标签页**（打开了不止一个时）：选择一个即可显示它。当网页在新标签页中打开链接时，智能体会在那里继续。
- **已保存在会话的文件夹中**：浏览器最近下载的文件；选择一个即可打开。
- **个人资料（换成其他个人资料会重启浏览器）**：**全新，未登录任何账号**，或你的某个个人资料。你创建过个人资料后才会有这一项。选择另一个会关闭浏览器；下次使用时，它会以新的个人资料打开。
- **此会话的网站**：这个会话的浏览器只能访问的网站（**仅限这些网站**，留空表示任何网站都可以）和它绝不访问的网站（**禁止访问这些网站**），每行一个。它们是在设置 → 浏览器中的列表之外另加的。按**保存**来保留它们。
- **关闭浏览器**。

## 自己打开浏览器

你可以在智能体之前先打开会话的浏览器，比如在让它去某个网站工作之前，先登录那个网站。打开会话的菜单（⋯）→ **更多** → **打开浏览器**。面板会出现在消息框上方：按**接管**即可使用。如果浏览器已经打开，同一项会显示为**显示浏览器**。如果浏览器在设置中被关闭了，你会收到提示。

## 下载和上传

网页下载的文件会保存在会话文件夹中一个名为 downloads 的文件夹里，智能体会被告知它们的位置。浏览器菜单会在**已保存在会话的文件夹中**下面列出最新的文件。

智能体只能把会话文件夹中的文件附加到网页的上传栏。要让它上传别的文件，先把文件复制到那个文件夹（见[文件、Git、终端和预览](/guide/files-git)）。

## 浏览器何时关闭

会话的浏览器会在以下情况下自动关闭：

- 15 分钟内没有人使用或观看它时；如果它在等你，或者正由你操控，则是两小时；
- 它的最后一个标签页关闭时；
- 会话的智能体停止运行，或会话被删除时；
- 你为它选择了另一个个人资料，或删除了它正在使用的个人资料时。

仍在等你处理的事情也会随之结束。智能体下次需要时会再次打开浏览器。

## 设置浏览器

打开[设置 → 功能 → 浏览器](/settings?s=browser)（“智能体使用的网页浏览器，你可以观看并接管”）。

### 供智能体使用的浏览器

[供智能体使用的浏览器](/settings?s=browser&find=A%20browser%20for%20agents)为所有智能体开启或关闭浏览器。一旦找到 Chromium，它就会自动开启；找到之前无法开启。关闭时，智能体就得不到浏览器的工具。

### Chromium

[Chromium](/settings?s=browser&find=Chromium) 显示正在使用的那个，以及它的版本和位置。应用按以下顺序挑选：这台电脑上安装的 Chrome 或 Chromium、应用自己下载的，然后是 Playwright（一个浏览器测试工具）安装的。找到不止一个时，会有一个选择器让你挑选：**找到的最佳选项**，或某个特定的。

一个都没找到时，这一行会说明。按**下载 Chrome** 把 Chrome for Testing（约 170 MB）下载到应用的数据文件夹；进度条会显示进度，如果失败，这一行会说明原因。只要还没有下载的副本，这个按钮就会一直在，即使已经找到了别的 Chromium。

如果 Chrome 自己的沙盒（隔开网页和电脑其余部分的那堵墙）无法在这台电脑上运行，会有一条说明。网页仍然无法访问这台机器的网络，但个人资料最好只用于你需要的网站。

### 显示窗口

[显示窗口](/settings?s=browser&find=Show%20a%20window)一开始是关闭的：浏览器在看不见的地方运行，你在应用里观看它。开启后，它还会在这台电脑的屏幕上打开一个窗口。Playwright 的 headless shell（没有窗口的 Chromium）无法显示窗口，所以用它时这个开关会保持关闭。更改会在浏览器下次启动时生效。

### 禁止网页访问本机及其所在网络

[禁止网页访问本机及其所在网络](/settings?s=browser&find=Keep%20pages%20off%20this%20machine%20and%20its%20network)一开始是开启的。网页无法访问这台电脑或其所在网络中的私有地址（路由器、打印机、本应用），无论是通过实时连接，还是通过之后会指向这类地址的网站名称：每个连接都要经过应用的检查点。经你允许后，会话仍然可以打开它自己的开发服务器（见[让会话打开这台电脑或你所在网络上的网站](/guide/web#let-a-session-open-a-site-on-this-computer-or-your-network)）。关闭后，网页可以访问你的网络，但 Naget Agent 本身仍然禁止访问。

### 为能看图片的模型提供截图

[为能看图片的模型提供截图](/settings?s=browser&find=Screenshots%20for%20models%20that%20see%20images)一开始是开启的：模型能看图片的智能体，可以查看画上了编号方框的网页。只能读文字的模型总是以文字形式获取网页；关闭这一项后，所有模型都是如此。

### 网站：仅限这些，禁止这些

在[网站](/settings?s=browser&find=Sites)下面，有两个列表适用于每个会话的浏览器，每行一个网站，比如 example.com（它的子域名也算在内）：

- **仅限这些网站**：只要列表中有网站，浏览器就只打开这些网站上的网页。留空表示任何网站都可以。
- **禁止访问这些网站**：这些网站的任何内容都不会加载。

修改后按**保存网站列表**。你可以粘贴完整的地址：应用只保留网站部分（“<https://www.example.com/page>”会变成 example.com）。每个会话都可以在它浏览器的菜单（**此会话的网站**）中添加自己的网站。

### 用个人资料保持登录

个人资料是一个独立的浏览器文件夹，会在不同会话之间保留登录状态，这样智能体就能在你已登录的网站上工作，而你的密码永远不会到它们手里。你自己的 Chrome 个人资料永远不会被使用。在[个人资料](/settings?s=browser&find=Profiles)下面：

1. 按**新建个人资料**，给它起个名字（比如“工作”或“购物”），然后按**添加**。
2. 会打开一个窗口：“登录网站 · 工作”。输入要登录的网站，比如 github.com/login，然后按**打开**。
3. 像在任何浏览器中一样在网页上点击和输入（在手机上，**键盘**会打开你的键盘），然后登录。用同样的方法打开更多网站。
4. 完成后关闭窗口。登录状态会保留在这个个人资料中。

要使用它，先打开会话的浏览器，然后在**浏览器选项**（⋯）→ **个人资料**下面选择这个个人资料。选择后浏览器会关闭；下次智能体或你打开它时，它会以已登录的状态重新打开，面板上会显示这个个人资料的名称。使用同一个个人资料的会话共享它的登录状态。

列表中的每个个人资料都有**登录网站**（用来登录更多网站）、铅笔图标（**重命名**）和垃圾桶图标（**删除**）；删除也会删掉它的登录状态以及浏览器为它保存的一切，并关闭正在使用它的浏览器。还没有任何个人资料时，列表会说明每个会话的浏览器都从全新状态开始，没有登录任何网站。
