# 智能体

智能体是会话以之工作的身份：它的指令、它可以使用什么、在哪里和何时工作、思考所用的模型档位、它把工作交给哪些其他智能体，以及它每月可以花多少钱。本主题介绍智能体页面、应用自带的智能体、通过说出它该做什么来创建你自己的智能体、修改智能体、智能体在哪里工作、它的定时运行、档位、把工作交给其他智能体的智能体、每月预算、以某个智能体开始和切换会话、导入 Claude Code 的智能体文件、没有选择文件夹时会话得到的任务文件夹，以及让智能体在任务完成后清理。

![智能体页面：你的智能体各占一张卡片，显示它的状态，下面是内置智能体](images/agents.webp)

## 什么是智能体

开始会话时，你在开始页上选择一个智能体，之后也可以在会话的消息框里换成另一个。它的指令会叠加在程序自身的指令之上，所以同一个程序在这次会话里是严谨的研究员，到下一次会话就可以是耐心的辅导老师。智能体适用于所有程序：Claude Code、Codex、Custom（应用自带的智能体），以及使用 ACP（Agent Client Protocol，智能体客户端协议）的智能体，例如 Gemini CLI 或 OpenCode。

一个智能体可以包含：

- **指令**：它是谁、怎样工作。它会被要求始终按这种方式工作，但你在对话中提出的要求优先。
- **在哪里工作**：所有地方，或只在你的某些项目中（见[智能体在哪里工作](#where-an-agent-works)）。
- **何时工作**：你或其他智能体请求时，以及按它自己的定时运行（见[智能体何时工作：定时运行](#when-an-agent-works-schedules)）。
- **思考使用**：自动，或一个档位（快速、标准或最佳），每个档位对应的模型由你为每个程序设定一次（见[智能体用什么思考：档位](#what-an-agent-thinks-with-tiers)）。
- **它的团队**：它可以把部分工作交给的其他智能体，以及其他智能体能否把工作交给它（见[把工作交给其他智能体的智能体](#agents-that-hand-work-to-other-agents)）。
- **每月预算**：它的会话在一个月内可以花多少钱（见[每月预算](#a-monthly-budget)）。
- **它交回什么**：每个结果的字段（会经过检查），以及每个结果送往何处：文件、资料库、webhook、通知（见[智能体交回什么](#what-an-agent-hands-back)）。
- **它自己的对话**：它可以保持一个对话，带一个收件箱，接收来自你和其他智能体的消息，它的定时运行也发到这个对话里（见[有自己对话的智能体](#an-agent-with-a-conversation-of-its-own)）。
- **它可以使用什么**：读取文件、创建和修改文件、运行命令、使用网络，以及其他工具。可以全部开着，也可以关掉其中一些。
- **优先使用的技能**：当这些技能适合任务时，它会在开始前先加载（见[技能](/guide/skills)）。
- **连接**：在它的会话中要开启的已连接账户（见[已连接的应用、密钥和工具](/guide/connections)）。
- **建议的程序、模型和权限模式**：在开始页上选中它时会一起选上，开始之前你仍然可以更改。
- **它的会话从哪里开始**（没有选择文件夹时）：一个属于会话自己的新任务文件夹，或开始页上显示的文件夹。

智能体是会话所扮演的角色。至于所有智能体都应该遵守的文字，比如你希望它们怎样和你说话，无论是适用于所有会话、某个项目还是某一个会话，都应该写进[智能体准则](/guide/guidelines)。在 0.37.0 版本之前，智能体叫作助手；它们是同一样东西，只是现在能做的更多。

## 智能体页面

在侧边栏中打开**智能体**，或前往 [/agents](/agents)。在手机上，侧边栏是一个抽屉：先把它打开。

- 顶部的**新建智能体**用来创建一个（见[创建智能体](#make-an-agent)）；**导入**用来导入 Claude Code 的智能体文件（见[导入 Claude Code 的智能体文件](#import-claude-codes-agent-files)）。
- 你的智能体以卡片显示。每张卡片上有智能体的名称、一句话介绍、它的状态（**工作中**；它的某个会话在等你回答时为**需要你处理**；**预算已用完**；或**空闲**）、它工作的项目（或**所有地方**）、它的档位、下次运行的时间、收件箱里等待的消息数，以及本月花费。
- 卡片上方的筛选按钮有**全部**、**所有地方**、每个拥有自己智能体的项目、**有定时运行**和**需要你处理**。
- 应用自带的智能体在**内置**下面。

点击一张卡片，打开这个智能体自己的页面：

- 用几句话写出它的设置，例如“工作范围：所有地方，每个工作日 09:00，思考使用快速。”点击任何带下划线的文字，就能在原地修改（见[修改智能体](#change-an-agent)）。
- **开始会话**会打开开始页，并选中这个智能体（如果它只在一个项目中工作，也会选中那个项目）。
- **所有设置**会在编辑器中打开它的全部设置（见[所有设置](#all-settings)）。**创建副本**会复制一份供你修改；**删除**会删除你自己的智能体。
- **定时运行**列出以它运行的定时任务，并有**添加定时运行**。
- **收件箱**，适用于保持自己对话的智能体：它的消息及回复、一个给它发消息的输入框，以及**它的对话**（见[有自己对话的智能体](#an-agent-with-a-conversation-of-its-own)）。
- **它交回的结果**，适用于为结果设了字段或去处的智能体：它最近的结果，每个都写明送到了哪里（见[智能体交回什么](#what-an-agent-hands-back)）。
- **本月**：以它开始了多少个会话、花了多少钱（设有预算时与预算对比）；以及它的**最近的会话**，每个都能打开对话。

## 内置智能体

应用自带八个智能体。它们都不会建议程序、模型、档位或权限模式，所以会沿用你在开始页上的选择；它们也都不限制能用什么或花多少。除程序员外，其他智能体在没有指定文件夹时，都会让会话在一个新的任务文件夹中开始（见[任务文件夹](#task-folders-where-a-task-without-a-folder-works)）。你不能修改或删除它们，但可以复制一个，再修改副本（见[复制或删除智能体](#duplicate-or-delete-an-agent)）。

### 通用

“什么都能帮：问题、写作、规划、文件。”在你选别的助手之前，开始页默认选的是通用。它是为不一定懂编程的人写的。

- 它会弄清你想要什么，然后去做。只有当请求不清楚、而且会影响结果时，它才会问一个简短的问题；否则它会做出合理的选择，并说明选了什么。
- 遇到有时效性的内容或它没把握的事，它会上网搜索；它会阅读你指给它的文件，并把你会想保留的成果存成会话文件夹中的文件；如果是你会反复使用的页面，比如追踪表或计算器，就存到你的[资料库](/guide/library)中。
- 它先给出答案，再讲重要的细节，用浅白的话，遇到避不开的专业术语会加以解释。
- 如果创建或修改了文件，它最后会说明是哪些文件、放在哪里。

### 研究员

“查找并核实来源，并注明出处。”

1. 它会用一句话复述你的问题，把宽泛的问题拆成几个需要回答的子问题。
2. 下结论之前，它会广泛搜索：换不同的说法做多次网络搜索，在合适的搜索类别中查找（论文、新闻、专利、公司公告、数据集），需要全面覆盖一个主题时会获取更多结果。
3. 它会阅读重要的来源，而不是只凭摘要片段回答，并优先采用一手和权威的来源：原始论文和数据、官方网站、公认的专家和媒体。它会记下每个来源的日期；如果事实会随时间变化，它会说明答案的时效。
4. 来源之间有分歧时，它会指出来，并按质量和新旧加以权衡，同时把已有定论的、有争议的和未知的内容区分开。
5. 它边写边注明出处：每个说法后面加一个编号标记，如 [1]，并在末尾列出来源，包括标题、作者或出版方、日期和链接。它从不编造来源、引文、数字或链接；有无法核实的内容时，它会如实说明。
6. 它先用简短的摘要给出结论，然后是细节，最后是仍不确定的地方。长篇报告还会另存为会话文件夹中的 Markdown 文件。

对于需要大量搜索的大问题，请参阅[深度研究、第二意见和多个智能体](/guide/research)中的深度研究。

### 撰稿人

“起草、编辑并润色你的文字”：电子邮件、信件、帖子、文章、报告、故事和演讲稿。

- 写长篇之前，它会先确认读者、目的、语气和篇幅。其中某一项不清楚又很重要时，它会简短地问一下；否则就用一句话说明它的假设，然后动笔。
- 它写得平实而具体：用词具体，要点先行，句式有变化，不说空话套话。
- 它会采用你要求的风格；如果你分享过以前写的东西，它会贴合你自己的风格。
- 修改你的文字时，它会保留你的意思和风格：改正错误，收紧松散之处，保留写得好的部分，并简要列出主要改动。
- 超过几段的内容都会存成会话文件夹中的文件（默认是 Markdown，除非你想要别的格式），并告诉你存在哪里。
- 遇到重要的选择（邮件主题、标题、开头），它会提供两三个选项。

### 程序员

“构建、修复和讲解软件。”程序员是在你的项目里工作的软件工程师，所以和其他内置助手不同，它在你于开始页上选择的文件夹中工作，而不是在新的任务文件夹中。

- 改动之前，它会先阅读相关的代码，并遵循项目的惯例和工具。
- 它只改你要求的部分；发现的其他问题会告诉你，而不是擅自去修。
- 改完代码后，如果项目有测试、构建或代码检查工具（linter），它会运行它们，并修复失败的地方。
- 如果你看起来是编程新手，它会用浅白的话解释它做了什么、怎么运行。
- 最后它会给出简短的总结：改了什么、怎么验证的，以及还有什么没做。

### 辅导老师

“一步步讲解，并确认你跟得上。”目标是让你真正理解，而不只是得到一个答案。

- 如果不清楚你的水平或目标，它会先快速问一个问题。
- 它一次讲一步，用浅白的话，每个新概念都配一个具体的例子，由浅入深。
- 每讲完一步，它会用一个简短的问题或小练习检查你是否掌握，等你回答后再继续。
- 你回答后，它会指出哪里对了，并和善而具体地纠正不对的地方，还会随时调整：你卡住时换一种讲法或例子，你学得快时加快进度。
- 遇到作业或练习题，它会用提示和提问引导你，只有在你要求、或者你尝试后仍然卡住时，才给出完整解答。
- 当图比文字讲得更清楚时，它会直接在回复里画出来：一张示意图、一个公式、一张插图，或一个可以动手试的小型互动图。每讲完一个主题，会做一个简短的回顾。

### 规划师

“规划旅行、活动和项目”，搬家和日常安排也可以。

- 首先，它会确定影响计划的要素：目标、日期和截止时间、预算、涉及的人以及硬性限制。对缺少且重要的少数几项，它会询问你；其余的则采用合理的默认值，并说明它做了哪些假设。
- 它会上网核实计划所依赖的事实（营业时间、路程时间、价格、是否有空位、相关规定），并指出哪些无法核实或可能变化。
- 它会把计划做得很具体：一条时间线或按天的日程，写明时间、地点、费用和分工，为可能延误的事情留出余地，并列出需要先预订或先决定的事项。
- 遇到重要的选择，它会给出两三个选项并说明各自的利弊。涉及花钱时，它会附上一份带总额的预算。
- 它会把计划存成会话文件夹中的文件（Markdown；适合放进电子表格的预算和日程则用 CSV），并主动提出可以再调整。

### 分析师

“用图表帮你看懂数据和电子表格”：电子表格、CSV 文件、导出的数据和各种数字。

- 分析之前，它会先查看数据（列、规模、类型和缺口），在下结论之前报告缺失值、重复项或奇怪的格式等问题。
- 它用代码计算（一段简短的 Python 或 JavaScript 脚本，或一个公式），从不靠目测估算，并把脚本保存在会话文件夹中，方便重复这项工作。
- 它先用浅白的话和关键数字回答问题，再展示这些数字是怎么得出的。它会说明假设和局限，不会声称数据无法证明的因果关系。
- 有帮助时，它会用图表和表格展示结果，直接放在回复里（图表多时放在会话中的页面上）：选用最简单的合适图表（比较用柱状图，随时间变化用折线图），坐标轴标注清楚、带单位，在手机上也看得清。
- 如果你会需要，它会把清理后的数据和结果存成文件（CSV；你要求时也可以是 XLSX）。

### 应用搭建师

“制作你自己的应用：表单、步骤、数据和界面”（见[应用](/guide/apps)）。

- 它先弄清楚输入什么、输出什么、一次好的运行是什么样子，只问会影响设计的问题，并说明它做了哪些假设。
- 它用自己的工具搭建应用，为每个部分选最省的步骤（一个工具、一次快速的模型回答、一条规则、代码），需要判断的地方才用智能体。
- 它给应用配上两到四个带检查的示例，试运行它们，把没通过的修好之后再交给你，并说明一次运行要花多少钱、用多长时间。
- 你自己修改了应用时，它会在你的修改之上继续。
- 它使用 app-builder 技能。

## 创建智能体

### 说出它该做什么

1. 在[智能体页面](/agents)上点击**新建智能体**。
2. 在“它该做什么？”下面用几句话说出来；如果它需要自动工作，也说明何时：“每周五下午，根据我的提交和笔记写我的每周进展报告，发出前先让我检查。”点击输入框下面的示例即可填入。
3. 点击**起草**。辅助模型（设置 → 模型 → 辅助模型）会起草这个智能体：它的名称、图标、一句话介绍、指令、它可以使用什么、思考所用的档位，以及你要求时的定时运行。
4. 以句子的形式阅读草稿，点击任何带下划线的文字来修改（见[修改智能体](#change-an-agent)）。有定时运行时，“每次定时运行的开头消息”写着每次运行开头的那条消息；**它的指示**会展开它要读的内容。
5. 点击**创建智能体**。应用会提示“*名称* 已准备好”，并打开它的页面；如果它有定时运行，那就是一个以它运行的定时任务。

**所有设置**会改为在编辑器中打开草稿，**重新描述**会回到输入框。项目的**智能体**标签页上有**在此新建智能体**，用它创建的智能体在那个项目中工作；在项目还没有智能体时，还有**为这个项目创建一个**，它根据项目对自己的说明或其所属类型的模板创建一个；新项目也可以在创建时就得到一个（见[项目](/guide/projects)）。

### 从空白开始

输入框下面的**从空白开始**会打开编辑器，除了图标之外什么都没有填（见[所有设置](#all-settings)）。你最多可以保存 200 个自己的智能体。

### 所有设置

**所有设置**打开的编辑器包含智能体的全部设置；在手机上，它会以面板形式从屏幕底部弹出。只有名称是必填的。**保存**会保留它（“*名称* 已保存”，新建的则是“*名称* 已准备好”）；**取消**会关闭编辑器，不保存。各个字段，从上到下：

- **图标**：名称左边的图标。点击它可以从 30 个中选一个（望远镜、钢笔、厨师帽、飞机、钱包等等）。
- **名称**：最多 60 个字符，例如“记账员”或“旅行顾问”。
- **一句话介绍**：最多 160 个字符，显示在它的卡片上和开始页的菜单中，例如“把家庭账目打理得井井有条”。
- **指令**：它是谁、怎样工作，最多 20,000 个字符。每次会话开始时它都会先读这段文字。可以照内置智能体的写法来写：“在本次会话中，你是用户的记账员”，然后用几行说明它怎样工作（“需要哪些对账单就向用户要”“把各项合计记在工作文件夹里的电子表格中”）。
- **在哪里工作**：**所有地方**，或**项目中**并为每个项目提供一个开关（见[智能体在哪里工作](#where-an-agent-works)）。
- **它的会话从哪里开始**（开始页上没有选择文件夹时）：
  - **新的任务文件夹**（默认）：每个会话都有一个属于自己的全新文件夹（见[任务文件夹](#task-folders-where-a-task-without-a-folder-works)）。
  - **开始页上的文件夹**：会话在开始页显示的文件夹中工作，和程序员一样。在项目中工作的智能体请选这一项。
- **运行于**：它建议使用的程序，在开始页上选中它时会一起选上。
  - **任意智能体**（默认）：沿用开始页上选中的程序。
  - **Claude Code**、**Codex**、**Custom**（“任意模型”），或你在[设置 → 智能体 → 更多智能体](/settings?s=agents)中添加的任何智能体。
  - 选定程序后，旁边会出现一个模型菜单，列出该程序的模型（适用于提供多个模型的程序）；不去动它，就使用该程序的默认模型。如果在下面设置了档位，则由档位选择模型。
- **权限模式**：它在什么情况下要先问你。
  - **沿用所选**（默认）：沿用开始页上选中的模式。
  - **询问**：修改文件和运行命令之前都会先问。
  - **接受编辑**：可以随意修改文件，运行命令前会先问。
  - **完全访问**：从不询问。
  - **计划**：在你批准之前，只阅读和制定计划。

  Claude Code、Codex 和 Custom 都有与这些对应的模式。其他智能体（Gemini CLI、OpenCode…）则保留它们自己的模式。
- **思考使用**：**自动**、**快速**、**标准**或**最佳**；下面是**它启动的助手，最高不超过**：**不限**，或一个档位；还有**检查未通过时升档**，除非你关掉，否则默认开启（见[智能体用什么思考：档位](#what-an-agent-thinks-with-tiers)）。
- **它可以使用什么**：五个开关，新智能体全部开启（见下文）。
- **优先使用的技能**：技能名称，一次添加一个（见下文）。
- **连接**：有已连接的账户时才显示（见下文）。
- **团队**：为每个可以交付工作的其他智能体提供一个开关，以及**其他智能体可以把工作交给它**（见[把工作交给其他智能体的智能体](#agents-that-hand-work-to-other-agents)）。
- **每月预算**：每月的美元金额，留空表示不限（见[每月预算](#a-monthly-budget)）。
- **它自己的对话**：**保持一个对话，带收件箱**（见[有自己对话的智能体](#an-agent-with-a-conversation-of-its-own)）。
- **交回**：每个结果的字段，以及每个结果送往何处（见[智能体交回什么](#what-an-agent-hands-back)）。

### 它可以使用什么

每个开关对应一类工具：

- **读取文件**：打开、列出和搜索文件与文件夹。
- **创建和修改文件**：写入新文件，编辑已有文件。
- **运行命令**：在这台电脑上运行程序和脚本。
- **使用网络**：搜索和阅读网页。
- **其他工具**：为智能体设置的 MCP 服务器（工具服务器）和插件。

关掉的开关会产生什么效果，取决于智能体：

- **Claude Code 和 Custom**：这些工具会被直接关闭。关闭**其他工具**后，Claude Code 只能使用应用自带的工具和你已连接的账户，你自己设置的 MCP 服务器一个都用不了。
- **Codex**：会被告知不要使用它们。关闭**使用网络**后，它自带的网络搜索也会关闭。如果关闭**运行命令**但开着**读取文件**，Codex 会被告知只能用 shell 读取和搜索文件，因为它是通过 shell 来读文件的。
- **其他智能体**：会被告知不要使用它们。

应用自带的工具（页面、记忆之类）会保持开启，除非它们属于你关掉的某个开关：关闭**使用网络**后，应用的网络搜索、网页阅读和浏览器也会一并关闭；关闭**读取文件**后，它的文档阅读器也会关闭。已连接的账户不算“其他工具”：它们由下面的**连接**决定。当任务需要这个智能体无法使用的东西时，它会被告知直接说明，而不是想办法绕过去。

### 优先使用的技能

输入技能名称后按 Enter（或输入逗号）即可添加。输入框会建议 Claude Code 和 Codex 自己的技能，也就是[设置 → 智能体 → 技能](/settings?s=skills)针对“文件”中打开的文件夹所列出的那些；你也可以输入技能库中某个技能的名称，例如 research。点击名称旁边的垃圾桶可以去掉它。最多 30 个。当其中某个技能适合任务时，智能体会在开始前加载并遵循它。应用自带哪些技能、如何添加更多技能，见[技能](/guide/skills)。

### 连接

只有当你有已连接的账户（在[应用 → 已连接的应用](/apps/connected)中设置）时，才会显示这一部分。每个账户都有一个开关：开启表示在这个智能体的会话中开启它。已经对所有会话开启的账户会显示“对所有会话开启”。如果智能体指定的某个账户已不再连接，它会显示为“（未连接）”，并带有一个移除按钮。见[已连接的应用、密钥和工具](/guide/connections)。

## 修改智能体

在智能体的页面上，它的设置以句子的形式呈现：它做什么，“工作范围：*所有地方*，*每个工作日 09:00*，思考使用*快速*。它可以*读取文件和使用网络*，求助对象：*没有其他智能体*。它交回*它的回复*。它每月最多花费 *$3*。”每个带下划线的部分都会打开修改它的地方，修改会立即保存：

- **在哪里工作**：**所有地方**，或为每个项目提供一个开关。
- **何时工作**：它的定时运行（每个都能打开自己的编辑器）、**添加定时运行**，以及**保持一个对话，带收件箱**。
- **它用什么思考**：自动或一个档位、**它启动的助手，最高不超过**，以及**检查未通过时升档**。
- **它可以使用什么**：五个开关。
- **它向谁求助**：为每个其他智能体提供一个开关，以及**其他智能体可以把工作交给它**。
- **它交回什么**：它的字段，以及每个结果送往何处。
- **它的每月预算**：每月的美元金额，或不设。

其余设置在**所有设置**中（见[所有设置](#all-settings)）。之后你开始的会话会使用新版本；已经在进行中、使用这个智能体的会话，也会从你的下一条消息起采用：Custom 在每一轮之前读取它，Claude Code 和 Codex 会在空闲时重新启动（对话照常继续）。

## 智能体在哪里工作

除非你为它选择了项目，否则智能体在**所有地方**工作。只在某些项目中工作的智能体：

- 只在那里提供：只有选中它的某个项目时，开始页的智能体菜单才会列出它；其他智能体也只能在它的项目的会话中把工作交给它；
- 如果它只在一个项目中工作，就在该项目的文件夹中工作，使用项目的知识、记忆、准则和技能；
- 显示在它的每个项目的**智能体**标签页上（见[项目](/guide/projects)）。

如果你在开始页上选了一个当前所选智能体不工作的项目，开始页会改为选中通用。

## 智能体何时工作：定时运行

当你以某个智能体开始会话、其他智能体把工作交给它，以及按它的定时运行时，它就会工作。定时运行是一个以该智能体运行的定时任务：在某个时间、每隔一段时间、只运行一次、页面或订阅源变化时，或其他服务调用它的 webhook 时（见[定时任务](/guide/tasks)）。

- 在智能体的页面上，**添加定时运行**会打开任务编辑器，已选好这个智能体并填好时间：给它起个名字、写下每次运行开头的消息，然后保存。
- 点击列表中的某个定时运行，可以修改、暂停或立即运行它。
- 和新智能体一起起草的定时运行会随它一起创建。

每个定时运行也都在[设置 → 智能体 → 定时任务](/settings?s=tasks)中，和其他任务在一起；任务的**智能体**选项就是它的运行所用的智能体。

## 智能体用什么思考：档位

档位按任务而不是按名称来选择模型：

- **快速**：最便宜，用于结果可以检查的明确任务，例如翻译、提取事实、分类、排版和简短摘要。
- **标准**：大多数工作：写作、研究、修改代码。
- **最佳**：最强，用于困难、开放的问题：规划、棘手的缺陷、证明、重要的审查。

设为某个档位的智能体，会使用该档位在它所运行程序上的模型，除非会话已选了模型；设为**自动**（默认）时，它使用开始处所选的模型：开始页、定时任务，或把工作交给它的智能体。

[设置 → 智能体 → 模型 → 档位](/settings?s=models&find=Tiers)用一个表格说明每个档位的含义，每个程序一列：**Claude Code** 为一个模型（初始为 Haiku、Sonnet 和 Opus）和投入程度；**Codex** 为一个模型和投入程度（初始为它的默认模型，投入程度分别为低、中、高）；**Custom** 为你的某个 Custom 模型，或不设，表示沿用会话所选的模型。**恢复默认**会把它们改回去。

**它启动的助手，最高不超过**限制一个智能体所启动助手的档位：请求更高档位的助手会得到这个档位，没有指定档位的助手也会得到它。直接指定的模型则按指定使用。

**检查未通过时升档**（除非你关掉，否则默认开启）：智能体在某个档位上启动的助手，如果它的回复没有通过一次快速检查（辅助模型会阅读它的任务说明和回复），或者因出错而停止，就会提高一个档位重新运行，但绝不会超过该智能体允许的最高档位。负责的会话会得知升档及原因，新的助手也会被告知第一次为什么不够好。智能体的定时运行如果在它的档位上失败，也会提高一个档位重新运行，最高到最佳。负责的会话觉得某个助手的结果不够好时，也可以自己让它升档。

## 把工作交给其他智能体的智能体

智能体可以把一部分工作交给一个新的会话，在旁边并行处理：子会话（见[深度研究、第二意见和多个智能体](/guide/research)）。它可以启动：

- **普通助手**，并为它的部分指定一个档位：明确、可检查的部分用快速，大多数用标准，困难的用最佳；
- **你的某个智能体**，按名称：它按自己的指令、工具、连接、模式和档位工作，它的回复会交回给请求它的智能体。

谁可以把工作交给谁：

- 以内置智能体（或不以任何智能体）工作的会话，可以把工作交给在那里工作的任何一个你的智能体。
- 你自己的智能体只能把工作交给它的**团队**列出的智能体。
- 关闭了**其他智能体可以把工作交给它**的智能体，不接受任何智能体交来的工作。
- 按名称请求的智能体只在它自己的项目中工作，而且权限模式绝不会比请求它的会话更宽松。

在对话中，每个助手都显示为一张卡片，位于启动它的那一轮下面，写着它所用的智能体（或“子会话”）、它的档位、程序和模型、正在做什么、花费，以及（如果升过档）从哪个档位升上来、为什么；**打开**会打开它的对话。项目的**智能体**标签页会显示它的智能体中哪个把工作交给哪个。

保持自己对话的智能体会把交来的工作放进它的收件箱，而不是开一个新会话；它处理到时，回复会送回来（见[有自己对话的智能体](#an-agent-with-a-conversation-of-its-own)）。

## 每月预算

智能体的**每月预算**限制它的会话一个月内的花费（从每月一日起，按这台电脑的时间）：

- 以它开始的每个会话，都会得到一个等于预算剩余金额的花费上限（如果会话本身已有上限，取较低者）。
- 它的普通助手的花费计入它的预算；按名称请求的智能体的工作计入那个智能体自己的预算。
- 预算用完后，到下个月之前不会再以它开始会话：定时运行会说明为什么无法开始，它的卡片会显示**预算已用完**。

每个会话花了多少，按[用量和费用](/guide/usage)中的方式计算。留空表示不限。

## 智能体交回什么

什么都不设时，智能体在对话中交回它的回复。在**交回**中给它设好字段和去处（在所有设置中，或从它的句子“它交回*它的回复*”中），它就会在每个任务结束时交回一个带有这些字段的结果，并在送往任何地方之前先经过检查：

- **每个结果的字段**：每个字段一个名称和一种类型（文本、长文本、数字、是或否、日期、链接、列表，或带列的表格），以及是否必填。智能体用它的 hand_back 工具填写；不符合的结果会退回给它，并说明要改什么。
- **除对话外，每个结果送往何处**：
  - **资料库中的一个页面**，以智能体和日期命名；如果它在一个项目中工作，就放在那个项目里；
  - **一条通知**，内容是结果的第一行；
  - **它工作文件夹中的一个文件**，例如 `reports/{date}.md`：`{date}`、`{time}` 和 `{agent}` 会自动填入；以 `.json` 结尾的文件名得到 JSON 格式的字段，其他的得到 Markdown；路径绝不会超出那个文件夹；
  - **一个 webhook**：把结果以 JSON 通过 POST 发送到一个 https 地址；你指定了密钥库中的某个密钥时会用它签名，而且只发往该密钥允许的主机（见[已连接的应用、密钥和工具](/guide/connections)）。

智能体的页面会列出**它交回的结果**：它最近的结果，每个都写明送到了哪里，以及哪些没能送达。

## 有自己对话的智能体

大多数智能体每次都开始一个新会话。打开**保持一个对话，带收件箱**（在所有设置中，或在它句子的“何时工作”部分），智能体就会改为保持一个它自己的对话，在第一次需要时创建；如果它只在一个项目中工作，就放在那个项目的文件夹里：

- 给它的消息会在它的**收件箱**里排队，一次一条地进入它的对话，每条都等前一条有了回复再进去：你从它的页面发的消息，以及其他智能体交给它的工作。
- 它的定时运行会发到同一个对话里，等正在进行的一轮结束后再进去；和任何运行一样，每次运行都显示在它的定时任务的历史记录中。
- 每条回复都会送回给发送者：其他智能体会以消息的形式收到，你自己的则会收到一条通知。
- 它会记得之前的内容，和任何对话一样。
- 每条消息进入时都会检查它的每月预算。

在它的页面上，**收件箱**列出消息，每条都写明状态（**排队中**、**正在处理**、**已回答**、**没有回答**）和它的回复，还有一个给它发消息的输入框，以及打开它的**它的对话**。

## 以某个智能体开始会话

1. 打开[开始页](/)。消息框下方有一行显示由谁来做：程序、模型、文件夹，以及**智能体**标签，上面写着当前选中的智能体。
2. 点击**智能体**。在**以以下身份开始**下，先列出内置智能体，然后是**你的**下面你自己的智能体：那些在所有地方工作的，以及在所选项目中工作的。
   - 在电脑上，名称排成网格，每行两个。把鼠标指向其中一个，就会在网格下方看到它的说明：它的描述；如果它建议了程序，还会显示“使用”加上那个程序及其模型。
   - 在手机上，菜单会以面板形式从屏幕底部弹出，列出每个智能体及其说明。
3. 选择一个。然后输入你的任务，按 Enter 或点击**开始**。

菜单末尾的**创建或修改智能体**会打开[智能体页面](/agents)。智能体页面上的**开始会话**会打开开始页并选中它。

在开始页上选择一个智能体会带来这些变化：

- **程序、模型和权限**：如果智能体建议了某个程序，开始页会切换到它；如果它用某个档位思考，会换上该档位的模型，否则换上它指定的模型。如果它设了权限模式，开始页的**权限**（在**选项**下）会换成该程序对应的模式。开始之前，这些你都还可以更改。
- **连接**：智能体开启的已连接账户，在新会话中都会开启。
- **文件夹**：除非你自己选了文件夹，否则由智能体决定。大多数智能体从**新建任务文件夹**开始；程序员，以及设置为“开始页上的文件夹”的智能体，则使用显示的那个文件夹。

无论你在哪台设备上，开始页打开时都会选中你上次选择的智能体；第一次使用时是通用。开始页这样打开时，你的其他选择（程序、模型、权限）保持你离开时的样子；只有选择智能体才会改变它们。如果你上次选的智能体已被删除，则改为选中通用。

在文件夹菜单中选择一个项目时，如果该项目设定了会话开始时使用的智能体，也会同时选中那个智能体（见[项目](/guide/projects)）。

## 在会话中切换智能体

会话的消息框会显示它当前使用的智能体，你随时可以换成另一个：比如资料查齐之后，从**研究员**换成**撰稿人**。

1. 它是消息框下方那个打开**选项**的按钮里的第一行，而那个按钮也会先写出它的名称，例如“研究员 · Opus 5.5”。
2. 点击它。在**切换到**下面选另一个：和开始页上的菜单一样，在电脑上是网格，在手机上是从屏幕底部弹出的面板。
3. 应用会提示“从你的下一条消息起，智能体将以 *名称* 的身份工作”。

从你的下一条消息起，会话就以新的智能体工作，对话照常继续：

- 程序会随你的消息得知这次切换（对话中不会显示这一点）。
- **Claude Code 和 Codex** 在启动时读取指令，所以会话空闲时，它的程序会在你的消息之前重新启动，带上新智能体的指令和限制；这条消息会稍慢一点。如果正在一轮工作之中，或者它正朝着目标工作、有后台任务，它会随你的消息收到新的指令，等之后空闲时，再在某条消息之前重新启动。
- **Custom** 在每一轮之前读取指令。其他智能体（Gemini CLI、OpenCode……）会随你的消息收到新智能体的指令。
- 新智能体开启的已连接账户会在这个会话中开启，取代上一个智能体开启的；你自己为这个会话开启或关闭的保持不变。如果它设定了权限模式，会话会换成对应的模式；如果它建议的正是这个会话的程序，还会换成它的模型。程序本身不变：要把对话转给另一个程序，见[转到另一个智能体继续](/guide/sessions#continue-in-another-agent)。

不是以智能体开始的会话（在 VS Code 或终端里开始的，或在应用有智能体之前开始的）在那里显示**无智能体**：选一个就能给它配上。会话菜单（⋯）→ **会话设置** → **智能体** 也会显示它的名称；点击它会打开这个智能体的页面。

## 复制或删除智能体

在智能体的页面上：

- **创建副本**（每个智能体都有）：以新智能体的形式打开编辑器，所有内容都已填好，名称为“*名称* (copy)”。改你想改的，然后**保存**。要做一个属于你自己的内置智能体版本，就用这个方法。
- **删除**（仅限你自己的智能体）：会先询问“删除 *名称*？”。以它开始的会话会继续进行，只是不再带有它的指令；它的定时运行会保留，成为普通的定时任务；原本可以把工作交给它的智能体不再列出它。

搜索框（Ctrl+K，Mac 上为 ⌘K）也能按名称和描述找到智能体；选中一个会打开它的页面。

## 导入 Claude Code 的智能体文件

Claude Code 可以把它自己的智能体保存为 `.claude/agents` 文件夹中的 Markdown 文件：开头是一小段文件头，写着智能体的名称、描述、模型和工具，下面是它的指令。应用会把这些文件转换成你自己的智能体，这样这里的每个程序都能按那种方式工作。

1. 打开[智能体页面](/agents)，点击顶部的**导入**。
2. **导入 Claude Code 智能体**会列出它找到的智能体文件：你自己的在 `~/.claude/agents` 中（标记为**你的**），以及在[文件](/files)中打开的文件夹里 `.claude/agents` 文件夹中的那些（标记为**此文件夹**）。要查看某个项目自己的智能体，请先在“文件”中打开该项目。
3. 点击文件旁边的**导入**。它对应的智能体随即出现在智能体页面上和开始页的智能体菜单中。
4. 如果文件在别的地方，点击**选择文件**（“或此设备上的智能体文件”），然后选择那个 `.md` 文件。

文件必须是 Markdown（`.md`），最大 256 KB。应用会从中提取以下内容：

| 智能体文件中 | 智能体中 |
|---|---|
| `name`（没有时用文件名） | **名称**：“code-reviewer”变成“Code reviewer” |
| `description` | **一句话介绍**：取它的第一句，不含示例 |
| `model` | **运行于**：Claude Code 加上该模型（“inherit”表示沿用开始页上的模型） |
| `tools` | **它可以使用什么**，按类别对应；没有 tools 这一行的文件可以使用全部工具 |
| `permissionMode` | **权限模式**：default → 询问，acceptEdits → 接受编辑，bypassPermissions → 完全访问，plan → 计划 |
| `skills` | **优先使用的技能** |
| 文件头下方的文字 | **指令** |

图标会根据智能体的名称和描述来选（研究用望远镜，写作用钢笔，审查和测试用代码图标，等等）。导入的智能体在开始页上的文件夹中工作，就像 Claude Code 的智能体在项目中工作一样。

已导入的文件在列表中显示的是**更新**，而不是**导入**。**更新**会重新读取文件，写入同一个智能体：它的各个字段会重新变成文件中的内容，只有你选的图标保持不变。从你的设备选择文件，则总是会新建一个智能体。

## 任务文件夹：没有指定文件夹的任务在哪里进行

很多任务并不属于哪个文件夹：一份旅行计划、一封信、一个问题。对于这些任务，开始页上的文件夹标签会显示**新建任务文件夹**；当你按下**开始**时，应用会为会话新建一个文件夹，以日期和你消息中的几个词命名，例如 `~/Hydor/2026-10-31-plan-trip-lisbon`。智能体会把成果保存在那里，你之后可以在[文件](/files)中再找到它。

名称是这样生成的：

- 日期，按你所在的时区。
- 你消息中的最多五个词，略去虚词（a、the、please、help、me…）、链接和开头的 `/command`，并去掉重音符号，最多 40 个字符。如果一个词都不剩，就用 `task`。
- 如果这个名称已被占用，会加上 `-2`、`-3` 等后缀。

### 选择任务文件夹或你自己的文件夹

打开开始页上的文件夹标签：

- **新建任务文件夹**（“位于 ~/Hydor”）会为每个会话新建一个文件夹。
- 选择一个项目、一个最近用过的文件夹，或输入名称或路径找到的任意文件夹，会话就会改在那里进行（见[项目](/guide/projects)和[会话](/guide/sessions)）。

在你做出选择之前，由智能体决定：除程序员以外的内置智能体，以及你自己设置为“新的任务文件夹”的智能体，会使用任务文件夹；程序员和设置为“开始页上的文件夹”的智能体，会使用显示的文件夹；只在一个项目中工作的智能体使用那个项目。开始页会记住你的选择。选择另一个智能体会把决定权交还给它，除非你在页面打开后选过文件夹。

任务文件夹不会挤满文件夹菜单：菜单中列出的最近用过的文件夹不包括它们。在免提模式下用语音开始的会话也会得到一个任务文件夹，除非开始页上次设置的是某个文件夹或项目（见[文档、图片、视频和语音](/guide/documents-voice)）。

### 移动任务文件夹

1. 在[设置 → 功能 → 你的智能体](/settings?s=assistants&find=Task%20folders)中找到**任务文件夹**（“未指定文件夹就启动的会话，会在这里获得一个新文件夹，以日期和任务命名”）。
2. 点击文件夹的名称。在**工作文件夹**下输入一个路径（输入时会建议文件夹，也会列出你最近用过的文件夹），然后点击**使用此文件夹**。请填写完整路径，或以 `~` 开头表示你的主文件夹。

从此以后，新的任务文件夹都会放在那里；已经建好的文件夹留在原处。改过位置后会出现**改回 ~/Hydor**，用来恢复默认。下方的一行会显示新文件夹的样子。获得自己文件夹的新项目，也会把文件夹建在这里，放在其中的 **Spaces** 文件夹里（见[项目](/guide/projects)）。

## 任务完成后清理

[设置 → 功能 → 你的智能体](/settings?s=assistants&find=Clean%20up%20after%20a%20task)中的**任务完成时**有一个开关：**任务完成后清理**。除非你关掉它，否则它一直开启，并且适用于所有会话，不管以哪个智能体工作。

开启后，智能体在任务中的最后一步，是清理它在过程中创建、已不再需要的东西：

- 草稿和测试文件、临时文件夹和数据、调试输出和截图；
- 它创建的、已合并或已放弃的 git 分支、工作树（仓库的额外副本，每个都在自己的分支上）和储藏（stash）；
- 它启动的进程、服务器或容器，除非你希望它们继续运行。

它会保留你要的成果，以及还需要有人审查或合并的工作（比如有未合并提交的分支），绝不删除不是它创建的东西；遇到大的或不确定的内容（比如一个很大的下载、任何共享的东西），会先问你。它会逐一点名要删除的东西，而不是按通配模式批量删除，并用一句话说明删了什么、留下了什么。应用自带的 clean-up 技能里写有具体做法（见[技能](/guide/skills)）。

关掉它，智能体就会把创建的东西留在原处。无论开还是关，智能体都会从下一个会话起按新设置执行（Custom 从下一条消息起）。

## 智能体还会在哪些地方用到

- **项目**：项目可以指定它的会话以哪个智能体开始（“它的会话开始时使用”）；在开始页上选中该项目时，就会选中那个智能体。它的**智能体**标签页显示在其中工作的智能体。见[项目](/guide/projects)。
- **应用**：应用可以指定一个**智能体**，它的运行就会以该智能体开始（来自公开页面的运行除外）；应用中的每个智能体步骤也都可以各自指定一个。见[应用](/guide/apps)。
- **定时任务**：任务以它的**智能体**选项指定的智能体运行；智能体在会话中为你设置的任务，会像那个会话一样运行。见[定时任务](/guide/tasks)。
- **免提语音**：你用语音开始的会话，会以开始页上最后选中的智能体开始。
