# 智能体

智能体决定了会话以什么身份工作：它的指令、它可以使用什么、在哪里和何时工作、用哪个模型档位思考、把工作交给哪些其他智能体，以及一个月可以花多少钱。本主题介绍智能体页面、应用自带的智能体、通过描述它该做什么来创建自己的智能体、修改智能体、智能体在哪里工作、它的定时运行、档位、把工作交给其他智能体的智能体、每月预算、智能体的版本和检验它的示例、以某个智能体的身份开始和切换会话、以文件形式分享智能体、导入 Claude Code 的智能体文件、任务文件夹、让智能体在任务结束后清理，以及每个智能体在自己的 shell 里都能找到的三个命令。

## 什么是智能体

开始会话时，你在开始页面选择一个智能体，之后也可以在会话的消息框里把它切换成另一个。智能体的指令会叠加在程序自身的指令之上，所以同一个程序在一个会话里可以是严谨的研究员，在下一个会话里又可以是耐心的辅导老师。智能体适用于所有程序：Claude Code、Codex、Custom（应用自己的智能体），以及支持 ACP（Agent Client Protocol）的智能体，例如 Gemini CLI 或 OpenCode。

一个智能体可以包含：

- **指令**：它是谁，以及它如何工作。它会被告知始终按此方式工作，但你在对话中提出的要求优先。
- **在哪里工作**：全部项目，或只在你的部分项目中（见[智能体在哪里工作](#where-an-agent-works)）。
- **何时工作**：在你或其他智能体提出要求时，以及按它自己的定时运行（见[智能体何时工作：定时运行](#when-an-agent-works-schedules)）。
- **它用什么思考**：自动，或一个档位（快速、标准、最佳或最大值），你只需为每个程序设置一次该档位对应的模型（见[智能体用什么思考：档位](#what-an-agent-thinks-with-tiers)）。
- **它的团队**：它可以把部分工作交给哪些其他智能体，以及其他智能体是否可以把工作交给它（见[把工作交给其他智能体的智能体](#agents-that-hand-work-to-other-agents)）。
- **每月预算**：它的会话每月可以花多少钱（见[每月预算](#a-monthly-budget)）。
- **它交回什么**：每个结果的各个字段（已经过检查），以及每个结果的去向：保留的网页、电子表格中的一行、发给他人的电子邮件、通知、文件、webhook（见[智能体交回什么](#what-an-agent-hands-back)）。
- **它自己的对话**：它可以保留一个对话，带有一个收件箱，接收你和其他智能体发来的消息，它的定时运行也会在这里发布内容（见[拥有自己对话的智能体](#an-agent-with-a-conversation-of-its-own)）。
- **它可以使用什么**：读取文件、创建和修改文件、运行命令、使用网络、使用浏览器、使用电脑（在开启“Computer use”的桌面应用中，可操作它的屏幕、鼠标和键盘），以及其他工具。可以全部保持开启，也可以关闭其中一些。
- **优先使用的技能**：当技能适合任务时，它会在开始前先加载这些技能（见[技能](/guide/skills)）。
- **已连接的应用**：在它的会话中开启的已连接账户（见[已连接的应用、密钥和工具](/guide/connections)）。
- **建议的程序、模型和权限模式**：在开始页面随智能体一起选定，开始之前你仍然可以更改。
- **它的会话从哪里开始**：当你不选文件夹时，是它自己的新任务文件夹，还是开始页面上显示的文件夹。

智能体是会话所扮演的一种角色。如果有些文字需要所有智能体在每个会话中都遵循，或在某个项目或某个会话中遵循，例如你希望它们怎样和你交谈，那应该放在[智能体准则](/guide/guidelines)里。在 0.37.0 版本之前，智能体被称为助手；它们是同一个东西，只是功能更多了。

## “智能体”页面

在侧栏中打开**智能体**，或前往 [/agents](/agents)。在手机上，侧边栏是一个抽屉：需要先打开它。[设置 → 功能 → 你的智能体](/settings?s=assistants&find=Your%20agents)中有一行**你的智能体**，同样可以打开这个页面（它会显示有多少个智能体是你自己的）；该部分的其余内容是关于任务文件夹和清理的，见下文。

- 在电脑上，页面在侧栏旁边有一列，就像“应用”和“设置”一样：顶部是徽标、**新增**和**隐藏侧边栏**（Ctrl+B，Mac 上为 ⌘B），下面是各个分类。**新增**会打开一个菜单：**新建智能体**用来创建一个（见[创建智能体](#make-an-agent)）；**从文件安装智能体**用来安装别人给你的文件中的智能体（见[把智能体分享为文件](#share-an-agent-as-a-file)）；**导入 Claude Code 智能体文件**用来导入 Claude Code 的智能体文件（见[导入 Claude Code 的智能体文件](#import-claude-codes-agent-files)）。
- 各个分类：**所有智能体**（你的智能体以卡片显示；当这一列被隐藏时，内置智能体显示在卡片下方，因为这一列本身会列出它们）、**你的智能体**（只有你自己的）、**需要你处理**和**有定时运行**（当你的智能体中有符合条件的才会显示），以及在**它们在哪里工作**下的**全部**和每个拥有自己智能体的项目。每个分类都会显示它包含多少个智能体。在**内置**下，应用自带的每个智能体各有一行，带有它的图标，点击会打开该智能体自己的页面。在一条分隔线之后，**定时运行**会按周显示所有自动运行的内容：你的智能体的定时运行以及你的其他定时任务、你的应用的定时运行、监视器和 webhook，每次运行按结果以不同颜色标示，还有接下来会运行什么，以及一个包含全部内容的列表，每项都有开关可以暂停（见[查看这一周：已运行的和接下来要运行的](/guide/tasks#see-the-week-what-ran-and-what-runs-next)）。当前打开的分类会被标出，地址中也会保留它（`/agents?place=mine`、`/agents/schedules`），所以通过链接可以直接打开它。
- 在页面顶部，左边是分类的名称，右边是查找框：**查找智能体**会把卡片和内置智能体缩小到名称或简介中含有你所输入内容的那些。
- 你的智能体以卡片显示。每张卡片包含智能体的名称、它的简介、它的状态（**工作中**、当它的某个会话在等你回答时显示**需要你处理**、**预算已用完**或**空闲**）、它工作所在的项目（或**全部**）、它的档位、它下次运行的时间、它的收件箱里有多少条消息在等待，以及它本月花了多少。
- 在手机和窄窗口中没有这一列：页面保留标题，右边是**新建智能体**、**导入**和**安装**，下面有两个标签页（**你的智能体**和**定时运行**），卡片上方是筛选标签，显示**全部**、**全部**、每个拥有自己智能体的项目、**有定时运行**和**需要你处理**。应用自带的智能体在**内置**下。

点击卡片会打开该智能体自己的页面，旁边保留着那一列，并标出该智能体（如果是你自己的，则标在**你的智能体**下）：

- 用几句话描述它的设置，例如“它在所有项目中工作，每个工作日 09:00 运行，使用快速档位思考。”点击任何带下划线的文字就可以在那里更改（见[修改智能体](#change-an-agent)）。
- **开始会话**会打开开始页面，并选好这个智能体（如果它在某个项目中工作，也会选好该项目）。
- **所有设置**会在一个窗口中打开该智能体的全部设置（见[所有设置](#all-settings)）。**创建副本**会生成一个副本供你修改；**删除**会移除你自己的智能体。
- **更多**（⋯）：**版本**（针对你自己的智能体）会列出每次更改之前它的样子，供你对比和恢复（见[版本：回到更早的版本](#versions-go-back-to-an-earlier-one)）；**下载为文件**会把它保存为文件，便于保留或送人（见[把智能体分享为文件](#share-an-agent-as-a-file)）。
- **示例**（针对你自己的智能体）：用来试用它的消息，以及它的回答必须做到什么，另有**试一试这些示例**（见[检查它的示例](#examples-that-check-it)）。
- **定时运行**会列出以它的身份运行的定时任务，并带有**添加定时运行**。
- **收件箱**（针对保留自己对话的智能体）：它的消息和对应的回答、一个向它发送消息的输入框，以及**它的对话**（见[拥有自己对话的智能体](#an-agent-with-a-conversation-of-its-own)）。
- **它交回的结果**（针对有结果字段或结果去向的智能体）：一张它的结果表，每个结果一行，并显示每个结果的去向（见[智能体交回什么](#what-an-agent-hands-back)）。
- **本月**：有多少个会话以它的身份开始、花了多少，如果它有预算，则与预算对比；还有它的**最近的会话**，每个都会打开它的对话，旁边是**在侧边栏中显示全部 23 个**（见[查找智能体的会话](#find-an-agents-sessions)）。

## 内置智能体

应用自带八个智能体。它们都不会指定程序、模型、档位或权限模式，所以会沿用你在开始页面选定的设置，也不会限制可用的功能或产生花费。除程序员外，其余智能体启动会话时都会在一个新的任务文件夹中工作，而不是在某个文件夹里（见[任务文件夹](#task-folders-where-a-task-without-a-folder-works)）。你不能修改或删除它们，但可以复制一个，再修改副本（见[复制或删除智能体](#duplicate-or-delete-an-agent)）。

每个智能体都会善用适合自己工作的[回答卡片](/guide/sessions#answer-uis-cards-charts-and-maps-in-replies)（事实核查、可以就地作答的练习题、带地图的行程、关键数字和图表），所以那些看比读更直观的内容，会以可以查看、比较、勾选或试用的形式呈现。

### 通用

“帮你处理各种事情：提问、写作、规划、文件。”在你选择其他智能体之前，开始页面默认选中通用（项目自带的智能体优先）。它是为可能不懂编程的人写的。

- 它会弄清你想要什么，然后去做。只有当请求不明确、而且会影响结果时，它才会问一个简短的问题；可能的答案不多时，会以按钮的形式列出供你点击。其他情况下，它会自己做出合理的选择，并说明选了什么。
- 它先给出答案，再用平实的语言说明重要的细节，遇到无法避免的技术术语时会加以解释。
- 它让每个回答都容易理解、方便使用：看比读更直观的内容（并排的选项、地图上的地点、可以勾选的步骤、以图表呈现的数字、配有图片的事物）会以回答卡片的形式呈现，在看比读更有帮助的地方还会配上图片或视频，而它自己的文字则负责说明理由和给出建议。
- 对于最新的信息或它不确定的内容，它会在网上搜索；你指给它的文件，它会去阅读；需要保留的成果，它会保存为会话文件夹中的文件，如果是你以后还会用到的网页（比如跟踪表或计算器），则保存在项目的文件中（详情 → **文件**）。
- 当一个回答之后有很自然的下一步（深入了解、比较、规划、用它做点什么）时，它会在结尾以按钮的形式列出两到四个供你点选；并不是每个回答之后都会这样。
- 当它创建或修改了文件时，会在结尾说明是哪些文件、在什么位置。

### 研究员

“查找并核实资料来源，并注明出处。”

1. 它会用一行话重述你的问题，并把宽泛的问题拆成几个需要回答的子问题。
2. 它先广泛搜索，再下结论：用不同的措辞进行多次网络搜索，选用合适的搜索类别（论文、新闻、专利、公司文件、数据集）；涉及面广的主题会获取更多结果。
3. 它会阅读重要的资料来源，而不是靠摘要片段作答，并且优先选择一手和权威的来源：原始论文和数据、官方网站、公认的专家和媒体。它会记下每个来源的日期，当事实会随时间变化时，还会说明答案的时效性。
4. 当不同来源的说法不一致时，它会指出来，并根据质量和时效性加以权衡，同时区分哪些是已确立的、哪些有争议、哪些还未知。
5. 它边写边注明出处：每个论断后面有一个编号标记，例如 [1]，末尾列出各来源的标题、作者或发布者、日期和链接。它从不编造来源、引文、数字或链接，遇到无法核实的内容会如实说明。
6. 它先给出发现：用一行话给出答案和几个重要的要点，然后是细节，最后是仍不确定的部分。
7. 对于本身有特定形态的内容，它会直接展示，而不是埋在大段文字里：用事实核查的形式把论断与证据对照，把选项或研究并排比较，用时间线展示事情的经过，列出关键数字、值得一读的论文，并用关系图展示人物、观点或组织之间的联系。
8. 较长的报告还会保存在项目的文件中，作为可以阅读、批注和导出的文档；如果你想要文件，则保存为会话文件夹中的 Markdown 文件。

对于需要大量搜索的大问题，请参阅[深度研究、第二意见与多个智能体](/guide/research)中的深度研究。

### 撰稿人

“起草、编辑并润色你的文字”：电子邮件、信函、帖子、文章、报告、故事和演讲稿。

- 在写长篇内容之前，它会先确认读者、目的、语气和篇幅。当其中某一项不明确且很重要时，它会简短地询问（有好几项时用表单）；否则，它会用一行话说明自己的假设，然后开始写。
- 它的文字平实而具体：用词具体，要点靠前，句式有变化，没有废话和陈词滥调。
- 它会模仿你要求的风格；如果你分享了以前写的东西，则会模仿你自己的风格。
- 编辑你的文字时，它会保留你的原意和风格：改正错误的地方，精简松散的地方，保留好的地方。它会展示所做的修改，方便你对照：想要反馈时，会展示标出每处改动并加以说明的原文；改写时，会展示不同版本之间的变化，然后给出干净的文本。
- 对于短篇内容，它会交付可以直接使用的成品：可以在多个版本之间切换的电子邮件，并在你的邮件应用中打开、所有内容都已填好；帖子会逐条对照各平台的长度限制进行检查；还有按你需要的格式写成的参考文献。
- 当某个选择很重要时（邮件主题、标题、开头、名称），它会给出两到四个选项，每个都附有说明，供你挑选。
- 超过几段的内容会保存为文档（在项目的文件中），你可以在其中编辑、批注和导出，它也会告知你这一点；当你要求文件时，它会在会话文件夹中创建一个文件（除非你想要其他格式，否则为 Markdown）。

### 程序员

“构建、修复并讲解软件。”程序员是在你的项目中工作的软件工程师，所以与其他内置智能体不同，它在你于开始页面选定的文件夹中工作，而不是在新的任务文件夹中。

- 修改之前，它会先阅读相关的代码，并遵循项目的约定和工具。
- 它只改你要求的内容，发现其他问题时只会提出来，而不会未经要求就去修复。
- 修改代码后，如果项目有测试、构建或代码检查工具，它会运行这些，并修复失败的地方。
- 如果你看起来刚接触编程，它会用平实的语言解释自己做了什么以及如何运行：给出需要你运行的命令，每条都带有复制按钮和说明，还有可以在演练场里试用的代码片段。
- 当它是在讲解代码而不是修改代码时，会展示本身有特定形态的内容，而不是一大堆文字：错误及其可能的原因和修复办法、一次测试运行、以树状形式展示的项目文件、一个接口、与代码行并排逐步讲解的代码、逐行展示变量变化的程序运行过程、并排权衡的各种方案，以及用于展示流程或架构的示意图。
- 最后它会给出简短的总结：改了什么、如何检查的，以及还有什么要做。

### 辅导老师

“一步一步地教，并检查你是否跟上了。”目标是让你真正理解并能自己动手，而不仅仅是得到一个答案。

- 如果你的水平或目标不明确，它会先问一个简短的问题，并把可能的答案做成按钮供你点击（刚接触、了解基础、备考复习）。
- 它一次只教一步，用平实的语言，每个新概念都配有具体的例子，由浅入深。
- 它让每一步都可以看、可以试，而不仅仅是读：示意图、图片、公式卡片、带滑块的函数图像、展示概念之间联系的图谱、可以切换深浅程度的讲解、一步步展开的例题、可以运行和修改的代码、逐行讲解的代码、在你预测输出之后一步步运行的程序、小型模拟；数学公式则像教科书上那样呈现。
- 每一步之后，它会用可以就地作答的内容来检查，并等你完成后再继续：简短的测验、用你自己的文字或数字作答的练习题（随答随查，尝试之后会给出提示和解答）、填空、配对或排序。它会读取你提交的得分和答案。
- 你作答之后，它会说明哪里对了，并亲切而具体地纠正错误，还会随之调整：你卡住时换一种讲解或例子，你进展顺利时给出更难的一步。
- 遇到作业或练习时，它会用提示和提问来引导你，只有在你提出要求、或你尝试之后仍然卡住时，才会给出完整的解答。
- 学习语言时，它会提供供你听和练习的词汇、动词变形、对话，并纠正你自己写的句子，标出每处错误并加以说明。
- 学完一个主题后，它会给出简短的回顾和需要记住的内容的记忆卡片，并以按钮的形式提供接下来可以学的内容供你点选。对于较长的课程，它会保存一份主题路线图，记录你学到了哪里。

### 规划师

“规划旅行、活动和项目”，也包括搬家和日常安排。

- 首先它会确定影响计划的因素：目标、日期和截止时间、预算、涉及的人员和硬性限制。对于缺失且重要的几项，它会向你询问（有好几项时用表单），其余的则采用合理的默认值，并说明自己的假设。
- 它会在网上核实计划所依赖的事实（营业时间、路程时间、价格、空位情况、规定、天气），并在某些内容无法核实或可能变化时告诉你。
- 它让计划变得具体：时间、地点、费用和谁负责什么，为可能延误的事情留出余地，以及需要先预订或先决定的事项。
- 它用专为计划设计的回答卡片展示计划，方便你一目了然：按天安排并在地图上标出地点的行程、一天的日程、日历上的日期或倒计时、按阶段或按周划分的项目、作为清单的预订或打包事项、天气预报，以及带有总额的预算和费用。
- 当某个选择很重要时，它会并排给出两三个选项及其利弊（例如旅行的航班和住宿）。
- 它会把计划保存在项目的文件中，供你修改：一份文档，以及用于预算和日程、带有合计的电子表格。它会主动提出调整，并把可能的修改做成按钮供你点选。当你要求文件时，它会改为在会话文件夹中创建文件。

### 分析师

“理解数据和电子表格，并配上图表”：电子表格、CSV 文件、导出文件和数字。

- 它会先查看数据再进行分析（列、规模、类型和缺失情况），并在得出结论之前，先报告缺失值、重复项或格式异常等问题。
- 它用代码进行计算（简短的 Python 或 JavaScript 脚本，或者公式），从不靠目测估算，并把脚本保存在会话文件夹中，以便重复这项工作。
- 它先回答问题，用平实的语言给出关键数字，然后展示这些数字是怎么得来的。它会说明假设和局限，也不会声称数据无法证明的因果关系。
- 它用专为数字设计的回答卡片展示结果：关键数字、图表（选最简单合适的：比较用柱状图，随时间变化用折线图）、可以排序和筛选的表格、数值的分布、整体中各部分的占比、总量的变化、流向、以热力图展示的两个维度上的数值、地图上各地点的数字，以及在你想尝试其他数值时使用的计算器。上述形式都画不出来的数字，会放在回复中的实时图表里，数字较多时则放在网页中；坐标轴和单位都有标注，在手机上也能看清。
- 当你需要时，它会把清理后的数据和结果保存为文件（CSV，你要求时则为 XLSX）。你要查看和修改的表格会保存为带有公式的电子表格，你会反复查看的仪表盘则保存为网页。

### 应用搭建师

“制作你自己的应用：针对某一项工作的小工具，带有表单、步骤和展示结果的视图”（见[应用](/guide/apps)）。

- 它使用**最佳**来思考，也就是 [设置 → 模型 → 档位](/settings?s=models&find=Tiers) 中为它所运行的程序指定的模型：在开始页面选中它，就会选中该模型，应用页面启动的会话也使用该模型。
- 它会确定输入什么、输出什么，以及一次好的运行是什么样的，并阅读与你的应用最接近的一两个现成应用，按照它们的方式来构建。
- 对于新应用，它的第一个回答是一份草图，此时还没有做出任何东西：应用会问什么、会做什么、一个虚构的结果、一次运行需要多少时间和花费、它做了哪些假设，以及最多三个其答案会改变设计的问题，以可点击的选项呈现。你按下**构建它**时，它才会构建应用（见[草图](/guide/apps#the-sketch)）。如果是修改你已有的应用，或者你说直接构建，它会立即构建。
- 它用自己的工具来构建应用，每个部分都选最省的步骤（工具、模型的快速回答、规则、代码），需要判断的地方才用智能体。对于数据，它会调用现成应用所用的免费服务，或者先阅读该服务的文档，而不是凭记忆写一个地址。
- 设计或修改应用的视图之后，它会查看视图的图片（在电脑上的深色和浅色模式下，以及在手机上），并修复看起来不对的地方。
- 它会为应用准备两到四个带有检查项的示例，试运行并修复失败的地方，然后才交付，并说明一次运行的花费和所需时间。
- 当你自己修改应用时，它会在你的修改基础上继续构建。
- 它使用 app-builder 技能。

应用页面会为你启动会话：在**描述一个应用，让智能体来做**下点击**创建**，在没有应用能满足你的搜索时点击**向智能体描述它**，以及在某个应用的**编辑**中点击**请智能体设计它**或**请智能体修复它**，都会立即启动一个会话，并带上你写的内容（见[制作你自己的应用](/guide/apps#make-your-own-app)）。

## 创建智能体

### 说出它该做什么

1. 在[智能体页面](/agents)，点击列顶部的 **新增**，再点击 **新建智能体**（在手机上，点击页面顶部的 **新建智能体**）。**新建智能体** 窗口分两步打开，在顶部显示为 **1 描述** 和 **2 配置**。
2. 在“你的智能体应该做什么？”下面，用你自己的话说出来；如果希望它自动工作，也说明什么时候工作：“每周五下午，根据我的提交记录和备注写出我的每周进度报告，发出之前让我先检查。”在 **或者从一个想法开始** 下面有 **论文摘要**、**每周报告**、**变更审阅者** 和 **翻译员**，点击其中一个，输入框里就会出现一句话，供你修改。
3. 点击 **起草我的智能体**（或按 Ctrl+Enter，Mac 上按 ⌘+Enter）。辅助模型（设置 → 模型 → 辅助模型）会起草这个智能体：它的名称、图标、一句话介绍、指令、它可以使用什么、它思考使用的档位，以及你提出要求时的定时运行。窗口随后进入 **配置**。
4. 通读草稿，按你的想法修改（参见[所有设置](#all-settings)）。**返回** 会回到 **描述**：你写的内容会保留，再次起草会替换草稿。
5. 点击 **创建智能体**。应用会提示“*名称* 已就绪”并打开它的页面；如果它有定时运行，这个定时运行就是一个以它的身份运行的定时任务。

如果你输入或修改过内容后关闭窗口（✕、Esc 或点击窗口外部），它会先询问 **放弃这个智能体？**。项目的 **智能体** 标签页有 **在此新建智能体**，会创建一个在该项目中工作的智能体；在项目还没有智能体时，还有 **为这个项目创建一个**，它会根据项目自身的介绍，或者根据该类项目的模板来创建；新项目在创建时也可以同时得到一个（参见[项目](/guide/projects)）。

### 自己来配置

输入框下面的 **我自己来配置** 会跳过起草，直接打开 **配置**，除图标外什么都不填（参见[所有设置](#all-settings)）。你最多可以拥有 200 个自己的智能体。

### 让智能体来创建

在任意会话中，用你自己的话提出要求：“帮我做一个智能体，每周五下午 5 点总结我未读的新闻简报。”你正在对话的智能体，无论它运行在哪个程序上（Claude Code、Codex、Custom 或其他），都会替你创建：它的名称、一句话介绍、指令、它可以使用什么、它的档位等，以及在它需要自动工作时的定时运行。对话中会先出现一张卡片，显示这个智能体和它的定时运行时间，带有 **创建智能体** 和 **不要**；在你回答之前不会保存任何内容（参见[卡片：确认更改](/guide/ask-agents#the-card-confirming-a-change)）。

同样地，智能体也可以修改你的某个智能体（只会更改你要求的部分，并由 **一个智能体** 保存为新版本）、为它添加定时运行、修改某个定时运行、删除不再需要的定时运行，或者删除一个智能体及其定时运行。添加、修改或删除定时运行的更改，以及每一次删除，每次都会询问你，除非该会话拥有 **完全访问** 权限。给某个智能体设置 **完全访问**（它从不询问）则每次都会询问。

### 所有设置

**配置** 是 **新建智能体** 的第二步，也是智能体页面上的 **所有设置** 为该智能体打开的窗口，没有 **描述** 这一步。在手机上，窗口会占满屏幕。顶部是图标（点击它可以从 30 个中选一个：望远镜、钢笔、厨师帽、飞机、钱包等）和名称，名称最多 60 个字符，例如“记账员”或“旅行顾问”。只有名称是必填的。

在电脑上，左侧的一列列出七个部分，每个部分的名称下面显示它当前的设置，这样整个智能体一目了然；点击其中一个，就能在旁边看到它的设置。当某个部分比窗口长时，会出现 **下面还有更多** 按钮，提示下面还有内容。在手机上，**配置** 会列出各个部分及其当前设置；点按一个即可打开，**‹ 所有设置** 则返回。

- **关于**：
  - **一句话介绍**：最多 160 个字符，显示在它的卡片上和开始页的菜单中，例如“让家庭账目井井有条”。
  - **指令**：它是谁，以及它如何工作，最多 20,000 个字符。它在每个会话开始时都会阅读这些内容。可以照内置智能体的写法来写：“在本次会话中，你是用户的记账员”，然后用几行说明它怎么工作（“向用户索要你需要的对账单”“把合计保存在工作文件夹的电子表格中”）。
- **位置和时间**：
  - **在哪里工作**：**全部**，或者 **只在某些项目中**，并为每个项目提供一个开关（参见[智能体在哪里工作](#where-an-agent-works)）。
  - **何时工作**：对于新智能体，有 **被请求时**、**定时**（几天和一个时间）或 **每隔…**（一个间隔），以及 **每次运行的开头消息**，即每次定时运行开始时的消息。对于你已有的智能体，它的定时运行会列在这里；你可以在它的页面上的 **定时运行** 下添加和修改（参见[智能体何时工作：定时运行](#when-an-agent-works-schedules)）。
  - **保持一个对话，带收件箱**（参见[拥有自己对话的智能体](#an-agent-with-a-conversation-of-its-own)）。
  - **它的会话从哪里开始**，在开始页没有选择文件夹时：
    - **新的任务文件夹**（默认）：每个会话都会得到一个全新的专属文件夹（参见[任务文件夹](#task-folders-where-a-task-without-a-folder-works)）。
    - **开始页上的文件夹**：会话在开始页显示的文件夹中工作，程序员就是这样。需要在项目中工作的智能体请选这一项。
- **模型**：
  - **思考使用**：**自动**、**快速**、**标准**、**最佳** 或 **最大值**，每一项都有一句话说明它的用途（参见[智能体用什么思考：档位](#what-an-agent-thinks-with-tiers)）。
  - **运行于**：它建议使用的程序，会在开始页上与它一起被选中。
    - **任意智能体**（默认）沿用开始页上选的程序。
    - **Claude Code**、**Codex**、**Custom**（“任意模型”），或者你在[设置 → 智能体 → 更多智能体](/settings?s=agents)中添加的任何智能体。
    - 选定程序后，旁边会出现一个模型菜单，列出该程序的模型（针对提供选择的程序）；不动它，就是该程序的默认模型。上面的档位则会改为由档位来选择模型。
  - **权限模式**：何时先询问你。
    - **沿用所选**（默认）：沿用开始页上选的模式。
    - **询问**：修改文件和运行命令前先询问。
    - **接受编辑**：可以自由修改文件，运行命令前询问。
    - **完全访问**：从不询问。
    - **计划**：只读取和制定计划，直到你批准。

    Claude Code、Codex 和 Custom 各有与这些对应的模式。其他智能体（Gemini CLI、OpenCode……）沿用它们自己的模式。
  - **它启动的子智能体**：**不限**，或者最高不超过某个档位。
  - **检查未通过时升档**：默认开启，除非你把它关掉。
- **工具**：**它可以使用什么**（七个开关，新智能体全部开启，有些关闭时会出现 **全部开启**；见下文）、**优先使用的技能**（见下文）和 **已连接的应用**（在你连接了账户时显示，见下文）。
- **Team**：**其他智能体可以把工作交给它**，以及 **它可以把工作交给**，并为其他每个智能体提供一个开关（参见[把工作交给其他智能体的智能体](#agents-that-hand-work-to-other-agents)）。
- **结果**：它交回什么：每个结果的字段，以及每个结果的去向（参见[智能体交回什么](#what-an-agent-hands-back)）。
- **预算**：**不限**，或者以美元计的 **每月限额**；对于你已有的智能体，这里会显示它本月的花费（参见[每月预算](#a-monthly-budget)）。

**创建智能体** 会创建一个新智能体。对于已有的智能体，**保存** 会保留你的更改（“*名称* 已保存”），**取消** 会不保存就关闭窗口；做过更改后关闭窗口，会询问 **放弃你的更改？**。

### 它可以使用什么

每个开关对应一类工具：

- **读取文件**：打开、列出和搜索文件与文件夹。
- **创建和修改文件**：写入新文件和编辑现有文件。
- **运行命令**：运行这台电脑上的程序和脚本。
- **使用网络**：搜索和阅读网页。
- **使用浏览器**：在真实的浏览器中打开网站、点击和填写表单。
- **使用电脑**：查看屏幕，并在任意应用中使用鼠标和键盘（桌面应用，需开启“电脑使用”）。
- **其他工具**：为智能体设置的 MCP 服务器（工具服务器）和插件。

关闭的开关会怎样，取决于程序：

- **Claude Code 和 Custom** 会关闭这些工具。关闭 **其他工具** 后，Claude Code 只能使用应用自己的工具和你已连接的账户，不能使用你自己设置的任何 MCP 服务器。
- **Codex** 会被告知不要使用它们。关闭 **使用网络** 后，它自带的网络搜索也会关闭。如果 **运行命令** 关闭而 **读取文件** 开启，Codex 会被告知只用它的 shell 来读取和搜索文件，因为它是通过 shell 读取文件的。
- 当 **使用浏览器** 或 **使用电脑** 关闭时，**Claude Code、Codex 和 Custom** 也会关闭浏览器和电脑的工具。
- **其他智能体** 会被告知不要使用它们。

应用自己的工具（页面、记忆之类）会保持开启，但属于你已关闭的开关范围的除外：关闭 **使用网络** 后，应用的网络搜索和网页阅读也会随之关闭；关闭 **使用浏览器** 后，它的浏览器会关闭；关闭 **使用电脑** 后，它的屏幕、鼠标和键盘工具会关闭；关闭 **读取文件** 后，它的文档阅读器会关闭。已连接的账户不属于“其他工具”：它们由下面的 **已连接的应用** 决定。当任务需要智能体无法使用的东西时，它会被告知如实说明，而不是绕过去。

### 优先使用的技能

在 **工具** 中，输入一个技能的名称并按 Enter（或逗号）来添加。输入框会建议 Claude Code 和 Codex 自带的技能，内容与[设置 → 智能体 → 技能](/settings?s=skills)中针对文件里打开的文件夹所列出的一致；你也可以输入技能资料库中某个技能的名称，例如 research。点击名称旁的垃圾桶可以移除它。最多 30 个。当其中某个技能适合当前任务时，智能体会在开始前加载它并照着做。随应用附带的技能以及如何添加更多技能，参见[技能](/guide/skills)。

### 连接

**工具** 中的 **已连接的应用** 只在你连接了账户时才显示（在[应用 → 已连接的应用](/apps/connected)中设置）。每个账户都有一个开关：开启表示它在这个智能体的会话中是开启的。已经对每个会话开启的账户会显示“对每个会话开启”。如果智能体指定的某个账户已不再连接，它的名称下会显示“未连接”，并带有一个移除它的按钮。参见[已连接的应用、密钥和工具](/guide/connections)。

## 修改智能体

在智能体的页面上，它的设置以句子的形式呈现：它做什么，“它在*全部*位置工作，*每个工作日 09:00* 运行，思考使用*快速*。它可以*读取文件和使用网络*，不向*任何其他智能体*求助。它交回*它的回复*。它每月最多花费 *$3*。”每个带下划线的部分都会打开用来修改它的内容，修改会立即保存：

- **在哪里工作**：**全部**，或者为每个项目提供一个开关。
- **何时工作**：它的定时运行，每一个都会打开自己的编辑器，还有 **添加定时运行** 和 **保持一个对话，带收件箱**。
- **它用什么思考**：自动或某个档位、**它启动的子智能体，最高不超过**，以及 **检查未通过时升档**。
- **它可以使用什么**：七个开关。
- **它向谁求助**：为其他每个智能体提供一个开关，以及 **其他智能体可以把工作交给它**。
- **它交回什么**：它的字段，以及每个结果的去向。
- **它的每月预算**：每月多少美元，或者不设预算。

**所有设置** 包含其余内容（参见[所有设置](#all-settings)）。每次更改都会保存为一个版本，这样你可以回退（参见[版本：回到更早的版本](#versions-go-back-to-an-earlier-one)）。从此以后你启动的会话会使用新版本，已经在进行中的、使用它的会话也会从你的下一条消息起使用新版本：Custom 在每一轮之前读取它，Claude Code 和 Codex 在空闲后会重新开始（对话会继续）。

## 版本：回到更早的版本

每次改变你某个智能体内容的保存都会保留一个版本：在它页面上的更改、在 **所有设置** 中的更改、通过命令行、由你要求的智能体（通过应用的 API）所做的更改，以及生成它的草稿或文件。打开它的页面，然后点击 **更多**（⋯）→ **版本**：

- 列表按从新到旧显示每个版本：**v1**、**v2**……，用几句话说明改了什么（“它现在思考使用最佳（之前是快速）。它的每月预算现在是 $5（之前是 $3）。”），或者是做出更改的智能体自己说它做了什么，还有谁保存了它（**你**、**一个智能体**、**已起草**、**已安装**、**已导入**）以及时间；**当前** 标记当前的版本。如果某个版本的示例做过试运行，会说明通过了多少（“示例：3 个中通过 2 个”），这样你可以看出某次更改是否让它变得更好。
- 点击某个版本，可以把它与前一个版本比较，也可以在 **比较** …… **与** …… 中任选两个：用句子说明它们之间有什么变化，并并排显示它们的 **指令**，删去的行为红色，加入的行为绿色。
- **恢复此版本** 会让所选版本再次成为当前版本。它会被保存为一个新版本，写着“已恢复版本 3。”，因此原来的那个版本仍留在列表中，可以随时回到它。它曾交付工作的智能体，以及此后已不存在的项目，会被略去。

智能体会保留最近的 50 个版本；删除它时这些版本也会一并删除。它的示例不属于版本的一部分：恢复旧版本时会保留它当前的示例。在开始保存版本之前创建的智能体，会在第一次更改时，把原来的样子保存为它的第一个版本（“在开始保存版本之前”）。

## 用示例检查智能体

示例让你在修改智能体之后，检查它是否仍能完成自己的工作，就像应用的示例一样。每个示例包含一条用来试它的消息，以及它的回答必须满足的要求。在智能体的页面上，找到 **示例**：

1. **添加示例**：你可以按需给它起个名字，像对智能体说话那样写下**用来试它的消息**，再为一个好的回答应做到的每件事添加一项检查。检查可以是一句普通的话，例如“它写出了两个拉取请求”或“它没找到新内容时会明确说明”，由辅助模型对照回答来判断；也可以是针对它给出内容的规则，就像应用的检查项一样：`{{reply}} contains Lisbon`，或者对于会交回结果的智能体，针对它的某个字段写 `{{result.count}} > 0`。然后点 **保存示例**。一个智能体最多可以有 10 个示例，每个示例最多有 8 项检查。
2. **试一试这些示例**（或点某个示例旁边的烧瓶按钮，只试这一个）会先说明它将要做什么以及要花多少：它会以该智能体的身份、在哪个档位上启动多少个会话，大约花费多少（根据它上次试运行的花费，或它的会话本月的花费估算；第一次试运行之前还没有依据），以及它每月预算还剩多少，试运行也会计入其中。点 **全部试一试**。
3. 每个示例都在各自的会话中运行，以该智能体的身份、在它的档位上启动，使用各自独立的空文件夹（结果保存后会被删除，对话会保留），并且不会出现在你的会话列表里。它不会发出任何东西：本来会通过你已连接的应用发出的内容，会被保留为“本来会发出的内容”，而它交回的内容只会留在这次试运行中。结束后，会读取它的检查项。需要交回字段的智能体，还必须交回一个结果。

之后每个示例会显示上次试运行的情况：**通过**、有多少项检查未通过、**未完成**，或者 **等你处理**（它的会话在问你一件事：请打开它），并附上时间和花费。点一个示例，可以看到它的消息、每项检查及其结果（✓ 或 ✗）、它交回的内容、它的回复，以及 **打开它的会话**。如果在示例上次试运行之后你修改了智能体，页面会用 **再试一次** 提示你。示例从不会自行运行。

## 智能体在哪里工作

除非你为智能体指定项目，否则它在 **全部** 项目中工作。只在部分项目中工作的智能体：

- 只会在这些项目中提供：当选中了它的某个项目时，开始页面的智能体菜单才会列出它，其他智能体也只能在它所在项目的会话中把工作交给它；
- 如果它只在一个项目中工作，就在该项目的文件夹中工作，并使用该项目的知识、记忆、准则和技能；
- 显示在它每个项目的 **智能体** 标签页上（参见[项目](/guide/projects)）。

如果你在开始页面选了一个项目，而当前选中的智能体不在该项目中工作，开始页面会改选该项目自己的智能体，否则选通用。

## 智能体何时工作：定时运行

智能体会在你以它的身份开始会话时、其他智能体把工作交给它时，以及按它的定时运行来工作。定时运行就是以该智能体的身份运行的定时任务：在某个时间、每隔一段时间、一次性、在某个网页或订阅源发生变化时，或者在其他服务调用它的 webhook 时（参见[定时任务](/guide/tasks)）。

- 在智能体的页面上，点 **添加定时运行** 会打开任务编辑器，已选好该智能体并填好时间：给它起个名字，写下每次运行开始时的消息，然后保存。
- 列表中的每个定时运行都有一个开关，用来暂停或开启它；还有一个垃圾桶图标，会在询问“删除 *名称*？”之后将其删除。点击它的名称可以修改：表单里在 **试运行** 旁边也有 **删除**。内置智能体也是如此：研究员上的定时运行可以像其他任何定时运行一样被暂停或删除。同样的开关和 **删除** 也出现在[定时运行](/agents/schedules)中，位于它的日历菜单和列表里。
- 与新智能体一起起草的定时运行，会以它的身份创建。
- 智能体为你的某个智能体添加的定时运行，在提供该选项的地方会以 **自动** 开始（参见[定时任务](/guide/tasks#model-effort-permissions-and-other-options)），除非该智能体指定了自己的模型。按档位思考的智能体仍会使用它的档位。
- 在任何会话中，智能体都可以为你添加、修改或删除某个智能体的定时运行（参见[让智能体来创建](#ask-an-agent-to-make-one)）。
- 不再需要的定时运行会自行消失：一次性的定时运行在成功运行一次后消失；而某次运行发现任务已完成（它等待或监视的事情已经发生，正如它的消息所说那时应停止）的定时运行也会消失，运行的通知会说明这一点。智能体被删除时，它的定时运行也会一并删除。

每个定时运行也都在[设置 → 智能体 → 定时任务](/settings?s=tasks)中，与其他所有任务放在一起；任务的 **智能体** 选项就是它的运行所用的智能体。智能体页面栏中的 [**定时运行**](/agents/schedules)（手机上是顶部的标签页）会把它们和其他所有任务一起按周显示：运行了什么、结果如何、接下来运行什么，列表中每一项都带有 **智能体 ·** 和智能体的名称；点它的铅笔会打开该智能体的页面。

## 智能体用什么思考：档位

档位按工作类型而不是按名称来选择模型：

- **快速**：最便宜，适合结果可以检查的、小而非常明确的工作，例如有针对性的修改、提取事实、排序、格式化和简短摘要。
- **标准**：中等规模的明确任务：已经写清楚的修改、测试、针对既定问题的研究、按提纲写的草稿。
- **最佳**：会话的主智能体。它弄清楚被要求做什么、制定计划、带领子智能体并检查它们的工作。
- **最大值**：最强，适合最难的问题：顽固的缺陷、证明、有许多约束的设计。

设为某个档位的智能体，会使用该档位对应其所运行程序的模型，除非会话另外选了模型；设为 **自动**（默认）时，它使用它启动处所选的模型：开始页面、定时任务（它本身也可以是 **自动**），或者把工作交给它的智能体。在开始页面上，这个选择本身也可以是 **自动**：最佳，如果问题太难则升到最大值（参见[档位：为每类工作配一个模型](/guide/agents-models#tiers-a-model-for-each-kind-of-job)）。

[设置 → 智能体 → 模型 → 档位](/settings?s=models&find=Tiers)用一张表说明每个档位的含义，每个程序一列：对于 **Claude Code**，是一个模型（起初有 Haiku、Sonnet、Opus 和最新的 Fable）和一个思考强度；对于 **Codex**，是一个模型和一个思考强度（起初有 Luna、Terra、Sol 和 Astra；如果你的套餐没有其中某个，就用它提供的最接近的一个，当两个档位共用一个模型时，较高的档位用更高的思考强度）；对于 **Custom**，是你的某个 Custom 模型：你没有改动的档位会取 Custom 所拥有的模型中同类最新的一个（参见[档位：为每类工作配一个模型](/guide/agents-models#tiers-a-model-for-each-kind-of-job)），如果只有小型或本地模型，则保持为空，这样会沿用会话所选的模型。你没有改动的档位会跟随其程序中同类最新的模型。**恢复默认** 会把它们恢复原状。

**它启动的子智能体，最高不超过** 限制智能体所启动的 Hydor 子智能体的档位：被要求用更高档位时，子智能体会使用这里设定的档位。子智能体也永远不会使用高于其负责人所用的档位。明确指定的模型会按指定的使用。

**检查未通过时升档**（默认开启，除非你关闭它）：智能体按某个档位启动的 Hydor 子智能体，如果它的回复没有通过一次快速检查（由辅助模型对照它的任务说明和它的回复来判断），或者因出错而停止，就会升高一档重新运行，最高到最佳，并且不会超过该智能体允许的最高档位。只检查它对任务说明的回复：之后对负责人或你的消息所作的回复，绝不会让整项工作重新来一遍。负责人会得知它升档了以及原因，新的子智能体也会被告知第一个为什么没达到要求。按档位运行失败的智能体定时运行，也会升高一档重新运行，最高到最佳。负责人在发现结果不够好时，也可以自己让子智能体升档。

## 把工作交给其他智能体的智能体

智能体可以把自己的一部分工作交给一个与它并行处理的新会话：Hydor 子智能体（参见[深度研究、第二意见和多个智能体](/guide/research)）。它可以启动：

- **一个普通子智能体**，为它的那部分指定一个档位：小而非常明确的工作用快速，中等规模的明确任务用标准（没有指定时子智能体得到的就是这个），独立的困难部分用最佳；
- **你的某个智能体**，按名称指定：它使用自己的指令、工具、连接、模式和档位来工作，它的回复会回到提出请求的智能体那里。

谁可以把工作交给谁：

- 以内置智能体（或没有智能体）身份工作的会话，可以把工作交给在那里工作的你的任何智能体。
- 你的某个智能体，只能把工作交给它的 **Team** 中列出的智能体。
- 关闭了 **其他智能体可以把工作交给它** 的智能体，不接受任何人交来的工作。
- 被指定的智能体只在它自己的项目中工作，并且使用的权限模式绝不会比提出请求的会话更宽松。

在对话中，一轮所启动的 Hydor 子智能体会合并显示为该轮下方的一张卡片，每个一行，包含它的标题、它所用的智能体（或“Hydor 子智能体”）、它的档位、程序和模型、当前状态和花费，如果它升过档，还会显示从哪个档位升上来以及原因（指向该行即可看到）；点一行可以打开它的对话。参见[子智能体](/guide/sessions#subagents)。项目的 **智能体** 标签页会显示它的哪些智能体把工作交给哪些智能体。

有自己对话的智能体，会把工作放进它的收件箱，而不是新建会话，它会在处理到时给出回答（参见[有自己对话的智能体](#an-agent-with-a-conversation-of-its-own)）。

## 每月预算

智能体的每月上限（在 **所有设置** 中的 **预算**，或它页面上的那句话）限制它的会话在一个月内的花费（从每月 1 日起，按这台电脑的时间）：

- 以它的身份开始的每个会话，其花费上限为预算的剩余额度（如果会话自己有上限，则取较低的那个）。
- 它的普通子智能体的花费会计入其中；被指定的智能体所做的工作，计入那个智能体自己的预算。
- 预算用完后，在下个月之前不会再以它的身份开始任何会话：定时运行会说明为什么无法开始，它的卡片上会显示 **预算已用完**。

每个会话的花费按[用量和费用](/guide/usage)中的方式计算。保持为 **不限** 即表示没有上限。

## 智能体交回什么

如果不做任何设置，智能体会在对话中交回它的回复。你可以在 **结果**（位于 **所有设置**中，或通过它的句子“它交回*它的回复*”）里为它设置字段和去处，这样每个任务结束时，它都会交回一份带有这些字段的结果，并在送往任何地方之前先经过检查：

- **每个结果的字段**：为每个字段设置名称和类型（文本、长文本、数字、是或否、日期、链接、列表，或带列的表格），以及是否必填。智能体用它的 hand_back 工具填写这些字段；不符合要求的结果会连同需要修正的地方一起退回给它。
- **每个结果的去处**，除了对话之外：
  - **保留的页面**：**同一个页面，更新**（新智能体默认使用此项）：第一次运行时会创建一个以智能体命名的网页，如果智能体在某个项目中工作，网页就放在该项目里；之后每次运行都会为这个网页放入一个新版本，所以你总是打开最新的一版，之前的版本保存在它的版本记录中。你重命名过的网页会保留你起的名字。如果想让每次运行都有一个独立的网页，请改选 **每次运行一个新页面**，网页以智能体和日期命名（在有这个选项之前创建的智能体仍然这样做）。
  - **电子表格中的一行**：每次运行都会在同一个电子表格中添加一行：一个 **日期** 列记录运行时间，然后是每个字段各一列，顺序与字段的顺序一致。数字会作为数字写入，日期作为日期，链接作为链接，所以合计、公式和图表都能直接使用；列表或表格会作为易读的文本放进一个单元格（“牛奶；鸡蛋”）。把电子表格保持为 **新建一个** 时，第一次运行会创建一个以智能体命名的电子表格；你也可以选择自己的某个电子表格以及要写入的标签页（不存在的标签页会被添加）。参见[电子表格中的一行](#a-row-in-a-spreadsheet)。
  - **一封邮件**：把结果作为邮件发给你指定的人（一个或多个地址），邮件带有主题（`{date}`、`{time}` 和 `{agent}` 会自动填入；留空时使用智能体的名称和日期），由你已连接的某个邮件账户发出（**从**；如果不选，则使用第一个；参见[已连接的应用、密钥和工具](/guide/connections#connect-your-email)）。它在任何邮件程序中都显示良好，每个字段都在各自的名称之下，表格显示为表格。由于收件人是你在这里亲自指定的，所以每个结果一准备好就会发出，不会在发件箱中等待。
  - **一条通知**，内容为结果的第一行；
  - **它工作文件夹中的一个文件**，例如 `reports/{date}.md`：`{date}`、`{time}` 和 `{agent}` 会自动填入，以 `.json` 结尾的文件名会写入 JSON 格式的字段，其他文件名则写入 Markdown，并且路径永远不会指向文件夹之外；
  - **一个 webhook**：把结果以 JSON 的形式通过 POST 发送到一个 https 地址；如果你指定了密钥库中的某个密钥，就会用它签名，并且只发送给该密钥允许的主机（参见[已连接的应用、密钥和工具](/guide/connections)）。

在这些输入框中输入的内容，会在你离开输入框或按下 Enter 后生效。设置中会显示它第一次运行时创建的网页和电子表格，并附有打开它们的链接。

### 电子表格中的一行

各列是根据表格第一行的标题找到的，所以电子表格仍然由你来安排：你可以移动列、调整列的样式（设为欧元格式的列会一直保持欧元格式），也可以在它们旁边添加你自己的列。你自己的列中的公式（比如累计总和）会像电子表格的表格那样向下填充到每个新行，读取已有行的图表也会把新行包含进来。表格下方的合计会妨碍新行的添加：请把它们放在单独的一列或另一个标签页里，并对整列使用公式（`=SUM(B:B)`）。之后给智能体添加字段时，会在末尾新增一列，原有的列保持不动；你重命名过的标题将不再匹配它的字段，该字段会得到一个新列（给字段起同样的名字，就能让它们继续对应）。每次运行添加的行都是电子表格的一个新版本，和任何修改一样，所以它的公式、图表和评论都保持原样。

### 它的结果历史

智能体的页面以表格形式显示 **它交回的结果**：每个结果一行，最新的在最前面，包含结果到达的时间、每个字段各一列，以及它的去向（**送往**：每个去处一个标记，无法送达的显示为红色；指向某个标记可以看到发生了什么，点击保留的页面可以打开它）。点击某一行可以查看完整的结果，每个字段都完整显示，并可 **打开它的会话**。表格可以滚动，**显示更早的** 会载入更早的结果。智能体会保留一年内的结果，最多 500 条（每天运行一次的智能体能保留整整一年；每小时运行一次的大约保留三周）；太长而无法保存在这里的字段会有说明，而在它送往的地方则是完整的。它填写的网页和电子表格会以链接的形式显示在表格上方。

## 拥有自己对话的智能体

大多数智能体每次都会开始一个新会话。打开 **保持一个对话，带收件箱**（在 **所有设置**的 **位置和时间** 下，或在它句子中的“何时”部分），智能体就会改为保持一个属于自己的对话，在第一次需要时创建；如果它在某一个项目中工作，就创建在该项目的文件夹中：

- 发给它的消息会在它的 **收件箱** 中等待，并逐条进入它的对话，每条都要等前一条得到回答之后：包括你从它的页面发送的消息，以及其他智能体交给它的消息。
- 它的定时运行会发到同一个对话中，并等待正在进行的一轮结束；每次运行都会显示在它的日程历史中，和任何运行一样。
- 每个回答都会回到发送者那里：其他智能体会把它当作一条消息收到，而你发的则会收到一条通知。
- 它会记住之前的内容，和任何对话一样。
- 每条消息进入时，都会检查它的每月预算。

在它的页面上，**收件箱** 列出各条消息，每条都带有它的状态（**排队中**、**正在处理**、**已回答**、**没有回答**）和它的回答，还有一个向它发送消息的输入框，以及打开对话的 **它的对话**。

## 以智能体身份开始会话

1. 打开[起始页](/)。在消息框下方有一行显示由谁来完成工作：程序、模型、文件夹，以及 **智能体** 标签，它显示当前选中的智能体。
2. 点击 **智能体**。在 **以以下身份开始** 下，内置智能体排在前面，然后是你自己的，位于 **你的** 之下：即在任何地方都能用的，以及在所选项目中能用的。
   - 在电脑上，名称以网格排列，每行两个。指向某一个，就能在网格下方看到它的说明：它的描述，以及当它建议使用某个程序时，“使用”后面跟着该程序及其模型。
   - 在手机上，菜单会从屏幕底部以面板形式打开，列出每个智能体及其说明。
3. 选择一个。然后输入你的任务并按 Enter，或点击 **开始**。

菜单末尾的 **创建或修改智能体** 会打开[智能体页面](/agents)。智能体页面上的 **开始会话** 会打开选中了该智能体的起始页。

在起始页上选择智能体会带来这些变化：

- **程序、模型和权限**：如果智能体建议使用某个程序，起始页就会切换到该程序；如果它按档位选择模型，就使用该档位的模型，否则在智能体指定了模型时使用该模型。如果它有权限模式，起始页的 **权限**（位于 **选项** 下）会改为该程序中对应的模式。开始之前，你仍然可以修改其中任何一项。
- **连接**：智能体打开的已连接账户，会在新会话中处于开启状态。
- **文件夹**：除非你自己选了文件夹，否则由智能体决定。大多数智能体会在 **新建任务文件夹** 中开始；程序员，以及设置为“起始页上的文件夹”的智能体，则使用当前显示的文件夹。在项目中，选择智能体永远不会把你带出该项目。当智能体改变了文件夹时，输入框会显示为该位置保留的选择，以及你选中的智能体。

起始页会为每个位置（每个项目、每个文件夹和 **新建任务文件夹**）记住所选的智能体，在你使用的任何设备上都一样，连同该位置的其他选择。尚未选过智能体的位置，在项目有自己的智能体时会使用项目自己的智能体，否则使用通用。已不存在的智能体，或在所选项目中不能使用的智能体，也会让位于这个默认值。

在文件夹菜单中选择一个项目，会打开带有该项目所选内容的输入框；在尚未做过任何选择的项目中，其中包括该项目用来开始会话的智能体（如果它有的话）（参见[项目](/guide/projects)）。

## 在会话中切换智能体

会话的消息框会显示它当前所用的智能体，你可以随时切换到另一个：比如资料收集完毕后，从 **研究员** 切换到 **撰稿人**。

1. 它是消息框下方那个打开 **选项** 的标签的第一行，标签中首先显示的就是它，例如“研究员 · Opus 5.5”。
2. 点击它。在 **切换到** 下选择另一个：菜单与起始页相同，电脑上是网格，手机上是从底部弹出的面板。
3. 应用会提示“该智能体将从你的下一条消息起以 *名称* 的身份工作”。

从你的下一条消息起，会话就以新的智能体身份工作，对话继续进行：

- 程序会随你的消息一起得知这次切换（对话中不会显示）。
- **Claude Code 和 Codex** 在启动时读取它们的指令，所以当会话空闲时，它的程序会在你的消息之前重新启动，带上新智能体的指令和限制；这条消息会多花一点时间。如果正处于一轮之中，或者正在朝着目标工作，或者有后台任务，它会改为随你的消息一起收到新指令，并在之后空闲时的某条消息处重新启动。
- **Custom** 在每一轮之前读取它的指令。其他智能体（Gemini CLI、OpenCode……）会随你的消息收到新智能体的指令。
- 新智能体打开的已连接账户会在会话中开启，取代之前那个智能体的；你自己为会话打开或关闭的设置保持不变。如果它有权限模式，会话会切换到对应的模式；当它建议使用会话自己的程序时，也会切换到它的模型。程序本身保持不变：要把对话转移到另一个程序，参见[在另一个智能体中继续](/guide/sessions#continue-in-another-agent)。

没有智能体而开始的会话（在 VS Code 或终端中，或在应用有智能体之前创建的）在那里会显示 **无智能体**：选择一个就能给它指定智能体。会话的菜单（⋯）→ **会话设置** → **智能体** 也会显示它；点击它会打开该智能体的页面。

## 查找某个智能体的会话

以非常用智能体开始的会话，会在侧边栏中注明：它那一行的第二行以智能体的图标和名称开头（“规划师 · web-agent · 5d”，或在工作时显示“研究员 · 工作中 · 2m 10s”）。常用的智能体指的是：对于在有自己智能体的项目中的会话，是该项目自己的智能体（**它的会话开始时使用**，位于项目的详情中）；对于其他所有会话，则是通用。在 Hydor 之外开始的会话，以及后来被你删除的智能体，同样不会被标出。筛选和搜索依据的是每个会话实际开始时使用的智能体，包括常用的那个。如果只想看某一个智能体的会话：

- 点击侧边栏顶部的筛选按钮（**筛选和分组会话**），在 **智能体** 下选择该智能体。它会列出你的会话所使用过的智能体，用得最多的排在前面（最多八个），每个都带有会话数量；**所有智能体** 会再次显示所有会话。只要有会话是以某个智能体开始的，这一部分就会显示。
- 或者打开该智能体的页面，点击 **最近的会话** 旁的 **在侧边栏中显示全部 23 个**（当智能体有八个或更少的会话时，显示为 **在侧边栏中显示它们**）。它会打开起始页，侧边栏中只显示该智能体的会话，并清除其他筛选；在手机上会打开菜单。
- 或者在搜索框中输入智能体的名称（Ctrl+K）：“辅导老师”会找到以辅导老师开始的会话。通用不包括在内，因为大多数会话都是以它开始的。会话在那里的预览会列出它的 **智能体**。

筛选开启时，**新建会话** 下方会有一个带图标的标签显示它：点击它的 × 可再次显示所有会话。智能体筛选可以和其他筛选（**运行于** 和 **项目**）一起使用，例如某个智能体在某个项目中的会话。如果该智能体被删除，列表会再次显示所有会话。参见[侧边栏](/guide/start#the-sidebar)。

## 创建副本或删除智能体

在智能体的页面上：

- **创建副本**（对所有智能体都可用）：在 **配置** 处打开窗口，作为一个新智能体，所有内容都已填好，名称为“*名称*（副本）”。按你的想法修改，然后点击 **创建智能体**；它的页面就会打开。你可以这样来创建内置智能体的自己的版本。
- **删除**（仅限你自己的）：会先询问“删除 *名称*？”。以它开始的会话会继续进行，但不再带有它的指令；它的定时任务会随它一起被删除，因为这些任务是为它写的；原本可以把工作交给它的智能体，也不再列出它。以它开始会话的项目会被清除这一设置：这些项目的会话会再次以通用（或你选择的智能体）开始。它的结果历史会随它一起删除；它填写过的网页和电子表格仍保留在原处。

搜索框（Ctrl+K，Mac 上为 ⌘K）也能按名称和描述查找智能体；选择一个就会打开它的页面。

## 将智能体分享为文件

你的一个智能体可以打包成一个文件，用来留存，或者交给同事，由同事安装到他们的 Hydor 上。

- **下载智能体**：打开它的页面，然后点击 **更多**（⋯）→ **下载为文件**。内置智能体也可以下载，下载后可作为某人自己的智能体安装。文件（`.hydor-agent`）包含它的指令、它可以使用什么、它的档位、程序和模型、它优先使用的技能、它的权限模式、预算和其他设置、它交办工作的智能体（按名称）、它交回的内容以及结果送往的地方的类型、它按时钟运行的定时任务（作为建议），以及它的示例。你的任何个人内容都不会放进去：它工作所在的项目、它使用的已连接的账户、它的结果写入的网页和电子表格、结果通过邮件发给谁以及从哪个账户发送，还有它的 webhook 地址和密钥，都会被略去；它那些由监视、webhook 或日期触发的定时任务也留在原处。文件会用文字列出被略去的内容，供你重新设置。
- **安装智能体**：在[智能体页面](/agents)打开 **新增**，选择 **从文件安装智能体**（在手机上，按 **安装**），然后点击 **选择文件** 并选取一个 `.hydor-agent` 文件（也可以把文件拖到那里）。在保存任何内容之前，会有一张卡片展示它：它的名称和一句话介绍、**它带来什么**（它的指令、它可以使用什么、它的档位、它交回的内容、它的示例、它建议的定时任务）、**它需要你做什么**（被略去的内容，以及它要交办工作但你没有的智能体），还有供你阅读的 **它的指示**。你的同名智能体不会被改动：新的会以“名称 (2)”的形式安装在它旁边，除非你选择 **替换我的**，这会把你的智能体变成这一个，作为新版本（原来的样子保留在它的 **版本** 中，你的示例也会保留，排在文件中的示例之后）。**添加它建议的定时运行（暂停）** 会添加它的定时任务，处于关闭状态，直到你自己打开。按 **安装**，它的页面就会打开。

有些内容在导入时会发生变化，卡片上会说明：从不在行动前询问的智能体（**完全访问**）会以 **接受编辑** 开始；在这里尚未设置的程序会让位于开始页上选择的那个；来自更新版 Hydor 的文件会带入这个版本所认识的内容（其余部分请更新 Hydor）。不是智能体文件或已损坏的文件会被拒绝，并说明问题所在；应用的文件则改在[应用页面](/guide/apps#share-an-app-as-a-file)安装，Claude Code 的智能体文件用 **导入** 导入（见下文）。

## 导入 Claude Code 的智能体文件

Claude Code 可以把它自己的智能体保存为 `.claude/agents` 文件夹中的 Markdown 文件：开头是一小段头部，写明智能体的名称、描述、模型和工具，下面是它的指令。应用会把这些文件变成你的智能体，这样这里的每个程序都能以这种方式工作。

1. 打开[智能体页面](/agents)，然后点击 **新增** 和 **导入 Claude Code 智能体文件**（在手机上，点击顶部的 **导入**）。
2. **导入 Claude Code 智能体** 会列出它找到的智能体文件：你自己位于 `~/.claude/agents` 的文件（标记为 **你的**），以及在[文件](/files)中打开的文件夹里 `.claude/agents` 文件夹中的文件（标记为 **此文件夹**）。要查看某个项目自己的智能体，请先在文件中打开该项目。
3. 点击文件旁边的 **导入**。它的智能体就会出现在智能体页面和开始页的智能体菜单中。
4. 如果文件在别处，点击 **选择文件**（“或者来自此设备的智能体文件”），然后选取 `.md` 文件。

文件必须是 Markdown（`.md`）格式，且不超过 256 KB。应用从中提取的内容如下：

| 智能体文件中的内容 | 智能体中的对应项 |
|---|---|
| `name`（没有时用文件名） | **名称**：“code-reviewer”变成“Code reviewer” |
| `description` | **一句话介绍**：它的第一句话，不含示例 |
| `model` | **运行于**：使用该模型的 Claude Code（“inherit”沿用开始页的设置） |
| `tools` | **它可以使用什么**，按类别；没有 tools 行的文件可以使用全部 |
| `permissionMode` | **权限模式**：default → 询问，acceptEdits → 接受编辑，bypassPermissions → 完全访问，plan → 计划 |
| `skills` | **优先使用的技能** |
| 头部下面的文字 | **指令** |

图标会根据智能体的名称和描述来选择（研究用望远镜，写作用笔，审查和测试用代码，等等）。导入的智能体在开始页上的文件夹中工作，就像 Claude Code 的智能体在项目中工作一样。

已导入的文件在列表中显示 **更新**，而不是 **导入**。**更新** 会把文件重新读入同一个智能体：它的各项内容会重新变成文件中的内容，只有你选择的图标会保留。从你的设备中选择文件总是会生成一个新的智能体。

## 任务文件夹：没有文件夹的任务在哪里工作

很多任务不属于任何文件夹：一份旅行计划、一封信、一个问题。对于这些任务，开始页上的文件夹标签显示 **新建任务文件夹**，当你按 **开始** 时，应用会为这个会话新建一个文件夹，用日期加上你消息中的几个词来命名，例如 `~/Hydor/2026-10-31-plan-trip-lisbon`。智能体把它的工作保存在那里，你可以在[文件](/files)中再次找到它。

名称的生成方式：

- 日期，按你所在的时区。
- 你消息中最多五个词，略去无实义的小词（a、the、please、help、me……）、链接和开头的 `/command`，去掉重音符号，最多 40 个字符。如果一个词也不剩，就用 `task`。
- 如果这个名称已被占用，就加上 `-2`、`-3`，依此类推。

### 选择任务文件夹或你自己的文件夹

打开开始页上的文件夹标签：

- **新建任务文件夹**（“在 ~/Hydor 中新建一个”）会为每个会话新建一个文件夹。
- 选择一个项目、最近用过的文件夹，或通过 **浏览** 找到的任意文件夹，也可以输入它的名称或路径，会话就会改在那里工作（见[项目](/guide/projects)和[会话](/guide/sessions)）。

在你做出选择之前，由智能体决定：除程序员之外的内置智能体，以及设为“新的任务文件夹”的你自己的智能体，会使用任务文件夹；程序员以及设为“开始页上的文件夹”的智能体会使用所显示的文件夹；只在一个项目中工作的智能体会使用该项目。开始页会记住你的选择。选择另一个智能体会把选择权交还给它，除非自页面打开后你选过文件夹，或你正处在某个项目中。文件夹变化时，输入框会显示为该位置保留的选择，以及你选的智能体。

任务文件夹不会挤占文件夹菜单：菜单中列出的最近用过的文件夹不包含它们。在免提模式下通过语音开始的会话也会得到任务文件夹，除非开始页最后一次设置的是某个文件夹或项目（见[文档、图片、视频和语音](/guide/documents-voice)）。

### 移动任务文件夹

1. 在[设置 → 功能 → 你的智能体](/settings?s=assistants&find=Task%20folders)中，于 **任务** 组里找到 **任务文件夹**（它的 (i) 说明：不带文件夹开始的会话会在这里得到一个新文件夹，按日期和任务命名，而程序员则改在你选的文件夹中工作）。
2. 点击文件夹的名称。在 **工作文件夹** 下输入路径（输入时会推荐文件夹，以及你最近用过的文件夹），然后点击 **使用此文件夹**。请给出完整路径，或以 `~` 开头表示你的主文件夹。

从此以后，新的任务文件夹会放在那里；已经建好的文件夹保持原处。你改动之后会出现 **返回 ~/Hydor**，用来恢复默认设置。它下面的一行显示新文件夹的样子。获得自己文件夹的新项目也会放在这里，位于其中的 **项目** 文件夹内（见[项目](/guide/projects)）。

## 任务完成后清理

[设置 → 功能 → 你的智能体](/settings?s=assistants&find=Clean%20up%20after%20a%20task)的 **任务** 组中有一个开关：**任务完成后清理**（它的 (i) 说明智能体会删除什么）。除非你关闭它，否则它是开启的，并且适用于每个会话，无论会话以哪个智能体工作。

开启后，智能体在任务中的最后一步是清除它在过程中产生且不再需要的东西：

- 临时文件和测试文件、临时文件夹和数据、调试输出和截图；
- 它创建的、已合并或已废弃的 git 分支、工作树（仓库的额外副本，各在自己的分支上）和暂存；
- 它启动的进程、服务器或容器，除非你希望保持运行。

它会保留你要求的内容，以及仍需有人审阅或合并的工作（例如含有未合并提交的分支），绝不删除不是它创建的任何东西，遇到体量大或不明确的情况（大型下载、任何共享内容）会先问你。它逐一点名要删除的每一项，而不是按模式批量删除，并用一行话说明删除了什么、留下了什么。应用自带的清理技能里有具体方法（见[技能](/guide/skills)）。

关闭后，智能体会把它们创建的东西留在原处。无论哪种情况，智能体从下一个会话开始遵循这一改动（Custom 从它的下一条消息开始）。

## 每个智能体都有的三个命令

应用启动的每个会话，无论使用 Claude Code、Codex 还是 Custom，都能在 shell 中找到三个小命令，并会被告知它们的用途。你不需要做任何事就能拥有它们：无论是 Mac、Windows 和 Linux 的桌面应用、Docker，还是你从代码仓库运行的副本，应用都会自行把它们放好，你的电脑上无需安装任何东西。

- **`waitfor`** 用一次调用等待耗时较长的作业完成，否则智能体就得每隔几秒反复检查。它可以等待某个程序退出、某个文件出现、日志中出现某一行、某个网址有响应、集群上的 Slurm 作业离开队列，或者某个命令执行成功。它可以在日志第一次出现表明作业崩溃的行时停止，完成后显示日志末尾，并在超过你设定的时间后放弃。它还可以自己启动一个命令并等待它结束。当等待可能超过几分钟时，智能体会把它作为后台命令运行，这样对话可以同时继续。
- **`edits`** 用一次调用完成多处精确的查找替换，涉及多少个文件都可以。只有当每一处改动要查找的文本都恰好出现一次时才会写入，因此只要有一处对不上，你的文件就保持原样。它会打印改动的行及行号，智能体就不必重新读取文件。
- **`sym`** 查找某个东西（函数、类、类型）在哪里定义，并带着准确的行号打印完整内容，支持 TypeScript、JavaScript、Python 和 Rust 文件。它还可以列出某个名称在哪些地方被使用，以及一个文件中的各项声明。它是按代码来解读的，所以字符串或注释里的花括号不会干扰它，而且它不需要索引。对于纯文本和其他语言，智能体仍使用 grep。

第四个命令用于证明：**`leancheck`** 判断 Lean 文件中的证明是否成立（能够构建、没有任何内容留作 `sorry`、每个定理只依赖 Lean 的标准假设，并且 Lean 的核心检查器接受每一步）。只有全部满足时它才算成功，因此可以用作目标的命令检查项（`leancheck Proofs/Main.lean`）。它需要先安装好 Lean（见[证明：用 Lean 检查](/guide/researchers#proofs-checking-them-with-lean)）。

简单来说，智能体在等待、多处编辑和阅读代码上花费的调用次数更少。每个命令都可以用 `--help` 查看自身说明，智能体想了解某个选项时读的就是它。智能体还会被要求用更少、更充实的步骤完成工作（把彼此独立的查找一起发出，并按照长任务预计的耗时来安排检查间隔）；这是应用给智能体下达指示的一部分，而不是由你编辑的准则。

有几点限制：

- 等待 systemd 服务仅在 Linux 上可用。
- 在 Windows 上，按名称等待程序需要 PowerShell；等待命令或 Slurm 作业需要 [Git for Windows](https://git-scm.com/download/win)，不过智能体的命令本来就需要它（它们在 Git 的 bash 中运行）。
- `sym` 能识别 TypeScript、JavaScript、Python 和 Rust 文件中的定义，当它无法判断某个定义在哪里结束时会如实说明。
- 在单个浏览器标签页中工作的会话没有 shell，因此不会获得这些命令。

应用启动时会按智能体 shell 的运行方式把每个命令试一次，只把能用的命令告诉智能体，所以绝不会提供在你电脑上无法运行的命令。智能体从下一个会话起按改动行事（Custom 从下一条消息起）。

要关闭此功能，请在启动应用时设置环境变量 `HYDOR_SHELL_TOOLS=0`（桌面应用和服务写在 `~/.config/hydor.env` 中，Docker 写在 `.env` 中）。这样智能体就不会得到额外的命令，也不会听到任何相关说明。设置中没有对应的开关。已经在运行的会话保留启动时拥有的命令。

## 智能体还会用在哪里

- **项目**：项目可以指定它的会话以哪个智能体开始（“它的会话以此开始”）；在开始页选择该项目就会选中它。它的 **智能体** 标签页显示在其中工作的智能体。见[项目](/guide/projects)。
- **应用**：应用可以指定一个 **智能体**，它的运行就以该智能体开始（从公开页面发起的运行除外）；应用中的各个智能体步骤也可以各自指定一个。见[应用](/guide/apps)。
- **定时任务**：任务以它的 **智能体** 选项所指定的智能体运行；智能体在会话中为你设置的任务，则以该会话相同的方式运行。见[定时任务](/guide/tasks)。
- **免提语音**：你通过语音开始的会话，会在开始页上最后选择的位置开始，带着它的选择，以在那里选中的智能体运行（否则用项目自己的智能体，再否则用通用）。
