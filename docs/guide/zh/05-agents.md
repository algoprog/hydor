# 智能体

智能体是会话所扮演的角色：它的指令、它可以使用什么、在哪里以及何时工作、它用什么档位的模型思考、它把工作交给哪些其他智能体，以及它每月可以花多少钱。本主题涵盖智能体页面、应用自带的智能体、通过描述它该做什么来创建你自己的智能体、修改智能体、智能体在哪里工作、它的定时运行、档位、把工作交给其他智能体的智能体、每月预算、智能体的版本和检查它的示例、以智能体身份开始和切换会话、把智能体分享为文件、导入 Claude Code 的智能体文件、你没有选择文件夹时会话获得的任务文件夹，以及让智能体在任务结束后做清理。

![智能体页面：你的智能体各以一张卡片显示它的运行状况，内置的智能体在它们下方](images/agents.webp)

## 什么是智能体

开始会话时，你在开始页面上选择一个智能体，之后也可以在会话的消息框里把会话切换到另一个智能体。智能体的指令会叠加在程序自身的指令之上，所以同一个程序在一个会话里可以是严谨的研究员，在下一个会话里则是耐心的辅导老师。智能体适用于所有程序：Claude Code、Codex、Custom（应用自己的智能体），以及支持 ACP（Agent Client Protocol）的智能体，例如 Gemini CLI 或 OpenCode。

一个智能体可以包含：

- **指令**：它是谁，以及它如何工作。它会被要求全程按这种方式工作，但你在对话中提出的要求优先。
- **在哪里工作**：所有地方，或只在你的部分项目中（见[智能体在哪里工作](#where-an-agent-works)）。
- **何时工作**：在你或其他智能体提出要求时，以及按它自己的定时运行（见[智能体何时工作：定时运行](#when-an-agent-works-schedules)）。
- **它用什么思考**：自动，或某个档位（快速、标准、最佳或最大值），其模型由你为每个程序分别设置一次（见[智能体用什么思考：档位](#what-an-agent-thinks-with-tiers)）。
- **它的团队**：它可以把部分工作交给的其他智能体，以及其他智能体是否可以把工作交给它（见[把工作交给其他智能体的智能体](#agents-that-hand-work-to-other-agents)）。
- **每月预算**：它的会话每月可以花多少钱（见[每月预算](#a-monthly-budget)）。
- **它交回什么**：每个结果的各个字段（经过检查），以及每个结果去往何处：保留的网页、电子表格中的一行、发给他人的电子邮件、通知、文件、webhook（见[智能体交回什么](#what-an-agent-hands-back)）。
- **它自己的对话**：它可以保留一个对话，带有收件箱，用来接收你和其他智能体发来的消息，它的定时运行也会在其中发帖（见[有自己对话的智能体](#an-agent-with-a-conversation-of-its-own)）。
- **它可以使用什么**：读取文件、创建和修改文件、运行命令、使用网络、使用浏览器、使用电脑（在开启“电脑使用”的桌面应用中，包括屏幕、鼠标和键盘），以及其他工具。可以全部保持开启，也可以关闭其中一些。
- **优先使用的技能**：当技能适合任务时，它在开始前会先加载这些技能（见[技能](/guide/skills)）。
- **已连接的应用**：在它的会话中要开启的已连接账户（见[已连接的应用、密钥和工具](/guide/connections)）。
- **建议的程序、模型和权限模式**：在开始页面上随智能体一起选定，你在开始前仍然可以更改。
- **它的会话从哪里开始**：当你没有选择文件夹时，是它们自己的新任务文件夹，或开始页面上显示的文件夹。

智能体是会话所扮演的角色。每个智能体在每个会话中都应遵循的文字，无论是针对一个项目还是一个会话，例如你希望它们如何与你交谈，应当放在[智能体准则](/guide/guidelines)里。在 0.37.0 版本之前，智能体被称为助手；它们是同一个东西，只是功能更多。

## 智能体页面

在侧栏中打开**智能体**，或访问 [/agents](/agents)。在手机上，侧边栏是一个抽屉：需要先打开它。[设置 → 功能 → 你的智能体](/settings?s=assistants&find=Your%20agents)中有一行**你的智能体**，也可以打开此页面（它会显示有多少个智能体是你自己的）；该部分的其余内容涉及任务文件夹和清理，见下文。

- 在电脑上，页面的侧栏旁有一栏，应用和设置也是如此：顶部是徽标、**新增**和隐藏侧边栏（Ctrl+B，Mac 上为 ⌘B），其下是各个位置。**新增**会打开一个菜单：**新建智能体**用来创建智能体（见[创建智能体](#make-an-agent)）；**从文件安装智能体**用来安装别人给你的文件中的智能体（见[把智能体分享为文件](#share-an-agent-as-a-file)）；**导入 Claude Code 智能体文件**用来导入 Claude Code 的智能体文件（见[导入 Claude Code 的智能体文件](#import-claude-codes-agent-files)）。
- 各个位置：**所有智能体**（你的智能体显示为卡片，栏被隐藏时内置的智能体显示在它们下方，因为栏中会列出它们）、**你的智能体**（只有你自己的）、**需要你处理**和**有定时运行**（当你的智能体中有符合条件的就会显示），以及在**它们在哪里工作**下的**全部**和每个有自己智能体的项目。每个位置都标有它包含的智能体数量。在**内置**下，应用自带的每个智能体都有一行，带有它的图标，点击会打开该智能体自己的页面。在一条分隔线之后，**定时运行**会按一周显示所有自动运行的内容：你的智能体的定时运行和你的其他定时任务、你的应用的定时运行、监视器和 webhook，每次运行按结果着色，并显示接下来要运行什么，以及全部列表，每项都有开关可以暂停（见[查看这一周：已运行的和接下来要运行的](/guide/tasks#see-the-week-what-ran-and-what-runs-next)）。当前打开的位置会被标出，地址中会保留它（`/agents?place=mine`、`/agents/schedules`），所以链接可以直接打开它。
- 页面顶部，左侧是位置的名称，右侧是查找框：**查找智能体**会把卡片和内置智能体缩小到名称或简介中含有你所输入内容的那些。
- 你的智能体显示为卡片。每张卡片包含智能体的名称、它的简介、它的运行状况（**工作中**、当它的某个会话在等你回答时显示**需要你处理**、**预算已用完**或**空闲**）、它工作的项目（或**全部**）、它的档位、下次运行时间、它的收件箱中有多少条消息在等待，以及它本月的花费。
- 在手机和窄窗口中没有这一栏：页面保留标题，右侧是**新建智能体**、**导入**和**安装**，其下有两个标签页（**你的智能体**和**定时运行**），卡片上方有几个筛选标签，显示**全部**、**全部**、每个有自己智能体的项目、**有定时运行**和**需要你处理**。应用自带的智能体在**内置**下。

点击卡片即可进入智能体自己的页面，旁边保留这一栏，并标出该智能体（你自己的智能体标在**你的智能体**下）：

- 用几句话描述它的设置，例如“它在所有地方工作，每个工作日 09:00 运行，使用快速档位思考。”点击任何带下划线的文字即可在那里更改（见[修改智能体](#change-an-agent)）。
- **开始会话**会打开开始页面，并选好该智能体（如果它在某个项目中工作，也会选好该项目）。
- **所有设置**会在一个窗口中打开该智能体的全部设置（见[所有设置](#all-settings)）。**创建副本**会生成一个可供修改的副本；**删除**会删除你自己的智能体。
- **更多**（⋯）：**版本**（针对你自己的智能体）列出每次更改之前它的样子，可以对比并恢复（见[版本：回到更早的版本](#versions-go-back-to-an-earlier-one)）；**下载为文件**会把它保存为文件，以便保留或分享给他人（见[把智能体分享为文件](#share-an-agent-as-a-file)）。
- **示例**（针对你自己的智能体）：用来试验它的消息，以及它的回答必须做到什么，并带有**试一试这些示例**（见[检查它的示例](#examples-that-check-it)）。
- **定时运行**列出以它的身份运行的定时任务，并带有**添加定时运行**。
- **收件箱**（针对保留自己对话的智能体）：它的消息和对它们的回答、一个向它发送消息的输入框，以及**它的对话**（见[有自己对话的智能体](#an-agent-with-a-conversation-of-its-own)）。
- **它交回的结果**（针对有结果字段或结果去向的智能体）：一张它的结果表，每个结果一行，并显示每个结果去了哪里（见[智能体交回什么](#what-an-agent-hands-back)）。
- **本月**：有多少个会话以它的身份开始、花了多少钱，若它有预算则与预算对比；以及它的**最近的会话**，每个都可以打开其对话，旁边有**在侧边栏中显示全部 23 个**（见[查找智能体的会话](#find-an-agents-sessions)）。

## 内置智能体

应用自带八个智能体。它们都不会指定程序、模型、档位或权限模式，所以会沿用你在起始页选好的设置，也不会限制可使用的内容或花费。除程序员外，其余智能体都会在新的任务文件夹中启动没有文件夹的会话（见[任务文件夹](#task-folders-where-a-task-without-a-folder-works)）。你不能修改或删除它们，但可以复制一个，再修改副本（见[复制或删除智能体](#duplicate-or-delete-an-agent)）。

每个智能体都会借助适合自己工作的[回答卡片](/guide/sessions#answer-uis-cards-charts-and-maps-in-replies)（事实核查、可以直接作答的练习题、带地图的行程、关键数字和图表），所以那些看比读更直观的内容，会以可以查看、对比、勾选或亲自试一试的形式呈现。

### 通用

“帮你处理各种事：提问、写作、规划、文件。”在你于起始页选择其他智能体之前，起始页默认选中通用（项目自己的智能体优先）。它是为可能不懂编程的人设计的。

- 它会弄清你想要什么并去完成。只有当请求不明确、而且会影响结果时，它才会问一个简短的问题；如果可能的答案只有几个，会以按钮的形式供你点选。其他情况下，它会自行做出合理的选择，并说明选了什么。
- 它先给出答案，再用通俗的语言讲重要的细节，遇到无法避免的技术术语也会加以解释。
- 它让每个回答都易于理解、便于使用：那些看比读更直观的内容（并排的选项、地图上的地点、可以逐项勾选的步骤、以图表呈现的数字、配有图片的事物）会以回答卡片的形式给出，需要看图的地方还会配上图片或视频，而它自己的文字则负责讲道理和提建议。
- 对于最新的信息，或者它没有把握的内容，它会在网上搜索；它会阅读你指给它的文件；你想留存的成果，会作为文件保存在会话的文件夹里；如果是你会反复使用的网页（比如记录表或计算器），则保存在项目的文件中（详情 → **文件**）。
- 如果回答之后自然会有下一步（深入了解、对比、制定计划、据此做点什么），它会在结尾给出两到四个可以点按的按钮，但不会每次回答后都这样做。
- 如果它创建或修改了文件，会在结尾说明是哪些文件、在什么位置。

### 研究员

“查找并核实资料来源，并注明出处。”

1. 它会用一句话重述你的问题，并把范围较大的问题拆成几个需要回答的子问题。
2. 它会先广泛搜索再下结论：用不同的措辞进行多次网络搜索，选择合适的搜索类别（论文、新闻、专利、公司披露文件、数据集）；当主题涉及面较广时，会取更多结果。
3. 它会阅读重要的资料来源，而不是靠摘要片段作答，并优先选择一手的权威来源：原始论文和数据、官方网站、公认的专家和媒体。它会记下每个来源的日期；当事实会随时间变化时，还会说明答案的时效性。
4. 当不同来源的说法不一致时，它会明确指出，并根据质量和时效性加以权衡，同时区分哪些已经确立、哪些存在争议、哪些尚不清楚。
5. 它边写边注明出处：在每个论断后加上带编号的标记，如 [1]，并在末尾列出来源的标题、作者或发布者、日期和链接。它绝不会编造来源、引文、数字或链接；遇到无法核实的内容，会如实说明。
6. 它先讲发现：用一句话给出答案和几个要点，然后是细节，最后是仍不确定的部分。
7. 对于本身有特定形态的内容，它会直接呈现，而不是埋在大段文字里：对照证据权衡论断的事实核查、并排比较的选项或研究、按时间线展示的事情经过、关键数字、值得一读的论文，以及用网络图展示的人物、观点或组织之间的联系。
8. 较长的报告还会作为可以阅读、评论和导出的文档保存在项目的文件中；如果你需要文件，则保存为会话文件夹里的 Markdown 文件。

对于需要大量搜索的大问题，请参阅[深度研究、第二意见与多个智能体](/guide/research)中的深度研究。

### 撰稿人

“起草、编辑并润色你的文字”：电子邮件、信函、帖子、文章、报告、故事和演讲稿。

- 在写长篇内容之前，它会先确认读者、目的、语气和篇幅。如果其中某一项不明确而且很重要，它会简短地询问（有好几项时用表单）；否则会用一句话说明自己的假设，然后开始写。
- 它的文字平实而具体：用词具体，主旨靠前，句式富于变化，没有废话和陈词滥调。
- 它会模仿你要求的风格；如果你分享了以前写的文字，就用你自己的风格。
- 编辑你的文字时，它会保留你的原意和风格：改正错误，收紧松散之处，保留好的部分。它会展示修改，方便你查看：想要反馈时，呈现标出并解释每处改动的原文；重写时，则呈现各版本之间的差异，然后给出干净的文本。
- 对于短篇内容，它会交付可以直接使用的成品：多个版本可切换的电子邮件，并在你的邮件应用中打开、所有内容都已填好；帖子，每条都按所在平台的长度限制检查过；以及按你所需格式写成的参考文献。
- 当某个选择很重要时（邮件主题、标题、开头、名称），它会提供两到四个选项，每个都附有说明，供你挑选。
- 超过几个段落的内容会保存为文档（在项目的文件中），你可以在其中编辑、评论和导出，它也会告诉你这一点；当你要求提供文件时，它会在会话的文件夹里创建文件（除非你想要其他格式，否则为 Markdown）。

### 程序员

“构建、修复并讲解软件。”程序员是在你的项目中工作的软件工程师，所以与其他内置智能体不同，它在你于起始页选择的文件夹中工作，而不是在新的任务文件夹中。

- 它会先阅读改动周围的代码，再动手修改，并遵循项目的约定和工具。
- 它只改你要求改的内容；注意到其他问题时会告诉你，而不会擅自去修复。
- 修改代码后，如果项目有测试、构建或代码检查工具，它会运行这些工具，并修复出现的失败。
- 如果你看起来刚接触编程，它会用通俗的语言解释自己做了什么、怎么运行：给出供你运行的命令，每条都带有复制按钮和说明，还有可以在演练场里试一试的代码片段。
- 当它讲解代码而不是修改代码时，会把本身有特定形态的内容直接呈现出来，而不是一大段文字：带有可能原因和修复办法的错误、测试运行情况、以树状显示的项目文件、接口、与代码行并排逐步讲解的代码、逐行展示变量变化的程序运行过程、并排权衡的各种方案，以及用于说明流程或架构的示意图。
- 它最后会给出简短的总结：改了什么、如何验证的，以及还有什么待办事项。

### 辅导老师

“一步一步地教你，并检查你是否跟上。”目标是让你真正理解并能自己动手，而不只是得到一个答案。

- 如果你的水平或目标不明确，它会先问一个简短的问题，可能的答案以按钮的形式供你点选（刚接触、了解基础、备考复习）。
- 它一次只教一步，用通俗的语言，每个新概念都配一个具体的例子，从简单到困难。
- 它让每一步都是可以看、可以试的，而不只是读：示意图、图片、公式卡片、带滑块的函数图像、展示概念之间如何联系的图谱、可以切换深浅程度的讲解、逐步展开的例题、可以运行和修改的代码、逐行讲解的代码、在你先预测输出之后再逐步运行的程序、小型模拟；数学公式像教科书中那样呈现。
- 每一步之后，它都会用可以直接作答的内容进行检查，并等你完成再继续：简短的测验、用你自己的文字或数字作答的练习题（边做边检查，尝试后给出提示和解答）、填空、配对或排序。它会读取得分和你提交的答案。
- 你作答之后，它会说明哪些是对的，并以友善而具体的方式纠正错误，再随之调整：你卡住时换一种讲解或例子，你进展顺利时给出更难的一步。
- 遇到作业或练习，它会用提示和提问来引导你，只有在你要求，或你尝试后仍然卡住时，才会给出完整解答。
- 学习语言时，它会提供可以听、可以练的词汇、动词变形、对话，并纠正你自己写的句子，标出每处错误并加以解释。
- 它会在一个主题结束时给出简短的回顾和需要记住的内容的记忆卡片，并以可以点按的按钮提供接下来可以学的内容。对于较长的课程，它会保留一份主题路线图，以及你已经学到哪里。

### 规划师

“规划旅行、活动和项目”，也包括搬家和日常安排。

- 首先它会确定影响计划的因素：目标、日期和截止时间、预算、涉及的人员和硬性限制。对于缺失而且重要的几项，它会向你询问（有好几项时用表单），其余的则采用合理的默认值，并说明做了哪些假设。
- 它会在网上核实计划所依赖的事实（营业时间、行程时间、价格、是否有位、规定、天气），并说明哪些无法核实或可能变化。
- 它会让计划具体可行：时间、地点、费用和谁负责什么，为可能延误的事情留出余地，以及哪些需要先预订或先决定。
- 它会以便于一目了然的方式展示计划，使用为计划设计的回答卡片：按天排列并在地图上标出地点的旅行、一天的日程、日历上的日期或倒计时、按阶段或按周划分的项目、作为清单的预订或打包事项、天气预报，以及带合计的预算费用。
- 当某个选择很重要时，它会并排给出两三个选项及其利弊（比如旅行的航班和住宿）。
- 它会把计划保存在项目的文件中，供你修改：一份文档，以及用于预算和日程、带合计的电子表格。它会主动提出调整计划，并以按钮的形式给出可能的修改供你点按。当你要求提供文件时，它会改为在会话的文件夹里创建文件。

### 分析师

“理解数据和电子表格，并配上图表”：电子表格、CSV 文件、导出文件和数字。

- 分析之前，它会先查看数据（列、规模、类型和缺失之处），并在得出结论之前报告缺失值、重复项或格式异常等问题。
- 它用代码计算（简短的 Python 或 JavaScript 脚本，或公式），绝不凭目测估算，并把脚本保存在会话的文件夹里，以便重复这项工作。
- 它先回答问题，用通俗的语言给出关键数字，再展示是如何得到的。它会说明假设和局限，也不会声称数据无法体现的因果关系。
- 它用为数字设计的回答卡片来展示结果：关键数字、图表（选用最合适的最简单类型：比较用柱状图，随时间变化用折线图）、可以排序和筛选的表格、数值的分布、占整体的份额、总数的变化、流向、以热力图展示的两个维度上的数值、地图上各地的数字，以及在你想尝试其他数值时用的计算器。上述类型都画不出的图形，会放在回复中的动态图形里；如果有好几个，则放在网页里；坐标轴和单位都有标注，在手机上也可以正常阅读。
- 当你需要时，它会把清理后的数据和结果保存为文件（CSV；你要求时则为 XLSX）。你要查看和修改的表格会保存为带公式的电子表格，你会反复查看的仪表盘则保存为网页。

### 应用搭建师

“制作你自己的应用：表单、步骤、数据和界面”（见[应用](/guide/apps)）。

- 它会确定输入什么、输出什么，以及一次好的运行是什么样子，只询问会影响设计的问题，并说明自己做了哪些假设。
- 它用自己的工具搭建应用，为每个部分选择成本最低的步骤（工具、模型的快速回答、规则、代码），在需要判断的地方才使用智能体。
- 它会为应用准备两到四个带检查的示例，先试运行，并在交付之前修复失败的地方，同时说明一次运行的费用和所需时间。
- 当你自己修改应用时，它会在你的修改基础上继续搭建。
- 它使用 app-builder 技能。

## 创建智能体

### 说出它该做什么

1. 在[智能体页面](/agents)，点击列顶部的 **新增**，然后点击 **新建智能体**（在手机上，点击页面顶部的 **新建智能体**）。**新建智能体** 窗口分两步打开，在窗口顶部显示为 **1 描述** 和 **2 配置**。
2. 在“你的智能体应该做什么？”下面，用你自己的话说出来；如果希望它自己定时工作，也说明什么时候工作：“每周五下午，根据我的提交记录和备注写出我的每周进度报告，发出之前先让我检查。”在 **或者从一个想法开始** 下面，有 **论文摘要**、**每周报告**、**变更审阅者** 和 **翻译员**，点击其中一个，输入框里就会填入一句话，供你修改。
3. 点击 **起草我的智能体**（或按 Ctrl+Enter，Mac 上按 ⌘+Enter）。辅助模型（设置 → 模型 → 辅助模型）会起草这个智能体：它的名称、图标、一句话介绍、指令、它可以使用什么、它思考使用的档位，以及你提出要求时的定时运行。窗口随后进入 **配置**。
4. 通读草稿，按你的想法修改（见[所有设置](#all-settings)）。**返回** 会回到 **描述**：你写的内容会保留，再次起草会替换草稿。
5. 点击 **创建智能体**。应用会提示“*名称* 已就绪”并打开它的页面；如果它有定时运行，这个定时运行就是一个以它的身份运行的定时任务。

如果你输入或修改了内容之后关闭窗口（✕、Esc 或点击窗口外），它会先询问 **放弃这个智能体？**。项目的 **智能体** 标签页有 **在此新建智能体**，可以创建一个在该项目中工作的智能体；在项目还没有智能体时，还有 **为这个项目创建一个**，它会根据项目对自身的描述或该类型项目的模板来创建；新项目在创建时也可以顺便创建一个（见[项目](/guide/projects)）。

### 自己来配置

文本框下方的 **我自己来配置** 会跳过起草，直接打开 **配置**，除了图标之外什么都不填（见[所有设置](#all-settings)）。你最多可以拥有 200 个自己的智能体。

### 让智能体来创建

在任意会话中，用你自己的话提出要求：“帮我创建一个智能体，每周五 5 点总结我未读的新闻简报。”你正在对话的智能体，无论它运行在哪个程序上（Claude Code、Codex、Custom 或其他），都会为你创建：它的名称、一句话介绍、指令、它可以使用什么、档位和其他内容，以及它需要自己定时工作时的定时运行。首先，对话中会出现一张卡片，显示这个智能体以及它的定时运行时间，并带有 **创建智能体** 和 **不要**；在你回答之前，不会保存任何内容（见[卡片：确认更改](/guide/ask-agents#the-card-confirming-a-change)）。

用同样的方式，智能体也可以修改你的某个智能体（只会修改你要求的部分，并作为新版本保存，来源标为 **一个智能体**）、给它添加定时运行、修改某个定时运行、删除不再需要的定时运行，或者删除一个智能体及其定时运行。凡是添加、修改或删除定时运行的更改，以及每一次删除，都会每次询问你，除非该会话拥有 **完全访问**。给某个智能体设置 **完全访问**（它从不询问）时，每次都会询问你。

### 所有设置

**配置** 是 **新建智能体** 的第二步，也是智能体页面上的 **所有设置** 为该智能体打开的窗口，没有 **描述** 这一步。在手机上，窗口会占满屏幕。顶部是图标（点击它可以从 30 个中选一个：望远镜、钢笔、厨师帽、飞机、钱包等）和名称，最多 60 个字符，例如“记账员”或“旅行顾问”。只有名称是必填的。

在电脑上，左侧有一列列出七个分区，每个分区名称下面显示它当前的设置，这样整个智能体一目了然；点击其中一个，就会在旁边看到它的设置。当某个分区比窗口还长时，会出现 **下面还有更多** 按钮，提示还有更多内容。在手机上，**配置** 会列出各个分区及其当前设置；点按一个即可打开，**‹ 所有设置** 可以返回。

- **关于**：
  - **一句话介绍**：最多 160 个字符，显示在它的卡片上和开始页的菜单中，例如“把家庭账目整理得井井有条”。
  - **指令**：它是谁、如何工作，最多 20,000 个字符。它在每个会话开始时都会读取这些内容。可以按内置智能体的写法来写：“在本次会话中，你是用户的记账员”，然后用几行说明它如何工作（“向我索要你需要的对账单”“把合计保存在工作文件夹的电子表格里”）。
- **位置和时间**：
  - **在哪里工作**：**全部**，或 **只在某些项目中**，并为每个项目提供一个开关（见[智能体在哪里工作](#where-an-agent-works)）。
  - **何时工作**：对于新智能体，可选 **被请求时**、**定时**（几天和一个时间）或 **每隔…**（一个间隔），以及 **每次运行的开头消息**，即每次定时运行开始时的消息。对于你已有的智能体，这里会列出它的定时运行；你可以在它的页面上的 **定时运行** 下添加和修改（见[智能体何时工作：定时运行](#when-an-agent-works-schedules)）。
  - **保持一个对话，带收件箱**（见[拥有自己对话的智能体](#an-agent-with-a-conversation-of-its-own)）。
  - **它的会话从哪里开始**，在开始页没有选择文件夹时：
    - **新的任务文件夹**（默认）：每个会话都会得到一个属于自己的全新文件夹（见[任务文件夹](#task-folders-where-a-task-without-a-folder-works)）。
    - **开始页上的文件夹**：会话在开始页显示的文件夹中工作，程序员就是这样。适合在项目中工作的智能体选择此项。
- **模型**：
  - **思考使用**：**自动**、**快速**、**标准**、**最佳** 或 **最大值**，每一项都有一行说明它的用途（见[智能体用什么思考：档位](#what-an-agent-thinks-with-tiers)）。
  - **运行于**：它建议使用的程序，在开始页上与它一起被选中。
    - **任意智能体**（默认）沿用开始页上选择的程序。
    - **Claude Code**、**Codex**、**Custom**（“任意模型”），或你在[设置 → 智能体 → 更多智能体](/settings?s=agents)中添加的任何智能体。
    - 选择一个程序后，旁边会出现一个模型菜单，列出该程序的模型（对于提供选择的程序）；不改动时，就是该程序的默认模型。上面的档位会改为由它来选择模型。
  - **权限模式**：何时先询问你。
    - **沿用所选**（默认）：沿用开始页上选择的模式。
    - **询问**：在修改文件和运行命令之前询问。
    - **接受编辑**：可以自由修改文件，运行命令前询问。
    - **完全访问**：从不询问。
    - **计划**：只读取和制定计划，直到你批准。

    Claude Code、Codex 和 Custom 各有一个与这些对应的模式。其他智能体（Gemini CLI、OpenCode……）保持它们自己的模式。
  - **它启动的子智能体**：**不限**，或最高不超过某个档位。
  - **检查未通过时升档**：除非你关闭，否则保持开启。
- **工具**：**它可以使用什么**（七个开关，新智能体全部开启；有些关闭时会出现 **全部开启**；见下文）、**优先使用的技能**（见下文）和 **已连接的应用**，后者在你连接了账户时显示（见下文）。
- **Team**：**其他智能体可以把工作交给它**，以及 **它可以把工作交给**，并为其他每个智能体提供一个开关（见[把工作交给其他智能体的智能体](#agents-that-hand-work-to-other-agents)）。
- **结果**：它交回什么：每个结果的字段，以及每个结果的去向（见[智能体交回什么](#what-an-agent-hands-back)）。
- **预算**：**不限**，或以美元计的 **每月限额**；对于你已有的智能体，会显示它本月的花费（见[每月预算](#a-monthly-budget)）。

**创建智能体** 会创建一个新智能体。对于你已有的智能体，**保存** 会保留你的更改（“*名称* 已保存”），**取消** 会不保存直接关闭窗口；做过更改后关闭窗口，会询问 **放弃你的更改？**。

### 它可以使用什么

每个开关对应一类工具：

- **读取文件**：打开、列出和搜索文件与文件夹。
- **创建和修改文件**：写入新文件并编辑现有文件。
- **运行命令**：运行这台电脑上的程序和脚本。
- **使用网络**：搜索和阅读网页。
- **使用浏览器**：在真实的浏览器中打开网站、点击和填写表单。
- **使用电脑**：查看屏幕，并在任何应用中使用鼠标和键盘（桌面应用，需开启“电脑使用”）。
- **其他工具**：为智能体设置的 MCP 服务器（工具服务器）和插件。

你关闭的这些工具会怎样，取决于程序：

- **Claude Code 和 Custom** 会关闭这些工具。关闭 **其他工具** 后，Claude Code 只能使用应用自带的工具和你已连接的账户，而不能使用你自己设置的任何 MCP 服务器。
- **Codex** 会被告知不要使用它们。关闭 **使用网络** 后，它自带的网络搜索也会被关闭。关闭 **运行命令** 但开启 **读取文件** 时，Codex 会被告知只能用它的 shell 来读取和搜索文件，因为它是通过 shell 读取文件的。
- 当 **使用浏览器** 或 **使用电脑** 关闭时，**Claude Code、Codex 和 Custom** 也会关闭浏览器和电脑的工具。
- **其他智能体** 会被告知不要使用它们。

应用自带的工具（页面、记忆等）保持开启，但属于你已关闭的某个开关的除外：关闭 **使用网络** 后，应用的网络搜索和网页阅读也会随之关闭；关闭 **使用浏览器** 后，它的浏览器会关闭；关闭 **使用电脑** 后，它的屏幕、鼠标和键盘工具会关闭；关闭 **读取文件** 后，它的文档阅读器会关闭。已连接的账户不属于“其他工具”：它们由下面的 **已连接的应用** 决定。当任务需要智能体无法使用的东西时，它会被告知如实说明，而不是绕过限制。

### 优先使用的技能

在 **工具** 中，输入技能的名称，然后按 Enter（或逗号）添加。该字段会建议 Claude Code 和 Codex 自带的技能，内容与[设置 → 智能体 → 技能](/settings?s=skills)中为文件中所打开文件夹列出的一致；你也可以输入技能库中某个技能的名称，例如 research。点击名称旁边的垃圾桶即可移除。最多 30 个。当这些技能中有一个适合当前任务时，智能体会在开始之前加载它，并按它的指引执行。关于应用自带的技能以及如何添加更多技能，见[技能](/guide/skills)。

### 连接

**工具** 中的 **已连接的应用** 只在你连接了账户时才显示（在[应用 → 已连接的应用](/apps/connected)中设置）。每个账户都有一个开关：开启表示它在这个智能体的会话中开启。已经对每个会话都开启的账户，会显示“对每个会话开启”。如果智能体指定的某个账户已不再连接，它会在名称下显示“未连接”，并带有一个移除按钮。见[已连接的应用、密钥和工具](/guide/connections)。

## 修改智能体

在智能体的页面上，它的设置像句子一样读起来：它做什么，“它在*全部*工作，*每个工作日 09:00*，使用*快速*思考。它可以*读取文件和使用网络*，不向*任何其他智能体*求助。它交回*它的回复*。它每月最多花费 *$3*。”每个带下划线的部分都会打开用于修改它的界面，修改会立即保存：

- **在哪里工作**：**全部**，或为每个项目提供一个开关。
- **何时工作**：它的定时运行，每个都会打开各自的编辑器，**添加定时运行**，以及 **保持一个对话，带收件箱**。
- **它用什么思考**：自动或某个档位、**它启动的子智能体，最高不超过**，以及 **检查未通过时升档**。
- **它可以使用什么**：七个开关。
- **它向谁求助**：为其他每个智能体提供一个开关，以及 **其他智能体可以把工作交给它**。
- **它交回什么**：它的字段，以及每个结果的去向。
- **它的每月预算**：每月多少美元，或不设预算。

**所有设置** 包含其余内容（见[所有设置](#all-settings)）。每次更改都会保存为一个版本，因此你可以回退（见[版本：回到更早的版本](#versions-go-back-to-an-earlier-one)）。此后你启动的会话会使用新版本，已经在进行中的、使用它的会话也会从你的下一条消息起使用新版本：Custom 在每一轮之前读取它，Claude Code 和 Codex 在空闲后重新开始（对话会继续）。

## 版本：回到更早的版本

每次改变你的某个智能体的保存都会留下一个版本：在它的页面上的更改、在 **所有设置** 中的更改、通过命令行的更改、由你要求的智能体（通过应用的 API）所做的更改，以及生成它的草稿或文件。打开它的页面，然后点击 **更多**（⋯）→ **版本**：

- 列表按从新到旧显示每个版本：**v1**、**v2**……，用几句话说明改了什么（“它现在使用最佳思考（之前是快速）。它的每月预算现在是 $5（之前是 $3）。”），或修改它的智能体自己说明的做法，保存者是谁（**你**、**一个智能体**、**已起草**、**已安装**、**已导入**）以及时间；**当前** 标出当前版本。用示例试过的版本会显示通过了多少个（“示例：3 个中通过 2 个”），这样你可以看出某次更改是否让它变得更好。
- 点击其中一个，可以与它之前的版本比较，或者在 **比较** … **与** … 中任选两个：以句子形式显示两者之间有什么变化，并并排显示它的 **指令**，删去的行用红色标出，新增的行用绿色标出。
- **恢复此版本** 会让选中的版本再次成为当前版本。它会保存为一个新版本，注明“已恢复版本 3。”，因此原来的版本仍保留在列表中，可以再回去。它曾交付工作的智能体，以及此后已不存在的项目，会被略去。

一个智能体保留它最近的 50 个版本；删除它时，这些版本会一并消失。它的示例不属于版本的一部分：恢复旧版本会保留它现在拥有的示例。在保留版本功能出现之前创建的智能体，会在第一次更改时，把原来的样子作为它的第一个版本（“保留版本之前”）。

## 用示例检查智能体

示例可以让你在修改智能体之后，检查它是否仍能做好自己的工作，就像应用的示例一样。每个示例包含一条用来试它的消息，以及它的回答必须做到的事。在智能体的页面上，进入 **示例**：

1. **添加示例**：如果愿意，可以给它起个名字；把**用来试它的消息**写成你平时对这个智能体说话的样子，再为一份好的回答应做到的每件事添加一项检查。检查可以是一句通俗的话，例如“它写出了两个拉取请求”或“没有新发现时，它会明确说明”，辅助模型会对照回答来判断；也可以是针对它给出内容的规则，就像应用的检查那样：`{{reply}} contains Lisbon`，或者对于会交回结果的智能体，针对其中某个字段写 `{{result.count}} > 0`。然后点击 **保存示例**。每个智能体最多可以有 10 个示例，每个示例最多有 8 项检查。
2. **试一试这些示例**（或点击某个示例旁边的烧瓶按钮，只试这一个）会先说明它将做什么、要花多少：它会以这个智能体的身份启动多少个会话、使用哪个档位，大约要花多少（根据它上几次试运行的花费，或本月它的会话花费估算；第一次试运行之前还没有依据），以及它每月预算还剩多少，试运行也会计入预算。点击 **全部试一试**。
3. 每个示例都在自己的会话中运行，以这个智能体的身份、在它的档位上启动，使用一个专属的空文件夹（结果保存后会被删除，对话仍会保留），并且不会出现在你的会话列表中。它不会发送任何内容：本来会通过你已连接的应用发送的内容，会被保存为“本来会发送的内容”，而它交回的内容只会留在这次试运行中。结束时，会逐项读取它的检查。有字段需要交回的智能体，还必须交回一个结果。

之后，每个示例会显示它上一次试运行的情况：**通过**、有多少项检查未通过、**未完成**，或 **等你处理**（它的会话在向你提问：请打开它），并附上时间和花费。点击某个示例，可以看到它的消息、每项检查及所见结果（✓ 或 ✗）、它交回的内容、它的回复，以及 **打开它的会话**。如果你在示例上次试运行之后修改了智能体，页面会提示你，并给出 **再试一次**。示例从不会自行运行。

## 智能体在哪里工作

除非你为智能体指定项目，否则它在 **全部** 项目中工作。只在部分项目中工作的智能体：

- 只会在这些项目中提供：当选中它的某个项目时，起始页的智能体菜单才会列出它，其他智能体也只能在它所属项目的会话中把工作交给它；
- 只在一个项目中工作时，会在该项目的文件夹中工作，并使用该项目的知识、记忆、准则和技能；
- 会显示在它所属每个项目的 **智能体** 标签页上（见[项目](/guide/projects)）。

如果你在起始页选了一个项目，而所选的智能体不在该项目中工作，起始页会改为选用该项目自己的智能体，否则选用通用智能体。

## 智能体何时工作：定时运行

智能体会在你以它的身份启动会话时、其他智能体把工作交给它时，以及按它的定时运行安排工作。定时运行是以该智能体身份运行的定时任务：在某个时间、每隔一段时间、仅一次、当某个网页或订阅源发生变化时，或当其他服务调用它的 webhook 时（见[定时任务](/guide/tasks)）。

- 在智能体的页面上，点击 **添加定时运行** 会打开任务编辑器，已选好该智能体并填好时间：给它起个名字，写下每次运行开始时的消息，然后保存。
- 点击列表中的某个定时运行，可以修改它、暂停它，或立即运行。
- 随新智能体一起起草的定时运行，会以该智能体的身份创建。
- 智能体为你的某个智能体添加的定时运行，在提供该选项的地方会使用 **自动**（见[定时任务](/guide/tasks#model-effort-permissions-and-other-options)），除非该智能体指定了自己的模型。以档位来思考的智能体仍然使用它的档位。
- 任何会话中的智能体都可以替你添加、修改或删除某个智能体的定时运行（见[让智能体来创建](#ask-an-agent-to-make-one)）。
- 不再需要的定时运行会自行消失：一次性的定时运行在成功运行后消失；而当某次运行发现任务已完成（它等待或监视的事情已经发生，且它的消息中写明此时应停止）时，该定时运行也会消失，运行的通知中会说明这一点。智能体被删除时，它的定时运行也会一并删除。

每个定时运行也都在 [设置 → 智能体 → 定时任务](/settings?s=tasks) 中，与所有其他任务放在一起；任务的 **智能体** 选项就是它的运行所使用的智能体。智能体页面栏中的 [**定时运行**](/agents/schedules)（手机上是顶部的标签页）会把它们和所有其他任务一起显示在一周视图中：运行了什么、结果如何、接下来运行什么，列表中每一项都带有 **智能体 ·** 和该智能体的名称；点击它的铅笔图标会打开该智能体的页面。

## 智能体用什么来思考：档位

档位按工作的类型而不是按名称来选择模型：

- **快速**：最便宜，适合结果可以检验、很明确的小任务，例如有针对性的修改、提取事实、排序、格式整理和简短摘要。
- **标准**：中等规模的明确任务：已经说清楚的修改、测试、针对既定问题的研究、按提纲写草稿。
- **最佳**：会话的主智能体。它负责弄清要做什么、制定计划、带领子智能体并检查它们的工作。
- **最大值**：最强的档位，适合最难的问题：顽固的缺陷、证明、约束很多的设计。

设为某个档位的智能体，会使用它所运行的程序在该档位上的模型，除非会话另外选了模型；设为 **自动**（默认）时，它使用启动处所选的模型：起始页、定时任务（它本身也可以是 **自动**），或把工作交给它的智能体。在起始页上，这个选择本身也可以是 **自动**：用最佳，如果问题证明太难，就升到最大值（见[档位：为每类工作选择模型](/guide/agents-models#tiers-a-model-for-each-kind-of-job)）。

[设置 → 智能体 → 模型 → 档位](/settings?s=models&find=Tiers) 用一张表说明每个档位的含义，每个程序一列：**Claude Code** 对应一个模型（起步为 Haiku、Sonnet、Opus 和最新的 Fable）和一个思考强度；**Codex** 对应一个模型和一个思考强度（起步为 Luna、Terra、Sol 和 Astra；如果你的套餐没有其中某个模型，就用它提供的最接近的一个，当两个档位共用一个模型时，较高的档位会用更高的思考强度）；**Custom** 对应你的某个 Custom 模型：你没有改动的档位会取 Custom 现有模型中同类里最新的一个（见[档位：为每类工作选择模型](/guide/agents-models#tiers-a-model-for-each-kind-of-job)），如果只有小型或本地模型，该档位就保持为空，沿用会话所选的模型。你没有改动的档位会跟随其程序中同类的最新模型。**恢复默认** 可以把它们还原。

**它启动的子智能体，最高不超过** 限制智能体所启动的 Hydor 子智能体的档位：如果请求更高的档位，子智能体就会得到这里设定的档位。子智能体的档位也绝不会高于其主导者所用的档位。直接指定名称的模型则按指定的使用。

**检查未通过时升档**（默认开启，除非你关闭它）：智能体按某个档位启动的 Hydor 子智能体，如果它的回复没有通过快速检查（辅助模型会对照它的任务说明来读它的回复），或者因错误而停止，就会在高一档上重新运行，最高到最佳，且绝不超过该智能体允许的最高档位。只检查它对任务说明的回复：之后对主导者或你的消息的回复，不会让整个工作重来一遍。主导者会得知此事及原因，新的子智能体也会被告知第一个为何不合格。智能体的定时运行如果在它的档位上失败，也会高一档重新运行，最高到最佳。当主导者发现结果不够好时，也可以自行为子智能体升档。

## 把工作交给其他智能体的智能体

智能体可以把自己的一部分工作交给一个新会话，与自己并行处理：这就是 Hydor 子智能体（见[深度研究、第二意见和多个智能体](/guide/research)）。它可以启动：

- **普通子智能体**，并为它的那部分工作指定档位：很明确的小任务用快速，中等规模的明确任务用标准（未指定时子智能体就是这个档位），可以独立完成的困难部分用最佳；
- **你的某个智能体**，按名称指定：它会使用自己的指令、工具、连接、模式和档位工作，回复会返回给发出请求的智能体。

谁可以把工作交给谁：

- 以内置智能体（或不以任何智能体）身份工作的会话，可以把工作交给你在该处工作的任何智能体。
- 你的某个智能体只能把工作交给它的 **Team** 中列出的智能体。
- 关闭了 **其他智能体可以把工作交给它** 的智能体，不接受任何智能体交来的工作。
- 被指名的智能体只在它自己的项目中工作，而且使用的权限模式绝不会比发出请求的会话更宽松。

在对话中，一轮所启动的 Hydor 子智能体会合并显示为该轮下方的一张卡片，每个一行，包括它的标题、它所用的智能体身份（或“Hydor 子智能体”）、它的档位、程序和模型、当前状态和花费，如果它升过档，还会显示从哪个档位升上来以及原因（将鼠标指向该行即可看到）；点击某一行可以打开它的对话。见[子智能体](/guide/sessions#subagents)。项目的 **智能体** 标签页会显示它的哪些智能体把工作交给了哪些智能体。

有自己对话的智能体会在它的收件箱中接收工作，而不是新建会话，它的回答会在它处理完之后返回（见[有自己对话的智能体](#an-agent-with-a-conversation-of-its-own)）。

## 每月预算

智能体的每月上限（在 **所有设置** 中的 **预算**，或它页面上的那句话）限制它的会话在一个月内的花费（从每月 1 日起，按这台电脑的时间计算）：

- 以它的身份启动的每个会话，花费上限为预算剩余的额度（如果会话自己也有上限，则取较低者）。
- 它的普通子智能体的花费会计入其中；被指名的智能体所做的工作则计入那个智能体自己的预算。
- 预算用完后，到下个月之前，不会再以它的身份启动任何会话：定时运行会说明无法启动的原因，它的卡片会显示 **预算已用完**。

每个会话的花费按[用量与费用](/guide/usage)中的方式计算。保持为 **不限** 则表示没有上限。

## 智能体交回什么

如果什么都不设置，智能体会在对话中交回它的回复。你可以在 **结果**（位于 **所有设置** 中，或通过它的句子“它交回*它的回复*”）里为它设置字段和去处，这样每个任务结束时，它就会交回一个带有这些字段的结果，并且会先经过检查，再送往各处：

- **每个结果的字段**：为每个字段设置名称和类型（文本、长文本、数字、是或否、日期、链接、列表，或带列的表格），以及是否必填。智能体用它的 hand_back 工具填写这些字段；不符合要求的结果会连同需要修正的地方一起退回给它。
- **每个结果送往何处**，除了对话之外：
  - **保留的页面**：**同一个页面，更新**（新智能体默认使用这一项）：它第一次运行时会创建一个以智能体命名的网页，如果它在某个项目中工作，就放在该项目里；之后每次运行都会为这个网页放入一个新版本，所以你打开的总是最新的，更早的版本保留在它的版本记录中。你重命名过的网页会保留你起的名字。如果想让每次都生成一个单独的网页，以智能体名称和日期命名，请改选 **每次运行一个新页面**（在有这个选项之前创建的智能体仍按这种方式工作）。
  - **电子表格中的一行**：每次运行都会在同一个电子表格中添加一行：先是一个 **日期** 列，记录运行时间，然后按字段的顺序，每个字段一列。数字会作为数字录入，日期作为日期，链接作为链接，因此合计、公式和图表都能直接使用；列表或表格会作为易读的文本放进一个单元格（“牛奶；鸡蛋”）。电子表格保持为 **新建一个** 时，第一次运行会创建一个以智能体命名的电子表格；你也可以选择自己的某个电子表格以及要写入的工作表标签（不存在的标签会被添加）。参见[电子表格中的一行](#a-row-in-a-spreadsheet)。
  - **一封邮件**：把结果作为邮件发给你指定的人（一个或多个地址），并带有主题（`{date}`、`{time}` 和 `{agent}` 会自动填入；留空时使用智能体名称和日期），从你已连接的某个邮箱账户发出（**从**；如果没有选择，则使用第一个；参见[已连接的应用、密钥和工具](/guide/connections#connect-your-email)）。它在任何邮件程序中都显示良好，每个字段都在各自的名称下方，表格仍然是表格。由于收件人是你亲自在这里选定的，每个结果一准备好就会立即发出，不会在发件箱中等待。
  - **一条通知**，内容为结果的第一行；
  - **它工作文件夹中的一个文件**，例如 `reports/{date}.md`：`{date}`、`{time}` 和 `{agent}` 会自动填入；以 `.json` 结尾的文件名会写入 JSON 格式的字段，其他文件名则写入 Markdown，并且路径永远不会指向文件夹之外；
  - **一个 webhook**：把结果以 JSON 格式通过 POST 发送到某个 https 地址；如果你指定了密钥库中的密钥，就会用它签名，并且只发送给该密钥允许的主机（参见[已连接的应用、密钥和工具](/guide/connections)）。

在这些输入框中输入的内容，会在你离开输入框或按下 Enter 后生效。设置中会显示它第一次运行所创建的网页和电子表格，并附有打开它们的链接。

### 电子表格中的一行

各列是根据表格第一行的标题找到的，所以电子表格仍由你自己安排：你可以移动列、调整列的样式（设为欧元格式的列会一直保持欧元格式），也可以在它们旁边添加你自己的列。你自己的列中的公式（比如累计总和）会像电子表格里的表格一样被向下填充到每个新行，读取已有各行的图表也会把新行纳入进来。表格下方的合计会妨碍新行的添加：请把它们放在单独的一列或另一个标签页中，并针对整列使用公式（`=SUM(B:B)`）。之后如果你给智能体添加字段，它会在末尾得到一个新列，原有的列保持不动；你重命名的标题将不再与它的字段匹配，这个字段就会得到一个新列（把字段改成同样的名字，就能让它们保持在一起）。每次运行产生的行都是电子表格的一个新版本，和任何修改一样，所以它的公式、图表和评论都保持原样。

### 它的结果历史

智能体的页面以表格形式显示 **它交回的结果**：每个结果一行，最新的在前，包括结果产生的时间、每个字段一列，以及它送往何处（**送往**：每个去处一个标记，无法送达的显示为红色；指向某个标记可以查看发生了什么，点击保留的页面可以打开它）。点击某一行可以查看完整的结果，每个字段都完整显示，并有 **打开它的会话**。表格可以滚动，**显示更早的** 会载入更早的结果。智能体会保留一年内的结果，最多 500 条（每天运行一次的智能体能保留整整一年；每小时运行一次的大约保留三周）；太长而无法保存在这里的字段会有相应提示，而在它送往的各处则是完整的。它填写的网页和电子表格会以链接的形式显示在表格上方。

## 拥有自己对话的智能体

大多数智能体每次都会开始一个新会话。打开 **保持一个对话，带收件箱**（在 **所有设置** 的 **位置和时间** 下，或在它句子中“何时”的部分），智能体就会改为保持一个属于自己的对话，在第一次需要时创建；如果它只在一个项目中工作，就放在该项目的文件夹里：

- 发给它的消息会在它的 **收件箱** 中等候，并逐条进入它的对话，每一条都要等前一条得到回答之后才进入：包括你从它的页面发出的消息，以及其他智能体交给它的消息。
- 它的定时运行会发布到同一个对话中，等待正在进行的一轮结束；每次运行都会显示在它的日程历史中，和任何运行一样。
- 每个回答都会回到发送者那里：其他智能体会收到一条消息，而你发出的消息则会收到一条通知。
- 它会记住之前的内容，就像任何对话一样。
- 每条消息进入时，都会检查它的月度预算。

在它的页面上，**收件箱** 列出各条消息，每条都显示当前状态（**排队中**、**正在处理**、**已回答**、**没有回答**）及其回答，并有一个向它发送消息的输入框，还有 **它的对话**，用来打开该对话。

## 以智能体身份开始会话

1. 打开[开始页面](/)。在消息框下方有一行显示由谁来完成工作：程序、模型、文件夹，以及 **智能体** 标签，它显示当前选中的智能体。
2. 点击 **智能体**。在 **以以下身份开始** 下，先是内置的智能体，然后是你自己的，位于 **你的** 下：即在所有地方都可用的智能体，以及在所选项目中可用的智能体。
   - 在电脑上，名称以网格排列，每行两个。指向其中一个，可以在网格下方看到它的说明：它的描述，以及当它建议使用某个程序时，显示“使用”，后面是该程序及其模型。
   - 在手机上，菜单会从屏幕底部以面板形式打开，并列出每个智能体及其说明。
3. 选择一个，然后输入你的任务并按 Enter，或点击 **开始**。

菜单末尾的 **创建或修改智能体** 会打开[智能体页面](/agents)。智能体页面上的 **开始会话** 会打开已选中它的开始页面。

在开始页面上选择智能体会带来这些变化：

- **程序、模型和权限**：如果智能体建议使用某个程序，开始页面会切换到该程序；如果它是按档位来思考的，就使用该档位的模型，否则在智能体指定了模型时使用它的模型。如果它设有权限模式，开始页面的 **权限**（位于 **选项** 下）会变为该程序中对应的模式。在开始之前，你仍然可以更改其中任何一项。
- **连接**：智能体打开的已连接账户，会在新会话中处于开启状态。
- **文件夹**：除非你自己选择了文件夹，否则由智能体决定。大多数智能体在 **新建任务文件夹** 中开始；程序员，以及设为“开始页面上的文件夹”的智能体，会使用当前显示的文件夹。在项目中，选择智能体永远不会把你带出该项目。当智能体更改了文件夹时，输入框会显示为该位置保留的选择，以及你选中的智能体。

开始页面会为每个位置（每个项目、每个文件夹以及 **新建任务文件夹**）记住智能体，在你使用的任何设备上都是如此，并连同该位置的其他选择一起保存。尚未选择过的位置，如果项目有自己的智能体，就用项目自己的智能体打开，否则使用通用。已不存在的智能体，或在所选项目中不可用的智能体，也会让位于这个默认值。

在文件夹菜单中选择一个项目，会以该项目的选择打开输入框；在尚未做过任何选择的项目中，这包括该项目开始会话时所用的智能体（如果它有的话）（参见[项目](/guide/projects)）。

## 在会话中切换智能体

会话的消息框会显示它当前所用的智能体，你可以随时切换到另一个：比如资料收集完毕后，从 **研究员** 切换到 **撰稿人**。

1. 它是消息框下方那个打开 **选项** 的标签的第一行，该标签首先显示它，例如“研究员 · Opus 5.5”。
2. 点击它。在 **切换到** 下选择另一个：菜单与开始页面上的相同，电脑上是网格，手机上是从底部弹出的面板。
3. 应用会提示“从你的下一条消息起，智能体将以 *名称* 的身份工作”。

从你的下一条消息起，会话就以新的智能体工作，对话继续进行：

- 程序会随你的消息一起得知这次切换（对话中不会显示这一点）。
- **Claude Code 和 Codex** 在启动时读取它们的指令，所以当会话空闲时，它的程序会在你的消息之前重新启动，带上新智能体的指令和限制；这条消息会多花一点时间。如果正处于一轮进行当中，或者正在朝着某个目标工作，或后台有任务在运行，它会随你的消息一起得到新的指令，并在之后空闲时的某条消息处重新启动。
- **Custom** 在每一轮之前读取它的指令。其他智能体（Gemini CLI、OpenCode……）会随你的消息得到新智能体的指令。
- 新智能体打开的已连接账户会在会话中开启，取代上一个智能体的；你自己为会话打开或关闭的内容保持不变。如果它设有权限模式，会话会切换到对应的模式；当它建议使用会话自己的程序时，也会切换到它的模型。程序本身保持不变：如果想把对话转移到另一个程序，参见[在另一个智能体中继续](/guide/sessions#continue-in-another-agent)。

没有智能体而开始的会话（在 VS Code 或终端中，或在应用有智能体之前）会在那里显示 **无智能体**：选择一个就能给它一个智能体。会话的菜单（⋯）→ **会话设置** → **智能体** 也会显示它；点击它会打开该智能体的页面。

## 查找智能体的会话

如果会话是以通常之外的智能体开始的，侧边栏会注明：它那一行的第二行以智能体的图标和名称开头（“规划师 · web-agent · 5d”，或在工作时显示“研究员 · 工作中 · 2m 10s”）。所谓通常的智能体，对于有自己智能体的项目中的会话，就是该项目自己的智能体（**它的会话开始时使用**，位于项目详情中），对其他所有会话则是通用。在 Hydor 之外开始的会话，以及后来被你删除的智能体，同样不会显示名称。筛选和搜索依据的是每个会话实际开始时所用的智能体，包括通常的那个。若只想查看某一个智能体的会话：

- 点击侧边栏顶部的筛选按钮（**筛选和分组会话**），在 **智能体** 下选择该智能体。它会列出你的会话所用过的智能体，最常用的排在前面（最多八个），每个都附有会话数量；**所有智能体** 会再次显示全部会话。一旦有会话是以某个智能体开始的，这一部分就会显示。
- 或者打开该智能体的页面，点击 **最近的会话** 旁边的 **在侧边栏中显示全部 23 个**（当智能体的会话不超过八个时，显示为 **在侧边栏中显示它们**）。它会打开开始页面，侧边栏只显示该智能体的会话，其他筛选已清除；在手机上则会打开菜单。
- 或者在搜索框（Ctrl+K）中输入智能体的名称：“辅导老师”会找到以辅导老师身份开始的会话。通用不在此列，因为大多数会话都是它。会话在那里的预览会列出它的 **智能体**。

筛选开启时，**新建会话** 下方会有一个带图标的标签标明它：点击它的 × 可以再次显示所有会话。智能体筛选可以与其他筛选（**运行于** 和 **项目**）一起使用，比如某个智能体在某个项目中的会话。如果该智能体被删除，列表会再次显示所有会话。参见[侧边栏](/guide/start#the-sidebar)。

## 创建智能体副本或删除智能体

在智能体的页面上：

- **创建副本**（每个智能体都有）：会以 **配置** 打开窗口，作为一个新智能体，所有内容都已填好，名称为“*名称*（副本）”。按你的想法修改，然后点击 **创建智能体**；它的页面会打开。这就是制作你自己的内置智能体版本的方法。
- **删除**（仅限你自己的智能体）：会先询问“删除 *名称*？”。以它开始的会话会继续运行，但不再带有它的指令；它的日程会随它一起被删除，因为那些日程是为它写的；可以把工作交给它的其他智能体将不再列出它。以它作为开始会话身份的项目会被清除这一设置：这些项目的会话会再次以通用（或你选择的智能体）开始。它的结果历史会随之一起删除；它所填写的网页和电子表格仍保留在原处。

搜索框（Ctrl+K，Mac 上为 ⌘K）也可以按名称和描述查找智能体；选择其中一个会打开它的页面。

## 将智能体分享为文件

你的智能体可以打包成一个文件，自己留存，或者交给同事，由同事安装到他们的 Hydor 上。

- **下载智能体**：打开它的页面，然后点击 **更多**（⋯）→ **下载为文件**。内置智能体也可以下载，安装后就成为某人自己的智能体。文件（`.hydor-agent`）包含这些内容：它的指令、它可以使用什么、它的档位、程序和模型、它优先使用的技能、它的权限模式、预算和其他设置、它交办工作的智能体（按名称）、它交回的内容和成果去往的位置类型、它按时间运行的定时任务（作为建议）以及它的示例。文件中不包含属于你的内容：它工作所在的项目、它使用的已连接账户、它的成果曾写入的网页和电子表格、成果通过邮件发给谁以及从哪个账户发出、它的 webhook 地址和密钥都不会带上，而由监视、webhook 或日期触发的定时任务也只留在你这里。文件会用文字列出哪些内容被去掉了，方便你重新设置。
- **安装智能体**：在[智能体页面](/agents)打开 **新增**，选择 **从文件安装智能体**（在手机上点按 **安装**），然后点击 **选择文件** 并选取一个 `.hydor-agent` 文件（也可以直接拖到那里）。在保存任何内容之前，会先显示一张卡片，列出它的名称和一句话介绍、**它带来什么**（它的指令、它可以使用什么、它的档位、它交回的内容、它的示例、它建议的定时任务）、**它需要你做什么**（被去掉的内容，以及它要交办工作但你还没有的智能体）和供你阅读的 **它的指示**。如果你已有同名的智能体，它不会被改动：新的会装在它旁边，名为“名称 (2)”；除非你选择 **替换我的**，这样会把你的智能体变成这一个，并作为新版本保存（原来的样子留在它的 **版本** 中，你的示例也会保留，排在文件中的示例之前）。**添加它建议的定时运行（暂停）** 会添加它的定时任务，这些任务处于关闭状态，直到你自己打开。点击 **安装**，它的页面就会打开。

有些内容在导入时会改变，卡片上会说明：从不在行动前询问的智能体（**完全访问**）会以 **接受编辑** 开始；这里没有设置的程序会让位给开始页上选择的程序；来自更新版本 Hydor 的文件，会带入当前版本所能识别的内容（其余部分请更新 Hydor）。不是智能体文件或已损坏的文件会被拒绝，并说明问题所在；应用的文件要安装在[应用页面](/guide/apps#share-an-app-as-a-file)，而 Claude Code 的智能体文件则通过 **导入** 带入（见下文）。

## 导入 Claude Code 的智能体文件

Claude Code 可以把它自己的智能体保存为 `.claude/agents` 文件夹中的 Markdown 文件：开头是一段简短的头部，写有智能体的名称、描述、模型和工具，下面是它的指令。应用会把这些文件变成你的智能体，这样这里的每个程序都能这样工作。

1. 打开[智能体页面](/agents)，然后点击 **新增** 和 **导入 Claude Code 智能体文件**（在手机上，点击顶部的 **导入**）。
2. **导入 Claude Code 智能体** 会列出它找到的智能体文件：你自己放在 `~/.claude/agents` 中的（标有 **你的**），以及[文件](/files)中当前打开的文件夹里 `.claude/agents` 文件夹中的（标有 **此文件夹**）。要查看某个项目自己的智能体，请先在文件中打开该项目。
3. 点击文件旁边的 **导入**。它的智能体就会出现在智能体页面和开始页的智能体菜单中。
4. 如果文件在其他位置，点击 **选择文件**（“或者选择此设备上的智能体文件”），然后选取该 `.md` 文件。

文件必须是 Markdown（`.md`）格式，且不超过 256 KB。应用从文件中取用的内容如下：

| 智能体文件中的内容 | 智能体中的对应项 |
|---|---|
| `name`（没有时用文件名） | **名称**：“code-reviewer” 变成 “Code reviewer” |
| `description` | **一句话介绍**：取它的第一句话，不含示例 |
| `model` | **运行于**：使用该模型的 Claude Code（“inherit” 保持开始页上的设置） |
| `tools` | **它可以使用什么**，按类别；没有 tools 行的文件可以使用全部 |
| `permissionMode` | **权限模式**：default → 询问，acceptEdits → 接受编辑，bypassPermissions → 完全访问，plan → 计划 |
| `skills` | **优先使用的技能** |
| 头部下方的文字 | **指令** |

图标会根据智能体的名称和描述来选择（研究用望远镜，写作用钢笔，审查和测试用代码图标，等等）。导入的智能体在开始页上的文件夹中工作，就像 Claude Code 的智能体在项目中工作一样。

已导入的文件在列表中显示 **更新**，而不是 **导入**。**更新** 会把文件重新读入同一个智能体：它的各项设置会重新变成文件中的内容，只有你选择的图标会保留。从你的设备中选择文件，总是会生成一个新的智能体。

## 任务文件夹：没有指定文件夹的任务在哪里工作

很多任务并不属于任何文件夹：一份旅行计划、一封信、一个问题。对于这些任务，开始页上的文件夹标签显示 **新建任务文件夹**，当你点击 **开始** 时，应用会为这次会话新建一个文件夹，名称由日期和你消息中的几个词组成，例如 `~/Hydor/2026-10-31-plan-trip-lisbon`。智能体会把它的工作成果保存在那里，你可以在[文件](/files)中再次找到。

名称是这样生成的：

- 日期，按你所在的时区。
- 取你消息中最多五个词，去掉无关紧要的小词（a、the、please、help、me……）、链接和开头的 `/command`，并去掉重音符号，最长 40 个字符。如果没有剩下任何词，就用 `task`。
- 如果这个名称已被占用，就加上 `-2`、`-3`，依此类推。

### 选择任务文件夹或你自己的文件夹

打开开始页上的文件夹标签：

- **新建任务文件夹**（“在 ~/Hydor 中新建一个”）会为每次会话新建一个文件夹。
- 选择一个项目、最近使用过的文件夹，或者通过 **浏览** 找到的任意文件夹，也可以直接输入它的名称或路径，会话就会改在那里工作（见[项目](/guide/projects)和[会话](/guide/sessions)）。

在你做出选择之前，由智能体决定：除程序员之外的内置智能体，以及设置为“新建任务文件夹”的你自己的智能体，使用任务文件夹；程序员以及设置为“开始页上的文件夹”的智能体，使用显示的那个文件夹；只在某一个项目中工作的智能体，则使用该项目。开始页会记住你的选择。换一个智能体会把选择权交还给它，除非你在页面打开后选过文件夹，或者你正处在某个项目中。当文件夹发生变化时，输入框会显示为该位置保存的选择，以及你选的智能体。

任务文件夹不会挤满文件夹菜单：菜单中列出的最近使用的文件夹不包含它们。在免提模式下通过语音开始的会话也会得到一个任务文件夹，除非开始页上一次设置的是某个文件夹或项目（见[文档、图片、视频和语音](/guide/documents-voice)）。

### 移动任务文件夹

1. 在[设置 → 功能 → 你的智能体](/settings?s=assistants&find=Task%20folders)中，找到 **任务** 分组里的 **任务文件夹**（它的 (i) 说明：没有指定文件夹就开始的会话会在这里得到一个新文件夹，按日期和任务命名，而程序员则在你选择的文件夹中工作）。
2. 点击文件夹的名称。在 **工作文件夹** 下输入一个路径（输入时会给出文件夹建议，以及你最近使用过的文件夹），然后点击 **使用此文件夹**。请给出完整路径，或以 `~` 开头表示你的主文件夹。

此后新的任务文件夹都会放到那里；已经创建的文件夹留在原处。更改之后会出现 **返回 ~/Hydor**，可以用它回到默认位置。它下面的一行会显示新文件夹的样子。有自己文件夹的新项目也会放在这里，位于其中的 **项目** 文件夹内（见[项目](/guide/projects)）。

## 任务完成后清理

[设置 → 功能 → 你的智能体](/settings?s=assistants&find=Clean%20up%20after%20a%20task)的 **任务** 分组中有一个开关：**任务完成后清理**（它的 (i) 说明智能体会删除什么）。除非你关闭，它默认是开启的，并且适用于每一次会话，不论会话以哪个智能体的身份工作。

开启后，智能体在任务中的最后一步，是删除它在过程中创建且已不再需要的东西：

- 临时文件和测试文件、临时文件夹和数据、调试输出和截图；
- 它创建的、已合并或已废弃的 git 分支、工作树（仓库的额外副本，各自位于独立的分支上）和暂存内容；
- 它启动的进程、服务器或容器，除非你希望它们继续运行。

它会保留你要求的内容，以及仍需有人审阅或合并的工作（例如带有未合并提交的分支），绝不删除不是它自己创建的任何东西；当某样东西很大或不明确（例如大型下载、任何共享内容）时，会先问你。它会逐一说出要删除的每样东西，而不是按模式批量删除，并用一行话说明删除了什么、留下了什么。应用自带的清理技能包含具体方法（见[技能](/guide/skills)）。

关闭后，智能体会把它们创建的东西留在原处。无论哪种情况，智能体都会从下一次会话起遵循这一更改（Custom 则从它的下一条消息起）。

## 智能体还会出现在哪些地方

- **项目**：项目可以指定它的会话以哪个智能体开始（“会话开始时的智能体”）；在开始页上选择该项目，就会选中这个智能体。项目的 **智能体** 标签页会显示在其中工作的智能体。见[项目](/guide/projects)。
- **应用**：应用可以指定一个 **智能体**，它的运行就以该智能体开始（来自公开页面的运行除外）；应用中的各个智能体步骤也可以分别指定一个。见[应用](/guide/apps)。
- **定时任务**：任务以它的 **智能体** 选项所指定的智能体运行；智能体在会话中为你设置的任务，则与该会话以同样的方式运行。见[定时任务](/guide/tasks)。
- **免提语音**：你通过语音开始的会话，在开始页上最后选择的位置开始，使用那里的选择，并以那里选定的智能体运行（否则用项目自己的智能体，再否则用通用）。
