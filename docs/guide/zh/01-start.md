# 入门

本主题带你熟悉 Hydor：它是什么、屏幕上有什么、怎样开始你的第一个会话、怎样用搜索框找到任何东西，以及怎样在手机上使用这个应用。最后会用一张表列出所有键盘快捷键。

![应用：左边是侧边栏和你的会话，右边是开始页面，你在这里说出想做的事](images/start.webp)

## Hydor 是什么

Hydor 在你自己的电脑上运行 AI 智能体，你可以在任何浏览器里使用它们，无论是在办公桌前还是在手机上。智能体是替你完成任务的程序：它会读写文件、运行命令、搜索网络，并告诉你它做了什么。你可以用自己的订阅来使用 Claude Code 和 Codex，也可以用 Custom（应用自带的智能体，能搭配任何模型，包括在你自己电脑上运行的开放模型），以及 Gemini CLI 或 OpenCode 等其他智能体。和智能体的每一段对话就是一个**会话**。关掉页面后会话仍会继续运行，所以你可以在办公桌前开始一个会话，再在手机上回复它。很多人用它来写代码，但它什么都能帮忙：研究、写作、文档、计划和日常事务。

## 熟悉界面

屏幕分为两部分：左边的**侧边栏**，以及旁边你所在的页面（开始页、某个会话、设置……）。在手机上，侧边栏是一个滑出来的抽屉（见[在手机上使用应用](#use-the-app-on-a-phone)）。

### 侧边栏顶部

- **Hydor**，带有标志。页面正在重新连接应用时，名称旁会出现一个划掉的 Wi-Fi 图标。
- **收件箱**（托盘图标）：所有等你处理的事，比如来自每个会话、定时任务和机器的批准请求、问题和表单。图标角上的数字表示此刻有多少个会话在等你。见[收件箱和通知](/guide/inbox)。
- **隐藏侧边栏**（Ctrl+B）。侧边栏隐藏时，每个页面左上角的按钮可以让它重新显示。在手机上，这个按钮是**关闭菜单**。
- 机器切换器，只有在你于[设置 → 机器](/settings?s=machines)中添加了其他机器后才会出现。它显示你正在查看的机器名称，另一台机器上的会话需要你时，会显示一个圆点。见[手机、其他机器和分享](/guide/devices)。
- **新建会话**会打开[开始页](#the-start-page)。
- **搜索会话**按标题、文件夹和会话中说过的话查找会话，包括已归档的会话。按 Escape 清空。在电脑上，输入框末尾的 **Ctrl+K** 标记则会打开搜索框（见[用 Ctrl+K 搜索一切](#search-everything-with-ctrlk)）。
- 这个输入框末尾的筛选按钮（**筛选和分组会话**）可以缩小列表范围：**所有智能体**、**Claude Code** 或 **Codex**；有了项目之后，还有**所有项目**或你的某个项目（最多列出八个），以及用来打开“项目”页面的**项目**。有筛选生效时，按钮会显示为强调色。菜单的最后一行**按文件夹或项目分组**用来打开或关闭你的项目和文件夹分组（见[会话列表](#the-session-list)）。见[项目和知识](/guide/projects)。

### 会话列表

搜索输入框下面是所有会话，分组列出：

- **活跃**：过去五分钟内有活动的所有会话，无论是在这里，还是在 VS Code 或终端里，包括已经完成的会话。五分钟没有活动后，它们会回到原来的分组，即使智能体仍然开着。因用量限额停止、并已安排自动继续的会话会留在这里；取消自动继续后，恢复五分钟规则。仍有后台智能体、命令或监视器在运行的会话也会留在这里，无论多久没有动静，直到它们结束。显示在这里时位置保持不变；拖动可以移动它们。
- **已置顶**：你置顶的会话，按你拖动排好的顺序。把下面各组中的会话拖到这里即可置顶。
- **项目**：你的每个项目各有一组，有两个或更多会话在其中工作的每个你的文件夹也各有一组，以它的名字为标题；最近用过的排在前面，直到你自己排好顺序：按住分组的标题把它拖到其他分组之间的新位置（在手机上，先按住标题片刻）。这个顺序在每台设备上都一样，你从未移动过的分组（比如之后新建的项目）排在最前面。每组显示最新的五个会话；**再显示 12 个**（或实际剩下的数量）列出其余的，**收起**则回到原样。
- **今天**、**昨天**、**本周**，然后是月份和年份：其余的会话，按最后活跃的时间排列。
- **已延后**：在最下面，直到它们的时间到了。

只有你自己选的文件夹才有分组。主文件夹、默认文件夹、新任务文件夹、应用运行所用的文件夹和临时文件夹都没有分组，它们的会话按天列出。worktree 中的会话归入创建该 worktree 的文件夹的分组；在项目中开始的会话归入该项目的分组，不论它在哪个文件夹中工作。Codex 项目的文件夹以项目名称显示。Codex 应用为你的 ChatGPT 项目创建的文件夹只以一串 ID 命名，所以除非 Codex 知道项目名称，它们也没有分组，其会话的文件夹显示为**ChatGPT 项目**。在它的某个会话的菜单中用**重命名文件夹**给它起个名称，它就会以这个名称获得一个分组。两个同名文件夹会显示它们上层的文件夹，直到能区分为止（“client/app”“server/app”）。

点击分组的标题可以把它折叠成一行，显示其中有多少个会话；若有会话在你上次查看之后完成，还会显示一个圆点。再点一次即可展开。过去一周内没有活跃会话的分组一开始是折叠的。当前打开的会话始终显示在它的分组中，无论分组是否折叠。你如何折叠分组会保存在这个浏览器中。标题末尾的笔形按钮（在电脑上，指向标题时出现）会在该文件夹或项目中新建会话；旁边的 **⋯**（或在标题上右键单击）打开它的菜单：**重命名**、**使用文件夹本来的名称**（针对你重命名过的文件夹），以及**打开项目**或**在“文件”中打开**。要重命名一个分组，也可以双击它的名称：输入新名称后按 Enter（按 Esc 保持原样）。项目的新名称在所有地方都是它的名称；文件夹的新名称是应用对它的称呼，显示在侧边栏、每个会话下方和文件夹菜单中，在所有设备上都一样（文件夹在磁盘上的名称不变）。清空名称即可让文件夹恢复本来的名称。

你在 Hydor 之外用 Claude Code 或 Codex 开始的会话（在 VS Code、终端、Claude 桌面版或 Codex 应用中）也会列出，所以它们的文件夹也会像其他文件夹一样获得分组。如果一个文件夹的第一个会话是在 Hydor 之外开始的，它就会显示其会话来自哪里：名称后面有 Claude Code 或 Codex 的标志，两者都有会话时两个都显示。指向名称，或打开标题的 **⋯**，即可看到它们是在哪些应用中启动的，例如**来自 Codex：VS Code, 终端**；如果它们属于你在[设置 → 智能体 → 账户](/settings?s=accounts&find=Your%20accounts)中添加的账户，还会显示该账户的名称。之后你从 Hydor 在那里继续工作时，标志仍会保留：它表明这个文件夹的工作是从哪里开始的。

若只想像以前那样按天列出会话，可以在筛选按钮的菜单中取消勾选**按文件夹或项目分组**，或者在搜索框中找到**按文件夹或项目给会话分组**；用同样的方法可以切换回来。列表只显示一个项目时，它的会话按天列出。

已归档的会话不会列出，但**搜索会话**仍然能找到它们。在你的第一个会话出现之前，这里会显示“还没有会话。”

每一行显示智能体的图标和一个状态圆点、会话标题，以及第二行文字。智能体运行时，第二行说明它在做什么（“工作中 · 2 分 10 秒”，之前已有几轮时还会写出合计工作了多久，如“工作中 · 2 分 10 秒 (47 分)”；“需要你处理”“就绪”“工作中 · 1 个在后台”“已在 VS Code 中打开”）。否则，它显示文件夹（你的主文件夹显示为“主文件夹”）、会话多久以前活跃过，以及增加和删除了多少行。在**项目**下，分组已经写明了文件夹，所以每个会话只占一行：标题，然后是会话多久以前活跃过（前面是 worktree 的分支），或者在智能体工作或需要你处理时显示它在做什么。标题后面可能跟着一些小标记：

- 一个强调色的圆点：自你上次查看以来它已经完成（第二行显示“已完成 · 5 分钟前”）；打开它，就会在所有设备上标为已读；
- 一个拉取请求标记，带有它的状态；
- 一个靶心：这个会话设有目标；
- 一枚图钉：它已置顶（在**已置顶**分组中没有，因为分组已经说明了）。

Custom 工作或启动时，工作指示器使用 Hydor 加载动画（Ω 中的水起伏涨落），而不是旋转的智能体图标。加载图标与旁边的文字垂直居中对齐。

状态圆点表示会话的情况：

| 圆点 | 含义 |
| --- | --- |
| 蓝色，呼吸闪烁 | 工作中：一轮对话正在进行，或有后台任务在运行 |
| 琥珀色 | 需要你处理：有批准请求、问题或表单在等待 |
| 绿色 | 就绪：智能体正在运行，等你发下一条消息 |
| 灰色 | 在 VS Code 或终端中打开，并在那里处于空闲状态 |
| 无圆点 | 已停止：智能体没有运行；你的下一条消息会让它重新启动 |

浏览器标签页会显示有多少个会话在等你，比如“(2) Hydor”。

智能体为完成部分工作而启动的会话（子会话）折叠在它下面，带有一行类似“3 个子会话 · 1 个需要你 · 2 个在工作”的文字；点击即可查看。见[子会话](/guide/sessions#child-sessions)。

列表中的每个会话都有一个菜单：指向它的行并点击末尾的 **⋯**，或者右键单击这一行（在手机上，轻点它的 **⋯**）。菜单里有**重命名**、**重命名文件夹**（针对不在项目中的会话）、**置顶**（或**取消置顶**）、**延后**、**告一段落**、**归档**和**删除**（删除前会先询问）。双击标题，或在选中的行上按 F2，即可重命名。这些操作都在[重命名、置顶、延后、告一段落、归档或删除](/guide/sessions#rename-pin-snooze-settle-archive-or-delete)中有说明。

### 底部的工具

侧边栏底部放着应用的工具，每行四个：

- **资料库**：智能体为你做的小工具和页面、你保存的图片和视频，以及你发布的内容。见[资料库：页面、图片、视频和网站](/guide/library)。
- **项目**：每个项目的会话、文档和准则都放在一起，还有每个会话都能搜索的共享知识。见[项目和知识](/guide/projects)。
- **应用**：你一再重复的任务：填好一张表单，智能体就会完成这项工作。见[应用](/guide/apps)。
- **智能体**：你的智能体，每个做什么、在哪里和何时工作、用什么思考、向谁求助，以及应用自带的智能体。见[智能体](/guide/agents)。
- **系统**：这台电脑，它的每个工具各有一个标签页：**概览**（它的运行状况，以及每个工具现在有什么）、**文件**（浏览、打开和编辑文件）、**Git**（你的代码仓库，以及它们的更改、分支和历史）、**终端**（离开页面后仍会继续运行的 shell）、**预览**（这里运行的 Web 应用开发服务器；只出现在这台机器自己的页面上）、**监控**（处理器、显卡、内存、磁盘和最忙的程序，实时显示）和**用量**（每个套餐的限额你用了多少、什么时候重置，带有**活动**和**竞技场**标签页；“系统”图标下的一条细线显示你所有付费订阅合计还剩多少（没有付费订阅时，按免费订阅计算），用完时变成红色）。见[系统：文件、Git、终端和预览](/guide/files-git)和[用量、限额和费用](/guide/usage)。
- **设置**：应用能设置的一切。上面有个圆点表示有新版本发布了。见[所有设置](/guide/settings)。
- **搜索**：打开搜索框（与 Ctrl+K 相同）。
- **帮助**：打开本指南，在那里还可以向智能体询问这个应用的用法。欢迎导览也从这里开始。

这是它们的默认顺序。要改变顺序，把一个工具拖到其他工具中间的另一个位置（在手机上，先按住它片刻）。工具会在每台设备上保持你设定的顺序，无论你在查看哪台机器。移动过之后，在电脑上右键点击任意一个工具，选择**恢复默认顺序**，就能把它们全部放回原位。

### 开始页

**新建会话**会打开开始页。它会问“我们来做点什么？”，有一个大大的消息框，下面有一排选项：

- **运行于**：由哪个程序来做这项工作（Claude Code、Codex、Custom，或你添加的其他智能体）。
- **模型**：那个智能体的模型。
- **文件夹**：智能体工作的地方，也可以是一个项目，或者为这项任务新建的文件夹。
- **智能体**：会话以谁的身份工作（通用、研究员、撰稿人、程序员、辅导老师、规划师、分析师、应用搭建师，或你自己的智能体；见[智能体](/guide/agents)）。
- **选项**：思考强度、权限、记忆、花费上限等。凡是你设得和平常不一样的，这个按钮上都会写出来。

在电脑上，输入框下面有一行提示：“Enter 开始 · Shift+Enter 换行”。再往下，**今天**汇总了今天到目前为止的情况（更改的行数、token、提示词、会话）；点击它可以打开“活动”页面。当某个智能体的套餐用量用完时，输入框上方会有一条横幅说明这一点，并告诉你何时重置。在手机上，**最近**会在输入框下面列出你最近的六个会话。

右上角的**探索**会打开一本为你制作的杂志：关于你所做的事和你关心的事的文章和近期新闻，根据你的档案和你最近的会话挑选（见[探索](/guide/apps#explore)）。上面有一个小圆点，表示有一期你还没打开的新杂志已经准备好了。

开始页上的所有内容都在[开始一个会话](/guide/sessions#start-a-session)中有说明。

## 开始你的第一个会话

1. 确保智能体能够工作。Claude Code 和 Codex 需要你登录：打开[设置 → 智能体 → 账户](/settings?s=accounts&find=Your%20accounts)，找到**你的账户**，按智能体旁边的**登录**，然后按步骤操作（打开一个链接、批准，再粘贴或输入一个代码）。Custom 需要一个模型：在[设置 → 智能体 → 模型](/settings?s=models)中添加一个。第一次使用时，欢迎导览会陪你完成这些。见[智能体、账户和模型](/guide/agents-models)。
2. 按侧边栏顶部的**新建会话**。应用启动时打开的也是开始页。
3. 按消息框下面的**运行于**，选择程序。旁边的**模型**用来选择它的模型；标着“默认”的那个就很适合起步。
4. 按**文件夹**，选择智能体工作的地方：
   - 你最近用过的某个文件夹，或另一个文件夹：在**查找文件夹，或输入它的路径**中输入它的名称或路径；
   - 一个项目，按名称选择，就会在那个项目的文件夹里工作，并带上它的文档和准则；
   - **新建任务文件夹**，为你的任务新建一个以它命名的文件夹（默认在 `~/Hydor` 中，可以在[设置 → 功能 → 你的智能体](/settings?s=assistants&find=Task%20folders)中更改）。

   大多数智能体在你不选文件夹时，会从一个新的任务文件夹开始；程序员智能体则在你选的文件夹里工作。
5. 在消息框里输入你想做的事：描述一项任务、问一个问题，或粘贴一段错误信息。用回形针添加文件，或者把文件拖到输入框上。已经在这台电脑上的文件可以从“文件”页面带过来：使用文件菜单中的**用它开始会话**（见[用文件开始会话](/guide/files-git#start-a-session-with-files)）。
6. 按 Enter，或按**开始**。在手机上，轻点圆形箭头。

会话随即打开。智能体工作时，你会看到它用平常话写出的各个步骤，最后是它的回复。当它想运行某个命令或修改某个文件，而它的权限不允许它自行这样做时，会出现一张卡片，请你选择**允许**或**拒绝**。在底部的消息框中输入，就能继续对话。你在开始页上的选择会保留到下一个会话，在所有设备上都一样。

下一步：[会话](/guide/sessions)介绍了你在会话中能做的一切。

## 用 Ctrl+K 搜索一切

搜索框会在你输入时找出应用中的任何东西，就像 Mac 上的 Spotlight。在任何页面上都可以用 Ctrl+K（Mac 上是 ⌘K）打开它，只有在代码编辑器或终端里输入时除外。侧边栏中的**搜索**图块和**搜索会话**中的 Ctrl+K 标记也能打开它。再按一次 Ctrl+K 或按 Esc 即可关闭。

### 它能找到什么

- **前往**：Hydor 的页面，比如新建会话、收件箱、文件、在文件中搜索、Git、终端、应用、新建应用、项目、共享知识、资料库、图片、视频、已发布、预览、用量与限额、模型竞技场、活动、系统和设置。
- **操作**：开始导览、免提对话、版本说明、在浅色和深色之间切换、显示或隐藏侧边栏、按文件夹或项目给会话分组、显示或隐藏终端面板。
- **设置**：设置中的每个部分以及其中的选项。打开其中一项，就会打开它所在的部分，并指向那个选项。
- **主题**：内置主题和你自己的主题。打开一个就会切换过去。
- **会话**：按标题、文件夹、分支和第一条消息查找（不含已归档的）。打开一个就会打开那个会话。
- **消息中**：包含你输入的词语的消息。打开一条，就会在那些词语处打开它所在的会话，并准备好查找栏。
- **记忆**：你的记忆笔记。打开一条，会在设置 → 记忆中定位到那条笔记。
- **项目**：你的项目，按名称和描述查找。打开一个就会打开那个项目。
- **应用**、**定时任务**、**智能体**、**技能**、**页面**、**图片、视频和音频**和**连接**：你自己的，以及现成的。每一项都会在它所在的地方打开。
- **文件**：名称相符的文件，最多五个，范围是“文件”页面显示的文件夹（或应用的默认文件夹）。

### 选择搜索范围

输入框末尾的**搜索范围**显示搜索框在哪里查找：在你挑选位置之前是**全部**。点击它会列出：**会话**、**消息**（会话中说过的话）、**项目**、**资料库**（页面、图片和视频）、**应用**、**文件**、**记忆**、**定时任务**、**智能体**、**技能**、**连接**、**设置**（包括主题）、**前往和操作**（应用自己的页面和操作）和**指南**。

- 勾选一个或几个，搜索框就只在那里查找。按钮会用强调色写出它们（“会话, 资料库”，或“3 个位置”）。再点一次某个位置可以把它去掉，点**全部**则重新在所有位置查找。
- 什么都没输入时，它会列出你挑选的位置里有什么，最常用的排在前面：你最近的会话、项目和页面，设置的各个部分，指南的各个主题。消息、记忆笔记和文件要等你输入词语。
- 你的选择会在所有设备上保留，直到你更改。什么都没找到时，提示下方的**搜索全部**会重新在所有位置查找。
- 在手机上，**搜索范围**是**取消**旁边的筛选图标（挑选位置后它会写出这些位置），它的列表从屏幕底部打开。

### 结果怎样显示

- **最佳匹配**排在最前面。然后每一类各有一组，每组最多四行；“3 条更多结果，来自会话”会显示其余的。
- 在宽屏幕上，列表旁边的预览会进一步介绍你当前选中的结果，以及打开它会去到哪里。
- ↑ 和 ↓ 移动，Enter 打开。Esc 清空你输入的内容，再按一次 Esc 关闭搜索框（**搜索范围**列表打开时，Esc 先关闭列表）。
- 什么都没输入时，它会列出**最近的会话**和**建议**：你最常去的地方（在它了解你之前，会先列出几个有用的地方）。在**搜索范围**中挑选了位置时，则改为列出这些位置里有什么。
- 底部那一行显示**词语**或**词语和含义**。[按含义搜索](/settings?s=memory&find=Search%20by%20meaning)开启时（除非你在设置 → 功能 → 记忆中把它关掉，否则它一直开启），结果还会匹配你用其他说法、甚至其他语言表达的意思。

### 它会学习你常用的东西

- 你选了什么，以及当时输入了什么。再次输入同样的词，那个结果会立刻排在最前面。
- 你去过的地方，无论是怎样去的：页面、设置的各个部分、会话、应用、文件。在相符的结果中，你常用的会往前排：和你输入的内容越相符，往前排得越多；随着时间推移，往前排得越少。
- 应用会替你保存这些，所以你的手机和电脑会一起学习。

侧边栏的**搜索会话**输入框是更简单的搜索：它只列出会话，按标题、文件夹和消息中的词语查找，包括已归档的会话。

## 在手机上使用应用

要从手机上访问这个应用，它需要一个 HTTPS 地址（Tailscale、Cloudflare 隧道或你自己的代理）。见[手机、其他机器和分享](/guide/devices)。

### 把它添加到主屏幕

这个应用可以像 App 一样安装，并全屏打开：

- **iPhone 或 iPad**：在 Safari 中打开它，然后点“分享”→ **添加到主屏幕**。
- **Android**：在 Chrome 中打开它，然后点 ⋮ → **添加到主屏幕**（或**安装应用**）。

在 iPhone 或 iPad 上，通知只在添加到主屏幕的应用中有效：从主屏幕打开它，然后在设置 → 应用 → 通知中开启[通知此设备](/settings?s=notifications&find=Notify%20this%20device)。见[收件箱和通知](/guide/inbox)。

### 侧边栏是一个抽屉

- 每个页面左上角的**菜单**按钮可以打开它。它会占满整个屏幕。
- 轻点一个会话或工具，就会跳转过去并关闭抽屉。**关闭菜单**（×）也能关闭它。
- 按住一个会话片刻把它拿起来，然后拖动（给活跃或已置顶的会话重新排序，或者把某个会话置顶）。
- 按住底部的一个工具片刻把它拿起来，然后把它拖到其他工具中间的另一个位置。
- 每行末尾的 **⋯** 打开会话的菜单：**重命名**、**重命名文件夹**、**置顶**、**延后**、**告一段落**、**归档**和**删除**（删除前会先询问）。

### 菜单以底部面板打开

在手机上，开始页消息框下面的选项（运行于、模型、文件夹、智能体、选项）会以面板形式从屏幕底部弹出，不会被键盘挡住。文件夹面板里的查找框要等你轻点后才会激活，这样键盘就不会盖住列表。

### 输入和发送

- 开始页会在消息框下面以**最近**列出你最近的六个会话；**所有会话**会打开抽屉。
- Enter 用来换行。轻点圆形箭头可以开始会话或发送消息（接上键盘时，Ctrl+Enter 或 ⌘Enter 也能发送）。
- 在会话中，消息框显示一个写着模型的按钮（思考强度和权限不是平常的设置时，也会一并显示）。它会打开一个面板，里面有**模型**、**思考强度**、**权限**，以及对话的上下文容量已用了多少，还有**压缩**。
- 要引用回复或你自己消息中的一部分，就选中它：**引用**会出现在选中内容的正下方。
- **详情**只在你需要时，才会覆盖在对话上方打开。
- 搜索框会占满屏幕；**取消**可以关闭它。
- 截图按钮只在电脑上有。

## 获取帮助

侧边栏中的**帮助**会打开本指南。在它首页顶部的框里输入一个问题或几个词：

- **匹配的章节**会随着你输入显示出来，点一个就能打开。搜索框（Ctrl+K）也能找到它们。
- **按 Enter**，或点**询问**，就会有一个智能体在指南旁边的面板里回答，并附上指向相应位置的链接。它还可以替你更改设置或设置好某样东西，但要等你在卡片上确认这项更改之后。这个回答是一个普通的会话，用的是你上次在开始页面选的智能体和模型：可以在面板里接着问，也可以用面板顶部的箭头在它自己的页面里打开。

每个帮助页面顶部的**问智能体**会打开同一个面板；搜索框中的“向智能体询问这个应用”也一样。各个主题按组排列在框的下方。每个主题的章节一次打开一个（**全部展开**会把它们都显示出来），主题末尾还有可以问智能体的问题：点一个，它会放进面板的输入框里，你可以先改一改，再发送。

- 欢迎导览会带你四处看看，并设置好你想用的智能体。可以用帮助页面顶部的**开始导览**启动它，也可以从设置 → 应用 → 通用中的[开始导览](/settings?s=general&find=Take%20the%20tour)启动，或者在搜索框中输入“tour”。如果 Hydor 在这台电脑上找到你以前用过的其他智能体（Claude Code、Codex 或其他）的文件夹，导览会多出一步：**从别的智能体转过来？**它会说出找到了什么，点**导入它们所了解的内容**会在导览之上打开[导入](/guide/memory#bring-in-from-other-assistants)，把它们对你的了解和你做的技能带过来。这些都没有时，就没有这一步。导览之后，小贴士会在你第一次用到应用的各个部分时，一次一个地为你介绍其余功能（参见[开始导览](/guide/app#take-the-tour)）。
- **版本说明**（在设置 → 应用 → 通用中，或从搜索框打开）介绍每个版本有哪些变化。更新之后，会显示一次“新功能”说明。
- 应用中的智能体也会读这份指南：在任何会话中问“怎么……”，它都能回答，或者直接替你去做（见[让智能体替你操作应用](/guide/ask-agents)）。
