# 入门

本主题带你熟悉 Hydor：它是什么、屏幕上有什么、怎样开始你的第一个会话、怎样用搜索框找到任何东西，以及怎样在手机上使用这个应用。最后会用一张表列出所有键盘快捷键。

![应用：左边是工具栏和带着你的会话的侧边栏，右边是开始页面，你在这里说出想做的事](images/start.webp)

## Hydor 是什么

Hydor 在你自己的电脑上运行 AI 智能体，你可以在任何浏览器里使用它们，无论是在办公桌前还是在手机上。智能体是替你完成任务的程序：它会读写文件、运行命令、搜索网络，并告诉你它做了什么。你可以用自己的订阅来使用 Claude Code 和 Codex，也可以用 Custom（应用自带的智能体，能搭配任何模型，包括在你自己电脑上运行的开放模型），以及 Gemini CLI 或 OpenCode 等其他智能体。和智能体的每一段对话就是一个**会话**。关掉页面后会话仍会继续运行，所以你可以在办公桌前开始一个会话，再在手机上回复它。很多人用它来写代码，但它什么都能帮忙：研究、写作、文档、计划和日常事务。

## 熟悉界面

屏幕分为三部分：最左边窄窄的一条**工具栏**，放着应用的工具；有些页面在它旁边还有一**栏**：在开始页和会话里是列出你的会话的**侧边栏**，在应用、智能体、帮助和设置里是它们各自的列表；以及你所在的页面（开始页、某个会话、设置……）。在电脑上，工具栏始终都在。在手机上没有工具栏：侧边栏是一个滑出来的抽屉，工具也放在里面（见[在手机上使用应用](#use-the-app-on-a-phone)）。

在电脑上，你可以把这一栏拉宽或收窄，范围是 180 到 560 像素：拖动它的右边缘，或者点一下边缘再按左右方向键。所有栏的宽度相同，并保存在这个浏览器里。

### 工具栏

工具栏是一列图标；把鼠标指向某个图标，或用 Tab 键移到它上面，旁边的提示会显示它的名称，有快捷键的还会显示快捷键。你当前所在页面的图标会高亮，紧贴屏幕边缘的一侧有一道强调色的竖条。从上到下依次是：

- **会话**：在侧边栏里显示你的会话。在开始页或某个会话里，它会隐藏或显示侧边栏（与 Ctrl+B 相同）。在其他任何页面，它会显示侧边栏，并带你回到你在这个窗口里最后打开的会话；没有的话，回到开始页。侧边栏隐藏时，这个图块上的一个小圆点表示其他机器上发生了什么事（见[在机器之间切换](/guide/devices#switch-between-machines)）。

然后是应用的各个板块（桌面应用有八个；Web 应用和手机上是七个，没有**浏览器**）：

- **浏览器**：属于你自己的浏览器，只在桌面应用中有，带有标签页、无痕标签页、智能地址栏、网页翻译、阅读视图、书签、历史记录、广告拦截器和 Chrome 扩展程序，你可以从中把一个页面交给智能体。见[你自己的浏览器](/guide/web#your-own-browser)。
- **项目**：每个项目一张卡片，显示它包含什么、最后一次工作是什么时候；点击卡片会打开项目的详情。见[找到你所有的项目](/guide/projects#find-all-your-projects)。
- **文件**：这台电脑上的文件，可以浏览、打开和编辑。见[打开文件页面](/guide/files-git#open-the-files-page)。
- **智能体**：你的智能体，每个做什么、在哪里和何时工作、用什么思考、向谁求助，以及应用自带的智能体。见[智能体](/guide/agents)。
- **应用**：你一再重复的任务：填好一张表单，智能体就会完成这项工作。见[应用](/guide/apps)。
- **Git**：你的代码仓库，以及它们的更改、分支和历史，第一次打开时有一段简短导览。见[在 Git 页面查看你的仓库](/guide/files-git#see-your-repositories-on-the-git-page)。
- **实验**：等待空闲 GPU、自行运行并作为记录保存下来的训练和评估作业，第一次打开时有一段简短导览。见[实验](/guide/experiments)。
- **作业**：你的会话在后台运行的耗时工作，显示还剩多长时间，以及哪个在等哪个。上面的数字表示正在运行的作业数量。参见[作业](/guide/jobs)。

紧挨在它们下面，位置始终不变：

- **收件箱**：所有等你处理的事，比如来自每个会话、定时任务和机器的批准请求、问题和表单。图标角上的数字表示此刻有多少件事在等你。见[收件箱和通知](/guide/inbox)。
- **搜索**：打开搜索框（与 Ctrl+K 相同）。

然后隔开一段距离，是各个工具：

- **用量**：每个套餐的限额你用了多少、什么时候重置，带有**活动**和**竞技场**标签页；它图标下的一条细线显示你所有付费订阅合计还剩多少（没有付费订阅时，按免费订阅计算），用完时变成红色。见[用量、限额和费用](/guide/usage)。
- **系统**：这台电脑，它的每个工具各有一个标签页：**概览**（它的运行状况，以及它的各个工具现在有什么）、**终端**（离开页面后仍会继续运行的 shell）、**预览**（这里运行的 Web 应用开发服务器；只出现在这台机器自己的页面上）和**监控**（处理器、显卡、内存、磁盘和最忙的程序，实时显示）。见[文件、Git、终端和预览](/guide/files-git)。
- **设置**：应用能设置的一切。上面有个圆点表示有新版本发布了。见[所有设置](/guide/settings)。
- **帮助**：打开本指南，在那里还可以向智能体询问这个应用的用法。欢迎导览也从这里开始。

板块的默认顺序是浏览器、项目、文件、智能体、应用、Git、实验、作业，然后是收件箱和搜索，它们下面的工具依次是用量、系统、设置、帮助。要改变顺序，把一个图块拖到它所在那一组里的另一个位置（板块一组，或最下面的工具一组）；收件箱和搜索始终紧挨在板块下面。新版本带来的图块会放在你设定的顺序里它的默认位置（比如文件就在智能体之前），而不是列表末尾。图块会在每台设备上保持你设定的顺序，无论你在查看哪台机器。移动过之后，右键点击任意一个图块，选择**恢复默认顺序**，就能把它们全部放回原位。窗口太矮放不下所有图块时，工具栏可以滚动。

列出会话的侧边栏只在开始页、会话里和会话的审阅页出现。**应用**、**智能体**、**帮助**和**设置**有同样的一栏，里面是标志、它们各自的列表（应用页面和智能体页面的各个位置，指南的各个主题，设置的各个分区）和**隐藏侧边栏**；**浏览器**页面则把它的标签页放在自己的一栏里，其他页面（项目、收件箱、用量、系统……）都用满整个宽度。**Ctrl+B** 隐藏或显示你所在页面的那一栏，所有栏的宽度都相同。一栏里的内容放不下时，会显示它的滚动条；下方还有内容时，栏的底部会渐隐。页面正在重新连接应用时，一个划掉的 Wi-Fi 图标会显示在这一栏顶部的标志旁边；没有栏可看时（它被隐藏了，或者页面没有栏），则显示在工具栏顶部。

### 侧边栏

侧边栏是工具栏旁边的那一栏。它包含：

- **HYDΩR** 标志，末尾是**筛选和分组会话**按钮和**隐藏侧边栏**（Ctrl+B）。侧边栏隐藏时，页面左上角的按钮可以让它重新显示，工具栏则一直都在。在手机上，这里换成标志、收件箱、筛选按钮和**关闭菜单**。
- 机器切换器，只有在你于[设置 → 机器](/settings?s=machines)中添加了其他机器后才会出现。它显示你正在查看的机器名称，并说明其他机器上发生了什么：强调色药丸里的数字表示自你上次查看以来那里已结束的会话数，橙色圆点表示那里有会话需要你处理。见[手机、其他机器和分享](/guide/devices)。
- **新建会话**会打开[开始页](#the-start-page)。
- 要查找会话，用搜索框：工具栏上的**搜索**（在手机上是抽屉底部工具中的**搜索**），或 Ctrl+K（Mac 上是 ⌘K）。它按标题、文件夹、会话是以哪个智能体开始的（输入 Tutor 就能找到以 Tutor 开始的会话；General 除外）和会话中说过的话查找会话，已归档的会话也在内，标有**已归档**，排在其他会话之后（见[用 Ctrl+K 搜索一切](#search-everything-with-ctrlk)）。
- 顶部的筛选按钮（**筛选和分组会话**）用来缩小列表范围。它的菜单分为几部分：**智能体**（先是**所有智能体**，然后是启动过你会话的智能体，按使用次数从多到少排列，最多八个，每个都标明有多少会话；只有在某个会话是以智能体启动的之后才会出现）、**运行于**（一个切换项，可选**不限**、**Claude Code** 和 **Codex**），以及有了项目之后出现的**项目**（先是**所有项目**，然后是你的项目，最多八个）。**新建项目…**用于创建项目，**新建文件夹…**（列表处于分组状态时显示）用于创建存放会话的文件夹（见[把会话归入文件夹](#sort-sessions-into-folders)）。多个筛选条件会同时生效，例如某个项目中某个智能体的会话。有筛选条件开启时，按钮会变为强调色，每个开启的条件会在**新建会话**下方显示一个带图标和名称的标签：点它的 × 可取消该条件，重新显示全部会话。筛选后没有任何结果时，列表会显示“没有符合筛选条件的会话。”，并提供**显示所有会话**。最后一行**按文件夹或项目分组**用于开启或关闭项目和文件夹的分组（见[会话列表](#the-session-list)）。见[查找某个智能体的会话](/guide/agents#find-an-agents-sessions)和[项目与知识](/guide/projects)。

### 会话列表

**新建会话**下面是所有会话，分组列出：

- **活跃**：过去五分钟内有活动的所有会话，无论是在这里，还是在 VS Code 或终端里，包括已经完成的会话。五分钟没有活动后，它们会回到原来的分组，即使智能体仍然开着。因用量限额停止、并已安排自动继续的会话会留在这里；取消自动继续后，恢复五分钟规则。仍有后台智能体、命令或监视器在运行的会话也会留在这里，无论多久没有动静，直到它们结束。显示在这里时位置保持不变；拖动可以移动它们。
- **已置顶**：你置顶的会话，按你拖动排好的顺序。把下面各组中的会话拖到这里即可置顶。点击标题可以折叠它；折叠时，拖动会话会在标题下方显示一个**拖到这里即可置顶**框，把会话放进去即可。
- **文件夹**：你为不属于任何项目的会话自己建立的文件夹（如果建过的话，见[用文件夹整理会话](#sort-sessions-into-folders)）。它位于**项目**上方。
- **项目**：每个有会话的项目各有一组；你的每个文件夹，只要有两个或更多会话在其中工作，也会以文件夹名称单独成组。最近使用过的排在最前面，直到你自己调整顺序：抓住某组的标题，把它拖到其他位置（在手机上，先按住标题片刻）。这个顺序在所有设备上都一样，你从未移动过的组（例如之后新建的项目）排在最前面。每组显示最新的五个会话；**Show 12 more**（数字为实际剩余数量）会列出其余会话，**收起**则恢复原样。项目自己的文件夹（见[用文件夹整理会话](#sort-sessions-into-folders)）排在项目标题下的最前面。
- **今天**、**昨天**、**本周**，然后是月份和年份：其余的会话，按最后活跃的时间排列。
- **已延后**：在最下面，直到它们的时间到了。

只有你自己选的文件夹才有分组。主文件夹、默认文件夹、新任务文件夹、应用运行所用的文件夹和临时文件夹都没有分组，它们的会话按天列出。worktree 中的会话归入创建该 worktree 的文件夹的分组；在项目的文件夹或其中的文件夹里工作的任何会话都归入该项目的分组，不论它是在哪里启动的：在 Hydor、Claude Code 还是 Codex 中。Codex 项目的文件夹以项目名称显示。Codex 应用为你的 ChatGPT 项目创建的文件夹只以一串 ID 命名，所以除非 Codex 知道项目名称，它们也没有分组，其会话的文件夹显示为**ChatGPT 项目**。在它的某个会话的菜单中用**重命名文件夹**给它起个名称，它就会以这个名称获得一个分组。两个同名文件夹会显示它们上层的文件夹，直到能区分为止（“client/app”“server/app”）。

在**文件夹**和**项目**下，列表是树状结构：每个标题前面都有一个箭头（点击可折叠），项目或文件夹下的会话沿一条细线缩进排列，折叠后的标题右端会显示它包含的会话数。**活跃**、**已置顶**、**文件夹**和**项目**这几个标题都可以折叠：点击一次隐藏其下的所有内容，再点击一次重新显示。折叠时，**活跃**和**已置顶**会显示包含的会话数；如果其中有会话在你上次查看之后完成了，还会显示一个圆点。当前打开的会话即使所在部分已折叠，也会在标题下保持可见。这些折叠状态会按你离开时的样子保存在这台电脑上，但**项目**内各个项目或文件夹的折叠状态除外。**项目**标题末尾的 **+** 始终可见，其中有**新建项目…**、**新建项目组…**（见[创建项目](/guide/projects#make-a-project)）和**新建文件夹…**。

点击文件夹的标题，可将它折叠成一行，显示包含的会话数；如果其中有会话在你上次查看之后完成了，还会显示一个圆点。再点击一次即可展开。项目标题的用法不同：点击项目名称会在窗口中打开项目详情（见[打开项目详情](/guide/projects#open-a-projects-details)），用名称前的箭头折叠它的会话。每个组一开始都是折叠的，只显示标题和包含的会话数；展开你需要的组，它们会保持你设置的状态。当前打开的会话无论所在组是否折叠，都保持可见。各组的折叠状态保存在这个浏览器中。标题末尾的按钮（在电脑上，把指针移到标题上时出现在末端；在触摸屏上始终显示）有两个：笔形按钮在该文件夹或项目中新建会话；**⋯** 打开它的菜单（右键点击标题也可以打开）。项目的菜单里有**项目详情**、**重命名**和**新建文件夹**；电脑上文件夹的菜单里有**重命名**、**使用文件夹本来的名称**（重命名过之后）、**设为项目**和**在“文件”中打开**。要重命名文件夹，也可以双击它的名称：输入新名称后按 Enter（按 Esc 则保持原样）。项目通过它的 ⋯ → **重命名**（或右键点击标题）来重命名。项目的新名称在所有地方生效；文件夹的新名称只是应用对它的称呼，用在侧边栏、每个会话下方和文件夹菜单中，所有设备上都一样（磁盘上的文件夹名称不变）。把名称清空，文件夹就会恢复本来的名称。

你在 Hydor 之外用 Claude Code 或 Codex 开始的会话（在 VS Code、终端、Claude 桌面版或 Codex 应用中）也会列出。你用它们工作的文件夹会自动变成项目（见[在 Claude Code 和 Codex 中找到的项目](/guide/projects#projects-found-in-claude-code-and-codex)），所以它们的分组就是项目的分组，名称后面仍有 Claude Code 或 Codex 的标志（或两者）。如果一个文件夹的会话来自 Hydor 之外、但它不是项目（只有一个来自外部的会话，或被 Hydor 排除了），它会像其他文件夹一样保留它的文件夹分组。如果一个文件夹的第一个会话是在 Hydor 之外开始的，它就会显示其会话来自哪里：名称后面有 Claude Code 或 Codex 的标志，两者都有会话时两个都显示。指向名称，或打开标题的 **⋯**，即可看到它们是在哪些应用中启动的，例如**来自 Codex：VS Code, 终端**；如果它们属于你在[设置 → 智能体 → 账户](/settings?s=accounts&find=Accounts)中添加的账户，还会显示该账户的名称。之后你从 Hydor 在那里继续工作时，标志仍会保留：它表明这个文件夹的工作是从哪里开始的。

若只想像以前那样按天列出会话，可以在筛选按钮的菜单中取消勾选**按文件夹或项目分组**，或者在搜索框中找到**按文件夹或项目给会话分组**；用同样的方法可以切换回来。列表只显示一个项目时，它的会话按天列出。

已归档的会话不会列出，但搜索框（Ctrl+K）仍然能找到它们，并标有**已归档**。在你的第一个会话出现之前，这里会显示“还没有会话。”

每一行显示智能体的图标和一个状态圆点、会话标题，以及第二行文字。智能体运行时，第二行说明它在做什么（“工作中 · 2 分 10 秒”，之前已有几轮时还会写出合计工作了多久，如“工作中 · 2 分 10 秒 (47 分)”；“需要你处理”“就绪”“工作中 · 1 个在后台”“已在 VS Code 中打开”）。否则，它显示文件夹（你的主文件夹显示为“主文件夹”）、会话多久以前活跃过，以及增加和删除了多少行。以不是常用智能体的智能体开始的会话（项目里的会话，若项目有自己的智能体，常用的就是它；其他会话是 General），第二行开头会显示那个智能体的图标和名称：空闲时是“Planner · web-agent · 5天”，工作时是“Researcher · 工作中 · 2 分 10 秒”。常用的智能体、在 Hydor 之外开始的会话，以及后来被删除的智能体都不显示名称，所以大多数行看起来和以前一样：在自己的智能体是 Coder 的项目里，Coder 的会话不显示名称，但 Researcher 的会话会显示，General 的会话也会显示。在**项目**下，分组已经写明了文件夹，所以每个会话只占一行：标题，然后是会话多久以前活跃过（前面是 worktree 的分支），或者在智能体工作或需要你处理时显示它在做什么；以不是常用智能体的智能体开始的会话在那里仍保留第二行，写出它的名称（“Planner · 5天”）。标题后面可能跟着一些小标记：

- 一个强调色的圆点：自你上次查看以来它已经完成（第二行显示“已完成 · 5 分钟前”）；打开它，就会在所有设备上标为已读；
- 一个拉取请求标记，带有它的状态；
- 一个靶心：这个会话设有目标；
- 一枚图钉：它已置顶（在**已置顶**分组中没有，因为分组已经说明了）。

Custom 工作或启动时，工作指示器使用 Hydor 加载动画（Ω 中的水起伏涨落），而不是旋转的智能体图标。加载图标与旁边的文字垂直居中对齐。

状态圆点表示会话的情况：

| 圆点 | 含义 |
| --- | --- |
| 蓝色，呼吸闪烁 | 工作中：一轮对话正在进行，或有后台任务在运行 |
| 琥珀色 | 需要你处理：有批准请求、问题或表单在等待 |
| 绿色 | 就绪：智能体正在运行，等你发下一条消息 |
| 灰色 | 在 VS Code 或终端中打开，并在那里处于空闲状态 |
| 无圆点 | 已停止：智能体没有运行；你的下一条消息会让它重新启动 |

浏览器标签页会显示有多少个会话在等你，比如“(2) Hydor”。

子智能体，即智能体为完成部分工作而启动的会话（Hydor 子智能体）和它的程序在会话内部运行的子智能体（Claude Code 和 Codex 自己的），在它们工作或等你的时候折叠在它下面，带有一行类似“3 个子智能体 · 1 个需要你”的文字；点击即可查看。一个子智能体完成后就会离开侧边栏（除非你正打开着它）：它仍在对话中的子智能体卡片里，以及消息框上方的那一行里。见[子智能体](/guide/sessions#subagents)。

列表中的每个会话都有一个菜单：把指针移到该行上，点击末尾的 **⋯**，或右键点击该行（在手机上，点按它的 **⋯**）。菜单包含**重命名**、**重命名文件夹**（用于不属于项目的会话）、**移到文件夹**（见[用文件夹整理会话](#sort-sessions-into-folders)）、**置顶**（或**取消置顶**）、**延后**、**告一段落**、**归档**和**删除**（删除前会先询问）。双击标题，或选中某行后按 F2，即可重命名。这些操作都在[重命名、置顶、延后、告一段落、归档或删除](/guide/sessions#rename-pin-snooze-settle-archive-or-delete)中有说明。

### 用文件夹整理会话

文件夹由你自己掌握，用来按你的思路整理会话：“旅行”“报税”“待阅读”。它们只存在于侧边栏中：你电脑上的任何内容都不会改变，所有设备显示的文件夹都一样。不要把它们和会话在电脑上工作所用的文件夹混淆，后者在**项目**下有自己的分组。

文件夹分为两种：

- **不属于任何项目**：显示在**项目**上方的**文件夹**部分，用来存放不属于任何项目的会话。
- **属于某个项目**：显示在该项目标题下，排在项目其他会话之前，用来存放该项目的会话。

创建文件夹的方法：

- 点击**文件夹**标题上的 **+**，或点击**项目**标题上的 **+** → **新建文件夹…**。这样创建的是不属于任何项目的文件夹。
- 要在项目内创建文件夹，请在侧边栏中打开项目的 **⋯** 菜单 → **新建文件夹**。
- 打开会话的菜单（⋯ 或右键点击）→ **移到文件夹** → **新建文件夹…**：文件夹创建后，会话会直接放进去（按钮显示为 **创建并移动**）。如果会话在某个项目下，文件夹会建在该项目内。
- 列表处于分组状态时，筛选按钮的菜单（**筛选和分组会话**）中也有**新建文件夹…**。

给文件夹命名（最多 60 个字符；同一位置的两个文件夹不能重名），然后按**创建**。

要把会话放进文件夹，打开它的菜单 → **移到文件夹**，然后选择文件夹；会话当前所在的文件夹带有勾号，选 **移出文件夹** 可将它移出。也可以直接把会话拖到文件夹标题上（在手机上，先按住会话片刻把它拿起来）。一个会话最多只能在一个文件夹中，项目中的会话只能放进该项目的文件夹。

点击文件夹标题即可折叠，和其他标题一样；文件夹一开始是折叠的，并显示包含的会话数。文件夹按名称排列。双击名称，或打开它的 **⋯** → **重命名**，即可重命名文件夹。**⋯** → **删除文件夹** 会删除文件夹：其中的会话不会被删除，仍留在列表中原来的位置（文件夹里有会话时会先询问）。删除项目时，它的文件夹也以同样方式移除；会话会保留。

正在工作或已置顶的会话仍显示在**活跃**或**已置顶**下，之后会回到原来的文件夹。只有在筛选按钮的菜单中开启**按文件夹或项目分组**时，才会显示文件夹。

### 开始页

**新建会话**会打开开始页。它会问“我们来做点什么？”，说“什么都可以问：调研、文档、计划、代码。”，有一个大大的消息框，下面有一排选项：

- **运行于**：由哪个程序来做这项工作（Claude Code、Codex、Custom，或你添加的其他智能体）。
- **模型**：那个智能体的模型。
- **文件夹**：智能体工作的地方，也可以是一个项目，或者为这项任务新建的文件夹。
- **智能体**：会话以谁的身份工作（通用、研究员、撰稿人、程序员、辅导老师、规划师、分析师、应用搭建师，或你自己的智能体；见[智能体](/guide/agents)）。
- **选项**：思考强度、权限、记忆、花费上限等。凡是你设得和平常不一样的，这个按钮上都会写出来。

在电脑上，输入框下面有一行提示：“Enter 开始 · Shift+Enter 换行”。当某个智能体的套餐用量用完时，输入框上方会有一条横幅说明这一点，并告诉你何时重置。

自你上次来过之后有事发生时，消息框下面会有一行**你不在时**：完成了什么、什么在等你、什么自动运行了，以及接下来要运行什么（见[你不在时](#while-you-were-away)）。没有事发生时，它不会出现。

输入框为空时，下面会有**开始建议**：三个示例请求、你的两个应用和一个自动化任务。

- 点击一个示例，把它填进输入框。你可以随意修改，再发送：在你发送之前，什么都不会发出。写着“…”的地方，填上你自己的内容。示例每天都会更换；在有代码的文件夹里，它们都和代码有关。
- 点击一个应用，打开它的表单：你最常运行的两个应用；在你还没运行过应用时，是**深度研究报告**和**旅行规划**（见[应用](/guide/apps)）。
- 点击自动化任务（“每周一 8:00，给我发一份关于…的本周新闻简报”），把它填进输入框：补全后发送，智能体就会把它设成[定时任务](/guide/tasks)。

你一开始输入，这些建议就会收起。**隐藏**会把它们彻底收起来，在所有设备上都是如此；要让它们回来，请在“设置 → 应用 → 通用”中打开[开始建议](/settings?s=general&find=Starter%20ideas)。在手机上，它们是一行，可以左右滑动。

再往下，**今天**用一行话汇总今天的情况：“今天 · 7 个会话 · 12 次文件编辑 · $0.84”，为零的部分不显示。这笔钱是今天的 token 按 API 价格计算的费用，与“活动”页面上的 **API 费用（估算）**是同一个估算：使用套餐（Claude Code、Codex）时，你支付的是套餐费用。把鼠标移到这一行上，可以看到更改的行数、token 和提示词；点击它可以打开“活动”页面。在手机上，**最近**会在输入框下面列出你最近的六个会话。

右上角的**探索**会打开一本为你制作的杂志：关于你所做的事和你关心的事的文章和近期新闻，根据你的档案和你最近的会话挑选（见[探索](/guide/apps#explore)）。上面有一个小圆点，表示有一期你还没打开的新杂志已经准备好了。

开始页会为每个项目、每个文件夹和**新建任务文件夹**分别记住它的选择，所以一个项目可以用它自己的程序、模型和智能体打开（见[开始页会记住什么](/guide/sessions#what-the-start-page-remembers)）。开始页上的所有内容都在[开始一个会话](/guide/sessions#start-a-session)中有说明。

### 你不在时

回到应用时，你可以在一个地方看到你不在时发生了什么：就在开始页的消息框下面（开始建议的上方）。它收起时只有一行，最要紧的排在最前面，比如“1 个需要你处理 · 1 个失败 · 3 个已完成 · 接下来：07:30 晨间简报 · 自昨天 18:40 起”，为零的部分不显示。点击这一行把它展开，或者点击其中的某一部分：**需要你处理**、**失败**或**已完成**只展开这一类（**全部显示**把其余的带回来），**接下来**打开定时任务，时间则显示全部内容。在手机上，整行就是一个按钮，点一下就展开；时间显示在展开后的标题里。

展开后，它最多显示六行，最重要的在最前面（**再显示 … 个**列出其余的）：

- **需要你处理**：等你处理的批准、问题、表单、发件箱里等你确认的调用，以及其他等你的事，和[收件箱](/guide/inbox)里的一样。批准、问题、表单或等你确认的调用有**在此回答**，它会在这一行下面打开收件箱自己的卡片；点击其他行，就会去到它等你的地方。
- **完成**和**失败**：自你上次来过之后结束、而你还没打开过的会话，每个都带着它最后一条回复的开头（或者出了什么问题），以及它生成的文件。点击文件可在“文件”中打开它，点击这一行则打开会话。如果一个会话的这一轮结束时，它启动的子智能体或后台任务仍在运行，它就还没有完成：等这些结束后，它才会出现在这里。
- **自动运行的**：你的[定时任务](/guide/tasks)、你的智能体的定时运行和你的应用（从“应用”页面、链接、API 或聊天应用启动）的运行，每个都带着结果（**完成**、**失败**或**没有新内容**）和花费。点击一项可打开它运行所在的会话，或者应用的那次运行。
- **今天接下来**：今天稍后要运行的定时任务，在各行下面。

在你展开之前它一直收起，即使有事需要你也一样。展开还是收起，它都会在这台设备上保持你离开时的样子。**全部标为已看**会清空它：其中列出的内容算作已看过，其中的会话算作已打开，在所有设备上都是如此（它们在侧边栏里的圆点也会消失）。之后发生的事会再次显示。没有新内容的运行和接下来要运行的任务，单独不会让它出现。

你上次来过，指的是应用最后一次在前台打开并使用超过一分钟的结束时刻，在你的任何设备上都算：在手机上来过，在电脑上也算数。刷新页面，或者看了不到一分钟，都不会改变它；你离开电脑时一直开着的窗口也不算。打开一个会话会像以前一样把它标为已看。在你第一次来过之前，它往回看一天。另一台机器的开始页（设置 → 机器）显示那台机器的内容；装着较旧版本 Hydor 的机器则什么都不显示。

在终端里，`hydor away` 列出同样的内容，`hydor away seen` 清空它（见[终端里的 Hydor](/guide/terminal)）。

## 开始你的第一个会话

1. 确保智能体能够工作。Claude Code 和 Codex 需要你登录：打开[设置 → 智能体 → 账户](/settings?s=accounts&find=Accounts)，找到**账户**组，按智能体旁边的**登录**，然后按步骤操作（打开一个链接、批准，再粘贴或输入一个代码）。Custom 需要一个模型：在[设置 → 智能体 → 模型](/settings?s=models)中添加一个。第一次使用时，欢迎导览会陪你完成这些。见[智能体、账户和模型](/guide/agents-models)。
2. 按侧边栏顶部的**新建会话**。应用启动时打开的也是开始页。
3. 按消息框下面的**运行于**，选择程序。旁边的**模型**用来选择它的模型；标着“默认”的那个就很适合起步。
4. 按**文件夹**，选择智能体工作的地方：
   - 一个项目，在**项目**下选择，就会在那个项目的文件夹里工作，并带上它的文档和准则；
   - 你最近用过的某个文件夹，在**文件夹**下选择，或另一个文件夹：点**浏览**查看你的文件夹，或在**查找项目或文件夹，或输入路径**中输入文件夹的名称或路径；
   - **新建任务文件夹**，为你的任务新建一个以它命名的文件夹（默认在 `~/Hydor` 中，可以在[设置 → 功能 → 你的智能体](/settings?s=assistants&find=Task%20folders)中更改）。

   大多数智能体在你不选文件夹时，会从一个新的任务文件夹开始；程序员智能体则在你选的文件夹里工作。
5. 在消息框里输入你想做的事：描述一项任务或问一个问题。用回形针添加文件，或者把文件拖到输入框上。已经在这台电脑上的文件可以从“文件”页面带过来：使用文件菜单中的**用它开始会话**（见[用文件开始会话](/guide/files-git#start-a-session-with-files)）。
6. 按 Enter，或按**开始**。在手机上，轻点圆形箭头。

会话随即打开。智能体工作时，你会看到它用平常话写出的各个步骤，最后是它的回复。当它想运行某个命令或修改某个文件，而它的权限不允许它自行这样做时，会出现一张卡片，请你选择**允许**或**拒绝**。在底部的消息框中输入，就能继续对话。你在开始页上的选择会保留到下一个会话，在所有设备上都一样。

下一步：[会话](/guide/sessions)介绍了你在会话中能做的一切。

## 用 Ctrl+K 搜索一切

搜索框会在你输入时找出应用中的任何东西，就像 Mac 上的 Spotlight。在任何页面上都可以用 Ctrl+K（Mac 上是 ⌘K）打开它，只有在代码编辑器或终端里输入时除外。工具栏上的**搜索**图块（在手机上是抽屉中工具里的**搜索**）也能打开它。再按一次 Ctrl+K 或按 Esc 即可关闭。

### 它能找到什么

- **前往**：Hydor 的页面，比如新建会话、收件箱、文件、在文件中搜索、Git、实验、作业、终端、应用、新建应用、项目、共享知识、已发布、预览、用量与限额、模型竞技场、活动、系统和设置。
- **操作**：参加导览、Hydor 能做什么、免提对话、版本说明、在浅色和深色之间切换、显示或隐藏侧边栏、按文件夹或项目给会话分组、显示或隐藏终端面板。
- **设置**：设置中的每个部分以及其中的选项。打开其中一项，就会打开它所在的部分，并指向那个选项。
- **主题**：内置主题和你自己的主题。打开一个就会切换过去。
- **会话**：按标题、文件夹、分支、第一条消息和开始它的智能体查找（General 除外，因为大多数会话都是它），已归档的也在内，标有**已归档**，排在其他之后。打开一个就会打开那个会话。它的预览会列出**智能体**。
- **消息中**：包含你输入的词语的消息。打开一条，就会在那些词语处打开它所在的会话，并准备好查找栏。
- **记忆**：你的记忆笔记。打开一条，会在设置 → 记忆中定位到那条笔记。
- **项目**：你的项目，按名称和描述查找。打开一个，就会打开那个项目的详情：在**项目**区域是它自己的页面，在其他任何地方则是你所在页面上方的窗口。
- **应用**、**定时任务**、**智能体**、**技能**、**页面**、**图片、视频和音频**和**连接**：你自己的，以及现成的。每一项都会在它所在的地方打开。
- **文件**：名称相符的文件，最多五个，范围是“文件”页面显示的文件夹（或应用的默认文件夹）。
- **历史**、**书签**和**下载**：在桌面应用中，指你在自己的[浏览器](/guide/web#your-own-browser)中访问过的页面、你的书签，以及它下载的文件。它们按字词匹配；[按含义搜索](/settings?s=memory&find=Search%20by%20meaning)开启时，还按内容大意匹配，即使字词不同。点开一个页面会在**浏览器**页面的新标签页中打开它；点开一个下载会在其文件夹中显示该文件。它们只留在这台电脑上，智能体永远拿不到，搜索框也不会记住你为找到它们而输入的内容。

### 选择搜索范围

输入框末尾的**搜索范围**显示搜索框在哪里查找：在你挑选位置之前是**全部**。点击它会列出：**会话**、**消息**（会话中说过的话）、**项目**、**已保留的文件**（智能体做出、你保留下来的页面、图片、视频和声音）、**应用**、**文件**、**记忆**、**定时任务**、**智能体**、**技能**、**连接**、**设置**（包括主题）、**前往和操作**（应用自己的页面和操作）、**指南**，以及仅在桌面应用中才有的**浏览器**（你的历史、书签和下载）。

- 勾选一个或几个，搜索框就只在那里查找。按钮会用强调色写出它们（“会话, 已保留的文件”，或“3 个位置”）。再点一次某个位置可以把它去掉，点**全部**则重新在所有位置查找。
- 什么都没输入时，它会列出你挑选的位置里有什么，最常用的排在前面：你最近的会话、项目和页面，设置的各个部分，指南的各个主题。消息、记忆笔记和文件要等你输入词语。
- 你的选择会在所有设备上保留，直到你更改。什么都没找到时，提示下方的**搜索全部**会重新在所有位置查找。
- 在手机上，**搜索范围**是**取消**旁边的筛选图标（挑选位置后它会写出这些位置），它的列表从屏幕底部打开。

### 结果怎样显示

- **最佳匹配**排在最前面。然后每一类各有一组，每组最多四行；“3 条更多结果，来自会话”会显示其余的。
- 图片、视频、声音、保留的页面和文件会带着缩略图和详细信息显示：它是什么（图片、视频、文档、幻灯片、电子表格、PNG 图片……），大小或时长，它在哪里（保留的东西会写成“文件 › 项目的名称”，即在项目的文件中），以及最后一次更改的时间。页面后面还会显示它的描述。
- 在宽屏幕上，列表旁边的预览会进一步介绍你当前选中的结果，以及打开它会去到哪里。图片或页面会在那里放大显示（点击即可打开），视频或音频可以直接在那里播放。
- 在手机上，结果铺满整个屏幕，没有预览：每一行写出的信息足以区分各个结果，而且大小便于点按。
- ↑ 和 ↓ 移动，Enter 打开。Esc 清空你输入的内容，再按一次 Esc 关闭搜索框（**搜索范围**列表打开时，Esc 先关闭列表）。
- 什么都没输入时，它会列出**最近的会话**和**建议**：你最常去的地方（在它了解你之前，会先列出几个有用的地方）。在**搜索范围**中挑选了位置时，则改为列出这些位置里有什么。
- 底部那一行显示**词语**或**词语和含义**。[按含义搜索](/settings?s=memory&find=Search%20by%20meaning)开启时（除非你在设置 → 功能 → 记忆中把它关掉，否则它一直开启），结果还会匹配你用其他说法、甚至其他语言表达的意思。

### 它会学习你常用的东西

- 你选了什么，以及当时输入了什么。再次输入同样的词，那个结果会立刻排在最前面。
- 你去过的地方，无论是怎样去的：页面、设置的各个部分、会话、应用、文件。在相符的结果中，你常用的会往前排：和你输入的内容越相符，往前排得越多；随着时间推移，往前排得越少。
- 应用会替你保存这些，所以你的手机和电脑会一起学习。

## 在手机上使用应用

要从手机上访问这个应用，它需要一个 HTTPS 地址。[设置 → 应用 → 在手机上使用](/settings?s=phone)用 Tailscale 点几下就能私密地给它一个：只有你自己的设备能访问，扫一下二维码就能在手机上打开。Cloudflare 隧道或你自己的代理也可以。见[手机、其他机器和分享](/guide/devices)。

### 把它添加到主屏幕

这个应用可以像 App 一样安装，并全屏打开：

- **iPhone 或 iPad**：在 Safari 中打开它，然后点“分享”→ **添加到主屏幕**。
- **Android**：在 Chrome 中打开它，然后点 ⋮ → **添加到主屏幕**（或**安装应用**）。

在 Android 上安装后，或在电脑上用 Chrome 或 Edge 安装后，Hydor 也会出现在分享面板中：从其他应用把照片、文件或链接分享给它，开始页就会打开，内容已在消息框里。见[从其他应用分享到 Hydor](/guide/devices#share-to-hydor-from-other-apps)。

在 iPhone 或 iPad 上，通知只在添加到主屏幕的应用中有效：从主屏幕打开它，然后在设置 → 应用 → 通知中开启[通知此设备](/settings?s=notifications&find=Notify%20this%20device)。见[收件箱和通知](/guide/inbox)。

### 侧边栏是一个抽屉

- 每个页面左上角的**菜单**按钮可以打开它。它会占满整个屏幕。
- 各个工具（包括**项目**）排成网格，在抽屉底部。
- 轻点一个会话或工具，就会跳转过去并关闭抽屉。**关闭菜单**（×）也能关闭它。
- 按住一个会话片刻把它拿起来，然后拖动（给活跃或已置顶的会话重新排序，或者把某个会话置顶）。
- 按住底部的一个工具片刻把它拿起来，然后把它拖到其他工具中间的另一个位置。
- 每行末尾的 **⋯** 打开会话的菜单：**重命名**、**重命名文件夹**、**置顶**、**延后**、**告一段落**、**归档**和**删除**（删除前会先询问）。

### 菜单以底部面板打开

在手机上，开始页消息框下面的选项（运行于、模型、文件夹、智能体、选项）会以面板形式从屏幕底部弹出，不会被键盘挡住。文件夹面板里的查找框要等你轻点后才会激活，这样键盘就不会盖住列表。

### 输入和发送

- 开始页会在消息框下面以**最近**列出你最近的六个会话；**所有会话**会打开抽屉。
- Enter 用来换行。轻点圆形箭头可以开始会话或发送消息（接上键盘时，Ctrl+Enter 或 ⌘Enter 也能发送）。
- 在会话中，消息框显示一个写着模型的按钮（思考强度和权限不是平常的设置时，也会一并显示）。它会打开一个面板，里面有**模型**、**思考强度**、**权限**，以及对话的上下文容量已用了多少，还有**压缩**。
- 要引用回复或你自己消息中的一部分，就选中它：**引用**会出现在选中内容的正下方。
- **详情**只在你需要时，才会覆盖在对话上方打开。
- 搜索框会占满屏幕；**取消**可以关闭它。
- 截图按钮只在电脑上有。

## 获取帮助

导航栏上的 **帮助**（在手机上位于抽屉中）会打开本指南。窗口较宽时，它有一列与侧边栏同类的栏：徽标和 **隐藏侧边栏** 排成一行，然后是 **帮助首页** 和所有主题，按首页的分组方式排列，每个主题都有图标，当前打开的会有标记。首页随后会显示搜索框、一些大家常问的问题和 **Hydor 能做什么**（见下文）。窗口较窄或在手机上时，首页的卡片会打开各个主题，主题顶部的 **所有主题** 可以返回；在宽窗口中隐藏了这一列时，卡片也会显示在首页上。在首页的搜索框中输入一个问题或几个词：

- 输入时会显示 **匹配的章节**，点击其中一个即可打开。搜索框（Ctrl+K）也能找到它们。输入时，常见问题和 **Hydor 能做什么** 会让开。
- **按 Enter**，或点**询问**，就会有一个智能体在指南旁边的面板里回答，并附上指向相应位置的链接。它还可以替你更改设置或设置好某样东西，但要等你在卡片上确认这项更改之后。这个回答是一个普通的会话，用的是你上次在开始页面选的智能体和模型：可以在面板里接着问，也可以用面板顶部的箭头在它自己的页面里打开。

在搜索框下面，首页有 **Hydor 能做什么**，其中每张卡片对应一件人们容易错过的事：**从 ChatGPT 或 Claude 导入**、**应用**、**制作你自己的应用**、**回答卡片**、**词语建议**、**文档、幻灯片和电子表格**、**深度研究**、**自动运行的工作**、**目标**、**实验**、**在你的手机上**，以及在桌面应用中的 **自带的浏览器**。每张卡片都有一行说明它的作用以及该先做什么：可以是一条请求，比如“规划 5 月去里斯本的 4 天行程”，它会放进起始页的消息框（绝不会替你发送，你可以先修改），也可以是打开相应位置的按钮（**打开“导入”**、**制作应用**、**打开设置**、**打开“实验”**、**在手机上使用**、**打开浏览器**）。**它是怎么工作的** 会打开指南中对应的章节。该章节有自己的地址，[帮助 → Hydor 能做什么](/guide#what-hydor-can-do)，导览的最后一页和搜索框中的“Hydor 能做什么”都会打开它。

在较窄的窗口或手机上，右上角的**问智能体**会打开同一个面板；搜索框中的“向智能体询问这个应用”也一样。各个主题按组以卡片排列在框的下方；在宽窗口里则列在栏中。在某个主题里，右上角的框同样能找到章节并向智能体提问。每个主题的章节一次打开一个（**全部展开**会把它们都显示出来），主题末尾还有可以问智能体的问题：点一个，它会放进面板的输入框里，你可以先改一改，再发送。

- 欢迎导览会带你熟悉应用，并设置好你想使用的智能体。你可以用帮助顶部的 **开始导览** 启动它，也可以从设置 → App → 通用 中的 [开始导览](/settings?s=general&find=Take%20the%20tour) 启动，或者在搜索框中输入“导览”。每个人都会看到一步，介绍其他助手对你的了解。如果这台电脑上没有其他智能体的内容，这一步就是 **从 ChatGPT 或 Claude 转过来？**：它会告诉你如何向它们索取你的数据（它们通过电子邮件发给你的导出文件，是一个 .zip：在 ChatGPT 中是设置 → 数据控制 → 导出数据；在 Claude 中是设置 → 隐私 → 导出数据），而 **导入它们所了解的内容** 会在导览之上打开[导入](/guide/memory#bring-in-from-other-assistants)，把内容读入你可以挑选的备注中。如果 Hydor 在这台电脑上找到了你以前用过的其他智能体（Claude Code、Codex 或别的）的文件夹，这一步就是 **从别的智能体转过来？**：它会列出找到的内容，同样提到导出文件，而同一个按钮会把那个智能体对你的了解以及你创建的技能带过来。**下一个** 会跳过这一步继续。在展示侧边栏工具的那几步之后，是关于 **应用** 的一步，附有三条可以试试的请求，最后一页有 **看看 Hydor 能做什么**，它会结束导览，并在帮助中打开 [Hydor 能做什么](/guide#what-hydor-can-do)。在桌面应用中，当 Hydor 在这台电脑上找到其他浏览器时，后面还有一步 **导入书签和历史记录？**：它会列出每个浏览器，以及各有多少书签和多少页历史记录，每个浏览器旁边的 **导入** 会导入已开启的项目，即 **书签** 和 **历史**（见[导入书签](/guide/web#bring-in-bookmarks)和[历史记录](/guide/web#history)）；**下一个** 会不导入而继续。在 Mac 上，如果 macOS 不允许 Hydor 读取 Safari，它那一行会用 **打开系统设置** 代替 **导入**；如果你在那里允许之后 Hydor 需要重新打开，导览会回到这一步。在桌面应用中，还有一步会问 **也在手机上用吗？**：**设置好** 会在 [在手机上使用](/settings?s=phone) 处结束导览，**暂不** 则继续。在此之后，每当你第一次来到应用的某个部分，就会有提示逐个介绍其余部分（见[开始导览](/guide/app#take-the-tour)）。
- **版本说明**（在设置 → 应用 → 通用中，或从搜索框打开）介绍每个版本有哪些变化。更新之后，会显示一次“新功能”说明。
- 应用中的智能体也会读这份指南：在任何会话中问“怎么……”，它都能回答，或者直接替你去做（见[让智能体替你操作应用](/guide/ask-agents)）。

- “在我的“论文”项目里建一个叫“审阅”的文件夹，把这个会话放进去。”

- “把开始页消息框下面的开始建议隐藏起来。”
- “我不在的时候发生了什么？有什么失败了吗？”
- “把“你不在时”里的内容全部标为已看。”
- “按 API 价格，我今天的会话花了多少钱？”

- “搜索框能找到我上个月看过的那个关于里斯本酒店的页面吗？”（在桌面应用中：你的历史、书签和下载，按字词或内容大意查找；智能体看不到它们）

- “我的收件箱里有什么？”
- “把应用设置好，让我能在手机上用它。”
