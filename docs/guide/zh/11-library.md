# 资料库：页面、图片、视频和网站

智能体可以用页面代替纯文字来回答：一份报告、一张图表、一个比较各个选项的表格，或者一个小工具，比如跟踪表或清单。它们还会制作幻灯片、文档、电子表格和 LaTeX 文档，你可以像在 PowerPoint、Word、Excel 或 Overleaf 中那样编辑它们。你保留的东西都按项目放在你的资料库里，你保存的图片、视频和声音也在那里，每一个都配有为它撰写的标题和说明。本主题介绍如何观看页面的编写过程、修改它、保留它（包括它的版本、它的数据，以及供手机使用的地址），如何保存图片、视频和声音、自己制作页面、导出文件、请智能体修改你打开的内容，以及如何发布到一个链接上。

## 对话中的页面

当一张图比文字更能说明问题时，智能体会显示一个页面：一份报告、一张图表、一个表格、一张示意图、一份设计稿，或者一些可供选择的选项。应用里的任何智能体都能做到；用平常的话提出要求就行（“把这个做成图表给我看”“用表格比较这三台笔记本电脑”）。单独一张图表、示意图或图片，通常会直接放在回复里（见[回复中的数学公式、示意图、插图和图片](/guide/sessions#maths-diagrams-figures-and-pictures-in-replies)）。

在宽屏上，智能体一开始编写页面，页面就会在对话旁边打开（见[观看页面的编写过程](#watch-a-page-as-it-is-written)），对话里则为它留一张小卡片：它的标题、它是什么（“页面 · 24 KB”“已保存到资料库 · 版本 2”），以及 **打开**；正在旁边显示的那一个则显示 **在旁边**。点击一张卡片，就会在对话旁边显示它的页面。

在较窄的窗口中、在手机上，或者关闭了对话旁边的面板时，页面位于回复中，和对话一样宽，并会随内容增高。较高的页面会停在窗口一半的高度，让周围的对话仍在视野中，并在底部边缘显示 **查看整个页面**（幻灯片总是完整显示）。页面上方的横条包含：

- 页面的标题；
- **保留**：把页面放进你的资料库（见[保留页面](#keep-a-page)）；
- **编辑**（铅笔图标）：打开它进行修改（见[自己修改页面](#change-a-page-yourself)）；
- **另存为文件**（下载图标）：把页面保存为 `.html` 文件，带着它的现成外观，可以在任何浏览器中打开；
- **全屏**（展开图标）：在应用上方打开页面。按 Escape 键、轻点关闭按钮（✕）或点击页面旁边的区域即可关闭。

页面运行在它自己的框架中，与应用隔离：它无法访问应用、你的文件或你的登录信息。它可以从网上加载图表库和其他库。

页面看起来就像应用的一部分：智能体按应用的主题来做页面，应用是浅色就是浅色，是深色就是深色，用你的主题颜色（包括你自己的主题）和应用的字体；你切换主题时，打开着的页面也会跟着变。自带浅色和深色两种外观的页面，会显示应用当前的那一种，不管你的设备设成什么。想要别的外观时直接说：“用我们品牌的颜色”“做一个带霓虹强调色的深色页面”。

智能体做的幻灯片在对话中以放映的形式显示：点击幻灯片或它的箭头可以逐张浏览，点网格按钮可以查看所有幻灯片，点全屏按钮可以放映（[幻灯片](#slides)）。

如果你用只读链接分享会话，对方也能看到其中的页面，但不能保留或修改它们，他们在页面上做的选择也不会发送到任何地方（[分享只读链接](/guide/sessions#share-a-read-only-link)）。

## 观看页面的编写过程

智能体编写页面时，你会看到它一点点长出来：先是标题，然后是文字、表格和卡片，写到哪里就显示到哪里。在宽屏上（1100 像素或更宽），对于屏幕上正在显示的会话，页面会自动在对话旁边的面板中打开。面板顶部那一行显示 **正在编写**，以及目前已经写了多少；旁边的代码按钮会改为显示正在写入的页面 HTML，眼睛按钮则回到页面。在较窄的窗口中或手机上，页面会在对话里它的卡片中逐渐长出来。页面的脚本会等到页面完整之后才运行。

智能体完整写出一个 HTML 文件时（比如静态网站的 `index.html`），面板也会打开它，并从文件所在的文件夹加载它的图片和样式。

- 拖动面板的左边缘可以让它变宽或变窄；应用会在这台设备上记住这个宽度。
- 一个对话中有多个页面时，点击面板中的页面标题，可以切换到另一个页面。
- 面板中的 **更多**（⋯）包含 **在资料库中打开**（已保存的页面）、**在“文件”中显示**（HTML 文件）、**另存为文件**（对于已保存的页面或幻灯片，则是 **下载为** PDF、Word 文档、PowerPoint 文件或网页），以及 **页面一开始编写就在这里打开**：关闭它后，页面会等你从它们的卡片中打开。
- 幻灯片会在面板里的幻灯片编辑器中打开（[编辑幻灯片](#edit-slides)）。
- ✕ 关闭面板。会话标题栏中的 **详情** 会在同一位置打开会话的详情。

## 自己修改页面

智能体显示或保存的任何页面、你库中的任何页面，以及智能体写出的任何 HTML 文件，都可以用三种方式修改。用页面顶部的按钮选择一种（在对话旁边的面板中，它们是图标：眼睛、铅笔和代码符号）：

- **使用**：页面本身，可以正常使用：在它的输入框中输入、勾选它的方框、选择它的选项。
- **编辑**：直接在页面上点击来修改它。修改期间，页面的脚本会暂停运行，所以页面保持不动。
- **代码**：它的 HTML，旁边是页面（在较窄的面板中则在下方），你输入后片刻就会显示你的更改。

在它们旁边，屏幕按钮可以按 **电脑**、**平板** 或 **手机** 的尺寸显示页面（在面板中和较窄的窗口里是一个带菜单的按钮）。页面打开时有多宽的项目就显示多宽；选了平板或手机的宽度后，在页面关闭前会一直保持。在 **编辑** 中，选着平板或手机时做的修改只用于那种尺寸的屏幕（[为手机和平板修改](#change-it-for-phones-and-tablets)）。

### 点击编辑

1. 点击页面的某个部分：一个标题、一个段落、一张图片、一张卡片、一个表格。它会出现一个带有名称的边框（“标题 2”“图片”“卡片”），旁边还有一个小工具条。
2. 再点一次（或者双击）就可以就地修改它的文字。文字上方的工具条有 **粗体**、**斜体**、**下划线**、**删除线**、**设为链接**（Ctrl+K）、**取消链接**、**清除格式** 和 **完成**。在段落里按 Enter 会另起一行，在标题里按 Enter 会结束编辑；按 Esc 结束编辑。
3. 选中部分旁边的工具条：拖动手柄（⠿）可以把这个部分移到页面的其他位置；**选择外层部分**（按 Esc 也一样）；**修改文字**；**上移** 和 **下移**；**创建副本**（Ctrl+D）；**删除**（Delete 键）。拖动它右边、下边和右下角的小手柄，可以把它拉宽或拉高。

按键和其他编辑器一样：Ctrl+C、Ctrl+X 和 Ctrl+V 可以复制、剪切和粘贴选中的部分（在应用打开期间，也能粘贴到另一个页面里）；Ctrl+G 把它包进一个块里，Ctrl+Shift+G 取出里面的内容；方向键选中上面、下面、外层或里面的部分；Alt+↑ 和 Alt+↓ 移动它。

在手机上，点一下某个部分就能选中它，再点一下就能修改它的文字。页面下方的标签（**部分**、**图层**、**网页**）会打开一个抽屉，里面是可以修改的内容；箭头可以收起它，你输入文字时它也会自动收起。

**添加** 会把一个新部分放在选中的部分之后、它里面，或者页面末尾（用 **放在** 选择位置）：**基础**（标题、文本、按钮、链接、图片、列表、引用、分隔线、一段空白）、**布局**（区块、两栏或三栏、卡片、一组卡片、表格、数字、折叠区、输入框）以及 **现成区块**（开场介绍、功能特点、价格、步骤、常见问题、用户评价、行动号召、联系表单、页脚）。在合适的地方，它的文字可以直接输入。

**撤销**（Ctrl+Z）和 **重做**（Ctrl+Shift+Z）可以一步步撤回或重做你的更改。

### 部分、图层和网页

页面旁边（在较窄的面板中或在手机上则在页面下方）有三个标签，显示你可以修改的内容。

**部分** 是选中的部分，上方是它外层的各个部分（点击其中一个即可选中它）。最上面是：**问智能体**（在对话中：它会在你的消息框里写下你指的是哪个部分，你只需说要改什么；还没保存的修改会先保存，好让智能体看到）、**复制**、**粘贴**，以及 **更多**（⋯），里面有 **剪切**、**粘贴到它里面**、**包进一个块里**、**取出里面的内容**、**创建副本**、**在页面里找到它** 和 **删除**。下面选择修改用于哪些部分：**仅这个部分**、所有同类的部分（“所有标题 2”），或者所有带它某个 class 的部分（“所有 .card”）；还有 **正常** 或 **悬停**，即鼠标指针停在上面时的样子（你修改时页面会显示这个样子）。然后是它的几组设置，可以收起：

- **内容**：它的文字；对于标题或文本，它的 **类型**（H1、H2、H3、文本、引用）；对于链接，它 **链接到** 哪里，以及是否在 **新标签页** 中打开；对于图片，它的地址或 **来自这台设备的图片**（会缩小到足以放进页面里），以及它的 **描述**。
- **文本**：**字体**、大小和粗细、**行距和字距**（行的高度、字母之间的距离）、**颜色**、**对齐** 和 **样式**（斜体、下划线、删除线、大写）。
- **填充和边框**：**填充**、放在后面的 **图片**、**透明度**、**圆角**、**边框** 和 **阴影**。
- **空间**：边框 **外** 和边框 **内** 的空间，按这个部分本身的样子并排显示。输入数字，或者上下拖动数字。
- **大小**：它的 **宽度** 和最多能有多宽，它的 **高度** 和至少要有多高，以及图片如何 **适配** 它的尺寸。
- **布局**：里面的部分如何 **显示**（上下排列、并排、竖向排列、网格排列，或者隐藏），它们怎么对齐和分布、彼此的间距，以及它的 **位置**：默认位置、从原位置偏移、相对所在的块、固定在屏幕上，或者在页面滚动时固定。
- **类名、名称和 CSS**：它的 class、它的 id，以及给它设置的 CSS。

某项设置有内容时，它的名称会变成金色；旁边的 ✕ 可以清除它。左右拖动数字前面的字母可以修改数字，也可以用方向键（按住 Shift 则每次改 10）。色块是页面自己的颜色；彩虹色的那个可以选择任何其他颜色。

**图层** 把页面的各个部分显示成一棵树，按它们互相包含的样子排列。指向其中一个，就能在页面里看到它；点击它就能选中它，即使它太小或被挡住，在页面里点不到。

**网页** 是整个页面：

- **页面**：它的 **标题**（浏览器标签页上的名称）、**背景**、**宽度**（在大屏幕上居中显示的内容有多宽：**全宽**、**宽**、**中等** 或 **窄**）、**内部留白** 和 **语言**。
- **颜色**：页面自己命名的颜色（它的 CSS 变量；用应用自带外观做的页面，有 **背景**、**卡片**、**文本**、**强调色** 等）。它们一开始就是你主题的颜色。改一个，用到它的地方都会一起变，而且在任何主题下都保持这样。
- **字体**：它的 **文本** 和 **标题** 用的字体：设备自带的字体，或者 Google 的字体，页面会自动加载。
- **文字样式**：**文本**、**标题 1** 到 **标题 3**、**链接** 和 **按钮** 在整个页面里的样子。你单独改过的部分会保留它自己的修改。
- **你的 CSS**：你为整个页面写的规则，会原样保存在页面里。

### 为手机和平板修改

在顶部选 **平板** 或 **手机**，页面就会按那个宽度显示，上方的工具条会出现 **平板专用** 或 **手机专用**。这时做的修改只用于那么宽或更窄的屏幕（平板 900 像素，手机 600 像素），页面在电脑上的样子不变：比如手机上的标题小一点、两栏在手机上变成上下排列、某个部分在手机上隐藏（**布局** → **显示** → **隐藏**）。再选 **电脑**，修改就又用于所有屏幕。

悬停时的样子、某种屏幕尺寸的修改，以及对所有同类部分的修改，会放进编辑器保存在页面里的样式表；对单个部分本身的修改则放在它自己的样式里。无论哪种，都是你保存的页面的一部分，以后修改这个页面的智能体也能看到。

### 保存或放弃

一旦你改了什么，底部就会出现一个横条，显示 **尚未保存**，以及 **放弃** 和 **保存**（Ctrl+S，在页面里面按也可以）。在 **使用**、**编辑** 和 **代码** 之间切换不会丢失你的更改。

- 已保存的页面（在你的库中）会得到一个新版本：智能体的版本都会保留，你可以回到其中任何一个（[回到早先的版本](#go-back-to-an-earlier-version)）。如果在你修改期间页面又被保存了一次（比如被某个智能体保存），应用会先问你，再把你的版本放在最上面；另一个版本会留在版本列表中。
- 对话中显示、还没有保留的页面，按钮会显示 **连同更改一起保留**：它会被放进资料库，智能体的页面作为版本 1，你的作为版本 2。
- HTML 文件会保存在原处。如果在你打开它之后它在磁盘上被改过，应用会告诉你，而不会覆盖它。

### 智能体会知道你的更改

显示这个页面的智能体（对于已保存的页面，还有创建它的那个会话的智能体）会在你下次给它发消息时知道你的更改：哪个页面、它的版本，以及你改了什么，这样它会在你的版本上继续，而不是用它自己的版本覆盖你的。对话中会显示一条提示：“你修改了‘旅行计划’（版本 3） · 智能体会在你发下一条消息时看到”，消息发出后，它会变成“智能体已看到”。点击这条提示可以再次打开页面。

## 在页面上选择选项或填写表单

有些页面会问你一些问题：三个方案中你更喜欢哪一个、旅行的日期、要保留哪些物品。你的回答会进入消息框，而不会直接发给智能体：

- **点击一个选项**，消息框中就会出现一行，比如 `Chose: B` 或 `Color: Blue`。如果页面允许多选，它们会一起放进去（`Color: Blue, Green`）。在同一组中选择另一个选项，它的那一行会替换第一行；不会越积越多。
- **填写表单并提交**，它的回答会以一个简短的列表放进去，标题是表单的名称，每个字段一行。

在消息中添加你想说的任何内容，然后像平常一样发送。智能体会把你的选择当作你消息的一部分来读。

页面全屏显示时，你的选择会先等着，在你关闭全屏时放进消息框（消息框在页面下方）。

## 保留页面

对话中显示的页面与对话共存。要以后再回来用它，就保留它：

1. 点击页面上方横条中的 **保留**。如果你有项目，会弹出一个小菜单问它放在哪里（**保留到**）：本会话所在的项目排在最前，标着 **本会话所在的**，然后是你的其他项目，以及 **不放在项目中**。
2. 提示“已保存到资料库”表示成功（放进项目时显示“已保存到资料库，放在 Thesis 中”）。按钮现在显示为 **已保留**；点击它可以在资料库中打开这个页面。

修改一个显示中的页面并保存，也会保留它（**连同更改一起保留**，见[保存或放弃](#save-or-discard)）。

页面还在对话中时你在上面输入的内容会随它一起保留。保留之前，页面只在显示在屏幕上时记住你输入的内容；一旦保留，它就会永久保存它的数据（见[页面保存的数据](#the-data-a-page-keeps)）。

你也可以一开始就请智能体做一个要保留的东西：“给我做一个能在手机上用的习惯打卡表”“一份搬家清单”。智能体会自己把它保存到资料库中（会话属于某个项目时，就放在那个项目里），对话中会显示一张卡片，上面有：

- 页面的标题和 **已保存到资料库 · 版本 2**（这条回复保存的版本：智能体在一条回复中多次保存同一个页面时，回复里只有一张卡片，显示最后保存的版本，较早的几次保存列在它的步骤中）；
- **打开**（在资料库中打开它）、**编辑**（铅笔图标）和 **全屏**；
- 页面本身，可以直接使用，带有它的数据，就在卡片中。

在宽屏上，当页面显示在对话旁边时，卡片会保持小尺寸，它的页面则在旁边打开。

之后（在后面的回复中，或由你自己）保存了更新的版本时，较早的卡片只保留标题这一行，并显示 **已有更新的版本**：**打开** 会显示最新版本。智能体在同一条回复中再次保存页面时，它的卡片会继续显示之前的版本，并显示 **正在保存新版本…**。如果页面被删除了，卡片也会说明。

智能体也可以修改你保留的页面：说“给我的习惯打卡表加一列备注”，智能体就会保存它的一个新版本。你的数据会保留，较早的版本也保持原样。

## 找到你的页面

侧边栏中的 **资料库**（[/library](/library)）存放着你保留、制作和发布的所有内容。在手机上，先用 **菜单**（≡）打开侧边栏。你也可以在搜索框（Ctrl+K，Mac 上为 ⌘K）中按文字查找页面、图片或视频。

卡片旁边是资料库的各个位置，每个都显示它有多少项内容（在较窄的窗口或手机上，是卡片上方的一排标签）：

- **所有内容**：你保留的一切。有项目时，每个项目的东西会放在它的名称下面，最近改动的项目排在前面，每个都带有 **查看全部**，用来只显示那个项目；然后是 **不在任何项目中** 的内容。
- 你的 **项目**，每个都显示它的标志和名称：智能体在它的会话中保存的东西，以及你放进去的东西（见[按项目整理](#sort-it-by-project)）。名称旁边的 **打开项目** 会转到这个项目自己的页面。
- **不在任何项目中**：不属于任何项目的内容（有了项目之后才会出现）。
- **已发布**：你发布的页面和文件夹，以及它们的链接（见[查看和取消发布你发布的内容](#see-and-unpublish-what-you-published)）。[打开“已发布”](/library?tab=published)。

还没有项目时，位置下方会有一段说明，讲项目能为资料库做什么，并提供前往 **项目** 的入口。

每一项都是一张卡片，上面有它的图片（页面是打开时的样子，带着它的数据；幻灯片显示它的第一张；文档、电子表格或 LaTeX 显示第一页或第一个工作表的顶部；图片或视频显示一张缩略图；在图片生成之前，显示它的首字母）、图片上标着它的类型（**幻灯片**、**文档**、**电子表格**、**LaTeX** 或 **图片**；视频显示它的时长）、它的标题和上次更改的时间；已发布的会显示一个地球图标，保存了数据的会显示一个圆柱图标。在“所有内容”中搜索时，每张卡片还会标出它所在的项目。点击卡片即可打开它。卡片的 **更多**（⋯）中有 **编辑**（幻灯片则是 **放映**）、**重命名**、**移到项目**、**创建副本**（不带数据的副本）、**下载为**（见[导出为文件](#export-to-a-file)）和 **删除**；图片或视频的则有 **用它开始会话**、**移到项目**、**下载**、**重新撰写标题和说明** 和 **删除**。

卡片上方：

- **按名称查找** 按标题（以及图片的说明）筛选它们。
- 旁边的按钮可以按 **最近更改**、**名称** 或 **最新创建** 排序。应用会在这台设备上记住排序方式。
- 一个位置里有不止一种内容时，**全部**、**页面**、**幻灯片**、**文档**、**电子表格**、**LaTeX**、**图片** 和 **视频** 可以一次只显示一种。[只显示图片](/library?kind=image)。

还没有保留任何内容时，资料库会显示“你的资料库是空的”，以及 **新建页面** 和 **新建幻灯片**。

## 按项目整理

资料库中的每样东西都属于一个项目，或者不属于任何项目（见[项目和知识库](/guide/spaces)）：

- 智能体保存的东西（页面、幻灯片、文档、电子表格、LaTeX 文档），在会话属于某个项目时，会放进那个项目。
- 你自己保留的东西（页面上的 **保留**、图片、视频或声音下方的 **保存到资料库**），在你有项目时会先问放在哪里，本会话所在的项目排在最前；没有项目时，会直接保留。
- 资料库右上角的 **新增** 会把新东西放进你正在看的项目；也可以在 **放在项目中** 下面选别的项目（见[制作页面](#make-a-page)）。
- 要移动某样东西，在它的卡片上或它自己的页面上打开 **更多**（⋯）→ **移到项目**，然后选一个项目或 **不放在项目中**。提示“已移到 Thesis”表示完成。移动不会改变别的：它的版本、数据和地址都保持不变。

项目自己的页面也会在 **概览** 和 **资料库** 标签页中显示它在资料库中的东西（见[项目自己的页面](/guide/spaces#a-projects-own-page)）。删除项目时，它在资料库中的东西会保留下来，不再属于任何项目。

## 资料库中的图片和视频

智能体为你生成的图片、视频和声音放在会话的文件夹里（见[请智能体生成图片或修改图片](/guide/documents-voice#ask-for-a-picture-or-have-one-changed)、[请智能体生成视频](/guide/documents-voice#ask-for-a-video)和[请智能体生成音乐、语音或声音](/guide/documents-voice#ask-for-music-a-voice-or-a-sound)）。要保留其中一个，就点击对话中它下方的 **保存到资料库**（有项目时，先选它放进哪个项目）：一份副本会放进你的资料库，即使会话的文件夹被清理了，它也会留在那里；模型会为它撰写标题和说明（见[标题和说明](#titles-and-descriptions)）。之后按钮会显示 **已在你的资料库中**，点击它就会在资料库中打开它。

它们和资料库中的其他东西显示在一起；卡片上方的 **图片**、**视频** 和 **音频** 可以分别只显示其中一种（[只显示视频](/library?kind=video)，[只显示音频](/library?kind=audio)）。每个都是一张卡片，上面有它的缩略图和标题（正在撰写时显示“正在撰写标题…”）；视频的卡片会在缩略图上显示它的时长；声音的卡片会显示它的波形，旁边有一个圆形按钮可以直接在这里播放，以及它的时长。点击卡片即可打开它（见[打开图片、视频或声音](#open-an-image-a-video-or-a-sound)）。卡片的 **更多**（⋯）中有 **用它开始会话**、**移到项目**、**下载**、**重新撰写标题和说明** 和 **删除**；删除会把它从你的资料库中移除（当初保存它的那个文件如果还在，会保留下来）。

资料库可以保存图片（PNG、JPEG、WebP、GIF、AVIF）、视频（MP4、WebM、MOV）和声音（MP3、WAV、M4A、AAC、OGG、OPUS、FLAC），每个最大 1 GB，总共最多 5000 个，存放在应用的数据文件夹中。智能体可以使用你保存的东西：说“用我资料库里那张小船的图片做一张生日贺卡”，智能体就会去那里找到它。

## 标题和说明

你保存的每张图片或每段视频都会得到标题和说明，由一个能看图片的模型撰写：它会看这张图片；如果是视频，就看从开头到结尾均匀取出、拼在一张图上的十帧画面，并把生成它时所用的文字作为提示。声音它听不到：声音的标题和说明根据生成它所用的内容来写（它的描述、歌词或台本，以及生成它的模型），声音本身不会发给模型。标题和说明用应用的语言撰写。

在 **[设置 → 功能 → 图片、视频和音频 → 资料库中的标题和说明](/settings?s=images&find=Captions%20in%20the%20Library)** 中选择模型：

- **运行位置**：**自动**（有 OpenRouter 密钥时，用 OpenRouter 上的一个便宜模型，首选 Google 的 Gemini Flash Lite；否则通过你的 Claude Code 登录使用 Claude Haiku）、**OpenRouter**（它目录中任何能看图片的模型：**选择模型** 会打开列表供你搜索）、**Claude**（**Claude Haiku**、**Claude Sonnet** 或 **Claude Opus**，通过你的 Claude Code 登录使用）、**Ollama** 或 **vLLM**（这台电脑上能看图片的模型，来自[设置 → 模型](/settings?s=models)），或者 **你的端点**（兼容 OpenAI 的端点上的模型；无法知道它能不能看图片，所以会显示“可能看不了图片”）。
- **模型**：对于 Claude、Ollama、vLLM 和你的端点，选择要用的模型。
- 它们下方会显示“撰写者：”和正在使用的模型，或者说明为什么现在没有模型能撰写它们。

通过 OpenRouter 撰写它们，花费不到一美分；用这台电脑上的模型则不花钱。截取视频的帧需要应用所在的电脑上装有 ffmpeg；没有它时，这一部分会说明，视频的标题和说明会取自生成它们时所用的文字，显示时也没有缩略图。ffmpeg 还会读出声音的时长和波形；没有它时，声音的卡片上会显示一个图标。

没有模型能撰写时，它们会取自生成这张图片、这段视频或这段声音时所用的文字（或者它的文件名），它的页面上会说明这一点，并提供 **重试** 和 **选择模型**。你也可以自己写：在它的页面上使用 **编辑标题和说明**。你写的内容会一直保留，直到你选择 **重新撰写**。

## 打开图片、视频或声音

图片、视频或声音会在资料库中它自己的位置打开。顶部的横条包含返回箭头（**资料库中的图片**、**资料库中的视频** 或 **资料库中的音频**）、它的标题（下方是“一张图片”“一段视频”或“音频”及其时长）、**用它开始会话**（打开开始页，它已在消息框中，新会话会随你的第一条消息收到它：写下你想用它做什么，比如“用这张图做一张海报”，然后发送）、**下载** 和 **更多**（⋯）：**编辑标题和说明**、**重新撰写**、**打开它的会话**（保存它时所在的对话）、**移到项目**（旁边显示它所在的项目）和 **删除**。

下面是图片（点击可查看原始大小），或者可以播放的视频或声音（声音在一个大播放器里，它的波形就是进度条，旁边是时间和语速），旁边（在手机上则在下方）是：

- 它的标题和说明，带一个用来修改它们的铅笔图标，以及撰写它们的模型；
- **所用模型**（生成它的模型）、**生成依据**（它是根据什么文字生成的）、它的 **大小**、**长度**（视频、声音）、**文件** 大小，以及 **已保留** 的时间；
- 对于视频，还有 **撰写说明时依据的帧画面**：模型看过的那十帧画面（点击可查看原始大小）；
- 对于声音，还有 **演唱或朗读的内容**：歌曲的歌词，或者朗读出来的文字。

## 制作页面

资料库右上角的 **新增**（或者[搜索框中的 **新建页面**](/library?new=1)）可以制作一个你自己的页面。先在顶部选择要做什么：**页面**、**幻灯片**（见[制作幻灯片](#make-slides)）、**文档**、**电子表格** 或 **LaTeX**（见[文档](#documents)、[电子表格](#spreadsheets)和 [LaTeX 文档](#latex-documents)）。如果是页面：

1. 选择从哪里开始：**空白页**（一个标题和几句话，可以在此基础上继续完善）、**备注**（一个用来写东西的页面，边写边保存）、**清单**（要做的事，做完一件勾掉一件）或 **跟踪表**（每天一个数字，并画出最近 30 天的数据）。
2. 如果愿意，可以修改 **名称**。有项目时，旁边的 **放在项目中** 会说明它放在哪里（你正在看的项目，或 **不放在项目中**），点击它可以换一个。然后点击 **创建**。空白页会在 **编辑** 中打开；其他的打开后就可以直接使用。

文档、电子表格或 LaTeX 文档一开始只有名称，内容是空的（LaTeX 文档则带有一篇简短的文章，供你在此基础上写），也可以从你自己的文件开始：**打开 Word 或文本文件**（.docx、.md、.txt 或 .html）、**打开 Excel 或 CSV 文件**（.xlsx、.ods、.csv 或 .tsv）或 **打开 .tex 或 .zip 文件**（一个 LaTeX 文件，或者打包成 .zip 的整个项目）。文件会变成一个对应类型的页面；文件本身保持原样。要修改文件本身，请在“文件”中打开它：它会在同一个编辑器中打开，并保存回这个文件（见[编辑 Word、Excel、CSV 和 LaTeX 文件](/guide/files-git#edit-word-excel-csv-and-latex-files)）。

或者在 **或者描述一下，让智能体来做** 下面描述你想要的东西（“一周徒步的行李清单”“两个人的月度预算”），然后点击 **询问**：开始页会带着你的话打开，由智能体来制作它并保存到你的资料库中（在 **放在项目中** 选了项目时，开始页也会选好那个项目，让它放进那里）。

## 打开页面

页面会在应用内全屏打开，在资料库中有它自己的位置。顶部的横条包含：

- 返回箭头（**资料库**），回到列表；
- 页面的标题，下方是它的版本、上次更改的时间和它保存了多少数据。点击标题可以重命名页面；
- **使用**、**编辑** 和 **代码**，以及 **电脑**、**平板** 和 **手机** 尺寸（见[自己修改页面](#change-a-page-yourself)）；
- **版本**（时钟图标）：它较早的版本（见[回到早先的版本](#go-back-to-an-earlier-version)）；
- **导出**：把页面导出为 PDF、Word 文档或网页（见[导出为文件](#export-to-a-file)）；
- **分享**：供你的手机使用的独立地址，以及把它发布到一个链接（见[在手机上使用页面](#use-a-page-on-your-phone)和[发布页面](#publish-a-page)）；
- **询问**：智能体在你眼前修改这个页面（见[请智能体来修改](#change-it-by-asking-an-agent)）；
- **更多**（⋯）：**它保存的内容**（见[页面保存的数据](#the-data-a-page-keeps)）、**重命名**、**创建副本**、**移到项目**（有项目时出现；旁边显示它所在的项目）、**在新标签页中打开**（在它的独立地址打开页面）和 **删除**。

在手机上，**使用**、**编辑** 和 **代码** 显示为图标，**分享** 显示为分享图标，**询问** 显示为闪光图标，**导出** 则在 **更多**（⋯）中，名为 **下载为**，尺寸按钮不显示（手机本身就是那个尺寸）。

幻灯片、文档、电子表格和 LaTeX 文档则会在各自的编辑器中打开，顶部是同样的横条（见[编辑幻灯片](#edit-slides)、[文档](#documents)、[电子表格](#spreadsheets)和 [LaTeX 文档](#latex-documents)）。

用应用现成的外观做的页面会跟随应用的浅色或深色主题。

## 导出为文件

打开的页面、幻灯片、文档、电子表格或 LaTeX 文档顶部的 **导出**（在手机上是 **更多**（⋯）→ **下载为**），或者列表中卡片的 **更多**（⋯）里的 **下载为**，会把它保存为文件，放进你的下载文件夹：

- 页面：**PDF**（就是它显示的样子，用 A4 纸，在通常用 Letter 的地方则用 Letter，带着它的数据和背景）、**Word 文档（.docx）**（它的标题、段落、列表、表格和链接都变成 Word 自己的格式，图表和图片作为图片，输入框里的值作为文字）或 **网页（.html）**（任何浏览器都能打开的文件，带着它的现成外观）；
- 幻灯片：**PowerPoint（.pptx）**（每张幻灯片上的文本框、形状、图片、表格和图表都仍然可以编辑，带着主题的颜色和字体、演讲者备注、切换效果和动画，可以直接用 PowerPoint、Keynote 或 Google Slides 打开）、**PDF**（每页一张幻灯片）或 **网页（.html）**（把整个放映装进一个文件，可以在任何浏览器中放映）；
- 文档：**Word 文档（.docx）**（它的样式、列表、表格、图片和链接都变成 Word 自己的格式，可以用 Word、Google Docs 或 LibreOffice 打开）、**PDF**（用它自己的纸张大小和页边距，保留它的分页）、**Markdown（.md）**（它的文字、标题、列表、表格和链接，以纯文本形式）或 **网页（.html）**；
- 电子表格：**Excel（.xlsx）**（每个工作表，带着它的公式、格式、列宽和冻结的行，可以用 Excel、Google Sheets 或 LibreOffice 打开）、**CSV（.csv）**（第一个工作表中显示的值）或 **PDF**（每个工作表一张表格）；
- LaTeX 文档：**PDF**（由 LaTeX 排版，和预览中显示的一样）、**LaTeX 源文件（.tex）**（主文件）或 **LaTeX 项目（.zip）**（所有文件和图片，可以拿到别处排版，比如 Overleaf）。

正在查看的旧版本会按它本身的样子导出。页面的 PDF 和 Word 文件，以及幻灯片、文档和电子表格的 PDF，都由应用用来截图的那个浏览器生成；如果没有这个浏览器，应用会告诉你，可以在 **设置 → 浏览器** 中下载一个（[浏览器设置](/settings?s=browser)）。这时幻灯片仍然可以从你自己的浏览器打印成 PDF：在它的打印窗口中选择 **另存为 PDF**。LaTeX 文档的 PDF 由应用所在电脑上的 LaTeX 生成（见 [LaTeX 文档](#latex-documents)）。

智能体也可以导出：说“把这套幻灯片作为 PowerPoint 文件发给我”“把报告页面做成 PDF”或“把预算做成 Excel 文件给我”，智能体就会在对话中把文件交给你。

## 幻灯片

幻灯片也保存在资料库中，有自己的版本、列表中的图片和独立的地址。你可以像在 PowerPoint 或 Google Slides 中那样编辑它们，全屏放映或用演示者视图放映，并把它们保存为 PowerPoint 或 PDF 文件。

### 制作幻灯片

- **问智能体**：“给我做 8 张讲我们第一年的幻灯片，加一张销售额图表”“把这份报告改成一个带演讲者备注的简短演讲”。智能体会在资料库中做好这套幻灯片，并在对话中以放映的形式显示它。
- 在资料库中点 **新建页面**，然后在顶部选 **幻灯片**（[也可以从搜索框用“新建幻灯片”](/library?new=slides)）：选一种外观（**日光**、**午夜**、**余烬**、**森林**、**海洋**、**暗黑**、**繁花** 或 **石板**）、**宽屏（16:9）** 或 **标准（4:3）**、一个名称，然后点 **创建**。也可以在 **或者描述一下，让智能体来做** 下面描述这场演讲。

### 编辑幻灯片

幻灯片编辑器的左边是幻灯片列表（在手机上或较窄的窗口中，则横排在幻灯片下方），中间是正在编辑的幻灯片，上方是工具栏，右边是侧边面板（在手机上是幻灯片下方的抽屉），幻灯片下方是 **演讲者备注**。

- **幻灯片列表**：点击一张来编辑它；拖动一张可以调整它的顺序；它的 **更多**（⋯，或者右键点击）中有 **在后面添加新幻灯片**、**创建副本**、**放映时跳过它**（跳过的幻灯片会变暗，并显示一只划掉的眼睛）和 **删除**。列表下方的 **添加幻灯片** 会在末尾加一张。
- **工具栏**：**撤销** 和 **重做**；**新幻灯片**，从一种版式开始（**标题**、**标题和文本**、**两栏**、**区块**、**文本和图片**、**图片**、**大数字**、**卡片**、**步骤**、**引用**、**图表**、**表格**、**仅标题**、**结束页** 或 **空白**）；然后是 **文本框**、**形状**（二十种，从矩形到箭头、星形和对话气泡）、**图片**（**来自这台设备** 或 **来自网址**）、**线条或箭头**、**表格** 和 **图表**。选中文字时，还有字体、字号、**粗体**、**斜体**、**下划线**、**删除线**、颜色、对齐、**项目符号列表**、**编号列表**、缩进和 **链接**。
- **选中**：点击一个部分就能选中它；按住 Shift 点击可以再加选一个，在幻灯片上拖过则会选中碰到的所有部分。拖动一个部分可以移动它：它会吸附到幻灯片的中线和边缘以及其他部分，并显示粉色参考线（按住 Alt 可以自由移动，按住 Shift 可以保持水平或垂直）。拖动它的手柄可以调整大小（图片会保持比例；按住 Shift 时任何部分都保持比例），拖动它上方的圆形手柄可以旋转它（按住 Shift：每次 15°）。线条的两端各有一个手柄。
- **修改文字**：双击文字（或者选中这个部分后按 Enter）。Tab 和 Shift+Tab 可以把一个要点降一级或升一级；按 Esc 或点击别处即可结束。双击图片可以换一张，双击表格的单元格可以在里面输入（Enter 往下走，Tab 跳到下一个单元格），双击图表可以修改它的数字。
- **按键**：Ctrl+C、Ctrl+X、Ctrl+V 和 Ctrl+D 可以复制、剪切、粘贴部分和创建部分的副本（在应用打开期间，也能粘贴到另一套幻灯片里）；Delete 删除它们；方向键可以微移它们（按住 Shift 则每次移 10）；Ctrl+A 全选；Ctrl+M 添加一张幻灯片；没有选中任何部分时，方向键会转到下一张或上一张幻灯片。粘贴或拖放到幻灯片上的图片会成为它的一个部分。右键点击某个部分或幻灯片，也有这些操作，还有 **就此问智能体**。
- **所有幻灯片**（**放映** 旁边的网格按钮）会一次显示所有幻灯片，你可以拖动它们调整顺序；点击一张即可编辑它。

和页面一样，更改在你点击底部横条中的 **保存**（Ctrl+S）之前都不会保存；**放弃** 会丢掉它们。每次保存都是一个版本。

### 格式、动画、幻灯片和主题

侧边面板有四个标签页：

- **格式**：选中的部分。它的名称、**锁定位置**、**删除** 和 **就此问智能体**；对于文字，有它们的 **字体**、**大小**、颜色、在 **上下位置** 中的位置、**行距**（以及段后间距）、**内** 的留白，以及 **放不下时缩小文字**；它的 **填充**（一种颜色、无，或者渐变到另一种颜色）、**边框**（颜色、宽度、虚线、圆角）和 **阴影**；形状的种类；图片的 **适配**（**填充**、**完整** 或 **拉伸**）、圆角、翻转、边框和描述；线条的颜色、宽度、样式，以及它的 **起点** 和 **终点**（箭头或圆点）；表格的行、列、标题行、隔行底色和颜色；图表的 **类型**（柱形图、条形图、折线图、面积图、饼图或环形图）、标题、图例、数值、堆积、网格线，以及它的 **数据**：每个标签一行，每个系列一列。然后是 **位置和大小**（以幻灯片的像素计，横向 1280）、旋转和透明度、**在幻灯片上**（靠某条边或居中）和前后顺序，以及 **链接**（一个地址，或者用 #3 表示第 3 张幻灯片）。选中多个部分时：可以对齐排列、均匀分布，或者删除它们。
- **动画**：选中一个部分，然后在 **进入**（**出现**、**淡化**、**飞行**、**浮动**、**缩放**、**擦除**、**弹跳**）、**强调**（**脉冲**、**旋转**、**放大**、**抖动**）或 **退出** 下选一种效果。**动画顺序** 列出这张幻灯片上的动画，以及每个动画在第几次点击时开始；展开一个就可以修改它的效果、它从哪一侧进入（**从**）或向哪一侧退出（**到**）、何时 **开始**（**单击时**、**与上一个同时** 或 **在上一个之后**）、持续多久、开始前等多久，对于文字还有 **逐段**。箭头可以把它提前或推后；**播放** 会按放映时的样子播放这张幻灯片。
- **幻灯片**：它的 **背景**（主题的背景、一种颜色、渐变到另一种颜色的颜色，或者 **添加图片**，可以在文字后面调暗），以及 **应用到所有幻灯片**；它出现时的 **切换效果**（**淡化**、**推入**、**擦除**、**覆盖**、**缩放** 或 **分割**，从哪一侧开始、持续多久），在 **换片** 中选 **单击时** 还是过几秒后 **自动** 换到下一张，以及 **应用到所有幻灯片**；还有 **跳过这张幻灯片**。
- **主题**：一种 **现成** 的外观，或者这套幻灯片自己的 **颜色**（背景、文本、标题、次要文字、强调色、强调色上的文字、柔和填充，以及六种图表颜色）和用于标题和正文的 **字体**；还有 **幻灯片比例**。用主题颜色上色的部分会跟着主题一起变。

### 放映

**放映** 会从你所在的幻灯片开始全屏放映；它旁边的箭头里有 **从头开始**、**从这张幻灯片开始** 和 **演示者视图（带备注）**。放映时：

- 点击、→、↓、空格键或 Page Down 继续（先是下一个动画，然后是下一张幻灯片）；←、↑ 或 Page Up 返回；在触摸屏上，滑动或轻点；
- 输入幻灯片的编号再按 Enter 就会跳到那一张；Home 和 End 跳到第一张和最后一张；
- **B** 让屏幕变黑，**W** 让屏幕变白（再按一次恢复）；**G** 显示所有幻灯片，方便跳到其中一张；
- 移动鼠标指针时，左下角会显示控制按钮；按 Esc 结束放映。

**演示者视图** 会显示当前幻灯片、下一张（或者提示这一张还有内容）、演讲者备注（用 − 和 + 调小或调大）、可以暂停和重新开始的计时器、当前时间，以及 **返回** 和 **下一个**。**打开观众窗口** 会在单独的窗口中打开放映：把它拖到另一块屏幕或投影仪上，双击即可全屏。它跟随演示者视图，演示者视图也跟随它。

幻灯片也可以在手机上从它的独立地址放映，或者从已发布的链接放映；导出的 **网页** 能在任何浏览器中播放它们。

## 文档

文档也保存在资料库中，有自己的版本、列表中的图片和独立的地址。你可以像在 Word 或 Google Docs 中那样撰写和编辑它们，页面和它的纸张一样大，并把它们保存为 Word、PDF 或 Markdown 文件。

- **新建**：问智能体（“根据这份招聘启事给我写一封求职信”“把我的笔记整理成一份两页的报告”），或者在资料库中点 **新建页面**，然后选 **文档**（[也可以从搜索框用“新建文档”](/library?new=doc)）：可以是空白的，也可以用 **打开 Word 或文本文件** 从你的文件开始。
- **工具栏**：**撤销** 和 **重做**；段落样式（**正文**、**标题**、**副标题**、**标题 1** 到 **标题 4**、**引用** 或 **代码**）；字体和字号；**粗体**、**斜体** 和 **下划线**；**文字颜色** 和 **突出显示**；**链接**（Ctrl+K）；**对齐方式**；**项目符号**、**编号** 和 **清单**；**插入**：**来自这台设备的图片**、**来自网络的图片**、**表格**（在网格上选择它的大小）、**横线** 或 **分页符**；在表格中时还有 **表格**：**在上方插入一行** 或 **在下方插入一行**、**在左侧插入一列** 或 **在右侧插入一列**、**标题行**，以及删除行、列或整个表格；还有 **更多格式**：**删除线**、**上标**、**下标**、**减少缩进**、**增加缩进** 和 **清除格式**。在手机上，工具栏可以左右滑动。
- **按键**：Ctrl+B、Ctrl+I 和 Ctrl+U；Ctrl+Alt+1 到 4 设为标题，Ctrl+Alt+0 设为正文；Ctrl+Shift+7、8 和 9 分别设为编号、项目符号和清单；Tab 和 Shift+Tab 调整列表的缩进（在表格中则跳到下一个单元格，在最后一个单元格之后会新加一行）；Ctrl+Enter 插入分页符。在一行的开头输入 `# `、`- `、`1. `、`[] ` 和 `> `，会变成标题、列表、清单或引用。
- **图片**：点击一张图片就能选中它，拖动一个角可以调整大小；它的工具条可以把它放在 **靠左**、**居中** 或 **靠右**，给它加 **说明文字** 和 **描述**（给看不到图片的人），用 **换一张图片** 替换它，或者删除它。粘贴或拖放到页面上的图片会放在你放下的位置。
- **粘贴**：从 Word、Google Docs 或网页粘贴时，标题、粗体、斜体、链接、列表和表格都会一起带过来，其他的会被去掉。
- 顶部有 **大纲**（各级标题，点击即可跳转；在宽屏上显示在页面旁边）和 **页面设置**：**纸张大小**（**A4** 或 **美式信纸**）、**页边距**（**窄**、**中等**、**宽**，或者以毫米为单位）以及文档的 **字体** 和 **大小**。右下角会显示字数。

选中一些文字，上方就会出现 **就此问智能体**。更改在你点击底部横条中的 **保存**（Ctrl+S）之前都不会保存；**放弃** 会丢掉它们。每次保存都是一个版本。

## 电子表格

电子表格也保存在资料库中，有自己的版本、列表中的图片和独立的地址。你可以像在 Excel 或 Google Sheets 中那样使用它们，包括公式，并把它们保存为 Excel、CSV 或 PDF 文件。

- **新建**：问智能体（“给我做一份两个人的月度预算，带合计”“把这些数字放进电子表格，再加一列显示每个数字的占比”），或者在资料库中点 **新建页面**，然后选 **电子表格**（[也可以从搜索框用“新建电子表格”](/library?new=sheet)）：可以是空白的，也可以用 **打开 Excel 或 CSV 文件** 从你的文件开始（.xlsx、.ods、.csv 或 .tsv）。
- **单元格**：点击一个，或者拖过几个（按住 Shift 点击可以扩大选区；点击列字母或行号可以选中整列或整行）。直接输入会替换单元格里的内容，双击它（或按 F2）则可以修改它；Enter 往下走，Tab 往右走，Esc 取消。以 = 开头的值是公式：`=SUM(B2:B9)`、`=B2*C2`、`=IF(C2>100,"high","ok")`（Excel 的函数，大约两百个，从 SUM、AVERAGE 和 IF 到 VLOOKUP、XLOOKUP、SUMIFS、TEXT，以及日期和贷款函数）。输入公式时，点击单元格就能把它们放进公式，下方会显示名称匹配的函数。
- 左上角的 **名称框** 显示选中的单元格；输入一个单元格或区域（C12、B2:D9）并按 Enter 即可跳转过去。它旁边是单元格的公式或值，也可以在那里修改。
- **工具栏**：**撤销** 和 **重做**；**数字显示方式**（**自动**、**数字**、**百分比**、以美元、英镑或欧元计的 **货币**、**日期** 或 **文本**），以及 **减少小数位数** 和 **增加小数位数**；**字号**；**粗体**、**斜体**、**下划线** 和 **删除线**；**文字颜色** 和 **填充颜色**；**左对齐**、**居中对齐** 和 **右对齐**；**单元格内自动换行**；**保持可见（冻结）**：**不冻结**、**首行**、**首列**，或者冻结到选中单元格为止的行或列；**从 A 到 Z 排序** 和 **从 Z 到 A 排序**，按单元格所在的列排序；以及 **行和列**，可以在上方或下方插入行、在左侧或右侧插入列，或者删除它们。
- **按键**：Ctrl+C、Ctrl+X 和 Ctrl+V 可以复制、剪切和粘贴，也能在这里和 Excel、Google Sheets 之间互相复制粘贴（粘贴的公式会随单元格移动，把一个值粘贴到多个单元格上会把它们全部填满）；Ctrl+D 和 Ctrl+R 向下和向右填充；Ctrl+B、Ctrl+I 和 Ctrl+U；Delete 清除；Ctrl+Z 撤销；Ctrl 加方向键跳到数据的边缘。在单元格上右键点击，会有 **剪切**、**复制**、**粘贴**、插入和删除行与列、排序、**清除** 和 **就此问智能体**。
- **列和行**：拖动列字母或行号的边缘可以调整大小；双击它可以让它适应内容。
- **工作表**：底部的标签页，带有 **添加工作表**（+）。标签页的菜单里有 **重命名**、**创建副本**、**左移**、**右移**、**从 CSV 文件添加工作表** 和 **删除这个工作表**；双击标签页可以重命名它。

选中多个数字时，底部的横条会显示它们的 **求和**、**平均值** 和 **计数**。在手机上，轻点单元格即可选中它，再点一次就能输入；长按会打开菜单，拖动圆形手柄可以扩大选区。更改在你点击底部横条中的 **保存**（Ctrl+S）之前都不会保存，每次保存都是一个版本。

## LaTeX 文档

LaTeX 文档由它的源文件（主文件 main.tex，以及它读入的其他文件，比如存放参考文献的 .bib）和它的图片组成，由应用所在电脑上的 LaTeX 排版成页面。你可以像在 Overleaf 中那样，在排版好的页面旁边编辑源文件，并保存 PDF、.tex 文件或整个项目。

- **新建**：问智能体（“把这些结果用 LaTeX 写成一篇简短的论文，给公式编号”），或者在资料库中点 **新建页面**，然后选 **LaTeX**（[也可以从搜索框用“新建 LaTeX 文档”](/library?new=tex)）：从一篇简短的文章开始，或者用 **打开 .tex 或 .zip 文件** 打开你自己的（一个文件，或者打包成 .zip 的项目文件夹；其中的 PDF 图片会变成 PNG 图片）。
- **源文件**：每个文件一个标签页，另外还有一个 **图片** 标签页（可以添加、重命名图片，把图片放进插图，或者移除图片）；**添加文件或图片**（+）里有 **新文件**、**来自这台设备的文件** 和 **添加图片**，文件的标签页可以重命名或删除它。输入 `\cite{`、`\ref{` 或 `\includegraphics{` 时，会列出文档自己的参考文献、标签和图片供你选择。
- **工具栏**：**插入**（在光标处插入一节、一小节、粗体或斜体文字、项目符号列表或编号列表、带图片的插图、表格、公式、对齐的多行公式、文献引用、脚注或链接）、**粗体** 和 **斜体**、**节标题**、**公式**、**带图片的插图**、**大纲**、**查找和替换**（Ctrl+F）、**在 PDF 中显示这一行** 和 **问智能体**。
- **排版**：你停下输入片刻后，页面就会跟着更新。**重新编译**（Ctrl+Enter）会立即排版，它旁边的箭头里有 **边输入边重新编译**（可以用它关闭自动排版）、**显示日志** 和 **打开 PDF**。顶部的排版引擎可以是 **pdfLaTeX**（最常用）、**XeLaTeX**（任何语言，以及这台电脑上的字体）或 **LuaLaTeX**。页面可以放大、缩小和 **适应宽度**；双击页面上的某个位置，可以跳到源文件中对应的那一行。
- **错误和警告** 显示在源文件下方和对应行的旁边：点击一个即可跳过去，或者点 **请智能体修正**。**日志** 显示 TeX 输出的全部内容。

在手机上，**代码** 和 **预览** 是两个标签页。更改在你点击底部横条中的 **保存**（Ctrl+S）之前都不会保存，每次保存都是一个版本。

应用所在的电脑上必须装有 LaTeX（TeX Live）。没有它的话，LaTeX 文档仍然可以保存和编辑，只是不会排版，编辑器会告诉你要安装什么。TeX 在它自己的文件夹中工作：文档不能读取或修改其他文件，也不能运行程序；在装有 bubblewrap 的地方，TeX 还会在它的沙盒中运行（LuaLaTeX 只在那里运行）。

## 请智能体来修改

打开的页面、幻灯片、文档、电子表格或 LaTeX 文档顶部的 **询问** 会在旁边打开一个面板（在手机上则盖在上面），由智能体在那里替你修改它：

1. 选择要改的范围：对于幻灯片，是 **这张幻灯片**、**所有幻灯片** 或 **选中的内容**（幻灯片上选中的部分）；对于文档，是 **整个文档**、**这一节**（你所在的那一节）、**选中的文字** 或 **选中的图片**；对于电子表格，是 **整个工作簿**、**这个工作表** 或选中的单元格；对于 LaTeX 文档，是 **整个文档**、**这个文件**、**这一节** 或选中的行；对于页面，是 **整个页面** 或 **选中的部分**（在 **编辑** 中对某个部分用过 **问智能体** 之后）。
2. 说出要改什么（“把标题改短一点”“加一张幻灯片，用图表展示这些数字”“把这一节写得更亲切一些”“在数字下方加一行合计”“修正错误，让它能排版”），然后发送。还没保存的更改会先保存，好让智能体在它们的基础上修改。
3. 智能体会使用你上次在开始页上选的智能体和模型；面板会显示它的工作过程和回答，它一保存，你打开的内容就会在你眼前改变。每次更改都是一个版本，所以你可以回退（[回到早先的版本](#go-back-to-an-earlier-version)）。

在面板的消息框中可以接着说；消息框上方的按钮会把你指的是哪张幻灯片或哪个部分放进消息里。**新请求** 会重新开始，**作为会话打开** 会在单独的页面中打开这段对话（它会留在你的会话中）。在手机上，**查看页面** 会在智能体工作时把面板收起来；底部的按钮可以把它找回来。

**就此问智能体** 会打开这个面板，并带上你选中的内容：幻灯片上的一个部分、**编辑** 中页面的一个部分、文档中的文字或图片、电子表格中的单元格（在它们的右键菜单中），或者 LaTeX 文档中的几行（在它的工具栏中用 **问智能体**）。LaTeX 文档的错误下方的 **请智能体修正** 会请智能体把它们全部修正。

## 重命名页面

点击顶部的页面标题，或者在页面中或列表中使用 **更多**（⋯）→ **重命名**。输入新名称（最多 120 个字符），然后点击 **重命名**。页面的名称也是你把它添加到手机主屏幕时使用的名称。

## 回到早先的版本

页面的每次保存都是一个独立的版本：第一个版本（由你保留或制作，或由智能体保存）、智能体保存的每次更改、你在编辑器中保存的每次更改，以及你恢复的每个旧版本。页面更改时不会丢失任何东西。

1. 打开页面，点击 **版本**。
2. 列表显示每个版本（`v3`）、它的标题（当前版本标为 **最新**）、创建时间、创建者（**由智能体生成**、**由你保留**、**由你修改**、**由你创建** 或 **已恢复**）以及大小。
3. 点击一个版本查看它。页面上方的横幅会显示“旧版本，来自 2 天前。它在这里所做的更改不会保存。”旧版本可以使用页面的数据，但你在其中做的任何更改都会被丢弃。
4. 点击 **恢复此版本** 让它成为当前版本，或者点击 **回到最新版本** 离开它。

恢复某个版本会把它作为一个新版本加在最上面（“版本 3 已恢复，成为版本 6”），所以它之后的版本也会保留。页面的数据不受影响。

页面保留它最新的 40 个版本。较旧的版本先被删除，所有版本加起来超过 24 MB 时也是如此；当前版本始终保留。

## 页面保存的数据

小工具需要记住一些东西：你记录的锻炼、你勾选的方框、你的预算条目。保留的页面会把这些数据存放在应用里，也就是应用运行的那台电脑上，而不是某一个浏览器里。所以无论你在哪里打开，它显示的数据都一样：在资料库中、在对话里它的卡片中，以及在你手机上它的独立地址。

- 列表和页面的顶部横条会显示它保存了多少数据（`keeps 14 KB`）。
- 一个页面总共可以保存约 2 MB，单个条目最多 512 KB，最多 1000 个条目。超过这些限制后，就无法再保存更多。
- 新版本和恢复的版本使用相同的数据。
- 智能体可以读取页面的数据，用来回答关于它的问题（“这个月我记录了几次跑步？”），或者修改页面以适应这些数据。
- 页面的已发布副本不会保存数据（见[发布页面](#publish-a-page)）。

要查看页面保存了什么，打开它，然后使用 **更多**（⋯）→ **它保存的内容**。每个值按名称列出，并显示它的大小和更改时间；点击一个值就可以读取它。值旁边的垃圾桶会删除这一个值；**下载** 会把所有值保存为一个 `.json` 文件，**全部清除** 会清空页面的数据（页面本身会保留）。这两种删除都会先问你，而且无法撤销。

## 在手机上使用页面

每个保留的页面都有它自己的独立地址。这个地址只打开这个页面，带着它的数据，在任何设备上都能打开，而且不需要登录 Hydor：很适合你在手机上填写的跟踪表。

1. 打开页面，点击 **分享**。
2. **在你的手机上** 下面会显示地址。点击复制按钮，或者点击旁边的打开按钮试一下。
3. 在手机上打开这个地址。要把它添加到主屏幕：
   - **iPhone**：在 Safari 中打开，然后点 **共享** → **添加到主屏幕**。
   - **Android**：在 Chrome 中打开，然后点 **⋮** → **添加到主屏幕**。

从主屏幕打开时，页面会像应用一样全屏显示，并使用它自己的名称。在独立地址打开时，它会跟随手机的浅色或深色设置。

任何拿到这个地址的人都可以打开这个页面，并更改它保存的内容，所以只把它分享给你在这方面信任的人。你的手机也必须能访问应用的地址（[从其他设备访问应用](/guide/devices#reach-the-app-from-another-device)）。

### 给页面换一个新地址

如果某个地址被发到了不该去的地方，就替换它：

1. 打开页面，点击 **分享**，然后点击 **给它换一个新地址（旧地址会失效）**。
2. 确认 **新地址**。旧地址会立即失效，已添加到主屏幕上的也一样。“页面有了新地址”表示已完成。

在你需要的地方，把新地址重新添加到主屏幕。

## 删除页面

在页面的卡片上或打开的页面中使用 **更多**（⋯）→ **删除**，并确认。页面会连同它的所有版本、它保存的数据以及它的任何已发布副本一起删除。它的地址也会失效。

资料库最多可容纳 1000 个页面和幻灯片。单个页面的 HTML 最大 2 MB；幻灯片的文字最多 3 MB，图片另算（每张最多 12 MB）。

## 发布页面

发布会把页面放到一个链接上，别人不需要应用的密码就能打开。用它来给别人看你做的报告或小工具。

1. 打开页面，点击 **分享**，然后点击 **发布到别人能打开的链接**。
2. 检查 **名称**（最多 60 个字符）。
3. 选择链接类型：
   - **私密链接**：一个无法猜到的链接，只有你把链接给了的人才能打开。
   - **公开链接**：一个由名称生成的可读链接（比如 `/site/trip-plan/`），任何人都可能找到并打开它。
4. 点击 **发布**。框中会显示链接，以及复制和打开它的按钮。点击 **完成**。

已发布的副本显示的是页面现在的样子，之后的版本也会显示在那里。它不会保存数据：别人输入的内容在重新加载后就没了。要自己在手机上使用页面并保存数据，请改用它的独立地址打开（[在手机上使用页面](#use-a-page-on-your-phone)）。

链接以你访问应用时用的地址开头，所以只有能访问那个地址的人才能打开它。如果只有你自己的设备能访问应用（比如通过 Tailscale），那么也只有它们能打开这个链接（[从其他设备访问应用](/guide/devices#reach-the-app-from-another-device)）。

## 从文件夹发布网站

你也可以发布项目构建出来的网站，比如用 Vite 或静态网站生成器做的应用：也就是构建输出的那个文件夹，里面要有一个 `index.html`。

1. 打开 [资料库 → 已发布](/library?tab=published)，点击 **发布文件夹**。
2. 选择 **文件夹**：一个包含 `index.html` 的已构建网站（构建后的 `dist/`、`build/` 或 `out/`）。
3. **名称** 会根据文件夹的名称自动填写；你可以修改它。
4. 选择 **私密链接** 或 **公开链接**，然后点击 **发布**。

网站直接从磁盘上的文件夹提供，所以新的构建会立即显示，不需要重新发布。可以发布的内容：

- 文件夹必须包含 `index.html`；
- 不能是你的主文件夹、主文件夹的上一级、磁盘的根目录、应用自己的数据，或者隐藏文件夹（名称以点开头的文件夹）里的文件夹；
- 最多 5000 个文件、300 MB；
- 名称以点开头的文件和文件夹（`.env`、`.git`）永远不会被提供。

网站内没有对应文件、也没有文件扩展名的地址（`/site/…/about`）会得到网站的 `index.html`，这样自己切换页面的应用也能正常工作。如果文件夹被移动或删除，链接会显示它已不存在：请重新发布。

### 已发布的网站能做什么

已发布的网站运行在它自己的一个封闭项目中，与应用隔离：没有 cookie，没有应用的任何登录信息或数据，它在浏览器中保存的内容在重新加载后就会被忘掉。它没有自己的服务器代码。它可以从自己的文件以及三个公共脚本托管站点（jsDelivr、unpkg 和 cdnjs）加载脚本，并通过 HTTPS 调用外部服务。私密链接不会被搜索引擎收录。

从地址根路径（`/assets/…`）加载文件的已构建网站，在网站的链接下找不到这些文件。请用相对路径构建它们（在 Vite 中是 `base: './'`）。智能体请求发布这样的文件夹时，会被提醒先重新构建。

## 当智能体请求发布时

智能体也可以发布，但必须得到你的同意。说“发布我的网站”或“把旅行计划放到网上”，智能体会在对话中显示一张卡片：

- **发布“旅行计划”？**，以及它要发布的内容：保存的页面，或者文件夹及其文件数量和大小；
- 可供选择的 **私密链接** 或 **公开链接**，以及各自的含义：“它会在沙盒中打开，与本应用相互隔离；你可以随时在资料库中取消发布。”；
- **发布** 和 **暂不**。

在你点击 **发布** 之前，什么都不会发布。然后智能体会收到一条消息，告知结果和链接。卡片会变成 **已发布“旅行计划”**，并附上可复制或打开的链接；如果你点击了 **暂不**，会变成 **未发布：“旅行计划”**；如果发布失败，会变成 **“旅行计划”发布失败**，并附上原因。

一个会话中，智能体最多可以有五个等待中的发布请求。

## 查看和取消发布你发布的内容

[资料库 → 已发布](/library?tab=published) 列出所有已发布的内容，最新的排在前面。每一项显示它的名称、**私密链接** 或 **公开链接**、它提供的内容（页面的标题或文件夹的路径）和发布时间，以及可复制或打开的链接。

要撤下其中一项：

1. 点击它旁边的 **取消发布**。
2. 确认 **取消发布**。“它的链接会立即失效。”“已取消发布”表示已完成。

你以后可以再次发布它；届时私密链接会是一个新的链接。删除保留的页面也会取消发布它。同一时间最多可以发布 200 个网站。

没有发布任何内容时，会显示“没有已发布的内容”，以及 **发布文件夹**；打开 **已发布** 时，它也在右上角。

## 问问智能体

智能体可以为你读取和修改你资料库里的内容，你在卡片上同意即可。可以试试这些：

- “给我做一个能在手机上用的健身记录，保存到我的资料库里。”
- “把我的行李清单移到‘旅行’项目。”
- “我改了旅行页面上的标题；现在在它们下面加一张地图。”

- “这周我在习惯打卡表里记了什么？帮我总结一下。”
- “把页面‘未命名清单’改名为‘搬家’。”
- “我把行李清单的地址发给了不该发的人：给它换一个新地址。”
- “用私密链接发布旅行计划”，或者“取消发布我们上周做的网站。”
- “把我的落地页上的标题在手机上改小一点，按钮改得更圆一些。”
