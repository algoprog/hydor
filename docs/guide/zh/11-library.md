# 资料库：页面、图片、视频和网站

智能体可以用页面代替纯文字来回答：一份报告、一张图表、一个比较各个选项的表格，或者一个小工具，比如跟踪表或清单。它们还会制作幻灯片、文档、电子表格和 LaTeX 文档，你可以像在 PowerPoint、Word、Excel 或 Overleaf 中那样编辑它们，还有可以在这里运行的 Jupyter 笔记本。你保留的东西都按项目放在你的资料库里，你保存的图片、视频和声音也在那里。本主题介绍如何观看页面的编写过程，如何修改和保留它（版本、数据、供手机使用的地址），图片、视频和声音，如何自己制作，面向网页或 PowerPoint 的幻灯片，用 AI 生成和编辑的图片，导出，请智能体来修改，以及如何发布到一个链接上。

## 对话中的页面

当一张图比文字更能说明问题时，智能体会显示一个页面：一份报告、一张图表、一个表格、一张示意图、一份设计稿，或者一些可供选择的选项。应用里的任何智能体都能做到；用平常的话提出要求就行（“把这个做成图表给我看”“用表格比较这三台笔记本电脑”）。单独一张图表、示意图或图片，通常会直接放在回复里（见[回复中的数学公式、示意图、插图和图片](/guide/sessions#maths-diagrams-figures-and-pictures-in-replies)）。

在宽屏上，智能体一开始编写页面，页面就会在对话旁边打开（见[观看页面的编写过程](#watch-a-page-as-it-is-written)），对话里则为它留一张小卡片：它的标题、它是什么（“页面 · 24 KB”“已保存到资料库 · 版本 2”），以及 **打开**；正在旁边显示的那一个则显示 **在旁边**。点击一张卡片，就会在对话旁边显示它的页面。

在较窄的窗口中、在手机上，或者关闭了对话旁边的面板时，页面位于回复中，和对话一样宽，并会随内容增高。较高的页面会停在窗口一半的高度，让周围的对话仍在视野中，并在底部边缘显示 **查看整个页面**（幻灯片总是完整显示）。页面上方的横条包含：

- 页面的标题；
- **保留**：把页面放进你的资料库（见[保留页面](#keep-a-page)）；
- **编辑**（铅笔图标）：打开它进行修改（见[自己修改页面](#change-a-page-yourself)）；
- **另存为文件**（下载图标）：把页面保存为 `.html` 文件，带着它的现成外观，可以在任何浏览器中打开；
- **全屏**（展开图标）：在应用上方打开页面。按 Escape 键、轻点关闭按钮（✕）或点击页面旁边的区域即可关闭。

页面运行在它自己的框架中，与应用隔离：它无法访问应用、你的文件或你的登录信息。它可以从网上加载图表库和其他库。

智能体为页面做的图片（一张图片、一张绘图、一张数据图、一张免费照片）会放进页面本身，在这台电脑做得到时还会缩小（一个页面总共最大 2 MB），所以无论页面在哪里打开都能显示。视频不会放进页面：页面按地址显示 YouTube 和 Vimeo 的视频。

页面看起来就像应用的一部分：智能体按应用的主题来做页面，应用是浅色就是浅色，是深色就是深色，用你的主题颜色（包括你自己的主题）和应用的字体；你切换主题时，打开着的页面也会跟着变。自带浅色和深色两种外观的页面，会显示应用当前的那一种，不管你的设备设成什么。想要别的外观时直接说：“用我们品牌的颜色”“做一个带霓虹强调色的深色页面”。

智能体做的幻灯片在对话中以放映的形式显示：点击幻灯片或它的箭头可以逐张浏览，点网格按钮可以查看所有幻灯片，点全屏按钮可以放映（[幻灯片](#slides)）。

如果你用只读链接分享会话，对方也能看到其中的页面，但不能保留或修改它们，他们在页面上做的选择也不会发送到任何地方（[分享只读链接](/guide/sessions#share-a-read-only-link)）。

## 观看页面的编写过程

智能体编写页面时，你会看到它一点点长出来：先是标题，然后是文字、表格和卡片，写到哪里就显示到哪里。在宽屏上（1100 像素或更宽），对于屏幕上正在显示的会话，页面会自动在对话旁边的面板中打开。面板顶部那一行显示 **正在编写**，以及目前已经写了多少；旁边的代码按钮会改为显示正在写入的页面 HTML，眼睛按钮则回到页面。在较窄的窗口中或手机上，页面会在对话里它的卡片中逐渐长出来。页面的脚本会等到页面完整之后才运行。

智能体完整写出一个 HTML 文件时（比如静态网站的 `index.html`），面板也会打开它，并从文件所在的文件夹加载它的图片和样式。

智能体编写文档、幻灯片、电子表格或 LaTeX 文档时，它们也会这样一点点长出来：在面板中（用它自己的编辑器显示），如果你在资料库中打开了它，那里也一样；在手机上或较窄的窗口中，点对话里它那一行的 **打开**，就会把它显示在所有内容上方。它的标题下方会显示“智能体正在编写新版本”和一个圆点，表示正在进行；在此期间它是只读的（工具栏变暗），智能体的光标带着一个小小的 **智能体** 旗标，显示它的文字正写到哪里，并会一直保持在视野中，除非你滚动到别处。重新写一份长文档时，文档会保持原样，只有改动的部分会动：新的文字一到，就会替换掉旧的。在幻灯片中，会显示正在编写的那张幻灯片，正在编写的部分周围有一个框；在电子表格中，正在编写的单元格会被框出来，它的公式随写随算；LaTeX 文档的源文件会逐渐变长，保存之后才会排版出页面。智能体保存完成后，它的版本会取代你刚才看到的内容；如果保存失败或者你让它停下，页面会保持原样。你还没保存的更改会原样保留：会有一条提示说智能体正在编写新版本，在你保存之前，这些更改仍然是你的。如果它开始时你正在输入（幻灯片上的文字、一个单元格、一条评论），智能体的版本会等你输入完，你输入的内容会算作你的更改。分步工作的智能体（每次一节、几张幻灯片或一些单元格）会在这里逐步显示每一步。

- 拖动面板的左边缘可以让它变宽或变窄；应用会在这台设备上记住这个宽度。
- 一个对话中有多个页面时，点击面板中的页面标题，可以切换到另一个页面。
- 面板中的 **更多**（⋯）包含 **在资料库中打开**（已保存的页面）、**在“文件”中显示**（HTML 文件）、**另存为文件**（对于已保存的页面或幻灯片，则是 **下载为** PDF、Word 文档、PowerPoint 文件或网页），以及 **页面一开始编写就在这里打开**：关闭它后，页面会等你从它们的卡片中打开。
- 幻灯片会在面板里的幻灯片编辑器中打开（[编辑幻灯片](#edit-slides)）。
- ✕ 关闭面板。会话标题栏中的 **详情** 会在同一位置打开会话的详情。

## 自己修改页面

智能体显示或保存的任何页面、你库中的任何页面，以及智能体写出的任何 HTML 文件，都可以用三种方式修改。用页面顶部的按钮选择一种（在对话旁边的面板中，它们是图标：眼睛、铅笔和代码符号）：

- **使用**：页面本身，可以正常使用：在它的输入框中输入、勾选它的方框、选择它的选项。
- **编辑**：直接在页面上点击来修改它。修改期间，页面的脚本会暂停运行，所以页面保持不动。
- **代码**：它的 HTML，旁边是页面（在较窄的面板中则在下方），你输入后片刻就会显示你的更改。

在它们旁边，屏幕按钮可以按 **电脑**、**平板** 或 **手机** 的尺寸显示页面（在面板中和较窄的窗口里是一个带菜单的按钮）。页面打开时有多宽的项目就显示多宽；选了平板或手机的宽度后，在页面关闭前会一直保持。在 **编辑** 中，选着平板或手机时做的修改只用于那种尺寸的屏幕（[为手机和平板修改](#change-it-for-phones-and-tablets)）。

### 点击编辑

1. 点击页面的某个部分：一个标题、一个段落、一张图片、一张卡片、一个表格。它会出现一个带有名称的边框（“标题 2”“图片”“卡片”），旁边还有一个小工具条。
2. 再点一次（或者双击）就可以在里面输入：光标会停在你点击的地方。输入时，点击其他文字，就会在那里接着输入。选中一些文字，上方会出现一个工具条，里面有文字所在块的类型（**文本**、**标题 1**、**项目符号列表**……，可以把它转换成另一种）、**粗体**、**斜体**、**下划线**、**删除线**、**代码**（Ctrl+E）、**颜色和突出显示**（给文字设一种颜色，或者在文字后面衬一种颜色）、**设为链接**（Ctrl+K）、**取消链接**、**清除格式** 和 **完成**。在手机上，你一开始输入，工具条就会出现。按 Esc 会停止输入，并选中这个块。
3. 选中部分旁边的工具条：拖动手柄（⠿）可以把这个部分移到页面的其他位置，点击手柄则会打开这个部分的菜单（和下文中块旁边的 ⋮⋮ 打开的菜单一样）；**选择外层部分**（按 Esc 也一样）；**修改文字**；**上移** 和 **下移**；**创建副本**（Ctrl+D）；**删除**（Delete 键）。拖动它右边、下边和右下角的小手柄，可以把它拉宽或拉高。

按键和其他编辑器一样：Ctrl+C、Ctrl+X 和 Ctrl+V 可以复制、剪切和粘贴选中的部分（在应用打开期间，也能粘贴到另一个页面里）；Ctrl+G 把它包进一个块里，Ctrl+Shift+G 取出里面的内容；方向键选中上面、下面、外层或里面的部分；Alt+↑ 和 Alt+↓ 移动它。页面上方工具条末尾的键盘按钮（或 Ctrl+Shift+/）会列出所有按键，还有一个输入框可以查找按键。

在手机上，点一下某个部分就能选中它，再点一下就能在里面输入。页面下方的标签（**部分**、**图层**、**网页**）会打开一个抽屉，里面是可以修改的内容；箭头可以收起它，你输入文字时它也会自动收起。

**添加** 会把一个新部分放在选中的部分之后、它里面，或者页面末尾（用 **放在** 选择位置：**在它后面**、**放在它里面** 或 **放在最后**）：**基础**（标题、文本、按钮、链接、图片、列表、待办清单、标注框、引用、分隔线、一段空白）、**布局**（区块、两栏或三栏、卡片、一组卡片、表格、数字、折叠区、目录、输入框）以及 **现成区块**（开场介绍、功能特点、价格、步骤、常见问题、用户评价、行动号召、联系表单、页脚）。在合适的地方，它的文字可以直接输入。它们下面的 **添加 AI 生成的模块** 会让智能体在 **放在** 指定的位置做一个它会做的模块，比如价格表、问答、团队介绍（[按类型用 AI 制作](#made-with-ai-from-a-kind)）。

**撤销**（Ctrl+Z）和 **重做**（Ctrl+Shift+Z）可以一步步撤回或重做你的更改。输入时，Ctrl+Z 会先撤回你最后输入的文字，然后再一块一块地撤回之前的每一处更改，光标也会回到原来的位置。

### 像在 Notion 中那样书写

在段落、标题或列表中输入时，文字会像在 Notion 或文字处理软件中那样，从一个块接到下一个块：

- 在块的末尾按 **Enter**，会新建下一个块并把光标放进去：标题之后是一个段落，列表中则是下一项。在中间按 Enter 会把块一分为二；在空的列表项中按 Enter 会离开列表。**Shift+Enter** 是在同一个块里换行。
- 在块的开头按 **Backspace**，会把它并入前一个块（空的块会被删掉）。在列表项的开头，它会先把这一项升一级，或者移出列表；在引用、标注框、折叠列表或代码的开头，它会把它变成段落；在紧跟着图片或横线的块的开头，它会选中那张图片或那条横线，再按一次 Backspace 就会删除它。
- 在第一行按 **↑**、在最后一行按 **↓**，会继续进入上面或下面的块；**Tab** 和 **Shift+Tab** 可以把列表项嵌套到前一项下面，或者再移出来。在紧跟着列表的段落（或任何块）中按 Tab，会像在 Notion 中那样把它放到列表最后一项的下面；按 Shift+Tab 则把它移出来。
- 空的块会显示一行淡淡的提示（“输入‘/’调出命令”“标题 1”“待办事项”“列表”），它永远不会成为页面的一部分。
- 点击最后一个块下方的空白处，会在末尾新起一个段落；最后一个块下面的 **+** 也一样，还会列出可以添加的块。
- 在 **编辑** 中也能勾选待办事项（点击方框），页面会记住勾选；点击折叠列表的三角形可以展开或收起它。在 **使用** 中，待办事项可以勾选，折叠列表可以展开和收起，和在别处一样。

输入时也可以用 Markdown：在段落开头输入“# ”“## ”和“### ”会变成标题，“- ”或“* ”变成项目符号列表，“1. ”变成编号列表，“[] ”变成待办事项，“> ”变成引用，“```”变成代码块，“---”变成横线。\*\*粗体\*\*、\*斜体\*、\`代码\` 和 \~\~删除线\~\~ 会在你输入结尾的标记时变成对应的样式。紧接着按 Ctrl+Z，会撤回这个变化，恢复成你输入的样子。粘贴多行文字时，每一行会变成一个块。

### 添加块

在空的块中，或者在空格之后输入 **/**，光标下方就会打开一个块的列表。继续输入可以筛选它（“/待办”或“/to”都能找到 **待办清单**），用方向键和 Enter（或者点击）选择，按 Esc 关闭。你在 / 之后输入的内容会消失。在空的块中，这个块会变成你选的那种；在一些文字之后，新的块会放在它们下面。

- **文本**、**标题 1** 到 **标题 3**、**项目符号列表**、**编号列表**、**待办清单**、**折叠列表**（一个标题，展开后显示它下面的内容）、**引用**、**标注框**（带底色的方框里放一个表情符号和一些文字：点击表情符号可以更换它）、**分隔线** 和 **代码**。
- **表格**、**按钮**、**两栏**、**三栏**、**卡片**、**目录**（指向页面各个标题的链接，你修改标题时会随时更新）和 **数据库**（见[数据库](#databases)）。
- **图片**（**来自这台设备的图片**、**用 AI 生成**、**绘图（SVG）**、**免费照片**，或者一张图片的网址：见[用 AI 生成图片、绘图、数据图和视频](#make-pictures-drawings-plots-and-videos-with-ai)）、**视频**（YouTube 或 Vimeo 的地址：页面显示它的静止画面，点击即可播放）、**数学**（LaTeX，边输入边显示排好的公式；以后可以在“部分”标签中修改）和 **表情符号**（按名称选择，最近用过的排在最前）会在光标旁边打开。在那里生成或找到的图片，一准备好就会填进它的位置，并缩小到足以放进页面里；在许可协议要求署名时，免费照片的署名会放在它下面。
- **链接到页面**，或者在书写时输入 **@**（在块的开头或空格之后）：列出你资料库中的页面，最新的排在最前。输入页面名称中的几个字找到它，再按 Enter：就会插入一个指向它的链接，显示这个页面的图标和名称，你给页面改名时链接也会跟着更新。在 **使用** 中，点击它会打开那个页面。

把电脑上的图片拖放到页面上，或者粘贴一张图片，它会落在你放下的位置（或者你正在输入的那个块之后），并缩小到足以放进页面里。

**代码** 块会在你输入时给代码着色（关键字、字符串、数字、注释、名称），按页面的浅色或深色外观显示，在 **使用** 中也一样。鼠标指向它或选中它时，它的右上角会显示它的语言：**自动** 会根据代码判断语言；点击它可以选择别的语言（Bash、C、C++、C#、CSS、Diff、Go、HTML、Java、JavaScript、JSON、Kotlin、Lua、Markdown、PHP、Python、Ruby、Rust、SQL、Swift、TypeScript、YAML，或者选 **纯文本** 表示不着色）。块的菜单（⋮⋮）里也有 **语言**，**部分** 标签中也有。页面会把代码连同它的语言一起按纯文本保存，无论在哪里打开都会给它着色，另存为文件的页面也一样。智能体按自己的方式写进页面的代码也会着色，使用页面自己为代码设定的外观：按智能体指明的语言着色；没有指明语言时，只有代码明显属于某种语言时才着色（命令的输出保持不着色），而且代码会按智能体写的样子保留。

### 数据库

用 **/** 或 **添加** 中的 **数据库**，可以在页面里放一个你自己的表格，就像 Notion 中的数据库那样：一个标题、若干列（每列只放一种值）和若干行。新的数据库有 **名称**、**状态**（待办、进行中、完成）和 **日期** 三列，以及三个空行。

- 直接在单元格里书写。点击 **单选** 或 **多选** 单元格会打开它的选项（输入一个新选项并按 Enter 就能添加它），**复选框** 点一下就会勾选，**链接** 用旁边的箭头打开。表格下方的 **新增** 会添加一行；行末的 × 会删除那一行。
- 点击列名会打开它的菜单：重命名它，修改它的 **类型**（**文本**、**数字**、**单选**、**多选**、**日期**、**复选框** 或 **链接**；与新类型相符的值会保留下来），修改单选列的 **选项** 及其颜色，**升序排序**、**降序排序**、**按此列筛选**、**左移**、**右移** 或 **删除列**。表头末尾的 + 会添加一列。
- 表格上方的 **排序** 和 **筛选** 会按某一列给行排序，并只显示符合条件的行（包含、等于、早于、已勾选……）。数据库会记住它们，下次还用。
- **看板视图** 会把行显示成分列排列的卡片，单选列的每个选项各占一列（用 **分组依据** 选择按哪一列分）。把卡片拖到另一列就会改变它的选项（在手机上是左右拖动）；点击卡片可以查看和修改它的全部内容；某一列里的 **新增** 会在那一列添加一张卡片。

它的行保存在页面的数据中（见[页面保存的数据](#the-data-a-page-keeps)），而不是页面本身里：无论在 **使用** 还是 **编辑** 中，你改的任何东西都会立即保存，不用点 **保存**，在每台设备上都能看到，并且在页面的各个版本之间保持不变。**创建副本** 会做出一个独立的数据库，带着它现在的行。在任何地方都无法保存改动的情况下（另存为文件的页面、PDF、页面的图片、发布出去的副本），数据库会按现在的样子显示它的行，供阅读和打印。智能体能看到每个数据库的列和行，并会按你的要求添加、修改或删除行。

### 移动、转换和给块上色

鼠标指向一个块，它左边的空白处会出现两个按钮：

- **+** 在它下面添加一个块，并打开块的列表（按住 Alt 点击则添加在上面）。
- **⋮⋮** 用来移动它：上下拖动，会有一条线显示它会落在哪里，可以落在两个块之间，或者放进一个空的栏里。点击它会打开这个块的菜单：**转换为**（转换成任何一种块，保留它的文字；嵌套列表中的一项转换成文本、标题、引用或待办事项时，会留在原处，仍在它的上级项下面，它下面的各项也仍在它下面）、**颜色**（给它的文字设一种颜色，或者给整个块衬一种背景色，色板在浅色和深色页面上都合适）、**在下方添加一个块**、**创建副本**、**上移**、**下移**、**复制**、**删除**，在对话中还有 **问智能体**（它会在你的消息框里写下你指的是哪个块）。

在手机上，点一下某个块就能选中它，再点它旁边工具条上的手柄（⠿），就会打开同样的菜单。

块的按键：Ctrl+/ 打开 **转换为**；Ctrl+Alt+0 把块变成文本，Ctrl+Alt+1 到 3 变成标题，Ctrl+Shift+7 变成编号列表，Ctrl+Shift+8 变成项目符号列表，Ctrl+Shift+9 变成待办清单（再按一次同样的键，列表会变回文本）；Ctrl+Shift+↑ 和 Ctrl+Shift+↓ 移动这个块；Ctrl+D 创建它的副本；Ctrl+Enter 勾选待办事项、展开或收起折叠列表，或者离开代码块。

要选中多个块，可以按住 Shift 点击它们（如果它们挨在一起，会选中从已选的那个到你点击的那个之间的所有块），或者像在 Notion 中那样拖过它们：在它们任意一侧的空白处、它们之间、某个块的文字旁边（或者在 **+** 上）按下鼠标并拖动；会有一个框显示你选中的内容，列表的各项会逐项选中，拖到页面的顶部或底部时页面会跟着滚动。从某个块的文字上开始的拖动，要等离开这个块才开始选择，所以单击仍然只是单击。这时删除、创建副本、移动、复制、**转换为** 和 **颜色** 都会作用于所有选中的块，**部分** 标签中的修改也一样。

### 块上的评论

和在 Notion 中一样，资料库中的页面可以在它的块上加评论：留给以后的备忘，或者想请智能体做的修改。选中一个块（或者选中其中的一些文字），然后点它 ⋮⋮ 菜单中的 **评论**，或文字上方工具条里的 **评论**，或者按 Ctrl+Alt+M。页面旁边的 **评论** 标签会打开，里面有一个输入框，上方是这个块的文字（或你选中的文字）；按 Ctrl+Enter 或点 **评论** 即可保存。有评论的块会在右边显示一个带评论数量的标记：点击它就能看到这些评论。每条评论都有 **回复** 和 **解决**（✓），⋯ 菜单里还有 **编辑** 和 **删除**；已解决的评论收在“… 条已解决”下面，在那里用 **重新打开** 可以把一条评论找回来。点击一条评论，它所在的块会在页面上被框出来。

评论和页面保存在一起，但不在页面里面：它们不会改变页面的外观或用法，只在这里的 **编辑** 中显示（在页面自己的地址上和发布出去的地方都不会显示），添加评论也不会产生新版本。你修改页面时，评论会留在它们的块上：你移动、在里面书写或转换成另一种类型的块，都会保留它的评论。被问到这个页面的智能体会读这些评论，回复或解决它们，也可以留下自己的评论。

### 图标和封面

和在 Notion 中一样，页面可以有一个图标（标题上方的一个表情符号）和一张封面（横跨页面顶部的一条色带或一张图片）。鼠标指向页面的第一个标题，上方就会出现 **添加图标** 和 **添加封面**；**网页** 标签的 **图标和封面** 下面也有它们。图标和表情符号一样按名称选择。封面可以是几种渐变色之一、**来自这台设备的图片**、为它生成的一张图片（**用 AI 生成**，和封面一样宽），或者一张图片的网址。点击图标可以更换它或 **移除图标**；鼠标指向封面会出现 **更换封面** 和 **移除**。

### 部分、图层和网页

页面旁边（在较窄的面板中或在手机上则在页面下方）有三个标签，显示你可以修改的内容（对于资料库中的页面，还有第四个标签，显示它的[评论](#comments-on-blocks)）。

**部分** 是选中的部分，上方是它外层的各个部分（点击其中一个即可选中它）。最上面是：**问智能体**（在对话中：它会在你的消息框里写下你指的是哪个部分，你只需说要改什么；还没保存的修改会先保存，好让智能体看到）、**复制**、**粘贴**，以及 **更多**（⋯），里面有 **剪切**、**粘贴到它里面**、**包进一个块里**、**取出里面的内容**、**创建副本**、**在页面里找到它** 和 **删除**。选中多个块时，会有一条提示说明这一点，你做的修改会用于所有选中的块。然后是它的几组设置，可以收起；大多数人常用的几组是展开的（**内容**、**文本**、**填充和边框**），其他几组要等你展开，每一组都会记住你上次是否让它展开着：

- **内容**：它的文字；对于一块文字，它的 **类型**（文本、标题、列表、待办清单、折叠列表、引用、标注框或代码：选另一种就能把它转换成那一种，保留它的文字）；对于链接，它 **链接到** 哪里，以及是否在 **新标签页** 中打开；对于图片，它的地址或 **来自这台设备的图片**（会缩小到足以放进页面里）、魔杖图标（**AI 生成的图片**，用一张新图片替换它）、**编辑**（**编辑图片**：裁剪、旋转，修改光线和颜色，加滤镜，在上面加文字和标注：[编辑图片和视频](#edit-pictures-and-videos)）、**用 AI**（**用 AI 修改**：用文字说明来修改它、去掉它的背景，或者擦除它的一部分），以及它的 **描述**；对于数学公式，它的 LaTeX。
- 下面的修改用于哪些部分：**仅这个部分**、所有同类的部分（“所有标题 2”），或者所有带它某个 class 的部分（“所有 .card”）；还有 **正常** 或 **悬停**，即鼠标指针停在上面时的样子（你修改时页面会显示这个样子）。
- **文本**：**颜色**、大小和粗细、**样式**（斜体、下划线、删除线、大写）、**对齐**、**字体** 和 **行距和字距**（行的高度、字母之间的距离）。
- **填充和边框**：**填充**、**圆角**、**边框**、**阴影**、放在后面的 **图片** 和 **透明度**。
- **空间**：边框 **外** 和边框 **内** 的空间，按这个部分本身的样子并排显示。输入数字，或者上下拖动数字。
- **大小**：它的 **宽度** 和最多能有多宽，它的 **高度** 和至少要有多高，以及图片如何 **适配** 它的尺寸。
- **布局**：里面的部分如何 **显示**（上下排列、并排、竖向排列、网格排列，或者隐藏），它们怎么对齐和分布、彼此的间距，以及它的 **位置**：默认位置、从原位置偏移、相对所在的块、固定在屏幕上，或者在页面滚动时固定。
- **类名、名称和 CSS**：它的 class、它的 id，以及给它设置的 CSS。

某项设置有内容时，它的名称会变成金色；旁边的 ✕ 可以清除它。左右拖动数字前面的字母可以修改数字，也可以用方向键（按住 Shift 则每次改 10）。色块是页面自己的颜色；彩虹色的那个可以选择任何其他颜色。

**图层** 把页面的各个部分显示成一棵树，按它们互相包含的样子排列。指向其中一个，就能在页面里看到它；点击它就能选中它，即使它太小或被挡住，在页面里点不到。

**网页** 是整个页面：

- **页面**：它的 **标题**（浏览器标签页上的名称）、**背景**、**宽度**（在大屏幕上居中显示的内容有多宽：**全宽**、**宽**、**中等** 或 **窄**）、**内部留白** 和 **语言**。
- **图标和封面**：页面的图标（标题上方的一个表情符号）和封面（一种渐变色，或者来自这台设备或网络的图片），见[图标和封面](#an-icon-and-a-cover)。
- **颜色**：页面自己命名的颜色（它的 CSS 变量；用应用自带外观做的页面，有 **背景**、**卡片**、**文本**、**强调色** 等）。它们一开始就是你主题的颜色。改一个，用到它的地方都会一起变，而且在任何主题下都保持这样。
- **字体**：它的 **文本** 和 **标题** 用的字体：设备自带的字体，或者 Google 的字体，页面会自动加载。
- **文字样式**：**文本**、**标题 1** 到 **标题 3**、**链接** 和 **按钮** 在整个页面里的样子。你单独改过的部分会保留它自己的修改。
- **你的 CSS**：你为整个页面写的规则，会原样保存在页面里。

### 为手机和平板修改

在顶部选 **平板** 或 **手机**，页面就会按那个宽度显示，上方的工具条会出现 **平板专用** 或 **手机专用**。这时做的修改只用于那么宽或更窄的屏幕（平板 900 像素，手机 600 像素），页面在电脑上的样子不变：比如手机上的标题小一点、两栏在手机上变成上下排列、某个部分在手机上隐藏（**布局** → **显示** → **隐藏**）。再选 **电脑**，修改就又用于所有屏幕。

悬停时的样子、某种屏幕尺寸的修改，以及对所有同类部分的修改，会放进编辑器保存在页面里的样式表；对单个部分本身的修改则放在它自己的样式里。无论哪种，都是你保存的页面的一部分，以后修改这个页面的智能体也能看到。

### 保存或放弃

一旦你改了什么，底部就会出现一个横条，显示 **尚未保存**，以及 **放弃** 和 **保存**（Ctrl+S，在页面里面按也可以）。在 **使用**、**编辑** 和 **代码** 之间切换不会丢失你的更改。

- 已保存的页面（在你的库中）会得到一个新版本：智能体的版本都会保留，你可以回到其中任何一个（[回到早先的版本](#go-back-to-an-earlier-version)）。如果在你修改期间页面又被保存了一次（比如被某个智能体保存），应用会先问你，再把你的版本放在最上面；另一个版本会留在版本列表中。
- 对话中显示、还没有保留的页面，按钮会显示 **连同更改一起保留**：它会被放进资料库，智能体的页面作为版本 1，你的作为版本 2。
- HTML 文件会保存在原处。如果在你打开它之后它在磁盘上被改过，应用会告诉你，而不会覆盖它。

### 智能体会知道你的更改

显示这个页面的智能体（对于已保存的页面，还有创建它的那个会话的智能体）会在你下次给它发消息时知道你的更改：哪个页面、它的版本，以及你改了什么，这样它会在你的版本上继续，而不是用它自己的版本覆盖你的。对话中会显示一条提示：“你修改了‘旅行计划’（版本 3） · 智能体会在你发下一条消息时看到”，消息发出后，它会变成“智能体已看到”。点击这条提示可以再次打开页面。

## 在页面上选择选项或填写表单

有些页面会问你一些问题：三个方案中你更喜欢哪一个、旅行的日期、要保留哪些物品。你的回答会进入消息框，而不会直接发给智能体：

- **点击一个选项**，消息框中就会出现一行，比如 `Chose: B` 或 `Color: Blue`。如果页面允许多选，它们会一起放进去（`Color: Blue, Green`）。在同一组中选择另一个选项，它的那一行会替换第一行；不会越积越多。
- **填写表单并提交**，它的回答会以一个简短的列表放进去，标题是表单的名称，每个字段一行。

在消息中添加你想说的任何内容，然后像平常一样发送。智能体会把你的选择当作你消息的一部分来读。

页面全屏显示时，你的选择会先等着，在你关闭全屏时放进消息框（消息框在页面下方）。

## 保留页面

对话中显示的页面与对话共存。要以后再回来用它，就保留它：

1. 点击页面上方横条中的 **保留**。如果你有项目，会弹出一个小菜单问它放在哪里（**保留到**）：本会话所在的项目排在最前，标着 **本会话所在的**，然后是你的其他项目，以及 **不放在项目中**。
2. 提示“已保存到资料库”表示成功（放进项目时显示“已保存到资料库，放在 Thesis 中”）。按钮现在显示为 **已保留**；点击它可以在资料库中打开这个页面。

修改一个显示中的页面并保存，也会保留它（**连同更改一起保留**，见[保存或放弃](#save-or-discard)）。

页面还在对话中时你在上面输入的内容会随它一起保留。保留之前，页面只在显示在屏幕上时记住你输入的内容；一旦保留，它就会永久保存它的数据（见[页面保存的数据](#the-data-a-page-keeps)）。

你也可以一开始就请智能体做一个要保留的东西：“给我做一个能在手机上用的习惯打卡表”“一份搬家清单”。智能体会自己把它保存到资料库中（会话属于某个项目时，就放在那个项目里），对话中会显示一张卡片，上面有：

- 页面的标题和 **已保存到资料库 · 版本 2**（这条回复保存的版本：智能体在一条回复中多次保存同一个页面时，回复里只有一张卡片，显示最后保存的版本，较早的几次保存列在它的步骤中）；
- **打开**（在资料库中打开它）、**编辑**（铅笔图标）和 **全屏**；
- 页面本身，可以直接使用，带有它的数据，就在卡片中。

在宽屏上，当页面显示在对话旁边时，卡片会保持小尺寸，它的页面则在旁边打开。

之后（在后面的回复中，或由你自己）保存了更新的版本时，较早的卡片只保留标题这一行，并显示 **已有更新的版本**：**打开** 会显示最新版本。智能体在同一条回复中再次保存页面时，它的卡片会继续显示之前的版本，并显示 **正在保存新版本…**。如果页面被删除了，卡片也会说明。

智能体也可以修改你保留的页面：说“给我的习惯打卡表加一列备注”，智能体就会保存它的一个新版本。你的数据会保留，较早的版本也保持原样。

## 找到你的页面

侧边栏中的 **资料库**（[/library](/library)）存放着你保留、制作和发布的所有内容。在手机上，先用 **菜单**（≡）打开侧边栏。你也可以在搜索框（Ctrl+K，Mac 上为 ⌘K）中按标题或说明查找页面、图片或视频。

卡片旁边是资料库的各个位置，每个都显示它有多少项内容（在较窄的窗口或手机上，是卡片上方的一排标签）：

- **所有内容**：你保留的一切。有项目时，每个项目的东西会放在它的名称下面，最近改动的项目排在前面，每个都带有 **查看全部**，用来只显示那个项目；然后是 **不在任何项目中** 的内容。
- 你的 **项目**，每个都显示它的标志和名称：智能体在它的会话中保存的东西，以及你放进去的东西（见[按项目整理](#sort-it-by-project)）。名称旁边的 **打开项目** 会转到这个项目自己的页面。
- **不在任何项目中**：不属于任何项目的内容（有了项目之后才会出现）。
- **已发布**：你发布的页面和文件夹，以及它们的链接（见[查看和取消发布你发布的内容](#see-and-unpublish-what-you-published)）。[打开“已发布”](/library?tab=published)。

还没有项目时，位置下方会有一段说明，讲项目能为资料库做什么，并提供前往 **项目** 的入口。

每一项都是一张卡片，上面有它的图片（页面是打开时的样子，带着它的数据；幻灯片显示它的第一张；文档、电子表格或 LaTeX 显示第一页或第一个工作表的顶部；图片或视频显示一张缩略图；在图片生成之前，显示它的首字母）、图片上标着它的类型（**幻灯片**、**文档**、**电子表格**、**LaTeX** 或 **图片**；视频显示它的时长）、它的标题和上次更改的时间；已发布的会显示一个地球图标，保存了数据的会显示一个圆柱图标。在“所有内容”中搜索时，每张卡片还会标出它所在的项目。点击卡片即可打开它。卡片的 **更多**（⋯）中有 **编辑**（幻灯片则是 **放映**）、**编辑标题和说明**、**移到项目**、**移到文件夹**（它所在的位置有文件夹时）、**创建副本**（不带数据的副本）、**转换为**（由智能体用它做出幻灯片、文档或页面：见[按类型用 AI 制作](#made-with-ai-from-a-kind)）、**下载为**（见[导出为文件](#export-to-a-file)）和 **删除**；图片或视频的则有 **用它开始会话**、**移到项目**、**移到文件夹**、**下载**、**重新撰写标题和说明** 和 **删除**。

项目以及 **不在任何项目中** 也可以包含文件夹：它们以图块的形式排在最前面，在卡片之前（见[文件夹](#folders)）。

卡片上方：

- **按名称或说明搜索** 找出与你输入的字词相符的东西，最相符的排在最前：按它们的标题和说明（见[说明](#descriptions)），开启了[按含义搜索](/guide/memory#search-by-meaning)时还按它们的含义，所以“里斯本之行的花费”能找到一份名叫“出门四天”、说明里讲的正是这件事的电子表格。标题或说明中有你输入的字词的东西，在你输入时就会立刻显示出来。它会查找整个位置，包括其中的每个文件夹，这时每张卡片都会标出它所在的文件夹。
- 旁边的按钮可以按 **最近更改**、**名称** 或 **最新创建** 排序。应用会在这台设备上记住排序方式。
- 一个位置里有不止一种内容时，**全部**、**页面**、**幻灯片**、**文档**、**电子表格**、**LaTeX**、**图片** 和 **视频** 可以一次只显示一种。[只显示图片](/library?kind=image)。

还没有保留任何内容时，资料库会显示“你的资料库是空的”，说明拖放到这里的文件会被添加进来，并提供 **新建页面** 和 **新建幻灯片**。

## 说明

除了标题，资料库中的每样东西都有一段说明：两三句话，最多 100 个词，讲它是什么、用来做什么。资料库的搜索、搜索框和智能体既按标题、也按说明来查找东西，所以你可以按一样东西讲的是什么来找它，而不必记得它叫什么。

- **智能体会写说明**：它们为你保存的每样东西都附有一段说明，东西本身变了，就再写一段新的。
- **你添加的文件**（拖放到资料库的、用 **上传文件** 选的、在 **新增** 中打开的，或者随导入的文件夹进来的）和你从对话中 **保留的页面**，由辅助模型来写说明（见[设置 → 模型](/settings?s=models)）：它在后台读每一个的开头，一次读一个。保密会话保存的东西，只会由在这台电脑上运行的辅助模型来读。你用 **新增** 做的空页面没有说明，直到你自己写一段。
- **图片、视频和声音** 的说明和标题一起撰写（见[标题和说明](#titles-and-descriptions)）。
- **自己写或修改**：在卡片的 **更多**（⋯）中选 **编辑标题和说明**，或者点击你打开的东西的标题。把指针停在卡片的标题上，就会显示它的说明。

## 按项目整理

资料库中的每样东西都属于一个项目，或者不属于任何项目（见[项目和知识库](/guide/projects)）：

- 智能体保存的东西（页面、幻灯片、文档、电子表格、LaTeX 文档），在会话属于某个项目时，会放进那个项目。
- 你自己保留的东西（页面上的 **保留**、图片、视频或声音下方的 **保存到资料库**），在你有项目时会先问放在哪里，本会话所在的项目排在最前；没有项目时，会直接保留。
- 资料库右上角的 **新增** 会把新东西放进你正在看的项目；也可以在 **放在项目中** 下面选别的项目（见[制作页面](#make-a-page)）。
- 你拖放到资料库的文件，会放进你在位置列表中拖放到的那个项目，或者你正在看的那个项目（见[添加你自己的文件](#add-files-of-yours)）。
- 要移动某样东西，在它的卡片上或它自己的页面上打开 **更多**（⋯）→ **移到项目**，然后选一个项目或 **不放在项目中**。提示“已移到 Thesis”表示完成。移动不会改变别的：它的版本、数据和地址都保持不变。

项目自己的页面也会在 **概览** 和 **资料库** 标签页中显示它在资料库中的东西（见[项目自己的页面](/guide/projects#a-projects-own-page)）。删除项目时，它在资料库中的东西会保留下来，不再属于任何项目。

## 文件夹

文件夹用来整理一个位置里的东西：一个项目，或者 **不在任何项目中**（没有项目时，就是整个资料库）。文件夹里可以放它所在位置的东西和其他文件夹。一个位置会先显示它的文件夹，以图块的形式显示每个文件夹里有多少项内容（什么都没有时显示 **空文件夹**），然后是位于这个位置顶层的东西。

- **新建文件夹**：点资料库右上角的 **新增**，然后选 **文件夹**，再给它起个名字（[也可以从搜索框用“新建文件夹”](/library?new=folder)）。它会建在你所在的地方：当前打开的文件夹里，或者这个位置的顶层（从 **所有内容** 新建时，建在 **不在任何项目中**）。
- **打开文件夹**：点击它的图块。卡片上方是返回的路径，先是位置，然后是一层层文件夹，直到当前打开的这个（**Thesis › Chapter drafts**）：点击其中一段就能回到那里。在文件夹中点 **新增**，做出的东西会放在这个文件夹里。
- **把东西放进文件夹**：卡片的 **更多**（⋯）→ **移到文件夹** 会以树的形式列出这个位置的文件夹，位置的顶层排在最前；当前所在的地方带有勾。在电脑上，你也可以把卡片拖到文件夹的图块上，或者拖到返回路径中的某一段上。单独打开的页面，它的 **更多**（⋯）里也有 **移到文件夹**。
- **文件夹的更多**（⋯）：**重命名**、**移到文件夹**（移进另一个文件夹，或者移到位置的顶层；在电脑上，也可以把它的图块拖到另一个文件夹上）、**移到项目**（连同其中的一切）和 **删除**。删除文件夹不会删除它里面的任何东西：里面的东西会往上移一层，移到它原来所在的文件夹，或者移到顶层。
- **在项目之间**：移到另一个项目的东西会离开它原来的文件夹；放进另一个项目的文件夹里的东西，会移到那个项目。删除项目时，它的文件夹以及其中的东西都会保留下来，不再属于任何项目。

卡片上方的 **按名称或说明搜索** 和各种类型（**文档**、**LaTeX**……）会查找整个位置，包括其中的每个文件夹，每张卡片都会标出它所在的文件夹。

### 导入文件夹

**新增 → 导入文件夹** 会把应用所在电脑上的一个文件夹导入资料库（[也可以从搜索框用“导入文件夹”](/library?new=import)）。在文件夹输入框里选择它（它从你的主文件夹开始：从它列出的文件夹中选择，或者输入一个路径），然后点 **导入**。它会放进当前打开的文件夹；如果你在一个位置的顶层，则放进 **放在项目中** 下面选的项目。

- **LaTeX 项目**，也就是装着一份完整文档的文件夹（一个带有 `\documentclass` 和 `\begin{document}` 的 .tex 文件），会作为一份 LaTeX 文档导入，它的所有文件和图片都放在各自的文件夹中（见[文件树](#the-files-tree)）。一份文档除主文件外最多包含 50 个文件、总共 4 MB 的文本和 200 张图片：超出时，文档用到的文件优先，放不下的会说明。PDF 图片会变成 PNG 图片；EPS 和 SVG 图片会被略去。
- **其他任何文件夹** 会作为资料库中的一个同名文件夹导入，其中的文档（Word、Markdown、文本和网页）、电子表格（Excel、OpenDocument、CSV 和 TSV）、笔记本和完整的 LaTeX 文档会成为其中的东西，导入方式和在 **新增** 中打开这个文件时一样，它的子文件夹会成为其中的文件夹（其中的 LaTeX 项目作为一份文档导入；没有可导入内容的文件夹不会生成文件夹）。一次最多导入 300 项。

之后它会说明导入了什么、略去了什么，以及原因：图片、视频和声音、PDF 和旧的 PowerPoint 文件（.ppt）会留在原文件夹中（在“文件”中打开它们；要把对话中的图片保留在这里，请保存它），PowerPoint 文件（.pptx）会作为幻灯片导入，LaTeX 文档的某个部分只会随它的文档一起导入。**显示列表** 会列出每个被略去的文件，**打开** 会打开导入的内容。原文件夹本身保持不变：资料库保存的是副本。

## 资料库中的图片和视频

智能体为你生成的图片、视频和声音放在会话的文件夹里（见[请智能体生成图片或修改图片](/guide/documents-voice#ask-for-a-picture-or-have-one-changed)、[请智能体生成视频](/guide/documents-voice#ask-for-a-video)和[请智能体生成音乐、语音或声音](/guide/documents-voice#ask-for-music-a-voice-or-a-sound)）。要保留其中一个，就点击对话中它下方的 **保存到资料库**（有项目时，先选它放进哪个项目）：一份副本会放进你的资料库，即使会话的文件夹被清理了，它也会留在那里；模型会为它撰写标题和说明（见[标题和说明](#titles-and-descriptions)）。之后按钮会显示 **已在你的资料库中**，点击它就会在资料库中打开它。

你自己的图片、视频和声音也可以这样放进来：把它们拖放到资料库，或者使用 **上传文件**（见[添加你自己的文件](#add-files-of-yours)）。

它们和资料库中的其他东西显示在一起；卡片上方的 **图片**、**视频** 和 **音频** 可以分别只显示其中一种（[只显示视频](/library?kind=video)，[只显示音频](/library?kind=audio)）。每个都是一张卡片，上面有它的缩略图和标题（正在撰写时显示“正在撰写标题…”）；视频的卡片会在缩略图上显示它的时长；声音的卡片会显示它的波形，旁边有一个圆形按钮可以直接在这里播放，以及它的时长。点击卡片即可打开它（见[打开图片、视频或声音](#open-an-image-a-video-or-a-sound)）。卡片的 **更多**（⋯）中有 **用它开始会话**、**移到项目**、**下载**、**重新撰写标题和说明** 和 **删除**；删除会把它从你的资料库中移除（当初保存它的那个文件如果还在，会保留下来）。

资料库可以保存图片（PNG、JPEG、WebP、GIF、AVIF）、视频（MP4、WebM、MOV）和声音（MP3、WAV、M4A、AAC、OGG、OPUS、FLAC），每个最大 1 GB，总共最多 5000 个，存放在应用的数据文件夹中。智能体可以使用你保存的东西：说“用我资料库里那张小船的图片做一张生日贺卡”，智能体就会去那里找到它。

## 标题和说明

你保存的每张图片或每段视频都会得到标题和说明，由一个能看图片的模型撰写：它会看这张图片；如果是视频，就看从开头到结尾均匀取出、拼在一张图上的十帧画面，并把生成它时所用的文字作为提示。声音它听不到：声音的标题和说明根据生成它所用的内容来写（它的描述、歌词或台本，以及生成它的模型），声音本身不会发给模型。标题和说明用应用的语言撰写。

在 **[设置 → 功能 → 图片、视频和音频 → 资料库中的标题和说明](/settings?s=images&find=Captions%20in%20the%20Library)** 中选择模型：

- **运行位置**：**自动**（有 OpenRouter 密钥时，用 OpenRouter 上的一个便宜模型，首选 Google 的 Gemini Flash Lite；否则通过你的 Claude Code 登录使用 Claude Haiku）、**OpenRouter**（它目录中任何能看图片的模型：**选择模型** 会打开列表供你搜索）、**Claude**（**Claude Haiku**、**Claude Sonnet** 或 **Claude Opus**，通过你的 Claude Code 登录使用）、**Ollama** 或 **vLLM**（这台电脑上能看图片的模型，来自[设置 → 模型](/settings?s=models)），或者 **你的端点**（兼容 OpenAI 的端点上的模型；无法知道它能不能看图片，所以会显示“可能看不了图片”）。
- **模型**：对于 Claude、Ollama、vLLM 和你的端点，选择要用的模型。
- 它们下方会显示“撰写者：”和正在使用的模型，或者说明为什么现在没有模型能撰写它们。

通过 OpenRouter 撰写它们，花费不到一美分；用这台电脑上的模型则不花钱。截取视频的帧需要应用所在的电脑上装有 ffmpeg；没有它时，这一部分会说明，视频的标题和说明会取自生成它们时所用的文字，显示时也没有缩略图。ffmpeg 还会读出声音的时长和波形；没有它时，声音的卡片上会显示一个图标。

没有模型能撰写时，它们会取自生成这张图片、这段视频或这段声音时所用的文字（或者它的文件名），它的页面上会说明这一点，并提供 **重试** 和 **选择模型**。你也可以自己写：在它的页面上使用 **编辑标题和说明**。你写的内容会一直保留，直到你选择 **重新撰写**。

## 打开图片、视频或声音

图片、视频或声音会在资料库中它自己的位置打开。顶部的横条包含返回箭头（**资料库中的图片**、**资料库中的视频** 或 **资料库中的音频**）、它的标题（下方是“一张图片”“一段视频”或“音频”及其时长）、**用它开始会话**（打开开始页，它已在消息框中，新会话会随你的第一条消息收到它：写下你想用它做什么，比如“用这张图做一张海报”，然后发送）、**编辑**（图片或视频，在它的编辑器中：见[编辑图片和视频](#edit-pictures-and-videos)）、**下载** 和 **更多**（⋯）：**编辑标题和说明**、**重新撰写**、**打开它的会话**（保存它时所在的对话）、**移到项目**（旁边显示它所在的项目）和 **删除**。

下面是图片（点击可查看原始大小），或者可以播放的视频或声音（声音在一个大播放器里，它的波形就是进度条，旁边是时间和语速），旁边（在手机上则在下方）是：

- 它的标题和说明，带一个用来修改它们的铅笔图标，以及撰写它们的模型；
- **所用模型**（生成它的模型）、**生成依据**（它是根据什么文字生成的）、它的 **大小**、**长度**（视频、声音）、**文件** 大小，以及 **已保留** 的时间；
- 对于视频，还有 **撰写说明时依据的帧画面**：模型看过的那十帧画面（点击可查看原始大小）；
- 对于声音，还有 **演唱或朗读的内容**：歌曲的歌词，或者朗读出来的文字。

## 制作页面

资料库右上角的 **新增**（或者[搜索框中的 **新建页面**](/library?new=1)）可以制作一个你自己的页面：在它的菜单中选 **网页**、**幻灯片**、**文档**、**电子表格**、**LaTeX 文档** 或 **笔记本**（菜单里还有 **文件夹** 和 **导入文件夹**：见[文件夹](#folders)）。在打开的页面顶部，你仍然可以换成要做别的：**页面**、**幻灯片**（见[制作幻灯片](#make-slides)）、**文档**、**电子表格**、**LaTeX** 或 **笔记本**（见[文档](#documents)、[电子表格](#spreadsheets)、[LaTeX 文档](#latex-documents)和[笔记本](#notebooks)）。在文件夹中，你做出的东西会放进这个文件夹。如果是页面：

1. 选择从哪里开始：**空白页**（一个标题和几句话，可以在此基础上继续完善）、**备注**（一个用来写东西的页面，边写边保存）、**清单**（要做的事，做完一件勾掉一件）或 **跟踪表**（每天一个数字，并画出最近 30 天的数据）。
2. 如果愿意，可以修改 **名称**。有项目时，旁边的 **放在项目中** 会说明它放在哪里（你正在看的项目，或 **不放在项目中**），点击它可以换一个。然后点击 **创建**。空白页会在 **编辑** 中打开；其他的打开后就可以直接使用。

幻灯片从你选的外观开始，也可以用 **打开 PowerPoint 文件** 从你自己的文件开始（.pptx；见[制作幻灯片](#make-slides)）。文档、电子表格或 LaTeX 文档一开始只有名称，内容是空的（LaTeX 文档则带有一篇简短的文章，供你在此基础上写），也可以从你自己的文件开始：**打开 Word 或文本文件**（.docx、.md、.txt 或 .html）、**打开 Excel 或 CSV 文件**（.xlsx、.ods、.csv 或 .tsv）或 **打开 .tex 或 .zip 文件**（一个 LaTeX 文件，或者打包成 .zip 的整个项目）。笔记本一开始以它的名称作标题，外加一个空的代码单元格，也可以用 **打开笔记本（.ipynb）** 开始。文件会变成一个对应类型的页面；文件本身保持原样。要修改文件本身，请在“文件”中打开它：它会在同一个编辑器中打开，并保存回这个文件（见[编辑 Word、Excel、CSV 和 LaTeX 文件](/guide/files-git#edit-word-excel-csv-and-latex-files)）。

或者在 **或者描述一下，让智能体来做** 下面描述你想要的东西（“一周徒步的行李清单”“两个人的月度预算”），然后点击 **询问**：开始页会带着你的话打开，由智能体来制作它并保存到你的资料库中（在 **放在项目中** 选了项目时，开始页也会选好那个项目，让它放进那里）。

对于页面、幻灯片、文档或电子表格，旁边的 **选择类型** 可以从智能体擅长制作的类型中选一种（习惯打卡、融资路演、求职信、预算……：[按类型用 AI 制作](#made-with-ai-from-a-kind)）。它会以一个标签的形式显示在输入框中（✕ 可以去掉它）；愿意的话说说它是关于什么的，然后点 **用 AI 制作**，就会立刻开始一个会话来制作它；或者点 **新建空白的**，自己来做。

左下角的 **上传文件** 则用来添加你自己的文件，选多少都可以，每个文件都会变成它相应的样子，放进 **放在项目中** 下面选的项目（见[添加你自己的文件](#add-files-of-yours)）。

## 添加你自己的文件

把电脑上的文件拖放到资料库的任何地方，就能添加它们：想放多少都可以，也可以是整个文件夹（添加其中的文件）。文件在资料库上方时，它们要去的位置会显示轮廓，并有一行字说明：“松开即可添加到‘Thesis’”，或者“松开即可添加到资料库，不放在项目中”。

- 拖放到卡片旁边位置列表中的某个项目上（在手机上是它的标签），它们会放进那个项目；拖放到 **所有内容**、**不在任何项目中** 或 **已发布** 上，则不放进任何项目。
- 拖放到卡片上，它们会放进你打开的那个位置：你正在看的项目；在 **所有内容** 和 **不在任何项目中** 中则不放进任何项目。
- 你也可以把它们拖放到[项目页面](/projects)上某个项目的卡片上，或者拖放到某个项目自己的页面上它在资料库中的内容上（它的 **概览** 和 **资料库** 标签页）：它们会放进那个项目。
- 没有鼠标时，在手机或平板上：**上传文件** 会打开设备的文件选择器，可以一次选好几个。它在左下角的 **新增** 中（文件会放进 **放在项目中** 下面选的项目）；打开某个项目的位置时，项目名称旁边也有（在手机上，是 **按名称或说明搜索** 旁边的上传按钮），用于那个项目。

每个文件都会变成它相应的样子：

- Word 文件（.docx）、Markdown、文本或网页（.html）会变成文档，Excel、OpenDocument 或 CSV 文件变成电子表格，PowerPoint 文件（.pptx）变成幻灯片，.tex 文件或 LaTeX 项目的 .zip 变成 LaTeX 文档，Jupyter 笔记本（.ipynb）变成笔记本，和 **新增** 从文件制作它们一样（见[制作页面](#make-a-page)）：最大 30 MB。
- 图片、视频或声音会保存在资料库中，并为它撰写标题和说明（见[标题和说明](#titles-and-descriptions)）：最大 1 GB。资料库里已有的（同一个文件，无论叫什么名字）不会保存两次：会显示“已在你的资料库中”。
- 其他文件（PDF、不是 LaTeX 项目的 .zip、大到无法变成文档的文件）拖放到项目上时，会放进项目的文件夹，在项目的 **文件** 标签页和“文件”页面中都能看到；拖放的是文件夹时，文件原来所在的那些文件夹也会一起带过来；那里已被占用的名字后面会加上“copy”。不在项目中时，资料库无法保存它，并会说明资料库能保存哪些文件。

右下角的一个小托盘会显示每个文件的进度：已经传了多少，然后是它变成了什么、放进了哪个项目，或者用平实的话说明它为什么没能添加。在那里点击一个文件，就能打开它变成的东西：一份文档、一张图片，或者“文件”中项目文件夹里的那个文件。**取消** 会停止还没添加的文件，某个文件旁边的 ✕ 只停止那一个。每次只传几个文件，其他的排队等候；大文件会分段传输，所以网络慢或者断开时也不会丢失。你打开传进来的东西时，托盘会留在那里，在任何页面上都是如此；文件全部添加完之后，✕ 会关闭它。

### 在桌面应用中，拖放会移动文件

在桌面应用中（Mac、Windows 和 Linux），从访达、资源管理器或你的文件管理器拖进来的文件会移动到资料库中，就像在文件夹之间移动文件那样，而不是复制；提示会显示“松开即可把它们移到‘Thesis’”。

- 图片、视频或声音会移到资料库自己的文件夹中，拖放到项目上的其他文件则移到项目的文件夹中。
- 资料库把 Word、Excel、PowerPoint、LaTeX 或笔记本文件做成页面之后，原处的文件就不再需要了：它会进入应用的废纸篓，在那里用 **放回原处** 可以把它放回去（见[删除和放回](/guide/files-git#delete-and-put-back)）。如果页面没能保留它的全部内容（Word 文件的脚注、Excel 文件的图表、读取同一文件夹中其他文件的 LaTeX 文件、显示同一文件夹中图片的 Markdown 文件），文件会留在原处，托盘会说明页面缺少什么。
- 项目文件夹、应用自己的文件夹或系统文件夹中的文件会留在原处，改为添加一份副本。资料库里已有的图片或视频也会留在原处，不会添加任何东西。
- 你拖放的文件夹，会在其中所有文件都移走之后被移除。

托盘会说明每个文件去了哪里，以及原文件在哪里。在浏览器中，以及在桌面应用中查看另一台机器的页面时（见[在一个应用里使用其他机器](/guide/devices#use-other-machines-from-one-app)），文件会被上传，原文件留在原处。

## 打开页面

页面会在应用内全屏打开，在资料库中有它自己的位置。顶部的横条包含：

- 返回箭头（**资料库**），回到列表；
- 页面的标题，下方是它的版本、上次更改的时间和它保存了多少数据。点击标题可以修改它的标题和说明；
- **使用**、**编辑** 和 **代码**，以及 **电脑**、**平板** 和 **手机** 尺寸（见[自己修改页面](#change-a-page-yourself)）；
- **版本**（时钟图标）：它较早的版本（见[回到早先的版本](#go-back-to-an-earlier-version)）；
- **导出**：把页面导出为 PDF、Word 文档或网页（见[导出为文件](#export-to-a-file)）；
- **分享**：供你的手机使用的独立地址，以及把它发布到一个链接（见[在手机上使用页面](#use-a-page-on-your-phone)和[发布页面](#publish-a-page)）；
- **询问**：智能体在你眼前修改这个页面（见[请智能体来修改](#change-it-by-asking-an-agent)）；
- **更多**（⋯）：**它保存的内容**（见[页面保存的数据](#the-data-a-page-keeps)）、**编辑标题和说明**、**创建副本**、**移到项目**（有项目时出现；旁边显示它所在的项目）、**在新标签页中打开**（在它的独立地址打开页面）和 **删除**。

在手机上，**使用**、**编辑** 和 **代码** 显示为图标，**分享** 显示为分享图标，**询问** 显示为闪光图标，**导出** 则在 **更多**（⋯）中，名为 **下载为**，尺寸按钮不显示（手机本身就是那个尺寸）。

幻灯片、文档、电子表格、LaTeX 文档和笔记本则会在各自的编辑器中打开，顶部是同样的横条（见[编辑幻灯片](#edit-slides)、[文档](#documents)、[电子表格](#spreadsheets)、[LaTeX 文档](#latex-documents)和[笔记本](#notebooks)）。

用应用现成的外观做的页面会跟随应用的浅色或深色主题。

## 导出为文件

打开的页面、幻灯片、文档、电子表格、LaTeX 文档或笔记本顶部的 **导出**（在手机上是 **更多**（⋯）→ **下载为**），或者列表中卡片的 **更多**（⋯）里的 **下载为**，会把它保存为文件，放进你的下载文件夹：

- 页面：**PDF**（就是它显示的样子，用 A4 纸，在通常用 Letter 的地方则用 Letter，带着它的数据和背景）、**Word 文档（.docx）**（它的标题、段落、列表、表格和链接都变成 Word 自己的格式，图表和图片作为图片，输入框里的值作为文字）或 **网页（.html）**（任何浏览器都能打开的文件，带着它的现成外观）；
- 幻灯片：**PowerPoint（.pptx）**（每张幻灯片上的文本框、形状、图片（保留裁剪和颜色调整）、表格（包括合并的单元格）、图表和组合都仍然可以编辑，图标作为放大也保持清晰的图片，公式作为图片，来自你设备的视频作为 PowerPoint 自己的视频（YouTube 和 Vimeo 的视频则作为链接到它的预览图），还带着幻灯片编号和页脚、主题的颜色和字体、演讲者备注、评论（作为 PowerPoint 自己的批注，只包括未解决的）、切换效果（平滑切换用 PowerPoint 自己的平滑切换）和动画，可以直接用 PowerPoint、Keynote 或 Google Slides 打开）。它在 PowerPoint 中看起来和这里一样：你的幻灯片用到的字体会放进文件里（按 PowerPoint 保存字体的方式压缩），所以即使电脑上一种都没有，也能显示出来；文字的换行、间距和缩放都和这里一样；图表的布局和这里一样，它们的数字放在旁边的一个工作簿里，供 PowerPoint 的 **编辑数据** 使用；编辑器的每种版式都是 PowerPoint 的一种版式，所以 **新建幻灯片** 会提供它们，**重置幻灯片** 会把幻灯片的各个部分放回原位；页脚放在 PowerPoint 自己的页脚框中（**插入 → 页眉和页脚** 可以打开或关闭它们）；你的参考线也是 PowerPoint 的参考线；面向网页的幻灯片中的互动部分和效果会变成图片，或者 PowerPoint 中最接近的效果，下载之后会有一条提示说明改了什么（见[面向网页或面向 PowerPoint 的幻灯片](#slides-for-the-web-or-for-powerpoint)）；**PDF**（每页一张幻灯片）、**幻灯片图片 (.png)**（一个 zip 压缩包，每张幻灯片一张图片，尺寸是幻灯片的两倍；在编辑器中用 **幻灯片 → 将这张幻灯片另存为图片** 可以只保存你所在的那一张）或 **网页（.html）**（把整个放映装进一个小文件，可以在任何浏览器中放映，字体、图片、3D 模型和来自你设备的视频都装在里面，视频每个最多 40 MB，测验、代码和效果也都能用）；
- 文档：**Word 文档（.docx）**（按编辑器的排版来排，所以 Word 的分页和你这里的一样：它的字体会像 Word 保存字体那样放进文件里，所以 Windows 或 Mac 上的 Word 即使没有安装这些字体也能显示它们（网页版 Word 会显示与每种字体最接近的 Office 字体，Inter 则显示为 Arial）；它的样式、列表、清单、引用、代码、标注框、表格、图片和说明文字、公式、目录、页眉和页脚、链接、评论和建议都变成 Word 自己的格式，可以用 Word、Google Docs 或 LibreOffice 打开）、**PDF**（用它自己的纸张大小和页边距，保留它的分页）、**Markdown（.md）**（它的文字、标题、列表、表格和链接，以纯文本形式）或 **网页（.html）**；
- 电子表格：**Excel（.xlsx）**（每个工作表，带着它的公式、格式、和这里一样的列宽和行高、冻结的行、筛选、决定单元格外观和可填内容的规则（列表中带颜色的选项保持它们的颜色）、合并的单元格、备注、评论和图表，打印方式也和应用打印时一样：名称在顶部，每页都有标题行，表格较宽时横向打印；Excel 无法携带字体，所以它的单元格使用 Arial，这是与应用字体最接近的 Office 字体；可以用 Excel、Google Sheets 或 LibreOffice 打开）、**CSV（.csv）**（第一个工作表中显示的值）或 **PDF**（每个工作表一张表格）；
- LaTeX 文档：**PDF**（由 LaTeX 排版，和预览中显示的一样）、**LaTeX 源文件（.tex）**（主文件）、**LaTeX 项目（.zip）**（所有文件和图片，可以拿到别处排版，比如 Overleaf）或 **arXiv 投稿包（.zip）**（先为 arXiv 准备好：见[arXiv 投稿包](/guide/researchers#the-arxiv-package)）；
- 笔记本：**Jupyter 笔记本（.ipynb）**（它的单元格连同输出，可用于 Jupyter、VS Code 或 Colab）、**Python 脚本（.py）**（它的代码，文字作为注释，每个单元格以 `# %%` 标出）、**PDF**（单元格和输出，和显示的一样）或 **网页（.html）**。

正在查看的旧版本会按它本身的样子导出。页面的 PDF 和 Word 文件、幻灯片、文档和电子表格的 PDF，以及幻灯片的图片，都由应用用来截图的那个浏览器生成；如果没有这个浏览器，应用会告诉你，可以在 **设置 → 浏览器** 中下载一个（[浏览器设置](/settings?s=browser)）。这时幻灯片仍然可以从你自己的浏览器打印成 PDF：在它的打印窗口中选择 **另存为 PDF**。LaTeX 文档的 PDF 由应用所在电脑上的 LaTeX 生成（见 [LaTeX 文档](#latex-documents)）。

智能体也可以导出：说“把这套幻灯片作为 PowerPoint 文件发给我”“把报告页面做成 PDF”或“把预算做成 Excel 文件给我”，智能体就会在对话中把文件交给你。

## 幻灯片

幻灯片也保存在资料库中，有自己的版本、列表中的图片和独立的地址。你可以像在 PowerPoint、Google Slides、Keynote 或 Canva 中那样编辑它们，在里面放测验、3D、可以运行的代码和网页效果（或者只用 PowerPoint 有的功能），用 AI 生成和修改图片，参考设计灵感，配上旁白；可以全屏放映或用演示者视图放映，用手机当遥控器；可以把它们保存为一个小小的网页、一个 PowerPoint 文件或 PDF；还可以把你自己的 PowerPoint 文件作为幻灯片打开。

### 制作幻灯片

- **问智能体**：“给我做 8 张讲我们第一年的幻灯片，加一张销售额图表”“把这份报告改成一个带演讲者备注的简短演讲”。智能体会在资料库中做好这套幻灯片，并在对话中以放映的形式显示它；在旁边，你可以看着它一张一张地做出来。
- 在资料库中点 **新建页面**，然后在顶部选 **幻灯片**（[也可以从搜索框用“新建幻灯片”](/library?new=slides)）：选一种外观（**日光**、**午夜**、**余烬**、**森林**、**海洋**、**暗黑**、**繁花** 或 **石板**，然后是你保存的主题：见[我的主题和标志](#charts-from-a-spreadsheet-slides-from-another-deck-and-my-themes)）、**宽屏（16:9）** 或 **标准（4:3）**、一个名称，然后点 **创建**。也可以在 **或者描述一下，让智能体来做** 下面描述这场演讲，或者用 **选择类型**（融资路演、讲课、论文答辩……：[按类型用 AI 制作](#made-with-ai-from-a-kind)）。新建的幻灯片面向网页（[面向网页或面向 PowerPoint 的幻灯片](#slides-for-the-web-or-for-powerpoint)）。
- **从 PowerPoint 文件开始**：**新建页面** → **幻灯片** → **打开 PowerPoint 文件**（.pptx，也可以是 .ppsx、.potx 或 .pptm），或者在“文件”中、或在智能体交给你的文件上，对这样的文件使用 **保存到资料库**。它的幻灯片会变成你可以在这里编辑的幻灯片：每个部分都在原来的位置，文本框和形状里的文字保持原来的样子（字体、字号、颜色、项目符号、编号和间距，按它们的版式和母版设定），还有图片（保留裁剪和颜色调整）、表格、图表（根据其中保存的数字）、组合、连接符、文件里的视频、PowerPoint 的公式（转为 LaTeX）、背景、演讲者备注、评论及其回复、页脚、切换效果和简单的动画；文件的颜色和字体会成为这套幻灯片的主题。打开时会说明哪些内容没能带过来：编辑器里没有类似形状的，会作为方框带进来；自由绘制的图形会变成它们的图片；SmartArt 和嵌入对象会被略去；文件里带着的字体，只有你的电脑上装有时才会显示。在这里制作并导出的文件，打开后会原样变回原来的幻灯片（面向网页的幻灯片则按它的 PowerPoint 文件里的样子变回来）。PowerPoint 97–2003 文件（.ppt）无法打开：请先在 PowerPoint 或 LibreOffice 中把它们另存为 .pptx。从 PowerPoint 文件打开的幻灯片面向 PowerPoint。

### 编辑幻灯片

幻灯片编辑器的左边是幻灯片列表（在手机上或较窄的窗口中，则横排在幻灯片下方），中间是正在编辑的幻灯片，上方是菜单和工具栏，右边是侧边面板（在手机上是幻灯片下方的抽屉），幻灯片下方是 **演讲者备注**。

- **菜单**：**编辑**、**视图**、**插入**、**格式**、**排列**、**幻灯片** 和 **工具**，在这套幻灯片的名称旁边（在手机上或较窄的窗口中，它们都收在一个 **菜单** 按钮里）。每个操作旁边都写着它的按键，和你选中的内容不相符的操作会变成灰色。**搜索菜单**（菜单末尾的放大镜，或 Alt+/）可以按文字找到任何操作：输入“裁剪”或“页脚”，然后按 Enter。
- **幻灯片列表**：点击一张来编辑它；拖动一张可以调整它的顺序；它的 **更多**（⋯，或者右键点击）中有 **在后面添加新幻灯片**、**在后面添加 AI 生成的幻灯片**（[按类型用 AI 制作](#made-with-ai-from-a-kind)）、**创建副本**、**放映时跳过它**（跳过的幻灯片会变暗，并显示一只划掉的眼睛）和 **删除**。列表下方的 **添加幻灯片** 会在末尾加一张。
- **工具栏**：**撤销** 和 **重做**；**新幻灯片**（最上面是 **AI 生成的幻灯片**，然后是一种版式：**标题**、**标题和文本**、**两栏**、**区块**、**文本和图片**、**图片**、**大数字**、**卡片**、**步骤**、**引用**、**图表**、**表格**、**仅标题**、**结束页** 或 **空白**，最下面是 **从另一套幻灯片导入**）；然后是 **文本框**、**形状**（二十种，从矩形到箭头、星形和对话气泡）、**图片**（**来自这台设备**、**来自网址**、**免费照片**、**用 AI 生成**、**绘图（SVG）** 或 **二维码**）、**线条或箭头**（以及连接符）、**表格** 和 **图表**、**格式刷**，以及 **设计灵感**（灯泡图标：[设计灵感和其他幻灯片助手](#design-ideas-and-other-helpers-for-slides)）。选中文字时，还有 **改写**、字体、字号、**粗体**、**斜体**、**下划线**、**删除线**、颜色、对齐、**项目符号列表**、**编号列表**、缩进和 **链接**。其余的在 **格式 → 文本** 里：**上标**、**下标**、**放大文字** 和 **缩小文字**（Ctrl+Shift+. 和 Ctrl+Shift+,）、**清除格式**。
- **选中**：点击一个部分就能选中它；按住 Shift 点击可以再加选一个，在幻灯片上拖过则会选中碰到的所有部分。拖动一个部分可以移动它：它会吸附到幻灯片的中线和边缘以及其他部分，并显示粉色参考线（按住 Alt 可以自由移动，按住 Shift 可以保持水平或垂直）。拖动它的手柄可以调整大小（图片、图标、公式或组合会保持比例；按住 Shift 则反过来），拖动它上方的圆形手柄可以旋转它（按住 Shift：每次 15°）。线条的两端各有一个手柄。
- **组合**：选中两个或更多部分，按 Ctrl+G（或者用 **排列 → 组合起来**、侧边面板中的同一按钮，或右键菜单）；它们会作为一个整体被选中、移动、调整大小、旋转、复制和添加动画。双击组合可以选中其中的一个部分（单独修改它的文字或颜色）；按 Esc 或点击组合外面，就会离开这个组合。Ctrl+Shift+G（**排列 → 取消分组**）会让它们重新成为各自独立的部分。
- **修改文字**：双击文字（或者选中这个部分后按 Enter）。Tab 和 Shift+Tab 可以把一个要点降一级或升一级；按 Esc 或点击别处即可结束。双击图片可以裁剪它，双击表格的单元格可以在里面输入（Enter 往下走，Tab 跳到下一个单元格），双击图表可以修改它的数字，双击公式可以修改它的 LaTeX，双击图标可以换一个。
- **查找和替换**：Ctrl+F 会在每张幻灯片上（文本框、形状、组合、表格、图表的标题、标签和系列名称、公式的 LaTeX、测验、测验得分和代码）和演讲者备注里查找文字，标出每一处匹配，并转到它所在的幻灯片（图表或公式会被选中，它的数字或 LaTeX 显示在侧边面板中）；Enter 和 Shift+Enter 转到下一处和上一处。**区分大小写**、**全字匹配** 和 **正则表达式** 在查找的文字旁边。Ctrl+H（**编辑 → 查找和替换**）还会加上 **替换** 和 **全部替换**；替换上去的文字会沿用被替换文字的样式，撤销会一次撤回整个 **全部替换**。
- **格式刷**（工具栏中的刷子，或 **格式 → 格式刷**）会把选中部分的外观（填充、边框、圆角、阴影，以及文字的样式）复制到你接下来点击的部分上；双击刷子可以连续刷给多个部分，完成后按 Esc。**编辑 → 复制外观**（Ctrl+Shift+C）和 **粘贴外观**（Ctrl+Shift+V）用按键做同样的事。
- **缩放**：**视图 → 缩放**（**适应幻灯片**，或者 50% 到 400%）、Ctrl+Alt+= 和 Ctrl+Alt+-、在鼠标指针处按住 Ctrl 滚动（或在触控板上双指捏合），或者在触摸屏上用两根手指。幻灯片比可用的空间大时可以滚动；点击右下角的百分比会让幻灯片重新适应窗口。
- **按键**：Ctrl+C、Ctrl+X、Ctrl+V 和 Ctrl+D 可以复制、剪切、粘贴部分和创建部分的副本（在应用打开期间，也能粘贴到另一套幻灯片里）；Delete 删除它们；方向键可以微移它们（按住 Shift 则每次移 10）；Ctrl+↑ 和 Ctrl+↓ 把它们上移一层或下移一层（按住 Shift 则置于顶层或底层）；Ctrl+A 全选；Ctrl+M 添加一张幻灯片；没有选中任何部分时，方向键会转到下一张或上一张幻灯片。粘贴或拖放到幻灯片上的图片会成为它的一个部分，拖放到上面的视频文件也一样，粘贴的 YouTube 或 Vimeo 地址会变成一个视频。右键点击某个部分或幻灯片，也有这些操作，还有 **就此问智能体**。Ctrl+/（**工具 → 键盘快捷键**）会列出所有按键。
- **所有幻灯片**（**放映** 旁边的网格按钮）会一次显示所有幻灯片，你可以拖动它们调整顺序；点击一张即可编辑它。

和页面一样，更改在你点击底部横条中的 **保存**（Ctrl+S）之前都不会保存；**放弃** 会丢掉它们。每次保存都是一个版本。

### 对齐与排列

- **参考线**：**视图 → 标尺和参考线** 会在幻灯片的上边和左边显示标尺（放大时，滚动过程中标尺会一直留在视图的上边和左边）。从标尺里拖出一条参考线（从上面的标尺往下拖，从左边的标尺往右拖）；移动部分时，它们会吸附到参考线上。拖动参考线可以移动它，把它拖回标尺上就会去掉它；**视图 → 参考线** 可以在正中加一条横向或纵向的参考线，或者去掉所有参考线。参考线会随这套幻灯片一起保存。
- **连接符**：**插入 → 线条或箭头 → 直线连接符** 或 **肘形连接符**（工具栏的线条按钮下也有）：选中了两个部分时，它会把它们连起来，否则它会单独出现在幻灯片中间。把一端拖到某个部分附近，会显示这个部分各条边的中点，把它放到其中一个上，就会粘在那里；粘住的一端会在它的部分移动、缩放或旋转时跟着走，肘形连接符会保持它的直角。把一端拖开就能松开它（按住 Alt：不粘住）；单独移动连接符时，它会和留在原地的部分分开。侧边面板中的 **走线** 可以把任何线条设为 **直线** 或 **肘形**。在 PowerPoint 中，它们是 PowerPoint 自己的连接符，仍然连着各自的形状。
- **网格**：**视图 → 显示网格** 会画出网格，**对齐到网格** 会让部分吸附到网格线上，**网格大小** 设定网格线之间的距离（10 到 80 像素）。
- **等间距**：当你在一排（或一列）其他部分旁边拖动一个部分时，它会吸附到与其他部分之间的间距相等的位置，或者两个部分正中间的位置，粉色标记会显示这些间距和它们的宽度。
- **排列**：**置于顶层**、**上移一层**、**下移一层**、**置于底层**；**在幻灯片上**（靠某条边或居中；在组合中则是在组合之内），或者在选中多个部分时 **对齐排列** 和均匀分布；**旋转**，向右或向左转 90°，以及翻转图片；**锁定位置**。

### 图片、图标、公式和视频

- **裁剪图片**：双击它（或者用侧边面板中的 **裁剪**、**格式 → 裁剪图片**，或右键菜单）。整张图片都会显示出来，框外的部分变暗：拖动框的边和角，或者拖动框下面的图片；按 Enter 保留裁剪，按 Esc 让图片保持原样。侧边面板中的 **取消裁剪** 会重新显示整张图片。
- **图片的颜色**：侧边面板的 **颜色** 中有 **亮度**、**对比度**、**饱和度**、**模糊**、**透明度** 和 **黑白**；**重置** 会把它们恢复原样。
- **编辑图片**（在 **格式** 菜单、右键菜单或侧边面板中）会在图片编辑器中打开这张图片，你在那里保存的东西会替换它（[编辑图片和视频](#edit-pictures-and-videos)）；**用 AI 修改** 可以用文字说明来修改它、去掉它的背景或擦除它的一部分（[用 AI 生成图片、绘图、数据图和视频](#make-pictures-drawings-plots-and-videos-with-ai)）。
- **图片的形状和外框**：在侧边面板的 **图片** 中，**形状** 会把它放进一个形状里（**矩形**、**圆角**、**圆形**、**椭圆**、**拱形**、**不规则圆形**、**花朵**、**六边形**、**星形**、**心形**、**三角形**、**菱形**、**五边形** 或 **八边形**），**外框** 会把它放进一个外框里（**拍立得**、**手机**、**笔记本电脑** 或 **浏览器窗口**，用来把截图显示在设备里），图片会适配到里面。PowerPoint 会把形状保留为图片的轮廓，把外框保留为它周围的形状。
- **插入 → 图片 → 免费照片**：采用开放许可的照片（Openverse：Flickr、Wikimedia Commons、博物馆等），可以免费使用和修改。搜索（愿意的话，只看 **宽**、**竖屏** 或 **正方形（1:1）** 的），选一张，然后点 **使用**（或者双击它）：它会放到幻灯片上，以它的标题作为描述，署名写在演讲者备注里；在许可协议要求署名时，旁边还会有一行小小的说明文字（**照片署名**，一个你可以移动的部分）。文档和页面中也有免费照片。
- **插入 → 图片 → 二维码**：把一个链接（或任何文字）做成手机摄像头能扫的二维码，颜色由你选（**方块颜色**、**底色**，底色可以是透明的）；以后可以在它的侧边面板中修改。在 PowerPoint 中，它是一张二维码的图片。
- **插入 → 图标或表情符号**：大约两千个图标，按英文名称查找（“arrow”“chart”“user”“rocket”），另一个标签页里是表情符号，会作为文字放到幻灯片上。图标在任何大小下都保持清晰；侧边面板可以给它设一种颜色（也可以用主题的颜色，这样它会跟着主题一起变）和 **线宽**，**换一个图标** 会用另一个图标替换它。
- **插入 → 公式**：用 LaTeX 写的公式（`\frac{a}{b}`、`x^{2}`、`\sum_{i=1}^{n}`），在它的框允许的范围内尽量画大，使用主题的文字颜色。在侧边面板的 **公式** 栏中修改它（下面的按钮可以插入分数、根号、求和、积分、矩阵或符号），还可以设置它的颜色和对齐方式。
- **插入 → 视频**：**来自 YouTube 或 Vimeo**（视频的地址；幻灯片上会显示它的预览图，随这套幻灯片一起保存）、**来自这台设备**（不超过 200 MB 的 MP4、MOV 或 WebM 文件，随这套幻灯片一起保存，幻灯片上显示它的第一帧；也可以把文件拖放到幻灯片上）或 **用 AI 生成**（[用 AI 生成图片、绘图、数据图和视频](#make-pictures-drawings-plots-and-videos-with-ai)）。在放映、演示者视图和观众窗口中，点击它就会播放；侧边面板可以设置它的 **开始于** 和 **结束于**（Vimeo 的播放器会一直播放到结尾），以及是否 **幻灯片出现时播放**、**静音** 或 **从头再次播放**。**编辑视频**（在 **格式** 菜单、右键菜单或侧边面板中）会在视频编辑器中打开来自你设备的视频（[编辑图片和视频](#edit-pictures-and-videos)）。在这套幻灯片自己的页面上（通过它的地址打开，或者已发布时），来自你设备的视频也会在那里播放，来自 YouTube 或 Vimeo 的视频则会在它的网站上打开。
- **表格**：双击一个单元格，再按住 Shift 点击另一个，就能选中它们之间的单元格；这时侧边面板中有 **合并单元格**（它们的文字会合到第一个单元格里）、**取消合并单元格** 和 **单元格填充**。
- **幻灯片 → 幻灯片编号和页脚**（或者 **幻灯片** 标签中的 **页脚**）：在每张幻灯片底部显示 **幻灯片编号**、**日期**（**放映当天**，或者选 **写作**，按你输入的样子显示）和 **页脚** 文字，愿意的话可以选 **标题幻灯片上不显示**；某一张不要的话，用 **这张幻灯片上不显示**（**幻灯片** 标签中也有）。

### 来自电子表格的图表、来自另一套幻灯片的幻灯片，以及我的主题

- **插入 → 图表 → 来自电子表格**：从你的资料库中选一份电子表格（**按名称查找**），选它的 **工作表**、**其中的表格** 之一或 **单元格**（“A1:D7”）、**系列**（**按列** 或 **按行**）和 **类型**（柱形图、条形图、折线图、面积图、饼图或环形图），然后点 **插入图表**。图表会记住它来自哪里：电子表格改了之后，它侧边面板中的 **从电子表格更新** 会重新画出它（每个系列保持它的颜色）。最多 80 个标签和 12 个系列。
- **从另一套幻灯片导入**（**插入 → 新幻灯片**，或者工具栏 **新幻灯片** 的最下面）：从你的资料库中选一套幻灯片，勾选其中的幻灯片（**全选** 或 **全不选**），然后点 **插入幻灯片**：它们会连同图片、视频和演讲者备注一起插在正在查看的幻灯片后面（评论留在原来那套幻灯片里），并适配这套幻灯片的比例。两套幻灯片外观不同时，选 **保留原外观** 或 **使用这套幻灯片的主题**；保留了原外观的幻灯片会在 **主题** 标签顶部说明这一点，并提供 **使用这套幻灯片的主题**。
- **我的主题**（**主题** 标签）：**保存为我的主题** 会把这套幻灯片的颜色和字体（以及它的标志）以一个名称保存下来。它们显示在每套幻灯片 **主题** 标签的 **我的主题** 下面（点击一个即可使用；它的 **更多** 里有 **重命名** 和 **删除**），也会出现在 **新建页面 → 幻灯片** 的外观中。最多 60 个。
- **每张幻灯片都显示标志**（**主题** 标签中的 **标志**）：把你设备上的一张图片放在每张幻灯片的一个 **角落**，**大小** 由你设定，愿意的话可以选 **标题幻灯片上不显示**；放映时和 PowerPoint 文件中也有。

### 幻灯片上的评论

选中幻灯片上的某个部分（什么都不选则针对整张幻灯片），然后用 **插入 → 评论**（Ctrl+Alt+M，或者右键菜单中的 **评论**），写下评论，再点 **评论**（或按 Ctrl+Enter）。这个部分的右上角会出现一个小标记（只在编辑器中显示：放映、这套幻灯片自己的页面和它导出的文件中都不会出现）；点击它就能阅读评论。侧边面板中的 **评论**（**主题** 后面的对话气泡，上面显示有多少条未解决）按顺序列出每张幻灯片上的评论，每条都排在它所在的部分下面：点击一条，就会转到它所在的幻灯片并选中那个部分。每条评论都有 **回复**、**解决**（对勾），以及 **更多** 菜单（⋯）里的 **编辑** 和 **删除**；**显示已解决的评论** 会把已解决的评论重新显示出来，并带有 **重新打开**。评论会随幻灯片一起保存（**保存**）；删除某个部分后，它的评论会留在它所在的幻灯片上。

智能体也会读这些评论，以及每条评论所在的部分。评论顶部的 **让智能体回复这些评论** 会请它按评论的要求修改，并逐条回复；它的回复显示为 **智能体**。在 PowerPoint 文件中，未解决的评论会成为 PowerPoint 自己的批注，连同回复一起。

### 格式、动画、幻灯片和主题

侧边面板有四个标签页：

- **格式**：选中的部分。它的名称、**锁定位置**、**删除** 和 **就此问智能体**；对于文字，有它们的 **字体**、**大小**、颜色、在 **上下位置** 中的位置、**行距**（以及段后间距）、**内** 的留白，以及 **放不下时缩小文字**；它的 **填充**（一种颜色、无，或者渐变到另一种颜色）、**边框**（颜色、宽度、虚线、圆角）和 **阴影**；形状的种类；图片的 **适配**（**填充**、**完整** 或 **拉伸**）、**裁剪**、**形状**、**外框**、圆角、翻转、边框、描述和 **颜色**，以及 **编辑图片** 和 **用 AI 修改**；线条的颜色、宽度、样式，以及它的 **起点** 和 **终点**（箭头或圆点）；表格的行、列、标题行、隔行底色、颜色和合并的单元格；图表的 **类型**（柱形图、条形图、折线图、面积图、饼图或环形图）、标题、图例、数值、堆积、网格线，以及它的 **数据**：每个标签一行，每个系列一列，还有 **用它生成数据图**（用它的数字画出任何一种数据图，由智能体写的代码来画，放在它的位置上），对于来自电子表格的图表，还有 **从电子表格更新**；图标的颜色和线宽；公式的 LaTeX；视频的地址和播放方式；二维码的文字和颜色；互动部分自己的设置（[互动部分](#interactive-parts)）；组合的 **取消分组**。在面向网页的幻灯片中，文字还有 **文字效果**，填充还有 **毛玻璃效果**，每个部分还有 **指针悬停时**（[网页效果](#effects-for-the-web)）。每个取色器都有主题的颜色、**其他颜色**，在浏览器支持时（Chrome 和 Edge）还有 **从屏幕上取色**。然后是 **位置和大小**（以幻灯片的像素计，横向 1280；组合中的部分显示的是它在幻灯片上的位置，你在这里输入的位置或旋转也会按幻灯片来移动它）、旋转和透明度、**在幻灯片上**（靠某条边或居中）和前后顺序，以及 **链接**（一个地址，或者用 #3 表示第 3 张幻灯片）。选中多个部分时：可以 **组合起来**、对齐排列、均匀分布，或者删除它们。
- **动画**：最上面的 **为每张幻灯片添加动画** 会一次给整套幻灯片加上动画（[设计灵感和其他幻灯片助手](#design-ideas-and-other-helpers-for-slides)）。或者选中一个部分，然后在 **进入**（**出现**、**淡化**、**飞行**、**浮动**、**缩放**、**擦除**、**弹跳**）、**强调**（**脉冲**、**旋转**、**放大**、**抖动**）或 **退出** 下选一种效果；面向网页的幻灯片还有更多效果，以及单击某个部分时开始的动画（[网页效果](#effects-for-the-web)）。**动画顺序** 列出这张幻灯片上的动画，以及每个动画在第几次点击时开始；展开一个就可以修改它的效果、它从哪一侧进入（**从**）或向哪一侧退出（**到**）、何时 **开始**（**单击时**、**与上一个同时** 或 **在上一个之后**）、持续多久、开始前等多久，对于文字还有 **逐段**。箭头可以把它提前或推后；**播放** 会按放映时的样子播放这张幻灯片。组合会作为一个整体添加动画。
- **幻灯片**：它的 **背景**（主题的背景、一种颜色、渐变到另一种颜色的颜色，或者 **添加图片**，可以在文字后面调暗，也可以用 **用 AI 生成** 为它生成一张；在面向网页的幻灯片中还可以是 **动态背景** 或 **背景视频**），以及 **应用到所有幻灯片**；它出现时的 **切换效果**（**淡化**、**推入**、**擦除**、**覆盖**、**缩放**、**分割** 或 **平滑**，在面向网页的幻灯片中还有 **立方体**、**翻转**、**溶解**、**圆形**、**百叶窗** 和 **故障**；从哪一侧开始、持续多久），在 **换片** 中选 **单击时** 还是过几秒后 **自动** 换到下一张，以及 **应用到所有幻灯片**；它的 **旁白**（[为放映配旁白、排练和录制](#narrate-rehearse-and-record-a-slideshow)）；**跳过这张幻灯片**；还有 **页脚**。**平滑** 会让这张幻灯片和上一张共有的部分从原来的位置滑到新的位置，途中跟着变大、旋转和变色，其余的部分则淡入淡出：复制一张幻灯片，移动、缩放、旋转它的部分或给它们换颜色，再给这张副本设置 **平滑**。一个部分是从另一个复制来的，或者两者的名称、文字或图片相同，它们就算作同一个部分。
- **主题**：一种 **现成** 的外观、**我的主题** 中的一个，或者这套幻灯片自己的 **颜色**（背景、文本、标题、次要文字、强调色、强调色上的文字、柔和填充，以及六种图表颜色）和用于标题和正文的 **字体**；**标志**；**幻灯片比例**；以及 **面向**（**网页** 或 **PowerPoint**：[面向网页或面向 PowerPoint 的幻灯片](#slides-for-the-web-or-for-powerpoint)），在面向网页的幻灯片中还有 **放映时显示进度条**。用主题颜色上色的部分会跟着主题一起变。

### 放映

**放映** 会从你所在的幻灯片开始全屏放映；它旁边的箭头里有 **从头开始**、**从这张幻灯片开始** 和 **演示者视图（带备注）**（**幻灯片** 菜单中也有），以及 **播放旁白**、**与教练一起排练** 和 **录制视频**（**幻灯片 → 更多放映方式** 中也有：见[为放映配旁白、排练和录制](#narrate-rehearse-and-record-a-slideshow)）。放映时：

- 点击、→、↓、空格键、N 或 Page Down 继续（先是下一个动画，然后是下一张幻灯片）；←、↑、Backspace 或 Page Up 返回；在触摸屏上，滑动或轻点；
- 输入幻灯片的编号再按 Enter 就会跳到那一张；Home 和 End 跳到第一张和最后一张；
- **B**（或 .）让屏幕变黑，**W**（或 ,）让屏幕变白（再按一次恢复）；**G** 显示所有幻灯片，方便跳到其中一张；
- **L** 把鼠标指针变成激光笔；**P** 是一支可以在幻灯片上画画的笔，有几种颜色可选，**E** 擦掉笔画的内容（换到别的幻灯片时，画的内容会消失）；**C** 会在幻灯片底部显示你所说的话的实时字幕，前提是浏览器能把语音转成文字（Chrome 和 Edge 可以）；
- **V** 会通过摄像头把你显示在幻灯片上方的一个圆形气泡里：把它拖到你想放的地方，**缩小** 或 **放大** 它，选择是否镜像，再按一次 V 就会隐藏它（这个浏览器会记住它的位置）；**K** 暂停和继续播放旁白（[为放映配旁白、排练和录制](#narrate-rehearse-and-record-a-slideshow)）；
- 点击视频就会播放；自定义代码、网页和 3D 会运行，测验会接收你的回答（[互动部分](#interactive-parts)）；
- 移动鼠标指针时，左下角会显示控制按钮，其中有激光笔、笔和字幕的按钮，**你的摄像头 (V)**、**手机遥控器**（用手机当遥控器：[为放映配旁白、排练和录制](#narrate-rehearse-and-record-a-slideshow)），在有旁白的放映中还有 **暂停旁白 (K)**；按 Esc 结束放映（如果正在用激光笔或笔，则先把它们收起来）。

**演示者视图** 会显示当前幻灯片、下一张（或者提示这一张还有内容）、演讲者备注（用 − 和 + 调小或调大）、可以暂停和重新开始的计时器、当前时间，以及 **返回** 和 **下一个**；它的幻灯片上也有放映的控制按钮、你的摄像头和手机遥控器。**打开观众窗口** 会在单独的窗口中打开放映：把它拖到另一块屏幕或投影仪上，双击即可全屏。它跟随演示者视图，演示者视图也跟随它；激光笔、笔画、字幕以及黑屏或白屏也会显示在里面，如果你在那里打开摄像头，它也会显示你的摄像头画面。

幻灯片也可以在手机上从它的独立地址放映，或者从已发布的链接放映；导出的 **网页** 能在任何浏览器中播放它们（[面向网页或面向 PowerPoint 的幻灯片](#slides-for-the-web-or-for-powerpoint)），公式在任何地方都能显示，即使没有联网也一样。

## 面向网页或面向 PowerPoint 的幻灯片

一套幻灯片要么面向网页，要么面向 PowerPoint。面向网页时，它有 PowerPoint 的全部功能，此外还有只有浏览器才能做到的：[互动部分](#interactive-parts)（可以运行的代码、网页、测验和 3D）和[效果](#effects-for-the-web)（单击某个部分时开始的动画、逐个出现的文字、立方体和故障切换效果、动态背景）。面向 PowerPoint 时，它只使用 PowerPoint 有的功能，所以它的 PowerPoint 文件在 PowerPoint、Keynote 和 Google Slides 中打开都一样。新建的幻灯片面向网页；从 PowerPoint 文件打开的幻灯片面向 PowerPoint。

- **主题 → 面向**：**网页**（全部功能：自定义代码、测验、3D、网页效果）或 **PowerPoint**（只用 PowerPoint 有的功能）。**工具 → 兼容 PowerPoint**（一个勾选项）的作用相同。
- 让一套幻灯片兼容 PowerPoint 之前会先问你：**要让它兼容 PowerPoint 吗？**，并逐张幻灯片列出 PowerPoint 保留不了的东西以及它们会变成什么（“自定义代码变成它的图片”“测验变成文本框，答案放进演讲者备注”“效果变成 PowerPoint 中最接近的效果”“动态背景被去掉”……），或者“其中没有任何内容会改变。”**改为兼容** 会进行转换，撤销可以把它们找回来；之后选 **面向 → 网页** 会重新用回网页格式，但那些东西不会回来。幻灯片兼容 PowerPoint 期间，网页格式的部分和效果都不会提供，只有 **插入 → 互动** 例外，它会先问 **使用网页格式吗？**：插入这个部分后，这套幻灯片就不再兼容 PowerPoint。**插入 → 代码** 在两种格式中都能用。
- **面向网页的幻灯片保存为 PowerPoint**（**导出 → PowerPoint（.pptx）**）：只有文件会变。动态的部分会变成它运行时的截图（由应用的浏览器截取：[设置 → 浏览器](/settings?s=browser)），否则就用它自己的图片；测验变成文本框，答案放进演讲者备注；测验得分变成文字；代码变成带颜色的文字；幻灯片背后的视频变成放在最底层的视频；每个效果和切换效果都变成 PowerPoint 自己最接近的那一个（立方体变成推入，打字机效果变成出现）；动态背景、文字效果、毛玻璃效果、指针效果和进度条会被去掉。下载之后会有一条提示说明改了什么（“为适配 PowerPoint：……”）。完全没有图片的动态部分不会放进文件。
- **把幻灯片导出为网页**（**导出 → 网页（.html）**）：一个能在任何浏览器中自行放映的小文件，字体、图片、3D 模型和来自你设备的视频都装在里面（每个最多 40 MB；更大的视频只显示它的封面），所以不联网也能用，只有 3D（它从网上加载代码）、幻灯片上的网页、YouTube 和 Vimeo 视频，以及自定义代码要加载的东西除外。它不会播放旁白。智能体也能把它交给你（“把这套幻灯片作为一个网页发给我”）。

## 互动部分

面向网页的幻灯片可以放一些能做事的部分，来自 **插入 → 互动**（**自定义代码**、**网页**、**测验**、**测验得分** 和 **3D**）和 **插入 → 代码**。每一种的设置都在侧边面板的 **格式** 标签中：

- **代码**（面向 PowerPoint 的幻灯片中也有）：像在编辑器中那样带颜色显示的代码：它的 **语言**（Python、JavaScript、SQL 等许多语言，或者 **纯文本**）、**颜色**（**深色**、**浅色** 或 **跟随幻灯片**）、**大小**、**行号** 和 **高亮行**（“2-4,7”：这些行会突出显示，其余的变暗）。在 PowerPoint 中是带颜色的文字。
- **自定义代码**：一个它自己的小网页（HTML，带有它的 CSS 和 JavaScript），在一个不能访问其他任何东西的框架中运行；这套幻灯片的颜色和字体就是它的 CSS 变量。可以从一个 **现成** 的开始（**计数按钮**、**倒计时器**、**弹跳的小球**、**增长的柱形**），在面板中自己写，或者 **请智能体来写**。**放映时可点击操作** 会让它在放映时接收点击和按键（否则点击它会继续到下一步）；**它的图片** 会在它无法运行的地方（PowerPoint 中、打印的纸上）以及它开始运行之前显示。它可以从 jsDelivr、unpkg 或 cdnjs 加载库。在面向网页的幻灯片中生成的数据图也会做成这样一个部分，会动，也会响应指针（[用 AI 生成图片、绘图、数据图和视频](#make-pictures-drawings-plots-and-videos-with-ai)）。
- **网页**（在 **网页** 中填一个地址，或者网站提供的嵌入代码，然后点 **添加**）：放在幻灯片上的一个网站，放映时可以点击操作；YouTube 和 Vimeo 的地址会变成它们的播放器。只有允许别人在框架中显示自己的网站才会出现（有些需要你登录的网站可能无法使用），这台电脑或你所在网络的地址会被拒绝。它有 **圆角** 和 **它的图片**。
- **测验**：一个 **问题** 和它的选项（最多 8 个；**添加选项** 会加一个），每个选项都有 **选中时显示的话**。标出正确的那一个，或者勾选 **多个正确答案** 后标出所有正确的（这时大家要按 **核对答案**），或者一个都不标，当作投票（会显示大家选了什么，不计分）；回答之后会显示 **答完后显示** 里写的话。它的外观：**备选** 排成一列或两两并排，以及字体、大小和颜色。放映时，选了之后会立刻显示对错。
- **测验得分**：显示目前得分的文字，来自放映中回答过的这套幻灯片里的测验：{right}、{total} 和 {percent} 会变成数字（“你答对了 {right} 题，共 {total} 题”）。
- **3D**：一个形状（**立方体**、**球体**、**圆环**、**扭结**、**圆锥**、**圆柱**、**宝石**，或者你自己的 **词语**）或者你自己的模型（一个 .glb 文件，或者连同它的文件一起选择的 .gltf，最大 12 MB，来自 3D 应用或提供免费模型的网站），它的 **材质**（模型用 **它自己的**，以及 **哑光**、**光泽**、**金属**、**玻璃**、**线框** 或 **卡通**）、**颜色**、**光照**（**影棚灯光**、**柔光**、**戏剧光** 或 **霓虹灯光**）和 **背后** 是什么；在 **旋转** 下面，有 **自动**（每秒转多少度）、**观众可以旋转和缩放它**、**视角** 和 **远近**。

自定义代码、网页和 3D 会在放映、演示者视图、观众窗口和这套幻灯片自己的网页中运行。在编辑器中，它们显示自己的图片：选中一个，按它下面的 **运行**（或 **格式 → 在这里运行**）就可以在那里试一试，然后按 **停止**。在 PowerPoint 中、打印的纸上和幻灯片的图片中，它们也显示自己的图片。3D 从 jsDelivr 加载代码，所以需要联网；保密会话的放映不会从网上加载任何东西，所以在那里不依赖其他东西的自定义代码可以运行，但网页和 3D 不行。

## 网页效果

面向网页的幻灯片有比 PowerPoint 更多的效果（面向 PowerPoint 的幻灯片不提供这些效果）：

- **动画** 标签：在 PowerPoint 的效果之后还有更多效果：进入有 **模糊**、**升起**、**落入**、**翻转**、**摇摆**、**滚入**、**弹入**、**打字机字体** 和 **数字递增**（用于文字），以及 **画出线条**（用于线条、形状和图标）；强调有 **发光**、**扭动**、**心跳**、**果冻摇晃**、**闪烁**、**上下浮动** 和 **彩纸迸发**；退出有 **模糊**、**落入**、**翻转**、**滚入** 和 **弹入**。动画还有：
  - **开始** → **单击某个部分时**：在列表中选择 **触发部分**，或者 **在幻灯片上选择**（按 Esc 停止）。放映时，每次点击那个部分都会再播放一次，和幻灯片本身的点击分开计算；用这种方式进入的部分在那之前会一直隐藏。
  - **运动方式**：**平滑**、**带回弹**、**带弹跳**、**匀速** 或 **干脆利落**。
  - **词语**（文本框和形状）：**一次全部**、**逐词** 或 **逐字**。
  - **循环播放**（强调效果）：它会一直持续下去（列表中显示 ∞）。
- **幻灯片** 标签：切换效果 **立方体**、**翻转**、**溶解**、**圆形**、**百叶窗** 和 **故障**；**动态背景**（**北极光**、**飘浮微粒**、**星空**、**波浪**、**网格渐变**、**流动网格** 或 **柔和光斑**，用主题的颜色，放映时会动，在这里则是静止的，在你的设备要求减少动态效果时会动得慢一些）；以及 **背景视频**（**来自这台设备**，或者 **选用这套幻灯片中的视频**），在幻灯片背后静音、循环播放（**调暗** 会让它暗一些）。
- **格式** 标签：文字的 **文字效果**（**颜色渐变**、**发光**、**空心字**、**Neon** 或 **长投影**）、填充的 **毛玻璃效果**（部分下面的东西会模糊地透出来），以及任何部分的 **指针悬停时**（**上浮**、**放大**、**发光** 或 **向指针倾斜**，在电脑上放映时生效）。
- **主题** 标签：**放映时显示进度条**，一条横跨顶部、用强调色显示的细线。

PowerPoint 文件则会改用它自己最接近的效果（[面向网页或面向 PowerPoint 的幻灯片](#slides-for-the-web-or-for-powerpoint)）。

## 设计灵感和其他幻灯片助手

- **设计灵感**（工具栏中的灯泡图标，或 **幻灯片 → 设计灵感**）：为你所在的幻灯片提供三种排版方式，用的是它自己的文字、图片和数字（不编造任何内容，也不遗漏任何内容），显示在侧边面板的位置上。它们是适合这张幻灯片内容的那些：**图片作背景**、**大数字**、**左右各半**、**卡片**、**步骤**、**一句话**、**侧边色带**、**按列**、**图片网格**、**图表优先**、**引用**、**杂志版式** 或 **居中**。点击一个就会把它用到幻灯片上（它会标上“在幻灯片上”，撤销可以把它去掉）；**更多灵感** 会画出别的方案。它们由[辅助模型](/settings?s=models&find=Helper%20model)来画（由应用选择时显示“作者：Claude”）。
- **改写**（选中文本框或形状时，文字工具栏中的第一个按钮）：由辅助模型把选中的文字（或者全部文字）改得 **更短**、**更长**、**更简单**、**更正式**、**更亲切**，或者 **修正拼写和语法**、**翻译成**（十二种语言，或 **其他语言**）或 **说说想怎么改写**，样式保持不变；撤销可以把它撤回。文档中也有。
- **为每张幻灯片添加动画**（在 **动画** 标签的最上面）：**柔和**（东西淡入，平静而快速）、**活泼**（东西升起和滑入，线条画出来，数字递增）或 **醒目**（东西落下、弹出和翻转着进入，幻灯片像立方体一样转动；在面向 PowerPoint 的幻灯片中则是缩放），会替换掉幻灯片原有的动画，每张幻灯片的标题最先出现；一个小预览会播放效果（**再播放一次**）。**去掉所有动画** 会去掉动画和切换效果。撤销可以撤回其中任何一种。
- **检查辅助功能**（**工具**）：**辅助功能检查** 面板会逐张幻灯片列出可能妨碍别人看到、读到或跟上这些幻灯片的问题，并随着你的修改随时更新：没有标题的幻灯片（其中某一行可以作为标题时，有 **设为标题**）、在其他文字之后才读到的标题（**先读标题**）、没有描述的图片（**用 AI 描述**：由为你资料库图片撰写说明的那个模型，用幻灯片的语言写一段描述）、与背后的内容反差太小的文字（**改用反差明显的颜色**，或者在幻灯片的背景图片上时，**调暗图片，调亮文字**）、小于 18 px 的文字（**改成 18 px**）、自动播放且带声音的视频（**静音播放**）以及没有标题行的表格（**加上标题行**）。**前往** 会选中那个部分；有好几处可以修正时，一个按钮就能把能修正的全部修正（**修正可以修正的 3 处**）。跳过的幻灯片不会检查。
- **翻译幻灯片**（**工具**）：选一种语言，或者 **其他语言**（输入语言名称，然后点 **问智能体**），**询问** 面板就会打开，里面已写好针对所有幻灯片的请求（它们的文字、图表、测验和演讲者备注，保持原有版式）。发送之后，智能体会在你眼前翻译它们。

## 为放映配旁白、排练和录制

- **旁白**（在 **幻灯片** 标签中）：给这张幻灯片配一段声音。**录制**：你照着演讲者备注朗读，同时录下来（一个音量表会显示它听到了你的声音；然后选 **重来** 或 **保留**）；**用 AI 生成** 会让语音模型通过 OpenRouter 朗读备注（没有备注时朗读幻灯片上的文字），用你选的或描述的声音，会先显示价格；**用 AI 为每张幻灯片配旁白** 会一次给所有幻灯片配好。旁白可以在那里播放，垃圾桶图标会删除它。语音模型就是[设置 → 图片、视频和音频](/settings?s=images&find=Voice%20and%20sound%20model)中的那一个；没有 OpenRouter 密钥时，对话框会向你要一个。
- **播放旁白**（**放映** 旁边的箭头，或 **幻灯片 → 更多放映方式**）：从头开始放映，每张幻灯片出现时播放它的旁白，它的动画分布在旁白播放的过程中，旁白结束时就换到下一张（没有旁白的幻灯片会等你）。**K** 暂停和继续播放。PowerPoint 文件会保留每张幻灯片的旁白，在幻灯片出现时播放。
- **与教练一起排练**：像平时那样讲一遍，愿意的话设定 **目标时长**。教练会给每张幻灯片计时；在浏览器能把语音转成文字的地方（Chrome、Edge 和 Safari 可以），它还会显示你每分钟讲多少个词的语速，在你讲得太快或太慢时轻轻提示，统计你的口头禅（它认识英语、中文、希腊语、西班牙语、法语和德语的口头禅），并在你照着幻灯片念时告诉你。然后是 **排练情况**：你用的时间与目标的对比、你的语速、你的口头禅、你照着念的、讲得太赶或停留太久的幻灯片，以及每张幻灯片用的时间。**使用这些计时** 会让每张幻灯片在排练时所用的时间过后自动换到下一张。
- **录制视频**（在电脑上）：全屏放映，在你演讲时录下来，带着你的声音、圆形气泡里的摄像头画面，愿意的话还有旁白。浏览器会问要分享什么（选这个标签页），倒计时之后开始录制，顶部有 **暂停** 和 **停止**。然后选 **保存到资料库** 或 **下载**（浏览器支持时为 MP4，否则为 WebM）。
- **你的摄像头**（**V**，或者控制按钮中的 **你的摄像头 (V)**）：在放映、演示者视图或观众窗口中，把你显示在幻灯片上方的一个圆形气泡里（[放映](#present)）。
- **手机遥控器**（在放映和演示者视图的控制按钮中）：一个给手机扫的二维码，手机登录了应用时会打开遥控器：**返回** 和 **下一个**（带有下一张幻灯片的图片）、**转到某张幻灯片**、**黑屏**、你的备注（**缩小备注文字**、**放大备注文字**）和一个计时器。手机必须能访问应用的地址：一个它能打开的地址，而不是这台电脑自己的地址（localhost）。

旁白随这套幻灯片一起保存（每段最多 40 MB）。这套幻灯片自己的网页不会播放它们，打开 PowerPoint 文件时，文件中的旁白也不会带进来。

## 文档

文档也保存在资料库中，有自己的版本、列表中的图片和独立的地址。你可以像在 Word 或 Google Docs 中那样撰写和编辑它们，页面和它的纸张一样大，并把它们保存为 Word、PDF 或 Markdown 文件。

- **新建**：问智能体（“根据这份招聘启事给我写一封求职信”“把我的笔记整理成一份两页的报告”），或者在资料库中点 **新建页面**，然后选 **文档**（[也可以从搜索框用“新建文档”](/library?new=doc)）：可以是空白的，可以用 **打开 Word 或文本文件** 从你的文件开始，也可以是智能体擅长制作的某种类型（简历、会议纪要、资助申请书：[按类型用 AI 制作](#made-with-ai-from-a-kind)）。
- **菜单**，在页面上方：**编辑**（**撤销**、**重做**、**剪切**、**复制**、**粘贴**、**粘贴为纯文本**、**全选**、**查找** 和 **查找和替换**）、**视图**（**大纲**、**评论**、**显示已解决的评论**、**编辑或建议**、从 50% 到 200% 的 **缩放** 或 **适应宽度**、**检查拼写** 和 **输入时显示字数**）、**插入**、**格式** 和 **工具**（**字数统计**、**键盘快捷键**、**接受所有建议**、**拒绝所有建议**、**格式刷** 和 **打印**）。菜单末尾的放大镜（或 Alt+/）是 **搜索菜单**：输入你想做的事（“字数”“合并”），然后按 Enter。在手机上和较窄的窗口中，菜单都收在一个按钮里。
- **工具栏** 里是最常用的：**撤销** 和 **重做**；段落样式（**正文**、**标题**、**副标题**、**标题 1** 到 **标题 4**、**引用**、**代码** 或 **标注框**）；字体和字号；**粗体**、**斜体** 和 **下划线**；**文字颜色** 和 **突出显示**；**链接**（Ctrl+K）；**评论**；**改写**；**格式刷**；**对齐方式**；**项目符号**、**编号** 和 **清单**；在表格中时还有 **表格**。在手机上，工具栏可以左右滑动。
- **改写**（选中一些文字时）会请[辅助模型](/settings?s=models&find=Helper%20model)改写它们：**更短**、**更长**、**更简单**、**更正式**、**更亲切**、**修正拼写和语法**、**翻译成**（十二种语言，或 **其他语言**）或 **说说想怎么改写**（“写得更激动人心一些”）。新的文字保留原来文字的样式，撤销可以把它们撤回；在提出修改建议期间，改写的结果会作为一条建议。
- **插入**：**AI 生成的章节**（智能体写出一种它会写的章节，比如执行摘要：[按类型用 AI 制作](#made-with-ai-from-a-kind)）、**图片**（**来自这台设备的图片**、**来自网络的图片**、**免费照片**、**AI 生成的图片** 或 **绘图（SVG）**：见[用 AI 生成图片、绘图、数据图和视频](#make-pictures-drawings-plots-and-videos-with-ai)）、**签名**（你保存的某个签名，或者当场画一个：见[签名](#signatures)）、**表格**（选择它的大小）、**数据图**、**链接**、**评论**、**公式**（单独占一行，或者 **文中的数学公式**）、**特殊字符**（表情符号和符号，按名称查找）、**标注框**（一个带底色和表情符号的方框：点击表情符号可以更换它，在 **格式 → 标注框** 中选择它的颜色）、**目录**（根据各级标题生成，并随时更新；点击其中一行就会跳到那个标题）、**分隔线或分页符**（**横线** 或 **分页符**）、**今天的日期**、**页眉和页脚**，以及 **页码**。光标在表格的单元格中时，图片、表格或横线会紧接着放在这个表格后面。
- **输入“/”**：在一行的开头或者空格之后输入，会出现一个简短的列表，列出可以放在那里的内容：标题、列表、清单、引用、代码、标注框、表格、图片、**AI 生成的图片**、**绘图（SVG）**、**数据图**、签名、公式、横线、分页符、目录或今天的日期。继续输入可以缩小范围（“/表格”或“/tab”），然后按 Enter（方向键可以在列表中上下移动，← 和 → 在它的两栏之间切换）；按 Esc 或空格会关闭它。
- **格式**：**文本**（还有 **删除线**、**上标**、**下标**、**代码**，以及 **全部大写**、**全部小写**、**每个单词首字母大写** 或 **句首字母大写**）、**段落样式**、**对齐和缩进**、**行距和段落间距**（**单倍**、**1.15**、**1.5** 或 **双倍**，添加或去掉段前和段后的间距，以及 **自定义间距**）、**项目符号和编号**、在表格中时的 **表格**、**格式刷**、**清除格式** 和 **页面设置**。
- **查找和替换**（Ctrl+F，要替换则按 Ctrl+H）：页面中的每一处匹配都会被标出来，你所在的那一处会更醒目；**区分大小写**、**全字匹配** 和 **正则表达式** 可以缩小范围。**替换** 会改掉你所在的那一处，**全部替换** 会改掉每一处，表格里的也算在内，按 Ctrl+Z 可以一次撤销。
- **格式刷**（油漆滚筒图标）：点击它，再选中一些文字，这些文字就会变成你光标原来所在处文字的样子，并采用那个段落的样式。双击它可以让它一直开着，刷更多的文字，直到你按 Esc。
- **公式**：点击一个公式就可以修改它。你用 LaTeX 来写（`\frac{a}{b}`、`x^2`、`\sqrt{x}`），有按钮可以插入常用的部分，输入时就能看到排好的公式。
- **表格**：拖动两列之间的边框可以调整列宽。在 **格式 → 表格**（或工具栏中的 **表格**）里：插入和删除行与列、**合并单元格**（先拖过要合并的单元格）、**取消合并单元格**、**单元格颜色**、**垂直对齐**、**标题行** 和 **用这个表格生成数据图**（用它的数字画一张数据图，放在它后面）。Tab 跳到下一个单元格，在最后一个单元格之后会新加一行。
- **分页**：文档会像在 Word 中那样，排在和它的纸张一样大的页面上：一页排满了，后面的内容就接到下一页。较长的段落会接到下一页的顶部继续（每页至少两行），较长的表格也一样，并在下一页重新显示标题行；标题会和它后面的段落放在同一页，**分页符**（Ctrl+Enter）会开始新的一页。这些页面和 PDF 以及 Word 文件中的页面一样。在手机上，以及窗口窄得放不下纸张时，文字会铺满屏幕，不分页。
- **页眉和页脚**：每一页顶部和底部的文字，可以放在左边、中间或右边，可以加上 **页码** 和 **总页数**（“第 3 页，共 9 页”），还可以用 **首页不同** 给标题页单独设置。**插入 → 页码** 会替你加好。每一页都会在页边距上显示它们，带着这一页自己的页码；PDF、Word 文件和打印出来的纸也一样。点击其中一个就可以修改它们。
- **图片**：点击一张图片就能选中它，拖动一个角可以调整大小；它的工具条可以把它放在 **靠左**、**居中** 或 **靠右**，给它加 **说明文字** 和 **描述**（给看不到图片的人），在图片编辑器中打开它（**编辑图片**：[编辑图片和视频](#edit-pictures-and-videos)），用 **换一张图片** 替换它，用 AI 修改它（魔杖图标 **用 AI 修改**，里面有 **用 AI 修改**、**去掉背景** 和 **擦除一部分**），或者删除它。粘贴或拖放到页面上的图片会放在你放下的位置。在许可协议要求署名时，免费照片的署名会成为它的说明文字。
- **按键**：Ctrl+B、Ctrl+I 和 Ctrl+U；Ctrl+Alt+1 到 4 设为标题，Ctrl+Alt+0 设为正文；Ctrl+Shift+7、8 和 9 分别设为编号、项目符号和清单；Tab 和 Shift+Tab 调整列表的缩进；Ctrl+Enter 插入分页符；Ctrl+Alt+M 添加评论；Ctrl+Alt+Shift+X 提出修改建议；Ctrl+Shift+C 查看字数统计；Ctrl+P 打印。在一行的开头输入 `# `、`- `、`1. `、`[] ` 和 `> `，会变成标题、列表、清单或引用。**工具 → 键盘快捷键**（Ctrl+/）会列出所有按键。
- **粘贴**：从 Word、Google Docs 或网页粘贴时，标题、粗体、斜体、链接、列表、表格和公式都会一起带过来，其他的会被去掉。
- 顶部有 **大纲**（各级标题，点击即可跳转；在宽屏上显示在页面旁边）和 **页面设置**：**纸张大小**（**A4** 或 **美式信纸**）、**页边距**（**窄**、**中等**、**宽**，或者以毫米为单位）、文档的 **字体** 和 **大小**，以及 **页眉和页脚**。右下角会显示字数；点击它会打开 **字数统计**：字数、字符数、段落数、页数和阅读时间，如果你选中了一些文字，就只统计选中的部分（页数则是这些文字跨过的那几页）。
- **打印**（Ctrl+P，或 **工具 → 打印**）会按文档 PDF 的样子打印它，包括你的修改、页眉页脚和页码。
- **工具 → 与某个版本比较**：选择文档的一个版本，就会显示从那以后改了什么：新增的文字显示为绿色并带下划线，删去的文字显示为红色并带删除线，还有新增或删去的段落，每一处更改都列在旁边（点击一处即可跳过去）。**恢复此版本** 会把那个版本恢复回来，和 **版本** 中的 **恢复此版本** 一样；**返回文档** 会离开比较。从 **版本**（时钟图标）打开的旧版本，也会用同样的方式显示自它以来的更改；**此版本的原样** 会不加标记地显示它。

选中一些文字，上方就会出现 **评论** 和 **就此问智能体**。更改在你点击底部横条中的 **保存**（Ctrl+S）之前都不会保存；**放弃** 会丢掉它们。每次保存都是一个版本。

### 评论

选中一些文字，然后点 **评论**（在文字上方、工具栏中、**插入 → 评论**，或按 Ctrl+Alt+M），写下评论，再点 **评论**（或按 Ctrl+Enter）。这些文字会被标成黄色；紧挨着它们在后面（或前面）输入的文字不会算进这条评论，和 Google Docs 一样。在宽屏上，评论显示在页面旁边，每条都和它的文字齐平；在较窄的屏幕和手机上，点击顶部显示未解决评论数量的按钮，会打开一个列出所有评论的面板。

每条评论都有 **回复**、**解决**（对勾），以及 **更多** 菜单（⋯）里的 **编辑** 和 **删除**。已解决的评论，它的标记会消失；**视图 → 显示已解决的评论** 会把它们重新显示出来，并带有 **重新打开**。点击一条评论，会把它的文字滚动到视野中；点击文字，则会选中它的评论。

智能体也会读这些评论，以及每条评论所在的文字。评论顶部的 **让智能体回复这些评论** 会请它按评论的要求修改，并逐条回复；它的回复显示为 **智能体**。评论会作为 Word 自己的批注（连同回复）写进 Word 文件，从 Word 文件中也会读回来，并带着每条评论的作者：同事的评论会显示他们的名字和姓名缩写（“Maria Lopez”），你的显示为 **你**，智能体的显示为 **智能体**。

### 提出修改建议

**视图 → 编辑或建议 → 提出修改建议**（或者点工具栏末尾的铅笔，或者按 Ctrl+Alt+Shift+X）会让你的修改变成建议，就像 Google Docs 的建议模式和 Word 的修订那样：你输入的文字会用你的颜色加上下划线；你删除的文字会带着删除线留在原处，直到这处修改被接受；新的样式（粗体、一种颜色）下面会有虚线；拆成两段或与前一段合并的段落，旁边会有一条竖线。粘贴的文字、你插入的表格或图片，以及你删除的表格或图片，也都是建议；段落的样式、对齐方式和间距则会像编辑时那样直接更改。删除你自己建议加入的文字，会立即把它们去掉。**直接编辑**（在同一个菜单里，或者再按一次那个键）会回到直接修改文档。

每条建议都和评论一起显示在页面旁边（在较窄的屏幕和手机上则在面板中）：谁提的、什么时候提的，以及它会做什么（“删除：‘10%’，添加：‘12%’”“格式更改：粗体”“新增一个段落”），还有 **接受**（对勾）、**拒绝**（叉号）和 **回复**。**工具 → 接受所有建议** 和 **拒绝所有建议** 会一次处理所有建议；按 Ctrl+Z 可以撤销其中任何一项操作。查找会略过标记为要删去的文字，建议模式下的 **替换** 会把替换作为建议提出，字数统计不算这些要删去的文字，**复制** 复制的是接受这些建议之后文字的样子。

智能体能看到这些建议，可以接受、拒绝或回复它们，也可以把自己的修改作为建议提出，而不是直接修改（“把你对我报告的修改作为建议提出”）。Word 文件会把建议保存为修订，导入和导出都一样，并带着每处修订的作者和时间；PDF 和文档自己的页面会按它们在这里的样子显示，Markdown 文件里则是接受所有建议之后的文字。

## 签名

把你的签名（以及姓名缩写）画一次，就能把它放进你要签署的东西里：你在这里的文档，以及智能体替你签署的 Word 文件、PDF、图片和文档，而且每次都要等你允许。这里的签名是你签名的一张图片，就像纸上的墨迹一样：它表明你签过名，但它不是加密的数字签名（数字签名能证明是谁签署了文件，以及文件在签署后没有任何改动）。

- **新建**：**设置 → 应用 → 签名 → 新建签名**。选择 **签名** 或 **姓名缩写**，然后用鼠标、手指或笔 **画出来**（线条会随笔的压力或你移动的快慢变化；可选黑色、蓝色或深蓝色墨水；有 **撤销** 和 **清除**，也可以按 Ctrl+Z），或者 **输入你的名字** 并从三种手写体中选一种，或者 **上传图片**：你在白纸上签名的照片或扫描件，纸的部分会变成透明的。给它起个名字，然后点 **保存**。它会保存为一张裁剪到墨迹边缘、周围透明的图片，并在运行本应用的电脑上加密保存。
- **修改**也在那里：每个签名的 **更多** 菜单（⋯）里有 **重命名**、**重新画** 和 **删除**。已经用了它的文档和文件会保留它。
- **签署文档**：把光标放在要签名的位置，然后用 **插入 → 签名**（或者输入“/签名”或“/signature”，或者用“搜索菜单”找到它）。选择你的一个签名，或者在那里 **画一个新的**，勾选 **保留以后再用** 就会把它也保存下来。它会作为一张靠左的图片插入，大小适合签名栏（姓名缩写小一些）；点击它就可以像其他图片一样调整大小或移动。Word 文件、PDF 和其他导出的文件都会保留它。
- **智能体请你签名时**：对话中会出现一张卡片 **请签名**，上面是同样的签名板。画出来、输入或上传，检查它的名称（**保存为**），然后点 **保存**；取消勾选 **保留以后再用**，它就只保留一天。智能体只会得知它已保存以及它的名称：它永远看不到这张图片。
- **智能体替你签署东西时**（Word 文件、PDF、PNG 图片或你资料库中的文档）：会先出现一张卡片询问你 **放置你的签名“…”？**，显示文件、签名的位置（“紧跟在以下文字之后：‘Signature:’”“替换以下文字：‘{{signature}}’”“第 3 页，共 4 页 · 在以下文字上方：‘Signed by the tenant’”），以及签名后页面的样子，或者签名位置周围的文字。**允许** 会放置一次；**在此会话中允许** 让那个会话的智能体以后不用再问就能再次放置这个签名；**拒绝** 则保持一切不变。文件会在旁边得到一份签好名的副本（“Lease (signed).docx”），除非你要求直接在原文件上签名；在 Word 文件中，紧跟在文字之后的签名会浮在文字前面，就像签在线上一样，不会挤动任何内容。你资料库中的文档会生成一个新版本。

## 电子表格

电子表格也保存在资料库中，有自己的版本、列表中的图片和独立的地址。你可以像在 Excel、Google Sheets 或 Airtable 中那样使用它们，包括公式、筛选、决定单元格外观和可填内容的规则、复选框、下拉列表、图表、合并的单元格、备注和评论，以及看板，并把它们保存为 Excel、CSV 或 PDF 文件。

- **新建**：问智能体（“给我做一份两个人的月度预算，带合计”“把这些数字放进电子表格，再加一列显示每个数字的占比”），或者在资料库中点 **新建页面**，然后选 **电子表格**（[也可以从搜索框用“新建电子表格”](/library?new=sheet)）：可以是空白的，也可以用 **打开 Excel 或 CSV 文件** 从你的文件开始（.xlsx、.ods、.csv 或 .tsv）。
- **单元格**：点击一个，或者拖过几个（按住 Shift 点击可以扩大选区；按住 Ctrl 点击或拖动可以在旁边再选一个区域，用来画由几个区域组成的图表；点击列字母或行号可以选中整列或整行）。直接输入会替换单元格里的内容，双击它（或按 F2）则可以修改它；Enter 往下走，Tab 往右走，Alt+Enter 在单元格内换行，Esc 取消。以 = 开头的值是公式：`=SUM(B2:B9)`、`=B2*C2`、`=IF(C2>100,"high","ok")`（Excel 的函数，大约两百个，从 SUM、AVERAGE 和 IF 到 VLOOKUP、XLOOKUP、SUMIFS、TEXT，以及日期和贷款函数）。输入公式时，点击单元格就能把它们放进公式；下方会显示名称匹配的函数，你所在的函数会显示它的参数，当前的参数用粗体，还有一行说明它返回什么。F4 会让光标处的引用依次换成不同的 $ 写法（$A$1、A$1、$A1）。FILTER、SORT、SORTBY、UNIQUE 和 SEQUENCE 会把结果溢出到下方和旁边的单元格中（`=SORT(A2:C20,3,-1)`、`=UNIQUE(B2:B50)`），这些单元格必须是空的：选中其中一个单元格，会框出整个数组，并在编辑栏中以浅色显示它的公式。
- 左上角的 **名称框** 显示选中的单元格；输入一个单元格或区域（C12、B2:D9）并按 Enter 即可跳转过去。它旁边是单元格的公式或值，也可以在那里修改。
- **菜单**：**编辑**、**视图**、**插入**、**格式**、**数据** 和 **工具** 里有编辑器能做的所有事，每一项都标着它的按键；没有地方放它们时（较窄的窗口、手机上），它们都收在一个 **菜单** 按钮里。**搜索菜单**（菜单旁边的放大镜，或 Alt+/）可以按文字找到某个操作并执行它。
- **工具栏** 里是最常用的：**撤销** 和 **重做**；**数字显示方式**，以及 **减少小数位数** 和 **增加小数位数**；**字号**；**粗体**、**斜体**、**删除线** 和 **文字颜色**；**填充颜色**、**边框**（线画在哪里：全部、内部、外部、某一边或者不画；以及线的样式和颜色）和 **合并单元格**；**对齐方式**（左、中或右；上、中或下）和 **单元格内自动换行**；还有 **创建筛选器**。
- **列和行**：拖动列字母或行号的边缘可以调整大小；双击它可以让它适应内容。右键点击列字母或行号，可以插入、删除、隐藏或排序；隐藏的行或列会收成相邻两者之间的一个小标记，点击它就能重新显示（也可以用 **视图 → 显示所有隐藏的行** 和 **显示所有隐藏的列**，或者 **格式 → 行和列**）。**视图 → 冻结** 可以在滚动时让前几行或前几列一直留在视野中。
- **工作表**：底部的标签页，带有 **添加工作表**（+）。标签页的菜单里有 **重命名**、**创建副本**、**左移**、**右移**、**从 CSV 文件添加工作表** 和 **删除这个工作表**；双击标签页可以重命名它。

选中多个数字时，底部的横条会显示它们的 **求和**、**平均值** 和 **计数**（统计选中的每个区域，公式溢出到其中的值也算在内）。在手机上，轻点单元格即可选中它，再点一次就能输入；长按会打开菜单，拖动圆形手柄可以扩大选区，菜单都收在一个按钮里，面板会从底部升起。更改在你点击底部横条中的 **保存**（Ctrl+S）之前都不会保存，每次保存都是一个版本。

### 复制、填充和查找

- **复制和粘贴**：Ctrl+C、Ctrl+X 和 Ctrl+V 可以复制、剪切和粘贴，也能在这里和 Excel、Google Sheets 之间互相复制粘贴（粘贴的公式会随单元格移动，把一个值粘贴到多个单元格上会把它们全部填满）。**选择性粘贴**（右键菜单，或 **编辑 → 选择性粘贴**）可以 **仅粘贴值**（Ctrl+Shift+V）、**仅粘贴格式**、**仅粘贴公式** 或 **转置**（把行变成列）。
- **填充柄**：选区角上的小方块。向下或横向拖动它，可以延续一个序列（1、2、3；5、10、15；日期按天延续，单元格按月或按年递增时则按月或按年；英文的星期和月份，比如 Monday、Tuesday 和 January、February；项目 1、项目 2），或者复制这些单元格（单个数字会被复制；按住 Ctrl 则从它开始往下数）；公式会像复制时那样跟着移动，每个单元格的样式也会一起带过去。双击填充柄，会向下填充到旁边那一列数据的末尾。Ctrl+D 和 Ctrl+R 用选区的第一行或第一列向下和向右填充。
- **查找和替换**（Ctrl+F、Ctrl+H，或 **编辑 → 查找和替换**）会在单元格显示的内容中查找文字，选 **在公式中查找** 则在公式中查找；**区分大小写**、**匹配整个单元格** 和 **所有工作表** 可以缩小或扩大范围，箭头（或 Enter）可以从找到的一个单元格转到下一个。**替换** 会改掉当前显示的那个单元格，**全部替换** 会改掉每一个，而且只算一步，可以撤销。
- **按键**：Ctrl+B、Ctrl+I 和 Ctrl+U；Alt+Shift+5 添加删除线；Delete 清除；Ctrl+Z 撤销，Ctrl+Shift+Z（或 Ctrl+Y）重做；Ctrl 加方向键跳到数据的边缘；Ctrl+Space 选中整列，Shift+Space 选中整行；Ctrl+; 填入今天的日期，Ctrl+Shift+; 填入当前时间；Ctrl+\ 清除格式；Ctrl+` 在单元格中显示公式；Ctrl+Alt+M 添加评论；Ctrl+/ 列出所有按键。在单元格上右键点击，会有 **剪切**、**复制**、**粘贴**、**选择性粘贴**、插入、删除和隐藏行与列、排序、**插入备注**、**评论**、**展开行**、**清除** 和 **就此问智能体**；在行号或列字母上右键点击，这些操作针对的是那一行或那一列。

### 排序、筛选和整理数据

- **筛选**：**数据 → 创建筛选器**（工具栏中的筛选按钮，或 Ctrl+Shift+L）会在表格标题行的每一列上放一个按钮。列上的按钮里有 **从 A 到 Z 排序** 和 **从 Z 到 A 排序**、**按条件筛选**（为空、文本包含、文本开头为、文本完全为、大于、介于、日期早于或晚于，或者自定义公式）和 **按值筛选**（列出每个值以及有多少行是这个值，有一个输入框可以查找值，还有 **全选** 和 **清除**）。被筛掉的行只是隐藏起来，并没有删除，公式仍然会把它们算进去；筛选覆盖的那些行，行号会显示成彩色，在表格正下方输入的新行会加入进来。**数据 → 移除筛选器** 会去掉筛选。
- **排序**：**数据 → 对区域排序** 会按几列依次排序选中的单元格（或选中单元格所在的整个表格），每一列可以从 A 到 Z 或从 Z 到 A，还可以选择是否 **数据包含标题行**；**数据 → 按列对工作表排序** 会按当前单元格所在的列排序整个表格。
- **数据 → 删除重复项** 会删掉在你选的几列中与上面某一行的值相同的行，并告诉你删了多少行；**将文本拆分成列** 会在逗号、分号、空格、制表符或你输入的字符处拆开每个单元格的文字（它会自己找出分隔符），放进右边的几列中；**删除多余空格** 会去掉文字前后的空格，并把连在一起的多个空格变成一个。
- **数据 → 分组汇总** 会像数据透视表那样，在一个新工作表上汇总一个表格：你选的那一列的每个值占一行（愿意的话，第二列的每个值各占一列），每个数值列可以求和、计数、求平均值，或者取最小值或最大值，还有总计。它是用公式做成的，所以表格的单元格变化时，它也会跟着更新。

### 条件格式、复选框和下拉列表

- **条件格式**（**格式 → 条件格式**）会打开一个面板，按顺序列出这个工作表的规则：对某个单元格来说，第一条条件成立的规则决定它的样子。一条规则用于一个区域，可以是 **单色**（一个条件，比如大于、介于、文本包含、为空、日期早于、晚于或是今天、重复值或唯一值、排在最前或最后的 10 项或 10%、高于或低于平均值，或者 `=$C2>100` 这样的公式，以及它给出的样式：粗体、斜体、下划线、删除线、文字颜色或填充色）、**色阶**（从最小值到最大值的两种或三种颜色）或 **数据条**（长度与每个值相应的条形）。规则可以在列表中上下移动。
- **复选框**：**插入 → 复选框** 会在每个选中的单元格中放一个方框；点击它或按空格键就能勾选，它在公式中的值是 TRUE 或 FALSE（`=COUNTIF(E2:E20,TRUE)`）。
- **下拉列表**：**插入 → 下拉列表** 会打开 **数据验证** 面板，用这些单元格自己的值作为选项，每个选项都有它的标签颜色。之后单元格会把它的选项显示成一个彩色标签；点击它的箭头（或按 Alt+↓）会打开列表，输入开头的几个字就能选中以它们开头的选项。
- **评分**：**插入 → 评分** 会给这些单元格五颗星；点击其中一颗即可评分。
- **日期**：双击一个日期（或在它上面按 Alt+↓，或用 **插入 → 日期**），就可以从日历中选一天。
- **数据 → 数据验证** 会列出这个工作表的每一条规则：一组选项或某个区域的值组成的下拉列表、复选框、评分、某个范围内的数字或日期（介于、大于……）、一定长度的文字，或者自定义公式。**如果数据无效**：**显示警告** 会保留你输入的内容，并在单元格上标一个红色的角；**拒绝输入** 会拒绝它，并说明这个单元格可以填什么。

### 外观、合并、备注和评论

- **格式 → 数字**：**自动**、**纯文本**、**数字**、**百分比**、**科学记数**、**会计专用**、**货币**（美元、欧元或英镑）、**日期**（2026-11-05、05/11/2026、11/05/2026、5 Nov 2026 或 Thursday, 5 November 2026）、**时间**、**日期时间**、**时长**（可以超过一天的小时数，如 26:30:00）和 **自定义数字格式**：像 `#,##0.00;[Red]-#,##0.00`、`0.0%` 或 `d mmm yyyy` 这样的 Excel 格式代码，会显示单元格将会是什么样子，还有一些可以拿来修改的代码。**格式** 里还有 **字体**、**字号**、**对齐方式**、**旋转**（倾斜，或者竖排朝上或朝下）、**边框** 和 **清除格式**。
- **合并的单元格**：**格式 → 合并单元格**（或工具栏中的按钮）里有 **全部合并**、**水平合并**、**垂直合并** 和 **取消合并**。合并的单元格显示为一个，选中它的任何部分都会选中整个，你输入的内容会放进它的第一个单元格（合并单元格时，只保留第一个单元格的值）。
- **备注**：右键点击一个单元格，选 **插入备注**（Shift+F2），就能在上面留一条备注：单元格上会出现一个橙色的小角标，鼠标指向它（或选中它）就会显示备注。**编辑备注** 可以修改或删除它。
- **评论**：和 Sheets 一样，备注之外还有评论，用来围绕一个单元格展开讨论：右键点击单元格，选 **评论**（或者用 **插入 → 评论**，或按 Ctrl+Alt+M），写下评论，再点 **评论**（或按 Ctrl+Enter）。评论未解决时，单元格上会有一个紫色的角标；鼠标指向这个单元格（或选中它）会显示评论的简要内容，点击这段内容会打开 **评论** 面板，里面是这个工作表的所有评论（**视图 → 评论** 也能打开它），选中单元格的评论排在最上面，未解决的排在前面。每条评论都有 **回复**、**解决**（对勾）或 **重新打开**，菜单（⋯）里还有 **编辑** 和 **删除**，并显示每一部分是谁写的（**你** 或 **智能体**）以及什么时候写的；点击一条评论所在的单元格即可跳到那里。插入或删除行和列、给行排序、剪切和粘贴单元格时，评论都会跟着它们的单元格走。智能体会读这些评论，回复、解决它们，也会添加自己的评论：请智能体回复它们就行。
- **缩放**：**视图 → 缩放**，从 50% 到 200%，会保存在这台设备上。

### 图表

**插入 → 图表** 会把选中的单元格（或选中单元格所在的整个表格）画成一张图表，放在它们旁边：柱形图、条形图、折线图、面积图、饼图、环形图或散点图。要用彼此分开的几个区域画图，先选中第一个，再按住 Ctrl 点击或拖动选中其他的，然后用 **插入 → 图表**：标签来自第一个区域，数值来自其他区域（A1:A7 和 F1:F7 会以 A 列的名称为标签画出 F 列，B 到 E 列不包括在内）。点击图表可以选中它，拖动可以移动它，拖动它的手柄可以调整大小，按 Delete 可以删除它，双击它会打开它的面板：它的 **类型**、**数据区域**（一个区域，或者用逗号分隔的几个区域：`A1:A7,F1:F7`）、系列 **按列** 还是 **按行**、是否把第一行和第一列作为名称和标签、**堆积**、它的 **标题**、**坐标轴标题**、**图例** 和 **颜色**。

图表放在它下面的单元格上，就像 Excel 中随单元格移动和调整大小的图表：在它上方或前面插入行或列会让它移动，在它覆盖的范围内插入行或列会把它拉长，把行调高或把列调宽也一样；隐藏它下面的行或列，它也会跟着收起来，它的数据区域也会跟着单元格变化。单元格变化时它会跟着变，会略去筛选隐藏的行，并会出现在工作簿自己的页面、它的 PDF 和 Excel 文件中，在 Excel 文件里是 Excel 自己的图表。如果它无法用某个区域画图（几个区域长短不一、分在两个工作表上，或者写的文字不是区域），图表里和它的 **数据区域** 下方都会说明原因，而不会让图表消失。

### 行卡片和看板

行号上的按钮（或者用 Shift+Space 选中一行后按空格键，或者右键 → **展开行**，或者 **工具 → 展开行**）会把这一行作为一张卡片打开，就像 Airtable 打开一条记录那样：它的单元格排在各自的列标题下面，可以阅读和修改，复选框、下拉列表和星级评分和在表格中一样；卡片顶部的箭头可以转到上一行和下一行。

**视图 → 看板** 会把带下拉列表列的表格显示成一块看板：这一列的每个选项各有一列卡片（没有选项的行也有一列），每张卡片是一行，以它的第一个单元格作为标题，下面是你选择显示的字段。把卡片拖到另一列，就会改变它那一行的选项；点击卡片会把那一行作为卡片打开；**添加一行** 会在表格末尾加一个新行。**分组依据** 可以选另一个下拉列表列，**卡片字段** 用来选择卡片显示哪些列，按住一列卡片的名称拖动，可以调整这些列的顺序；× 回到表格。看板会按你的设置随工作表一起保存，**视图 → 打开工作表时显示看板** 会让这个工作表一打开就显示看板。

你打开或保存的 Excel 文件会保留这一切：筛选、条件格式、下拉列表（连同它们标签的颜色；含有逗号或引号的选项，或者选项多到 Excel 的一条规则放不下时，则放在一个隐藏的列表工作表上）、复选框和其他规则、合并的单元格、隐藏的行和列、边框、数字格式、备注、评论（作为 Excel 自己可以回复的批注）和放在单元格上的图表。打开 OpenDocument 文件（.ods）时，它的合并单元格、备注、验证列表和规则，以及 LibreOffice 给它设置的条件格式，也会一起带进来。工作簿自己的页面和它的 PDF 也会显示它们。

## LaTeX 文档

LaTeX 文档由它的源文件（主文件 main.tex，以及它读入的其他文件，比如存放参考文献的 .bib）和它的图片组成，由应用所在电脑上的 LaTeX 排版成页面。你可以像在 Overleaf 中那样，在排版好的页面旁边编辑源文件，可以看代码，也可以看成文档的样子，并保存 PDF、.tex 文件或整个项目。

- **新建**：问智能体（“把这些结果用 LaTeX 写成一篇简短的论文，给公式编号”），并看着它的源文件一点点写出来；或者在资料库中点 **新建页面**，然后选 **LaTeX**（[也可以从搜索框用“新建 LaTeX 文档”](/library?new=tex)），再选它从什么开始：**文章**、**报告**、**书籍或学位论文**、**信件**、**Beamer 幻灯片**、**履历或简历**、**作业**、**会议论文** 或 **海报**（只列出这台电脑上的 TeX 能排版的那些；下面有一行会说明其余的是哪些，以及要为它们安装什么）。会议论文的卡片下方有它的 **论文格式**：**两栏**，或者按 **IEEE**、**ACM** 或 **Springer LNCS** 的要求，每种都有它自己的文档类、标题区、参考文献样式，以及一个起步用的 refs.bib。也可以用 **打开 .tex 或 .zip 文件** 打开你自己的（一个文件，或者打包成 .zip 的项目文件夹；其中的 PDF 图片会变成 PNG 图片）。
- **源文件**：只有一个文件的文档，有一个它的标签页和一个 **图片** 标签页（可以添加、重命名图片，把图片放进插图，或者移除图片），它们旁边的 **+** 里有 **新建文件**、**新建文件夹**、**添加图片** 和 **从这台设备添加文件**。有多个文件的文档（一个章节、一份参考文献、一张图片）会在左边以树的形式显示它的文件，标签页则是你打开的那些文件（见[文件树](#the-files-tree)）。
- **代码或可视化**，源文件上方的开关：**可视化** 会在你输入时把源文件显示成文档的样子：标题、粗体和斜体文字、排好的数学公式、列表的项目符号和编号、图片，带框显示并附有标题的插图和表格，文献引用、交叉引用和标签显示成小标记，脚注收成一个记号（鼠标指向它就能阅读），注释则显示得很淡。光标所在的地方会重新显示为源代码，让你按原样修改它：无论用哪种方式，文本都是一样的。编辑器会在这台设备上记住你的选择。
- **输入时**，编辑器会提示合适的内容：输入反斜杠会列出 LaTeX 命令，每个都附有它的作用（包括文档自己用 `\newcommand` 定义的命令，以及它加载的宏包里的命令）；`\begin{` 会列出环境，并补上对应的 `\end{…}`；`\usepackage{` 会列出常用宏包，并说明这台电脑上缺少哪些；`\cite{`、`\ref{` 和 `\includegraphics{` 会列出文档自己的参考文献、标签和图片。在手机上，输入这些内容时也会打开这个列表，每一行都大到可以用手指点，并写明它的作用；点一下就能选用（Return 仍然是换行）。按 Tab 跳到下一个要填的位置。括号和 `$` 会自动补全，在你输入的 `\begin{…}` 之后按 Enter，会在下面放上它的 `\end{…}`。光标在公式中时（`$…$`、`\[…\]`、equation 环境、对齐的多行公式……），上方会出现一张卡片，显示排好的公式，你自己用 `\newcommand` 定义的命令也会生效。
- **菜单**：**编辑**（撤销、按 Ctrl+F 打开的 **查找和替换**、**跳转到行**、按 Ctrl+/ 的 **注释或取消注释**）、**插入**（标题、列表、表格、带图片的插图、公式、符号、参考文献、文献引用、交叉引用、脚注，以及 **更多** 下面的链接、引文、证明、目录或分页符）、**格式**（按 Ctrl+B 的 **粗体** 和按 Ctrl+I 的 **斜体**，对已经是粗体或斜体的文字再用一次，会让它恢复普通样式；还有下划线、等宽字体、小型大写字母、上标和下标、**文字大小**、**对齐方式**、**文字颜色** 和 **清除格式**）、**视图** 和 **工具**。**搜索菜单**（放大镜，或 Alt+/）可以按文字找到其中任何一项。工具栏上保留了 **粗体**、**斜体**、**符号**、**公式**、**带图片的插图**、**大纲**、**查找和替换**、**在 PDF 中显示这一行** 和 **问智能体**；在较窄的窗口中，放不下的按钮会收进菜单里，最少用的先收，**工具** 里也有 **问智能体**。在手机上，菜单收在一个按钮里。**工具 → 键盘快捷键** 会列出所有按键。
- **符号**（工具栏中的 Ω，或 **插入 → 符号**）：按类分组的数学符号（希腊字母、运算符、关系符、箭头、括号、重音符号、大型运算符等），有一个输入框可以按名称查找；最近用过的排在最前。点击一个符号会插入它的命令，光标不在数学公式中时会放进 `$…$` 里，并加载它需要的宏包。
- **表格**：**插入 → 表格** 会打开一个网格，让你在里面输入单元格：添加和删除行与列，设置每一列的对齐方式、标题行、行与行之间的线（**Booktabs**、**加横线**、**每行** 或 **无线条**）、列与列之间的线，以及给由 LaTeX 安排位置的浮动表格加标题和标签。从电子表格复制的行可以直接粘贴进来。光标在表格中时，**插入 → 编辑此表格** 会把它读回网格中（限没有合并单元格的表格）。
- **参考文献**：**插入 → 网上的参考文献**，或者参考文献文件标签页中的 **按 DOI、arXiv 编号或标题查找参考文献**：粘贴 DOI、arXiv 编号或它的网址，或者输入标题或作者中的一些词。应用会从 doi.org、arXiv 和 Crossref 获取 BibTeX（只发送你输入的内容），并列出找到的结果，每一条都可以查看它的 BibTeX。**引用** 会用一个不和其他条目重复的键把它加进参考文献，并在光标处引用它；**添加** 只把它加进去。没有参考文献的文档会得到一个 refs.bib，在文档末尾读入。
- **视图**：**代码** 或 **可视化**、**大纲**、**检查拼写**（用浏览器的拼写检查检查文字，跳过命令和数学公式）、**全部折叠** 和 **全部展开**（环境、节、导言区和较长的组也可以用行号旁边的箭头折叠）、**在 PDF 中显示这一行**、**深色页面**（在深色主题下，把页面显示为深底浅字）和 **放映页面**（一次一页，铺满整个屏幕：方向键前进和后退，按 Esc 离开；beamer 演讲会显示为幻灯片）。
- **工具**：**立即重新编译**、**边输入边重新编译**、**排版引擎**（选择引擎）、**字数统计**（正文、标题以及图表标题和脚注各有多少字，还有标题、插图、表格和公式各有多少个，按 texcount 的方式统计，可以统计 **整个文档** 或某一个文件）、**比较版本**、**修订**、**接受所有修订**、**拒绝所有修订**、**显示日志**、**打开 PDF**、**请智能体修正**（有错误时）和 **键盘快捷键**。
- **评论**：在源文件中选中一些文字，用 **插入 → 评论**（Ctrl+Alt+M）写一条评论；它会显示在源文件旁边的 **评论** 中（**视图 → 评论**，或者工具栏上显示未解决评论数量的评论按钮；在手机上是从底部升起的面板），它针对的文字会在源文件中标出来，文本改动时标记也会跟着这些文字。每条评论都有 **回复**、**解决**，菜单里还有 **编辑** 和 **删除**；已解决的评论点一下就能看到。评论会随文档一起保存，被问到这个文档的智能体会读这些评论，回复并解决它们，或者添加自己的评论。从[文件](/guide/files-git#edit-word-excel-csv-and-latex-files)中打开的 .tex 文件也可以有评论，应用会把它们保存在文件旁边。
- **修订**（**工具 → 修订**），和 Overleaf 中一样：开启后，你输入的内容会被标记为插入（绿色下划线），你删除的内容会以红色删除线留在原处，标记为删去；鼠标指向其中一处，就能看到是谁、在什么时候改的。这些修订列在源文件旁边的 **评论** 中，排在评论上面，每一处都写明是谁、什么时候改的：点击一处即可跳过去，**接受** 会保留这处修订，**拒绝** 会把文本恢复成原来的样子，**全部接受** 和 **全部拒绝**（也可以用 **工具 → 接受所有修订** 和 **拒绝所有修订**）会一次处理所有修订；撤销可以撤回其中任何一项操作。排版出来的页面相当于接受了所有修订。修订会随文档一起保存；修订开启时，智能体保存时所做的修改会被标记为智能体的修改，由你来接受或拒绝；如果你请智能体处理，它也可以接受或拒绝这些修订。这个功能用于资料库中的文档：从“文件”中打开的文件只保存它的文本。
- **比较版本**（**工具 → 比较版本**）：选一个较早的版本，就能看到从那以后每个文件增加和删除了哪些行，可以 **并排** 或 **上下排列**，和编辑器里现在的内容对比。**恢复此版本** 会把一个文件恢复成那个版本中的样子（在你保存之前不会保存，撤销可以把它撤回）。
- **排版**：你停下输入片刻后，页面就会跟着更新。**重新编译**（Ctrl+Enter）会立即排版，它旁边的箭头里有 **边输入边重新编译**（可以用它关闭自动排版）、**显示日志** 和 **打开 PDF**。顶部的排版引擎可以是 **pdfLaTeX**（最常用）、**XeLaTeX**（任何语言，以及这台电脑上的字体）或 **LuaLaTeX**。页面可以放大、缩小和 **适应宽度**；页面上方的页码框会显示当前看到的是哪一页，输入页码就会跳到那一页；**放映页面** 就在它旁边。双击页面上的某个位置，可以跳到源文件中对应的那一行。
- **错误和警告** 显示在源文件下方和对应行的旁边：点击一个即可跳过去，或者点 **请智能体修正**。**日志** 显示 TeX 输出的全部内容。
- **投稿前检查**（**工具**）：选择投稿的会议，它就会像会议的初审和审稿人那样检查论文：它的参考文献（对照它的参考文献列表，也在网上核对：它们是否存在，作者、年份和发表处是否正确，预印本此后是否已经正式发表）、它是否暴露了你的身份、它的页数和字体、会议要求的部分，以及它表格里的数字。每条发现都会显示它所在的行，在修改安全的地方带有 **修复**，否则带有 **问智能体**；**添加为评论** 会把它们放到对应的文字上。见[投稿前检查论文](/guide/researchers#check-a-paper-before-you-submit)。
- **工具 → 你的论文**：**改成终稿** 和 **迁移到另一个模板** 会向编辑器旁边的智能体提出请求，请求根据会议的规则写成；**像审稿人那样审阅它**、**回复审稿意见** 和 **制作演讲、海报和推文串** 会打开对应的应用，并填好这篇论文。见[终稿、换模板，以及在应用中使用你的论文](/guide/researchers#camera-ready-another-template-and-your-paper-in-the-apps)。
- **arXiv 投稿包**：**导出 → arXiv 投稿包（.zip）** 会生成一个用来上传到 arXiv 的 .zip：删除了注释，只包含论文用到的文件，并加入 .bbl；生成前还会排版一次，确认它能编译通过。见[arXiv 投稿包](/guide/researchers#the-arxiv-package)。

在手机上，或者窗口窄得无法并排显示两者时，**LaTeX 源码** 和 **预览** 是工具栏开头、**重新编译** 旁边的两个标签页。更改在你点击底部横条中的 **保存**（Ctrl+S）之前都不会保存，每次保存都是一个版本。

应用所在的电脑上必须装有 LaTeX（TeX Live）。没有它的话，LaTeX 文档仍然可以保存和编辑，只是不会排版，编辑器会告诉你要安装什么。IEEE、ACM 和 Springer LNCS 论文还需要出版商的文档类（在 Debian 或 Ubuntu 上是 texlive-publishers，ACM 论文还需要 texlive-fonts-extra）；MacTeX 自带它们，MiKTeX 会在第一次排版论文时自动安装它们。TeX 在它自己的文件夹中工作：文档不能读取或修改其他文件，也不能运行程序；在装有 bubblewrap 的地方，TeX 还会在它的沙盒中运行（LuaLaTeX 只在那里运行）。

### 文件树

有多个文件的 LaTeX 文档（章节、参考文献、图片），在宽屏上会在源文件左边以树的形式显示它的文件。**视图 → 文件** 可以显示或隐藏它，应用会在这台设备上记住你的选择。这个面板有两个标签页：**文件** 和 **大纲**（**视图 → 大纲** 会打开它并停在大纲上）。在手机上或较窄的窗口中，源文件上方那一排标签页开头的 **文件** 会在从底部升起的面板中打开文件树。

- **它显示什么**：主文件排在最前，标着 **main**，然后是文档用到的文件夹和文件，按合理的顺序排列：在每个文件夹中，先是它的子文件夹，然后是它的源文件（章节按文档读取它们的顺序）、参考文献、样式和文档类、图片、数据和其他文件。它像 TeX 那样读取文档：`\input`、`\include`、`\subfile` 和 `\import` 放进来的内容，`\bibliography` 和 `\addbibresource` 的参考文献，`\includegraphics` 的图片（通过 `\graphicspath` 和 TeX 会尝试的扩展名找到），`\usepackage` 和 `\documentclass` 加载的文档自己的样式和文档类，以及代码清单和绘图用的数据。被注释掉的内容不算。
- **未使用**：文档保存着但不读取的文件，会以灰色显示在 **未使用** 下面，排在其他文件之后。它们仍留在文档中（也在它的 .zip 里），只有在有地方读取它们时才会参与排版。
- **打开文件**：点击它。源文件或参考文献会在它的编辑器中以标签页打开；图片会显示在源文件的位置，附上它的尺寸、文档在哪里用到它（点击即可跳到那一行）、**作为插图插入**、**复制名称**、**重命名** 和 **移除**。当前查看的文件会在树中标出来。源文件上方的标签页就是你打开的那些文件，每个都有 × 可以关闭它。
- **修改它们**：树的 **+** 里有 **新建文件**、**新建文件夹**、**添加图片** 和 **从这台设备添加文件**。文件夹的 **⋯** 里有同样的选项（放进这个文件夹），还有 **重命名** 和 **删除**（连同其中的文件）；文件的 **⋯**，或者在它上面点右键，里面有 **重命名** 和 **删除**。名称中带斜杠，就会把文件放进文件夹（`chapters/intro.tex`）。重命名或移动文件或文件夹时，文档中提到它的地方（`\input`、`\includegraphics`、`\bibliography`……）也会按原来的写法一起修改（从 `\graphicspath` 的文件夹算起，不带扩展名）。在电脑上，把文件和文件夹拖到一个文件夹上，就能把它们移到那里（拖到 **main.tex** 上则移到顶层）；把电脑上的文件拖放到一个文件夹上，就能把它们添加进去。新文件夹要等里面有了东西才会保留。

从“文件”中打开的 .tex 文件也会这样显示它所属文档的文件，TeX 从它的文件夹中原样取用的东西（图片、样式、文档类、数据）会以灰色显示，供你查看（见[编辑 Word、Excel、CSV 和 LaTeX 文件](/guide/files-git#edit-word-excel-csv-and-latex-files)）。

## 笔记本

笔记本是保存在资料库中的 Jupyter 笔记本：由文本单元格和代码单元格组成，每个代码单元格都带着它上一次运行显示的内容（文字、表格、图表、图片、错误）。它在和“文件”中的笔记本相同的视图中打开（见[运行 Jupyter 笔记本](/guide/files-git#run-a-jupyter-notebook)），有版本、列表中的图片和它自己的地址，可以保存为 .ipynb 文件、Python 脚本、PDF 或网页。

- **新建一个**：请智能体来做（“用这个 CSV 做一个画出我每月开销的笔记本，并保存在我的资料库里”），或者在资料库中点 **新建页面**，然后选 **笔记本**（[或者在搜索框中用新建笔记本](/library?new=notebook)）：以它的名称作标题，外加一个空的代码单元格；也可以用 **打开笔记本（.ipynb）** 打开你自己的笔记本。智能体写好并运行过的笔记本文件，进入资料库时会带着它的输出。
- **运行它**：顶部的内核按钮（还没有运行时显示 **没有内核**）用来选择运行代码的 Python 环境，从这台电脑上的环境中选；它旁边是 **运行所有单元格**、**中断**、**重启内核** 和 **清除所有输出**（在手机上，它们在横条下面单独一行）。资料库中的笔记本在应用数据文件夹里它自己的文件夹中运行：代码写到那里的东西（下载的数据、保存的模型）会跟着它，删除它时也一起删除。
- **单元格**：和在“文件”中一样，点击代码单元格来编辑，双击文本单元格，用 Shift+Enter 或 Ctrl+Enter 运行，用单元格的工具移动、添加或删除单元格；单元格的工具中还有 **就这个单元格问智能体**。

运行显示的内容会立即出现，但在点击底部横条中的 **保存**（Ctrl+S）之前不会保存；**放弃** 会回到保存的版本。每次保存都是一个版本，连同输出一起。查看较早的版本时，它保持原样，不能编辑或运行。

## 用 AI 生成图片、绘图、数据图和视频

幻灯片、文档和页面可以在你放图片的地方直接用 AI 生成：图片、绘图（SVG）、数据图，在幻灯片中还有视频。每一种都有一个对话框（在手机上是从底部升起的面板），在花任何钱之前说明要花多少，并在你使用之前先给你看它做出了什么。它们在这些地方：

- **幻灯片**：**插入 → 图片 → 用 AI 生成** 或 **绘图（SVG）**、**插入 → 数据图**、**插入 → 视频 → 用 AI 生成**、**幻灯片** 标签中的 **背景**（**用 AI 生成**），以及选中图表时的 **用它生成数据图**（在 **格式** 菜单和侧边面板中）。选中图片时，它的 **用 AI 修改**、**去掉背景** 和 **擦除一部分** 在 **格式** 菜单中，在右键菜单和侧边面板中则在 **用 AI 修改** 下面。
- **文档**：**插入 → 图片 → AI 生成的图片** 或 **绘图（SVG）**、**插入 → 数据图**，或者“/”（**AI 生成的图片**、**绘图（SVG）**、**数据图**）。光标在表格中时，**格式 → 表格 → 用这个表格生成数据图**（工具栏的 **表格** 菜单中也有）会把这个表格画出来，数据图放在它后面。选中图片时，它的魔杖图标（**用 AI 修改**）里有 **用 AI 修改**、**去掉背景** 和 **擦除一部分**。
- **页面**（在 **编辑** 中）：添加图片时的 **用 AI 生成** 或 **绘图（SVG）**、封面的 **用 AI 生成**，以及选中图片时 **部分** 标签中的魔杖图标（**AI 生成的图片**，用一张新图片替换它）和 **用 AI 修改**。

**图片**（对话框 **用 AI 生成图片**）：描述它（或者从一个示例开始），然后选择：

- **适用于**：**图片**、**照片**、**插画**、**背景**、**图标**、**示意图**、**纹理** 或 **标志**：每一种都会按那种用途的需要去生成（背景平静、边缘留空，图标是居中的一个简单物体，纹理可以重复拼接）；
- **风格**：**任意风格**、**摄影**、**水彩**、**扁平**、**3D 渲染**、**线描**、**铅笔素描** 或 **油画**；
- **形状**：**正方形（1:1）**、**横向**、**宽**、**纵向** 或 **竖屏**，或者它要放的位置的形状；
- **质量**：**自动**（根据你的要求选“快速”或“最佳”）、**快速**（更便宜、更快：图标、背景、纹理）或 **最佳**（场景、照片、图中文字、示意图），也就是[设置 → 图片、视频和音频](/settings?s=images&find=For%20most%20pictures%20%28Best%29)中的那两个模型；
- **有多少**（1 到 4 张）、用于图标或标志的 **透明背景**，在幻灯片中还有 **使用这些颜色**（这套幻灯片的主题颜色），在文档中还有 **参照所选的图片**，照着它再做一张。

它们下方的一行字会说明用哪个模型、要花多少钱（“用 … 约需 $0.04”），按钮上也有。然后会显示生成的图片（点击一张来选中它），以及“所用模型”和花费：**修改描述**、**重新生成** 或 **用这张**。

**对图片做修改**（对话框 **修改图片**）有三个标签页：

- **用 AI 修改**：说出要改什么（“把天空改成日落”“把杯子去掉”），改整张图，或者用 **只改我涂抹的地方** 只改你涂抹的地方。由“最佳”模型来做，价格写在按钮上。
- **去掉背景**：配置好[图片工具](#the-picture-tools-on-this-computer)后，在这台电脑上免费完成（**去掉背景（免费）**；第一次会下载它的模型）。没有这些工具时，会显示设置它们的卡片，或者 **改用 OpenRouter**，并标出价格。
- **擦除一部分**：涂抹要去掉的东西（**画笔**、**撤销上一笔**、**清除涂抹**），然后在这台电脑上 **擦除（免费）**，或者像上面那样通过 OpenRouter 来做。

然后会有一个滑块显示 **修改前** 和 **修改后**（拖动它，或者按 ← 和 →），并说明它是怎么做的。**保留** 会把它放进去；**重试** 再做一次；**用 AI 修改** 会在它的基础上接着改；在这台电脑上做出的结果之后，**改用 AI 来做** 会让图像模型重新做一次（需要付费）。

**绘图**（对话框 **绘图（SVG）**）：由形状而不是像素组成，任何大小下都清晰，而且文件很小。描述它，然后选 **它是什么**（**图标**、**插画**、**示意图**、**图案**、**标志** 或 **形状**）、它的 **形状**、它的 **颜色**（在幻灯片中是这套幻灯片自己的颜色；点击一种可以更换它，+ 可以加一种，最多 6 种），以及 **快速** 或 **最佳**：“快速”由 Claude（或[辅助模型](/settings?s=models&find=Helper%20model)）写出来，不用为图片模型付钱，最多一分钟；“最佳”由一个矢量模型（Recraft 的）通过 OpenRouter 绘制，需要付费。点 **画出来**，然后选 **重新绘制** 或 **使用**。

**数据图**（对话框 **数据图**）：由代码画出的图表，用于幻灯片的图表画不了的东西（散点图、直方图、误差线、函数）。说出要画什么（“按月的销售额柱形图，2025 年对比 2026 年”）。它的数据来自它要放的地方（文档中的表格、幻灯片上的图表：**显示数据** 会把数据显示出来）、来自 **导入文件**（CSV、TSV、JSON 或文本，最大 200 KB），或者直接粘贴。在幻灯片中，**另做一个会动的版本，用于放映** 会再加一张能响应指针的数据图，作为自定义代码，以这张图片作为它的封面（[互动部分](#interactive-parts)）。Claude（或辅助模型）写出它的 Python 代码，在这台电脑上运行：不花钱，也不需要密钥，但需要带 matplotlib 的 Python，图片工具会带一个。点 **生成数据图**；然后说出一处修改（**确认修改**），或者打开 **代码（Python）**，修改代码后点 **再运行一次**（Ctrl+Enter）；最后点 **使用**。

**视频**（对话框 **一段视频**，在幻灯片中）：说出视频里发生什么、镜头怎么移动，以及它的 **长度**、**形状**、**带声音**（模型能生成声音时）和 **从所选图片开始**（模型支持时）。那一行字会说明它可能要花多少钱（“用 … 生成 5 秒约需 $0.40 到 $0.80。视频比图片贵得多。”），按钮上也有。它需要几分钟：**关闭（会继续生成）** 让你可以接着做这套幻灯片，做好后会有一条提示“视频已做好”，带有 **插入**，点它就会把视频放进去。然后选 **再做一个** 或 **使用**。视频模型就是[设置 → 图片、视频和音频](/settings?s=images&find=Video%20model)中的那一个。

**没有 OpenRouter 密钥时**，对话框会当场向你要：“这会通过 OpenRouter 使用模型，需要你的 OpenRouter 密钥”，并带有一个输入框、**保存密钥**（它会存进[设置 → 模型](/settings?s=models&find=OpenRouter)）和 **跳过**（什么都不生成，也不花钱），在合适的地方还有一种不需要密钥的办法：图片可以 **改为绘图（SVG）**，绘图可以 **用“快速”绘制**。数据图不需要密钥；配置好图片工具后，去掉背景和擦除也不需要。

幻灯片和文档按图片生成时的样子保存它们（每张最大 12 MB）；页面则把它们保存在页面内部，并会缩小（最长边最多 1,600 像素，约 450 KB）。视频只能放进幻灯片。要自己裁剪图片、修改它的颜色或在上面加文字，见[编辑图片和视频](#edit-pictures-and-videos)。

## 这台电脑上的图片工具

去掉图片的背景、擦除图片的一部分，可以在应用所在的电脑上完成，而不用通过图像模型：免费、私密（你的图片留在这台电脑上），而且精确（抠图会保留主体原本的像素）。用 **[设置 → 功能 → 图片、视频和音频 → 这台电脑上的图片工具](/settings?s=images&find=Picture%20tools%20on%20this%20computer)** 中的 **配置** 把它们设置一次，也可以在某个工具用得上它们的地方，从它显示的卡片上设置（**安装（约 145 MB，只需一次）**）。

- **它们会下载什么**：一个它们自己专用的 Python，放在应用的数据文件夹中，带有 ONNX Runtime、NumPy、Pillow、Matplotlib、pandas 和 ffmpeg（约 145 MB，只需一次），然后在每个工具第一次使用时下载它的模型：背景去除工具（BiRefNet-lite，192 MB）和擦除工具（LaMa，208 MB）。两个都下载后，总共约占 1.3 GB 磁盘空间。设置或下载期间，它们下方的一行字会说明正在做什么（“正在下载背景去除工具（192 MB，只需一次）：40%”）；之后会说明它们已就绪、哪些模型已下载，以及哪些正在内存中。
- **内存**：每个模型只在用到它的工具时才加载，空闲约三分钟后就会离开内存，运行它们的程序也会在稍后停止。处理一张图片时，背景去除工具最多需要约 2 GB 内存，擦除工具约 1 GB；空闲内存不够时，工具会说明它需要多少，并提议改用 OpenRouter。它们在处理器上运行（不需要显卡）：每张图片几秒到半分钟。
- **力有不及时**：抠得不好的图会交给图像模型重新做；要擦除的区域很大（超过图片的约八分之一，或者横跨图片的五分之二以上），或者位于文字等精细内容之间时，会交给图像模型，由它把这块区域连同周围重新画出来。结果会说明它是用哪种方式做的；在这台电脑上做出的结果下方，**改用 AI 来做** 会请图像模型来做（会先显示价格）。
- **数据图和视频**：数据图也在同一个 Python 中运行（[用 AI 生成图片、绘图、数据图和视频](#make-pictures-drawings-plots-and-videos-with-ai)），在没有自带 ffmpeg 的电脑上，视频编辑器会使用它们的 ffmpeg（[编辑图片和视频](#edit-pictures-and-videos)）。
- **移除**：设置好之后，它会先问你（“移除图片工具？”），然后把它们的 Python 和模型从这台电脑上删掉；之后去掉背景和擦除会通过 OpenRouter 进行，需要付费。你可以再次设置它们。

它们需要这台电脑上有 Python 3.10 或更高版本，或者 uv；两者都没有时，这一部分会说明为什么无法设置。智能体也会使用它们（[抠图、擦除和编辑](/guide/documents-voice#cut-out-erase-and-edit)）；你让智能体设置它们时，它每次都会先问你。

## 编辑图片和视频

图片和视频在应用内部各自的编辑器中打开：对图片进行裁剪、旋转、调整、加滤镜和标注，或者用 AI 去掉它的背景、擦除其中的东西；对视频进行修剪、剪切、裁剪、加字幕、调色和配乐。可以从这些地方打开它们：

- **放大显示的图片**（在对话、回复或应用的结果中）：它顶部的 **编辑**。你保存的东西会作为一张新图片放进你的资料库。
- **资料库**：图片或视频页面顶部的 **编辑**。**保存** 会用编辑后的版本替换它（它的标题、说明、项目和文件夹都保持不变）；**另存副本** 会在它旁边保留一个新的，名为“…… (edited)”。
- **文件**：打开的图片或视频顶部的 **编辑**，或者文件的 **更多**（⋯）中的 **编辑图片** 或 **编辑视频**。**保存** 会覆盖这个文件，它的旧版本会进入废纸篓；**另存副本** 会在它旁边放一个“名称 (edited)”。不是 PNG、JPEG 或 WebP 的图片，或者要另存为其他文件类型的图片，会保存为副本。
- **幻灯片**：**格式** 菜单、右键菜单和侧边面板中的 **编辑图片**，以及（对于来自你设备的视频）**编辑视频**。**文档**：选中图片后，它工具条上的 **编辑图片**。**页面**（在 **编辑** 中）：选中图片后，它 **部分** 标签中的 **编辑图片**。在这些地方，**保存** 会把它放回原处，撤销可以一步撤回；**另存副本** 会把它保存到你的资料库中。
- **智能体生成或编辑的视频**：视频上方的 **编辑**。你保存的东西会放进你的资料库。

**保存** 旁边的箭头 **保存方式** 会说明每样东西保存到哪里。

### 在标签页中打开的编辑器

编辑器会在它自己的标签页中打开：顶部的一条横栏先显示你来自的页面（这套幻灯片、这份文档、这个会话、资料库、“文件”……），然后是每个编辑器的标签页，“图片 · 名称”或“视频 · 名称”。点击一个就会转到它：页面会保持它的位置和更改，对同一张图片再点 **编辑** 会回到它的标签页。标签页的 × 换成一个圆点，表示它有尚未保存的更改；这时关闭它会问“不保存就关闭‘……’吗？”（**不保存并关闭** 或 **取消**），离开应用时也会提醒你。在手机上，编辑器会占满屏幕，有一个返回页面的箭头；打开两个或更多编辑器时，用 **已打开的编辑器** 在它们之间切换。

### 图片编辑器

顶部是：**裁剪**、**调整**、**滤镜**、**标注** 和 **AI**，然后是 **撤销**、**重做**、**按住与原图比较**（按住它可以看到图片原来的样子）、**更多**（⋯：**适合屏幕**、**实际大小**、**恢复原图**）、**另存副本** 和 **保存**。滚动、捏合或拖动可以缩放和移动；双击一个滑块会让它回到起始位置。

- **裁剪**：**形状**（**原始比例**、**任意形状**、**正方形（1:1）**、4:3、3:2、16:9、9:16 或 4:5；然后拖动裁剪框）、**旋转**（**向左旋转**、**向右旋转**、**镜像**、**上下颠倒**）、**拉直**（向两边各最多 45°）和 **撤销裁剪和旋转**。
- **调整**：**曝光**、**亮度**、**对比度**、**高光**、**阴影**、**饱和度**、**自然饱和度**、**色温**、**色调**、**锐度**、**模糊** 和 **暗角**；**全部还原**。
- **滤镜**：你的图片套用每种风格后的样子（**鲜艳**、**暖色调**、**冷色调**、**黑白**、**棕褐色**、**褪色**、**哑光**、**暗黑**、**复古**、**胶片**、**戏剧感**、**黄金时刻**、**粉彩**，或者 **无**），以及它的 **强度**。
- **标注**：**移动**、**笔**、**荧光笔**、**箭头**、**直线**、**矩形**、**椭圆**、**文本**、**模糊区域**、**给区域打马赛克**（一张脸、一块车牌、一个名字）和 **表情符号**，每个都附有用法提示。选择 **颜色** 和 **粗细**；对于文字，选择 **字体**（**无衬线**、**衬线**、**等宽**、**手写** 或 **特粗**）、**大小** 和 **文字背景**（**无**、**深色** 或 **浅色**）；对于遮挡的区域，选择 **遮挡程度**。在你保存之前，标注都保持为标注：选中一个就可以移动它、拖动它的角来调整大小，或者 **删除标注**。
- **AI**：**去掉背景**、**抹除**（涂抹要去掉的东西）、**用 AI 修改**（说出要改什么，改整张图，或者用 **只改我涂抹的地方** 只改你涂抹的地方）和 **扩展图片**（扩展到 16:9、4:3、**正方形（1:1）**、4:5、9:16 或 **四周**，新增的部分由 AI 来画）。配置好[图片工具](#the-picture-tools-on-this-computer)后，去掉背景和擦除在这台电脑上免费完成（**去掉背景（免费）**、**擦除（免费）**）；没有这些工具时，会有一张卡片提议设置它们，或者 **改用 OpenRouter**，需要付费。修改和扩展会交给通过 OpenRouter 使用的“最佳”图像模型，价格写在按钮上。每个结果都会说明它是怎么做出来的（“已在这台电脑上免费完成”，或者“所用模型”加上模型和花费），撤销可以把它撤回；免费完成的结果之后，**改用 AI 来做** 会让图像模型来做。没有 OpenRouter 密钥时，它会当场向你要，和那些对话框一样（[用 AI 生成图片、绘图、数据图和视频](#make-pictures-drawings-plots-and-videos-with-ai)）。

**保存方式**：**尺寸（像素）**（**原尺寸**、75%、50%、25% 或任意尺寸，每边最多 8,192）、**文件类型**（**PNG** 保留每一个像素和透明部分；**JPEG** 适合照片，文件小，透明部分会变成白色；**WebP** 文件小，并保留透明部分），以及 JPEG 和 WebP 的 **质量**。Ctrl+S 保存；Ctrl+Z 和 Ctrl+Shift+Z 撤销和重做（80 步）；Delete 删除选中的标注。每边超过 8,192 像素或总共超过 4000 万像素（在触摸屏上是 1600 万）的图片，会缩小后再编辑，编辑器会说明这一点。

### 视频编辑器

顶部是：**修剪**、**裁剪**、**文本**、**调整** 和 **声音**，然后是 **撤销**、**重做**、**更多**、**另存副本** 和 **保存**。画面下方是：播放和暂停（空格键）、时间、**分割**（S）、**删除这一段**（Delete；对于已剪掉的一段，则是 **恢复**）和 **把这一帧存为图片**。再下面是时间轴：视频的各帧、保留部分两端各一个手柄、以斜线标出的剪掉的部分、一条放文字的轨道（拖动文字或它们的两端）和一条放音乐的轨道，对于幻灯片的视频，还有 **封面**。

- **修剪**：**保留的部分**（**开始于** 和 **结束于**，各自带有 **设为播放头位置**，或者拖动时间轴上的手柄）、**剪掉的部分**（每一段都带有 **放回原处**；要剪掉一段，在它的开头和结尾各分割一次，然后删除它）和 **播放速度**（0.25× 到 4×；声音保持原来的音高）。
- **裁剪**：**形状**（**任意形状**、16:9、9:16、**正方形（1:1）** 或 4:5；拖动裁剪框）、**旋转和镜像**（**向左旋转**、**向右旋转**、**镜像**、**上下颠倒**）和 **完整画面，恢复原样**。
- **文本**：**在播放头处添加文字**，然后是 **文字**、**文字大小**、**颜色**、**文字背景**（**无**、**深色底框** 或 **浅色底框**）、**粗体**、**位置**（**顶部**、**居中** 或 **底部**，也可以在画面上拖动文字）和 **显示时间**（**从** 和 **到**）；**删除这些文字**。最多 30 组文字。
- **调整**：**亮度**、**对比度** 和 **饱和度**，**淡入** 和 **淡出**（画面和声音，最长 5 秒），以及 **恢复原来的颜色**。
- **声音**：它自己的声音（**去掉原声**，或者它的 **音量**，最高 200%），以及来自你资料库中声音的 **音乐**（**试听**、**使用**；然后是 **音量**、**开始于** 和 **去掉音乐**）。

**更多** 里有 **把这一帧存为图片**、**用这一帧作封面**（用于幻灯片的视频）、**另存为 GIF**（最长 60 秒，没有声音）和 **恢复原图**。**保存方式**：**大小**（保持原样，或者 1080p、720p 或 480p）和 **文件类型**：MP4，在哪里都能播放；或者 WebM，更小，适合网页（覆盖保存一个文件或资料库中的视频时，会保持它原来的类型）。帧或 GIF 会放在文件旁边，或者放进你的资料库。生成期间，会有一行字说明进度，**停止** 会结束它，什么都不保存。编辑后的视频最长可以有 30 分钟。

视频编辑器需要应用所在的电脑上有 ffmpeg：电脑自己的，或者[图片工具](#the-picture-tools-on-this-computer)带来的那个。没有时它会显示“编辑视频需要 ffmpeg”，以及 **打开“设置 → 图片、视频和音频”**。它可以打开 MP4、MOV、M4V 和 WebM 视频。← 和 → 逐帧移动（按住 Shift 则每次一秒）；Home 和 End 跳到保留部分的两端。

## 按类型用 AI 制作

应用知道怎样把 216 种东西做好：幻灯片（SWOT 分析、时间安排、测验题）、整套幻灯片（融资路演、讲课、论文答辩）、文档（求职信、会议纪要、资助申请书）、文档中的章节（执行摘要、风险表）、页面（习惯打卡、落地页、贷款计算器）、页面中的模块（价格表、问答）和电子表格（预算、还款计划表）。选一种，愿意的话说说它是关于什么的，智能体就会根据已有的内容、按它的外观把它做出来：

- **幻灯片**：**插入 → AI 生成的幻灯片**、工具栏 **新幻灯片** 菜单的最上面，或者幻灯片列表中某张幻灯片的 **更多**（⋯）里的 **在后面添加 AI 生成的幻灯片**。它会放在正在查看的幻灯片（或那一张）后面。
- **文档**：**插入 → AI 生成的章节**，放在光标所在的位置。
- **页面**（在 **编辑** 中）：**添加 → 添加 AI 生成的模块**，放在 **放在** 指定的位置（**在它后面**、**放在它里面** 或 **放在最后**）。
- **新建的东西**：**新增** 中 **或者描述一下，让智能体来做** 旁边的 **选择类型**（用于页面、幻灯片、文档或电子表格：见[制作页面](#make-a-page)）。
- **用已有的东西**：资料库中卡片的 **更多**（⋯）里的 **转换为**，然后选 **幻灯片**、**文档** 或 **页面**（它还不是的那几种）：会用它做出一个新的，它本身保持不变。

类型库以卡片的形式显示各种类型，带有 **按名称查找** 和每一组的标签（比如幻灯片分在 **开场**、**内容**、**数字**、**步骤与时间**、**商务**、**教学**、**图片** 和 **结尾** 下面）。选一个就会显示它的描述；在 **关于什么？（可选）** 下面写上它是关于什么的，然后点 **创建**。在面向 PowerPoint 的幻灯片中，需要网页格式的类型（测验题、投票、记忆卡片、3D 模型、互动部分）会标上 **网页格式**，并在 PowerPoint 允许的范围内尽量做得接近（[面向网页或面向 PowerPoint 的幻灯片](#slides-for-the-web-or-for-powerpoint)）。

然后：

- **在资料库中**，编辑器的 **询问** 面板会打开，智能体会立刻开始（你的更改会先保存），使用你上次在开始页上选的智能体和模型。你会看到你的请求显示为一行（“在第 3 张幻灯片后添加一张：SWOT 分析 — 我们面包店的第一年”），智能体会先读取应用制作这类东西的方法（“正在读取‘SWOT 分析’的制作方法”），然后在你眼前把它做出来（[请智能体来修改](#change-it-by-asking-an-agent)）。
- **用“新增”中的类型或“转换为”时**，会立刻开始一个会话（“制作幻灯片：融资路演 — ……”“把‘面包店计划’转换为幻灯片”），使用你上次选的智能体和模型，放在你所在的项目中（用它的文件夹和助手），或者一个新的任务文件夹中，它做出的东西会放进你当时所在的资料库位置。
- **在对话旁边**，在打开页面和幻灯片的面板中，请求会放进那个对话的消息框，由你来发送。

## 请智能体来修改

打开的页面、幻灯片、文档、电子表格、LaTeX 文档或笔记本顶部的 **询问** 会在旁边打开一个面板（在手机上则盖在上面），由智能体在那里替你修改它：

1. 选择要改的范围：对于幻灯片，是 **这张幻灯片**、**所有幻灯片** 或 **选中的内容**（幻灯片上选中的部分）；对于文档，是 **整个文档**、**这一节**（你所在的那一节）、**选中的文字** 或 **选中的图片**；对于电子表格，是 **整个工作簿**、**这个工作表** 或选中的单元格；对于 LaTeX 文档，是 **整个文档**、**这个文件**、**这一节** 或选中的行；对于笔记本，是 **整个笔记本** 或选中的单元格（**单元格 3**）；对于页面，是 **整个页面** 或 **选中的部分**（在 **编辑** 中对某个部分用过 **问智能体** 之后）。
2. 说出要改什么（“把标题改短一点”“加一张幻灯片，用图表展示这些数字”“把这一节写得更亲切一些”“在数字下方加一行合计”“修正错误，让它能排版”），然后发送。还没保存的更改会先保存，好让智能体在它们的基础上修改。
3. 智能体会使用你上次在开始页上选的智能体和模型；面板会显示它的工作过程和回答，你打开的内容会随着它的编写显示它的更改，智能体的光标显示它的文字写到哪里（[观看页面的编写过程](#watch-a-page-as-it-is-written)）。大的改动可能会分步到来，每次一节或几张幻灯片，每一步保存后就会显示出来。每次更改都是一个版本，所以你可以回退（[回到早先的版本](#go-back-to-an-earlier-version)）。

在面板的消息框中可以接着说；消息框上方的按钮会把你指的是哪张幻灯片或哪个部分放进消息里。**新请求** 会重新开始，**作为会话打开** 会在单独的页面中打开这段对话（它会留在你的会话中）。在手机上，**查看页面** 会在智能体工作时把面板收起来；底部的按钮可以把它找回来。

**就此问智能体** 会打开这个面板，并带上你选中的内容：幻灯片上的一个部分、**编辑** 中页面的一个部分、文档中的文字或图片、电子表格中的单元格（在它们的右键菜单中），LaTeX 文档中的几行（在它的工具栏中用 **问智能体**），或者笔记本的一个单元格（在它的工具中用 **就这个单元格问智能体**）。笔记本的智能体也可以只是回答问题：“第 4 个单元格是做什么的？”LaTeX 文档的错误下方的 **请智能体修正** 会请智能体把它们全部修正。

页面旁边的智能体确切知道你选中了什么（幻灯片的编号和标题、一个部分和它的图片、单元格、几行内容、笔记本的某个单元格），也知道编辑器能做什么。除了修改文字、部分和单元格，它还能对整个页面做编辑器点一下就能做的事，每一项都是一个单独的版本，并会立刻显示出来：给每张幻灯片添加动画，修正辅助功能检查发现的问题，让幻灯片兼容 PowerPoint 或给它换一个主题，更新根据电子表格制作的图表，接受或拒绝修改建议，给工作表排序或删除其中重复的行，在新工作表上汇总一张表格，移动 LaTeX 文档的文件，或者清除笔记本的输出（[让智能体做编辑器能做的事](/guide/ask-agents#have-an-agent-do-what-an-editor-does)）。它会用自己的图片工具生成、修改和编辑选中的图片，并把结果放回原处。

## 重命名页面

点击顶部的页面标题，或者在页面中或列表中使用 **更多**（⋯）→ **编辑标题和说明**。输入新名称（最多 120 个字符），愿意的话也修改它的说明（见[说明](#descriptions)），然后点击 **保存**。页面的名称也是你把它添加到手机主屏幕时使用的名称。

## 回到早先的版本

页面的每次保存都是一个独立的版本：第一个版本（由你保留或制作，或由智能体保存）、智能体保存的每次更改、你在编辑器中保存的每次更改，以及你恢复的每个旧版本。页面更改时不会丢失任何东西。

1. 打开页面，点击 **版本**。
2. 列表显示每个版本（`v3`）、它的标题（当前版本标为 **最新**）、创建时间、创建者（**由智能体生成**、**由你保留**、**由你修改**、**由你创建** 或 **已恢复**）以及大小。
3. 点击一个版本查看它。页面上方的横幅会显示“旧版本，来自 2 天前。它在这里所做的更改不会保存。”旧版本可以使用页面的数据，但你在其中做的任何更改都会被丢弃。文档打开时，会在文字中标出自那个版本以来的更改，并在旁边列出它们（[与某个版本比较](#documents)）。
4. 点击 **恢复此版本** 让它成为当前版本，或者点击 **回到最新版本** 离开它。

恢复某个版本会把它作为一个新版本加在最上面（“版本 3 已恢复，成为版本 6”），所以它之后的版本也会保留。页面的数据不受影响。

智能体在回答一条消息时连续多次保存一个页面（比如一节一节地写文档），只会留下一个版本：最后那个，它那一行会写明它包含了几次保存（**4 次保存**）。你保存或恢复的版本永远不会被这样替换，你发出的下一条消息也会开始一个新版本。

页面保留它最新的 40 个版本。较旧的版本先被删除，所有版本加起来超过 24 MB 时也是如此；当前版本始终保留。

## 页面保存的数据

小工具需要记住一些东西：你记录的锻炼、你勾选的方框、你的预算条目。保留的页面会把这些数据存放在应用里，也就是应用运行的那台电脑上，而不是某一个浏览器里。所以无论你在哪里打开，它显示的数据都一样：在资料库中、在对话里它的卡片中，以及在你手机上它的独立地址。

- 列表和页面的顶部横条会显示它保存了多少数据（`keeps 14 KB`）。
- 一个页面总共可以保存约 2 MB，单个条目最多 512 KB，最多 1000 个条目。超过这些限制后，就无法再保存更多。
- 新版本和恢复的版本使用相同的数据。
- 智能体可以读取页面的数据，用来回答关于它的问题（“这个月我记录了几次跑步？”），或者修改页面以适应这些数据。
- [数据库](#databases)的行也保存在这里，放在它的名称下（`n-db:` 加上名称）。
- 页面的已发布副本不会保存数据（见[发布页面](#publish-a-page)）。

要查看页面保存了什么，打开它，然后使用 **更多**（⋯）→ **它保存的内容**。每个值按名称列出，并显示它的大小和更改时间；点击一个值就可以读取它。值旁边的垃圾桶会删除这一个值；**下载** 会把所有值保存为一个 `.json` 文件，**全部清除** 会清空页面的数据（页面本身会保留）。这两种删除都会先问你，而且无法撤销。

## 在手机上使用页面

每个保留的页面都有它自己的独立地址。这个地址只打开这个页面，带着它的数据，在任何设备上都能打开，而且不需要登录 Hydor：很适合你在手机上填写的跟踪表。

1. 打开页面，点击 **分享**。
2. **在你的手机上** 下面会显示地址。点击复制按钮，或者点击旁边的打开按钮试一下。
3. 在手机上打开这个地址。要把它添加到主屏幕：
   - **iPhone**：在 Safari 中打开，然后点 **共享** → **添加到主屏幕**。
   - **Android**：在 Chrome 中打开，然后点 **⋮** → **添加到主屏幕**。

从主屏幕打开时，页面会像应用一样全屏显示，并使用它自己的名称。在独立地址打开时，它会跟随手机的浅色或深色设置。

任何拿到这个地址的人都可以打开这个页面，并更改它保存的内容，所以只把它分享给你在这方面信任的人。你的手机也必须能访问应用的地址（[从其他设备访问应用](/guide/devices#reach-the-app-from-another-device)）。

### 给页面换一个新地址

如果某个地址被发到了不该去的地方，就替换它：

1. 打开页面，点击 **分享**，然后点击 **给它换一个新地址（旧地址会失效）**。
2. 确认 **新地址**。旧地址会立即失效，已添加到主屏幕上的也一样。“页面有了新地址”表示已完成。

在你需要的地方，把新地址重新添加到主屏幕。

## 删除页面

在页面的卡片上或打开的页面中使用 **更多**（⋯）→ **删除**，并确认。页面会连同它的所有版本、它保存的数据以及它的任何已发布副本一起删除。它的地址也会失效。

资料库最多可容纳 1000 个页面和幻灯片。单个页面的 HTML 最大 2 MB；幻灯片的文字最多 3 MB，图片另算（每张最多 12 MB）。

## 发布页面

发布会把页面放到一个链接上，别人不需要应用的密码就能打开。用它来给别人看你做的报告或小工具。

1. 打开页面，点击 **分享**，然后点击 **发布到别人能打开的链接**。
2. 检查 **名称**（最多 60 个字符）。
3. 选择链接类型：
   - **私密链接**：一个无法猜到的链接，只有你把链接给了的人才能打开。
   - **公开链接**：一个由名称生成的可读链接（比如 `/site/trip-plan/`），任何人都可能找到并打开它。
4. 点击 **发布**。框中会显示链接，以及复制和打开它的按钮。点击 **完成**。

已发布的副本显示的是页面现在的样子，之后的版本也会显示在那里。它不会保存数据：别人输入的内容在重新加载后就没了。要自己在手机上使用页面并保存数据，请改用它的独立地址打开（[在手机上使用页面](#use-a-page-on-your-phone)）。

链接以你访问应用时用的地址开头，所以只有能访问那个地址的人才能打开它。如果只有你自己的设备能访问应用（比如通过 Tailscale），那么也只有它们能打开这个链接（[从其他设备访问应用](/guide/devices#reach-the-app-from-another-device)）。

## 从文件夹发布网站

你也可以发布项目构建出来的网站，比如用 Vite 或静态网站生成器做的应用：也就是构建输出的那个文件夹，里面要有一个 `index.html`。

1. 打开 [资料库 → 已发布](/library?tab=published)，点击 **发布文件夹**。
2. 选择 **文件夹**：一个包含 `index.html` 的已构建网站（构建后的 `dist/`、`build/` 或 `out/`）。
3. **名称** 会根据文件夹的名称自动填写；你可以修改它。
4. 选择 **私密链接** 或 **公开链接**，然后点击 **发布**。

网站直接从磁盘上的文件夹提供，所以新的构建会立即显示，不需要重新发布。可以发布的内容：

- 文件夹必须包含 `index.html`；
- 不能是你的主文件夹、主文件夹的上一级、磁盘的根目录、应用自己的数据，或者隐藏文件夹（名称以点开头的文件夹）里的文件夹；
- 最多 5000 个文件、300 MB；
- 名称以点开头的文件和文件夹（`.env`、`.git`）永远不会被提供。

网站内没有对应文件、也没有文件扩展名的地址（`/site/…/about`）会得到网站的 `index.html`，这样自己切换页面的应用也能正常工作。如果文件夹被移动或删除，链接会显示它已不存在：请重新发布。

### 已发布的网站能做什么

已发布的网站运行在它自己的一个封闭项目中，与应用隔离：没有 cookie，没有应用的任何登录信息或数据，它在浏览器中保存的内容在重新加载后就会被忘掉。它没有自己的服务器代码。它可以从自己的文件以及三个公共脚本托管站点（jsDelivr、unpkg 和 cdnjs）加载脚本，并通过 HTTPS 调用外部服务。私密链接不会被搜索引擎收录。

从地址根路径（`/assets/…`）加载文件的已构建网站，在网站的链接下找不到这些文件。请用相对路径构建它们（在 Vite 中是 `base: './'`）。智能体请求发布这样的文件夹时，会被提醒先重新构建。

## 当智能体请求发布时

智能体也可以发布，但必须得到你的同意。说“发布我的网站”或“把旅行计划放到网上”，智能体会在对话中显示一张卡片：

- **发布“旅行计划”？**，以及它要发布的内容：保存的页面，或者文件夹及其文件数量和大小；
- 可供选择的 **私密链接** 或 **公开链接**，以及各自的含义：“它会在沙盒中打开，与本应用相互隔离；你可以随时在资料库中取消发布。”；
- **发布** 和 **暂不**。

在你点击 **发布** 之前，什么都不会发布。然后智能体会收到一条消息，告知结果和链接。卡片会变成 **已发布“旅行计划”**，并附上可复制或打开的链接；如果你点击了 **暂不**，会变成 **未发布：“旅行计划”**；如果发布失败，会变成 **“旅行计划”发布失败**，并附上原因。

一个会话中，智能体最多可以有五个等待中的发布请求。

## 查看和取消发布你发布的内容

[资料库 → 已发布](/library?tab=published) 列出所有已发布的内容，最新的排在前面。每一项显示它的名称、**私密链接** 或 **公开链接**、它提供的内容（页面的标题或文件夹的路径）和发布时间，以及可复制或打开的链接。

要撤下其中一项：

1. 点击它旁边的 **取消发布**。
2. 确认 **取消发布**。“它的链接会立即失效。”“已取消发布”表示已完成。

你以后可以再次发布它；届时私密链接会是一个新的链接。删除保留的页面也会取消发布它。同一时间最多可以发布 200 个网站。

没有发布任何内容时，会显示“没有已发布的内容”，以及 **发布文件夹**；打开 **已发布** 时，它也在右上角。
