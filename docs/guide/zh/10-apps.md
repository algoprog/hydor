# 应用

应用是一项你会反复运行的任务：填一张简短的表单，按下“运行”，智能体就会完成工作并交回结果，结果显示在为它做的视图中（一页页可以点开和操作的页面，带有地图、图表、图片和视频），或者以卡片和表格的形式呈现。本主题介绍现成应用、如何运行应用、应用需要的密钥、如何在任何会话中让智能体替你运行应用、如何创建你自己的应用（步骤、视图、它自己的文件、数据、记忆、界面）、如何共享应用（API 密钥、其他智能体、公开页面、CSV 的各行），以及如何把应用作为文件传给别人。智能体连接的服务就在应用旁边：见[已连接的应用、密钥和工具](/guide/connections)。

![应用：你自己的应用，以及一开始就已安装的现成应用](images/apps.webp)

## 什么是应用

应用是只做一件事的小工具，帮你看清和找到信息：你回答几个问题，它的步骤会去查找、计算，答案会显示在为它定制的视图中（地图、图表、表格、卡片）。使用它有两种方式：在应用页面上打开它，或者直接在任何会话中提出它能做的事，智能体就会在那里替你运行它。应用有意做得很小：每个只把一类问题回答好，而不是一个大程序。

应用保存了一项任务所需的一切，只有每次都会变的细节除外：

- **表单**：每次运行前要回答的问题（“去哪里？”“天数”）。
- **任务**：要智能体做的事，其中会填入这些回答。
- **答案**：结果中的各个字段（一段摘要、一个列表、一张表格），由智能体在完成时填写。没有回答字段的应用，则以智能体的回复作为结果。
- **由谁来做**：智能体、它的模型、它的模式，以及它可以使用的工具。

每次运行应用时，Hydor 都会用填好的任务启动一个会话。智能体会从头到尾一口气做完，中途不会停下来问你：它会做出合理的假设，并说明做了哪些假设。这样完整的一次就叫作一次**运行**。之后你还可以对结果提出修改，智能体会交回更新后的结果。

点击侧边栏底部的**应用**图块打开应用页面，或前往 [/apps](/apps)。在手机上，侧边栏是一个抽屉：先把它打开。你也可以在搜索框中输入应用名称来找到任意应用，无论是你自己的还是现成的（Ctrl+K，Mac 上为 ⌘K）。

## 认识应用页面

页面标题是**应用**，有两个标签页：**智能体应用**，也就是本主题介绍的应用；以及**已连接的应用**，即每个智能体都能使用、只需连接一次的服务，还有它们使用的密钥（[打开“已连接的应用”](/guide/connections#open-connected-apps)）。每个标签页都会显示它有多少项。在**智能体应用**上，顶部是**新建应用**：它的菜单里有**向智能体描述它**、**从零开始**和**从文件安装**。然后从上到下是：

- **已置顶**：你最常用的应用，以大图块的形式按你排好的顺序显示，轻点一下就能打开。在应用卡片的**更多**（⋯）中，或者在应用自己页面的**更多**菜单中选**置顶**，就会把它放到这里；在同样的地方选**取消置顶**，就会把它拿掉。拖动图块可以移动它（在手机上，先按住它），也可以用图块的**更多**（⋯）：**取消置顶**、**左移**和**右移**。最多 12 个应用；它们由应用保存，所以每台设备上显示的都一样。
- **查找应用：天气、食谱、旅行…**：一个输入框，随着你输入，按名称、类别或用途找出任何应用（你输入的每个词都必须在某处对得上；英文的复数也能找到单数：“recipes”能找到一个 recipe 应用），范围包括你自己的应用、现成应用、你卸载了的应用和构建模块，最相符的排在最前。按 Enter 打开第一个；按 Esc 清空输入框。页面滚动时，它会一直停在顶部。它下面是每个类别的标签，标着这个类别有多少个应用（**全部**在最前，然后是现成应用的各个类别），用来只显示一个类别。
- **最近使用**：你最近运行过的应用，每个只出现一次，最新的排在最前（最多 8 个）：无论是从它的表单运行、在它自己的页面或界面上运行，还是由智能体在对话中替你运行的。每张卡片都会说明它上次被问了什么、那次运行的状态和时间，并带有**打开结果**（有专属视图的应用会在它的页面上打开）、等你处理时的**去回答**、工作中的**跟进**，或者失败或停止时的**打开这次运行**；还有**再运行一次**，它会打开表单，填好和上次相同的回答。标题旁边的**最近的运行**会以列表的形式展开你最近的运行（最多六次）；在你用过任何应用之前，这一部分显示的就是它们，名称也是这个。来自 CSV 各行和公开页面的运行不在这个列表中，而是留在各自的应用下；在自己的页面上打开的应用（探索）的运行也一样，它的最新一次会显示在那里。在你置顶任何应用之前，会有一行提示，告诉你可以从最常用的应用的 ⋯ 菜单把它们置顶。
- **从这些开始**：在你运行任何应用之前，这里有四个大多数人都会用的现成应用（**天气展望**、**旅行规划**、**用现有食材做饭**和**比较产品**），点一下就能打开它的表单，还有一行说明应用是什么，以及**了解更多**（[什么是应用](#what-an-app-is)）。
- **你自己的应用**：你做的、或从文件安装的应用，标着有多少个，还有**制作应用**图块，点它会新建一个应用（向智能体描述它、从零开始，或者安装一个文件）。你自己的应用有四个或更多时，标题旁边的按钮可以按**最常用**、**按名称排序**或**最新**排列它们；这台设备会记住你的选择。
- **现成应用**：Hydor 自带并已安装的应用，按类别排列（**研究**、**规划中**、**购物**、**天气**、**体育**、**美食**、**娱乐**等）：运行其中一个，或者把它改成你自己的，再去修改它。

每张卡片（包括你自己的应用）大小都一样：它的图标、名称和用途，然后是它要问什么（它表单中的问题，或者**可以运行了**），一些小标记（把指针指向一个，就会显示它的说明：它的答案在专属视图中打开，带有地图、图表和表格；它可以在对话中使用，所以你可以在任何会话中提出它能做的事，智能体就会在那里运行它；它需要一个应用还没有的密钥；公开页面已开放时显示**公开**），在相应情况下显示**未安装**或**构建模块**，还有它上次运行的时间。它的**更多**（⋯，在卡片右上角；在电脑上，指针移到卡片上时才会出现）里有**打开**、**置顶**（或**取消置顶**）和**下载为文件**。没有应用符合你输入的内容时，页面会显示“还没有应用能做这件事”，以及**向智能体描述它**，它会带着你的话启动应用搭建师。

在它们下面：

- **可安装的现成应用**：你卸载某个现成应用后才会出现。每张卡片会显示它的类别、它做什么，以及你能从中得到什么（它的视图有哪些页面，比如“旅行规划”的**你的旅行**、**每日行程**、**提前预订**和**预算**），还有**安装**（见[安装或卸载现成应用](#install-or-uninstall-a-ready-made-app)）。
- **构建模块**（折叠，标着有多少个）：专门用作你自己应用步骤的小应用（总结网页、翻译、从网上找答案、分类、提取事实），以及你自己做的模块；每个应用的步骤里，**添加步骤**都会提供它们。

运行的状态以标记显示：**等待中**（在排队）、**正在启动**、**工作中**、**需要你处理**（它在等你批准或回答）、**完成**、**失败**或**已停止**。

把应用的文件（`.hydor-app` 或 `.json`）拖放到页面上的任意位置即可安装它：会先打开一张说明它是什么的卡片（见[把应用作为文件分享](#share-an-app-as-a-file)）。

在手机上，页面只有一栏：已置顶和最近使用的应用各排成一行，可以左右滑动，类别标签也一样；卡片上只显示名称和用途。

## 使用现成应用

这些应用随 Hydor 提供，并且已经安装：它们一开始就在**你的应用**中，智能体也能在你的会话中替你运行它们（见[让智能体替你运行应用](#have-an-agent-run-an-app-for-you)）。每个都按步骤工作：它的页面会显示**它是怎么工作的**，**以图查看**（或**改成我自己的**）会在编辑器中打开这些步骤。每个应用都会在自己的视图中交回答案，视图里有对应它各个部分的页面，还有能做事的按钮（见[它的视图](#its-view)）。除非你在应用页面上选了别的智能体，否则它们的智能体步骤都用 Claude Code 运行；它们的快速步骤则交给辅助模型（设置 → 模型）。带有“让我……”这类问题的应用，只有在你打开这个开关、并且有人可以回答时，才会中途停下来等你：从表单运行，或由智能体在你的某个会话中运行。

- **深度研究报告**：就任何问题写一份有出处的报告：搜索网络、交叉核对事实，每个说法都注明来源。你只需给出主题、重点、深度和读者对象。它会先规划要研究的问题，每次同时搜索三个，给来源排序，并行阅读最好的页面，某个问题来源不足时再搜一次，最后写出带编号引用的报告；**让我先检查问题**会让它等你保留或修改这些问题。它的视图有**摘要**（问题、可信度和各项主要发现，每项发现都带**深入研究**，可以就它单独开始一份报告）、**完整报告**（带**复制报告**）和**来源**，来源可以只看某个出版方的。
- **旅行规划**：按天安排的行程，并对照你的日期核实过（开放时间、活动、路上要花的时间），附带预算和需要提前预订的事项。它先算出日期，然后并行查找活动和节假日、天气（离出发十天以内时查天气预报）、可看的景点和住宿地点，以及当地交通，再安排每一天、算出预算；**让我在规划前先选**会让它问你想住在哪里、计划里必须有什么。它的视图有**你的旅行**（用数字概括的行程、计划、各天一览和小贴士；**轻松**、**均衡**或**紧凑**，以及**+ 再加一天**，会按那样重新规划）、**每日行程**（一条时间线，每天的上午、下午和晚上都可以勾掉，每天开头有一张当天主要景点的图片，并附有当天所在区域的地图）、每一天的单独页面（它的图片，带**复制这一天**，以及**研究**当天的区域）、**地图**（每天的区域都标在地图上，按顺序编号并连起来）、**提前预订**（订好一项就勾掉一项的列表）和**预算**（一张图表和各项估算）。
- **比较产品**：当前价格、独立评测和已知问题，按你看重的方面逐一权衡，并给出明确的推荐。如果你描述的是需求而不是列出产品，它会先找出可选的产品（**让我挑选要比较哪些**）；然后逐一调查，每次三个，给它们打分，并按你看重的方面排出名次。它的视图有**首选**（推荐的产品和它的图片、它的价格和理由，以及它权衡过的其他产品）、**并排**（每个产品满分 100 的得分画在图表上，然后是每个产品的图片、优点和缺点，首选会标出来）、每个产品的单独页面（带**研究它是否耐用**）和**注意事项**。它的答案也会写明**首选**，名称和比较中列出的一致，供程序使用。
- **文档问答**：根据你附上的文档回答问题，每个回答都附上原文段落及其位置。它会读取文档，为每个问题找出相关段落，每次回答三个，同时写出一份文档摘要；如果还有问题没有答案，就让一个智能体通读整份文档。它的视图有**回答**（每个回答都附有原文段落及其位置；**查找问题**可以缩小范围，**就这份文档再问些问题**会用新的问题和同一个文件再运行一次）和**文档**。
- **会议记录转行动项**：从原始笔记或会议转录中整理出决定、带负责人和日期的待办事项、未决问题，以及一封跟进邮件。它会拆分笔记，提取做出的决定，从今天起算出截止日期，并问你没人认领的行动项由谁来做（**问我没人认领的事由谁来做**）。它的视图有**概览**（参会的人、用数字概括的会议、摘要和做出的决定）、**操作**（每完成一项就勾掉一项，也可以只看某个人的）、**跟进邮件**（带**复制邮件**）和**仍未解决**。
- **求职信**：针对某个职位的求职信，以你经历中的真实例证为依据，并坦诚指出不足之处。它会读取招聘启事，弄清这个职位要求什么，一边查这家公司一边匹配你的例证，写出求职信，然后检查并修改，最多两次。它的视图有**求职信**（单独占一页，带**复制求职信**；**亲切**、**自信**或**正式**，以及**简短**或**标准**，会按那样重写）、**你为什么合适**（每项要求旁边是你的证据）和**要准备的不足之处**，可以逐项勾掉。
- **教案**：从教学目标倒推、带时间安排的一节课，包括课堂活动、理解程度检查、辅助支持和拓展提高。它会核实要教的事实，并分配好各部分的时间，让它们加起来正好。它的视图有**概览**（教学目标，以及准备好一项就勾掉一项的材料）、**时间安排**（整节课画成一条长条，每个活动的宽度和它的分钟数成正比，下面是各个活动）、**支持与检查**和**完整教案**（带**复制教案**）。
- **每周新闻摘要**：你关注的主题在过去一周的动态，取材于原始报道，合并重复内容，并说明每条新闻为什么重要。它会搜索每个主题这一周的新闻，每次三个，合并相同的报道，阅读其中最好的，再挑出要保留的。它的视图有**报道**（每条都带它自己网页上的图片；可以只看某个主题的，把每条标为已读，或**研究**其中一条）和**新闻摘要**（带**复制新闻摘要**）。
- **解读合同**：用浅白的话讲清协议的内容：关键条款、日期、不寻常之处，以及签字前该问的问题。附上文件或粘贴文本即可。它会把合同拆分成条款，并行阅读各个部分，遇到严重的问题还会让一个智能体再看一遍。它的视图有**简而言之**（主要内容、用数字概括的风险点，以及要问的问题，带**复制问题**）、**风险点**（按严重程度，可以只看某一种）、**关键术语**和**日期**。
- **做一个小型网页应用**：根据描述做出一个能用的应用，使用纯 HTML、CSS 和 JavaScript，直接打开文件就能运行，交付前会先测试。它会先规划应用（**让我在构建前先检查计划**），然后构建、测试，并修复到测试通过为止，最多修复两次。它的视图有**做出了什么**（怎么打开它、它的文件，以及**改动后重新构建**）和**后续步骤**，可以逐项勾掉。

日常用途的应用更小也更快：有免费服务提供数据的地方，就取用真实数据（天气用 Open-Meteo，还有 TheSportsDB、食谱用的 TheMealDB、TVmaze、CheapShark、Open Library、维基百科、OpenStreetMap），由程序算出必须精确的部分，再由一个快速模型阅读、挑选，并用浅白的话说出来。它们都不需要密钥。

- **天气展望**：任何地方未来几天的天气：图表上的最高最低气温和降雨概率、未来 48 小时、最适合你计划的日子、该穿什么以及要注意什么。给出一个地方（一个城镇，或带上地区，比如“Paris, Texas”）。它的视图有**预报**（现在的天气，每一天是一块小卡片，点开可看当天逐小时的情况，还有图表；**用 °F** 或**用 °C**，以及**看未来 14 天**，会按那样重新运行）、**未来 48 小时**和**穿什么**（带**复制天气预报**、**最佳出行月份**，以及这个地方的地图）。
- **最佳出行时间**：任何地方逐月的天气，取过去五年的平均：图表上的气温、雨天和日照时数，每个月按你想在那里做的事打分（城市观光、海滩、徒步、雪、避暑）。它的视图有**逐月**（顶部一张这个地方的照片、最佳月份、按合适程度上色的十二个月、图表；**最适合**可换一种旅行）、**什么时候去**（最佳月份及原因、不宜去的月份、小贴士）和**数字**。
- **球队追踪**：任何球队接下来的比赛、最近的赛果和状态、排名，以及本周的新闻。它的视图有**球队**（队徽、用彩色字母表示的状态、下一场比赛，带**看前瞻**）、**赛果**（图表上的得分和失分）、**赛程**（每场都有**预览**，会开始一次赛前前瞻）和**新闻**。
- **赛前前瞻**：两队交锋之前：各自的状态、最近的交手、球队消息和专家的看法，以及每种结果的概率。它的视图有**预览**（两个队徽、可能的结果、用一根条表示的概率）、**状态和交手记录**（最近交手谁赢了，画在图表上）和**球队消息**（带**复制前瞻**和**关注**这支球队）。
- **用现有食材做饭**：为你冰箱里的东西找食谱：每道用到你的哪些、你还需要什么，附照片、按时间排好的步骤，有视频时也附上。说明你的饮食和有多少时间；盐、油和香料默认算作已有，除非你另外说明。它的视图有**食谱**（**来点更快的**会重新运行）、每道食谱的单独页面（步骤排成一条按分钟分段的条，做的时候逐一勾掉，你已有的食材会标出来，**复制步骤**）和**要买什么**。
- **餐食计划和购物清单**：按你的家庭、饮食和喜好挑选一周（最多两周）的晚餐，每道都有食谱和照片，另附一份所有晚餐合在一起的购物清单，用量已经加总，按货架分好。它的视图有**这一周**（**再规划一周**）、每顿晚餐的单独页面（食材、做法和视频）、**购物清单**（只看一个货架，边买边勾掉，**复制清单**）和**小贴士**。
- **礼物点子**：在你的预算内为某人挑选贴心的礼物，有实物也有体验，每件都说明为什么适合 TA、通常的价格，以及一件现在就能买的、它的价格和商店。它的视图有**点子**（每个都带一张可买礼物的图片，按类别；**☆ 收藏**你喜欢的，**更多类似的**会重新运行）和**按价格**（图表上的价格区间）。
- **看什么**：按你今晚的心情挑选的电影和剧集，附上每部在你所在国家的播放平台（你已有的平台排在前面）、时长、预告片和为什么适合。它的视图有**今晚**（今晚的推荐，然后是其他的；图片上的 ▶ 表示有预告片）、每部的单独页面（在那里播放它的预告片，带**看过了：重新挑选**）和**并排**。
- **找游戏**：按你的喜好和游戏平台（可选 Nintendo Switch 2）挑选的游戏，可以是已发售的、即将推出的（附上各自的发售时间）或两者都有，每款都带图片和预告片，说明为什么适合、要玩多久；PC 游戏还附今天的最低价和史低价。它的视图有**游戏**（图片上的 ▶ 表示有预告片，尚未发售的游戏会写出何时推出）、每款游戏的单独页面（在那里播放它的预告片，带优惠和**更多类似的**）、**价格**（图表上的当前价和史低价）和**通关时长**。
- **任意主题测验**：直接在页面上玩的测验，题目所依据的事实取自维基百科：选一个答案，它会显示你答对没有以及原因，顶部显示你的得分；每次答案的顺序都会打乱。它的视图有**玩测验**（**重新开始**、**来个更难的**、**新题目**）、**回答**和**关于这个主题**（带**复制测验**）。
- **找书**：根据你喜欢过的书，推荐你很可能会爱上的书，每本都在 Open Library 核对过封面、页数和评分。它的视图有**你的书架**（每本书都有单独页面，带**更多类似的**）和**阅读清单**（**标为已读**）。
- **近期活动**：在你选的日子里（默认是即将到来的周末）城里有什么可做：从网上找到的音乐会、市集、展览和家庭出游，附每天的天气。它的视图有**按天**（每个活动都带它自己网页上的图片）、**地图**（每个场地都编了号）和**按类别**；标出你要去的（**要去吗？**），或**复制清单**。
- **储蓄计划**：如何在某个日期前存够目标：每月该存多少（加上利息）、余额在图表上的增长，以及多存或少存 20% 时什么时候能达成。它的视图有**计划**（你填了金额时，有**每月多存 50**或**每月少存 50**）、**逐月**（里程碑和每个月）和**小贴士**。
- **把数据画成图表**：把电子表格、CSV 或你粘贴的数字画成最多三张合适类型的图表，并用几句话说明它们显示了什么。它的视图有**图表**、**数据说明了什么**（每条发现都能复制）和**数据**（各列的概况，以及**就这份数据再问一个问题**）。
- **主题时间线**：把任何主题变成时间线，内容取自维基百科：带日期的关键时刻（选**详细**时最多三十个）、各个时期和简要经过。它的视图有**时间线**（可只看一条线索；**就它出个测验**会就这个主题开始一次测验）和**图表**（按年份排列的时刻，转折点画得更大，以及各个时期）。
- **探索一个地方**：任何地方周边有什么，标在地图上：景点、博物馆、公园和地标，每处配一张图和一句介绍，挑出最适合你的并按步行顺序排好。它的视图有**步行路线**（地图上编号并连起来的站点，每处都可标为看过；**那里的天气**）和**周边的一切**（只看一种类别）。

研究和实验室类的应用帮你跟上所在领域的进展，阅读和检查论文，照看你的实验和报告。其中几个和“探索”一样，在自己的页面上打开，并且可以自动更新；[研究](/guide/researchers)主题介绍了它们怎样配合使用。

- **论文雷达**：每天早上带来你所在领域的新论文（arXiv 上你关注的分类、主题和人的论文，以及 OpenAlex 上与你的主题相关的论文），按你的项目、主题和档案排序，每篇都用一句话说明它做了什么、为什么对你重要。它在自己的页面上打开，可以每天更新。它的视图有**今天**（论文放在每篇所契合的项目或主题下面，带有 **☆ 保存**、**引用**、**PDF**、**深入研究**和**不适合我**，它们会影响之后几天的挑选）和**已保存的论文**（带有**全部复制为 BibTeX** 和**加入阅读清单**）。见[跟上你所在领域的进展](/guide/researchers#keep-up-with-your-field)。
- **引用提醒**：自它上次查看以来谁引用了你的论文，附上引用你的那句话（其中提到你论文的地方会标出来），并说明对方是基于、比较、质疑还是只是提及你的工作。它在自己的页面上打开。它的视图有**新增**（按你的论文分组的新引用；可以只看一种）和**你的论文**（每篇都有它的引用数和其中有多少是新的）。
- **新模型追踪**：Hugging Face 上某一类的新模型（重排序模型、嵌入模型等），按你对许可证、大小和下载量的要求检查，概括每个模型的卡片；如果给了你的评估命令，每个模型都会在“实验”中运行，只有某个模型超过你的最佳成绩时才会告诉你。它在自己的页面上打开。它的视图有**模型**（每个的状态、它的卡片怎么说、它的分数）和**你的评估**。
- **截稿雷达**：你投稿的会议的截稿日期，取自开放列表 ccfddl 和 ai-deadlines，从 AoE（或征稿启事给出的时区）换算到你的时区，在你设定的那几天（14、3 和 1 天）用一条通知提醒你，并链接每个征稿启事的页数限制和模板。它在自己的页面上打开。它的视图有**时间安排**（每个截稿日期及剩余时间、**复制截稿日期**、**显示已过去的**）和**会议**。
- **动态相关工作**：每个主题一个页面，随着新论文出现而增长（arXiv 和 OpenAlex 上的论文，以及引用你的种子论文的论文），每篇论文都有一句话概括并说明它的关系，按方向分组，新的会标出来。它在自己的页面上打开。它的视图有**相关工作**（每个主题按方向排列，带有**起草相关工作**（由智能体写出的、带 `\cite` 键的 LaTeX 章节）、**导出 BibTeX**，以及论文上的**不相关**）和**本次新增**。
- **研究空白发现器**：把你的论文和某个领域本月的论文交叉得到的项目点子，每个都检查了前人工作（**新增**、**部分已有人做过**或**已有人做过**，附上最接近的论文），并按你拥有的算力估算规模，附上它的第一个实验。它的视图有**研究想法**（每个都带有**规划它**，会用它打开研究冲刺应用，还有**深入研究**）和**交叉组合了什么**。
- **阅读清单**：按项目整理你的论文，每篇都有它的 PDF、BibTeX、标签、状态和备注，并与 Zotero 保持同步。它打开时显示你的论文：**+ 添加**会按 DOI、arXiv ID、链接或标题查找一篇论文并填好它（已有的论文会被补全，不会重复添加）；可以搜索论文，只显示一种状态、一个标签或一个项目，并把每篇标为**待读**、**在读**或**已读**。论文自己的页面有它的链接、备注和 BibTeX，以及**复现它**；**按项目**统计每个项目的论文。**更多**里有**导入 .bib**、**导出 .bib** 和**与 Zotero 同步**（第一次会要它的密钥），勾选的论文可以制作**文献矩阵**。见[阅读和整理论文](/guide/researchers#read-and-organise-papers)。
- **文献矩阵**：把论文并排读进一张电子表格：每篇一行，你要比较的每一项一列（除非你修改，否则是 Task、Data、Method、Metrics、Results 和 Limits，即任务、数据、方法、指标、结果和局限），每个单元格都注明出自哪一页。每行给一篇论文，或者用“my reading list”加上标签、项目或状态。它一次读三篇，并把矩阵保存在你的资料库中。它的视图有**矩阵**（**在资料库中打开**、**复制为表格**、它没能读的论文及原因，以及**再加一列**）、**论文**和**综合来看**。
- **复现论文**：运行论文的代码来检查它的数字：它找到代码（在论文里，或在 GitHub 和网上），搭建一个干净的环境，获取数据和检查点，先在一小部分数据上运行，再正式运行（耗时长的放在[实验](/guide/experiments)中运行，并等它结束），全程守住你给出的限制，并把每个数字和论文的对比。它的视图有**复现成功了吗？**（论文的数字与我们的数字并排、**打开文件夹**、**重试**）、**过程**和**报告**。
- **审稿人模拟器**：用会议自己的审稿表和评分审阅你的草稿（ACL Rolling Review、SIGIR、NeurIPS、ICLR、ICML、KDD、CIKM、WSDM、TheWebConf 或期刊），最多五位审稿人，各有自己的角度，再加上领域主席的元评审。它的视图有**审稿意见**、**元评审**（附上可能让它被拒的问题，最危险的排在最前）、审稿人会要求的**基线和消融实验**，以及**投稿之前**（一份可以逐项勾掉的清单，以及**回复这些审稿意见**，会启动反驳工作台）。见[审阅、回复和展示你的论文](/guide/researchers#review-answer-and-present-your-paper)。
- **反驳工作台**：把各位审稿人的要点归并并分类（误读、需要实验、需要文字、次要），在会议的限制内用你选的语气为每个要点起草回复，需要新结果的地方留下占位符。它的视图有**提出的要点**（每个都有它的草稿、长度与分到的限额对比，以及**复制**）、**待办**（要做的实验和修改，可以逐项勾掉）和**完整反驳**（带有**复制完整反驳**）。
- **论文转演讲、海报和推文串**：从你的论文做出你选的那些东西：用上论文真实的图和公式、按时间安排并附讲稿的幻灯片，一张 A0 海报（一份 LaTeX 文档），发到 X 和 Bluesky 的推文串和发到 LinkedIn 的帖子，以及一个项目主页，都保存在你资料库里你指定的项目中。它的视图有**做出的东西**（每样都带有**打开**）、**演讲**（它的幻灯片排成一条按分钟分段的条）和**推文串**（每个平台的帖子，可以复制）。
- **插图医生**：把你的绘图脚本改得适合论文：符合会议模板的栏宽、论文的字体、色盲读者也能区分的颜色、嵌入字体的矢量 PDF（没有 Type 3 字体），以及全部共用的一个样式文件，原来的脚本保留在旁边。它的视图有**修改前后**、**样式文件**（带有**复制**）和**改了什么**。
- **标注工作台**：你和一个模型标注同一批文本样本。给它标签（最多九个）、你的标注准则和文本：CSV 或 JSON lines 文件、按名称指定的 Hugging Face 数据集，或者粘贴的文本；它随机抽取样本，让辅助模型按你的准则标注。它的运行就是你标注的地方：**标注**（一次一条文本，每个标签一个大按钮和 1 到 9 中的一个按键，你给出自己的标签后才显示模型的标签）、并排显示的**分歧**、**一致率**（你们一致的比例、Cohen's κ 和混淆矩阵）和**导出**（下载为 CSV 或 JSON lines，或者带上数据集卡片**发布到 Hugging Face**）。见[管理实验室的日常工作](/guide/researchers#run-your-labs-work)。
- **研究冲刺**：在你自己的代码上，通过一次冲刺推进一个研究问题：提出假设，在它自己的分支上（在它建的工作树中）写出计划和代码，在你的 GPU 小时数内在[实验](/guide/experiments)中运行，再做一个分析笔记本和一份简短的报告；保留假设和开始运行之前都会等你确认。它的视图有**冲刺**（每个假设及其结论和证据）、**运行记录**（附上对比基线的结果表）和**报告**。
- **参数扫描规划**：在运行次数或 GPU 小时数的预算内，为一个训练脚本做超参数扫描：一个智能体读取脚本的参数，提出要调的设置和取值（或者采用你的），“实验”运行它们并提前停止糟糕的试验，再由一个程序算出每个设置有多重要。它的视图有**结果**（最佳运行、它的发现、下一步可以尝试什么）、**按设置**（每个设置一张图）和**所有运行**。
- **每周进展报告**：把你的一周写成给导师、团队或经理的进展汇报（完成了什么、带数字的结果、困难和阻碍、下周的计划、要问的问题），依据是你的会话（包括 VS Code 和终端里的会话）、提交、运行和阅读。它在自己的页面上打开，显示本周的报告，带有**复制为 Markdown**、**复制为邮件**和**保存为文档**，下面是之前的各周；打开**自动更新**后，每周五 16:00 会有一份新的。见[报告：你的一周和实验记录本](/guide/researchers#reports-your-week-and-your-lab-notebook)。
- **实验记录本**：为你工作过的每一天保存一条带日期的条目：尝试了什么、发现和决定了什么，以及还有什么悬而未决，附上当天的会话、提交、运行和文件的链接。它在自己的页面上打开，显示这些条目，最新的排在最前，可以按字词和含义搜索，每条条目都有可供引用的链接；打开**自动更新**后，它会在每天晚上 21:00 写出当天的条目。

现成应用本身不能修改。要调整它，打开后按**改成我自己的**（在手机上是**编辑**）：编辑器会打开一份副本，你创建后它就成为你自己的应用。

### 探索

**探索**是一本为你制作的杂志：关于你所做的事和你关心的事的文章和近期新闻。可以从开始页右上角的**探索**打开它，也可以从“应用”页面打开。它没有每次都要填写的表单：它会在自己的页面上打开，显示最新的一期，智能体也不会在你的会话中运行它。

- **它怎么挑选**：它会读取你的档案、记忆中关于你的笔记，以及你最近会话的标题（不包括关闭了记忆的会话、智能体为完成部分工作而启动的会话，以及没人看着的应用运行），然后让辅助模型挑出你现在会喜欢的大约六个主题：大约一半来自你的工作，一半来自你生活的其他方面，绝不涉及任何隐私。对每个主题，它会在新闻网站上搜索最近两周的报道，并寻找值得一读的长文（讲解、分析、随笔），同时阅读其中最好的页面，为每篇写出摘要并找到配图。不让程序访问的网站，会根据搜索结果中显示的内容来概括。每一期需要一两分钟。
- **一期杂志**：它的日期和封面标题、编辑寄语、各个主题（点击一个只看它的报道，点**所有内容**看全部）、封面故事，然后是每个主题的版块。每篇报道都有配图、**新闻**或**长文**标记、来源和日期、它讲了什么，以及它为什么出现在你的这一期里。点击它的图片或标题就会在它的网站上阅读：之后它会标上 **✓ 已读**，以后的各期里也一样。**深入研究**会针对它开始一份深度研究报告。在这一期下面，**更早**会列出之前的各期，每一期都按原样打开。
- 顶部的**更新**会立刻做出新的一期。在它工作时，会有一行说明它正在做什么，并带有**跟进**；新的一期准备好之前，你手上的这一期会一直保留。在第一期之前，**做出第一个**也能做同样的事。
- **设置**，即**更新**旁边的滑块图标：**自动更新**（在你打开之前一直是关闭的）会在早上准备好新的一期；在它下面选择日子（**每天**、**每个工作日**，或**每周一次**，在你选的某一天）和时间（除非你修改，否则是 07:00）。它是一个[定时任务](/guide/tasks)，所以“设置 → 定时任务”里也会列出它；关闭它就会把它删除。下面是**要读取的最近会话数**（它会读取多少个你最近会话的标题：除非你修改，否则是 1,000，最多 1,000）、**也要涵盖**（一定要包含的主题，每行一个）和**排除**（要跳过的主题或网站，用逗号分隔）。**保存**会让之后的每次更新都使用它们，包括每天的更新。
- **改成我自己的**和**卸载**在它的**更多**（⋯）菜单里。

每一期会向辅助模型提出大约二十个简短的问题，并在网上搜索十来次；如果登录了 Claude Code，这些问题会计入你的套餐用量。

### 安装或卸载现成应用

用不到的现成应用可以去掉：打开它，然后选择**更多**（⋯）→ **卸载**，再确认。它会离开**你的应用**，智能体也不再在你的会话中运行它，它会留在应用页面的**可安装的现成应用**中。它的运行会保留。

要找回它，就在那里点它的卡片。在做出任何改变之前，会有一张卡片说明它是什么：它做什么、**它会问你什么**（可选的问题会标出来）、**你会得到什么**、用浅白的话说明的**它是怎么工作的**，以及带开关的**智能体可以使用它**。**安装**会把它放回你的应用中并打开它。它自己的页面也会写着“你已卸载它”，并带有**安装**。

## 运行应用

1. 从应用页面或搜索框打开应用。它的页面最上面会说明它做什么，下面是**你的回答**（它的表单），旁边（在手机上是下面）有**你会得到什么**（它的答案会在哪些页面中打开，或者它的答案字段）、**在你的会话中**（智能体能否替你运行它：见[让智能体替你运行应用](#have-an-agent-run-an-app-for-you)）、**最近的运行**（每一项都会打开那次运行），带步骤的应用还有**它是怎么工作的**：按顺序列出它的步骤，每一步都注明它怎样运行（**逐项**处理、**一次**处理几个、几个**并行**），还有**以图查看**，会在编辑器中打开这些步骤。
2. 填写表单。标有红色 **\*** 的问题是必填的。
3. 表单下面的一行会说明由谁来运行，例如“Claude Code · Sonnet · 高思考强度 · 自动”。在现成应用上，**修改**会显示选择器（见下文）；在你自己的应用上，用**编辑**来更改。
4. 按**运行**。运行页面会打开，并实时跟进工作进度。

如果有遗漏，页面会提示“请先填写标记的问题”，并在每个问题下方指出问题所在（“必填”“请输入数字”“选择文件”）。

链接也可以替你填写表单：在应用的地址后面加上 `?in.`、问题的名称、`=` 和回答，打开的页面上表单里就已经填好了这个回答，你还可以修改：在你按**运行**之前，什么都不会运行。[这个链接](/apps/t/reproduce-paper?in.paper=2104.08663)会打开复现论文，并填好一篇论文；更多的回答用 `&in.` 接在后面（文件不行）。智能体会给你这样的链接，视图中的按钮也会（比如阅读清单里论文的**复现它**）。在自己的页面上打开的应用，这时会打开它的表单。

### 问题的类型

- **短文本**和**长文本**：一行输入框，或一个随输入内容变高的文本框。
- **数字**：普通数字；“$1,250.50”会被读作 1250.5。
- **日期**：一个日期选择器。
- **选项**：选项少而短时显示为一排标签；多时显示为列表。对于非必填的问题，再次点击已选中的标签即可清除。
- **是 / 否**：一个开关。
- **文件**：需要附上的文件。

问题下方可以有一行帮助说明，输入框里可以有示例答案，也可以预先填入一个值。

### 选择智能体、模型、思考强度和模式

在现成应用上，表单下面那一行旁边的**修改**会显示选择器（**完成**会把它们收起来）：

- 程序：Claude Code、Codex、Custom（Hydor 自带、可搭配任意模型的智能体），或你添加的其他智能体。
- **模型**：该智能体的模型。
- **思考强度**：模型思考得有多用力，仅适用于提供不同档位的模型（Custom 和其他添加的智能体没有）。
- **模式**：智能体不经询问就可以做哪些事。默认是**自动**，因为运行时没有人在旁边看着。如果选了每一步都要先询问的模式，运行就会停下来等你。

这个浏览器会记住你上次的选择，用于你下次运行的现成应用。

### 附加文件

文件类问题会显示**选择文件**，你也可以把文件拖放到上面（在电脑上）。每个文件最大 25 MB。文件会保存在这次运行的文件夹中，智能体会拿到它的路径，因此可以像读取任何文件一样读取 PDF、Word 文档、电子表格和其他文件。点击已选文件旁边的 **×** 可以移除它。

### 提供它需要的密钥

有些应用要用到需要密钥的服务：API 密钥或令牌（天气服务、地图服务商、你在某处的账户）。应用只写明它需要哪些密钥，从不包含它们的值：每个密钥你只需提供一次，它会保存在你的保险库中（[把密钥存放在保险库中](/guide/connections#keep-keys-in-the-vault)），智能体按名称使用它，却看不到它。

- 在应用的页面上，表单下面的**它需要的密钥**会逐一列出：它是什么、它在保险库中的名称、一句怎么获取它的说明、一个用来粘贴它的输入框，以及**获取**，点它会打开获取密钥的页面。按**运行**：密钥会先存入保险库，然后运行开始。保险库里已经有的密钥显示为**已保存**，附上它的最后几个字符和**修改**；应用没有它也能运行的密钥会标为**可选**。
- 从文件安装应用时，它的卡片也会询问它需要的密钥：可以那时提供，也可以在它第一次运行时再提供。
- 智能体在会话中替你运行它时，那里的卡片会询问它缺少的密钥；密钥会直接存入保险库，绝不会进入对话。
- 只有应用的某一部分才需要的密钥（阅读清单的 Zotero 密钥，用于**与 Zotero 同步**）不会在表单上询问：你第一次使用那一部分时，它的页面会向你要这个密钥。

缺少必需密钥的运行不会开始：在它的表单上，会要求你提供（“运行它需要这个密钥”）；来自 API、定时运行或 CSV 各行的运行会被拒绝，并说明要添加哪个密钥（在它的页面上，或以那个名称添加到**应用 → 已连接的应用 → 密钥**中）。如果你已经保存的某个密钥不允许发送到这个应用要发送的网站，它那一行会说明这一点，并带有**允许**。

有些应用会通过 OpenRouter 使用某个模型（比如一个会画图的模型）。它们会用同样的方式要你的 **OpenRouter API 密钥**，并带有**获取**：这个密钥保存在[设置 → 模型](/settings?s=models)中，而不是保险库中，你的其他应用和 Custom 也能用；应用第一次运行时，会自动把那个模型加到你的模型中。在 Ollama、vLLM 或某个端点上运行的模型，要在“设置 → 模型”中手动准备好：在那之前，运行会被拒绝，并说明是哪个模型、该怎么做。

### 运行在哪里进行

每次运行都有一个属于自己的新文件夹，位于你主文件夹下的 `hydor-apps` 文件夹中，以应用名称和时间命名。应用也可以改为指定一个文件夹（见[由谁来做](#who-does-it)）；这样每次运行都在那里进行。

你从表单启动的运行，其会话会和其他会话一样显示在侧边栏的会话列表中，标题是应用名称加上你最前面的几个回答。来自 API、其他智能体、公开页面或 CSV 各行的运行会被归档，所以不会出现在列表中，而是显示在各自的应用下。

## 让智能体替你运行应用

你不必打开应用才能用它：在任何会话中提出它能做的事（“帮我们两个人规划五月去里斯本的四天行程”），智能体就会在那里运行它。

1. 智能体会找出能做你所要求的事的应用，并填入你说过的内容：地点、天数、谁去。如果你的消息明确是在要你某个应用做的事，智能体会随你的消息被告知是哪个应用，这样它会运行这个应用，而不是自己去做。应用很多时，它会按它们能做的事去搜索（按文字；开启按含义搜索时也按含义），再从最合适的二十个中挑选。
2. 如果应用需要你没说的东西，它的卡片会出现在对话中，带有应用的图标和名称、**来自你的消息：**以及它从你的话里取到的内容，还有剩下的问题。它需要而你还没提供的密钥也会在那里询问：密钥会存入你的保险库，不会进入对话。标有红色 **\*** 的要填写，可选的如果你不在意可以留空。它没法照你的原话接受的问题（比如日期写成“五月”），会在下面显示你的原话。**运行它**会运行这个应用；**暂不**会关闭卡片，什么也不运行。卡片等待期间，会话显示**需要你处理**，收件箱里也会列出它。
3. 应用的卡片会留在对话中、智能体的回复下面，并跟进这次运行：它进行到哪里、经过的步骤，然后按应用自己的方式显示答案（它的视图，带有页面和按钮；**普通答案**显示卡片和表格）。它的某个步骤提出的问题（“让我……”这类）也会在那里等你。**打开**会进入这次运行的页面，点应用名称会进入这个应用。
4. 然后智能体会用一两句话说明结果；这次运行自己的回复留在运行页面上。运行时间长的话，智能体停止等待后它还会继续：它的卡片会继续跟进，运行结束时智能体会收到它的答案（对话中不会为此显示一条你的消息）并回复，卡片会移到那条回复下面。

它的运行在应用的运行列表中显示为**来自会话**。

每个应用的页面上，表单旁边都有**在你的会话中**，带有开关**智能体可以使用它**（你自己的应用在 **API 与分享**下也有）。关掉它，智能体就不再运行这个应用；你随时可以再打开。每个应用一开始都是打开的。构建模块，以及要在自己的页面上使用的应用（有自己的界面，或有展示它所保存内容的视图），会在那里说明这一点，智能体不会运行它们。如果你自己的某个应用和某个现成应用做的事一样，智能体会优先用你的。

每个会话都会被告知你的应用：你最常运行的几个连同它们做什么，其他的只告知名称，总共最多 40 个。超过这个数量时，有请求需要，智能体会去找出其他的应用。

## 跟进运行并查看结果

运行页面会显示应用名称、这次运行收到的回答（排成一行：“里斯本 · 2026-11-20 · 3”）、它的来源（“来自表单”“试运行”“来自 API”“来自另一个智能体”“公开页面”“第 3 行”）以及开始时间。运行结束后，顶部的**再运行一次**会打开按同样方式填好的表单。

顶部的状态卡片会说明它进行到了哪一步：

- **排队中**、**正在启动…**，或**工作中**并显示已用时间。工作期间，你能看到它最近的几个步骤（“已搜索网络”“已读取页面”“已更新计划”），以及智能体最后所说内容的开头。
- **它需要你在会话中批准**或**它在会话中有个问题要问你**：智能体在等你。打开会话去回答；需要批准的请求也会显示在[收件箱](/inbox)中。
- **已完成，用时**后面跟着所花的时间，并附上花费。
- **已停止**，或**它没有完成**并附上原因。

下面是结果。有视图的应用会在那里用视图显示结果（见[它的视图](#its-view)）；状态卡片里的**普通答案**会改为以普通卡片和表格显示它，**它的视图**则切换回来。没有视图时：

- 简短的回答字段（文本、数字、日期、链接、是或否）放在同一张卡片里。
- 长文本、列表和表格各自在标题下占一张卡片。长文本有**复制**按钮；表格有**复制**和 **CSV**（下载），图片列会以小图显示图片（点击会打开大图）。
- 图片、视频、声音和文件：图片排成网格（点击会打开大图，用箭头可以浏览其他图片），视频和声音可以播放，其他文件可以下载。放在其他网站上的（YouTube 上的视频、一个网页）会在那里打开。
- 在手机上，太宽放不下的表格会改为每行一张卡片。

接着是智能体自己的回复。应用没有回答字段时，它展开显示在**回答**下；否则折叠在**智能体的回复**下。**提出的请求**（折叠）列出了这次运行收到的回答。

如果智能体结束时没有提交回答字段，会被提醒一次。既没有回复也没有结果就结束的运行算作失败（“智能体结束了，但没有给出答案”）。

底部的**用这些回答再运行一次**会打开按同样方式填好的表单，可以修改后再运行。文件不会带过去：需要重新选择。

顶部的**打开会话**（在手机上是**会话**）会打开这次运行的完整对话。

### 它的视图

应用的视图是为它的答案专门做的：一些页面用它们自己的元素（卡片、时间线、图表、可以勾掉的列表）显示答案，还有可以用答案做事的按钮。

- **页面**：视图顶部的标签页；第一个最先打开。有些页面是点击后打开的（旅行中的某一天、某个产品），它们的顶部有返回的入口。
- **勾选和选择**：你勾掉的东西（已经订好的事项、已经完成的行动项）会和这次运行一起保存，在每台设备上都一样；筛选和挑选（某个主题、某个负责人）只在页面打开期间有效。
- **再运行一次的按钮**：旅行的**轻松**或**+ 再加一天**、求职信的**正式**、针对同一份文档提出新问题的输入框。每个按钮都会先跟你确认，然后用你原样不变的其他回答（文件也一样）开始一次新的运行并打开它。
- **启动另一个应用的按钮**：新闻报道或旅行区域上的**研究**、某项发现上的**深入研究**：每个都会先跟你确认，然后开始那个应用的一次运行并打开它。
- **复制**：复制其中一部分，粘贴到别处（一封邮件、一封信、要问的问题）。
- **地图、图表、图片和视频**：一张标出答案中各个地点的地图（可以拖动和缩放；地点会显示它的名字，点击它可以打开它的页面），一张图表或一个 3D 图（指向某个条形或某个点即可读出数值，可以放大，3D 的还可以转动），可以打开大图的图片，以及来自文件或 YouTube、Vimeo、可以播放的视频和声音。地图、图表和视图自己画的内容要从网上加载它们的库（地图还要从 OpenStreetMap 加载图块），所以需要这台设备联网。
- 在你自己的应用上，视图还可以请它的智能体做修改（没有步骤的应用）、运行它的其他某个流程，或者在它保存的内容里存一条记录。

视图会显示在运行页面上、它的会话的**结果**中，以及应用的公开页面上；在公开页面上，它的页面和勾选都能用，但什么都不会触达应用（不能再运行一次，不能开始新的运行，什么也不保存）。

## 对结果提出修改

运行结果并不是定稿。运行页面底部有一个输入框，提示**对结果提出修改…**（应用没有回答字段时则是**提出修改…**）。

1. 输入要改的地方：“第 2 天别排得那么满”“加一列营业时间”“再短一点，语气再亲切些”。
2. 按 Enter，或点击箭头按钮。Shift+Enter 换行。在手机上 Enter 是换行：点箭头发送。

追问会发送到这次运行的会话中。智能体完成修改后，会交回完整的更新结果，替换页面上原来的结果。每条追问都显示在**追问**下，附有智能体的答复；结果有变化时还会显示**已更新结果**。之后状态卡片会显示**已更新，用时 …**；如果追问只需要回答（比如一个问题、一句感谢），则显示**已回答，用时 …**。

如果你在智能体还在工作时发送追问，它会标注“排队中”并等待，等当前这一轮结束后再交给智能体。一条追问最多 20,000 个字符。

来自公开页面的运行不接受追问。会话已被删除的运行，或会话正在另一个程序中打开的运行（请在那个程序里继续），也不接受。

## 在运行的会话中操作

从侧边栏打开时，运行的会话会先显示**结果**，和运行页面的视图一样，顶部有一个切换到**对话**的开关。（运行页面上的**打开会话**会直接进入对话。）这时会话的消息框会提示**对结果提出修改…**：你在那里发送的任何内容都是追问，和在运行页面上一样；在一处开始写的草稿也会带到另一处。

在**结果**视图中，智能体的批准卡片会显示在结果下方，你可以直接在那里批准或拒绝。如果它是有问题要问，就会出现一张卡片，写着 **它有个问题要问你。** 并带有**去回答**按钮，点击后会切换到对话。

在对话中，智能体提交结果的那一刻会显示为**结果已提交**，并带有**打开结果**。如果它提交的内容不符合回答字段，会显示**结果暂时还不符合答案字段**以及哪里不对；智能体会修正后重新提交。

## 停止或移除运行

- **停止**（运行进行时位于顶部）：还在排队的运行会立即结束；正在工作的运行会被中断，并显示**已停止**。
- 运行结束后，垃圾桶按钮（**从列表中移除**）会询问“移除这次运行？”，然后把它从应用的运行列表中移除。会话会保留：如果也想删掉，请从会话菜单中删除。

## 查看应用的所有运行

你自己的应用页面有四个标签页：**运行**、**运行记录**、**逐行运行**和 **API 与分享**。**运行记录**显示今天运行了几次，并按从新到旧列出每次运行：收到的回答、来源、多久以前、花费和状态。**显示更早的运行**会加载更多，每次 50 条。

现成应用没有“运行记录”标签页：可以在应用页面的**最近的运行**下找到它们的运行，或在侧边栏中作为会话找到。

## 创建你自己的应用

有四种开始方式：

- **从零开始**：应用页面上的**新建应用** → **从零开始**、你自己的应用下面的**制作应用**图块，或前往 [/apps/new](/apps/new)。
- **描述它**：在应用页面（或新建应用页面）上，在**描述一个应用，让智能体来做**下面写出它该做什么，然后按**创建**。会话会以**应用搭建师**（[智能体](/guide/agents)）开始，由它制作应用、试运行并交给你。
- **从现成应用开始**：打开它并按**改成我自己的**（在手机上是**编辑**）。
- **从一个顺利的会话开始**：在会话菜单（⋯）中选择**更多** → **另存为应用**。页面会显示“正在根据会话起草应用…”，同时辅助模型会根据你的请求和智能体的回复，把会话的第一个请求变成表单、任务和回答字段。每次使用都会变化的部分会变成问题。草稿会沿用会话的程序、模型、思考强度、模式和智能体。如果智能体调用过步骤自己就能调用的工具（读取了网页、搜索了网络），草稿还会带上步骤：这些调用变成工具步骤，表单的回答填在相应位置，其余部分交给一个模型步骤或智能体步骤。检查不通过的步骤会被去掉，保留交给一个智能体的任务；保存前请检查这些步骤并试一试。如果辅助模型起草不了，你会得到原样的请求，放在一个**请求**问题中，并附上一条说明原因的备注；辅助模型在[设置 → 智能体 → 模型](/settings?s=models&find=Helper%20model)中设置。

你也可以在任何会话中让智能体帮你创建应用（见[问问智能体](#ask-an-agent)）。

编辑器打开时标题为**新建应用**：最上面是它的图标、名称和描述（点击名称或描述即可修改），下面是它的各个部分，排成几个标签页：先是**它做什么**，然后是**表单**、**回答**、**设计**、**示例**和**设置**（由谁来做、它的工具、它的限制、它保存的内容、它是不是一个模块，保存之后还有它的文件夹和版本；每一项都折叠成一行，说明它现在怎么设置，点开才会展开）。每个标签页都一样宽；在电脑上，滚动时标签页会留在顶部，在手机上则排成两行。在宽屏上，**表单**和**回答**旁边有**预览**，会随你的输入变化：一个是应用页面上问的表单，一个是按运行结果的样子显示的模拟答案。填好各部分，用**试运行**试一试，然后按**创建**。应用页面随即打开，可以运行了。

### 名称、描述和图标

- 点击图标可以选择它的颜色（11 种颜色）和图案（32 个图标）。
- **名称**（必填，最多 60 个字符），例如“旅行规划”。
- 描述：用一句话说明它做什么（最多 300 个字符）。

应用的地址在创建时由名称生成（“Trip planner”变成 `trip-planner`）。之后改名时地址保持不变，所以链接、密钥和其他智能体调用的工具都能继续使用。

### 表单

每次运行前要回答的问题。**添加问题**会添加一行，其中包括：

- 问题本身，也就是填写的人看到的文字（“去哪里？”）。
- 它的类型：**短文本**、**长文本**、**数字**、**日期**、**选项**、**是 / 否**或**文件**。
- **必填**：没有它，运行就无法开始。
- 对于**选项**：各个选项，每行一个（留空时提供“是”和“否”）。
- **帮助文字、示例、默认值…** 会再打开三个输入框：**问题下方的帮助说明**、**示例答案**（在空输入框中以灰色显示）和**初始填入的值**。

问题的 **⋯** 菜单里有**上移**、**下移**和**移除**。每个问题下方会显示它的占位符，例如 `{{destination}}`：任务就是用它来引用这个问题的回答，程序也用这个名字。新问题的占位符会随问题文字自动变化，直到任务用到它为止。一个应用最多可以有 30 个问题。

### 任务

要智能体做的事，其中会填入各个回答（最多 30,000 个字符；必填）。像你亲自向智能体提要求那样来写，不只说要做出什么，还要说明怎么做。

- **它做什么**可以把应用的工作显示为**单个任务**（就是这个输入框）、步骤的**列表**或步骤的**图**；见[按步骤工作的应用](#apps-with-steps)。
- **插入**后面的标签会把问题的占位符插入光标所在位置。任务还没用到的问题会突出显示。**今天**、**现在**和 **weekday** 会插入你所在地的日期、日期和时间，以及星期几。
- `{{question}}` 会被替换为该问题的回答。
- `{{#question}}` 和 `{{/question}}` 之间的文字，仅在问题已作答（且回答不是“否”）时保留。`{{^question}}` 和 `{{/question}}` 之间的文字，仅在问题留空时保留。
- **预览**（在一排**插入**标签的末尾）会显示填入了各问题默认值（或方括号中的问题名）的任务。**编辑**返回编辑状态。

输入框下方的警告会在两种情况下提醒你：某个占位符对应不到任何问题（它会原样保留），或者某个必填问题在任务中从未被用到。

### 答案

智能体完成时要填写的字段。它们显示为卡片或表格，程序则以 JSON 形式拿到它们。没有回答字段时，智能体的回复就是答案。

**添加回答字段**会添加一行，其中包括：

- 一个标题（“推荐”）。
- 它的类型：**文本**、**长文本**（带格式的文本）、**数字**、**是 / 否**、**日期**、**链接**、**列表**、**表格**或**图片、视频或文件**。
- **必填**：智能体必须填写它。
- **这里填什么，供智能体参考（可选）**：给智能体的提示。
- 对于**表格**：它的**列**，每列都有名称和类型（**文本**、**数字**、**是 / 否**、**日期**、**链接**或**图片**）。**添加一列**会添加一列；表格至少保留一列。

答案字段的 **⋯** 菜单里有**上移**、**下移**和**移除**。

**图片、视频或文件**字段（以及**图片**列）接收智能体找到或做出的东西：网上的一个地址，或这台电脑上的一个文件（你“图片”文件夹里的一张照片、它画的一张图表、一段录音），每个都带一行说明文字。Hydor 会为这台电脑上的文件、以及网上的图片（最大 15 MB）保留一份副本，这样答案显示在哪里，它们就能显示在哪里；网上的视频仍然是链接。公开页面的运行只能指向网上的内容。

Hydor 会检查智能体提交的内容：数字必须是数字，日期必须是真实的日期，链接必须是完整的网址。有不符合的地方，会告诉智能体要修正什么。一个应用最多可以有 30 个回答字段，一张表格最多 16 列。新回答字段在保存时会根据标题生成供程序使用的名称；之后这个名称保持不变，所以读取它的程序能继续正常工作。

### 示例

示例是用来试运行应用的回答，以及对运行结果的检查：这样你可以试一试改动，并在应用变差时及时发现。**添加示例**会添加一个：愿意的话给它起个名字，填好它的回答，再为一次好的运行应给出的每样东西**添加检查**。检查是对运行中的值的规则，和步骤的规则一样：`{{answer.unread}} > 0`、`{{find.count}} = 3`、`{{reply}} contains Lisbon`。**{ }** 按钮会插入一个值：表单的回答、步骤给出的结果、**它的答案**（`{{answer.field}}`）和**它的回复**。

**全部试一试**会把每个示例作为一次试运行来运行，用的是屏幕上的应用，不管保存了没有；示例旁的烧瓶按钮只试那一个。每个示例都会显示它上次试运行的结果：**通过**、有几项检查未通过，或者**未完成**，以及用了多长时间、花了多少钱；打开的示例会说明每项未通过的检查看到了什么（"answer.unread is 2"）。

### 由谁来做

这一部分写着：“运行时没有人看着，所以请选择一个不会停下来询问的模式（Auto，或允许编辑的模式）。”

- 程序、**模型**、**思考强度**和**模式**选择器，和现成应用上的一样。模式默认是**自动**。
- **智能体**：**无**，或每次运行所用的智能体（研究员、撰稿人……或你自己的智能体），连同它的指令、档位和预算。见[智能体](/guide/agents)。
- **文件夹**：默认是**每次运行使用新文件夹**。**选择一项**会让每次运行都在你选定的文件夹中进行（运行开始时它必须存在）；**每次都用新的**则恢复默认。选定文件夹后，附加的文件会放在一个单独的上传文件夹里，不会混进你的文件。

### 工具

运行可以使用 Hydor 自带的哪些工具：网络搜索、浏览器、页面、记忆等等。**全部**默认是开启的。把它关掉就会看到一个列表，列出每个工具的名称和作用，勾选运行可以使用的那些。智能体自己的文件和命令工具由它的模式决定，不受这个列表控制。

### 它需要的密钥

**它需要的密钥**（在**设置**中）按它们在你保险库中的名称，列出它的运行要用的密钥：每个都有它是什么、**可以发送到哪里（主机）**、**在哪里获取**、一句怎么获取的说明，以及**没有它也能运行**和**这台电脑上的命令会使用它**两个开关。**添加它需要的密钥**会添加一个。它的运行会被告知每个密钥的名称和用法；安装这个应用的人提供密钥的值（见[提供它需要的密钥](#give-it-the-keys-it-needs)），这些值绝不会成为应用或它的文件的一部分。

### 限制

- **每天运行次数（来自任何地方）**：这个应用一天内最多可以运行几次，从午夜起算，来自表单、API、其他智能体、CSV 各行和公开页面的运行，以及它界面上的对话，都计算在内。超过之后，运行会被拒绝，并提示“此应用今天已运行 … 次，已达上限”。留空：不限制。
- **单次运行最多可花费（US$）**：每次运行的花费上限。达到上限时运行会停止。留空：没有上限。见[用量、限额和费用](/guide/usage)。

### 保存前先测试

**试运行**（在手机上是烧瓶按钮）会打开一个对话框，里面是屏幕上当前的表单，无论是否已保存。填好后按**运行测试**：运行过程会在对话框中展开。**打开会话**会显示它的对话，**再测一次**会回到表单。已保存应用的试运行会以“试运行”显示在它的**运行记录**标签页中。**保存为示例**会把一次已完成试运行的回答保存为新的示例，再到**示例**下给它加上检查。

## 修改、复制或删除应用

在你的应用页面上：

- **编辑**会打开编辑器，标题是**编辑**加上应用名称。改完后按**保存**；保存之前，它旁边会显示**尚未保存**。更改只对之后的运行生效；正在进行的运行会继续使用开始时的版本。
- **更多**（⋯）→ **创建副本**会复制出一份，名称末尾加上“副本”，并有自己的地址。它的界面会作为副本自己的页面一起复制；副本的公开页面一开始是关闭的，密钥和它保存的记录不会被复制。
- **更多**（⋯）→ **删除**会先询问“删除 …？”：它的运行、密钥和公开页面会一并删除，仍在进行的运行会被停止。它启动过的会话会保留。从文件安装的应用这里显示的是**卸载**：它会以同样的方式被彻底删除，要再用它就重新安装它的文件。

现成应用的**更多**（⋯）里有**卸载**，卸载后它会留在**可安装的现成应用**中（见[安装或卸载现成应用](#install-or-uninstall-a-ready-made-app)）。

### 版本

每次改变了应用做什么的保存都是一个版本：**编辑**页靠后的**版本**会从新到旧列出它们，每个都写明改了什么（或者智能体说它做了什么）、由谁保存（**你**、**一个智能体**、**它的文件夹**或**已安装**）以及何时保存；对于用保存后的样子试过示例的版本，还会显示通过了几个、一次运行用了多久、花了多少钱，这样你就能看出一次修改有没有让它变好。**恢复此版本**会把较早的版本放到屏幕上，按**保存**它就再次成为最新的版本。在图中移动步骤的位置、修改它的界面（界面有自己的版本）都不会产生新版本。每次运行都会记下它运行的是哪个版本。

### 把它当作文件来修改

已保存应用的**编辑**页靠后的**它的文件夹**会把应用放进一个文件夹（**建立它的文件夹**；默认在你主文件夹的 Hydor/Apps 里），这样就能用任何编辑器、或者用在那个文件夹上打开的编程智能体来修改它。app.json 就是这个应用（它问什么、做什么、给出什么），instructions/ 里是每一步的指示（Markdown），steps/ 里是每个代码步骤运行的函数，screens/ 里是它的界面，graph.json 记录各步骤在图中的位置；.naget/ 里有 app.json 的结构说明和代码步骤的类型，让你的编辑器能补全和检查它们。你在那里保存的每次修改都会作为一个由**它的文件夹**保存的版本来到这里，在**编辑**页打开的应用也会跟着改变（如果你这里也有修改，会提示**你在这里修改时，它在它的文件夹中被改变了。**）；那里的错误会在这里说明，而且什么都不会改变。在这里保存会把文件夹写回，**不再同步**会让文件留在原处。它的数据留在这里，不在文件夹里。

在运行 Hydor 的电脑上，命令行也能做到这些，在它的文件夹里运行：`node dist/server/cli.js app new "Reading list"` 会创建一个应用和它的文件夹，`app folder <应用>` 会建立某个应用的文件夹，`app dev <应用>` 会在你每次保存修改时试运行它的示例，`app try <应用>` 试运行一次（有检查不通过时会报失败），`app export` 和 `app import` 把它作为一个文件带到另一台电脑，安装前会先说明它会做什么。`app help` 会列出这些命令；它们使用自己的一个密钥，**设置 → 机器**中显示为“This computer’s command line”。

## 从你自己的程序调用应用

脚本、快捷指令和其他程序可以用密钥运行你的应用并拿回答案。打开你的应用 → **API 与分享** → **API**。

1. 按**新建密钥**，写明谁会使用它（用来区分不同的密钥），然后按**生成密钥**。
2. 立即复制密钥：“这是你的新密钥。现在就复制：它不会再显示。”

一个密钥只能用于这个应用，不能访问 Hydor 里的其他任何东西。列表会显示每个密钥的名称、开头和结尾的几个字符，以及上次使用的时间。**撤销**会让密钥失效：使用它的程序会立即停止工作。

这个标签页会显示一个调用示例，其中包含你应用的地址和示例回答。如果你有一个名为 Trip planner 的应用，示例大致如下：

```bash
curl -X POST https://your-address/api/apps/trip-planner/run \
  -H "Authorization: Bearer napp_…" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"destination": "Lisbon", "start": "2026-11-20", "days": 4}, "wait": 300}'
```

- 把表单的回答放在 `inputs` 下，按占位符名称填写。对于文件类问题，可以给出这台电脑上某个文件的路径，或者把文件放在 `files` 下发送，带上它的 `name`，并把 base64 编码的内容作为 `data`。
- `wait` 是等待答案的秒数，最多 900。
- 响应中包含这次运行的 `status`、`result`（回答字段）、`reply`（智能体最后说的话）和 `session`（指向会话的链接），有的话还会附上 `error` 和 `costUsd`。
- 对于仍在进行的运行，可以用 `GET …/run/<run>?wait=60` 查询它的情况。
- 如果前面有会切断长请求的代理（Cloudflare 的代理在 100 秒时切断），就把等待时间设短一些，然后再查询。

每个密钥每分钟最多调用 30 次，并且受应用每日上限的约束。关于 Hydor 自己的 API 的更多内容，见[应用的 API](/guide/api)。

## 让其他智能体把应用当作工具运行

Claude Code、Cursor 或其他连接到 Hydor 自带 MCP 服务器（智能体使用工具的一种标准方式）的智能体，都可以把你的应用当作工具来运行。在 **API 与分享** → **其他智能体**下，**提供给其他智能体**开关会把应用作为一个以其地址命名的工具提供出去，例如 `app_trip_planner`。新应用默认开启这个开关。智能体会把表单当作工具的输入来填写，然后等待答案；运行时间较长时，会先返回运行的 id，智能体再用第二个工具 `app_run_status` 查询。这类智能体需要的地址和令牌在[设置 → 应用 → 连接其他智能体](/settings?s=connect)中。

## 开放一个人人可用的公开页面

公开页面让任何拿到链接的人都能填写表单并查看答案，无需登录，也无法访问这里的其他任何东西。它在 **API 与分享** → **公开页面**下。

公开运行始终使用 Custom，所以请先在[设置 → 智能体 → 模型](/settings?s=models)中为 Custom 添加一个模型。然后：

1. 打开开关。状态会从**已关闭**变为**对所有拿到链接的人开放**，并自动选用 Custom 的第一个模型（可在下方更改）。
2. 复制链接（Hydor 的地址后面接 `/a/` 和应用的地址），或点击**打开**。
3. 设置其余各项：
   - **模型（Custom 的模型之一）**：公开运行使用的模型。
   - **搜索和阅读网页**：默认开启。关闭后，智能体只凭自己已知的内容回答。
   - **每位访客每小时运行次数**（默认 5）、**每天公开运行次数**（50）和**每天最多可花费**（$2）。有一行会显示今天的公开运行次数和花费。

访客能看到的：应用的名称、图标、描述和表单，他们这次运行的进展，以及他们自己之前的运行（最近 10 次，靠他们浏览器中的 cookie 来区分）。他们永远看不到任务、设置、其他人的运行、会话或花费，出错时也只会看到笼统的说明。他们附上的文件最大 3 MB，他们的回答长度限制也比你的更短。页面底部会提醒他们答案可能有误。

公开运行能做的：使用 Custom 和所选模型，不能执行命令，不能使用文件，记忆和连接都关闭，在一个运行结束就删除的临时文件夹中进行。它们只能提交回答字段，以及在你允许时搜索网络和阅读公开网页。附上的文件会以文本形式交给智能体。每次运行的花费上限是当天预算的剩余部分。

为了避免负载过大：同一个应用最多同时进行 3 个公开运行（所有应用合计 8 个），访客要等上一次运行结束才能开始下一次，同一个网络地址在所有页面上每小时最多运行 60 次。公开运行计入应用的每日上限，并且不接受追问。关掉开关即可关闭页面；访客随后会看到“此页面未开放”。

## 对 CSV 的每一行各运行一次应用

一次性对整个列表运行应用：把电子表格另存为 CSV，每一行运行一次。打开你的应用 → **逐行运行**。（现成应用需要先按**改成我自己的**。）

1. 点击**选择 CSV 文件**，或把文件拖到框里。第一行是列名。逗号、分号和制表符分隔都可以，最多 500 行。
2. 在**哪一列回答哪个问题**下，为每个问题指定一列（应用会按名称猜测），或选择**每一行都一样…** 并填一个值。必填问题需要指定一列或一个值。
3. 检查**前几行，按表单将收到的形式呈现**。
4. 看一下费用估算（见[一次运行的费用](#what-a-run-costs)），并选择**同时运行**几个：1、2、3、4 或 6（默认 2）。
5. 按**运行**（按钮上会写明行数）。

文件类问题会把单元格内容当作文本：这台电脑上的路径，或一个网址。某一行的值不符合表单要求时，会立即失败，原因显示在表格中，让你知道要改什么。如果这些行会让应用超出每日上限，Hydor 会在开始前就拒绝。

各行运行时，会逐步填出一张表格：行号、前两个问题、状态、最多四个回答字段（或回复），以及每次运行的链接。表格上方显示：已完成多少、有多少没完成、目前的花费、同时运行几个，以及一个进度条。

- **停止**会结束仍在等待的行，并中断正在运行的行。
- **CSV** 会下载结果：每一行的回答、所有回答字段、状态、错误（如有）、花费和会话链接。电子表格会当作公式处理的单元格，开头会加一个撇号。
- **×** 会关闭表格。

即使 Hydor 重启，各行也会继续运行。**之前的表格**列出你过去的逐行运行（最近 30 次），显示进度以及状态是**正在运行**、**已停止**还是**已完成**；点击一项可以重新打开它的表格。

## 让应用自行运行

应用可以自行运行：在每天的某个时间、每隔一段时间、只运行一次、在另一个服务调用 webhook 时，或者在监测器发现变化时（订阅源、网页、某个值、文件夹）。每次运行都像从它的表单运行一样，使用你设定的回答，运行记录和其他运行一起显示在**运行记录**下。

- **设置方法**：打开应用，然后点**运行记录** → **何时自行运行** → **添加定时运行**。起个名字，填好每次运行要用的回答，再选择运行时间，和任何[定时任务](/guide/tasks#when-it-runs)一样。**试运行**会不保存地试运行一次。
- **来自外部的回答**：webhook 的回答可以取用调用中的部分（`{{body.title}}`、`{{headers.name}}`、`{{query.name}}`），监测器的回答可以用 `{{change}}`，也就是它看到的变化。运行会把它们当作数据，绝不当作指令。
- 每次运行结束都会通知你它返回了什么，或者为什么没能完成，点通知会打开那次运行。**何时自行运行**下它的那一行可以暂停、立即运行、查看历史或删除它；这个任务也在[设置 → 定时任务](/settings?s=tasks)中。
- **在自己的页面上打开的应用**（[探索](#explore)、每周进展报告、实验记录本）用起来更顺手：在它的**设置**（它页面顶部的滑块图标）中，**自动更新**会用那里保存的回答运行它，可以选**每天**、**每个工作日**或**每周一次**（在你选的某一天），时间也由你选。现成的应用可能自带开始的日子：每周进展报告是每周五 16:00，实验记录本是每天晚上 21:00。

## 一次运行的费用

每次运行结束后，花费会显示在它的页面上和**运行记录**列表中。这个数字是智能体报告的金额，或者按 API 价格计算的用量（对 Custom，是根据它读写的内容估算的）；在这台电脑上运行的模型花费为 $0。

运行 CSV 之前，Hydor 会估算整批的花费：“… 行约 $…”，依据是该应用最近已完成运行（最多 30 次）花费的中位数。设置了单次上限时，它还会加上这些行最多可能花掉多少。如果应用从未完成过一次运行，它会提示“先运行一次应用，看看每次运行要花多少钱。”

要控制花费，可以在应用的**限制**下设置 **单次运行最多可花费（US$）** 和 **每天运行次数（来自任何地方）**，如果有公开页面，还可以设置它的每日预算。所有会话的花费见[用量、限额和费用](/guide/usage)。

## 按步骤工作的应用

应用也可以按**步骤**来完成工作：由一个智能体做其中一部分，向模型快速提个问题来理清某件事，用工具获取一个网页，按规则决定走哪条路，对列表中的每一项执行同样的步骤。每个步骤把它的发现交给下一步，运行结束时交回答案字段。与让一个智能体包揽一切相比，步骤让应用更省钱、更快、更可靠，也能做更多事：在多次运行之间保存数据，调用你的其他应用，让几部分并排运行。

你可以在应用的**编辑**中创建按步骤工作的应用，也可以问智能体。在**编辑**中，**它做什么**会把它的工作显示为**单个任务**、步骤的**列表**或步骤的**图**（在电脑上默认打开图，直到你改选列表）。对于只有一个任务的应用，**列表**或**图**会把任务变成第一个步骤：一个完成它的智能体；**单个任务**则会把唯一的智能体步骤变回任务。**添加步骤**用来选择步骤的类型；点击一个步骤会打开它的设置，它的 **⋯** 菜单可以移动、复制或删除它。**判断**、**重复**或**同时进行**里面的步骤显示在它下面，每个列表都有自己的**添加步骤**。文本框旁的 **{ }** 按钮（**插入一个值**）会插入一个值：表单中的一个回答、前面某个步骤给出的结果（`{{find.records}}`），或者一个内置的值：**今天**（`{{today}}`）、**当前**（`{{now}}`，日期和时间）、**星期几**（`{{weekday}}`）和**时区**（`{{timezone}}`），都以你所在地为准，还有**是什么启动了这次运行**（`{{run.source}}`：从表单运行时是 web，还有 api、task、screen，按行运行时是 batch……）和**这次运行**（`{{run.id}}`）。**它的答案从哪里来**说明每个答案字段由哪个值填入（留空：由最后一个给出同名值的步骤填入）。需要修改的地方会随时显示在对应步骤下面，**试运行**会试一试屏幕上的内容。**图**会把它们显示为节点和连线：灰色的线是顺序（判断的各条路径和并排的分支、框在一起的重复步骤、步骤失败时运行的红线），彩色的线表示哪一步用了哪一步的值。

你也可以直接在图中搭建（在电脑上；手机上仍用列表）。图会显示整个运行过程：最上面是**表单**，步骤用到内置的值时旁边还有**内置**，下面是各个步骤，最后是**答案**；虚线从表单和内置的值连到用到它们的步骤，也从给出答案的步骤连到答案。点击**表单**或**答案**会打开它的标签页。点击步骤的节点会在图旁边打开它的设置，**更多**（⋯）可以移动、复制或删除它；连线上的 **+** 会在那里放一个新步骤，空路径里的**添加步骤**会开始这条路径。把节点右侧的圆点拖到另一个步骤上，就能把它的某个值放进那一步（它的指示、工具的输入、规则……），拖到空白处则会新建一个用这个值的步骤。拖动节点可以摆放位置（判断或重复里面的步骤会跟着移动），双击某个值的连线可以在那里弯折它（拖动弯折点，或双击它把它去掉），**整理：重新排布全部**会让它们自动排好；按住 Shift 点选几个节点，可以**把它们编成一组并加备注**。拖动背景可以移动画布，按住 Ctrl 滚动滚轮可以缩放，**全屏**会让它占满整个窗口。

图上方按钮中的**试一试**会在图中用屏幕上现在的应用做一次试运行：每一步运行时和结束时都会亮起来，通向已运行步骤的连线也会一起亮起；指向某条值的连线可以看到它带过去的值，步骤的设置最上面会显示它**上次试运行中**的情况。在步骤的设置里，**试运行时在它之前暂停**会让试运行停在那里，直到你按**继续**（或者**单步执行**，在下一步之前再次暂停）；雪花图标（**冻结**）会让试运行沿用这一步上次给出的结果，这样就能反复试它后面的步骤，而不用再为前面那一步花钱。

选中步骤时（按住 Shift 点选几个前后相连的步骤），图上方按钮中的**合并成一个模块**会把它们变成一个独立的应用，也就是一个模块，由一个**调用应用**步骤在原来的位置运行它：它们从外面用到的东西（表单的回答、前面步骤的值）变成它的表单，由调用步骤提供；后面的步骤用到的它们的值变成它的答案。其他应用也可以调用这个模块，改它一次，所有调用它的应用都会跟着改变。保存数据的步骤要留在应用里，因为模块有自己单独的数据；列表和表格会以文本形式传给模块。

或者问智能体：“创建一个应用，读取我给的每个链接，用一个快速模型总结它，并把它保存到阅读清单里。”智能体会写好步骤、检查并试运行，之后你也可以在**编辑**中修改它们。智能体在任何会话中都有为此准备的工具：读取你的应用，保存应用（先检查，错误用文字说明；可以是整个应用、其中几部分或某一步），试运行它的示例并等待结果，给它一个界面，以及读取它保存的记录或添加记录（修改或删除记录由你决定：在它的界面上做，或者先征得你的同意）；把应用交给你之前，它们会说明一次运行要花多少钱。

在对话中，智能体保存的每个应用都会显示为一张卡片；屏幕够宽时，应用会在搭建的同时在对话旁边打开（卡片上的**在旁边打开**会再次打开它，**打开它的页面**打开它自己的页面）。你在那里修改并保存的内容，会在你发下一条消息时传给智能体，让它在你的版本上继续：你改过之后，智能体再保存时会先读取你的版本。如果智能体在你有未保存的修改时保存了，会出现一条提示，让你选择**载入它**或**保留我的**。在那里，步骤的 **⋯** 菜单中的**就此问智能体**会在对话的消息框里写好关于这一步的开头。

步骤的类型：

- **问智能体**：由一个会话用它的工具处理自己那一部分，并交回它的发现。每个这样的步骤都有自己的会话，你可以从运行页面打开它。
- **问模型**：让模型快速给出一个回答，不用工具：分类、提取、总结。花费很少，用这台电脑上的模型则不花钱。
- **使用工具**：用设定好的输入调用 Hydor 自己的一个工具：搜索网络、读取网页、为列表中的每个事物找一张图片（和一段视频）、用保存的密钥调用一个地址、读取文档、生成图片、给你发一条通知、读取 Hydor 对你的了解、按你在意的程度给事物排序，或者把它做出的东西保存到你的资料库（幻灯片、文档、电子表格、LaTeX 文档或页面，放进它指定的项目）。针对论文：查找并阅读一篇论文（从开放的副本读取，附上它的记录和 BibTeX）、维护阅读清单，以及把它与 Zotero 同步。这样找到的图片放进答案的图片列，视频（YouTube 或 Vimeo 链接）在视图的视频元素中播放。
- **判断**：走这条路或那条路，依据一条规则（“价格低于 100”）或一个用文字写的问题，由辅助模型回答。
- **重复**：对列表中的每一项各执行一遍它里面的步骤（愿意的话可以几项同时进行），或者一遍遍执行，直到某个条件成立。
- **同时进行**：几个分支并排运行；全部结束后流程再继续。
- **调用应用**：把你的另一个应用当作一个步骤。在各种步骤下面，**添加步骤**还提供模块：专门作为其他应用步骤的应用，有你自己的（在应用答案字段下标为**一个模块**的那些，以及合并成模块时做出的那些），也有现成的（**总结网页**、**翻译**、**从网上找答案**、**分类**和**提取事实**，放进去时会先变成你的）。模块放进去后是一个调用，表单待填；应用自己的表单里同名的问题会直接填好。改一次模块，所有调用它的应用都会跟着改变。
- **保存数据**：添加、查找、修改或删除应用保存的记录（见下文）。
- **问一个人**：运行会等待你的回答，是或否，或者一个简短的表单：通知会打开这次运行，那里有一张卡片向你提问，收件箱也会列出它。除非你另设期限，它会等一周，之后就会失败。
- **运行代码**：你写的一段 JavaScript、TypeScript 或 Python 程序，拿到你给它的值，返回这一步的值（**它给出的值**会说明这些值的名字，供后面的步骤使用）。它在沙盒中运行：没有网络，除了应用安装的包，看不到这台电脑上的任何文件。它只能通过 `ctx` 与外界打交道，每次调用都是这次运行的一个步骤：`ctx.model` 问模型，`ctx.agent` 问智能体，`ctx.tool` 使用应用的某个工具，`ctx.ask` 等你回答，`ctx.data` 保存记录，`ctx.app` 运行另一个应用。所以整个流程可以就是一段程序，带着自己的判断和循环；它的调用会像步骤一样显示在运行的页面上，重启后运行重新开始时，程序会再运行一次，之前做过的调用直接给出当时的结果，不会再运行。带有代码步骤的应用文件会在安装卡片上说明这一点。
- **算出一个值**：从另一个值立即算出一个值，不花钱：列表的第一项或最后一项、有多少、总和、平均值、最小值或最大值（针对每一项的某个字段）、每一项的某个字段、把各项连成文字、去掉重复、按某个字段排序、作为数字，或者几天后的日期。它给出 `{{id.value}}`，在图中显示为一个小药丸形状。

一个步骤可以只在某条规则成立时运行，也可以说明失败时怎么办：改为运行其他步骤，不用它继续，或者（工具、模型、代码、数据或应用步骤）选**由智能体代为完成它的工作**：智能体会拿到这一步的输入和失败原因，交回后面步骤要用的值，运行继续进行。之后，运行的页面会在这一步旁边显示**由智能体代为完成**，并写明失败原因。

运行进行时，页面会随着进度列出各个步骤。运行结束后，**步骤**会列出每一步的结果、用时和花费；会话按钮可以打开某个智能体步骤的对话。按步骤工作的运行不接受后续追问：修改答案后重新运行即可。

按步骤工作的运行结束后，它的每个步骤都有**从这里再次运行**（↺）：用同样的回答开始一次新的运行，这一步之前的步骤沿用这次给出的结果（标为**沿用上次运行**，不花钱），其余步骤按应用现在的样子运行。**编辑**中的**试运行**也有这个按钮，用的是屏幕上的内容：修改后面的某一步，不必重新运行前面的步骤就能再试一次。

### 固化它

在**编辑**里的步骤上方，应用最近的运行会告诉你两件事。某个步骤失败、由智能体代为完成时，会说明这发生在几次运行中，以及上一次失败的原因；**请智能体修复它**会去问旁边的智能体（应用在对话旁边打开时），或者以**应用搭建师**开始一个会话。某个智能体步骤在最近每次运行中都做了同样的事（比如读取给它的网页，然后回答），就会出现**固化它**：花费更少就能完成它的固定步骤——智能体每调用一次工具就对应一个工具步骤，用的是它当时用的值，然后是一个模型步骤，带着它的指示和工具给出的结果。**用它的示例试一试**（没有示例时是**全部试一试**，用那几次运行的回答）会先运行这些步骤，并显示用它的智能体和用这些步骤时，一次运行各要多久、花多少钱；**使用这些步骤**会在屏幕上替换它，按**保存**才会保留。它生成的工具步骤失败时会由智能体代为完成，所以以前能成功的运行仍然能成功。

搭建应用的智能体也能看到这些，连同可以试的步骤。

### 应用保存的内容

应用可以在多次运行之间保存数据：一组组记录，比如阅读清单里的链接，或小型客户管理中的客户。它的步骤会添加、查找和修改这些记录，它的智能体也可以，用的是它们自己的一个工具。一组记录可以说明每条记录包含什么（标题、评分、日期……），应用会据此检查写入的内容。在**编辑**中，**它保存的内容**会列出它们：点**添加列表**，给它起个名字，愿意的话再写出记录包含的字段（没有字段时，任何记录都可以放进去）。

现成应用也会保存记录：[阅读清单](/guide/researchers#reading-list)保存你的论文，它的页面显示和修改这些论文，其他应用也会读取它们（文献矩阵接受“my reading list”）。

步骤和智能体也可以像搜索你的知识库那样，为一个问题搜索这些记录：按其中的字词，并在开启[按含义搜索](/settings?s=memory&find=Search%20by%20meaning)时按含义，最相关的排在最前。步骤也可以用 knowledge_search 和 recall 工具搜索你的知识库和记忆笔记。

应用保存的内容会一直跟着它，直到你删除这个应用。来自它的公开页面的运行永远碰不到这些数据。现成应用也会保存记录：标注工作台保存它的各组文本和你的标签，实验记录本保存它的条目；你卸载应用时，这些记录会保留下来，重新安装后随应用一起回来。

### 会记住内容的应用

应用可以跨运行记住内容：它的智能体会把以后的运行应该知道的事（你表现出的偏好、一个好用的来源、一个要避免的错误）保存在应用自己的记忆中，每次运行都从这些记忆开始。[设置 → 记忆](/settings?s=memory)会把它列为一个项目，名字就是应用的名字。在它的**编辑**中，打开**它保存的内容**下的**跨运行记忆**即可。

### 应用在这台电脑上需要的东西

应用可能需要这台电脑上的一些东西：它的智能体要用的 Node 或 Python 包，以及 ffmpeg 之类的命令。这些包会在你安装或修改应用时立即装到应用自己的文件夹里，不影响整台电脑；它的第一次运行会等它们装好。应用页面上会有一行提示正在安装或没能装上，并附有**显示输出**和**重新安装**。它要用但这台电脑上没有的命令也会在那里列出：这类命令需要你自己安装。

## 设计它的样子

应用的视图就是它的答案的样子：页面（标签页，以及点击后打开的页面）、为它的答案做的元素（一张日程卡片、一个带优缺点的产品），以及事件（说明一次点击会做什么）。没有视图时，它的答案以普通卡片和表格显示。

在应用的**编辑**中，**设计**标签页会用它最近一次运行的答案显示它的视图；**模拟答案**则改用一个按它的格式模拟出来的答案，需要修改的地方会列在下面。在预览中，点击可以前往各个页面、勾掉事项；需要触达应用的操作（问它的智能体、再运行一次）在运行的页面上才能用。

- **请智能体设计它**（应用保存之后才能用）：会以**应用搭建师**开始一个会话，并带上一条关于它的消息；如果应用正在某个对话旁边打开，这条消息就发给那个智能体。智能体会编写视图，用一次运行试一试，并修正不合适的地方。
- **从它的答案开始**：一个页面，每个答案字段各一个块，你可以从这里接着改。
- **请智能体修改它**：同上，用于已经有的视图。
- **以代码修改**：以 JSON 表示的视图，包括它的页面、元素（带有 `{{result.days}}` 这类值的 HTML，以及 CSS）和事件，写法见指南的 API 主题（[应用：视图](/guide/api#apps-views)）；预览会随你的输入而变化。
- **移除它的视图**：保存后，它的答案会重新以普通卡片显示。

视图的事件可以：前往某个页面（带上被点击的那一项）、勾掉某件事或设置一个筛选（指定时会随运行保存）、复制、打开一个地址、请运行的智能体做修改（没有步骤的应用）、运行它的其他某个流程、改动部分回答后再运行一次、启动另一个应用，以及添加、修改或删除它保存的一条记录。标为用于应用自己页面的页面会显示在那里，代替它的表单，同时显示它保存的内容和它最近一次运行。这样的页面顶部有**更新**，会立刻运行这个应用，旁边是**设置**：它表单的回答（为这些运行保存下来）和**自动更新**（每天、每个工作日或每周一次，时间由你选），就像[探索](#explore)那样。如果应用的页面是用来处理它所保存内容的工作场所（比如阅读清单），这两样都没有：它的页面会直接显示它的记录，它的按钮会运行它的表单。视图是应用的一部分：它和应用一起有版本，随应用文件一起传递，它的元素在应用的文件夹里（ui/）各有自己的文件。

除了它自己的元素，视图还有内置的元素：文本、可以勾掉的列表、表格和条形图，以及这些用于媒体的元素：

- **图片**：一张，或并排的几张，每张都带说明文字。
- **视频**：一个文件，在视图中播放；或者一个 YouTube 或 Vimeo 链接，显示它的静帧画面，点击后在页面上方播放。
- **声音**：可以播放的一段录音或一首歌。
- **地图**：答案中的各个地点，依据它们的纬度和经度标出；视图要求时，会按顺序编号并连起来。
- **图表**：折线图、条形图（也可以堆叠）、面积图、散点图、饼图、直方图、箱线图和热力图，以及 3D 的点、线和曲面，用 Plotly 绘制。

视图还可以有**小组件**：由它们自己的脚本绘制的元素（一个 3D 场景、一个游戏、一张用你选的库画的图表），它们会从网上（jsDelivr）加载它们指定的库，每个库都固定在一个确切的版本。视图中的一切都在和页面相同的沙盒中绘制：它碰不到这台电脑、你的登录或你的其他应用，只能做它的事件允许的事。

**设计**标签页下的**它自己的文件**存放随应用一起提供的图片、视频、声音和数据：**添加文件**会添加它们（每个最大 100 MB，总共 150 MB），图片可以打开大图，复制按钮会给出视图用来显示它的名字（`asset:tram.jpg`，用在图片、视频或声音块中，或模板的 `src` 里）。它们会随应用文件一起传递。预览会用它最近一次运行的答案填充视图，或者用一个模拟答案，其中的图片和视频就是它自己的文件。

## 给应用一个界面

应用可以有一个自己的界面：一个代替表单的页面，用来运行应用并显示它保存的内容。阅读清单可以把链接放在一张能搜索和整理的表格里，小型客户管理可以列出客户并配一个起草跟进邮件的按钮，记录器可以显示它记了多少条。界面是实时的：你在它的表单里提交的内容会运行应用，答案准备好就会显示出来，它的步骤和智能体修改记录时，表格也会随之变化。

- **添加界面**：打开你的应用，然后选择**更多**（⋯）→ **给它一个界面**。界面由应用自己的部件组成：它的表单、它的答案、它保存的每组记录各一张表格（下面还有与它的智能体对话），以及它之前的运行。之后它的页面会打开在这个界面上。
- **修改界面**：**更多**（⋯）→ **编辑界面**会在资料库的页面编辑器中打开它，你可以像修改任何页面一样修改它（[自己修改页面](/guide/library#change-a-page-yourself)）：移动部件、改变样式，或者问智能体。**添加**中有一个**应用**标签页，里面是应用自己的部件：**它的表单**、**它的答案**、**它的运行**、**与它的智能体对话**，它的每个其他流程各有一个表单和一个按钮，它保存的每组记录各有一张表格和一个计数。
- **或者问智能体**：“给我的阅读清单做一个界面，未读链接放在最上面，再加一个按钮生成本周摘要。”智能体会用同样的部件编写界面，也可以给应用添加更多流程，供界面上的按钮启动。

**和它的智能体对话。** 界面上的对话（由部件组成的界面上的**问问它的智能体**）是和应用自己的智能体聊天，用的是它的模型和工具：写一条消息，按**发送**（或回车），它就在那里回答。它可以查找和修改应用保存的内容，也可以替你运行应用的流程并等待结果，所以“加上《皮拉内西》，我已经读过了”或“这些里面哪些我还没读？”都能直接用。回来时，最近的一次对话还在；**新对话**开始另一个，**之前的对话**打开你以前的对话。对话和应用保存在一起，不算在它的运行里。

界面是应用自己的页面：它不会出现在你的资料库中，删除应用时会一并删除，并且会随应用文件一起传递。要用之前的答案通过表单再次运行应用，请在某次运行的页面上使用**用这些回答再运行一次**。

## 把应用作为文件分享

应用可以打包成一个文件，用来留存，或安装到另一个 Hydor 上。

- **下载**：打开应用，然后选择**更多**（⋯）→ **下载为文件**，或者在应用页面上使用它卡片上的**更多**（⋯）。现成应用也可以这样下载。这个文件（`.hydor-app`）包含它所做和所需的一切、它自己的文件（图片、视频、数据），以及它的步骤调用的应用。如果它保存了数据，打开**包含它保存的记录**就会把记录也放进去。它的文件夹、密钥和公开页面留在这里：它需要的密钥只以名称随文件传递，在安装它的地方会再询问。
- **安装**：在应用页面按**新建应用**，然后选择**从文件安装**，再选一个 `.hydor-app`、`.zip` 或 `.json` 文件（最大 160 MB）；也可以把文件拖放到应用页面上。在创建任何东西之前，会有一张卡片用浅白的话说明它是什么：它的名称和它做什么、**它会问你什么**（可选的问题会标出来）、**你会得到什么**、**它是怎么工作的**、**智能体可以使用它**（带一个开关，可以不让智能体运行它），以及**它需要的密钥**，可以现在提供，也可以在它第一次运行时再提供。**它在这里用到什么**（折叠着，有需要你留意的地方时会自己展开）列出由谁来做、它的步骤、它自己的文件、它的视图的脚本以及这些脚本加载的库、它的界面、它可以使用的工具、它使用的模型、随附的应用、它会安装的东西和用到的命令、它保存的内容、是否会记住内容，以及它的限制。每个模型都会标明是已在这里设置好、在这里用了别的名字、通过 OpenRouter 运行（第一次运行时会自动加到你的模型中，它的密钥会和应用的其他密钥一起询问），还是这里没有设置：对于这里没有的，请从你的模型中挑一个代替，或者交给智能体的默认模型。按**安装**。

有些东西会在安装时改变，卡片会说明是哪些：它在别处使用的文件夹不会带过来（每次运行都会有自己的文件夹），允许每一步都不经询问的模式会改为从**自动**开始，这台电脑上没有的智能体会被去掉。随附的应用如果和你已有的一模一样，就沿用你已有的；否则会装在你的那个旁边。它的公开页面一开始是关闭的，也没有 API 密钥。

现成应用的文件会说明它是哪个应用：在你卸载过那个应用的地方，安装这个文件会把它找回来（**已重新安装**）；在你还有它的地方，这个文件会作为你自己的一份副本安装，你可以随意修改。

## 问问智能体

Hydor 里的智能体可以通过它的 API 帮你创建和运行应用，只需你在卡片上同意即可。例如：

- “创建一个叫‘周报’的应用，询问项目和日期范围，回答包括一段摘要和一张变更表格。”
- “把这个会话变成一个我可以反复运行的应用。”
- “把‘旅行规划’和我的‘周报’置顶到应用页面最上面，周报排在前面。”
- “我最近用过哪些应用？它们上一次运行的情况怎么样？”
- “用和上次一样的回答，再运行一次我的‘比价’。”
- “帮我们两个人规划五月去里斯本的四天行程。”（“旅行规划”会在这里运行，并询问它需要的信息）
- “这周采尔马特天气怎么样？用鸡蛋、菠菜和土豆能做什么菜？”（“天气展望”和“用现有食材做饭”会在这里运行，各自在自己的视图里显示答案）
- “出十道关于罗马帝国的难题考考我。”
- “用‘旅行规划’应用安排去里斯本的行程，从 11 月 20 日开始玩四天，做好后把结果给我看。”
- “用我的‘公司调研’应用把这 20 家公司各跑一遍，然后把表格给我。”
- “每周五 18:00 运行我的‘旅行规划’，目的地里斯本，玩三天。”
- “给我的‘求职信’应用开放一个公开页面，每天最多花 $1。”
- “停止我的‘比价’应用的所有运行，并撤销它的 API 密钥。”
- “卸载‘每周新闻摘要’应用，并且不要让智能体在会话中运行我的‘比价’应用。”
- “创建一个按步骤工作的应用，读取我发来的每个链接，用一个快速模型总结它，并把它保存到阅读清单里。”
- “给我的‘竞品观察’应用加一个步骤，只在有变化时通知我。”
- “安装我‘下载’文件夹里的 reading-list.hydor-app 应用。”
- “创建一个应用，用 OpenWeather 的数据总结某个城市的天气。它需要我的 OpenWeather API 密钥。”
- “在我的‘城市短途游’应用的视图里，加一张各个停靠点的地图，再加一张每天花费的图表。”
- “把 ~/Pictures/Lisbon 里的照片加到我的‘城市短途游’应用里，并在它的第一个页面上显示出来。”
- “给我的‘周报’应用的视图加一张显示这些数字的 3D 图表，做成一个用 three.js 的小组件。”
- “给我的阅读清单做一个界面，未读链接放在最上面，再加一个按钮生成本周摘要。”
- “给我的‘周报’应用设计一个视图：一个页面在最上面放摘要和数字，另一个页面把每项变更显示成一张我可以勾掉的卡片。”
- “在我的‘比价’应用的视图里，给每家商店加一个按钮，只针对那家商店再运行一次。”
- “固化我的‘链接摘要’应用，先用它的示例试一试。”
- “让我的‘链接摘要’里‘查找标题’这一步在失败时把工作交给智能体。”
- “让探索每天早上 6:30 做出新的一期，并且每期都要有一级方程式。”
