# 应用

应用是你会一次又一次运行的任务：你填写一份简短的表单，按下“运行”，智能体就会完成这项工作，并把结果交还给你。结果会显示在专为它设计的视图中（可以点击浏览并进行操作的页面，配有地图、图表、图片和视频），或者以卡片和表格的形式呈现。本主题涵盖现成应用、如何运行应用、应用需要的密钥、如何在任意会话中让智能体替你运行应用、制作你自己的应用（步骤、视图、专属文件、数据、记忆、屏幕）、分享应用（API 密钥、其他智能体、公开网页、CSV 的各行数据），以及把应用作为文件传给别人。智能体连接的各种服务与应用并列存在：请参阅[已连接的应用、密钥和工具](/guide/connections)。

## 什么是应用

应用是针对某一项工作的小工具，帮助你查看和查找信息：你回答几个问题，它的各个步骤会查找资料并进行推算，答案则显示在专为它设计的视图中（地图、图表、表格、卡片）。你可以用两种方式使用它：在“应用”页面中打开它，或者直接在任意会话中说出你想要的功能，智能体会在那里替你运行它。应用刻意做得小巧：每个应用只把一类问题回答好，而不是做成庞大的程序。

应用包含一项任务所需的一切，只有每次都会变化的细节除外：

- **表单**：每次运行前由使用者回答的问题（“去哪里？”“几天”）。
- **任务**：要求智能体去做的事，其中已填入你的回答。
- **答案**：结果的各个字段（摘要、列表、表格），由智能体在完成后填写。没有答案字段的应用，则会给出智能体的回复。
- **由谁来做**：智能体、它的模型或档位、它的模式，以及它可以使用的工具。

每次运行应用时，Hydor 都会用填好的任务启动一个会话。智能体会从头到尾完成任务，中途不会停下来向你提问：它会做出合理的假设，并说明这些假设是什么。这样的一次完整过程称为一**次运行**。之后你可以要求修改结果，智能体会交回更新后的版本。

从侧栏的 **应用** 图标进入“应用”页面，或者访问 [/apps](/apps)。在手机上，侧边栏是一个抽屉：需要先将它打开。你也可以在搜索框中输入名称来找到任何应用，无论是你自己的还是现成的（Ctrl+K，Mac 上为 ⌘K）。

## 熟悉“应用”页面

在电脑上，页面在侧栏旁边有一列，与设置页面相同：Hydor 标志、**新建应用**（它的菜单中有 **向智能体描述它**、**从零开始** 和 **从文件安装**）以及 **隐藏侧边栏**（Ctrl+B；**显示侧边栏** 可以把它调回来），其下是页面的各个分区，每个分区标明所含应用的数量，并标出当前打开的分区：

- **所有应用**：整个页面，如下所述。
- **已置顶**、**最近使用** 和 **你自己的应用**：各自只显示那一部分。**已置顶** 和 **最近使用** 在有内容后才会出现；**你自己的应用** 则始终存在，并带有 **制作应用**。
- **类别**，这是一个标签，下方每种应用类别各占一行，并显示数量（**研究**、**规划中**、**购物**、**工作**、**写作**、**学习**、**制作**、**天气**、**体育**、**美食**、**娱乐**、**实验室** 等等，有两个或更多时才会出现）：显示该类别的应用，包括你自己的和现成的。
- **已连接的应用**，位于一条分隔线之后：所有智能体都可以使用的服务，只需连接一次，并附有它们使用的密钥（[打开“已连接的应用”](/guide/connections#open-connected-apps)）。它所在的行会显示这些服务的数量。

分区体现在地址中（`/apps`、`/apps?place=pinned`、`/apps?place=recent`、`/apps?place=own`、`/apps?kind=Research`、`/apps/connected`），因此可以通过链接直接打开。页面顶部有一行，左侧是分区名称（**所有应用**、**已置顶**、**研究**、**已连接的应用**），右侧是查找框，旁边是该分区特有的内容：**你自己的应用** 的排序方式，或者 **最近使用** 的 **最近的运行**。切换到另一个分区会清空查找框。在窄窗口和手机上没有这一列：页面标题为 **应用**，下设两个标签页 **智能体应用** 和 **已连接的应用**，各自显示所含数量；**新建应用** 位于 **智能体应用** 的顶部；各个类别则以标签的形式显示在标题行下方。以下是 **所有应用** 从上到下的内容（其他分区在同一行之下只显示各自的那一部分）：

- **查找应用：天气、食谱、旅行…**：一个输入框，输入时即可按名称、类别或功能找到任何应用（你输入的每个词都必须在某处匹配，复数也能找到单数：“recipes”能找到食谱应用），范围包括你自己的应用、现成应用、你已卸载的应用和构建模块，最匹配的排在最前。按 Enter 打开第一个结果；按 Esc 清空输入框。它位于带有页面标题（**所有应用**，或你选择的分区）那一行的右侧，页面滚动时始终停留在顶部。在某个类别的分区中，它只在该类别的应用中查找；在其他分区中，则在所有应用中查找。没有侧栏列时，它下方会有一排标签，每种应用类别一个，并标明各有多少应用（首先是 **全部**，然后是现成应用的各个类别），用来只显示某一类别。
- **已置顶**：你最常用的应用，显示为大图块，按你排列的顺序摆放，点一下就能打开。在应用卡片的 **更多**（⋯）中，或应用自己页面的 **更多** 菜单里，选择 **置顶** 就会把它放到这里，在同一处选择 **取消置顶** 则把它移走。拖动图块可以调整位置（在手机上先按住它），也可以使用图块的 **更多**（⋯）：**取消置顶**、**左移** 和 **右移**。最多 12 个应用；应用会保存这些设置，因此每台设备显示的都是同样的内容。
- **最近使用**：你最近运行过的应用，每个只显示一次，最新的在前（最多 8 个）：包括从表单运行的、从它自己的页面或屏幕运行的，或者由智能体在聊天中替你运行的。每张卡片会说明它上次被要求做什么、那次运行的进展如何以及发生在何时，并附有 **打开结果**（有自己视图的应用会在它自己的页面打开）、在等你处理时显示 **去回答**、在工作时显示 **跟进**、在失败或停止后显示 **打开这次运行**；还有 **再运行一次**，它会打开填好相同回答的表单。标题旁的 **最近的运行** 会以列表形式展开你最近的运行（最多六次）；在你用过任何应用之前，它们就是该分区的内容，名称相同。来自 CSV 各行和公开网页的运行不会出现在这个列表中，而是保留在各自的应用之下，在自己页面打开的应用（Explore）也是如此，它会在自己那里显示最近的运行。在你置顶任何应用之前，会有一行提示，告诉你可以从应用的 ⋯ 菜单中置顶最常用的那些。
- **从这些开始**：在你运行任何应用之前，显示四个大多数人都会用的现成应用（**天气展望**、**旅行规划**、**用现有食材做饭** 和 **比较产品**），点一下即可进入它们的表单，并附有一行说明应用是什么，以及 **了解更多**（[什么是应用](#what-an-app-is)）。
- **你自己的应用**：你制作的或从文件安装的应用，并显示数量，还有 **制作应用** 图块，它会打开一个新应用（可以向智能体描述它、从零开始，或安装文件）。当你的应用达到四个时，标题旁的按钮可以按 **最常用**、**按名称排序** 或 **最新** 排序；这台设备会记住你的选择。
- **现成应用**：随 Hydor 提供且已安装的应用，按类别归类（**研究**、**规划中**、**购物**、**天气**、**体育**、**美食**、**娱乐** 及其他）：可以直接运行，也可以把它变成你自己的并加以修改。

每张卡片（包括你自己的）大小都相同：它的图标、名称和功能，然后是它需要的内容（表单中的问题，或者 **可以运行了**），小标记（指向其中一个可看到说明：它的答案会在专属视图中打开，配有地图、图表和表格；它可在聊天中使用，因此你可以在任意会话中说出它的功能，智能体会在那里运行它；它需要一个应用尚未拥有的密钥；当它的公开网页已开放时显示 **公开**），在相应情况下显示 **未安装** 或 **构建模块**，以及它上次运行的时间。它的 **更多**（⋯，位于右上角；在电脑上，指向卡片时才会显示）中有 **打开**、**置顶**（或 **取消置顶**）和 **下载为文件**。当没有任何内容与你输入的匹配时，页面会显示“目前还没有应用能做这件事”，并带有 **向智能体描述它**，它会用你输入的话启动应用搭建师。

在它们下方：

- **可安装的现成应用**：当你卸载某个现成应用后就会出现。每张卡片显示它的类别、功能，以及你能从中得到什么（它视图中的各个页面，例如旅行规划的 **你的旅行**、**每日行程**、**提前预订** 和 **预算**），以及 **安装**（请参阅[安装或卸载现成应用](#install-or-uninstall-a-ready-made-app)）。
- **构建模块**（已折叠，并显示数量）：专为充当你自己应用的步骤而做的小应用（概括网页、翻译、根据网络回答、分类、提取事实），其中也包括你自己制作的模块；**添加步骤** 会在每个应用的步骤中提供它们。

一次运行的状态以徽标显示：**等待中**（排队）、**正在启动**、**工作中**、**需要你处理**（等待批准或回答）、**完成**、**失败** 或 **已停止**。

把应用的文件（`.hydor-app` 或 `.json`）拖到页面的任意位置即可安装：首先会打开一张说明它是什么的卡片（请参阅[把应用作为文件分享](#share-an-app-as-a-file)）。

在手机上，页面只有一列，没有各个分区（它的两个标签页和类别标签就代替了它们）：已置顶和最近使用的应用是可横向滚动的行，类别标签也是如此，卡片只保留名称和功能。

## 使用现成的应用

这些应用随 Hydor 一起安装：从一开始它们就在**你的应用**里，智能体可以在你的会话中替你运行它们（见[让智能体替你运行应用](#have-an-agent-run-an-app-for-you)）。每个应用都分步骤工作：它的页面会显示**它是怎么工作的**，点击**以图查看**（或**改成我自己的**）可在搭建器中打开。每个应用都会在自己的视图中给出答案，视图里有按部分划分的页面，还有能执行操作的按钮（见[它的视图](#its-view)）。它们的智能体步骤默认用 Claude Code 运行，除非你在它的页面上选了别的智能体；它们的快速步骤则交给辅助模型处理（设置 → 模型）。带有“让我……”问题的应用，只有在你勾选了该选项并且有人能回答时，才会在中途等你：可以是从它的表单运行，也可以是由智能体在你的某个会话中运行。

- **深度研究报告**：针对任意问题的带来源报告，会搜索网络、交叉核对事实，并为每个论断标注出处。你需要给出主题、关注重点、深度和读者对象。它会先规划问题，每次同时搜索三个，对来源排序，并排阅读最好的页面，遇到来源不足的问题会再次搜索，最后写出带编号引用的报告；选择**让我先检查问题**，它会等你保留或修改这些问题。它的视图有**摘要**（问题、把握程度，以及各项关键发现，每项都有**深入研究**，点击后会就它单独开始一份报告）、**完整报告**（带**复制报告**）和**来源**，来源可以按出版方显示。
- **旅行规划**：对照你的日期检查过的每日行程（营业时间、活动、路程时间），附带预算和需要提前预订的事项。它会先算出日期，然后并排查询活动和节假日、天气（行程在十天内时用天气预报）、该看什么和住哪里、以及出行方式，之后再规划每一天并汇总预算；选择**让我在规划前先选**，它会问你住哪里、哪些内容必须安排。它的视图有**你的旅行**（用数字概括的行程、计划、一目了然的每天安排和小贴士；**轻松**、**均衡**或**紧凑**，以及**+ 再加一天**，都会按那种方式重新规划）、**每日行程**（一条时间线，你可以勾掉每天的上午、下午和晚上，每天顶部是当天主要景点的图片，还有当天所在区域的地图）、每天各一页（它的图片，带**复制这一天**，以及对该区域的**研究**）、**地图**（每天的区域标在地图上，编号并按顺序连线）、**提前预订**（预订一项就勾掉一项的清单）和**预算**（一张图表和每项估算）。
- **比较产品**：当前价格、独立评测和已知问题，按你在意的方面权衡，给出明确的首选。当你描述需求而不是指定产品时，它会先找出备选项（**让我挑选要比较哪些**）；然后每次同时研究三个，给它们打分，并按你在意的方面排序。它的视图有**首选**（带图片的产品、价格和理由，以及它比较过的其他产品）、**并排**（图表上每个产品的百分制得分，然后是带图片、优缺点的每个产品，并标出首选）、每个产品各一页（带**研究它是否耐用**）和**注意事项**。它的回答里也会给出**首选**，与比较列表一致，供程序使用。
- **文档问答**：根据你附上的文档作答，每个回答都附上原文段落及其位置。它会先读文档，为每个问题找出相关段落，每次同时回答三个并在旁边给出摘要，如果某个问题仍未得到解答，就让智能体通读全文。它的视图有**回答**（每条都带原文段落和位置；**查找问题**可以缩小范围，**就这份文档再问些问题**会用新的问题和同一个文件再运行一次）和**文档**。
- **会议记录转行动项**：从原始记录或逐字稿中整理出决定、有负责人和日期的行动项、未解决的问题和一封跟进邮件。它会拆分记录，提取已做出的决定，按今天的日期推算截止日期，并询问没人认领的行动项由谁来做（**问我没人认领的事由谁来做**）。它的视图有**概览**（谁参加了、用数字概括的会议、摘要和已做的决定）、**操作**（完成一项就勾掉一项，也可以只显示某个人的）、**跟进邮件**（带**复制邮件**）和**仍未解决**。
- **求职信**：针对某个职位的求职信，以你背景中的真实证据为基础，并如实指出不足之处。它会阅读招聘启事，梳理这份工作的要求，在匹配你的证据的同时查询这家公司，写出求职信，然后检查并修改，最多两次。它的视图有**求职信**（单独一页，带**复制求职信**；**亲切**、**自信**或**正式**，以及**简短**或**标准**，会按那种方式重写）、**你为什么合适**（每项要求旁边是你的证据）和**要准备的不足之处**，可以逐项勾掉。
- **教案**：从教学目标倒推、带时间安排的课程，包含活动、理解检查、支持与拓展。它会核对所教的事实，并分配分钟数使总和刚好对得上。它的视图有**概览**（教学目标，以及准备好一样就勾掉一样的教具）、**时间安排**（整节课是一条横条，每项活动的宽度对应它的分钟数，下面再逐项列出各个活动）、**支持与检查**和**完整教案**（带**复制教案**）。
- **每周新闻摘要**：你关注的话题在过去一周的动态，来自原创报道，重复内容已合并，并说明每条报道的重要性。它会按每个话题搜索这一周，每次同时搜索三个，合并相同的报道，阅读最好的几篇并决定保留哪些。它的视图有**报道**（每条都带来自其原页面的图片；可以只显示某个话题的，把每条标为已读，或对某条进行**研究**）和**新闻摘要**（带**复制新闻摘要**）。
- **解读合同**：用平实的话讲清协议说了什么：关键术语、日期、不寻常之处，以及签字前该问什么。附上文件或粘贴文本即可。它会把合同拆成条款，并排阅读各部分，对任何严重的问题让智能体再看一遍。它的视图有**简而言之**（内容概述、用数字表示的风险点，以及要问的问题，带**复制问题**）、**风险点**（按严重程度排列，可只显示某一类）、**关键术语**和**日期**。
- **做一个小型网页应用**：根据描述做出能用的应用，使用纯 HTML、CSS 和 JavaScript，从文件就能打开，交付前已经过测试。它会规划应用（**让我在构建前先检查计划**），构建、测试，并修复到测试通过为止，最多两次。它的视图有**做出了什么**（如何打开、它的文件，以及**改动后重新构建**）和**后续步骤**，可以逐项勾掉。

日常生活类的应用更小、更快：只要有免费服务能提供真实数据，它们就会去获取（天气用 Open-Meteo，还有 TheSportsDB、做菜用的 TheMealDB、TVmaze、CheapShark、Open Library、Wikipedia、Wikidata、OpenStreetMap），必须精确的结果由程序算出，再由一个快速模型阅读、挑选，并用平实的话讲出来。它们都不需要密钥。

- **天气展望**：任何地方未来几天的天气：图表上的最高温、最低温和降雨概率、未来 48 小时、适合你计划的最佳日子、穿什么以及要注意什么。请给出一个地点（城镇名，或带地区的，如“Paris, Texas”）。它的视图有**预报**（当前天气、每天一块可展开查看逐小时情况的磁贴，以及图表；**用 °F** 或**用 °C**，以及**看未来 14 天**，会按那种方式重新运行）、**未来 48 小时**和**穿什么**（带**复制天气预报**、**最佳出行月份**，以及该地的地图）。
- **最佳出行时间**：任何地方逐月的天气，取最近五年的平均值：图表上的气温、雨天数和日照时数，并按你想在那里做的事（城市观光、海滩、徒步、滑雪、避暑）给每个月打分。它的视图有**逐月**（顶部是该地的照片、最佳月份、按适合程度着色的十二个月，以及图表；**最适合**可以改选另一种旅行类型）、**什么时候去**（最佳月份及原因、应避开的月份、小贴士）和**数字**。
- **球队追踪**：任何球队接下来的比赛、最新结果和状态、所处排名，以及本周的新闻。它的视图有**球队**（队徽、用彩色字母表示的近期状态、带**看前瞻**的下一场比赛）、**结果**（图表上的进球和失球）、**赛程**（每场都带**预览**，点击后会开始一份赛前前瞻）和**新闻**。
- **赛前前瞻**：两支球队交手之前的情况：它们的状态、最近几次交手、球队消息和专家的预期，以及各种结果的概率。它的视图有**预览**（双方队徽、可能的结果、用一条横条表示的概率）、**状态和交手记录**（图表上显示最近几次交手谁赢了）和**球队消息**（带**复制前瞻**和**跟随最新**球队）。
- **用现有食材做饭**：用你冰箱里的东西做的食谱：每道菜用了你有的哪些食材、还需要什么，附照片、带时间安排的步骤，有视频时还会附上。请说明你的饮食要求和你有多长时间；盐、油和香料默认算作已有，除非你另外说明。它的视图有**食谱**（**来点更快的**会重新运行）、每道食谱各一页（它的步骤是一条分钟横条，做的时候逐步勾掉；食材有的会标记出来；带**复制步骤**）和**要买什么**。
- **餐食计划和购物清单**：一周的晚餐（最多两份），按你的家庭情况、饮食和口味挑选，每道都有食谱和照片，另有一份涵盖所有菜的购物清单，用量已汇总，并按货架区域分类。它的视图有**这一周**（**再规划一周**）、每顿晚餐各一页（它的食材、做法和视频）、**购物清单**（可以只显示某个区域，购物时逐项勾掉，**复制清单**）和**小贴士**。
- **礼物点子**：在你的预算内为某个人挑选用心的礼物，包括物品和体验，每个都说明为什么适合对方、通常的价格，以及一个可以现在购买的选择，附上价格和商店。它的视图有**点子**（每个都带可购买选项的图片，按类别排列；**☆ 收藏**你喜欢的，**更多类似的**会重新运行）和**按价格**（图表上的价格区间）。
- **看什么**：按你今晚的心情挑选的电影和剧集，列出每部在你所在国家的哪个平台播出（先列你订阅的服务）、时长、预告片以及为什么适合你。它的视图有**今晚**（今晚的首选，然后是其他的；图片上的 ▶ 表示有预告片）、每部各一页（预告片就在那里播放，带**看过了：重新挑选**）和**并排**。
- **找游戏**：根据你的喜好和你玩游戏的平台（可选项包括 Nintendo Switch 2）挑选的游戏，可以是已发售的、即将发售的（并说明发售时间），或两者都有，每个都带图片和预告片、为什么适合你以及通关要多久；PC 游戏还会给出今天的最低价和历史最低价。它的视图有**游戏**（图片上的 ▶ 表示有预告片，尚未发售的游戏会注明发售时间）、每个游戏各一页（预告片就在那里播放，带它的优惠和**更多类似的**）、**价格**（图表上显示当前价和历史最低价）和**通关时长**。
- **任意主题测验**：可以在它的页面上玩的测验，题目事实取自 Wikipedia：选一个答案，它会告诉你对不对以及原因，得分显示在顶部；每次答案顺序都会重新打乱。它的视图有**玩测验**（**重新开始**、**来个更难的**、**新题目**）、**回答**和**关于这个主题**（带**复制测验**）。
- **找书**：根据你喜欢过的书，推荐你可能会爱上的书，每本都用 Open Library 核对过封面、页数和评分。它的视图有**你的书架**（每本书各一页，带**更多类似的**）和**阅读清单**（**标为已读**）。
- **有什么活动**：你选的日期里（不指定就是即将到来的周末）一个城市里可以做的事：从网上找到的音乐会、集市、展览和亲子活动，并附上每天的天气。它的视图有**按天**（每个活动都带来自其原页面的图片）、**地图**（每个场地都有编号）和**按类别**；可以标记你要去的活动（**要去吗？**），也可以**复制清单**。
- **储蓄计划**：如何在某个日期前达成储蓄目标：每月存多少（已计入利息）、图表上不断增长的余额，以及多存或少存 20% 时你什么时候能达成。它的视图有**计划**（如果你给出了金额，会有**每月多存 50** 或**每月少存 50**）、**逐月**（各个里程碑和每个月的情况）和**小贴士**。
- **把数据画成图表**：把电子表格、CSV 或你粘贴的数字，做成最多三张合适类型的图表，并用几句话说明它们显示了什么。它的视图有**图表**、**数据说明了什么**（每项发现，都可以复制）和**数据**（各列的概要，以及**就这份数据再问一个问题**）。
- **主题时间线**：把任意主题做成时间线，内容取自 Wikipedia：带日期的关键时刻（**详细**模式下最多三十个）、各个时代，以及简短的来龙去脉。它的视图有**时间线**（可以只显示一条线索；**就它出个测验**会就这个主题开始一个测验）和**图表**（按年份排列的时刻，转折点画得更大，以及各个时代）。
- **探索一个地方**：在地图上显示任何地方（城市、街区或地标）周边有什么：你在**你喜欢什么**下写出的地点类型（狗公园、咖啡馆、游乐场……）排在最前，来自 OpenStreetMap，然后是来自 Wikipedia 和 Wikidata 的最知名景点，再是博物馆、公园和地标，每个都有一张图片和一行说明，最适合你的会被挑出来，并按步行顺序排好。什么都不填，它就只根据景点来安排。它的视图有**步行路线**（各站编号并连在地图上，每站可标记已看过；**那里的天气**）和**周边的一切**（可以只显示一类）。

研究和实验室类的应用会跟进你所在的领域，阅读并核查论文，并照看你的实验和报告。其中几个会在各自的页面中打开，并且可以自行更新，就像“探索”那样；[研究](/guide/researchers)主题介绍了它们如何配合使用。

- **论文雷达**：每天早上推送你所在领域的新论文（arXiv 的，按你关注的类别、主题和作者筛选；以及 OpenAlex 上按你的主题筛选的），按你的项目、主题和个人资料排序，每篇都用一句话说明它做了什么以及为什么对你重要。它在自己的页面中打开，可以每天更新。它的视图有**今天**（论文按它契合的项目或主题归类，带有**☆ 保存**、**引用**、**PDF**、**深入研究**和**不适合我**，这些操作会影响之后几天的推荐）和**已保存的论文**（带**全部复制为 BibTeX**和**加入阅读清单**）。见[跟进你所在的领域](/guide/researchers#keep-up-with-your-field)。
- **引用提醒**：自它上次查看以来，谁引用了你的论文，附上引用你的那句话（你的论文被提及的地方会标出），以及对方是在你的工作基础上展开、与之比较、质疑它，还是只是提到它。它在自己的页面中打开。它的视图有**新增**（按你的论文列出的新引用；可以只显示一类）和**你的论文**（每篇都带它的引用，以及其中有多少是新的）。
- **新模型追踪**：Hugging Face 上某一类的新模型（重排序模型、嵌入模型等），对照你的许可证、大小和下载量进行检查，概括每个模型的模型卡；如果你提供了评估命令，还会在实验中运行每一个，并且只有在某个模型胜过你目前最好的结果时才通知你。它在自己的页面中打开。它的视图有**模型**（每个模型的位置、它的模型卡说了什么、它的得分）和**你的评估**。
- **截稿雷达**：根据开放的 ccfddl 和 ai-deadlines 列表整理出你关注的会议的截止日期，从 AoE（或征稿通知中给出的时区）换算成你的时区，并按你指定的天数（14、3 和 1）提醒，合并成一条通知，同时附上每个征稿通知的页数限制和模板链接。它在自己的页面中打开。它的视图有**时间安排**（每个截止日期及剩余时间、**复制截止日期**、**显示已过去的**）和**会议**。
- **动态相关工作**：每个主题一个页面，随着论文出现而不断增长（来自 arXiv 和 OpenAlex，以及引用了你的种子论文的论文），每篇论文都有概述，并说明它与你的关系，按主题分组，新的会被标出。它在自己的页面中打开。它的视图有**相关工作**（逐个主题、逐个议题地显示，带**起草相关工作**——由智能体写出带 `\cite` 键的 LaTeX 章节、**导出 BibTeX**，以及每篇论文上的**不相关**）和**本次新增**。
- **研究空白发现器**：把你的论文与某个领域本月的论文交叉组合，得出项目想法，每个都核查过已有工作（**新增**、**部分已有人做过**或**已有人做过**，并附上最接近的论文），并按你拥有的算力来估算规模，给出它的第一个实验。它的视图有**研究想法**（每个都带**规划它**，点击后会把它带进“研究冲刺”应用，以及**深入研究**）和**交叉组合了什么**。
- **阅读清单**：按项目整理的你的论文，每篇都有它的 PDF、BibTeX、标签、状态和备注，并与 Zotero 保持同步。它在你的论文上打开：**+ 添加**可以通过 DOI、arXiv 编号、链接或标题查找一篇并自动填好（你已有的会被补全，不会重复添加）；可以搜索论文，只显示某个状态、标签或项目，并把每篇标为**待读**、**在读**或**已读**。每篇论文自己的页面上有它的链接、备注和 BibTeX，以及**复现它**；**按项目**会统计每个项目的论文数。**更多**里有**导入 .bib**、**导出 .bib**和**与 Zotero 同步**（第一次会要求输入它的密钥），勾选的论文可以生成一份**文献矩阵**。见[阅读和整理论文](/guide/researchers#read-and-organise-papers)。
- **文献矩阵**：把论文并排阅读后做成电子表格：每篇论文一行，每个比较项一列（除非你更改，默认是任务、数据、方法、指标、结果和局限），每个单元格都标明出自哪一页。论文可以一行一篇地给出，或者给“我的阅读清单”并带上标签、项目或状态。它每次同时阅读三篇，并把矩阵作为电子表格保存在你指定的项目的文件中。它的视图有**矩阵**（**打开电子表格**、**复制为表格**、它没能读取的论文及原因，以及**再加一列**）、**论文**和**跨论文综述**。
- **复现论文**：运行论文的代码来核对它的数字：它会找到代码（在论文里，或在 GitHub 和网上），搭建干净的环境，获取数据和检查点，先跑一小部分，再跑完整的运行（耗时长的会放在[实验](/guide/experiments)中并等待完成），全程不超出你给的限制，并把每个数字与论文中的对比。它的视图有**复现成功了吗？**（论文的数字与我们的数字并排、**打开文件夹**、**重试**）、**所花的功夫**和**报告**。
- **审稿人模拟器**：用会议自己的表格和评分标准来审阅你的草稿（ACL Rolling Review、SIGIR、NeurIPS、ICLR、ICML、KDD、CIKM、WSDM、TheWebConf 或某个期刊），由最多五位审稿人各从自己的角度审阅，再由领域主席给出元评审。它的视图有**审稿意见**、**元评审**（包括可能使论文被拒的问题，最危险的排在最前）、审稿人会要求的**基线和消融实验**，以及**投稿前要做的事**（一份可逐项勾掉的清单，和**回复这些审稿意见**，点击后会开始“反驳工作台”）。见[审阅、回复和展示你的论文](/guide/researchers#review-answer-and-present-your-paper)。
- **反驳工作台**：把各位审稿人的意见要点归并后分类（误读、需要实验、需要文字说明、次要问题），在会议的字数限制内按你选的语气为每一点起草回复，需要新结果的地方留有占位符。它的视图有**提出的要点**（每点都有它的草稿、长度与其应占份额的对比，以及**复制**）、**待办**（需要做的实验和修改，可以逐项勾掉）和**完整反驳**（带**复制完整反驳**）。
- **论文转演讲、海报和推文串**：根据你的论文，生成你挑选的内容：带时间安排、使用论文真实插图和公式并附讲稿的幻灯片，A0 海报（一份 LaTeX 文档），给 X 和 Bluesky 的推文串、给 LinkedIn 的帖子，以及项目主页，保存在你指定的项目的文件中。它的视图有**做好的内容**（每项都带**打开**）、**演讲**（它的幻灯片是一条分钟横条）和**推文串**（每个平台的帖子，可以复制）。
- **插图医生**：把你的绘图脚本改到适合放进论文：按会议模板设置栏宽、使用论文的字体、选用色盲读者也能分辨的颜色、输出嵌入字体的矢量 PDF（不含 Type 3 字体），以及一份通用的样式文件，原始文件会保留在旁边。它的视图有**修改前后**、**样式文件**（带**复制**）和**有哪些变化**。
- **标注工作台**：你和一个模型给同一批文本样本做标注。给它标签（最多九个）、你的标注准则，以及文本：一个 CSV 或 JSON lines 文件、按名称指定的 Hugging Face 数据集，或粘贴的文本；它会随机抽取一份样本，并让辅助模型按你的准则标注。它的运行页面就是你做标注的地方：**标注**（一次一条文本，一个大按钮，每个标签对应一个 1 到 9 的按键，只有在你给出自己的标签之后才显示模型的标签）、并排显示的**分歧**、**一致率**（你们多常一致、Cohen's κ 和混淆矩阵）和**导出**（下载为 CSV 或 JSON lines，或者**发布到 Hugging Face**并附上数据集卡片）。见[运行你实验室的工作](/guide/researchers#run-your-labs-work)。
- **研究冲刺**：在你自己的代码上，把一个研究问题推进一轮冲刺：提出假设、制定计划，并在单独的分支上写代码（放在它创建的工作树里），在你的 GPU 小时数内于[实验](/guide/experiments)中运行，附一个分析笔记本和一份简短报告，并会等你确认保留这些假设、再开始运行。它的视图有**冲刺**（每个假设及其结论和证据）、**运行记录**（带与基线对比的结果表）和**报告**。
- **参数扫描规划**：在运行次数或 GPU 小时数的预算内，对训练脚本做超参数扫描：智能体读取脚本的参数并提出设置和取值（或采用你给的），实验负责运行并提前停掉表现差的尝试，再由程序算出每个设置的影响有多大。它的视图有**结果**（最佳运行、它的发现、接下来可以试什么）、**按参数**（每个参数一张图表）和**所有运行**。
- **每周进展报告**：把你这一周整理成给导师、团队或经理的更新（完成了什么、带数字的结果、问题和阻碍、下周计划、要提的问题），资料来自你的会话（包括 VS Code 和终端中的会话）、提交、运行和阅读。它在自己的页面中打开，显示本周的报告，带**复制为 Markdown**、**复制为邮件**和**保存为文档**，更早几周的报告排在下面；打开**自动更新**后，每周五 16:00 会生成新的一份。见[报告：你的一周和你的实验记录本](/guide/researchers#reports-your-week-and-your-lab-notebook)。
- **实验记录本**：你工作的每一天各有一条带日期的记录：试了什么、发现了什么、决定了什么，以及还有什么没解决，并链接到当天的会话、提交、运行和文件。它在自己的页面中打开，记录按时间从新到旧排列，可以按字词和含义搜索，每条记录都有可供引用的链接；打开**自动更新**后，它会在每天晚上 21:00 写下当天的记录。

你不能修改现成的应用本身。要调整某个应用，请打开它并点击**改成我自己的**（在手机上是**编辑**）：搭建器会打开一份副本，创建之后它就成为你自己的应用。

### 探索

**探索**是为你量身定制的杂志：收录与你的工作和兴趣相关的文章与最新资讯。你可以从起始页右上角的**探索**打开，也可以从“应用”页面打开。它不需要每次填写表单：它有自己的页面，打开后就是最新的一期，智能体不会在你的会话中运行它。

- **它如何挑选内容**：它会读取你的个人资料、记忆中关于你的备注，以及你最近会话的标题（不包括已关闭记忆的会话、智能体为完成部分工作而启动的会话，以及无人查看的应用运行），然后让辅助模型挑选大约六个你现在会感兴趣的主题：约一半来自你的工作，另一半来自你生活的其他方面，绝不涉及任何私密内容。针对每个主题，它会在新闻网站上搜索过去两周的报道，并寻找长文（解读、分析、随笔），**并行**阅读最好的网页，为每篇写出摘要并找到配图。对于不允许程序访问的网站，它会根据搜索结果中显示的内容来写摘要。一期杂志需要一两分钟。
- **一期杂志**：包含日期和封面语、编辑的话、各个主题（点击某个主题只显示它的报道，点击**所有内容**显示全部）、封面报道，然后是每个主题各自的版块。每篇报道都有配图、**新闻**或**长文**标记、来源和日期、内容概要，以及它出现在你这一期中的原因。点击配图或标题即可在原网站阅读：之后它会被标记为**✓ 已读**，在以后的各期中也是如此。**深入研究**会针对这篇报道启动一份深度研究报告。在这一期的下方，**更早**列出之前的各期，每一期打开后都保持当时的样子。
- 顶部的**更新**会立即生成新的一期。生成期间，会有一行文字说明它正在做什么，并带有**跟进**，而你现有的这一期会保留，直到新的一期准备好。在第一期出现之前，**做出第一个**的作用相同。
- **设置**，即**更新**旁边的滑块图标：**自动更新**（默认关闭，需要你手动开启）会在每天早上准备好新的一期；在它下面，选择日期（**每天**、**每个工作日**，或**每周一次**，星期几由你选择）和时间（默认 07:00）。它是一个[定时任务](/guide/tasks)，因此“设置 → 定时任务”中也会列出它；关闭它会将其删除。再往下是**要读取的最近会话数**（读取你最近多少个会话的标题：默认 1,000，最多 1,000）、**也要涵盖**（始终包含的主题，每行一个）和**排除**（要跳过的主题或网站，用逗号分隔）。**保存**会将这些设置用于之后的每次更新，包括每日自动更新。
- **改成我自己的**和**卸载**位于它的**更多**（⋯）菜单中。

每一期会向辅助模型提出大约二十个简短的问题，并进行十几次网络搜索；如果已登录 Claude Code，这些问题会消耗你的套餐额度。

### 安装或卸载现成应用

你不用的现成应用可以卸载：打开它，然后依次选择**更多**（⋯）→**卸载**，并确认。它会从**你的应用**中移除，智能体不再在你的会话中运行它，它会出现在“应用”页面的**可安装的现成应用**下等待。它的运行记录会保留。

想要恢复它，点击那里的卡片即可。在做出任何更改之前，卡片会展示这个应用的情况：它能做什么、**它会问你什么**（可选的问题会有标注）、**你会得到什么**、用通俗的话说明的**它是怎么工作的**，以及带有开关的**智能体可以使用它**。**安装**会把它放回你的应用中并打开它。它自己的页面会显示“你已卸载它”，同样带有**安装**。

## 运行应用

1. 从“应用”页面或搜索框打开应用。它的页面顶部会说明它能做什么，下面是**你的回答**（即它的表单），在它们旁边（手机上在下方）是**你会得到什么**（它的回答所在的页面，或它的回答字段）、**在你的会话中**（智能体是否可以替你运行它：参见[让智能体替你运行应用](#have-an-agent-run-an-app-for-you)）、**最近的运行**（每一项都会打开对应的运行），以及对于有步骤的应用，还有**它是怎么工作的**：按顺序列出它的各个步骤，并说明每一步的运行方式（**逐项**处理、几个**个同时运行**、**并行**），以及**以图查看**，它会在构建器中打开这些步骤。
2. 填写表单。带红色 **\*** 的问题是必填的。
3. 表单下方的一行说明由谁来运行，例如“Claude Code · Sonnet · high effort · Auto”。对于现成应用，**修改**会显示选择器（见下文）；对于你自己的应用，请用**编辑**来修改。
4. 点击**运行**。运行页面会打开，并实时跟进工作进展。

如果有内容缺失，页面会显示“请先填写标有标记的问题”，并在每个问题下指出问题所在（“必填”“请输入数字”“选择文件”）。

链接可以替你填好表单：在应用的地址后加上 `?in.`、问题的名称、`=` 和答案，就会打开它的页面，并把这个答案填入表单，随时可以修改：在你点击**运行**之前不会运行任何内容。[这个链接](/apps/t/reproduce-paper?in.paper=2104.08663)会打开“复现论文”，并已填好一篇论文；更多答案用 `&in.` 继续添加（文件除外）。智能体会给你这样的链接，视图中的按钮也会（例如阅读列表中某篇论文的**复现它**）。有独立页面的应用，此时会打开它的表单。

### 问题的类型

- **短文本**和**长文本**：一行文字，或随输入自动变大的文本框。
- **数字**：普通数字；“$1,250.50”会被识别为 1250.5。
- **日期**：日期选择器。
- **选项**：少量选项以标签显示；较多时以列表显示。再次点击已选中的标签可清除可选问题的选择。允许多选的选项会显示可勾选的标签，每个已勾选的带有对勾；你勾选的内容会按每行一个选项保存。
- **是 / 否**：一个开关。
- **文件**：要附加的文件。

问题下方可能有一行帮助说明、框中的示例答案，以及一开始就填好的值。

### 选择智能体、模型、思考强度和模式

对于现成应用，表单下方那一行旁边的**修改**会显示选择器（**完成**会将其收起）：

- 程序：Claude Code、Codex、Custom（Hydor 自己的智能体，可用于任何模型），或你添加的其他智能体。
- **模型**：首先是**快速**、**标准**、**最佳**和**最大值**，每个都对应该程序当前所指的模型（参见[档位：为每类工作选择合适的模型](/guide/agents-models#tiers-a-model-for-each-kind-of-job)）；然后是该智能体按名称列出的模型。档位会随模型的变化而跟随[设置 → 模型 → 档位](/settings?s=models&find=Tiers)。按名称选择的模型优先于档位。更换程序时会保留档位，但不会保留按名称选择的模型。
- **思考强度**：模型思考的投入程度，适用于提供分级的模型（Custom 和其他添加的智能体不适用）。
- **模式**：智能体无需询问你就可以做的事情。它从**自动**开始，因为运行时没有人在旁边看着。如果选择每一步之前都要询问的模式，运行就会停下来等你。

此浏览器会记住你上一次的选择（包括档位），用于你接下来运行的下一个现成应用。现成应用本身不会改变：它们会从你在这里选择的内容开始。

### 附加文件

文件问题会显示**选择文件**，在电脑上你也可以把文件拖放到它上面。每个文件最大 25 MB。文件会保存在这次运行的文件夹中，智能体会拿到它的路径，因此可以像读取其他文件一样读取 PDF、Word 文档、电子表格和其他文件。已选文件旁边的 **×** 可以将其移除。

### 提供它需要的密钥

有些应用要配合需要密钥的服务使用：API 密钥或令牌（天气服务、地图提供商，或你在某处的账户）。应用只会列出它需要的密钥名称，绝不会列出密钥的值：每个密钥你只需提供一次，它会保存在你的保管库中（[把密钥存放在保管库中](/guide/connections#keep-keys-in-the-vault)），智能体按名称使用它，但看不到它的内容。

- 在应用页面上，表单下方的**它需要的密钥**（或**它需要的密钥**）会列出每一个：它是什么、它在保管库中的名称、一行获取方法的说明、一个用来粘贴密钥的框，以及**获取**，它会打开获取密钥的页面。点击**运行**：密钥会先存入保管库，然后运行开始。保管库中已有的密钥会显示为**已保存**，并带有它的最后几个字符和**修改**；应用没有它也能工作的密钥会标为**可选**。
- 从文件安装应用时，它的卡片也会要求提供它的密钥：可以在那时提供，也可以在它第一次运行时提供。
- 当智能体在会话中替你运行它时，那里的卡片会要求提供它缺少的密钥；密钥会直接进入保管库，绝不会出现在对话中。
- 只有应用的某一部分需要的密钥（阅读列表的 Zotero 密钥，用于**与 Zotero 同步**）不会在它的表单上询问：你第一次使用那一部分时，它的页面会要求提供。

缺少所需密钥的运行不会启动：在它的表单上，系统会向你索要（“运行它需要此项”）；通过 API、定时计划或 CSV 的各行发起时，运行会被拒绝，并说明要添加哪个密钥（在它的页面上，或在**应用 → 已连接的应用 → 密钥**中按该名称添加）。如果你保存的某个密钥原本不允许发送到应用要发送的网站，它所在的行会说明这一点，并带有**允许**。

有些应用会通过 OpenRouter 使用模型（比如会画图的模型）。它们会以同样的方式要求你提供 **OpenRouter API 密钥**，并带有**获取**：它保存在[设置 → 模型](/settings?s=models)中，而不是保管库，也供你的其他应用和 Custom 使用，应用第一次运行时，模型会自动添加到你的模型中。在 Ollama、vLLM 或某个端点上运行的模型需要在“设置 → 模型”中手动设置：在设置好之前，运行会被拒绝，并说明缺少哪个模型以及如何设置。

### 运行在哪里进行

每次运行都会在你的主文件夹内的 `hydor-apps` 文件夹中获得一个属于自己的新文件夹，以应用名称和时间命名。应用也可以指定一个文件夹（参见[由谁来做](#who-does-it)）；这样每次运行都在那里工作。

你从表单发起的运行，其会话会像其他会话一样显示在侧边栏的会话列表中，标题是应用的名称和你的前几个回答。通过 API、其他智能体、公开页面或 CSV 的各行发起的运行会被归档，因此不会出现在列表中，而是显示在对应的应用下。

## 让智能体为你运行应用

你不必打开应用才能使用它：在任意会话中说出你想要的结果（“帮我们两个人规划 5 月去里斯本的 4 天行程”），智能体就会在会话里运行它。

1. 智能体会找到能完成你请求的应用，并填入你说过的内容：地点、天数、同行人数。当你的消息明确要求某个应用所做的事时，智能体会随你的消息得知是哪个应用，因此会直接运行它，而不是自己动手做。应用很多时，它会按应用的功能来搜索（按字词搜索；开启按含义搜索后也会按含义搜索），并从最匹配的二十个中挑选。
2. 应用运行之前，它的卡片会出现在对话中并先征求你的同意，除非该应用在你的“无需询问直接运行”应用列表里（见下文）。卡片上写着“智能体想为你运行这个应用。”，并显示应用的图标和名称、它的功能简介、**它做什么**（按顺序列出它的步骤，最多六步，之后显示“另外 3 步”）、**来自你的消息：**以及它从你的话里提取的内容、**上次运行:**（最近一次运行花了多长时间、花费多少），还有**关于这个应用**，点击会打开该应用的页面。当应用需要你没有说明的信息时，剩下的问题也会显示在卡片上：它需要但你还没提供的密钥会在这里询问，并存入你的保险库，而不会出现在对话里。请填写标有红色 **\*** 的项目；如果不介意，可以将可选项留空。如果某个问题无法按你说的方式理解（例如把“5 月”当作日期），卡片会在它下面显示你原来的话。**运行它**会运行应用一次；**总是运行**会把该应用加入你的列表并运行它，之后它的卡片就不再询问；**不运行**会关闭卡片且不运行任何东西：智能体会用别的方式完成任务，或者来问你。卡片等待期间，会话会显示**需要你处理**，收件箱中也会列出它。列表中的应用如果需要你的消息里遗漏的细节，仍会显示卡片；此时的按钮是**运行它**和**暂不**。定时任务自己的会话会不经询问直接运行应用：任务是你设置的，而且没有人在场回答。
3. 应用的卡片会留在对话中，位于智能体回复的下方，并跟随运行过程：先显示运行进度和经过的步骤，然后按应用自身的方式显示它的回答（它的视图，含页面和按钮；**普通答案**则以卡片和表格显示）。它的某个步骤提出的问题（以“让我……”开头的那种）也会在这里等待。**打开**会进入这次运行的页面，点击应用名称则进入该应用。
4. 随后，智能体会用一两句话说明结果；这次运行自己的回复则保留在运行页面上。如果应用的回答与你的请求不符，智能体改为自己作答，它会把应用的卡片从对话中移除，这样你只会得到一个答案，而不是两个；这次运行仍保留在该应用的运行记录中。较长的运行会在智能体停止等待后继续进行：它的卡片会继续跟随运行，运行结束时智能体会收到它的回答（这时不会显示你的任何消息）并作出回复，卡片会移到这条回复下方。高于屏幕的回答会从顶部开始显示，智能体对它的说明在其上方；其余部分向下滚动即可看到，**最新**会跳到末尾。

它的运行在该应用的运行记录中会显示**来自会话**。

每个应用的页面上，表单旁边有**在你的会话中**，其中有开关**智能体可以使用它**（你自己的应用在**API 与分享**下也有这个开关）。关闭后，智能体不再运行该应用；你可以随时重新打开。每个应用默认都是开启的。构建模块，以及设计成在自己页面上单独使用的应用（带有界面，或带有它所保存内容的视图），会在那里另作说明，智能体不会运行它们。当你自己的应用与现成的应用功能相同时，智能体会优先选择你的。

[设置 → 应用](/settings?s=apps&find=Run%20without%20asking)中的**无需询问直接运行**列出了智能体无需先询问就会运行的应用：点击某个应用旁边的 **×** 会让智能体重新先询问，**添加应用**则可以在被询问之前先添加一个。

每个会话都会被告知你的应用：你最常运行的几个会附上功能简介，其余的只列名称，总共最多 40 个。超过这个数量时，当请求需要时，智能体会自己去找其他应用。

## 跟踪运行并查看结果

运行页面会显示应用的名称、它收到的回答（一行显示，如“Lisbon · 2026-11-20 · 3”）、它的来源（“来自表单”“测试运行”“来自 API”“来自另一个智能体”“公开页面”“第 3 行”）以及开始时间。运行结束后，顶部的**再运行一次**会打开以相同方式填好的表单。

顶部的状态卡片会显示当前进度：

- **排队中**、**正在启动…**，或带有已用时间的**工作中**。工作时，你会看到它最近的步骤（“搜索了网页”“阅读了一个页面”“更新了计划”）以及智能体最后所说内容的开头。
- **它需要你在会话中批准**或**它在会话中有个问题要问你**：智能体正在等你。打开会话进行回答；批准请求也会显示在[收件箱](/inbox)中。
- **完成，用时**多久，并显示花费。
- **已停止**，或带有原因的**它没有完成**。

下面是结果。带视图的应用会在这里显示视图（见[它的视图](#its-view)）；状态卡片中的**普通答案**会改为以普通卡片和表格显示，**它的视图**则切换回去。没有视图时：

- 简短的答案字段（文本、数字、日期、链接、是或否）会合并在同一张卡片中。
- 长文本、列表和表格各自在标题下有一张卡片。长文本有**复制**按钮；表格有**复制**和 **CSV**（下载），图片列会以小图显示（点击可查看大图）。
- 图片、视频、声音和文件：图片以网格显示（点击可查看大图，用箭头切换其他图片），视频和声音可播放，其他文件可下载。位于其他网站的内容（YouTube 上的视频、某个页面）会在那里打开。
- 在手机上，对屏幕来说太宽的表格会按每行一张卡片显示。

智能体自己的回复紧随其后。当应用没有答案字段时，它会展开显示在**回答**下；否则会折叠在“智能体的回复”下。**提出的请求**（已折叠）列出这次运行收到的回答。

如果智能体在没有提交答案字段的情况下结束，会被提醒一次。既没有回复也没有结果就结束的运行会被视为失败（“智能体结束时没有给出回答”）。

底部的**用这些回答再运行一次**会打开以相同方式填好的表单，可修改后运行。文件不会被带过去：请重新选择。

顶部的**打开会话**（在手机上是**会话**）会打开这次运行的完整对话。

### 它的视图

应用的视图是为它的回答量身定做的：用专属元素展示回答的页面（卡片、时间线、图表、可勾选的清单），以及用回答来做事的按钮。

- **页面**：顶部的标签页；第一个最先打开。有些页面通过点击打开（行程中的某一天、某个产品），页面顶部有返回的入口。
- **勾选和选择**：你勾掉的项目（已完成的预订、已做的操作）会保留在这次运行中，并在所有设备上同步；筛选和选择（某个主题、某个负责人）在页面打开期间保持有效。
- **再次运行的按钮**：行程上的**轻松**或 **+ 再加一天**，信件上的**正式**，针对同一份文档的新问题框。每个按钮都会先询问，然后以你的其他回答原样（包括文件）开始一次新的运行并打开它。
- **启动另一个应用的按钮**：新闻报道或行程所在地区上的**研究**，某个发现上的**深入研究**：每个都会先询问，然后启动该应用的运行并打开它。
- **复制**：可粘贴到别处的一部分内容（一封邮件、一封信、要提的问题）。
- **地图、图表、图片和视频**：显示其回答中各地点的地图（可拖动和缩放；地点会显示名称，点击它可能会打开其页面）、图表或 3D 图（指向某根柱子或某个点即可读取数值，可放大，3D 图可旋转）、可放大查看的图片（没有图片或图片无法加载的条目会不带图片显示，文字占据其空间），以及可播放的视频和声音，来源可以是文件，也可以是 YouTube 或 Vimeo。地图、图表和视图自带的绘图会从网络加载它们的库（地图还会从 OpenFreeMap 加载地图本身，随应用显示浅色或深色），因此这台设备需要联网。
- 在你自己的应用上，视图还可以请它的智能体做修改（没有步骤的应用）、运行它的其他流程，或在它保存的内容中记录一条记录。

视图会显示在运行页面上、它所属会话的**结果**中，以及应用的公开页面上；在公开页面上，它的页面和勾选可用，但不会影响应用本身（不能再运行，不能新建运行，也不会保存任何内容）。

## 请求修改结果

运行并不是最终的。在运行页面底部有一个框，写着**对结果提出修改…**（当应用没有答案字段时是**提出修改…**）。

1. 输入要修改的内容：“让第 2 天别那么紧凑”“加一列营业时间”“更简短，也更温暖一些”。
2. 按 Enter 或点击箭头按钮。Shift+Enter 换行。在手机上，Enter 是换行：点击箭头发送。

追问会发送到这次运行的会话。智能体完成工作后会提交整个更新后的结果，替换页面上的旧结果。每条追问都会显示在**追问**下，附有智能体的回答；如果结果有变化，还会显示**已更新结果**。状态卡片随后会显示“已更新，用时 …”，如果追问只需要一个回答（一个问题、一句感谢），则显示“已回答，用时 …”。

如果你在智能体仍在工作时发送追问，它会带着“排队中”的提示等待，并在当前这一轮结束后发送给智能体。一条追问最多 20,000 个字符。

来自公开页面的运行不接受追问。会话已被删除的运行，或会话在其他程序中打开的运行，也不接受（请在那里继续）。

## 处理运行的会话

从侧边栏打开时，运行的会话首先显示**结果**，与运行页面上的视图相同，顶部有切换到**对话**的开关。（运行页面上的**打开会话**会直接进入对话。）此时会话的消息框写着**对结果提出修改…**：你在这里发送的任何内容都是追问，与在运行页面上一样，你在一处开始写的草稿会带到另一处。

在**结果**视图中，智能体的批准卡片显示在结果下方，因此你可以在那里批准或拒绝。如果它有的是问题，则会有一张卡片写着**它有个问题要问你。**，并带有**去回答**，点击后会切换到对话。

在对话中，智能体提交结果的时刻会显示为**结果已提交**，并带有**打开结果**。如果它提交的内容不符合答案字段，会显示**结果暂时还不符合答案字段**以及问题所在；智能体会修正并重新提交。

## 停止运行或移除它

- **停止**（运行进行时位于顶部）：排队等待的运行会立即结束；正在工作的运行会被中断并显示**已停止**。
- 运行结束后，垃圾桶按钮（**从列表中移除**）会询问“移除这次运行？”，并把它从应用的运行列表中删除。会话仍会保留：如果也想删除它，请从会话的菜单中删除。

## 查看应用的所有运行

你自己的应用页面有四个标签页：**运行**、**运行记录**、**逐行运行**和 **API 与分享**。**运行记录**会显示今天运行了多少次，并列出每一次运行，最新的在前：它收到的回答、来源、多久以前、花费和状态。**显示更早的运行**每次多加载 50 条。

现成的应用没有“运行记录”标签页：请在应用页面的**最近的运行**下查找它们的运行，或在侧边栏中以会话的形式查找。

## 制作你自己的应用

有四种方式可以开始：

- **从零开始**：在“应用”页面选择 **新建应用** → **从零开始**，或点击你自己的应用下方的 **制作应用** 图块，也可以前往 [/apps/new](/apps/new)。
- **通过描述来创建**：在“应用”页面（或“新建应用”页面）的 **描述一个应用，让智能体来做** 下写下它应该做什么，然后按 **创建**。会话会以 **应用搭建师**（[智能体](/guide/agents)）的身份启动，由它制作应用、试用并交给你。
- **从现成的应用开始**：打开它，然后按 **改成我自己的**（在手机上是 **编辑**）。
- **从一次进展顺利的会话开始**：在会话的菜单（⋯）中选择 **更多** → **另存为应用**。辅助模型会根据你的请求和智能体的回复，把会话的第一个请求变成表单、任务和回答字段，此时页面会显示“Drafting an app from the session…”。每次使用时会变化的部分会变成问题。草稿会保留会话所用的程序、模型、思考强度、模式和智能体。如果智能体调用过某个步骤可以自行调用的工具（读取网页、搜索网络），草稿中也会有步骤：这些调用会成为工具步骤，表单的回答会填入相应位置，其余部分则是模型步骤或智能体步骤。检查不通过的步骤会被舍弃，只保留单个智能体的任务；保存之前，请检查这些步骤并试一试。如果辅助模型无法生成草稿，你会得到原样保留的请求，放在一个 **请求** 问题中，并附上说明原因的备注；辅助模型可在[设置 → 智能体 → 模型](/settings?s=models&find=Helper%20model)中设置。

你也可以在任何会话中请智能体为你制作应用（见[请智能体来做](#ask-an-agent)）。负责搭建应用的智能体会让应用使用某个档位来思考，选能把事情做好的最低档位：**快速** 适合简短明确的工作（摘要、排版、查询），**标准** 适合大多数情况，**最佳** 适合研究和复杂推理，**最大值** 很少用；你可以在 **由谁来做** 中更改（见[由谁来做](#who-does-it)）。

搭建器打开后标题是 **新建应用**：上方是它的图标、名称和说明（点击名称或说明即可修改），下面是以标签页呈现的各个部分，首先是 **它做什么**，然后是 **表单**、**回答**、**设计**、**示例** 和 **设置**（由谁来做、它的工具、它的限制、它保存什么、它是否是一个模块，以及保存之后的文件夹和版本，每一项在你展开之前都折叠成一行，说明它目前的设置）。每个标签页宽度相同；在电脑上，滚动时标签页会固定在顶部，在手机上则分成两行显示。在宽屏上，**表单** 和 **回答** 旁边有 **预览**，会随着你输入而变化：显示应用页面向用户提问时的表单，以及一次运行所呈现的模拟回答。填好之后，用 **试运行** 试一下，然后按 **创建**。应用的页面会打开，可以直接运行。

### 名称、说明和图标

- 点击图标可选择颜色（11 种）和图案（32 个图标）。
- **名称**（必填，最多 60 个字符），例如“行程规划”。
- 说明：用一句话说明它做什么（最多 300 个字符）。

应用的地址在创建时由它的名称生成（“Trip planner”会变成 `trip-planner`）。之后重命名不会改变地址，因此链接、密钥以及其他智能体调用的工具都会继续有效。

### 表单

每次运行前由人来回答的问题。**添加问题** 会添加一行，包含：

- 问题本身，也就是用户看到的文字（“去哪里？”）。
- 问题的类型：**短文本**、**长文本**、**数字**、**日期**、**选项**、**是 / 否** 或 **文件**。
- **必填**：没有它，运行就无法开始。
- 对于 **选项**：各个选项，每行一个（留空时会提供“是”和“否”），以及 **可以选多个**，让用户可以勾选多个选项（此时答案中每行是一个选项）。
- **帮助文字、示例、默认值…** 会展开另外三个框：**问题下方的帮助说明**、**示例答案**（以灰色显示在空框中）和 **初始填入的值**。

问题的 **⋯** 菜单中有 **上移**、**下移** 和 **移除**。每个问题下方可以看到它的占位符，例如 `{{destination}}`：任务就是用它来引用该问题的答案，程序也用它作为该答案的名称。新问题的占位符会跟随它的措辞，直到任务用到它为止。一个应用最多可以有 30 个问题。

### 任务

要求智能体去做的事，其中会填入各个答案（最多 30,000 个字符；必填）。像你亲自对智能体说话那样来写，不仅要说明做什么，也要说明怎么做。

- **它做什么** 把应用的工作显示为 **单个任务**（就是这个框）、步骤的 **列表** 或步骤的 **图**；见[带步骤的应用](#apps-with-steps)。
- **插入** 标签会把某个问题的占位符放到光标所在位置。任务中尚未用到的问题会高亮显示。**今天**、**现在** 和 **星期** 会分别填入你所在地的日期、日期和时间，以及星期几。
- `{{question}}` 会被替换为它的答案。
- 位于 `{{#question}}` 和 `{{/question}}` 之间的文字，只有在该问题已回答（且回答不是“否”）时才保留。位于 `{{^question}}` 和 `{{/question}}` 之间的文字，只有在该问题留空时才保留。
- **预览** 位于一排 **插入** 标签的末尾，会显示填入了各问题默认值（或用括号括起的问题名称）的任务。**编辑** 可返回。

当占位符没有对应任何问题（它会保持原样），或者某个必填问题在任务中从未用到时，框下方会出现警告。

### 回答

智能体完成时要填写的字段。它们以卡片或表格的形式显示，程序则以 JSON 的形式取回。如果没有回答字段，智能体的回复就是回答。

**添加回答字段** 会添加一行，包含：

- 标题（“推荐”）。
- 字段的类型：**文本**、**长文本**（带格式的文本）、**数字**、**是 / 否**、**日期**、**链接**、**列表**、**表格** 或 **图片、视频或文件**。
- **必填**：智能体必须填写。
- **这里填什么，供智能体参考（可选）**：给智能体的提示。
- 对于 **表格**：它的 **列**，每列有名称和类型（**文本**、**数字**、**是 / 否**、**日期**、**链接** 或 **图片**）。**添加一列** 可以增加一列；表格至少保留一列。

回答字段的 **⋯** 菜单中有 **上移**、**下移** 和 **移除**。

**图片、视频或文件** 字段（以及 **图片** 列）接收智能体找到或制作的内容：网上的地址，或这台电脑上的文件（你“图片”文件夹中的照片、它绘制的图表、一段录音），每项都带有说明文字。Hydor 会保留这台电脑上文件的副本，以及网上图片的副本（最大 15 MB），这样无论回答显示在哪里都能看到；网上的视频则仍是链接。公开页面的运行只能指向网络上的内容。

Hydor 会检查智能体交上来的内容：数字必须是数字，日期必须是真实的日期，链接必须是完整的网址。当有内容不符时，智能体会被告知需要修正什么。一个应用最多可以有 30 个回答字段，一个表格最多可以有 16 列。新的回答字段在你保存时会根据它的标题生成供程序使用的名称；此后这个名称保持不变，因此读取它的程序会继续有效。

### 示例

示例是用来试用应用的回答，也是对一次运行结果的检查，这样你在尝试修改时就能发现应用是否变差了。**添加示例** 会添加一个示例：可以给它起个名字，填入它的回答，并为一次良好运行应给出的每一项内容 **添加检查**。检查是针对运行中各个值的规则，和步骤的规则一样：`{{answer.unread}} > 0`、`{{find.count}} = 3`、`{{reply}} contains Lisbon`。**{ }** 按钮会插入一个值：表单的回答、各步骤给出的内容、**它的答案**（`{{answer.field}}`）和 **它的回复**。

**全部试一试** 会把每个示例都作为试运行来运行，使用的是屏幕上当前的应用，无论是否已保存；某个示例旁边的烧瓶按钮则只试这一个。每个示例会显示它上次试运行的结果：**通过**、有几项检查未通过，或 **未完成**，以及耗时和花费；展开的示例会说明每项未通过的检查看到了什么（“answer.unread is 2”）。

### 由谁来做

这一部分写着：“Runs go ahead without anyone watching, so pick a mode that does not stop to ask (Auto, or one that allows edits).”

- 程序、**模型**、**思考强度** 和 **模式** 选择器，与现成应用上的相同。模式起初是 **自动**。**模型** 菜单先列出各档位（**快速**、**标准**、**最佳** 和 **最大值**，每个都标明它当前对应该程序的模型），然后是按名称列出的模型：按档位思考的应用会在模型更新时跟随[设置 → 模型 → 档位](/settings?s=models&find=Tiers)，并且无论由哪个程序运行都能工作。选能把事情做好的最低档位：**快速** 适合简短明确的工作（摘要、排版、查询），**标准** 适合大多数情况，**最佳** 适合研究和复杂推理，**最大值** 很少用。按名称选择的模型优先于档位，更换程序会保留档位，但会清除按名称选择的模型。
- **智能体**：**无**，或者每次运行所扮演的智能体（研究员、撰稿人…或你自己的智能体），连同它的指令、档位和预算。见[智能体](/guide/agents)。
- **文件夹**：默认是 **每次运行使用新文件夹**。**选择一项** 会让每次运行都在你选定的文件夹中工作（运行开始时它必须存在）；**每次都用新的** 可改回来。选定文件夹后，附加的文件会保存在单独的上传文件夹中，而不会混入你的文件夹。

### 工具

运行时可以使用 Hydor 自带的哪些工具：网络搜索、浏览器、页面、记忆等。起初 **全部** 是开启的。关闭它可以看到列表，其中列出每个工具的名称和作用，然后勾选允许运行使用的工具。智能体自己的文件和命令工具遵循它的模式，不受这个列表控制。

### 它需要的密钥

**它需要的密钥**（在 **设置** 中）列出了它的运行会用到的密钥，以它们在你的密钥库中的名称表示：每个密钥都有说明它是什么、**可以发送到哪里（主机）**、**在哪里获取**、一行关于如何获取的说明，以及 **没有它也能运行** 和 **这台电脑上的命令会使用它** 两个开关。**添加它需要的密钥** 可以添加一个。运行时会被告知每个密钥的名称和使用方法；密钥的值由安装这个应用的人提供（见[提供它需要的密钥](#give-it-the-keys-it-needs)），它们绝不会成为应用或应用文件的一部分。

### 限制

- **每天运行次数（来自任何地方）**：这个应用一天最多可以运行的次数，统计来自表单、API、其他智能体、CSV 的各行、公开页面的运行，以及它界面上的对话，从午夜开始计算。超过之后，运行会被拒绝，并提示“This app has run … times today, its limit”。留空：不限制。
- **单次运行最多可花费（US$）**：每次运行的花费上限。运行达到上限时会停止。留空：没有上限。见[用量、限制和费用](/guide/usage)。

### 保存前先测试

**试运行**（在手机上是烧瓶按钮）会打开一个对话框，其中是屏幕上当前的表单，无论是否已保存。填好后按 **运行测试**：运行过程会在对话框中进行。**打开会话** 可查看它的对话，**再测一次** 则回到表单。已保存应用的试运行会在它的 **运行记录** 标签页中显示为“Test run”。**保存为示例** 会把一次已完成的试运行的回答保存为新的示例，以便在 **示例** 下为它添加检查。

## 更改、复制或删除应用

在你的应用页面上：

- **编辑** 会打开搭建器，标题为 **编辑** 加上应用的名称。完成后按 **保存**；在此之前，旁边会显示 **尚未保存**。更改会应用于之后的运行；已经在运行的任务仍使用它们启动时的版本。
- **更多**（⋯）→ **创建副本** 会生成一个名称末尾带有“ copy”的副本，并拥有自己的地址。它的界面会作为独立的网页一并复制；它的公开页面一开始是关闭的，它的密钥和它保存的记录不会被复制。
- **更多**（⋯）→ **删除** 会询问“Delete …?”：它的运行记录、密钥和公开页面会一并删除，仍在运行的任务会被停止。它启动过的会话会保留。从文件安装的应用这里显示的是 **卸载**：它会以同样的方式被彻底删除，若想再次使用，需要重新安装它的文件。

现成应用的 **更多**（⋯）中有 **卸载**，卸载后它会保留在 **可安装的现成应用** 下（参见[安装或卸载现成应用](#install-or-uninstall-a-ready-made-app)）。

### 版本

每次更改了应用行为的保存都会成为一个版本：**版本** 位于应用 **编辑** 页面的靠近末尾处，按从新到旧列出所有版本，每个版本都附有更改了什么（或智能体说它做了什么）、由谁保存（**你**、**一个智能体**、**它的文件夹** 或 **已安装**）以及保存时间；对于用保存时的示例试运行过的版本，还会显示通过了多少个、一次运行耗时多久、花费多少，这样你就能看出某次更改是否让它变得更好。**恢复此版本** 会把较早的版本放到屏幕上，再按 **保存** 就会让它重新成为最新版本。在图中移动它的步骤，以及它的界面（界面有各自独立的版本），不会产生新版本。每次运行都会保留它所运行的那个版本。

### 以文件方式处理

**它的文件夹** 位于已保存应用的 **编辑** 页面靠近末尾处，可以把应用放进一个文件夹中的一组文件里（**建立它的文件夹**；默认位于你主目录下的 Hydor/Apps），这样你就可以用任何编辑器，或用在该文件夹上打开的编程智能体来修改它。app.json 是应用本身（它询问什么、做什么、返回什么），instructions/ 以 Markdown 存放每个步骤的说明，steps/ 存放每个代码步骤所运行的函数，screens/ 存放它的界面，graph.json 记录它的步骤所在的位置；.naget/ 中有 app.json 的结构定义和代码步骤的类型，这样你的编辑器就能补全并检查它们。你在那里保存的每次更改都会作为一个来自 **它的文件夹** 的版本出现在这里，并且在 **编辑** 中打开的应用会随之改变（或提示 **你在这里修改时，它在它的文件夹中被改变了。**）；那里的错误会在这里指出，并且不会改变任何内容。在这里保存会重新写入该文件夹，而 **不再同步** 会让文件保持原样。它的数据保存在这里，不在文件夹中。在桌面应用中，文件夹路径旁边有一个按钮，可在系统的文件管理器中显示它（**在访达中显示**、**在文件资源管理器中显示** 或 **在文件夹中显示**）。

在运行 Hydor 的电脑上，可以用命令行在它的文件夹中完成同样的事：`node dist/server/cli.js app new "Reading list"` 会创建一个应用及其文件夹，`app folder <app>` 为已有应用建立文件夹，`app dev <app>` 会在你每次保存更改时试运行它的示例，`app try <app>` 会试运行一次（如果某项检查未通过则报错失败），`app export` 和 `app import` 会把它作为一个文件带到另一台电脑上，并在安装之前说明它在那里会做什么。`app help` 会列出这些命令；它们使用自己专用的密钥，**设置 → 机器** 中将其列为“This computer’s command line”。

## 在你自己的程序中调用应用

脚本、快捷方式和其他程序可以用密钥运行你的应用并取回它的回答。打开你的应用 → **API 与分享** → **API**。

1. 按 **新建密钥**，说明它将被什么使用（用来区分不同的密钥），然后按 **创建密钥**。
2. 立即复制密钥：“Your new key. Copy it now: it is not shown again.”

一个密钥只能打开这一个应用，不能访问 Hydor 中的其他任何内容。列表会显示每个密钥的名称、它的前几个和最后几个字符，以及最后一次使用的时间。**撤销** 会终止一个密钥：使用它的程序会立即停止工作。

该标签页会显示一个带有你的应用地址和示例回答的调用示例。对于名为 Trip planner 的应用，它大致如下：

```bash
curl -X POST https://your-address/api/apps/trip-planner/run \
  -H "Authorization: Bearer napp_…" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"destination": "Lisbon", "start": "2026-11-20", "days": 4}, "wait": 300}'
```

- 把表单的答案按占位符名称放在 `inputs` 下发送。对于文件类问题，给出这台电脑上某个文件的路径，或者把文件放在 `files` 下发送，包含它的 `name`，以及以 base64 编码的内容作为 `data`。
- `wait` 是等待回答的秒数，最多 900。
- 回复中包含运行的 `status`、`result`（回答字段）、`reply`（智能体的最后一段话）和 `session`（指向它的链接），如有的话还有 `error` 和 `costUsd`。
- 对仍在运行的任务，可以通过 `GET …/run/<run>?wait=60` 查询。
- 如果处在会切断长请求的代理之后（Cloudflare 的上限是 100 秒），请缩短等待时间并再次查询。

一个密钥每分钟最多可调用 30 次，并且同时适用该应用的每日限制。关于 Hydor 自身 API 的更多内容，参见[应用的 API](/guide/api)。

## 让其他智能体把应用当作工具来运行

Claude Code、Cursor 或其他连接到 Hydor 自带 MCP 服务器（智能体访问工具的一种标准方式）的智能体，可以把你的应用当作工具来运行。在 **API 与分享** → **其他智能体** 下，开关 **提供给其他智能体** 会把它作为一个以其地址命名的工具提供出去，例如 `app_trip_planner`。新应用默认开启。智能体把表单作为工具的输入填写并等待回答；运行时间较长时会返回它的 id，智能体可以用第二个工具 `app_run_status` 来查看。这类智能体所需的地址和令牌在[设置 → 应用 → 连接其他智能体](/settings?s=connect)中。

## 开放一个任何人都能使用的公开页面

公开页面让任何拿到链接的人都能填写表单并查看回答，无需登录，也无法访问这里的其他任何内容。它位于 **API 与分享** → **公开页面** 下。

公开运行始终使用 Custom，所以请先在[设置 → 智能体 → 模型](/settings?s=models)中为 Custom 添加一个模型。然后：

1. 打开开关。状态会从 **已关闭** 变为 **任何拿到链接的人都能打开**，并且会为它选定 Custom 的第一个模型（可在下方更改）。
2. 复制链接（Hydor 的地址后接 `/a/` 和应用的地址），或者 **打开** 它。
3. 设置其余选项：
   - **模型（Custom 中的一个）**：公开运行所使用的模型。
   - **搜索和阅读网页**：起初是开启的。关闭后，智能体只凭已有的知识回答。
   - **每位访客每小时的运行次数**（起初为 5）、**每天的公开运行次数**（50）和 **每天最多可花费**（$2）。有一行会显示今天的公开运行次数和花费。

访客能看到的内容：应用的名称、图标、说明和表单，他们自己正在进行的运行，以及他们自己之前的运行（最近 10 次，通过他们浏览器中的 cookie 来区分）。他们看不到任务、设置、其他人的运行、会话或花费，出错时他们只会看到笼统的说明。他们附加的文件最大可达 3 MB，并且他们得到的回答会比你得到的更短。页面页脚会提醒他们回答可能有误。

公开运行能做什么：使用 Custom 和所选的模型，没有命令、没有文件，记忆和连接均关闭，在运行结束时即被删除的临时文件夹中进行。它们只能交回回答字段，并且在你允许时可以搜索网页和阅读公开网页。附加的文件会以文本形式交给智能体。每次运行的花费以当天预算的剩余部分为上限。

为了保持平稳：同一个应用最多同时进行 3 个公开运行（所有应用合计 8 个），访客要等上一次运行结束后才能开始下一次，并且同一个地址在所有页面上合计每小时最多 60 次运行。公开运行计入应用的每日限制，并且不接受后续追问。关闭开关即可关闭该页面；此后访客会看到“This page is not open”。

## 对 CSV 的每一行各运行一次应用

一次性对整个列表运行你的应用：对保存为 CSV 的电子表格的每一行各运行一次。打开你的应用 → **逐行运行**。（现成应用需要先 **改成我自己的**。）

1. **选择 CSV 文件**，或者把它拖到框中。第一行是列名。逗号、分号和制表符都可以，最多 500 行。
2. 在 **哪一列回答哪个问题** 下，每个问题对应一列（应用会按名称猜测），或者选 **每一行都一样…** 并填一个值。必填的问题需要一列或一个值。
3. 检查 **前几行，按表单将收到的形式呈现**。
4. 阅读费用估算（参见[一次运行的花费](#what-a-run-costs)），并选择 **同时运行** 的数量：1、2、3、4 或 6（起初为 2）。
5. 按 **运行** 和行数。

文件类问题会把它的单元格当作文本：这台电脑上的路径，或者一个网址。如果某一行的值不符合表单，它会立即失败，并在表格中给出原因，方便你知道该修正什么。如果这些行会让应用超过它的每日限制，Hydor 会在开始前拒绝。

各行运行时，会有一个表格逐步填满：行号、前两个问题、状态、最多四个回答字段（或回复），以及指向每次运行的链接。表格上方显示：已完成多少、未完成多少、目前的花费以及同时运行的数量，并带有进度条。

- **停止** 会结束仍在等待的行，并中断正在运行的行。
- **CSV** 会下载结果：每一行的回答、每个回答字段、它的状态、任何错误、它的花费以及指向它的会话的链接。电子表格会当作公式处理的单元格会以撇号开头。
- **×** 会关闭表格。

即使 Hydor 重启，各行也会继续运行。**之前的表格** 会列出你过去的逐行运行（最近 30 次）及其进度，以及它们是 **正在运行**、**已停止** 还是 **已完成**；点击其中一个即可再次打开它的表格。

## 让应用自行运行

应用可以自行运行：在每天的某个时间、每隔一段时间、仅一次、在其他服务调用 webhook 时，或者在监视器发现变化时（订阅源、网页、某个值、某个文件夹）。每次它都会用你设置的答案运行，就像从它的表单提交一样，并且这次运行会和它的其他运行一起列在 **运行记录** 下。

- **设置方法**：打开应用，然后依次进入 **运行记录** → **何时自行运行** → **添加定时运行**。给它起个名字，填写每次运行得到的答案，并选择运行时间，与任何[定时任务](/guide/tasks#when-it-runs)相同。**试运行** 会试跑一次而不保存。
- **来自外部的答案**：webhook 的答案可以取用调用的一部分（`{{body.title}}`、`{{headers.name}}`、`{{query.name}}`），监视器的答案可以取用 `{{change}}`，即它看到的变化。运行会把它们当作数据，绝不会当作指令。
- 每次运行都会通知你它交回的内容，或者它为何没有完成，并且通知会打开这次运行。它在 **何时自行运行** 下的那一行可以暂停它、立即运行它、显示它的历史或移除它；该任务也在[设置 → 定时任务](/settings?s=tasks)中。
- **在自己页面上打开的应用**（[Explore](#explore)、每周进展报告、实验笔记本）把它放在更近的地方：在它的 **设置**（页面顶部的滑块）中，**自动更新** 会用保存在那里的答案运行它，可选 **每天**、**每个工作日** 或 **每周一次**（在你选定的某一天），时间也由你选定。现成的应用可能有自己的起始日：每周进展报告在周五 16:00，实验笔记本在每天晚上 21:00。

## 一次运行的花费

每次运行的花费会在它结束后显示在它的页面上，也显示在 **运行记录** 列表中。它是智能体报告的数字，或者是按 API 费率为其用量计算的价格（对于 Custom，则根据它读取和写入的内容估算）；在这台电脑上运行的模型花费为 $0。

运行 CSV 之前，Hydor 会估算整批的花费：“About $… for … rows”，依据是该应用最近已完成的运行（最多 30 次）的中位花费。如果设置了每次运行的上限，还会加上这些行最多可能花费的金额。如果该应用从未完成过运行，它会说“Run the app once to see what a run costs.”

为了控制花费，请在应用的 **限制** 下设置 **单次运行最多可花费（US$）** 和 **每天运行次数（来自任何地方）**，对于公开页面，还要设置它的每日预算。所有会话的花费请参见[用量、限制与费用](/guide/usage)。

## 带步骤的应用

应用也可以分**步骤**完成工作：由智能体做一部分，向模型快速提一个问题来分类，用工具获取一个网页，用规则决定走哪条路，同样的步骤对列表中的每一项各走一遍。每一步把找到的结果交给下一步，运行结束时给出各个答案字段。与让一个智能体包办一切相比，步骤让应用更省钱、更快、更可靠，还能做更多事：在多次运行之间保存数据，调用你的其他应用，让几个部分并行运行。

你可以在应用的**编辑**中搭建带步骤的应用，也可以让智能体来做。在**编辑**中，**它做什么**可以把应用的工作显示为**单个任务**、步骤的**列表**或步骤的**图**（在电脑上，默认打开图，直到你选择列表）。对于只有一个任务的应用，点**列表**或**图**会把这个任务变成第一步，即由一个智能体来完成它；点**单个任务**则会把单独的智能体步骤变回去。**添加步骤**用来选择步骤的种类；点击一个步骤会展开它的设置，它的 **⋯** 菜单可以移动、复制或删除它。**判断**、**重复**或**同时进行**里面的步骤显示在它下方，每个列表都有自己的**添加步骤**。文本框里的 **{ }** 按钮（**插入一个值**）用来插入一个值：表单中的一个答案、前面某一步给出的值（`{{find.records}}`），或一个内置的值：**今天**（`{{today}}`）、**当前**（`{{now}}`，日期和时间）、**星期几**（`{{weekday}}`）和**时区**（`{{timezone}}`），这些都以你所在的地方为准；还有**是什么启动了这次运行**（`{{run.source}}`：web 表示它的表单，api、task、screen，batch 表示一行数据……）和**这次运行**（`{{run.id}}`）。**它的答案从哪里来**说明每个答案字段由哪个值填充（留空时：取最后一个给出同名值的步骤）。需要修正的地方会随着你的操作显示在对应步骤下方，**试运行**会试跑屏幕上当前的内容。**图**把它们显示为节点和连线：灰色连线表示顺序（判断的各条路径和并行的各个分支、框内重复的步骤、步骤失败时才运行的内容用红色表示），彩色连线表示哪个步骤使用了哪些值。

你也可以在图里搭建（在电脑上；手机上保留列表）。图展示整个运行过程：顶部是**表单**，当步骤用到内置的值时，旁边会有**内置**，步骤在它们下方，末尾是**答案**；虚线连线从表单和内置的值连到使用它们的步骤，也从给出答案的步骤连到答案。点击**表单**或**答案**会打开它的标签页。点击某个步骤的节点，会在图旁边打开它的设置，其中的**更多**（⋯）可以移动、复制或删除它；连线上的 **+** 会在那里放入一个新步骤，**添加步骤**则开始一条空的路径。把节点右侧的圆点拖到另一个步骤上，就能把它的一个值放进那个步骤（它的指令、工具的输入、规则……）；如果在空白处松开，则会生成一个使用该值的新步骤。拖动节点可以摆放它们（判断或重复里面的步骤会一起移动），双击某个值的连线可以在该处弯折（拖动弯折点，或双击它来去掉），**整理：重新排布全部**会自动排布所有节点；按住 Shift 点击多个节点，可以**把它们编成一组并加备注**。拖动背景可以平移，按住 Ctrl 滚动滚轮可以缩放，**全屏**会让它占满整个窗口。

图的按钮中有一个**试一试**，它把屏幕上当前的应用当作一次试运行，就在图里进行：每个步骤在运行和结束时都会亮起，通向已运行步骤的连线也随之亮起；把鼠标指向某个值的连线，可以看到它传递了什么，而某个步骤的设置开头会显示它**上次试运行中**的情况。在某个步骤的设置里，**试运行时在它之前暂停**会让试运行停在那里，直到你按**继续**（或**单步执行**，它会在下一步之前再次暂停）；雪花（**冻结**）会让试运行直接使用该步骤上一次给出的值，这样一个耗费较大的步骤之后的各步骤就可以反复试运行，而不产生任何费用。

选中步骤后（按住 Shift 点击几个相连的步骤），图的按钮中会出现**合并成一个模块**，它把这些步骤变成一个独立的应用，即模块，并由一个**调用应用**步骤来代替它们运行：这些步骤从外部用到的内容（表单的答案、前面各步骤的值）成为模块的表单，由调用来提供；后面的步骤用到的它们的值则成为模块的答案。其他应用也可以调用这个模块，对它的修改会影响所有调用它的应用。保存数据的步骤会留在原应用里，因为模块有自己的数据，而且列表和表格会以文本形式传给模块。

或者问智能体：“做一个应用：读取我给它的每个链接，用快速模型总结，并存入阅读清单。”智能体会写好步骤、检查并试运行，之后你可以在**编辑**中修改。智能体在任何会话中都有专门的工具来做这件事：读取你的应用，保存应用（先检查，并用文字说明其中的错误；可以保存整个应用、其中几个部分或单个步骤），用应用的示例试运行并等待结果，为它做一个界面，读取它保存的记录或添加记录（修改或删除记录由你在它的界面上操作，或先征得你的同意）；在交付应用之前，它们会告诉你一次运行要花多少钱。

在对话中，智能体保存的每个应用都会显示为一张卡片，在宽屏上，应用会在搭建过程中在对话旁边打开（卡片上的**在旁边打开**可以再次打开它，**打开它的页面**则打开它自己的页面）。你在那里所做并保存的修改，会随你的下一条消息传给智能体，让它在你的版本上继续搭建：在你修改之后保存的智能体会先读取你的版本。当智能体保存时，如果你屏幕上有自己尚未保存的修改，会出现一条提示，让你选择**载入它**或**保留我的**。在那里的步骤的 **⋯** 菜单中，**就此问智能体**会在对话的消息框里开始一条关于该步骤的消息。

步骤的种类：

- **问智能体**：一个会话用自己的工具处理自己负责的部分，并交回找到的结果。每个这样的步骤都有自己的会话，你可以从这次运行的页面打开它。它的**它用什么思考**菜单（模型和思考强度）和应用本身的一样，先提供档位：在这里选的档位或模型只替换这个步骤所用的，而运行另一个程序的步骤会沿用应用的档位，但不沿用按名称指定的模型。
- **问模型**：向模型要一个快速的回答，不使用工具：分类、提取、总结。它花费很少，若使用这台电脑上的模型则完全免费。
- **使用工具**：使用 Hydor 自带的某个工具，输入固定：搜索网络、读取网页、为列表中的每一项找一张图片（和一段视频）、用保存的密钥调用一个地址、读取文档、生成图片、给你发送通知、读取 Hydor 对你的了解、按你的关注程度排序，或保存它生成的内容（幻灯片、文档、电子表格、LaTeX 文档或网页，保存到它指定的项目的文件中）。对于论文：查找并阅读一篇（从开放获取的版本，附带它的记录和 BibTeX）、保存阅读清单，并与 Zotero 同步。这样找到的图片会放进答案的图片列，视频（YouTube 或 Vimeo 链接）则在视图的视频元素中播放。
- **判断**：二选一，依据一条规则（“价格低于 100”），或依据一个用文字提出、由辅助模型回答的问题。
- **重复**：对列表中的每一项各运行一次它的步骤（如果你愿意，可以每次几项同时进行），或者一直重复到某个条件成立为止。
- **同时进行**：并行运行的各个分支；等它们全部结束后，流程才继续。
- **调用应用**：把你的另一个应用当作一个步骤。在这些种类下方，**添加步骤**还提供模块：专门做成其他应用的步骤的应用，包括你自己的（在应用的答案字段下标有**一个模块**的那些，以及合并成一个模块所生成的）和现成的（**总结网页**、**翻译**、**从网上找答案**、**分类**和**提取事实**，加入时每个都会变成你自己的）。模块以调用的形式加入，带有需要填写的表单；表单中与应用自己的表单同名的问题会自动填好；对模块的修改会影响所有调用它的应用。
- **保存数据**：添加、查找、修改或删除应用保存的记录（见下文）。
- **问一个人**：运行会等待你的回答，可以是“是”或“否”，也可以是一个简短的表单：一条通知会打开这次运行，其中一张卡片会向你提问，收件箱里也会列出它。它默认等待一周，除非你另设限制，到期后就会失败。它表单中的**选项**问题可以提供运行中找到的内容：把前面某个步骤的值单独写成一个选项，例如 `{{find.items}}`，当该步骤提问时，卡片会把那个列表的每一项（或文本的每一行）作为选项列出，这样运行就可以问你要深入研究它找到的哪几项。使用**可以选多个**时，你可以勾选任意多项，而 `{{step.field}}` 就是被勾选的那些，每行一个。问题、帮助文字和选项中的其他文字也会用值填充，而没有任何内容可供选择的选项会变成一个普通的文本框。
- **运行代码**：你自己的一段程序，用 JavaScript、TypeScript 或 Python 编写，接收你给它的值，并给出该步骤的值（**它给出的值**为这些值命名，供后面的步骤使用）。它在沙盒中运行：没有网络，也不能访问这台电脑上的文件，只能使用应用安装的软件包。它只能通过 `ctx` 与外界联系，每次调用都是这次运行的一个步骤：`ctx.model` 询问模型，`ctx.agent` 调用智能体，`ctx.tool` 使用应用的某个工具，`ctx.ask` 等待你的回答，`ctx.data` 保存记录，`ctx.app` 运行另一个应用。这样整个流程可以是一段程序，自带 if 和循环；它的调用会像步骤一样显示在这次运行的页面上，而当运行在重启后再次开始时，程序会重新运行，它先前做过的调用会直接给出当时的结果，不会再次执行。含有代码步骤的应用文件会在它的安装卡片上注明。
- **算出一个值**：由一个值直接算出另一个值，立即完成且不产生费用：列表的第一项或最后一项、数量、总和、平均值、最小值或最大值（针对每一项的某个字段）、每一项的某个字段、把各项连接成文本、去重、按某个字段排序、转成数字，或几天之后的日期。它给出 `{{id.value}}`，在图中显示为一个小药丸形状。

一个步骤可以只在某条规则成立时才运行，并且可以设定它失败时的处理方式：改为运行其他步骤、不理它继续往下走，或者（对于工具、模型、代码、数据或应用步骤）**由智能体代为完成它的工作**：一个智能体拿到该步骤收到的内容和失败的原因，交回后面步骤要用的值，然后运行继续。此时这次运行的页面会在该步骤旁边显示**由智能体代为完成**，并附上失败的原因。

运行进行时，它的页面会随进度列出各个步骤。运行结束后，**步骤**会显示每个步骤的情况、耗时和花费；会话按钮会打开智能体步骤的对话。带步骤的运行不接受后续追问：请修改答案后再运行一次。

带步骤的运行结束后，它的每个步骤都有**从这里再次运行**（↺）：用相同的答案开始一次新的运行，其中该步骤之前的各步骤直接给出这次所给出的值（标记为**沿用上次运行**，不产生费用），其余步骤按应用现在的样子运行。**编辑**中的**试运行**也有这个功能，针对屏幕上当前的内容：修改后面的某个步骤，再试一次，而不必重新运行前面的步骤。

### 固化它

在**编辑**的各个步骤上方，应用最近的几次运行会告诉你两件事。如果某个步骤失败并由智能体代为完成，它会说明这种情况发生在多少次运行中，以及上次失败的原因；**请智能体修复它**会询问旁边的智能体（当应用在某个对话旁边打开时），或者启动一个与**应用搭建师**的会话。如果某个智能体步骤在最近的每次运行中做的事都相同（比如读取给它的网页，然后作答），就会提供**固化它**：用固定的步骤以更低的成本完成同样的事，智能体的每次调用对应一个工具步骤，并带上调用时用的值，然后是一个模型步骤，带有它的指令和这些工具给出的内容。**用它的示例试一试**（如果它没有示例，则是**全部试一试**，使用那些运行的答案）会先运行它们，并显示用智能体和用这些步骤各自一次运行所需的时间和费用；**使用这些步骤**会在屏幕上用它们取代原来的步骤，**保存**则把它们保存下来。它生成的工具步骤在失败时会让智能体代为完成，因此以前能正常运行的运行仍然可以正常运行。

搭建应用的智能体看到的是同样的内容，并附有可供试运行的步骤。

### 应用保存的内容

应用可以在多次运行之间保存数据：记录的列表，例如阅读清单里的链接，或小型 CRM 里的客户。它的步骤可以添加、查找和修改这些记录，它的智能体也可以，用的是它们自己的工具。列表可以说明每条记录包含什么（标题、分数、日期……），之后应用会检查录入的内容。在**编辑**中，**它保存的内容**列出了它们：点**添加列表**，然后给它起一个名字，如果你愿意，再填上它的记录包含的字段（没有字段时，任何记录都可以放入）。

现成的应用也会保存记录：[阅读清单](/guide/researchers#reading-list)保存你的论文，它的页面会显示并修改这些论文，其他应用也能读取（文献矩阵会取“我的阅读清单”）。

步骤和智能体还可以针对一个问题搜索这些记录，方式与搜索你的知识库一样：按其中的字词搜索，在开启[按含义搜索](/settings?s=memory&find=Search%20by%20meaning)时也按含义搜索，最相关的排在最前。步骤也可以用 knowledge_search 和 recall 工具搜索你的知识库和记忆备注。

应用保存的内容会一直跟着它，直到你删除这个应用。来自它公开页面的运行永远不会访问这些内容。现成的应用也会保存记录：标注工作台保存带有你的标签的文本集，实验笔记本保存它的条目；这些内容在你卸载应用后依然保留，重新安装应用时会随之恢复。

### 会记忆的应用

应用可以在多次运行之间记忆：它的智能体会把以后的运行应该知道的内容（你展示过的偏好、一个好用的来源、一个要避免的错误）保存到应用自己的记忆中，每次运行都从这些记忆开始。[设置 → 记忆](/settings?s=memory)会把它作为一个项目列出，以应用的名称命名。在它的**编辑**中，**它保存的内容**下方，打开**跨运行记忆**即可启用。

### 应用在这台电脑上需要什么

应用可能需要这台电脑上的一些东西：它的智能体用到的 Node 或 Python 软件包，以及 ffmpeg 之类的命令。软件包会安装在应用自己的文件夹中，绝不会装到整台电脑上，一旦你安装或修改应用就会开始安装，它的第一次运行会等待安装完成。在应用的页面上，有一行文字会在软件包安装期间或安装失败时显示提示，并带有**显示输出**和**重新安装**。如果它用到的某个命令这台电脑上没有，也会在那里指出：请你自己安装那个命令。

## 设计它的外观

应用的视图决定了它的答案长什么样：包括页面（标签页，以及点击后打开的页面）、为它的答案专门做的元素（比如一张某天的卡片，或一个列出优缺点的产品），还有事件，用来规定点击会发生什么。没有视图时，它的答案会显示为一张普通卡片和若干表格。

在应用的**编辑**中，**设计**标签页会用最近一次运行的答案展示它的视图；**模拟答案**则会用一份形状相同的模拟答案来展示，需要修正的地方会列在它下面。在预览里，点击可以跳转页面、勾选事项；要传到应用里的操作（问问它的智能体、再运行一次）则要在某次运行的页面上进行。

- **请智能体设计它**（应用保存之后）：会开启一个以**应用搭建师**身份工作的会话，并附上一条与该应用有关的消息；如果应用与某个对话并排打开，这条消息则会发给那个智能体。它会编写视图，用一次运行试一试，并修正不合适的地方。
- **从它的答案开始**：生成一个网页，为答案的每个字段各放一个区块，你可以在此基础上修改。
- **请智能体修改它**：同上，适用于已有视图的应用。
- **以代码修改**：把视图显示为 JSON，包含它的页面、元素（带有 `{{result.days}}` 这类值的 HTML，以及 CSS）和事件，指南的 API 主题对此有说明（[应用：视图](/guide/api#apps-views)）；预览会随着你的输入同步更新。
- **移除它的视图**：保存后，它的答案会重新显示为一张普通卡片。

视图的事件可以：跳转到某个页面（并带上被点击的条目）、勾选某项或设置筛选条件（若事件这样指定，会随运行一并保存）、复制、打开一个地址、请这次运行的智能体做修改（没有步骤的应用）、运行它的另一个流程、改动部分回答后再运行一次、启动另一个应用，以及添加、修改或删除它保存的记录。标记为应用自有页面的页面，会代替它的表单显示在那里，并带上它保存的内容和最近一次运行。这样的页面顶部有**更新**，用来立即运行应用，旁边是**设置**：包含为这些运行保存的表单回答，以及**自动更新**（每天、工作日或每周一次，时间由你选定），与[探索](#explore)中的一样。如果应用的页面是用来处理它所保存内容的地方（比如“阅读清单”），就两者都没有：页面会直接显示它的记录，按钮则运行它的表单。视图是应用的一部分：它随应用一起有版本，随应用的文件一起传递，它的元素是应用文件夹（ui/）里属于它自己的文件。

除了自己的元素，视图还有内置元素：文本、可勾选的列表、表格和条形图，以及以下这些媒体元素：

- **图片**：一张，或并排的几张，每张都有自己的说明文字。
- **视频**：一个文件，在视图中播放；或一个 YouTube 或 Vimeo 的链接，会显示封面，点击后在页面上方播放。
- **声音**：一段录音或一首歌，可供播放。
- **地图**：答案里的地点，根据它们的经纬度标出；当视图要求时，会按顺序编号并连线。
- **图表**：折线图、条形图（也可堆叠）、面积图、散点图、饼图、直方图、箱线图和热力图，以及 3D 的点、线和曲面，由 Plotly 绘制。

视图还可以有**小组件**：由各自的脚本绘制的元素（3D 场景、游戏、你选用的图表库绘制的图表），它们会从网络（jsDelivr）加载所需的库，每个库都指定确切的版本。视图中的所有内容都和页面一样在同一个沙盒中绘制：它无法访问这台电脑、你的登录信息或你的其他应用，只能执行它的事件所允许的操作。

在**设计**标签页下，**它自己的文件**存放随应用附带的图片、视频、声音和数据：**添加文件**可以添加它们（每个最大 100 MB，总共最大 150 MB），点击图片可放大查看，复制按钮会给出视图引用它的名称（`asset:tram.jpg`，用在图片、视频或声音区块，或模板的 `src` 中）。它们会随应用的文件一起传递。预览会用它最近一次运行来填充视图，或者用一份模拟答案来填充，其中的图片和视频就是它自己的文件。

## 给应用一个界面

应用可以有一个自己的界面：用一个页面代替它的表单，用来运行应用并展示它保存的内容。阅读清单可以用表格显示链接，供你搜索和整理；小型 CRM 可以显示客户，并带一个起草跟进邮件的按钮；记录追踪器可以显示已记录内容的计数。界面是实时工作的：你在表单中提交的内容会运行应用，答案准备好后就会显示出来，而随着它的步骤和智能体改动记录，表格也会随之变化。

- **给它一个界面**：打开你的应用，然后点击**更多**（⋯）→ **给它一个界面**。界面由它的各个部分组成：它的表单、它的答案、它保存的每个列表各一个表格（表格下方是与它的智能体的对话），以及它之前的运行。之后它的页面就会打开这个界面。
- **修改界面**：**更多**（⋯）→ **编辑界面**会在页面编辑器中打开它，你可以像修改任何页面一样修改它（[自己修改网页](/guide/library#change-a-page-yourself)）：移动各个部分并调整样式，或者请智能体来做。**添加**里有一个**应用**标签页，包含应用自己的各个部分：**它的表单**、**它的答案**、**它的运行**、**与它的智能体对话**，为它的每个其他流程提供的表单和按钮，以及为它保存的每个列表提供的表格和计数。
- **或者请智能体来做**：“给我的阅读清单做一个界面，把未读链接放在最上面，再加一个生成本周摘要的按钮。”智能体用同样的各个部分编写界面，还可以给应用增加更多流程，供界面上的按钮启动。

**与它的智能体交谈。** 界面中的对话（由它的各个部分组成的界面上的**问问它的智能体**）是与应用自己的智能体的聊天，使用它的模型和工具：写一条消息并按**发送**（或回车键），它会在那里回答。它可以查找和修改应用保存的内容，也可以替你运行应用的流程并等待结果，所以“添加《皮拉内西》，我已经读过了”或“这些里我还有哪些没读？”这样的话直接就能用。当你回来时，最近一次对话还在那里；**新对话**会开始另一个，**之前的对话**会打开你以前的某次对话。对话随应用一起保存，与它的运行分开。

界面是应用自己的页面：它不在任何项目的文件之中，删除应用时它也会一并消失，并随应用的文件一起传递。若要用之前的回答通过表单运行应用，请在某次运行的页面上使用**用这些回答再运行一次**。

## 把应用分享为文件

应用可以作为一个文件传递，用于保存，或安装到另一台 Hydor 上。

- **下载**：打开应用，然后点击**更多**（⋯）→ **下载为文件**，或者在应用页面上使用它卡片上的**更多**（⋯）。现成的应用也以同样方式下载。文件（`.hydor-app`）包含它所做的和所需要的一切、它自己的文件（图片、视频、数据），以及它的步骤所调用的应用。当它保存了数据时，**包含它保存的记录**会把这些也放进去。它的文件夹、密钥和公开页面留在本机：它需要的密钥只以名称随文件传递，会在安装的地方再询问。
- **安装**：在应用页面上点击**新建应用**，然后点击**从文件安装**，选择一个 `.hydor-app`、`.zip` 或 `.json` 文件（最大 160 MB）；或者把文件拖到应用页面上。在创建任何东西之前，会有一张卡片用通俗的话说明它是什么：它的名称和用途、**它会问你什么**（可选的问题会有标记）、**你会得到什么**、**它是怎么工作的**、**智能体可以使用它**（带一个开关，可以阻止智能体运行它），以及**它需要的密钥**（或**它需要的密钥**），可以现在提供，也可以在首次运行时提供。**它在这里用到什么**（默认折叠，当有东西需要留意时会自动展开）列出谁来做这些工作、它的步骤、它自己的文件、它的视图的脚本及其加载的库、它的界面、它可以使用的工具、它使用的模型、随它附带的应用、它安装的内容和使用的命令、它保存的内容、它是否有记忆，以及它的限制。每个模型会显示为：在这里已设置、在这里使用另一个名称、通过 OpenRouter（首次运行时添加到你的模型中，它的密钥会与应用的密钥一起询问），或在这里未设置：对于这些，请选择你的一个模型来代替，或者交给智能体的默认设置。然后点击**安装**。

有些内容在导入时会变化，卡片会说明具体是哪些：它在别处使用的文件夹会被舍弃（每次运行会得到自己的文件夹），允许每一步都无需询问的模式会改为以**自动**开始，而这台电脑上没有的智能体会被去掉。随它附带的应用如果与你已有的一个相同，就会直接使用你已有的；否则会安装在你的应用旁边。它的公开页面一开始是关闭的，也没有 API 密钥。

现成应用的文件会说明它是哪个应用：如果你曾卸载过那个应用，安装该文件会把它带回来（**已重新安装**）；如果你已有这个应用，该文件会作为你自己应用的副本安装，供你随意修改。

## 请智能体来做

Hydor 中的智能体可以通过它的 API 为你制作和运行应用，卡片上会请你确认。例如：

- “做一个叫‘每周报告’的应用，让我输入一个项目和一个日期范围，答案是一份摘要和一张变更内容的表格。”
- “把这个会话变成一个我可以再次运行的应用。”
- “把‘旅行规划’和我的‘每周报告’置顶到应用页面最上面，报告放在前面。”
- “我最近用过哪些应用？它们上次运行得怎么样？”
- “用和上次相同的回答再运行一次我的‘价格查询’。”
- “为我们两个人规划一次五月去里斯本的 4 天旅行。”（“旅行规划”在这里运行，并询问它需要的信息）
- “这周采尔马特的天气怎么样？还有，用鸡蛋、菠菜和土豆能做什么菜？”（“天气展望”和“用现有食材做菜”在这里运行，各自在它的视图中显示答案）
- “考考我罗马帝国的知识，十道难题。”
- “找出柏林亚历山大广场附近的狗公园和咖啡馆。”（“探索一个地方”应用在这里运行，除非它在你的名单上，否则会先询问）
- “运行我的‘旅行规划’，不用每次都问我。”（智能体会把它放进**无需询问直接运行**，就像它卡片上的**总是运行**一样）
- “运行‘旅行规划’应用，去里斯本，从 11 月 20 日起四天，完成后把结果给我看。”
- “对这 20 家公司，分别运行我的‘公司调研’应用，然后把表格给我。”
- “每周五 18:00 运行我的‘旅行规划’，去里斯本，三天。”
- “为我的‘求职信’应用开一个公开页面，每天最多花 1 美元。”
- “停止我的‘价格查询’应用的所有运行，并撤销它的 API 密钥。”
- “卸载‘每周新闻摘要’应用，并禁止智能体在会话中运行我的‘价格查询’应用。”
- “做一个带步骤的应用：读取我发送的每个链接，用快速模型总结，并保存到阅读清单里。”
- “让我的‘测验’应用用快速来思考。”
- “给我的‘竞品监测’应用加一个步骤，只在有变化时才通知我。”
- “在我的‘购物侦察’应用里，找到商品之后，让我用可勾选的选项选择要比较哪些，然后只比较这些。”
- “从我的下载文件夹安装 reading-list.hydor-app 里的应用。”
- “做一个应用，用 OpenWeather 总结某个城市的天气。它需要我的 OpenWeather API 密钥。”
- “在我的‘城市短途游’应用的视图里，加上停靠点的地图和每天花费的图表。”
- “把 ~/Pictures/Lisbon 里的照片添加到我的‘城市短途游’应用，并显示在它的第一页上。”
- “给我的‘每周报告’应用的视图加一个这些数字的 3D 图表，用 three.js 做成小组件。”
- “给我的阅读清单做一个界面，把未读链接放在最上面，再加一个生成本周摘要的按钮。”
- “为我的‘每周报告’应用设计一个视图：一个页面把摘要和数字放在最上面，另一个页面把每处变更显示为可以勾选的卡片。”
- “在我的‘价格查询’应用的视图里，给每家商店加一个按钮，只针对那家商店再运行一次。”
- “把我的‘链接摘要’应用完善一下，先用它的示例试一试。”
- “让我的‘链接摘要’应用里的‘查找标题’步骤在失败时把工作交给智能体。”
- “让探索每天早上 6:30 生成一期新的，内容里始终包含一级方程式。”
