# 外观、语言和更新

应用呈现给你的样子和行为方式，以及它如何保持更新：深色或浅色模式、内置主题和你自己的主题、语言、智能体工作时 Enter 的作用、开机启动、更新和版本说明。本主题还介绍你的密码、退出登录，以及应用把数据保存在哪里。

![设置 → 通用：主题](images/app.webp)

## 选择深色、浅色或跟随设备

打开[设置 → 应用 → 通用](/settings?s=general&find=Theme)。**主题**部分的顶部有一个切换开关：

- **深色**：始终使用深色主题。
- **浅色**：始终使用浅色主题。
- **系统**：跟随你的设备，设备设为深色时（比如在夜间）用深色主题，否则用浅色主题。

模式保存在这个浏览器中，所以你的手机和电脑可以不一样。搜索框（Ctrl+K，Mac 上是 ⌘K）中有**在浅色和深色之间切换**，可以立即把模式切换为浅色或深色。

## 选择主题

开关下方，各个主题以应用的小缩略图显示，用的是主题自己的配色，分为两行：**深色**和**浅色**。应用自带四个主题：

- **Hydor 深色**：会话后面是纯黑色，面板为冷调的蓝黑色，搭配长春花蓝强调色。初始的深色主题。
- **午夜**：会话后面是纯黑色，面板为温暖的近黑色，搭配金色强调色。
- **Hydor 浅色**：温暖的米白色，搭配深金色强调色。初始的浅色主题。
- **鼠尾草**：冷调的灰绿色纸张质感，搭配深青色强调色。

点击一个主题即可使用。它会成为所属模式的主题，并且模式会切换过去（除非模式是**系统**：那样的话，只要你的设备处于该模式，就会显示它）。每种模式各自记住自己的选择，所以你可以晚上用午夜，白天用鼠尾草。开启**系统**时，各行会标明哪一个是“当前显示”的。在搜索框中输入主题的名称也能找到它，选中即可切换过去。

每张缩略图都有一个菜单（⋯，在电脑上鼠标指向时显示）：

- **复制一份来编辑**：用它的副本打开主题编辑器。
- **复制以分享**：把主题复制为文本，用于在别处导入。
- **编辑**和**删除**：仅限你自己创建的主题。删除前会先询问，正在使用它的设备会回到 Hydor 主题。

显示哪个主题由每个浏览器分别选择。你创建的主题由应用保存，在你使用的每台设备上都可以选用。

## 制作你自己的主题

1. 点击缩略图下方的[**新建主题**](/settings?s=general&find=New%20theme)。编辑器会打开当前显示主题的副本，命名为“我的主题”（也可以对任意主题使用**复制一份来编辑**）。
2. 给它起个名字，并选择**深色**或**浅色**作为基础。基础决定代码的颜色和程序在终端中输出的颜色，并补上主题没有设置的任何颜色。
3. 修改任意颜色：点击色块来选色，或输入十六进制色值，例如 `#1e3a2f`。
4. 点击**保存主题**。应用会立即使用它。

编辑时，整个应用都会显示你的更改，这样你能在每种颜色实际使用的地方看到它。保存之前什么都不会保留：**取消**、✕（**不保存并关闭**）或 Esc 都会恢复你原来的主题。**复制**会把主题复制为文本，和**复制以分享**一样。在电脑上，编辑器是右侧的一个面板；在手机上，则是从屏幕底部弹出的面板。

你最多可以有 40 个自己的主题；达到上限时，**新建主题**和**导入**会变灰。

### 你可以设置的颜色

- **背景**：网页（位于所有内容之后）、侧边栏、卡片（消息框、设置卡片、面板）、菜单和对话框、输入框（输入框和浅色填充）、悬停（鼠标指向的行、标签）、选中（展开的行、次要按钮）。
- **文本**：文本、次要文字、弱化文字（提示、时间、标签）。
- **边框**：边框、醒目边框（输入框和描边按钮）。
- **强调色**：强调色（主按钮、链接、焦点、选中项）、强调色上的文字。
- **状态**：工作中；需要你处理、警告；完成、新增的行；失败、删除的行；信息。
- **智能体**：Claude、Codex。
- **代码与终端**：代码块、终端背景、终端文字。

如果某个文字颜色在它所在的背景上难以看清，会显示一条警告“难以阅读”，并附上对比度（例如 2.8:1）。4.5:1 就很好读，弱化文字则 3:1 即可。

## 分享或导入主题

要把主题给别人，或给你的另一个 Hydor：

1. 在主题的菜单（⋯）中选择**复制以分享**（或在编辑器中点**复制**）。主题会被复制为一小段文本。
2. 把这段文本发出去。

要添加别人给你的主题：

1. 点击主题缩略图下方的[**导入**](/settings?s=general&find=Import)。
2. 把文本粘贴到**导入主题**中，然后点击**添加主题**。

主题会加入你自己的主题中，并立即使用。如果这段文本不是主题，应用会提示“这不是主题”，并请你粘贴**复制以分享**给你的内容。

## 更改语言

[设置 → 应用 → 通用 → 语言](/settings?s=general&find=Language)可以把应用显示为：

- **English**
- **中文（简体）**（简体中文）
- **Ελληνικά**（希腊语）

选择一种语言后，页面会以该语言重新加载。这个选择保存在这个浏览器中；一开始，如果应用支持你浏览器的语言，就会跟随浏览器的语言，否则使用英语。

只有应用自身的文字会改变，日期和时间也会按该语言的写法显示。人和智能体写下的内容保持原样：对话、记忆笔记、你给各种东西起的名字和写的描述、文件、代码和终端。

智能体会用你选的语言给你写回复：它们会被要求这样做，除非你用另一种语言给它们写消息，或要求使用某种语言；代码、命令和文件名则保持原样。每个智能体在启动或继续时会收到这一要求。通知也会使用这种语言，手机上的通知也一样。应用每次打开时都会把它的语言告诉智能体，所以如果你的设备设置了不同的语言，智能体和通知会跟随最后打开的那台设备的语言。

## 决定智能体工作时 Enter 的作用

[**智能体工作时发送**](/settings?s=general&find=Sending%20while%20an%20agent%20works)决定当智能体正处于一轮之中时，你发送消息会发生什么：

- **加入本轮**（初始设置）：按 Enter 会把你的消息加入正在进行的这一轮，智能体会马上考虑它。按 Ctrl+Enter（Mac 上是 ⌘Enter）则会等这一轮结束再发。
- **等它结束**：按 Enter 会把你的消息放进队列，在这一轮结束时发出。按 Ctrl+Enter（Mac 上是 ⌘Enter）则会把它加入正在进行的这一轮。

这个选择保存在这个浏览器中。关于队列的更多内容，参见[会话](/guide/sessions)。

## 开启或关闭终端建议

[**终端建议**](/settings?s=general&find=Terminal%20suggestions)（初始为开启）会在应用的终端中，于光标后用灰色文字显示命令最可能的剩余部分；按 → 即可采用。关闭它只会隐藏灰色文字：按 Ctrl+Space 仍会列出建议。这个设置保存在这个浏览器中。参见[灰色建议](/guide/files-git#grey-suggestions)。

## 使用限额解除后继续会话

[**用量限制解除后继续**](/settings?s=general&find=Resume%20after%20usage%20limits)（初始为关闭）：当一轮因为套餐用量耗尽而停止时，会话会在限额重置一分钟后自动继续。这个设置由应用保存，所以即使没有打开任何浏览器也能生效。更多内容参见[用量、限额和费用](/guide/usage)。

## 删除不活跃的会话

不管智能体自己的程序怎么做，应用都会保留每一个会话（参见[每个会话都会保留](/guide/usage#every-session-is-kept)），直到它很长时间没人用为止。[**删除不活跃的会话**](/settings?s=general&find=Delete%20inactive%20sessions)（初始为开启）会删除不活跃达 **1 年**的会话，每天最多删除几百个。

- 在开关旁边的菜单中选择会话可以保持不活跃多久：**3 个月后**、**6 个月后**、**1 年后**、**2 年后**或 **5 年后**。
- 关闭开关，就会永久保留每个会话。
- 会话从它最后一次有任何动静时起算作不活跃。
- 有些会话会始终保留：置顶的会话，以及正在工作、在等你处理、有排队消息、已延后、等待在限额解除后继续、在 VS Code 或终端中运行，或有未关闭的拉取请求的会话。
- 被删除的会话会从列表中消失，对话也没有了，但它的统计数字会保留在[活动](/stats)中。

这个设置由应用保存，所以即使没有打开任何浏览器也能生效。

## 开机时启动应用

[**开机时启动**](/settings?s=general&find=Start%20when%20this%20computer%20starts)会在电脑重启后以及崩溃后让应用重新运行。它初始为开启：安装程序会把应用设置为一个服务；从 git 克隆手动启动的副本会在第一次运行时自己设置服务。这个开关能做什么取决于应用的运行方式，开关下方的那行文字会说明是哪一种：

- **作为你的用户服务**（通常的安装方式）：开关可以开启或关闭它。它在开机时就会启动，甚至在任何人登录之前；如果那行文字说它要等你登录后才启动，在电脑上运行一次 `sudo loginctl enable-linger $USER` 即可改变这一点。
- **作为系统服务**：更改它需要这台电脑的管理员权限。
- **在 Docker 中**：由它的重启策略让它重新运行（`restart: unless-stopped`），开关无法更改。
- **在 Mac 应用中**：登录 Mac 时它会在后台打开，图标在菜单栏中，窗口保持关闭。从“应用程序”文件夹第一次打开它时，这项就是开启的。
- **以其他方式启动**：打开开关会把它设置为你的用户服务。如果做不到（你的用户没有 systemd），那行文字会说明。

应用加载时（在浏览器中，或 Mac 应用启动时），会显示它的标志，水在 Ω 中升起；应用一准备好就会出现。

## 让应用保持最新

从 git 安装的副本（安装程序安装的，或 Docker 的）会在启动几分钟后检查是否有新版本，之后每天检查一次；Mac 应用会在打开一分钟后检查，之后每 4 小时检查一次。[设置 → 应用 → 通用](/settings?s=general&find=Check%20now)底部的**关于**会显示你正在运行的版本以及当前状态：

- “已是最新 · 检查于 … 前”，旁边的**立即检查**可以马上再查一次。
- 有新版本时：显示“有 … 个更新”、最新一项更改的标题，以及**立即更新**。它会获取新版本、构建它并重启应用；正在运行的智能体会在重启过程中继续工作，这个标签页也会自动重新加载为新版本。如果应用无法自己重启，它会获取并构建新版本，然后由你重启应用来使用它。
- 更新过程中依次显示：“正在获取新版本…”、“正在安装软件包…”、“正在构建…”，然后是“正在重启，此页面会自动重新连接…”。
- 之后一周内，会显示上一次更新的结果：何时更新的（以及从哪个版本更新到哪个版本），或者失败的原因。

有新版本时，侧边栏中的**设置**上会出现一个圆点。不是从 git 安装的副本无法检查：**立即检查**会说明这一点。

[**自动更新**](/settings?s=general&find=Update%20automatically)（初始为开启）会自动安装新版本：从 git 安装的副本在你 5 小时没有发消息后安装，每天最多一次；Mac 应用则在新版本一发布时安装，并提前一分钟告诉你。正在运行的智能体会继续工作。它要求应用能够自己重启（安装程序设置的服务、Docker，或放在“应用程序”文件夹中的 Mac 应用）；否则开关会处于关闭状态并说明原因。

你的设备上打开的其他页面会发现应用的版本比它们正在运行的更新，并提供**重新加载**（“Hydor 已更新”）。

### Mac 应用的更新

Mac 应用则按发布的版本更新。开启[**自动更新**](/settings?s=general&find=Update%20automatically)时，新版本一发布它就会下载，并核对它正是发布中注明的那个版本，不必等你离开。然后它会在两个地方告诉你：

- Mac 发出的一条通知：“Hydor … 已就绪”，一分钟后重启以安装它。点按通知会打开应用；通知上的**立即重启**按钮会马上安装新版本。
- 应用每个打开的页面角落里的一条提示，按秒倒数（“42 秒后重启以安装”），带有**立即重启**和**推后**。

一分钟到时，应用会重启为新版本：正在运行的智能体会继续工作，它的窗口也会自动回来。**推后**会把它推迟 4 小时，届时通知和提示会再次出现。在那之前，菜单栏中应用图标的菜单（以及 **Hydor** 菜单）里的 **Restart to Update to …**（这些菜单是英文的）随时都能安装它，**关于**下方的**立即重启**也可以；**关于**会显示“版本 … 已可安装”以及何时再次提醒。

关闭**自动更新**时，不会自动下载任何东西：**关于**会显示“版本 … 已发布”，**立即更新**会下载它、核对它，然后用它替换你正在运行的版本打开（先是“正在下载新版本…”，然后是“正在打开新版本，此页面会自动重新连接…”）。

如果新版本无法启动，之前的版本会自动回来，**关于**下方的那行文字会说明原因；之后那个版本只会在你按下**立即更新**时安装。Mac 应用只有放在“应用程序”文件夹（或其他你可以写入的文件夹）中才能自我更新：从磁盘映像中打开时，它会提示你把它移到那里。

## 阅读版本说明

每个版本都有版本说明：对使用者来说有哪些变化。

- 在[设置 → 应用 → 通用](/settings?s=general)底部的**关于**中，点击版本号旁边的**版本说明**。
- 或者在搜索框中输入“release notes”或“what's new”。

版本说明列出每一个版本，最新的在前，每个都附有日期；你正在运行的版本标有“当前版本”，从设置打开时会直接定位到那里。

应用更新后，角落里会出现一次提示“已更新到 Hydor …”，并带有**新功能**按钮，点击会在该版本处打开版本说明。每个浏览器只显示一次，浏览器第一次访问时不显示。

## 开始导览

欢迎导览是为刚接触 AI 的人准备的。它先用一段小短片演示一个请求是怎样完成的（你用自己的话提出请求，智能体一步步完成，结果就绪），然后问你由什么来完成工作：**Claude** 或 **ChatGPT**（用你已经付费的套餐）、**按用量付费**（通过 OpenRouter 使用各家公司的模型）、**免费，在这台电脑上**（在这里运行的模型），或者**其他智能体**。它会在全屏页面上为你选的每一项完成设置，每页的图示和文字都在同样的位置，也不需要滚动：登录、添加你的 OpenRouter 密钥并挑选给智能体用的模型，再挑选制作图片、音乐、语音和视频的模型，或者一键安装为这台电脑推荐的模型。每个页面旁边的图示把你选的各项画成溪流，流进 Ω 周围的水池，你选得越多，Ω 里的水就越满；底部的小圆点表示你走到了哪一步，下方的海浪缓缓漂动。然后它带你一部分一部分地熟悉应用，途中还可以试一试：一键把第一个任务放进消息框。你第一次使用应用时，它会自动打开。

想再看一次：[设置 → 应用 → 通用 → 欢迎导览 → **开始导览**](/settings?s=general&find=Take%20the%20tour)，搜索框中的**开始导览**，或侧边栏中**帮助**页面顶部的**开始导览**。更多内容参见[入门](/guide/start)。

导览之后，小贴士会在你用到应用的其他部分时为你介绍它们。应用的某个部分第一次出现在屏幕上时（收件箱、会话菜单、Git 页面、**设置 → 记忆**……），旁边会出现一张小卡片，说明它的用途；**了解更多**会打开本指南中详细介绍它的地方。小贴士一次只出现一条，彼此间隔一段时间，也不会在你打字或打开菜单时出现。

- 点**知道了**，或者直接使用它所指的部分，这条小贴士就不会再出现，在每台设备上都是如此。
- **跳过小贴士**会在每台设备上停止全部小贴士。导览第一页上的**跳过导览**也一样；用 ✕ 关闭导览则会让小贴士保持开启。
- 想再次打开或关闭它们：[设置 → 应用 → 通用 → **小贴士**](/settings?s=general&find=Tips)。

## 修改密码

应用只有一个密码，是安装时设定的。要修改它，打开[设置 → 应用 → 密码](/settings?s=security&find=Change%20password)：

1. 输入你的**当前密码**。
2. 输入**新密码**（至少 10 个字符），并在**再次输入新密码**中再输一遍。
3. 点击**修改密码**。

修改密码会让其他所有浏览器退出登录：手机、其他电脑，除了当前这个以外的所有地方。如果当前密码不对，或两次输入的新密码不一致，什么都不会改变，应用会说明原因。

如果你忘了密码，在运行应用的那台电脑上、在应用的文件夹中运行：`node dist/server/cli.js set-password`（使用 Docker 时：`docker compose exec -it hydor node dist/server/cli.js set-password`）。所有浏览器都会退出登录，因输错密码而被暂停的地址也能马上重新登录。

## 在此浏览器上退出登录

[设置 → 应用 → 密码 → 在此浏览器上退出登录](/settings?s=security&find=Sign%20out%20of%20this%20browser) → **退出登录**会让这个浏览器退出登录，而且只影响这一个。要重新进入，你需要输入密码。

## 应用把数据保存在哪里

应用把它自己的数据保存在一个文件夹里，即它的数据文件夹：你主文件夹中的 `~/.hydor`（0.5 版之前的安装是 `~/.web-agent`，或者 `DATA_DIR` 设置指向的位置）。你在“文件”页面上删除的文件会进入其中的废纸篓；“文件”页面位置中的**废纸篓**会写明它在哪里。它包含：

- 密码的哈希值（密码本身从不保存）；
- 数据库，其中有会话列表、搜索、设置以及应用的其他记录；
- 当前正在运行的智能体的日志；
- 等待发送的附件（应用保存的副本会在 14 天后删除，总量保持在 2 GB 以内）；
- “文件”页面的废纸篓；
- 笔记本内核，以及终端所运行的私有服务器；
- 开启按含义搜索后，它的私有 Python 环境。

对话本身保存在智能体写入的位置：Claude Code 的在 `~/.claude/projects`，Codex 的在 `~/.codex/sessions`；应用直接从那里读取（设置 → 通用中的**关于**也写明了这一点）。使用 Docker 时，这些都位于容器的 `/home/node` 中，保存在它的数据卷里。

### 每个浏览器各自保存的内容

有些选择属于你做出选择时所用的浏览器，所以每台设备可以不同：

- 模式（深色、浅色或系统），以及显示哪个深色主题和哪个浅色主题；
- 语言；
- 智能体工作时 Enter 的作用；
- 终端建议、通知提示音，以及这台设备是否接收通知；
- “文件”页面的当前文件夹、已打开的文件、最近的文件，以及文件夹的显示方式（列表还是图块，以及排序）；置顶的文件夹保存在服务器上，在每台设备上都一样；
- 审查分支时标记为**已查看**的文件；
- “新功能”提示是否已经显示过。

其余的由应用保存，在每台设备上都一样：你创建的主题、**用量限制解除后继续**、**删除不活跃的会话**、**开机时启动**、**自动更新**、是否已经参加过导览，以及小贴士（是否开启，以及已经显示过哪些）。
