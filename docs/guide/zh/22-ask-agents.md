# 让智能体替你操作应用

这里的每个智能体都熟悉这份指南，也能替你操作应用。问它某样东西怎么用，它会根据指南回答，并附上通往正确位置的链接。让它更改某项设置或帮你建好某样东西（一个空间、一个助手、一个定时任务），它会在你在卡片上确认后去做。当它需要你提供细节时，会显示一个表单让你填写。

## 问某件事怎么做

在任何会话中，用任何智能体，都可以像问人一样问关于应用的问题：“我怎么把这个会话分享给同事？”“在手机上去哪里打开通知？”“自动模式是做什么的？”。智能体会在这份指南里查找答案，所以它描述的是应用现在的样子，它给的链接也会打开它提到的地方。

你也可以自己读这份指南：点侧边栏中的**帮助**，或者在搜索框（Ctrl+K，Mac 上是 ⌘K）里搜索，指南的各个章节会显示在**指南**下面。

## 请智能体更改设置或帮你建好某样东西

你在应用的各个页面里能做的事，智能体也能在应用里做。下面是一些你可以提的要求：

- “打开按含义搜索。”
- “为我的学位论文建一个叫 Thesis 的空间，用研究员助手。”
- “每个工作日早上 8 点，给我一份可再生能源方面的新闻简报。”
- “在我的准则里加上一条：回答要简短。”
- “先用 Brave Search，再用 DuckDuckGo。”
- “删除关于我以前那份工作的记忆笔记。”
- “我有哪些模板？用旅行规划给我安排一个在 Lisbon 过的长周末。”
- “把这台设备切换到浅色主题。”

智能体会先读取现在的情况，然后请你在对话中的一张卡片上确认这项更改。读取从来不需要询问：智能体随时都可以查看你的设置、空间、任务等等，来回答你。

## 卡片：确认一项更改

在智能体更改任何东西之前，对话中会出现一张卡片（也会出现在你的[收件箱](/inbox)里，如果你不在，还会收到通知）。卡片上写着：

- **这是什么更改**，用智能体自己的话说：“创建空间‘Thesis’”。
- **会改动什么**，逐个字段列出：一项设置现在的值和将来的值（“**结果数**：10 → 20”），或者新建的东西会用什么内容来创建。
- **调用本身**，用小字显示（例如 `PUT /api/search/settings`），这样无论智能体怎么说，你都能确切看到会发生什么。

然后由你选择：

- **允许**会执行这项更改。
- **在此会话中允许**会执行它，并让这个会话之后再做同类的日常更改时不必再问。每次都要问的更改（见下文）仍然会问。
- **不允许**（或**拒绝**）什么都不会改。你可以说明原因，或者说该改做什么，智能体会读到。

有些更改每次都会问，即使你已经点过**在此会话中允许**：删除任何东西、启动一个会话或一次定时任务的运行、给另一个会话发消息、添加 MCP 服务器或插件、更改智能体在 Custom 或浏览器中可以做什么、添加一台机器或一个账户、下载模型、更新应用。如果是删除，按钮上会写**删除**。

一张卡片大约等九分钟。如果到时你还没回应，它就会消失，智能体会改为在回复中问你。

## 智能体需要细节时：表单

当智能体需要你提供好几样东西时，它可以在对话中显示一个表单，而不是列一串问题：比如一次旅行的日期和预算，一个新模板的名称和字段。填好后点击按钮（**发送**，或者智能体给它起的名字）；**暂不**会关闭表单，智能体会在没有它的情况下继续，或者改用文字来问。

用于更改的卡片也可以带一个表单：“创建空间”可以显示智能体猜测的名称、描述和准则，让你在点击**保存**之前修改。

## 智能体在应用里不能做的事

有些事情始终由你自己来做。智能体如果尝试去做，会被告知这些事要你在哪里做：

- 你的密码，以及登录和退出登录（[设置 → 密码](/settings?s=security)、[账户](/settings?s=accounts)）；
- 密钥的值：智能体会用一张卡片向你要密钥，你在卡片上把它输入保险库，智能体从来看不到它（[连接、密钥和工具](/guide/connections)）；
- 为其他机器或智能体创建访问令牌，以及模板的 API 密钥；
- 回应批准卡片，无论是它自己的还是其他会话的，以及对那些询问你的卡片做决定（一个提议的技能、一个定时任务、一次发布）；
- 会话的权限和它的花费上限；
- 通过应用操作文件、命令、终端和 git：这些事智能体会用它们自己的工具来做，而这些工具会按照会话的权限设置来问你。

## 权限与卡片

会话的权限允许什么，决定了卡片会问多少：

- **计划**（以及 Codex 的**只读**）：智能体可以读取应用的设置并回答问题，但什么都不改。它会告诉你它本来会改什么。
- **询问**、**接受编辑**、**自动**等：更改会通过卡片来问，如上所述。
- **绕过**（Claude Code）和**完全访问**（Codex）：没有卡片；智能体会直接做你要求的更改。当智能体需要细节时，仍然会显示表单。
- Custom 的**完全访问**：只有每次都要问的那些更改才会显示卡片。

## 每台设备各自保存的设置

有几项设置属于每台设备，而不属于整个应用：主题、语言、通知声音、智能体工作时 Enter 的作用、终端建议，以及是否显示侧边栏。智能体可以在你和它对话所用的那台设备上（显示那个会话的页面）更改这些设置，不需要卡片：“切换到深色主题”“使用鼠尾草主题”“用希腊语显示应用”。你的其他设备会保留它们各自的设置。

- “把浏览器的截图关掉。”
- “告诉我有哪些定时任务，并把价格监控关掉。”
- “把这台设备切换到浅色主题。”
