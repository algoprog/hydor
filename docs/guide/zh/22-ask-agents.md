# 让智能体替你操作应用

这里的每个智能体都熟悉这份指南，也能替你操作应用。问它某样东西怎么用，它会根据指南回答，并附上通往正确位置的链接。让它更改某项设置或帮你建好某样东西（一个项目、一个智能体、一个定时任务），它会在你在卡片上确认后去做。当它需要你提供细节时，会显示一个表单让你填写。

![智能体替你更改设置：卡片会在更改之前显示要改的内容](images/ask-agents.webp)

## 问某件事怎么做

在任何会话中，用任何智能体，都可以像问人一样问关于应用的问题：“我怎么把这个会话分享给同事？”“在手机上去哪里打开通知？”“自动模式是做什么的？”。智能体会在这份指南里查找答案，所以它描述的是应用现在的样子，它给的链接也会打开它提到的地方。

你也可以自己读这份指南：点侧边栏中的**帮助**，或者在搜索框（Ctrl+K，Mac 上是 ⌘K）里搜索，指南的各个章节会显示在**指南**下面。在帮助页面顶部的框里输入问题并按 Enter，问题就会交给一个智能体，它的回答显示在指南旁边（见[获取帮助](/guide/start#get-help)）。

## 请智能体更改设置或帮你建好某样东西

你在应用的各个页面里能做的事，智能体也能在应用里做。下面是一些你可以提的要求：

- “打开按含义搜索。”
- “为我的学位论文建一个叫 Thesis 的项目，用研究员智能体。”
- “每个工作日早上 8 点，给我一份可再生能源方面的新闻简报。”
- “在我的准则里加上一条：回答要简短。”
- “先用 Brave Search，再用 DuckDuckGo。”
- “删除关于我以前那份工作的记忆笔记。”
- “我有哪些应用？用旅行规划给我安排一个在 Lisbon 过的长周末。”
- “把这台设备切换到浅色主题。”

智能体会先读取现在的情况，然后请你在对话中的一张卡片上确认这项更改。读取从来不需要询问：智能体随时都可以查看你的设置、项目、任务等等，来回答你。

## 让智能体做编辑器能做的事

智能体修改你资料库里的内容，就像你在它的编辑器里修改一样：它们会写幻灯片、文档、电子表格、LaTeX 文档、笔记本和示意图，还能一次做完编辑器点一下就对整份内容做的事：

- **幻灯片**：给每张幻灯片添加动画（**柔和**、**活泼**或**醒目**，或者去掉所有动画），修正**检查辅助功能**发现的问题，为没有描述的图片写上描述，让这套幻灯片兼容 PowerPoint 或改回网页格式，给它换上一种现成主题或你自己的主题，把幻灯片设为宽屏或标准比例，从另一套幻灯片导入幻灯片，以及更新根据电子表格制作的图表。
- **文档**：接受或拒绝修改建议，更改页面设置，加上页眉、页脚和页码。
- **电子表格**：给表格排序，删除其中重复的行，向下或向右填充，清除单元格，去掉多余的空格，把文字拆分成多列，在新工作表上汇总一张表格（和**数据 → 分组汇总**一样），插入或删除行和列，以及重命名、复制、移动或删除工作表；公式会跟着变，和在编辑器里一样。
- **LaTeX 文档**：重命名或移动文件、图片和文件夹，文档中提到它们的那些行也会跟着改。
- **笔记本**：清除输出。
- **示意图**：重新排布一页（或每一页），排成纵向或横向的流程图、树形、思维导图、同心环、圆形或网格；给每个形状换上同一种外观，给文字换上同一种字体，或者让整个示意图看起来像手绘的。
- **以上任何一种**：在资料库里做一份副本，或者用它做出另一种类型的东西（**转换为**）。

每一项都会保存一个新版本（之前的版本仍留在版本列表中），打开着它的编辑器会立刻显示出来，你自己的修改和评论也都会保留。这些操作免费且即时完成，只有为图片写描述要由模型来做。页面旁边的智能体（[请智能体来修改](/guide/library#change-it-by-asking-an-agent)）知道所有这些操作，也确切知道你选中了什么。例如：

- “给我的‘发布计划’的每张幻灯片加上活泼的动画，再修正辅助功能检查发现的问题。”
- “让我的‘发布计划’幻灯片兼容 PowerPoint。”
- “在‘预算’文档里接受 Maria 的建议，拒绝其余的。”
- “在我的‘销售’电子表格里，按收入从高到低给表格排序，并删除重复的行。”
- “在我的 LaTeX 学位论文里，把 figures/ 里的图片移到 img/。”
- “把我的‘结账流程’示意图改成从左到右排列，并把所有形状都改成蓝色。”

## 卡片：确认一项更改

在智能体更改任何东西之前，对话中会出现一张卡片（也会出现在你的[收件箱](/inbox)里，如果你不在，还会收到通知）。卡片上写着：

- **这是什么更改**，用智能体自己的话说：“创建项目‘Thesis’”。
- **会改动什么**，逐个字段列出：一项设置现在的值和将来的值（“**结果数**：10 → 20”），或者新建的东西会用什么内容来创建。
- **调用本身**，用小字显示（例如 `PUT /api/search/settings`），这样无论智能体怎么说，你都能确切看到会发生什么。

然后由你选择：

- **允许**会执行这项更改。
- **在此会话中允许**会执行它，并让这个会话之后再做同类的日常更改时不必再问。每次都要问的更改（见下文）仍然会问。
- **不允许**（或**拒绝**）什么都不会改。你可以说明原因，或者说该改做什么，智能体会读到。

有些更改每次都会问，即使你已经点过**在此会话中允许**：删除任何东西、启动一个会话或一次定时任务的运行、给另一个会话发消息、添加 MCP 服务器或插件、更改智能体在 Custom 或浏览器中可以做什么、添加一台机器或一个账户、下载模型、在这台电脑上配置图片工具、更新应用。如果是删除，按钮上会写**删除**。

一张卡片大约等九分钟。如果到时你还没回应，它就会消失，智能体会改为在回复中问你。

## 智能体需要细节时：表单

当智能体需要你提供好几样东西时，它可以在对话中显示一个表单，而不是列一串问题：比如一次旅行的日期和预算，一个新应用的名称和字段。填好后点击按钮（**发送**，或者智能体给它起的名字）；**暂不**会关闭表单，智能体会在没有它的情况下继续，或者改用文字来问。

表单会一直等你填写。如果你大约九分钟内没有回答，智能体会在那里结束这一轮，表单仍留在对话中，即使智能体停止或应用重新启动也是如此。你填好后，你的回答会作为你的下一条消息发给智能体（“我对……的回答”），它就从那里接着做；如果回答发不出去，表单会留着，让你再发一次。比屏幕还高的表单会从它的顶部显示，**最新**可以跳到它的末尾。

用于更改的卡片也可以带一个表单：“创建项目”可以显示智能体猜测的名称、描述和准则，让你在点击**保存**之前修改。

## 智能体在应用里不能做的事

有些事情始终由你自己来做。智能体如果尝试去做，会被告知这些事要你在哪里做：

- 你的密码，以及登录和退出登录（[设置 → 密码](/settings?s=security)、[账户](/settings?s=accounts)）；
- 密钥和登录信息的值：智能体会用一张卡片向你要它们，你在卡片上把它们输入保险库，智能体从来看不到它们（[已连接的应用、密钥和工具](/guide/connections)）；OpenRouter 密钥有一张自己的卡片，会把它直接存进设置 → 模型（[智能体需要 OpenRouter 密钥时](/guide/documents-voice#when-an-agent-needs-the-openrouter-key)）；
- 为其他机器或智能体创建访问令牌，以及应用的 API 密钥；
- 回应批准卡片，无论是它自己的还是其他会话的，以及对那些询问你的卡片做决定（一个提议的技能、一个定时任务、一次发布）；
- 会话的权限和它的花费上限；
- 通过应用操作文件、命令、终端和 git：这些事智能体会用它们自己的工具来做，而这些工具会按照会话的权限设置来问你；
- 编辑器自带的 AI 工具，以及图片和视频编辑器：智能体用它们自己的工具来生成、查找、修改和编辑图片、绘图、数据图和视频，做出的东西保存在会话的文件夹里（[文档、图片、视频和语音](/guide/documents-voice)），也会用每张幻灯片备注的配音给幻灯片配上旁白。

## 权限与卡片

会话的权限允许什么，决定了卡片会问多少：

- **计划**（以及 Codex 的**只读**）：智能体可以读取应用的设置并回答问题，但什么都不改。它会告诉你它本来会改什么。
- **询问**、**接受编辑**、**自动**等：更改会通过卡片来问，如上所述。
- **绕过**（Claude Code）和**完全访问**（Codex）：没有卡片；智能体会直接做你要求的更改。当智能体需要细节时，仍然会显示表单。
- Custom 的**完全访问**：不显示批准卡片，包括通常每次都要问的更改。需要补充信息时仍会显示表单。

## 每台设备各自保存的设置

有几项设置属于每台设备，而不属于整个应用：主题、语言、通知声音、智能体工作时 Enter 的作用、终端建议，以及是否显示侧边栏。智能体可以在你和它对话所用的那台设备上（显示那个会话的页面）更改这些设置，不需要卡片：“切换到深色主题”“使用鼠尾草主题”“用希腊语显示应用”。你的其他设备会保留它们各自的设置。
