# 智能体、账户和模型

Hydor 可以运行好几种 AI 智能体：Claude Code、Codex、Custom（应用自己的智能体，可用于任何模型），以及其他支持 ACP 的智能体，比如 Gemini CLI 或 OpenCode。本主题会讲它们有什么不同、它们的程序如何安装并保持最新、如何登录它们（包括登录多个账户），以及 Custom 的模型从哪里来：OpenRouter、Ollama、在这台电脑上运行的 Hugging Face 模型，或者任何兼容 OpenAI 的端点。

![在开始页面选智能体：Claude Code、Codex 或 Custom](images/agents-models.webp)

## 我该用哪个智能体？

智能体是会话里干活的程序：它读你的消息，使用工具（文件、命令、网络），然后回答。模型则是它背后的 AI。这里的每个智能体都能从应用得到同样的帮助（网页搜索、浏览器、记忆、技能、你的连接），区别在于它们的模型从哪里来。

- **Claude Code**（Anthropic）。使用你的 Claude 套餐运行，或者从 Anthropic API 账户计费。它的模型是 Anthropic 的（Opus、Sonnet、Haiku）。它有自己的用量限制，显示在[用量页面](/usage)上。
- **Codex**（OpenAI）。使用你的 ChatGPT 套餐运行。它的模型是 OpenAI 的。它也有用量限制，同样显示在用量页面上。Codex 随应用一起提供。
- **Custom**，应用自己的智能体。它可以运行你在[设置 → 智能体 → 模型](/settings?s=models)中添加的任何模型：通过 OpenRouter 使用的模型、这台电脑上的模型（用 Ollama 或 vLLM），或者任何兼容 OpenAI 的端点。想用开放模型、更便宜的模型，或者完全不离开你电脑的模型时，就用它。请看[Custom，应用自己的智能体](/guide/custom)。
- **支持 ACP 的智能体**：Gemini CLI、OpenCode、Qwen Code、Goose、Kimi CLI、Auggie，或者你自己的命令。ACP（Agent Client Protocol，智能体客户端协议）是应用与智能体程序对话的一种通用方式。每个智能体都在它自己的程序里登录一次，并使用它自己的模型。

各自在应用里能做什么：

- 目标（智能体持续工作，直到某个条件成立）和分叉（从较早的某条回复开始复制出一个会话）：Claude Code、Codex 和 Custom 可以。其他 ACP 智能体不行。
- **转到…继续**（把对话交给另一个智能体）：从 Claude Code 或 Codex 转到另一个，或者转到 Custom。
- 思考强度（模型思考得多用力）：Claude Code 和 Codex，适用于提供这一选项的模型。
- 多个账户：Claude Code 和 Codex。
- 套餐用量限制和限制重置：Claude Code 和 Codex。

## 为新会话选择智能体和模型

在开始页（`/`）上，消息框下面那一行写明了由谁来干活。

1. 点击**智能体**。列表里有 **Claude Code**（“Anthropic · Claude 套餐或 API 密钥”）、**Codex**（“OpenAI · ChatGPT 套餐或 API 密钥”）、**Custom**（“任意模型：OpenRouter、Ollama、vLLM”），以及你在设置 → 更多智能体中添加的每个智能体（“ACP 智能体 · ”加上它的命令）。最下面，**Custom 的模型**会打开设置 → 模型，**添加或管理智能体**会打开设置 → 更多智能体。
2. 点击**模型**并选一个。列表里只显示这个智能体自己的模型。智能体的默认模型标有“默认”。一个模型的旧版本收在“2 个较旧的模型”这样的一行后面；点击它就能看到。模型超过八个时，顶部会有一个**搜索模型**框：输入几个字母，按 Enter 就会选中第一个匹配项。
3. 在**选项**下可以找到**思考强度**（适用于有这项设置的智能体和模型：默认、低、中等、高，等等）和**权限**（智能体不问你就可以做什么）。在消息框中按 Shift+Tab 也可以切换权限。

开始页会按智能体记住你的选择，在每台设备上都一样：下次打开时，还是同样的智能体、模型、思考强度和权限。

除 Custom 之外的 ACP 智能体，要在它的第一个会话之后才会显示**模型**和**权限**的选项：列出的是这个智能体上次运行时提供的选项。

在手机上，这些菜单都会以面板的形式从屏幕底部弹出。

## 在会话中途切换模型

在会话中，模型、思考强度和权限位于消息框下方。它们合成一个按钮，上面写着类似“Opus 5.5 · 高 · 计划”的内容：点击它就能选择**模型**、**思考强度**和**权限**。

另选一个模型，会话就会用它继续：

- Claude Code 会立即切换。
- Codex 从下一轮开始使用新模型。
- Custom 从下一步开始使用它，即使正处在一轮的中间。
- 其他 ACP 智能体如果提供模型选择，也会切换。

模型菜单只列出这个会话自己的智能体的模型。要把对话转给另一个智能体，请使用会话的菜单（⋯）→ **转到 Codex 继续**、**转到 Claude Code 继续**或**转到 Custom 智能体 继续**（在 Claude Code 和 Codex 会话中可用；Custom 要等它有了模型才会出现）。之后你发的下一条消息会在同一个文件夹中，带着目前为止的对话，开启那个智能体的一个新会话。已停止的会话重新开始时，会使用它上次用的模型，除非你在发送前另选一个。

## 智能体程序会自己安装和更新

Claude Code、Codex、Gemini CLI 等都是这台电脑上的程序。你不必手动安装它们。

打开[设置 → 智能体 → 账户](/settings?s=accounts&find=Agent%20programs)，滚动到**智能体程序**。这里列出 Claude Code、Codex、Gemini CLI、OpenCode、Qwen Code 和 Auggie，每个都注明了会话所运行的版本和来源：

- **你自己安装的**：是你自己装的。
- **由应用安装**：应用把它装在了自己的文件夹里。
- **随应用提供**：Codex 随应用一起提供。
- **不在本机：首次使用时会自动安装**：还没有安装。点击**安装**可以现在就装上。

有更新的版本发布时，这一行还会写着“… 已发布”。如果你自己也装了 Codex，Codex 这一行会加上“你在终端里用的：…”：会话运行的是应用的那份，终端运行的是你自己的。

缺少的程序在第一次需要时也会自动安装：Claude Code 是在你登录它或开始一个 Claude Code 会话时，ACP 智能体是在你于设置 → 更多智能体中添加它或用它开始会话时。应用会用 npm 把它们装进自己的文件夹，所以你不需要管理员权限。

Goose 和 Kimi CLI 不在这个列表里：请自己安装它们（设置 → 更多智能体里写明了去哪里获取）。

## 让智能体程序保持最新

**智能体程序**下的[**自动更新**](/settings?s=accounts&find=Update%20automatically)打开时（除非你关掉，它一直是开着的），应用每天一次把每个智能体程序更新到最新版本。第一次在应用启动大约十分钟后进行。

- 应用安装的副本通过 npm 在它自己的文件夹里更新。Codex 会换用比应用自带的那份更新的副本。
- 你自己安装的程序用它们自带的更新程序更新：Claude Code 用 `claude update`，Codex 用 `codex update`（也就是你终端里运行的那份），OpenCode 用 `opencode upgrade`。
- 你用 `npm install -g` 安装的 Gemini CLI、Qwen Code 或 Auggie 会通过 npm 更新，前提是你的用户可以写入那个文件夹。用其他方式安装的，请按你安装它的方式自己更新。
- Claude Code 跟随它自己的发布渠道：它的设置里写着 `"autoUpdatesChannel": "stable"` 时用稳定版，否则用最新版。
- 如果你用 `DISABLE_AUTOUPDATER=1` 关掉了 Claude Code 自己的更新（Docker 镜像就是这样做的），应用也不会自行更新你的 Claude Code。**立即更新**仍然会更新它。

只有当新版本能像会话那样正常使用时，应用才会保留它。Claude Code 要像会话开始时那样作出回应并列出它的模型，Codex 要启动它的 app server 并列出它的模型，其他程序要能启动并报出自己的版本。这些都不需要登录，也不会用掉你套餐的任何额度。没有通过的版本会被撤回：

- 应用安装的副本，或者它通过 npm 为你更新的程序，会回到之前的版本。
- 对你自己的 Claude Code，会话会继续运行之前的版本，Claude Code 的安装程序把它保留在新版本旁边。终端里的 `claude` 命令仍然是新版本。这一行会写着“… 在这里无法正常工作”。
- 没有通过的版本不会再自行尝试，但下一个版本会；**立即更新**会再试一次。

在开关下面，这一部分会写着应用上次查找的时间，比如“已是最新 · 检查于 2 小时前”，并带有**立即检查**可以再查一次。有更新的版本时会写明，并带有**立即更新**可以马上安装；更新时它会显示正在更新哪个程序。下面一行写着上次更新改了什么，比如“Claude Code 2.1.308 → 2.1.316”，或者某个版本为什么没能安装。

正在运行的会话会继续使用它们启动时的版本；新的会话使用新版本。**自动更新**关掉时，应用仍然每天查找一次并显示有哪些新版本，但在你点击**立即更新**之前什么都不会安装。

## 登录 Claude Code 和 Codex

Claude Code 和 Codex 需要先登录才能工作。打开[设置 → 智能体 → 账户](/settings?s=accounts)（在手机上，设置是一个分区列表：轻点“智能体”下的**账户**；点顶部的标题可以返回）。**你的账户**（“你的会话使用的 Claude Code 和 Codex 登录。再添一个订阅，比如工作用和个人用各一个，开始会话时选择其中一个。”）先列出每个智能体自己的登录，再列出你为它添加的账户。每一行会显示一个绿色对勾以及邮箱、套餐和登录方式，或者一个红叉以及“未登录”或出错的原因。

登录方法：

1. 点击智能体旁边的**登录**。
2. 选择登录方式：
   - Claude Code：**Claude 订阅**（你的 Claude 套餐）或 **Console（API 计费）**（一个 Anthropic API 账户）。
   - Codex：**设备码**或**浏览器跳转**。
3. 点击**获取登录链接**。
4. 按照对话框显示的步骤操作：
   - Claude Code：打开链接（**打开登录页面**），在浏览器中批准访问，然后把页面上显示的代码粘贴到**粘贴页面上的代码**中，再点击**完成登录**。
   - Codex，设备码：在任意设备上打开链接，登录 ChatGPT，然后输入对话框中显示的一次性代码。你完成后，对话框会自己察觉到。
   - Codex，浏览器跳转：登录后，你的浏览器会尝试打开一个“localhost”页面，但会失败。复制那个页面的地址，粘贴到**粘贴浏览器中的 localhost 地址**中，然后点击**完成登录**。

成功后你会看到“Claude Code 已登录”（或 Codex）。如果失败，对话框会说明原因；点击**重试**。

登录之后，按钮会变成**切换账户**：它会为另一个账户启动同样的登录流程。**退出登录**在这一行的 **⋯** 菜单里：它会在你确认后，让这台电脑上的这个程序退出登录，所有使用它的终端和编辑器都会随之退出。

欢迎导览（从侧边栏的**帮助**进入）会问你想用哪些智能体和模型，也会一步步带你完成这些登录。

## 添加第二个账户（工作和个人）

你可以登录多个 Claude Code 或 Codex 账户，比如一个工作用的套餐和一个个人用的套餐，然后每个会话选一个。

1. 打开[设置 → 智能体 → 账户](/settings?s=accounts&find=Your%20accounts)。
2. 点击**你的账户**顶部的**添加账户**。
3. 选择 **Claude Code** 或 **Codex**，输入一个名字（最多 40 个字符，比如“工作”或“个人”），然后点击**添加并登录**。
4. 新账户的登录对话框会打开。按上面说的方法登录。

每个添加的账户单独登录，并保留自己的会话历史。你的设置、指令、技能和插件与这个智能体的主登录共用，所以改动会同时作用于两者。同一个智能体的两个账户不能重名。

每个添加的账户都有自己的一行，排在这个智能体自己的登录下面，带有**登录**或**切换账户**；它的 **⋯** 菜单里有**退出登录**、**重命名**和**移除**：

- **重命名**会让你输入新名字。
- **退出登录**会让以这个账户运行的会话无法工作，直到它重新登录。
- **移除**会把这个账户从应用中拿掉。它的会话会从列表中消失，但历史记录仍保留在磁盘上，除非你同时勾选了**同时删除它的登录信息和会话历史**。有会话正以这个账户运行时，不能移除它：请先停止那些会话。

[用量页面](/usage)会为每个添加的账户显示一张卡片，上面有它自己的限制。

## 选择会话使用的账户

当你选的智能体有添加的账户时，开始页的**选项**里会出现**账户**一行。点击它：

- **你的登录**是这个程序自己的账户（也就是“你的账户”下这个智能体的第一行）。
- 每个添加的账户都按名字列出。
- **管理账户**会打开设置 → 账户。

开始页会为那个智能体记住你的选择。以添加的账户运行的会话，会在会话顶部显示那个账户的名字，旁边有一个人像图标。如果那个账户达到了用量限制，消息框上方的限制提示说的就是那个账户。账户在会话开始时就定下了。只有找到**达到限额时切换账户**（见下文）后，它才会自己改变。

## 用上你所有的账户：达到限额时切换

同一个智能体有两个或更多账户时，应用可以把它们都用上：一个账户的用量用完了，你的工作就换另一个账户继续。打开[设置 → 智能体 → 账户](/settings?s=accounts&find=Switch%20accounts%20at%20a%20limit)，在**你的账户**底部（添加了账户之后才会出现）开启**达到限额时切换账户**（“当某个会话所用的账户用量耗尽时，会话会转到这个智能体另一个还有用量的账户上继续。新会话会跳过已达到限额的账户。”）。它一开始就是开启的（如果你想自己选账户，可以在那里关闭）；即使没有打开任何浏览器，它也能工作。

- 当某一轮因为会话所用的账户达到用量限制而停止时，应用会挑选同一个智能体下另一个已登录、还有用量的账户（用得最少的那个），把会话连同全部历史移到那里，并发送“… reached its usage limit, so this session now runs on …. Continue where you left off.”。应用顶部会有一条提示，说明会话移到了哪个账户。
- 你的主登录和每个添加的账户都算在内。Claude Code 账户之间互相接替，Codex 账户之间互相接替。
- Codex 的目标会随会话一起移过去，并继续进行。
- 如果每个账户都达到了限额，就什么都不会移动。开启**用量限制解除后继续**时，会话会在第一个账户重置时，在那个账户上继续。更多内容见[用量、限额和费用](/guide/usage#continue-sessions-automatically-after-a-limit)。
- 在已达到限额的账户上开始的新会话，会改在还有用量的账户上开始；你发给某个会话的消息，如果它的账户已达到限额，会先把会话移过去，这样消息就不会被拒。
- 应用自己向 Claude Code 或 Codex 提的简短问题（**自动**模式下的辅助模型、应用的快速模型步骤、拉取请求说明、命令建议）在某个账户达到限额或已退出登录时，也会同样交给你下一个已登录的账户。

## 添加 Gemini CLI、OpenCode 和其他 ACP 智能体

打开[设置 → 智能体 → 更多智能体](/settings?s=agents&find=Agents%20that%20speak%20ACP)。

- **你的智能体**（“开始会话时，它们会显示在 Claude Code 和 Codex 旁边”）先列出 Custom，然后是你添加的智能体。程序已经装在这里的，会显示一个对勾。
- **支持 ACP 的智能体**（“先安装一个，在它自己的 CLI 中登录一次，然后在这里添加”）列出你还没添加的已知智能体：Gemini CLI、OpenCode、Qwen Code、Goose、Kimi CLI 和 Auggie。带叉号的一行表示还没安装，并会说明怎么获取。

添加方法：

1. 点击它旁边的**添加**。如果程序已经装好，这个按钮会显得更醒目。
2. 如果应用知道怎么安装它（Gemini CLI、OpenCode、Qwen Code、Auggie），会立即在后台安装。Goose 和 Kimi CLI 需要你自己按它们那一行里的地址安装。
3. 在智能体自己的程序里登录一次：打开[终端](/terminal)，运行它的命令（例如 `gemini`），然后按它的登录步骤操作。如果跳过这一步，会话会告诉你：“Gemini CLI 尚未登录。请在终端中运行一次 gemini 并在那里登录，然后重试。”

现在这个智能体就会出现在开始页的**智能体**列表里了。

要修改已添加的智能体，点击**编辑**。要移除它，点击垃圾桶图标并确认：它的会话仍会留在列表中，但要继续这些会话，需要重新设置这个智能体。Custom 是内置的：它那一行写着“内置：模型来自 OpenRouter、Ollama 和 vLLM，在设置 → 模型中”，并且有一个**模型**按钮，而不是编辑和移除。

### 添加你自己的智能体

任何支持 ACP 的程序都可以在这里运行。

1. 在**你的智能体**中，点击**添加你自己的**。
2. 填写：
   - **名称**：它在列表中显示的名字，例如“Gemini CLI”。
   - **命令**：要启动的程序，例如 `gemini`，或者完整路径。
   - **参数**：让它以 ACP 模式启动的参数，例如 `--experimental-acp`。
   - **环境变量（可选，每行一个 NAME=value）**：程序需要的设置，比如一个 API 密钥变量。
3. 点击**保存**。

这个命令必须以 ACP 模式启动智能体，通过它的标准输入和输出进行通信。

### ACP 智能体在这里能做和不能做的事

应用会在你选的文件夹中打开会话，显示智能体的消息和步骤，并在智能体请求权限时询问你。有些地方和 Claude Code、Codex 不一样：

- 它一次只接收一条消息。它工作时你发的消息会在消息框上方的队列里等着，等这一轮结束再发出。（Custom 也是这样。）
- 不能重新打开之前会话的智能体，在你继续一个旧会话时会从头开始，不带上面的对话。会话里会注明这一点。
- 你附加的图片，只有在它接受图片时才能传给它。
- 目标、分叉和转交都不可用（Custom 有目标和分叉）。

## Custom 的模型从哪里来

Custom 可以运行你在[设置 → 智能体 → 模型](/settings?s=models)中设置的任何模型，并使用和其他智能体相同的工具、技能和 MCP 服务器。在开始页上选 Custom，再选模型。这个页面从上到下分成五个部分：

- **辅助模型**：负责应用里各种小活的模型。
- **在本机**：这台电脑有什么，以及装在这里的模型。
- **从 Hugging Face 添加模型**：搜索、查看并安装开放模型。
- **OpenRouter**：一个密钥就能用上数百个模型。
- **运行时和端点**：Ollama、vLLM、其他兼容 OpenAI 的服务器，以及 Hugging Face 令牌。

在 Custom 的**模型**菜单中，把鼠标悬停在一个模型上，可以看到它在哪里运行、一次能读多少内容，例如“OpenRouter · 128K 上下文”或“vLLM，在本机 · 32K 上下文 · 用到时启动”。这些列表每分钟会自动刷新。

## 选择辅助模型

辅助模型在你的会话之外、不属于任何对话，负责做一些小活：

- 在 Custom 的自动模式下检查步骤，并在每轮结束后检查 Custom 的目标；
- 每晚整理记忆；
- 回答关于浏览器中打开的网页的单个问题；
- 为看不了图片的 Custom 模型描述图片；
- 总结子会话发来的长回复；
- 根据会话起草应用或定时任务；
- 免提语音模式。

打开[设置 → 智能体 → 模型](/settings?s=models&find=Helper%20model)，点击**辅助模型**旁边的菜单：

- **自动**（默认）：通过 Claude Code 使用 Claude Haiku，Claude Code 无法回答时则用 Codex。达到用量限额的账户会先把问题交给你下一个已登录的账户（需开启**达到限额时切换账户**）。都无法回答时，错误信息会分别说明原因：“You've hit your weekly limit”、你的 Codex 套餐不提供的模型……
- Custom 的任何一个模型，注明它在哪里运行（openrouter、ollama、vllm 或 endpoint），能看图片的还会标有“能看图片”。

“自动”看不了图片。如果你在 Custom 中使用的模型看不了图片，请选一个能看图片的辅助模型，否则 Custom 就没法请辅助模型描述你的图片。

## 看看这台电脑能运行什么

[设置 → 智能体 → 模型](/settings?s=models&find=On%20this%20machine)中的**在本机**部分，开头是这台电脑的概况：

- **显卡**：显卡（GPU）及其显存；在搭载 Apple 芯片的 Mac 上，是它的芯片（“Apple M3 Max”，它的图形处理与电脑共用内存）；或者“没有 GPU”（这时模型在处理器上运行）。
- **记忆**（即内存）：总量和可用量。
- **磁盘**：可用空间，以及已安装的模型占了多少。
- **Ollama** 和 **vLLM** 是否已安装，以及它们的版本，或者一个用来安装它们的链接。
- 有显卡时，能装下多大的模型：“单块 GPU 以 4-bit 约可容纳 30B 参数”（在 Mac 上：“以 4-bit 约可容纳 40B 参数”）。参数是衡量模型大小的一种方式；4-bit 是一种常见的压缩形式，只需要大约四分之一的内存。

在它下面：

- **正在进行的下载**，每个都有进度条、已完成多少，以及它是给 Ollama 还是 vLLM 用的。**取消**可以停止一个下载。失败或被取消的下载会显示原因，并带有**关闭**。
- **已安装的模型**，每个都注明了运行时（Ollama 或 vLLM）、大小、详细信息（比如 Ollama 模型的规模和压缩方式）、能看图片的标有“能看图片”，以及它是否正在运行。
  - vLLM 模型有**开始**和**停止**。会话第一次用到它时，它会自动启动（第一次启动需要一两分钟）：在空闲显存最多的那块显卡上，或者没有哪一块显卡装得下时，拆分到 2、4 或 8 块显卡上（“在 GPU 1、2 上运行”）；在 Mac 上，则在它的 Apple 芯片上。然后它一直运行，即使应用重启也一样，直到你点击**停止**。如果它无法启动，原因会显示在它下面。
  - **移除**会在你确认后，从这台电脑上删除这个模型的文件。以后你可以再安装它。

还没有模型时会显示：“这里还没有模型：从下方的 Hugging Face 添加一个。”

## 从 Hugging Face 添加模型

Hugging Face 是开放模型的主要网站。[从 Hugging Face 添加模型](/settings?s=models&find=Add%20a%20model%20from%20Hugging%20Face)部分（“为这台电脑推荐的模型，或者搜索，看看每一个在这里运行得如何，然后安装它”）会推荐几个模型，也可以搜索它，并在下载任何东西之前，告诉你每个模型在这台电脑上会运行得怎么样。

### 为这台电脑推荐

在你搜索之前，**为这台电脑推荐**会按这台电脑的配置，列出应用推荐的、能在它上面运行的模型：

- **LFM3-VL 2B**（Liquid AI）：小巧快速，还能读图片。几乎任何电脑都能运行。
- **Gemma 4 12B**（Google）：能读图片的全能型模型，适合有一块好显卡的电脑。
- **Flint**（Recursive）：为编程智能体打造，适合搭载 Apple 芯片、内存 32 GB 或以上的 Mac。
- **GLM-5.3 Flash**（Z.ai）：最强的开放模型之一，适合装有多块大显卡的服务器。

每一项都会显示它在这里运行得好还是慢、会怎样运行（“vLLM，拆分到 2 块 GPU”“vLLM，在 Apple 芯片上”）、下载大小，以及**安装**。**本机最佳**标出运行得好的模型中最强的那一个。它们默认用 vLLM 运行；既没有 NVIDIA 显卡也没有 Apple 芯片的电脑，会改用那个小模型的 Ollama 版本。如果运行它们所需的程序还没设置好（“vLLM 未设置”“Ollama 未运行”），后面会有提示：见[连接 Ollama、vLLM 或其他端点](#connect-ollama-vllm-or-another-endpoint)。**另有 2 个适合更强的电脑**（或实际的数量）会显示其余的模型，以及每个需要什么。欢迎导览推荐的也是这几个。

### 搜索和筛选

1. 在 **搜索 Hugging Face，或粘贴 org/name** 中输入：一个名字，比如 `qwen3`，或者模型的全名（`org/name`），或者它在 huggingface.co 上的地址。在你输入之前，它会推荐几个名字，或者**查看下载最多的**。
2. 用筛选条件缩小列表（可以组合使用）：
   - **在这里运行流畅**：只显示在这台电脑上能运行流畅的模型。
   - **GGUF · Ollama**：GGUF 格式的模型，由 Ollama 运行。
   - **vLLM**：safetensors 格式的模型，由 vLLM 在显卡上运行。
   - **能看图片**：也能读图片的模型。
3. 用右边的菜单更改排序：**下载最多**、**热门**、**最受喜爱**或**最新**。

最多显示 40 个模型。你输入了全名的模型会排在最前面，即使搜索结果里没有它；按 Enter 会直接查看它。

每一行显示厂商和名称、它的格式（**GGUF** 或 **vLLM**）、能看图片的标有**图片**、厂商要求先接受条款的标有**受限**，还有它的参数规模、最近 30 天的下载量、点赞数，以及最近一次更新的时间。

### 初步判断

每个模型下面都有一个彩色标签，仅根据它的大小给出初步估计：

- **用 vLLM 运行流畅**或**用 Ollama 运行流畅**，并附上大致速度（“约 40 tokens/s”；一个 token 是一个词的一部分）：它能装进你显卡的显存。
- **用处理器运行，较慢**或**用处理器运行，非常慢**：它只能装进电脑的内存，所以要在处理器上运行。只有 Ollama 能这样做。
- **对这台电脑来说太大**：它装不下，或者下载的文件在磁盘上放不下。
- **用 Ollama 以 4-bit 运行：运行流畅…**：按原样存储的模型太大，但它压缩后的 4-bit 版本用 Ollama 可以运行流畅。

把鼠标悬停在标签上，可以看到背后的具体数字。

### 下载前先查看

点击模型上的**查看**，就能确切了解它在这里会怎样运行。面板会显示它的大小、一次能读多少内容（它的上下文）、能否看图片，然后是：

- 对于 GGUF 模型：“通过 Ollama 运行”，以及每个可用的大小（较小的文件会牺牲一点质量，换来速度并节省内存），从最小的开始。每一行都给出判断、所需内存、大致运行速度和下载大小，并带有**安装**按钮。当 Ollama 没有在这里运行，或者某个大小太大时，“安装”会变成灰色。
- 对于 vLLM 模型：“通过 vLLM 运行，会话用到它时，vLLM 会在 GPU 上启动它”，同样的各项数字、关于它会使用哪块显卡的说明，以及一个**下载**按钮。如果没有安装 vLLM，或者你的 vLLM 还不能运行这类模型，它会说明这一点；如果存在 GGUF 版本，它会改为提供**检查**那个版本。
- 其他情况：“没有本应用能运行的权重文件（vLLM 需要 safetensors，Ollama 需要 GGUF）。”

这些数字假设对话最长约 32,000 个 token，也就是这台电脑上的模型被分配的长度。**关闭**会收起面板。

### 安装，以及之后会发生什么

点击**安装**（Ollama）或**下载**（vLLM）。下载会显示在**在本机**下面，并显示进度。完成后，这个模型就会出现在 Custom 的**模型**菜单中。中断了的 vLLM 下载，在你重试时会从中断的地方继续。如果一个 vLLM 模型对任何一块显卡来说都太大，只要几块显卡加起来装得下，它启动时就会拆分到这几块显卡上。

### 受限模型和私有模型

有些厂商要求你先接受他们的条款；他们的模型会显示**受限**。在 huggingface.co 上该模型的页面接受条款，然后添加一个 Hugging Face 令牌（见 [Hugging Face 令牌](#hugging-face-token)）。私有模型也需要这个令牌。

## 通过 OpenRouter 使用模型

OpenRouter（openrouter.ai）让你用一个密钥使用来自众多厂商的数百个模型，按用量付费。

### 添加你的密钥

1. 在 openrouter.ai 获取一个密钥（这个部分有通往那里的链接）。
2. 在[设置 → 智能体 → 模型](/settings?s=models&find=OpenRouter)中，把它粘贴到 **你的 OpenRouter 密钥：sk-or-…** 中，然后点击**保存**。

之后这个部分会显示**已连接到 OpenRouter**，以及你密钥的开头和结尾。**移除**会忘掉这个密钥。密钥保存在服务器上，之后不会再完整显示。

### 推荐的模型

在你搜索之前，**推荐**会列出四个适合 Custom 的模型，并说明理由：**GPT-6 Luna**（快速又便宜）、**GLM 5.3**（不错，拒答更少）、**GPT-6.1 Sol**（更好）和 **Claude Opus 5.5**（综合最佳）。**添加**会把它放进选择列表。对于图片、音乐、语音和视频，应用的选择是 Seedream 5.0 Pro（以及更快、更便宜的 Flash）、Lyria 3 Pro、Seed Audio 1.0 和 Seedance 2.5：见[设置 → 能力 → 图片、视频和音频](/settings?s=images)。

### 搜索目录

在 **搜索 OpenRouter：deepseek、qwen、claude…** 中输入，或者点击一个推荐的名字，或者**查看最新的**。筛选条件：

- **工具调用**：原生支持调用工具的模型，这是 Custom 用起来效果最好的方式（“最佳匹配”会把这些排在前面）。
- **能看图片**
- **推理**：先思考再回答的模型。
- **免费**

右边的菜单决定结果的排序：**最佳匹配**（按名字搜索时）、**最新**、**最便宜**或**最长上下文**。最多显示 50 个模型。

每个模型都显示厂商、名称和标签：**最新**（始终是厂商的最新版本）、**新增**（最近三周内上架）、**免费**、**推理**、**图片**，以及**无原生工具**（这时 Custom 会在指令中描述它的工具，并从它的文字中读出它的调用）。下面是：一次能读多少内容（“128K 上下文”）、最长回复（“输出 16K”）、每百万输入和输出 token 的价格、上架的月份、一段简短描述，以及它在 OpenRouter 上的名字。

### 把模型加到选择列表中

点击模型上的**添加**。它那一行会显示**已添加**，这个模型会出现在这个部分顶部的**你的模型 · 显示在选择列表中**下面，以及 Custom 的**模型**菜单中。点击“你的模型”中某个模型上的 ×，就能把它从菜单中拿掉。在你添加至少一个模型之前，OpenRouter 不提供任何模型（“至少添加一个模型才能使用 OpenRouter。”）。

## 连接 Ollama、vLLM 或其他端点

**运行时和端点**部分用来连接运行模型的程序。在[设置 → 智能体 → 模型](/settings?s=models&find=Runtimes%20and%20endpoints)中打开它。

### Ollama

Ollama 是一个免费程序，可以在你的电脑上用显卡或处理器运行模型。这一行会显示“运行中”和它的版本，或者“此地址上未在运行”以及一个**安装 Ollama**链接。它的地址是 `http://127.0.0.1:11434`，除非你更改：输入另一个地址，然后点击**保存**。那个 Ollama 里的每个模型都会显示在 Custom 的模型列表中，包括你在应用之外拉取的模型。

### vLLM

vLLM 是一个在 NVIDIA 显卡上运行模型的快速服务器，也是这里运行 Hugging Face 模型的默认方式。一块显卡装不下的模型，会拆分到 2、4 或 8 块显卡上运行。在 Mac 上，vLLM 通过它的 Metal 插件（vllm-metal）在 Apple 芯片上运行。应用会自己在 PATH 中或 conda、venv 环境里找到它，并显示它的版本和位置。如果显示“未找到（pip install vllm），或填写它的命令”，就安装它，或者输入它的 `vllm` 命令的完整路径，然后点击**保存**。把这一栏留空，应用就会自己去找。

### 其他兼容 OpenAI 的端点

很多程序和服务的应答方式和 OpenAI 的 API 一样：LM Studio、llama.cpp 的服务器，以及其他提供商。添加方法：

1. 输入一个**名称**、它的地址（例如 `http://localhost:1234/v1`）和**密钥（可选）**。
2. 点击**添加**。

这个端点会显示它的地址和它提供多少个模型。它的模型以“模型（名称）”的形式出现在 Custom 的列表中。点 × 可以移除它。再添加一个同名的端点会替换掉前一个。

### Hugging Face 令牌

[Hugging Face 令牌](/settings?s=models&find=Hugging%20Face%20token)让应用可以下载受限或私有的模型（“仅用于受限或私有模型。”）。在你的 Hugging Face 账户设置中创建一个，粘贴到这一栏中（它以 `hf_` 开头），然后点击**保存**。之后这个部分会显示它的开头和结尾，并带有**移除**。
