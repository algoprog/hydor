# 空间和知识库

空间把一个项目集中在一起：它的会话、存放它文件的文件夹（以及它使用的你的其他文件夹）、它自己的文档、智能体记住的关于它的内容、其中每个智能体都遵循的准则、它自己的技能，以及它的会话开始时使用的助手。共享知识存放你只需添加一次的文档和文件夹，让每个会话都能搜索它们，并注明读到的文件和页码。本主题介绍如何创建和使用空间及空间组、如何给空间添加它自己的技能，以及如何添加、搜索和管理智能体会搜索的文档。

![空间页面：每个项目的会话、文档和准则都在一处](images/spaces.webp)

## 什么是空间

空间就是一个项目，连同属于它的一切，类似 ChatGPT 或 Claude 中的“项目”（Projects）。一份报税表、一篇论文、一个花园、一个网站：每一样都可以是一个空间。在开始页上，你按名称选择空间，而不是选文件夹；你在空间里启动的每个会话都会：

- **在空间的文件夹里工作**。智能体会被告知这个文件夹存放着空间的文件、里面现在有什么（最近改动的排在最前），并且要把为空间做的东西放在那里。它也会就地使用空间的其他文件夹：Claude Code 可以像在自己的文件夹里一样在其中工作，其他智能体会被告知它们在哪里；
- **遵循空间的准则**：空间里每个智能体都应该知道的事，例如这份工作是为谁做的、怎么做、要注意什么（见[智能体准则](/guide/guidelines)）；
- **获得空间自己的技能**，和你的技能库一起：说明这里的工作怎么做的书面方法，任务需要时智能体会加载它们（见[给空间添加它自己的技能](#give-a-space-skills-of-its-own)）；
- **开始时使用空间的助手**，如果空间设置了助手的话（见[助手](/guide/assistants)）；
- **记得空间里之前的会话学到的东西**：智能体按文件夹保存关于一个项目的笔记，所以同一个空间的会话会共享这些笔记（见[记忆](/guide/memory)）；
- **搜索空间自己的文档**，除非空间关闭了共享知识，否则也会搜索共享知识（见[哪些会话搜索哪些知识](#which-sessions-search-which-knowledge)）。

空间还可以把其他空间组合在一起。这就是**组**：见[把空间组合成组](#bring-spaces-together-in-a-group)。

## 打开空间页面

点击侧边栏底部工具中的**空间**。在手机上，先打开侧边栏：它是一个抽屉。你也可以在搜索框（Ctrl+K，Mac 上是 ⌘K）里输入“空间”。

页面有两个标签页：

- **所有空间**：你的空间，右上角有**新建空间**。
- **共享知识**：每个会话都能搜索的文档（见[共享知识：每个会话都能搜索的文档](#shared-knowledge-documents-every-session-can-search)）。

每个空间显示为一张卡片：

- 它的标志：一个空间颜色的圆角方块，里面是名称的第一个字（组的标志后面还叠着第二个方块）；
- 它的名称，名称下面是它的简介；没有简介时则显示它的文件夹。组会显示“组合了”以及它的各个空间的名称；
- 它有多少个会话、多少份文档，以及它的会话最近一次工作是多久以前。

点击卡片即可打开空间自己的页面；也可以在搜索框（Ctrl+K）里输入空间的名称，直接前往。还没有空间时，页面会说明空间是做什么用的；点击**新建空间**即可创建一个。

在空间下方，**你常用但还不属于任何空间的文件夹**列出了你的会话最近用过、可以做成空间的文件夹（见[你常用但还不属于任何空间的文件夹](#folders-you-work-in-not-in-a-space-yet)）。

## 创建空间

1. 在[空间页面](/spaces)上，点击**新建空间**。开始页的文件夹菜单里也有**新建空间**（见[在空间里启动会话](#start-a-session-in-a-space)）。
2. 填写窗口中的内容：
   - **名称**：你对这个项目的称呼，例如“2026 年报税”、“花园”或“毕业论文”。最多 60 个字符。这是唯一必须填写的字段。旁边的方块是空间的标志，显示它将得到的颜色：点击它可以从八种颜色（琥珀色、蓝色、绿色、粉色、紫色、青色、橙色、石板灰）中另选一种。如果你一个都不选，空间会轮流使用这些颜色。
   - **文件存放位置**：二选一。
     - **放在新文件夹中**（通常的选择）：应用会为空间建一个以它命名的专属文件夹。
     - **放在我已有的文件夹中**：这台电脑上的一个项目或文档文件夹，它会留在原处。下面的**最近使用过，尚未加入任何空间**会把你的会话最近工作过的文件夹列成一点即选的选项；也可以点击**选择文件夹…**，按名称找到文件夹或输入它的路径。如果选的时候名称还空着，文件夹的名称就会成为空间的名称。**修改**可以另选一个。
3. 需要的话，点击**更多选项**填写其余内容（旁边有圆点表示其中已经填了东西）：
   - **它是关于什么的**：显示在名称下面的一行说明。最多 300 个字符。
   - **智能体准则**：空间里每个智能体都应遵循的内容，例如这份工作是为谁做的、怎么做、要注意什么：“金额以欧元计。我在希腊是自雇人士。”最多 20,000 个字符。见[智能体准则](/guide/guidelines)。
   - **它使用的其他文件夹**：它的智能体可以就地使用的更多文件夹，什么都不会被复制。**添加文件夹**可以添加一个，最多 12 个；✕ 会再把某个文件夹移除。
4. 点击**创建空间**，或在名称字段中按 Enter。

新文件夹会放在任务文件夹所在位置的 **Spaces** 文件夹里：“Taxes 2026”会得到 `~/Naget/Spaces/taxes-2026`，除非你把任务文件夹移到了别处（见[移动任务文件夹](/guide/assistants#move-task-folders)）。如果这个名字已被占用，它会加上 `-2`、`-3` 等。从空间页面创建时，会打开新空间的页面。从开始页创建时，新空间会直接选好，供你即将启动的会话使用。

另外两样要在之后到空间的**设置**标签页里设置：它的会话开始时使用的助手，以及它组合的空间。它的文档放在它的**知识库**标签页里，它的技能放在它的**技能**标签页里，更多文件夹则放在它的**文件**标签页里。

### 为已有的文件夹创建空间

在**新建空间**窗口中，在**文件存放位置**下选择**放在我已有的文件夹中**，然后选择那个文件夹：空间会在其中工作，不会新建文件夹。智能体也能做到：“为 ~/code/shop 建一个叫 Shop 的空间”。空间创建后，它自己的文件夹就不能再更改，但它使用的文件夹可以：见[文件](#files)。

### 你常用但还不属于任何空间的文件夹

在[空间页面](/spaces)上你的空间下方，应用最多列出六个可以做成空间的文件夹：过去 90 天里你的会话在其中工作过、或在别处工作时修改过其中文件，而且还没有任何空间拥有的文件夹。用得最多、最近用过的排在前面。用 Git 管理的项目里的文件夹算作整个项目。每一行显示文件夹的名称、位置、用过它的会话数，以及最近一次使用的时间。

- **创建空间**会打开**新建空间**窗口，已选好这个文件夹并填好名称。
- ✕（**不是项目**）不再推荐这个文件夹。文件夹本身不受影响。

你的主文件夹、隐藏文件夹、临时文件夹，以及应用为自己建的文件夹（任务文件夹、应用的运行、工作树）永远不会被推荐。一旦某个空间拥有了一个文件夹（作为它自己的文件夹，或它使用的文件夹之一），这个文件夹就会从列表中消失。**新建空间**窗口里的**最近使用过，尚未加入任何空间**显示的也是这些文件夹。

## 在空间里启动会话

有两种方式：

- **从空间开始**：在空间的页面上，点击**新建会话**。开始页会打开，并已选好这个空间；如果空间设置了助手，也会选好它的助手。
- **从开始页开始**：打开消息框下方那一行里的文件夹标签。它的菜单先列出你的空间，然后是正在使用的文件夹和你最近用过的文件夹，最后是**新建任务文件夹**和**新建空间**。在你输入之前，它显示最近在工作的三个空间（以及当前选中的那个，如果它不在其中）。在顶部的字段里输入名称的一部分，就能找到任何空间或任何文件夹。每个空间都显示它的标志、名称和简介。

选好空间后，这个标签会显示空间的标志和名称，而不是文件夹，会话将在空间的文件夹里工作。如果空间的会话开始时使用某个助手，**助手**标签就会换成那个助手，并带上该助手建议的智能体、模型和权限。在开始之前，你仍然可以更改其中任何一项。然后输入你的消息，点击**开始**。

开始页会为你的下一个会话记住这个空间，无论你用哪台设备。要重新在空间之外工作，在同一个菜单里选一个文件夹或**新建任务文件夹**。如果你选过的空间被删除了，开始页会保留它的文件夹，但不再保留这个空间。

在手机上，这个菜单会以面板的形式从屏幕底部打开，标题为“工作所在的空间或文件夹”，键盘要等你轻点输入字段时才会弹出。

当空间的文件夹是一个 Git 仓库时，菜单末尾会提供**新建工作树**，和仓库里的任何文件夹一样：会话随后会在自己的分支上、在仓库的一份单独副本中工作（见[会话](/guide/sessions)）。在免提模式下用语音启动的会话，会在开始页上最后选中的空间里启动（见[文档、图片、视频和语音](/guide/documents-voice)）。

## 空间自己的页面

在空间页面上点击一个空间即可打开它。顶部是它的标志和名称、简介，以及两个按钮：**所有空间**返回列表（在手机上只显示它的箭头），**新建会话**在这个空间里启动一个会话。下面是五个标签页：**会话**、**文件**、**知识库**、**技能**和**设置**。**会话**、**知识库**和**技能**带有计数；在手机上，标签页不显示计数，好让它们都放得下。

### 会话

- **它的文件**会打开**文件**标签页。
- **智能体记住的内容**会打开[设置 → 记忆](/settings?s=memory)，智能体关于这个空间保存的笔记都列在它的文件夹下。
- 它们旁边是文件夹的路径。
- 下面是在这个空间里启动的会话，最近在工作的排在最前，每个都带有它的智能体图标、标题，以及上次工作是多久以前。点击一个即可打开。

还没有会话时，这个标签页会说明：**新建会话**会在这里启动一个会话，使用空间的文件夹、助手、准则和技能。

### 文件

空间的文件夹，以及它使用的其他文件夹，显示方式和[文件页面](/guide/files-git#browse-a-folder)显示文件夹一样：可以打开、多选、拖动、上传，每一行也都有菜单。文件会在页面上方的窗口中打开。

- 文件夹上方，每个文件夹都有一个标签：空间自己的文件夹以空间的名称显示，它使用的每个文件夹以各自的名称显示。点击一个即可显示它。
- **关联文件夹**会添加一个你的文件夹，让空间就地使用：按名称找到它或输入它的路径。什么都不会被复制。最多 12 个。
- 文件夹标签上的 ✕ 会把它从空间中移除；文件夹本身保持不变。随后的消息里有**撤销**。
- **在“文件”中打开**会在“文件”页面上打开这个文件夹。

要从别处添加文件，在“文件”页面、文件的窗口或智能体的文件卡片上使用**添加到空间**：文件会被复制到空间的文件夹中，文件夹则加入它使用的文件夹（见[把文件添加到空间](/guide/files-git#add-files-to-a-space)）。

### 知识库

空间自己的文档（只有它的会话会搜索），以及这些会话是否也搜索共享知识。见[给空间添加它自己的文档](#give-a-space-documents-of-its-own)。

### 技能

空间自己的技能，只有它的会话会获得，和你的技能库一起使用。见[给空间添加它自己的技能](#give-a-space-skills-of-its-own)。

### 设置

关于空间本身的一切：

- **名称**、**它是关于什么的**和**智能体准则**，和创建时一样。
- **它组合的空间**：在这里选择空间，就能把这个空间变成一个组（见[把空间组合成组](#bring-spaces-together-in-a-group)）。
- **它的会话开始时使用**：**开始页上选中的助手**（默认值：选择这个空间不会改变开始页上的助手），或你的任何一个助手，内置的或你自己的都行。这样，在开始页上选这个空间时，也会同时选上那个助手。
- 颜色圆点。
- **保存**（你改动了什么之后才会亮起），以及**删除空间**。

## 给空间添加它自己的技能

技能是书面的方法，任务需要时智能体会加载它们（见[技能](/guide/skills)）。你的技能库会提供给每个会话；空间还可以有自己的技能，只有它的会话才会获得：一步一步说明这里的工作怎么做。比如论文空间的“用 APA 7 格式引用，并检查每个 DOI”，或家庭食谱的“先列配料（以克计），再写编号的步骤”。它们在空间的**技能**标签页里。

还没有技能时，这个标签页会说明它们的用途，并有两个按钮：

- **新建技能**会打开一个有三个字段的窗口，填好后点击**添加技能**：
  - **名称**：用短横线连接的小写英文单词，例如 `citation-style`。离开这个字段时，空格和大写字母会自动变成这种形式。智能体按这个名称认识这个技能。
  - **何时使用**：一行字，例如“在论文中引用资料时使用”。智能体在空间的每个会话里都会看到这一行，只有任务合适时才会读取技能的其余部分。
  - **技能内容**：按顺序写出的步骤、检查项和要避免的错误，使用 Markdown。
- **从技能库中选**会列出你的技能库中空间还没有的技能，并带有一个字段，可以按名称或用途查找。输入之前显示八个，以及还有多少个。选一个：它会连同其他文件（示例、脚本）一起复制到空间中，并打开修改它的窗口。只为这个空间修改它：技能库中的那个对其他每个会话保持不变。

技能需要 2 到 64 个字符的名称、至少 10 个字符的何时使用说明，以及不止几个字的步骤；整个技能最多 20,000 个字符。看起来含有密码、密钥或令牌的技能会被拒绝：请改为写明秘密保存在哪里。

### 空间技能的列表

每个技能显示为一行：它的名称、何时使用、空间里（以及组合了它的组里）的智能体用过它多少次，以及多久以前保存的。与你技能库中某个技能同名的技能带有**替代技能库中的同名技能**标记：空间的会话会获得它，而不是技能库中的那个。

- 点击名称可以阅读技能及其更改的**历史**；那个窗口底部的**修改**可以编辑它。
- 铅笔图标用来修改它：名称、何时使用和内容。改名后，它的其他文件和历史都会保留。
- 垃圾桶图标会在你确认后移除它。空间的会话将不再看到它，或改回使用技能库中的同名技能。移除的技能列在列表下方的**已移除：**之后：点击一个即可按原样恢复。

**新建技能**和**从技能库中选**一直在列表下方。

### 智能体如何获得这些技能

在空间里启动的每个 Claude Code、Codex 和 Custom 会话都会获得它的技能，和你的技能库一起：Claude Code 在同一个名为“naget”的插件里（naget:citation-style），Codex 在同一个额外的技能文件夹里，Custom 在它的技能列表里。智能体还会被告知哪些技能是这个空间自己的，并在合适时使用。你添加或修改的技能，Custom 从下一轮开始就有；Claude Code 和 Codex 从下一个会话开始。

这些技能保存在应用的数据文件夹里，而不是空间的文件夹里，所以你的文件保持原样。组的会话还会获得它所组合的空间的技能（见[组里的会话能得到什么](#what-sessions-in-a-group-get)）。

### 智能体在空间里提议的技能

完成一项真正费力的任务后，智能体可以提议把它的做法保存为技能，或改进它所遵循的某个技能，由你批准、编辑或忽略（见[批准、编辑或忽略提议的技能](/guide/skills#approve-edit-or-dismiss-a-proposed-skill)）。会话在空间里时，卡片会在**保存给**下询问保存到哪里：

- **所有会话**：保存到你的技能库，和在空间外一样；
- 空间的名称：只保存到空间的技能中。如果是对技能库中某个技能的改进，空间会得到带有这项更改的自己的版本，技能库中的那个保持原样。

智能体会建议其中一个；你在批准前做出选择。对空间自己的技能的改进没有这个选择：它会留在空间里。

## 更改空间

打开空间，进入它的**设置**标签页，改你想改的内容，然后点击**保存**。此后你在这个空间里启动的会话会使用新的名称、简介和准则。新的助手会在你下次在开始页上选择这个空间，或在它的页面上点击**新建会话**时生效。空间的文件夹保持不变：它不能移到另一个文件夹。

## 删除空间

1. 打开空间，进入它的**设置**标签页。
2. 点击**删除空间**。
3. 应用会询问“删除空间 *名称*？”点击**删除**。

删除空间会保留其中的一切：

- **它的文件夹**以及里面的文件都留在原处，它使用过的文件夹也一样。
- **它的会话**会保留，只是不再属于任何空间。
- **它的文档**会移到共享知识里，从此每个会话都能搜索它们。要让它们保持独立，请把它们的知识库移到另一个空间（见[重命名、移动、重新读取或删除知识库](#rename-move-read-again-or-delete-a-knowledge-base)）。
- **它的技能**会移到你的技能库里，从此每个会话都会获得它们。如果技能库中已有同名技能，它会在自己的名称后加上空间的名称：名为 Thesis 的空间的 `research` 会变成 `research-thesis`。
- **智能体记住的内容**（关于它的文件夹）会保留：笔记属于文件夹，而不属于空间。
- 它会离开它所在的任何组。一个组如果它的空间都没了，就会变成普通空间。

## 把空间组合成组

组是一个把几个空间组合在一起的空间，用于横跨这些空间的工作：比如“论文相关的一切”组合了“毕业论文”和“读书笔记”。空间有的它都有：名称、自己的文件夹、准则、文档、技能和助手。它的会话还能使用它组合的每一个空间。

### 组里的会话能得到什么

- **各空间的文件夹**：Claude Code 可以像在自己的文件夹里一样在每个文件夹中工作；其他智能体会被告知每个文件夹在哪里。会话做出的东西放在组自己的文件夹里，除非你另有说明。
- **各空间的准则**：在组自己的准则之后，依次是每个空间的名称、简介、文件夹和准则。
- **各空间的文档**：与组自己的文档和共享知识一起搜索（除非组关闭了共享知识）。智能体会被告知每个知识库来自哪个空间。
- **各空间的技能**，和组自己的技能以及你的技能库一起。两个技能同名时，组自己的优先，然后是它最先组合进来的那个空间的。
- **记忆**来自组自己的文件夹。智能体在各个空间里保存的笔记仍然留在各自的空间。

### 创建组

1. 在[空间页面](/spaces)上，点击**把空间组合在一起**。至少有两个不是组的空间时，才会显示这张卡片。
2. 在**新建空间组**中，给它起一个**名称**，例如“工作”或“论文相关的一切”。
3. 在**它组合的空间**下，轻点每个要加入的空间；再点一次即可把它移出。至少选一个。
4. 可以选填**它是关于什么的**和**智能体准则**，并选一个颜色。
5. 点击**创建组**。和空间一样，它会得到一个自己的文件夹，用来存放在其中做出的东西，然后它的页面会打开。

你也可以把一个现有的空间变成组：在它的**设置**标签页上，在**它组合的空间**下选择空间，然后点击**保存**。更改组里的空间也是同样的方法。把它们全部移出，它就又变回普通空间。

组的**知识库**标签页还会显示**还包括它所组合的空间里的文档**：它的每个空间，以及每个空间有多少份文档。点击其中一个，即可打开那个空间的知识库标签页。它的**技能**标签页也会以同样的方式显示**还包括它所组合的空间里的技能**。

### 限制

- 组只组合普通空间，不组合其他组：组只有一层。已经在某个组里的空间，自己不能再组合其他空间；它的设置标签页会改为显示它在哪个组里。
- 一个空间可以在多个组里。
- 一个组最多组合 12 个空间。选满 12 个之后，其他空间就无法再点选。

## 在侧边栏只显示一个空间的会话

侧边栏为每个空间单独分一组，以空间的名字和标记为标题，列出它最新的会话；分组标题末尾的笔形按钮会在这个空间中新建会话。见[会话列表](/guide/start#the-session-list)。

若只想列出一个空间的会话：

1. 在侧边栏中，点击**搜索会话**字段末尾的筛选按钮（**筛选和分组会话**）。
2. 菜单会列出**所有智能体**、**Claude Code** 和 **Codex**，然后是**所有空间**、你的最多八个空间，以及打开空间页面的**空间**。选择一个空间。

然后会话列表只按天显示在那个空间里启动的会话；筛选生效期间，筛选按钮会带有颜色。选择**所有空间**即可重新看到所有会话。智能体筛选可以同时使用，只显示某个空间里某一个智能体的会话。如果这个空间被删除，列表会重新显示所有会话。

在手机上，先打开侧边栏（一个抽屉）。

## 共享知识：每个会话都能搜索的文档

智能体可以搜索你只需添加一次的文档：合同、手册、笔记、论文、整个文件夹。它们按字词或按含义查找段落，并注明读到的文件和页码。文档保存在**知识库**里：知识库是有名称的集合，由你拖入的文件和这台电脑上的文件夹组成。

- **共享知识**（[空间 → 共享知识](/knowledge)）：每个会话都会搜索它；空间里的会话也会，除非空间关闭了这一项。
- **空间自己的知识库**，在空间的**知识库**标签页上：只有那个空间的会话，以及组合了这个空间的组里的会话，才会搜索它。

要打开共享知识，点击空间页面上的**共享知识**标签页，或在搜索框（Ctrl+K）里输入“共享知识”。

## 添加文档

还没有共享知识时，页面会在一个用来拖入文档的大框上方显示“只需添加一次你的文档”。把文件或文件夹拖到那里，就会为它们创建一个名为“我的文档”的知识库。**改为从这台电脑上的文件夹开始**会创建一个空的“我的文档”知识库，然后你再往里面添加文件夹。

每个知识库都有自己的拖放框和自己的**添加这台电脑上的文件夹**按钮。要新建另一个知识库，点击页面顶部的**新建知识库**（手机上是**新增**）。分开的知识库能让内容互不混杂，智能体也可以按名称只搜索其中一个，不过一开始有一个就够了。

### 拖入或选择文件

把文档或文件夹拖到知识库的框上（“将文档或文件夹拖到这里”），或点击**选择文件**，或点击**文件夹**来选取整个文件夹。文件会被复制到应用的数据文件夹里，一放进去就会被读取，所以之后对原文件的改动不会影响知识库。一个小面板会显示上传情况。如果知识库里已经有同名文件，面板会询问是**替换**、**跳过已存在的**还是**取消**。

文件来自你正在使用的设备。在手机上，**选择文件**会打开手机的文件选择器；选取整个文件夹只在电脑上提供。

### 添加这台电脑上的文件夹

1. 在一个知识库上，点击**添加这台电脑上的文件夹**。
2. 在打开的菜单（“要读取并保持更新的文件夹”）中，输入文件夹的名称，从你最近用过的文件夹和你主文件夹里的文件夹中找到它，或者输入它的路径，例如 `~/Documents/Manuals`。选中它。

文件夹会在原处被读取：不会复制任何东西。它在知识库上显示为一个标签，知识库会随它保持更新。应用启动一分钟后，以及之后每隔一小时，应用都会读取文件夹中新增或改动的内容，并去掉已删除的内容。要立即读取，在知识库的菜单里选择**立即重新读取**。

“这台电脑”指的是运行 Naget Agent 的那台电脑，不一定是你面前的设备。

要停止读取某个文件夹，点击它标签上的 ×。它的文档会离开知识库；文件夹和其中的文件不受影响。

### 能读取哪些文件

- **文档**：PDF、Word、Excel、PowerPoint、OpenDocument、EPUB、CSV 和 RTF；如果这台电脑上安装了 LibreOffice，旧的 .doc、.xls 和 .ppt 文件也可以。
- **文本**：纯文本和 Markdown、网页（只取文字，不含标记），以及 JSON、YAML、Python 或 JavaScript 之类的代码和数据文件。

不会读取的有：图片；名称以点开头的文件和文件夹（隐藏的那些）；以及工具生成的文件夹，例如 `node_modules`、`.git`、`dist`、`build`、`target` 和 `venv`。一个文件夹最多读取 20,000 个文件、12 层深。超过 4 MB 的文本文件和超过 300 MB 的文档不会被读取。没有文字层的扫描版 PDF 没有可搜索的文字。

每份文档都会被切成最多约 1,400 个字符的段落，每个段落都会记下它来自哪一页、哪张幻灯片、哪个工作表或哪个标题，以便智能体引用。

## 查看知识库里有什么

每个知识库都是一张卡片。名称下面有一行，统计它包含的内容：文档和段落的数量、其中有多少已可按含义搜索（开启了按含义搜索时显示：“已可按含义搜索”，准备期间显示一个百分比），以及上次读取是多久以前。正在读取时，这一行以“正在读取第 12 个，共 40 个…”开头。

- **显示文档**会列出每份文档：它的名称或路径，然后是它有多少个段落以及它的大小。**无文本**标记里面没有可读内容的文档，**无法读取**标记读取失败的文档；把鼠标指向它可以看到原因。点击一份文档即可打开它。**隐藏文档**会收起列表。
- 当有些文档无法读取时，会有一行红字说明有多少份，并列出前几份及各自的原因。
- 你拖入的文件可以用它那一行末尾的 × 删除（在电脑上，鼠标指向那一行时才会显示）。这会删除知识库里的副本。来自这台电脑上某个文件夹的文档没有 ×：要从文件夹本身删除它，或者停止读取那个文件夹。

## 重命名、移动、重新读取或删除知识库

知识库右上角的 ⋯ 按钮（**更多**）会打开它的菜单：

- **立即重新读取**：立刻重新读取它的文件和文件夹，适用于刚添加的文件或有改动的文件夹。
- **重命名**：打开**重命名知识库**。输入新名称（最多 60 个字符），然后点击**保存**。
- **移到**：**共享知识**，或你的某个空间；勾号标出知识库当前所在的位置。放在空间里时，只有那个空间的会话会搜索它；放在共享知识里时，每个会话都会搜索它。有了空间之后才会显示这一项。
- **删除**：会询问“删除 *名称*？”它的段落会被删除，拖入其中的文件也会一起删除；这台电脑上的文件夹保持原样。点击**删除**继续。

## 给空间添加它自己的文档

打开空间，进入它的**知识库**标签页。

- **同时搜索共享知识**是一个开关，除非你关掉它，否则一直开启。关掉后，空间的会话只搜索空间自己的文档（如果是组，还包括它的各个空间的文档）。它下面的一行说明共享文档有多少份，并附有**共享知识**链接。
- 还没有文档时，把文档或文件夹拖进框里，或者选择它们：会为它们创建一个以空间命名的知识库。**改为从这台电脑上的文件夹开始**会创建一个以空间命名的空知识库，供你往里面添加文件夹。
- 有了文档之后，这个标签页会显示一个搜索框（见[自己试试搜索](#try-a-search-yourself)）、空间的知识库（卡片和菜单与共享的知识库相同），以及底部的**新建知识库**。

共享知识库可以通过它的菜单（**移到**）移进某个空间，也可以再移回来。

## 智能体如何搜索你的文档

只要至少有一个知识库，智能体就会得到一些工具：搜索它们的会话可以搜索的文档、阅读某个段落前后更多的内容，以及列出知识库里有什么。Claude Code、Codex、Custom，以及支持 ACP 并能接入 MCP 服务器（工具服务器）的智能体都会得到这些工具。

会话开始时，智能体会被告知它可以搜索哪些知识库，以及每个知识库有多少份文档；在空间里，还会被告知每个知识库是空间自己的、共享的，还是来自它的组所组合的某个空间。它会被要求：当问题可能从这些文档中找到答案时，先搜索它们，再去搜索网络或记忆；根据段落的内容作答；引用用到的每个段落，注明它的文件和页码或部分，以及路径；文档回答不了问题时要如实说明。

在对话中，一次搜索显示为一个步骤：**已搜索你的文档**、它找的是什么，以及找到了多少个段落，或者“未找到任何内容”。点击它可以看到这些段落，每个都附有文件、页码和知识库。点击一个段落即可打开文件。

### 按字词、按含义，或按精确文本

智能体有三种搜索方式：

- **按字词**：包含问题中词语的段落，最匹配的排在最前。始终可用。
- **按含义**：意思与问题所问相符的段落，即使用的是别的说法或另一种语言。这需要**按含义搜索**，在[设置 → 记忆](/settings?s=memory&find=Search%20by%20meaning)中开启。它在这台电脑上运行，开启后，每个知识库都会在后台为它做好准备（见[记忆](/guide/memory#search-by-meaning)）。关闭期间，共享知识标签页和每个空间的知识库标签页会告诉你在哪里开启它，智能体则按字词查找段落。
- **精确文本**：放在英文双引号里的短语（"通知期"）或两条斜杠之间的模式（正则表达式，例如 `/INV-\d+/`），像 grep 命令那样查找：适合名称、数字和代码。这些段落按它们在文档中出现的顺序排列。

除非智能体指定只用一种方式，否则它会同时按字词和按含义搜索；放在引号里或两条斜杠之间的问题会按精确文本搜索。它每次得到 8 个段落，除非它要求更多（最多 25 个），它也可以按名称只搜索某一个知识库。

### 自己试试搜索

在知识库上方，有一个字段写着“像智能体一样试试搜索：一个问题，或加引号的‘精确词语’”。输入内容后按 Enter。最多返回 10 个段落，每个都附有文件和页码、所属知识库，以及它是怎么找到的：**按字词匹配**、**按含义匹配**，或两者兼有；精确文本则是**按精确文本匹配**。点击一个即可打开文件。

在共享知识标签页上，它搜索的范围和不在任何空间里的会话一样。在空间的知识库标签页上，它搜索的范围和那个空间里的会话一样。

## 哪些会话搜索哪些知识

| 会话… | 搜索的内容 |
|---|---|
| 不在任何空间里 | 共享知识 |
| 在空间里 | 空间自己的文档，以及共享知识（除非空间关闭了它） |
| 在组里 | 组自己的文档、它组合的每个空间的文档，以及共享知识（除非组关闭了它） |
| 由另一个会话启动（子会话） | 启动它的那个会话所搜索的内容 |

知识库工具绝不会调出另一个空间的文档，即使智能体按路径请求某个文件也不会。所属空间已被删除的知识库会变成共享的。
