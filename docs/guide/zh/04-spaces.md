# 项目和知识库

项目把一项工作集中在一起：它的会话、存放它文件的文件夹（以及它使用的你的其他文件夹）、它自己的文档、智能体记住的关于它的内容、其中每个智能体都遵循的准则、它自己的技能，以及它的会话开始时使用的助手。共享知识存放你只需添加一次的文档和文件夹，让每个会话都能搜索它们，并注明读到的文件和页码。本主题介绍如何创建和使用项目及项目组、如何给项目添加它自己的技能，以及如何添加、搜索和管理智能体会搜索的文档。

![项目页面：每个项目一张卡片，显示它有什么，以及新建会话](images/spaces.webp)

## 什么是项目

项目就是一个项目，连同属于它的一切，类似 ChatGPT 或 Claude 中的“项目”（Projects）。一份报税表、一篇论文、一个花园、一个网站：每一样都可以是一个项目。在开始页上，你按名称选择项目，而不是选文件夹；你在项目里启动的每个会话都会：

- **在项目的文件夹里工作**。智能体会被告知这个文件夹存放着项目的文件、里面现在有什么（最近改动的排在最前），并且要把为项目做的东西放在那里。它也会就地使用项目的其他文件夹：Claude Code 可以像在自己的文件夹里一样在其中工作，其他智能体会被告知它们在哪里；
- **遵循项目的准则**：项目里每个智能体都应该知道的事，例如这份工作是为谁做的、怎么做、要注意什么（见[智能体准则](/guide/guidelines)）；
- **获得项目自己的技能**，和你的技能库一起：说明这里的工作怎么做的书面方法，任务需要时智能体会加载它们（见[给项目添加它自己的技能](#give-a-project-skills-of-its-own)）；
- **开始时使用项目的助手**，如果项目设置了助手的话（见[助手](/guide/assistants)）；
- **记得项目里之前的会话学到的东西**：智能体按文件夹保存关于一个项目的笔记，所以同一个项目的会话会共享这些笔记（见[记忆](/guide/memory)）；
- **搜索项目自己的文档**，除非项目关闭了共享知识，否则也会搜索共享知识（见[哪些会话搜索哪些知识](#which-sessions-search-which-knowledge)）。

项目还可以把其他项目组合在一起。这就是**组**：见[把项目组合成组](#bring-projects-together-in-a-group)。

## 打开项目页面

点击侧边栏底部工具中的**项目**。在手机上，先打开侧边栏：它是一个抽屉。你也可以在搜索框（Ctrl+K，Mac 上是 ⌘K）里输入“项目”。

页面有两个标签页：

- **所有项目**：你的项目，右上角有**新建项目**。
- **共享知识**：每个会话都能搜索的文档（见[共享知识：每个会话都能搜索的文档](#shared-knowledge-documents-every-session-can-search)）。

每个项目显示为一张卡片：

- 一条项目颜色的色带，上面是它的标志：一个项目颜色的圆角方块，里面是名称的第一个字（组的标志后面还叠着第二个方块，色带上还标着**组合**）；
- 它的名称，名称下面是它的简介；没有简介时则显示它的文件夹。组会显示“组合了”以及它的各个项目的名称；
- 它有什么：多少个会话、资料库中多少项内容、多少份文档和多少个技能；
- 它的会话最近一次工作是多久以前，以及**新建会话**，可以直接在其中启动一个会话。

点击卡片即可打开项目自己的页面；也可以在搜索框（Ctrl+K）里输入项目的名称，直接前往。还没有项目时，页面会分三小段说明项目是做什么用的，并提供**创建项目**。

在项目下方，**你常用的文件夹**列出了你的会话最近用过、可以做成项目的文件夹（见[你常用但还不属于任何项目的文件夹](#folders-you-work-in-not-in-a-project-yet)）。

## 创建项目

1. 在[项目页面](/spaces)上，点击**新建项目**。开始页的文件夹菜单里也有**新建项目**（见[在项目里启动会话](#start-a-session-in-a-project)）。
2. 填写窗口中的内容：
   - **名称**：你对这个项目的称呼，例如“2026 年报税”、“花园”或“毕业论文”。最多 60 个字符。这是唯一必须填写的字段。旁边的方块是项目的标志，显示它将得到的颜色：点击它可以从八种颜色（琥珀色、蓝色、绿色、粉色、紫色、青色、橙色、石板灰）中另选一种。如果你一个都不选，项目会轮流使用这些颜色。
   - **文件存放位置**：二选一。
     - **放在新文件夹中**（通常的选择）：应用会为项目建一个以它命名的专属文件夹。
     - **放在我已有的文件夹中**：这台电脑上的一个项目或文档文件夹，它会留在原处。下面的**最近使用过，尚未加入任何项目**会把你的会话最近工作过的文件夹列成一点即选的选项；也可以点击**选择文件夹…**，按名称找到文件夹或输入它的路径。如果选的时候名称还空着，文件夹的名称就会成为项目的名称。**修改**可以另选一个。
3. 需要的话，点击**更多选项**填写其余内容（旁边有圆点表示其中已经填了东西）：
   - **它是关于什么的**：显示在名称下面的一行说明。最多 300 个字符。
   - **智能体准则**：项目里每个智能体都应遵循的内容，例如这份工作是为谁做的、怎么做、要注意什么：“金额以欧元计。我在希腊是自雇人士。”最多 20,000 个字符。见[智能体准则](/guide/guidelines)。
   - **它使用的其他文件夹**：它的智能体可以就地使用的更多文件夹，什么都不会被复制。**添加文件夹**可以添加一个，最多 12 个；✕ 会再把某个文件夹移除。
4. 点击**创建项目**，或在名称字段中按 Enter。

新文件夹会放在任务文件夹所在位置的 **Projects** 文件夹里：“Taxes 2026”会得到 `~/Hydor/Projects/taxes-2026`，除非你把任务文件夹移到了别处（见[移动任务文件夹](/guide/assistants#move-task-folders)）。如果这个名字已被占用，它会加上 `-2`、`-3` 等。从项目页面创建时，会打开新项目的页面。从开始页创建时，新项目会直接选好，供你即将启动的会话使用。

另外两样要在之后到项目的**设置**标签页里设置：它的会话开始时使用的助手，以及它组合的项目。它的文档放在它的**知识库**标签页里，它的技能放在它的**技能**标签页里，更多文件夹则放在它的**文件**标签页里。

### 为已有的文件夹创建项目

在**新建项目**窗口中，在**文件存放位置**下选择**放在我已有的文件夹中**，然后选择那个文件夹：项目会在其中工作，不会新建文件夹。智能体也能做到：“为 ~/code/shop 建一个叫 Shop 的项目”。项目创建后，它自己的文件夹就不能再更改，但它使用的文件夹可以：见[文件](#files)。

### 你常用但还不属于任何项目的文件夹

在[项目页面](/spaces)上你的项目下方，应用最多列出六个可以做成项目的文件夹：过去 90 天里你的会话在其中工作过、或在别处工作时修改过其中文件，而且还没有任何项目拥有的文件夹。用得最多、最近用过的排在前面。用 Git 管理的项目里的文件夹算作整个项目。每张卡片显示文件夹的名称、位置、用过它的会话数，以及最近一次使用的时间。

- **创建项目**会打开**新建项目**窗口，已选好这个文件夹并填好名称。
- ✕（**不是项目**）不再推荐这个文件夹。文件夹本身不受影响。

你的主文件夹、隐藏文件夹、临时文件夹，以及应用为自己建的文件夹（任务文件夹、应用的运行、工作树）永远不会被推荐。一旦某个项目拥有了一个文件夹（作为它自己的文件夹，或它使用的文件夹之一），这个文件夹就会从列表中消失。**新建项目**窗口里的**最近使用过，尚未加入任何项目**显示的也是这些文件夹。

## 在项目里启动会话

有两种方式：

- **从项目开始**：在项目页面上它的卡片上，或在它自己页面的顶部，点击**新建会话**（在手机上点那支笔）。开始页会打开，并已选好这个项目；如果项目设置了助手，也会选好它的助手。
- **从开始页开始**：打开消息框下方那一行里的文件夹标签。它的菜单先列出你的项目，然后是正在使用的文件夹和你最近用过的文件夹，最后是**新建任务文件夹**和**新建项目**。在你输入之前，它显示最近在工作的三个项目（以及当前选中的那个，如果它不在其中）。在顶部的字段里输入名称的一部分，就能找到任何项目或任何文件夹。每个项目都显示它的标志、名称和简介。

选好项目后，这个标签会显示项目的标志和名称，而不是文件夹，会话将在项目的文件夹里工作。如果项目的会话开始时使用某个助手，**助手**标签就会换成那个助手，并带上该助手建议的智能体、模型和权限。在开始之前，你仍然可以更改其中任何一项。然后输入你的消息，点击**开始**。

开始页会为你的下一个会话记住这个项目，无论你用哪台设备。要重新在项目之外工作，在同一个菜单里选一个文件夹或**新建任务文件夹**。如果你选过的项目被删除了，开始页会保留它的文件夹，但不再保留这个项目。

在手机上，这个菜单会以面板的形式从屏幕底部打开，标题为“工作所在的项目或文件夹”，键盘要等你轻点输入字段时才会弹出。

当项目的文件夹是一个 Git 仓库时，菜单末尾会提供**新建工作树**，和仓库里的任何文件夹一样：会话随后会在自己的分支上、在仓库的一份单独副本中工作（见[会话](/guide/sessions)）。在免提模式下用语音启动的会话，会在开始页上最后选中的项目里启动（见[文档、图片、视频和语音](/guide/documents-voice)）。

## 项目自己的页面

在项目页面上点击一个项目即可打开它。页面顶部是这个项目的颜色：左边的箭头返回你的所有项目（和应用的其他页面一样），接着是项目的标志和名称，以及简介（组则显示它组合的项目；没有简介时显示它的文件夹）。右边，**新建会话**在这个项目里启动一个会话（在手机上点那支笔），**更多**（⋯）里有：

- **在“文件”中打开它的文件夹**：在文件页面上打开项目的文件夹。
- **侧边栏只显示它的会话**：会话列表只显示在这个项目里启动的会话，和侧边栏自己的筛选一样（见[在侧边栏只显示一个项目的会话](#show-one-projects-sessions-in-the-sidebar)）。再选一次即可重新看到所有会话。
- **删除项目**（见[删除项目](#delete-a-project)）。

下面是六个标签页：**概览**、**资料库**、**文件**、**知识库**、**技能**和**设置**。**资料库**、**知识库**和**技能**带有计数；在手机上，标签页不显示计数，好让它们都放得下。每个标签页都会立刻显示。

### 概览

一眼看清这个项目，分成几张卡片：

- **会话**：在这个项目里启动的会话，最近在工作的排在最前，每个都带有它的智能体图标、标题、运行时正在做什么（**工作中**、**需要你处理**、**就绪**；手机上不显示），以及上次工作是多久以前。点击一个即可打开。超过六个时，**全部**会显示其余的。还没有会话时，它会说明新会话会在项目的文件夹里工作，并带上它的准则、文档和技能，并提供**新建会话**。
- **在资料库中**：项目在资料库中的东西，最近更改的排在最前（见[资料库](#library)）。**在资料库中打开**会在那里显示它们。
- **这里的每个会话**（在旁边，手机上则在下方）：项目里每个会话都会得到的东西。**文件夹**（它的文件夹，以及它还使用多少个文件夹：点击转到**文件**标签页）、**准则**（它的准则的开头：点击转到**设置**）、**知识库**（它有多少份文档）、**技能**（它自己有多少个）、**开始时使用**（它的助手）和**记忆**（**智能体记住的关于它的内容**，会打开[设置 → 记忆](/settings?s=memory)，智能体关于这个项目保存的笔记都列在它的文件夹下）。
- **它组合的项目**（仅限组）：它的每个项目，以及各有多少个会话。点击一个即可打开。

### 资料库

项目在资料库中的所有东西：智能体在它的会话中保存的页面、幻灯片、文档、电子表格和 LaTeX 文档，以及你保留到这里或移到这里的东西（见[按项目整理](/guide/library#sort-it-by-project)）。点击每张卡片即可打开，它的**更多**（⋯）和在资料库中一样。**在资料库中打开**会在资料库中显示项目的东西，可以用资料库的搜索和类型筛选。还没有东西时，这个标签页会说明，并提供**新建页面**和**新建幻灯片**，在这个项目里制作。

### 文件

项目的文件夹，以及它使用的其他文件夹，显示方式和[文件页面](/guide/files-git#browse-a-folder)显示文件夹一样：可以打开、多选、拖动、上传，每一行也都有菜单。文件会在页面上方的窗口中打开。

- 文件夹上方，每个文件夹都有一个标签：项目自己的文件夹以项目的名称显示，它使用的每个文件夹以各自的名称显示。点击一个即可显示它。
- **关联文件夹**会添加一个你的文件夹，让项目就地使用：按名称找到它或输入它的路径。什么都不会被复制。最多 12 个。
- 文件夹标签上的 ✕ 会把它从项目中移除；文件夹本身保持不变。随后的消息里有**撤销**。
- **在“文件”中打开**会在“文件”页面上打开这个文件夹。

要从别处添加文件，在“文件”页面、文件的窗口或智能体的文件卡片上使用**添加到项目**：文件会被复制到项目的文件夹中，文件夹则加入它使用的文件夹（见[把文件添加到项目](/guide/files-git#add-files-to-a-project)）。

### 知识库

项目自己的文档（只有它的会话会搜索），以及这些会话是否也搜索共享知识。见[给项目添加它自己的文档](#give-a-project-documents-of-its-own)。

### 技能

项目自己的技能，只有它的会话会获得，和你的技能库一起使用。见[给项目添加它自己的技能](#give-a-project-skills-of-its-own)。

### 设置

关于项目本身的一切，分四部分，每部分都有一行说明它的用途：

- **项目**：它的**名称**（旁边是它的标志，显示所选的颜色）、**它是关于什么的**和**它的颜色**。
- **其中每个智能体遵循的准则**：它的**智能体准则**，和创建时一样。
- **它的会话如何开始**：在**它的会话开始时使用**下点选一项：**开始页上选中的助手**（默认值：选择这个项目不会改变开始页上的助手），或你的某个助手，内置的或你自己的都行。这样，在开始页上选这个项目时，也会同时选上那个助手。
- **它组合的项目**：在这里选择项目，就能把这个项目变成一个组（见[把项目组合成组](#bring-projects-together-in-a-group)）。

你改动了什么之后，会出现一条显示**未保存的更改**的栏，带有**撤销更改**和**保存**；滚动时它一直可见。底部的**删除项目**会说明哪些东西会保留，并带有它的按钮。

## 给项目添加它自己的技能

技能是书面的方法，任务需要时智能体会加载它们（见[技能](/guide/skills)）。你的技能库会提供给每个会话；项目还可以有自己的技能，只有它的会话才会获得：一步一步说明这里的工作怎么做。比如论文项目的“用 APA 7 格式引用，并检查每个 DOI”，或家庭食谱的“先列配料（以克计），再写编号的步骤”。它们在项目的**技能**标签页里。

还没有技能时，这个标签页会说明它们的用途，并有两个按钮：

- **新建技能**会打开一个有三个字段的窗口，填好后点击**添加技能**：
  - **名称**：用短横线连接的小写英文单词，例如 `citation-style`。离开这个字段时，空格和大写字母会自动变成这种形式。智能体按这个名称认识这个技能。
  - **何时使用**：一行字，例如“在论文中引用资料时使用”。智能体在项目的每个会话里都会看到这一行，只有任务合适时才会读取技能的其余部分。
  - **技能内容**：按顺序写出的步骤、检查项和要避免的错误，使用 Markdown。
- **从技能库中选**会列出你的技能库中项目还没有的技能，并带有一个字段，可以按名称或用途查找。输入之前显示八个，以及还有多少个。选一个：它会连同其他文件（示例、脚本）一起复制到项目中，并打开修改它的窗口。只为这个项目修改它：技能库中的那个对其他每个会话保持不变。

技能需要 2 到 64 个字符的名称、至少 10 个字符的何时使用说明，以及不止几个字的步骤；整个技能最多 20,000 个字符。看起来含有密码、密钥或令牌的技能会被拒绝：请改为写明秘密保存在哪里。

### 项目技能的列表

每个技能显示为一行：它的名称、何时使用、项目里（以及组合了它的组里）的智能体用过它多少次，以及多久以前保存的。与你技能库中某个技能同名的技能带有**替代技能库中的同名技能**标记：项目的会话会获得它，而不是技能库中的那个。

- 点击名称可以阅读技能及其更改的**历史**；那个窗口底部的**修改**可以编辑它。
- 铅笔图标用来修改它：名称、何时使用和内容。改名后，它的其他文件和历史都会保留。
- 垃圾桶图标会在你确认后移除它。项目的会话将不再看到它，或改回使用技能库中的同名技能。移除的技能列在列表下方的**已移除：**之后：点击一个即可按原样恢复。

**新建技能**和**从技能库中选**一直在列表下方。

### 智能体如何获得这些技能

在项目里启动的每个 Claude Code、Codex 和 Custom 会话都会获得它的技能，和你的技能库一起：Claude Code 在同一个名为“hydor”的插件里（hydor:citation-style），Codex 在同一个额外的技能文件夹里，Custom 在它的技能列表里。智能体还会被告知哪些技能是这个项目自己的，并在合适时使用。你添加或修改的技能，Custom 从下一轮开始就有；Claude Code 和 Codex 从下一个会话开始。

这些技能保存在应用的数据文件夹里，而不是项目的文件夹里，所以你的文件保持原样。组的会话还会获得它所组合的项目的技能（见[组里的会话能得到什么](#what-sessions-in-a-group-get)）。

### 智能体在项目里提议的技能

完成一项真正费力的任务后，智能体可以提议把它的做法保存为技能，或改进它所遵循的某个技能，由你批准、编辑或忽略（见[批准、编辑或忽略提议的技能](/guide/skills#approve-edit-or-dismiss-a-proposed-skill)）。会话在项目里时，卡片会在**保存给**下询问保存到哪里：

- **所有会话**：保存到你的技能库，和在项目外一样；
- 项目的名称：只保存到项目的技能中。如果是对技能库中某个技能的改进，项目会得到带有这项更改的自己的版本，技能库中的那个保持原样。

智能体会建议其中一个；你在批准前做出选择。对项目自己的技能的改进没有这个选择：它会留在项目里。

## 更改项目

打开项目，进入它的**设置**标签页，改你想改的内容，然后点击**保存**。此后你在这个项目里启动的会话会使用新的名称、简介和准则。新的助手会在你下次在开始页上选择这个项目，或在它的页面上点击**新建会话**时生效。项目的文件夹保持不变：它不能移到另一个文件夹。

## 删除项目

1. 打开项目，点击顶部的**更多**（⋯），或进入它的**设置**标签页。
2. 点击**删除项目**。
3. 应用会询问“删除项目 *名称*？”点击**删除**。

删除项目会保留其中的一切：

- **它的文件夹**以及里面的文件都留在原处，它使用过的文件夹也一样。
- **它的会话**会保留，只是不再属于任何项目。
- **它在资料库中的东西**会留在那里，不再属于任何项目。
- **它的文档**会移到共享知识里，从此每个会话都能搜索它们。要让它们保持独立，请把它们的知识库移到另一个项目（见[重命名、移动、重新读取或删除知识库](#rename-move-read-again-or-delete-a-knowledge-base)）。
- **它的技能**会移到你的技能库里，从此每个会话都会获得它们。如果技能库中已有同名技能，它会在自己的名称后加上项目的名称：名为 Thesis 的项目的 `research` 会变成 `research-thesis`。
- **智能体记住的内容**（关于它的文件夹）会保留：笔记属于文件夹，而不属于项目。
- 它会离开它所在的任何组。一个组如果它的项目都没了，就会变成普通项目。

## 把项目组合成组

组是一个把几个项目组合在一起的项目，用于横跨这些项目的工作：比如“论文相关的一切”组合了“毕业论文”和“读书笔记”。项目有的它都有：名称、自己的文件夹、准则、文档、技能和助手。它的会话还能使用它组合的每一个项目。

### 组里的会话能得到什么

- **各项目的文件夹**：Claude Code 可以像在自己的文件夹里一样在每个文件夹中工作；其他智能体会被告知每个文件夹在哪里。会话做出的东西放在组自己的文件夹里，除非你另有说明。
- **各项目的准则**：在组自己的准则之后，依次是每个项目的名称、简介、文件夹和准则。
- **各项目的文档**：与组自己的文档和共享知识一起搜索（除非组关闭了共享知识）。智能体会被告知每个知识库来自哪个项目。
- **各项目的技能**，和组自己的技能以及你的技能库一起。两个技能同名时，组自己的优先，然后是它最先组合进来的那个项目的。
- **记忆**来自组自己的文件夹。智能体在各个项目里保存的笔记仍然留在各自的项目。

### 创建组

1. 在[项目页面](/spaces)上，点击**把项目组合在一起**。至少有两个不是组的项目时，才会显示这张卡片。
2. 在**新建项目组**中，给它起一个**名称**，例如“工作”或“论文相关的一切”。
3. 在**它组合的项目**下，轻点每个要加入的项目；再点一次即可把它移出。至少选一个。
4. 可以选填**它是关于什么的**和**智能体准则**，并选一个颜色。
5. 点击**创建组**。和项目一样，它会得到一个自己的文件夹，用来存放在其中做出的东西，然后它的页面会打开。

你也可以把一个现有的项目变成组：在它的**设置**标签页上，在**它组合的项目**下选择项目，然后点击**保存**。更改组里的项目也是同样的方法。把它们全部移出，它就又变回普通项目。

组的**知识库**标签页还会显示**还包括它所组合的项目里的文档**：它的每个项目，以及每个项目有多少份文档。点击其中一个，即可打开那个项目的知识库标签页。它的**技能**标签页也会以同样的方式显示**还包括它所组合的项目里的技能**。

### 限制

- 组只组合普通项目，不组合其他组：组只有一层。已经在某个组里的项目，自己不能再组合其他项目；它的设置标签页会改为显示它在哪个组里。
- 一个项目可以在多个组里。
- 一个组最多组合 12 个项目。选满 12 个之后，其他项目就无法再点选。

## 在侧边栏只显示一个项目的会话

侧边栏为每个项目单独分一组，以项目的名字和标记为标题，列出它最新的会话；分组标题末尾的笔形按钮会在这个项目中新建会话。见[会话列表](/guide/start#the-session-list)。

若只想列出一个项目的会话：

1. 在侧边栏中，点击**搜索会话**字段末尾的筛选按钮（**筛选和分组会话**）。
2. 菜单会列出**所有智能体**、**Claude Code** 和 **Codex**，然后是**所有项目**、你的最多八个项目，以及打开项目页面的**项目**。选择一个项目。

然后会话列表只按天显示在那个项目里启动的会话；筛选生效期间，筛选按钮会带有颜色。选择**所有项目**即可重新看到所有会话。智能体筛选可以同时使用，只显示某个项目里某一个智能体的会话。如果这个项目被删除，列表会重新显示所有会话。

在项目自己的页面上，**更多**（⋯）→ **侧边栏只显示它的会话**也有同样的作用，开启时会带一个勾；再选一次即可重新看到所有会话。

在手机上，先打开侧边栏（一个抽屉）。

## 共享知识：每个会话都能搜索的文档

智能体可以搜索你只需添加一次的文档：合同、手册、笔记、论文、整个文件夹。它们按字词或按含义查找段落，并注明读到的文件和页码。文档保存在**知识库**里：知识库是有名称的集合，由你拖入的文件和这台电脑上的文件夹组成。

- **共享知识**（[项目 → 共享知识](/knowledge)）：每个会话都会搜索它；项目里的会话也会，除非项目关闭了这一项。
- **项目自己的知识库**，在项目的**知识库**标签页上：只有那个项目的会话，以及组合了这个项目的组里的会话，才会搜索它。

要打开共享知识，点击项目页面上的**共享知识**标签页，或在搜索框（Ctrl+K）里输入“共享知识”。

## 添加文档

还没有共享知识时，页面会在一个用来拖入文档的大框上方显示“只需添加一次你的文档”。把文件或文件夹拖到那里，就会为它们创建一个名为“我的文档”的知识库。**改为从这台电脑上的文件夹开始**会创建一个空的“我的文档”知识库，然后你再往里面添加文件夹。

每个知识库都有自己的拖放框和自己的**添加这台电脑上的文件夹**按钮。要新建另一个知识库，点击页面顶部的**新建知识库**（手机上是**新增**）。分开的知识库能让内容互不混杂，智能体也可以按名称只搜索其中一个，不过一开始有一个就够了。

### 拖入或选择文件

把文档或文件夹拖到知识库的框上（“将文档或文件夹拖到这里”），或点击**选择文件**，或点击**文件夹**来选取整个文件夹。文件会被复制到应用的数据文件夹里，一放进去就会被读取，所以之后对原文件的改动不会影响知识库。一个小面板会显示上传情况。如果知识库里已经有同名文件，面板会询问是**替换**、**跳过已存在的**还是**取消**。

文件来自你正在使用的设备。在手机上，**选择文件**会打开手机的文件选择器；选取整个文件夹只在电脑上提供。

### 添加这台电脑上的文件夹

1. 在一个知识库上，点击**添加这台电脑上的文件夹**。
2. 在打开的菜单（“要读取并保持更新的文件夹”）中，输入文件夹的名称，从你最近用过的文件夹和你主文件夹里的文件夹中找到它，或者输入它的路径，例如 `~/Documents/Manuals`。选中它。

文件夹会在原处被读取：不会复制任何东西。它在知识库上显示为一个标签，知识库会随它保持更新。应用启动一分钟后，以及之后每隔一小时，应用都会读取文件夹中新增或改动的内容，并去掉已删除的内容。要立即读取，在知识库的菜单里选择**立即重新读取**。

“这台电脑”指的是运行 Hydor 的那台电脑，不一定是你面前的设备。

要停止读取某个文件夹，点击它标签上的 ×。它的文档会离开知识库；文件夹和其中的文件不受影响。

### 能读取哪些文件

- **文档**：PDF、Word、Excel、PowerPoint、OpenDocument、EPUB、CSV 和 RTF；如果这台电脑上安装了 LibreOffice，旧的 .doc、.xls 和 .ppt 文件也可以。
- **文本**：纯文本和 Markdown、网页（只取文字，不含标记），以及 JSON、YAML、Python 或 JavaScript 之类的代码和数据文件。

不会读取的有：图片；名称以点开头的文件和文件夹（隐藏的那些）；以及工具生成的文件夹，例如 `node_modules`、`.git`、`dist`、`build`、`target` 和 `venv`。一个文件夹最多读取 20,000 个文件、12 层深。超过 4 MB 的文本文件和超过 300 MB 的文档不会被读取。没有文字层的扫描版 PDF 没有可搜索的文字。

每份文档都会被切成最多约 1,400 个字符的段落，每个段落都会记下它来自哪一页、哪张幻灯片、哪个工作表或哪个标题，以便智能体引用。

## 查看知识库里有什么

每个知识库都是一张卡片。名称下面有一行，统计它包含的内容：文档和段落的数量、其中有多少已可按含义搜索（开启了按含义搜索时显示：“已可按含义搜索”，准备期间显示一个百分比），以及上次读取是多久以前。正在读取时，这一行以“正在读取第 12 个，共 40 个…”开头。

- **显示文档**会列出每份文档：它的名称或路径，然后是它有多少个段落以及它的大小。**无文本**标记里面没有可读内容的文档，**无法读取**标记读取失败的文档；把鼠标指向它可以看到原因。点击一份文档即可打开它。**隐藏文档**会收起列表。
- 当有些文档无法读取时，会有一行红字说明有多少份，并列出前几份及各自的原因。
- 你拖入的文件可以用它那一行末尾的 × 删除（在电脑上，鼠标指向那一行时才会显示）。这会删除知识库里的副本。来自这台电脑上某个文件夹的文档没有 ×：要从文件夹本身删除它，或者停止读取那个文件夹。

## 重命名、移动、重新读取或删除知识库

知识库右上角的 ⋯ 按钮（**更多**）会打开它的菜单：

- **立即重新读取**：立刻重新读取它的文件和文件夹，适用于刚添加的文件或有改动的文件夹。
- **重命名**：打开**重命名知识库**。输入新名称（最多 60 个字符），然后点击**保存**。
- **移到**：**共享知识**，或你的某个项目；勾号标出知识库当前所在的位置。放在项目里时，只有那个项目的会话会搜索它；放在共享知识里时，每个会话都会搜索它。有了项目之后才会显示这一项。
- **删除**：会询问“删除 *名称*？”它的段落会被删除，拖入其中的文件也会一起删除；这台电脑上的文件夹保持原样。点击**删除**继续。

## 给项目添加它自己的文档

打开项目，进入它的**知识库**标签页。

- **同时搜索共享知识**是一个开关，除非你关掉它，否则一直开启。关掉后，项目的会话只搜索项目自己的文档（如果是组，还包括它的各个项目的文档）。它下面的一行说明共享文档有多少份，并附有**共享知识**链接。
- 还没有文档时，把文档或文件夹拖进框里，或者选择它们：会为它们创建一个以项目命名的知识库。**改为从这台电脑上的文件夹开始**会创建一个以项目命名的空知识库，供你往里面添加文件夹。
- 有了文档之后，这个标签页会显示一个搜索框（见[自己试试搜索](#try-a-search-yourself)）、项目的知识库（卡片和菜单与共享的知识库相同），以及底部的**新建知识库**。

共享知识库可以通过它的菜单（**移到**）移进某个项目，也可以再移回来。

## 智能体如何搜索你的文档

只要至少有一个知识库，智能体就会得到一些工具：搜索它们的会话可以搜索的文档、阅读某个段落前后更多的内容，以及列出知识库里有什么。Claude Code、Codex、Custom，以及支持 ACP 并能接入 MCP 服务器（工具服务器）的智能体都会得到这些工具。

会话开始时，智能体会被告知它可以搜索哪些知识库，以及每个知识库有多少份文档；在项目里，还会被告知每个知识库是项目自己的、共享的，还是来自它的组所组合的某个项目。它会被要求：当问题可能从这些文档中找到答案时，先搜索它们，再去搜索网络或记忆；根据段落的内容作答；引用用到的每个段落，注明它的文件和页码或部分，以及路径；文档回答不了问题时要如实说明。

在对话中，一次搜索显示为一个步骤：**已搜索你的文档**、它找的是什么，以及找到了多少个段落，或者“未找到任何内容”。点击它可以看到这些段落，每个都附有文件、页码和知识库。点击一个段落即可打开文件。

### 按字词、按含义，或按精确文本

智能体有三种搜索方式：

- **按字词**：包含问题中词语的段落，最匹配的排在最前。始终可用。
- **按含义**：意思与问题所问相符的段落，即使用的是别的说法或另一种语言。这需要**按含义搜索**，在[设置 → 记忆](/settings?s=memory&find=Search%20by%20meaning)中开启。它在这台电脑上运行，开启后，每个知识库都会在后台为它做好准备（见[记忆](/guide/memory#search-by-meaning)）。关闭期间，共享知识标签页和每个项目的知识库标签页会告诉你在哪里开启它，智能体则按字词查找段落。
- **精确文本**：放在英文双引号里的短语（"通知期"）或两条斜杠之间的模式（正则表达式，例如 `/INV-\d+/`），像 grep 命令那样查找：适合名称、数字和代码。这些段落按它们在文档中出现的顺序排列。

除非智能体指定只用一种方式，否则它会同时按字词和按含义搜索；放在引号里或两条斜杠之间的问题会按精确文本搜索。它每次得到 8 个段落，除非它要求更多（最多 25 个），它也可以按名称只搜索某一个知识库。

### 自己试试搜索

在知识库上方，有一个字段写着“像智能体一样试试搜索：一个问题，或加引号的‘精确词语’”。输入内容后按 Enter。最多返回 10 个段落，每个都附有文件和页码、所属知识库，以及它是怎么找到的：**按字词匹配**、**按含义匹配**，或两者兼有；精确文本则是**按精确文本匹配**。点击一个即可打开文件。

在共享知识标签页上，它搜索的范围和不在任何项目里的会话一样。在项目的知识库标签页上，它搜索的范围和那个项目里的会话一样。

## 哪些会话搜索哪些知识

| 会话… | 搜索的内容 |
|---|---|
| 不在任何项目里 | 共享知识 |
| 在项目里 | 项目自己的文档，以及共享知识（除非项目关闭了它） |
| 在组里 | 组自己的文档、它组合的每个项目的文档，以及共享知识（除非组关闭了它） |
| 由另一个会话启动（子会话） | 启动它的那个会话所搜索的内容 |

知识库工具绝不会调出另一个项目的文档，即使智能体按路径请求某个文件也不会。所属项目已被删除的知识库会变成共享的。

## 问问智能体

- “建一个叫‘2026 年报税’的项目，放我的收据和报税表。它的会话开始时要使用研究员助手，项目里的每个智能体都要知道金额以欧元计。”
- “为我在 ~/code/shop 的项目建一个叫 Shop 的项目。”
- “我的 Thesis 项目在资料库中有什么？把阅读跟踪表移进去。”
- “我最近在哪些还不属于任何项目的文件夹里工作过？为最常用的两个各建一个项目。”
- “把 ~/Downloads/contract.pdf 复制到我的‘2026 年报税’项目，并让它也使用 ~/Documents/Receipts。”
