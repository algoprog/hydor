# 插件

插件一次性为智能体带来某一类工作所需的一切：技能、工具、几行指令、它自己的文件，以及需要安装的东西。你开启的插件，应用启动的每个智能体都会获得：Claude Code、Codex、Custom 和其他智能体都一样。本主题介绍应用自带的插件、从链接、文件或文件夹添加其他插件、制作和分享你自己的插件，以及 Claude Code 和 Codex 自己的插件。

![设置 → 插件：你的插件，以及应用自带的插件](images/plugins.webp)

## 什么是插件

插件是一个文件夹，里面可以有：

- **技能**：智能体在任务需要时加载的成文方法。插件开启期间，它们会加入[技能库](/guide/skills)。
- **工具**：为智能体提供新能力的工具服务器（MCP 服务器），比如读取图片中的文字或查询数据库。服务器在这台电脑上运行，或者是位于某个地址的服务。
- **指令**：插件开启期间，加到每个智能体自己的指令中的几行文字。
- **它自己的文件**：它的技能和工具用到的数据、模板、图片或脚本。
- **它需要的东西**：其他插件、Python 或 Node 软件包、这台电脑上的程序、要下载的文件，以及你保险库中的密钥。

插件采用开放的 Agent Plugins 格式，其他工具（VS Code、Cursor、Codex、OpenHands…）也能读取这种格式。为 Claude Code 制作的插件也可以添加到这里：它们的技能和工具会提供给每个智能体。

## 打开插件页面

前往**设置 → 智能体 → 插件**（[打开](/settings?s=plugins)）。在手机上，先打开设置，再轻点“智能体”下的**插件**。

顶部有三个标签页：**所有智能体**（这个应用的插件，供每个智能体使用），以及 **Claude Code** 和 **Codex**（这两个智能体各自的插件：参见[Claude Code 和 Codex 自己的插件](#claude-codes-and-codexs-own-plugins)）。

在**所有智能体**下：

- 一个搜索框，以及**添加**，其中有**制作插件**、**让智能体帮你制作**、**来自链接**、**来自 .zip 文件**和**来自文件夹**；
- 添加或配置插件期间，它正在进行的各个步骤；
- **你的插件**：你添加的插件，每个都有开关；
- **应用自带**：还没添加的内置插件，每个都有**添加**。

每个插件显示它的名称和版本、用途、它带来的东西（“1 个技能 · 1 个工具服务器”），以及任何让它无法完全正常工作的问题：配置失败、缺少它需要的程序、某个密钥还没保存。点击插件即可打开它。

你也可以在搜索框（Ctrl+K，Mac 上是 ⌘K）中查找插件：它们显示在**插件**下。

## 添加应用自带的插件

1. 在**应用自带**下，点击它所在行的**添加**，或者打开它再点击**添加**。
2. 它的步骤会显示在页面顶部：先添加它，再配置它（安装它的软件包和下载内容）。准备好后它就会开启。

需要其他插件的插件会把它们一并带来：它们会先被添加，插件的页面会在你添加之前说明是哪些。

## 应用自带的插件

- **Audio and video**（音频和视频）：转换、剪辑、拼接、压缩和检查音频和视频，提取声音，统一播客的响度，缩短过长的停顿，按要保留的片段清单剪辑录音，制作竖屏短片、GIF 和缩略图，添加字幕，下载你有权下载的媒体。它需要这台电脑上有 ffmpeg（它的页面会说明如何获取），并会在它自己的环境中安装 yt-dlp。
- **Ebooks**（电子书）：读取 EPUB 的信息、目录和正文，用 Markdown 或 HTML 写的书稿制作带封面和目录的规范 EPUB，并在交给 Kindle、Apple Books 或 Kobo 之前检查或修复它。它会在自己的环境中安装所需的 Python 包；这台电脑上有 EPUBCheck 时，它还会运行各书店使用的那项检查，有 pandoc 时也能处理 Word 文件。
- **Library docs**（库文档）：来自 Context7 服务的编程库和框架的最新文档和代码示例，让智能体按你用的版本写代码。不会安装任何东西；问题会发送给 Context7。
- **Meeting recordings**（会议录音）：把会议、通话或采访的录音整理成笔记：摘要、决定、带负责人和日期的待办事项、未解决的问题和一封跟进邮件，每一条都附上说出它的时间点。它会一并带来 **Speech to text**。
- **Python for data**（Python 数据分析）：一个独立的 Python，带有 pandas、NumPy、SciPy、Matplotlib、openpyxl 和 PyArrow，用来分析表格和制作图表，不会往你自己的 Python 里安装任何东西。
- **Speech to text**（语音转文字）：在这台电脑上用 Whisper 把录音、语音备忘和视频转成文字和字幕，支持约 100 种语言。它会一并带来 **Audio and video**；它的模型在第一次用到时各下载一次。
- **SQLite databases**（SQLite 数据库）：用来查看 SQLite 数据库内部、安全地查询、一次性完成修改，以及在数据库和 CSV 文件之间导入导出数据的工具。它只需要 Python 3。
- **Text from pictures**（图片转文字）：在这台电脑上读取图片、文档照片、截图、收据和扫描版 PDF 中的文字。

## 打开插件

点击一个插件。它的窗口显示：

- 它的来源（**应用自带**、一个链接、一个文件、**在这里制作**或一个文件夹）、作者、许可证和网站；
- 添加之后，它的开关：**已为所有智能体开启**，或**关闭**；
- 它的用途；
- **它为智能体提供什么**：它的技能（以及每个技能何时使用）、它的工具服务器（每个运行什么，或位于哪里）和它的指令；以及哪些智能体会获得它；
- **它需要什么**，每一项都带有勾或叉：其他插件、Python 和 Node 软件包、要下载的文件、这台电脑上的程序（缺少时会说明如何获取），以及密钥（还没保存的密钥带有**添加**）；
- 它自己的文件、它的文件夹中的问题（如果有），以及**关于它**：它自己的说明；
- 对于你添加的插件，还有它的文件夹和它的数据文件夹。

你添加的插件在底部有一个 **⋯** 菜单：**确认修改**（适用于你制作的插件，或从文件夹使用的插件）、**获取最新版本**（适用于来自链接的插件）、**重新配置**、**打包成 .zip**、**显示它的文件夹**和**移除**。

## 插件需要的东西及其配置

当插件需要软件包或下载内容时，添加它会在它自己的数据文件夹中把这些配置好，绝不会为整台电脑安装：

- Python 软件包装进它自己的 Python 环境（这台电脑上有 uv 时用 uv 创建，否则用 Python 自带的工具）。
- Node 软件包装进它自己的文件夹，安装时不运行它们的安装脚本。
- 文件下载到它的数据文件夹中；如果插件给出了文件的指纹，还会用指纹核对。

智能体会被告知它的 Python、软件包和文件在哪里，它的工具服务器也会优先找到它们。插件配置完成后，它的工具才会提供给智能体。

如果配置失败，插件所在的行会注明；它的窗口会显示原因，并提供**重试**，**显示它的输出**会显示完整的输出。当插件需要的东西发生变化（应用更新，或插件更新）时，它会重新配置：内置插件会自动重新配置，其他插件则在你点击**重新配置**时进行。

它需要的程序（比如 ffmpeg）不会替你安装：缺少的程序会显示出来，并说明如何获取。它需要的密钥按名称从你的保险库中获取：在[应用 → 已连接的应用 → 密钥](/apps/connected?tab=keys)中添加。它的工具服务器会获得这个密钥；智能体永远看不到它。

## 开启或关闭插件

使用它所在行或它窗口中的开关。关闭后，智能体从下一个会话起将不再获得它的技能、工具和指令；它仍保持已添加的状态，配置也会保留，可以随时重新开启。

- 关闭一个其他插件需要的插件，也会关闭那些插件：应用会先询问你，并说出它们的名称。
- 开启一个插件，也会开启它需要的插件。

## 从链接、文件或文件夹添加插件

1. 点击**添加**，然后点**来自链接**、**来自 .zip 文件**或**来自文件夹**。
2. 提供：
   - **来自链接**：一个存放插件的 Git 仓库，可以写成 owner/repo（GitHub 上的仓库）或它的地址，或者是指向插件在 GitHub 上的文件夹的链接。**指定分支，或仓库里的某个文件夹…** 可以填写分支或标签，以及文件夹。
   - **来自 .zip 文件**：打包成 .zip 的插件，在这里或在别处打包的都可以。选择它，或把它拖到框里。
   - **来自文件夹**：这台电脑上的一个文件夹。插件就在原处使用：在它的文件夹中所做的更改会进入新的会话，适合正在制作中的插件。
3. 点击**查看**。你会看到插件为智能体提供什么、需要什么、会一并带来哪些内置插件，以及它需要但应用没有的插件（这时要先添加那些插件，才能添加它）。
4. 点击**添加**（如果这里已有同名的插件，则是**替换**；它的数据会保留）。

配置期间会显示它的步骤。与内置插件同名的插件无法添加：请在它的 plugin.json 中给它改名。

## 制作你自己的插件

1. 点击**添加**，然后点**制作插件**。
2. 给它一个**名称**和用途，然后点击**创建**。它会被添加并开启，同时打开它的编辑器。
3. 填写它的各个标签页，然后点击**保存**：
   - **关于**：显示的名称、版本（分享新版本时调高它）、用途、所属组合和图片。
   - **技能**：**编写技能**（它的名称、组合、何时使用和指令），或从你的技能中**复制你的技能**。点击某个技能可以修改它。
   - **工具**：**添加工具服务器**：**本机程序**（要启动的程序、每行一个的参数，以及写成 NAME=value 行的环境变量），或**网络地址**（MCP 服务器的地址和请求头）。用 `${PLUGIN_ROOT}` 表示插件的文件夹，用 `${PLUGIN_DATA}` 表示它的数据文件夹：比如，服务器的参数可以写成 `${PLUGIN_ROOT}/files/server.py`。
   - **依赖**：Python 软件包、Node 软件包、程序、密钥、其他插件和要下载的文件，每行一个。
   - **文件**：**添加文件**把文件放进插件（每个最大 50 MB，总共最多 200 MB）；垃圾桶图标可以删除文件。文件会立即添加或删除，不需要点**保存**。
   - **指令**：插件开启期间每个智能体都会获得的几行文字。

保存时会先检查所有内容：技能必须说明何时使用，工具服务器的程序必须是一个程序（而不是一行 shell 命令），等等；应用会告诉你要改什么。如果它的软件包有变化，它会重新配置。

你制作的插件保存在应用的数据文件夹中（plugins/mine）。以后要修改，打开它，在它的 **⋯** 菜单中选择**确认修改**。

**让智能体帮你制作** 会打开一个新会话，消息框里已经写好了请求的开头（“Help me make a plugin for Hydor that…”，意思是“帮我为 Hydor 做一个插件，用来…”）：说出它要做什么，智能体会编写插件、检查它，并在你同意后从它的文件夹添加它。

## 分享插件

- **作为文件**：打开插件，然后点 **⋯ → 打包成 .zip**（或在它的编辑器中点**打包成 .zip**）。任何人都可以用 **添加 → 来自 .zip 文件** 添加它。它的配置不会被打包：在添加它的地方会重新配置。
- **作为链接**：把它的文件夹放进一个 Git 仓库（比如放到 GitHub 上）。任何人都可以用 **添加 → 来自链接** 添加它，并用**获取最新版本**获得你的新版本。

其他读取 Agent Plugins 格式的工具也能使用它的技能和工具服务器；只有这个应用读取的部分（它需要的东西、它的指令）保存在它的 `com.naget.agent` 部分中，其他工具会跳过这一部分。

## 更新或移除插件

- 内置插件随应用一起更新。
- 来自链接的插件：**⋯ → 获取最新版本** 会重新下载它，如果它需要的东西有变化，还会重新配置。
- 来自 .zip 文件的插件：添加更新的文件；它会替换旧的。
- 来自文件夹的插件：文件夹中的更改会自动进入新的会话。

要移除一个插件：点 **⋯ → 移除**，然后确认。需要它的插件也会被移除（应用会先说出它们的名称）。它的软件包和下载的文件会被删除。你在这里制作的插件会连同它的文件夹一起删除：要保留副本，请先把它打包成 .zip。从你的某个文件夹使用的插件会留在它的文件夹中。

## 哪些智能体获得插件

应用启动的每个会话都会获得这样的插件：已开启、已配置好，并且它需要的插件也都已开启。会话获得：

- 它们的**技能**，通过技能库提供，和其他技能一样（参见[哪些智能体获得哪些技能](/guide/skills#which-agents-get-which-skills)）。名称与技能库中已有技能相同的技能会被略去：插件的窗口会说明智能体改用哪个技能；
- 它们的**工具服务器**，作为 MCP 服务器提供，在插件的文件夹中启动，使用插件自己的软件包；
- 它们的**指令**，附带一行说明它们的软件包和文件在哪里。

插件可以只适用于部分智能体；它的窗口会说明是哪些。已经在运行的会话会在下次启动时获得插件的更改。

## Claude Code 和 Codex 自己的插件

Claude Code 和 Codex 有它们自己的插件，来自它们的市场，只有它们自己使用。它们在插件页面上各有一个标签页：

- **Claude Code**：**已安装**（每个都有开关和**卸载**）、**浏览**（搜索市场，安装最多的排在前面，可以**安装**）以及**市场**（通过 owner/repo、Git 地址或文件夹添加市场；或移除市场）。
- **Codex**：**已添加到 Codex**（每个都有**移除**）、**查找更多**（搜索 Codex 的市场，可以**添加**）以及**市场**（添加、**刷新**或移除市场）。

它们的技能显示在技能页面上，归在该智能体自己的技能下。要让每个智能体都能使用某个 Claude Code 插件，用 **添加 → 来自链接** 把它添加到这个应用的插件中。

## 插件与安全

插件的工具服务器会以你的身份在这台电脑上运行程序，每个智能体都会获得它的指令。只添加你信任的人提供的插件，并在添加之前看看插件提供什么、需要什么：应用会在安装任何东西之前把这些显示出来。应用自带的插件是和应用一起制作并检查过的。

密钥绝不放进插件：插件只写明它需要的密钥，它的服务器在运行时从你的保险库中获得它们。
