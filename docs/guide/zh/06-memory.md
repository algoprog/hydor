# 记忆

Hydor 中的智能体会把重要的事情从一个会话记到下一个会话：关于你的事实、关于每个项目的事实、某项任务进行到了哪一步，以及每个智能体开始时都会拿到的一份你的档案。本主题介绍它们记住什么、什么时候记，你的档案，智能体开始时带着什么，如何查看、更正或撤销已保存的内容，以及“设置 → 记忆”中的所有内容，包括按含义搜索和自动进行的整理。用好记忆，智能体就不会把同样的事问两遍，你也能随时知道它们知道些什么。

![设置 → 记忆：智能体记住的关于你和你项目的事](images/memory.webp)

## 智能体记住什么

记忆是一组简短的笔记，叫作记忆笔记。每条一两句话，最多 500 个字符。应用运行的所有智能体都共享这些笔记：Claude Code、Codex、Custom，以及使用 ACP 的智能体，例如 Gemini CLI。在应用运行的会话中，Claude Code 和 Codex 自己的记忆功能保持关闭，所以这些笔记是它们共享的唯一一份记忆，它们记下的一切你都能看到，也都能撤销。每条笔记属于以下三个位置之一：

- **关于你**：关于你的长期事实和偏好（“偏好公制单位”“喜欢简短的回答”“主要用 Python 工作”）。每个会话都会得到这些笔记。
- **某个项目**：关于某一个项目的事实，比如它的惯例、构建和测试它的命令、各种东西放在哪里，以及已做的决定。项目就是会话工作所在的文件夹：如果它在某个 Git 仓库中，就是仓库的顶层文件夹，否则就是这个文件夹本身。工作树（仓库在自己分支上的一份独立副本）与主仓库共享笔记，所以每个分支上的会话看到的都是同一批笔记。直接在你主文件夹中进行的会话没有项目笔记：它只得到关于你的笔记和它自己的笔记。
- **某个会话**：某项任务进行到哪一步，供该会话继续时接上。会话被删除时，这些笔记也随之删除。

一个会话只能看到和修改三组笔记：关于你的、它所在项目的，以及它自己的。在一个项目中工作的智能体永远看不到另一个项目的笔记。一个[项目](/guide/projects)中的会话都在该项目的文件夹中工作，因此共享它的项目笔记。获得了自己新文件夹的任务（见[智能体](/guide/agents)），就以那个文件夹作为它的项目。

当某个位置的笔记变多后，那里还会出现更多种条目：**主题**，每个主题汇总一组相关的笔记；对于项目，还有**档案**，一份智能体总是最先拿到的简短概要。它们由整理写出（见[自动整理](/guide/memory#tidy-up-automatically)），整理还会给每条笔记和每个主题写一个简短的标题，用于智能体开始时拿到的索引。你自己的档案则是另一回事：由你和你的智能体来写（见[你的档案](/guide/memory#your-profile)）。

记忆只在本应用运行的会话中起作用，对它只是列出的会话无效，比如在终端或 VS Code 中打开的会话。

## 笔记是怎样写下的

智能体在两种情况下保存笔记：你要求时（“记住我吃素”“记住测试服务器是 test.example.com”），或者它们了解到之后的会话自己查不出来的长期信息时：你想要什么、一个决定及其原因、一个坑、一条吃过亏才学到的规则。每次回复之后不会自动写入任何东西：笔记只来自智能体主动选择保存、你自己写下或编辑的笔记，以及整理；整理会重新加工已有的笔记，开启[从对话中学习](/guide/memory#learn-from-conversations)后，每天还会留下最多三件没有智能体保存过的事。

- **由智能体选择位置**：关于你、这个项目，或这个会话。
- **一条笔记只写一件事，并写得以后找得到**：每条笔记用一句能独立成立的话说一件事，写明它关于什么（项目、工具、人或地点），这样以后换个说法提出的请求也能找到它。每个智能体都应该一直知道的关于你的事，则写进你的档案。项目的文件或历史中已经写明的事则不写：代码在哪里、做什么都会变，而且文件本来就会说明。
- **如何得知**：智能体会说明它是怎样知道所保存的内容的：你说过，它核验过（一次测试、一条命令的输出、一个文件），或者那是它自己的结论，尚未核验。之后的智能体会被告知哪些笔记尚未核验，整理时也会优先核验这些笔记。你自己写的笔记算作你说过。
- **有些笔记只在某个日期前有效**：一次旅行、一个截止日期、一次拜访。智能体会给这类笔记设一个结束日期。从那以后，智能体就不会再拿到它，并且在一小时内它会被移到“已删除的笔记”，30 天内你都可以从那里恢复。
- **更正会替换旧笔记**：要更新一条笔记时，智能体会按它的编号改写，而不是再添一条。内容完全相同的笔记不会保存两次。开启[按含义搜索](/guide/memory#search-by-meaning)后，换个说法表达同一件事的笔记也不会重复保存。
- **智能体也会遗忘**：当一条笔记被证明是错的或过时了，或者你提出要求时（“忘掉我的旧地址”），智能体会删除它。
- **绝不保存机密**：看起来含有密码、密钥、令牌或卡号的笔记会被拒绝。读起来像是给智能体下指令的文字（“忽略之前的指令…”）也会被拒绝，因为它会传到之后的每一个会话中。

你也可以在[设置 → 记忆](/settings?s=memory&find=Add%20a%20note)中用**添加笔记**自己写一条笔记，并在那里查找、编辑每条笔记、给它设日期或删除它（见[备注](/guide/memory#notes)）。

## 你的档案

除了笔记，记忆还为你保留一份档案：你是谁、做什么，用什么，喜欢怎样的回答，以及要避免什么。记忆开启时，每个智能体都会在会话开始时拿到它一次，紧接在你的[智能体准则](/guide/guidelines)之后，并让它影响自己与你合作的方式；你的准则和你在会话中说的话仍然优先。笔记记的是时不时用得上的事；档案记的是每个智能体都应该一直知道的事。

- **智能体让它保持最新。** 当你说的话透露出某件长期有用、能帮助每个智能体更好地为你服务的事，比如你的工作、你用的工具或你喜欢的回复方式，智能体就会把它写进档案。大多数消息不会带来任何改动。改动会以**你的档案**显示在它的回复下方，并可撤销（见[查看智能体在回复后保存了什么](/guide/memory#see-what-an-agent-saved-after-a-reply)）。智能体绝不会把机密写进档案，不能清除它，也不能覆盖在它的会话开始之后做出的改动：它会看到档案现在的样子，然后重新改。
- **自己来写。** 在[设置 → 记忆](/settings?s=memory&find=Your%20profile)中，第一组**你的档案**会显示它的六行，更长时有**全部显示**（和**收起**）。组标题旁的**编辑**（还没有档案时为**自己写**）会打开它来编写：Enter 换行，Ctrl+Enter（Mac 上为 ⌘+Enter）或**保存**会保存，Escape 或**取消**则保持原样。写的时候，会有一个计数显示它有多少个词、最多可以有多少个。
- **可以有多长。** [档案长度](/settings?s=memory&find=Profile%20length)在页面更下面的**智能体得到什么**组里，是它最多可有的词数：250、500、1,000（通常）或 2,000 个词。智能体会让它保持在这个范围内。更长的档案，无论是你保存的，还是你选了更短的长度后留下的，都会先按原样保留，同时辅助模型在后台把它缩短到限额以内（“正在缩短到 1,000 个词以内…”）；缩短后的版本会显示为由**辅助模型**修改。辅助模型做不到时，会在档案下方显示原因和**重试**。
- **下方**：它有多少个词、最多可以有多少个，以及它何时写下或最近一次何时修改、由谁修改：**你**、**某个智能体**（附上它所在的会话）或**辅助模型**。**编辑**旁的 **⋯**（档案菜单）中有**更改历史**，列出每个版本以及是谁写的、为什么写，还有**清除档案**，会先询问。清除的档案会在[已删除的笔记](/guide/memory#deleted-notes)中保留 30 天，在那里用**恢复**即可找回。

## 查看智能体在回复后保存了什么

当智能体在一轮对话中保存、修改或删除笔记时，它的回复下方会出现一个标签，例如**记忆 · 1 条已添加，1 条已更新**。它统计仍然有效的更改（添加、更新、删除）；如果所有更改都被撤销了，它会显示**已撤销**。同一轮中的多处更改显示为一个标签，同一条笔记被改了好几次时也只算一次更改，展示从改之前到改之后的内容。

点击标签即可展开。每处更改会显示：

- 一个标记：**已添加**、**已更新**、**已移除**或**已撤销**。
- 笔记属于哪里（**关于你**、**项目 ·** 加文件夹名称、**此会话**或**另一个会话**；对档案的改动则显示**你的档案**）、“由智能体保存”，以及它在那一轮中经历了几次更改。
- 笔记的文字。对于更新，删掉的字词会加删除线，新加的字词会被标出。如果大部分内容都被改写了，旧文字会加上删除线显示在新文字上方。
- **此后又有改动**：在这一轮之后笔记又被编辑过时显示；点击可以查看它现在的内容。
- 最后一行是智能体给出的理由（如果有的话）；如果笔记在这一轮之后被删除或抹除，还会显示**后来已删除**或**已不再保留**。

每处更改上的按钮：

- **撤销此更改**（或**撤销这些更改**）：添加的笔记会被去掉，更新过的笔记恢复原来的文字，删除的笔记会回来。
- **编辑**：直接在原处修改文字。Enter 保存，Shift+Enter 换行，Escape 取消。对于你的档案，它会打开“设置 → 记忆”，那里有足够的地方分行显示档案。
- **删除**：删除这条笔记。它会在设置的“已删除的笔记”中保留 30 天。你的档案在这里没有删除按钮：请在设置中清除它。
- **恢复**：找回之后被删除的笔记。

展开的标签顶部有一个 **⋯**（记忆选项），其中有**此会话的记忆**，用于为这个会话关闭或开启记忆，以及**全部记忆**，用于打开“设置 → 记忆”。点击标签的顶行可以把它收起。

## 智能体开始时带着什么

每个智能体开始时都会拿到一段关于记忆的简短说明、你的档案、所记内容的索引，以及与你的请求相关的笔记，只给一次：

- **何时**：Claude Code 和 Codex 在开始时的指令中拿到说明、档案、笔记不多的位置的笔记和索引，与你的请求相关的笔记则随你的第一条消息拿到。在项目的笔记变化之前，这些指令对该项目的每个会话都相同，所以模型的提供方可以在会话之间重用它已留存的内容，既更快，也更省钱。使用 ACP 的智能体随你的第一条消息拿到全部内容。[Custom](/guide/custom) 随你的第一条消息拿到，并在工作期间一直保留：只有在压缩很长的对话时，它才会针对你最新的消息再读一次记忆。一小时内继续的会话（比如在应用重启之后）会再拿到同样的指令，以及它自己的笔记和与你最新消息相关的笔记，这样模型的提供方就能重用它已留存的对话内容。
- **哪些**：你的档案（见[你的档案](/guide/memory#your-profile)）；这个项目的档案（如果有的话）；这个会话自己的笔记（会话继续时）；笔记不多的位置（关于你或某个项目，还没有主题）中的每一条笔记；以及从笔记较多的位置中，与你的请求相关的笔记和主题，最多 10 条，可以用[每个智能体开始时获得的笔记](/settings?s=memory&find=Notes%20each%20agent%20starts%20with)更改。不会只为了凑满数量而多给：相关的较少时，智能体拿到的也较少。已经给出的主题所汇总的笔记会被略去。
- **索引**：对于每个笔记较多的位置，智能体还会拿到其笔记和主题的标题（Custom：没有给它的那些），这样它知道记着哪些内容，需要时再去查找；一个主题代表它所汇总的那些笔记。标题由整理写出（见[自动整理](/guide/memory#tidy-up-automatically)）；在那之前，用笔记开头的几个字代替。
- **怎样找到笔记**：用混合搜索。一个列表按字词给笔记排序，越少见的词分量越重；开启按含义搜索后，另一个列表按含义排序，所以“简短些”也能找到“喜欢简短的回答”。两个列表按名次合并，智能体最近和经常查找的笔记略占优势。一条笔记只有在针对这个请求、比其余笔记明显更贴近时，才算与你的请求相关：有的请求和每条笔记都很像，有的几乎和哪条都不像，所以每条笔记都要对照这个请求与所有笔记的整体相似程度来衡量。开启按含义搜索时，你开始写消息时它的模型就会启动，所以你的第一条消息也能按含义匹配；会话从不等它：在它就绪之前开始的会话，按字词获得与你的消息相关的笔记。
- **合适的技能**：同样的搜索还会找出明显适合你第一条消息的技能（见[技能](/guide/skills#skills-that-fit-a-new-session)）。
- **如何对待**：当作背景信息。智能体会被告知这些笔记可能已经过时、其中哪些尚未核验、你现在说的话永远优先，而且除非有帮助，否则不要提起它们。

智能体因为与你的请求相关而拿到的笔记，算作**被用到**。设置中会显示每条笔记被用到的次数和最近一次的时间（笔记里的**必填**一项），并在**最近没用到**下列出几个月来没有任何智能体用到的笔记，让你保留或删除它们（见[最近没有智能体用到的笔记](/guide/memory#notes-no-agent-needed-lately)）。下一次哪些笔记排在前面，只看智能体自己查找过哪些：开始时被给出的笔记，不会因此下一次又排在前面。

智能体还有一些记忆工具：保存笔记（放到某个位置，注明如何得知，有结束日期的就带上），更正笔记，忘掉某条笔记，按字词和含义查找笔记（包括某个主题所代表的那些笔记），更新你的档案，以及搜索和阅读过去的对话（见[搜索之前的会话](/guide/memory#search-earlier-sessions)）。通过查找找到的笔记也算被用到。

## 为单个会话关闭记忆

在开始页上开始一个不带记忆的会话：

1. 在消息框下方，打开**选项**。
2. 打开**记忆**，选择**本会话已关闭**（“从零开始，也不会从中保留任何内容”）。通常选的是**开启**（“使用并补充智能体记住的内容”）。
3. 这时“选项”标签上会显示**无记忆**。开始页会把这个选择保留到你之后的会话，直到你把它改回“开启”。

该菜单底部的**智能体记住的内容**会打开“设置 → 记忆”。在手机上，这些菜单会以面板形式从屏幕底部弹出。当所有会话的记忆都已关闭时，就没有“记忆”这个选项。

对于已经在进行的会话，打开会话菜单（⋯）→ **会话设置** → **记忆**。它的提示会显示**开启**或**关闭**；点击即可切换。记忆标签的 ⋯ 中也有同样的开关，叫作**此会话的记忆**。当所有会话的记忆都已关闭时，两者都会变灰，并提示**已全局关闭**。

关闭记忆后，会话“既不读取也不写入笔记”：

- 它的智能体拿不到笔记和档案，也没有记忆工具，会话中的任何内容都不会被保存。
- 其他会话中的智能体在搜索过去的对话时找不到它，也无法读取它。

定时任务的编辑器里也有同样的“记忆”标签，所以它的运行可以不带记忆（见[定时任务](/guide/tasks)）。从应用公开页面启动的运行总是关闭记忆的（见[应用](/guide/apps)）。

## 为所有会话关闭记忆

关掉[设置 → 记忆](/settings?s=memory&find=Memory)中标题旁的**记忆**开关，它在该部分的右上角。关闭后，页面顶部会有一条提示：“记忆已关闭：智能体得不到笔记，也不会保存新内容。你的笔记会保留。”

关闭期间：

- 没有智能体能拿到笔记、你的档案或记忆工具，也不会保存任何内容。
- 你的笔记会保留。把开关重新打开，智能体就又能拿到它们。
- 开始页上的“记忆”选项会消失，搜索框（Ctrl+K）也不再显示笔记。
- **从对话中学习**、**自动整理**、带有**立即整理**的**上次整理**一行，以及**按含义搜索**会变灰。
- 你的档案和你的笔记仍留在页面上：你依然可以阅读、编辑、添加、删除和导出它们。

## 设置 → 记忆

关于记忆的一切都在[设置 → 功能 → 记忆](/settings?s=memory)中：“智能体记住的关于你、你的项目和每个会话的内容，以及记录时间”。**记忆**开关在该部分的标题旁，标题下的**了解更多**会打开这个主题。再往下，页面从上到下有五组：

- **你的档案**：每个智能体拿到的关于你的内容，带有**编辑**和一个 **⋯** 菜单（见[你的档案](/guide/memory#your-profile)）。
- **备注**：所有保留的笔记，带有**添加笔记**、一个搜索框和一个位置索引（见[备注](/guide/memory#notes)）。
- **学习**：**从对话中学习**、**自动整理**，以及带有**有哪些变化**和**立即整理**的**上次整理**。
- **智能体得到什么**：**按含义搜索**、**每个智能体开始时获得的笔记**和**档案长度**。
- **你的数据**：从其他助手**导入…**、**导出**（Markdown、JSON）和**全部清除…**。

一行的名称旁可以有一个 **(i)** 按钮，它会进一步说明这一行的作用。在手机上，设置会以列表形式打开：点按**记忆**即可在单独的页面中打开它。在那里，笔记占满屏幕的宽度，页面上的每个菜单都会以从屏幕底部弹出的面板形式打开。

### 备注

**备注**组列出所有保留的笔记，标题旁是数量（比如 33 条笔记）。标题右侧的**添加笔记**可以写一条你自己的笔记（见[添加笔记](/guide/memory#add-a-note)）。你的档案不在其中，也不计入数量：它在上面有自己的组。

标题下方是一个搜索框和一个位置索引。每个位置会打开它自己的页面：

- **关于你**：关于你的笔记，并显示有多少条。
- **每个项目**，按它的文件夹名称，显示它的笔记数量和文件夹路径，最近改动的项目排在最前。先显示前五个；**再显示 N 个项目**会显示其余的。
- **会话**：各个会话各自保留的笔记。
- **最近没用到**：只有当有些笔记四个月没被用到时才会有（见[最近没有智能体用到的笔记](/guide/memory#notes-no-agent-needed-lately)）。
- **已删除的笔记**：保留 30 天，可以恢复（见[已删除的笔记](/guide/memory#deleted-notes)）。

一个位置的页面会在这个部分里打开，顶部有**记忆**链接可以返回（浏览器的“后退”按钮也能返回）。它会显示这个位置的名称和数量（项目还有它的文件夹路径）、**添加笔记**（在“关于你”和项目中；笔记会从这个位置开始）、它自己的搜索框（“搜索这些笔记”），以及它的笔记：先是项目的档案，然后是它的主题，再然后是笔记，最近更改的排在最前，每次二十条，下面有**显示更多**。没有笔记时，它会这样说明。页面的地址是 `/settings?s=memory&notes=global`、`&notes=session`、`&notes=stale` 或 `&notes=deleted`，或者 `&notes=repo:` 加上项目的文件夹。

**要找一条笔记**，在这一组（或某个位置页面）的搜索框里输入：“搜索 33 条笔记”，按含义搜索就绪时为“按字词或含义搜索 33 条笔记”。它会找出包含你输入的每个词的笔记，最后一个词可以只是词的开头；开启按含义搜索时，还会找出意思相同的笔记。最匹配的排在最前面，每条都注明它所属的位置，**显示更多**会再给出二十条。“没有匹配的笔记”表示一条也没有。按 Escape 或 **×** 会清空搜索，索引会回来。记忆里还没有笔记时，这一组会这样说明，并带有一个**从其他助手导入**按钮和**已删除的笔记**一行。

列表中的每条笔记会显示它文字的前两行（如果是主题或档案，会带有**主题**或**档案**标记），下面有一行信息：位置（在混合了多个位置的列表里：搜索、**会话**、**最近没用到**、**已删除的笔记**）；**已添加**或**已修改**以及多久以前（把鼠标指向它可以看到确切日期）；没有人核验过时显示**尚未核验**；**被用到一次**或**被用到 N 次**，即智能体因为与请求相关而拿到它、或通过查找找到它的次数；以及有结束日期时的**有效至**某个日期。点击一条笔记即可打开它。

### 打开一条笔记

点击一条笔记，会在一个对话框中打开它，标题为**备注**、**主题**或**档案**，显示它的全文，下面是**编辑**。文字下方是：

- **位置**：**关于你**、项目（它的文件夹名称和路径），或它所属的会话（点击会话名即可打开该会话）。
- **已写**：**已添加**或**已修改**以及时间，由**你**、**某个智能体**或**辅助模型**（整理）做的，以及它出自的会话，点击即可打开。把鼠标指向它可以看到确切日期。
- **如何得知**：**你说过**、**已核验**或**尚未核验**（把鼠标指向它可以看到它的含义）。应用开始记录这一点之前的笔记不显示这一项。
- **智能体用到**：**一次**、**N 次**（附上最近一次的时间）或**还没有**。
- **结束日期**：日期，或**无**，旁边有**修改**（见下文）。
- **汇总了**（针对主题或档案）：它代表多少条笔记，**显示**会把它们列出来，已删除的加删除线。
- **历史**：**显示**会列出这条笔记经历的每一步，从新到旧：已添加、已修改（旧文字 → 新文字）、已删除、已恢复、结束日期（“直到”某个日期，或“已移除”）、如何得知，每一步都注明时间、由谁做的、在哪个会话中，以及原因。**隐藏**会把它关闭。

按钮：

- **编辑**：直接在原处修改文字，最多 500 个字符（主题或档案为 800 个）。Enter 保存，Shift+Enter 换行，Escape 或**取消**放弃更改。看起来含有机密的文字无法保存。
- **结束日期** → **修改**：在“有效期至”下选一个日期，然后点**保存**。笔记在那一天结束时失效：日期可以选明天起、最远五年后。**无结束日期**会取消结束日期。
- **删除**，在左下角：“已删除。它会在‘已删除的笔记’中保留 30 天。”对话框随之关闭。
- **保留**，当你是从**最近没用到**打开这条笔记时（见下文）。
- **关闭**，或按 Escape，离开对话框。

已删除的笔记打开时，是**恢复**和**永久抹除**（见[已删除的笔记](/guide/memory#deleted-notes)）；它不能编辑，也没有结束日期。

### 添加笔记

[添加笔记](/settings?s=memory&find=Add%20a%20note)在**备注**的标题旁（在“关于你”或某个项目的页面上也有），会打开一个对话框：“想让智能体记住什么？比如‘我喜欢简短的回答’。”写下笔记，然后点**保存**或按 Enter。Shift+Enter 换行；按 Escape 或点**取消**则放弃。

- **归属于**：除非你选了某个项目，否则笔记是关于你的。按钮前面的选择框（**关于你**）列出记忆中已有笔记的项目；关于某个项目的笔记只会给在该项目中工作的会话。还没有项目笔记时，不会出现这个选择框，笔记就是关于你的。从某个项目的页面打开时，对话框一开始就选着那个项目。
- 规则与智能体的笔记相同：最多 500 个字符，保存为一个段落，绝不能含有看起来像密码、密钥、令牌或卡号的内容。
- 这条笔记会显示**由你**添加。和每条笔记一样，会话在开始时就会拿到它（Custom 则在下一轮之前）。

### 最近没有智能体用到的笔记

当有笔记四个月没被用到时，索引里会有一行**最近没用到**，并显示数量：“有 3 条笔记已四个月没有智能体用到”。它的页面写着：“已有四个月没有智能体需要这些笔记。留下仍然重要的，删除其余的。”这里没有搜索框。

只有关于你和关于项目的笔记会被建议删除，主题、档案、有结束日期的笔记和会话的笔记都不会。每一行有两个按钮：**保留**会把这条笔记算作今天被用到，于是它会离开这个列表；**删除**会删掉它。先打开一条笔记读完全文，看它的**必填**一项和它的历史：那里的**保留**和**删除**作用相同。一条也不剩时，会显示“最近每条笔记都用到过”，这一行也会从索引中消失。

### 已删除的笔记

[已删除的笔记](/settings?s=memory&find=Deleted%20notes)是索引的最后一行，会打开被你、智能体、整理或到达结束日期而删除的笔记：“已删除的笔记保留 30 天，之后永久删除”。会话的笔记会在会话本身被删除后不久被永久删除。它的搜索框可以按字词查找已删除的笔记，顶部的**记忆**链接可以返回。

- **恢复**在笔记所在的行或它的对话框里，会把笔记找回来。结束日期已过的笔记恢复后不再带有结束日期。清除的档案会以**你的档案**显示在这里：恢复后，它会重新成为你的档案，取代在那之后写的档案。
- 打开一条笔记，按**永久抹除**：它会先询问“永久抹除这条笔记？”（“它会连同历史记录一起删除，而且无法恢复。”），然后立即删除它。它的**历史**会显示发生过什么。

### 自动整理

[自动整理](/settings?s=memory&find=Tidy%20up%20automatically)，在**学习**组里，让记忆保持精简和及时。它默认开启：它的提示写着“每天一次，合并内容相同的笔记，并归纳相关的笔记”。这项工作由辅助模型完成：应用在会话之外处理各种杂事时使用的小模型，在[设置 → 模型 → 辅助模型](/settings?s=models&find=Helper%20model)中选择（见[智能体、账户和模型](/guide/agents-models)）。它只读笔记，除非开启了[从对话中学习](/guide/memory#learn-from-conversations)：那样的话，它会先阅读上次整理以来的对话。它不会动会话自己的笔记：这些笔记很少，而且会随会话一起删除。

每次整理做这几件事：

1. **近似重复、错误的笔记、结束日期**。自上次整理以来添加或修改过的每条笔记，都会与同一位置中最接近的笔记比较（开启按含义搜索时按含义比较，否则按字词）。说的是同一件事、或者一条是另一条的更新的笔记，会合并成一条，保留所有仍然成立的事实；有矛盾时以较新的为准，并且合并后的笔记必须比被合并的笔记更短。被较新笔记证明有误的笔记会被删除。只在它提到的某个日期之前有效的笔记（“到周五为止”“三月的那次旅行”），会被设上那个结束日期。一次整理最多检查 200 条笔记；其余的等下一次。
2. **主题，以及项目的档案**。当某个位置的笔记超过约 2,400 个字符时，相关的笔记会被归纳成主题，每个主题涵盖少量笔记（最多 12 条）。之后智能体拿到的是主题，仍然可以查看它所代表的那些笔记。项目还会得到一份简短的档案（最多 700 个字符），智能体总是最先拿到它：写项目是什么、如何构建、测试和运行，以及有哪些坑。当所汇总的内容发生变化时，主题或档案会重新撰写。你自己的档案则留给你和你的智能体（见[你的档案](/guide/memory#your-profile)）。
3. **标题**。关于你和你的项目的每条笔记和每个主题，都会得到一个几个字的标题，用于智能体开始时拿到的索引。新笔记在一小时内得到标题，文字有改动的笔记会得到新的标题。

它大约每天自动运行一次，只要应用开着就行，所以晚上休眠的电脑也能做到：距上次整理过了 20 小时、有了新内容（你写的一条消息，或你或某个智能体改过的一条笔记），并且你停下来十分钟没有写东西时，它就会运行，所以从不会在你打字时运行。没有新内容时它根本不会运行。它做的每处更改都会以“辅助模型”的名义记入笔记的历史，并且上一次整理的每处更改都可以撤销（见[立即整理并撤销其更改](/guide/memory#tidy-up-now-and-undo-its-changes)）。

### 从对话中学习

[从对话中学习](/settings?s=memory&find=Learn%20from%20conversations)，**学习**组的第一行，默认开启。它的提示写着“每天一次，纠正对话中显示有误的内容，并补上智能体漏掉的”，它的 **(i)** 补充说：“整理时，辅助模型会阅读上次整理以来的对话（关闭记忆的除外）：更正对话表明有误的笔记，核验尚未核验的笔记，并且每天最多留下几件没有智能体保存过的事。”它是每次整理的第一部分，无论整理是自动进行，还是用**立即整理**进行。

智能体是在当下保存笔记的，那时还不知道后面会发生什么，所以一条笔记可能一开始就是错的，或者后来过时了，还有些长期有用的事从来没被记下。辅助模型会逐个项目地阅读你写的内容和每一轮的最后一条回复（从不读你附加的文件、粘贴的文字、中间的步骤、工具输出或网页），以及这些对话涉及的笔记，然后：

- **更正**对话表明有误或已过时的笔记；如果笔记中已经没有成立的内容，就删除它；
- **核验**对话表明属实、但尚未核验的笔记；对于这样的笔记，它还会阅读写下这条笔记的那个对话；
- **留下**之后的会话会需要、又无法在项目文件中找到的内容：你想要的或纠正过的事、一个决定及其原因、一个坑。每天最多三件，让记忆保持精简；之后，整理会像对待每条新笔记一样，把它们与近似重复的笔记合并。

如果某条项目笔记提到的文件已经不在项目中，应用会向辅助模型指出这一点，好让它更正这条笔记。

它从不读取关闭了记忆的会话（保密会话的记忆是关闭的）、子会话（它们的请求是智能体写的）或定时运行；第一次运行时，它会往回读三天。每处更改都会连同它所来自的对话，一起显示在整理的更改列表中，也可以在那里撤销（见[立即整理并撤销其更改](/guide/memory#tidy-up-now-and-undo-its-changes)）。关掉这个开关，整理就只读笔记。

### 立即整理并撤销其更改

**自动整理**下方的**上次整理**一行，在它的提示里报告上一次整理的情况：

- “还没有整理过”
- 正在运行时显示“正在整理…”。
- “3 小时前：2 条已添加，1 条已更新，3 条已删除。”（它改了什么），或“3 小时前：没有需要更改的（查看了 14 条笔记）。”
- [从对话中学习](/guide/memory#learn-from-conversations)读了一些对话时，显示“它读了 12 个对话。”；这一部分失败时，会在下面一行显示“从对话中学习已停止：”加上原因（整理的其余部分仍照常完成）。
- 如果最近一次没有发现需要改的，但更早的一次改过：“3 小时前：没有需要更改的。在那之前，2 天前：”加上那次更早整理的更改。这些更改会一直列着、也可以撤销，直到某次整理再次做出更改。
- 如果失败了，会在时间后面显示原因，比如辅助模型没有回应。

**有哪些变化**在这一行的右侧（上次整理改了东西时才显示），会打开“上次整理改了什么”。每一项会显示一个标记（已添加、已更新、已移除、到期、无结束日期、已核验或已撤销），如果是主题或档案，还会显示**主题**或**档案**，以及所在位置和原因（“已合并到 #12”“汇总了 5 条相关笔记”“从‘上传页面’中学到”），还有文字内容：旧文字加删除线显示在新文字上方。对话气泡按钮（**打开对话**）会打开某项更改所学自的那个对话。箭头按钮（**撤销此更改**）会撤回其中一项：它添加的会被去掉，它修改的恢复原文，它删除的会回来，它设的结束日期会被取消，它核验过的笔记会恢复为尚未核验。完成后关闭对话框即可。

[立即整理](/settings?s=memory&find=Tidy%20up%20now)是同一行里的按钮，会马上进行一次整理，不管**自动整理**是否开启：“正在整理：需要一两分钟”。它需要记忆处于开启状态。

### 按含义搜索

[按含义搜索](/settings?s=memory&find=Search%20by%20meaning)，**智能体得到什么**组的第一行，“不只按字词，也按含义查找笔记、资料库中的内容等，使用在这台电脑上运行的模型”：LightOn 的 mDenseOn，支持九种语言。除非你把它关掉，否则它一直开启，所以笔记和资料库都用混合搜索来查找：既按字词，也按含义，两个列表按名次合并。模型就在这里运行，所以你的笔记不会被发送到某个服务去搜索。关闭时，只能按字词查找笔记。开启时：

- 即使笔记用的字词和你说的不一样，智能体开始时也能拿到与你的请求相关的笔记。
- 智能体查找笔记时，以及**备注**组的搜索框，都能既按字词、也按含义找到笔记。
- 与已有笔记意思相同、只是换了说法的笔记不会再次保存，整理时也会按含义给笔记分组。
- 资料库的搜索会按标题和说明的含义，找到页面、文档、图片和其他东西（见[找到你的页面](/guide/library#find-your-pages)）。
- 搜索框（Ctrl+K）能按含义找到页面、设置、会话、应用等内容，知识库也会按含义搜索（见[项目和知识库](/guide/projects)）。

**怎样准备就绪**（只需一次）：

1. 应用第一次启动一分钟后，会在它的数据文件夹中建立一个私有的 Python 环境，并安装 ONNX Runtime、Hugging Face 的分词器和 NumPy（约 150 MB）；如果你关掉过它，那么你一重新开启**按含义搜索**，应用就会做这件事（记忆本身必须是开启的）。这一行下方的那一行会显示每一步，例如“正在创建私有 Python 环境”和“正在安装 ONNX Runtime 和分词器”。旧版本用 PyTorch 建立的环境会先被删除，腾出它占用的数 GB 空间：“正在删除旧版本建立的环境”。
2. 然后它会下载模型，仅此一次：“正在下载模型：120 / 340 MB，仅此一次”。这是 8 位版本的 mDenseOn（Hugging Face 上的 algoprog/mDenseOn-ONNX），大小只有完整模型的四分之一，找到的笔记相同。每个文件在使用前都会先校验，下载中断时，下次会从中断处继续。
3. 每条笔记都会在后台得到它的向量（按含义搜索时用来比较的一组数字），资料库中的每样东西也一样。那一行会显示笔记的数量：“全部 120 条笔记可按含义查找”，或“80 / 120 条笔记可按含义查找（其余的稍后）”。

用这一行的开关可以**关闭它**：模型会停止，所有东西都只按字词查找。磁盘空间或内存不够的电脑可以不用它。记忆对所有会话关闭时，这个开关是灰色的。

**需要什么**：

- 这台电脑上有 Python 3.10 或更新版本；如果装了 uv 工具则不需要，它会自己获取 Python。两者都没有时，安装会停下来并说明原因，同时告诉你怎样安装 Python：在 Debian 或 Ubuntu 上用 `sudo apt install python3 python3-venv`，在 Mac 上从 python.org 下载，或者用 Homebrew 安装（`brew install python`）。在 Mac 上，苹果自带的 Python 只有在装了它的开发者工具时才算数，所以应用从不会要你去安装这些工具。
- 磁盘空间：环境约占 150 MB，模型约 340 MB。可用空间少于约 1 GB 时，安装会停止，并提示“磁盘空间不足”。
- 需要联网一次，用于下载。
- 启动模型所需的空闲内存：约 1.5 GB。内存不够时，会显示“正在等待内存”，这期间按字词查找笔记。

**怎样运行**：在电脑的处理器（CPU）上，通过 ONNX Runtime，使用它的几个核心。它只在需要时启动，运行时约占 0.6 到 1 GB 内存，空闲几分钟后停止：“需要时启动，空闲几分钟后停止”，运行时显示“已加载”。启动只需一两秒，你在开始页（或在代理已停止的会话中）开始写消息时它就会启动，计划任务运行前不久也会启动：这样新会话的笔记和技能也能按含义找到。会话从不等它加载：在它就绪之前开始的会话，按字词获得笔记和技能。它不使用显卡，有 8 GB 内存的电脑就够用。

出问题时，状态行会变成一条警告，写明原因（例如“模型加载时间过长”），并带有一个**重试**按钮。关掉开关会停止模型；已安装的东西会保留，所以重新开启很快。

### 每个智能体开始时获得的笔记

[每个智能体开始时获得的笔记](/settings?s=memory&find=Notes%20each%20agent%20starts%20with)，在**智能体得到什么**组里，设置智能体开始时，除了你的档案之外，最多还能拿到多少条关于你和项目的笔记和主题：**5**、**10**（通常）、**20** 或 **40**，在这一行的按钮里选择。它的提示写着“除了你的档案：与你的请求相关的笔记”，它的 **(i)** 说明：“除了你的档案：最多这么多条关于你和项目、与你的请求相关的笔记，按字词查找，开启按含义搜索时也按含义查找；另有其余笔记的标题，智能体需要时会去查。只有少量笔记的地方会整体给出。”多一些，与请求相关的内容一开始就能多进来一些，但每个会话要读的也更多；少一些，开始时拿到的内容就更短。这个会话自己的笔记不算在内。见[智能体开始时带着什么](/guide/memory#what-an-agent-starts-with)。

它下面的一行，[档案长度](/settings?s=memory&find=Profile%20length)，选择你的档案最多可以有多少个词（见[你的档案](/guide/memory#your-profile)）。

### 导出你的笔记

[导出](/settings?s=memory&find=Export)在**你的数据**组里，会下载所有保留的笔记。**Markdown**（“便于阅读的列表”）是一份按位置分组、便于阅读的列表，包含每条笔记的添加和修改时间以及结束日期。**JSON**（“含更改历史”）包含每条笔记及其历史；对于主题和档案，还带有它们汇总的笔记。已删除的笔记不包括在内。

### 从其他助手导入

[导入…](/settings?s=memory&find=Bring%20in%E2%80%A6)是**你的数据**组的第一行（“Claude Code、Codex、ChatGPT 和其他助手对你的了解，以及你的技能”；记忆里还没有笔记时，则是**备注**组里的**从其他助手导入**按钮），会把这台电脑上其他智能体对你和你的项目的了解带进记忆，变成可供你挑选的笔记。在你挑选之前，不会添加任何内容。

1. 在**在这台电脑上**下，勾选要读取的内容。Hydor 会找到以下智能体保存的内容，并显示每个有多少个记忆文件：
   - **Claude Code**：它为每个项目保存的记忆，以及你为所有项目写的 CLAUDE.md（也包括 Hydor 中各个账户的）。
   - **Codex**：它的记忆，以及你的 AGENTS.md。
   - **其他智能体**：有些其他智能体会保存关于你的记忆文件（它们对你和你的工作的了解），有些会保存你为所有文件夹给它们写的指令。Hydor 会读取这些内容，以了解你喜欢怎样工作。它们的登录信息、密钥和设置绝不会被读取。当某个智能体把记忆放在正在使用的存储里时，Hydor 读取的是一份副本，所以那个智能体可以照常运行。
2. 在**来自导出文件**下，**添加导出文件**接受你申请数据时 ChatGPT 或 Claude 通过电子邮件发给你的 .zip（在 ChatGPT 中，设置 → 数据控制 → 导出数据；在 Claude 中，设置 → 隐私 → 导出数据），或其中的 conversations.json。它会显示文件里有什么：Claude 的记忆或 ChatGPT 的自定义指令，以及有多少个对话、从何时到何时。对话中只读取你自己写的内容，从最新的开始：不读回复，也不读你附加的文件。
3. 按**开始读取**。[辅助模型](/settings?s=models&find=Helper%20model)一次读取一部分，同时参照记忆里已有的笔记，只保留会长久有用的内容。它会略过记忆里已经有的内容（即使换了说法）、密钥等机密，以及用来操纵智能体的文字。内容多时需要几分钟：期间你可以关闭对话框，按**停止**会让它停下。
4. 取消勾选你不想保留的内容。笔记分组显示：先是**关于你**，然后是每个项目（按其文件夹），前提是读到的内容所涉及项目的文件夹在这台电脑上。**添加到你的档案**列出它会添加到[你的档案](/guide/memory#your-profile)的几行。按**添加 N 条笔记**；**放弃**会把它们全部丢弃。

技能会单独导入，不经过辅助模型。在**你在那里做的技能**下，Hydor 会列出它在这台电脑上的其他智能体中找到的技能（它们的每个配置文件和工作区，以及共享的和它们学会的技能），每个都带有名称、用途、来源和文件数。它们的格式都与这里的技能相同：一个带 SKILL.md 的文件夹。这个列表就是预览：取消勾选你不想要的，再按**复制 N 个技能**，每个技能连同它的文件就会进入你自己的技能（参见[技能从哪里来](/guide/skills#where-skills-come-from)）。有些技能列在**N 个未提供**下，并附有原因：智能体自带的技能是它自己的，不是你的；名称已在你的技能中的技能（内置的、你的或插件的）绝不会被替换；没有描述、超过 20,000 个字符，或其中含有密钥的技能会被略去。保存密钥或登录信息的文件（.env 文件、私钥、名为 credentials、secrets 或 tokens 的文件，以及其中含有密钥的文件）绝不会被复制，一个技能的文件夹最多复制 200 个文件、每个 512 KB、总共 2 MB：**N 个文件未复制**会说明哪些没有带过来。MCP 服务器（工具服务器）不会被导入：请在[设置 → MCP 服务器](/settings?s=mcp)中添加，它们需要的密钥放进保管库。

导入的笔记会在历史中注明：“Brought in from Claude Code”。其他助手里的内容不会有任何改变，你添加的导出文件会在其笔记添加后删除。辅助模型设为**自动**时，由 Claude Haiku 通过你的 Claude Code 套餐来读取。

### 全部清除…

[全部清除…](/settings?s=memory&find=Clear%20all%E2%80%A6)是**你的数据**组的最后一行（**清除所有记忆**），会删除所有笔记及其历史，也包括你的档案。它会先询问：“清除所有记忆？所有关于你、你的项目和你的会话的笔记都会连同历史记录一起删除。此操作无法撤销；如需保留副本，请先导出。”点击**全部清除**继续。没有笔记时（不算你的档案），这个按钮是灰色的。

## 搜索之前的会话

除了笔记，智能体还可以翻阅你过去与任何智能体的对话。问一句“上个月我们关于场地是怎么决定的？”，智能体就会在每个会话中你和智能体写过的内容里搜索这些词（必须全部匹配）；开启[按含义搜索](/guide/memory#search-by-meaning)时，还会按含义搜索你在每个会话中问过的内容，所以换个说法提出的问题也能找到它；需要时还会搜索运行过的命令和修改过的文件。你写的每条消息都会在后台得到它的向量，每次几条，最新的最先：只取你自己的话，不含你附加的文件或粘贴的文字。然后它会阅读含有答案的那个会话：它的消息和所执行步骤的标题，按从旧到新的顺序。

关闭了记忆的会话不在搜索范围内，也无法从其他会话中读取。只有当智能体所在的会话开启了记忆时，才有这些工具。

你也可以自己用搜索框（Ctrl+K，Mac 上为 ⌘K）搜索过去的会话。它会按标题找到会话，找到包含你输入字词的消息，并在**记忆**下找到记忆笔记。打开一条笔记会“打开‘设置 → 记忆’，并定位到此笔记”。

## 问问智能体

- “你记得我哪些事？把关于我以前工作的内容都删掉。”
- “在我的档案里加上：我是护士，喜欢用要点列表回答。”
- “给我看看我的档案，并把它缩短到 300 个词左右。”
- “以后每个会话开始时给 20 条笔记，而不是 10 条。”
- “让按含义搜索只在 CPU 上运行，把显卡空出来。”
- “现在整理一下记忆，然后告诉我合并了哪些。”
- “哪些笔记已经好几个月没有智能体用到了？把关于旧网站的那些删掉。”
- “关于我去里斯本旅行的那条笔记只到 5 月 12 日有效：给它设上这个结束日期。”
- “关于这个项目，哪些笔记尚未核验？对照代码核验一下。”
- “别再从对话中学习了，但保留整理。”
- “把名为‘报税’的会话的记忆关掉。”
- “把 Claude Code 和 Codex 记得的关于我的内容导入进来，添加之前先给我看看这些笔记。”
- “我以前用过别的智能体：把它对我的了解和我做的技能都导入进来，先给我看看清单。”
