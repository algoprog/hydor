# 作业

“作业”页面把你的会话在后台运行的耗时工作集中在一处，并按标签分类，标签说明每项工作属于哪件事：构建、训练、索引、下载和子智能体。对每一项工作，你可以看到它已经运行了多久、进展到哪里、大约还要多久，哪些在等待开始、在等什么，以及已结束的结果如何。你可以在这里查看作业的输出、停止作业，还可以让智能体按先后顺序运行任务。

![“作业”页面：四个汇总卡片、每个标签对应的小按钮，以及按标签分组的进行中作业及其进度和剩余时间](images/jobs.webp)

## “作业”页面显示什么

点击导航栏上的**作业**，或前往[作业](/jobs)。在手机上，它位于抽屉底部的工具中。图标上的数字表示有多少个作业正在运行。

以下几类都算作业：

- 你的某个会话的后台任务：命令、监控（持续关注某个日志或程序），或智能体自身程序（例如 Claude Code）的子智能体。你在 Hydor 之外（VS Code 或终端中）运行的会话，其后台任务也会显示；
- 智能体以作业方式启动的工作（见[智能体如何把工作放到这里](#how-agents-put-work-here)）；
- 正在运行或在队列中等待的[实验](/guide/experiments)运行；
- 正在工作的 Hydor 子智能体，即一个会话为完成自己的部分工作而启动的另一个会话（见[子智能体](/guide/sessions#subagents)）。

顶部的四个卡片给出汇总：

- **正在运行**和**排队中**：有多少个作业在运行、多少个在等待；
- **全部完成**：这些工作预计何时全部结束，例如“约 2 小时 10 分钟后”。只有当每个作业都有尚未到点的预估时间时才会显示，否则只显示一个短横线。子智能体从来没有预估时间，因此不计算在内；
- **今天完成**：今天有多少个作业结束。旁边的“1 个失败”（或实际的数量）可点击，带你查看这些失败的作业。

卡片下方是每个[标签](#tags)对应的小按钮、项目菜单（**所有项目**，见[查看某个项目的作业](#see-one-projects-jobs)），以及**筛选任务**输入框。在框中输入文字，就只显示名称、命令、会话、项目或标签中包含这些词的作业；如果没有任何匹配，点击**显示所有任务**即可恢复全部显示。再往下是**进行中**、**服务器**和**已完成**三个部分，有内容时才会出现。卡片只统计经过标签、项目和筛选后剩下的作业。正在运行的服务器不计入卡片，也不计入导航栏上的数字。页面会自动更新。

当没有任何作业在运行或等待时，你会看到“目前后台没有任何任务在运行。”

## 进行中

**进行中**列出正在运行和正在等待的作业，每个标签一张卡片；没有标签的作业放在最后一张**无标签**卡片里。卡片顶部显示标签、该标签下有多少作业在运行和排队（例如“3 个正在运行 · 1 个排队中”），如果每个作业都有预估时间，还会显示预计何时完成（“预计约 34 分钟后完成”）。如果一张卡片中的所有工作都来自同一个会话，这个会话及其项目也会写在顶部，各行中就不再重复。点击卡片顶部可以折叠或展开它；应用会在当前浏览器中记住你的选择。在筛选或选中某个标签时，所有卡片都不会折叠。如果没有任何作业带标签，作业会直接列出，不按标签分卡片。

每个作业占一行。图标表示它的类型（把鼠标指向图标可看到**命令**、**监视器**、**Claude Code 子智能体**、**Hydor 子智能体**、**实验运行**或**任务**），图标上的圆点表示它的状态。名称旁边是它的其他标签；把鼠标指向名称可查看它的命令。名称下方是当前状况、启动它的会话和所属[项目](#see-one-projects-jobs)（两者都是链接），以及它最后输出的内容。

点击某一行可打开[作业面板](#a-jobs-panel-and-stop)。它的 **⋯** 菜单中有**详情和输出**、**打开会话**（实验运行则是**打开运行**）、**编辑标签…**和**停止**。

## 正在运行

正在运行的作业会显示已经运行了多久（“已运行 12 分 05 秒”）。如果作业报告了自己的进度，就会显示进度条和百分比；把鼠标指向进度条可看到作业自己的计数，例如“step 120/500”。当没有可显示的剩余时间时，这个计数会显示在进度条下方。

### 剩余时间

如果有可参考的依据，该行会显示“大约还剩 1 小时 12 分钟”。应用按以下顺序采用第一个可用的依据：

1. 作业自己输出的剩余时间，很多进度条都会输出；
2. 到目前为止进度推进的速度；
3. 智能体启动作业时给出的预估；
4. 同一命令之前在同一文件夹中花费的时间（限最近一周内成功完成的那次）。

把鼠标指向时间可看到采用的是哪一种；作业面板中也会说明。时间旁边的**（猜测）**表示这只是粗略估计：依据是单次进度读数、智能体的预估或以前的某次运行。当作业运行得比预期久时，则会显示**已超出预估时间**。如果没有任何依据，就不显示时间。

## 排队中

排队中的作业尚未开始。它所在的行会说明原因：

- **正在等待**加上其他作业的名称：等那些作业全部成功完成后，它才会开始。点击名称可找到对应的行。被别人等待的作业会显示**然后：**以及接下来轮到谁；
- **队列中的下一个**加队列名称，或它的位置，例如“队列第 3 位 gpu”：一个队列每次只运行一个作业，按加入的先后顺序进行，涵盖你的所有会话。排在最前面的作业可能还在等另一个作业，后面的也要跟着等；
- **正在等待空闲的 GPU**或**正在等待空闲名额**：某个实验运行在等待资源（见[队列如何选择](/guide/experiments#how-the-queue-chooses)）。

当排在前面的作业都有预估时间时，还会显示它预计何时开始，例如“预计约 40 分钟后开始”。

对排队中的作业点击**停止**，意味着它永远不会开始，等待它的作业也一样。如果某个被等待的作业失败或被停止，等待它的作业同样永远不会开始。

## 服务器

有些命令永远不会自行结束：会话留在后台运行的开发服务器、网页或 API 服务器、笔记本服务器或模型服务器。“作业”页面根据命令识别出它们，列在**服务器**下，显示各自运行了多久，但没有剩余时间。它们会一直运行，直到你停止它们，和其他命令一样用**停止**。它们不计入正在运行的作业数，**时间线**视图也不包括它们。一旦结束，就会移到**已完成**。

## 已完成

**已完成**保留最近 7 天内结束的作业，最新的在最前面，按日期分组并带标题：**今天**、**昨天**，更早的则显示日期。默认显示最近的十个，点击**全部显示**可看到其余的。每一项都说明结果如何、何时结束、用了多久：

- **已完成**：成功结束；
- **失败**，如果有退出代码会一并显示（即程序结束时返回的数字；0 以外的值都表示出了问题）；
- **已停止**：被你或某个智能体停止；
- **从未启动**，并附原因，例如它等待的某个作业失败了；
- **已结束**：某项工作在添加到“作业”时就已经在运行，现在它结束了，但没有人看到结果是否顺利。

当有作业失败时，可以从**全部**切换到**失败**，只看失败的作业。某一行 **⋯** 菜单中的**从此列表中移除**会移除该项，**清除**会在询问后移除全部，包括被标签、项目菜单或筛选隐藏的项。这只是整理列表：你的会话和实验运行都会保留。

## 标签

标签说明一项工作属于哪件事，例如 `intent-data` 或 `search-index`，这样你能看出每个正在运行的东西是做什么用的，也能一次只看某一件事的工作。一个作业最多有 3 个标签，使用小写字母，单词之间用连字符连接：“Intent data”会保存为 `intent-data`。第一个标签决定它列在哪里。

你不必自己给任何东西加标签：

- 智能体会给它启动的每个作业加标签；只要工作属于某个已有标签，就沿用该标签，让同一件事保持同一个名字。你指定想用的标签，智能体就会使用它；
- 没有自带标签的工作（会话的后台命令、子智能体、实验运行，以及启动时未加标签的作业）会沿用所属会话的标签。会话标签的来源依次是：你在这里为该会话设置的标签；否则是该会话最近一周的作业最常用的标签；否则是[辅助模型](/settings?s=models&find=Helper%20model)为该会话挑选的标签，在合适时会复用已有的标签。

辅助模型在后台挑选标签，所以这样的标签可能比工作本身稍晚一点出现。挑选时，它会读取会话的标题、项目以及部分工作的名称。对于[机密会话](/guide/sessions#keep-a-session-confidential)，绝不会向它询问。

### 修改标签

在作业的 **⋯** 菜单中选择**编辑标签…**，或点击作业面板中标签旁边的铅笔图标。输入标签，用逗号分隔，也可以点击**使用中的标签**下面的标签，然后点击**保存**。

对于智能体以作业方式启动的工作，这些是该作业自己的标签。对于其他工作，则是其所属会话的标签，因此该会话中所有没有自带标签的工作都会使用它们。保存一个空白输入框即可移除你设置的标签：系统会按上述方式重新为它挑选标签。不属于任何会话的工作无法加标签，作业除外。

### 只看一个标签

点击某个标签的小按钮，就只显示列在该标签下的工作：卡片、**进行中**、**服务器**、**已完成**和时间线都会随之变化。按钮上的数字表示该标签下有多少作业在运行或等待。点击**全部**可重新查看所有内容；**无标签**按钮显示[没有标签的工作](/jobs?untagged=1)。

你选中的标签会成为页面网址的一部分（网址以 `?tag=` 和标签名结尾），因此你可以把它加入书签或发送到手机上。标签按钮按每个作业的第一个标签归类；要按其他标签查找作业，请在**筛选任务**中输入该标签。

## 查看某个项目的作业

项目菜单位于**筛选任务**旁边。它显示**所有项目**，或你所选项目的名称和标识。打开菜单可以选择：

- **所有项目**：全部作业；
- 在这里有作业的某个项目；旁边的数字表示其中有多少个正在运行或等待；
- **不放在项目中**：不属于任何项目的作业。

选择后，卡片、**进行中**、**服务器**、**已完成**和时间线都只显示这些作业。选择项目时会回到**全部**按钮，标签按钮及其数字也只涵盖该项目的作业；点击某个按钮可以查看项目内的这个标签。选中单个项目时，各行不再显示项目名称。只有当至少有一个作业属于某个项目时，这个菜单才会出现。

你选中的项目同样会写进页面地址（`?project=` 加项目 id，或 `?project=none`），因此可以加入书签。[项目组](/guide/projects#bring-projects-together-in-a-group)的作业包括它所汇集的各个项目的作业。当某个项目有作业正在运行或等待，或有服务器仍在运行时，该项目自己的页面会在[概览](/guide/projects#overview)下显示它们。

作业归属于其会话所在的项目。如果没有这样的项目（会话不在任何项目中，或作业没有会话，例如你从自己的终端启动的作业，或在“实验”页面启动的运行），它就归属于运行所在文件夹对应的项目。如果一个项目的文件夹位于另一个项目的文件夹之内，归内层项目。项目组，以及文件夹是你的主文件夹或整个磁盘的项目，永远不会以这种方式获得作业。作业面板中会写明它的**项目**。

## “时间线”视图

可在右上角切换**列表**和**时间线**；应用会在当前浏览器中记住你的选择。时间线视图沿时间轴为每个正在运行或等待的作业画一个长条，名称前有一个对应标签颜色的圆点。标签按钮、项目菜单和**筛选任务**对它的筛选方式与列表相同：

- **目前已运行**部分是实心的，超出它的条纹部分是**预计**时间；
- **排队中**的作业用虚线表示，画在预计开始的位置；
- **无预估**的长条会逐渐淡出；
- 标有**当前**的线表示现在的时间，细线把作业与等待它的作业连接起来。

超出预估时间的作业会变成琥珀色。把鼠标指向长条可查看其状态和时间，点击则打开作业面板。在窄屏幕上，图表可左右滚动，名称保持固定。已结束的作业列在图表下方。

## 作业面板和“停止”

面板在页面右侧弹出（在手机上占满整个屏幕）。顶部是作业的名称、状态、标签、**打开会话**（或**打开运行**）和**停止**。下面是关于它的已知信息，例如所属会话、项目和文件夹，何时开始、还剩多久及预估依据、在等什么、结果如何。接着是它的命令，旁边有复制按钮。

**输出**显示作业打印内容的末尾部分，运行期间每隔几秒刷新一次；除非你向上滚动，否则最新的几行会一直可见。对于子智能体，这里列出它的步骤。有些作业（例如 Hydor 子智能体和 Codex 的后台任务）在这里没有输出：请使用**打开会话**。

点击**停止**会先询问你，然后结束作业：作业或命令会停止，实验运行会像在它自己的页面上一样被停止，Hydor 子智能体的会话会被停止。作业已经完成的内容会保留。在 Hydor 之外的会话中运行的工作，以及 Codex 的后台任务，无法从这里停止，因此没有**停止**按钮。

## 智能体如何把工作放到这里

你无需做任何设置。会话启动的后台任务会自动显示在这里。应用启动的每个会话还带有一个名为 `job` 的命令，智能体会按要求用它来运行耗时工作（超过约十分钟的任何工作），这样工作就能带着名称、标签、进度和剩余时间显示在这里（见[每个智能体都有的四个命令](/guide/agents#four-commands-every-agent-has)）。

用日常语言说出你的需求，剩下的交给智能体：

- **先后执行**：“等索引构建完成后再运行评估”。第二个作业会等待第一个，如果第一个失败，它就永远不会开始；
- **逐个执行**：“把这些参数扫描放进一个队列”。队列名相同的作业会轮流运行；
- **需要多长时间**：智能体可以给出自己的预估，在作业的进度提供更多信息之前会一直使用它；
- **属于哪件事**：“给索引构建加上 search-index 标签”。智能体还可以列出使用中的标签，并在事后修改作业的标签；
- **已经在运行的工作**：“把你之前启动的训练显示到‘作业’里”。智能体会添加它而不重新启动（`job adopt`）；Windows 上不支持此功能。它结束时会显示**已结束**，因为没有人能判断结果如何。

只要某个会话启动的作业仍在等待或运行（用 `job` 运行的作业，或它启动的实验运行），该会话就不算结束：即使它的智能体已经停下，会话的圆点仍会持续闪动蓝色，状态显示为“工作中 · 1 个在后台”，它的**已完成**通知也要等作业结束后才会发出。消息框旁的停止按钮不会停止这些作业：请在这里停止它们。

如果智能体启动作业时无法连接到应用，命令仍会照常运行，只是不会显示在这里。

## 向智能体提问

- “索引构建完成后，把评估作为一个作业来运行。”
- “给索引构建打上 search-index 标签。”
- “intent-data 还有什么在运行？”
- “我的 Thesis 项目里有什么在运行？”
- “在“作业”里显示你之前启动的训练。”
- “把这三组参数扫描放进队列，一次运行一个。”
- “还有什么在运行，什么时候能完成？”
- “停止下载，改为把测试作为一个作业来运行。”
- “上次构建为什么失败了？查看一下它那个作业的输出。”
