# 作业

“作业”页面把你的各个会话在后台运行的耗时任务集中在一处：构建、训练、建索引、下载和子智能体。对每个作业，你可以看到它已经运行了多久、进展到哪里、大约还要多久，哪些作业在排队、正在等什么，以及已结束的作业结果如何。你可以在这里查看作业的输出、停止作业，还可以让智能体按顺序一件接一件地执行任务。

![“作业”页面：正在运行的作业及其进度和剩余时间、排队等待的作业，以及已完成的作业](images/jobs.webp)

## “作业”页面显示什么

点击导航栏上的**作业**，或前往[作业](/jobs)。在手机上，它位于抽屉底部的工具中。图标上的数字表示正在运行的作业数量。

以下任何一种都算作业：

- 某个会话的后台任务：命令、监控（盯着某个日志或程序），或智能体自身程序（如 Claude Code）的子智能体。你在 Hydor 之外（VS Code 或终端中）运行的会话，其后台任务也会显示；
- 智能体以作业方式启动的工作（见[智能体如何把工作放到这里](#how-agents-put-work-here)）；
- [实验](/guide/experiments)中正在运行或在其队列中等待的运行；
- 正在工作的 Hydor 子智能体，即另一个会话为分担部分工作而启动的会话（见[子智能体](/guide/sessions#subagents)）。

顶部那一行是汇总，例如“3 个运行中 · 2 个排队中 · 预计约 2 小时 10 分钟后全部完成”。只有当每个作业都有预估时间时，才会显示结束时间；子智能体从来没有预估，不计入其中。下面分为**正在运行**、**排队中**、**服务器**和**已完成**几个部分，有内容时才显示。导航栏上的数字、顶部的汇总和结束时间都不包含服务器。页面会自动更新。

每一行有一个带状态圆点的图标和作业名称；将鼠标指向名称可以查看它的命令。名称下方依次是作业类型（**命令**、**监视器**、**Claude Code 子智能体**、**Hydor 子智能体**、**实验运行**、**任务**或**服务器**）、启动它的会话及其项目，后两者都是链接。右侧的**输出**显示它打印的内容，**打开**前往它对应的运行或会话，**停止**用于结束它。

没有正在运行或等待中的作业时，你会看到“目前后台没有任何任务在运行。”

## 正在运行

正在运行的作业会显示已经运行了多久（“已运行 12 分 05 秒”）。如果作业会报告进度，就会显示带百分比的进度条，旁边通常还有作业自己的计数，例如“step 120/500”。下方的灰色文字是它最后打印的一行内容。

### 剩余时间

如果有可参考的信息，该行会显示“大约还剩 1 小时 12 分钟”。应用按以下顺序，采用第一个可用的依据：

1. 作业自己打印出的剩余时间，很多进度条都会打印；
2. 到目前为止进度推进的速度；
3. 智能体启动作业时给出的预估时间；
4. 最近一周内，同一命令在同一文件夹中成功完成时所用的时间。

将鼠标指向时间，可以看到用的是哪一种依据。时间旁的**（猜测）**表示这只是粗略估计：依据是单次进度读数、智能体的预估或以前的某次运行。当作业运行得比预期久时，则会显示**已超出预估时间**。如果没有任何依据，就不显示时间。

## 排队中

排队中的作业尚未开始。它所在的行会说明原因：

- **正在等待**加上其他作业的名称：这些作业全部成功完成后，它才会开始。点击名称可以找到对应的行。被其他作业等待的作业会显示**然后：**以及接下来轮到谁；
- **队列中的下一个**加上队列名称，或它在队列中的位置，例如“队列第 3 位 gpu”：一个队列一次只运行一个作业，按进入顺序执行，你的所有会话共用。排在最前面的作业可能还在等另一个作业，排在它后面的也要一起等；
- **正在等待空闲的 GPU** 或**正在等待空闲名额**：某个实验运行正在等待空位（见[队列如何选择](/guide/experiments#how-the-queue-chooses)）。

如果排在它前面的作业都有预估时间，还会显示它预计何时开始，例如“预计约 40 分钟后开始”。

对排队中的作业点击**停止**，它将永远不会开始，等待它的作业也一样。如果某个被等待的作业失败或被停止，等待它的作业同样不会开始。

## 服务器

有些命令永远不会自己结束：会话在后台一直运行着的开发服务器、Web 或 API 服务器、notebook 或模型服务器。“作业”页面根据命令识别它们，并单独列在**服务器**下，显示各自已运行多久，但没有剩余时间。它们会一直运行到你停止为止，和其他命令一样用**停止**即可。它们不计入正在运行的作业，**时间线**视图也不画它们。某个服务器结束后，会进入**已完成**。

## 已完成

**已完成**保留最近 7 天内结束的作业，最新的排在最前：默认显示最近 10 个，点击**全部显示**查看其余的。每个作业会说明结束方式、结束时刻和耗时：

- **完成**：成功结束；
- **失败**，如有退出代码会一并显示（即程序结束时给出的数字；0 以外的任何值都表示出了问题）；
- **已停止**：被你或某个智能体停止；
- **从未启动**，后面附原因，例如它等待的某个作业失败了；
- **已结束**：添加到“作业”时就已经在运行的工作现已结束，但没有人看到它是否成功。

行末的 ×（**从此列表中移除**）可移除单个作业，**清除**会在询问确认后移除全部。这只是整理列表：你的会话和实验运行都会保留。

## 时间线视图

在右上角切换**列表**和**时间线**；应用会在这个浏览器中记住你的选择。时间线视图沿时间轴为每个正在运行或等待中的作业画一条横条：

- 实心部分是**目前已运行**，超出它的条纹部分是**预计**；
- **排队中**的作业用虚线表示，画在它们应当开始的位置；
- **无预估**的横条会逐渐淡出；
- 标有**当前**的线表示现在，细线把一个作业和等待它的作业连起来。

超出预估时间的作业会变成琥珀色。将鼠标指向横条可以查看状态和时间，点击它可以查看输出；如果没有可显示的输出，则会打开它。在窄屏上，图表可以左右滚动，名称保持不动。已完成的作业列在图表下方。

## 输出和停止

**输出**会打开一个面板，显示作业打印内容的末尾部分，作业运行期间每隔几秒刷新一次；除非你向上滚动，否则最新的行会一直保持可见。对于子智能体，面板会列出它的各个步骤。有些作业（例如 Hydor 子智能体和 Codex 的后台任务）在这里没有输出：请使用**打开**。

**停止**会先询问确认，然后结束作业：作业或命令会停止，实验运行会像在它自己的页面上一样被停止，Hydor 子智能体的会话也会停止。作业此前已完成的内容会保留。在 Hydor 之外的会话中运行的工作，以及 Codex 的后台任务，无法从这里停止，因此没有**停止**。

## 智能体如何把工作放到这里

你不需要做任何设置。会话启动的后台任务会自动显示在这里。应用启动的每个会话还带有一个名为 `job` 的命令，智能体被要求用它来处理耗时工作（任何超过大约十分钟的工作），这样作业在这里会带有名称、进度和剩余时间（见[每个智能体都有的四个命令](/guide/agents#four-commands-every-agent-has)）。

用平常的话说出你的要求，剩下的交给智能体：

- **一个接一个**：“索引构建完成后运行评估”。第二个作业会等待第一个，如果第一个失败，它就永远不会启动；
- **一次一个**：“把这些参数扫描放进一个队列”。队列名称相同的作业会轮流运行；
- **应该花多长时间**：智能体可以给出自己的预估，在作业进度提供更多信息之前就用这个预估；
- **已经在运行的工作**：“把你之前启动的训练显示在‘作业’里”。智能体会添加它而不重新启动（`job adopt`）；此功能在 Windows 上不可用。它结束时会显示**已结束**，因为没有人能判断结果如何。

如果智能体启动作业时无法连接到应用，命令仍会照常运行，只是不会显示在这里。

## 向智能体提问

- “索引构建完成后，把评估作为作业运行。”
- “把你之前启动的训练显示在‘作业’里。”
- “把这三组参数扫描放进队列，一次运行一个。”
- “还有什么在运行？什么时候能完成？”
- “停止下载，改为把测试作为作业运行。”
- “上次构建为什么失败了？查看一下它的作业输出。”
