# Συνδεδεμένες εφαρμογές, κλειδιά και εργαλεία

Συνδέστε μία φορά τις υπηρεσίες που χρησιμοποιείτε (Notion, Gmail, GitHub, Stripe, έναν φάκελο σε αυτόν τον υπολογιστή…), στις **Συνδεδεμένες εφαρμογές** της σελίδας Εφαρμογές, και κάθε πράκτορας και κάθε εφαρμογή μπορεί να δουλεύει με αυτές. Κρατήστε κλειδιά API και στοιχεία σύνδεσης σε ένα κρυπτογραφημένο θησαυροφυλάκιο που οι πράκτορες χρησιμοποιούν χωρίς να τα βλέπουν ποτέ, προσθέστε διακομιστές εργαλείων στο Claude Code και στο Codex, και πρόσθετα στο Claude Code. Χρησιμοποιήστε τα όταν θέλετε οι πράκτορες να ενεργούν στους δικούς σας λογαριασμούς, να καλούν μια υπηρεσία με το κλειδί σας ή να έχουν εργαλεία που δεν έχουν από μόνοι τους.

![Εφαρμογές → Συνδεδεμένες εφαρμογές: οι υπηρεσίες που συνδέσατε, η αγορά και τα κλειδιά σας](images/connections.webp)

## Τι είναι οι συνδέσεις, τα κλειδιά και τα εργαλεία

Οι πράκτορες μπορούν να κάνουν περισσότερα όταν τους δίνετε εργαλεία. Υπάρχουν τρία σημεία για να το κάνετε:

- **Συνδεδεμένες εφαρμογές** ([Εφαρμογές → Συνδεδεμένες εφαρμογές](/apps/connected)): υπηρεσίες από μια αγορά, που συνδέονται μία φορά για κάθε πράκτορα: Claude Code, Codex, Custom και τους πράκτορες που μιλούν ACP, καθώς και τις εφαρμογές που εκτελούν. Κάθε συνδεδεμένος λογαριασμός δίνει στους πράκτορες τα εργαλεία του.
- **Το θησαυροφυλάκιο** (η καρτέλα **Κλειδιά** της ίδιας σελίδας): κλειδιά API, tokens και κωδικοί πρόσβασης για σύνδεση. Ένα κλειδί API είναι ένας κωδικός που σας δίνει μια υπηρεσία, ώστε προγράμματα να μπορούν να χρησιμοποιούν τον λογαριασμό σας. Οι πράκτορες τα χρησιμοποιούν για να καλούν μια υπηρεσία, να συνδέονται σε έναν ιστότοπο ή να εκτελούν ένα πρόγραμμα, αλλά δεν τα βλέπουν ποτέ.
- **Διακομιστές MCP και πρόσθετα** ([Ρυθμίσεις → Διακομιστές MCP](/settings?s=mcp) και [Ρυθμίσεις → Πρόσθετα](/settings?s=plugins)): διακομιστές εργαλείων που ρυθμίζετε μόνοι σας στις ρυθμίσεις του ίδιου του Claude Code και του Codex, και πρόσθετα που φέρνουν δεξιότητες και εργαλεία σε κάθε πράκτορα (δείτε [Πρόσθετα](/guide/plugins)).

Το MCP (Model Context Protocol) είναι ο κοινός τρόπος με τον οποίο μια υπηρεσία προσφέρει εργαλεία σε πράκτορες. Ένας συνδεδεμένος λογαριασμός είναι ένας διακομιστής MCP που το Hydor ρυθμίζει, και στον οποίο συνδέεται, για κάθε πράκτορα. Οι διακομιστές MCP στις Ρυθμίσεις → Πράκτορες είναι όσοι ρυθμίζετε με το χέρι, με μια εντολή ή μια διεύθυνση.

## Ανοίξτε τις Συνδεδεμένες εφαρμογές

Ανοίξτε τις **Εφαρμογές** από την πλευρική στήλη και επιλέξτε την καρτέλα τους **Συνδεδεμένες εφαρμογές**, ή μεταβείτε στις [Εφαρμογές → Συνδεδεμένες εφαρμογές](/apps/connected). (Παλιότερα βρίσκονταν στις Ρυθμίσεις, ως Συνδέσεις: ένας παλιός σύνδεσμος προς αυτές σας φέρνει εδώ.) Κάτω από μια γραμμή που λέει σε τι χρησιμεύουν, με το **Σύνδεση υπηρεσίας**, υπάρχουν τρεις καρτέλες:

- **Συνδεδεμένο**: οι λογαριασμοί που συνδέσατε, και πώς πάει ο καθένας. Ο αριθμός στην καρτέλα τους μετρά· τους μετρά και η καρτέλα **Συνδεδεμένες εφαρμογές**.
- **Αγορά**: κάθε υπηρεσία που μπορείτε να συνδέσετε.
- **Κλειδιά**: το θησαυροφυλάκιο. Ο αριθμός στην καρτέλα μετρά τα κλειδιά σας.

Η σελίδα ανοίγει στο **Συνδεδεμένο** όταν έχετε συνδέσει κάτι, και στην **Αγορά** όταν δεν έχετε· κάθε καρτέλα έχει δική της διεύθυνση (`/apps/connected?tab=market`, `?tab=keys`). Σε κινητό οι καρτέλες κυλούν οριζόντια, και τα παράθυρα διαλόγου ανεβαίνουν από το κάτω μέρος της οθόνης.

## Βρείτε μια υπηρεσία στην αγορά

Ανοίξτε [την καρτέλα Αγορά](/apps/connected?tab=market).

- Το πλαίσιο αναζήτησης («Αναζήτηση σε … υπηρεσίες: email, Notion, τιμολόγια…») ψάχνει σε ονόματα, περιγραφές, λέξεις-κλειδιά και κατηγορίες. Κάθε λέξη που πληκτρολογείτε πρέπει να ταιριάζει.
- Τα κουμπιά από κάτω δείχνουν μία κατηγορία τη φορά, το καθένα με το πόσες υπηρεσίες έχει: **Όλα**, **Σημειώσεις & έγγραφα**, **Εργασίες & έργα**, **Email, συνομιλίες & συσκέψεις**, **Ημερολόγιο και προγραμματισμός**, **Αρχεία & αποθήκευση**, **Σχεδιασμός & πολυμέσα**, **Εργαλεία προγραμματιστών**, **Cloud και φιλοξενία**, **Βάσεις δεδομένων και δεδομένα**, **Αναλύσεις και παρακολούθηση**, **Πωλήσεις, μάρκετινγκ & υποστήριξη**, **Πληρωμές & οικονομικά**, **Ιστότοποι & καταστήματα**, **Αναζήτηση & ιστός**, **AI και αυτοματισμοί**, **Ταξίδια & καθημερινότητα** και **Σε αυτόν τον υπολογιστή**. Σε κινητό κυλούν οριζόντια.
- **Προτεινόμενα**: μια σειρά από μεγαλύτερες κάρτες για γνωστές υπηρεσίες (Notion, Linear, GitHub, Figma, Stripe, Zapier…). Εμφανίζεται όσο δεν έχετε κάνει αναζήτηση ούτε έχετε επιλέξει κατηγορία. Ακολουθεί το **Όλες οι υπηρεσίες**.

Κάθε κάρτα δείχνει το όνομα της υπηρεσίας, τι μπορεί να κάνει ένας πράκτορας με αυτήν και πώς συνδέεται:

- **Σύνδεση μέσω προγράμματος περιήγησης**: συνδέεστε στον λογαριασμό σας στο πρόγραμμα περιήγησης.
- **Κλειδί API**: επικολλάτε ένα κλειδί που σας δίνει η υπηρεσία.
- **Δεν χρειάζεται σύνδεση**: δεν υπάρχει τίποτα να συμπληρώσετε.
- **Τρέχει σε αυτόν τον υπολογιστή**: ένα πρόγραμμα που το Hydor ξεκινά εδώ όταν το χρειάζεται ένας πράκτορας.
- **Τρέχει εδώ, με κλειδί**: το ίδιο, με ένα κλειδί που του δίνετε.

Ένα σημάδι ελέγχου δίπλα στο όνομα σημαίνει ότι κάποιος έλεγξε ότι ο διακομιστής της υπηρεσίας απαντά όπως λέει η καταχώρισή της. Το **μη ελεγμένο** σημαίνει ότι δεν το έχει ελέγξει ακόμη κανείς. Οι υπηρεσίες που συνδέσατε δείχνουν **Συνδεδεμένο** (ή **Συνδεθείτε ξανά**) εκεί όπου οι άλλες δείχνουν **Σύνδεση**.

Μερικά από όσα υπάρχουν:

- **Σημειώσεις, εργασίες και έργα**: Notion, Craft, Linear, Asana, Atlassian (Jira και Confluence), ClickUp, monday.com, Todoist.
- **Email, συνομιλίες και ημερολόγια**: Gmail, Slack, Fireflies, Granola, Google Calendar, Calendly.
- **Αρχεία και σχεδιασμός**: Google Drive, Dropbox, Box, Figma, Canva, Miro, Gamma, Cloudinary.
- **Εργαλεία προγραμματιστών και φιλοξενία**: GitHub, GitLab, Sentry, CircleCI, Postman, Cloudflare, Vercel, Netlify, Railway, Context7, DeepWiki.
- **Δεδομένα και αναλύσεις**: Airtable, Supabase, Neon, PostgreSQL, MongoDB, SQLite, PostHog, Mixpanel, Amplitude, Datadog.
- **Επιχειρήσεις**: Stripe, PayPal, Plaid, Square, HubSpot, Intercom, Attio, Klaviyo, Webflow, Wix, WordPress.com.
- **Αναζήτηση και ιστός**: Exa, Perplexity, Tavily, Brave Search, Firecrawl, Wolfram, ένα πρόγραμμα περιήγησης Playwright.
- **AI και καθημερινή ζωή**: Hugging Face, Zapier, AllTrails, Kiwi.com, trivago, Strava.
- **Σε αυτόν τον υπολογιστή**: Files on this computer (οι φάκελοι που επιλέγετε), Git, Time και ένας γράφος μνήμης.

Όταν καμία υπηρεσία δεν ταιριάζει, η σελίδα γράφει **Καμία υπηρεσία δεν ταιριάζει**. Μπορείτε να προσθέσετε την υπηρεσία μόνοι σας: δείτε [Προσθέστε μια υπηρεσία στην αγορά](/guide/connections#add-a-service-to-the-marketplace). Νέες υπηρεσίες έρχονται με τις ενημερώσεις του Hydor.

## Συνδέστε μια υπηρεσία

1. Κάντε κλικ στην κάρτα της υπηρεσίας. Ένα παράθυρο διαλόγου δείχνει τι κάνει, την κατηγορία της, πώς συνδέεται, και **Ελέγχθηκε** με ημερομηνία (ή **Η διεύθυνση δεν έχει ελεγχθεί ακόμη**). Τα **Ιστότοπος** και **Τεκμηρίωση** οδηγούν στην υπηρεσία. Ένα πλαίσιο δείχνει πού τρέχει: τη διεύθυνση του διακομιστή ή την εντολή που εκτελεί εδώ. Λέει επίσης ότι κάθε πράκτορας παίρνει τα εργαλεία της υπηρεσίας με το σύντομο όνομά της (του Notion με το «notion»), και ότι μπορείτε να την απενεργοποιήσετε ανά συνεδρία.
2. Διαβάστε τη σημείωση στο κίτρινο πλαίσιο, αν υπάρχει. Λέει τι πρέπει να ξέρετε πρώτα, όπως «Χρειάζεται το uv (uvx) σε αυτόν τον υπολογιστή.» ή ότι μια υπηρεσία χρειάζεται δικό σας client σύνδεσης.
3. Συμπληρώστε ό,τι ζητά το παράθυρο και μετά κάντε κλικ στο **Σύνδεση**, ή στο **Σύνδεση στο** ακολουθούμενο από το όνομα της υπηρεσίας.

Μόλις συνδεθεί, η υπηρεσία μετακινείται στην καρτέλα **Συνδεδεμένο** και δοκιμάζεται στο παρασκήνιο. Τι ζητά το παράθυρο εξαρτάται από την υπηρεσία.

### Υπηρεσίες χωρίς τίποτα να συμπληρώσετε

Κάντε κλικ στο **Σύνδεση**. Κάποιες ζητούν πρώτα μια ρύθμιση. Το GitLab ζητά τη διεύθυνσή του (gitlab.com, εκτός αν τρέχετε δικό σας). Το Files on this computer ζητά τους φακέλους που μπορεί να χρησιμοποιεί, ως πλήρεις διαδρομές, μία ανά γραμμή· μπορεί να διαβάζει και να αλλάζει αρχεία μόνο μέσα σε αυτούς. Το SQLite ζητά το αρχείο της βάσης δεδομένων. Τα πεδία με την ένδειξη **προαιρετικό** μπορούν να μείνουν κενά. Το **Αποκτήστε ένα** δίπλα σε ένα πεδίο οδηγεί εκεί όπου παίρνετε αυτή την τιμή.

### Υπηρεσίες που χρειάζονται κλειδί

Μια υπηρεσία στο internet έχει ένα πεδίο **Κλειδί**, με το **Απόκτηση κλειδιού** να οδηγεί στη σελίδα όπου φτιάχνει ένα. Μια υπηρεσία που τρέχει εδώ ζητά το κλειδί της σε ένα ή περισσότερα δικά της πεδία (ένα token, ένα connection string). Επικολλήστε το κλειδί και κάντε κλικ στο **Σύνδεση**.

Το κλειδί μπαίνει στο θησαυροφυλάκιο, κρυπτογραφημένο. Από εκεί και πέρα βλέπετε μόνο τους τελευταίους χαρακτήρες του. Το GitHub, για παράδειγμα, δέχεται ένα fine-grained personal access token: ένα κλειδί που μπορείτε να περιορίσετε στα αποθετήρια και στα δικαιώματα που θέλετε να έχουν οι πράκτορες.

### Υπηρεσίες στις οποίες συνδέεστε από το πρόγραμμα περιήγησης

1. Κάντε κλικ στο **Σύνδεση στο** με το όνομα της υπηρεσίας.
2. Σε υπολογιστή, ανοίγει ένα μικρό παράθυρο. Σε κινητό, η σελίδα σύνδεσης της υπηρεσίας ανοίγει αντί γι’ αυτό στην ίδια καρτέλα.
3. Συνδεθείτε και επιτρέψτε την πρόσβαση. Όσο το κάνετε, το παράθυρο διαλόγου γράφει «Αναμονή να ολοκληρώσετε τη σύνδεση…».
4. Όταν τελειώσετε, μια ειδοποίηση λέει ότι ο λογαριασμός συνδέθηκε. Σε κινητό επιστρέφετε στις Εφαρμογές → Συνδεδεμένες εφαρμογές.

Τα tokens μένουν κρυπτογραφημένα σε αυτόν τον υπολογιστή και ανανεώνονται μόνα τους· οι πράκτορες δεν τα βλέπουν ποτέ. Μια σύνδεση πρέπει να ολοκληρωθεί μέσα σε 15 λεπτά· μετά από αυτό, ξεκινήστε από την αρχή. Αν αρνηθείτε την πρόσβαση, βλέπετε «Δεν επιτρέψατε την πρόσβαση».

Ορισμένες υπηρεσίες σας αφήνουν να συνδεθείτε μόνο μέσω ενός δικού σας client σύνδεσης (μιας εφαρμογής OAuth): για παράδειγμα το Asana, το Box, το HubSpot, το Slack και οι εφαρμογές της Google. Στο παράθυρό τους ανοίγει το **Το δικό σας client ID (αυτή η υπηρεσία χρειάζεται ένα)**, με οδηγίες για το τι να κάνετε. Άλλες συνδέσεις μέσω προγράμματος περιήγησης προσφέρουν το ίδιο ως **Χρήση δικού σας client ID (προαιρετικό)**, που ανοίγει επίσης μόνο του όταν αποδειχθεί ότι μια υπηρεσία δεν αφήνει τις εφαρμογές να εγγράφονται μόνες τους.

1. Φτιάξτε το client στις ρυθμίσεις για προγραμματιστές της υπηρεσίας.
2. Δώστε του τη διεύθυνση κάτω από το **Διεύθυνση επανάκλησης που θα του δώσετε** (έχει κουμπί αντιγραφής).
3. Επικολλήστε το **Αναγνωριστικό πελάτη** του, και το **Μυστικό πελάτη** του, αν έχει.
4. Κάντε κλικ στο **Σύνδεση στο** με το όνομα της υπηρεσίας.

### Υπηρεσίες που τρέχουν σε αυτόν τον υπολογιστή

Αυτές ξεκινούν ένα πρόγραμμα εδώ (με npx ή uvx) για τον πράκτορα κάθε συνεδρίας. Η πρώτη δοκιμή μπορεί να αργήσει, αν το πρόγραμμα πρέπει πρώτα να κατέβει. Ένα κλειδί που χρειάζεται μια τέτοια υπηρεσία μπαίνει στο περιβάλλον της από το θησαυροφυλάκιο όταν ξεκινά. Δεν εμφανίζεται ποτέ σε γραμμή εντολών, όπου θα μπορούσαν να το διαβάσουν άλλα προγράμματα.

## Ελέγξτε ότι ένας συνδεδεμένος λογαριασμός λειτουργεί

Στην καρτέλα **Συνδεδεμένο**, κάθε λογαριασμός λέει πώς είναι:

- **Εργάζεται**, πότε ελέγχθηκε τελευταία φορά, και πόσα από τα εργαλεία του είναι ενεργά («12 από 14 εργαλεία ενεργά»).
- **Δεν έχει δοκιμαστεί ακόμα**.
- **Χρειάζεται νέα σύνδεση**: η σύνδεσή του έληξε και δεν μπόρεσε να ανανεωθεί.
- **Δεν λειτουργεί**, με τον λόγο.

Το **Δοκιμή** συνδέεται στην υπηρεσία όπως θα συνδεθούν οι πράκτορες και δείχνει τα εργαλεία της. Μια ειδοποίηση λέει ότι ο λογαριασμός λειτουργεί και πόσα εργαλεία έχει, ή τι πήγε στραβά: «Το κλειδί απορρίφθηκε» ή «Η σύνδεση απορρίφθηκε: συνδεθείτε ξανά» (ο λογαριασμός τότε δείχνει **Χρειάζεται νέα σύνδεση**). Οι λογαριασμοί δοκιμάζονται αυτόματα αμέσως μόλις τους συνδέσετε.

## Απενεργοποιήστε έναν λογαριασμό ή μερικά από τα εργαλεία του

- **Όλες οι συνεδρίες** (σε κινητό, μόνο ο διακόπτης): όταν είναι ενεργό, ο πράκτορας κάθε συνεδρίας παίρνει τον λογαριασμό, εκτός αν μια συνεδρία τον απενεργοποιήσει. Όταν είναι ανενεργό, καμία συνεδρία δεν τον παίρνει, εκτός αν εκείνη η συνεδρία τον ενεργοποιήσει. Ένας λογαριασμός που μόλις συνδέθηκε ξεκινά ενεργός.
- **Εργαλεία**: μόλις μια δοκιμή δείξει τα εργαλεία ενός λογαριασμού, αυτό το κουμπί τα ανοίγει, το καθένα με διακόπτη και με το τι κάνει. Απενεργοποιήστε όσα δεν πρέπει να χρησιμοποιούν οι πράκτορες, όπως διαγραφή ή αποστολή. Ένας πράκτορας που δοκιμάζει ένα εργαλείο που απενεργοποιήσατε ενημερώνεται ότι είναι ανενεργό.

## Αλλάξτε μια σύνδεση ή συνδεθείτε ξανά

- Το **Αλλαγή** (για λογαριασμούς με κλειδί ή ρυθμίσεις) ανοίγει ξανά το παράθυρο διαλόγου με όσα συμπληρώσατε. Οι ρυθμίσεις κρατούν τις τιμές τους. Τα πεδία κλειδιού και μυστικού γράφουν «Αποθηκευμένο: αφήστε το κενό για να το κρατήσετε»: πληκτρολογήστε νέο για να το αντικαταστήσετε και μετά κάντε κλικ στο **Αποθήκευση**.
- Το **Συνδεθείτε ξανά** (για συνδέσεις μέσω προγράμματος περιήγησης) κάνει νέα σύνδεση από την αρχή. Όταν ένας λογαριασμός δείχνει **Χρειάζεται νέα σύνδεση**, οι πράκτορες σταματούν να τον παίρνουν μέχρι να το κάνετε.

Αν η αγορά αλλάξει τη διεύθυνση μιας υπηρεσίας ή τον τρόπο σύνδεσής της αφού τη συνδέσατε, ο λογαριασμός γράφει «Ο κατάλογος έχει νέα διεύθυνση ή νέο τρόπο σύνδεσης για αυτήν. Συνεχίζει να χρησιμοποιεί τα παλιά μέχρι να συνδεθείτε ξανά.» Το κλειδί ή η σύνδεσή σας δεν πηγαίνει ποτέ σε νέα διεύθυνση μέχρι να συνδεθείτε ξανά εσείς οι ίδιοι.

## Αποσυνδέστε έναν λογαριασμό

Κάντε κλικ στο **Αποσύνδεση** (σε κινητό, ένα εικονίδιο βύσματος που αποσυνδέεται) και επιβεβαιώστε. Η σύνδεση ή το κλειδί του λογαριασμού διαγράφεται εδώ, και οι πράκτορες σταματούν να παίρνουν τα εργαλεία του. Για μια σύνδεση μέσω προγράμματος περιήγησης, το Hydor λέει επίσης στην υπηρεσία ότι τα tokens δεν χρειάζονται πια, όταν η υπηρεσία προσφέρει τρόπο γι’ αυτό.

## Επιλέξτε τους λογαριασμούς που χρησιμοποιεί μια συνεδρία

Κάθε συνεδρία παίρνει τους συνδεδεμένους λογαριασμούς που έχουν ενεργό τον διακόπτη **Όλες οι συνεδρίες**. Για να το αλλάξετε σε μία συνεδρία:

1. Ανοίξτε το μενού της συνεδρίας (⋯) → **Ρυθμίσεις συνεδρίας** → **Συνδεδεμένοι λογαριασμοί**.
2. Ενεργοποιήστε ή απενεργοποιήστε λογαριασμούς για αυτή τη συνεδρία. Ο καθένας λέει σε ποια κατάσταση βρίσκεται: «Ενεργό, όπως σε κάθε συνεδρία», «Ανενεργό, όπως σε κάθε συνεδρία», «Ενεργό μόνο εδώ» ή «Ανενεργό μόνο εδώ».
3. Κάντε κλικ στο **Τέλος**.

Οι υπηρεσίες στο internet ακολουθούν την αλλαγή αμέσως. Όσες τρέχουν σε αυτόν τον υπολογιστή την ακολουθούν την επόμενη φορά που θα ξεκινήσει ο πράκτορας. Όταν δεν έχει συνδεθεί ακόμη τίποτα, το παράθυρο προσφέρει το **Άνοιγμα Συνδεδεμένων εφαρμογών**.

Ένας βοηθός μπορεί επίσης να ενεργοποιεί λογαριασμούς για τις συνεδρίες που ξεκινούν με αυτόν: δείτε [Βοηθοί](/guide/assistants).

## Πώς χρησιμοποιούν οι πράκτορες τους συνδεδεμένους λογαριασμούς

- Κάθε είδος πράκτορα παίρνει έναν συνδεδεμένο λογαριασμό με τον ίδιο τρόπο: το Claude Code, το Codex, ο Custom και οι πράκτορες ACP παίρνουν τα εργαλεία του με το σύντομο όνομα της υπηρεσίας.
- Στην αρχή μιας συνεδρίας, ο πράκτορας ενημερώνεται ποιοι από τους λογαριασμούς σας είναι συνδεδεμένοι, και ότι πρέπει να τους χρησιμοποιεί όταν μια εργασία τους αφορά. Μπορεί επίσης να δει τι είναι συνδεδεμένο και ποια κλειδιά είναι αποθηκευμένα, μόνο με το όνομά τους.
- Ένας πράκτορας παίρνει μόνο τους λογαριασμούς που είναι ενεργοί για τη συνεδρία του και έχουν ενεργή σύνδεση. Οι συνδέσεις ανανεώνονται στο παρασκήνιο, ακόμη και για λογαριασμούς που δεν χρησιμοποιεί καμία συνεδρία, ώστε οι μεγάλες συνεδρίες να συνεχίζουν να λειτουργούν.
- Τα κλειδιά και τα tokens δεν μπαίνουν ποτέ στις ρυθμίσεις ή στη γραμμή εντολών ενός πράκτορα. Οι γνωστές τιμές κλειδιών καλύπτονται σε ό,τι επιστρέφουν τα εργαλεία της υπηρεσίας.
- Το πλαίσιο αναζήτησης (Ctrl+K, ⌘K σε Mac) βρίσκει και τους συνδεδεμένους λογαριασμούς σας.

## Προσθέστε μια υπηρεσία στην αγορά

Οποιοσδήποτε μπορεί να προσθέσει μια υπηρεσία στην αγορά, ή να διορθώσει μία, με ένα pull request στο αποθετήριο του Hydor στο GitHub. Το **Πώς να προσθέσετε μία**, στο κάτω μέρος της καρτέλας Αγορά, ανοίγει τον σχετικό οδηγό.

1. Γράψτε ένα μικρό αρχείο JSON για την υπηρεσία στον φάκελο `catalog/` του αποθετηρίου, όπως περιγράφει ο οδηγός εκεί. Περιέχει το όνομα της υπηρεσίας, μία απλή πρόταση για το τι μπορεί να κάνει ένας πράκτορας με αυτήν, την κατηγορία της, το εικονίδιο και το χρώμα της, την αρχική σελίδα και την τεκμηρίωσή της, τον διακομιστή της (μια διεύθυνση, ή μια εντολή που τρέχει εδώ) και πώς συνδέεται (χωρίς τίποτα, με σύνδεση μέσω προγράμματος περιήγησης ή με κλειδί), καθώς και τυχόν πεδία που συμπληρώνουν οι χρήστες.
2. Χρησιμοποιήστε τον δικό διακομιστή MCP της υπηρεσίας, στην τεκμηριωμένη διεύθυνσή του, όταν υπάρχει. Ένα πρόγραμμα που τρέχει εδώ είναι ευπρόσδεκτο όταν δεν υπάρχει τέτοιος διακομιστής, ή για πράγματα που μόνο ένα τοπικό πρόγραμμα μπορεί να κάνει, όπως τα αρχεία σε αυτόν τον υπολογιστή.
3. Μη βάζετε κλειδιά ή tokens στο αρχείο. Οι χρήστες βάζουν τα δικά τους, στο θησαυροφυλάκιο.
4. Εκτελέστε τον έλεγχο που περιγράφει ο οδηγός. Ελέγχει το αρχείο με βάση τους κανόνες και μπορεί να ρωτήσει τον διακομιστή για να δει πώς απαντά.
5. Στείλτε το pull request. Μόλις γίνει merge, η υπηρεσία φτάνει στην αγορά όλων με την επόμενη ενημέρωση.

## Κρατήστε κλειδιά στο θησαυροφυλάκιο

Ανοίξτε [την καρτέλα Κλειδιά](/apps/connected?tab=keys). Το θησαυροφυλάκιο κρατά κλειδιά API, tokens και κωδικούς πρόσβασης για σύνδεση, που οι πράκτορες χρησιμοποιούν χωρίς να τα βλέπουν. Είναι κρυπτογραφημένα σε αυτόν τον υπολογιστή και δεν εμφανίζονται ποτέ ξανά, ούτε εδώ ούτε σε κάποιον πράκτορα: μόνο οι τελευταίοι χαρακτήρες τους.

Οι πράκτορες τα χρησιμοποιούν μέσω των δικών εργαλείων του Hydor: του εργαλείου αιτημάτων web, του προγράμματος περιήγησης και, όπου το επιτρέπετε, των εντολών σε αυτόν τον υπολογιστή. Η εφαρμογή βάζει μόνη της το κλειδί, και μόνο όπου το επιτρέπετε.

Κάθε κλειδί στη λίστα δείχνει:

- το όνομά του και μια καλυμμένη ένδειξη της τιμής (όπως «…f3a9»)·
- τη σημείωσή του·
- τους διακομιστές όπου μπορεί να σταλεί, και **σε εντολές** όταν μπορούν να το χρησιμοποιούν οι εντολές σε αυτόν τον υπολογιστή (**Δεν επιτρέπεται ακόμη κανένας διακομιστής** όταν δεν ισχύει κανένα από τα δύο)·
- πότε χρησιμοποιήθηκε τελευταία φορά («δεν έχει χρησιμοποιηθεί ακόμα» μέχρι τότε), και πότε προστέθηκε ή πότε άλλαξε τελευταία η τιμή του.

Όταν δεν υπάρχουν ακόμη κλειδιά, η καρτέλα λέει ότι μπορείτε να προσθέσετε ένα εδώ ή να αφήσετε έναν πράκτορα να ζητήσει ένα.

Και οι εφαρμογές μπορεί να χρειάζονται κλειδιά (μιας υπηρεσίας καιρού, ενός παρόχου χαρτών): μια εφαρμογή ονομάζει τα κλειδιά που χρειάζεται, και δίνετε το καθένα στη σελίδα της, στην κάρτα που την εγκαθιστά ή στην κάρτα της σε μια συνεδρία ([Δώστε της τα κλειδιά που χρειάζεται](/guide/apps#give-it-the-keys-it-needs)). Κρατιούνται εδώ, με τα ονόματα που τους δίνει η εφαρμογή, με τους διακομιστές που ορίζει, και η σημείωσή τους αναφέρει την εφαρμογή.

### Προσθέστε ένα κλειδί

1. Κάντε κλικ στο **Προσθήκη κλειδιού**.
2. **Όνομα**: πώς το λένε οι πράκτορες, όπως WEATHER_API_KEY: κεφαλαία λατινικά γράμματα, ψηφία και κάτω παύλες, 2 έως 64 χαρακτήρες, με γράμμα στην αρχή. Ό,τι πληκτρολογείτε μετατρέπεται σε τέτοιο όνομα (το «github token» γίνεται GITHUB_TOKEN), και το πεδίο το δείχνει.
3. **Τιμή**: επικολλήστε το κλειδί. Πρέπει να είναι μία γραμμή, εκτός αν είναι ένα μπλοκ που ξεκινά με -----BEGIN (ένα πιστοποιητικό ή ιδιωτικό κλειδί).
4. **Διακομιστές όπου μπορεί να σταλεί**: οι διευθύνσεις της υπηρεσίας, χωρισμένες με κόμματα, όπως api.example.com (έως 20). Το κλειδί πηγαίνει μόνο σε αυτούς τους διακομιστές και στους υποτομείς τους, μέσω https. Μέχρι να προσθέσετε έναν, οι πράκτορες δεν μπορούν να χρησιμοποιήσουν το κλειδί.
5. **Οι εντολές σε αυτόν τον υπολογιστή μπορούν να το χρησιμοποιούν** (ανενεργό αρχικά): ενεργοποιήστε το για ένα κλειδί που χρειάζεται ένα πρόγραμμα εδώ, όπως τον κωδικό πρόσβασης μιας βάσης δεδομένων ή ένα token για το git. Δείτε [Εντολές που χρησιμοποιούν ένα κλειδί](/guide/connections#commands-that-use-a-key).
6. **Σημείωση**: για τι είναι το κλειδί. Οι πράκτορες βλέπουν αυτή τη σημείωση.
7. **Τρόπος αποστολής** (προαιρετικό): από προεπιλογή το κλειδί μπαίνει στην κεφαλίδα Authorization, μετά το «Bearer ». Μπορείτε να αλλάξετε την **Κεφαλίδα** (όπως X-Api-Key) και ό,τι μπαίνει **Πριν από το κλειδί** (τίποτα, για άλλες κεφαλίδες), ή να το στείλετε **Ή ως παράμετρος ερωτήματος** (όπως api_key).
8. Κάντε κλικ στο **Αποθήκευση**.

Ένα όνομα που υπάρχει ήδη στο θησαυροφυλάκιο απορρίπτεται: δώστε σε εκείνο το κλειδί νέα τιμή.

### Δώστε σε ένα κλειδί νέα τιμή

Κάντε κλικ στο κυκλικό βέλος (**Νέα τιμή**) δίπλα στο κλειδί, επικολλήστε τη νέα τιμή στο **Νέα τιμή** και κάντε κλικ στο **Αντικατάσταση**. Οι διακομιστές, η σημείωση και ο τρόπος αποστολής μένουν όπως ήταν.

### Αλλάξτε πού μπορεί να πηγαίνει ένα κλειδί

Κάντε κλικ στο μολύβι (**Διακομιστές, σημείωση και τρόπος αποστολής**), αλλάξτε τους διακομιστές, το αν μπορούν να το χρησιμοποιούν οι εντολές, τη σημείωση ή τον τρόπο αποστολής και κάντε κλικ στο **Αποθήκευση**. Η τιμή μένει ίδια.

### Διαγράψτε ένα κλειδί

Κάντε κλικ στον κάδο (**Διαγραφή**) και επιβεβαιώστε. Οι πράκτορες δεν μπορούν πια να χρησιμοποιήσουν το κλειδί, και η τιμή του χάνεται οριστικά.

### Τι μπορούν και τι δεν μπορούν να κάνουν οι πράκτορες με ένα κλειδί

- Να καλέσουν μια υπηρεσία με αυτό, χρησιμοποιώντας το όνομά του. Η εφαρμογή βάζει το κλειδί στο αίτημα: εκεί όπου έχει ρυθμιστεί να μπαίνει, ή εκεί όπου ο πράκτορας γράφει το όνομά του μέσα σε διπλά άγκιστρα (όπως {{GITHUB_TOKEN}}) στη διεύθυνση, σε μια κεφαλίδα ή στο σώμα του αιτήματος, ή ως όνομα χρήστη και κωδικό πρόσβασης μιας βασικής σύνδεσης (basic).
- Να το πληκτρολογήσουν στη σελίδα σύνδεσης ενός ιστότοπου, στο πρόγραμμα περιήγησής τους, χρησιμοποιώντας το όνομά του: μόνο σε πεδίο μίας γραμμής, σε σελίδα ενός από τους διακομιστές του κλειδιού, μέσω https (ή σε αυτόν τον υπολογιστή). Το πεδίο τότε δείχνει τελείες, και ο πράκτορας βλέπει μόνο ότι συμπληρώθηκε από το θησαυροφυλάκιο.
- Να το δώσουν σε μια εντολή σε αυτόν τον υπολογιστή, όταν έχετε ενεργοποιήσει το **Οι εντολές σε αυτόν τον υπολογιστή μπορούν να το χρησιμοποιούν**, και μόνο αφού επιτρέψετε την εντολή (δείτε [Εντολές που χρησιμοποιούν ένα κλειδί](/guide/connections#commands-that-use-a-key)).
- Στον ιστό, μόνο προς τους διακομιστές που επιτρέψατε και τους υποτομείς τους, μόνο μέσω https, και ποτέ προς αυτόν τον υπολογιστή ή το τοπικό του δίκτυο. Μια ανακατεύθυνση προς διακομιστή όπου το κλειδί δεν επιτρέπεται να πάει δεν ακολουθείται.
- Να αλλάξουν, για μία κλήση, σε ποια κεφαλίδα ή παράμετρο ερωτήματος μπαίνει το κλειδί.
- Να βλέπουν τα ονόματα, τους διακομιστές και τις σημειώσεις των κλειδιών. Ποτέ τις τιμές τους: οι απαντήσεις, οι σελίδες και ό,τι τυπώνουν οι εντολές επιστρέφουν με το κλειδί καλυμμένο.

## Όταν ένας πράκτορας ζητά ένα κλειδί

Οι πράκτορες έχουν οδηγία να μη σας ζητούν ποτέ να πληκτρολογήσετε κωδικό, token ή κλειδί στη συνομιλία. Όταν μια εργασία χρειάζεται ένα κλειδί που δεν είναι αποθηκευμένο, ο πράκτορας δείχνει αντί γι’ αυτό μια κάρτα στη συνομιλία: **Ο πράκτορας ζητά ένα κλειδί**, με το όνομα του κλειδιού και το γιατί το χρειάζεται (συχνά και πού θα το βρείτε).

1. Επικολλήστε το κλειδί στο πεδίο.
2. Ελέγξτε το **Αποστέλλεται μόνο σε**: τους διακομιστές που πρότεινε ο πράκτορας. Αλλάξτε τους αν χρειάζεται. Χωρίς διακομιστή, οι πράκτορες δεν μπορούν να χρησιμοποιήσουν το κλειδί.
3. Κάντε κλικ στο **Αποθήκευση στο θησαυροφυλάκιο**.

Το κλειδί πηγαίνει κατευθείαν στο κρυπτογραφημένο θησαυροφυλάκιο, ποτέ στη συνομιλία. Η κάρτα γίνεται μια σημείωση ότι το κλειδί αποθηκεύτηκε, και ο πράκτορας παίρνει ένα μήνυμα ότι υπάρχει (ποτέ ποιο είναι), ώστε να συνεχίσει.

- Το **Όχι τώρα** το αρνείται. Ο πράκτορας ενημερώνεται ότι προτιμάτε να μην το δώσετε τώρα, και ότι πρέπει να συνεχίσει χωρίς αυτό ή να πει τι άλλο θα μπορούσε να λειτουργήσει. Η κάρτα τότε λέει ότι δεν το δώσατε, με **Εισαγωγή τελικά**, σε περίπτωση που αλλάξετε γνώμη.
- Όσο μια κάρτα περιμένει, εμφανίζεται και στα [Εισερχόμενα](/guide/inbox) ως «Ζητά ένα κλειδί» με το όνομα του κλειδιού. Το **Άνοιγμα** σας πηγαίνει στη συνεδρία.
- Αν υπάρχει ήδη κλειδί με αυτό το όνομα στο θησαυροφυλάκιο, ο πράκτορας ενημερώνεται να το χρησιμοποιήσει, και η κάρτα λέει μόνο ότι βρίσκεται στο θησαυροφυλάκιο. Όταν ένα αποθηκευμένο κλειδί σταμάτησε να λειτουργεί, ο πράκτορας μπορεί να το ζητήσει ξανά: το πεδίο τότε λέει ότι αντικαθιστά το αποθηκευμένο.
- Όταν ο πράκτορας χρειάζεται το κλειδί για εντολές σε αυτόν τον υπολογιστή, η κάρτα έχει επίσης το **Οι εντολές σε αυτόν τον υπολογιστή μπορούν να το χρησιμοποιούν**, ενεργό αρχικά. Απενεργοποιήστε το αν προτιμάτε να μην το επιτρέψετε· ο πράκτορας μπορεί και πάλι να χρησιμοποιεί το κλειδί στους διακομιστές του. Για ένα κλειδί που είναι ήδη αποθηκευμένο, η κάρτα γράφει **Ο πράκτορας ζητά να χρησιμοποιήσει ένα κλειδί σε εντολές**: αφήστε το πεδίο κενό για να κρατήσετε την τιμή, και κάντε κλικ στο **Αποθήκευση στο θησαυροφυλάκιο**.

### Στοιχεία σύνδεσης σε πολλά πεδία

Για να συνδεθεί σε έναν ιστότοπο ή μια υπηρεσία, ένας πράκτορας τα ζητά όλα μαζί: **Ο πράκτορας ζητά στοιχεία σύνδεσης**, με ένα πεδίο για κάθε μέρος, όπως ένα email και έναν κωδικό πρόσβασης, ή τη διεύθυνση, τον χρήστη και τον κωδικό πρόσβασης μιας βάσης δεδομένων. Οι κωδικοί πρόσβασης και τα άλλα μυστικά κρύβονται καθώς τα πληκτρολογείτε· το μάτι τα εμφανίζει.

1. Συμπληρώστε τα πεδία. Όποιο έχει την ένδειξη **προαιρετικό** μπορεί να μείνει κενό.
2. Ελέγξτε το **Αποστέλλεται μόνο σε**: τους διακομιστές για τους οποίους είναι τα στοιχεία σύνδεσης.
3. Κάντε κλικ στο **Αποθήκευση στο θησαυροφυλάκιο**.

Κάθε μυστικό πηγαίνει στο θησαυροφυλάκιο ως ξεχωριστό κλειδί, με όνομα από τα στοιχεία σύνδεσης (ένας κωδικός πρόσβασης του Voltaro γίνεται VOLTARO_PASSWORD). Ένα πεδίο με την ένδειξη **Αυτό ο πράκτορας το βλέπει** είναι μια λεπτομέρεια που δεν είναι μυστική, όπως η διεύθυνση ενός διακομιστή: ο πράκτορας παίρνει ό,τι πληκτρολογείτε εκεί, και αυτό δεν κρατιέται στο θησαυροφυλάκιο. Ένα πεδίο που υπάρχει ήδη στο θησαυροφυλάκιο το λέει: αφήστε το κενό για να κρατήσετε ό,τι είναι αποθηκευμένο. Μόλις αποθηκευτούν, η κάρτα δείχνει τα κλειδιά, και ο πράκτορας μπορεί να συνδεθεί με αυτά στο πρόγραμμα περιήγησής του, μόνο σε εκείνους τους διακομιστές, χωρίς να τα βλέπει.

## Εντολές που χρησιμοποιούν ένα κλειδί

Ορισμένες δουλειές χρειάζονται έναν κωδικό πρόσβασης ή ένα token σε ένα πρόγραμμα σε αυτόν τον υπολογιστή: ένα push στο GitHub με token, η ανάγνωση μιας βάσης δεδομένων με τον κωδικό της, ένα σενάριο (script) που καλεί μια υπηρεσία. Για αυτές, οι πράκτορες έχουν ένα εργαλείο που εκτελεί μία εντολή με κλειδιά από το θησαυροφυλάκιο στις μεταβλητές περιβάλλοντός της, το καθένα με το δικό του όνομα. Ό,τι τυπώνει η εντολή επιστρέφει στον πράκτορα με τα κλειδιά καλυμμένα.

- Σε μια εντολή μπορούν να δοθούν μόνο κλειδιά με ενεργό το **Οι εντολές σε αυτόν τον υπολογιστή μπορούν να το χρησιμοποιούν**. Ενεργοποιήστε το στο παράθυρο που ανοίγει το μολύβι του κλειδιού, ή στην κάρτα όταν το ζητά ένας πράκτορας.
- Πριν εκτελεστεί μια τέτοια εντολή, μια κάρτα τη δείχνει: **Run a command with** και τα ονόματα των κλειδιών, έπειτα την εντολή και τον σκοπό της. Το **Να επιτραπεί** την εκτελεί μία φορά. Το **Να επιτραπεί σε αυτή τη συνεδρία** αφήνει επίσης τις επόμενες εντολές αυτής της συνεδρίας με τα ίδια κλειδιά να εκτελούνται χωρίς ερώτηση, μέχρι να επανεκκινηθεί η εφαρμογή. Το **Να μη γίνει** τη σταματά, και μπορείτε να πείτε στον πράκτορα τι να κάνει αντί γι’ αυτό.
- Μια συνεδρία με πλήρη πρόσβαση εκτελεί αυτές τις εντολές χωρίς να ρωτά, όπως και τις άλλες εντολές της. Στη λειτουργία Σχέδιο δεν εκτελείται καμία.
- Μια εντολή μπορεί να κάνει ό,τι μπορεί να κάνει ένα πρόγραμμα, ακόμη και να στείλει το κλειδί αλλού: επιτρέψτε μόνο εντολές που καταλαβαίνετε, και ενεργοποιήστε αυτή την επιλογή μόνο για κλειδιά που χρειάζεται ένα πρόγραμμα εδώ.
- Μια εντολή σταματά μετά από δύο λεπτά, εκτός αν ο πράκτορας της δώσει περισσότερο χρόνο (έως δέκα).

## Συμπληρώστε μια φόρμα που ζητά μια υπηρεσία

Ορισμένες υπηρεσίες χρειάζονται κάτι από εσάς στη μέση μιας εργασίας: μια ημερομηνία, μια επιλογή, ένα ναι ή όχι, ή μια σελίδα να ανοίξετε. Όποιος πράκτορας κι αν δουλεύει, το αίτημα εμφανίζεται ως κάρτα στη συνεδρία, δίπλα στις εγκρίσεις του ίδιου του πράκτορα, και στα [Εισερχόμενα](/guide/inbox). Ο τίτλος της κάρτας λέει τι θέλει η υπηρεσία:

- **…σας ζητά να συμπληρώσετε μια φόρμα**: το μήνυμα της υπηρεσίας και μετά τα πεδία της, ως φόρμα. Υπάρχουν πλαίσια κειμένου, μεγαλύτερο κείμενο, αριθμοί, ημερομηνίες, ένας διακόπτης για ναι ή όχι, και κουμπιά ή μια λίστα για να επιλέξετε (κουμπιά από τα οποία μπορείτε να επιλέξετε πολλά, όταν η υπηρεσία επιτρέπει περισσότερα από ένα). Κάντε κλικ στο **Αποστολή**. Τα κενά πεδία που χρειάζονται («Υποχρεωτικό») και οι αριθμοί που δεν είναι αριθμοί επισημαίνονται πριν σταλεί οτιδήποτε. Μια απάντηση που η υπηρεσία δεν μπορεί να δεχτεί (πολύ μεγάλη, όχι διεύθυνση email, πολύ λίγες επιλογές) απορρίπτεται με το τι πρέπει να διορθώσετε, και η κάρτα μένει.
- **…σας ζητά να ανοίξετε μια σελίδα**: ένας σύνδεσμος. Το **Άνοιγμα** ανοίγει τη σελίδα σε νέα καρτέλα (για να εγκρίνετε κάτι ή να συνδεθείτε εκεί) και λέει στην υπηρεσία ότι το κάνατε.
- **…ζητά άδεια να προχωρήσει**: ένα απλό ναι ή όχι. Το **Να επιτραπεί** λέει ναι.

Το **Απόρριψη** λέει όχι. Το **Όχι τώρα** ακυρώνει αυτή τη φορά. Η κάρτα μιας υπηρεσίας περιμένει έως μία ώρα· αν ο γύρος του πράκτορα τελειώσει πρώτα, το αίτημα ακυρώνεται. Οι διακομιστές MCP που ρυθμίσατε για το Codex ρωτούν με το ίδιο είδος κάρτας.

## Ρυθμίστε διακομιστές MCP για το Claude Code και το Codex

Ανοίξτε τις [Ρυθμίσεις → Πράκτορες → Διακομιστές MCP](/settings?s=mcp). Αυτοί είναι διακομιστές εργαλείων στις ρυθμίσεις του ίδιου του Claude Code και του Codex, για εργαλεία που δεν έχει η αγορά ή για διακομιστές που τρέχετε εσείς. Οι νέες συνεδρίες τους φορτώνουν· οι συνεδρίες που τρέχουν ήδη παίρνουν τις αλλαγές όταν ξεκινήσουν ξανά. Ο Custom, ο πράκτορας της ίδιας της εφαρμογής, τους χρησιμοποιεί επίσης, όλους εκτός από τους SSE (δείτε [Custom](/guide/custom)).

Η σελίδα δείχνει τους διακομιστές του Claude Code και του Codex σε δύο μέρη. Το κουμπί **Φάκελος** στο πάνω μέρος επιλέγει τον φάκελο του οποίου τους διακομιστές βλέπετε, αφού το Claude Code μπορεί να κρατά διακομιστές για έναν μόνο φάκελο αλλά και για όλους.

Κάθε διακομιστής δείχνει:

- το όνομα και τον τύπο του: **Εντολή** (ένα πρόγραμμα που εκτελεί αυτό το μηχάνημα), ή **HTTP** ή **SSE** (ένας διακομιστής σε μια διεύθυνση· το SSE είναι το παλαιότερο είδος)·
- για το Claude Code, πού ισχύει: **Όλοι οι φάκελοι**, **Αυτός ο φάκελος, μόνο εσείς** ή **Αυτός ο φάκελος, κοινή χρήση**·
- **Ανενεργό**, για έναν διακομιστή του Codex που είναι απενεργοποιημένος στις ρυθμίσεις του ίδιου του Codex·
- την εντολή ή τη διεύθυνσή του, και τα ονόματα των μεταβλητών περιβάλλοντος, των κεφαλίδων ή της μεταβλητής bearer token. Οι τιμές τους μένουν στον διακομιστή και δεν εμφανίζονται ποτέ·
- μετά από έναν έλεγχο, πώς πάει ο διακομιστής.

### Προσθέστε έναν διακομιστή

Κάντε κλικ στο [Προσθήκη διακομιστή](/settings?s=mcp&find=Add%20server). Το παράθυρο **Προσθήκη διακομιστή MCP** ζητά:

- **Προσθήκη σε**: Claude Code, Codex ή και τα δύο (αρχικά και τα δύο).
- **Όνομα**: γράμματα, ψηφία, τελείες, παύλες ή κάτω παύλες, έως 64, με γράμμα ή ψηφίο στην αρχή. Οι πράκτορες δείχνουν τα εργαλεία του ως το όνομα, μια κάθετο και το εργαλείο.
- **Πληκτρολόγηση** (ο τύπος του διακομιστή): **Εντολή**, **HTTP** ή **SSE**. Το Codex δεν υποστηρίζει SSE, οπότε αν επιλέξετε SSE το Codex μένει έξω.
- Για εντολή:
  - **Εντολή**: ολόκληρη η γραμμή εντολής, όπως `npx -y @modelcontextprotocol/server-github`. Εκτελείται σε αυτό το μηχάνημα όταν ξεκινά μια συνεδρία. Βάλτε σε εισαγωγικά τα ορίσματα που περιέχουν κενά. Ένα ~ στην αρχή ενός ορίσματος σημαίνει τον αρχικό σας φάκελο.
  - **Περιβάλλον**: ένα KEY=value ανά γραμμή (οι γραμμές που ξεκινούν με # παραλείπονται). Οι τιμές μπαίνουν στα αρχεία ρυθμίσεων των πρακτόρων και δεν εμφανίζονται ποτέ ξανά εδώ.
- Για HTTP ή SSE:
  - **URL**: η διεύθυνση του διακομιστή, που ξεκινά με http:// ή https://.
  - **Κεφαλίδες** (για το Claude Code): ένα «Όνομα: τιμή» ανά γραμμή, για διακομιστές που δέχονται κλειδί API. Οι διακομιστές που χρησιμοποιούν σύνδεση στο πρόγραμμα περιήγησης (OAuth) δεν χρειάζονται: συνδεθείτε από τη λίστα μετά την προσθήκη.
  - **Μεταβλητή bearer token** (για το Codex, προαιρετικό): το όνομα μιας μεταβλητής περιβάλλοντος, της οποίας την τιμή το Codex στέλνει ως bearer token.
- **Πού το χρησιμοποιεί το Claude Code** (**Πού χρησιμοποιείται** όταν έχει επιλεγεί μόνο το Claude Code):
  - **Όλοι οι φάκελοι**: κάθε συνεδρία του Claude Code σε αυτό το μηχάνημα. Αυτή είναι η προεπιλογή.
  - **Αυτός ο φάκελος**: μόνο οι συνεδρίες στον φάκελο που έχει επιλεγεί στο πάνω μέρος, αποθηκευμένο στις δικές σας ρυθμίσεις του Claude Code.
  - **Κοινόχρηστο .mcp.json**: αποθηκεύεται σε ένα αρχείο .mcp.json σε εκείνον τον φάκελο, ώστε να το παίρνει όποιος δουλεύει στο αποθετήριο.

  Οι διακομιστές του Codex ισχύουν πάντα για κάθε φάκελο.

Κάντε κλικ στο **Προσθήκη διακομιστή**. Το Hydor τον προσθέτει μέσω της δικής εντολής κάθε πράκτορα, ώστε οι ρυθμίσεις τους να μένουν όπως τις περιμένουν. Αν ένας πράκτορας αρνηθεί, το παράθυρο δείχνει ότι δεν πρόσθεσε τον διακομιστή, μαζί με όσα είπε ο πράκτορας. Διορθώστε το πρόβλημα και κάντε ξανά κλικ στο **Προσθήκη διακομιστή**: δοκιμάζονται μόνο οι πράκτορες που απέτυχαν.

### Ελέγξτε ποιοι διακομιστές συνδέονται

Το [Έλεγχος συνδέσεων](/settings?s=mcp&find=Check%20connections), δίπλα στο Claude Code ή στο Codex, ξεκινά κάθε διακομιστή όπως θα τον ξεκινούσε μια νέα συνεδρία και δείχνει πώς τα πήγε ο καθένας:

- **Συνδεδεμένο**, με τον αριθμό των εργαλείων του·
- **Χρειάζεται σύνδεση**·
- **Συνδέεται ακόμα**·
- **Απέτυχε**, με τον λόγο («Ο διακομιστής δεν ξεκίνησε ή δεν απάντησε.» όταν δεν δίνεται λόγος)·
- **Ανενεργό**.

Δεν χρησιμοποιείται κανένα μοντέλο. Μπορεί να πάρει έως ένα με δύο λεπτά. Για το Claude Code, εκτελείται στον φάκελο που έχει επιλεγεί στο πάνω μέρος, ώστε να μετρούν και οι διακομιστές εκείνου του φακέλου.

### Συνδεθείτε σε έναν διακομιστή

Ένας διακομιστής σε μια διεύθυνση που συνδέεται με OAuth χρειάζεται σύνδεση μία φορά. Κάντε κλικ στο **Σύνδεση** (εμφανίζεται όταν ένας έλεγχος λέει ότι χρειάζεται σύνδεση) ή στο εικονίδιο σύνδεσης στη γραμμή του. Ανοίγει ένα τερματικό μέσα στην εφαρμογή, που εκτελεί τη σύνδεση του ίδιου του πράκτορα για εκείνον τον διακομιστή: ακολουθήστε τα βήματά της εκεί.

### Αφαιρέστε έναν διακομιστή

Κάντε κλικ στον κάδο δίπλα σε έναν διακομιστή και επιβεβαιώστε με **Αφαίρεση**. Ο πράκτορας σταματά να τον φορτώνει. Οι συνεδρίες που τρέχουν ήδη τον κρατούν μέχρι να ξεκινήσουν ξανά.

## Προσθέστε πρόσθετα στο Claude Code

Το Claude Code έχει δικά του πρόσθετα: επεκτάσεις που περιέχουν μαζί δεξιότητες, εντολές, πράκτορες, hooks και διακομιστές MCP, από αγορές (καταλόγους πρόσθετων που φυλάσσονται σε ένα αποθετήριο GitHub, σε άλλο αποθετήριο git ή σε έναν φάκελο). Λειτουργούν μόνο για το Claude Code. Βρίσκονται στην καρτέλα **Claude Code** των [Ρυθμίσεων → Πράκτορες → Πρόσθετα](/settings?s=plugins&find=Claude%20Code)· τα πρόσθετα του ίδιου του Codex βρίσκονται στην καρτέλα του **Codex**. Τα πρόσθετα για κάθε πράκτορα βρίσκονται στην καρτέλα **Όλοι οι πράκτορες**: δείτε [Πρόσθετα](/guide/plugins).

### Εγκατεστημένα πρόσθετα

Το **Εγκατεστημένο** δείχνει τα πρόσθετα του Claude Code σε αυτό το μηχάνημα. Οι νέες συνεδρίες του Claude Code τα φορτώνουν. Το καθένα δείχνει το όνομά του, την αγορά του, την έκδοσή του και τι κάνει.

- Ο διακόπτης απενεργοποιεί ή ενεργοποιεί ένα πρόσθετο χωρίς να το αφαιρεί.
- Ο κάδος το απεγκαθιστά, αφού επιβεβαιώσετε. Οι νέες συνεδρίες του Claude Code σταματούν να φορτώνουν τις δεξιότητες, τις εντολές και τους διακομιστές του.

### Βρείτε και εγκαταστήστε ένα πρόσθετο

Το **Περιήγηση** δείχνει κάθε πρόσθετο που μπορείτε να εγκαταστήσετε από τις αγορές σας, πρώτα τα πιο εγκατεστημένα, με το πόσες εγκαταστάσεις έχει το καθένα. Το **Αναζήτηση πρόσθετων** περιορίζει τη λίστα. Δείχνει 40 τη φορά: το **Εμφάνιση περισσότερων** προσθέτει άλλα 40.

Κάντε κλικ στο **Εγκατάσταση** και επιβεβαιώστε. Το πρόσθετο εγκαθίσταται για κάθε συνεδρία του Claude Code. Τα πρόσθετα μπορούν να προσθέσουν hooks και διακομιστές που εκτελούν εντολές σε αυτό το μηχάνημα, οπότε εγκαταστήστε μόνο πρόσθετα που εμπιστεύεστε.

Το Hydor ζητά από το Claude Code τη λίστα των πρόσθετων το πολύ κάθε 10 λεπτά, και ξανά μετά από κάθε αλλαγή. Η πρώτη φορά μπορεί να αργήσει.

### Αγορές πρόσθετων

Το **Αγορές** δείχνει τους καταλόγους από τους οποίους το Claude Code εγκαθιστά πρόσθετα.

- Για να προσθέσετε έναν, πληκτρολογήστε ένα owner/repo του GitHub, ένα URL git ή έναν φάκελο στο πλαίσιο κάτω από τη λίστα και κάντε κλικ στο **Προσθήκη**.
- Για να αφαιρέσετε έναν, κάντε κλικ στον κάδο του και επιβεβαιώστε. Τα πρόσθετα που εγκαταστάθηκαν από αυτόν απεγκαθίστανται επίσης.

## Ρωτήστε έναν πράκτορα

Οι πράκτορες μπορούν να τα κάνουν αυτά για εσάς, με τη δική σας έγκριση σε μια κάρτα. Δεν πληκτρολογούν ποτέ την τιμή ενός κλειδιού στην εφαρμογή: για ένα κλειδί ή για στοιχεία σύνδεσης, δείχνουν την κάρτα όπου τα εισάγετε.

- «Ποιοι λογαριασμοί είναι συνδεδεμένοι; Δοκίμασε το Notion και πες μου αν λειτουργεί.»
- «Σύνδεσε το Context7, ώστε οι πράκτορες να μπορούν να ψάχνουν την τεκμηρίωση βιβλιοθηκών.»
- «Απενεργοποίησε το Gmail για όλες τις συνεδρίες, αλλά κράτα το ενεργό σε αυτήν εδώ.»
- «Δείξε μου τα εργαλεία του Notion και απενεργοποίησε όσα διαγράφουν σελίδες.»
- «Πρόσθεσε έναν διακομιστή MCP για το Claude Code και το Codex που εκτελεί npx -y @modelcontextprotocol/server-memory, και μετά έλεγξε ότι συνδέεται.»
- «Δείξε μου τα πιο εγκατεστημένα πρόσθετα του Claude Code και μετά εγκατάστησε αυτό που θα διαλέξω.»
- «Συνδέσου στον λογαριασμό μου στο Voltaro και κατέβασε τα φετινά τιμολόγια σε αυτόν τον φάκελο.» (Την πρώτη φορά, ζητά τα στοιχεία σύνδεσης σε μια κάρτα.)
- «Κάνε push αυτόν τον κλάδο στο GitHub με το token που είναι στο θησαυροφυλάκιο.»
