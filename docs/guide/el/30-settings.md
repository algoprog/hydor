# Όλες οι ρυθμίσεις

Κάθε ενότητα των Ρυθμίσεων και ό,τι περιέχει, με τη σειρά που τις δείχνει η εφαρμογή, με σύνδεσμο προς την καθεμία και προς το μέρος αυτού του οδηγού που την εξηγεί. Χρησιμοποιήστε τη για να βρείτε πού ρυθμίζεται κάτι· τα θέματα εξηγούν πώς χρησιμοποιείται.

## Πώς είναι οργανωμένες οι Ρυθμίσεις

Ανοίξτε τις **Ρυθμίσεις** από την πλαϊνή στήλη. Σε υπολογιστή, οι Ρυθμίσεις έχουν τρεις καρτέλες επάνω: **Εφαρμογή** (η ίδια η εφαρμογή), **Πράκτορες** (οι πράκτορες και ό,τι διαβάζουν) και **Δυνατότητες** (ό,τι προσθέτει η εφαρμογή σε κάθε πράκτορα: αναζήτηση, πρόγραμμα περιήγησης, μνήμη και τα υπόλοιπα). Κάθε καρτέλα δείχνει τις ενότητές της αριστερά, και η ενότητα που ανοίγετε γεμίζει τη σελίδα. Σε κινητό, οι Ρυθμίσεις δείχνουν όλες τις ενότητες σε μία λίστα· πατήστε μία για να ανοίξει, και το βέλος επάνω για να επιστρέψετε.

Δεν χρειάζεται να ξέρετε πού βρίσκεται μια επιλογή: γράψτε αυτό που θέλετε στο πλαίσιο αναζήτησης (Ctrl+K, ⌘K σε Mac), για παράδειγμα «σκοτεινό θέμα» ή «ειδοποιήσεις», και επιλέξτε το. Η εφαρμογή ανοίγει τη σωστή ενότητα και δείχνει την επιλογή. Μπορείτε επίσης να ζητήσετε από οποιονδήποτε πράκτορα να αλλάξει μια ρύθμιση για εσάς ([Αφήστε τους πράκτορες να χειρίζονται την εφαρμογή για εσάς](/guide/ask-agents)).

## Εφαρμογή

### Γενικά

[Ρυθμίσεις → Γενικά](/settings?s=general): θέμα, και τι κάνει το Enter όσο δουλεύει ένας πράκτορας. Περισσότερα στο [Εμφάνιση, γλώσσα και ενημερώσεις](/guide/app).

- [**Θέμα**](/settings?s=general&find=Theme): Σκούρο, φωτεινό ή ανάλογα με τη συσκευή σας· ή ένα δικό σας θέμα.
- [**Νέο θέμα**](/settings?s=general&find=New%20theme): Φτιάξτε δικό σας θέμα από οποιοδήποτε από αυτά.
- [**Εισαγωγή**](/settings?s=general&find=Import): Προσθήκη θέματος που μοιράστηκε κάποιος.
- [**Γλώσσα**](/settings?s=general&find=Language): Η γλώσσα στην οποία εμφανίζεται η εφαρμογή και γράφουν οι πράκτορες.
- [**Αποστολή ενώ δουλεύει ο πράκτορας**](/settings?s=general&find=Sending%20while%20an%20agent%20works): Το Enter μπαίνει στον τρέχοντα γύρο ή περιμένει να τελειώσει.
- [**Προτάσεις τερματικού**](/settings?s=general&find=Terminal%20suggestions): Γκρι προτάσεις συμπλήρωσης μετά τον δρομέα στα τερματικά.
- [**Συνέχεια μετά από όρια χρήσης**](/settings?s=general&find=Resume%20after%20usage%20limits): Συνεχίζει μια συνεδρία ένα λεπτό αφού ανανεωθεί το όριο του προγράμματος.
- [**Διαγραφή ανενεργών συνεδριών**](/settings?s=general&find=Delete%20inactive%20sessions): Διαγράφει συνεδρίες που δεν χρησιμοποίησε κανείς για έναν χρόνο, ή όσο διαλέξετε· ως τότε κάθε συζήτηση κρατιέται.
- [**Εκκίνηση μαζί με τον υπολογιστή**](/settings?s=general&find=Start%20when%20this%20computer%20starts): Εκκινεί την εφαρμογή όταν ξεκινά ο υπολογιστής.
- [**Αυτόματη ενημέρωση**](/settings?s=general&find=Update%20automatically): Ενημερώνεται μόνο του όταν δεν το έχετε χρησιμοποιήσει για κάποιο διάστημα.
- [**Κάντε την περιήγηση**](/settings?s=general&find=Take%20the%20tour): Δείτε τι κάνει κάθε μέρος της εφαρμογής.
- [**Έλεγχος τώρα**](/settings?s=general&find=Check%20now): Έλεγχος για νεότερη έκδοση τώρα.

### Ειδοποιήσεις

[Ρυθμίσεις → Ειδοποιήσεις](/settings?s=notifications): όταν μια συνεδρία ολοκληρώνεται, αποτυγχάνει ή χρειάζεται την απάντησή σας. Περισσότερα στο [Εισερχόμενα και ειδοποιήσεις](/guide/inbox).

- [**Ειδοποιήσεις σε αυτή τη συσκευή**](/settings?s=notifications&find=Notify%20this%20device): Ειδοποίηση όταν μια συνεδρία ολοκληρώνεται, αποτυγχάνει ή χρειάζεται την απάντησή σας, ακόμη και με την εφαρμογή κλειστή.
- [**Ήχος**](/settings?s=notifications&find=Sound): Ένας σύντομος ήχος με κάθε ειδοποίηση όσο η εφαρμογή είναι ανοιχτή.
- [**Δοκιμαστική αποστολή**](/settings?s=notifications&find=Send%20a%20test): Αποστολή ειδοποίησης σε αυτή τη συσκευή τώρα.

### Κωδικός πρόσβασης

[Ρυθμίσεις → Κωδικός πρόσβασης](/settings?s=security): ο κωδικός πρόσβασης αυτής της εφαρμογής και η αποσύνδεση. Περισσότερα στο [Εμφάνιση, γλώσσα και ενημερώσεις](/guide/app).

- [**Αλλαγή κωδικού πρόσβασης**](/settings?s=security&find=Change%20password): Η αλλαγή του αποσυνδέει όλα τα άλλα προγράμματα περιήγησης.
- [**Αποσύνδεση από αυτό το πρόγραμμα περιήγησης**](/settings?s=security&find=Sign%20out%20of%20this%20browser): Χρειάζεστε τον κωδικό πρόσβασης για να επιστρέψετε.

### Έλεγχος εκδόσεων

[Ρυθμίσεις → Έλεγχος εκδόσεων](/settings?s=scm): λογαριασμοί GitHub και Gitea για άνοιγμα pull requests. Περισσότερα στο [Κινητά, άλλα μηχανήματα και κοινοποίηση](/guide/devices).

- [**Προσθήκη λογαριασμού**](/settings?s=scm&find=Add%20an%20account): Λογαριασμός για να ανοίγετε pull requests.

### Σύνδεση άλλων πρακτόρων

[Ρυθμίσεις → Σύνδεση άλλων πρακτόρων](/settings?s=connect): επιτρέψτε σε πράκτορες από αλλού να ξεκινούν και να κατευθύνουν συνεδρίες εδώ, μέσω του διακομιστή MCP αυτής της εφαρμογής. Περισσότερα στο [Κινητά, άλλα μηχανήματα και κοινοποίηση](/guide/devices).

- [**Νέο διακριτικό**](/settings?s=connect&find=New%20token): Ένα token για να ξεκινά και να καθοδηγεί συνεδρίες εδώ ένας πράκτορας από αλλού.
- [**Τι μπορούν να κάνουν**](/settings?s=connect&find=What%20they%20can%20do): Τα εργαλεία που παίρνει ένας πράκτορας με token.

### Μηχανήματα

[Ρυθμίσεις → Μηχανήματα](/settings?s=machines): άλλα μηχανήματα με το Naget Agent, για χρήση από εδώ, και πρόσβαση σε αυτό. Περισσότερα στο [Κινητά, άλλα μηχανήματα και κοινοποίηση](/guide/devices).

- [**Προσθήκη μηχανήματος**](/settings?s=machines&find=Add%20a%20machine): Ένα άλλο μηχάνημα που τρέχει το Naget Agent, για χρήση από εδώ.
- [**Πρόσβαση από άλλα μηχανήματα**](/settings?s=machines&find=Access%20from%20other%20machines): Tokens που χρησιμοποιούν άλλα μηχανήματα για να συνδεθούν σε αυτό.

## Πράκτορες

### Λογαριασμοί

[Ρυθμίσεις → Λογαριασμοί](/settings?s=accounts): οι συνδέσεις Claude Code και Codex που χρησιμοποιεί κάθε συνεδρία. Περισσότερα στο [Πράκτορες, λογαριασμοί και μοντέλα](/guide/agents-models).

- [**Οι συνδέσεις σας**](/settings?s=accounts&find=Your%20sign-ins): Οι λογαριασμοί Claude Code και Codex που χρησιμοποιούν οι συνεδρίες.
- [**Περισσότεροι λογαριασμοί**](/settings?s=accounts&find=More%20accounts): Ακόμη μία συνδρομή για έναν πράκτορα.
- [**Αλλαγή λογαριασμού στο όριο**](/settings?s=accounts&find=Switch%20accounts%20at%20a%20limit): Μια συνεδρία που εξαντλεί τη χρήση της συνεχίζει με άλλον λογαριασμό.
- [**Προγράμματα πρακτόρων**](/settings?s=accounts&find=Agent%20programs): Ποια προγράμματα πρακτόρων είναι εγκατεστημένα, και εγκατάσταση των υπολοίπων.

### Περισσότεροι πράκτορες

[Ρυθμίσεις → Περισσότεροι πράκτορες](/settings?s=agents): Gemini CLI, OpenCode, Qwen Code, Goose και άλλοι πράκτορες που μιλούν ACP. Περισσότερα στο [Πράκτορες, λογαριασμοί και μοντέλα](/guide/agents-models).

- [**Οι πράκτορές σας**](/settings?s=agents&find=Your%20agents): Πράκτορες που εμφανίζονται δίπλα στο Claude Code και το Codex.
- [**Προσθήκη δικού σας**](/settings?s=agents&find=Add%20your%20own): Οποιοσδήποτε πράκτορας που υποστηρίζει ACP, μέσω της εντολής του.
- [**Πράκτορες που μιλούν ACP**](/settings?s=agents&find=Agents%20that%20speak%20ACP): Gemini CLI, OpenCode, Qwen Code και Goose, έτοιμα για προσθήκη.

### Μοντέλα

[Ρυθμίσεις → Μοντέλα](/settings?s=models): μοντέλα για το Custom, τον δικό πράκτορα της εφαρμογής: OpenRouter, Ollama και μοντέλα Hugging Face που τρέχουν εδώ με vLLM. Περισσότερα στο [Πράκτορες, λογαριασμοί και μοντέλα](/guide/agents-models).

- [**Βοηθητικό μοντέλο**](/settings?s=models&find=Helper%20model): Το μοντέλο για μικρές δουλειές δίπλα στις συνεδρίες.
- [**Σε αυτό το μηχάνημα**](/settings?s=models&find=On%20this%20machine): Μοντέλα εγκατεστημένα εδώ και οι λήψεις τους.
- [**Προσθήκη μοντέλου από το Hugging Face**](/settings?s=models&find=Add%20a%20model%20from%20Hugging%20Face): Αναζητήστε, δείτε πώς θα έτρεχε το καθένα εδώ και εγκαταστήστε το.
- [**OpenRouter**](/settings?s=models&find=OpenRouter): Μοντέλα μέσω OpenRouter, με το κλειδί σας.
- [**Περιβάλλοντα εκτέλεσης και τελικά σημεία**](/settings?s=models&find=Runtimes%20and%20endpoints): Ollama, vLLM και άλλα τελικά σημεία συμβατά με OpenAI.
- [**Token Hugging Face**](/settings?s=models&find=Hugging%20Face%20token): Μόνο για μοντέλα με περιορισμένη πρόσβαση ή ιδιωτικά.

### Οδηγίες πρακτόρων

[Ρυθμίσεις → Οδηγίες πρακτόρων](/settings?s=guidelines): ό,τι ακολουθεί κάθε πράκτορας: σε κάθε συνεδρία, σε έναν χώρο ή σε μία συνεδρία. Περισσότερα στο [Οδηγίες πρακτόρων](/guide/guidelines).

- [**Για κάθε συνεδρία**](/settings?s=guidelines&find=For%20every%20session): Ό,τι ακολουθεί κάθε πράκτορας, σε κάθε συνεδρία.
- [**Για έναν χώρο**](/settings?s=guidelines&find=For%20a%20space): Οδηγίες που ακολουθούν οι συνεδρίες ενός χώρου.
- [**Για μία συνεδρία**](/settings?s=guidelines&find=For%20one%20session): Οδηγίες για μία συνεδρία, από την αρχική σελίδα ή το μενού της συνεδρίας.
- [**Αρχεία που διαβάζουν επίσης ο Claude Code και ο Codex**](/settings?s=guidelines&find=Files%20Claude%20Code%20and%20Codex%20read%20too): CLAUDE.md και AGENTS.md, που διαβάζουν μόνοι τους ο Claude Code και ο Codex.

### Διακομιστές MCP

[Ρυθμίσεις → Διακομιστές MCP](/settings?s=mcp): εργαλεία που μπορούν να καλούν οι πράκτορες. Περισσότερα στο [Συνδέσεις, κλειδιά και εργαλεία](/guide/connections).

- [**Προσθήκη διακομιστή**](/settings?s=mcp&find=Add%20server): Ένας διακομιστής εργαλείων για Claude Code ή Codex.
- [**Έλεγχος συνδέσεων**](/settings?s=mcp&find=Check%20connections): Δείτε αν απαντά κάθε διακομιστής MCP.

### Δεξιότητες

[Ρυθμίσεις → Δεξιότητες](/settings?s=skills): τεχνογνωσία που φορτώνουν οι πράκτορες όταν τη χρειάζεται μια εργασία. Περισσότερα στο [Δεξιότητες](/guide/skills).

- [**Νέα δεξιότητα**](/settings?s=skills&find=New%20skill): Γράψτε μια δεξιότητα για το Claude Code ή το Codex.

### Πρόσθετα

[Ρυθμίσεις → Πρόσθετα](/settings?s=plugins): πρόσθετα του Claude Code που περιλαμβάνουν δεξιότητες, εντολές, πράκτορες και διακομιστές MCP. Περισσότερα στο [Συνδέσεις, κλειδιά και εργαλεία](/guide/connections).

- [**Εγκατεστημένο**](/settings?s=plugins&find=Installed): Τα πρόσθετα που έχει το Claude Code.
- [**Περιήγηση**](/settings?s=plugins&find=Browse): Βρείτε πρόσθετα για εγκατάσταση.
- [**Αγορές**](/settings?s=plugins&find=Marketplaces): Από πού προέρχονται τα πρόσθετα.

- [**Νέα εργασία**](/settings?s=tasks&find=New%20task): Δουλειά πρακτόρων που ξεκινά μόνη της.
- [**Ξεκινήστε από ένα παράδειγμα**](/settings?s=tasks&find=Start%20from%20an%20example): Έτοιμες προγραμματισμένες εργασίες.
- [**Πρωινή ενημέρωση**](/settings?s=tasks&find=Morning%20brief): Μια έτοιμη προγραμματισμένη εργασία.
- [**Ειδήσεις για ένα θέμα**](/settings?s=tasks&find=News%20on%20a%20topic): Μια έτοιμη προγραμματισμένη εργασία.
- [**Παρακολούθηση τιμής**](/settings?s=tasks&find=Price%20watch): Μια έτοιμη προγραμματισμένη εργασία.
- [**Ειδοποίηση αλλαγής σελίδας**](/settings?s=tasks&find=Page%20change%20alert): Μια έτοιμη προγραμματισμένη εργασία.
- [**Εβδομαδιαία αναφορά από έναν φάκελο**](/settings?s=tasks&find=Weekly%20report%20from%20a%20folder): Μια έτοιμη προγραμματισμένη εργασία.
- [**Σύνοψη Εισερχομένων**](/settings?s=tasks&find=Inbox%20digest): Μια έτοιμη προγραμματισμένη εργασία.
- [**Έλεγχος συνηθειών**](/settings?s=tasks&find=Habit%20check-in): Μια έτοιμη προγραμματισμένη εργασία.
- [**Νέες εκδόσεις**](/settings?s=tasks&find=New%20releases): Μια έτοιμη προγραμματισμένη εργασία.
- [**Έλεγχος λειτουργίας ιστοτόπου**](/settings?s=tasks&find=Site%20up%20check): Μια έτοιμη προγραμματισμένη εργασία.
- [**Ειδοποίηση για χώρο στον δίσκο**](/settings?s=tasks&find=Disk%20space%20alert): Μια έτοιμη προγραμματισμένη εργασία.
- [**Έλεγχος νέων pull request**](/settings?s=tasks&find=Review%20new%20pull%20requests): Μια έτοιμη προγραμματισμένη εργασία.
- [**Νέα αρχεία σε φάκελο**](/settings?s=tasks&find=New%20files%20in%20a%20folder): Μια έτοιμη προγραμματισμένη εργασία.
- [**Υπενθύμιση**](/settings?s=tasks&find=Reminder): Μια έτοιμη προγραμματισμένη εργασία.

## Δυνατότητες

### Αναζήτηση

[Ρυθμίσεις → Αναζήτηση](/settings?s=search): πώς αναζητούν οι πράκτορες στο διαδίκτυο: Naget Search και άλλοι πάροχοι. Περισσότερα στο [Αναζήτηση και πρόγραμμα περιήγησης](/guide/web).

- [**Πάροχοι**](/settings?s=search&find=Providers): Ποιους παρόχους αναζήτησης χρησιμοποιούν οι πράκτορες και με ποια σειρά.
- [**Naget Search**](/settings?s=search&find=Naget%20Search): Η αναζήτηση ιστού της ίδιας της εφαρμογής.
- [**SearXNG**](/settings?s=search&find=SearXNG): Μια μηχανή αναζήτησης που τρέχετε εσείς.
- [**Brave Search**](/settings?s=search&find=Brave%20Search): Αναζήτηση στο διαδίκτυο με κλειδί Brave.
- [**DuckDuckGo**](/settings?s=search&find=DuckDuckGo): Αναζήτηση στο διαδίκτυο χωρίς κλειδί.
- [**Αποτελέσματα ανά αναζήτηση**](/settings?s=search&find=Results%20per%20search): Πόσα αποτελέσματα δίνει μια αναζήτηση.

### Πρόγραμμα περιήγησης

[Ρυθμίσεις → Πρόγραμμα περιήγησης](/settings?s=browser): ένα πρόγραμμα περιήγησης που χρησιμοποιούν οι πράκτορες, το οποίο μπορείτε να παρακολουθείτε και να αναλάβετε τον έλεγχό του. Περισσότερα στο [Αναζήτηση και πρόγραμμα περιήγησης](/guide/web).

- [**Πρόγραμμα περιήγησης για πράκτορες**](/settings?s=browser&find=A%20browser%20for%20agents): Οι πράκτορες ανοίγουν ιστότοπους, κάνουν κλικ, πληκτρολογούν και διαβάζουν σελίδες.
- [**Chromium**](/settings?s=browser&find=Chromium): Ποιο Chromium εκτελεί το πρόγραμμα περιήγησης.
- [**Εμφάνιση παραθύρου**](/settings?s=browser&find=Show%20a%20window): Εκτέλεση του προγράμματος περιήγησης σε παράθυρο που βλέπετε.
- [**Οι σελίδες να μη φτάνουν σε αυτό το μηχάνημα και στο δίκτυό του**](/settings?s=browser&find=Keep%20pages%20off%20this%20machine%20and%20its%20network): Οι ιστότοποι σε αυτόν τον υπολογιστή και στο δίκτυό του μένουν εκτός ορίων.
- [**Στιγμιότυπα οθόνης για μοντέλα που βλέπουν εικόνες**](/settings?s=browser&find=Screenshots%20for%20models%20that%20see%20images): Τα μοντέλα που βλέπουν εικόνες παίρνουν στιγμιότυπα της σελίδας.
- [**Ιστότοποι**](/settings?s=browser&find=Sites): Μόνο αυτοί οι ιστότοποι ή ποτέ αυτοί.
- [**Προφίλ**](/settings?s=browser&find=Profiles): Ξεχωριστές συνδέσεις για το πρόγραμμα περιήγησης.

### Μνήμη

[Ρυθμίσεις → Μνήμη](/settings?s=memory): τι θυμούνται οι πράκτορες για εσάς, τα έργα σας και κάθε συνεδρία, και πότε γράφτηκε. Περισσότερα στο [Μνήμη](/guide/memory).

- [**Μνήμη**](/settings?s=memory&find=Memory): Οι πράκτορες ξεκινούν με ό,τι κράτησαν προηγούμενες συνεδρίες και αποθηκεύουν σημειώσεις όταν το ζητάτε.
- [**Αναζήτηση βάσει νοήματος**](/settings?s=memory&find=Search%20by%20meaning): Βρίσκει σημειώσεις, και οτιδήποτε σε αυτή την αναζήτηση, με βάση το νόημα.
- [**Τακτοποίηση κάθε βράδυ**](/settings?s=memory&find=Tidy%20up%20each%20night): Το βοηθητικό μοντέλο συγχωνεύει σημειώσεις που λένε το ίδιο και συνοψίζει τις σχετικές.
- [**Τακτοποίηση τώρα**](/settings?s=memory&find=Tidy%20up%20now): Τακτοποιεί τη μνήμη αμέσως.
- [**Σημειώσεις**](/settings?s=memory&find=Notes): Κάθε σημείωση που φυλάσσεται, ανά θέση.
- [**Προσθήκη σημείωσης**](/settings?s=memory&find=Add%20a%20note): Γράψτε μια σημείωση για να τη θυμούνται οι πράκτορες, για εσάς ή για ένα έργο.
- [**Διαγραμμένες σημειώσεις**](/settings?s=memory&find=Deleted%20notes): Σημειώσεις που διαγράφηκαν τις τελευταίες 30 ημέρες, για επαναφορά.
- [**Εξαγωγή**](/settings?s=memory&find=Export): Όλες οι σημειώσεις σε Markdown για ανάγνωση ή σε JSON με το ιστορικό τους.
- [**Εκκαθάριση όλων…**](/settings?s=memory&find=Clear%20all%E2%80%A6): Διαγράφει κάθε σημείωση και το ιστορικό της.

### Θυγατρικές συνεδρίες

[Ρυθμίσεις → Θυγατρικές συνεδρίες](/settings?s=children): πράκτορες που αναθέτουν μέρη μιας δουλειάς σε άλλους πράκτορες, και σμήνη για δύσκολα προβλήματα. Περισσότερα στο [Σε βάθος έρευνα, δεύτερες γνώμες και πολλοί πράκτορες](/guide/research).

- [**Ταυτόχρονα σε εργασία, ανά συνεδρία**](/settings?s=children&find=Working%20at%20once%2C%20per%20session): Πόσες θυγατρικές συνεδρίες τρέχει ταυτόχρονα μία συνεδρία.
- [**Μέγεθος σμήνους**](/settings?s=children&find=Swarm%20size): Πόσοι πράκτορες ενός σμήνους δουλεύουν ταυτόχρονα.

### Εικόνες

[Ρυθμίσεις → Εικόνες](/settings?s=images): εικόνες που φτιάχνουν οι πράκτορες για εσάς, με ένα μοντέλο εικόνων μέσω OpenRouter. Περισσότερα στο [Έγγραφα, εικόνες και φωνή](/guide/documents-voice).

- [**Δημιουργία εικόνων**](/settings?s=images&find=Making%20images): Επιτρέψτε στους πράκτορες να φτιάχνουν εικόνες.
- [**Μοντέλο εικόνων**](/settings?s=images&find=Image%20model): Το μοντέλο που τις φτιάχνει.

### Συνδέσεις

[Ρυθμίσεις → Συνδέσεις](/settings?s=connections): εφαρμογές που μπορεί να χρησιμοποιεί κάθε πράκτορας, από μια αγορά στην οποία μπορεί να προσθέσει ο καθένας, και ένα θησαυροφυλάκιο για κλειδιά. Περισσότερα στο [Συνδέσεις, κλειδιά και εργαλεία](/guide/connections).

- [**Αγορά**](/settings?s=connections&find=Marketplace): Εφαρμογές που μπορεί να χρησιμοποιεί κάθε πράκτορας, με μία μόνο σύνδεση.
- [**Προσθήκη κλειδιού**](/settings?s=connections&find=Add%20a%20key): Ένα κλειδί που οι πράκτορες χρησιμοποιούν χωρίς να το βλέπουν.

### Φωνή

[Ρυθμίσεις → Φωνή](/settings?s=voice): υπαγορεύστε μηνύματα και ακούστε τις απαντήσεις φωναχτά. Περισσότερα στο [Έγγραφα, εικόνες και φωνή](/guide/documents-voice).

- [**Υπαγόρευση**](/settings?s=voice&find=Dictation): Πείτε ένα μήνυμα αντί να το πληκτρολογήσετε.
- [**Γλώσσα που μιλάτε**](/settings?s=voice&find=Language%20you%20speak): Η γλώσσα που αναγνωρίζει η υπαγόρευση.
- [**Αναγνώριση ομιλίας στον διακομιστή**](/settings?s=voice&find=Speech%20recognition%20on%20the%20server): Αναγνώριση ομιλίας σε αυτόν τον υπολογιστή ή με μια υπηρεσία.
- [**Ανάγνωση φωναχτά**](/settings?s=voice&find=Read%20aloud): Ανάγνωση των απαντήσεων φωναχτά.

### Βοηθοί

[Ρυθμίσεις → Βοηθοί](/settings?s=assistants): προεπιλογές για να ξεκινούν οι συνεδρίες (Ερευνητής, Συγγραφέας, Δάσκαλος…), και πού πηγαίνουν οι φάκελοι εργασιών. Περισσότερα στο [Βοηθοί](/guide/assistants).

- [**Νέος βοηθός**](/settings?s=assistants&find=New%20assistant): Μια προεπιλογή για να ξεκινάτε συνεδρίες.
- [**Καθαρισμός μετά από μια εργασία**](/settings?s=assistants&find=Clean%20up%20after%20a%20task): Οι πράκτορες αφαιρούν ό,τι έφτιαξαν στην πορεία και δεν χρειάζονται πια.
- [**Φάκελοι εργασιών**](/settings?s=assistants&find=Task%20folders): Πού πηγαίνουν οι νέοι φάκελοι εργασιών ενός βοηθού.

### Βιβλιοθήκη δεξιοτήτων

[Ρυθμίσεις → Βιβλιοθήκη δεξιοτήτων](/settings?s=skillpack): δεξιότητες που συνοδεύουν την εφαρμογή, και όσες έμαθαν οι πράκτορες με την έγκρισή σας. Περισσότερα στο [Δεξιότητες](/guide/skills).

- [**Μαθημένες**](/settings?s=skillpack&find=Learned): Δεξιότητες που έμαθαν οι πράκτορες με την έγκρισή σας.
- [**Ενσωματωμένο**](/settings?s=skillpack&find=Built%20in): Δεξιότητες που συνοδεύουν την εφαρμογή.
- [**Φόρτωση δεξιοτήτων με λέξεις-κλειδιά**](/settings?s=skillpack&find=Bring%20skills%20in%20by%20keywords): Λέξεις-κλειδιά σε ένα μήνυμα φορτώνουν δεξιότητες από μόνες τους.

### Custom

[Ρυθμίσεις → Custom](/settings?s=custom): αυτόματη λειτουργία, απομονωμένο περιβάλλον για τις εντολές και πόση ώρα τρέχουν οι στόχοι. Περισσότερα στο [Custom, ο πράκτορας της ίδιας της εφαρμογής](/guide/custom).

- [**Αυτόματη λειτουργία**](/settings?s=custom&find=Auto%20mode): Ο Custom εγκρίνει μόνος του τα ασφαλή βήματα.
- [**Απομόνωση εντολών**](/settings?s=custom&find=Sandbox%20for%20commands): Οι εντολές εκτελούνται σε απομονωμένο περιβάλλον.
- [**Στόχοι**](/settings?s=custom&find=Goals): Πόσους γύρους μπορεί να τρέξει ένας στόχος.
