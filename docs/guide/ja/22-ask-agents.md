# エージェントにアプリを操作してもらう

ここのエージェントはすべてこのガイドを把握していて、アプリの操作を代わりに行えます。使い方を尋ねると、ガイドをもとに答え、該当する場所へのリンクも示します。設定の変更やセットアップ（プロジェクト、エージェント、スケジュールタスクなど）を頼むと、カードで確認したうえで実行します。詳細が必要なときは、入力用のフォームが表示されます。

![エージェントが設定を変更しているところ：変更前に、カードで内容を確認できます](images/ask-agents.webp)

## やり方を尋ねる

どのセッションでも、どのエージェントにでも、人に尋ねるようにアプリのことを質問できます。「このセッションを同僚と共有するには？」「スマートフォンで通知をオンにする場所は？」「自動モードは何をするの？」など。エージェントはこのガイドを調べて答えるので、現在のアプリの状態に沿った説明になり、リンクを開くと該当の場所に移動します。

ガイドは自分で読むこともできます。アイコンバーの**ヘルプ**を開くか、検索ボックス（Ctrl+K、Macでは⌘K）で検索すると、該当するセクションが**ガイド**の下に表示されます。ヘルプでは、上部のボックスに質問を入力してEnterを押すとエージェントに送られ、回答がガイドの横に表示されます（[ヘルプを使う](/guide/start#get-help)を参照）。

## 設定の変更やセットアップをエージェントに頼む

アプリのページで行える操作は、エージェントにもできます。頼める内容の例です。

- 「意味で検索をオンにして。」
- 「メモリの設定はどうなってる？」「オフになっている設定はどれ？」
- 「博士論文用に、リサーチャーエージェントで『Thesis』というプロジェクトを作って。」
- 「毎週金曜の5時に、未読のニュースレターを要約するエージェントを作って。」
- 「平日の朝8時に、再生可能エネルギーのニュースまとめを送って。」
- 「ガイドラインに、回答は短くするよう追加して。」
- 「DuckDuckGoより先にBrave Searchを使って。」
- 「前の職場に関するメモリのメモを削除して。」
- 「どんなアプリがある？ 旅行プランナーで、リスボンの週末旅行を作って。」
- 「このデバイスをライトテーマに切り替えて。」
- 「このセッションではOpusを使って、もっとよく考えて。」「プランモードを終了して進めて。」

エージェントはまず現在の状態を読み取り、そのうえで会話内のカードで変更の確認を求めます。読み取りに確認は不要です。エージェントは設定、プロジェクト、タスクなどをいつでも確認して回答できます。設定のすべての項目と、それぞれが今どうなっているかも把握しているので、どの項目についても説明でき、どの項目も変更できます。本人だけが変更できるごく一部（パスワード、サインイン、キーの値、デバイスでの通知のオン）については、どこで行うかを案内します。

## エディタの操作をエージェントに任せる

エージェントは、エディタで行うのと同じように保存した内容を変更できます。スライド、ドキュメント、スプレッドシート、LaTeXドキュメント、ノートブック、図を作成でき、エディタでクリック1つで全体に行う操作もまとめて実行します。

- **スライド**：すべてのスライドにアニメーションを付ける（**控えめ**、**にぎやか**、**印象的**から選択。すべて外すことも可能）、**アクセシビリティをチェック**で見つかった問題を修正する、説明のない画像に説明を付ける、プレゼンテーションをPowerPoint互換にする、またはWeb形式に戻す、用意されたテーマや自分のテーマを適用する、スライドをワイドまたは標準サイズにする、別のプレゼンテーションからスライドを取り込む、スプレッドシートから作ったグラフを更新する。
- **ドキュメント**：提案された変更を承認または却下する、ページ設定を変更する、ヘッダー、フッター、ページ番号を入れる。
- **スプレッドシート**：表を並べ替える、重複行を取り除く、下方向や右方向に埋める、セルをクリアする、余分な空白を削除する、語句を列に分割する、表を新しいシートに集計する（**データ → 集計の基準**と同じ）、行や列を挿入または削除する、シートの名前変更、コピー、移動、削除を行う。数式はエディタと同様に追従します。
- **LaTeXドキュメント**：ファイル、画像、フォルダの名前変更や移動。それらを参照する行も追従します。
- **ノートブック**：出力をクリアする。
- **図**：1ページ（またはすべてのページ）を、下向きや横向きのフローチャート、ツリー、マインドマップ、リング、円、グリッドとして配置し直す。すべての図形を同じ見た目に、文字を同じフォントに、図全体を手描き風にそろえる。
- **共通**：コピーを新しいものとして保存する、または別の種類に作り替える（**変換**）。

どの操作も新しいバージョンとして保存され（元のバージョンはバージョン履歴に残ります）、開いているエディタには即座に反映されます。自分で加えた変更やコメントはそのまま残ります。画像の説明付けはモデルが行いますが、それ以外は無料で即座に完了します。ページの横にあるエージェント（[エージェントに頼んで変更する](/guide/library#change-it-by-asking-an-agent)）は、これらをすべて把握していて、選択している内容も正確に分かります。例：

- 「『Launch plan』のスライドすべてに、にぎやかなアニメーションを付けて、アクセシビリティチェックで見つかった問題を直して。」
- 「『Launch plan』のスライドをPowerPoint互換にして。」
- 「『Budget』ドキュメントのMariaの提案を承認して、残りは却下して。」
- 「『Sales』スプレッドシートで、表を売上の多い順に並べ替えて、重複行を取り除いて。」
- 「LaTeXの論文で、画像をfigures/からimg/に移動して。」
- 「『Checkout flow』の図を左から右に配置し直して、すべての図形を青にして。」

## カード：変更の確認

エージェントが何かを変更する前に、会話内にカードが表示されます（[受信トレイ](/inbox)にも届き、離席中は通知されます）。カードには次の内容が表示されます。

- **変更の概要**：エージェントの言葉で、「プロジェクト『Thesis』を作成する」のように表示されます。
- **変更内容**：項目ごとの変更点。設定の現在値と変更後の値（「**結果**：10 → 20」）や、新しく作るものの内容が示されます。
- **呼び出しの内容**：小さな文字で表示されます（例：`PUT /api/search/settings`）。エージェントの説明にかかわらず、実際に行われる処理を確認できます。自分のエージェントに関するカードでは、代わりにエージェントそのものが表示されます。どんなエージェントになるか、または何が変わるかが文章で示され、各スケジュールがいつ実行されるかも表示されます。

そのうえで、次のいずれかを選びます。

- **許可**：変更を実行します。
- **このセッションで許可**：変更を実行し、このセッションでは同じ種類の日常的な変更を、以降は確認なしで行えるようにします。毎回確認が必要な変更（下記）は、引き続き確認されます。
- **しない**（または**辞退**）：何も変更しません。理由や代わりにしてほしいことを伝えると、エージェントがそれを読み取ります。

**このセッションで許可**を選んだ後でも、毎回確認が必要な変更があります。何かの削除、セッションやスケジュールタスクの実行の開始、エージェントのスケジュールの追加・変更・削除、別のセッションへのメッセージ送信、MCPサーバーの追加、プラグインの追加・有効化・変更、Customやブラウザでエージェントに許可する内容の変更、マシンやアカウントの追加、モデルのダウンロード、このコンピューターでの画像ツールのセットアップ、アプリの更新です。削除の場合、ボタンは**削除**と表示されます。新しいエージェントでは**エージェントを作成**、エージェントの変更では**保存**と表示されます。

自分のエージェントに**フルアクセス**（確認なしで動く）を与える操作は、このセッションにフルアクセスがあっても、セッション自身の権限と同じように、毎回確認されます。

カードは約9分間待機します。それまでに答えないとカードは消え、エージェントが返信の中で改めて尋ねます。

## エージェントが詳細を必要とするとき：フォーム

エージェントがいくつかの情報を必要とするとき、質問を並べる代わりに、会話内にフォームを表示できます。旅行の日程と予算、新しいアプリの名前とフィールドなどです。入力してボタン（**送信**、またはエージェントが付けた名前）をクリックします。**今はしない**でフォームを閉じると、エージェントはフォームなしで続行するか、言葉で尋ねます。

フォームは必要なだけ待機します。約9分以内に回答がないと、エージェントはそこでターンを終了し、フォームは会話内に残ります。エージェントが停止したりアプリが再起動したりしても残ります。入力すると、回答は次のメッセージ（「…への回答」）としてエージェントに送られ、続きから進みます。届かなかった場合は、フォームが残るので、もう一度送信できます。画面より縦に長いフォームは先頭から開き、**最新**で末尾に移動できます。

変更用のカードにフォームが付くこともあります。「プロジェクトを作成」では、エージェントが推測した名前、説明、ガイドラインが表示され、**保存**をクリックする前に修正できます。

## エージェントにできないこと

一部の操作は、ユーザー自身だけが行えます。エージェントが試みると、どこで行えばよいかが案内されます。

- パスワードと、サインインおよびサインアウト（[設定 → パスワード](/settings?s=security)、[アカウント](/settings?s=accounts)）。
- キーやサインインの値：エージェントは、保管庫に入力するためのカードで依頼します。値そのものは見えません（[接続済みアプリ、キー、ツール](/guide/connections)）。OpenRouterキーには専用のカードがあり、設定 → モデルに直接保存されます（[エージェントがOpenRouterキーを必要とするとき](/guide/documents-voice#when-an-agent-needs-the-openrouter-key)）。
- 他のマシンやエージェント向けのアクセストークン、アプリのAPIキーの作成。
- 承認カードへの回答（自分のセッションのものも他のセッションのものも）、およびユーザーに判断を求めるカード（提案されたスキル、スケジュールタスク、公開）の決定。
- アプリ経由でのファイル、コマンド、ターミナル、Gitの操作：エージェントは自分のツールを使い、セッションの権限に応じて確認が求められます。
- エディタ独自のAIツール、および画像・動画エディタ：エージェントは、独自のツールで画像、図、プロット、動画を作成、検索、変更、編集し、結果はセッションのフォルダに保存されます（[ドキュメント、画像、動画、音声](/guide/documents-voice)）。また、各スライドのメモを読み上げるナレーションを付けることもできます。

## 権限とカード

セッションの権限によって、カードで確認される範囲が決まります。

- **プラン**（Codexでは**読み取り専用**）：エージェントはアプリの設定を読み取って質問に答えられますが、何も変更しません。変更する場合の内容を伝えます。例外は自分のセッションの設定です。プランモードの終了、別のモデルの使用、より深い思考を頼むと、カードで確認されます。
- **質問**、**編集を承認**、**自動**など：変更はカードで確認されます（上記のとおり）。
- **バイパス**（Claude Code）と**フルアクセス**（Codex）：カードは表示されず、エージェントは頼まれた変更をそのまま行います。エージェントが詳細を必要とするときは、フォームが表示されます。
- Customの**フルアクセス**：承認カードは表示されません。通常は毎回確認される変更も同様です。詳細が必要なときは、フォームが表示されます。

権限の種類にかかわらず、セッションの権限や支出上限の変更は、毎回カードで確認されます。**このセッションで許可**は表示されません。「このセッションをバイパスに切り替える」「上限を$20に引き上げる」などです。アプリでもターミナルでも頼めます。ターミナルでも同じカードが表示され、**y**または**n**で回答します。

## デバイスごとの設定

一部の設定は、アプリ全体ではなくデバイスごとのものです。テーマ、言語、動きと文字サイズ、通知音、エージェントの作業中にEnterを押したときの動作、ターミナルの入力候補、サイドバーの表示、音声（話す言語、音声入力の聞き取り方、返信を読み上げる音声とその速さ）です。アプリの開いているページは、そのデバイスが何を保持しているかをエージェントに伝えるため、エージェントはこれらの設定を答えることも変更することもできます。変更は、話しかけているデバイス（そのセッションを表示しているページ）に対して、カードなしで行います。「ダークテーマに切り替えて」「Sageテーマを使って」「アプリをギリシャ語で表示して」「返信の読み上げを少し速くして」などです。他のデバイスの設定は変わりません。チャットアプリやターミナルから書き込むなど、そのセッションを表示しているページがないときは、アプリを開いている別のデバイスの設定を変更できます。「ノートパソコンの文字を大きくして」。通知は例外です。ブラウザが許可を求めるため、通知はデバイスごとに自分でオンにします。

## エージェントに頼んでみる

- 「スマートフォンで通知を受け取るには？」
- 「庭のプロジェクト用に新しいプロジェクトを作って、ガイドラインに『寒冷な地域に住んでいる』と入れて。」
- 「ブラウザのスクリーンショットをオフにして。」
- 「スケジュールタスクを一覧で見せて、価格ウォッチをオフにして。」
- 「このデバイスをライトテーマに切り替えて。」
- 「今の設定を全部教えて。」
- 「このセッションを、思考レベルを低にしてSonnetに切り替えて。」
