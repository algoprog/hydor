# ドキュメント、画像、動画、音声

Hydorのエージェントは、PDF、Word、Excel、PowerPointなどのドキュメントを読み、新しいドキュメントを作り、開いたりダウンロードしたりできるカードとして渡します。また、画像、図、プロット、短い動画を作ったり、無料の写真を探したり、画像や動画を加工したり（切り抜き、背景の除去、消去、トリミング）、曲、ナレーション、効果音を作ったりもできます。これには、画像・動画・音声のモデムと、このコンピューターにあるツールを使います。作ったものはプロジェクトのファイルに保存できます。さらに、入力の代わりに声で話しかけたり、返信を読み上げさせたり、歩きながらハンズフリーでアプリと会話したりもできます。

![レポートを読み、1ページのWordの要約と、グラフ付きのスプレッドシートを作ったエージェント](images/documents-voice.webp)

## エージェントにドキュメントを読ませる

アプリで動くエージェントは、どれもドキュメントを読めます。Claude Code、Codex、Custom、そしてACPに対応しMCPサーバーを使えるエージェントです。事前に変換する必要はありません。次のいずれかの方法でドキュメントを渡します。

1. **メッセージに添付する**：メッセージ欄のクリップのアイコン（**ファイルを添付**）を使うか、ファイルを欄にドラッグするか、貼り付けます。画像は画像のままモデルに渡されます。それ以外のファイルは、Hydorを実行しているコンピューターに保存され、エージェントが開けるようにそのパスがメッセージに追加されます。1回のメッセージで添付できるファイルは合計25 MBまでです。
2. **このコンピューター上のファイルを指定する**：「~/Documents/lease.pdf を要約して」のように伝えます。`/` や `~` で始まらないパスは、セッションのフォルダが起点になります。
3. **プロジェクトや共有ナレッジにドキュメントを置く**：セッションから検索してページを引用できます。詳しくは[プロジェクトとナレッジ](/guide/projects)をご覧ください。

エージェントが読んでいる間、作業の表示は**lease.pdfを読み込み中**、続いて**lease.pdfを読み込みました**となります。画面が広い場合は、その行にドキュメントの種類、ページ・シート・スライドの数、読み取った行も表示されます。行をクリックすると、エージェントが受け取ったテキストを確認できます。**lease.pdfを開く**をクリックすると、ファイルそのものを確認できます。

長いドキュメントは、1回に約1,200行ずつ分けて読み込まれ、続きがあることはエージェントに伝えられます。エージェントには、ドキュメントに書かれた内容は情報として扱い、指示としては扱わないよう指示されています。ドキュメント内のものは何も実行されません。マクロは実行されず、WebリンクとメールのリンクだけがKeepされます。

Customも、通常のファイル読み取りでPDF、Officeドキュメント、画像を読めます。詳しくは[Custom、アプリ独自のエージェント](/guide/custom)をご覧ください。

## エージェントがドキュメントから読み取れるもの

### PDF

- 各ページのテキスト。ページ上のレイアウトに沿って読み取られます。
- pdftotextプログラム（poppler-utils内）を使うと最も正確です。ない場合は、アプリがpdf.jsを一度だけ取得します（約35 MB、初回のみインターネット接続が必要）。その場合、レイアウトはおおよそのものになります。
- スキャンしたページにはテキストがなく、エージェントにはどのページかが伝えられます（「3、5～7ページにテキストがありません」）。**pdf**スキルを使うと、それらのページを画像として見て自分で読み取るか、tesseractがインストールされていればOCRを実行します。
- パスワードで保護されたPDFは読み取れません。エージェントにパスワードを伝えると、**pdf**スキルがロックを解除したコピーを作ります。パスワードなしで開けるものの変更が制限されているPDF（多くの公的なフォームなど）は、ほかのPDFと同じように読み取れます。
- **フォーム**：エージェントはPDFのフォームフィールドを一覧にし、それぞれの横に印刷されている文言（「f1_02」というフィールドが何のためのものかを示します）を添えます。また、フィールドに番号を振り、ポイント単位の定規を付けた画像として各ページを確認します。
- **ハイライトとメモ**：ファイルのリーダーでページごとにハイライトした内容に、メモと、選んだ図や数式の画像を添えて読み取ります（[PDFを読んでハイライトする](/guide/files-git#read-and-highlight-a-pdf)）。要約したり、論文と照らし合わせたりできます。頼めば、エージェントが語句をハイライトすることもでき、リーダーに表示されます。

### Word、Excel、PowerPoint

- **Word**（.docx、およびそのマクロ形式とテンプレート形式）：見出し、段落、番号付きリストと箇条書き、表、リンク、テキストボックス、説明による画像、脚注、文末脚注、コメント。
- **Excel**（.xlsx、およびそのマクロ形式とテンプレート形式）：すべてのシートを行番号と列の文字付きの表として読み取り、数値は書式（日付、パーセント、金額）にほぼ沿った形になり、各シートの数式は最大40件まで読み取られます。非表示のシートには印が付きます。各シートは最初の2,000行と60列まで読み取られ、それを超える場合はエージェントに伝えられます。大きなシートを全部読み込みたいときは、**spreadsheets**スキルが別の方法で読み込みます。
- **PowerPoint**（.pptx、およびそのマクロ形式、テンプレート形式、スライドショー形式）：各スライドのタイトル、テキスト、表、画像（説明による）、グラフ（タイトルとデータ系列）、スピーカーノート。非表示のスライドには印が付きます。最大1,000枚のスライドまで読み取れます。

### OpenDocument、EPUB、CSV、RTF

- **OpenDocument**（LibreOfficeの.odt、.ods、.odp、それらのテンプレート、および.odg）：見出し、リスト、表、リンク、脚注を含むテキスト、表示どおりのシート、タイトル・テキスト・ノート付きのスライド。
- **EPUB**の本：見出し、リスト、表、引用を含む、読む順に並んだ章。
- **CSV**と**TSV**の表、**RTF**のテキスト。

### 古いOfficeファイル、保護されたファイル、非常に大きなファイル

- 古い.doc、.xls、.pptファイルは、LibreOfficeで現行の形式に変換してから読み取られます。LibreOfficeがない場合は読み取れず、エージェントは.docx、.xlsx、.pptxで保存し直したファイルを求めるか、LibreOfficeをインストールするよう伝えます。
- パスワードで保護されたWord、Excel、PowerPointのファイルは読み取れません。
- 300 MBまでのファイルを読み取れます。1つのドキュメントから読み取れるテキストは約1,000,000文字（約250,000トークン）までで、それを超えると切り捨てられ、そのことがエージェントに伝えられます。

## エージェントにドキュメントを作らせる

アプリには、すべてのエージェントが読み込めるドキュメント用のスキルが4つ付属しています。**word-documents**、**spreadsheets**、**presentations**、**pdf**です。[設定 → スキル](/settings?s=skills&find=Built%20in)の**ドキュメント**にあります（[スキル](/guide/skills)を参照）。スキルを選ぶ必要はありません。普通の言葉で頼めば（「私のメモから1ページの履歴書をWordドキュメントで作って」「この経費を月ごとの合計とグラフ付きのスプレッドシートにして」「ミツバチについての発表用に8枚のスライドを作って」「この3つのPDFを結合して」）、エージェントが必要に応じて適切なスキルを読み込みます。

どのスキルも、次の流れで動きます。

1. エージェントが最初にドキュメントの構成、つまりアウトライン、シート、スライドを計画します。
2. セッションのフォルダで、短いスクリプトを使ってファイルを書き出します。
3. 結果をページ画像として確認し、テキストがページからはみ出していないか、表が収まっているか、スライドが詰め込みすぎていないかを調べ、問題があれば直します。
4. 短い説明を添えて、返信の下にカードとしてファイルを渡します（[エージェントが作ったファイルを開く・ダウンロードする](/guide/documents-voice#open-or-download-the-files-an-agent-made)を参照）。

ユーザーのファイルを変更する場合、上書きを頼まれていない限り、結果は新しい名前で保存されます。

### Wordドキュメント

レポート、手紙、履歴書、メモ、契約書、フォーム、配布資料、ノートなど。Word、Googleドキュメント、Pagesで開けます。

- 本物の構造：見出し（Wordのナビゲーションウィンドウやスクリーンリーダーで使えます）、箇条書きと番号付きリスト、ヘッダー行のある表、画像、改ページ。
- 目次（ファイルを開いたときにWordが内容を埋めます）、ページ番号（「1/3ページ」）、リンク、網掛けの表のセル。
- A4またはUSレターのサイズと、どのコンピューターでも同じ見た目になるフォント（Calibri、Arial、Cambria、Times New Roman）。
- ユーザー自身のドキュメントを、スタイル、ヘッダー、レイアウトを保ったまま、その場で変更。書式を失わずにテキストを置き換え、コメントを追加。
- 保存済みの署名での署名：{{signature}}の代わりに、「署名：」などの文言のすぐ後、表のセル、または末尾に入れます。カードで許可した場合に限ります（[署名](/guide/library#signatures)）。
- LibreOffice経由でのPDF化も可能。

### スプレッドシート

予算、管理表、スケジュール、請求書、データの表（.xlsx）。

- 数値は値として、結果は数式として入るので、数値を変えるとほかの部分も連動して変わります。
- 金額、パーセント、日付の表示形式、常に表示される太字のヘッダー行、列幅、リストのフィルタ。
- データの横に、棒グラフ、折れ線グラフ、円グラフ。
- すべての数式のチェック。LibreOfficeがインストールされていれば、チェックで数式を計算してエラー（#REF!、#DIV/0!、#NAME?）を一覧にし、エージェントがそれを修正します。
- ユーザー自身のブックを、数式、スタイル、レイアウトの大部分を保ったまま変更（ピボットテーブルは保持されず、グラフはエージェントが作り直した場合のみ残ります）。頼めば、代わりにCSVファイルにもできます。

### プレゼンテーション

ピッチ資料、発表、授業、要約（.pptx）。PowerPoint、Keynote、Googleスライドで表示できます。

- ブランドカラーを使い、全体で統一感のある見た目の、すっきりした16:9のスライド：タイトルスライド、階層付きの箇条書き、2列、スライドに合わせた画像、表、グラフ（縦棒、横棒、折れ線、円、積み上げ）、セクションスライド、話す内容のスピーカーノート。
- 1枚のスライドに1つの考え。タイトルは要点を伝えるもの（「売上が12%増加」）にし、発表では通常6～12枚のスライドにします。
- ユーザーが用意した画像、Webの画像、または画像モデルで作った画像（[エージェントに画像を作らせる](/guide/documents-voice#let-agents-make-images)を参照）。
- ユーザー自身のテンプレートを使った新しいプレゼンテーション、または、テーマとレイアウトを保ったままの既存プレゼンテーションの変更。
- LibreOffice経由でのスライドのPDF化。

### PDF

レポート、請求書、証明書、チラシ、手紙、フォームなど。

- 大半がテキストの場合や、後で編集したい場合：エージェントがWordドキュメントを作り、LibreOfficeでそこからPDFを作ります。
- 厳密なレイアウトが必要な場合（請求書、証明書、チケット、フォーム）：PDFを直接描画します。
- スライドやシートをPDFにする場合：それぞれのスキルで作ってから、PDFに変換します。
- **フォームに入力する**：フィールドを名前で指定して入力します（テキスト、チェック、選択肢。ギリシャ文字、中国語、その他どんな文字でも可）。そのため、どのビューアでも表示され、そこで変更もできます。印刷された線と枠だけのフォームの場合は、印刷された文言（「生年月日：」など）の横のページ上に文字を書き込み、枠にチェックを入れます。スキャンしたフォームには見つけられる文言がないため、エージェントはページの画像から空欄の位置を判断します。エージェントは、わからない内容をユーザーに尋ね、前後のページも確認します。電子署名されたフォームは、フィールドへの入力だけなら有効なままです。XFAフォーム（Adobe LiveCycle）はAdobe純正のアプリでしか入力できません。その場合、エージェントはそのことを伝え、それでもページ上に書き込むことはできます。
- **ページに書き込む**：文字、チェックとバツ、画像、既存の内容を覆う白い四角（目に見えなくするだけで、文字自体はファイルに残るため、墨消しにはなりません）、枠線と線、PDF標準のハイライトとコメント（ほかのビューアでも一覧表示でき、削除もできます）。
- **ページを変更する**：回転、削除、移動、白紙ページの挿入、PDFの結合、一部のページを別のファイルに取り出す、1つを複数に分割する。この方法で変更したファイルには電子署名を残せず、エージェントはそのことを伝えます。
- エージェントが書き込んだ内容は、ファイルの隣のコピー（「name (filled).pdf」）に保存されます。ファイルそのものの変更を頼んだ場合は、元のバージョンがゴミ箱に移ります。PDFへの入力と署名は自分で行うこともできます。[PDFに入力して署名する](/guide/files-git#fill-in-and-sign-a-pdf)をご覧ください。
- **pdf**スキルで、DRAFTのような大きな薄い文字を全ページに入れたり、パスワードを外したコピーを作ったりもできます（パスワードはユーザーが伝えます）。
- 保存済みの署名での署名：ページ上の文言の横、または先に示された位置に入れます。カードで許可した場合に限り、PDFの元の内容を変えずに追加されます（[署名](/guide/library#signatures)）。
- OfficeファイルのPDF化。

### コンピューターに必要なもの

ここで述べるのは、Hydorを実行しているコンピューターについてであり、Hydorを操作しているデバイスのことではありません。

- **Python 3**（venvモジュール付き）：ドキュメントを作るために必要です。初回は、スキルがOfficeファイルとPDF用のPythonライブラリをいくつか、アプリ専用のフォルダにインストールします（約30 MB、一度だけ、インターネット経由）。システム全体には何もインストールされません。Pythonがない場合、エージェントが実行すべきコマンドを1つ伝えます（DebianまたはUbuntuでは `sudo apt install python3 python3-venv`、Macでは `brew install python`）。
- **LibreOffice**（任意）：ファイルビューアでのレイアウト済みページとしてのプレビュー、古い.doc、.xls、.pptファイルの読み取り、エージェントがOfficeドキュメントをページとして確認すること、数式のチェック、OfficeファイルからのPDF作成。DebianまたはUbuntuでは `sudo apt install libreoffice-writer-nogui libreoffice-calc-nogui libreoffice-impress-nogui`、Macでは `brew install --cask libreoffice`。
- **poppler-utils**（任意）：最良のPDF読み取りと、エージェントや**入力と署名**で使うPDFページの画像。ない場合、アプリはコンピューターにあるもの（MacやWindowsに標準のPDF描画機能）か、**設定 → ブラウザ**のブラウザで描画します。DebianまたはUbuntuでは `sudo apt install poppler-utils`、Macでは `brew install poppler`。
- **tesseract**（任意）：スキャンしたPDFのOCR。

LibreOfficeやpoppler-utilsがない場合、エージェントは確認のためにファイルをテキストとして読み戻し、レイアウトをシンプルに保ちます。

## エージェントが作成したファイルを開く・ダウンロードする

エージェントがファイル（ドキュメント、スプレッドシート、スライド、PDF、画像、アーカイブ）を作成すると、返信の下にカードとして一度に最大12件まで表示されます。各カードには次の内容が表示されます。

- 種類別のアイコン（色付き。Wordは青、Excelは緑、PowerPointはオレンジ、PDFは赤）。画像の場合は小さな画像
- ファイル名、種類、サイズ（「Wordドキュメント · 24 KB」）
- エージェントによる説明文（「四半期ごとにシートを分けた予算表」）
- **開く**、ダウンロードボタン、**その他**（⋯）

**開く**を押すと、会話の上に重なるウィンドウのファイルビューアでファイルが表示されます。会話はそのままの位置に残ります（スマートフォンでは、ウィンドウが画面の下から現れます）。ウィンドウ上部の**ファイルで開く**を押すと、ファイルがファイルページに移ります。×印かEscapeキーでウィンドウを閉じます。ファイルの上にはパスが表示されます。ファイルページと同じです（[ファイルを開いて編集する](/guide/files-git#open-and-edit-a-file)）。パス内のフォルダは同じウィンドウで開き、そこでファイルが選択された状態になります（未保存の変更がある場合は、先に確認が表示されます）。ウィンドウ上部の**‹**を押すと、ファイルに戻ります。ダウンロードボタンを押すと、ファイルがお使いのデバイスに保存されます。

カードとウィンドウ上部の**その他**（⋯）には、次の項目があります。**このファイルでセッションを開始**（開始ページが、ファイルをメッセージ欄に添えた状態で開きます）、**プロジェクトに追加**（プロジェクトのフォルダにコピーします）、**コピーを保存**（Jupyterノートブック、PowerPointのプレゼンテーション、WordまたはMarkdownのドキュメント、スプレッドシート、LaTeXファイルが対象です。独立したドキュメントとして、それぞれのエディタで開けるコピーを保存します。保存先は、プロジェクトがある場合は選択したプロジェクトのファイル、ない場合はセッションのファイルです）、**ファイルで表示**（カードのみ）、**Finderで表示**・**エクスプローラーで表示**・**フォルダで表示**（デスクトップアプリ。[ファイルとフォルダを操作する](/guide/files-git#work-with-files-and-folders)を参照）、**パスをコピー**です。[ファイルでセッションを開始する](/guide/files-git#start-a-session-with-files)と[プロジェクトにファイルを追加する](/guide/files-git#add-files-to-a-project)もご覧ください。

削除または移動されたファイルは**既に存在しません**と表示されます。エージェントが存在しないファイルを指定した場合は、「Could not show the files」と理由が表示され、エージェントには修正するよう伝えられます。

### 作成・変更したドキュメントと返信内のファイル名

エージェントの返信の下には、そのターンで作成または変更したドキュメントが、受け渡したかどうかにかかわらず毎回カードとして表示されます。対象は、PDF、Word、Excel、PowerPoint、OpenDocumentのファイル、CSVとTSVの表、LaTeX、Jupyterノートブック、EPUB、Markdownです。エージェントの編集で書き込まれたファイルと、ターンの実行中にコマンドがセッションのフォルダに作成したファイルが対象です（ターンで名前が挙がったもの、または変更したファイルの隣にあるものに限ります。同じフォルダで作業している他のセッションのファイルは含まれません）。

- 各カードには**新規**または**更新済み**、種類、サイズが表示され、上記のカードと同じく**開く**、ダウンロードボタン、**⋯**があります。
- 完成したドキュメント（PDFやWordファイルなど）は、元になるファイル（LaTeX、Markdown、表）より前に表示されます。最初の4件が表示され、**残りN件のドキュメントを表示**で残りを表示し、**表示を減らす**で再び折りたたみます。
- エージェントが受け渡したファイルは専用のカードと説明文のまま表示され、二重には表示されません。既に存在しないファイルは表示されません。画像、コードファイル、データファイルはこの方法では表示されません（画像はエージェントが引き続き受け渡します）。

返信内のファイル名とパスはリンクになっています。コード内の名前やパス（`report.tex`、`docs/report.pdf`、`src/app.ts:42`。この場合は該当行で開きます）、テキスト内の絶対パスや`~/`で始まるパス、ファイルへのリンクは、カードの**開く**と同じように、会話の上のウィンドウでファイルが開きます。名前だけの場合は、その名前の会話内のファイルが開きます。先頭から始まらないパスは、セッションのフォルダからのパスとして扱われます。

## ファイルビューアでドキュメントをプレビューする

ファイルビューアでは、カード、ファイルページ、返信内のリンクからドキュメントを表示できます（[システム：ファイル、Git、ターミナル、プレビュー](/guide/files-git)を参照）。

- **PDF**はブラウザ標準のPDFビューでそのまま表示され、**入力と署名**で入力と署名ができます（[PDFに入力して署名する](/guide/files-git#fill-in-and-sign-a-pdf)）。
- **PowerPoint**ファイル（.pptxと、そのマクロ付き、スライドショー、テンプレート形式）は**スライド**で開きます。「アプリが描画したスライド」です。各スライドは、保存済みのプレゼンテーションと同じ見た目（画像、図形、表、グラフ、背景、フッターもそのまま）で、番号とスピーカーノートとともに上から順に並びます。スマートフォンでも同様です。プレゼンテーションで使われているフォントがこのコンピューターにない場合は別のフォントで代用され、より広い場所が必要になるときは、文字が切れないようにボックス内の文字が少し小さくなります。**テキスト**（「スライドの文字とスピーカーノート」）はスライドの文字を表示し、**ページ**はLibreOfficeがインストールされている場合に、そのレイアウトで表示します。スライドを描画できない場合は、ビューアが**テキスト**で開き、理由が表示されます。
- **Word、Excel、PowerPoint、OpenDocument、EPUB、RTF**のファイル（古い.doc、.xls、.pptも含む）はプレビューとして表示されます。LibreOfficeがインストールされている場合は、上部のスイッチで2つの表示を切り替えられます。
  - **ページ**：「LibreOfficeのレイアウトどおりに表示」します。印刷した場合と同じ各ページの見た目です。初回は少し時間がかかります（「Laying out the pages…」）。その後は、ファイルが変更されるまですぐに開きます。
  - **テキスト**：「テキスト、シート、スライド」を、アプリが読み取った形で表示します。テキストドキュメントは1枚の用紙のように、ワークブックは列の文字、行の番号、下部の各シートのタブ付きの表として（非表示のシートには取り消し線入りの目のマークが付きます）、スライドはそれぞれ番号とスピーカーノートが下に付いたカードとして表示されます。画像は、その説明が入ったボックスとして表示されます。何かが省略された場合は、上部の1行でお知らせします（「Shows the first 1000 rows」）。
- LibreOfficeがない場合は、**テキスト**表示のみです。EPUBの書籍は常にこの表示で開きます。
- スマートフォンでは、プレビューは**テキスト**で開きます（PowerPointファイルは**スライド**）。小さな画面ではスクロールや拡大縮小がしやすいためです。スイッチでページ表示に切り替えられます。

LibreOfficeでファイルのレイアウトができない場合は、ビューアがその旨を表示し、テキストは引き続き**テキスト**で見られます。プレビューのないファイルには「No preview for this file」と表示されます。ダウンロードして、お使いのデバイスで開いてください。ビューアのダウンロードボタンは常に使えます。

## エージェントによる画像の生成を許可する

どのエージェントにも、画像を頼めます（「パン屋のロゴを作って」「この写真を水彩画にして」）。エージェントはOpenRouterの画像モデルで画像を作り、セッションのフォルダに保存して、返信とともに表示します。設定は**[設定 → 機能 → 画像、動画、音声](/settings?s=images)**で行います（スマートフォンでは、設定から**画像、動画、音声**）。

- **[画像の生成](/settings?s=images&find=Making%20images)**：グループのタイトルの横にあるスイッチ**エージェントによる画像の生成を許可**をオンにすると、すべてのエージェントが画像用のツールを使えるようになります。画像、イラスト、グラフの作成、画像の背景の除去、一部の消去ができます。オフにしない限りオンです。オフにすると、エージェントにこれらのツールは提供されません。
- **OpenRouterキー**：画像、動画、音声のモデルはOpenRouter経由で利用し、画像、動画、音声は1件ごとにOpenRouterキーで支払われます。キーがない場合、このセクションにその旨が表示され、**openrouter.aiで取得**と**キーを追加**が表示されます。**キーを追加**を押すと、キーを入力する[設定 → エージェント → モデル → OpenRouter](/settings?s=models&find=OpenRouter)が開きます（[エージェント、アカウント、モデル](/guide/agents-models)を参照）。キーが必要なエージェントは、代わりにカードで入力を求めます（[エージェントがOpenRouterキーを必要とするとき](#when-an-agent-needs-the-openrouter-key)）。
- **[ほとんどの画像向け（最高）](/settings?s=images&find=For%20most%20pictures%20%28Best%29)**：風景、写真、人物、画像内の文字、図の作成と、画像へのあらゆる変更に使うモデルです。モデル名、提供元、画像1枚あたりのおおよその費用（約1メガピクセルの画像の場合）、OpenRouterに掲載された月が表示され（IDは(i)にあります）、次のタグが付きます。**新規**（直近30日以内に掲載）、**編集**（変更または参照する画像を受け取れます）、**テキストにも対応**（画像とともにテキストも書けます）。選ぶまではアプリが選んだモデルになります（「The app’s choice, until you pick one」）。OpenRouterで引き続き提供されている短いリストの先頭が使われます。ByteDanceのSeedream 5.0 ProとFlash、続いてGoogle Gemini、OpenAI、FLUXの画像モデルです。
- **[シンプルな画像向け（高速）](/settings?s=images&find=For%20simple%20pictures%20%28Quick%29)**：アイコン、背景、テクスチャ、シンプルな画像向けの、より安価で高速なモデルです。表示は同じです。選ぶまではアプリが選んだモデルになります。OpenRouterで引き続き提供されている高速モデルの短いリストの先頭が使われます。最初はByteDanceのSeedream 5.0 Flash、続いてGoogle、Recraft、FLUX、OpenAIの高速モデルです（どれもOpenRouterで提供されていない場合は、最高のモデルがシンプルな画像も作ります）。
- **[このコンピューター上の画像ツール](/settings?s=images&find=Picture%20tools%20on%20this%20computer)**：画像の背景の除去、一部の消去、拡大を、OpenRouterではなくこのコンピューター上で行います。無料で、画像はこのコンピューターの外に出ません。**設定**で1回ダウンロードし、その下の行に動作状況が表示されます。**⋯ → 削除**で、このコンピューターから再び取り除けます（[このコンピューター上の画像ツール](/guide/library#the-picture-tools-on-this-computer)を参照）。

最高または高速のモデルを選ぶには：

1. 横にある**変化**をクリックします。OpenRouterの画像モデルのリストが開きます（**ほとんどの画像向けの画像モデル（最高）**または**シンプルな画像向けの画像モデル（高速）**）。
2. 名前で検索し（「seedream」「flux」「gemini」）、**おすすめ**（アプリのおすすめが先頭）、**新しい順**、**最安**で並べ替えます。
3. 使うモデルの行をクリックします。一度選ぶと、その行の**⋯**メニューに**代わりにアプリに選んでもらう**が表示され、アプリが選んだモデルに戻せます。

リストはOpenRouterから取得され、キーは不要です。取得できない場合は、リストにその旨が表示されます。

## エージェントによる動画の生成を許可する

エージェントは短い動画も作れます（「夕暮れの波を10秒」「うちの犬のこの写真が野原を走る動画にして」）。OpenRouterの動画モデルを使い、同じセクションの**[設定 → 機能 → 画像、動画、音声](/settings?s=images)**で設定します。

- **[動画の生成](/settings?s=images&find=Making%20videos)**：グループのタイトルの横にあるスイッチ**エージェントによる動画の生成を許可**をオンにすると、すべてのエージェントが動画用のツールを使えるようになります。オフにしない限りオンです。
- **[動画モデル](/settings?s=images&find=Video%20model)**：動画を作るモデルです。提供元、1秒あたりの費用（最低解像度の音声なしから最高解像度の音声付きまでの範囲。「$0.03 to $0.08 a second」）、作れる長さ（「4 to 8 s」）、最高解像度（「up to 1080p」）、OpenRouterに掲載された月が表示され、次のタグが付きます。**音声**（映像に合わせて音声も作ります）、**画像から**（渡した画像から始められます）、**動画を編集します**（文章から作るのではなく、渡した動画を変更します）。選ぶまではアプリが選んだモデルになります。OpenRouterで引き続き提供されている、音声付きモデルの短いリストの先頭が使われます。最初はByteDanceのSeedance 2.5、続いてGoogle Veo 3.1 Liteなど、より安価で高速なモデルです。**変化**をクリックするとリストが開き、検索（「seedance」「veo」「kling」）と、**おすすめ**、**新しい順**、**最安**での並べ替えができます。

- **[動画にグラフィックカードを使う](/settings?s=images&find=Use%20the%20graphics%20card%20for%20videos)**（**動画を編集中**の中）：**自動**にすると、使えるグラフィックカード（NVIDIA、Intel、AMD、Apple）がある場合、編集する動画とエージェントによる編集をグラフィックカードで処理します。大幅に速くなり、プロセッサーに余裕が残ります。動画を最初に作るときに試され、その下の行に検出結果が表示されます（「NVIDIA GeForce RTX 4090 · NVENC」）。**今すぐ確認**でもう一度試せます。カードで編集に失敗した場合は、すぐにプロセッサーでやり直します。**オフ**にすると、プロセッサーで処理します。

動画は画像よりはるかに費用がかかります。1秒あたり数セントから数ドルで、最上位モデルで音声付きの8秒の動画なら数ドルになることもあります。いずれもOpenRouterキーで支払われ、作成の前にフォームで料金が表示されます。

## エージェントによる音声の生成を許可する

エージェントは音声も作れます。曲やジングル（「ポッドキャスト用の30秒のジングル」）、言葉で指定した声（「この挨拶を温かくゆっくりした声で読んで」）や手持ちの録音から複製した声でのナレーション、効果音や環境音（「トタン屋根に降る雨」）です。同じセクションの**[設定 → 機能 → 画像、動画、音声](/settings?s=images)**で設定します。

- **[音声の生成](/settings?s=images&find=Making%20audio)**：グループのタイトルの横にあるスイッチ**エージェントによる音声の生成を許可**をオンにすると、すべてのエージェントが音声用のツールを使えるようになります。オフにしない限りオンです。
- **[音楽モデル](/settings?s=images&find=Music%20model)**：曲や音楽を作るモデルです。提供元、料金（「$0.08 a song」）、作れる最長の長さ（「up to 3:00」）、OpenRouterに掲載された月が表示され、**音楽**のタグが付きます。選ぶまではアプリが選んだモデルになります。GoogleのLyria 3 Proで、歌ありでもなしでも最長約3分の曲全体を作れます。それが使えない場合は、30秒のクリップを作るLyria 3 Clipです。
- **[音声・サウンドモデル](/settings?s=images&find=Voice%20and%20sound%20model)**：話す音声やその他の音を作るモデルです。料金（「$0.0025 a second」「$0.08 per 1,000 characters」「about $0.014 a minute」）、作れる最長の長さ、声の数が表示され、次のタグが付きます。**音声にも対応**（声に加えて、説明から効果音や環境音も作れます）、**声を複製します**（渡した短い録音から複製した声で話します）、**会話**（複数の話し手を、それぞれ別の声で読み上げます）、**演出あり**（トーン、ペース、感情などの話し方の指示を受け付けます）。選ぶまではアプリが選んだモデルになります。ByteDanceのSeed Audio 1.0で、これらすべてを説明から行え、一度に最長2分です。それが使えない場合はGoogleのGemini 3.8 Flash TTS、さらにその次はElevenLabs v3です。

**変化**をクリックすると各モデルのリストが開き、検索（「lyria」、「seed」「elevenlabs」「gemini」）と、**おすすめ**、**新しい順**、**最安**での並べ替えができます（声は、1分間の読み上げのおおよその費用で並べ替えます）。選んだモデルの行の**⋯ → 代わりにアプリに選んでもらう**で、アプリが選んだモデルに戻せます。選んだ音声モデルが文章を読み上げるだけの場合、効果音や複製した声は、それができるアプリ選択のモデルで作られ、フォームにその旨が表示されます。

音声モデルの多くは読み上げた文字数で、Seed Audioは作った音声の秒数で、Lyriaは曲ごとに課金されます。いずれもOpenRouterキーで支払われ、作成の前にフォームで料金が表示されます。

## 作成前に設定を確認する

エージェントが画像、精密な描画、動画、音声を作成する前に、会話の中に短いフォームが表示されます。フォームには、そのモデルが対応する設定と作成にかかる費用が示され、依頼した内容とアプリの既定値があらかじめ入力されています。

- 画像：**形**（正方形、横長、縦長など。モデルが対応するもの）、**解像度**（1K、2K、4Kなど）、**品質**、**画像の枚数**（一度に複数枚作成できるモデルの場合）、**透明な背景**（ロゴやアイコン用）
- 精密な描画（Recraftのベクターモデルによるもの）：**形**
- 動画：**動画の長さ**（モデルが作成できる長さ。または**長さ（秒）**）、**形**、**解像度**、**音声**
- 音声：曲の場合は**インストゥルメンタル（歌なし）**と、長い曲を作成できるモデルでは**長さ（秒）**（空欄にすると、曲に必要な長さになります）。効果音の場合は**長さ（秒）**（Seed Audioは秒単位の課金です）。読み上げの場合は**音声**（モデル独自の声がある場合）と**ファイル**（モデルが両方に対応している場合は**MP3（小さいサイズ）**または**WAV（非圧縮）**）

フィールドの上には、モデル名、料金（「1枚あたり約$0.08」「1秒あたり$0.03～$0.08（解像度と音声により異なります）」「1曲あたり$0.08」「音声1秒あたり$0.0025」。動画や音声では、表示中の設定での合計金額）、そしてエージェントが依頼する内容がエージェント自身の言葉でそのまま表示されます。必要に応じて変更し、**作成する**をクリックしてください。**今はしない**を選ぶとフォームが閉じ、何も作成されず、費用もかかりません。フォームには、モデルが提供する設定だけが表示されます。

フォームが表示されるのは、セッション内でモデルごとに1回です。同じセッションでその後に作成する画像、動画、音声には、選んだ設定（音声の場合は声とファイル）が使われます。別の設定にしたいときは、その旨を伝えてください（「今度は縦長で」）。「設定をもう一度見せて」と伝えるとフォームが表示され、「そのまま進めて、任せるよ」と伝えるとフォームなしで作成されます。スケジュールタスクやアプリの実行では、答える人がいないため、フォームなしでアプリの既定値で作成されます。

## エージェントにOpenRouterキーが必要なとき

画像、精密な描画、動画、音楽、音声は、OpenRouter経由のモデルで作成され、料金はOpenRouterキーで支払われます。エージェントが作成しようとしたときにキーが設定されていないと、会話の最初に**OpenRouterキーが必要です**というカードが表示されます。カードには、どのモデルで作成するか、おおよその費用、作成されたものの料金はOpenRouterに支払うことが示され、キーを入力するフィールドがあります。

- キーを貼り付けて**キーを保存**をクリックします（Enterキーでも可）。OpenRouterが先にキーを確認します。キーは会話には入らず、[設定 → エージェント → モデル → OpenRouter](/settings?s=models&find=OpenRouter)に直接保存され、エージェントは続行します（これまでどおり、設定のフォームに進みます）。その後、カードに「OpenRouterキーは設定 → モデルに保存されました。」と表示されます。
- **キーを取得**をクリックすると、キーを作成するOpenRouterのページが開きます。
- **スキップ**：そのモデルは実行されず、何も作成されず、費用もかかりません。エージェントはそのモデルなしで続行し、キーが不要な別の方法（自分で書く簡単な描画、[このコンピューターの画像ツール](/guide/library#the-picture-tools-on-this-computer)）を使うか、何も作成しません。そのセッションでは、6時間は再度確認されません。

カードは最大9分間待機します。その後はキーなしでエージェントが続行し、あとでキーを追加した場合はその旨が伝えられます。スケジュールタスクやアプリの実行では、答える人がいないためカードは表示されず、キーがないことが表示されます（「画像にはOpenRouterキーが必要です」と**OpenRouterのキーを追加**）。エディタ独自のAIツールでは、代わりにそのダイアログでキーを求められます（[AIで画像、描画、プロット、動画を作成する](/guide/library#make-pictures-drawings-plots-and-videos-with-ai)）。

## 画像を依頼する、または変更してもらう

ほしいものを説明してください。被写体、場面、スタイル（写真、イラスト、水彩画）、色、光、画像に入れたい文字などを伝えます。エージェントは次のこともできます。

- **画像の変更や合成**：このコンピューター上の画像ファイル（PNG、JPEG、WebP、GIF。1枚あたり最大20MB。ほとんどのモデルは最大4枚、それ以上に対応するモデルもあります）。セッションのフォルダ内のファイルはパスを指定して使えます。プレゼンテーション、ドキュメント、残しておいたページにすでにある画像も使えます。変更したい内容を伝えてください。（メッセージに添付した画像は、モデルが見るためだけに渡されます。画像モデルがそれをもとに作成するには、ファイルである必要があります。ファイルページでアップロードしてください。）これには**編集**タグのあるモデルが必要です。それ以外のモデルでは、エージェントは変更内容を言葉で説明するか、画像を編集できるモデルを選ぶよう案内します。
- **高速モデルまたは最高モデルの使用**：エージェントは、簡単な画像（背景、テクスチャ、アイコン）には高速モデルを、場面、写真、画像内の文字、図、すべての変更には最高モデルを使います。依頼内容から判断することもあります。もう一方を使いたいときは、そう伝えてください（「高速なものでいいよ」「最高モデルを使って」）。
- **背景を透明にする**（ロゴ、アイコン）：対応していないモデルの場合は、対応しているモデルに任せます。[画像ツール](/guide/library#the-picture-tools-on-this-computer)がセットアップされていれば、無地の背景で画像を作成し、このコンピューター上で背景を取り除きます。
- **別のモデルの使用**：モデル名を伝えると（「FLUX 2 Proで作って」）、設定を変更せずに、その1枚だけ別のモデルで作成できます。

画像は、セッションのフォルダ内の**画像**フォルダに、内容にちなんだ名前で保存されます。すでにあるファイルが上書きされることはありません。

会話では、次のように表示されます。

- モデルが作業している間は、指定した形のプレースホルダーに「画像を作成中」と経過時間、その下に説明が表示されます。
- その後、返信とともに画像が表示され、その下に説明とモデル名、そして**残す**が表示されます（[エージェントが作成したものを残す](#keep-what-an-agent-made)を参照）。画像をクリックすると大きく表示されます。もう一度クリックすると原寸で表示されます。複数枚ある場合は矢印（または矢印キー）で切り替えられます。**新しいタブで開く**でその画像だけを開き、**編集**で画像エディタで開きます（そこで保存したものは新しい画像として残ります：[画像と動画を編集する](/guide/library#edit-pictures-and-videos)）。Escapeキーで閉じます。各画像にポインタを合わせると、**ファイルで表示**、**ダウンロード**、**その他**（⋯：**このファイルでセッションを開始**、**プロジェクトに追加**、**パスをコピー**、デスクトップアプリでは**Finderで表示**、**エクスプローラーで表示**、**フォルダで表示**）が表示されます（スマートフォンでは常に表示されます）。複数枚ある場合は**残す**も表示されます。
- OpenRouterキーが設定されていない場合は、最初にキーを求めるカードが表示されます（[エージェントにOpenRouterキーが必要なとき](#when-an-agent-needs-the-openrouter-key)）。誰も見ていない実行（スケジュールタスクやアプリ）では、代わりに「画像にはOpenRouterキーが必要です」と**OpenRouterのキーを追加**が表示されます。何も作成されなかった場合（キーをスキップした、フォームを閉じた、モデルが拒否したなど）は、「今回は画像なし」と理由が表示されます。

## 描画やプロットを依頼する

画像モデルで描くよりも、図形から描いたり数値から計算したりしたほうがよい画像もあります。

- **描画**（SVG：ピクセルではなく図形でできており、どんなサイズでも鮮明）：アイコン、ロゴ、図、繰り返しのパターン、図形、フラットなイラストなど。色は指定したものを使います（プレゼンテーションやドキュメントの色など）。簡単なものはClaude（または選んだ[補助モデル](/settings?s=models&find=Helper%20model)）が書くため、画像モデルの料金はかからず、1分以内にできます。精密なもの（イラスト、または最高品質を求めた場合）は、価格が表示されたフォームのあと、OpenRouter経由でRecraftのベクターモデルが描き、1枚あたり約$0.08です。スクリプト、リンク、描画が外部から読み込むものは、残す前にすべての描画から取り除かれます。
- データや数式の**プロット**：スライドのグラフでは描けないもの向けです。散布図、ヒストグラム、箱ひげ図、誤差バー、複数の軸やパネル、ヒートマップ、関数、フィッティング、重要な点への注釈などがあります。Claude（または補助モデル）がPythonのmatplotlibで書き、このコンピューター上で実行されます。エラーが出た場合は修正のために戻されます（最大3回）。約30秒かかり、費用はその回答分だけです。数値はメッセージに書くか、ファイル（CSV、TSV、JSON。最大20MB）で渡し、伝えたいこと（「春に倍増したことを示して」）も添えてください。描画（SVG。点が非常に多い場合はPNG）として作成され、サイズの指定がなければ960×540ピクセルです。そのPythonコードも隣に保存されるため、「今度は対数目盛で」と頼めば、そのプロットが変更されます。Webプレゼンテーション向けには、動いてポインタに反応するプロットにもできます。アプリが動作しているコンピューターに、matplotlib入りのPythonが必要です。画像ツールのセットアップ後はそれが使われ（[このコンピューターの画像ツール](/guide/library#the-picture-tools-on-this-computer)）、すでに入っているものがあればそれが使われます。

どちらもセッションのフォルダ内の**画像**フォルダに保存され、画像と同じように返信とともに表示されます。作成中のプレースホルダーには「描画を作成中」または「プロットを作成中」と表示されます。

## 無料の写真を探す

モデルが作成した画像ではなく写真を依頼すると（「タイトルスライド用にリスボンの路面電車の写真を2枚探して」）、エージェントは、無料で使えて、変更でき、商用利用もできるオープンライセンスの写真を検索します。検索先はOpenverseのカタログ（Flickr、ウィキメディア・コモンズ、美術館など）で、Openverseで見つからない場合はウィキメディア・コモンズ自体の検索を使います。そのうち良いものを数枚（指定がなければ4枚、最大10枚）、それぞれのクレジット（タイトル、作者、ライセンス、リンク）を記したファイルとともに、セッションの**画像**フォルダに保存します。使う前に内容を確認し、ライセンスの求めに従ってクレジットを表示します。スライドではスピーカーノート、ドキュメントやページでは画像の下に表示し、CC0とパブリックドメイン以外のライセンスでは写真のそばに小さなキャプションを付けます（「写真：「タイトル」 作者、CC BY 2.0」）。無料で、数秒しかかかりません。検索中のプレースホルダーには「無料の写真を探しています」と表示されます。

## 切り抜き、消去、編集

エージェントは、画像や動画を作り直さなくても加工できます。

- 画像から**背景を切り抜く**：被写体（人物、商品、動物、ロゴ）を透明な背景にして、PNGで保存します。このコンピューターで[画像ツール](/guide/library#the-picture-tools-on-this-computer)を設定済みなら、無料でプライバシーも守られ、被写体のピクセルがそのまま残り、数秒で終わります。仕上がりがよくない切り抜きは、画像モデルがやり直します。設定していない場合は、OpenRouter経由の画像モデルが（約$0.01〜$0.04で）背景のない画像として描き直すため、細部が少し変わることがあります。
- 画像から**何かを消す**（背景の人物、看板、透かし、汚れ、ケーブルなど）：対象を取り除き、周囲のつながりに合わせて埋めます。エージェントが場所に印を付けるか、画像モデルが見つけられるように言葉で指定します。小さな範囲はこのコンピューターで無料で消去します。大きな範囲、画像全体に広がるもの、文字のような細かいものに重なる場合は、画像モデルが処理します（約$0.01〜$0.04）。
- **画像を拡大する**：縦横それぞれ2倍または4倍にし、ぼかさずに細部をくっきり描き込みます（印刷やスライド用の小さな写真、古い画像など）。このコンピューターで[画像ツール](/guide/library#the-picture-tools-on-this-computer)を設定済みなら、無料でプライバシーも守られます（初回はモデルを約5 MBダウンロードします）。大きな画像は1〜2分かかります。
- **画像を編集する**：トリミング、回転や反転、サイズ変更、明るさや色の調整（露出、コントラスト、色温度などのほか、カーブ、レベル、特定の色の色相と彩度、カラーバランス、明瞭度、かすみの除去、ノイズ除去、粒状感、さらにすべてをまとめて行う自動補正）、フィルタ（**ヴィンテージ**、**白黒**など）、文字の書き込み、矢印や枠の描画、一部のぼかしやモザイク（顔、ナンバープレート、名前など）ができます。このコンピューター上で無料です。JPEG、WebP、GIFの画像や、それらへの文字の書き込みには、ffmpegまたは画像ツールが必要です。
- **動画を編集する**：トリミング、一部の削除、形に合わせたクロップ（16:9、9:16、正方形、4:5）、回転や反転、速度の変更（早送り、スロー、逆再生、手ぶれ補正）、複数のクリップや画像をトランジション（ディゾルブ、暗転、ワイプ、スライド）でつなぐ、画像へのゆっくりしたズーム、色の調整（露出、色温度、コントラスト、シネマ風や白黒などの雰囲気、ビネット、粒状感）、フェードイン・フェードアウト、音声の削除や音量の変更、聞こえるチャンネルの選択（片側のピンマイクを両側から聞こえるようにするなど）、音声の一部を無音にする、音楽への音量ラインの設定、ロゴ、透かし、グリーンバックの重ね合わせ、文字の追加（タイトル、字幕、話した内容から作る字幕。.srtファイルも横に作られます）、音楽やナレーションの追加（声のクリーンアップ、話し声の下で音楽を下げる、音量の均一化）ができます。さらに、GIFにしたり、1コマを画像として取り出したりもできます。このコンピューターのffmpeg（画像ツールにも含まれています）を使い、グラフィックカードがあればそれを使って無料で処理します。**エージェントによる動画の生成を許可**がオンのときに使えます。
- **音声を編集する**（音声ファイル、動画の音声、残した音声）：一部を残す、一部を削除する、または無音にする、長い間を短くする、フィラー（「えー」「あのー」など。このコンピューターで音声認識をオンにしている場合。[サーバーでの音声認識](#speech-recognition-on-the-server)を参照）を取り除く、音程を保ったまま速く、または遅く再生する、音程を変える、音量を上げ下げする、フェードをかける、最大ピークやラウドネス（ポッドキャスト、ストリーミング、放送）を設定する、ノイズを減らす、音色を変える（クリアな声、電話、ラジオ）、コンプレッサーやリミッターをかける、エコーやリバーブを加える、逆再生やモノラル化をする、ほかの音を指定の位置に重ねる（声の下の音楽、効果音）ことができます。このコンピューターのffmpegを使い、無料で処理します。**エージェントによる音声の生成を許可**がオンのときに使えます。

どの加工も、セッションのフォルダにあるファイル、またはプレゼンテーション、ドキュメント、ページにすでにある画像や動画を元にし、できたものはセッションの**画像**フォルダに保存されます（編集した動画は**動画**、編集した音声は**音声**）。元のファイルが上書きされることはありません。残した画像や音声も編集でき、エディタの**保存**や**コピーを保存**と同じように、元の場所に戻すことも、新しいものとして横に置くこともできます（「残した港の写真を明るくして」「『インタビュー』の音声をポッドキャスト並みの音量にして」）。エージェントが作った画像と同じように返信とともに表示され、作業中はプレースホルダーに「背景を切り抜いています」「消去しています」「拡大しています」「画像を編集しています」「動画を編集しています」「音声を編集しています」と表示されます。切り抜きや消去の場合は、どの方法でなぜそうしたかが返信で伝えられます。気に入らない場合は「AIでやり直して」と伝えると、エージェントが画像モデルに依頼します。自分で行うには、画像、動画、音声をそれぞれのエディタで開きます（[画像と動画を編集する](/guide/library#edit-pictures-and-videos)、[音声エディタ](/guide/library#the-sound-editor)）。

## 動画を依頼する

場面、動くものとその動き方、カメラ（「ゆっくり寄っていく」「自転車の人を追う」）、スタイルと光、音や話される言葉を説明します。エージェントは次のこともできます。

- **画像から始める**：動画の最初のフレームにする画像ファイル（「この写真を動かして」）を使えます。モデルによっては最後のフレームにする画像も使えます。**画像から**のタグが付いたモデルが対象です。
- **画像に沿って作る**：キャラクター、商品、スタイルの画像を最大4枚まで渡し、フレームにはせずに、その特徴を保った動画にします。
- **動画を変更する**：**動画を編集します**のタグが付いたモデルに、動画ファイル（MP4、WebM、MOV。40 MBまで）を渡して、編集、延長、高精細化ができます。

動画は1分未満から数分かかります。エージェントは最大で約9分待ちます。それより長くかかる場合は、アプリが生成を続け、できあがったら保存します。エージェントは次に確認したときに表示します。待っても追加の費用はかかりません。

動画は、セッションのフォルダ内の**動画**フォルダに、内容にちなんだ名前で保存されます。

会話では次のように表示されます。

- モデルが作業中は、動画と同じ形のプレースホルダーに「動画を生成しています」と経過時間が表示されます。
- 完成すると、返信とともに動画が表示され、そのまま再生できます（コントロールから全画面表示も可能）。下には説明とモデル名、そして**残す**が表示されます。ポインターを合わせると、動画の上に**編集**（動画エディタ。保存した内容は残ります）、**ファイルで表示**、**ダウンロード**、**その他**（⋯：画像の下にあるものと同じです。デスクトップアプリでは**Finderで表示**、**エクスプローラーで表示**、**フォルダで表示**があります）が表示されます。
- 「まだ生成中です」は、動画ができる前にエージェントが待つのをやめたという意味です。エージェントが次に確認したときに表示されます（されない場合は確認するよう頼んでください）。「今回は動画がありません」には理由が表示されます。フォームを閉じた場合か、モデルが拒否した場合です（その理由はモデルのメッセージに書かれています）。

## 音楽、音声、効果音を依頼する

聞きたいものをエージェントに伝えます。

- **音楽**：ジャンルと雰囲気、楽器、テンポ、歌う声とその歌い方を伝えます（「月曜の朝をテーマにした、2分間のアップテンポなシンセポップ。女性ボーカルで、キャッチーなサビ付き」）。自分の歌詞を渡すことも、モデルに書かせることもできます。歌が要らない場合はインストゥルメンタルを頼みます。Lyria 3 Clipは常に30秒です。Lyria 3 Proは、頼んだ長さで最大約3分まで作れます。曲の生成には1〜2分かかります。
- **ナレーション**：読み上げる言葉を一字一句そのまま、そして聞こえ方を伝えます（「落ち着いた低い声で、ゆっくり読んで」）。独自の声を持つモデルでは、フォームで声を選びます。Seed Audioは、説明した声を作ります。複数の話者による会話（「2人のホストによる短いポッドキャストの導入」）も、それぞれの声を付けられるモデルなら可能です。
- **録音から複製した声**：声の録音を1〜3個、このコンピューター上のファイル（WAV、MP3、M4A、OGG、FLAC。各30 MBまで。各ファイルの最初の30秒が使われます）として渡します。**声を複製します**のモデル（Seed Audio）が対象です。使えるのは、自分の声や、持ち主が同意した声だけにしてください。コンピューターにffmpegがあればどのファイルでも使えます。ない場合はWAVとMP3のみです。
- **効果音や環境音**：その内容、起こること、そのタイミング、長さを伝えます（「トタン屋根に当たる激しい雨、最後に雷が近づいてくる、声は入れない」）。
- 1つの音だけ**別のモデル**を使うには、名前を伝えます（「ElevenLabs v3で読んで」）。設定は変わりません。

音声は、セッションのフォルダ内の**音声**フォルダに、内容にちなんだ名前でMP3（頼めばWAV）として保存されます。

会話では次のように表示されます。

- モデルが作業中は、カードに「音楽を生成しています」「ナレーションを生成しています」「音を生成しています」と経過時間が表示されます。
- 完成すると、返信とともにプレーヤーで音声が表示されます。丸いボタンで再生と一時停止ができ（同時に再生されるのは1つだけ）、波形は移動用のバーです（クリックまたはドラッグ）。その横に時間と速度（**1×**、**1.25×**、**1.5×**、**2×**、**0.75×**）があります。プレーヤーにフォーカスがあるときは、SpaceまたはKで再生と一時停止、← →で5秒移動します。タイトルはファイル名から付けられ、横に**編集**（[音声エディタ](/guide/library#the-sound-editor)。保存した内容は残ります）、**ファイルで表示**、**ダウンロード**、**その他**（⋯：画像の下にあるものと同じです。デスクトップアプリでは**Finderで表示**、**エクスプローラーで表示**、**フォルダで表示**があります）があります。下には元になった言葉、モデル名、**残す**があり（[エージェントが作ったものを残す](#keep-what-an-agent-made)を参照）、曲の場合はその下に**歌詞**が開きます。
- OpenRouterのキーがない場合は「音声にはOpenRouterのキーが必要です」と表示され、**OpenRouterのキーを追加**が表示されます。「今回は音がありません」には理由が表示されます。フォームを閉じた場合か、モデルが拒否した場合です（その理由はモデルのメッセージに書かれています）。

エージェントは、自分が作った音を聞くことはできません。依頼した内容から音を把握しています。イメージと違う場合は直す点を伝えると、作り直します。または、編集を頼むこともできます（「ジングルの最後の2秒をフェードアウトして」「ナレーションの0:05の位置に重ねて」）。エージェントに頼む方法のほか、音声エディタでも編集できます。

## エージェントが作るものに入る画像

エージェントがスライド、ドキュメント、ページを作ったり変更したりするときは、画像が役立つ場所（タイトルスライド、セクション、アイデアなど。すべてのスライドではありません）に、デザイナーのように、全体の色や雰囲気に合わせて自分で画像を添えます。背景、テクスチャ、アイコンには高速の画像、場面、写真、図には最高の画像、くっきり保ちたいアイコン、ロゴ、図には描画、数値にはグラフ、実在の場所や物には無料の写真を使い、必要に応じて画像を切り抜いたり、消したり、編集したりして合わせます。ファイルだけでなく、開いているものにすでにある画像も元にできます。頼めば、説明のないプレゼンテーションの画像ごとに、見えない人のための説明文も書きます（残した画像の説明を作るモデルが担当します）。費用がかかるものは、作る前にフォームに金額が表示されます（[作る前に設定を確認する](#check-the-settings-before-anything-is-made)）。そうしたくないときは、「画像なしで」や「無料の写真だけで」と伝えてください。

SWOT分析のスライド、ピッチデッキ、カバーレター、エグゼクティブサマリー、習慣トラッカー、料金表、予算など、よく知られた種類のものを名前で頼むと、エージェントはまず、アプリがその種類をうまく作る方法を読み込みます。何を入れるか、どの順にするか、見た目はどうか、どこに画像が役立つかです。ギャラリーの種類と同じ作り方です（[種類からAIで作る](/guide/library#made-with-ai-from-a-kind)）。これに費用はかかりません。

[機密セッション](/guide/sessions#keep-a-session-confidential)では、これらは使えません。エージェントは画像も動画も作成、検索、編集しません。

## エージェントが作ったものを残す

エージェントが作った画像、動画、音声の下にある**残す**を押すと、そのコピーがプロジェクトのファイルに残ります。モデルがタイトルと説明を付け（音声の場合は、音を聞けるモデルがないため、元になった言葉から付けます。モデルは[設定 → 機能 → 画像、動画、音声 → 残すものの説明文](/settings?s=images&find=Captions%20for%20what%20you%20keep)で選びます）、セッションのフォルダを整理した後も残ります。プロジェクトがある場合は、短いメニューで保存先を尋ねられます（**保存先**）。最初にそのセッションのプロジェクト、次にほかのプロジェクト、そして**プロジェクトなし**が並びます。**プロジェクトなし**を選ぶと会話とともに残り、検索ボックス（Ctrl+K）で見つけられます。その後、ボタンは**残した**に変わり、押すと開きます。残した画像は、プロジェクトのファイルの中に表示されます（プロジェクトの詳細 → **ファイル**で、画像付きのタイルとして）。エディタでは、**残す**は編集した画像を新しいものとして残し、**保存**は元の場所に戻し、**コピーを保存**は横に別のものを残します。

## メッセージを音声入力する

メッセージボックス（スタートページと各セッションにあります）のマイクは、話した内容をメッセージの文章に変換します。自動で送信されることはありません。内容を確認してから、いつもどおり送信します。

1. マイクをクリックまたはタップします。
2. 話します。メッセージボックスの上のパネルに、時間、ここまでに聞き取った言葉（サーバーが音声を認識する場合は、声に合わせて動くバーとともに「録音中…」）、聞き取りの対象言語が表示されます。
3. **完了**をクリックするか、もう一度マイクをクリックします。言葉は、すでに書いてある文章に追加されます（サーバーの場合は、その前に「音声をテキストに変換しています…」としばらく表示されます）。

パネルの言語チップ（「DE」「PT-BR」など）を使うと、話している途中で言語を変更できます。そのまま新しい言語で続けられます。サーバーが音声を認識する場合、録音は10分たつと自動的に止まります。

マイクが表示されるのは、音声入力が使える場合だけです。ブラウザ自体が音声を認識できる場合（Chrome、Edge、Safari）か、サーバーが認識する場合です（[サーバーでの音声認識](/guide/documents-voice#speech-recognition-on-the-server)を参照）。開始できないときは、理由と対処方法が表示されます。

- **マイクには安全な接続が必要です**：ブラウザでマイクを使えるのは、HTTPSのアドレスか、コンピューター自体のlocalhostだけです。HTTPSのアドレスからHydorを開いてください（[スマートフォン、他のマシン、共有](/guide/devices)を参照）。
- **このサイトではマイクがブロックされています**：ブラウザのサイト設定で許可してから、もう一度試してください（iPhoneの場合は、アドレスバーの**aA**から**Webサイトの設定 → マイク**）。
- **マイクが見つかりませんでした**、または**マイクは使用中です**（別のアプリが使用しています）。
- **ここでは音声認識がオフです**：iPhoneでは、設定 → 一般 → キーボードで音声入力をオンにするか、サーバーに音声を認識させてください。
- **このブラウザでは録音できません**：最新のChrome、Edge、Firefox、Safariを使ってください。

これらの通知にはそれぞれ**音声設定**ボタンがあり、設定 → 音声が開きます。

## 音声を設定する

音声に関する設定はすべて**[設定 → 機能 → 音声](/settings?s=voice)**にあります（スマートフォンでは、設定から**音声**）。3つの部分があります。

### 音声入力

**[音声入力](/settings?s=voice&find=Dictation)**には、まずこのブラウザでできることが表示されます。

- ブラウザ自体が音声を認識できる場合は、話しながら言葉が表示されます。そのために、声がブラウザの提供元に送られることがあります（ChromeはGoogle、SafariはApple）。声を自分のマシンの中にとどめたい場合は、下のwhisper.cppをオンにして、サーバーを選んでください。
- ブラウザ自体が音声を認識できない場合は、サーバーでの音声認識をオンにすると、サーバー経由で音声入力できます。

その下の項目です。

- **[話す言語](/settings?s=voice&find=Language%20you%20speak)**：**このブラウザと同じ**、または56の言語・地域から選びます。音声入力はこの言語を聞き取り、ハンズフリーモードはこの言語で話し、聞き取ります。
- **認識に使うもの**：**このブラウザ**（話しながら言葉が表示されます）または**サーバー**（whisper.cppならプライベートです。言葉は話し終えてから表示されます）。両方が使える場合にのみ表示されます。

言語と**認識に使うもの**はこのブラウザに保存されるため、デバイスごとに別々の設定になります。

### サーバーでの音声認識

**[サーバーでの音声認識](/settings?s=voice&find=Speech%20recognition%20on%20the%20server)**は、ブラウザ自体が音声を認識できない場合や、声を自分のマシンの中にとどめたい場合のための機能です。オンにするまではオフで、それまでは何もダウンロードされません。設定はアプリ全体で1つで、すべてのデバイスに適用されます。**実行場所**で、次の3つから選びます。

- **オフ**。
- **このマシン上**：Hydorを実行しているコンピューターでwhisper.cppが動き、声はそこにとどまります。whisper.cppが使えるGPU（MacのGPUまたはNVIDIAのGPU）があればGPUで、なければプロセッサで動きます。
  - **モデル**：**極小**（74 MB。最速ですが、ときどき聞き間違えます）、**ベース**（141 MB。高速で、ほとんどの音声入力には十分です。デフォルト）、**小**（465 MB。より正確に聞き取ります。CPUでは1文につき数秒かかります）、**普通**（1.4 GB。最も正確に聞き取りますが、高速なCPUがないと遅くなります）。
  - **言語**：**すべての言語**（話す言語に合わせます）または**英語のみ**（英語ではやや正確になります）。
  - **オンにする · ダウンロード …**には、ダウンロードの容量が表示されます。モデルと、初回はwhisper.cpp本体も含まれます（すべて揃っている場合は、**このマシン上**を選ぶとすぐにオンになります）。バーでダウンロードの進行状況が分かります。**キャンセル**を押すと中止され、サーバーでの音声認識はオフになります。Linuxでは、アプリが配布済みのwhisper.cppをダウンロードし、プロセッサで動かします。Macや、配布済みのものが動かない環境では、このコンピューター上でwhisper.cppをビルドします。それにはC++コンパイラとCMakeが必要です（DebianやUbuntuでは`sudo apt install build-essential cmake`、Macでは`xcode-select --install`のあと`brew install cmake`）。MacではMacのGPU（Metal）向けにビルドされます。コンピューターにすでにあるご自身のwhisper.cpp（GPU向けにビルドしたものなど）は、そのまま使われます。
  - LinuxでのNVIDIA GPU：whisper.cppにはこのGPU向けの配布済みビルドがないため、プロセッサで音声入力が使えるようになったあと、アプリがNVIDIAのCUDAツールキット（`nvcc`）を使って、バックグラウンドでGPU向けのビルドを作成します。バーで進行状況が分かります（5〜20分かかります）。その間はプロセッサで、ビルドが終わるとGPUで音声入力が動きます。ツールキットがない場合はその旨の通知が表示され、インストールしたあとで**もう一度チェック**できます。ビルドに失敗した場合は理由と**もう一度試す**が表示され、音声入力はプロセッサのままです。
  - 準備ができると、「準備完了：whisper.cpp …（ベースモデル）。声はここにとどまります。」と表示され、その下に、whisper.cppが直近の実行時に報告した実行環境が表示されます（準備ができるとすぐに1秒間の無音で試し実行します）。「GPUで動作しています：Apple M2 Pro（Metal）。」または「このマシンのプロセッサで動作しています。」のように表示されます。GPUで失敗した場合（メモリ不足など）は、その録音はプロセッサで処理され、通知に理由が表示されて、数分後にあらためてGPUが試されます。**テスト**を押すと、応答するかどうかと速度を確認できます。失敗した場合は、理由と**もう一度試す**が表示されます。
  - オンの間に別のモデルを選ぶと、そのモデルがダウンロードされます。
- **サービス**：OpenAIの音声テキスト変換のアドレス（`/audio/transcriptions`）に対応していれば、どのサービスでも使えます。OpenAI自体のほか、ネットワーク内のサーバー（Speaches、LocalAI、whisper.cppのサーバー、GPU上のサーバー）などです。録音はそのサービスに送信されます。
  - サービスの行の**設定**（設定後は**編集**）でフォームが開きます。**アドレス**（`https://api.openai.com/v1`など）、**APIキー**（ネットワーク内のほとんどのサーバーでは不要です）、**モデル**（ほかを指定しなければ`whisper-1`）を入力します。
  - **保存してオンにする**（設定後は**保存**）。オンになったら、行の**テスト**。キーを保存したあとは、**⋯**メニューの**キーを削除**。サービスを保存したあとは、もう一度**サービス**を選ぶとすぐに切り替わります。

**このマシン上**というグループには、合計サイズとともに、whisper.cppがこのコンピューターに残したものが一覧表示されます。whisper.cpp本体（アプリがGPU向けにビルドした場合は「Metal向けにここでビルド」または「CUDA向け」）と、サイズ付きの各モデルです。使用中のものには「使用中」と表示されます。モデルの**⋯**メニューには**外す**があります（使用中のモデルを外すと、確認のあとサーバーでの音声認識がオフになります）。**すべて削除**はグループ自体の**⋯**メニューにあり、whisper.cppとモデルをすべて削除します。サーバーでの音声認識がオフのとき、またはサービスを使っているときに表示されます。

### 読み上げ

**[読み上げ](/settings?s=voice&find=Read%20aloud)**：返信のスピーカーボタンを押すと、コードを除いて返信を読み上げます。声と速度はブラウザごとに保存されます（グループの(i)にも記載があります）。

- **音声**：**自動**（話す言語に合ったブラウザの音声）、またはこのブラウザにある任意の音声です。話す言語の音声が先に並びます。それぞれに言語が表示され、インターネットが必要なものには「オンライン」と表示されます。
- **速度**：0.5倍から2倍まで。
- **試す**：**サンプルを再生**を押すと、その声と速度で1文を読み上げます。

ブラウザがテキストを読み上げられない場合は、そのことがセクションに表示されます。

## 返信を読み上げる

1. 返信にポインタを合わせると、右上のコピーボタンの横にスピーカーが表示されます。
2. スピーカーをクリックします。メッセージボックスの上のバーに**読み上げ中**と、全体のうちの何番目の部分か、返信の最初の言葉が表示されます。
3. バーから一時停止と再開ができます。停止はバー、またはスピーカーで行えます。

返信は、ふつうの言葉として読み上げられます。コードは読み飛ばされ、リンクはリンクの文言で、Webアドレスはサイト名で、表は1行ずつ読まれます。別の返信を開始すると最初のものは止まり、会話から離れても止まります。スピーカーはマウスでポインタを合わせると表示されます。スマートフォンでは、ハンズフリーモードが返信を読み上げます（「答えを読んで」）。

## ハンズフリーでアプリと話す

ハンズフリーモードは、歩いているときなど、画面を見られないときのためのモードです。話しかけると、アプリが処理して何をしたかを話し、再び聞き取りを始めます。セッションの開始、セッションへの言葉の伝達、状況の報告、承認への応答、結果の読み上げができます。

### 開始と終了

- セッション内では、メッセージボックスのヘッドホンボタン（マイクの横の**ハンズフリー**）で開きます。そのセッションに追従します。
- スタートページでは、同じボタンで開きます。特定のセッションには追従しません。
- 検索ボックス（Ctrl+K、Macでは⌘K）の**ハンズフリーで話す**アクションからも開けます。

画面全体に表示され、「聞いています」と話し、開いている間は画面をオンにしておくようデバイスに求めます。上部には、追従しているセッション（または「Hydorと話す」）が表示されます。大きな丸いボタンには、現在の状態が表示されます。**聞き取り中…**、**対応中…**、**読み上げ中**、**一時停止中：タップして聞き取り**のいずれかです。その下に、聞き取った内容が引用符つきで、続いて応答が表示されます。

- 読み上げ中に丸いボタンをタップすると途中で止まります。それ以外のときにタップすると、一時停止または聞き取りの続行になります。
- 終了するには、「さようなら」（または「バイバイ」「以上です」「聞き取りを止めて」「ハンズフリーを終了」「終了」）と言うか、右上の×をタップします。

### 話しかけられること

- **セッションを開始**：「週末のクレタ島旅行を計画するセッションを開始して」。スタートページと同じように、そこで最後に選んだプログラム、モデル、思考レベル、権限、エージェント、プロジェクトで、新しいタスクフォルダ（またはそこで最後に選んだフォルダ）に開始されます。以降は、そのセッションに追従します。
- **セッションに伝える**：「メートル法の単位を使うように伝えて」。追従しているセッションに、あなたのメッセージとして伝えられます。
- **状況を尋ねる**：「セッションの状況は？」。作業中のもの、対応が必要なものとその内容、最近終わったものを答えます。
- **結果を聞く**：「答えを読んで」。追従しているセッション（追従がなければ、最も忙しい、または最新のセッション）の最新の返信を読み上げます。長い返信は3〜5文の要点にまとめて読み上げます。アプリが英語以外の言語で表示されている場合は、すべての返信がその言語の要点になります。
- **承認に答える**：「承認」または「拒否」。追従しているセッション（追従がなければ、どのセッションでも）が単純なはい・いいえを待っているときに使います。質問、プラン、フォームには画面上で答える必要があり、その旨が伝えられます。
- **作業を止める**：「止めて」と言うと、追従しているセッションの作業が止まります（ハンズフリーモードは終了しません）。
- **切り替え**：別のセッションの名前を言う（「クレタ島旅行について話そう」）と、そのセッションに追従します。
- アプリのことなど、ほかのことも尋ねられます。短く答えるか、確信がないときは聞き返します。

### 自動で知らせてくれること

- 追従しているセッションが終わったとき：「…が完了しました。「読んで」と言うと答えを聞けます。」
- どれかのセッションが対応を必要としているとき：「…が対応を待っています：…」に続けて、単純なはい・いいえなら「承認か拒否と言ってください」、そうでなければ「画面で答えてください」。その後はそのセッションに追従するので、「承認」でそのセッションに答えられます。
- どれかのセッションがエラーで止まったとき：「…がエラーで停止しました。」

これらを話すときは聞き取りをいったん止め、話し終えるとまた聞き取ります。ほかのマシン上のセッションについては知らせません。

### 知っておくと便利なこと

- 補助モデルが話した内容を理解します（[設定 → エージェント → モデル → 補助モデル](/settings?s=models&find=Helper%20model)）。補助モデルに接続できない場合でも、決まった言葉は使えます。「状況」「承認」または「はい」、「拒否」または「いいえ」、「停止」、「読んで」、「開始 …」です。それ以外は、追従しているセッションに送られます。追従しているセッションがなければ、新しいセッションが開始されます。
- アプリの表示言語（設定 → 一般 → 言語）で応答し、話す言語（設定 → 音声）で聞き取ります。話す言語が未設定の場合は、アプリの言語で聞き取ります。
- 声と速度は[読み上げ](/guide/documents-voice#read-aloud)の設定が使われます。
- 読み上げができるブラウザと、聞き取りの手段が必要です。ブラウザ自体の音声認識（Chrome、Edge、Safari）か、サーバーでの音声認識です。ヘッドホンは、使える場合にのみ表示されます。サーバーを使う場合、話した内容は1.5秒の無音で区切られ（最長30秒）、15秒間無音が続くと、再び聞き取りを始めます。
- マイクが許可されていない、またはない場合は、1回だけそう伝えて一時停止します。ブラウザで許可してから、タップして聞き取ってください。
