# エージェントガイドライン

エージェントガイドラインは、ここで使うすべてのエージェントに守ってほしいことをまとめたものです。仕事の進め方の好み、必ずすること・決してしないこと、話しかけ方などを書けます。1つの文章がすべてのエージェント（Claude Code、Codex、Custom、ACPに対応したエージェント）に通用し、すべてのセッション用、プロジェクト用、1つのセッション用のいずれでも書けます。

![設定 → エージェント → エージェントガイドライン：すべてのセッションが従う内容と、各プロジェクトのガイドライン](images/guidelines.webp)

## ガイドラインとは

ガイドラインは、セッションの開始時、最初のメッセージより前に、アプリがエージェントへ渡す普通の言葉の指示です。たとえば「やさしい言葉で答え、専門用語は説明する」「何かを削除する前に確認する」「作ったものは~/Workに保存する」「イギリス式のつづりで書く」といったものです。エージェントはセッションの間ずっとこれに従います。

各エージェントが指示をどう読み込むかを知る必要はありません。Claude CodeとCodexにはそれぞれ専用のファイル（CLAUDE.mdとAGENTS.md）があり、ほかのエージェントにもそれぞれの方法があります。アプリがガイドラインをそれぞれに合った形で渡すので、1つの文章だけですべてに対応できます。

会話の中でのお願いが常に優先されます。ガイドラインに「短く答える」とあっても、詳しいレポートを頼めばレポートが返ってきます。

## 3つのレベル

ガイドラインには、もっとも一般的なものからもっとも具体的なものまで、3つのレベルがあります。

1. **すべてのセッション用**：すべてのセッションの、すべてのエージェントが対象です。[設定 → エージェント → エージェントガイドライン](/settings?s=guidelines)で設定します。
2. **プロジェクト用**：その[プロジェクト](/guide/projects)のすべてのセッションが対象です。プロジェクトの詳細の**設定**タブにある**エージェントガイドライン**欄で設定します。
3. **1つのセッション用**：そのセッションだけが対象です。開始ページで始める前に（**オプション → ガイドライン**）、または始めたあとにセッションのメニュー（⋯）→ **セッション設定 → ガイドライン**から設定します。

エージェントには、そのセッションに当てはまるすべてのレベルがこの順番で渡されます。2つの内容が食い違う場合は、より具体的なものが優先されます。セッションのガイドラインはプロジェクトのものより、プロジェクトのものはすべてのセッション用より優先されます。（設定の**1つのセッション用**の横にある(i)にも同じことが書かれています。）

## すべてのセッション用のガイドラインを書く

1. [設定 → エージェント → エージェントガイドライン](/settings?s=guidelines)を開きます。
2. **すべてのセッション用**の下に、エージェント全員に知っておいてほしい自分のことや仕事の進め方を書きます。
3. **保存**をクリックします。

入力欄の下の**テンプレートから…**では、エージェントの話し方をあらかじめ用意したものから選べます（**やさしい言葉で、短く答え、専門用語は説明する**、**温かく励ます：初心者です**、**簡潔で専門的**）。選ぶと「私への話し方：…」という1行が追加されるので、保存する前に書き換えられます。**保存**は何か変更するまで薄い表示のままです。**変更を元に戻す**を押すと、保存済みの内容に戻ります。

各レベルには20,000文字まで書けます。できるだけ短くまとめてください。どのセッションもすべてを読み込むので、何ページも書くより、わかりやすい数行のほうがうまくいきます。

## プロジェクトにガイドラインを設定する

プロジェクトごとに専用のガイドラインを設定できます。そこで続ける作業に合わせて、誰のためのものか、書き方のスタイル、プロジェクトのルールなどを書きます。

1. セッションのサイドバーでプロジェクト名をクリックし（**プロジェクトの詳細**が開きます）、**設定**タブを開きます。
2. **エージェントガイドライン：プロジェクト内のすべてのエージェントが従う内容**の欄に書きます。
3. プロジェクトを保存します。

プロジェクトを作るときに書くこともできます。**新しいプロジェクト**ウィンドウで**その他のオプション**をクリックし、**エージェントガイドライン**に書きます。**設定 → エージェント → エージェントガイドライン → プロジェクト用**には、ガイドラインのあるすべてのプロジェクトが、それぞれの1行目とともに一覧表示されます（多い場合は**すべて表示**）。プロジェクトをクリックすると、そのプロジェクトが開きます。

グループ（複数のプロジェクトをまとめたプロジェクト）では、そのセッションはグループ自身のガイドラインに従い、グループ内の各プロジェクトの作業をするときに、そのプロジェクトが求める内容も読み込みます。

## 1つのセッション用のガイドライン

### 始める前

1. 開始ページで、メッセージ欄の横にある**オプション**を開きます。
2. **ガイドライン**をクリックします。**このセッション**のタブでダイアログが開きます。
3. このセッションだけが従うことを書き、**保存**をクリックします。すると、オプションのチップに**このセッション用**と表示されます。

同じダイアログには、プロジェクトのガイドライン（プロジェクトを選んでいる場合）と、すべてのセッション用のガイドラインも、それぞれ別のタブで表示されます。エージェントが従う内容をすべて確認でき、それらも変更できます。タブに点があれば、そのレベルに内容があるという意味です。

### 実行中のセッションで

1. セッションのメニュー（⋯）→ **セッション設定 → ガイドライン**を開きます。
2. **このセッション**（またはプロジェクト用、すべてのセッション用）を変更し、**保存**をクリックします。

変更は次のメッセージから有効になります。Claude CodeとCodexは起動時に指示を読み込むので、次のメッセージを送ると、アプリが新しいガイドラインでエージェントを裏で再起動します。会話はそのまま続きます。ただし、エージェントがターンの途中にいるとき、目標に向かって作業しているとき、バックグラウンドで作業が実行されているときは待機し、待機が終わってから行われます。Customはどのみちターンごとに読み込みます。そのほかのエージェント（Gemini CLI、OpenCodeなど）は、変更したガイドラインを次のセッションから反映します。

## よいガイドラインとは

- **ほしいことをはっきり書く**：「気をつけて」より「何かをインストールする前に確認して」のほうが明確です。
- **ずっと変わらないことはここに、作業内容はメッセージに書く**：ガイドラインは、いつでも当てはまることのためのものです。
- **適切なレベルを使う**：話しかけ方の好みはすべてのセッション用に、プロジェクトのルールはそのプロジェクトに、一度きりの制約はそのセッションに書きます。
- **最新の状態に保つ**：エージェントがしてほしくないことを繰り返すときは、1行追加します。

例をいくつか挙げます。

- すべてのセッション用：「やさしい言葉で答える。専門用語は最初に出てきたときに説明する。ファイルを削除するときや、このコンピューターの外へ何かを送るときは確認する。」
- 「論文」プロジェクト用：「引用はAPAスタイルで行う。論文のテーマはギリシャの酪農。下書きはdraftsフォルダに保存する。」
- 1つのセッション用：「Pythonの標準ライブラリだけを使う。」

## エージェントの話し方

以前は**エージェントの話し方**（設定 → 機能 → アシスタント、現在はあなたのエージェント）という設定がありましたが、現在はすべてのセッション用のガイドラインの一部になっています。そこに書いてあった内容は、「私への話し方：」で始まる1行として移されています。変更や削除はガイドラインで行います。

## CLAUDE.mdとAGENTS.md

Claude CodeとCodexは、それぞれ専用の指示ファイルも読み込みます。Claude Codeは CLAUDE.md、CodexはAGENTS.mdで、すべてのセッション用にはホームフォルダに、そのフォルダで作業するセッション用にはプロジェクトのフォルダに置きます。これらはこれまでどおり使えます。リポジトリに置いて、作業する全員で共有している場合は、ここから編集することもできます。

1. [設定 → エージェント → エージェントガイドライン](/settings?s=guidelines)を開きます。
2. **1つのセッション用**の下の最後のグループにある**指示ファイル**を開きます（ヒントには「プロジェクトのフォルダにあるCLAUDE.mdとAGENTS.md」と表示され、(i)にはここにある理由が書かれています）。
3. フォルダを選び、**Claude Code**または**Codex**を選んで、編集するファイルを選びます（または**作成**します）。

一覧には、そのフォルダでのセッションのためにエージェントが読み込むすべてのファイルが、読み込まれる順番で表示されます。ほとんどの人にとっては、ガイドラインのほうが簡単です。すべてのエージェントに通用し、ファイルも必要ありません。

## エージェントに頼む

- 「ガイドラインに、いつもギリシャ語で答えるよう追加して。」
- 「このセッションはどんなガイドラインに従っている？」
- 「論文プロジェクトに、APAスタイルで引用するというガイドラインを設定して。」
- 「ガイドラインからイギリス式のつづりの行を削除して。」
- 「このセッションだけ、標準ライブラリ以外のライブラリは使わないで。」
