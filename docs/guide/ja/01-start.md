# はじめに

このトピックでは、Hydorの概要、画面の見方、最初のセッションの始め方、検索ボックスでの検索、スマートフォンでの使い方を紹介します。最後に、すべてのキーボードショートカットを1つの表にまとめています。

![アプリの画面：左にツールのアイコンバーとセッションのサイドバー、そして、やりたいことを伝えるスタートページ](images/start.webp)

## Hydorとは

Hydorは、AIエージェントをお使いのコンピューター上で動かすアプリです。デスクでも外出先でも、ブラウザやスマートフォンから利用できます。エージェントとは、作業を代わりに進めるプログラムのことです。ファイルの読み書き、コマンドの実行、Webの検索を行い、何をしたかを報告してくれます。ご自身のサブスクリプションでClaude CodeやCodexを使えるほか、Custom（あらゆるモデルで動くアプリ独自のエージェントで、お使いのコンピューター上のオープンモデルにも対応）や、Gemini CLI、OpenCodeなどのエージェントも使えます。エージェントとのやり取りの1つ1つが**セッション**です。ページを閉じてもセッションは動き続けるので、デスクで始めたセッションにスマートフォンから答えることもできます。コードの作成に使う人が多いですが、調査、文章作成、ドキュメント、計画、日々のタスクなど、あらゆる作業に役立ちます。

## 画面の見方

画面は3つの部分でできています。左端にあるツールの細い帯の**アイコンバー**、ページによってはその隣に表示される**列**（スタートページとセッションではセッションの**サイドバー**、アプリ・エージェント・ヘルプ・設定ではそれぞれ専用の一覧）、そして今開いているページ（スタートページ、セッション、設定など）です。コンピューターでは、アイコンバーは常に表示されます。スマートフォンにはアイコンバーがなく、サイドバーが横からスライドして開くドロワーになり、ツールもそこにまとまっています（[スマートフォンでの使い方](#use-the-app-on-a-phone)を参照）。

コンピューターでは、列の幅を180〜560ピクセルの間で変更できます。右端をドラッグするか、端をクリックして左右の矢印キーを押します。幅はすべての列で共通で、このブラウザに保存されます。

### アイコンバー

アイコンバーはアイコンが縦に並んだ列です。アイコンにポインタを合わせるか、Tabキーで移動すると、横に名前と（ある場合は）ショートカットがツールチップで表示されます。今開いているページのアイコンは点灯し、画面の端のそばにアクセントカラーのバーが表示されます。上から順に紹介します。

- **セッション**：サイドバーにセッションを表示します。スタートページやセッションの画面では、サイドバーの表示と非表示を切り替えます（Ctrl+Bと同じ）。それ以外のページでは、サイドバーを表示したうえで、このウィンドウで最後に開いていたセッションに戻ります。開いていたセッションがなければスタートページに移動します。サイドバーを隠している間は、このタイルの小さなドットが、他のマシンで何かあったことを知らせます（[マシンを切り替える](/guide/devices#switch-between-machines)を参照）。

続いて、アプリの各セクションです（デスクトップアプリでは4つ、Webアプリとスマートフォンでは**ブラウザ**がない3つです）。

- **ブラウザ**：デスクトップアプリ専用の独自ブラウザです。タブ、プライベートタブ、スマートアドレスバー、ページの翻訳、リーダービュー、ブックマーク、履歴、広告ブロック、Chrome拡張機能を備え、ページをエージェントに渡すこともできます。[独自のブラウザ](/guide/web#your-own-browser)を参照してください。
- **アプリ**：繰り返し実行するタスク向けです。フォームに入力すると、エージェントが作業を行います。[アプリ](/guide/apps)を参照してください。
- **プロジェクト**：すべてのプロジェクトをカードで表示します。何が入っているか、最後にいつ作業があったかが分かり、カードをクリックするとプロジェクトの詳細が開きます。[すべてのプロジェクトを見つける](/guide/projects#find-all-your-projects)を参照してください。
- **エージェント**：エージェントの一覧です。それぞれの役割、作業する場所と時間、使用するモデル、確認する相手のほか、アプリに付属のエージェントも確認できます。[エージェント](/guide/agents)を参照してください。

その真下には、常に同じ位置に次の2つがあります。

- **受信トレイ**：承認、質問、フォームなど、すべてのセッション、スケジュールタスク、マシンから届いた、対応待ちの項目がまとまっています。アイコンの角の数字は、今対応待ちの項目の数です。[受信トレイと通知](/guide/inbox)を参照してください。
- **検索**：検索ボックスを開きます（Ctrl+Kと同じ）。

少し間をあけて、ツールが並びます。

- **使用量**：各プランの上限をどれだけ使ったか、いつリセットされるかを確認できます。**アクティビティ**と**アリーナ**のタブがあります。アイコンの下の細いバーは、有料のサブスクリプション全体の残量を示します。有料のものがない場合は無料のものの残量を示し、残りがなくなると赤になります。[使用量、上限、費用](/guide/usage)を参照してください。
- **システム**：このコンピューターの画面で、ツールごとにタブがあります。**概要**（動作状況と、各ツールが今保持している内容）、**ファイル**（ファイルの閲覧、オープン、編集）、**Git**（リポジトリ、変更、ブランチ、履歴）、**ターミナル**（ページを離れても動き続けるシェル）、**プレビュー**（このマシンで動いているWebアプリの開発サーバー。このマシン自身のページでのみ利用可能）、**モニター**（プロセッサ、グラフィックスカード、メモリ、ディスク、負荷の高いプログラムをリアルタイムで表示）です。[システム：ファイル、Git、ターミナル、プレビュー](/guide/files-git)を参照してください。
- **設定**：アプリで変更できるすべての設定です。点が付いているときは、新しいバージョンが公開されています。[すべての設定](/guide/settings)を参照してください。
- **ヘルプ**：このガイドを開きます。アプリについてエージェントに質問することもできます。ようこそツアーもここから始められます。

セクションは、ブラウザ、プロジェクト、エージェント、アプリの順に並び、その下に受信トレイと検索、さらに下のツールが使用量、システム、設定、ヘルプの順に並びます。これが通常の順序です。順序を変えるには、タイルを同じグループ内（セクション、または下部のツール）の別の位置にドラッグします。受信トレイと検索は、常にセクションの真下に残ります。新しいバージョンで加わったタイルは、設定した順序の中で通常の位置に入ります（たとえばプロジェクトはエージェントの直前）。リストの末尾にはなりません。設定した順序は、どのマシンを見ていても、すべてのデバイスで共通です。並べ替えたあとにタイルを右クリックして**通常の順序に戻す**を選ぶと、すべて元に戻ります。すべてのタイルが収まらない高さのウィンドウでは、アイコンバーがスクロールします。

セッションのサイドバーが表示されるのは、スタートページ、セッション、そのレビューの画面だけです。**アプリ**、**エージェント**、**ヘルプ**、**設定**にも同じ種類の列があり、ロゴ、それぞれの一覧（アプリページとエージェントページの各項目、ガイドのトピック、設定のセクション）、**サイドバーを隠す**が表示されます。**ブラウザ**のページでは、タブが専用の列に表示されます。そのほかのページ（プロジェクト、受信トレイ、使用量、システムなど）は、幅全体を使います。**Ctrl+B**で、今開いているページの列を表示または非表示にできます。列の幅はすべて共通です。内容が収まりきらない列にはスクロールバーが表示され、下にまだ続きがあるときは列の下端がフェードします。ページがアプリに再接続している間は、線で消されたWi-Fiアイコンが、列の上部のロゴの横に表示されます。列が表示されていない場合（非表示にしたか、そのページに列がない場合）は、アイコンバーの上部に表示されます。

### サイドバー

サイドバーは、アイコンバーの隣にある列です。次の内容が表示されます。

- **HYDΩR**のロゴと、末尾にある**セッションのフィルタとグループ化**ボタンおよび**サイドバーを隠す**（Ctrl+B）。サイドバーを隠している間は、ページの左上のボタンで再び表示でき、アイコンバーはそのまま残ります。スマートフォンのドロワーでは、代わりにロゴ、受信トレイ、フィルタボタン、**メニューを閉じる**がここに並びます。
- マシンの切り替え。[設定 → マシン](/settings?s=machines)で他のマシンを追加した場合にのみ表示されます。今見ているマシンの名前が表示され、他のマシンで起きたことも分かります。前回見た後にそちらで完了したセッションの数はアクセントカラーの丸い印に、対応待ちのセッションがあるときはオレンジのドットになります。[スマートフォン、他のマシン、共有](/guide/devices)を参照してください。
- **新しいセッション**：[スタートページ](#the-start-page)を開きます。
- セッションを探すには、検索ボックスを使います。アイコンバーの**検索**（スマートフォンではドロワー下部のツールにある**検索**）か、Ctrl+K（Macでは⌘K）です。タイトル、フォルダ、開始時に選んだエージェント（チューターで始めたセッションを探すにはチューターと入力します。一般は対象外）、セッション内で交わされた言葉から探せます。アーカイブしたセッションも対象で、**アーカイブ済み**と表示され、ほかのセッションの後ろに並びます（[Ctrl+Kですべてを検索](#search-everything-with-ctrlk)を参照）。
- 見出しにあるフィルタボタン（**セッションのフィルタとグループ化**）で、一覧を絞り込めます。メニューには次の項目があります。**エージェント**（**すべてのエージェント**に続いて、セッションの開始に使ったエージェントが、よく使う順に最大8件、それぞれのセッション数とともに並びます。何かのエージェントとして始めたセッションがあると表示されます）、**実行環境**（**すべて**、**Claude Code**、**Codex**の切り替え）、そしてプロジェクトがある場合は**プロジェクト**（**すべてのプロジェクト**に続いて、プロジェクトが最大8件）です。**新しいプロジェクト…**はプロジェクトを作り、**新しいフォルダ…**（一覧をグループ化しているときに表示）はセッション用のフォルダを作ります（[セッションをフォルダに整理する](#sort-sessions-into-folders)を参照）。フィルタは組み合わせて使えます。たとえば、あるプロジェクト内の、あるエージェントのセッションだけを表示できます。フィルタがオンの間はボタンがアクセントカラーになり、**新しいセッション**の下に、オンになっているフィルタごとのチップがアイコンと名前付きで表示されます。チップの×を押すと、そのフィルタを解除してすべてのセッションを表示します。絞り込んだ一覧に何もない場合は、「フィルタに一致するセッションはありません。」と表示され、**すべてのセッションを表示**を選べます。最後の行の**フォルダまたはプロジェクトでグループ化**で、プロジェクトとフォルダによるグループ分けのオンとオフを切り替えます（[セッションの一覧](#the-session-list)を参照）。[エージェントのセッションを探す](/guide/agents#find-an-agents-sessions)と[プロジェクトとナレッジ](/guide/projects)を参照してください。

### セッション一覧

**新しいセッション**の下に、すべてのセッションがグループごとに並びます。

- **アクティブ**：直近5分以内にアクティビティがあったすべてのセッションです。ここ、VS Code、ターミナルのいずれでの操作も対象で、終了したものも含まれます。5分間アクティビティがないと、エージェントが開いたままでも、通常のグループに戻ります。使用量の上限で停止したセッションは、自動再開が予定されている間はここに残ります。その再開を取り消すと、5分のルールに戻ります。バックグラウンドのエージェント、コマンド、モニターがまだ動いているセッションも、どれだけ静かでも、それらが終わるまでここに残ります。一覧にある間は位置が固定されます。ドラッグすると移動できます。
- **ピン留め**：ピン留めしたセッションです。ドラッグした順に並びます。下のグループからセッションをドラッグして重ねると、ピン留めされます。見出しをクリックすると折りたたまれます。折りたたんでいる間にセッションをドラッグすると、見出しの下に**ここにドロップしてピン留め**というボックスが表示され、そこにドロップできます。
- **フォルダ**：どのプロジェクトにも属さないセッションのために自分で作ったフォルダです（作った場合のみ表示されます。[セッションをフォルダに分ける](#sort-sessions-into-folders)を参照）。**プロジェクト**の上にあります。
- **プロジェクト**：セッションのあるプロジェクトごと、また2件以上のセッションが作業しているフォルダごとに、その名前のグループができます。独自の順番に並べ替えるまでは、最後に使ったものが先頭に来ます。並べ替えるには、グループの見出しをドラッグして、ほかのグループの間の好きな位置に移します（スマートフォンでは、先に見出しを少し長押しします）。この順番はすべての端末で共通です。一度も動かしていないグループ（その後に作ったプロジェクトなど）は先頭に来ます。各グループには新しい順に5件のセッションが表示されます。**Show 12 more**（数字は残りの件数）で残りを表示し、**表示を減らす**で元に戻ります。プロジェクト内のフォルダ（[セッションをフォルダに分ける](#sort-sessions-into-folders)を参照）は、見出しのすぐ下に先に並びます。
- **今日**、**昨日**、**今週**、続いて月名と年：残りのセッションが、最後にアクティブだった時期ごとに並びます。
- **スヌーズ中**：一番下に表示され、設定した時刻になるまでそこにあります。

グループになるのは、選んだフォルダだけです。ホームフォルダ、デフォルトのフォルダ、新しいタスクフォルダ、アプリが動作するフォルダ、一時フォルダはグループにならず、それらのセッションは日付ごとに並びます。ワークツリーのセッションは、そのワークツリーの元になったフォルダのグループに入ります。プロジェクトのフォルダ、またはその中のフォルダで作業しているセッションは、Hydor、Claude Code、Codexのどこで開始したものでも、プロジェクトのグループに入ります。Codexプロジェクトのフォルダは、プロジェクト名で表示されます。CodexアプリがChatGPTプロジェクト用に作るフォルダはIDだけの名前なので、Codexがプロジェクト名を把握していない場合はグループにならず、そのセッションではフォルダとして**ChatGPTプロジェクト**と表示されます。そのセッションのメニューの**フォルダ名を変更**で名前を付けると、その名前のグループになります。同じ名前のフォルダが2つあるときは、見分けがつくまで上位のフォルダ名も一緒に表示されます（「client/app」「server/app」）。

**フォルダ**と**プロジェクト**の下の一覧は、ツリー形式です。どの見出しも先頭に矢印があり（クリックで折りたたみ）、プロジェクトやフォルダのセッションは、細い線に沿って見出しの下に字下げして表示されます。折りたたんだ見出しは、右端に中のセッション数を表示します。**アクティブ**、**ピン留め**、**フォルダ**、**プロジェクト**の見出しは折りたためます。クリックすると下の内容がすべて隠れ、もう一度クリックすると表示されます。折りたたんだ状態の**アクティブ**と**ピン留め**には、中のセッション数が表示されます。前回確認した後に完了したセッションがある場合は、点も表示されます。開いているセッションは、そのセクションを折りたたんでも見出しの下に表示されたままです。折りたたみの状態は、このコンピューターで保たれます。ただし、**プロジェクト**内の各プロジェクトやフォルダの折りたたみは別の扱いです。**プロジェクト**の見出しの右端にある**+**は常に表示されています。ここには**新しいプロジェクト…**、**新しいプロジェクトグループ…**（[プロジェクトを作る](/guide/projects#make-a-project)を参照）、**新しいフォルダ…**があります。

フォルダの見出しをクリックすると1行に折りたたまれ、中のセッション数と、前回確認した後に完了したものがあれば点が表示されます。もう一度クリックすると開きます。プロジェクトの見出しは動きが異なります。名前をクリックすると詳細がウィンドウで開き（[プロジェクトの詳細を開く](/guide/projects#open-a-projects-details)を参照）、名前の前の矢印でセッションを折りたたみます。各グループは最初は折りたたまれ、見出しとセッション数だけが表示されます。必要なものを開くと、その状態が保たれます。開いているセッションは、折りたたみの有無にかかわらずグループ内に表示されます。グループの折りたたみ方は、このブラウザに保存されます。見出しの端にあるボタン（コンピューターでは見出しにポインターを合わせると端に重なって表示され、タッチ画面では常に表示されます）は、そのフォルダやプロジェクトで新しいセッションを始めるペンと、メニューを開く**⋯**です（見出しを右クリックしても開きます）。メニューの内容は、プロジェクトでは**プロジェクトの詳細**、**名前を変更**、**新しいフォルダ**です。コンピューター上のフォルダでは、**名前を変更**、**フォルダ本来の名前を使う**（名前を変更した後）、**プロジェクトにする**、**ファイルで開く**です。フォルダの名前は、名前をダブルクリックして変更することもできます。新しい名前を入力してEnterを押します（Escを押すと元のままになります）。プロジェクトの名前は、⋯ → **名前を変更**（または見出しの右クリック）で変更します。プロジェクトの新しい名前は、どこでもその名前になります。フォルダの新しい名前は、アプリ内での呼び名で、サイドバー、各セッションの下、フォルダのメニューで、すべての端末に反映されます（ディスク上のフォルダ名は変わりません）。名前を空にすると、本来の名前に戻ります。

Hydorの外（VS Code、ターミナル、Claudeのデスクトップアプリ、Codexアプリ）でClaude CodeやCodexで行ったセッションも一覧に表示されます。それらで作業しているフォルダは自動的にプロジェクトになるため（[Claude CodeとCodexで見つかったプロジェクト](/guide/projects#projects-found-in-claude-code-and-codex)を参照）、そのグループはプロジェクトのグループとなり、名前の後ろにClaude CodeまたはCodex（または両方）のマークが付きます。外部のセッションがあってもプロジェクトではないフォルダ（外部のセッションが1件だけの場合や、Hydorが除外した場合）は、ほかのフォルダと同じようにフォルダのグループのままです。最初のセッションがHydorの外で開始されたフォルダには、セッションの出どころが表示されます。名前の後ろにClaude CodeまたはCodexのマークが付き、両方にセッションがあれば両方のマークが付きます。名前にポインターを合わせるか、見出しの**⋯**を開くと、開始したアプリが**From Codex: VS Code, Terminal**のように表示されます。[設定 → エージェント → アカウント](/settings?s=accounts&find=Accounts)で追加したアカウント内のものであれば、そのアカウント名も表示されます。Hydorから作業を続けてもマークは残ります。そのフォルダでの作業がどこで始まったかを示しているためです。

セッションを日付ごとだけに並べる従来の表示にするには、フィルタボタンのメニューで**フォルダまたはプロジェクトでグループ化**のチェックを外すか、検索ボックスで**セッションをフォルダまたはプロジェクトでグループ化**を探します。同じ方法で元に戻せます。一覧に1つのプロジェクトだけが表示されている間は、そのセッションは日付ごとに並びます。

**アーカイブ済み**のセッションは一覧に表示されませんが、検索ボックス（Ctrl+K）では見つかり、**アーカイブ済み**と表示されます。最初のセッションを作るまでは、「No sessions yet.」と表示されます。

各行には、状態を示すドットが付いたエージェントのアイコン、セッションのタイトル、2行目が表示されます。エージェントが実行中のとき、2行目にはその作業内容が表示されます（「Working · 2m 10s」。以前のターンも含めた合計作業時間は「Working · 2m 10s (47m)」、ほかに「Needs you」「Ready」「Working · 1 in background」「Open in VS Code」）。それ以外のときは、フォルダ（自分のホームフォルダなら「Home folder」）、最後にアクティブだった時刻からの経過時間、追加・削除した行数が表示されます。通常のエージェント以外で開始したセッション（プロジェクトに専用エージェントがある場合はそのエージェント、それ以外のセッションでは一般）では、2行目の先頭にそのエージェントのアイコンと名前が付きます。待機中は「Planner · web-agent · 5d」、作業中は「Researcher · Working · 2m 10s」のようになります。通常のエージェント、Hydorの外で開始したセッション、その後削除したエージェントには名前が付かないため、ほとんどの行はこれまでどおりの見た目です。専用エージェントがCoderのプロジェクトでは、Coderのセッションには名前が付きませんが、リサーチャーのセッションには付き、一般のセッションにも付きます。**プロジェクト**の下では、グループ名がすでにフォルダを示しているため、行は1行になります。タイトルの後に、最後にアクティブだった時刻からの経過時間（ワークツリーのブランチの後）、または作業中や確認待ちのときはエージェントの状況が表示されます。通常のエージェント以外で開始したセッションには2行目が残り、そこにエージェント名が表示されます（「Planner · 5d」）。タイトルの後ろに小さなマークが付くことがあります。

- アクセントカラーのドット：前回見た後に完了したことを示します（2行目は「Done · 5m ago」）。開くと、すべてのデバイスで既読になります。
- 状態付きのプルリクエストのバッジ
- ターゲット：セッションにゴールがあります。
- ピン：ピン留めされています（そう表示される**ピン留め**グループの中には付きません）。

Customが作業中または起動中のときは、回転するエージェントのアイコンの代わりに、Hydorのローディングアニメーション（Ωの中で水位が上下する動き）が作業中の表示になります。ローディングのマークは、横のテキストと上下中央で揃って表示されます。

状態を示すドットは、セッションの様子を表します。

| ドット | 意味 |
| --- | --- |
| 青、呼吸するように明滅 | 作業中：ターンまたはバックグラウンドのタスクが実行中です |
| 琥珀色 | 対応待ち：承認、質問、フォームが待っています |
| 緑 | 準備完了：エージェントが実行中で、次のメッセージを待っています |
| グレー | VS Codeまたはターミナルで開いていて、そこでは待機中です |
| ドットなし | 停止中：エージェントは動いていません。次のメッセージを送ると再び起動します |

ブラウザのタブには、対応待ちのセッションの数が「(2) Hydor」のように表示されます。

サブエージェント、つまりエージェントが仕事の一部のために開始したセッション（Hydorサブエージェント）や、そのプログラムがセッション内で実行したもの（Claude CodeとCodex独自のもの）は、作業中または対応待ちの間、そのセッションの下に折りたたまれて表示され、「3 subagents · 1 needs you」のような行が付きます。クリックすると中身が表示されます。完了したものは、開いていない限りサイドバーから消えます。会話内のサブエージェントのカードと、メッセージボックスの上の行には残ります。[サブエージェント](/guide/sessions#subagents)を参照してください。

一覧の各セッションにはメニューがあります。行にポインターを合わせて右端の**⋯**をクリックするか、行を右クリックします（スマートフォンでは**⋯**をタップ）。メニューには、**名前を変更**、**フォルダ名を変更**（プロジェクトに属さないセッション）、**フォルダに移動**（[セッションをフォルダに分ける](#sort-sessions-into-folders)を参照）、**ピン留め**（または**ピン留めを外す**）、**スヌーズ**、**完了にする**、**アーカイブ**、確認の後に実行される**削除**があります。タイトルをダブルクリックするか、選択した行でF2を押しても名前を変更できます。それぞれの詳しい説明は、[名前の変更、ピン留め、スヌーズ、完了、アーカイブ、削除](/guide/sessions#rename-pin-snooze-settle-archive-or-delete)にあります。

### セッションをフォルダに分ける

フォルダは、「旅行」「税金」「あとで読む」のように、自分の考え方でセッションを分けるためのものです。サイドバー上だけの存在で、コンピューター上は何も変わりません。どの端末でも同じフォルダが表示されます。セッションがコンピューター上で作業するフォルダとは別のものです。そちらは**プロジェクト**の下に独自のグループができます。

フォルダには2種類あります。

- **プロジェクトの外**：**プロジェクト**の上の**フォルダ**セクションに表示され、どのプロジェクトにも属さないセッションを入れます。
- **1つのプロジェクトの中**：そのプロジェクトの見出しの下で、ほかのセッションより前に表示され、そのプロジェクトのセッションを入れます。

作り方は次のとおりです。

- **フォルダ**の見出しの**+**をクリックするか、**プロジェクト**の見出しの**+** → **新しいフォルダ…**を選びます。この方法では、プロジェクトの外にフォルダができます。
- プロジェクト内にフォルダを作るには、サイドバーでプロジェクトの**⋯**メニューを開き、**新しいフォルダ**を選びます。
- セッションのメニュー（⋯または右クリック）を開き、**フォルダに移動** → **新しいフォルダ…**を選びます。フォルダが作られ、セッションがそこに入ります（ボタンの表示は**作成して移動**です）。プロジェクト内のセッションでは、フォルダもそのプロジェクト内に作られます。
- 一覧をグループ化している間は、フィルタボタンのメニュー（**セッションのフィルタとグループ化**）にも**新しいフォルダ…**があります。

名前を付けて（60文字まで。同じ場所に同じ名前のフォルダは2つ作れません）、**作成**を押します。

セッションをフォルダに入れるには、メニューを開いて**フォルダに移動**からフォルダを選びます。現在入っているフォルダにはチェックが付き、**フォルダから外す**で取り出せます。セッションをフォルダの見出しにドラッグしても入れられます（スマートフォンでは、先にセッションを少し長押ししてつかみます）。セッションを入れられるフォルダは1つまでで、プロジェクトのセッションはそのプロジェクトのフォルダにしか入れられません。

フォルダの見出しは、ほかの見出しと同じように折りたためます。フォルダは最初は折りたたまれ、中のセッション数が表示されます。フォルダは名前順に並びます。名前を変更するには、名前をダブルクリックするか、**⋯** → **名前を変更**を選びます。**⋯** → **フォルダを削除**でフォルダを削除できます。中のセッションは削除されず、一覧の元の場所に残ります（セッションが入っている場合は、先に確認があります）。プロジェクトを削除すると、そのフォルダも同じように削除されますが、セッションは残ります。

作業中やピン留めしたセッションは、引き続き**アクティブ**や**ピン留め**に表示され、その後フォルダに戻ります。フォルダが表示されるのは、フィルタボタンのメニューで**フォルダまたはプロジェクトでグループ化**がオンの間だけです。

### スタートページ

**新しいセッション**をクリックするとスタートページが開きます。「What should we work on?」と尋ねられ、「Ask for anything: research, documents, plans, code.」と表示され、大きなメッセージボックスと、その下に選択項目の列が並びます。

- **実行環境**：作業を行うプログラムです（Claude Code、Codex、Custom、または追加したほかのエージェント）。
- **モデル**：そのエージェントのモデルです。
- **フォルダ**：エージェントが作業する場所、プロジェクト、またはタスク用に新しく作るフォルダです。
- **エージェント**：セッションがどのエージェントとして動くかです（一般、リサーチャー、ライター、プログラマー、チューター、プランナー、アナリスト、アプリビルダー、または自分で作ったもの。[エージェント](/guide/agents)を参照）。
- **オプション**：思考レベル、権限、メモリ、支出上限などです。通常と違う設定にしたものは、チップに表示されます。

コンピューターでは、ボックスの下に「Enter to start · Shift+Enter for a new line」という案内が表示されます。エージェントのプランの使用量を使い切ったときは、ボックスの上にバナーが表示され、リセットされる時刻も案内されます。

前回の訪問以降に何かあったときは、ボックスの下に**不在中の出来事**が1行で表示されます。完了したこと、対応待ちのこと、自動で実行されたこと、次に実行されることが分かります（[不在中の出来事](#while-you-were-away)を参照）。何もなかったときは表示されません。

ボックスが空の間は、その下に**スターターアイデア**が表示されます。リクエストの例が3つ、自分のアプリが2つ、自動化が1つです。

- 例をクリックするとボックスに入力されます。自由に直してから送信してください。送信するまでは何も送られません。「…」とある部分には、自分の言葉を入れます。例は毎日変わり、コードのあるフォルダではコードに関するものになります。
- アプリをクリックするとそのフォームが開きます。よく実行する上位2つのアプリが表示されます。まだ実行したことがない間は、**ディープリサーチレポート**と**旅行プランナー**が表示されます（[アプリ](/guide/apps)を参照）。
- 自動化（「Every Monday at 8:00, send me …」）をクリックするとボックスに入力されます。続きを入力して送信すると、エージェントが[スケジュールタスク](/guide/tasks)として設定します。

アイデアは、入力を始めるとすぐに折りたたまれます。**非表示**にすると、すべてのデバイスで完全に非表示になります。元に戻すには、設定 → アプリ → 一般で[スターターアイデア](/settings?s=general&find=Starter%20ideas)をオンにします。スマートフォンでは、横にスクロールする1行で表示されます。

その下には、**今日**の1日のまとめが1行で表示されます（「Today · 7 sessions · 12 file edits · $0.84」。0の項目は省略されます）。金額は、その日のトークンをAPI料金で計算した場合の費用で、アクティビティページの**APIコスト（概算）**と同じ見積もりです。プラン（Claude Code、Codex）を使っている場合は、実際にはプランの料金を支払います。この行にポインターを合わせると、変更された行数、トークン、プロンプトが表示されます。クリックするとアクティビティページが開きます。スマートフォンでは、ボックスの下の**最近**に、直近の6件のセッションが表示されます。

右上の**探索**を開くと、自分向けに作られたマガジンが表示されます。取り組んでいることや関心のあることについての記事や最新ニュースが、プロフィールと最近のセッションから選ばれます（[探索](/guide/apps#explore)を参照）。ドットが付いているときは、まだ開いていない新しい号が用意されています。

スタートページでの選択は、プロジェクト、フォルダ、**新しいタスクフォルダ**ごとに別々に保持されるため、プロジェクトごとに専用のプログラム、モデル、エージェントで開くことができます（[スタートページが記憶するもの](/guide/sessions#what-the-start-page-remembers)を参照）。スタートページのすべての項目は、[セッションを開始する](/guide/sessions#start-a-session)で説明しています。

### 離れている間に

アプリに戻ると、開始ページのメッセージ欄の下（スターターアイデアの上）に、離れている間に起きたことがまとめて表示されます。表示は1行に折りたたまれ、重要なものが先頭に並びます。例：「1件 対応が必要 · 1件 失敗 · 3件 完了 · 次へ：Morning brief 07:30 · 昨日18:40以降」。0件の項目は表示されません。行をクリックすると開きます。行の一部をクリックすることもできます。**対応が必要**・**失敗**・**完了**はその項目だけを開き（**すべて表示**で残りも表示されます）、**次へ**はスケジュールタスクを開き、時刻はすべてを表示します。スマートフォンでは行全体が1つのボタンで、タップすると開きます。時刻は開いたブロックのヘッダーに表示されます。

開くと、重要なものから順に最大6行が表示されます（**あと…件を表示**で残りを一覧できます）。

- **対応が必要**：承認、質問、フォーム、送信トレイで保留中の呼び出しなど、返答を待っているものです。[受信トレイ](/guide/inbox)と同じ内容が並びます。承認、質問、フォーム、保留中の呼び出しには**ここで回答**があり、行の下に受信トレイのカードが開きます。それ以外の行をクリックすると、待っている場所に移動します。
- **完了**と**失敗**：前回の訪問以降に終了し、まだ開いていないセッションです。それぞれ最後の返信の冒頭（または問題の内容）と、作成されたファイルが表示されます。ファイルをクリックするとファイルで開き、行をクリックするとセッションが開きます。ターンが終了しても、開始したサブエージェントやバックグラウンドタスクがまだ実行中のセッションは、完了していません。それらが終わると、ここに表示されます。
- **自動実行**：[スケジュールタスク](/guide/tasks)、エージェントのスケジュール、アプリ（アプリページ、リンク、API、チャットアプリから開始したもの）の実行です。それぞれ結果（**完了**、**失敗**、**新着なし**）とかかった費用が表示されます。クリックすると、実行されたセッションまたはアプリの実行が開きます。
- **本日の予定**：今日これから予定されているスケジュールタスクが、行の下に表示されます。

自分で開くまで、対応が必要なものがあっても折りたたまれたままです。開いた状態も折りたたんだ状態も、この端末では最後の状態のままになります。**すべて確認済みにする**を押すと一覧が消え、表示されていた内容は確認済み、セッションは開いたものとして、すべての端末で扱われます（サイドバーのドットも消えます）。その後に起きたことは、再び表示されます。新着のなかった実行や次の実行の予定だけでは、自動的に表示されることはありません。

前回の訪問とは、いずれかの端末でアプリが前面に開かれ、1分を超えて使われた最後の時点の終わりです。スマートフォンでの訪問は、コンピューターでも訪問として扱われます。ページの再読み込みや1分未満の確認では更新されず、席を外している間に開いたままのウィンドウも対象外です。セッションを開くと、従来どおり確認済みになります。最初の訪問までは、1日前までさかのぼって表示します。別のマシン（設定 → マシン）の開始ページには、そのマシンの内容が表示されます。古いバージョンのHydorでは表示されません。

ターミナルでは、`hydor away`で同じ内容を一覧表示し、`hydor away seen`で消去できます（[ターミナルでのHydor](/guide/terminal)を参照）。

## 最初のセッションを始める

1. エージェントが動作する状態にします。Claude CodeとCodexはサインインが必要です。[設定 → エージェント → アカウント](/settings?s=accounts&find=Accounts)を開き、**アカウント**グループでエージェントの横にある**サインイン**を押して、手順に従います（リンクを開き、承認して、コードを貼り付けるか入力します）。Customにはモデルが必要です。[設定 → エージェント → モデル](/settings?s=models)で追加します。ウェルカムツアーでは、初回にこの手順を一緒に進めます。詳しくは[エージェント、アカウント、モデル](/guide/agents-models)をご覧ください。
2. サイドバーの上部にある**新しいセッション**を押します。アプリを開いたときも開始ページが表示されます。
3. メッセージ欄の下にある**実行環境**を押して、プログラムを選びます。その横の**モデル**でモデルを選びます。「default」と表示されているものから始めれば問題ありません。
4. **フォルダ**を押して、エージェントが作業する場所を選びます。
   - **プロジェクト**の下のプロジェクト：そのプロジェクトのフォルダで、ドキュメントやガイドラインを使って作業します。
   - **フォルダ**の下にある最近使ったフォルダ、またはほかのフォルダ：フォルダを**参照**するか、**プロジェクトやフォルダを検索、またはパスを入力**にフォルダ名やパスを入力します。
   - **新しいタスクフォルダ**：タスク名を付けた新しいフォルダです（変更しない限り`~/Hydor`に作られます。[設定 → 機能 → エージェント](/settings?s=assistants&find=Task%20folders)で変更できます）。

   ほとんどのエージェントは、フォルダを選ばなければ新しいタスクフォルダで始まります。プログラマーは選んだフォルダで作業します。
5. メッセージ欄に、してほしいことを入力します。タスクの説明でも、質問でも構いません。クリップのアイコンでファイルを追加するか、メッセージ欄にドロップします。このコンピューターにあるファイルは、ファイルページから渡せます。ファイルのメニューの**このファイルでセッションを開始**を使います（[ファイルでセッションを開始する](/guide/files-git#start-a-session-with-files)を参照）。
6. Enterキーまたは**開始**を押します。スマートフォンでは、丸い矢印をタップします。

セッションが開きます。エージェントの作業中のステップが分かりやすい言葉で表示され、最後に返信が表示されます。権限だけでは許可されていないコマンドの実行やファイルの変更をエージェントが求めると、**許可**または**拒否**を選ぶカードが表示されます。下部のメッセージ欄に入力すると、会話を続けられます。開始ページでの選択は、すべての端末で次のセッションにも引き継がれます。

次は：[セッション](/guide/sessions)で、セッションでできることをすべて紹介しています。

## Ctrl+Kですべてを検索

検索ボックスは、入力に合わせてアプリ内のあらゆるものを探します。MacのSpotlightのようなものです。コードエディタやターミナルで入力中を除き、どのページでもCtrl+K（Macでは⌘K）で開きます。アイコンバーの**検索**タイル（スマートフォンではドロワーのツールにある**検索**）でも開けます。もう一度Ctrl+KまたはEscを押すと閉じます。

### 検索対象

- **移動**：Hydorのページ（新しいセッション、受信トレイ、ファイル、ファイル内検索、Git、ターミナル、アプリ、新しいアプリ、プロジェクト、共有ナレッジ、公開済み、プレビュー、使用量と上限、モデルアリーナ、アクティビティ、システム、設定など）です。
- **アクション**：ツアーを見る、Hydorでできること、ハンズフリーで話す、リリースノート、ライトとダークの切り替え、サイドバーの表示と非表示、セッションをフォルダまたはプロジェクトでグループ化、ターミナルパネルの表示と非表示などがあります。
- **設定**：設定のすべてのセクションとその中の項目です。開くと、そのセクションが開き、項目が示されます。
- **テーマ**：組み込みのテーマと自作のテーマです。開くと、そのテーマに切り替わります。
- **セッション**：タイトル、フォルダ、ブランチ、最初のメッセージ、開始時のエージェントで検索できます（ほとんどのセッションが該当するため、一般は除きます）。アーカイブ済みのセッションも対象で、**アーカイブ済み**と表示され、ほかの結果の後に並びます。開くとそのセッションが開きます。プレビューには**エージェント**が表示されます。
- **メッセージ内**：入力した言葉を含むメッセージです。開くと、その言葉の位置でセッションが開き、検索バーも使える状態になります。
- **メモリ**：メモリのメモです。開くと、設定 → メモリのそのメモが開きます。
- **プロジェクト**：プロジェクトの名前と説明で検索できます。開くと、表示中のページの上にウィンドウでプロジェクトの詳細が開きます。
- **アプリ**、**スケジュールタスク**、**エージェント**、**スキル**、**ページ**、**画像、動画、音声**、**接続**：自分のものと、用意済みのものが対象です。それぞれ、あるべき場所で開きます。
- **ファイル**：ファイルページに表示されているフォルダ（またはアプリの既定のフォルダ）にある、名前が一致するファイルを最大5件表示します。
- **履歴**、**ブックマーク**、**ダウンロード**：デスクトップアプリで、自分の[ブラウザ](/guide/web#your-own-browser)で訪問したページ、ブックマーク、ダウンロードしたファイルです。言葉で一致するほか、[意味で検索](/settings?s=memory&find=Search%20by%20meaning)がオンなら、言葉が違っても内容が近いものが一致します。ページを開くと**ブラウザ**ページの新しいタブで開き、ダウンロードを開くとそのファイルがフォルダに表示されます。これらはこのコンピューターにだけ保存され、エージェントには渡されず、探すために入力した内容もボックスには記憶されません。

### 検索場所を選ぶ

フィールドの端にある**検索範囲**で、検索する場所を選びます。場所を選ぶまでは**すべての場所**です。クリックすると一覧が開きます。**セッション**、**メッセージ**（セッション内の発言）、**プロジェクト**、**保存済みファイル**（エージェントが作成し、保存したページ、画像、動画、音声）、**アプリ**、**ファイル**、**メモリ**、**スケジュールタスク**、**エージェント**、**スキル**、**接続**、**設定**（テーマを含む）、**移動とアクション**（アプリ自体のページとアクション）、**ガイド**、そしてデスクトップアプリのみ**ブラウザ**（履歴、ブックマーク、ダウンロード）です。

- 1つ以上にチェックを入れると、その場所だけを検索します。ボタンにはアクセントカラーで場所の名前（「セッション、保存済みファイル」や「3か所」）が表示されます。場所をもう一度クリックすると外れ、**すべての場所**をクリックするとすべてが対象に戻ります。
- 何も入力していないときは、選んだ場所にあるものを、よく使うものから順に表示します。最近のセッション、プロジェクト、ページ、設定のセクション、ガイドのトピックなどです。メッセージ、メモリのメモ、ファイルは、入力した言葉を待ちます。
- 選択内容は、変更するまですべての端末で保持されます。何も見つからないときは、メッセージの下の**すべてを検索**を押すと、すべての場所を再び検索します。
- スマートフォンでは、**検索範囲**は**キャンセル**の横にあるフィルタのアイコンです（場所を選ぶとその名前が表示されます）。一覧は画面の下から開きます。

### 結果の表示

- **最も一致**するものが最初に表示されます。続いて、種類ごとに最大4行のグループが並びます。「セッションにあと3件」を押すと残りが表示されます。
- 画像、動画、音声、保存したページやファイルは、サムネイルと詳細付きで表示されます。種類（画像、動画、ドキュメント、スライド、スプレッドシート、PNG画像など）、サイズまたは長さ、場所（保存したものは、プロジェクトのファイル内の「ファイル › プロジェクト名」）、最終更新日時です。ページには説明が続きます。
- 幅の広い画面では、一覧の横のプレビューに、選択中の結果の詳しい内容と、開いたときの移動先が表示されます。画像やページはそこで大きく表示され（クリックで開きます）、動画や音声はその場で再生できます。
- スマートフォンでは、プレビューなしで結果が画面いっぱいに表示されます。各行には結果を見分けるのに十分な情報があり、タップしやすい大きさです。
- ↑と↓で移動し、Enterで開きます。Escで入力内容が消え、もう一度Escを押すとボックスが閉じます（**検索範囲**の一覧が開いているときは、先に一覧が閉じます）。
- 何も入力していないときは、**最近のセッション**と**候補**が表示されます。候補はよく使う場所です（使い方が分かるまでは、便利なものがいくつか表示されます）。**検索範囲**で場所を選んでいるときは、代わりにその場所にあるものが表示されます。
- 最下行には**言葉**または**言葉と意味**と表示されます。[意味で検索](/settings?s=memory&find=Search%20by%20meaning)がオンのとき（設定 → 機能 → メモリでオフにしない限りオンです）、言い換えた言葉や別の言語でも、意味が合う結果が一致します。

### 使うものを学習する

- 選んだ結果を、入力した言葉と一緒に覚えます。同じ言葉をもう一度入力すると、その結果がすぐに先頭に表示されます。
- どの経路で開いたかにかかわらず、訪問した場所（ページ、設定のセクション、セッション、アプリ、ファイル）を覚えます。一致した結果のうち、よく使うものが上位に表示されます。入力した言葉によく一致するほど優先され、時間がたつにつれて順位は下がります。
- アプリがこの情報を保持するため、スマートフォンとコンピューターで一緒に学習します。

## スマートフォンでアプリを使う

スマートフォンからアプリにアクセスするには、HTTPSアドレスが必要です。[設定 → アプリ → スマートフォンで使う](/settings?s=phone)で、数回のクリックでアドレスを用意できます。Tailscaleを使うため非公開で、自分のデバイスだけがアクセスでき、QRコードでスマートフォンから開けます。Cloudflareトンネルや自分のプロキシでも利用できます。詳しくは[スマートフォン、ほかのマシン、共有](/guide/devices)をご覧ください。

### ホーム画面に追加する

アプリとしてインストールでき、全画面で開きます。

- **iPhoneまたはiPad**：Safariで開き、共有 → **ホーム画面に追加**を選びます。
- **Android**：Chromeで開き、⋮ → **ホーム画面に追加**（または**アプリをインストール**）を選びます。

Androidにインストールした場合や、コンピューターのChromeまたはEdgeでは、Hydorは共有シートにも表示されます。ほかのアプリから写真、ファイル、リンクをHydorに共有すると、開始ページが開き、メッセージ欄に入った状態になります。[ほかのアプリからHydorに共有する](/guide/devices#share-to-hydor-from-other-apps)をご覧ください。

iPhoneまたはiPadでは、通知はホーム画面に追加したアプリでのみ動作します。そこから開き、設定 → アプリ → 通知で[このデバイスに通知](/settings?s=notifications&find=Notify%20this%20device)をオンにします。詳しくは[受信トレイと通知](/guide/inbox)をご覧ください。

### サイドバーはドロワー

- 各ページの左上の**メニュー**ボタンで開きます。画面全体に表示されます。
- ツールは、**プロジェクト**も含め、ドロワー下部のグリッドに並んでいます。
- セッションやツールをタップすると、そこに移動してドロワーが閉じます。**メニューを閉じる**（×）でも閉じます。
- セッションを少し長押しして持ち上げ、ドラッグします（アクティブやピン留めのセッションの並べ替え、またはピン留めに使います）。
- 下部のツールを少し長押しして持ち上げ、ほかのツールの間にドラッグして並べ替えます。
- 各行の端にある**⋯**で、セッションのメニューが開きます。**名前を変更**、**フォルダ名を変更**、**ピン留め**、**スヌーズ**、**完了にする**、**アーカイブ**、**削除**（先に確認が表示されます）があります。

### メニューはシートで開く

スマートフォンでは、開始ページのメッセージ欄の下にある選択肢（実行環境、モデル、フォルダ、エージェント、オプション）が、画面の下からシートとして開き、キーボードと重なりません。フォルダのシートの検索欄は、タップするまで待機するため、キーボードが一覧を隠すことはありません。

### 入力と送信

- 開始ページには、メッセージ欄の下に最新の6件のセッションが**最近**として表示されます。**すべてのセッション**でドロワーが開きます。
- Enterキーは改行です。丸い矢印をタップすると、セッションが始まり、またはメッセージが送信されます（キーボードを接続している場合は、Ctrl+Enterまたは⌘Enterでも送信できます）。
- セッションでは、メッセージ欄にモデルを示すチップが1つ表示されます（思考レベルと権限は、通常と異なるときだけ併記されます）。タップするとシートが開き、**モデル**、**思考レベル**、**権限**と、会話の使用済みの容量、そして**圧縮**があります。
- 返信やメッセージの一部を引用するには、その部分を選択します。選択範囲のすぐ下に**見積もり**が表示されます。
- **詳細**は、求めたときだけ会話の上に開きます。
- 検索ボックスは画面全体に表示され、**キャンセル**で閉じます。
- スクリーンショットボタンはコンピューターにだけあります。

## ヘルプを使う

アイコンバーの**ヘルプ**（スマートフォンではドロワー内）で、このガイドが開きます。広いウィンドウでは、サイドバーと同じ種類の列が表示されます。ロゴと「サイドバーを隠す」が1行に並び、その下に**ヘルプホーム**とすべてのトピックが、最初のページでのグループ分けと同じ形で並びます。各トピックにはアイコンが付き、開いているトピックには印が付きます。最初のページには、ボックス、よくある質問、そして**Hydorでできること**（下記）が表示されます。狭いウィンドウやスマートフォンでは、最初のページのカードからトピックを開き、トピックの上部にある**すべてのトピック**で戻ります。列を隠した広いウィンドウでは、最初のページにもカードが表示されます。最初のページのボックスに、質問や数個の単語を入力します。

- 入力するにつれて**一致するセクション**が表示されるので、クリックして開きます。検索ボックス（Ctrl+K）でも見つかります。入力中は、よくある質問と**Hydorでできること**が脇に退きます。
- **Enterを押す**か**質問**をクリックすると、ガイドの横のパネルでエージェントが回答し、適切な場所へのリンクを示します。カードで変更を確認すれば、設定の変更や準備もエージェントが代わりに行えます。回答は通常のセッションで、スタートページで最後に選んだエージェントとモデルが使われます。パネルでさらに質問することも、パネル上部の矢印で専用のページに開くこともできます。

ボックスの下には、見落とされがちな機能ごとのカードを集めた**Hydorでできること**があります。**ChatGPTやClaudeから取り込む**、**アプリ**、**自分のアプリを作る**、**回答カード**、**単語候補**、**ドキュメント、スライド、スプレッドシート**、**ディープリサーチ**、**自動で動く作業**、**ゴール**、**実験**、**スマートフォンで**、そしてデスクトップアプリでは**専用のブラウザ**です。各カードには、機能の説明と最初にすることが1行で書かれています。最初にすることは、「リスボンで5月に4日間の旅行を計画して」のような依頼（スタートページのメッセージ欄に入るだけで、自動では送信されないので、先に直せます）か、その場所を開くボタン（**「取り込む」を開く**、**アプリを作成**、**設定を開く**、**実験を開く**、**スマートフォンで使う**、**ブラウザを開く**）です。**仕組み**を押すと、ガイドのその機能のセクションが開きます。このセクションには専用のアドレス [ヘルプ → What Hydor can do](/guide#what-hydor-can-do) があり、ツアーの最後のページや、検索ボックスの「What Hydor can do」からも開けます。

幅の狭いウィンドウやスマートフォンでは、右上の**エージェントに質問**から同じパネルを開けます。検索ボックスの「アプリについてエージェントに質問」でも開きます。トピックは、ボックスの下にカードとして、広いウィンドウでは列に分類されています。トピック内では、右上のボックスでセクションを探したり、エージェントに質問したりできます。各トピックではセクションが1つずつ開き（**すべて開く**で全部表示）、最後にエージェントへの質問例が並びます。クリックするとパネルのボックスに入るので、必要なら書き換えて送信します。

- ウェルカムツアーでは、アプリの案内と、使いたいエージェントの設定を行います。ヘルプ上部の**ツアーを始める**、設定 → アプリ → 一般の[ツアーを始める](/settings?s=general&find=Take%20the%20tour)、または検索ボックスに「tour」と入力して開始します。ほかのアシスタントがユーザーについて知っていることに関するステップが、全員に1つ表示されます。このコンピューターにほかのエージェントのデータがない場合は**ChatGPTやClaudeからお引っ越しですか？**になり、データの依頼方法（メールで届くエクスポートの.zip：ChatGPTでは設定 → データコントロール → データをエクスポート、Claudeでは設定 → プライバシー → データをエクスポート）が示されます。**持っている知識を取り込む**を押すと、ツアーの上に[取り込み](/guide/memory#bring-in-from-other-assistants)が開き、選んだメモに読み込めます。以前使っていたほかのエージェント（Claude Code、Codexなど）のフォルダがこのコンピューターで見つかった場合は、**ほかのエージェントから移行しますか？**というステップになります。見つかったものが示され、エクスポートにも触れ、同じボタンで、そのエージェントがユーザーについて知っていることと、作成したスキルを取り込めます。**次へ**を押すと、取り込まずに進みます。サイドバーのツールを紹介するステップの後に**アプリ**のステップがあり、試せる依頼が3つ表示されます。最後のページの「Hydorでできること」でツアーを終え、ヘルプの[What Hydor can do](/guide#what-hydor-can-do)が開きます。デスクトップアプリでは、このコンピューターでほかのブラウザが見つかると、さらに**ブックマークと履歴を取り込みますか？**というステップが続きます。ブラウザごとに、ブックマークの数と履歴のページ数が一覧表示され、その横の**インポート**で、オンにしている**ブックマーク**と**履歴**が取り込まれます（[ブックマークを取り込む](/guide/web#bring-in-bookmarks)と[履歴](/guide/web#history)を参照）。**次へ**を押すと、取り込まずに進みます。Macで、macOSがHydorによるSafariの読み取りを許可していない間は、その行に**インポート**の代わりに**システム設定を開く**が表示されます。そこで許可した後にHydorの再起動が必要な場合は、ツアーはこのステップに戻ります。デスクトップアプリでは、さらにもう1つ**スマートフォンでも使いますか？**というステップがあります。**設定する**を押すとツアーが終了して[スマートフォンで使う](/settings?s=phone)が開き、**今はしない**を押すと次へ進みます。その後は、アプリの各部分を初めて開いたときに、ヒントが1つずつ表示されます（[ツアーを始める](/guide/app#take-the-tour)を参照）。
- **リリースノート**（設定 → アプリ → 一般、または検索ボックスから）では、各バージョンの変更内容を確認できます。アップデート後には、「新機能」のお知らせが1回表示されます。
- アプリ内のエージェントもこのガイドを読みます。どのセッションでも「～するには？」と尋ねれば、回答したり、代わりに操作したりできます（[エージェントにアプリを操作してもらう](/guide/ask-agents)を参照）。

## エージェントに質問

- 「今、私の返答待ちのセッションはどれですか？それぞれ何が必要ですか？」
- 「~/code/shopでCodexセッションを開始して、チェックアウトのテストを通してください。」
- 「リスボン旅行を計画したセッションを探して、ピン留めしてください。」
- 「使用量のリセットを待っているセッションが、まだアクティブに表示されているのはなぜですか？」
- 「サイドバーのセッションを、フォルダのグループなしで日ごとに並べてください。」
- 「『旅行』というフォルダを作って、リスボンのセッションを入れて。」
