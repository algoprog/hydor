# セッション

**セッション**とは、1つのフォルダでエージェントと行う1回の会話のことです。やりたいことを伝えるとエージェントが作業を進め、その様子を確認しながら、実行しようとする操作を承認したり、方向を調整したりできます。このトピックでは、セッションに関するすべてを説明します。スタートページとそのオプション、エージェントの作業中に表示される内容、ターンの途中でのメッセージ送信、そしてフォークやゴールからワークツリーや共有まで、セッションのメニューにあるすべての項目です。

![作業中のセッション：エージェントのステップと返信、コマンドの実行許可を求めるカード](images/sessions.webp)

## セッションを開始する

サイドバー上部の**新しいセッション**を押すと、スタートページが開きます。メッセージ欄にやりたいことを書き、下の選択肢の行を確認して、Enterキー（または**開始**。スマートフォンでは丸い矢印）を押します。セッションのページがすぐに開き、メッセージと、それに取り組むエージェントの様子が表示されます（**実行中**）。セッションを開始できなかった場合は、ページに理由が表示され、**スタートページに戻る**を押すと、メッセージ（と添付したもの）がメッセージ欄に戻ります。

アプリから応答が返る前に接続が切れた場合（スマートフォンがスリープした、ネットワークが切り替わったなど）、ページには**再接続しています…**と表示され、接続できるようになるとメッセージがどうなったかをアプリに問い合わせます。開始されていればセッションが開き、セッションが2回開始されることはありません。約1分たってもアプリに接続できないときは、ページに**アプリに接続できませんでした**と表示されます。**もう一度試す**を押すと、もう一度問い合わせます。

開始から少しすると、セッションにタイトルが付きます。依頼内容を表す短い言葉（「リスボン週末旅行」「決済テストの修正」など）で、補助モデル（[設定 → エージェント → モデル](/settings?s=models&find=Helper%20model)）が裏側で書くため、会話には何も表示されません。タイトルは、サイドバー、セッションのヘッダー、検索ボックスに表示されます（サイドバーでは、メッセージの冒頭に代わって、言葉が順に現れます）。Claude CodeとCodexにも、それぞれの一覧用に渡されます。タイトルが付くまでの間や、補助モデルが応答できないときは、メッセージの冒頭が代わりに使われます。**名前を変更**で自分で付けたタイトルが置き換えられることはありません。サイドバーには、送信した時点からセッションが一覧に表示され、**アクティブ**の先頭に置かれます（**開始中**）。

メッセージ欄の下の行には、**実行環境**、**モデル**、**フォルダ**（または**プロジェクト**）、**エージェント**、そして右端に**オプション**が並びます。スマートフォンでは、それぞれが画面下からシートとして開きます。

### エージェントとモデルを選ぶ

**実行環境**には、使えるプログラムがすべて並びます。

- **Claude Code**：Anthropicのエージェントです。Claudeのプランまたはapi キーで使います。
- **Codex**：OpenAIのエージェントです。ChatGPTのプランまたはAPIキーで使います。
- **Custom**：アプリ独自のエージェントで、OpenRouter、Ollama、vLLMなど任意のモデルを使えます。[Custom、アプリ独自のエージェント](/guide/custom)をご覧ください。
- 追加したその他のACP対応エージェント（Gemini CLI、OpenCode、Qwen Code、Gooseなど）。名前の下にコマンドが表示されます。

一番下の**Custom用モデル**は[設定 → モデル](/settings?s=models)を、**エージェントを追加・管理**は[設定 → その他のエージェント](/settings?s=agents)を開きます。[エージェント、アカウント、モデル](/guide/agents-models)をご覧ください。

**モデル**は**自動**で開きます。セッションは最高ティアのモデルで始まり、メインのエージェントは切り分けやすい部分をより低いティアのサブエージェントに任せ、問題が難しすぎると判断したときは最大ティアのモデルに自分で切り替えることもあります（[ティア：仕事の種類ごとのモデル](/guide/agents-models#tiers-a-model-for-each-kind-of-job)をご覧ください）。その下のメニューには、選んだエージェント自身のモデルだけが表示されます。エージェントのデフォルトには「default」と表示されます。古いバージョンのモデルは「古いモデル2件」の中にまとめられます。一覧が長いときは**モデルを検索**欄があり、Enterキーで最初の一致を選べます。Customでは設定 → モデルで追加したモデルが一覧に並びます。ほかのACPエージェントでは、前回の実行時に提示されたモデルが並び、一度実行するとチップが表示されます。

### フォルダ、プロジェクト、新しいタスクフォルダを選ぶ

**フォルダ**チップは、エージェントが作業する場所を示します。メニュー（「作業するプロジェクトまたはフォルダ」）には**プロジェクトやフォルダを検索、またはパスを入力**欄があり、その下に2つの短い一覧があります。各行には場所が表示されます。

- **プロジェクト**：プロジェクトが名前順に並びます（直近に作業した5件と、選択中のもの）。各行にはフォルダも表示されます。選ぶと、フォルダがプロジェクト自身のフォルダになり、そのエージェントと、そのセッション用のガイドラインも設定されます。チップは**プロジェクト**となり、プロジェクト名が表示されます。プロジェクトのグループも同様で、グループ内のすべてのプロジェクトが対象になります。見出し右端の**新規**を押すと、プロジェクト（セッション、ファイル、メモリがひとまとまりになったもの）が作られ、選択されます。[プロジェクトとナレッジ](/guide/projects)と[エージェントガイドライン](/guide/guidelines)をご覧ください。
- **フォルダ**：使用中のフォルダと、最後に選んだ3つのフォルダが並びます。各行には、それが入っているフォルダも表示されます。見出し右端の**参照**を押すと、ホームフォルダ内のフォルダが一覧表示されます。
- **新しいタスクフォルダ**（「~/Hydorに新規作成」）：このタスク用の新しいフォルダです。名前は日付とメッセージの数語から付けられ（`2026-11-01-plan-trip-lisbon`など）、[タスクフォルダ](/settings?s=assistants&find=Task%20folders)（設定 → 機能 → 自分のエージェント）で別の場所を指定していない限り、`~/Hydor`に作られます。

プロジェクト自身のフォルダは、そのままプロジェクトとして扱われます。メニューにはプロジェクトとしてのみ表示され、そのフォルダで開始したセッションは、スタートページでプロジェクトではなくフォルダを選んでいた場合でも、プロジェクトで作業します。

メニューは、チップの上または下の、余裕のある側に開き、スクロールせずに収まります。小さなウィンドウではフォルダの表示数、次にプロジェクトの表示数が減り、プロジェクトの下に「ほか2件」のような行が表示されて、残りを表示できます。

欄に入力すると、さらに検索できます。

- 名前を入力すると、一致するプロジェクトと、最近使ったフォルダ、使用中のフォルダ、ホームフォルダの中のフォルダが見つかります。プロジェクトのフォルダが名前で見つかった場合は、プロジェクトとして表示されます。
- パス（`~/code/`、またはホームフォルダからの`code/`）を入力すると、**参照**と同様に、そこにあるフォルダが一覧表示されます。欄の右端の矢印で1つ上のフォルダに移動し、×印またはEscキーで一覧に戻ります。
- ↑ ↓とEnterキーで選びます。Tabキー、または行の右端の矢印で、その中のフォルダが一覧表示されます。

フォルダがgitリポジトリ内にある場合（新しいタスクフォルダを選んでいない場合）、メニューの最後にスイッチが表示されます。**mainから新しいワークツリー**（またはチェックアウト中のブランチ）で、「新しいブランチ、リポジトリのコピー内」と表示されます。オンにすると、セッションは新しいブランチ上の専用コピーで作業し、チップには「· 新しいワークツリー」と表示されます。[ワークツリーで作業する](#work-in-a-worktree)をご覧ください。

セッションが新しいタスクフォルダを使うかどうかの初期設定はエージェントによって異なります。ほとんどのエージェントは、フォルダを選ばなければ新しいタスクフォルダで始まります。プログラマーは選んだフォルダで、1つのプロジェクトのエージェントはそのプロジェクトで作業します。

### エージェントを選ぶ

**エージェント**は、セッションが誰として作業するかを決めます。**一般**（ほかを選ぶまで。独自のエージェントを持つプロジェクトでは、そのエージェント）、**リサーチャー**、**ライター**、**プログラマー**、**チューター**、**プランナー**、**アナリスト**、**アプリビルダー**、または**自分用**の下にある自作のエージェント（どこでも使えるものと、選択中のプロジェクトのもの）から選べます。ポインタを合わせると、そのエージェントの役割と、使うプログラムやモデルが表示されます。選ぶと、そのエージェントが推奨するプログラム、モデル、権限も設定でき（ティアを持つ場合は、そのティアのモデル）、接続済みのアカウントもオンになります。**エージェントを作成・変更**は、[エージェントページ](/agents)を開きます。[エージェント](/guide/agents)をご覧ください。

### オプション：思考レベル、権限など

**オプション**には、そのほかの設定があります。チップには「オプション」と表示されるか、通常から変更した内容が「高 思考レベル · プラン · 上限$5.00」のように表示されます。パソコンでは、メニューの最後に、メッセージ欄でShift+Tabキーを押すと権限を切り替えられるという案内が表示されます。

- **思考レベル**：モデルがどれだけ深く考えるかです。**デフォルト**はモデル自身の設定を使い、そのほかはモデルが提供するレベルが並びます。**低**（高速で軽い推論）、**普通**（バランス型）、**高**（より深い推論）、**超高**（さらに深い推論）、**最大**（最大の推論）、モデルによっては**ミニマル**、**なし**、**ウルトラ**もあります。Custom、その他のACPエージェント、レベルのないモデルでは表示されません。
- **権限**：エージェントが事前に確認なしでできることです。モードはエージェントごとに異なります。[各権限モードの意味](#what-each-permissions-mode-means)をご覧ください。メッセージ欄でShift+Tabキーを押すと、次のモードに切り替わります。
- **アカウント**：[設定 → エージェント → アカウント](/settings?s=accounts&find=Accounts)でClaude CodeまたはCodex用に別のアカウントを追加した場合のみ表示されます。**サインイン情報**はエージェント自身のアカウントです。別のアカウントを選ぶと、そのアカウントでこのセッションを実行します。**アカウントを管理**は設定を開きます。
- **機密**：錠前マークのスイッチです（「このコンピューター上のモデルのみ。外部には何も送信されません。」）。査読中の論文、患者データ、顧客のコードなどに使います。**実行環境**は**Custom**に、**モデル**はここにインストールされている最良のモデルになります。[セッションを機密にする](#keep-a-session-confidential)をご覧ください。
- **メモリ**：設定でメモリがオンのときのみ表示されます。**オン**はエージェントの記憶を使い、追加もします。**このセッションではオフ**は白紙の状態で始まり、このセッションの内容は何も記憶されません。[メモリ](/guide/memory)をご覧ください。
- **支出上限**：このセッションで使える上限額で、API料金で計算されます。金額を入力して**設定**を押すか、$1、$5、$10、$25から選びます。**上限なし**で解除できます。上限に達するとセッションは止まり、上限を引き上げるまで再開しません。[使用量、制限、コスト](/guide/usage)をご覧ください。
- **スウォーム**：**オフ**、または**スウォーム**。リードエージェントがタスクをいくつもの切り口に分け、それぞれにメンバーを立ち上げます。同時に作業する数は**スウォームの規模**（[設定 → 機能 → サブエージェント](/settings?s=children&find=Swarm%20size)）で決まります。メンバーは見つけたことをボードで共有し、互いにメッセージを送り合います。難しい問題向けですが、エージェント1つの場合の数倍のコストがかかります。もう1つは**キャンペーン**（「大きな変更を分割し、それぞれをワークツリーで」）です。リードが大きな変更をいくつかの部分に分け、メンバーがそれぞれ専用のブランチで1つずつテストとともに作り、リードがそれらをマージします。フォルダはgitリポジトリである必要があります（[キャンペーン](/guide/engineering#campaigns-a-big-change-in-many-parts)をご覧ください）。
- **リサーチ**：**オフ**、または**ディープリサーチ**。エージェントが検索を計画し、各部分にリサーチャーを送り、重要な主張を2つの情報源で裏付け、出典付きのレポートを届けます。**同時リサーチャー数**（1〜8）、**ラウンド数**（1〜5）、**検索の合計**（10〜500）、**レポート**（**ページ**または**Word**）を設定できます。
- **ゴール**：**オフ**（「エージェントは、終わったと判断するまで作業します」）、または**完了するまで**（オプションのチップには「ゴールモード」と表示されます）（「合意したチェックが満たされるまで、ラウンドを重ねて作業します」）。最初のメッセージがゴールとなり、エージェントはまず確認方法を考えて提示し、合意するまで何も始まりません。**確認の頻度**で、進め方をどのくらいの頻度で尋ねるかを選べます。どのエージェントでも使えますが、多くのターンを消費し、合意した上限（ラウンド、費用、時間）で止まります。[セッションにゴールを設定する](#give-the-session-a-goal)をご覧ください。
- **アリーナ**：**オフ**、または**モデルを比較**。同じメッセージが、チェックを入れたさらに1〜2つのモデルにも送られ、それぞれ同じフォルダ内の別々のセッションで作業します（長い一覧では**モデルを探す**欄が役立ちます）。回答を比べて最良のものを残し、ほかはアーカイブされます。gitリポジトリでは、フォルダメニューの**新しいワークツリー**をオンにすると、各モデルが自分専用のコピーで作業します。

スウォーム（またはキャンペーン）とディープリサーチはどちらもHydorサブエージェントを率いるため、一方をオンにするともう一方はオフになります。**ゴール**も、スウォーム、キャンペーン、ディープリサーチ、アリーナとは併用できません。どちらかをオンにするともう一方はオフになり、これらを率いるセッションには、このバージョンではゴールを設定できません（メニューに**ゴールを設定**は表示されません）。**機密**をオンにすると、スウォーム、ディープリサーチ、アリーナはオフになり、これらのいずれかをオンにすると機密はオフになります（機密セッションでもゴールは実行できます）。スウォーム、ディープリサーチ、アリーナ、ゴールは、コストが高いため、次のセッションには引き継がれません。選んだリサーチの数値とアリーナのモデルは、再びオンにしたときのために、このブラウザに保存されます。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research)をご覧ください。

### 各権限モードの意味

**Claude Code**

| モード | エージェントができること |
| --- | --- |
| 確認（デフォルト） | 設定で許可されていない編集やコマンドの前に確認する |
| 編集を許可 | ファイルを自由に編集し、それ以外のコマンドの前に確認する |
| 自動 | 安全性チェックが通常の操作を承認し、リスクのある操作は確認する |
| プラン | 読み取りと計画のみを行い、承認用のプランを提案する |
| バイパス | 一切確認しない（フルアクセス） |

**Codex**

| モード | エージェントができること |
| --- | --- |
| プラン | まず話し合って計画を立て、質問で確認することもある |
| 読み取り専用 | ファイルを読んで回答し、変更の前に確認する |
| 自動（デフォルト） | フォルダ内でファイルを編集しコマンドを実行し、それ以外は確認する |
| 自動レビュー | 自動と同様だが、承認リクエストにレビュー担当エージェントが回答する |
| フルアクセス | サンドボックスも承認もなし |

Docker内ではCodex自身のサンドボックスを起動できないため、そこでは**フルアクセス**がデフォルトになり、メニューにその理由が表示されます。

**Custom**

| モード | エージェントができること |
| --- | --- |
| 確認（デフォルト） | ファイルの編集とコマンドの実行の前に確認する。見て回るだけの操作は自由に実行する |
| 編集を許可 | フォルダ内のファイルを自由に編集し、コマンドの実行の前に確認する |
| 自動 | 通常の手順は進め、リスクのある操作は簡易チェックを通じて確認する |
| フルアクセス | 承認の確認もコマンドのサンドボックスもなしでツールとコマンドを実行し、コンピューターのアカウントの権限を使う |
| プラン | 読み取りと計画のみ：編集もコマンドもなし |

フルアクセス以外では、Customはリスクのあるコマンドの前に確認します。確認、編集を許可、プランでは、フォルダ外のファイルや、キーやパスワードを含むファイルを読んだり変更したりする前にも確認します。自動では、簡易チェックがまずそれらを判断します。[Custom、アプリ独自のエージェント](/guide/custom)をご覧ください。

**その他のACPエージェント**は、それぞれ独自のモードを持ち、エージェントを一度実行すると一覧に表示されます。

### セッションを機密にする

コンピューターの外に出してはならない作業があります。査読を依頼された論文（多くの学会やジャーナルは、投稿論文をオンラインAIに渡すことを禁じています）、患者や顧客の記録、契約のもとで扱う企業のコードなどです。機密セッションは、このコンピューター上のモデルで実行され、その内容はどこにも送信されません。

1. スタートページで**オプション**を開き、**機密**をオンにします（「このコンピューター上のモデルのみ。外部には何も送信されません。」）。チップには「機密」と表示されます。
2. **実行環境**は**Custom**に、**モデル**はここにインストールされている最良のモデルになります。オンの間は、それぞれのメニューにそれらだけが表示されます。まだモデルがない場合はその旨が表示されます。[設定 → エージェント → モデル](/settings?s=models)で、このコンピューター向けに推奨されるモデルをワンクリックでインストールできます。
3. やりたいことを書き、論文を添付するかフォルダを選んで、Enterキーを押します。たとえば、「添付の投稿論文を、NeurIPSの査読者として査読してください。要約、長所、短所、著者への質問、スコアをお願いします。」

このコンピューター上のモデルとは、ここにあるOllamaとvLLMのモデル、およびアドレスがこのコンピューターまたはプライベートネットワークのエンドポイントです。具体的には、`localhost`、`127.0.0.1`、`::1`、`10.…`、`192.168.…`、`172.16.…`から`172.31.…`、または`.local`で終わる名前です（[Ollama、vLLM、その他のエンドポイントに接続する](/guide/agents-models#connect-ollama-vllm-or-another-endpoint)をご覧ください）。名前が「cloud」で終わるOllamaのクラウドモデルはollama.com上で動作するため、対象外です。スタートページは、オフにするまで、次回以降のセッションでもスイッチをオンのままにします。

機密セッションには、ヘッダーとサイドバーのタイトルの横に錠前マークが付き、メッセージ欄の枠は落ち着いた緑色になります。閉じるまで、その意味を説明する行が欄の上に表示されます。錠前マークをクリックすると、何がオンで何がオフかを確認できます。

- **オフ**：Web検索とWebページ、ブラウザと画面、接続済みアプリとキー、アプリ、公開、スケジュールタスク、画像・図・プロット・動画・音声の作成、検索、編集、外部のモデル（ディープリサーチ、スウォーム、アリーナ。[セカンドオピニオン](/guide/research)は、このコンピューター上の別メーカーのモデルからのみ得られます）、会話を別のエージェントに引き継ぐこと、メモリへの保存、ページのファイルとしてのエクスポート（ページから自分でエクスポートしてください）。
- **ネットワークなしのコマンド**：エージェントのコマンドは、どの権限モードでもネットワークから切り離されて実行されるため、ダウンロード、インターネットからのインストール、プッシュ、送信はできません。これができない環境（Windows、一部のコンテナ）では、モードにかかわらず各コマンドの前に確認が入り、錠前の説明にもその旨が表示されます。
- **引き続きオン**：フォルダ内のファイル、ドキュメント（このコンピューター上で読み取り）、保存したページ・画像・ファイル、共有ナレッジ、メモリのメモとプロフィール（読み取りのみで、追加はされません）、同じく機密であるHydorサブエージェント、回答UI（Webの画像や地図は表示されません）。
- **外部には何も送信されません**：タイトルは、補助モデルがこのコンピューター上で動作している場合はそのモデルから、そうでなければメッセージの最初の数語から付けられます。通知には「機密セッション」と、完了した、操作が必要、失敗したのいずれかだけが表示されます。閲覧専用リンク、メニューからのプルリクエスト、そこから作るオートメーションやアプリはありません。ほかのセッションのエージェントや外部のエージェントはこのセッションを読めません。返信にはWebの画像は表示されず、表示するページも外部から何も読み込みません（そのため、Webのライブラリが必要なグラフは描画されません）。音声入力は、このコンピューター上の音声認識（[設定 → 機能 → 音声](/settings?s=voice)）でのみ動作し、返信の読み上げは、お使いのデバイス上の音声でのみ行われます。
- **機密のまま維持されます**：フォークと**ここから編集**も機密になり、解除することはできません。そのため、話した内容はその場に残ります。コンピューターの外に出してもよい作業は、新しいセッションで始めてください。

保証できないこともあります。Hydorが確認するのはモデルのサーバーの所在地であり、そのサーバーが何をするかではありません。そのため、ネットワーク上に設定したエンドポイントがリクエストをオンラインのサービスに転送する場合は、やはりオンラインです。セッションからコピーしたもの、自分でほかから開いたり送ったりしたもの（返信内のリンク、プロジェクトのファイルから開いた作成済みのページ、Gitページからのプッシュ）は、自分で管理する必要があります。別のデバイスで閲覧した内容も同様で、アプリのページは通常どおりそのデバイスに届きます（トンネルを使っている場合は、そのトンネル経由です）。

### ファイルの添付、ファイルの指定、コマンドの使用

- **ファイルを添付**（メッセージ欄の下の行の左端の**+**）、メッセージ欄へのファイルのドロップ、画像やファイルの貼り付けができます。1回のメッセージで添付できるファイルは合計25MBまでです。画像（PNG、JPEG、GIF、WebP）は画像としてモデルに渡され、1回のメッセージで8枚までです。そのほかのファイル（20件まで）はこのコンピューターに保存され、メッセージの末尾に一覧として付くため、エージェントが開けます。送信前に、各ファイルの×で取り除けます。添付したファイルは、ほかのページに移動しても、送信するまでメッセージ欄に残ります（ページを再読み込みすると消えます）。
- **スクリーンショットを添付**（同じ**+**メニュー内、パソコンの場合。ブラウザがスクリーンショットを撮れない場合、**+**はファイルを添付するクリップになります）：ブラウザが、どの画面、ウィンドウ、タブにするかを尋ね、その画像が1枚添付されます。
- **@**：@とファイル名の一部を入力すると、フォルダ内の一致するファイルが一覧表示されます。↑ ↓で移動し、EnterキーまたはTabキーで挿入、Escキーで閉じます。
- **/**：メッセージの先頭で/を入力すると、エージェントのコマンドとスキル（Claude Codeのもの）が、それぞれの説明とともに一覧表示されます。
- マイク（メッセージを音声入力）とヘッドフォン（ハンズフリー音声モード）は、ブラウザまたはこのコンピューターが音声認識に対応している場合、送信ボタンの横に表示されます。[ドキュメント、画像、動画、音声](/guide/documents-voice)をご覧ください。

### スタートページが記憶するもの

スタートページは、作業する場所ごとに選択内容を記憶します。各プロジェクト、各フォルダ、**新しいタスクフォルダ**が対象で、すべてのデバイスで共通です。場所ごとに、**実行環境**（プログラム）、各プログラムの**モデル**、**オプション**内の**思考レベル**と**権限**、**エージェント**、**メモリ**、**支出上限**、**機密**、**新しいワークツリー**のスイッチが記憶されます。アカウント（**オプション → アカウント**）は場所ごとには記憶されず、どこでも選んだままです。ある場所でプログラムを選ぶと、そこでそのプログラムを最後に使ったときの内容が戻ります。

場所が選択内容を記憶するのは、そこで選択を1つ変えたとき、またはそこでセッションを開始したときです。見ただけでは何も記憶されません。**フォルダ**チップで場所（プロジェクト、フォルダ、**新しいタスクフォルダ**）を選ぶと、メッセージ欄はその場所の選択内容で開き、書いた内容と添付したものはそのまま残ります。プロジェクトから開始すると（プロジェクトのカードまたはページの**新しいセッション**、またはサイドバーのプロジェクト）、スタートページはそのプロジェクトの選択内容で開きます。また、フォルダ（ファイルまたはサイドバー内）の**このフォルダで新しいセッション**を押すと、そのフォルダの選択内容で開きます。ページは、最後に選んだ場所で開きます。

まだ何も選んだり開始したりしていない場所は、デフォルトで開きます。エージェントは**一般**で、プロジェクトに独自のエージェントがある場合はそのエージェントになります（そのエージェントの推奨設定、つまりプログラム、ティアのモデル、権限は、選んだときと同様に適用されます）。**モデル**は、提供されていれば**自動**、そうでなければプログラムのデフォルトです。**思考レベル**と**権限**はプログラムの通常の設定、メモリはオン、支出上限はなし、**機密**と**新しいワークツリー**はオフです。**実行環境**は最後に使ったプログラムのままです。この機能が追加される前に最後に選んでいた場所は、それまでの選択内容を保持します。

スタートページへのリンクで内容を入力しておくこともできます。たとえば`/?prompt=Summarize%20my%20notes&agent=codex`のようにします。`model=`、`cwd=`（フォルダのパス）、`confidential=1`（機密をオン）も追加できます。メッセージ欄と選択肢が入力されるだけで、自動的に何かが開始されることはありません。リンクのメッセージに含まれる不可視文字は取り除かれ、その旨が通知されます。

メッセージ欄に書いた内容は、ほかのページに移動しても残ります。メッセージ、添付したファイル、そのタスク限りのオプション（**スウォーム**、**ディープリサーチ**、**アリーナ**、このセッション用の**ガイドライン**）、リンクや**新しいエージェントセッションをここで開始**で開いたフォルダが対象です。セッションが開始されると、メッセージ欄は空になります。エージェントが動き出す間は**開始**の矢印が上がり続け、その後スタートページがセッションに変わり、メッセージ欄は下の定位置に移り、書いた内容は最初のメッセージとして上に移ります。メッセージとこれらのオプションはこのブラウザに保存されるため、再読み込み後も残ります。添付したファイルは残りません。

## セッションでの作業を追う

### ヘッダー

セッションの上部には次のものが表示されます。

- エージェントのアイコンとタイトル（ダブルクリックで名前を変更）。[機密セッション](#keep-a-session-confidential)には鍵のマークも付きます。
- ステータス：**実行中**、**対応が必要**、**準備完了**、**開始中**、**メモリを構築中**、**停止中**。ほかの場所で実行中のセッションには「Open in VS Code」と表示されます。エージェントが動いていない状態になると、作業の終わり方が表示されます。最後のターンが終わったときは**完了**（ファイルを作成または変更した場合は「· 2 files made」や「· 3 files changed」付き）、自分で止めたとき、または終わる前に中断されたときは**停止**、エラーで終わったときは**失敗**です。ステータスにポインタを合わせると、次にできることが表示されます。
- フォルダ（クリックするとファイルで開きます）、プルリクエストのバッジ、追加したアカウントで実行している場合はそのアカウント、画面が広いときはGitブランチとモデル。
- 今できることを示すボタンが1つ表示されます。ターンの実行中は**停止**、エージェントが動いていないとき（**停止**や**失敗**のあと）は**再開**、VS Codeやターミナルで開いているClaude Codeのセッションでは**ここで続ける**です。**完了**のあとは目立たない表示になります。ボックスにメッセージを入力すれば、そのままセッションが続くためです。
- **詳細**（ファイルが変更されると、追加・削除された行数も表示されます）。[詳細パネル](#the-details-panel-changes-commands-and-info)が開きます。
- セッションのメニュー（⋯）：[セッションのメニューのすべて](#everything-in-the-sessions-menu)をご覧ください。

### ターン、ステップ、返信

会話はチャットのように読めます。各ターンは、自分のメッセージ、エージェントの作業、そして最後の返信で構成されます。

- **自分のメッセージ**は右側に表示されます。送信した直後、エージェントが受け取る前の段階で表示され、その下にエージェントの作業中の様子が現れます。メッセージボックスは次のメッセージのために空きます。送信できなかった場合（接続がない、支出上限に達したなど）は、メッセージが取り消されてメッセージボックスに戻り、理由を知らせる通知が表示されます。長いメッセージは最初の数行に折りたたまれ、**もっと見る**で全体を開けます。
- **作業**は、要約の行の下にまとまります。「Worked for 2m 10s · 3 commands」「Thought」「Stopped after 40s」「Failed after 5s」などと表示され、右側にはそのターンの費用（「≈ $0.12」）が表示されます。クリックすると、そのターンの[時間とコスト](/guide/sessions#a-turns-time-and-cost)が開きます。プラン（Claude Code、Codex）では、これはAPI料金で計算した場合のトークンの費用であり、実際の支払額ではありません。モデルの価格が不明な場合は、代わりにトークン数が表示されます。ターンの実行中、この行には「Working · 1m 2s」（または「Waiting for you」）と表示され、作業のアウトラインが進行に合わせて伸びていきます。それ以前のターンがある場合は、セッション全体の作業時間（すべてのターンの合計）も加わり、「Working · 1m 2s (47m)」のように表示されます。終わったターンは作業が折りたたまれます。行をクリックすると開きます。
- **作業のアウトライン**：エージェントがステップの合間に書く短いメモ（見つけたこと、次に行うこと）が1つのパートの始まりとなり、その後に行うステップがそのパートに入ります。終わったパートは、チェックマーク付きの1行になります。メモの要点を数語にまとめたもの（「Run the checkout tests first to see what fails」「Apply the discount first and round once」）、ステップ数、変更した行数が表示されます。クリックすると、メモの全文と各ステップが開きます。進行中のパートには、エージェントのメモが全文で表示され、その下に現在のステップ（「Editing total.ts · 4 s」など）が表示されます。その行をクリックすると、ここまでのパートのステップが開きます。エージェントの最初のメモより前のステップは、その内容にちなんだ名前のパート（「Ran 3 commands, read 2 files」）になります。長いターンでは最新のパートが表示され、**Show 12 earlier parts**で残りが表示されます。
- **ステップ**には、「Run the tests」「Read index.ts」「Searched the web」のように、わかりやすい言葉で名前が付き、コマンド自体は目立たない文字で添えられます。クリックすると、何を行ったかがわかります。Claude Codeは、コマンドやその他の変更を伴うステップを自分で実行します。同じメッセージ内でそのあとにエージェントが依頼したHydor独自のステップ（Web検索、ページの読み取りなど）は、終了するまで待ちます。そうしたステップは、実際に始まるまで時計の代わりに**待機中**と控えめに表示され、始まった時点から時計が進みます。終わったステップには、実際にかかった時間が表示されます。進行中のステップを示すアウトラインの行には、実際に実行中のステップの名前が表示されます。
- **思考**は「Thought for 12s」と最初の見出し付きで表示されます。クリックすると読めます。
- **返信**は、エージェントが最後のステップのあとに書いた内容です。エージェントが見せたページも返信と一緒に表示されます。エージェントの作業中に、最後のステップのあとで書かれた短いメモは、進行中のパートとしてアウトラインに表示されます。ターンがそこで終わると、それが返信になります。
- **ステップの合間の返信**：エージェントがステップの合間に書いた内容のうち、返信として読めるもの（作業中に送ったメッセージへの答え、続行前にわかったことを複数の段落、リスト、表にまとめたもの）は、作業に折りたたまれず、その位置に返信として表示されます。その前後の作業は、それぞれ「Worked for 20s · 2 commands」のような独自の行にまとまります。
- **変更されたファイル**：返信の下に、そのターンで変更されたすべてのファイルが、追加・削除された行数とともにカードで一覧表示されます。ファイルをクリックすると差分が表示され、**ファイルを開く**でそのファイルが開きます。5件を超える分は「Show 3 more files」の下に折りたたまれます。
- **作成されたドキュメント**：返信の下に、そのターンでエージェントが作成または変更したドキュメント（PDF、Word、Excel、PowerPoint、LaTeX、ノートブック、Markdownなど）が、**新規**または**更新済み**と記されたカードで表示されます。エージェントが渡したかどうかは関係ありません。返信内のファイル名やパスはリンクになっており、クリックすると会話の上に重なるウィンドウでファイルが開きます（[作成または変更したドキュメント](/guide/documents-voice#documents-it-made-or-changed-and-file-names-in-its-reply)）。
- **コミット**：エージェントがそのターンでコミットを行った場合、返信の下にチップが表示されます。**コミット済み**・コミットのタイトル（複数の場合は「3 commits」とブランチ）、追加・削除された行数が表示されます。クリックすると（複数の場合は、続けてコミットをクリックすると）、メッセージ全文、作成者と日時、ハッシュ（クリックでコピー）、変更したすべてのファイルとその差分が表示されます。**Gitで開く**を押すと、[Gitページ](/git)でセッションのリポジトリが開きます。同じターンの中でエージェントが修正（amend）したりリベースで消したりしたコミットは含まれません。

エージェントがチェックリスト（**プラン**または**ToDo**。完了した数も表示）を持つこともあり、作業が進むにつれてチェックが付いていきます。アプリからの通知は、関係するターンのあとに表示されます。メモリに保存された内容、セカンドオピニオン、支出上限への到達、ターンで開始されたサブエージェントのカードなどです。ほかのセッションからのメッセージは「From …」、サブエージェント（Hydor、Claude Code、Codexのサブエージェント）の返信は「Reply from …」と表示され（クリックすると返信を読めます）、スケジュールタスクの実行は、そのタスク名を示す行から始まります。

日付の行（「Yesterday」「Today」）で日ごとに区切られます。すべて今日の会話には日付の行はありません。古いメッセージは、上にスクロールすると読み込まれるほか、**以前のメッセージを表示**でも読み込まれます。新しいメッセージや返信は会話の末尾に追加され、その下に空白は残りません。返信が画面いっぱいになるほど長くなると、表示は最初の行で止まり、返信が伸びてもそのままになるので、長い返信を最初から読めます。短い返信は、それまでの内容の下にそのまま表示されます。エージェントの作業中に上へスクロールすると、表示は今の位置のままです。**最新**を押すと末尾に戻ります。返信が画面の下で続いているときにも表示されます。

終わった各返信の下には、**メッセージをコピー**、**この返信からフォーク**、**読み上げ**があります。**この返信からフォーク**は、Claude Codeではどの返信でも使えます。CodexとCustomはターン全体をフォークするため、終わったターンの最後の返信でのみ使えます。自分の各メッセージの下には、**メッセージをコピー**、**ここから編集**、送信した時刻が、ポインタを合わせたときだけでなく常に表示されます。

### ターンの時間とコスト

終わったターンの行の右側にある費用（「≈ $0.12」。モデルの価格が不明な場合はトークン数）を押すと**時間とコスト**が開き、ターンに時間や費用がかかった理由を確認できます。

- **所要時間**：ターンの時間がどこで使われたかを示すバーで、各部分の割合と長さが表示されます。**モデル**（与えられた内容の読み取り、思考、執筆）、**コマンド**、**ファイルの読み取りと編集**、**Web**、**その他のステップ**（サブエージェント、接続済みアプリのツール）、**回答待ち**（承認、質問、フォーム。各カードが表示されてから回答するまで）、**その他**（開始時とステップの合間）です。並行して実行されたステップは1回として数えます。その下には「First reply or step after 3 s」と表示され、エージェントがどれだけ早く動き始めたかがわかります。
- **トークン**：**新規読み取り**、**キャッシュへの書き込み**（新規に読み取られ、モデルの提供元に保持されるので、次のリクエストでは安く読み取れます）、**キャッシュから読み取り**（読み取った全体に占める割合付き）、**出力**（返信、思考、ステップ）。
- **費用**：そのターンの費用と、モデルの価格がわかる場合は種類ごとの費用、さらに「The cache saved about $0.80.」が表示されます。プラン（Claude CodeとCodex。セッションがAPIクレジットで動いている場合を除く）では、「At API prices: on a plan you pay your plan's fee」と表示されます。モデルの価格が不明な場合は、費用が計算されていないと表示されます。

Claude Codeのターンでは、モデル自身の時間と最初の返信までの時間がわかります。ほかのエージェントでは、モデルの部分は思考にかかった時間です。費用とこのパネルは、画面が広いときに表示されます。

### 返信内の数式、図、グラフ、画像

エージェントは、ターミナル向けではなくこのアプリ向けに返信を書くため、返信にはテキスト以外のものも含まれます。どのエージェントも、回答がわかりやすくなる場面では自分でこれらを使います。

- **書式**：見出し、リスト、表、太字、コードが、読みやすく配置されます。
- **数式**：教科書のような数式が、文中や独立した行で表示されます。化学反応式（2H₂ + O₂ → 2H₂O）も表示できます。対になったドル記号で囲まれた数字（`$1$`、`$0$`）も数式として扱われます。`$4.70`のような通常の価格は金額のままです。
- **図**：フローチャート、シーケンス図、状態遷移図、タイムライン、マインドマップ、ガントチャート、円グラフが、ライトまたはダークのアプリの配色で描かれます。図の上のバーには、**コードを表示**（エージェントが書いたコード。同じボタンで図に戻ります）、**画像として保存（SVG）**、**全画面**、コードをコピーするボタンがあります。描画できない図は、理由とともにコードが表示されます。
- **グラフと小さなツール**：グラフ、注釈付きの図、電卓、スライダー付きのシミュレーション、短いクイズなどが返信の中で動きます。エージェントが見せるページと同様に、アプリやファイルからは隔離されています。アプリの見た目に合わせ、大きさも内容に合わせて広がります（縦に長いものは**すべて表示**で開きます）。バーには**コードを表示**（**表示**で元に戻ります）、**ファイルとして保存**、**全画面**があります。クリックして選んだ内容はメッセージボックスに入ります。返信の執筆中はその場で組み上がっていき（表示できるものができるまで「Writing…」）、完成すると動き出します。
- **画像**：Webの写真（場所、商品、植物、美術作品など）やこのコンピューター上の画像が、返信に合わせて表示されます。クリックすると大きく表示され、**編集**で画像エディタが開きます（[画像と動画を編集する](/guide/library#edit-pictures-and-videos)）。Webの画像はこのアプリのサーバーを経由して届くので、画像を持つサイトにブラウザが知られることはありません。読み込めなかった画像は、その画像へのリンクとして表示されます。

プレーンテキストにしたい場合は、[エージェントガイドライン](/guide/guidelines)（「図や画像を使わず、プレーンテキストで答えて」）か、メッセージでそう伝えてください。これらは普通の言葉で頼むこともできます。「手順をフローチャートで描いて」「その画像を見せて」「ほかの値を試せるスライダーを付けて」。

### 回答UI：返信の中のカード、グラフ、地図

回答の一部が、読むものではなく、見る、比較する、選ぶ、たどる、試す、練習するものである場合、エージェントはアプリの回答UIのどれかでそれを表示します。回答の内容で埋められた、約150種類の既製のカード、表、グラフ、地図、ギャラリー、タイムライン、小さなツールです。数行を超える回答の多くにはこうした部分があるため、ほとんどの回答で目にします。比較する選択肢は、各行で最良の値に印が付く表になり、レシピは人数に応じて分量が変わるカード、天気予報は今後数時間や数日の予報、場所は番号付きのピンが立つ地図、クイズや練習問題はその場で答えられる問題になります。どれも返信が届くにつれて組み上がり、ライトまたはダークのアプリの見た目で表示されます。

- **回答UIでできること**：表の並べ替えとフィルタ、グラフの数値表示への切り替え、チェックリストのチェック、レシピのタイマー開始、フラッシュカードをめくる、ペアを合わせる、空欄を埋める、トラブルシューティングの質問に答える、ホイールを回して決めてもらう、電卓や関数グラフのスライダーを動かす、動画を再生する、などです。チェックした内容や回答は、このデバイスで会話に戻ったときも残っています（練習問題の回答も同様です）。**送信**と書かれたボタン（**選択を送信**、**スコアを送信**、**結果を送信**、**送信**など）は、そこに書かれた内容を、入力してEnterを押したかのように次のメッセージとしてすぐ送ります。選んだ選択肢、クイズのスコア、ホイールが止まった場所などです。横に**送信済み**と表示されれば、送信されたことを示します。入力中の内容はメッセージボックスに残ります。セッションがそのときメッセージを受け付けられない場合（前のメッセージがまだ送信中など）は、その内容がボックスに入るので、自分で送信します。さらに、次のようなものもあります。
  - **練習問題**で、自分の言葉や数字で答えるものは、その場で確認されます（数値は許容誤差の範囲内、言葉は大文字小文字を区別せず、アクセントだけが違う正解はその旨が示されます）。**ヒントを表示**でヒントが1つずつ表示されます。解答例は、1回試したあとか、すべてのヒントを表示したあとに表示されます。スコアが表示され、**結果を送信**でエージェントに送れます。自由回答への答えは**確認のために送信**でエージェントに送り、確認してもらいます。
  - **実行して変更できるコード**：プレイグラウンドで、JavaScript、Python、小さなWebページをその場で実行できます。アプリからは隔離されており、出力（Pythonのグラフも）がその下に表示されます。**実行**、**リセット**、**コピー**、**コードを送信**（エージェントに見てもらうために送ります）があり、試すための課題が出されることもあります。PythonはWebから最初に読み込まれるため、[機密セッション](/guide/sessions#keep-a-session-confidential)では実行できません。
  - **コードのウォークスルー**は、コードをガイド付きのツアーとして説明します。コードの横に番号付きのステップが並び、各ステップが説明する行が強調され、ほかは薄く表示されます。矢印（または**←**と**→**キー）で進むか、行をタップしてその行を説明するステップを開きます。**このステップについて質問**を押すと、そのステップについての質問がメッセージボックスに入ります。
  - **1ステップずつ実行されるプログラム**では、各ステップでプログラムがどこにいるかがわかります。今の行、変数（変わったばかりのものに印が付きます）、実行中の呼び出し、これまでに出力された内容です。前後にステップを進めたり、スライダーをドラッグしたり、再生を押したりできます。最初に出力を予想するよう求められたら、予想を入力して**確認**を押します。ここでも**このステップについて質問**が使えます。
  - **ネットワークグラフ**は、物事のつながり（概念マップ、小説の登場人物、何が何に依存しているか）を示します。ノードをタップするとそのつながりが強調されてメモを読めます。ノードをドラッグして動かしたり、凡例を読んだり、**リスト**表示に切り替えたりできます。
  - **注釈付きテキスト**は、テキスト内の箇所に印を付けます。タップするとそのメモ（修正、コメント、意味）と提案される変更を読めるほか、**これについて質問**もできます。メモを種類で絞り込んだり、**原文**と**修正後**を切り替えたり、**修正後のテキストをコピー**を使ったり、テキストを聞いたりできます。
  - **ファクトチェック**は、主張を1つずつ確認します。それぞれに判定、理由、エージェントの確信度、賛否の根拠と情報源が付きます。上部の判定の集計をタップすると、主張が絞り込まれます。
  - **フォローアップ**は、回答の最後に表示される、次の質問や手順を示す2～5個のボタンです。メッセージボックスが空のときはタップすると次のメッセージとして送信され、入力中のときは入力内容に追加されます。使ったボタンにはチェックマークが付きます。
- **画像**：画像のない項目や、画像を読み込めない項目は画像なしで表示され、テキストがその場所を占めるので、空の枠は残りません。
- **スプレッドシートやファイルの数値**：表、グラフ、主要な数値、ランキング、ヒストグラム、地図上の値は、数値を自分で持つ代わりに、スプレッドシート（[スプレッドシート](/guide/library#spreadsheets)を参照）の1つ、または会話のフォルダやそのプロジェクトのフォルダにあるCSV、TSV、JSON、JSONLファイルから読み取れます。エージェントは、数値がそこにあるとき、行数が数十行を超えるとき、保存しておきたいカードのときにこれを行います。カードが自分で合計、カウント、グループ化、フィルタ、並べ替えを行うので、数値を入力し直す必要はなく、表示されるたびに最新の数値が表示されます（あとから追加した行も同様です。ただしセルの範囲が固定されている場合を除きます）。カードの下の行には、数値の取得元（**データの取得元** *Shop numbers · Sales*。スプレッドシートまたはファイルを開くリンク）、読み取った日時、一部だけ表示している場合はその量（「1,000 of 12,400 shown」）が表示されます。**もう一度読み取る**で数値を再度読み取ります。スプレッドシートを保存すると、カードは自動で再描画されます。スプレッドシート、そのタブ、列、またはファイルがなくなった場合は、カードがわかりやすい言葉でそう伝え、**もう一度試す**が表示されます。カードが読み取れるのは、会話のフォルダにあるファイルのみで、このコンピューター上のほかの場所のファイルは読み取れません。サイズは50MBまで（JSONファイルは20MB）、行は最初の1,000,000行までです。[機密セッション](/guide/sessions#keep-a-session-confidential)で作成されたスプレッドシートは、そのセッション内のカードだけが読み取れます。
- **ポインタを合わせたとき**（またはキーボードで移動したとき）、右上に小さなバーが表示されます。**データを表示**はエージェントが書いた内容を表示します（スプレッドシートやファイルを読み取るカードでは、読み取り元とそこから何を表示しているか。**表示**で元に戻ります）。**テキストとしてコピー**はプレーンテキストとしてコピーし、**全画面**はカードだけをページの上に、ウィンドウの幅いっぱいに表示します（スマートフォンでは画面全体）。縦に長い場合はスクロールできます。**Esc**、**閉じる**、またはカードの外側をクリックすると戻ります。**その他**（…）の中には次があります。**ボードにピン留め**は、カードのコピーをボードに保存します。選んだボードか、その場で名前を付ける**新しいボード…**に保存され、ほかのカードと並べてあとで見返せます（[ボード](/guide/library#boards)を参照）。**画像として保存**は、見ているテーマのまま、鮮明さを保つため2倍のサイズで、カードのPNGを保存します。ファイル名はカードのタイトルになります。**画像としてコピー**は同じ画像をクリップボードにコピーし、メッセージやドキュメントに貼り付けられます（ブラウザがページにそれを許している場合）。全画面表示の上部にも同じ2つがあります。地図、チャートライブラリで描かれたプロット、動画プレーヤー、コードプレイグラウンドの出力を含むカードには、画像のボタンはありません（ピン留めはできます）。これらの部分は画像に描き込めないためです。
- **エージェントが使うとき**：エージェントは、回答のうち、見る、比較する、選ぶ、たどる、試す、練習する、保存するものにあたるすべての部分に回答UIを使うよう指示されています。数行を超える回答では、ほとんどの場合これにあたります。検討する選択肢、画像と詳細がある対象（場所、商品、映画、本、人物、論文、ニュース）、数値、時間と計画、やること、学ぶこと、確認する文章、検証する主張、取りたい次のステップなどです。画像も埋め、写真より見たほうがわかりやすい場面では動画を再生します。カードでは伝えられないこと（理由づけ、アドバイス、注意点）は、エージェントの言葉に残ります。普通の会話、短い質問への短い答え、コードの変更はテキストのままです。最初の回答も、それ以降の各回答も、部分ごとに1つずつ、複数を含められます（旅行の旅程、天気、持ち物リストなど）。そのため、会話には回答が必要とするだけ多くのカードがたまります。あとの回答で、データを更新して同じカードを再び表示することもあります。エージェントは、1回の検索で合うものを見つけます。すでに知っているものは名前で、そのほかの部分は、それぞれが何を表示するかを数語で表して検索します（言葉で、さらに[設定 → メモリ](/settings?s=memory)で**意味で検索**がオンのときは意味でも）。そのため、すべてを渡されることはありません。[組み込みエージェント](/guide/agents#the-built-in-agents)は、それぞれ自分の作業に合うものを多く使います。
- **すべてを見る**：[回答UI](/answers)では、すべての回答UIが、まとめ、比較、ショッピング、場所と旅行、食べ物、計画、仕事とビジネス、数値とグラフ、お金、学習、科学、メディア、人物とスポーツ、文章、コードのグループごとに、例とともに見られます。**ストリーミング中に再生**を押すと、返信で届くときのように表示されます。

普通の言葉で頼むこともできます。「表で比較して」「地図に載せて」「クイズを出して」「これについての練習問題を出して」「直すところを私のエッセイに書き込んで」。プレーンテキストにしたい場合は、[エージェントガイドライン](/guide/guidelines)（「カードやグラフを使わず、プレーンテキストで答えて」）かメッセージで頼めます。

### ステップを開いて出力を見る

ステップをクリックすると開きます。

- コマンド：コマンド、実行したフォルダ、終了コード、かかった時間、コピーボタン、出力（途中で切れている場合は**出力をすべて読み込む**）。
- ファイルの編集：差分（途中で切れている場合は**差分をすべて読み込む**）。
- ファイルの読み取り：そのファイルへのリンクと、読み取った内容。
- Webページ：そのアドレスと、そこから読み取った内容。
- サブエージェントに与えられたタスク：**与えられたタスク**と、返ってきた内容。
- そのほか：エージェントが送った内容と、返ってきた内容。

ステップには、**バックグラウンド**（実行し続ける）、**自動**（CustomのAutoモードが判断したもので、理由はポインタを合わせると表示される）の印が付くことがあり、赤い終了コードが表示されることもあります。バックグラウンドタスク（実行したままのコマンド、モニター、ワークフロー）は、メッセージボックスの上の行に、セッションのサブエージェントとともに一覧表示されます。タスクを開くと出力が見られ（Claude Code）、**停止**もできます（その前に確認が表示されます）。サブエージェントは、それ自身のセッションとして開きます。[サブエージェント](/guide/sessions#subagents)をご覧ください。

## エージェントの開始前にプロジェクトのメモリを作成する

開始ページで、[Wikiメモリ](/guide/wiki-memory)がまだ新しい（記事が10件未満で、履歴からの作成を一度も実行していない）プロジェクトでセッションを開始し、そのプロジェクトにメモリの元になるもの（会話、コミットメッセージ、ドキュメント、メモ、README、docs/フォルダ）がある場合、セッションは最初に確認を求めます。メッセージの下のカードに**「<project>のメモリを先に作成しますか？」**と表示され、読み込む内容と、エージェントが開始するまでのおおよその所要時間が示されます。選択するまで、セッションには**対応が必要**と表示されます（通知も届きます）。

- **メモリを作成して開始**：メモリの作成が始まり、カードは進捗表示に変わり、セッションには**メモリを構築中**と表示されます。メッセージは待機し（「メモリの準備ができたらエージェントに送信されます」）、最も重要な部分が書き込まれた時点でエージェントに届きます。最も重要な部分とは、ファイルから作ったプロジェクトの概要、メモ、内容が最も多い会話です。残りはバックグラウンドで作成が続き、書き込まれたものからエージェントが見つけられるようになります。**今すぐ開始**を押すとメッセージをすぐに送信し、作成は続行されます。**作成を停止**を押すと作成を止め（書き込まれた内容は残ります）、エージェントを開始します。アプリを閉じても、エージェントは自動で開始されます。その時点より前に作成が失敗した場合は、カードにその旨が表示され、**もう一度試す**と**そのまま開始**を選べます。エージェントがメッセージを受け取る前に終了し（クラッシュした、または待機中にコンピューターが再起動した場合など）、再び開始できないときは、カードに**新しいセッションで開始**が表示されます。同じ設定の新しいセッションがメッセージを受け取り、その間に送信した内容も引き継ぎ、空のセッションはアーカイブされます。
- **メモリなしで開始**：エージェントがすぐに開始され、このプロジェクトでは1週間確認されなくなります。
- **このプロジェクトでは確認しない**：このプロジェクトについて今後は確認されません。**履歴からWikiを作成…**は、プロジェクトの詳細にある**メモリ**タブの**⋯**メニューに残ります。

待機中に送信したものは、最初のメッセージの後にエージェントへ届きます。確認が表示されるのは、開始ページで自分でセッションを開始したときだけです。スケジュールされた実行、アプリ、サブエージェント、エージェントが開始したセッションでは表示されず、作成済みのプロジェクトでも表示されません。

## エージェントの操作を承認または拒否する

エージェントが、権限の範囲では単独で行えないことをしようとすると、待機して、会話の末尾のカードで確認を求めます。カードには、実行したいコマンド、差分付きのファイル変更、または別のツールとその詳細が、待機時間とともに表示されます。セッションのドットが琥珀色になり、受信トレイにカウントされ、オンにしていれば通知も届きます。回答はカードから、[受信トレイ](/guide/inbox)から、または単純な可否であればブラウザがボタンを表示する場合は通知そのものからできます。

ボタンはエージェントによって異なります。

- **Claude Code**：**許可**、**拒否**、そして「Bash npm testを常に許可」や「このセッションですべての編集を許可」のようなルールが表示されることも多くあります。
- **Codex**：**許可**、**このセッションで許可**、**このコマンドを常に許可**、**拒否**、**拒否して停止**。ファイル変更には**このセッションで編集を許可**、より広い権限には**このターンで許可**と**このセッションで許可**。
- **Custom**：**許可**、「**常に許可**」の後に対象の内容がそのまま続くもの（承認したコマンドだけが対象なので、後ろに何かを付け足すことはできません）、そして**却下**。
- その他のエージェント：そのエージェントが提示する選択肢。

**拒否**を押すと、まず「任意：代わりにどうするかをエージェントに伝える」というボックスが開きます。もう一度**拒否**を押すと、メモありでもなしでも送信されます（Customの**却下**とCodexの**拒否して停止**はすぐに回答します）。

接続済みアプリのツールのうち**事前に確認**に設定したものは、セッション内では確認しません。呼び出しは送信トレイに保留され、エージェントは作業を続けます。会話には**送信トレイで承認待ち**という行が表示され、後で送信されたか破棄されたかが表示されます（[送信トレイ](/guide/inbox#the-outbox-calls-held-for-your-ok)）。

Claude Codeの**自動**モードでは、安全チェックが確認せずにコマンドを拒否することがあります。その場合、メッセージ欄の上のカードに「Claudeがコマンドをブロックしました」と理由が表示されます。**承認して再試行**を押すとセッションが確認に切り替わり、エージェントがもう一度実行するので、通常の承認として手元に届きます。**閉じる**を押すと、そのままにします。

## 質問に回答し、プランを承認する

エージェントから質問されると、琥珀色の縁のカードに質問と選択肢が表示されます。

- 選択肢を1つ選びます。「複数選択可」と表示されている場合は複数選べます。**その他：自分の回答を入力**では、自分の言葉で回答できます。
- **ファイルを添付**で、回答にファイルを追加できます。
- 1〜9のキーで、まだ回答していない最初の質問の選択肢を選べます。
- **回答を送信**を押すと、次のメッセージとして送信されます。質問中にセッションが停止していた場合は、**再開して回答**を押すと、回答付きで再び開始されます。VS Codeやターミナルで待機しているClaude Codeのセッションでは、**ここで回答**を押すとそちらを終了し、回答付きでこちらで続行します。Codexのセッションは、そちらで回答する必要があります。

質問が承認カードの形で表示された場合のボタンは**回答を送信**で、Claude Codeでは**スキップ**もあります。

**プラン.** Claude Codeの**プラン**モードでは、エージェントは読み込みとプラン作成を行い、カードにプランを表示します。**承認、編集を自動承認**（確認なしで編集しながら進めます）、**承認、編集前に確認**、**プランを続ける**（プランモードのままです。変更してほしい点を伝えます）から選びます。CodexのPlanモードでは、Codexがまず話し合ってプランを立て、確認の質問をすることがあります。CustomのPlanモードは、番号付きのプランで終わります。権限を切り替え（Shift+Tab）、返信すると実行されます。

## サービスから求められるフォームに入力する

接続したサービスが、タスクの途中で何か（日付、選択、承認するページなど）を求める場合、そのフォームがカードとして表示されます。どのエージェントが作業していても同じです。「Linearがフォームへの入力を求めています」「…がページを開くよう求めています」「…が続行の許可を求めています」のように表示されます。項目を入力して**送信**（ページを開く場合は**開く**、または**許可**）を押すか、**辞退**または**今はしない**を押します。Codex独自のツールサーバーも同じ方法で確認します。[接続済みアプリ、キー、ツール](/guide/connections)をご覧ください。

## 作業中のエージェントにメッセージを送る

ターンの実行中でも入力できます。そのときのEnterの動作は、ブラウザごとに[設定 → アプリ → 一般](/settings?s=general&find=Sending%20while%20an%20agent%20works)の**エージェントの作業中に送信**で決まります。

- **ターンに参加**（既定）：Enterで、進行中のターンにメッセージが追加され、エージェントがすぐに考慮します。Ctrl+Enter（Macでは⌘Enter）では、代わりにキューに入ります。
- **待つ**：Enterで、メッセージがキューに入り、ターンの終了時に送信されます。Ctrl+Enterでは、代わりにターンに追加されます。

どちらになるかはメッセージ欄に表示されます。「実行中のターンに追加メッセージを送信」または「このターンの終了時に送るメッセージをキューに入れる」です。タッチスクリーンでは、送信ボタンがEnterと同じ動作をします。Customは、実行中のツールが終わった後の次のモデルのステップで追加メッセージを取り込みます。キューにあるメッセージでは**今すぐ送信**が同じ動作をします。アプリの更新前から実行中だったCustomのセッションがまだ追加メッセージをリアルタイムで受け取れない場合は、メッセージはターンの終了までキューに残ります。ほかのACPエージェントは一度に1件のメッセージしか受け付けないため、作業中に送ったメッセージは常にキューで待ちます。Claude Codeでは、エージェントの作業中に入ったメッセージの下に「作業中に送信」と表示されます。それに対するエージェントの回答は、その後もエージェントが作業を続ける場合でも、メッセージの下に返信として表示されます。

## キューを管理する

キューに入ったメッセージはメッセージ欄の上で待機し、送信される順に番号が付きます。キューに入れたメッセージは、送信した瞬間にそこに表示されます。ターンが終わるたびに1件ずつ自動で送信されます。

- ハンドルをドラッグすると、順序を変更できます。
- **今すぐ送信**（矢印）：実行中のターンにすぐ送信します。
- **編集**（鉛筆）：テキストの変更、添付ファイルの取り外し、追加（**添付**、またはファイルの貼り付けやドロップ）ができます。Enterで保存、Escでキャンセルします。
- **外す**（ゴミ箱）：キューから外します。添付ファイルは削除されます。
- エージェントを停止したときやアプリが再起動したときは、キューが一時停止します。「キューは一時停止中です（エージェントが停止されたか、サーバーが再起動しました）。」**再開**を押すと、エージェントが空き次第、メッセージが再び送信されます。エージェント同士が送り合うメッセージ（セッションからHydorサブエージェントへのメッセージとその返信）は、再起動では一時停止しません。待っているエージェントがまだ作業中なら、そのターンが終わったときに送信されます。支出上限に達した場合もキューが保留されます。上限を上げると続行されます。

## エージェント、モデル、思考レベル、権限を変更する

セッションのメッセージ欄には、開始ページの**エージェント**と、その3つの選択肢**モデル**、**思考レベル**、**権限**が、**+**の横の1つのチップにまとまっています（**オプション**が開きます。スマートフォンでは下から出るシートです）。その下には、開始ページの残りのオプションが、同じ順序で並びます。**アカウント**（次のメッセージから別のアカウントがセッションを引き継ぎます。エージェントに複数のアカウントがある場合に表示されます）、**機密**と**アリーナ**（表示のとおりです。どちらもセッションの開始時に選ぶもので、クリックするともう一方の選び方が表示されます）、**メモリ**、**支出上限**、**スウォーム**、**リサーチ**、**ガイドライン**（セッションメニューの[セッション設定](/guide/research#turn-it-on)と同じ選択肢とダイアログです。スウォームとリサーチは次のメッセージから変更されます）です。チップにはエージェントとモデルの名前が表示され、思考レベルと権限は通常と異なる場合に表示されます。エージェントが確認なしで何でもできる間（**バイパス**、またはCodexの**フルアクセス**）は、琥珀色になります。別のエージェントへの変更は、次のメッセージから適用されます（[セッションでエージェントを切り替える](/guide/agents#switch-agents-in-a-session)をご覧ください）。モデル、思考レベル、権限の変更は、実行中のエージェントにすぐ適用され、セッションに残ります。Shift+Tabで次の権限モードに移ります。モデルメニューには、このエージェントのモデルだけが表示されます。会話を別のエージェントに移すには、[別のエージェントで続ける](#continue-in-another-agent)を使います。

## 返信の一部を引用する

エージェントの返信、または自分のメッセージの文章を選択すると、その上に**見積もり**ボタンが表示されます（タッチスクリーンでは下に表示されます）。選んだテキストが引用としてメッセージ欄に入り、カーソルがその後ろに置かれるので、その部分に返答したり、以前に自分が言ったことを持ち出したりできます。

## セッション内のテキストを検索する

セッションでCtrl+F（⌘F）を押します。**このセッション内を検索**は、自分のメッセージとエージェントのメッセージを検索します（まだ読み込まれていない部分も含み、コマンドの出力は含みません）。2文字以上を入力すると、最新の一致箇所に移動して語句が強調表示され、「3/12」のように表示されます。Enterで古い一致箇所へ、Shift+Enterで新しい一致箇所へ移動します（矢印も使えます）。Escで閉じます。折りたたまれた長いメッセージは、見つかった箇所が開きます。検索ボックス（Ctrl+K）で選んだメッセージは、このバーに入力済みの状態でそのセッションが開きます。

## メッセージ欄のその他の機能

- 空のメッセージ欄で↑を押すと、このセッションの以前のメッセージが新しい順に呼び出されます。↓で新しい方へ戻ります。
- 入力した内容は、このブラウザでセッションごとに下書きとして保存されるので、戻ってきたときにもそのまま残っています。
- Ctrl+S（⌘S）で下書きを脇に置いて、メッセージ欄を空にします。空のメッセージ欄でCtrl+Sを押すと、元に戻ります。
- 非常に長い貼り付け（32,000文字以上）は、メッセージ欄をいっぱいにする代わりにテキストファイルとして添付されます。
- プレースホルダーに、送信するとどうなるかが表示されます。「Claudeにメッセージ…」、またはエージェントが実行中でないときは「メッセージを送って続ける…」です。送信すると、会話全体を引き継いで再び開始されます。

## 詳細パネル：変更、コマンド、情報

ヘッダーの**詳細**を押すと、3つのタブを持つパネルが開きます。広い画面では会話の横に表示され、セッションを移動しても開いたままです。狭い画面ではページの上にスライドして表示され、スマートフォンでは操作したときだけ開きます。

- **変更**：セッションが変更したすべてのファイルが、変更の多い順に、追加・削除された行数とともに表示されます。ファイルをクリックすると、各編集の差分が表示されます。**開く**でファイルを開きます。
- **コマンド**：エージェントが実行したすべてのシェルコマンドが、新しい順に表示され、**すべて**、**失敗**、**背景**のフィルタがあります。クリックすると出力が表示されます。
- **情報**：エージェント、状態（ヘッダーと同じ：**完了**、**停止**、**失敗**、または現在の動作）、フォルダ、ブランチ、モデルと思考レベル、コンテキストの使用量、開始時刻と最終アクティビティ、アクティビティ（プロンプト、ターン、ツール呼び出し、コマンド）、トークン（入力、キャッシュ、出力）、APIコスト（同じ作業をAPI料金で行った場合の費用）、出力速度、開始元（Hydor、VS Code、ターミナル、Claudeのデスクトップアプリなど）、そしてエージェントの実行中は**そのプログラム**：現在の使用状況（CPU、メモリ、プログラム数）と、適用されている[制限](/guide/app#limit-each-session)が表示されます。その下には、バックグラウンドタスク（開くと実行内容を確認でき、**停止**もできます）と、**ターミナルで続ける**があり、セッションをターミナルで再開するコマンドとセッションIDが、それぞれコピーボタン付きで表示されます（Claude CodeとCodex）。

## メーターの見方：コンテキスト、キャッシュ、速度

マイクの横にある割合付きの小さなリングは、会話がモデルのコンテキストウィンドウを使うにつれて満たされていきます。詳細は、オプションのチップのメニューの下部にあります。

- **コンテキスト**：リングと、オプションの**コンテキスト**行（「42%使用中」）。リングにポインタを合わせると、正確なトークン数が表示されます。85%を超えると琥珀色になります。リング、またはオプションの**圧縮**をクリックすると、会話を圧縮します（ターンの実行中はできません）。Customのセッションでは、リングにポインタを合わせるとトークン数と内訳が表示され、内訳は**コンテキスト**行の矢印の下にあります。Customは自動で要約するため、**圧縮**はなく、リングをクリックしても何も起こりません（[長い会話と長い出力](/guide/custom#long-conversations-and-long-output)をご覧ください）。
- **cache 4m**（Claude Code）：プロンプトキャッシュは会話をしばらくの間（5分または1時間）準備した状態に保つので、次のメッセージは安く、速くなります。何も送信しない間はカウントダウンし、その前にメッセージを送ると再利用されてカウントが再開されます。**キャッシュなし**は、次のメッセージで再構築されることを意味します。
- **85 tok/s**：直近の返信が書かれた速さで、1秒あたりのトークン数です。

## ターンの停止、エージェントの停止、再開

メッセージ欄の横にある停止ボタンには、エージェントが起動中または作業中のあいだ、回転するリングが表示されます。ユーザーの操作が必要なときはリングが一時停止し、デバイスでモーションの軽減が設定されている場合は静止したままになります。ターンが終わったあとも、エージェントが開始したバックグラウンドタスクやサブエージェント（Hydorサブエージェント、Claude Codeサブエージェント、実行したままのコマンド、モニターなど）が動いているあいだは、停止ボタンがリングとともに残ります。その横に送信ボタンがあり、メッセージ欄はいつもどおりメッセージを受け付けます。停止ボタンにポインタを合わせると、何が止まるかが表示されます。「このターン、2件のサブエージェント、1件のバックグラウンドタスクを停止します」や「2件のサブエージェントを停止します」のように表示されます。停止すると、ターン、実行中の各サブエージェント、実行中の各バックグラウンドタスク、そしてそれらが開始したものがまとめて止まります。この方法で停止したHydorサブエージェントは、親に報告を返しません。すでに送られていた報告は、親を起こさずに親の一時停止中のキューで待機します。キューを再開するには**再開**を押します。

- **ターンを停止**：ヘッダーの**停止**、またはメッセージ欄の横にある丸みのある四角いボタンを押します。後者は、セッションが開始したものも止めます（上記）。（Escでは停止しません。Escは、検索バーやリストなど、開いているものを閉じるだけです。）エージェントは作業をやめ、ターンには「停止しました…」と表示されます。**停止**を押した瞬間にセッションは停止した状態になります。実行中のコマンドを終了するなど、エージェントが完全に止まるまで数秒かかる場合も同様です。20秒後もエージェントが作業中であれば、セッションは再び作業中の表示に戻ります。エージェントは次のメッセージを受け付ける状態のままで、キューは再開するまで一時停止します。
- **エージェントのプロセスを停止**：ターンが実行されていないときに、セッションのメニュー（⋯）→ **その他** → **エージェントのプロセスを停止**を選びます。エージェントのプログラムは終了しますが、セッションと履歴は残り、直前のターンの結末（**完了**、**停止**、**失敗**）が表示されます。
- **再開**：ヘッダーの**再開**を押すと、会話全体を引き継いでエージェントが再び起動します。または、メッセージ（「続きのメッセージ…」）を送るだけでも再び起動します。Claude Code、Codex、Customのいずれも同様です。**完了**のあとは、次のメッセージを送るだけで済むため、**再開**は目立たないボタンになります。VS Codeやターミナルなどから、数秒前にそのセッションへ書き込みがあった場合は、先に確認が表示されます。2つのプログラムが1つのセッションに書き込むと、履歴が壊れるおそれがあるためです。
- 待機中のエージェントは、3時間たつと自動的に停止します（ユーザーの操作待ちがなく、バックグラウンドタスクも動いていない場合）。次のメッセージを送ると、再び起動します。

## セッションにゴールを設定する

ゴールは、合意したチェックが成立するまで、エージェントをラウンドごとに働かせ続ける機能です。まず、ユーザーとエージェントで「完了」の意味を短いチェックのリストとして合意します。その後は、アプリ自身が毎ラウンドの後にそのチェックを実行し、ラウンドで目標に近づいたかどうかを判断します。そのため、エージェントが「完了した」と言っても何も変わりません。ゴールを終わらせられるのはチェックだけです。アプリ自身のループで動かすので、すべてのエージェント（Claude Code、Codex、Custom、追加したその他のエージェント）で使えます。

設定するには、セッションのメニュー（⋯）→ **ゴールを設定**を開き、作業が終わったときに成り立っている状態（「npm testが通り、アップロードページが2GBのファイルを処理できる」）を入力して、**確認の頻度**を選び、**チェックを作成**を押します（Ctrl+Enterでも可）。または、セッションの開始時に設定することもできます。開始ページで**オプション**→ **ゴール**→ **完了するまで**を開くと、最初のメッセージがゴールになります。ゴールを設定できないセッションは次のとおりです。

- 別のセッションが開始したセッション（Hydorサブエージェント。そのメニューには**ゴールを設定**がありません）
- VS Codeやターミナルで実行しているセッション（先にアプリで続行してください）
- プランモードのセッション（エージェントは何も変更しません）
- スウォーム、キャンペーン、ディープリサーチ、アリーナ対戦を率いているセッション（「チーム向けのゴールは今後のバージョンで対応します」）
- そのプログラム独自の `/goal` があるセッション（先に `/goal clear` でクリアしてください）

**ゴール**で開始したセッションでゴールを設定できない場合は、通常のセッションとして続行され、理由が通知されます（「ゴールを設定しませんでした：…」）。セッションに設定できるゴールは一度に1つです。ゴールは多くのターンを消費しますが、以下で合意する上限が歯止めになります。ゴールは、セッションがアーカイブされると自動で停止し、**ここから編集**で置き換えられた場合も終了します。

サイドバーの的のマークで、ゴールのあるセッションがわかります。マークにポインタを合わせると、ラウンド数と成立しているチェックの数が表示されます。セッション自身のオプションのチップには「ゴールモード」と表示されます。開始ページでゴールを初めてオンにするときは、機能の内容と費用を説明する短い案内が表示されます。

### 「完了」の意味を合意する

エージェントはプロジェクトを読み込み、チェック、変更してはいけないパス、上限を提案します。これらはメッセージ欄の上に、**これで完了とみなしてよいですか？**というカードで表示されます。**完了の条件**にチェックが並び、それぞれに種類のタグが付きます。

- **コマンド**：成功する必要があるコマンド（「npm test」）。
- **測定済み**：数値を出力するコマンドと、その目標値（以上または以下）です（「検索のp95が200ミリ秒未満」）。ラウンドの値がこれまでの最良値より少し（1割まで）下回っても、成立とみなされます。
- **レビュアー**：レビュアーが正しいと判断する必要がある文です。レビュアーは作業に関わっていないモデルで、変更内容や、チェックが指定するファイルまたは出力を読み、その文が成立しているかを理由とともに答えます。「設定ページにダークモードがある」のように、コマンドでは確かめられない内容に使います。
- **自分**：ユーザーだけが確認できる内容です。ほかがすべて成立すると、ユーザーの確認待ちになります。

**保護済み**には、エージェントが変更できないパス（テスト、テストデータ、チェック自体のスクリプト）と、作業する場所が表示されます。**上限**は、使えるラウンド数、費用（APIの料金換算）、時間の最大値です。ラウンド数は[ゴールが一時停止するまでのラウンド数](/settings?s=custom&find=Rounds%20before%20a%20goal%20pauses)で決まり（変更しなければ30）、費用と時間は設定するまで無制限です。**確認の頻度**では、確認の頻度をここでも変更できます。セッションの支出に価格がない場合（価格のないモデル）、カードには費用の上限では止められないと表示されますが、ラウンド数と時間の上限は有効です。

ラウンドの前に、アプリは現状を測定します。そのため、カードには「3分前に測定 · 5件中3件が成立」のように表示されます。この測定が提案の直後に行われるのは、セッションの権限がすでにエージェントによるコマンドの実行を確認なしで許可していて（Claude Codeの**バイパス**、CodexとCustomの**フルアクセス**）、セッションが機密セッションでない場合だけです。それ以外では何も実行されず、カードに「まだ測定していません」「**開始**を押すと初めてチェックが実行されます」と表示されます。コマンドはエージェントの提案なので、先にユーザーが同意する必要があるためです。実行できなかったチェックは、成立していないものとして数えられます。カードにその旨が表示され、ボタンは**そのまま開始**になります。

チェックは、セッション自身のコマンドと同じ条件で、つまりそれより自由になることなく、エージェントに渡される環境で実行されます。機密セッションでは、常にネットワークなしのアプリのサンドボックス内で実行され、サンドボックスのないコンピューターでは実行できません（チェックに「実行できるサンドボックスがこのコンピューターにありません」と表示されます）。自動モードでサンドボックスがオンのCustomセッションでも、サンドボックス内でフォルダに限定して実行されます。**フルアクセス**未満のCodexセッションでは、サンドボックス内でフォルダに限定され、Codex自身のサンドボックスポリシーが許可しない限りネットワークなしで実行されます。それ以外の場合は直接実行されます。

- **開始**：チェックに同意します。すべてがすでに成立していれば、ゴールはすぐに達成されます。そうでなければ、ラウンド1が始まります。
- **変更…**：各行を入力欄に切り替えます。チェックの削除、ラベル、コマンド、目標、文の編集、種類を選んだ**チェックを追加**、保護するパス（1行に1つ）と上限の編集ができます。その後に**開始**を押します。**変更を取り消す**を押すと、カードが元に戻ります。
- **今はしない**：ゴールを停止します。

エージェントが2回依頼されても何も提案しない場合は、アプリが代わりに1つのチェックを提案します。ユーザーのゴールに照らして変更をレビュアーが読むチェックです。

### ラウンド：残すか、取り消すか

ラウンドでは、エージェントに作業の内容が渡されます。各チェックの現状、前のラウンドの内容、ユーザーが依頼した内容、変更してはいけないものです。エージェントは通常のメッセージと同じように、セッションの権限で作業し、行ったことと残りの作業をアプリに伝えてターンを終えます。ユーザー自身のメッセージは常に優先されます。ラウンドの中の通常のターンとして扱われます。

ターンが終わると（エージェントが開始したHydorサブエージェントなどがまだ動いていない場合）、アプリはすべてのチェックを実行します。開発サーバーのように実行中のままのコマンドは、ターン終了後に10分待たれ、その後でチェックが実行されます。ラウンドの間にユーザーがファイルに加えた変更は、そのラウンドの変更とはみなされず、ラウンドの取り消しでも元に戻されません。ラウンドが**残した**と判定されるのは、目標に近づき、何も壊れていない場合です。次の場合は**取り消し済み**になります。

- 変更してはいけないパスを変更した。
- ユーザーのルールに違反した（[いつでも操作する](#steer-it-whenever-you-want)を参照）。
- 成立していたチェックが成立しなくなった。
- 測定値が最良値を大きく下回った。
- 何も近づかなかった。

取り消されたラウンドは、開始時のファイルの状態に戻ります（ラウンドの間にユーザーが何か変更していない限り、一覧で**これまでで最良**と表示されるこれまでの最良のラウンドの状態です）。これには、ワークツリーで作業するセッション（開始ページの**新しいワークツリー**）が必要です。カードに、どちらかが「専用のブランチで作業します」または「ユーザーのフォルダで作業するため、ラウンドを取り消せません」と表示されます。ユーザー自身のフォルダでは、悪化したラウンドは**そのまま**と表示され、次のラウンドには何が悪化したかが伝えられ、修正するよう指示されます。

アプリが自動でファイルを元に戻すのは、ラウンドの開始以降にそのフォルダで誰も作業しておらず（同じフォルダの別のセッション、たとえばフォークなど）、このセッションがラウンド終了後に静かだった場合だけです。元に戻す前に、アプリはフォルダ内のすべて（チェック自身の出力やユーザーの編集も含む）をそのラウンド専用のファイルとして保存します。そのため、そのラウンドの**それでも保持…**で、すべてを元に戻せます。別のセッションがフォルダで作業していた場合や、コミットが作られた場合、ラウンドは**取り消されません**。ラウンドはそのまま残り、「**そのまま**」と理由（「取り消されませんでした：別のセッション（「…」）がフォルダで作業していました」）が表示されて、ゴールは続行され、次のラウンドにはファイルが元に戻されなかったことが伝えられます。チェックの実行中にユーザー自身のメッセージが届いた場合は、セッションが静かになったときにそのラウンドが改めてチェックされます（3回繰り返すとゴールは一時停止します：「ラウンド4をチェックできませんでした：チェックの実行中にセッションがフォルダで作業を続けました。**再開**すると、もう一度チェックします。」）。アプリが2回試みることはありません。ファイルを元に戻す処理が完了しなかった場合（失敗した場合や、途中でアプリが再起動した場合）、ゴールは一度だけ一時停止して、次のように表示します。「ラウンド4のファイルを元に戻す処理が完了しなかったため、ファイルが一部だけ戻っている可能性があります。フォルダにあったものはすべて保存されています。ラウンド4の**それでも保持…**で元に戻せます。**再開**すると、現在のファイルの状態から続行します。」残したラウンドが削除したファイルは、後で取り消しても削除されたままです。

メッセージ欄の上のバーには、ゴール、現在の動作（「ラウンド7/12 · 作業中」、「チェックを実行中」、「確認中」、「一時停止中」）、各チェックのピル（成立していればチェックマーク、数値なら小さなメーター付きの「0.73 / 0.80」、まだ成立していなければ白抜きの点、実行できなかった場合はオレンジのマーク）、上限に対する費用と時間、そして**ラウンド · 3件残した · 2件取り消し**が表示されます。これを開くとラウンドの一覧が表示され、各ラウンドの内容、変化したもの（「関連度 0.61 → 0.68」）、**残した**か**取り消し済み**か、費用と所要時間がわかります。ラウンドを開くと、エージェントが報告した内容、各チェックの結果、その結論に至った理由を確認できます。ループがエージェントに送るメッセージは、会話の中に「ゴール · ラウンド5/12」という控えめな1行で表示されます。クリックするとメッセージを読めます。

成立していたチェックが実行できなくなった場合（レビュアーが利用できない、タイムアウト、ツールの不足）、成立しなくなったとは扱われません。もう一度だけ実行され、それでも実行できなければゴールは一時停止し（「「テストが通る」を実行できませんでした：…**再開**すると、ラウンドをもう一度チェックします」）、そのラウンドは残されることも取り消されることもありません。レビュアーがユーザーのルールを読めなかった場合、ラウンドは続行され、その行に「このラウンドではユーザーのルールをチェックできませんでした」と表示されます。

すべてのチェックが成立しても、アプリはすぐには信用しません。コマンドと数値をもう一度実行し、レビュアーが変更全体を読んで、テストが弱められたりスキップされたりしていないか、答えがコードに直接書き込まれていないか、ゴールが本当に達成されているかを確かめます。これらを満たして初めてゴールが達成されます。これに失敗した場合、次のラウンドには最終チェックで見つかった内容が伝えられ、以降のラウンドは、何も壊れておらずファイルが変更されていれば残され、変更されていなければ「変更なし」として取り消されます。**自分**のチェックがある場合は、ユーザーに確認が求められます。**成立しています**か**まだです**を、メモ付きで選びます。「まだです」を選んだ場合も同様に扱われます。

### 確認の頻度

**確認の頻度**には3つの設定があり、開始ページ、**ゴールを設定**ダイアログ、カード、バーのチップで選べます。

- **自動で**（チップには「自動で作業します」と表示）：ユーザーなしでは先に進めないとき（ユーザーだけが提供できるものがある、またはユーザーだけが確認できるチェックがある場合）だけ確認します。
- **転換点**（デフォルト。チップには「転換点で確認します」と表示）：方針を変えようとするときに確認します。これは、2ラウンド続けて進展がなかった後に行われます。
- **毎ラウンド**（「毎ラウンド確認します」）：各ラウンドの後に、わかったことと次のおすすめを表示します。

確認する場合、質問カードに2〜4つの進め方が表示され、それぞれに理由、期待される成果、費用が示され、エージェント自身のおすすめには**おすすめ**が付きます。進め方を1つまたは複数選ぶと、選んだ順に1つずつ実行されます。**その他：方法を入力**で独自の方法を指定でき、**エージェントへのメモ（任意）**は次のラウンドに渡されます。メインのボタンは**この方法で進める**、または「この2つを順番に進める」と表示されます。**おすすめのみ**を押すと、エージェントのおすすめが採用されます。1〜4のキーで進め方を選べます。

回答がない場合は、10分後におすすめで続行するか（分数は0〜1,440の整数で、0は待ち続ける）、返事を待つかを選べます。**回答しない場合**で両方を選べます。カードにはカウントダウンが表示され（「9分後におすすめで続行します」）、**私の返事を待つ**を押すとタイマーが止まります。ユーザーだけが確認できるチェックや、ユーザーだけが提供できるものについては、常に返事を待ちます。

### いつでも操作する

ゴールは、いつでも操作できます。

- いつものとおり**エージェントにメッセージを送る**と、そのメッセージが優先され、そこからラウンドが続きます。
- バーの**一時停止**と**再開**。実行中のターンは最後まで進み、再開するまで何も送られません。**停止**でゴールを終了します（下記参照）。ラウンドの途中でエージェントを止めた場合は、**再開**すると、それまでの作業内容がチェックされます。
- バーの⋯メニューの**ルールを追加…**で、今後のすべてのラウンドに適用する内容を固定できます（「新しい依存関係を追加しない」）。レビュアーは各ラウンドをユーザーのルールに照らしてチェックし、ルールに違反したラウンドは取り消されます。ルールは**あなたから**の下に表示され、それぞれの×で削除できます。
- 同じメニューの**チェックを変更…**で、実行中にチェック、パス、上限を編集できます。追加または変更したチェックは、改めて測定されます。上限の変更はすぐに反映されます。チェックやパスの変更は、ラウンドの実行中なら、そのラウンドが開始時のチェックで判定されるまで待ちます（バーに「チェックの変更は、このラウンドの後に反映されます。」と表示されます）。それ以外の場合は、次のラウンドから反映されます。
- ラウンドへの**ユーザーの判断**は、セッションがワークツリーで作業していて、ゴールがラウンドの途中でないときに使えます（一時停止するか、待ってください）。次の場合は、何が妨げているかを示す文とともに拒否されます。このセッションのエージェントが作業中（「このセッションのエージェントが作業中です。ターンが終わるまで待ってから、もう一度お試しください。」）、別のセッションがフォルダで作業中、ゴールが前回ファイルを残して以降にフォルダでコミットが作られた場合（先に専用のブランチに移してください）、ゴールが前回ファイルを残して以降にゴール外でファイルが変更された場合です。最後の場合は、メッセージにそのファイル名（最大5件）と、ワークツリーの最上位フォルダで実行するコマンドが示されます。これらのコマンドは、それらのファイルへのユーザーの変更をスタッシュに退避し、ゴール自身のバージョンを戻します（`git stash push --include-untracked -- <files>`、続いて `git restore --source=<checkpoint> --worktree -- <files>`。10件を超える場合はフォルダ全体に同じことを行います）。そのため、ユーザー自身の変更が失われることはありません。ラウンドの実行中に一時停止したゴールでは、そのラウンドのまだチェックされていない作業がフォルダに残っています。その場合はメッセージがそう伝え、**再開**するとアプリがまずそのラウンドをチェックします。
  - 取り消されたラウンドの**それでも保持…**：そのファイルを残し、最良のラウンドにします。目標を満たしていない測定チェックごとに、目標を維持するか、そのラウンドが達した値に変更するかを選び、理由を入力できます。
  - 残したラウンドの**元に戻す**：ファイルをその1つ前に残したラウンドの状態に戻し、試した内容は二度と試されません。
  - **ここから別の方法で**：そのラウンドのファイルを残し、次のラウンドではそこから別の方法を取ります。代わりに試す内容を入力することもできます。

### 停止するとき、さらに追加するとき

ゴールが自動で停止するのは、達成されたとき、**停止**を押したとき、上限（ラウンド数、費用、時間）に達したときです。次のような場合も、理由が表示されて一時停止します。エージェントを止めた、ターンが失敗した、アプリがファイルを保存できない、ラウンドのファイルを元に戻す処理が完了しなかった（上記のとおり）、チェックを実行できない、セッションが作業を続けたためにラウンドをチェックできなかった、メッセージを送信できない、アプリの再起動でエージェントのターンが2回目に途中で終了した（1回目は、アプリがその旨を伝えてラウンドのメッセージを再送します）、ループのメッセージが送られる途中でアプリが再起動した（何も開始されないまま2分たつと、アプリはメッセージを一度だけ再送し、それでも駄目なら一時停止してその旨を伝えます）、またはエージェントがプランの使用量上限で止まり、アプリが自動では続行しない場合です。セッションのキューが保留中の場合は、ゴールがそこで**再開**を押すよう求めます。アプリの再起動後は、ゴールは待たずにすぐ現状を確認します。その後、カードにレポートが表示されます：**ゴール達成**、**上限に達して停止**、または**ユーザーが停止**です。ラウンド数、費用、時間、要約、各チェックの開始時、現在、必要な値を示す表（ゴールの実行中に追加または変更したチェックは、開始時が「—」と表示され、最初に測定された後のラウンドがタイトルに表示されます）、そして最終レビューの理由が含まれます。**変更を見る**でセッションの変更を開きます。**閉じる**でレポートを消し、新しいゴールを設定できます。

上限に達して停止したゴールには**追加する…**が表示されます。使い切ったもの（ラウンド数、費用、時間）を引き上げて**続ける**を押すと、どのラウンドの後とも同じように、ファイルの現状から続行します。それでも上限に達する場合は、ダイアログにゴールがこれまでに使った量が表示され（「4ラウンド実行しました。それより多く設定してください。」、費用と時間も同様）、何も変更されません。上限に達しても、何も元に戻されません。費用や時間の上限で途中で止まったラウンドは、エージェントが残したままフォルダに残ります。それは独立したラウンドとして記録され（**そのまま**、「上限で途中停止しました」）、そのファイルとともに保存されます。レポートには「ラウンド4は途中で停止し、その作業はフォルダに残っています。ラウンド3の**それでも保持…**で、ファイルが最良のラウンドの状態に戻ります。」と表示されます。**追加する…**は、ファイルの現状から続行します。達成されたゴールやユーザーが停止したゴールは、そのまま終了です。

通知：ゴールの実行中は、ラウンドごとの「完了」通知の代わりに、チェックの準備ができたとき、チェックを実行できなかったとき、ユーザーに質問または対応が必要なとき、一時停止したとき、上限で停止したとき、達成されたとき（「目標達成：…」）に通知が届きます。ユーザーの返事を待っている間は、「完了」通知は保留されません。[各通知の内容](/guide/inbox#what-each-notification-says)を参照してください。

### Claude CodeやCodexで入力する /goal

Claude CodeまたはCodexのチャットで `/goal` に続けて条件を入力すると、そのプログラム独自の、よりシンプルなゴールになります。プログラムがゴールを達成したと判断するまで続行します（Claude Codeは各ターンの後にチェックし、Codexは自分で判断します）。合意したチェック、ラウンド、取り消しはなく、メッセージ欄の上の従来の小さなバーに、**一時停止**と**再開**（Codex）、**クリア**とともに表示されます。セッションのメニューの**ゴールを設定**はアプリ独自のゴールで、すべてのエージェントで使えます。Customセッションや他のエージェントでは、`/goal` はただのテキストです。1つのセッションに両方を設定することはできません。プログラム独自のゴールが設定されている間は**ゴールを設定**が拒否され、アプリのゴールの実行中に入力した `/goal` は、通常のメッセージと同様にプログラムに送られ、アプリは何も反応しません。

## セッションをフォークする

フォークとは、この会話を引き継いだうえで別の方法を試す新しいセッションです。元のセッションはそのまま残ります。

1. セッションのメニュー（⋯）→ **フォーク** を選びます。または、返信の下にある **この返信からフォーク** を押すと、そこまでの会話だけを引き継げます（Claude Codeではどの返信でも可能です。CodexとCustomでは、完了したターンの最後の返信が対象です）。
2. フォークで行いたいことを書きます（「代わりにどんな方法を試しますか？」）。
3. **フォーク** を押します（またはCtrl+Enter）。

フォークが開き、タイトルは「… · fork」となり、エージェント、モデル、思考レベル、権限、アカウントは元のセッションと同じです。先頭には「Forked from …」という行と **開く** が表示されます（Codexのフォークには、それ以降の内容だけが表示されます。それ以前の会話は元のセッションにあります）。フォークは、Claude Code、Codex、Customで利用できます。別のアプリで開いているセッションでは利用できません。会話が圧縮される前のClaude Codeの返信もフォークできます。その場合、フォークは、圧縮される前の状態のまま、その返信までの会話全体を引き継いで始まります。

## ここから編集

自分のメッセージの時点に戻って、別の内容で送り直せます。

1. メッセージの下にある **ここから編集** を押します。
2. テキストを変更します。
3. それ以降のエージェントによる変更も取り消したい場合は、**このメッセージの前の状態にファイルを戻す** にチェックを入れます。
4. **ここから送信**（Enter）を押します。やめる場合は **キャンセル**（Esc）を押します。

会話は、そのメッセージの直前までを含むコピーで続きます。コピーはこのセッションのタイトルを引き継ぎ、このセッションはアーカイブされます。ファイルを元に戻せるのは、Claude Code（このアプリから送信したメッセージごとの独自のチェックポイントを使用）、Custom（Custom自身の編集で変更されたファイルが対象で、コマンドによる変更は戻りません）、そしてワークツリー内のすべてのセッション（メッセージを送信するたびにスナップショットが作成されます）です。Codexのセッションでファイルを戻せるのは、ワークツリー内の場合のみです。ターンが実行中の場合は、先にエージェントを停止してください。セッションの[ゴール](#give-the-session-a-goal)がファイルのチェック中、またはファイルを戻している間は、ファイルを戻す操作は受け付けられません（「このセッションのゴールは今ファイルをチェックしています：完了するまで待つか、先にゴールを一時停止してください」）。なお、セッションが置き換えられると、ゴール自体は停止します。「ここから編集」は、Claude Code、Codex、Customで利用できます。

## 別のエージェントで続ける

会話を別のエージェントに引き継いで、そこで作業を続けます。

1. セッションのメニュー（⋯）→ **Codexで続ける**（または **Claude Codeで続ける**、Customにモデルが設定されている場合は **Custom Agentで続ける**）を選びます。
2. メッセージ欄の上に、次のメッセージがそちらに送られることを示す案内が表示されます。モデル、思考レベル、権限の選択は、新しいエージェントに適用されます。キャンセルするには ×（「ここに残る」）を押します。
3. メッセージを書くか、そのまま送信して続けます。

同じフォルダで新しいセッションが開き、これまでの会話が引き継がれます。内容は、最初の依頼、約15,000トークンに収まる直近のメッセージ、変更されたファイルです。新しいエージェントには会話全体の保管場所が伝えられるため、省略された部分も読み取れます。最初のメッセージには「Continued from Claude Code」と表示され、**そのセッションを開く** と、引き継がれたメッセージを表示するボタンがあります。元のセッションには「This conversation continued in Codex」と表示され、**開く** があります。この機能は、Claude CodeとCodexのセッションから使えます。

## 会話を圧縮

圧縮すると、これまでの履歴が要約に置き換えられ、この先のためにモデルのコンテキストの空きが増えます。セッションのメニュー（⋯）→ **その他** → **会話を圧縮** を選ぶか、メッセージ欄のコンテキストメーターをクリックし、**圧縮** で確定します。Claude CodeとCodexで、ターンの合間に使えます。Customは、長い会話を自動で要約します。

## 名前の変更、ピン留め、スヌーズ、完了、アーカイブ、削除

これらの操作の多くは、セッションのメニュー（⋯）と、サイドバーにあるその行のメニューにあります。行にポインターを合わせて末尾の **⋯** をクリックするか、右クリックします（スマートフォンでは **⋯** をタップします）。

- **名前を変更**：新しいタイトルを入力します（200文字まで）。Enterで保存、Escでキャンセルです。ヘッダーまたはサイドバーのタイトルをダブルクリックするか、選択した行でF2を押しても同じ操作ができます。
- **フォルダ名を変更**（サイドバーで、プロジェクトに属さないセッションの場合）：セッションが作業するフォルダに、独自の名前を付けられます。この名前は、サイドバー、セッションの行、フォルダのメニューに、すべてのデバイスで表示されます。ディスク上のフォルダ名は変わりません。空にすると、フォルダ本来の名前になります。
- **先頭にピン留め** / **ピン留めを外す**：ピン留めしたセッションは **ピン留め** グループに残り、ドラッグして並べた順に表示されます。下のグループ（プロジェクトやフォルダ、今日、昨日など）からセッションをピン留めの位置にドラッグすることもできます。まだ何もピン留めされていない場合は、「Drop here to pin」にドラッグします。
- **スヌーズ**：セッションを下部の **スヌーズ中** グループに隠し、**1時間**、**3時間**、**今夜**（午後5時前の場合）、**明日の朝**、**翌週**（月曜の朝）、または **日時を選択** で指定した時刻まで表示しません。時刻になると通知とともに自動で戻ります。ユーザーの対応が必要になった場合は、それより早く戻ります。**スヌーズを解除** を選ぶと、すぐに戻ります。
- **完了にする：いったん終了**：作業が一段落したセッション向けです。エージェントが停止し（ターンの実行中は選べません）、セッションは既読になります。履歴とワークツリーは残ります。ワークツリー内のセッションでは、ワークツリーのダイアログが開き、取り除くことができます。
- **アーカイブ** / **アーカイブを解除**：セッションを一覧から外します。何も削除されません。アーカイブしたセッションは、検索ボックス（Ctrl+K）で見つけられ、**アーカイブ済み** と表示されます。開いて、メニューの **アーカイブを解除** を選びます。
- **セッションを削除**：確認すると、セッションの履歴がディスクから削除されます。そのため、エージェント自身のコマンドラインやVS Codeからも消えます。この操作は元に戻せません。サイドバーの行のメニューにある **削除** も同じ動作です。

削除するまで、アプリはすべてのセッションを保持します。エージェント自身のプログラムが会話を削除した場合（Claude Codeは、設定を変えなければ30日後に削除します）でも、セッションは一覧に戻り、開けます。1年間誰も使っていないセッションは自動的に削除されます。ただし、ピン留めしている場合や、設定 → 一般で変更している場合は対象外です（[使われていないセッションを削除](/guide/app#delete-inactive-sessions)を参照）。

ピン留め、ピン留めの解除、アーカイブ、アーカイブの解除、スヌーズを行うと、**元に戻す** 付きの通知が表示されます。また、8秒以内ならCtrl+Zで取り消せます。

## 閲覧専用リンクを共有

セッションのメニュー（⋯）→ **閲覧専用リンクを共有** を選ぶと、パスワードなしで誰でも開けるリンクが作成されます（[機密セッション](#keep-a-session-confidential)では使えません）。リンクを開いた人は、会話をリアルタイムで見られます（メッセージ、ステップ名、ファイルの変更、エージェントが表示したページ）。コマンドの出力やエージェントの思考は見られず、入力や変更もできません。リンクの有効期間（**1日**、**1週間**、**1か月**、**オフにするまで**）を選び、**リンクを作成** を押します。リンクが表示されるのは1回だけです。同じダイアログに、現在有効なリンク、それぞれが開かれた回数が一覧表示され、リンクをオフにすることもできます。[スマートフォン、他のマシン、共有](/guide/devices)を参照してください。

## 会話をエクスポート

セッションのメニュー（⋯）→ **エクスポート** で、会話をチャットの外に取り出せます。

- **Markdownとしてエクスポート** は、セッションのタイトルを名前にしたMarkdownファイルとしてダウンロードします。保存したり、送ったり、任意のメモアプリで開いたりできます。
- **Markdownとしてコピー** は、同じテキストをクリップボードにコピーします。メモ、メール、他のアプリに貼り付けられます。
- **ドキュメントとして保存** は、会話からドキュメントを作成し、セッションのプロジェクトに保存します（プロジェクトの **ファイル** に表示されます。プロジェクトがない場合は、この会話に紐づいて残ります）。そこで読んだり、編集したり、コメントを付けたり、印刷したり、WordやPDFとしてエクスポートしたりできます。準備ができるとメッセージが表示され、**開く** でそのドキュメントに移動できます。

含まれる内容は、タイトルと日付、続いて自分のメッセージとエージェントの返信が、時刻付きで順番に並びます。ターンのステップは省かれ、代わりに「Worked for 2 min · 5 steps」のような1行が入ります。エージェントが渡したファイルは名前で一覧表示されます。回答カードは読めるテキストになり、表は表のまま残ります（比較、データテーブル、グラフの数値）。図はMermaidコードのまま、数式はエージェントが書いたLaTeXのままです。ドキュメントには、メッセージに添付した画像と、エージェントが渡した画像も含まれます。

[機密セッション](#keep-a-session-confidential)もエクスポートできます。そのドキュメントも、ほかの作業内容と同じようにこのコンピューターにだけ保存されます。Web上の画像は、取得されずリンクのままになります。ターミナルからは `hydor sessions export` で同じことができます（[ターミナルでHydorを使う](/guide/terminal)）。

## ワークツリーで作業する

ワークツリーとは、新しいブランチ上にあるリポジトリのファイルの別コピーです。エージェントが手元のコピーに触れずに変更でき、複数のエージェントが1つのリポジトリで同時に作業できます。

- **作成する**：スタートページで **フォルダ** を開き、**New worktree from …** をオンにします（フォルダはgitリポジトリ内にある必要があります）。アプリは、チェックアウト中のブランチから、`agent/` に作業内容を表す数語を付けた名前のブランチを作り、アプリのデータフォルダ内にそのためのフォルダを作成します。このスイッチの状態は次回も保持されます。
- **スナップショット**：ワークツリーでは、メッセージを送信するたびにアプリがファイルのスナップショットを保存するので、[ここから編集](#edit-from-here)でファイルを元に戻せます。
- **確認する**：セッションのメニュー（⋯）→ **フォルダとコード** → **Worktree: agent/…** を選ぶと、ブランチとその元のブランチ、フォルダ、コミットの先行・遅れの数、未コミットの変更が表示されます。ここに **変更を確認** と **Gitで開く** があります。
- 作業が終わったら **取り除く**：同じダイアログの **ワークツリーを取り除く** を使います。フォルダは削除され、セッションの履歴は残ります。ブランチは残るので、コミット済みの内容は失われません。ただし **Delete branch … too** にチェックを入れた場合は、ブランチも削除されます（新しい内容がないブランチは、チェックなしでも削除されます）。未コミットの変更がある場合は、先に **Discard the … uncommitted changes** にチェックを入れてください。エージェントが実行中だった場合は停止し、同じワークツリーを共有するフォークや編集も、そのワークツリーを失います。

## プルリクエストを開く

セッションのブランチから、セッションのメニュー（⋯）→ **フォルダとコード** → **プルリクエストを開く** を選ぶと、GitHubまたはGiteaでプルリクエストを開けます。**自動で書く** は、コミットと差分からタイトルと説明の下書きを作成します。ボックスをオンにすると、先に未コミットの変更をコミットできます。**下書き** はプルリクエストをドラフトとして扱い、ブランチは **プルリクエストを開く** を押したときにプッシュされます。[設定 → ソース管理](/settings?s=scm)にアカウントが必要です。**既存のプルリクエストをリンク…** で、別の場所で開いたプルリクエストをリンクできます。

リンクすると、その状態とチェックがバッジとしてサイドバーとヘッダーに表示され、数分ごとに更新されます。マージされたときやチェックが終わったときには通知が出ます。同じメニュー項目は **Pull request #12** という名前になり、**GitHubで開く**（またはGitea）、**変更をレビュー**、**今すぐ確認**、**リンクを解除** があります。サブメニューの **変更をレビュー** では、ブランチの変更内容をファイルごとに確認できます。[システム：ファイル、Git、ターミナル、プレビュー](/guide/files-git)を参照してください。

## 使用量の上限でセッションが止まったとき

Claude CodeまたはCodexのプランの使用量を使い切ると、メッセージ欄の上にバナーが表示され、どのアカウントの、どの上限に達したか、そしていつリセットされるかが示されます。そのエージェントのアカウントが1つの場合は「You've hit the Claude Code usage limit」、複数あってどれも使用量が残っていない場合は「All your Claude Code accounts have hit their usage limit」、ほかに使用量が残っているアカウントがある場合は、そのアカウント名で「Work has hit its usage limit」と表示されます。

そのエージェントの別のアカウントに使用量が残っている場合、**上限時にアカウントを切り替え** がオンならバナーは表示されません。セッションはそのアカウントに移って続行されます（新しいセッションもそこから始まります）。オフの場合は、バナーにそのアカウントの名前が表示され、**オンにする** が表示されます。

- **リセット時に再開** は、上限のリセットから1分後に、「Continue where you left off.」というメッセージでセッションを自動的に続けます。その後、バナーに再開される時刻と **キャンセル** が表示されます。
- **リセットを使う**：アカウントに上限のリセットがある場合、バナーにその数が表示され、これで1つをすぐに使えます。
- 設定 → アプリ → 一般の[使用量の上限後に再開](/settings?s=general&find=Resume%20after%20usage%20limits)は、上限で止まったすべてのセッションにこれを適用します。オンにすると、セッション内に警告は表示されません。代わりにメッセージ欄の上の1行に、どのアカウントの、どの上限に達したか、いつ続行されるかが表示されます（バナーと同様です）（「All your Claude Code accounts have hit their usage limit」に続いて「Current session (5 h) · Continues by itself in 3 h 15 min.」）。リセットがある場合は **リセットを使う** と **キャンセル** も表示されます。自分で **停止** したセッションは、自動では続行されません。

再開の時刻は上限に合わせて変わります。リセットが前後したり、使用量が早く戻ったりした場合は、そのタイミングでセッションが続行されます。[使用量、上限、コスト](/guide/usage)を参照してください。

## VS Codeやターミナルで実行中のセッション

このコンピューター上のClaude CodeとCodexのセッションはすべて一覧に表示されます。VS Code、ターミナル、Claudeのデスクトップアプリで実行しているものも含まれます。そちらで実行中の間は、一覧に「Working in VS Code」「Needs you in terminal」「Open in VS Code」（グレーの点）と表示され、作業の様子を読んで確認できます。そちらでユーザーの対応を待っている場合、アプリが通知するのは、1分後もまだ待っているときだけです。

- **Claude Codeのセッションを引き継ぐ**：ヘッダーの **ここで続ける** を押すか、そのままメッセージを送信します（「Open in VS Code — sending moves it here」）。アプリは先に確認します。そのアプリでのセッションを終了して、実行中の処理を止め、全履歴を引き継いでここで再開します。そのアプリではセッションが終了した状態で表示されますが、後でそちらで再び開けます。
- **Codexのセッション**は、他の場所で開いている場合、ここでは読み取り専用です。1つのCodexプロセスがそのスレッドすべてを扱っているためです。そちらで続けるか、そちらで閉じてからここで再開してください。
- 別のアプリでセッションを開いている間は、フォークは使えません。

## サブエージェント

エージェントは、作業の一部をサブエージェントに任せ、その結果を受け取れます。サブエージェントには2種類あり、アプリがどちらかを表示します。

- **Hydorサブエージェント**は、Hydorが起動する独立したセッションで、エージェントとモデルを自由に選べます。親の会話のサブエージェントカードに1行で表示され、サイドバーでは親の下に並び、開いて話しかけることもできます。コストと、親の支出上限のうちの割り当て分が個別にあり、返信はメッセージとして親に戻ります。
- **Claude Codeサブエージェント**（Codexでは「Codexサブエージェント」：セッション自身のプログラムの名前）は、そのプログラムがセッション内で、作業の短い一部のために実行するものです。表示や開き方はHydorサブエージェントと同じで、会話内のカードに1行、サイドバーと受信トレイに行があり、会話全体を見られる専用ページもあります。ただし話しかけることはできず（リード役はできます）、使った分はリードの使用分として数えられ、支出上限の割り当てもありません。

サイドバーでは、サブエージェントは作業中またはユーザーの対応待ちの間、親の下に折りたたまれて表示されます。Hydorのものとプログラム自身のものはまとめて1行になります（「サブエージェント3件・対応待ち1件」「サブエージェント2件」）。この行をクリックすると、それぞれの行が表示されます。終了したものは、見ている場合を除いてサイドバーから消え、そのうちの1つを見ている間は行が開いたままになります。スウォームのメンバーは「スウォームメンバー」、キャンペーンのメンバーは「キャンペーンメンバー」と表示されます。親の会話では、1つのターンで起動されたサブエージェントが、そのターンの下に1枚のカードとしてまとまって表示されます。Hydorサブエージェントは1枚に、プログラム自身のもの（Claude CodeまたはCodex）は別の1枚になります。最上部の行には、数と種類、全員に共通する内容（「Claude Codeサブエージェント6件・Sonnet 5.5」「Hydorサブエージェント3件・Claude Code・Sonnet 5.5」、ディープリサーチでは「リサーチャー4件」）、そして状況（「作業中5件・完了1件」のほか「対応待ち1件」「停止1件」「失敗1件」）が表示されます。この行をクリックするとカードを折りたたんだり開いたりできます。いずれかが作業中または対応待ちの間は開いており、すべて終了すると1行に折りたたまれます。

その下には、サブエージェントごとに1行が表示されます。状態を表す色の点（作業中は青でゆっくり点滅、対応待ちは琥珀色、完了は緑、停止はグレー、失敗は赤）、タイトル、広い画面では他と異なる情報（種類やモデル、担当として動いている自分のエージェント、ティア）、そして状況（これまでの作業時間、「対応待ち」、終了時刻（「3分前」）、「停止」、「失敗」）です。Hydorサブエージェントの行にはコストも表示され、ティアを上げたものにカーソルを合わせると、最初のティアと理由が「ティアを上げた元」として表示されます。行をクリックすると、そのサブエージェントが開きます。ほかが作業中の間は、終了したものが「終了4件：」とタイトルの1行にまとまり、クリックすると中身を確認できます。失敗したものは独立した行のまま残ります。作業中のものが6件を超えると5件が表示され、**さらに3件を表示**で残りを表示できます。

1つのターンで起動されたサブエージェントが1件だけの場合は、1行のカードで表示されます。状態の点が付いたアイコン、タイトル、種類（「Claude Codeサブエージェント・Explore・Sonnet 5.5」や「Hydorサブエージェント・Claude Code・Sonnet 5.5」。担当のエージェントとティアがあればそれも）、そして状況が並びます。

停止するには、その行にカーソルを合わせる（またはTabキーで移動する）と、時間の代わりに**停止**が表示されます。タッチ画面では小さな停止ボタンが常に表示されます。Claude Codeサブエージェントは先に確認があり（「このサブエージェントを停止しますか？」）、Hydorサブエージェントはすぐに停止します。Codexサブエージェントは、ここから1件ずつ停止することはできません。カードの**⋯**メニューには**サブエージェント5件を停止**（停止できる数が入ります）があり、確認なしですべて停止します。サブエージェントを起動した呼び出しは、ターンの折りたたまれた作業の中の1ステップとして残ります。

バックグラウンドで動いていたサブエージェントが戻ると、親の会話に1行が表示されます。「返信元」とタイトル、または「…は停止しました」、「…はエラーで停止しました」と、書かれた内容の冒頭が表示されます。クリックすると返信を読め、**セッションを開く**でそのセッションに移動できます。Codexサブエージェントの返信は、行を開いたときに、その会話から取得されます。親がまだ作業中に届いた返信は、前後のステップの間にそのまま表示されます。

Hydorサブエージェントの中では、メッセージ欄の上のバーに「サブエージェント：」と親のタイトル（「返信は親に戻ります」）が表示され、**親を開く**があります。Claude CodeまたはCodexのサブエージェントもセッションとして開きますが、閲覧専用です。与えられたタスク、ステップ、返信が、作業中はリアルタイムで表示され、メッセージ欄も**再開**もセッションメニューもありません。メッセージ欄の代わりに、「Claude Codeサブエージェントの親：」と親のタイトル（「返信は親に戻ります」）を示すバーが表示され、**親を開く**があります。Claude Codeサブエージェントが作業中は、ヘッダーの**停止**で停止でき、先に確認があります。メッセージの送信、再開、フォーク、引き継ぎ、削除はできません。そのプログラムが親のセッション内で実行しているため、親に話しかけてください。

親自身のターンが終わっても、サブエージェントがまだ動いている間は、親は終了していません。点は青く脈動し続け、メッセージ欄の停止ボタンのリングも回り続け、ステータスは「作業中・サブエージェント2件実行中」と表示され、「完了」マークは付かず、アクティブに残り、メッセージも送れます。これはClaude CodeセッションにもCodexセッションにも当てはまります。Hydorサブエージェントも、自身のターンが終わった後に、起動したサブエージェントやバックグラウンドタスク（コマンド、モニター）が動いている間は実行中として数えられるため、その親は完了ではなく作業中と表示されます。親の支出上限はHydorサブエージェントも対象にし、Claude CodeまたはCodexのサブエージェントが使った分はすでに親の使用分です。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research)をご覧ください。

メッセージ欄の上の1行には、セッションが起動したすべてのもの、つまりサブエージェントとバックグラウンドタスク（コマンド、モニター、ワークフロー）がまとめて表示されます。「サブエージェント2件とバックグラウンドタスク1件を実行中」と表示され、Hydorサブエージェントが対応を待っているときは琥珀色で「対応待ち1件」が付きます。何も動いていないときは「サブエージェント3件・バックグラウンドタスク2件・すべて完了」と表示されます。セッションを開くたびに折りたたまれた状態になります。クリックするとそれぞれが一覧表示されます。対応待ちが先頭、次に実行中、最後に終了したものが新しい順に並び、5件ほどを超えると内部でスクロールします。どの行も同じ形式で、状態の点が付いたアイコン、タイトル、種類（「Hydorサブエージェント・Claude Code・Sonnet 5.5」「Claude Codeサブエージェント・Explore・Haiku 5.5」「コマンド」「モニター」「ワークフロー」）、状況（「作業中・2分10秒」「対応待ち」「完了・3分前」「停止」「失敗」）、Hydorサブエージェントのコスト（プログラムのサブエージェントには表示されません。使った分は親の使用分です）、**開く**、そして実行中は停止ボタン（円の中の四角）が表示されます。種類にカーソルを合わせると、誰が実行しているかが表示されます。「Hydorが独立したセッションとして起動しました。開くと様子を見たり話しかけたりできます」、または「Claude Codeがこのセッション内で実行しています。開くと様子を見られます」です。**開く**を押すと、Hydorサブエージェント、またはClaude CodeやCodexのサブエージェントのセッションに移動します。コマンド、モニター、ワークフローは、ページの右側にパネルで開き（スマートフォンでは画面全体）、タイトル、種類、状態、実行中は**停止**、その下に出力が表示されます。出力は2秒ごとに更新され、上にスクロールしない限り最新の行を表示し続けます。サブエージェントの停止ボタンは「このサブエージェントを停止」、タスクのものは「このタスクを停止」と表示されます。行の右端の**すべて停止**は、メッセージ欄の横の停止ボタンと同様に、実行中のものをすべて停止します。スウォームやキャンペーンのメンバーはここには一覧表示されず、そのボードに表示されます。終了したタスクは、エージェントのプログラムが停止するまで一覧に残ります。VS Codeやターミナルで開いているセッションでは、タスクは一覧表示されますが、停止はできません。

1つのセッションでHydorサブエージェントを同時にいくつ実行するかは、[設定 → 機能 → サブエージェント](/settings?s=children)で決めます。この設定はHydorサブエージェント用です。Claude CodeとCodex自身のサブエージェントは、それぞれのセッション内で動くためです。設定 → モデル → ティアで[サブエージェントで主導](/settings?s=models&find=Lead%20with%20subagents)をオンにすると、セッションのメインエージェントが計画を立て、明確な部分をより低いティアのサブエージェントに任せ、その作業を確認します。

## セッションメニューのすべての項目

セッションの右上にある⋯ボタンで、そのメニューが開きます。項目によっては、該当する場合にのみ表示されます。[機密セッション](#keep-a-session-confidential)のメニューには、**閲覧専用リンクを共有**、**プルリクエストを開く**、**ブラウザを開く**、**接続済みアカウント**、**自動化にする**、**アプリとして保存**がなく、メモリはオフのままです。

- **名前を変更**：タイトルをその場で編集します。
- **先頭にピン留め** / **ピン留めを外す**。
- **スヌーズ**（時刻のサブメニュー）。スヌーズ中は**スヌーズを解除（…に戻る）**と表示されます。
- **完了にする：いったん終了**：エージェントを停止し、セッションを既読にします（ターンの実行中は使えません）。
- **フォーク**：この会話から新しいセッションを作ります（Claude Code、Codex、Custom）。
- **Codexで続ける**、**Claude Codeで続ける**、**Custom Agentで続ける**：会話を別のエージェントに引き継ぎます（Claude CodeとCodexから）。
- **ゴールを設定**：エージェントとユーザーでチェックを決め、それが満たされるまでラウンドを重ねて作業します。すべてのエージェントで使え、ゴールが未設定のときに表示されます。[セッションにゴールを設定する](#give-the-session-a-goal)をご覧ください。
- **セカンドオピニオン**：別の会社のモデルが、ターンの作業を依頼内容と照らして確認し、その結果をそのターンの下に表示します。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research)をご覧ください。
- **閲覧専用リンクを共有**。
- **エクスポート**（サブメニュー）：**Markdownとしてエクスポート**、**Markdownとしてコピー**、**ドキュメントとして保存**。[会話をエクスポートする](#export-a-conversation)をご覧ください。
- **フォルダとコード**（サブメニュー。フォルダのあるセッション向け）：
  - **変更をレビュー**：ブランチの変更内容をファイルごとに表示します。
  - **プルリクエストを開く**。すでにある場合は**プルリクエスト #12**と表示されます。
  - **ワークツリー：agent/…**：ワークツリーのダイアログです（ワークツリー内のセッション）。
  - **フォルダを開く**：セッションのフォルダでファイルを開きます。
  - **Finderで表示**、**エクスプローラーで表示**、**フォルダで表示**：デスクトップアプリで、セッションのフォルダを選択した状態でシステムのファイルマネージャーを開きます（[ファイルとフォルダを扱う](/guide/files-git#work-with-files-and-folders)をご覧ください）。
  - **ここでターミナルを開く**：フォルダで新しいターミナルを開きます（コンピューターでは下部のパネル、スマートフォンではターミナルページ）。
- **セッション設定**（サブメニュー）：
  - **メモリ**：横に**オン**または**オフ**が表示され、このセッションのメモリをオンまたはオフにします（設定でメモリがオフの場合は「すべてオフ」）。[メモリ](/guide/memory)をご覧ください。
  - **支出上限**：横に上限が表示され、設定、変更、引き上げができます。[使用量、上限、コスト](/guide/usage)をご覧ください。
  - **接続済みアカウント**：接続済みアカウントごとに、このセッションだけオンまたはオフにします。[接続済みアプリ、キー、ツール](/guide/connections)をご覧ください。
  - **スウォーム**：横に**オフ**、**オン**または**キャンペーン**が表示され、次のメッセージからスウォームまたはキャンペーンをオンまたはオフにするダイアログを開きます。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research#set-a-swarm-on-a-hard-problem)をご覧ください。
  - **ディープリサーチ**：横に**オフ**または検索回数が表示され、次のメッセージからディープリサーチをオンにしたり、オフにしたり、変更したりするダイアログを開きます。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research#turn-it-on)をご覧ください。（スウォームとディープリサーチは、機密セッションや、別のセッションが起動したセッションには表示されません。）
  - **エージェント**：横に名前が表示され、そのエージェントのページを開きます（エージェントのあるセッション）。切り替えはメッセージ欄で行います。
- **その他**（サブメニュー）：
  - **ブラウザを開く** / **ブラウザを表示**：このセッション用のエージェントのブラウザです。様子を見たり、操作を引き継いだりできます。[検索とブラウザ](/guide/web)をご覧ください。
  - **自動化にする**：補助モデルがセッションを読み、そこからスケジュールタスクの下書きを作ります。内容を自由に変更し、テスト実行で試してから保存します。[スケジュールタスク](/guide/tasks)をご覧ください。
  - **アプリとして保存**：このセッションから新しいアプリを作り始めます。[アプリ](/guide/apps)をご覧ください。
  - **会話を圧縮**（Claude CodeとCodex）。
  - **CLIの再開コマンドをコピー**：このセッションをターミナルで続けるためのコマンドです。
  - **エージェントのプロセスを停止**（エージェントの実行中で、ターンが進行していないとき）。
- **アーカイブ** / **アーカイブを解除**。
- **セッションを削除**：確認後、履歴をディスクから削除します。
