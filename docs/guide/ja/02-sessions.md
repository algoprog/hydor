# セッション

セッションとは、1つのフォルダでエージェントと交わす1回の会話のことです。やってほしいことを伝えるとエージェントが作業を進め、その様子を見守りながら、エージェントが行おうとする操作を承認したり、方向を調整したりできます。このトピックでは、セッションに関するすべてを取り上げます。開始ページとそのオプション、エージェントの作業中に表示される内容、ターン途中でのメッセージ送信、そしてフォークやゴール、ワークツリー、共有まで、セッションのメニューにあるすべての項目です。

![作業中のセッション：エージェントのステップと返信、コマンドの実行を求めるカード](images/sessions.webp)

## セッションを始める

サイドバーの上部にある**新しいセッション**を押すと、スタートページが開きます。メッセージ欄にやってほしいことを書き、その下に並ぶ選択項目を確認して、Enterキーを押します（または**開始**を押します。スマートフォンでは丸い矢印を押します）。すぐにセッションのページが開き、送ったメッセージと、それに取りかかるエージェントが表示されます（**実行中**）。セッションを開始できなかった場合は、ページに理由が表示され、**スタートページに戻る**を押すと、メッセージと添付したファイルがメッセージ欄に戻ります。

アプリから応答が返る前に接続が切れた場合（スマートフォンがスリープした、ネットワークが切り替わったなど）は、ページに**再接続しています…**と表示されます。接続できるようになると、メッセージがどうなったかをアプリに問い合わせます。セッションが開始されていれば開き、同じセッションが2回開始されることはありません。約1分たってもアプリに接続できない場合は、ページに**アプリに接続できませんでした**と表示されます。**もう一度試す**を押すと、もう一度問い合わせます。

開始から少したつと、セッションにタイトルが付きます。依頼内容を表す短い言葉（「リスボン週末旅行」「決済テストの修正」など）で、補助モデル（[設定 → エージェント → モデル](/settings?s=models&find=Helper%20model)）が裏で書くため、会話には何も表示されません。タイトルは、サイドバー、セッションのヘッダー、検索ボックスに表示されます（サイドバーでは、メッセージの冒頭の代わりに、言葉が順に現れます）。Claude CodeとCodexにも、それぞれの一覧用に渡されます。タイトルが付くまでの間や、補助モデルが応答できない場合は、メッセージの冒頭がタイトルの代わりになります。**名前を変更**で自分で付けたタイトルが置き換えられることはありません。サイドバーには、送信した時点からセッションが一覧され、**アクティブ**の先頭に表示されます（**開始中**）。

メッセージ欄の下の行には、**実行環境**、**モデル**、**フォルダ**（または**プロジェクト**）、**エージェント**が並び、右端に**オプション**があります。スマートフォンでは、それぞれが画面の下からシートとして開きます。

### エージェントとモデルを選ぶ

**実行環境**には、使えるプログラムがすべて並びます。

- **Claude Code**：Anthropicのエージェントです。Claudeのプランまたは APIキーで使います。
- **Codex**：OpenAIのエージェントです。ChatGPTのプランまたはAPIキーで使います。
- **Custom**：アプリ独自のエージェントで、OpenRouter、Ollama、vLLMなど、どのモデルでも使えます。[Custom、アプリ独自のエージェント](/guide/custom)をご覧ください。
- ACPに対応した、追加済みのその他のエージェント（Gemini CLI、OpenCode、Qwen Code、Gooseなど）。名前の下にコマンドが表示されます。

下部の**Custom用モデル**は[設定 → モデル](/settings?s=models)を開き、**エージェントを追加・管理**は[設定 → その他のエージェント](/settings?s=agents)を開きます。[エージェント、アカウント、モデル](/guide/agents-models)をご覧ください。

**モデル**は**自動**になっています。この場合、セッションは最高ティアのモデルで始まり、メインのエージェントが切り分けやすい部分をより低いティアのサブエージェントに任せます。問題が難しすぎると分かった場合は、最大ティアのモデルに自分で切り替えることもあります（[ティア：仕事の種類ごとのモデル](/guide/agents-models#tiers-a-model-for-each-kind-of-job)をご覧ください）。その下のメニューには、選んだエージェント自身のモデルだけが並びます。エージェントのデフォルトには「デフォルト」と表示されます。古いバージョンのモデルは「古いモデル2件」の中にまとまっています。リストが長い場合は**モデルを検索**欄が表示されます（Enterキーで最初の一致を選びます）。Customには、設定 → モデルで追加したモデルが並びます。その他のACPエージェントには、前回の実行時に提示されたモデルが並び、チップは一度実行されてから表示されます。

### フォルダ、プロジェクト、新しいタスクフォルダを選ぶ

**フォルダ**チップは、エージェントが作業する場所を示します。メニュー（「作業するプロジェクトまたはフォルダ」）には**プロジェクトやフォルダを検索、またはパスを入力**欄があり、その下に2つの短いリストが並びます。各行には場所が表示されます。

- **プロジェクト**：プロジェクトが名前で並びます。最近作業した5件（と選択中のもの）が、それぞれのフォルダとともに表示されます。選ぶと、フォルダがプロジェクト自身のフォルダになり、そのエージェントとガイドラインがこのセッションに適用されます。チップは**プロジェクト**となり、プロジェクト名が表示されます。プロジェクトのグループも同様で、グループ内のすべてのプロジェクトが対象になります。見出しの右端の**新規**を押すと、プロジェクト（セッション、ファイル、メモリがひとまとまりになったもの）を作成して選択します。[プロジェクトとナレッジ](/guide/projects)と[エージェントガイドライン](/guide/guidelines)をご覧ください。
- **フォルダ**：使用中のフォルダと、最後に選んだ3つのフォルダが、それぞれが入っているフォルダとともに並びます。見出しの右端の**参照**を押すと、ホームフォルダ内のフォルダが一覧されます。
- **新しいタスクフォルダ**（「~/Hydorに新規作成」）：このタスク用の新しいフォルダです。名前は日付とメッセージ内の数語から付き（`2026-11-01-plan-trip-lisbon`など）、[タスクフォルダ](/settings?s=assistants&find=Task%20folders)（設定 → 機能 → 自分のエージェント）で別の場所を設定していなければ`~/Hydor`に作られます。

プロジェクト自身のフォルダはプロジェクトそのものです。メニューにはプロジェクトとしてのみ表示され、そのフォルダで始めたセッションは、スタートページでプロジェクトではなくフォルダを選んでいた場合でも、プロジェクトで作業します。

メニューは、チップの上か下の、広いほうに開き、スクロールせずに収まります。小さなウィンドウではフォルダ、次にプロジェクトの表示数が減り、プロジェクトの下の「ほか2件」のような行を押すと残りが表示されます。

欄に入力すると、さらに探せます。

- 名前を入力すると、一致するプロジェクトと、最近使ったフォルダ、使用中のフォルダ内、ホームフォルダ内の一致するフォルダが見つかります。プロジェクトのフォルダを名前で見つけた場合は、プロジェクトとして表示されます。
- パス（`~/code/`、またはホームフォルダからの`code/`）を入力すると、**参照**と同様に、そこにあるフォルダが一覧されます。欄の右端の矢印で1つ上のフォルダに移動し、×印またはEscキーでリストに戻ります。
- ↑ ↓とEnterキーで選びます。Tabキー、または行の右端の矢印で、その中のフォルダが一覧されます。

フォルダがgitリポジトリ内にある場合（新しいタスクフォルダを選んでいないとき）、メニューの最後にスイッチが表示されます。**mainから新しいワークツリー**（またはチェックアウト中のブランチ）で、「リポジトリのコピーに新しいブランチを作成」します。オンにすると、セッションは新しいブランチ上の専用のコピーで作業し、チップには「・新しいワークツリー」と表示されます。[ワークツリーで作業する](#work-in-a-worktree)をご覧ください。

セッションが新しいタスクフォルダで始まるかどうかは、既定ではエージェントによって決まります。多くのエージェントは、フォルダを選ばなければ新しいタスクフォルダで始まります。プログラマーは選んだフォルダで作業し、1つのプロジェクトに属するエージェントはそのプロジェクトで作業します。

### エージェントを選ぶ

**エージェント**は、セッションがどの役割で作業するかを決めます。**一般**（ほかを選ぶまでこれです。専用のエージェントを持つプロジェクトでは、そのエージェント）、**リサーチャー**、**ライター**、**プログラマー**、**チューター**、**プランナー**、**アナリスト**、**アプリビルダー**、または**自分用**の下にある自作のもの（どこでも使えるものと、選択中のプロジェクトのもの）から選びます。ポインタを合わせると、そのエージェントの役割と、使うプログラムとモデルが表示されます。選ぶと、そのエージェントが推奨するプログラム、モデル、権限（ティアで考えるエージェントの場合は、そのティアのモデル）が設定され、接続済みのアカウントがオンになることもあります。**エージェントを作成・変更**で[エージェントページ](/agents)が開きます。[エージェント](/guide/agents)をご覧ください。

### オプション：思考レベル、権限など

**オプション**には、そのほかの項目があります。チップには「オプション」と表示され、通常と異なる設定がある場合は、その内容（「高思考レベル・プラン・上限$5.00」など）が表示されます。コンピューターでは、メニューの最後に、メッセージ欄でShift+Tabキーを押すと権限が切り替わるという案内が表示されます。

- **思考レベル**：モデルがどれだけ深く考えるかです。**デフォルト**はモデル自身の設定を使い、その下にモデルが対応するレベルが並びます。**低**（高速で軽い推論）、**普通**（バランス型）、**高**（より深い推論）、**Xhigh**（さらに深い推論）、**最大**（最大限の推論）があり、モデルによっては**ミニマル**、**なし**、**Ultra**もあります。Customやその他のACPエージェント、レベルのないモデルでは表示されません。
- **権限**：事前に確認を取らずにエージェントができることです。モードはエージェントごとに異なります。[各権限モードの意味](#what-each-permissions-mode-means)をご覧ください。メッセージ欄でShift+Tabキーを押すと、次のモードに切り替わります。
- **アカウント**：[設定 → エージェント → アカウント](/settings?s=accounts&find=Accounts)で、Claude CodeまたはCodex用に別のアカウントを追加した場合のみ表示されます。**サインイン情報**はエージェント自身のアカウントです。別のアカウントを選ぶと、このセッションはそのアカウントで実行されます。**アカウントを管理**で設定が開きます。
- **機密**：錠前付きのスイッチです（「このコンピューター上のモデルのみ使用。外部には何も送信されません。」）。査読中の論文、患者データ、クライアントのコードなどに使います。**実行環境**は**Custom**に、**モデル**はここにインストールされている最良のモデルになります。[セッションを機密にする](#keep-a-session-confidential)をご覧ください。
- **メモリ**：設定でメモリがオンのときだけ表示されます。**オン**ではエージェントが記憶している内容を使い、追加もします。**このセッションではオフ**では何も覚えていない状態で始まり、このセッションの内容は何も残りません。[メモリ](/guide/memory)をご覧ください。
- **支出上限**：このセッションで使える最大額で、API価格で計算されます。金額を入力して**設定**を押すか、$1、$5、$10、$25から選びます。**上限なし**にすると上限が外れます。上限に達するとセッションは停止し、上限を引き上げるまで再開しません。[使用量、制限、費用](/guide/usage)をご覧ください。
- **スウォーム**：**オフ**。**スウォーム**にすると、リードエージェントがタスクをいくつかの切り口に分け、それぞれにメンバーを起動します。同時に動くメンバーの数は、**スウォームの規模**（[設定 → 機能 → サブエージェント](/settings?s=children&find=Swarm%20size)）で決まります。メンバーは見つけたことをボードで共有し、互いにメッセージをやり取りします。難しい問題向けで、費用は1つのエージェントの数倍かかります。または**キャンペーン**（「1つの大きな変更を部分に分け、それぞれをワークツリーで」）：リードが1つの大きな変更を部分に分け、メンバーがそれぞれ専用のブランチでテストとともに1つずつ作り、リードがマージします。フォルダはgitリポジトリである必要があります（[キャンペーン](/guide/engineering#campaigns-a-big-change-in-many-parts)をご覧ください）。
- **リサーチ**：**オフ**、または**ディープリサーチ**。エージェントが検索を計画し、各部分にリサーチャーを送り、重要な主張を2つの情報源で確認して、出典付きのレポートを届けます。**同時リサーチャー数**（1～8）、**ラウンド数**（1～5）、**検索の合計**（10～500）、**レポート**（**ページ**または**Word**）を設定できます。
- **アリーナ**：**オフ**、または**モデルを比較**。同じメッセージが、チェックを付けた1つか2つの別のモデルにも送られます（リストが長い場合は**モデルを探す**欄が役立ちます）。それぞれ同じフォルダで、専用のセッションとして動きます。回答を比べて最良のものを残し、ほかはアーカイブされます。gitリポジトリでは、フォルダメニューの**新しいワークツリー**をオンにすると、各モデルが自分のコピーで作業します。

スウォーム（またはキャンペーン）とディープリサーチはどちらもHydorサブエージェントを率いるため、一方をオンにするともう一方はオフになります。**機密**をオンにするとスウォーム、ディープリサーチ、アリーナがオフになり、これらのいずれかをオンにすると**機密**がオフになります。スウォーム、ディープリサーチ、アリーナは費用がかかるため、次のセッションには引き継がれません。選んだリサーチの数値とアリーナのモデルは、再びオンにするときのためにこのブラウザに保存されます。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research)をご覧ください。

### 各権限モードの意味

**Claude Code**

| モード | エージェントができること |
| --- | --- |
| 確認（デフォルト） | 設定で許可されていない編集とコマンドの前に確認する |
| 編集を承認 | ファイルを自由に編集し、それ以外のコマンドの前に確認する |
| 自動 | 安全確認が通常の操作を承認し、リスクのある操作についてはユーザーに確認する |
| プラン | 読み取りと計画のみを行い、承認用のプランを提案する |
| バイパス | 確認しない（フルアクセス） |

**Codex**

| モード | エージェントができること |
| --- | --- |
| プラン | 先に話し合って計画する。ユーザーに確認の質問をすることもある |
| 読み取り専用 | ファイルを読んで回答する。何かを変更する前に確認する |
| 自動（デフォルト） | フォルダ内でファイルを編集しコマンドを実行する。範囲を超える場合は確認する |
| 自動レビュー | 自動と同様だが、レビュー担当のエージェントが承認リクエストに答える |
| フルアクセス | サンドボックスも承認もなし |

Docker内ではCodex自身のサンドボックスが起動できないため、そこでは**フルアクセス**がデフォルトになり、メニューにその理由が表示されます。

**Custom**

| モード | エージェントができること |
| --- | --- |
| 確認（デフォルト） | ファイルの編集とコマンドの実行の前に確認する。見て回ることは自由にできる |
| 編集を承認 | フォルダ内のファイルを自由に編集し、コマンドの実行前に確認する |
| 自動 | 通常の手順は進める。リスクのある操作は簡易チェックで確認する |
| フルアクセス | 承認の確認もコマンドのサンドボックスもなしで、ツールとコマンドを実行する。コンピューターのアカウントの権限を使う |
| プラン | 読み取りと計画のみ。編集もコマンドもなし |

**フルアクセス**以外では、Customはリスクのあるコマンドの前に確認します。確認、編集を承認、プランでは、フォルダ外のファイルや、キーやパスワードを含むファイルを読んだり変更したりする前にも確認します。自動では、それらをまず簡易チェックで判断します。[Custom、アプリ独自のエージェント](/guide/custom)をご覧ください。

**その他のACPエージェント**には、それぞれ独自のモードがあり、エージェントを一度実行すると一覧されます。

### セッションを機密にする

作業の中には、コンピューターの外に出してはいけないものがあります。査読を依頼された論文（多くの学会やジャーナルは、投稿論文をオンラインのAIに渡すことを禁じています）、患者やクライアントの記録、契約のもとで扱う企業のコードなどです。機密セッションはこのコンピューター上のモデルで実行され、内容はどこにも送信されません。

1. スタートページで**オプション**を開き、**機密**（「このコンピューター上のモデルのみ使用。外部には何も送信されません。」）をオンにします。チップには「機密」と表示されます。
2. **実行環境**は**Custom**に、**モデル**はここにインストールされている最良のモデルになります。オンの間は、メニューにはこれらだけが表示されます。まだモデルがない場合はその旨が表示され、[設定 → エージェント → モデル](/settings?s=models)でこのコンピューター向けに提案されたモデルをワンクリックでインストールできます。
3. やってほしいことを書き、論文を添付するかそのフォルダを選んで、Enterキーを押します。例：「添付した投稿論文を、NeurIPSの査読者として査読してください。要約、長所、短所、著者への質問、スコアをお願いします。」

このコンピューター上のモデルとは、ここにあるOllamaとvLLMのモデル、およびアドレスがこのコンピューターまたはプライベートネットワークであるエンドポイントです。`localhost`、`127.0.0.1`、`::1`、`10.…`、`192.168.…`、`172.16.…`から`172.31.…`まで、または`.local`で終わる名前が該当します（[Ollama、vLLM、その他のエンドポイントを接続する](/guide/agents-models#connect-ollama-vllm-or-another-endpoint)をご覧ください）。名前が「cloud」で終わるOllamaのクラウドモデルはollama.com上で実行されるため、対象外です。スタートページでは、オフにするまで、このスイッチが次のセッションでもオンのままになります。

機密セッションには、ヘッダーとサイドバーのタイトルの横に錠前が表示され、メッセージ欄は落ち着いた緑色の枠になります。その意味を説明する行が、閉じるまで欄の上に表示されます。錠前を押すと、何がオンで何がオフかが表示されます。

- **オフ**：ウェブ検索とウェブページ、ブラウザと画面、接続済みアプリとキー、アプリ、公開、スケジュールタスク、画像・図・プロット・動画・音声の作成、検索、編集、外部のモデル（ディープリサーチ、スウォーム、アリーナ。[セカンドオピニオン](/guide/research)は、このコンピューター上の別の開発元のモデルからのみ得られます）、会話の別のエージェントへの引き継ぎ、メモリへの保存、ページのファイルとしての書き出し（ページから自分で書き出してください）。
- **ネットワークなしのコマンド**：エージェントのコマンドは、どの権限モードでもネットワークから切り離されて実行されるため、ダウンロード、インターネットからのインストール、プッシュ、送信はできません。それができない環境（Windows、一部のコンテナ）では、モードにかかわらず各コマンドの前に確認が表示され、錠前の注記にもその旨が書かれます。
- **引き続きオン**：フォルダ内のファイル、ドキュメント（このコンピューター上で読み取り）、保存したページ・画像・ファイル、共有ナレッジ、メモリのメモとプロフィール（読み取りのみで、追加はされません）、同様に機密として扱われるHydorサブエージェント、回答UI（ウェブからの画像や地図なし）。
- **外部には何も送られないこと**：タイトルは、補助モデルがこのコンピューター上で動いていればそのモデルから、そうでなければメッセージの最初の言葉から付きます。通知には「機密セッション」と、完了した、ユーザーの対応が必要、失敗したのいずれかだけが表示されます。読み取り専用リンクはなく、メニューからプルリクエストは作れず、そこから作られる自動化やアプリもありません。ほかのセッションのエージェントや別の場所のエージェントは、その内容を読めません。返信にはウェブからの画像が表示されず、表示するページも外部から何も読み込みません（そのため、ウェブ上のライブラリが必要なグラフは描画されません）。音声入力はこのコンピューター上の音声認識がオンのときだけ動作し（[設定 → 機能 → 音声](/settings?s=voice)）、返信の読み上げはお使いのデバイス上の音声でのみ行われます。
- **機密のまま**：フォークと**ここから編集**も機密になり、オフにすることはできないため、話した内容はその場にとどまります。コンピューターの外に出てもよい作業には、新しいセッションを始めてください。

保証できないこと：Hydorが確認するのはモデルのサーバーの場所であり、そのサーバーの動作ではありません。そのため、ネットワーク上に設定した、リクエストをオンラインのサービスに転送するエンドポイントは、やはりオンラインです。セッションからコピーしたもの、自分でほかの場所から開いたり送ったりしたもの（返信内のリンク、プロジェクトのファイルから開いた作成済みのページ、Gitページからのプッシュ）は、自分で管理する必要があります。別のデバイスでその内容を読む場合も同様で、アプリのページは通常どおり（トンネルを使っている場合はそのトンネルを通って）そのデバイスに届きます。

### ファイルを添付する、ファイルを指定する、コマンドを使う

- **ファイルを添付**（ボックスの下の行の左端の**+**）を使うか、メッセージ欄にファイルをドロップするか、画像やファイルを貼り付けます。1つのメッセージに添付できるファイルは合計25MBまでです。画像（PNG、JPEG、GIF、WebP）は1メッセージにつき8枚までが画像としてモデルに渡され、それ以外のファイル（20個まで）はこのコンピューターに保存されてメッセージの末尾に一覧されるため、エージェントがそれを開きます。送信前に、×でどれでも取り外せます。添付したファイルは、ほかのページに移動しても送信するまでボックスに残ります（ページを再読み込みすると消えます）。
- **スクリーンショットを添付**（同じ**+**メニュー内。コンピューターの場合。ブラウザがスクリーンショットを撮れない環境では、**+**はクリップのアイコンになり、ファイルを添付します）：ブラウザが画面、ウィンドウ、タブのどれにするかを尋ね、その画像が1枚添付されます。
- **@**：@とファイル名の一部を入力すると、フォルダ内の一致するファイルが一覧されます。↑ ↓で移動し、EnterキーまたはTabキーで挿入し、Escキーで閉じます。
- **/**：メッセージの先頭で/を入力すると、エージェントのコマンドとスキル（Claude Codeのもの）が、それぞれの説明とともに一覧されます。
- ブラウザまたはこのコンピューターが音声を認識できる場合は、送信ボタンの横にマイク（メッセージを音声入力）とヘッドフォン（ハンズフリー音声モード）が表示されます。[ドキュメント、画像、動画、音声](/guide/documents-voice)をご覧ください。

### スタートページが覚えていること

スタートページは、作業する場所ごとに選択を保存します。各プロジェクト、各フォルダ、**新しいタスクフォルダ**ごとに、すべてのデバイスで共通です。場所ごとに保存されるのは、**実行環境**（プログラム）、各プログラムの**モデル**、**オプション**の**思考レベル**と**権限**、**エージェント**、**メモリ**、**支出上限**、**機密**、**新しいワークツリー**のスイッチです。アカウント（**オプション → アカウント**）は場所ごとには保存されず、どこでも選んだままになります。ある場所でプログラムを選ぶと、そこで最後に使った内容が戻ります。

場所の選択は、そこで選択を1つでも変更するか、そこでセッションを始めた時点で保存されます。見ただけでは何も保存されません。**フォルダ**チップで場所（プロジェクト、フォルダ、**新しいタスクフォルダ**）を選ぶと、ボックスはその場所の選択で開き、書いた内容と添付はそのまま残ります。プロジェクトから始める場合（カードやページの**新しいセッション**、またはサイドバーのプロジェクト）は、そのプロジェクトの選択でスタートページが開き、フォルダ（ファイルまたはサイドバー内）の**このフォルダで新しいセッション**を押すと、そのフォルダの選択で開きます。ページは、最後に選んだ場所で開きます。

まだ何も選んでおらず、何も始めていない場所は、デフォルトで開きます。エージェントは**一般**、またはプロジェクトに専用のエージェントがある場合はそのエージェントです（そのエージェントの推奨も、選んだときと同様に適用されます。プログラム、そのティアのモデル、権限です）。**モデル**は、選べる場合は**自動**、そうでなければプログラムのデフォルトです。**思考レベル**と**権限**はプログラムの通常のものです。メモリはオンで、支出上限はなく、**機密**と**新しいワークツリー**はオフです。**実行環境**は、最後に使ったプログラムのままです。この機能が追加される前に最後に選んでいた場所は、それまでの選択が引き継がれます。

スタートページへのリンクで、内容をあらかじめ入力しておくこともできます。たとえば`/?prompt=Summarize%20my%20notes&agent=codex`のようにし、`model=`、`cwd=`（フォルダのパス）、`confidential=1`（機密をオン）を追加できます。メッセージ欄と選択項目が入力されるだけで、自動的に何かが始まることはありません。リンクで渡されたメッセージから見えない文字は取り除かれ、その旨が通知されます。

ボックスに書いた内容は、ほかのページに移動している間も残ります。メッセージ、添付したファイル、このタスクだけのオプション（**スウォーム**、**ディープリサーチ**、**アリーナ**、このセッションの**ガイドライン**）、リンクや**このフォルダで新しいエージェントセッション**で開いたフォルダが対象です。ボックスはセッションが始まると空になります。エージェントが動き出す間、**開始**の矢印は上に動き続けます。その後、スタートページがセッションになり、ボックスは下の定位置に移り、書いた内容が最初のメッセージとして上に移ります。メッセージとこれらのオプションはこのブラウザに保存されるため、再読み込みしても残りますが、添付ファイルは残りません。

## セッションの作業を追う

### ヘッダー

セッションの最上部には次のものが表示されます。

- エージェントのアイコンとタイトル（ダブルクリックで名前を変更）。[機密セッション](#keep-a-session-confidential)には鍵のマークも付きます。
- ステータス：**実行中**、**対応が必要**、**準備完了**、**開始中**、**メモリを構築中**、**停止中**、または別の場所で実行しているセッションでは「Open in VS Code」。エージェントがすでに実行されていない場合は、作業の終わり方が表示されます。最後のターンが終わったときは**完了**（ファイルを作成または変更した場合は「· 2 files made」や「· 3 files changed」が付きます）、停止したとき、または完了前に中断されたときは**停止**、エラーで終わったときは**失敗**です。ポインタを合わせると、次にすることが表示されます。
- フォルダ（クリックするとファイルで開きます）、プルリクエストのバッジ、追加したアカウントで実行している場合はそのアカウント、画面が広い場合はGitのブランチとモデル。
- 今できることを示すボタンが1つ：ターンの実行中は**停止**、エージェントが実行されていないとき（**停止**や**失敗**のあと）は**再開**（**完了**のあとは控えめな表示です。メッセージボックスに入力すればセッションは続きます）、VS Codeやターミナルで開いているClaude Codeセッションでは**ここで続ける**。
- **詳細**（ファイルが変更されると追加・削除された行数も表示）：[詳細パネル](#the-details-panel-changes-commands-and-info)を開きます。
- セッションのメニュー（⋯）：[セッションのメニューにあるすべての項目](#everything-in-the-sessions-menu)を参照してください。

### ターン、手順、返信

会話はチャットのように表示されます。各ターンは、送信したメッセージ、エージェントの作業、そして最後の返信で構成されます。

- **送信したメッセージ**は、エージェントが受け取る前の送信直後から右側に表示されます。その下でエージェントが作業している様子が表示され、メッセージボックスは次のメッセージのために空きます。送信に失敗した場合（接続がない、支出上限に達したなど）は、メッセージが取り消されてメッセージボックスに戻り、理由を知らせる通知が表示されます。長いメッセージは最初の数行に折りたたまれ、**もっと見る**で全文が開きます。
- **作業**は、要約する行の下にまとまります。「Worked for 2m 10s · 3 commands」「Thought」「Stopped after 40s」「Failed after 5s」などと表示され、右側にはそのターンの費用（「≈ $0.12」）が表示されます。クリックすると、そのターンの[時間とコスト](/guide/sessions#a-turns-time-and-cost)が開きます。プラン（Claude Code、Codex）では、これはAPI料金で計算した場合のトークンの費用であり、実際の支払額ではありません。モデルの価格が不明な場合は、代わりにトークン数が表示されます。ターンの実行中は「Working · 1m 2s」（または「Waiting for you」）と表示され、作業の概要が進行に合わせて増えていきます。以前のターンがある場合は、セッションがこれまでに作業した合計時間（全ターンの合計）も加わり、「Working · 1m 2s (47m)」のようになります。完了したターンは作業が折りたたまれ、その行をクリックすると開きます。
- **作業の概要**：エージェントが手順の合間に書く短いメモ（見つけたこと、次にすること）が1つの区切りの始まりとなり、その後に行う手順がその中に入ります。完了した区切りはチェック付きの1行で表示されます。メモの要点を数語にしたもの（「Run the checkout tests first to see what fails」「Apply the discount first and round once」）、手順の数、変更した行数です。クリックすると、メモの全文と各手順が開きます。進行中の区切りでは、エージェントのメモが全文で表示され、その下に現在行っている手順（「Editing total.ts · 4 s」など）が表示されます。その行をクリックすると、その区切りのこれまでの手順が開きます。エージェントの最初のメモより前の手順は、その内容にちなんだ名前の区切りになります（「Ran 3 commands, read 2 files」）。長いターンでは最新の区切りが表示され、**Show 12 earlier parts**で残りが表示されます。
- **手順**は、「Run the tests」「Read index.ts」「Searched the web」のように分かりやすい言葉で名前が付けられ、コマンド自体は目立たない文字で添えられます。クリックすると、その手順が行ったことを確認できます。Claude Codeは、コマンドやそのほかの変更を伴う手順を自分で実行します。同じメッセージでエージェントがそのあとに依頼したHydor独自の手順（Web検索、ページの読み取りなど）は、それが終わるまで待ちます。そのような手順では、実際に開始されるまで時計の代わりに控えめに**待機中**と表示されます。開始されるとその時点から時計が進み、完了した手順には実際にかかった時間が表示されます。概要で進行中の手順の行には、実際に実行されている手順が示されます。
- **思考**は「Thought for 12s」と最初の見出しとともに表示され、クリックすると読めます。
- **返信**は、エージェントが最後の手順のあとに書いたものです。エージェントが見せたページも一緒に表示されます。エージェントの作業中、最後の手順のあとに書かれた短いメモは、進行中の区切りとして概要に表示されます。ターンがそこで終わった場合は、それが返信になります。
- **手順の合間の返信**：エージェントが手順の合間に書いた内容のうち、返信として読めるもの（作業中に送ったメッセージへの回答、または続行する前に見つけたことを複数の段落、リスト、表にしたもの）は、作業に折りたたまれず、その位置に返信として表示されます。その前後の作業は、それぞれ「Worked for 20s · 2 commands」のような独自の行にまとまります。
- **変更されたファイル**：返信の下に、そのターンで変更されたすべてのファイルが、追加・削除された行数とともにカードで表示されます。ファイルをクリックすると差分が表示され、**ファイルを開く**でそのファイルが開きます。6件以上は「Show 3 more files」の中に折りたたまれます。
- **作成されたドキュメント**：返信の下に、そのターンでエージェントが作成または変更したドキュメント（PDF、Word、Excel、PowerPoint、LaTeX、ノートブック、Markdownなど）が、**新規**または**更新済み**と記されたカードで表示されます。エージェントが渡したかどうかは問いません。返信内のファイル名やパスはリンクになっており、会話の上に重なるウィンドウでファイルが開きます（[作成または変更されたドキュメント](/guide/documents-voice#documents-it-made-or-changed-and-file-names-in-its-reply)）。
- **コミット**：エージェントがそのターンでコミットを作成した場合、返信の下にチップが表示されます。**コミット済み**・コミットのタイトル（または、ブランチ付きの「3 commits」）、追加・削除された行数です。クリックすると（複数ある場合は、さらにコミットを選ぶと）、メッセージ全文、作成者と日時、ハッシュ（クリックでコピー）、変更されたすべてのファイルとその差分が表示されます。**Gitで開く**を押すと、セッションのリポジトリが[Gitページ](/git)で開きます。同じターンのうちにエージェントが修正または リベースして消えたコミットは表示されません。

エージェントはチェックリスト（**プラン**または**ToDo**。完了した数も表示）を持つこともあり、作業の進行に合わせてチェックが付いていきます。アプリからの通知は、関係するターンの後に表示されます。メモリが保存した内容、セカンドオピニオン、支出上限への到達、そのターンが開始したサブエージェントのカードなどです。ほかのセッションからのメッセージは「From …」、サブエージェント（Hydor、Claude Code、Codexのいずれか）の返信は「Reply from …」（クリックで返信を読めます）と表示され、スケジュールタスクの実行は、そのタスクの名前を示す行から始まります。

日付の行（「Yesterday」「Today」）で日ごとに区切られます。すべて今日の会話には日付の行はありません。古いメッセージは、上にスクロールすると読み込まれるほか、**以前のメッセージを表示**でも読み込めます。新しいメッセージや返信は会話の末尾に追加され、その下に余分な空白は残りません。返信が画面いっぱいになるほど長くなると、表示は最初の行で止まったまま、返信が伸びても動かないため、長い返信は最初から読めます。短い返信は、それまでの内容の下にそのまま表示されます。エージェントの作業中に上へスクロールすると、表示はその位置のままになります。**最新**を押すと末尾に戻ります。この表示は、返信が画面の下に続いているときにも表示されます。

完了した各返信の下には、**メッセージをコピー**、**この返信からフォーク**、**読み上げ**があります。**この返信からフォーク**は、Claude Codeではどの返信でも使え、CodexとCustomではターン全体をフォークするため、完了したターンの最後の返信でのみ使えます。自分のメッセージの下には、**メッセージをコピー**、**ここから編集**、送信した時刻が、ポインタを合わせたときだけでなく常に表示されます。

### ターンの時間とコスト

完了したターンの行の右側にある費用（「≈ $0.12」、モデルの価格が不明な場合はトークン数）をクリックすると**時間とコスト**が開き、ターンに時間がかかった理由や費用が大きかった理由を確認できます。

- **所要時間**：ターンの時間がどこに使われたかを示すバーで、各部分の割合と長さが表示されます。**モデル**（与えられた内容の読み取り、思考、執筆）、**コマンド**、**ファイルの読み取りと編集**、**Web**、**その他のステップ**（サブエージェント、接続済みアプリのツール）、**回答待ち**（承認、質問、フォーム。各カードが表示されてからあなたが答えるまで）、**その他**（開始時と手順の合間）です。並行して実行された手順は1回として数えます。その下の「First reply or step after 3 s」は、エージェントがどれだけ早く開始したかを示します。
- **トークン**：**新規読み取り**、**キャッシュへの書き込み**（新規に読み取られ、モデルの提供元に保持されるため、次のリクエストではより少ない費用で読み取れます）、**キャッシュから読み取り**（読み取られた全体に占める割合付き）、**出力**（返信、思考、手順）です。
- **費用**：そのターンの費用と、モデルの価格が分かる場合は種類別の費用、および「The cache saved about $0.80.」が表示されます。プラン（Claude CodeとCodex。セッションがAPIクレジットで実行される場合を除く）では、「At API prices: on a plan you pay your plan's fee」と表示されます。モデルの価格が不明な場合は、費用が計上されないことが表示されます。

Claude Codeのターンでは、モデル自体の時間と最初の返信までの時間が分かります。ほかのエージェントでは、モデルの部分は思考時間です。費用とこのパネルは、画面が広い場合に表示されます。

### 返信内の数式、図、グラフ、画像

エージェントは、ターミナルではなくこのアプリ向けに返信を書くため、返信にはテキスト以外も含められます。どのエージェントもこれらの方法を知っており、答えが分かりやすくなる場面では自分で使います。

- **書式**：見出し、リスト、表、太字、コードが、読みやすく配置されます。
- **数式**：教科書のように描かれた数式で、文中にも、独立した行にも置けます。化学反応式（2H₂ + O₂ → 2H₂O）も使えます。ドル記号で囲まれた数字（`$1$`、`$0$`）も数式として扱われ、$4.70のような通常の金額は金額のままです。
- **図**：フローチャート、シーケンス図、状態遷移図、タイムライン、マインドマップ、ガントチャート、円グラフが、ライトでもダークでもアプリの色で描かれます。図の上のバーには、**コードを表示**（エージェントが書いたコード。同じボタンで図に戻せます）、**画像として保存（SVG）**、**全画面**、そしてコードをコピーするボタンがあります。描画できない図は、理由とともにコードが表示されます。
- **グラフと小さなツール**：チャート、注釈付きの図、電卓、スライダー付きのシミュレーション、短いクイズが返信の中で動きます。エージェントが表示するページと同様に、アプリやファイルからは隔離されています。アプリの見た目に合わせ、大きさも自動で調整されます（縦に長いものは**すべて表示**で開きます）。バーには**コードを表示**（**表示**で戻ります）、**ファイルとして保存**、**全画面**があります。クリックして選んだ内容は、メッセージボックスに入ります。返信の執筆中はその場で組み上がっていき（表示できるものができるまでは「Writing…」）、完成すると操作できるようになります。
- **画像**：Webの写真（場所、商品、植物、美術作品）やこのコンピューター上の画像が、返信に合わせて表示されます。クリックすると大きく表示され、**編集**で画像エディタが開きます（[画像と動画を編集する](/guide/library#edit-pictures-and-videos)）。Webの画像はこのアプリのサーバーを経由して届くため、画像を持つサイトがブラウザを知ることはありません。読み込めない画像は、そのリンクとして表示されます。

テキストだけにしたい場合は、[エージェントガイドライン](/guide/guidelines)（「図や画像を使わず、プレーンテキストで答えてください」）またはメッセージで伝えてください。これらは普通の言葉で頼むこともできます。「手順をフローチャートで描いて」「その画像を見せて」「ほかの値を試せるスライダーを付けて」。

### 回答UI：返信内のカード、グラフ、地図

答えの一部が、読むものではなく、見る、比べる、選ぶ、たどる、試す、練習するものである場合、エージェントはアプリの回答UIのひとつで表示します。回答UIは、約150種類の既製のカード、表、グラフ、地図、ギャラリー、タイムライン、小さなツールで、答えの内容そのもので埋められます。数行を超える答えの多くにはこうした部分があるため、ほとんどの答えで目にします。比べる選択肢は各行の最良値に印が付いた表に、レシピは人数に合わせて分量が変わるカードに、天気予報は今後の数時間と数日に、場所は番号付きのピンが立つ地図に、クイズや練習問題はその場で答えられる問題になります。どれも返信が届くにつれて組み上がり、ライトでもダークでもアプリの見た目になります。

- **回答UIでできること**：表の並べ替えや絞り込み、グラフを数値表示に切り替える、チェックリストにチェックを付ける、レシピのタイマーを開始する、フラッシュカードをめくる、ペアを合わせる、空欄を埋める、トラブルシューターの質問に答える、ルーレットを回して決める、電卓や関数プロットのスライダーを動かす、動画を再生する、などです。チェックや回答は、このデバイスで会話に戻ったときにも残っています（練習問題の回答も同様です）。**送信**（**選択を送信**、**スコアを送信**、**結果を送信**、**送信**など）というボタンは、その名前が示す内容を、入力してEnterを押したかのように、すぐに次のメッセージとして送信します。選んだ選択肢、クイズのスコア、ルーレットが止まった位置などです。横に**送信済み**と表示されれば送信されています。書きかけの内容はメッセージボックスに残ります。セッションがそのときメッセージを受け付けられない場合（別のメッセージがまだ送信中）は、その言葉がメッセージボックスに入るので、自分で送信してください。さらに次のようなものもあります。
  - **練習問題**で、自分の言葉や数字で答えるものは、その場で確認されます（数値は許容範囲内、言葉は大文字小文字を区別しません。アクセントだけが違う正解は、その旨が表示されます）。**ヒントを表示**でヒントが1つずつ表示され、解答例は挑戦したあと、またはすべてのヒントを表示したあとに表示されます。スコアが出て、**結果を送信**でエージェントに送れます。自由回答は**確認のために送信**でエージェントに送り、確認してもらいます。
  - **実行して変更できるコード**：プレイグラウンドで、JavaScript、Python、小さなWebページをその場で実行できます。アプリからは隔離されており、出力（Pythonではプロットも）がその下に表示されます。**実行**、**リセット**、**コピー**、**コードを送信**（エージェントが確認できるよう送られます）があり、試すための課題が出されることもあります。Pythonは初回にWebから読み込まれるため、[機密セッション](/guide/sessions#keep-a-session-confidential)では実行できません。
  - **ネットワークグラフ**は、物事のつながり（概念マップ、小説の登場人物、依存関係）を示します。ノードをタップするとつながりが強調されてメモが読め、ノードをドラッグして動かせ、凡例も確認できます。**リスト**表示に切り替えることもできます。
  - **注釈付きテキスト**は、テキスト内の箇所に印を付けます。タップするとそのメモ（修正、コメント、意味）と提案される変更が読め、**これについて質問**も使えます。メモを種類で絞り込み、**原文**と**修正後**を切り替え、**修正後のテキストをコピー**を使うことも、テキストを聞くこともできます。
  - **ファクトチェック**は、主張を1つずつ確認し、それぞれに判定、理由、エージェントの確信度、賛否の根拠と出典を示します。上部の判定の集計をタップすると、主張が絞り込まれます。
  - **フォローアップ**は、答えの末尾にある、次の質問や手順を示す2〜5個のボタンです。メッセージボックスが空のときはタップすると次のメッセージとして送信され、入力中のときはその内容に追加されます。使ったボタンにはチェックマークが付きます。
- **画像**：画像がない項目や、画像を読み込めない項目は画像なしで表示され、テキストがその場所を占めるため、空のボックスは残りません。
- **スプレッドシートやファイルの数値**：表、グラフ、主要な数値、ランキング、ヒストグラム、地図上の値は、数値を自分で保持する代わりに、スプレッドシート（[スプレッドシート](/guide/library#spreadsheets)を参照）のひとつ、または会話のフォルダかそのプロジェクトのフォルダにあるCSV、TSV、JSON、JSONLファイルから読み取れます。エージェントは、数値がそこにあるとき、行数が数十行を超えるとき、残しておきたいカードのときにこの方法を使います。カードが自分で合計、カウント、グループ化、絞り込み、並べ替えを行うため、数値を打ち直す必要はなく、表示のたびに最新の数値が表示されます（あとから追加した行も同様です。ただし、セル範囲が固定されている場合は除きます）。その下の行に、取得元、読み取った日時、一部だけを表示している場合はその量（「1,000 of 12,400 shown」）が表示されます（**データの取得元** *Shop numbers · Sales*。スプレッドシートまたはファイルを開くリンクです）。**もう一度読み取る**でもう一度読み取り、スプレッドシートを保存するとカードは自動的に再描画されます。スプレッドシート、そのタブ、列、またはファイルがなくなっている場合は、カードがその旨を分かりやすい言葉で表示し、**もう一度試す**が表示されます。カードが読み取れるのは、その会話のフォルダにあるファイルだけで、コンピューター上のほかの場所のファイルは読み取れません。上限は50 MB（JSONファイルは20 MB）、先頭の1,000,000行までです。[機密セッション](/guide/sessions#keep-a-session-confidential)で作成されたスプレッドシートは、そのセッション内のカードだけが読み取れます。
- **ポインタを合わせたとき**（またはキーボードで移動したとき）、右上に小さなバーが表示されます。**データを表示**はエージェントが書いた内容を表示します（スプレッドシートやファイルを読み取るカードでは、読み取り元とそのうち何を表示しているか。**表示**で戻ります）。**テキストとしてコピー**はプレーンテキストでコピーし、**全画面**はカードだけをページの上に、ウィンドウの幅いっぱいに表示します（スマートフォンでは画面全体）。縦に長い場合はスクロールできます。**Esc**、**閉じる**、またはカードの外側のクリックで戻ります。**その他**（…）の中：**ボードにピン留め**は、カードのコピーをいずれかのボードに保存し、ほかのカードと並べて後で見返せるようにします。ボードは選ぶか、そこで名前を付けて**新しいボード…**を作ります（[ボード](/guide/library#boards)を参照）。**画像として保存**は、表示されているテーマのまま、シャープさを保つため2倍のサイズで、カードのPNGをタイトルに基づく名前で保存します。**画像としてコピー**は同じ画像をクリップボードにコピーし、メッセージやドキュメントに貼り付けられます（ブラウザがページにこれを許可している場合）。全画面表示の上部にも、同じ2つがあります。地図、チャートライブラリで描画されたプロット、動画プレーヤー、コードプレイグラウンドの出力を含むカードには、画像のボタンがありません（ピン留めはできます）。これらの部分は画像に描画できないためです。
- **エージェントが使う場面**：エージェントは、答えのうち、見る、比べる、選ぶ、たどる、試す、練習する、残す対象となる部分のすべてに回答UIを使うよう指示されています。数行を超える答えでは、ほとんどの場合に当たります。比べる選択肢、画像や詳細のあるもの（場所、商品、映画、本、人物、論文、ニュース）、数値、時間と計画、やること、学ぶこと、確認する文章、検証する主張、取りたい次の手順などです。画像を入れ、写真より動画で見たほうが分かりやすい場面では動画を再生します。カードでは伝えられないこと（理由、アドバイス、注意点）は、エージェントの言葉で伝えます。普通の会話、短い質問への短い答え、コードの変更はテキストのままです。最初の答えも以降の答えも、それぞれの部分に1つずつ、複数含められるので（旅行の日程、天気、持ち物リストなど）、会話には答えが必要とするだけ多くのカードがたまります。後の答えで、データを最新にして同じものを再び表示することもあります。エージェントは1回の検索で合うものを見つけます。すでに知っているものは名前で、それ以外は各部分が示す内容を数語で表して探します（言葉で、そして[設定 → メモリ](/settings?s=memory)で**意味で検索**がオンのときは意味でも）。そのため、すべてを渡されることはありません。[組み込みのエージェント](/guide/agents#the-built-in-agents)は、それぞれ作業に合うものを重視して使います。
- **すべてを見る**：[回答UI](/answers)では、すべてを例とともにグループ別に確認できます。要約、比較、ショッピング、場所と旅行、食べ物、計画、仕事とビジネス、数値とグラフ、お金、学習、科学、メディア、人物とスポーツ、文章、コードです。**ストリーミング中に再生**で、返信として届くときの表示を確認できます。

普通の言葉で頼むこともできます。「表で比べて」「地図に載せて」「クイズを出して」「これの練習問題を出して」「エッセイを直すべき点に印を付けて」。プレーンテキストにしたい場合は、[エージェントガイドライン](/guide/guidelines)（「カードやグラフを使わず、プレーンテキストで答えてください」）またはメッセージで頼んでください。

### 手順を開いて出力を見る

手順をクリックすると開きます。

- コマンド：コマンド、実行したフォルダ、終了コード、所要時間、コピーボタン、そして出力（途中で切れている場合は**出力をすべて読み込む**）。
- ファイルの編集：差分（途中で切れている場合は**差分をすべて読み込む**）。
- ファイルの読み取り：ファイルへのリンクと、読み取った内容。
- Webページ：そのアドレスと、そこから読み取った内容。
- サブエージェントに与えたタスク：**与えられたタスク**と、返ってきた内容。
- そのほか：エージェントが送った内容と、返ってきた内容。

手順には、**バックグラウンド**（実行が続く）、**自動**（Customの自動モードが判断したもので、理由はポインタを合わせると表示）の印が付くことがあり、赤い終了コードが表示されることもあります。バックグラウンドタスク（実行したままのコマンド、モニター、ワークフロー）は、メッセージボックスの上の行に、セッションのサブエージェントとともに一覧表示されます。タスクを開くと出力（Claude Code）を確認でき、**停止**もできます（停止前に確認が入ります）。サブエージェントは、それ自体のセッションとして開きます。[サブエージェント](/guide/sessions#subagents)を参照してください。

## エージェントの開始前にプロジェクトのメモリを作成する

開始ページで、[Wikiメモリ](/guide/wiki-memory)がまだ新しい（記事が10件未満で、履歴からの構築も未実行の）プロジェクトでセッションを始めるとき、そのプロジェクトに構築の元になるもの（会話、コミットメッセージ、ドキュメント、メモ、README、docs/フォルダ）があれば、セッションは最初に確認します。メッセージの下にカードが表示され、**<project>のメモリを先に作成しますか？** と尋ねます。カードには、読み込む内容と、エージェントが開始するまでにかかるおおよその時間が表示されます。選択するまで、セッションには**対応が必要**と表示されます（通知も届きます）。

- **メモリを作成して開始**：メモリの構築が始まり、カードは進捗表示に変わり、セッションには**メモリを構築中**と表示されます。メッセージは待機し（「メモリの準備ができたらエージェントに送信されます」）、最も重要な部分が書き終わった時点でエージェントに送られます。重要な部分とは、プロジェクトのファイルから作る概要、メモ、そして内容が最も豊富な会話です。残りはバックグラウンドで構築が続き、書き上がったものからエージェントが利用できます。**今すぐ開始**はメッセージをすぐに送信し、構築はそのまま続けます。**作成を停止**は構築を止めて（書き込まれた分は残ります）エージェントを開始します。アプリを閉じても、エージェントは自動で開始します。その時点より前に構築が失敗した場合は、カードにそのことが表示され、**もう一度試す**と**そのまま開始**を選べます。エージェントがメッセージを受け取る前に終了し（クラッシュした、または待機中にコンピューターが再起動した）、再び開始できない場合、カードには**新しいセッションで開始**が表示されます。同じ設定の新しいセッションがメッセージを受け取り、その間に送信した内容も引き継ぎ、空になった元のセッションはアーカイブされます。
- **メモリなしで開始**：エージェントはすぐに開始し、このプロジェクトでは1週間確認しません。
- **このプロジェクトでは確認しない**：このプロジェクトについて、以後は確認しません。**履歴から構築**は、プロジェクトの詳細の**メモリ**タブに残ります。

待機中に送信した内容は、最初のメッセージの後にエージェントへ送られます。確認が行われるのは、開始ページで自分でセッションを始めた場合だけです。スケジュールされた実行、アプリ、サブエージェント、エージェントが開始したセッションでは確認されず、すでに構築済みのプロジェクトでも確認されません。

## エージェントの操作を承認または拒否する

エージェントが、権限の範囲では単独で行えないことをしようとすると、待機して、会話の末尾のカードで確認します。カードには、実行しようとしているコマンド、差分付きのファイル変更、またはその他のツールとその詳細が表示され、待機時間も表示されます。セッションのドットは琥珀色に変わり、受信トレイにも数えられ、通知をオンにしていれば通知も届きます。回答はカードから、[受信トレイ](/guide/inbox)から、または単純な承認か拒否であれば、ブラウザがボタンを表示する場合は通知から直接行えます。

ボタンはエージェントによって異なります。

- **Claude Code**：**許可**、**拒否**、そして多くの場合「Always allow Bash npm test」や「Allow all edits this session」のようなルール。
- **Codex**：**許可**、**このセッションで許可**、**このコマンドを常に許可**、**拒否**、**拒否して停止**。ファイル変更では**このセッションで編集を許可**、より広い権限では**このターンで許可**と**このセッションで許可**。
- **Custom**：**許可**、**常に許可**（続けて対象の内容が正確に表示されます。承認したコマンドだけが対象なので、後ろに別のものを付け足すことはできません）、**却下**。
- その他のエージェント：エージェントが提示する選択肢。

**拒否**を押すと、まず「任意：代わりにどうしてほしいかをエージェントに伝える」という入力欄が開きます。もう一度**拒否**を押すと、メモ付きまたはメモなしで送信されます。（Customの**却下**とCodexの**拒否して停止**は、すぐに回答します。）

接続済みアカウントのツールを**事前に確認**に設定している場合、セッション内では確認されません。呼び出しは送信トレイで保留され、エージェントは作業を続けます。会話には**送信トレイで承認待ち**という行が表示され、その後、送信されたか破棄されたかが表示されます（[送信トレイ](/guide/inbox#the-outbox-calls-held-for-your-ok)）。

Claude Codeの**自動**モードでは、安全チェックが確認せずにコマンドを拒否することがあります。その場合、メッセージ欄の上にカードが表示され、「Claude blocked a command」とその理由が示されます。**承認して再試行**はセッションを確認モードに切り替え、エージェントにもう一度実行させます。そのため通常の承認として戻ってきます。**閉じる**はそのままにします。

## 質問に回答し、プランを承認する

エージェントから質問があると、琥珀色の縁のカードに質問と選択肢が表示されます。

- 選択肢を1つ選びます。「Pick any」と表示されている場合は複数選べます。**その他：自分の回答を入力**では、自分の言葉で回答できます。
- **ファイルを添付**で、回答にファイルを追加できます。
- 1～9キーで、まだ回答していない最初の質問の選択肢を選べます。
- **回答を送信**は、回答を次のメッセージとして送信します。質問中にセッションが停止していた場合は、**再開して回答**で回答とともにセッションを再び開始します。VS Codeやターミナルで待機しているClaude Codeのセッションでは、**ここで回答**でそちらを終了し、回答を添えてここで続けます。Codexのセッションは、そちらで回答する必要があります。

質問が承認カードとして表示される場合、ボタンは**回答を送信**で、Claude Codeでは**スキップ**もあります。

**プラン。** Claude Codeの**プラン**モードでは、エージェントは読み取りと計画を行い、プランをカードで表示します。**承認、編集を自動承認**（確認せずに編集を進めます）、**承認、編集前に確認**、**プランを続ける**（プランモードのままです。変更してほしい点を伝えます）から選べます。CodexのプランモードではCodexがまず話し合いと計画を行い、確認の質問をすることもあります。Customのプランモードは、番号付きのプランで終わります。権限を切り替え（Shift+Tab）、返信して実行させます。

## サービスが求めるフォームに入力する

接続したサービスが、タスクの途中で日付、選択、承認用のページなど、何かを求める場合、どのエージェントが作業していても、そのフォームがカードとして表示されます。「Linear asks you to fill in a form」「… asks you to open a page」「… asks to go ahead」のように表示されます。項目を入力して**送信**（またはページを開く**開く**、もしくは**許可**）を押すか、**辞退**または**今はしない**を押します。Codex独自のツールサーバーも同じ方法で確認します。[接続済みアプリ、キー、ツール](/guide/connections)をご覧ください。

## エージェントの作業中にメッセージを送る

ターンの実行中でも入力できます。そのときEnterがどう動くかは、ブラウザごとに[設定 → アプリ → 一般](/settings?s=general&find=Sending%20while%20an%20agent%20works)の**エージェントの作業中に送信**で決まります。

- **ターンに参加**（デフォルト）：Enterで、進行中のターンにメッセージが追加され、エージェントはすぐにそれを考慮します。Ctrl+Enter（Macでは⌘Enter）では、代わりにキューに入ります。
- **待つ**：Enterでメッセージがキューに入り、ターンの終了時に送信されます。Ctrl+Enterでは、代わりにターンに追加されます。

メッセージ欄には、どちらになるかが表示されます。「Send a follow-up into the running turn」または「Queue a message for when this turn ends」です。タッチスクリーンでは、送信ボタンがEnterと同じ動作をします。Customは、実行中のツールが終わった後の次のモデルステップでフォローアップを受け取ります。キューにあるメッセージには**今すぐ送信**で同じ動作をさせられます。Customのセッションがアプリの更新前から実行中で、まだライブのフォローアップを受け取れない場合は、メッセージはターンが終わるまでキューに残ります。その他のACPエージェントは一度に1件しかメッセージを受け取れないため、作業中に送ったメッセージは常にキューで待機します。Claude Codeでは、エージェントの作業中に入ったメッセージの下に「sent while working」と表示されます。それに対するエージェントの回答は、エージェントがその後も作業を続けている場合でも、メッセージの下に返信として表示されます。

## キューを管理する

キューに入ったメッセージはメッセージ欄の上で待機し、送信される順に番号が付きます。キューに入れたメッセージは、送信した瞬間にそこへ表示されます。ターンが終わるたびに、1件ずつ自動で送信されます。

- ハンドルをドラッグして、順序を変更できます。
- **今すぐ送信**（矢印）：実行中のターンに、すぐ送信します。
- **編集**（鉛筆）：テキストの変更、添付ファイルの削除、追加ができます（**添付**、またはファイルの貼り付けやドロップ）。Enterで保存、Escでキャンセルします。
- **外す**（ゴミ箱）：キューから外します。添付ファイルは削除されます。
- エージェントを停止したとき、またはアプリを再起動したときは、キューが一時停止します。「The queue is paused (the agent was stopped, or the server restarted).」と表示されます。**再開**を押すと、エージェントが空き次第、メッセージが再び送信されます。支出上限に達した場合もキューは保留されます。上限を引き上げると続行します。

## エージェント、モデル、思考レベル、権限を変更する

セッションのメッセージ欄には、開始ページの**エージェント**と、その3つの選択肢である**モデル**、**思考レベル**、**権限**が、**+**の横の1つのチップにまとまっています（**+**は**オプション**を開きます。スマートフォンでは下から出るシートです）。その下に、このセッション向けの開始ページのその他のオプションが同じ順序で並びます。**アカウント**（次のメッセージから別のアカウントがセッションを引き継ぎます。エージェントに複数のアカウントがある場合に表示されます）、**機密**と**アリーナ**（そのまま表示されます。どちらもセッション開始時に選ぶもので、クリックするともう一方の選び方が示されます）、**メモリ**、**支出上限**、**スウォーム**、**リサーチ**、**ガイドライン**（セッションメニューの[セッション設定](/guide/research#turn-it-on)と同じ選択肢とダイアログです。スウォームとリサーチは次のメッセージから変更が反映されます）です。チップにはエージェントとモデルの名前が表示され、思考レベルと権限は通常と異なる場合に表示されます。エージェントが確認なしで何でも実行できる間は、チップが琥珀色になります（**バイパス**、またはCodexの**フルアクセス**）。別のエージェントへの変更は、次のメッセージから適用されます（[セッション内でエージェントを切り替える](/guide/agents#switch-agents-in-a-session)をご覧ください）。モデル、思考レベル、権限の変更は、実行中のエージェントにすぐ適用され、セッションに残ります。Shift+Tabで次の権限モードに移ります。モデルメニューには、このエージェントのモデルだけが表示されます。会話を別のエージェントに移すには、[別のエージェントで続ける](#continue-in-another-agent)を使います。

## 返信の一部を引用する

エージェントの返信、または自分のメッセージ内のテキストを選択すると、その上に**見積もり**ボタンが表示されます（タッチスクリーンでは下に表示されます）。テキストが引用としてメッセージ欄に入り、カーソルはその後ろに置かれるので、その部分に答えたり、以前に言ったことを持ち出したりできます。

## セッション内のテキストを検索する

セッションでCtrl+F（⌘F）を押します。**このセッション内を検索**は、自分のメッセージとエージェントのメッセージ（まだ読み込まれていない部分も含む。コマンドの出力は対象外）を検索します。2文字以上を入力すると、最新の一致箇所に移動して該当の語を強調表示し、「3 of 12」のように表示します。Enterで古い一致箇所、Shift+Enterで新しい一致箇所に移動します（矢印も使えます）。Escで閉じます。折りたたまれた長いメッセージは、見つかった箇所で開きます。検索ボックス（Ctrl+K）で選んだメッセージは、このバーにすでに入力された状態でそのセッションを開きます。

## メッセージ欄のその他の機能

- 空のメッセージ欄で↑を押すと、このセッションの以前のメッセージが新しい順に呼び出されます。↓で再び先へ進みます。
- 入力中の内容は、このブラウザでセッションごとに下書きとして保存されるので、戻ってきても残っています。
- Ctrl+S（⌘S）で下書きを脇に置いて欄を空にします。空の欄でCtrl+Sを押すと、下書きが戻ります。
- 非常に長い貼り付け（32,000文字以上）は、欄を埋める代わりにテキストファイルとして添付されます。
- プレースホルダーには、送信すると何が起こるかが表示されます。「Message Claude…」、またはエージェントが実行中でないときは「Message to continue…」です。送信すると、会話全体を引き継いで再び開始します。

## 詳細パネル：変更、コマンド、情報

ヘッダーの**詳細**で、3つのタブがあるパネルが開きます。広い画面では会話の横に表示され、セッションを移動しても開いたままです。狭い画面ではページの上に重ねて表示され、スマートフォンでは操作したときだけ開きます。

- **変更**：セッションが変更したすべてのファイルが、変更の多い順に、追加行数と削除行数とともに表示されます。ファイルをクリックすると各編集の差分が表示され、**開く**でそのファイルを開きます。
- **コマンド**：エージェントが実行したすべてのシェルコマンドが新しい順に表示され、**すべて**、**失敗**、**背景**のフィルタがあります。コマンドをクリックすると出力が表示されます。
- **情報**：エージェント、ステータス（ヘッダーと同じで、**完了**、**停止**、**失敗**、または現在の動作）、フォルダ、ブランチ、モデルと思考レベル、コンテキストの使用量、開始時刻と最終アクティブ時刻、アクティビティ（プロンプト、ターン、ツール呼び出し、コマンド）、トークン（入力、キャッシュ、出力）、APIコスト（同じ作業をAPI料金で行った場合の費用）、出力速度、開始場所（Hydor、VS Code、ターミナル、Claudeのデスクトップアプリなど）が表示されます。エージェントの実行中は**そのプログラム**も表示され、現在の使用状況（CPU、メモリ、数）と、適用されている[制限](/guide/app#limit-each-session)が分かります。その下には、バックグラウンドタスク（開くと何をしたかが分かり、**停止**もできます）と、**ターミナルで続ける**が表示されます。これはターミナルでセッションを再開するコマンドとセッションIDで、それぞれにコピーボタンがあります（Claude CodeとCodex）。

## メーターを読む：コンテキスト、キャッシュ、速度

マイクの横にある、割合が表示された小さなリングは、会話がモデルのコンテキストウィンドウを使うにつれて埋まっていきます。残りの情報は、オプションのチップのメニューの下部にあります。

- **コンテキスト**：リングと、オプション内の**コンテキスト**行（「42% in use」）です。リングにポインタを合わせると、正確なトークン数が表示されます。85%を超えると琥珀色になります。リング、またはオプションの**圧縮**をクリックすると、会話が圧縮されます（ターンの実行中は不可）。Customのセッションでは、リングにポインタを合わせるとトークン数と内訳が表示され、内訳は**コンテキスト**行の矢印の下にあります。Customは自動で圧縮するため、**圧縮**はなく、リングをクリックしても何も起こりません（[長い会話と長い出力](/guide/custom#long-conversations-and-long-output)をご覧ください）。
- **cache 4m**（Claude Code）：プロンプトキャッシュは、会話をしばらくの間（5分または1時間）準備した状態に保つので、次のメッセージが安く速くなります。何も送信しない間はカウントダウンし、それまでにメッセージを送るとキャッシュが再利用されてカウントが最初から始まります。**キャッシュなし**は、次のメッセージでキャッシュが再構築されることを意味します。
- **85 tok/s**：直前の返信が書かれた速さで、1秒あたりのトークン数です。

## ターンの停止、エージェントの停止、再開

メッセージ欄の横にある**停止**ボタンには、エージェントの起動中や作業中に回転するリングが表示されます。ユーザーの対応が必要なときはリングが止まり、端末で視覚効果の軽減が設定されている場合も動きません。ターンが終わっても、エージェントが開始したバックグラウンドタスクやサブエージェント（Hydorサブエージェント、Claude Codeサブエージェント、実行したままのコマンド、モニターなど）が動いている間は、**停止**ボタンがリングつきのまま残ります。その横には送信ボタンがあり、メッセージ欄はいつもどおりメッセージを受け付けます。**停止**にポインタを合わせると、止まる対象が表示されます。「このターン、2件のサブエージェント、1件のバックグラウンドタスクを停止します」や「2件のサブエージェントを停止します」といった表示です。ターン、実行中の各サブエージェント、実行中の各バックグラウンドタスク、さらにそれらが開始したものまで、すべて一度に止まります。この方法で停止したHydorサブエージェントは、親に結果を報告しません。すでに送られていた報告は、親を起こさず、親の一時停止中のキューで待機します。キューを再開するには**再開**を押します。

- **ターンを停止**：ヘッダーの**停止**、またはメッセージ欄の横にある角丸の四角いボタンを押します。このボタンは、セッションが開始したもの（上記）も止めます。（Escでは止まりません。Escは、検索バーや一覧など開いているものを閉じるだけです。）エージェントは作業を中断し、ターンには「停止しました…」と表示されます。エージェントが終了処理（実行中のコマンドの終了など）に数秒かかる場合でも、**停止**を押した時点でセッションは停止と表示されます。20秒後にもエージェントが作業中であれば、セッションは再び作業中の表示に戻ります。エージェントは次のメッセージを受け付ける状態のままで、キューは再開するまで一時停止します。
- **エージェントのプロセスを停止**：ターンが実行中でないときに、セッションのメニュー（⋯）→**その他**→**エージェントのプロセスを停止**を選びます。エージェントのプログラムは終了しますが、セッションと履歴は残り、直前のターンの終わり方（**完了**、**停止**、**失敗**）が表示されます。
- **再開**：ヘッダーの**再開**を押すと、会話全体を引き継いでエージェントが再び起動します。メッセージ（「続けるメッセージ…」）を送るだけでも再び起動します。Claude Code、Codex、Customのどれでも同様です。**完了**の後は、次のメッセージを送るだけで足りるため、**再開**は控えめなボタンになります。VS Codeやターミナルなどから数秒前にセッションへ書き込みがあった場合は、2つのプログラムが1つのセッションに書き込むと履歴が壊れるおそれがあるため、先に確認が表示されます。
- アイドル状態のエージェントは、3時間たつと自動的に停止します（ユーザーの対応待ちがなく、バックグラウンドタスクも実行されていない場合）。次のメッセージを送ると、再び起動します。

## セッションにゴールを設定する

ゴールを設定すると、設定した条件が満たされるまで、エージェントがターンをまたいで作業を続けます。セッションのメニュー（⋯）→**ゴールを設定**を開くか、Claude CodeまたはCodexのセッションで `/goal` に続けて条件を入力します。「完了」がどういう状態かを書き（例：「npm testが通り、アップロードページが2GBのファイルを扱える」）、**作業を開始**（またはCtrl+Enter）を押します。

- **Claude Code**は作業を続けます。各ターンの後に、簡単な確認でゴールが達成されたかどうかを判定します。
- **Codex**は、ゴールが達成されたと判断するまで作業を続けます。
- **Custom**は作業を続けます。各ターンの後に補助モデルが根拠を確認し、次のステップを伝えます。進捗が止まると一時停止します。実行するラウンド数は、[設定 → Custom → ゴール → ゴールが一時停止するまでのラウンド数](/settings?s=custom&find=Rounds%20before%20a%20goal%20pauses)で設定した回数が上限です。

ゴールが設定されている間は、メッセージ欄の上にバーが表示され、ゴールとその状況（作業中、一時停止、行き詰まり：エージェントに対応が必要、使用量またはトークンの上限で停止）、確認した回数、費やした時間とトークン、直近の確認の理由が示されます。**一時停止**と**再開**はCodexとCustomで使えます。**クリア**を押すと、ゴールへの作業を終了します。サイドバーでは、ターゲットのマークでゴールのあるセッションが分かります。

## セッションをフォークする

フォークは、ここまでの会話を引き継いで別の方法を試す新しいセッションです。元のセッションはそのまま残ります。

1. セッションのメニュー（⋯）→**フォーク**を選びます。または、返信の下にある**この返信からフォーク**を押すと、そこまでの会話だけが引き継がれます（Claude Codeではどの返信でも、CodexとCustomでは完了したターンの最後の返信で可能です）。
2. フォークで行うことを書きます（「フォークでは代わりに何を試しますか？」）。
3. **フォーク**（またはCtrl+Enter）を押します。

フォークが開き、タイトルは「… · fork」となり、エージェント、モデル、思考レベル、権限、アカウントは元と同じです。先頭の行に「元のセッション：…」と表示され、**開く**が付きます（Codexのフォークには、その後の内容だけが表示されます。それより前の会話は元のセッションにあります）。フォークは、Claude Code、Codex、Customで使えますが、別のアプリで開いているセッションでは使えません。会話が圧縮される前のClaude Codeの返信もフォークできます。その場合、フォークは、圧縮される前の状態のまま、その返信までの会話全体から始まります。

## ここから編集

自分のメッセージまで戻って、別の内容に言い換えます。

1. メッセージの下にある**ここから編集**を押します。
2. テキストを変更します。
3. このメッセージ以降のエージェントによる変更も取り消すには、**このメッセージの前の状態にファイルを戻す**にチェックを入れます。
4. **ここから送信**（Enter）、または**キャンセル**（Esc）を押します。

会話は、そのメッセージの直前までのコピーで続き、このコピーが元のセッションのタイトルを引き継ぎます。元のセッションはアーカイブされます。ファイルを元に戻せるのは、Claude Code（このアプリから送ったメッセージのチェックポイントを使用）、Custom（Custom自身の編集で変わったファイル。コマンドによる変更は戻りません）、およびワークツリー内のすべてのセッション（メッセージを送るたびにスナップショットを作成）です。Codexのセッションでファイルを戻せるのは、ワークツリー内だけです。ターンが実行中の場合は、先にエージェントを停止してください。ここから編集は、Claude Code、Codex、Customで使えます。

## 別のエージェントで続ける

会話を別のエージェントに引き渡して、そこで続けます。

1. セッションのメニュー（⋯）→**Codexで続ける**（または**Claude Codeで続ける**、Customにモデルが設定されている場合は**Custom Agentで続ける**）を選びます。
2. メッセージ欄の上にメモが表示され、次のメッセージがそちらに送られることを示します。モデル、思考レベル、権限の選択は、新しいエージェントに適用されます。×（「ここに留まる」）を押すと取り消せます。
3. メッセージを書くか、そのまま送信して続けます。

同じフォルダで新しいセッションが開き、ここまでの会話が引き継がれます。内容は、最初のリクエスト、約15,000トークンに収まる直近のメッセージ、変更されたファイルです。新しいエージェントには会話全体の保存場所が伝えられるため、省かれた内容も読めます。最初のメッセージには「Claude Codeから続けています」と表示され、**そのセッションを開く**と、引き継がれたメッセージを表示するボタンが付きます。元のセッションには「この会話はCodexで続けられました」と表示され、**開く**が付きます。この機能は、Claude CodeとCodexのセッションから使えます。

## 会話を圧縮

圧縮すると、ここまでの履歴が要約に置き換わり、モデルのコンテキストに空きができて、この先のやり取りに使えるようになります。セッションのメニュー（⋯）→**その他**→**会話を圧縮**を選ぶか、メッセージ欄のコンテキストメーターをクリックし、**圧縮**で確定します。Claude CodeとCodexで、ターンの合間に使えます。Customは、長くなった会話を自動で要約します。

## 名前の変更、ピン留め、スヌーズ、完了、アーカイブ、削除

これらの多くは、セッションのメニュー（⋯）と、サイドバーの行のメニューにあります。行にポインタを合わせて末尾の**⋯**をクリックするか、右クリックします（スマートフォンでは、**⋯**をタップします）。

- **名前を変更**：新しいタイトルを入力します（200文字まで）。Enterで保存、Escでキャンセルです。ヘッダーまたはサイドバーのタイトルをダブルクリックするか、選択した行でF2を押しても、同じ操作ができます。
- **フォルダ名を変更**（サイドバーで、プロジェクトに属さないセッション用）：セッションが作業するフォルダに、独自の名前を付けます。サイドバー、セッションの行、フォルダのメニューで、すべての端末にその名前が表示されます。ディスク上のフォルダ名は変わりません。空にすると、フォルダ本来の名前に戻ります。
- **先頭にピン留め** / **ピン留めを外す**：ピン留めしたセッションは**ピン留め**グループに残り、ドラッグして並べた順に表示されます。下にあるグループ（プロジェクトやフォルダ、今日、昨日…）のセッションをピン留めにドラッグしてもかまいません。まだ何もピン留めされていないときは、「ここにドロップしてピン留め」にドラッグします。
- **スヌーズ**：セッションを下部の**スヌーズ中**グループに隠し、**1時間**、**3時間**、**今夜**（午後5時前の場合）、**明日の朝**、**翌週**（月曜の朝）、または**日時を選択**で指定した時刻まで表示しません。時間になると通知とともに自動で戻り、対応が必要になった場合はそれより早く戻ります。**スヌーズを解除**を押すと、すぐに戻ります。
- **完了にする：いったん終了**：作業が終わったセッション向けです。エージェントが停止し（ターンの実行中は選べません）、セッションは既読として扱われます。履歴とワークツリーは残ります。ワークツリー内のセッションでは、ワークツリーのダイアログが開き、取り除くことができます。
- **アーカイブ** / **アーカイブを解除**：セッションを一覧から外します。何も削除されません。アーカイブしたセッションは検索ボックス（Ctrl+K）で見つかり、**アーカイブ済み**と表示されます。開いて、メニューの**アーカイブを解除**を選びます。
- **セッションを削除**：確認すると、セッションの履歴がディスクから削除されるため、エージェント自身のコマンドラインやVS Codeからも見えなくなります。この操作は元に戻せません。サイドバーの行のメニューにある**削除**も同じ動作です。

削除するまで、アプリはすべてのセッションを保持します。エージェント自身のプログラムが会話を削除した場合（Claude Codeは、設定しない限り30日後に削除します）も、セッションは一覧に戻り、開けます。1年間誰も使っていないセッションは自動的に削除されます。ただし、ピン留めしている場合や、設定 → 一般で変更した場合は除きます（[使われていないセッションを削除](/guide/app#delete-inactive-sessions)を参照）。

ピン留め、ピン留めの解除、アーカイブ、アーカイブの解除、スヌーズを行うと**元に戻す**付きの通知が表示され、8秒以内ならCtrl+Zでも元に戻せます。

## 閲覧専用リンクを共有

セッションのメニュー（⋯）→**閲覧専用リンクを共有**を選ぶと、パスワードなしで誰でも開けるリンクが作成されます（[機密セッション](#keep-a-session-confidential)では使えません）。リンクを開いた人は、会話の進行をリアルタイムで見られます（メッセージ、名前で示されるステップ、ファイルの変更、エージェントが表示したページ）。コマンドの出力やエージェントの思考は見えず、入力や変更もできません。リンクが有効な期間（**1日**、**1週間**、**1か月**、**オフにするまで**）を選んで**リンクを作成**を押します。リンクが表示されるのは一度だけです。同じダイアログには、現在有効なリンクと、それぞれが開かれた回数が一覧表示され、リンクをオフにすることもできます。詳しくは[スマートフォン、他のマシン、共有](/guide/devices)を参照してください。

## 会話をエクスポートする

セッションのメニュー（⋯）→**エクスポート**を選ぶと、会話をチャットの外に取り出せます。

- **Markdownとしてエクスポート**は、セッションのタイトルを名前にしたMarkdownファイルとしてダウンロードします。保存したり、送ったり、任意のメモアプリで開いたりできます。
- **Markdownとしてコピー**は、同じテキストをクリップボードにコピーします。メモ、メール、他のアプリに貼り付けられます。
- **ドキュメントとして保存**は、会話をドキュメントにして、セッションのプロジェクトに保存します（プロジェクトの**ファイル**に表示されます。プロジェクトがない場合は、この会話に保存されます）。そこで読んだり、編集したり、コメントしたり、印刷したり、WordやPDFとしてエクスポートしたりできます。準備ができるとメッセージが表示され、**開く**でドキュメントに移動します。

含まれる内容：タイトルと日付、続いてユーザーの各メッセージとエージェントの各返信が、時刻とともに順番に並びます。ターン内のステップは省かれ、代わりに「2分間作業 · 5ステップ」のような1行が入ります。エージェントが渡したファイルは名前で一覧表示されます。回答カードは読めるテキストになり、表は表のまま残ります（比較、データ表、グラフの数値）。図はMermaidコード、数式はLaTeXのまま、エージェントが書いたとおりに残ります。ドキュメントには、メッセージに添付した画像と、エージェントが渡した画像も含まれます。

[機密セッション](#keep-a-session-confidential)もエクスポートでき、そのドキュメントも、他の作業内容と同様にこのコンピューターに残ります。Webの画像は取得されず、リンクのままになります。ターミナルからは、`hydor sessions export` で同じことができます（[ターミナルでHydorを使う](/guide/terminal)）。

## ワークツリーで作業する

ワークツリーは、新しいブランチ上にあるリポジトリのファイルの別コピーです。エージェントは自分のコピーに触れずに変更でき、1つのリポジトリで複数のエージェントが同時に作業できます。

- **作成する**：スタートページで**フォルダ**を開き、**…から新しいワークツリーを作成**をオンにします（フォルダがGitリポジトリ内にある必要があります）。アプリは、チェックアウト中のブランチから、`agent/` にタスクの数語を続けた名前のブランチを作り、アプリのデータフォルダ内にそのためのフォルダを作成します。このスイッチの設定は次回も保持されます。
- **スナップショット**：ワークツリーでは、メッセージを送るたびにアプリがファイルのスナップショットを保存するため、[ここから編集](#edit-from-here)でファイルを元に戻せます。
- **確認する**：セッションのメニュー（⋯）→**フォルダとコード**→**ワークツリー：agent/…**で、ブランチと分岐元のブランチ、フォルダ、先行または遅れているコミット数、未コミットの変更が表示され、**変更を確認**と**Gitで開く**が使えます。
- 作業が終わったら**取り除く**：同じダイアログで**ワークツリーを取り除く**を選びます。フォルダはなくなりますが、セッションの履歴は残ります。ブランチは残るため、コミット済みの内容は失われません。ただし、**ブランチ … も削除**にチェックを入れた場合は別です（新しい内容のないブランチは、そのまま削除されます）。未コミットの変更がある場合は、先に**… 件の未コミットの変更を破棄**にチェックを入れます。エージェントが実行中の場合は停止し、そのワークツリーを共有しているフォークや編集コピーも使えなくなります。

## プルリクエストを開く

セッションのブランチから、セッションのメニュー（⋯）→**フォルダとコード**→**プルリクエストを開く**を選ぶと、GitHubまたはGiteaでプルリクエストが開きます。**自動で書く**は、コミットと差分からタイトルと説明の下書きを作ります。チェックボックスで、未コミットの変更を先にコミットできます。**下書き**にチェックを入れると下書きとして扱われます。ブランチは、**プルリクエストを開く**を押したときにプッシュされます。[設定 → ソース管理](/settings?s=scm)でアカウントが必要です。**既存のプルリクエストをリンク…**を選ぶと、ほかの場所で開いたプルリクエストをリンクできます。

リンクすると、その状態とチェックの結果がサイドバーとヘッダーにバッジで表示され、数分ごとに更新されます。マージされたときやチェックが完了したときは通知されます。同じメニュー項目は**プルリクエスト #12**に変わり、**GitHubで開く**（またはGiteaで開く）、**変更をレビュー**、**今すぐ確認**、**リンクを解除**が使えます。サブメニューの**変更をレビュー**では、ブランチの変更をファイルごとに確認できます。詳しくは[システム：ファイル、Git、ターミナル、プレビュー](/guide/files-git)を参照してください。

## 使用量の上限でセッションが止まったとき

Claude CodeまたはCodexのプランの使用量が尽きると、メッセージ欄の上にバナーが表示され、どのアカウントの、どの上限に達したか、そしていつリセットされるかが分かります。そのエージェントのアカウントが1つだけの場合は「You've hit the Claude Code usage limit」、複数あってどれにも使用量が残っていない場合は「All your Claude Code accounts have hit their usage limit」、ほかのアカウントにまだ余裕がある場合はアカウント名（「Work has hit its usage limit」）が表示されます。

そのエージェントのほかのアカウントにまだ使用量が残っている場合、**上限時にアカウントを切り替え**がオンなら、バナーは表示されません。セッションはそのアカウントに移って続行されます（新しいセッションもそのアカウントで始まります）。オフの場合は、バナーにそのアカウントの名前が表示され、**オンにする**が用意されます。

- **リセット時に再開**：上限がリセットされた1分後に、「Continue where you left off.」というメッセージでセッションが自動的に続きます。バナーには再開の時刻と**キャンセル**が表示されます。
- **リセットを使う**：アカウントに上限のリセットが残っている場合、バナーにその数が表示され、これで1回分をすぐに使えます。
- 設定 → アプリ → 一般の[Resume after usage limits](/settings?s=general&find=Resume%20after%20usage%20limits)は、上限で止まったすべてのセッションに対して同じ動作を行います。オンにすると、セッション内に警告は表示されません。代わりにメッセージ欄の上の1行に、（バナーと同じく）どのアカウントの、どの上限に達したか、そしていつ再開するかが表示されます（「All your Claude Code accounts have hit their usage limit」に続けて「Current session (5 h) · Continues by itself in 3 h 15 min.」）。リセットが残っている場合は**リセットを使う**も表示され、**キャンセル**もあります。**停止**で自分で止めたセッションは、自動では再開しません。

再開の時刻は上限に合わせて変わります。リセットの時刻が変わった場合や、使用量が早めに戻った場合は、そのときにセッションが再開します。[使用量・上限・コスト](/guide/usage)もご覧ください。

## VS Codeやターミナルで実行中のセッション

このコンピューター上のClaude CodeとCodexのセッションはすべて一覧に表示されます。VS Code、ターミナル、Claudeのデスクトップアプリで実行しているものも同様です。それらが向こうで実行されている間、一覧には「Working in VS Code」「Needs you in terminal」「Open in VS Code」（グレーのドット）と表示され、作業の様子を読むことができます。向こうで入力待ちになっている場合、アプリが通知するのは、1分たってもまだ待っているときだけです。

- **Claude Codeセッションを引き継ぐ**：ヘッダーの**ここで続ける**を押すか、そのままメッセージを送ります（「Open in VS Code — sending moves it here」）。先に確認が表示されます。引き継ぐと、そのアプリでのセッションは終了して作業も止まり、これまでの履歴がすべて付いた状態でこちらで再開されます。そのアプリでは終了として表示されますが、あとからそちらで開き直すこともできます。
- 別のアプリで開いている**Codexセッション**は、こちらでは読み取り専用です。向こうのCodexプロセスは1つで、すべてのスレッドを担当しているためです。向こうで続けるか、向こうで閉じてからこちらで再開してください。
- 別のアプリでセッションが開いている間は、フォークできません。

## サブエージェント

エージェントは、作業の一部をサブエージェントに任せ、その結果を受け取ることができます。サブエージェントには2種類あり、アプリがどちらかを表示します。

- **Hydorサブエージェント**は、Hydorが開始する独立したセッションで、エージェントもモデルも自由に選べます。親の会話にあるサブエージェントのカードに1行表示され、サイドバーでは親の下に並び、開いて話しかけることもできます。コストは独自に発生し、親の支出上限のうちの割り当て分を持ちます。その返信は、メッセージとして親に戻ります。
- **Claude Codeサブエージェント**（Codexの場合は「Codexサブエージェント」で、セッション自身のプログラムの名前になります）は、そのプログラムがセッション内で、作業のごく一部のために実行するものです。表示や開き方はHydorサブエージェントと同じで、会話内のカードの1行、サイドバーとトレイの行、会話の全体を見られる専用ページがあります。ただし話しかけることはできず（リードは可能です）、使った分はリード自身の分として数えられ、支出上限の割り当てもありません。

サイドバーでは、サブエージェントは作業中か入力待ちの間、親の下にまとめて折りたたまれます。Hydorのものもプログラム自身のものも、まとめて1行です（「3 subagents · 1 needs you」「2 subagents」）。その行をクリックすると、1件ずつの行が表示されます。終了したものは、見ている場合を除いてサイドバーから消え、いずれかを見ている間はその行も開いたままです。スウォームのメンバーは「swarm members」、キャンペーンのメンバーは「campaign members」と表示されます。親の会話では、1回のターンで開始されたサブエージェントが、そのターンの下に1枚のカードとしてまとめて表示されます。Hydorサブエージェントは1枚のカード、プログラム自身のもの（Claude CodeまたはCodex）は別の1枚のカードです。カードの最上段には、数と種類、全員に共通する内容（「6 Claude Code subagents · Sonnet 5.5」「3 Hydor subagents · Claude Code · Sonnet 5.5」、ディープリサーチでは「4 researchers」）、そして状況（「5 working · 1 done」、ほかに「1 needs you」「1 stopped」「1 failed」）が表示されます。この行をクリックするとカードの折りたたみと展開ができます。いずれかが作業中か入力待ちの間は開いていて、すべて終了すると、その1行に折りたたまれます。

その下には、サブエージェントごとに1行あります。状態の色のドット（作業中は青でゆっくり点滅、入力待ちは黄色、完了は緑、停止はグレー、失敗は赤）、タイトル、広い画面では他と違う点（種類やモデル、そのエージェントとして動いている自分のエージェント、ティア）、そして状況（ここまでの作業時間、「Needs you」、終了時刻（「3 min ago」）、「Stopped」、「Failed」）です。Hydorサブエージェントの行にはコストも表示され、ティアを上げたものにポインタを合わせると、「Stepped up from」に続けて最初のティアとその理由が表示されます。行をクリックすると、そのサブエージェントが開きます。ほかが作業中の間、終了したものは「4 finished: 」とそのタイトルのような1行にまとまり、クリックすると中身が見られます。失敗したものは、それぞれ独立した行のまま残ります。作業中のものが6件を超える場合は5件が表示され、**Show 3 more**があります。

1回のターンで開始されたサブエージェントが1つだけの場合は、1行のカードで表示されます。状態ドット付きのアイコン、タイトル、その種類（「Claude Code subagent · Explore · Sonnet 5.5」、または「Hydor subagent · Claude Code · Sonnet 5.5」。エージェントとティアがある場合はそれも表示）、そして状況です。

止めるには、その行にポインタを合わせる（またはTabキーで移動する）と、時間の代わりに**停止**が表示されます。タッチ画面では小さな停止ボタンが常に表示されています。Claude Codeサブエージェントは先に確認があり（「Stop this subagent?」）、Hydorサブエージェントはすぐに止まります。Codexサブエージェントは、ここから1件ずつ止めることはできません。カードの**⋯**メニューには**Stop 5 subagents**（止められる数が入ります）があり、確認なしですべて止まります。サブエージェントを開始した呼び出しは、そのターンの折りたたまれた作業内のステップとして残ります。

バックグラウンドで作業していたサブエージェントが戻ると、親の会話に1行表示されます。「Reply from」とそのタイトル、または「… was stopped」「… stopped with an error」と、書かれた内容の冒頭です。クリックすると返信を読むことができ、**セッションを開く**でそのセッションに移動できます。Codexサブエージェントの返信は、行を開いたときに、そのサブエージェント自身の会話から取得されます。親がまだ作業中に届いた返信は、その前後のステップの間の位置に表示されます。

Hydorサブエージェントの中では、メッセージ欄の上のバーに「Subagent of」と親のタイトル（「its replies go back there」）が表示され、**親を開く**があります。Claude CodeやCodexのサブエージェントもセッションとして開きますが、読み取り専用です。与えられたタスク、ステップ、返信が表示され、作業中はリアルタイムで更新されます。メッセージ欄はなく、**再開**もセッションメニューもありません。メッセージ欄の代わりに、バーに「Claude Code subagent of」と親のタイトル（「its replies go back there」）が表示され、**親を開く**があります。Claude Codeサブエージェントが作業している間は、ヘッダーの**停止**で止められ、先に確認があります。メッセージの送信、再開、フォーク、ハンドオフ、削除はできません。そのプログラムが親のセッション内で実行しているため、親に話しかけてください。

親自身のターンが終わっても、サブエージェントがまだ実行中の間は、親は終了していません。そのドットは青く呼吸するように点滅し続け、メッセージ欄の停止ボタンのリングも回り続け、ステータスは「Working · 2 subagents running」となり、「Done」のマークは付かず、「Active」に残り、メッセージを送ることもできます。これはClaude CodeセッションにもCodexセッションにも当てはまります。Hydorサブエージェントも、自分のターンが終わったあとに、開始したサブエージェントやバックグラウンドタスク（コマンド、モニター）がまだ実行中であれば、実行中として数えられるため、その親は完了ではなく作業中と表示されます。親の支出上限はそのHydorサブエージェントも対象とし、Claude CodeやCodexのサブエージェントが使った分は、すでに親自身の分です。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research)もご覧ください。

メッセージ欄の上の1行に、そのセッションが開始したすべてのものがまとめて表示されます。サブエージェントとバックグラウンドタスク（コマンド、モニター、ワークフロー）です。「2 subagents and 1 background task running」のように表示され、Hydorサブエージェントが入力待ちのときは黄色で「1 needs you」、何も実行中でないときは「3 subagents · 2 background tasks · all done」と表示されます。セッションを開くたびに折りたたまれた状態になります。クリックすると、1件ずつ一覧表示されます。上から入力待ち、実行中、終了済みの順で、終了済みは新しい順に並び、5件ほどを超えると内部でスクロールします。どの行も同じ形式です。状態ドット付きのアイコン、タイトル、その種類（「Hydor subagent · Claude Code · Sonnet 5.5」「Claude Code subagent · Explore · Haiku 5.5」「Command」「Monitor」「Workflow」）、状況（「Working · 2m 10s」「Needs you」「Done · 3 min ago」「Stopped」「Failed」）、Hydorサブエージェントのコスト（プログラムのサブエージェントには表示されません。その使用分は親のものです）、**開く**、そして実行中は停止ボタン（円の中の四角）です。その種類にポインタを合わせると、実行しているのが誰かが表示されます。「Hydor started it as a session of its own: open it to watch it or talk to it」、または「Claude Code runs it inside this session: open it to watch it」です。**開く**を押すと、Hydorサブエージェント、またはClaude CodeやCodexのサブエージェントのセッションに移動します。コマンド、モニター、ワークフローは、ページの右側のパネル（スマートフォンでは画面全体）に開き、タイトル、種類、状態、実行中は**停止**、その下に出力が表示されます。出力は2秒ごとに更新され、上にスクロールしない限り最新の行が表示されます。サブエージェントの停止ボタンは「Stop this subagent」、タスクの停止ボタンは「Stop this task」と表示されます。行の右端の**すべて停止**は、メッセージ欄の横の停止ボタンと同じように、実行中のものをすべて止めます。スウォームやキャンペーンのメンバーはここには一覧表示されず、そのボードに表示されます。終了したタスクは、エージェントのプログラムが止まるまで一覧に残ります。VS Codeやターミナルで開いているセッションでは、タスクは一覧表示されますが、止めることはできません。

1つのセッションが同時に実行できるHydorサブエージェントの数は、[設定 → 機能 → サブエージェント](/settings?s=children)で設定します。これらの設定はHydorサブエージェント向けです。Claude CodeとCodexのサブエージェントは、それぞれのセッション内で実行されるためです。設定 → モデル → ティアで[Lead with subagents](/settings?s=models&find=Lead%20with%20subagents)をオンにすると、セッションのメインエージェントが計画を立て、明確な部分をより低いティアのサブエージェントに任せ、その作業を確認します。

## セッションメニューのすべての項目

セッションの右上にある⋯ボタンで、そのセッションのメニューが開きます。項目によっては、該当する場合にだけ表示されます。[機密セッション](#keep-a-session-confidential)のメニューには**閲覧専用リンクを共有**、**プルリクエストを開く**、**ブラウザを開く**、**接続済みアカウント**、**自動化にする**、**アプリとして保存**がなく、メモリもオフのままです。

- **名前を変更**：タイトルをその場で編集します。
- **先頭にピン留め** / **ピン留めを外す**。
- **スヌーズ**（時刻のサブメニュー）。スヌーズ中は **スヌーズを解除（…に戻る）** と表示されます。
- **完了にする：いったん終了**：エージェントを停止し、セッションを既読にします（ターンの実行中は使えません）。
- **フォーク**：この会話から新しいセッションを作ります（Claude Code、Codex、Custom）。
- **Codexで続ける**、**Claude Codeで続ける**、**Custom Agentで続ける**：会話を別のエージェントに引き継ぎます（Claude CodeとCodexから）。
- **ゴールを設定**：条件が満たされるまで作業を続けます（Claude Code、Codex、Custom。ゴールが未設定のとき）。
- **セカンドオピニオン**：別の会社のモデルが、依頼内容に照らしてターンの作業を確認し、その結果をそのターンの下に表示します。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research)をご覧ください。
- **閲覧専用リンクを共有**。
- **エクスポート**（サブメニュー）：**Markdownとしてエクスポート**、**Markdownとしてコピー**、**ドキュメントとして保存**。[会話をエクスポートする](#export-a-conversation)をご覧ください。
- **フォルダとコード**（サブメニュー。フォルダのあるセッション向け）：
  - **変更をレビュー**：ブランチによる変更をファイルごとに表示します。
  - **プルリクエストを開く**。すでにある場合は **プルリクエスト #12** と表示されます。
  - **ワークツリー：agent/…**：ワークツリーのダイアログです（ワークツリー内のセッション）。
  - **フォルダを開く**：セッションのフォルダでファイルを開きます。
  - **Finderで表示**、**エクスプローラーで表示**、**フォルダで表示**：デスクトップアプリで、セッションのフォルダをシステムのファイルマネージャーで選択した状態にします（[ファイルとフォルダを扱う](/guide/files-git#work-with-files-and-folders)をご覧ください）。
  - **ここでターミナルを開く**：フォルダで新しいターミナルを開きます（コンピューターでは下部のパネル、スマートフォンではターミナルページに表示されます）。
- **セッション設定**（サブメニュー）：
  - **メモリ**：横に**オン**または**オフ**が表示されます。このセッションでメモリをオンまたはオフにします（設定でメモリがオフの場合は「すべてオフ」）。[メモリ](/guide/memory)をご覧ください。
  - **支出上限**：横に上限額が表示されます。設定、変更、引き上げができます。[使用量、上限、費用](/guide/usage)をご覧ください。
  - **接続済みアカウント**：接続済みの各アカウントを、このセッションだけオンまたはオフにします。[接続済みアプリ、キー、ツール](/guide/connections)をご覧ください。
  - **スウォーム**：横に**オフ**、**オン**または**キャンペーン**が表示されます。ダイアログが開き、次のメッセージからスウォームまたはキャンペーンをオンまたはオフにできます。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research#set-a-swarm-on-a-hard-problem)をご覧ください。
  - **ディープリサーチ**：横に**オフ**または検索回数が表示されます。ダイアログが開き、次のメッセージからディープリサーチをオンまたはオフにしたり、設定を変更したりできます。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research#turn-it-on)をご覧ください。（スウォームとディープリサーチは、機密セッションと、別のセッションが開始したセッションには表示されません。）
  - **エージェント**：横にエージェント名が表示されます。エージェントのページが開きます（エージェントのあるセッション）。切り替えはメッセージ欄で行います。
- **その他**（サブメニュー）：
  - **ブラウザを開く** / **ブラウザを表示**：このセッション用のエージェントのブラウザです。様子を見たり、操作を引き継いだりできます。[検索とブラウザ](/guide/web)をご覧ください。
  - **自動化にする**：補助モデルがセッションを読み取り、そこからスケジュールタスクの下書きを作ります。内容を自由に変更し、テスト実行で試してから保存します。[スケジュールタスク](/guide/tasks)をご覧ください。
  - **アプリとして保存**：このセッションから新しいアプリを作り始めます。[アプリ](/guide/apps)をご覧ください。
  - **会話を圧縮**（Claude CodeとCodex）。
  - **CLIの再開コマンドをコピー**：ターミナルでこのセッションを続けるためのコマンドです。
  - **エージェントのプロセスを停止**（エージェントが実行中で、ターンが進行中でないとき）。
- **アーカイブ** / **アーカイブを解除**。
- **セッションを削除**：確認後、履歴をディスクから削除します。
