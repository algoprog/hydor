# セッション

セッションとは、1つのフォルダでエージェントと交わす1回の会話のことです。やりたいことを伝えるとエージェントが作業を進め、その様子を見ながら、実行しようとする操作を承認したり、方向を調整したりできます。このトピックでは、セッションに関するすべてを取り上げます。開始ページとそのオプション、エージェントの作業中に表示される内容、ターンの途中でのメッセージ送信、そしてフォークやゴール、ワークツリー、共有まで、セッションのメニューにあるすべての項目です。

![作業中のセッション：エージェントのステップと返信、コマンドの実行を確認するカード](images/sessions.webp)

## セッションを開始する

サイドバーの上部にある**新しいセッション**を押すと、スタートページが開きます。メッセージ欄にやりたいことを書き、その下に並ぶ選択項目を確認して、Enterキーを押します（**開始**を押す方法もあります。スマートフォンでは丸い矢印を押します）。セッションのページがすぐに開き、メッセージと、それに取り組むエージェントの様子が表示されます（**実行中**）。セッションを開始できなかった場合は、ページに理由が表示されます。**スタートページに戻る**を押すと、メッセージ（と添付したファイル）がメッセージ欄に戻ります。

アプリから応答が届く前に接続が切れた場合（スマートフォンがスリープした、ネットワークが切り替わったなど）、ページに**再接続しています…**と表示されます。接続できるようになると、メッセージがどうなったかをアプリに問い合わせます。セッションが開始されていれば開き、セッションが二重に開始されることはありません。約1分たってもアプリに接続できないときは、ページに**アプリに接続できませんでした**と表示されます。**もう一度試す**を押すと、もう一度問い合わせます。

開始から少しすると、セッションにタイトルが付きます。依頼した内容を表す数語（「週末のリスボン旅行」「決済テストの修正」など）で、補助モデル（[設定 → エージェント → モデル](/settings?s=models&find=Helper%20model)）が裏で作成するため、会話には何も表示されません。タイトルはサイドバー、セッションのヘッダー、検索ボックスに表示されます（サイドバーでは、メッセージの文言に代わって、タイトルの言葉が順に現れます）。Claude CodeとCodexにも、それぞれの一覧用に渡されます。タイトルが付くまでの間や、補助モデルが応答できなかったときは、メッセージの冒頭が代わりに表示されます。**名前を変更**で自分で付けたタイトルが置き換えられることはありません。サイドバーには、送信した時点からセッションが一覧され、**アクティブ**の先頭に表示されます（**開始中**）。

メッセージ欄の下の行には、**実行環境**、**モデル**、**フォルダ**（または**プロジェクト**）、**エージェント**、そして右端に**オプション**が並びます。スマートフォンでは、それぞれ画面の下からシートとして開きます。

### エージェントとモデルを選ぶ

**実行環境**には、使えるプログラムがすべて並びます。

- **Claude Code**：Anthropicのエージェントです。Claudeのプランまたは APIキーで使います。
- **Codex**：OpenAIのエージェントです。ChatGPTのプランまたはAPIキーで使います。
- **Custom**：アプリ独自のエージェントです。OpenRouter、Ollama、vLLMのどのモデルでも使えます。[Custom（アプリ独自のエージェント）](/guide/custom)を参照してください。
- ACPに対応した、追加済みのその他のエージェント（Gemini CLI、OpenCode、Qwen Code、Gooseなど）。名前の下にそのコマンドが表示されます。

下部の**Custom用モデル**は[設定 → モデル](/settings?s=models)を開き、**エージェントを追加・管理**は[設定 → その他のエージェント](/settings?s=agents)を開きます。[エージェント、アカウント、モデル](/guide/agents-models)を参照してください。

**モデル**は**自動**で開きます。セッションは最高ティアのモデルで始まり、メインのエージェントは切り出しやすい作業を、より低いティアのサブエージェントに任せます。難しい問題だと分かったときは、最大ティアのモデルに切り替わることもあります（[ティア：作業の種類ごとのモデル](/guide/agents-models#tiers-a-model-for-each-kind-of-job)を参照）。その下のメニューには、選んだエージェント自身のモデルだけが並びます。エージェントのデフォルトには「default」と表示されます。古いバージョンのモデルは「古いモデル2件」の中にまとめられます。一覧が長い場合は**モデルを検索**欄が表示されます（Enterキーで最初の一致を選択）。Customには、設定 → モデルで追加したモデルが並びます。ほかのACPエージェントには、前回の実行時に提示されたモデルが並び、チップは一度実行してから表示されます。

### フォルダ、プロジェクト、新しいタスクフォルダを選ぶ

**フォルダ**チップは、エージェントが作業する場所を示します。そのメニュー（「作業するプロジェクトまたはフォルダ」）には、**プロジェクトやフォルダを検索、またはパスを入力**欄があり、その下に2つの短い一覧が並びます。各行には場所も表示されます。

- **プロジェクト**：プロジェクトが名前順に並びます。最近作業した5件（と選択中のもの）が対象で、それぞれのフォルダも表示されます。選ぶと、フォルダがプロジェクト自身のフォルダになり、そのエージェントと、プロジェクトのガイドラインがセッションに設定されます。チップは**プロジェクト**に変わり、プロジェクト名が表示されます。プロジェクトのグループも同様で、グループ内のすべてのプロジェクトが対象になります。見出しの右端にある**新規**を押すと、プロジェクト（セッション、ファイル、メモリがひとまとまりになったもの）を作成して選択します。[プロジェクトとナレッジ](/guide/projects)と[エージェントガイドライン](/guide/guidelines)を参照してください。
- **フォルダ**：使用中のフォルダと、最近選んだ3つのフォルダが並び、それぞれが入っているフォルダも表示されます。見出しの右端にある**参照**を押すと、ホームフォルダ内のフォルダが一覧されます。
- **新しいタスクフォルダ**（「~/Hydorに新規作成」）：このタスク用の新しいフォルダです。名前は日付とメッセージの数語から付けられます（例：`2026-11-01-plan-trip-lisbon`）。場所は`~/Hydor`で、[タスクフォルダ](/settings?s=assistants&find=Task%20folders)（設定 → 機能 → 自分用のエージェント）で別の場所を指定した場合はそちらになります。

プロジェクト自身のフォルダはそのままプロジェクトとして扱われます。メニューにはプロジェクトとしてのみ表示され、スタートページでプロジェクトではなくフォルダを選んでいた場合でも、そのフォルダで始めたセッションはプロジェクトで作業します。

メニューは、チップの上下のうち広いほうに開き、スクロールせずに収まります。小さいウィンドウでは、表示されるフォルダが減り、次にプロジェクトが減ります。プロジェクトの下にある「ほか2件」のような行を押すと、残りが表示されます。

欄に入力すると、さらに探せます。

- 名前を入力すると、一致するプロジェクトと、最近使ったフォルダ、使用中のフォルダ、ホームフォルダ内のフォルダから一致するものが見つかります。プロジェクトのフォルダが名前で見つかった場合は、プロジェクトとして表示されます。
- パス（`~/code/`、またはホームフォルダからの`code/`）を入力すると、**参照**と同じように、その場所のフォルダが一覧されます。欄の右端の矢印で1つ上のフォルダに移動し、×印またはEscapeキーで一覧に戻ります。
- ↑ ↓とEnterキーで選択します。Tabキー、または行の右端の矢印で、その中のフォルダが一覧されます。

フォルダがgitリポジトリにある場合（新しいタスクフォルダを選んでいないとき）、メニューの末尾にスイッチが表示されます。**mainから新しいワークツリー**（またはチェックアウト中のブランチ）、「リポジトリのコピーに新しいブランチを作成」です。オンにすると、セッションは新しいブランチ上の専用のコピーで作業します。チップには「· 新しいワークツリー」と表示されます。[ワークツリーで作業する](#work-in-a-worktree)を参照してください。

セッションが新しいタスクフォルダで始まるかどうかは、エージェントによって初期設定が異なります。ほとんどのエージェントは、フォルダを選ばない限り新しいタスクフォルダで始まります。プログラマーは選んだフォルダで作業し、1つのプロジェクト専用のエージェントはそのプロジェクトで作業します。

### エージェントを選ぶ

**エージェント**は、セッションがどの役割で作業するかを決めます。**一般**（ほかを選ぶまでの設定。専用のエージェントを持つプロジェクトでは、そのエージェント）、**リサーチャー**、**ライター**、**プログラマー**、**チューター**、**プランナー**、**アナリスト**、**アプリビルダー**、または**自分用**の下にある自作のエージェント（どこでも使えるものと、選択中のプロジェクトのもの）から選べます。ポインターを合わせると、そのエージェントの役割と、使うプログラムやモデルが表示されます。選ぶと、そのエージェントが推奨するプログラム、モデル、権限（ティアに基づく場合は、そのティアのモデル）が設定され、接続済みのアカウントがオンになることもあります。**エージェントを作成・変更**は[エージェントのページ](/agents)を開きます。[エージェント](/guide/agents)を参照してください。

### オプション：思考レベル、権限など

**オプション**には、そのほかの設定がまとまっています。チップには「オプション」と表示されるか、通常から変えた内容（「高 思考レベル · プラン · 上限$5.00」など）が表示されます。コンピューターでは、メニューの末尾に、メッセージ欄でShift+Tabキーを押すと権限を切り替えられるという案内が表示されます。

- **思考レベル**：モデルがどれだけ深く考えるかを決めます。**デフォルト**はモデル本来の設定を使います。その下に、モデルが提供するレベルが並びます。**低**（高速、軽い推論）、**普通**（バランス型）、**高**（深い推論）、**Xhigh**（さらに深い推論）、**最大**（最大の推論）があり、モデルによっては**ミニマル**、**なし**、**Ultra**もあります。Customでは、推論するエンドポイントのモデルにだけ表示されます（低・普通・高）。他のACPエージェントはレベルを一覧にしたときに表示し、レベルのないモデルでは表示されません。
- **権限**：確認なしにエージェントができることです。モードはエージェントごとに異なります。[各権限モードの意味](#what-each-permissions-mode-means)を参照してください。メッセージ欄でShift+Tabキーを押すと、次のモードに切り替わります。
- **アカウント**：[設定 → エージェント → アカウント](/settings?s=accounts&find=Accounts)でClaude CodeまたはCodex用のアカウントを追加した場合にのみ表示されます。**サインイン情報**はエージェント自身のアカウントです。ほかのアカウントを選ぶと、このセッションはそのアカウントで実行されます。**アカウントを管理**は設定を開きます。
- **機密**：鍵のアイコン付きのスイッチです（「このコンピューター上のモデルのみ。外部には何も送信されません。」）。査読中の論文、患者データ、顧客のコードなどに使います。**実行環境**は**Custom**に、**モデル**はここにインストールされている最良のモデルになります。[セッションを機密にする](#keep-a-session-confidential)を参照してください。
- **メモリ**：設定でメモリがオンのときのみ表示されます。**オン**ではエージェントが記憶している内容を使い、そこに追加します。**このセッションではオフ**では、何も参照せずに始まり、このセッションの内容は何も保存されません。[メモリ](/guide/memory)を参照してください。
- **支出上限**：このセッションで使える最大額です（APIの価格で計算）。金額を入力して**設定**を押すか、$1、$5、$10、$25から選びます。**上限なし**にすると上限が外れます。上限に達すると、引き上げるまでセッションは停止します。[使用量、制限、費用](/guide/usage)を参照してください。
- **スウォーム**：**オフ**、または**スウォーム**：リードエージェントがタスクをいくつもの切り口に分け、それぞれにメンバーを割り当てます。同時に動くメンバーの数は**スウォームの規模**で決まります（[設定 → 機能 → サブエージェント](/settings?s=children&find=Swarm%20size)）。メンバーは見つけたことをボードで共有し、互いにメッセージを送り合います。難しい問題向けで、費用はエージェント1つの場合の数倍かかります。もう1つは**キャンペーン**（「大きな変更を複数の部分に分け、それぞれをワークツリーで」）です。リードが1つの大きな変更を部分に分け、メンバーがそれぞれ専用のブランチでテストとともに1つずつ作成し、リードがそれらをマージします。フォルダはgitリポジトリである必要があります（[キャンペーン](/guide/engineering#campaigns-a-big-change-in-many-parts)を参照）。
- **リサーチ**：**オフ**、または**ディープリサーチ**：エージェントが検索を計画し、各部分にリサーチャーを送り、重要な主張を2つの情報源で確認して、出典付きのレポートを届けます。**同時リサーチャー数**（1～8）、**ラウンド数**（1～5）、**検索の合計**（10～500）、**レポート**（**ページ**または**Word**）を設定できます。
- **ゴール**：**オフ**（「エージェントは、終わったと判断するまで作業します」）、または**完了するまで**（オプションのチップは「ゴールモード」になります）（「合意したチェックが満たされるまで、ラウンドを重ねて作業します」）。最初のメッセージがゴールになり、エージェントはまず確認方法を考えて提示し、同意するまで何も始めません。**確認の頻度**で、進め方をどのくらいの頻度で確認するかを選びます。どのエージェントでも使えますが、多くのターンを消費し、合意した上限（ラウンド、金額、時間）で停止します。[ゴール](/guide/goals)を参照してください。
- **アリーナ**：**オフ**、または**モデルを比較**：同じメッセージが、チェックを付けた1～2個のモデルにも送られ、それぞれが同じフォルダ内の専用セッションで作業します。回答を比べて最良のものを残すと、ほかはアーカイブされます。一覧が長い場合は**モデルを探す**欄が役立ちます。gitリポジトリでは、フォルダメニューの**新しいワークツリー**をオンにすると、各モデルが専用のコピーで作業します。

スウォーム（またはキャンペーン）とディープリサーチは、どちらもHydorサブエージェントを率いるため、一方をオンにするともう一方はオフになります。**ゴール**はスウォームと併用できます（ゴールを持つのはそのリードです：[スウォームのためのゴール](/guide/goals#a-goal-for-a-swarm)）が、キャンペーン、ディープリサーチ、アリーナとは併用できません。**ゴール**をオンにするとこれらはオフになり、これらのいずれかをオンにするとゴールはオフになり、これらを率いるセッションにはゴールを設定できません（メニューに**ゴールを設定**は表示されません）。**機密**をオンにすると、スウォーム、ディープリサーチ、アリーナはオフになり、これらのいずれかをオンにすると機密はオフになります（機密セッションでもゴールは実行できます）。スウォーム、ディープリサーチ、アリーナ、ゴールは費用がかさむため、次のセッションには引き継がれません。選んだリサーチの数値とアリーナのモデルは、再びオンにしたときのために、このブラウザに保存されます。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research)を参照してください。

### 各権限モードの意味

**Claude Code**

| モード | エージェントができること |
| --- | --- |
| 確認（デフォルト） | 設定で許可されていない編集とコマンドの前に確認する |
| 編集を承認 | ファイルは自由に編集し、それ以外のコマンドの前に確認する |
| 自動 | 安全性チェックが通常の操作を承認し、リスクのある操作はユーザーに確認する |
| プラン | 読み取りと計画のみを行い、承認用のプランを提案する |
| バイパス | 確認しない（フルアクセス） |

**Codex**

| モード | エージェントができること |
| --- | --- |
| プラン | まず話し合って計画を立て、確認の質問をすることもある |
| 読み取り専用 | ファイルを読んで回答し、何かを変更する前に確認する |
| 自動（デフォルト） | 自分のフォルダ内でファイルを編集しコマンドを実行し、その外に出るときは確認する |
| 自動レビュー | 自動と同様だが、レビュー担当のエージェントが承認リクエストに回答する |
| フルアクセス | サンドボックスも承認もなし |

Docker内ではCodex自体のサンドボックスを起動できないため、そこでは**フルアクセス**がデフォルトになり、メニューにその理由が表示されます。

**Custom**

| モード | エージェントができること |
| --- | --- |
| 確認（デフォルト） | ファイルの編集とコマンドの実行の前に確認する。見て回るだけなら自由に実行する |
| 編集を承認 | フォルダ内のファイルは自由に編集し、コマンドの実行前に確認する |
| 自動 | 通常の手順はそのまま進み、リスクのあるものはクイックチェックでユーザーに確認する |
| フルアクセス | 承認の確認もコマンドのサンドボックスもなしで、ツールとコマンドをコンピューターのアカウントの権限で実行する |
| プラン | 読み取りと計画のみ。編集もコマンドもなし |

フルアクセス以外では、Customはリスクのあるコマンドの前に確認します。確認、編集を承認、プランでは、フォルダ外のファイルや、キーやパスワードを含むファイルを読んだり変更したりする前にも確認します。自動では、クイックチェックが先にそれらを判断します。[Custom（アプリ独自のエージェント）](/guide/custom)を参照してください。

**その他のACPエージェント**には、それぞれ独自のモードがあり、エージェントを一度実行すると一覧に表示されます。

### セッションを機密にする

コンピューターの外に出してはならない作業があります。査読のために送られてきた論文（多くの学会やジャーナルが、投稿原稿をオンラインのAIに渡すことを禁じています）、患者や顧客の記録、契約に基づいて扱う企業のコードなどです。機密セッションは、このコンピューター上のモデルで実行され、その内容はどこにも送信されません。

1. スタートページで**オプション**を開き、**機密**をオンにします（「このコンピューター上のモデルのみ。外部には何も送信されません。」）。チップには「機密」と表示されます。
2. **実行環境**は**Custom**に、**モデル**はここにインストールされている最良のモデルになります。オンの間は、それぞれのメニューにこれらしか表示されません。まだ1つもない場合はその旨が表示されます。[設定 → エージェント → モデル](/settings?s=models)で、このコンピューターに推奨されるモデルをワンクリックでインストールできます。
3. やりたいことを書き、論文を添付するかそのフォルダを選んで、Enterキーを押します。例：「添付の投稿論文を、NeurIPSの査読者として査読してください。要約、長所、短所、著者への質問、スコアをお願いします。」

このコンピューター上のモデルとは、ここにあるOllamaとvLLMのモデル、および、アドレスがこのコンピューターまたはプライベートネットワーク内にあるエンドポイントのものです。具体的には`localhost`、`127.0.0.1`、`::1`、`10.…`、`192.168.…`、`172.16.…`～`172.31.…`、または`.local`で終わる名前です（[Ollama、vLLM、その他のエンドポイントに接続する](/guide/agents-models#connect-ollama-vllm-or-another-endpoint)を参照）。名前が「cloud」で終わるOllamaのクラウドモデルはollama.com上で実行されるため、対象外です。スタートページでは、オフにするまで、次のセッションでもスイッチがオンのままになります。

機密セッションでは、ヘッダーとサイドバーのタイトルの横に鍵のアイコンが表示され、メッセージ欄は落ち着いた緑色の枠になります。欄の上の行に、その意味が表示されます（閉じるまで表示されます）。鍵をクリックすると、オンとオフの内容を確認できます。

- **オフになるもの**：ウェブ検索とウェブページ、ブラウザと画面、接続済みアプリとキー、アプリ、公開、スケジュールタスク、画像・図・プロット・動画・音声の作成、検索、編集、外部のモデル（ディープリサーチ、スウォーム、アリーナ。[セカンドオピニオン](/guide/research)は、このコンピューター上の別の開発元のモデルからのみ得られます）、会話をほかのエージェントに引き継ぐこと、メモリへの保存、ページのファイルとしてのエクスポート（ページから自分でエクスポートしてください）。
- **ネットワークなしのコマンド**：エージェントのコマンドは、どの権限モードでもネットワークから切り離されて実行されるため、ダウンロード、インターネットからのインストール、プッシュ、送信はできません。これができない環境（Windows、一部のコンテナ）では、モードにかかわらず、コマンドごとに事前に確認され、鍵の説明にもその旨が表示されます。
- **オンのまま**：フォルダ内のファイル、ドキュメント（このコンピューター上で読み取り）、保存したページ、画像、ファイル、ファイルから表示するスクリーンショット、共有ナレッジ、メモリのメモとプロフィール（読み取りのみで、追加はされません）、同じく機密となるHydorサブエージェント、回答UI（ウェブからの画像や地図なし）。
- **外部には何も送られないもの**：タイトルは、補助モデルがこのコンピューター上で動く場合はそれが作成し、そうでなければメッセージの最初の数語になります。通知には「機密セッション」と、完了した、ユーザーの対応が必要、失敗したのいずれかだけが表示されます。閲覧専用リンク、メニューからのプルリクエスト、そこから作るオートメーションやアプリはありません。ほかのセッションのエージェントや、ほかの場所にあるエージェントは読み取れません。返信にウェブからの画像は表示されず、表示するページも外部から何も読み込みません（そのため、ウェブ上のライブラリが必要なグラフは描画されません）。音声入力は、このコンピューター上の音声認識がオンのときだけ使え（[設定 → 機能 → 音声](/settings?s=voice)）、返信の読み上げは、お使いのデバイス上の音声でのみ行われます。
- **機密のまま**：フォークと**ここから編集**も機密になり、オフにはできないため、これまでの内容はその場にとどまります。コンピューターの外に出てもよい作業は、新しいセッションで始めてください。

保証できないこと：Hydorが確認するのはモデルのサーバーの場所であり、そのサーバーが何をするかではありません。そのため、ネットワーク上に設定したエンドポイントがオンラインのサービスにリクエストを転送する場合、それはオンラインとして扱われます。セッションからコピーしたもの、またはほかの場所から自分で開いたり送ったりしたもの（返信内のリンク、プロジェクトのファイルから開いた、作成されたページ、Gitページからのプッシュ）は、自分で管理してください。ほかのデバイスで読む内容も同様です。アプリのページは、いつもどおり（トンネルを使っている場合はそのトンネル経由で）そのデバイスに届きます。

### ファイルの添付、ファイルの指定、コマンドの使用

- **ファイルを添付**（メッセージ欄の下の行の左端にある**+**）、メッセージ欄へのファイルのドロップ、または画像やファイルの貼り付けができます。1回のメッセージで送れるファイルは最大25 MBです。画像（PNG、JPEG、GIF、WebP）は1回のメッセージにつき8枚まで、画像としてモデルに渡されます。それ以外のファイル（20個まで）はこのコンピューターに保存され、メッセージの末尾に一覧されるため、エージェントがそれを開きます。送信前に、×で取り除けます。添付したファイルは、送信するまでメッセージ欄に残ります（ほかのページに移動しても同様です。ページを再読み込みすると消えます）。
- **スクリーンショットを添付**（同じ**+**メニュー内。コンピューターの場合。ブラウザがスクリーンショットを取得できない環境では、**+**はファイルを添付するクリップになります）：ブラウザが画面、ウィンドウ、タブのどれにするかを尋ね、その画像が1枚添付されます。
- **@**：@とファイル名の一部を入力すると、フォルダ内の一致するファイルが一覧されます。↑ ↓で移動し、EnterキーまたはTabキーで挿入、Escキーで閉じます。
- **/**：メッセージの先頭で/を入力すると、エージェントのコマンドとスキル（Claude Codeのもの）が、それぞれの説明とともに一覧されます。
- ブラウザまたはこのコンピューターが音声を認識できる場合、送信ボタンの横にマイク（メッセージを音声入力）とヘッドフォン（ハンズフリー音声モード）が表示されます。[ドキュメント、画像、動画、音声](/guide/documents-voice)を参照してください。

### スタートページが記憶する内容

スタートページは、作業する場所ごとに選択内容を記憶します。対象は、各プロジェクト、各フォルダ、**新しいタスクフォルダ**で、すべてのデバイスで共通です。場所ごとに記憶されるのは、**実行環境**（プログラム）、各プログラムの**モデル**、**オプション**の**思考レベル**と**権限**、**エージェント**、**メモリ**、**支出上限**、**機密**、**新しいワークツリー**のスイッチです。アカウント（**オプション → アカウント**）は場所ごとには記憶されず、選んだものがどこでもそのまま使われます。ある場所でプログラムを選ぶと、そこで最後に使った内容が戻ります。

場所が選択内容を記憶するのは、そこで選択を変えたとき、またはそこでセッションを開始したときです。場所を見ただけでは何も記憶されません。**フォルダ**チップで場所（プロジェクト、フォルダ、**新しいタスクフォルダ**）を選ぶと、メッセージ欄はその場所の選択内容で開き、書いた内容や添付したファイルはそのまま残ります。プロジェクトから始める場合（カードやページの**新しいセッション**、またはサイドバーのプロジェクト）は、そのプロジェクトの選択内容でスタートページが開き、フォルダ（ファイルまたはサイドバー内）の**このフォルダで新しいセッション**を選ぶと、そのフォルダの選択内容で開きます。ページは、最後に選んだ場所で開きます。

まだ何も選んでおらず、セッションも開始していない場所は、デフォルトで開きます。エージェントは**一般**です。プロジェクトに専用のエージェントがある場合はそのエージェントになります（選んだときと同じく、そのエージェントが推奨する内容、つまりプログラム、そのティアのモデル、権限が適用されます）。**モデル**は、選べる場合は**自動**、そうでなければプログラムのデフォルトです。**思考レベル**と**権限**はプログラムの通常の設定、メモリはオン、支出上限はなし、**機密**と**新しいワークツリー**はオフです。**実行環境**は、最後に使ったプログラムのままです。この機能が追加される前に最後に選んでいた場所は、それまでの選択内容を保持します。

スタートページへのリンクで、内容をあらかじめ入力できます。例：`/?prompt=Summarize%20my%20notes&agent=codex`。`model=`、`cwd=`（フォルダのパス）、`assistant=`（`app-builder`などのエージェントのID。リンクでプログラムやモデルを指定しない限り、そのエージェントが推奨するプログラム、モデル、権限も選ばれます）、`confidential=1`（機密をオン）を追加できます。メッセージ欄と選択内容を入力するだけで、自動的に何かが始まることはありません。リンクされたメッセージに含まれる不可視文字は、通知とともに取り除かれます。

メッセージ欄に書いた内容は、ほかのページに移動しても残ります。対象は、メッセージ、添付したファイル、このタスク限りのオプション（**スウォーム**、**ディープリサーチ**、**アリーナ**、このセッションの**ガイドライン**）、そしてリンクや**New agent session here**で開いたときのフォルダです。メッセージ欄は、セッションが開始されると空になります。エージェントが動き出す間は、**開始**の矢印が上がり続け、その後スタートページがセッションに変わり、メッセージ欄は下の定位置に移り、書いた内容は最初のメッセージとして上に移ります。メッセージとこれらのオプションはこのブラウザに保存されるため、再読み込みしても残ります。添付したファイルは残りません。

## セッションの作業を追う

### ヘッダー

セッションの上部には次のものが並びます。

- エージェントのアイコンとタイトル（ダブルクリックで名前を変更）。[機密セッション](#keep-a-session-confidential)には鍵も表示されます。
- ステータス：**実行中**、**対応が必要**、**準備完了**、**開始中**、**メモリを構築中**、**停止中**。別の場所で実行しているセッションには「Open in VS Code」と表示されます。エージェントがもう実行されていないときは、作業の終わり方が表示されます。最後のターンが終わったときは**完了**（ファイルを作成または変更したときは「· 2 files made」や「· 3 files changed」が付きます）、自分で止めたとき、または終わる前に中断されたときは**停止**、エラーで終わったときは**失敗**です。ポイントすると、次にすることが表示されます。
- フォルダ（クリックするとファイルで開けます）、プルリクエストのバッジ、追加したアカウントで実行している場合はそのアカウント、画面が広いときはGitのブランチとモデル。
- 今できることを示すボタンが1つ表示されます。ターンの実行中は**停止**、エージェントが実行されていないとき（**停止**や**失敗**のあと）は**再開**です。**完了**のあとは目立たない表示になります。メッセージ欄に入力すればセッションは続けられるためです。VS Codeやターミナルで開いているClaude Codeセッションでは**ここで続ける**が表示されます。
- **詳細**（ファイルが変更されると、追加・削除された行数も表示されます）。[詳細パネル](#the-details-panel-changes-commands-and-info)が開きます。
- 会話を[拡大・縮小](#zoom-in-and-full-screen)しているときは、現在の倍率を示す**− 125% +**。
- セッションのメニュー（⋯）：[セッションのメニューの内容](#everything-in-the-sessions-menu)をご覧ください。

### ターン、ステップ、返信

会話はチャットのように読めます。各ターンは、メッセージ、エージェントの作業、そして最後の返信で構成されます。

- **メッセージ**は、送信するとすぐに、エージェントが受け取る前の段階で、右側に画像や添付ファイルとともに表示されます。その下でエージェントが作業している様子が表示され、メッセージ欄は次のメッセージのために空きます。送信できなかった場合（接続がない、支出上限に達したなど）は、メッセージが取り消されてメッセージ欄に戻り、理由を知らせる通知が表示されます。長いメッセージは最初の数行に折りたたまれ、**もっと見る**で開きます。
- **作業**は、要約の行の下にまとまります。「Worked for 2m 10s · 3 commands」「Thought」「Stopped after 40s」「Failed after 5s」などと表示され、右側にはそのターンの費用（「≈ $0.12」）が表示されます。クリックすると、そのターンの[時間とコスト](/guide/sessions#a-turns-time-and-cost)が開きます。プラン（Claude Code、Codex）の場合、これはトークンをAPI料金で計算した場合の金額であり、実際に支払う額ではありません。モデルの料金が不明なときは、代わりにトークン数が表示されます。ターンの実行中、この行には「Working · 1m 2s」（または「Waiting for you」）と表示され、作業の概要は進行に合わせて増えていきます。以前のターンがある場合は、セッション全体で作業した時間（すべてのターンの合計）も加わり、「Working · 1m 2s (47m)」のようになります。終了したターンは作業が折りたたまれ、行をクリックすると開きます。
- **作業の概要**：エージェントがステップの合間に書く短いメモ（見つけたことや次にすること）が、1つのパートの始まりになり、その後に行うステップがそのパートに入ります。終了したパートは、チェックマーク付きの1行になります。メモを数語にまとめたもの（「まずチェックアウトのテストを実行して失敗を確認する」「割引を先に適用して、丸めは1回だけにする」）、ステップ数、変更した行数が表示されます。クリックすると、メモ全体と各ステップが開きます。進行中のパートには、エージェントのメモが全文表示され、その下に現在実行中のステップ（「Editing total.ts · 4 s」など）が表示されます。その行をクリックすると、これまでのパートのステップが開きます。エージェントが最初のメモを書く前に行ったステップは、その内容にちなんだ名前のパート（「Ran 3 commands, read 2 files」）になります。長いターンでは最新のパートが表示され、**Show 12 earlier parts**で残りが表示されます。
- **ステップ**は、わかりやすい言葉で名前が付けられます（「Run the tests」「Read index.ts」「Searched the web」）。コマンド自体は目立たない文字で表示されます。クリックすると、そのステップの内容が表示されます。Claude Codeは、コマンドや、変更を伴うほかのステップを自分で実行します。同じメッセージの中でエージェントがそのあとに依頼したHydor独自のステップ（Web検索、ページの読み取りなど）は、Claude Codeの処理が終わるまで待ちます。このようなステップは、実際に始まるまで時計の代わりに**待機中**と控えめに表示され、始まった時点から時計が進みます。終了したステップには、実際にかかった時間が表示されます。概要の中で現在のステップを示す行には、実際に実行中のステップが表示されます。
- **思考**は「Thought for 12s」と、最初の見出しとともに表示されます。クリックすると読めます。
- **返信**は、エージェントが最後のステップのあとに書いたものです。エージェントが表示したページも返信に付きます。エージェントの作業中は、最後のステップのあとに書いた短いメモが、進行中のパートとして概要に表示されます。ターンがそこで終わると、そのメモが返信になります。
- **ステップの合間の返信**：エージェントがステップの合間に書いたもののうち、返信と読めるもの（作業中に送ったメッセージへの答えや、先に進む前にわかったことで、複数の段落、リスト、表になっているもの）は、作業にまとめられず、その位置に返信として表示されます。その前後の作業は、それぞれ「Worked for 20s · 2 commands」のような独自の行の下にまとまります。
- **変更されたファイル**：返信の下に、そのターンで変更されたすべてのファイルが、追加・削除された行数とともにカードで一覧表示されます。ファイルをクリックすると差分が開き、**ファイルを開く**でファイルが開きます。6件以上は「Show 3 more files」の中に折りたたまれます。
- **作成したドキュメント**：返信の下に、そのターンでエージェントが作成または変更したドキュメント（PDF、Word、Excel、PowerPoint、LaTeX、ノートブック、Markdownなど）が、**新規**または**更新済み**の印が付いたカードで表示されます。エージェントがそれを渡したかどうかは関係ありません。返信内のファイル名やパスはリンクになっていて、会話の上に重なるウィンドウでファイルが開きます（[作成または変更したドキュメント](/guide/documents-voice#documents-it-made-or-changed-and-file-names-in-its-reply)）。画面が広い場合、ターンで作成または変更されたものが1つだけなら、会話の横にも開きます。
- **コミット**：エージェントがそのターンでコミットを作成した場合、返信の下にチップが表示されます。**コミット済み**・コミットのタイトル（または「3 commits」とブランチ）と、追加・削除された行数が表示されます。クリックすると（複数ある場合は、続けてコミットをクリックすると）、メッセージ全文、作成者と日時、ハッシュ（クリックでコピー）、変更したすべてのファイルとその差分が表示されます。**Gitで開く**を押すと、セッションのリポジトリが[Gitページ](/git)で開きます。同じターンの中でエージェントが修正した、またはリベースで消えたコミットは含まれません。

エージェントがチェックリスト（**プラン**または**ToDo**。完了した数も表示）を持つこともあり、作業の進行に合わせてチェックが付いていきます。アプリからの通知は、関連するターンの後ろに表示されます。メモリに保存された内容、セカンドオピニオン、支出上限への到達、ターンが開始したサブエージェントのカードなどです。ほかのセッションからのメッセージは「From …」、サブエージェント（Hydor、Claude Code、Codexのサブエージェント）の返信は「Reply from …」（クリックすると返信を読めます）と表示され、スケジュールタスクの実行は、そのタスク名を示す行から始まります。

日付の行（「Yesterday」「Today」）で日ごとに区切られます。すべて今日の会話には日付の行はありません。古いメッセージは、上にスクロールすると読み込まれるか、**以前のメッセージを表示**で読み込まれます。新しいメッセージや返信は会話の末尾に追加され、その下に余白は残りません。返信が画面いっぱいになるほど長くなると、表示は最初の行で止まり、返信が伸びてもそのままなので、長い返信は最初から読めます。短い返信は、それまでの内容の下にそのまま表示されます。エージェントの作業中に上にスクロールすると、表示位置はそのままです。**最新**を押すと末尾に戻ります。返信が画面の下で続いているときにも表示されます。

終了した各返信の下には、**メッセージをコピー**、**この返信からフォーク**、**読み上げ**があります。**この返信からフォーク**は、Claude Codeではどの返信でも使えます。CodexとCustomはターン全体をフォークするため、終了したターンの最後の返信でのみ使えます。エージェントがツールを使った、またはカードを表示したターンの最後の返信の下には、**もう一度実行…**（円を描く矢印）が表示され、同じ作業をもう一度頼まずにやり直せます。**アプリにする**は、そのターンからアプリの下書きを作ります。途中で行った修正はそのタスクに、カードは回答として残ります（[うまくいったセッションから](/guide/apps#make-your-own-app)）。**実行の間隔…**は、依頼した内容で新しい[スケジュールタスク](/guide/tasks)を開きます。機密セッションでは表示されません。自分のメッセージの下には、**メッセージをコピー**、**ここから編集**、送信した時刻が、ポイントしなくても常に表示されます。

### ターンの時間とコスト

終了したターンの行の右側にある費用（「≈ $0.12」。モデルの料金が不明なときはトークン数）を押すと**時間とコスト**が開き、ターンに時間がかかった理由や費用がかさんだ理由を確認できます。

- **所要時間**：ターンの時間が何に使われたかを示すバーで、各部分の割合と長さが表示されます。**モデル**（与えられた内容の読み取り、思考、執筆）、**コマンド**、**ファイルの読み取りと編集**、**Web**、**その他のステップ**（サブエージェント、接続済みアプリのツール）、**回答待ち**（承認、質問、フォーム。カードが表示されてから回答するまで）、**その他**（開始と、ステップの合間）です。並行して実行されたステップは1回として数えます。その下に「First reply or step after 3 s」と表示され、エージェントがどれだけ早く動き出したかがわかります。
- **トークン**：**新規読み取り**、**キャッシュへの書き込み**（新規に読み取られ、モデルの提供元に保持されるため、次のリクエストではより少ない費用で読み取れます）、**キャッシュから読み取り**（読み取り全体に占める割合付き）、**出力**（返信、思考、ステップ）です。
- **費用**：そのターンの費用と、モデルの料金がわかる場合は各種類ごとの費用、さらに「The cache saved about $0.80.」が表示されます。プラン（Claude CodeとCodex。ただしAPIクレジットで実行しているセッションを除く）では「At API prices: on a plan you pay your plan's fee」と表示されます。モデルの料金が不明なときは、費用は計算されないと表示されます。

Claude Codeのターンでは、モデル自身の時間と最初の返信までの時間がわかります。ほかのエージェントでは、モデルの部分は思考の時間です。費用とこのパネルは、画面が広いときに表示されます。

### 返信内の数式、図、グラフ、画像

エージェントは、ターミナルではなくこのアプリ向けに返信を書くため、返信にはテキスト以外のものも含められます。どのエージェントもその方法を知っていて、回答がわかりやすくなる場面では自分で使います。

- **書式**：見出し、リスト、表、太字、コードが、読みやすく整えられます。
- **数式**：教科書のように描画された数式が、文中や独立した行に表示されます。化学反応式（2H₂ + O₂ → 2H₂O）も使えます。対になったドル記号に挟まれた数字（`$1$`、`$0$`）も数式として扱われます。$4.70のような通常の価格は金額のままです。
- **図**：フローチャート、シーケンス図、状態遷移図、タイムライン、マインドマップ、ガントチャート、円グラフが、ライトまたはダークのアプリの配色で描かれます。図の上のバーには、**コードを表示**（エージェントが書いたコード。同じボタンで図に戻ります）、**画像として保存（SVG）**、**全画面**、コードをコピーするボタンがあります。描画できない図は、コードと理由が表示されます。
- **図表と小さなツール**：グラフ、注釈付きの図、電卓、スライダー付きのシミュレーション、短いクイズが返信の中で動きます。アプリやファイルからは隔離されており、エージェントが表示するページと同じです。アプリの見た目に合わせて、大きさも内容に合わせて広がります（縦に長いものは**すべて表示**で開きます）。バーには**コードを表示**（**表示**で戻ります）、**ファイルとして保存**、**全画面**があります。クリックした選択肢はメッセージ欄に入ります。返信がまだ書かれている間はその場で組み上がり（表示できるものができるまでは「Writing…」）、完成すると動くようになります。
- **画像**：Webの写真（場所、商品、植物、美術作品）やこのコンピューター上の画像が返信に合わせて配置されます。クリックすると大きく表示され、**編集**で画像エディタが開きます（[画像と動画を編集する](/guide/library#edit-pictures-and-videos)）。続けて並んだ複数の画像はグリッドで表示され、それぞれの下に説明が付きます。2枚は横に並び、4枚は2×2、それ以上は1行に3枚（電話では2枚）です。返信のどの画像をクリックしても、ビューアにはその返信のすべての画像が入り、矢印で次々に移動できます。アプリやページのスクリーンショットは、代わりに1つのカードとして届き、会話の横でレビューします（[エージェントによるWebアプリの変更をレビューする](/guide/files-git#review-an-agents-changes-to-a-web-app)）。Webの画像はこのアプリのサーバー経由で届くため、画像を持つサイトにブラウザが知られることはありません。読み込めない画像は、リンクとして表示されます。

プレーンテキストにしたいときは、[エージェントガイドライン](/guide/guidelines)（「図や画像を使わず、プレーンテキストで答えて」）やメッセージで伝えます。ふつうの言葉で頼むこともできます。「手順をフローチャートで描いて」「その画像を見せて」「ほかの値を試せるスライダーを付けて」。

### 回答UI：返信内のカード、グラフ、地図

回答の一部が、読むものではなく、見る、比べる、選ぶ、たどる、試す、練習するものであるとき、エージェントは、アプリの回答UIのいずれかでそれを表示します。回答の内容で埋められた、約150種類のカード、表、グラフ、地図、ギャラリー、タイムライン、小さなツールが用意されています。数行を超える回答のほとんどにこうした部分があるため、たいていの回答で目にします。比べる選択肢は、各行の最良の値に印が付いた表になり、レシピは分量が人数に応じて変わるカードに、天気予報は今後の数時間と数日に、場所は番号付きのピンがある地図に、クイズや練習問題はその場で答えられる問題になります。どれも返信の進行に合わせて組み上がり、ライトまたはダークのアプリの見た目で表示されます。

- **回答UIでできること**：表の並べ替えと絞り込み、グラフの数値表示への切り替え、チェックリストのチェック、レシピのタイマーの開始、フラッシュカードをめくる、ペアを合わせる、空欄を埋める、トラブルシューティングの質問に答える、ホイールを回して決めてもらう、電卓や関数グラフのスライダーを動かす、動画を再生する、などです。チェックした内容や答えは、このデバイスで会話に戻ったときも残っています（練習の答えも同様です）。**送信**と書かれたボタン（**選択を送信**、**スコアを送信**、**結果を送信**、**送信**など）は、そこに書かれた内容を、入力してEnterを押したときのように、次のメッセージとしてすぐに送ります。選んだ選択肢、クイズのスコア、ホイールが止まった場所などです。隣の**送信済み**は、送られたことを示します。入力中の内容はメッセージ欄に残ります。ほかのメッセージの送信中などで、セッションがそのときメッセージを受け付けられない場合は、その言葉がメッセージ欄に入るので、あとで送信してください。さらに、次のようなものもあります。
  - **練習問題**に自分の言葉や数字で答えると、その場で確認されます（数字は許容範囲内かどうか、言葉は大文字小文字を区別せずに判定され、アクセントだけが違う正解にはその旨が表示されます）。**ヒントを表示**で、ヒントが1つずつ表示されます。解答例は、一度試したあと、またはすべてのヒントを表示したあとに表示されます。スコアが表示され、**結果を送信**でエージェントに送られます。自由記述の問題の答えは**確認のために送信**でエージェントに送られ、エージェントが確認します。
  - **実行して変更できるコード**：プレイグラウンドで、JavaScript、Python、小さなWebページをその場で実行できます。アプリからは隔離されていて、出力（Pythonのグラフも）が下に表示されます。**実行**、**リセット**、**コピー**、**コードを送信**（エージェントが確認できるように送ります）があり、試してみる課題が出されることもあります。PythonはWebから初回に読み込まれるため、[機密セッション](/guide/sessions#keep-a-session-confidential)では実行できません。
  - **コードの解説**は、コードを案内付きのツアーとして説明します。コードの横に番号付きのステップが並び、各ステップが説明する行が強調され、残りは薄くなります。矢印（または**←**キーと**→**キー）で進みます。行をタップすると、その行を説明するステップが開きます。**このステップについて質問**を押すと、そのステップについての質問がメッセージ欄に入ります。
  - **プログラムのステップ実行**では、各ステップでプログラムがどこにいるかが表示されます。実行中の行、変数（変わったばかりのものに印が付きます）、進行中の呼び出し、ここまでに出力された内容です。前後に進めたり、スライダーをドラッグしたり、再生を押したりできます。最初に出力を予想するよう求められたら、予想を入力して**確認**を押します。ここでも**このステップについて質問**が使えます。
  - **ネットワークグラフ**は、物事のつながり（概念マップ、小説の登場人物、何が何に依存しているかなど）を表示します。ノードをタップするとそのつながりが強調されてメモが読め、ノードをドラッグして動かしたり、凡例を見たり、**リスト**表示に切り替えたりできます。
  - **注釈付きテキスト**は、テキスト中の箇所に印を付けます。タップすると、そのメモ（修正、コメント、意味）と提案される変更が表示されるほか、**これについて質問**もできます。メモを種類で絞り込んだり、**原文**と**修正後**を切り替えたり、**修正後のテキストをコピー**を使ったり、テキストを聞いたりもできます。
  - **ファクトチェック**は、主張を1つずつ確認します。それぞれに判定、理由、エージェントの確信度、賛成と反対の根拠、出典が付きます。上部の判定の集計をタップすると、主張が絞り込まれます。
  - **フォローアップ**は、回答の最後に表示される、次の質問や手順を示す2〜5個のボタンです。タップすると、メッセージ欄が空のときは次のメッセージとして送信され、入力中のときはその内容に追加されます。使ったボタンにはチェックマークが付きます。
- **画像**：画像がない、または画像を読み込めない項目は、画像なしで表示され、テキストがその分の場所を使うため、空の枠は残りません。
- **リンク**：回答が挙げたもののうち、開きたくなりそうなもの（場所、商品、論文、本、映画、イベント、ページ）は、それぞれのページへのリンクになります。エージェントの言葉の中でも、カードの中でも同じです。そのため、同じものを二度探す必要はありません。カードでは、リンクになっている名前に下線が引かれ、その後ろに小さな↗が付くので、スマートフォンでもリンクだとわかります。タップまたはクリックすると、新しいタブでページが開きます（選んで使うカードでは、選択肢を選ばずにページだけが開きます）。場所の住所は Google Maps で開きます。表では、名前の列をリンクにすることもできます。
- **スプレッドシートやファイルの数値**：表、グラフ、主要な数値、ランキング、ヒストグラム、地図上の値は、数値を自分で持つ代わりに、スプレッドシート（[スプレッドシート](/guide/library#spreadsheets)をご覧ください）や、会話のフォルダまたはそのプロジェクトのフォルダにあるCSV、TSV、JSON、JSONLファイルから読み取れます。数値がそこにあるとき、行数が数十行を超えるとき、残しておきたいカードのときに、エージェントはそうします。カード自身が合計、カウント、グループ化、絞り込み、並べ替えを行うため、数値を入力し直す必要はなく、表示されるたびに最新の数値が表示されます（あとから追加した行も同様です。ただし、セルの範囲が固定されている場合を除きます）。カードの下の行には、取得元（**データの取得元** *Shop numbers · Sales*。スプレッドシートまたはファイルを開くリンク）、読み取った日時、一部しか表示していない場合はその量（「1,000 of 12,400 shown」）が表示されます。**もう一度読み取る**でもう一度読み取り、スプレッドシートを保存すると、カードは自動的に再描画されます。スプレッドシート、そのタブ、列、またはファイルがなくなっている場合は、カードがわかりやすい言葉でその旨を表示し、**もう一度試す**が表示されます。カードが読み取れるのは、その会話のフォルダにあるファイルのみで、コンピューター上のほかの場所のファイルは読み取れません。サイズは50 MBまで（JSONファイルは20 MB）、行は最初の1,000,000行までです。[機密セッション](/guide/sessions#keep-a-session-confidential)で作成したスプレッドシートは、そのセッションのカードだけが読み取れます。
- **ポイントしたとき**（またはキーボードで移動したとき）、右上に小さなバーが表示されます。**データを表示**はエージェントが書いた内容を表示します（スプレッドシートやファイルを読み取るカードでは、読み取り元とそこから表示している内容。**表示**で戻ります）。**テキストとしてコピー**はプレーンテキストとしてコピーし、**全画面**はカードだけをページの上に、ウィンドウと同じ幅で表示します（スマートフォンでは画面全体。縦に長いときはスクロールします）。**Esc**、**閉じる**、またはカードの外側をクリックすると戻ります。**その他**（…）の中には、次のものがあります。**ボードにピン留め**は、カードのコピーをボードに残します。選んだボードか、その場で名前を付ける**新しいボード…**に保存され、ほかのカードと並べて見返せます（[ボード](/guide/library#boards)をご覧ください）。**画像として保存**は、表示しているテーマのまま、シャープさを保つために2倍の大きさで、カードのPNGをタイトルに基づく名前で保存します。**画像としてコピー**は同じ画像をクリップボードにコピーするので、メッセージやドキュメントに貼り付けられます（ブラウザがページにそれを許可している場合）。全画面表示でも、上部に同じ2つがあります。地図、グラフ作成ライブラリで描かれたプロット、動画プレーヤー、コードプレイグラウンドの出力を含むカードには、画像のボタンはありません（ピン留めはできます）。これらの部分は画像に描画できないためです。
- **エージェントが使うとき**：エージェントは、回答のうち、見る、比べる、選ぶ、たどる、試す、練習する、残すものにあたる部分ごとに、回答UIを使うよう指示されています。数行を超える回答では、ほとんどの場合がそうです。検討する選択肢、画像や詳細のあるもの（場所、商品、映画、本、人物、論文、ニュース）、数値、時間と計画、やること、学ぶこと、確認する文章、検証する主張、取りたい次のステップなどです。画像を埋め、写真より動画のほうがわかりやすい場面では動画を再生します。カードでは言えないこと（理由、アドバイス、注意点）は、エージェントの言葉で書かれます。ふつうの会話、短い質問への短い答え、コードの変更は、テキストのままです。最初の回答も、その後の回答も、それぞれの部分ごとに複数のカードを含められる（旅行なら行程、天気、持ち物リスト）ので、会話には、回答に必要なだけのカードがたまります。のちの回答で、データを更新した状態で同じカードをもう一度表示することもできます。エージェントは、1回の検索で合うものを見つけます。すでに知っているものは名前で、そのほかの部分は、それぞれが何を表示するかを数語で表して検索します（言葉で、そして[設定 → メモリ](/settings?s=memory)で**意味で検索**がオンのときは意味でも）。そのため、すべてを一度に渡されることはありません。[組み込みエージェント](/guide/agents#the-built-in-agents)は、それぞれの作業に合ったものを中心に使います。
- **アプリの中で**：アプリの回答も、実行のたびにアプリのエージェントが埋めるこうしたカードにできます（[回答](/guide/apps#the-answer)をご覧ください）。カードを表示した返信の下で**もう一度実行…**を使うと、そのカードを回答とするアプリが作られます。
- **すべてを見る**：[回答UI](/answers)では、すべてをグループごとに例とともに見られます。サマリー、比較、ショッピング、場所と旅行、食べ物、計画、仕事とビジネス、数値とグラフ、お金、学習、科学、メディア、人物とスポーツ、文章、コードです。**ストリーミング中に再生**を押すと、返信で届くときの様子を再生できます。

ふつうの言葉で頼むこともできます。「表で比べて」「地図に載せて」「クイズを出して」「これの練習問題を出して」「エッセイの直すところに印を付けて」。[エージェントガイドライン](/guide/guidelines)（「カードやグラフを使わず、プレーンテキストで答えて」）やメッセージで、プレーンテキストを頼むこともできます。

### 拡大表示と全画面

会話だけを大きくしたり小さくしたりできます。サイドバー、ヘッダー、メッセージ欄はそのままです。会話内のすべて（文章、コード、カード、画像）が拡大・縮小され、行は幅に合わせて折り返し直されます。倍率は67、80、90、100、110、125、150、175、200%です。倍率はデバイスごとに保持され、そのデバイスのすべてのセッションに適用されます。

- **キー**：**Ctrl**（Macでは**⌘**）を押しながら**+**または**=**で拡大、**−**で縮小、**0**で100%に戻ります。デスクトップアプリでは**View → Zoom In**、**Zoom Out**、**Actual Size**でも操作できます。セッション以外の画面では、ウィンドウ全体が拡大・縮小されます。会話がすでに100%のときに**0**を押すと、ブラウザーやウィンドウ自体の拡大率がリセットされます。
- **マウスとトラックパッド**：**Ctrl**を押しながらスクロールするか、トラックパッドでピンチします。Safariではピンチも使えます。
- **ヘッダー**：倍率が100%でない間は、**詳細**の横に**− 125% +**が表示されます。パーセントの数字をクリックすると100%に戻ります。
- **メニュー**：セッションの⋯メニューには、スマートフォンでも常に**ズーム**の行があります。

倍率を変えても、画面の上端で読んでいた内容はその位置に残ります。ターミナルやコードエディタでは、これらのキーはそれぞれの操作に使われます。

ズームは[設定 → アプリ → 一般 → 外観 → 文字サイズ](/settings?s=general&find=Text%20size)とは別のものです。**文字サイズ**は、アプリ全体の読む文章（メッセージ、ヘルプのページ、入力欄）を大きくし、カードと画像は変えません。ズームはセッションの会話全体を拡大し、会話の外は何も変えません。

**表、コード、図の全画面表示**：表には右上の隅に小さなボタンが、コードのブロックには**コピー**の横にボタンがあり、図のバーには**全画面**があります。どれもページの上に開き、次の操作ができます。

- 上部の**− 100% +**で表示内容を拡大・縮小し、パーセントの数字をクリックすると100%に戻ります。
- **Ctrl**または**⌘**と**+**、**−**、**0**でも同じ操作ができ、**Ctrl**を押しながらのスクロールやピンチでは、ポインターの位置を中心に拡大・縮小します。
- 拡大した状態では、マウスでドラッグして移動できます（スクロールもできます）。
- **Esc**、**閉じる**、または外側のクリックで戻ります。

画像は、クリックすると最初から大きく開きます。

### ステップを開いて出力を見る

ステップをクリックすると開きます。

- コマンド：コマンド、実行したフォルダ、終了コード、所要時間、コピーボタン、出力（途中で切れているときは**出力をすべて読み込む**）。
- ファイルの編集：差分（途中で切れているときは**差分をすべて読み込む**）。
- ファイルの読み取り：ファイルへのリンクと読み取った内容。
- Webページ：そのアドレスと、そこから読み取った内容。
- サブエージェントに与えたタスク：**与えられたタスク**と、返ってきた内容。
- そのほか：エージェントが送った内容と返ってきた内容。

ステップには、**バックグラウンド**（実行し続ける）、**自動**（CustomのAutoモードが判断したもの。理由はポイントすると表示されます）の印が付くことや、赤い終了コードが表示されることがあります。バックグラウンドタスク（実行したままのコマンド、モニター、ワークフロー）は、メッセージ欄の上の行に、セッションのサブエージェントとともに一覧表示されます。タスクを開くと出力を見ることができ（Claude Code）、**停止**で止められます（先に確認が表示されます）。サブエージェントは、独立したセッションとして開きます。[サブエージェント](/guide/sessions#subagents)をご覧ください。

## エージェントが始まる前にプロジェクトのメモリを作成する

スタートページでセッションを開始したとき、そのプロジェクトの[Wikiメモリ](/guide/wiki-memory)がまだ新しく（記事が10件未満で、履歴からの作成も未実行）、かつメモリの元になるもの（会話、コミットメッセージ、ドキュメント、メモ、READMEやdocs/フォルダ）がある場合は、セッションが先に確認します。メッセージの下に **<project>のメモリを先に作成しますか？** というカードが表示され、読み込む内容と、エージェントが始まるまでのおおよその所要時間が示されます。選択するまで、セッションには **対応が必要** と表示されます（通知も届きます）。

- **メモリを作成して開始**：メモリの作成が始まり、カードは進行状況の表示に変わり、セッションには **メモリを構築中** と表示されます。メッセージは待機し（「メモリの準備ができたらエージェントに送信されます」）、最も重要な部分が書き終わった時点でエージェントに渡されます。最初に書かれるのは、プロジェクトのファイルから作る概要、メモ、内容がとくに多い会話です。残りはバックグラウンドで作成が続き、書き込まれたものからエージェントが利用できます。**今すぐ開始** はメッセージをすぐに送信し、作成はそのまま続けます。**作成を停止** は作成を止めて（書き終えた分は残ります）エージェントを開始します。アプリを閉じても、エージェントは自動で開始します。その時点より前に作成が失敗した場合は、カードにその旨が表示され、**もう一度試す** と **そのまま開始** を選べます。メッセージがエージェントに届く前にエージェントが終了し（クラッシュした、または待機中にコンピューターが再起動した）、再開できない場合は、カードに **新しいセッションで開始** が表示されます。同じ設定の新しいセッションがメッセージを受け取り、その間に送ったものも引き継ぎ、空のセッションはアーカイブされます。
- **メモリなしで開始**：エージェントがすぐに始まり、このプロジェクトでは1週間確認しません。
- **このプロジェクトでは確認しない**：このプロジェクトでは今後確認しません。**履歴からWikiを作成…** は、プロジェクトの詳細にある **メモリ** タブの **⋯** メニューに残ります。

待機中に送ったメッセージは、最初のメッセージの後でエージェントに渡されます。確認が出るのは、スタートページで自分でセッションを開始したときだけです。スケジュールされた実行、アプリ、サブエージェント、エージェントが開始したセッションでは確認せず、すでに作成済みのプロジェクトでも確認しません。

## エージェントの操作を承認または拒否する

エージェントが、権限の範囲では単独で行えないことをしようとすると、作業を止めて、会話の末尾のカードで確認します。カードには、実行しようとしているコマンド、差分付きのファイル変更、または別のツールとその詳細が、待機時間とともに表示されます。セッションのドットは琥珀色になり、受信トレイにも数えられ、オンにしていれば通知も届きます。回答はカードからでも、[受信トレイ](/guide/inbox)からでも行えます。単純な承認か拒否であれば、ブラウザがボタンを表示する場合は通知から直接答えることもできます。

ボタンはエージェントによって異なります。

- **Claude Code**：**許可**、**拒否**、そして「Bash npm testを常に許可」や「このセッションですべての編集を許可」のようなルールが表示されることも多くあります。
- **Codex**：**許可**、**このセッションで許可**、**このコマンドを常に許可**、**拒否**、**拒否して停止**。ファイル変更では **このセッションで編集を許可**、より広い権限では **このターンで許可** と **このセッションで許可** が表示されます。
- **Custom**：**許可**、**常に許可**（続けて対象の内容がそのまま表示されます。承認したコマンドだけが対象で、後ろに別のものを付け足すことはできません）、**却下**。
- その他のエージェント：そのエージェントが提示する選択肢。

**拒否** を押すとまず「任意：代わりに何をすべきかエージェントに伝える」というボックスが開きます。もう一度 **拒否** を押すと、メモありでもなしでも送信されます（Customの **却下** とCodexの **拒否して停止** はすぐに回答します）。

接続済みアカウントのツールを **事前に確認** に設定している場合、セッション内では確認されません。その呼び出しは送信トレイで保留され、エージェントは作業を続けます。会話には **送信トレイで承認待ち** という行が表示され、あとで送信されたか破棄されたかが示されます（[送信トレイ](/guide/inbox#the-outbox-calls-held-for-your-ok)）。

Claude Codeの **自動** モードでは、安全チェックが確認なしでコマンドを拒否することがあります。その場合、メッセージボックスの上のカードに「Claudeがコマンドをブロックしました」と理由が表示されます。**承認して再試行** はセッションを確認モードに切り替えてエージェントに再実行させるため、通常の承認として改めて確認が届きます。**閉じる** はそのままにします。

## 質問に回答し、プランを承認する

エージェントから質問があると、琥珀色の縁のカードに質問と選択肢が表示されます。

- 選択肢を1つ選びます。「複数選択可」と書かれている場合は複数選べます。**その他：自分の回答を入力** では自分の言葉で答えられます。
- **ファイルを添付** で、回答にファイルを追加できます。
- 1〜9のキーで、まだ回答していない最初の質問の選択肢を選べます。
- **回答を送信** は、回答を次のメッセージとして送信します。質問中にセッションが停止していた場合は、**再開して回答** で回答とともにセッションを再開します。VS Codeやターミナルで待機しているClaude Codeのセッションでは、**ここで回答** でそちらを終了し、回答を添えてここで続行します。Codexのセッションは、そちらで回答する必要があります。

質問が承認カードとして表示される場合、ボタンは **回答を送信** と、Claude Codeの場合は **スキップ** です。

**プラン.** Claude Codeの **プラン** モードでは、エージェントは読み取りと計画を行い、カードにプランを表示します。選択肢は **承認、編集を自動承認**（実行に進み、確認なしで編集します）、**承認、編集前に確認**、**プランを続ける**（プランモードのままで、変更点を伝えます）です。CodexのPlanモードでは、Codexはまず話し合いと計画を行い、確認のための質問をすることがあります。CustomのPlanモードは番号付きのプランで終わります。権限を切り替え（Shift+Tab）、返信して実行させます。

## サービスが求めるフォームに入力する

接続したサービスが作業の途中で入力を求めてくる場合（日付、選択、承認するページなど）、どのエージェントが作業していても、そのフォームがカードとして表示されます。「Linearがフォームへの入力を求めています」「…がページを開くよう求めています」「…が続行の許可を求めています」といった表示です。項目を入力して **送信** を押します（ページを開く場合は **開く**、続行の場合は **許可**）。または **辞退** か **今はしない** を押します。Codex自身のツールサーバーも同じ方法で確認します。[接続済みアプリ、キー、ツール](/guide/connections)をご覧ください。

## エージェントの作業中にメッセージを送る

ターンの実行中でも入力できます。そのときEnterがどう動くかは、ブラウザごとに[設定 → アプリ → 一般](/settings?s=general&find=Sending%20while%20an%20agent%20works)の **エージェントの作業中に送信** で決まります。

- **ターンに参加**（デフォルト）：Enterで、進行中のターンにメッセージを追加し、エージェントがすぐに考慮に入れます。Ctrl+Enter（Macでは⌘Enter）では、代わりにキューに入れます。
- **待つ**：Enterでメッセージをキューに入れ、ターンの終了時に送信されます。Ctrl+Enterでは、代わりにターンに追加します。

メッセージボックスには、どちらになるかが「実行中のターンにフォローアップを送信」または「このターンの終了時に送るメッセージをキューに追加」と表示されます。タッチスクリーンでは、送信ボタンがEnterと同じ動作をします。Customは、実行中のツールが終わった後の次のモデルステップでフォローアップを受け取ります。キューにあるメッセージには **今すぐ送信** で同じ動作をさせられます。アプリのアップデート前から実行中だったCustomセッションがまだライブのフォローアップを受け取れない場合は、代わりにターンが終わるまでメッセージがキューに残ります。その他のACPエージェントは一度に1件のメッセージしか受け付けないため、作業中に送ったメッセージは常にキューで待ちます。Claude Codeでは、エージェントの作業中に入ったメッセージの下に「作業中に送信」と表示されます。それに対するエージェントの回答は、その後エージェントが作業を続けた場合でも、メッセージの下に返信として表示されます。

## キューを管理する

キューに入ったメッセージはメッセージボックスの上で待機し、送信される順に番号が付きます。キューに入れたメッセージは、送信した瞬間にそこに表示されます。ターンが終わるたびに、1件ずつ自動で送信されます。

- メッセージのハンドルをドラッグして、順序を変更できます。
- **今すぐ送信**（矢印）：実行中のターンに、すぐ送信します。
- **編集**（鉛筆）：テキストの変更、添付ファイルの削除、追加ができます（**添付**、またはファイルの貼り付けやドロップ）。Enterで保存、Escでキャンセルします。
- **外す**（ゴミ箱）：キューから外します。添付ファイルは削除されます。
- エージェントを停止したときやアプリを再起動したときは、キューが一時停止します。「キューは一時停止しています（エージェントが停止したか、サーバーが再起動しました）。」**再開** を押すと、エージェントが空き次第、メッセージが再び送信されます。エージェント同士が送り合うメッセージ（セッションからHydorサブエージェントへのメッセージとその返信）は、再起動では一時停止しません。待っている相手のエージェントがまだ作業中なら、そのターンが終わったときに送信されます。支出上限に達した場合もキューは保留され、上限を引き上げると続行します。

## エージェント、モデル、思考レベル、権限を変更する

セッションのメッセージボックスには、スタートページの **エージェント** と、3つの選択肢 **モデル**、**思考レベル**、**権限** が、**+** の横の1つのチップにまとまっています（これで **オプション** が開きます。スマートフォンでは下から出るシートです）。その下には、スタートページの残りのオプションが、同じ順序でこのセッション用に並んでいます。**アカウント**（次のメッセージから別のアカウントがセッションを引き継ぎます。エージェントに複数のアカウントがある場合に表示されます）、**機密** と **アリーナ**（表示のとおり、どちらもセッション開始時に選ぶもので、クリックするともう一方の選び方が表示されます）、**メモリ**、**支出上限**、**スウォーム**、**リサーチ**、**ガイドライン**（セッションメニューの[セッション設定](/guide/research#turn-it-on)と同じ選択肢とダイアログです。スウォームとリサーチは次のメッセージから変更が反映されます）です。チップにはエージェントとモデルが表示され、思考レベルと権限は通常と異なる場合に表示されます。エージェントが確認なしで何でもできる状態（**バイパス**、またはCodexの **フルアクセス**）のときは、琥珀色になります。別のエージェントへの変更は次のメッセージから適用されます（[セッション内でエージェントを切り替える](/guide/agents#switch-agents-in-a-session)をご覧ください）。モデル、思考レベル、権限の変更は、実行中のエージェントにすぐ適用され、セッションに保持されます。Shift+Tabで次の権限モードに切り替わります。モデルメニューには、このエージェントのモデルだけが表示されます。会話を別のエージェントに移すには、[別のエージェントで続ける](#continue-in-another-agent)を使います。

## 返信の一部を引用する

エージェントの返信、または自分のメッセージのテキストを選択すると、その上（タッチスクリーンでは下）に **見積もり** ボタンが表示されます。選択したテキストが引用としてメッセージボックスに入り、カーソルはその後ろに置かれるので、その部分に答えたり、以前の発言を持ち出したりできます。

## セッション内のテキストを検索する

セッションでCtrl+F（⌘F）を押します。**このセッション内を検索** は、自分のメッセージとエージェントのメッセージを検索します（まだ読み込まれていない部分も含みますが、コマンドの出力は含みません）。2文字以上を入力すると、最新の一致箇所に移動して語句がハイライトされ、「12件中3件目」と表示されます。Enterで古い一致、Shift+Enterで新しい一致に移動します（矢印も使えます）。Escで閉じます。折りたたまれた長いメッセージは、見つかった箇所で開きます。検索ボックス（Ctrl+K）で選んだメッセージは、このバーにすでに入力された状態でセッションが開きます。

## メッセージボックスのその他の機能

- 空のボックスで↑を押すと、このセッションの以前のメッセージが新しい順に呼び出されます。↓で元に戻ります。
- 入力中の内容は、このブラウザでセッションごとに下書きとして保存されるので、戻ってきたときにも残っています。
- Ctrl+S（⌘S）で下書きを脇に置いてボックスを空にします。空のボックスでCtrl+Sを押すと、元に戻ります。
- 非常に長い貼り付け（32,000文字以上）は、ボックスを埋める代わりにテキストファイルとして添付されます。
- プレースホルダーには、送信したときの動作が表示されます。「Claudeにメッセージ…」、またはエージェントが実行中でないときは「メッセージを送って続ける…」と表示され、送信すると会話全体を引き継いで再開します。

## 詳細パネル：変更、コマンド、情報

ヘッダーの **詳細** で、3つのタブがあるパネルが開きます。広い画面では会話の横に表示され、セッションを移動しても開いたままです。狭い画面ではページの上にスライドして表示され、スマートフォンでは操作したときだけ開きます。

- **変更**：セッションが変更したすべてのファイルが、変更の多い順に、追加行数と削除行数とともに表示されます。ファイルをクリックすると各編集の差分が表示され、**開く** でファイルが開きます。
- **コマンド**：エージェントが実行したすべてのシェルコマンドが新しい順に表示され、**すべて**、**失敗**、**背景** のフィルタがあります。クリックすると出力が表示されます。
- **情報**：エージェント、ステータス（ヘッダーと同じで、**完了**、**停止**、**失敗**、または現在の動作）、フォルダ、ブランチ、モデルと思考レベル、コンテキストの使用量、開始時刻と最終アクティビティ、アクティビティ（プロンプト、ターン、ツール呼び出し、コマンド）、トークン（入力、キャッシュ、出力）、APIコスト（同じ作業をAPI料金で行った場合の費用）、出力速度、開始場所（Hydor、VS Code、ターミナル、Claudeのデスクトップアプリなど）が表示されます。エージェントの実行中は **そのプログラム** も表示され、現在の使用量（CPU、メモリ、プログラム数）と、適用されている[制限](/guide/app#limit-each-session)が確認できます。その下には、バックグラウンドタスク（開くと実行内容を確認でき、**停止** もできます）と **ターミナルで続ける** があり、セッションをターミナルで再開するコマンドとセッションIDが、それぞれコピーボタン付きで表示されます（Claude CodeとCodex）。

## メーターの見方：コンテキスト、キャッシュ、速度

マイクの横にある、パーセンテージ付きの小さなリングは、会話がモデルのコンテキストウィンドウを使うにつれて満ちていきます。残りの項目は、オプションチップのメニューの下部にあります。

- **コンテキスト**：リングと、オプションの **コンテキスト** 行（「42%使用中」）。リングにポインタを合わせると、正確なトークン数が表示されます。85%を超えると琥珀色になります。リング、またはオプションの **圧縮** をクリックすると、会話が圧縮されます（ターンの実行中は不可）。Customのセッションでは、リングにポインタを合わせるとトークン数とその内訳が表示され、内訳は **コンテキスト** 行の矢印の下にあります。Customは自動で圧縮するため **圧縮** はなく、リングをクリックしても何も起こりません（[長い会話と長い出力](/guide/custom#long-conversations-and-long-output)をご覧ください）。
- **キャッシュ4m**（Claude Code）：プロンプトキャッシュは、しばらくの間（5分または1時間）会話を準備しておくので、次のメッセージのコストが下がり、速くなります。何も送らない間はカウントダウンし、その前にメッセージを送るとキャッシュが再利用されてカウントが最初からになります。**キャッシュなし** は、次のメッセージでキャッシュが再構築されることを意味します。
- **85 tok/s**：直前の返信が書かれた速さで、1秒あたりのトークン数です。

## ターンの停止、エージェントの停止、再開

メッセージ欄の横にある停止ボタンには、エージェントが起動中または作業中のあいだ、回転するリングが表示されます。ユーザーの操作が必要になるとリングは一時停止し、デバイスでモーションの軽減が設定されている場合は静止したままになります。ターンが終わっても、エージェントが開始したバックグラウンドタスクやサブエージェント（Hydorサブエージェント、Claude Codeサブエージェント、実行したままのコマンド、モニターなど）が実行中であるあいだは、リング付きの停止ボタンが残ります。その横には送信ボタンがあり、メッセージ欄はいつもどおりメッセージを受け付けます。停止にポインタを合わせると、何が停止されるかが表示されます。「このターン、2件のサブエージェント、1件のバックグラウンドタスクを停止します」や「2件のサブエージェントを停止します」のように表示されます。停止の対象は、ターン、実行中の各サブエージェント、実行中の各バックグラウンドタスク、さらにそれらが開始したものすべてで、まとめて停止されます。この方法で停止したHydorサブエージェントは、親に報告しません。すでに送信途中だった報告は、親を起こさずに、親の一時停止中のキューで待機します。キューを再開するには**再開**を押します。

- **ターンを停止**：ヘッダーの**停止**、またはメッセージ欄の横にある丸い四角のボタンを押します。このボタンは、セッションが開始したもの（上記）も停止します。（Escでは停止しません。Escは、検索バーや一覧など、開いているものを閉じるだけです。）エージェントは作業をやめ、ターンには「停止しました…」と表示されます。**停止**を押した時点で、エージェントが終了するまで数秒かかる場合（実行中のコマンドを終了させる場合など）でも、セッションは停止した状態として表示されます。20秒後もエージェントが作業を続けていれば、セッションは再び作業中の表示に戻ります。エージェントは次のメッセージを受け付ける状態のままで、キューは再開するまで一時停止します。
- **エージェントのプロセスを停止**：ターンが実行されていないときに、セッションのメニュー（⋯）→ **その他** → **エージェントのプロセスを停止**を選びます。エージェントのプログラムは終了しますが、セッションと履歴は残り、直前のターンの終わり方（**完了**、**停止**、**失敗**）が表示されます。
- **再開**：ヘッダーの**再開**を押すと、会話全体を引き継いでエージェントが再び起動します。メッセージ（「続きのメッセージ…」）を送っても再び起動します。これはClaude Code、Codex、Customのいずれでも同じです。**完了**の後は、次のメッセージを送るだけで済むため、**再開**は目立たないボタンになります。数秒前にVS Codeやターミナルなどからセッションに書き込みがあった場合は、2つのプログラムが1つのセッションに書き込むと履歴が壊れるおそれがあるため、先に確認が表示されます。
- アイドル状態のまま放置されたエージェントは、3時間後に自動的に停止します（待機中の操作がなく、バックグラウンドタスクも実行されていない場合）。次のメッセージを送ると、再び起動します。

## セッションにゴールを設定する

ゴールは、合意したチェックが成立するまで、エージェントにラウンドを重ねて作業を続けさせます。セッションのメニュー（⋯）→**ゴールを設定**で設定するか、スタートページの**オプション**からゴール付きでセッションを始めます。チェックの合意から実行中のゴールの操作まで、ゴールの仕組みは[ゴール](/guide/goals)で説明しています。

## セッションをフォークする

フォークは、この会話を引き継いだうえで別の方法を試す新しいセッションです。元のセッションはそのまま残ります。

1. セッションのメニュー（⋯）→ **フォーク** を選びます。または、返信の下にある **この返信からフォーク** を押すと、そこまでの会話だけを引き継ぎます（Claude Codeでは任意の返信、CodexとCustomでは完了したターンの最後の返信が対象です）。
2. フォークで何をするか入力します（「代わりに何を試しますか？」）。
3. **フォーク** を押します（またはCtrl+Enter）。

フォークが開き、タイトルは「… · fork」になります。エージェント、モデル、思考レベル、権限、アカウントは元のセッションと同じです。上部には「Forked from …」という行が表示され、**開く** も使えます（Codexのフォークには、その後の内容だけが表示されます。それ以前の会話は元のセッションにあります）。フォークできるのはClaude Code、Codex、Customのセッションで、別のアプリで開いているセッションはフォークできません。会話が圧縮される前のClaude Codeの返信もフォークできます。その場合、フォークはその返信までの会話全体を、圧縮される前の状態で引き継ぎます。

## ここから編集

自分のメッセージまで戻って、別の内容で送り直せます。

1. 自分のメッセージの下にある **ここから編集** を押します。
2. テキストを編集します。
3. それ以降のエージェントによる変更も元に戻したい場合は、**このメッセージの前の状態にファイルを戻す** にチェックを入れます。
4. **ここから送信**（Enter）を押します。やめる場合は **キャンセル**（Esc）を押します。

会話は、そのメッセージの直前までを複製したセッションで続きます。複製したセッションにはこのセッションのタイトルが引き継がれ、このセッションはアーカイブされます。ファイルを元に戻せるのは、Claude Code（このアプリから送信したメッセージのチェックポイントを使用）、Custom（Custom自身の編集で変更されたファイルが対象で、コマンドによる変更は残ります）、およびワークツリー内のすべてのセッション（メッセージを送信するたびにスナップショットを作成）です。Codexのセッションでファイルを戻せるのは、ワークツリー内の場合のみです。ターンが実行中の場合は、先にエージェントを停止してください。セッションの[ゴール](/guide/goals)がファイルをチェックしている間、または戻している間は、ファイルを戻せません（「このセッションのゴールがいまファイルをチェックしています：完了するまで待つか、先にゴールを一時停止してください」）。なお、セッションが置き換えられると、ゴール自体は停止します。ここから編集は、Claude Code、Codex、Customで使えます。

## 別のエージェントで続ける

会話を別のエージェントに引き継いで、そちらで作業を続けます。

1. セッションのメニュー（⋯）→ **Codexで続ける**（または **Claude Codeで続ける**、Customにモデルが設定されている場合は **Custom Agentで続ける**）を選びます。
2. メッセージ欄の上に、次のメッセージがそちらに送られることを示すメモが表示されます。モデル、思考レベル、権限の選択は新しいエージェントに適用されます。キャンセルするには ×（「ここに残る」）を押します。
3. メッセージを入力するか、そのまま送信して続けます。

同じフォルダで新しいセッションが開き、これまでの会話が引き継がれます。引き継がれるのは、最初の依頼、約15,000トークンに収まる直近のメッセージ、変更されたファイルです。新しいエージェントには会話全体の保存場所が伝えられるため、省かれた部分も読み取れます。最初のメッセージには「Continued from Claude Code」と表示され、**そのセッションを開く** ボタンと、引き継いだメッセージを表示するボタンが付きます。元のセッションには「This conversation continued in Codex」と表示され、**開く** も使えます。この機能はClaude CodeとCodexのセッションから使えます。

## 会話を圧縮

圧縮すると、ここまでの履歴が要約に置き換わり、モデルのコンテキストに次のやり取りのための空きができます。セッションのメニュー（⋯）→ **その他** → **会話を圧縮** を選ぶか、メッセージ欄のコンテキストメーターをクリックし、**圧縮** で確定します。Claude CodeとCodexで、ターンとターンの間に使えます。Customは、長い会話を自動的に要約します。

## 名前の変更、ピン留め、スヌーズ、完了、アーカイブ、削除

これらの多くは、セッションのメニュー（⋯）と、サイドバーにあるその行のメニューから操作できます。行にポインタを合わせて末尾の **⋯** をクリックするか、右クリックします（スマートフォンでは、行の **⋯** をタップします）。

- **名前を変更**：新しいタイトルを入力します（200文字まで）。Enterで保存、Escでキャンセルします。ヘッダーやサイドバーのタイトルをダブルクリックするか、選択した行でF2を押しても同じ操作ができます。
- **フォルダ名を変更**（サイドバーで、プロジェクトに属さないセッション向け）：セッションが作業しているフォルダに付ける自分用の名前です。サイドバー、セッションの行、フォルダのメニューに、すべてのデバイスでこの名前が表示されます。ディスク上のフォルダ名は変わりません。空にすると、フォルダ本来の名前に戻ります。
- **フォルダに移動**（サイドバー）：セッションを、セッション整理用の自分のフォルダに入れたり、そこから出したりします。新しいフォルダを作ることもできます。セッションをフォルダの見出しにドラッグしても移動できます。[セッションをフォルダで整理する](/guide/start#sort-sessions-into-folders)をご覧ください。
- **先頭にピン留め** / **ピン留めを外す**：ピン留めしたセッションは **ピン留め** グループに残り、ドラッグした順に並びます。その下のグループ（プロジェクトやフォルダ、今日、昨日など）からセッションを **ピン留め** にドラッグすることもできます。まだ何もピン留めされていない場合は、「Drop here to pin」にドラッグします。
- **スヌーズ**：セッションを下部の **スヌーズ中** グループに隠します。期間は **1時間**、**3時間**、**今夜**（午後5時前のみ）、**明日の朝**、**翌週**（月曜の朝）、**日時を選択** から選べます。時間になると通知とともに自動的に戻ります。ユーザーの対応が必要になった場合は、それより早く戻ります。**Unsnooze** を押すと、すぐに戻せます。
- **完了にする：いったん終了**：作業が一区切りしたセッション向けです。エージェントが停止し（ターンの実行中は選べません）、セッションは既読として扱われます。履歴とワークツリーは残ります。ワークツリー内のセッションでは、ワークツリーのダイアログが開き、そこで取り除けます。
- **アーカイブ** / **アーカイブを解除**：セッションを一覧から外します。何も削除されません。アーカイブしたセッションは検索ボックス（Ctrl+K）で見つかり、**アーカイブ済み** と表示されます。開いて、メニューの **アーカイブを解除** を選びます。
- **セッションを削除**：確認すると、セッションの履歴がディスクから削除されます。そのため、エージェント自身のコマンドラインやVS Codeからも消えます。この操作は元に戻せません。サイドバーの行のメニューにある **削除** も同じ操作です。

削除しない限り、アプリはすべてのセッションを保持します。エージェント側のプログラムが会話を削除した場合（Claude Codeは、設定を変えなければ30日後に削除します）でも、セッションは一覧に戻り、開けます。1年間誰も使っていないセッションは、ピン留めしている場合を除き自動的に削除されます。この動作は、設定 → 一般で変更できます（[Delete inactive sessions](/guide/app#delete-inactive-sessions)を参照）。

ピン留め、ピン留めの解除、アーカイブ、アーカイブの解除、スヌーズを行うと、**元に戻す** が付いた通知が表示されます。8秒以内ならCtrl+Zでも元に戻せます。

## 閲覧専用リンクを共有

セッションのメニュー（⋯）→ **閲覧専用リンクを共有** を選ぶと、パスワードなしで誰でも開けるリンクを作成できます（[機密セッション](#keep-a-session-confidential)では使えません）。相手には、進行中の会話（メッセージ、ステップ名、ファイルの変更、エージェントが表示したページ）が見えます。コマンドの出力やエージェントの思考は見えず、入力や変更もできません。リンクの有効期間（**1日**、**1週間**、**1か月**、**オフにするまで**）を選び、**リンクを作成** を押します。リンクが表示されるのは一度だけです。同じダイアログに、現在有効なリンク、それぞれが開かれた回数が一覧表示され、リンクをオフにすることもできます。[スマートフォン、他のマシン、共有](/guide/devices)を参照してください。

## 会話をエクスポート

セッションのメニュー（⋯）→ **エクスポート** で、会話をチャットの外に持ち出せます。

- **Markdownとしてエクスポート**：セッションのタイトルを名前にしたMarkdownファイルとしてダウンロードします。保存や送信、メモアプリでの利用に便利です。
- **Markdownとしてコピー**：同じテキストをクリップボードにコピームします。メモやメール、別のアプリに貼り付けられます。
- **ドキュメントとして保存**：会話をドキュメントにして、セッションのプロジェクトに保存します（プロジェクトの **ファイル** に表示されます。プロジェクトがない場合は、この会話に紐づいて保存されます）。そこで読んだり、編集、コメント、印刷したり、WordやPDFとしてエクスポートしたりできます。準備ができるとメッセージが表示され、**開く** で移動できます。

含まれる内容：タイトルと日付に続いて、ユーザーのメッセージとエージェントの返信が、時刻付きで順番に並びます。ターン内のステップは省かれ、代わりに「Worked for 2 min · 5 steps」のような1行が入ります。エージェントが渡したファイルは名前が一覧されます。回答カードは読めるテキストになり、表は表のまま残ります（比較、データ表、グラフの数値など）。図はMermaidコードのまま、数式はエージェントが書いたLaTeXのまま残ります。ドキュメントには、メッセージに添付した画像と、エージェントが渡した画像も含まれます。

[機密セッション](#keep-a-session-confidential)もエクスポートでき、そのドキュメントも他の作業と同様にこのコンピューターに残ります。Webの画像は取得されず、リンクのままになります。ターミナルからは `hydor sessions export` で同じことができます（[ターミナルでのHydor](/guide/terminal)）。

## ワークツリーで作業する

ワークツリーは、新しいブランチ上に作られるリポジトリのファイルの別コピーです。エージェントは自分のコピーに手を加えずに変更でき、1つのリポジトリで複数のエージェントが同時に作業できます。

- **開始する**：スタートページで **フォルダ** を開き、**New worktree from …** をオンにします（フォルダがgitリポジトリ内にある必要があります）。アプリは、チェックアウト中のブランチから、`agent/` にタスクを表す数語を付けた名前のブランチを作成し、アプリのデータフォルダにそのためのフォルダを作ります。このスイッチの設定は次回も保持されます。
- **スナップショット**：ワークツリーでは、メッセージを送信するたびにアプリがファイルのスナップショットを保存します。これを使って、[ここから編集](#edit-from-here)でファイルを元に戻せます。
- **確認する**：セッションのメニュー（⋯）→ **フォルダとコード** → **Worktree: agent/…** を選ぶと、ブランチと分岐元のブランチ、そのフォルダ、先行・遅れているコミット数、未コミットの変更が表示されます。**変更を確認** と **Gitで開く** も使えます。
- 作業が終わったら **取り除く**：同じダイアログの **ワークツリーを取り除く** を使います。フォルダは削除されますが、セッションの履歴は残ります。ブランチは残るため、コミット済みの内容は失われません。ただし **Delete branch … too** にチェックを入れた場合は削除されます（新しい内容がないブランチは、チェックなしでも削除されます）。未コミットの変更がある場合は、先に **Discard the … uncommitted changes** にチェックを入れます。エージェントが実行中だった場合は停止します。このワークツリーを共有しているフォークや編集後のセッションも、ワークツリーを失います。

## プルリクエストを開く

セッションのブランチから、セッションのメニュー（⋯）→ **フォルダとコード** → **プルリクエストを開く** を選ぶと、GitHubまたはGiteaでプルリクエストを開きます。**自動で書く** を使うと、コミットと差分からタイトルと説明の下書きが作られます。ボックスにチェックを入れると、先に未コミットの変更をコミットできます。**下書き** にチェックを入れると、下書きとして扱われます。ブランチは **プルリクエストを開く** を押したときにプッシュされます。[設定 → ソース管理](/settings?s=scm)でアカウントを設定しておく必要があります。**既存のプルリクエストをリンク…** で、ほかの場所で開いたプルリクエストをリンクできます。

リンクすると、その状態とチェックがサイドバーとヘッダーにバッジで表示され、数分ごとに更新されます。マージされたときやチェックが完了したときは通知が出ます。同じメニュー項目は **Pull request #12** という表示に変わり、**Open on GitHub**（またはGitea）、**変更をレビュー**、**今すぐ確認**、**リンクを解除** が使えます。サブメニューの **変更をレビュー** では、ブランチの変更内容をファイルごとに順に確認できます。[ファイル、Git、ターミナル、プレビュー](/guide/files-git)を参照してください。

## 使用量の上限でセッションが止まったとき

Claude CodeまたはCodexのプランで使用量を使い切ると、メッセージ欄の上にバナーが表示され、どのアカウントの、どの上限に達したか、そしていつリセットされるかが示されます。そのエージェントのアカウントが1つの場合は「You've hit the Claude Code usage limit」、複数あってどれも使用量が残っていない場合は「All your Claude Code accounts have hit their usage limit」、ほかのアカウントにまだ余裕がある場合はアカウント名で「Work has hit its usage limit」と表示されます。

そのエージェントの別のアカウントにまだ使用量が残っている場合、**上限時にアカウントを切り替え** がオンなら、バナーは表示されません。セッションはそのアカウントに移って続行されます（新しいセッションもそちらで始まります）。オフの場合は、バナーにそのアカウントの名前が表示され、**オンにする** が表示されます。

- **リセット時に再開**：上限がリセットされた1分後に、セッションが自動的に続行されます。送られるメッセージは「Continue where you left off.」です。バナーには再開される時刻と **キャンセル** が表示されます。
- **リセットを使う**：アカウントに上限リセットの残りがある場合、バナーにその数が表示され、これを押すとすぐに1回分を使います。
- 設定 → アプリ → 一般の[Resume after usage limits](/settings?s=general&find=Resume%20after%20usage%20limits)は、上限で止まったすべてのセッションに対してこれを行います。オンにすると、セッション内に警告は表示されません。代わりにメッセージ欄の上の1行に、どのアカウントのどの上限に達したか、いつ続行されるかが表示されます（「All your Claude Code accounts have hit their usage limit」に続けて「Current session (5 h) · Continues by itself in 3 h 15 min.」）。リセットが残っていれば **リセットを使う** も表示され、**キャンセル** も使えます。自分で **停止** したセッションは、自動では続行されません。

再開の時刻は上限に合わせて変わります。リセットが前後したり、使用量が早く戻ったりした場合は、そのタイミングでセッションが続行されます。[使用量、上限、コスト](/guide/usage)を参照してください。

## VS Codeやターミナルで実行中のセッション

このコンピューター上のClaude CodeとCodexのセッションはすべて一覧に表示されます。VS Code、ターミナル、Claudeのデスクトップアプリで実行しているものも含まれます。そちらで実行中の間は、一覧に「Working in VS Code」「Needs you in terminal」「Open in VS Code」（グレーの点）と表示され、作業の様子を読み進められます。そちらで入力待ちになっている場合、アプリが通知するのは、1分後にもまだ待っているときだけです。

- **Claude Codeセッションを引き継ぐ**：ヘッダーの **ここで続ける** を押すか、そのままメッセージを送信します（「Open in VS Code — sending moves it here」）。先に確認が表示されます。引き継ぐと、そのアプリでのセッションは終了し（実行中の作業も停止します）、履歴をすべて引き継いでこちらで再開します。そのアプリではセッションが終了した状態で表示されますが、あとでそちらから開き直せます。
- ほかで開いている**Codexセッション**は、こちらでは読み取り専用です。1つのCodexプロセスがそのスレッドすべてを扱っているためです。そちらで続けるか、そちらで閉じてからこちらで再開してください。
- 別のアプリで開いているセッションは、フォークできません。

## サブエージェント

エージェントは、作業の一部をサブエージェントに任せて、その結果を受け取れます。サブエージェントには2種類あり、アプリはどちらかを表示します。

- **Hydorサブエージェント**は、Hydorが起動する独立したセッションで、エージェントもモデルも自由に選べます。親の会話にあるサブエージェントカードに1行で表示され、サイドバーでは親の下に並びます。開いて話しかけることもできます。コストは個別にかかり、親の支出上限のうち専用の割り当てを持ちます。返信は親にメッセージとして届きます。
- **Claude Codeサブエージェント**（Codexでは「Codexサブエージェント」。セッション自身のプログラムの名前が付きます）は、そのプログラムがセッション内で、作業の一部を短時間任せるために実行するものです。Hydorは自身が実行するセッションではこれを無効にするため、表示されるのは、VS Codeやターミナルで実行されているセッションと、以前のセッションだけです。表示と開き方はHydorサブエージェントと同じで、会話のカードに1行、サイドバーとトレイに1行、会話全体を見られる専用ページがあります。ただし話しかけることはできず（リード側からは可能です）、使った費用はリード自身の分として数えられ、支出上限の割り当てもありません。

サイドバーでは、サブエージェントは作業中またはユーザーの対応待ちの間、親の下にまとめて折りたたまれます。Hydorのものとプログラム自身のものがひとつの行にまとまり（「3件のサブエージェント · 1件が対応待ち」「2件のサブエージェント」）、行をクリックするとそれぞれの行が表示されます。終了したものは、開いて見ている場合を除いてサイドバーから消え、いずれかを見ている間はこの行も開いたままです。スウォームのメンバーは「スウォームメンバー」、キャンペーンのメンバーは「キャンペーンメンバー」と表示されます。親の会話では、1回のターンで起動されたサブエージェントがそのターンの下にひとつのカードとしてまとまります。Hydorサブエージェントは1枚のカード、プログラム自身のもの（Claude CodeまたはCodex）は別のカードです。先頭の行には、件数と種類、全員に共通する内容（「6件のClaude Codeサブエージェント · Sonnet 5.5」「3件のHydorサブエージェント · Claude Code · Sonnet 5.5」、ディープリサーチでは「4件のリサーチャー」）、そして状況（「5件作業中 · 1件完了」、ほかに「1件が対応待ち」「1件停止」「1件失敗」）が表示されます。この行をクリックするとカードを折りたたんだり開いたりできます。どれかが作業中か対応待ちの間は開いており、すべて終了すると1行に折りたたまれます。

その下には、サブエージェントごとに1行あります。状態を示す色の点（作業中は青でゆっくり点滅、対応待ちは琥珀色、完了は緑、停止はグレー、失敗は赤）、タイトル、広い画面ではほかと異なる情報（種類やモデル、ユーザーのどのエージェントとして動いているか、ティア）、そして状況（これまでの作業時間、「対応待ち」、終了した時刻（「3分前」）、「停止」、「失敗」）が並びます。Hydorサブエージェントの行にはコストも表示され、ティアを上げたものにカーソルを合わせると、最初のティアと理由が「ティアを上げた元」として表示されます。行をクリックするとそのサブエージェントが開きます。ほかが作業中の間は、終了したものが「4件完了：」とそのタイトルを並べた1行にまとまり、クリックすると中身が見られます。失敗したものは独立した行のまま残ります。作業中のものが6件を超えると5件が表示され、**さらに3件を表示**が付きます。

1回のターンで起動されたサブエージェントが1件だけの場合は、1行のカードで表示されます。状態の点が付いたアイコン、タイトル、種類（「Claude Codeサブエージェント · Explore · Sonnet 5.5」や「Hydorサブエージェント · Claude Code · Sonnet 5.5」。エージェントやティアがある場合はそれも表示）、そして状況です。

サブエージェントを停止するには、その行にカーソルを合わせる（またはTabキーで移動する）と、時間の代わりに**停止**が表示されます。タッチ画面では小さな停止ボタンが常に表示されます。Claude Codeサブエージェントは先に確認があり（「このサブエージェントを停止しますか？」）、Hydorサブエージェントはすぐに停止します。Codexサブエージェントはここから個別に停止できません。カードの**⋯**メニューには**5件のサブエージェントを停止**（停止できる件数が入ります）があり、確認なしですべて停止します。サブエージェントを起動した呼び出しは、ターンの折りたたまれた作業のステップとして残ります。

バックグラウンドで作業したサブエージェントが戻ってくると、親の会話に1行が表示されます。「返信元」とそのタイトル、または「…は停止しました」「…はエラーで停止しました」と、書かれた内容の冒頭が付きます。クリックすると返信を読めて、**セッションを開く**でそのセッションに移動できます。Codexサブエージェントの返信は、行を開いたときにそのサブエージェント自身の会話から取得されます。親がまだ作業中に届いた返信は、前後のステップの間にそのまま表示されます。

Hydorサブエージェントの中では、メッセージ欄の上のバーに「サブエージェントの親：」と親のタイトル（「返信はそこに戻ります」）が表示され、**親を開く**が付きます。Claude CodeやCodexのサブエージェントもセッションとして開きますが、閲覧専用です。与えられたタスク、ステップ、返信が作業中はリアルタイムで表示され、メッセージ欄も**再開**もセッションメニューもありません。メッセージ欄の代わりに、「Claude Codeサブエージェントの親：」と親のタイトル（「返信はそこに戻ります」）を示すバーがあり、**親を開く**が付きます。Claude Codeサブエージェントが作業中は、ヘッダーの**停止**で、先に確認のうえ停止できます。メッセージの送信、再開、フォーク、引き継ぎ、削除はできません。そのプログラムが親のセッション内で実行しているため、親に話しかけてください。

親自身のターンが終わっても、サブエージェントがまだ動いている間は、親は終了していません。点は青く脈動し続け、メッセージ欄の停止ボタンのリングも回り続け、状況は「作業中 · 2件のサブエージェントが実行中」と表示され、「完了」マークは付かず、アクティブに残り、メッセージも送れます。これはClaude CodeのセッションにもCodexのセッションにも当てはまります。Hydorサブエージェントも、自身のターンが終わった後に、起動したサブエージェントやバックグラウンドタスク（コマンドやモニター）が動いている間は実行中として数えられ、その親は完了ではなく作業中と表示されます。親に設定した支出上限はそのHydorサブエージェントも対象とし、Claude CodeやCodexのサブエージェントが使った費用はすでに親自身の分です。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research)をご覧ください。

メッセージ欄の上の1行には、セッションが起動したすべて（サブエージェントとバックグラウンドタスク（コマンド、モニター、ワークフロー））がまとめて表示されます。「2件のサブエージェントと1件のバックグラウンドタスクが実行中」、Hydorサブエージェントがユーザーを待っているときは琥珀色で「1件が対応待ち」、何も動いていないときは「3件のサブエージェント · 2件のバックグラウンドタスク · すべて完了」と表示され、セッションを開くたびに折りたたまれた状態になります。クリックするとひとつずつ一覧表示されます。対応待ちが先頭、次に実行中、最後に終了したものが新しい順に並び、5件ほどを超えると内部でスクロールします。どの行も同じ構成です。状態の点が付いたアイコン、タイトル、種類（「Hydorサブエージェント · Claude Code · Sonnet 5.5」「Claude Codeサブエージェント · Explore · Haiku 5.5」「コマンド」「モニター」「ワークフロー」）、状況（「作業中 · 2分10秒」「対応待ち」「完了 · 3分前」「停止」「失敗」）、Hydorサブエージェントのコスト（プログラムのサブエージェントには表示されません。費用は親の分です）、**開く**、そして実行中は停止ボタン（円の中の四角）です。種類にカーソルを合わせると、誰が実行しているかが表示されます。「Hydorが独立したセッションとして起動しました。開いて見守ったり話しかけたりできます」、または「Claude Codeがこのセッション内で実行しています。開いて見守れます」。**開く**を押すと、Hydorサブエージェントや、Claude CodeまたはCodexのサブエージェントのセッションに移動します。コマンド、モニター、ワークフローは、ページの右側に重なるパネル（スマートフォンでは画面全体）で開き、タイトル、種類、状態、実行中は**停止**、その下に出力が表示されます。出力は2秒ごとに更新され、上にスクロールしない限り最新の行を表示し続けます。サブエージェントの停止ボタンは「このサブエージェントを停止」、タスクのものは「このタスクを停止」と表示されます。行の右側の**すべて停止**は、メッセージ欄の横の停止ボタンと同様に、実行中のものをすべて停止します。スウォームやキャンペーンのメンバーはここには一覧表示されず、そのボードに表示されます。終了したタスクは、エージェントのプログラムが停止するまで一覧に残ります。VS Codeやターミナルで開いているセッションでは、タスクは一覧表示されますが、停止はできません。

1つのセッションで同時に実行するHydorサブエージェントの数は、[設定 → 機能 → サブエージェント](/settings?s=children)で指定します。この設定はHydorサブエージェント用で、Claude CodeとCodexのサブエージェントはそれぞれのセッション内で動くためです。設定 → モデル → ティアで[サブエージェントを先頭に](/settings?s=models&find=Lead%20with%20subagents)をオンにすると、セッションのメインエージェントが計画を立て、明確な部分をより低いティアのサブエージェントに任せ、その作業をチェックします。

## セッションメニューのすべての項目

セッションの右上にある⋯ボタンでメニューが開きます。項目は該当する場合のみ表示されます。[機密セッション](#keep-a-session-confidential)のメニューには、**閲覧専用リンクを共有**、**プルリクエストを開く**、**ブラウザを開く**、**接続済みアカウント**、**自動化にする**、**アプリとして保存**がなく、メモリもオフのままです。

- **名前を変更**：タイトルをその場で編集します。
- **ズーム**：**−**、倍率、**+**で、このデバイスでの[会話](#zoom-in-and-full-screen)の表示を拡大・縮小します。倍率をクリックすると100%に戻ります。
- **先頭にピン留め** / **ピン留めを外す**。
- **スヌーズ**（時間のサブメニュー）。スヌーズ中は**スヌーズを解除（…に戻る）**。
- **完了にする：いったん終了**：エージェントを停止し、セッションを既読にします（ターンの実行中は使えません）。
- **フォーク**：この会話から新しいセッションを作ります（Claude Code、Codex、Custom）。
- **Codexで続ける**、**Claude Codeで続ける**、**Custom Agentで続ける**：会話を別のエージェントに引き継ぎます（Claude CodeとCodexから）。
- **ゴールを設定**：エージェントとユーザーでチェックを決め、それが満たされるまでラウンドを重ねて作業します。すべてのエージェントで使え、ゴールが未設定のときに表示されます。[ゴール](/guide/goals)をご覧ください。
- **セカンドオピニオン**：別の会社のモデルが、ターンの作業を依頼内容と照らして確認し、結果をそのターンの下に表示します。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research)をご覧ください。
- **閲覧専用リンクを共有**。
- **エクスポート**（サブメニュー）：**Markdownとしてエクスポート**、**Markdownとしてコピー**、**ドキュメントとして保存**。[会話をエクスポートする](#export-a-conversation)をご覧ください。
- **フォルダとコード**（サブメニュー。フォルダのあるセッション向け）：
  - **変更をレビュー**：ブランチの変更をファイルごとに表示します。
  - **プルリクエストを開く**。すでにある場合は**プルリクエスト #12**。
  - **ワークツリー：agent/…**：ワークツリーのダイアログです（ワークツリーのセッション）。
  - **フォルダを開く**：セッションのフォルダでファイルを開きます。
  - **Finderで表示**、**エクスプローラーで表示**、**フォルダで表示**：デスクトップアプリで、セッションのフォルダをシステムのファイルマネージャーで選択した状態で表示します（[ファイルとフォルダを扱う](/guide/files-git#work-with-files-and-folders)をご覧ください）。
  - **ここでターミナルを開く**：そのフォルダで新しいターミナルを開きます（コンピューターでは下部のパネル、スマートフォンではターミナルページ）。
- **セッション設定**（サブメニュー）：
  - **メモリ**：横に**オン**または**オフ**が表示され、このセッションのメモリをオンまたはオフにします（設定でメモリがオフの場合は「すべてオフ」）。[メモリ](/guide/memory)をご覧ください。
  - **支出上限**：横に上限が表示され、設定、変更、引き上げができます。[使用量、上限、コスト](/guide/usage)をご覧ください。
  - **接続済みアカウント**：接続済みアカウントごとに、このセッションだけオンまたはオフにします。[接続済みアプリ、キー、ツール](/guide/connections)をご覧ください。
  - **スウォーム**：横に**オフ**、**オン**、または**キャンペーン**が表示され、次のメッセージからスウォームやキャンペーンをオンまたはオフにするダイアログが開きます。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research#set-a-swarm-on-a-hard-problem)をご覧ください。
  - **ディープリサーチ**：横に**オフ**または検索回数が表示され、次のメッセージからディープリサーチをオン、オフ、または変更するダイアログが開きます。[ディープリサーチ、セカンドオピニオン、複数のエージェント](/guide/research#turn-it-on)をご覧ください。（スウォームとディープリサーチは、機密セッションや、別のセッションが起動したセッションには表示されません。）
  - **エージェント**：横に名前が表示され、エージェントのページが開きます（エージェントのあるセッション）。切り替えはメッセージ欄で行います。
- **その他**（サブメニュー）：
  - **ブラウザを開く** / **ブラウザを表示**：このセッション用のエージェントのブラウザで、見守ることも操作を引き継ぐこともできます。[検索とブラウザ](/guide/web)をご覧ください。
  - **自動化にする**：補助モデルがセッションを読み取り、スケジュールタスクの下書きを作ります。内容を自由に変更し、テスト実行で試してから保存します。[スケジュールタスク](/guide/tasks)をご覧ください。
  - **アプリとして保存**：このセッションから新しいアプリを作り始めます。[アプリ](/guide/apps)をご覧ください。
  - **会話を圧縮**（Claude CodeとCodex）。
  - **CLIの再開コマンドをコピー**：このセッションをターミナルで続けるためのコマンドです。
  - **エージェントのプロセスを停止**（エージェントが動いていて、ターンが進行中でないとき）。
- **アーカイブ** / **アーカイブを解除**。
- **セッションを削除**：確認のうえ、履歴をディスクから削除します。
