# 検索とブラウザ

アプリ内のエージェントは、モデルを問わず、Webを検索したりページを読んだり、実際のブラウザを使ったりできます。このトピックでは、エージェントが使う検索プロバイダとその設定方法、検索で表示される内容とソース、そしてブラウザについて説明します。ブラウザについては、ライブでの様子の確認、ログイン・確認の通過・支払いのための操作の引き継ぎ、設定を取り上げます。また、デスクトップアプリに用意されている自分用のブラウザであるブラウザページ（タブ、プライベートタブ、スマートアドレスバー、ブックマーク、履歴、広告ブロック、翻訳、リーダービュー、拡張機能）と、そのページをエージェントに渡す方法も取り上げます。デスクトップアプリ（Mac、Windows、Linux）では、ブラウザがアプリの中で動作し、エージェントはコンピューターそのもの（画面、マウス、キーボード）も使えます。

![Webを検索し、ページを読み、見つけた内容を表で比較したエージェント](images/web.webp)

## エージェントがWebを検索する仕組み

ここで実行するすべてのエージェント（Claude Code、Codex、Custom、ACPに対応したエージェント）は、アプリから3つのツールを受け取ります。Web検索、ページを読む機能、そしてものの画像や動画を探す機能です。これらはモデルを問わず同じように動くため、お使いのコンピューター上の小さなモデルでも、大きなモデルと同じように検索できます。

- 検索は、**設定 → 機能 → 検索**にあるプロバイダへ、その順番で送られます。オンになっている最初のプロバイダが回答します。回答できない場合（キーが必要、無料枠を使い切った、接続できない、検索がボットによるものではないことの証明を求められた、など）は、次のプロバイダが回答します。どのプロバイダが回答したかは、エージェントに伝えられます。
- エージェントは最大100件の結果を求めることができ、検索を特定のサイトに絞る（または除外する）、日付、言語、PDF、サイト自身のホームページ（個人のページ、公式サイト）に絞ることもできます。Naget Searchでは、学術論文、プレプリント、生物医学論文、米国特許、企業の提出書類、ニュース、ドキュメント、ディスカッションといったページの種類にも絞れます。プロバイダが絞り込みに対応できない場合は、エージェントに伝えられます。エージェント自身が絞り込みを指定していなくても、検索の言葉に絞り込みが含まれている場合（「先月のnasa.govの気候レポート」「2024年以降の検索拡張生成に関する論文」など）は、まず補助モデルがそれを読み取り（[補助モデルを選ぶ](/guide/agents-models#choose-the-helper-model)を参照）、Naget Searchは残りの言葉をその絞り込みで検索します。これは、言葉に絞り込みが含まれていそうな検索に限り、一度に少数ずつ、約8秒以内に行われます。補助モデルが時間内に回答できない場合や、2回続けて読み取りに失敗した場合（読み取りは10分間停止します）、検索はエージェントが書いたとおりに送られます。SearXNG、Brave Search、DuckDuckGoの場合や、エージェント自身が絞り込みを指定した場合も同様です。読み取った絞り込みで何も見つからないときは、Naget Searchは書かれたとおりの言葉で検索し直します。
- Naget Searchは、結果ごとに、単なるスニペットの代わりに、検索に答えているページの文章を返すこともできます。この方法は時間がかかるため、エージェントはページから事実が必要なときに求めます。キーがなくても利用できます。
- 表示するもののリスト（ゲーム、映画、場所、料理、商品、チーム）について、エージェントはそれぞれの画像を探せます。そのもののWikipedia記事の画像（ゲームのカバー、場所の写真、チームのエンブレム）、なければページが共有時に表示する画像です。依頼があれば、タイトルにその名前が入ったYouTube動画（トレーラー、レシピ、ハイライト）も探します。そのものだとはっきり分かるものだけが対象のため、見つからないものもあります。アプリはこれを使って、回答に画像や動画を表示します（[アプリ](/guide/apps)を参照）。
- エージェントは、使ったページを引用するよう指示されています。各ページが裏付ける内容の後ろに角括弧付きの番号を付け、返信の最後にそれらのページだけの一覧を載せます。アプリはこれをリンクとカードで表示します（[返信の下にソースを表示する](/guide/web#see-the-sources-under-a-reply)を参照）。エージェントは、結果やページに書かれている内容を情報として扱い、指示としては扱いません。

失敗したプロバイダはしばらく休止します（たとえば無料枠が戻るまで）。そのため、その後の検索はそのプロバイダを待ちません。同じ検索を10分以内にもう一度行うと、検索し直さずに前回の結果が返されます。

Claude CodeとCodexには、それぞれ独自のWebツールもあります。その返信が見つけたページを引用している場合も、同じように表示されます。

## 検索プロバイダを選ぶ

[設定 → 機能 → 検索](/settings?s=search)を開きます。スマートフォンでは、設定は一覧になっています。機能の下の**検索**をタップします。

[プロバイダ](/settings?s=search&find=Providers)（「上から順に試します。オンになっている最初のものが回答します」）の下に、プロバイダごとの行があります。

- 名前。オンになっている最初のプロバイダには**デフォルト**が付きます。現在の設定で回答できない場合は、**キーが必要**や**インスタンスのアドレスが必要です**などの警告が表示されます。
- どんなものかを説明する1行。名前の横の（i）には、検索を絞り込める条件が追加で表示されます（「最大100件 · カテゴリ · 日付 · ホームページ · 回答にあたるページの部分」など）。
- 保存済みのキーがあれば、そのヒント（「sk-ab…12cd」のように。キーそのものは表示されません）。
- 直近のエラー。赤字で、何時間前かも表示されます。
- 右側のオン・オフを切り替えるスイッチと、**⋯**メニュー。メニューには、**キーを追加**（または**キーを変更**）、**アドレスを設定**（または**アドレスを変更**）、**テスト**、**デフォルトにする**（オンになっているが先頭ではないプロバイダの場合）、順番を変えるための**上へ移動**と**下へ移動**があります。

**プロバイダ**の横の（i）には、エージェントはモデルを問わずWebを検索してページを読めること、そして検索結果とページは外部のデータであり、エージェントはそれを情報として使い、指示としては使わないことが説明されています。

**デフォルトにする**を選ぶと、そのプロバイダがリストの先頭に移動します。初期状態の順番は、Naget Search、SearXNG、Brave Search、DuckDuckGoです。Naget SearchとDuckDuckGoは最初からオンで、SearXNGとBrave Searchは、必要なものを設定するまでオフです。

### Naget Search

[Naget Search](/settings?s=search&find=Naget%20Search)はデフォルトで、Nagetが独自に持つ、Web、論文、特許、提出書類のインデックスです。キーは不要で、キーなしの検索には1日ごとの無料枠が使われます。一度回答すると、行に**今日の残り無料枠**（その日の枠のうちの残り件数）、バー、次に枠が増える時刻が表示されます。無料枠を使い切ると、行にその旨が表示され、枠が戻るまでは次のプロバイダが回答します。

naget.comのキーを使うと、より多く検索できます。キーがある場合、行には代わりに**残りクレジット**が表示されます。キーがあると、エージェントがページを読むときに、質問に答えているページの部分をNaget Searchが選べるようになります（[ページ全体を読む、または質問に答える部分だけを読む](/guide/web#read-whole-pages-or-only-the-parts-that-answer-a-question)を参照）。キーがない場合は、アプリが言葉をもとに選びます。検索に答えている文章は、キーなしでも結果に含まれます。行に「Naget Searchは今のところキーが必要です」と表示されている場合、キーなしの検索は受け付けられていません。キーを追加するまでは、次のプロバイダが回答します。

フォームには**アドレス**もあります。別のアドレスを設定しない限り、https://naget.com です。別のアドレスを教えられた場合を除き、そのままにしてください。

### SearXNG

[SearXNG](/settings?s=search&find=SearXNG)は、自分で運用する検索エンジンです。多数の検索エンジンに同時に問い合わせ、利用者の記録を残しません。キーは不要で、必要なのはインスタンスのアドレスだけです。**⋯**メニューを開いて**アドレスを設定**を選び、アドレス（https://searx.example.org など）を入力して、**保存**を押します。アドレスを設定すると、オンになります。最大100件の結果を返します。

### Brave Search

[Brave Search](/settings?s=search&find=Brave%20Search)は、Search APIを通じて、Brave独自のインデックスを検索します。キーが必要で、Braveには無料プランがあります。**⋯ → キーを追加**を選ぶと、リンク **Get one at api-dashboard.search.brave.com** が付いたフォームが開きます。キーを追加すると、オンになります。最大100件の結果を返します。

### DuckDuckGo

[DuckDuckGo](/settings?s=search&find=DuckDuckGo)はキーが不要で、最初からオンになっており、最後の手段としてリストの最後にあります。1ページあたり約10件（最大30件）の結果を返します。検索がボットによるものではないことの証明を求められる場合があり、その場合は、次のプロバイダがあればそちらが回答します。

### キーやアドレスを追加・変更する

1. プロバイダの行で**⋯**メニューを開き、**キーを追加**（または**キーを変更**、**アドレスを設定**、**アドレスを変更**）を選びます。
2. **キー**にキーを貼り付ける（ドットで表示されます）か、**アドレス**を入力します。Naget Searchのキーには「任意、より多くの検索用」と表示されます。
3. **保存**を押します。**キャンセル**を押すとフォームが閉じ、元の状態のままになります。

プロバイダに必要なキーやアドレスを設定すると、オンになります。キーはサーバーに保存され、ページにはそのヒントしか表示されません。保存したキーを取り除くには、フォームを開いて**保存したキーを削除**を押します。

### プロバイダをテストする

行の**⋯**メニューを開いて**テスト**を選びます。アプリは、次のプロバイダに切り替えることなく、そのプロバイダだけで小さな検索を実行します。フォームに入力した内容は、保存前でも使われます。「Works:」の表示、結果の件数、かかった時間と、最初の3件の結果へのリンク、または失敗した理由が表示されます。保存されている設定のままプロバイダをテストして再び動作した場合は、以前のエラーも消去されます。

### 1回の検索あたりの結果数

[1回の検索あたりの結果数](/settings?s=search&find=Results%20per%20search)は、エージェントが件数を指定しなかった場合に、1回の検索で返す結果の数を決めます。**10**、**20**（デフォルト）、**50**、**100**から選べます。論文を探すような深い検索では、エージェントはさらに多く（最大100件まで）求めることもできます。結果が多いほど、エージェントの読む量も増えます。

ページの下部にある注記には、開発者が別のプロバイダを追加する方法へのリンクがあります。

### どのプロバイダも回答できない場合

オンになっているすべてのプロバイダが失敗した場合や、すべてオフにした場合は、それぞれが回答できなかった理由がエージェントに伝えられます。するとClaude CodeとCodexは、その検索と残りのタスクで、代わりに組み込みのWeb検索（Claude CodeのWebSearch、CodexのWeb検索）を使い、これまでどおりそのページを引用します。それらの検索も失敗した場合にだけ、設定 → 検索について知らせます。Customなどのその他のエージェントには独自のWeb検索がないため、設定 → 検索でキーを設定するか、別のプロバイダをオンにできることを知らせるよう求められます。[ディープリサーチ](/guide/research)では、すべての検索が予算に計上されるよう、エージェント独自のWeb検索はオフになっています。その場合も、直すべき点が知らされます。

## 検索で見つかった内容を確認する

エージェントのステップは、メッセージの間で「4回検索しました」のような1行にまとめられます（Web検索と読んだページは、ここでは検索として数えられます）。開くと、各ステップが表示されます。検索は「Webを検索しました「2,000ユーロ以下の電動自転車」」のように表示され、右側には回答したプロバイダと結果の件数が出ます（スマートフォンでは件数のみ）。実行中は「Webを検索中」と表示され、タイマーも出ます。失敗した場合は「Web検索に失敗しました」と表示されます。

検索をクリックすると開きます。

- 使われた絞り込み（サイト、日付、カテゴリなど）が小さなタグで表示されます。検索の言葉から読み取られたものも含まれ、検索された言葉を示す注記が付きます。エージェントが答えにあたる文章を求めた場合は「回答にあたるページの部分」も表示されます。
- 注記。回答できなかったプロバイダとその代わりに回答したプロバイダ、プロバイダが対応できなかった絞り込みなどです。
- 結果。エージェントが見たとおりに番号が付き、タイトル（リンク）、サイト、日付、ページの種類のタグ（論文、arXiv、PubMed、特許、SEC提出書類、ドキュメントなど）、PDFタグ、そしてスニペットまたは検索に答えている文章が表示されます。それぞれに開くボタン（↗）があります。

最初の8件が表示され、**Show all N results**で残りが表示されます。

## 返信の下にソースを表示する

エージェントが使ったページを引用すると、返信の最後に番号付きの一覧を置く代わりに、2か所にソースが表示されます。

- **本文中**：ページを引用している箇所に、サイトのアイコンと名前が付いた小さなチップ（**ign** など）が表示されます。複数のページを表すチップには、追加の数が表示されます（**ign +1**）。コンピューターでは、チップにポインタを合わせるとそのページがタイトルとサイト付きで表示され、クリックするとそのページが開きます（複数ある場合はカードから1つ選びます）。スマートフォンでは、タップして表示し、1つをタップして開きます。
- **返信の下**：最初のサイトのアイコンと、返信が引用しているページ数が表示された**ソース**の行があります。クリックすると、ページごとにカードが開き、タイトル、サイト、リンクが表示されます。

表示されるのは、返信が引用しているページだけです。エージェントが付けた番号のとおりに表示され、実行したすべての検索が出るわけではありません。検索したことや読んだことは、そのステップに表示されます（返信の上にある**Worked for…**を開きます）。**メッセージをコピー**（返信の下）を押すと、エージェントが書いたとおりに、ソースの一覧も含めてコピーされます。読み上げでは、番号と一覧は省かれます。サイトのアイコンは、最初に表示されるときにそのサイト自体から取得され、保存されます。アイコンのないサイトには、頭文字が表示されます。

## ページ全体を読む、または質問に答える部分だけを読む

スニペットだけでは足りないとき、エージェントはページを読みます。ページ全体を読むこともでき、長いページは約3,000語ずつに分けて届き、エージェントは必要になったときに次の部分を求めます。あるいは、ページに質問をして、それに答えている部分だけを受け取ることもでき、こちらのほうがずっと短くなります。

- Naget Searchがオンでキーも追加されている場合は、Naget Searchがページのうち質問に答えている文章を選びます。ステップには、ページの語数のうちどれだけが残されたかが表示されます。検索に答えている文章とは違い、こちらにはキーが必要です。
- そうでない場合は、アプリが質問と共通する語が最も多い段落を選び、答えが見当たらなければページ全体を読むようエージェントに伝えます。

PDFもテキストとして読まれます。この方法で読めるのは、公開されているWebページだけです。このコンピューターやそのネットワーク上のアドレスは読めません（許可すれば、[ブラウザ](/guide/web#the-browser-agents-use)で開けます）。ページは一度取得されると10分間保存されるため、次の部分はすぐに届きます。

会話の中では、読み取りは「読み取り」とページのタイトルで表示され、画面が広い場合は、ページに尋ねた質問も表示されます。クリックすると、アドレス、どの部分か（「3つのうちの1つ目」）または質問に「答えている部分」、そしてエージェントが受け取ったテキストが表示されます。

## エージェントが使うブラウザ

サイトによっては、クリック、フォーム、ログイン、スクリプトが必要で、単純な読み取りでは先に進めません。そのためエージェントには、普段使っているブラウザとは別のブラウザがあります。普段お使いのChrome、Edge、Firefox、Safariのサインイン状態は一切引き継ぎません。このブラウザはライブで見ることができ、いつでも操作を代われます。どのブラウザになるかは、アプリが動いている場所によって決まります。

- **デスクトップアプリ**（Mac、Windows、Linux）では、Chromium（Chromeのもとになっているオープンソースのブラウザ）をベースにしたアプリ専用ブラウザが、アプリの中で動きます。インストールは不要で、別のものを選ばない限りアプリがこれを使います（[Chromium](/guide/web#chromium)を参照）。ページはアプリのウィンドウ内で高速に描画され、クリックするとそのまま操作でき、ウィンドウを閉じても動き続けます。
- **それ以外の場所**（Dockerやサーバー上のアプリ、それを表示しているスマートフォンやWebページ）では、アプリが動いているコンピューター上で本物のChromiumを起動します。画面はライブの画像として表示されます。

ブラウザをオンにすると、どのエージェントも次のことができます。

- 今のタブまたは新しいタブでページを開く（ページのスクリプトも動きます）
- ページをアウトラインとして見る（テキストと、番号付きのリンク、ボタン、入力欄）
- クリック、ダブルクリック、ポイント、入力欄への入力（内容の置き換えまたは追記、Enterキーの押下を含む）、リストからの選択、スクロール、キー操作、戻る、待機を、最大10ステップまとめて実行する（ページが変わったら途中で止まります）
- 保管庫に保存したサインイン情報でサインインする（パスワードなどのキーは、名前を指定してページに入力されます。エージェント自身は中身を見ず、許可したホストのページでのみ入力されます。[保管庫にキーを保管する](/guide/connections#keep-keys-in-the-vault)を参照）
- 番号を描き込んだスクリーンショットを見る（モデルが画像を扱え、スクリーンショットがオンの場合）
- ページ内のテキストを探す、テキストを分割して読む、長いページへの質問に補助モデルで答える（[エージェント、アカウント、モデル](/guide/agents-models)を参照）
- タブの一覧表示、切り替え、閉じる操作
- セッションのフォルダにあるファイルを、ページのアップロード欄に添付する（それ以外の場所のファイルは添付できません）
- ブラウザを操作者に引き渡す

次のことは、常に操作者が行うか、承認を待ちます。

- **保存済みのサインインがないログイン、確認、エージェントが判断に迷うこと。** エージェントは、これらを自分で試さずに操作者へ引き渡すよう指示されています。CAPTCHA（人間であることの確認）や、本人に届くコードもこれに含まれます。スケジュールタスクのように、操作者なしで再度サインインが必要になるタスクでは、エージェントがカードでサインイン情報を尋ね、保管庫に保存することがあります。
- **支払いと注文。** エージェントは、支払いや注文になるボタン（支払う、今すぐ購入、注文を確定、今すぐ登録、寄付する、今すぐ予約、カード入力欄があるフォームの送信ボタンなど）を押しません。手前で止まり、操作者に完了を求めます。
- **サインイン済みのサイトで、送信、投稿、削除、送金を行うボタン。** エージェントがこれらを押す前に、許可を求められます（[送信、投稿、削除のボタン](/guide/web#buttons-that-send-post-or-delete)を参照）。この確認は設定でオフにできます。
- **入力した内容。** パスワード、カード番号、セキュリティコード、ワンタイムコードの値はエージェントに表示されません。操作者が自分で操作して入力した内容も同様です。アドレスのうちパスワードのような部分も隠されます。エージェントが保管庫から入力した欄にはドットが表示され、エージェントには入力済みであることだけが伝わります。
- **ページからのポップアップの質問**（[ページのポップアップの質問に答える](/guide/web#answer-a-pages-pop-up-questions)を参照）

ブラウザはセッションごとに専用のものがあります。プロファイルがなければ新規の状態で始まり、どこにもログインしておらず、閉じると何も残りません。プロファイルを使うと、そのプロファイルでログインしているサイトにログインした状態になります（[プロファイルでサインインを保持する](/guide/web#keep-sign-ins-with-profiles)を参照）。ブラウザページにある操作者自身のブラウザは別のもので、エージェントは使いません。ただし、そのページを引き渡した場合は別です（[エージェントにページを渡す](/guide/web#hand-a-page-to-an-agent)を参照）。

## ブラウザをライブで見る

セッションのブラウザが開いている間、メッセージ欄のすぐ上にパネルが表示されます。パネルには、ページのタイトル（または「空白のページ」）と、その下にエージェントの動作（「「サインイン」をクリック中」「「検索」に入力中」）、使用中のプロファイル、開いているタブの数が表示されます。操作者の対応を待っているときは「応答を待っています」、操作者が使っているときは「操作中：エージェントは待機しています」と表示されます。

コンピューターでは次のようになります。

- 折りたたんだパネルの左側には、ページの小さなライブ画像が表示されます。この画像、タイトル、矢印のいずれかをクリックする（**ライブビューを表示**）とライブビューが開き、**ライブビューを隠す**でもう一度折りたたみます。
- **全画面**でアプリ全体にブラウザが表示され、**全画面を閉じる**で元に戻ります。
- **操作を代わる**でブラウザを自分で操作でき（下記を参照）、**ブラウザのオプション**（⋯）でメニューが開きます。

スマートフォンでは、パネルをタップするとブラウザが全画面で開き、×で閉じます。

デスクトップアプリでは、ライブビューはアプリが描画するページそのもので、ページの変化に合わせて素早く更新されるため、スクロールや入力は通常のブラウザと同じ感覚です。それ以外の環境では、ページの画像が見ている間に毎秒数回送られてきます。最初の画像が届くまでは「ブラウザに接続しています…」と表示されます。

### エージェントの指す位置を見る

ブラウザは画面に表示されない状態で動いているため、ライブビューにエージェントのポインターが描かれます。アプリのテーマカラーの大きな矢印に、やわらかい光の輪と**エージェント**のタグが付いています。

- エージェントがクリック、入力、スクロールをする前に、ポインターは元の位置からその場所まで約3分の1秒で移動します。目で追えるようにするためです。見ている間はエージェントがその動きを待ち、誰もブラウザを見ていないときは待ちません。
- クリックした場所には輪が広がります（ダブルクリックでは2つ）。入力した欄や選択したリストは、しばらく枠線で囲まれます。スクロールの向きはポインターの横の矢印で示され、押したキー（Enter、Tab、Ctrl+Aなど）はタグの横に表示されます。
- ポインターは、エージェントが最後に操作した場所に残ります。折りたたんだパネルの小さな画像では、小さな矢印として表示されます。
- 操作者が操作している間、エージェントのポインターはライブビューから消え、ポインターは操作者のものだけになります。ブラウザを戻すと、再び表示されます。

エージェントがブラウザで行った各ステップは、会話の中にも、ほかのステップと並んで1行で表示されます（「github.comを開きました」「[12] ボタン「サインイン」をクリックしました」「操作者に依頼しました：GitHubにログイン」など）。その後ろには、操作後のページの小さな画像が付きます。行をクリックすると、画像が大きく表示され、エージェントの回答全文も見られます。大きな画像では、クリックした場所に輪、入力した欄に破線の枠が表示されます。ステップで複数の操作をした場合は、番号が付きます。アプリは各セッションの直近400ステップ分の画像を保持し、1か月間操作のないセッションの画像は削除されます。

## 操作を代わって、ログイン、確認、支払いを行う

エージェントがブラウザで操作者を必要とするときは、複数の場所で同時に通知されます。

- ブラウザのパネル上部に、ボタン付きの行が表示されます。
- 会話に、「ブラウザで操作が必要です：GitHubにログイン」のようなカードが表示され、**表示**ボタンが付きます（スマートフォンでは**開く**）。
- セッションが回答を求めるときと同様の通知と、[受信トレイ](/inbox)の項目が表示されます（[受信トレイと通知](/guide/inbox)を参照）。

コンピューターでは、ログイン、支払い、ポップアップの質問のときにライブビューが自動で開き、対応が済むと再び閉じます（操作者が自分で開いた場合を除く）。

### コンピューターの場合

1. 行（またはパネル）の**操作を代わる**を押します。パネルに「操作中：エージェントは待機しています」と表示され、ライブビューに色付きの枠線が付きます。
2. 通常のブラウザと同じようにページを操作します。クリック、ホイールでのスクロール、入力ができます。最初にページ内をクリックしてください。以降、キー入力はページに送られ（アプリ自体のショートカットは待機します）、貼り付けた内容はテキストとして入力されます。デスクトップアプリでは、ページ内でクリックまたは入力するだけで操作を代われます。パネルが自動で「操作中：エージェントは待機しています」に切り替わり、エージェントが操作している間は、アドレスの下に「ページ内をクリックすると自分で操作できます」と表示されます。
3. 操作している間は、ページの上のバーに**戻る**、**再読み込み**、アドレスが表示されます。アドレスを入力してEnterを押すと、そのページに移動します。
4. 終わったら、行の**完了**を押します。アプリが、ブラウザが現在表示しているページとともに完了をエージェントに伝え、エージェントが作業を続けます。

### スマートフォンの場合

1. **操作を代わる**をタップします。ブラウザが全画面で開き、操作中はページがスマートフォンの画面に合わせて表示されます。**戻る**、**再読み込み**、アドレスのバーはその上にあります。
2. タップでクリック、ドラッグでスクロールします。**入力**でスマートフォンのキーボードが開き、その横の行にはTab、Enter、Esc、⌫、矢印キーがあります。
3. 終わったら**完了**をタップします。ページが通常のサイズに戻り、エージェントが作業を続けます。

### 支払いと注文

エージェントは、支払いや注文になるボタンに到達すると、そこで止まります。「支払いまたは注文の手前で停止しました：shop.example.comの注文を確定。ここからは操作者が行います。」というメッセージが表示されます。操作を代わり、注文内容を確認して自分で支払い、**完了**を押してください。進めない場合は**今はしない**を押します。どちらの場合も、エージェントにはその結果が伝わります。

### そのほかの回答と、自分から操作を代わる場合

- **できません**は、エージェントに頼まれたことができなかったことを伝えます。
- 頼まれたときだけでなく、いつでも自分から操作を代われます。パネルの**操作を代わる**を押してください。エージェントは待機します。その間にエージェントがブラウザを使おうとすると、操作者が使用中であること、終わったら知らせが届くことが伝えられます。**戻す**を押すとブラウザがエージェントに戻ります。エージェントがブラウザを待っていた場合は、ブラウザが表示しているページを添えたメッセージが届きます。

操作者の代わりにアプリがエージェントへ送るメッセージは、会話に表示されます。エージェントが応答の途中の場合、メッセージはその応答が終わるまで待機します。

## 送信、投稿、削除のボタン

ブラウザがサインイン済みのサイトでは、エージェントは、送信、投稿、公開、共有、返信、削除、取り除き、送金、引き出しを行うボタンを押す前に、確認を求めます。対象は、プロファイルを使うブラウザ（[プロファイルでサインインを保持する](/guide/web#keep-sign-ins-with-profiles)を参照）と、エージェントに渡したページ（[エージェントにページを渡す](/guide/web#hand-a-page-to-an-agent)を参照）です。新規の状態で始まり、どこにもログインしていないブラウザには守るものがないため、確認は求められません。支払いと注文は、これまでどおり操作者だけが行います（上記を参照）。

エージェントは、これらのボタンを、英語、ドイツ語、ギリシャ語、中国語、フランス語、スペイン語の文言で判断します。Send、Post、Publish、Delete、Transferなどがその例で、ページがこれらに関するものであれば、単なる「Confirm」や「Yes」も対象になります（「この投稿を削除しますか？」というポップアップなど）。「Sign in」、「Next」、「Save draft」、「Cancel」、検索ボタン、自分宛てのコードの送信（Resend code）は止められません。

エージェントはこれらのボタンに到達すると、止まってターンを終え、待機します。ほかの質問と同じ場所（ブラウザのパネルの行と会話のカード）に、「mail.example.comの「Delete」を押そうとしています」と表示され、**許可しない**と**許可**が付きます。ライブビューは自動では開きません。

- **許可**を押すと、エージェントは今そのボタンを押してよいと伝えられます。許可されるのは、そのサイトで、同じ文言のボタンを今後2分以内に1回押すことだけです。それを過ぎると、エージェントは再度確認します。
- **許可しない**を押すと、エージェントはそのボタンを押さないよう伝えられます。エージェントは押さずに作業を続けるか、できなかったことを知らせます。その後、カードには「許可済み」または「許可されていません」と表示されます。

この確認は最初からオンになっています。オフにするには、[サインイン済みのサイトで送信前に確認する](/guide/web#ask-before-sending-on-signed-in-sites)を参照してください。

## ページのポップアップの質問に答える

ページがポップアップ（アラート、はい・いいえの質問、テキスト入力の求め、「このページを離れますか？」など）を開くと、ライブビューの上に、サイト名、「の内容」（または「ページを離れるか確認しています」）、メッセージが表示されます。回答できるのは操作者だけで、**OK**または**キャンセル**（テキスト入力の場合は入力欄も表示）、あるいは**離れる**または**宿泊**を選びます。エージェントのステップがポップアップを開いた場合は通知が届き、エージェントには操作者の回答が伝わります。

## セッションにこのコンピューターやネットワーク内のサイトを開かせる

[このマシンとそのネットワークにページからアクセスさせない](/settings?s=browser&find=Keep%20pages%20off%20this%20machine%20and%20its%20network)がオン（初期設定）の間、ページはこのコンピューターやネットワーク上のほかの機器にアクセスできません。エージェントがアクセスしたい場合（たとえば、このコンピューター上で動かしている制作中のWebサイト（開発サーバー）など）は、先に確認を求めます。「localhost:3000（このマシンまたはそのネットワーク内）を開こうとしています」と表示され、**許可しない**と**このセッションで許可**が付きます。許可すると、このセッションのブラウザは以後そのアドレスを開けるようになり、エージェントにもう一度開くよう伝えられます。

操作中に自分で入力した、このコンピューターやネットワーク内のアドレスも、同様にそのセッションで許可されます。ブラウザのメニューの**このセッションのサイト**には、「このマシンまたはそのネットワークで許可済み」の下に、許可したものが一覧表示されます。横の×で取り消せます。Hydor自体をブラウザから開くことはできません。

## ブラウザのメニュー

パネルの**ブラウザのオプション**（⋯）でメニューが開きます。

- **タブ**：2つ以上開いているときに表示されます。選ぶとそのタブが表示されます。ページがリンクを新しいタブで開いた場合、エージェントはそのタブで作業を続けます。
- **セッションのフォルダに保存しました**：ブラウザが最近ダウンロードしたファイルです。選ぶと開きます。
- **プロファイル（別のプロファイルにするとブラウザが再起動します）**：**新規（ログインなし）**か、作成済みのプロファイルから選びます。プロファイルを作成すると表示されます。別のものを選ぶとブラウザが閉じ、次に使うときに新しいプロファイルで開きます。
- **このセッションのサイト**：このセッションのブラウザが訪問できるサイトだけ（**これらのサイトのみ**。空欄の場合はすべてのサイト）と、常に訪問しないサイト（**これらのサイトは常に除外**）を、1行に1つずつ指定します。設定 → ブラウザにあるリストに追加されます。**保存**を押すと保持されます。
- **ブラウザを閉じる**

## ブラウザを自分で開く

エージェントより先にセッションのブラウザを開くこともできます。たとえば、エージェントに作業を頼む前にサイトへログインしておきたいときです。セッションのメニュー（⋯）→ **その他** → **ブラウザを開く**を選びます。メッセージ欄の上にパネルが表示されるので、**操作を代わる**を押して操作します。ブラウザがすでに開いているときは、同じ項目が**ブラウザを表示**になります。ブラウザが設定でオフになっている場合は、その旨が表示されます。セッションに紐づかない自分専用のブラウザについては、[自分専用のブラウザ](/guide/web#your-own-browser)をご覧ください。

## ダウンロードとアップロード

ページがダウンロードしたファイルは、セッションのフォルダ内の downloads というフォルダに保存され、保存先はエージェントに伝えられます。ブラウザのメニューには、最新のものが**セッションのフォルダに保存しました**の下に一覧表示されます。

エージェントがページのアップロード欄に添付できるのは、セッションのフォルダにあるファイルだけです。別のファイルをアップロードさせたいときは、先にそのファイルをセッションのフォルダへコピーしてください（[システム：ファイル、Git、ターミナル、プレビュー](/guide/files-git)を参照）。

## ブラウザが閉じるとき

セッションのブラウザは、次の場合に自動で閉じます。

- 15分間、誰も使っておらず見てもいないとき。ユーザーの操作待ちのときや、ユーザーが操作しているときは2時間です。
- 最後のタブが閉じたとき。
- セッションのエージェントが停止したとき、またはセッションが削除されたとき。
- ブラウザに別のプロファイルを選んだとき、または使用中のプロファイルを削除したとき。

ユーザーの操作待ちだったものも、ブラウザと一緒に終了します。エージェントは、次にブラウザが必要になったときにあらためて開きます。

デスクトップアプリでは、エージェントのブラウザはアプリのウィンドウがなくても動作します。アプリが起動している間は、ウィンドウを閉じていても隠していても動き続けます（アプリはメニューバー、通知領域、トレイに残ります）。ウィンドウを開けば、ページを見守ることができます。

## 自分専用のブラウザ

**ブラウザ**ページは、デスクトップアプリ（Mac、Windows、Linux）の中にある自分専用のブラウザで、エージェントが使うブラウザとは別に用意されています。アイコンバーの**ブラウザ**を開くか、[ブラウザ](/browser)にアクセスします。この機能はデスクトップアプリだけのものです。ブラウザで使うWebアプリとスマートフォンには**ブラウザ**ボタンがなく、そこで[ブラウザ](/browser)のアドレスを開くと、その旨が表示されます。エージェントのブラウザはどこでも動作し、各セッションで様子を見られます。

ページ上部にはバーがあり、検索、アドレスを開く操作、ページについてエージェントに質問したり指示したりする操作をまとめて行えるボックスがあります。ページの左側にはタブの列があり、ピン留めしたサイトや作業中のエージェントも並びます。右側には、ドラッグして幅を変えられる列があり、ページについてエージェントに質問したり指示したりするほか、エージェントとの会話、履歴、ダウンロード、ブックマーク、拡張機能、設定を表示します。戻る、進む、再読み込み、ブックマーク、履歴、Chrome拡張機能、広告とトラッカーのブロック（Cookieバナーも非表示にします）、ページ内検索、ズーム、印刷、ダウンロードに対応しています。閉じるとすべてを忘れる[プライベートタブ](/guide/web#private-tabs)、ページを自分の言語にする[ページの翻訳](/guide/web#translate-a-page)、記事向けの[リーダービュー](/guide/web#reader-view)、[ダークページ](/guide/web#dark-pages)、[スクリーンショットとPDFとしてのページ保存](/guide/web#screenshots-and-pdfs)も使えます。サイトが勝手に音を再生しないようにもなっています。リンクにポインターを合わせると、Chromeと同じように、移動先がページの左下の小さなボックスに表示されます（マウスがそこにあるときは右下に表示されます）。タブはアプリのウィンドウ内にある本物のページで、一般的なブラウザと同じ速度とキー操作で使え、サイトにも一般的なブラウザと同じように直接接続します。アプリのメニューやダイアログがページの上に開くと、ページは一時的に隠れます（閉じるまでは、その画像が表示されます）。サインイン状態は、エージェントが選べない専用のプロファイルに保存され、訪問のあいだも保たれます。次に開いたときは、前回のタブ（最大30個。空白のタブとプライベートタブは除きます）が復元されます。タブでは、このコンピューターやそのネットワーク上のアドレス（たとえば開発中のWebサイト）も開けます。ブラウザを起動できないときは、ページに理由が表示され、**もう一度試す**と**ブラウザの設定**が並びます。**ブラウザの設定**を押すと[設定 → ブラウザ](/settings?s=browser)が開きます。

### バーとボックス

ページの上部をバーが横切っています。左端のタブの列の上には、アプリのロゴ、**新しいタブ**（+）、**タブを隠す**（Ctrl+Bと同じ）があります。**タブを隠す**を押すとタブの列がたたまれ、**タブを表示**を押すと元に戻ります。バーの残りの部分は、今開いているページのためのものです。

- **戻る**、**進む**、**再読み込み**、**ホーム**はボックスの左にあります。ページの読み込み中は、再読み込みが**停止**に変わります。**ホーム**は今のタブでホームページを開きます。**新しいタブ**は、新しいタブでホームページを開きます。
- 中央のボックスがアドレスバーです。通常は、ページのアドレスのうちサイト名の部分を通常の色で、残りを薄い色で表示し、ヒントとして**Ctrl+L**も表示します。クリックするか Ctrl+L を押すと、アドレス全体が表示されて編集できます。ここに入力した内容は、ほかのアプリに移っている間も残ります。ページ内をクリックすると、アドレスが元に戻ります。アドレスは https:// の有無にかかわらず入力でき（`example.com`、`localhost:3000`、`192.168.1.5`、`file://` のアドレスなど）、**Enter**を押すと開きます。それ以外の入力は、検索エンジンで検索されます（初期設定はGoogleです。[ブラウザの設定](/guide/web#browser-settings)を参照）。`yt` のようなショートカットに続けてスペースと言葉を入力すると、そのサイト内を検索します（[候補](/guide/web#suggestions)を参照）。**Alt+Enter**または Ctrl+Enter（Macでは ⌘+Enter）を押すと、新しいタブで開きます（プライベートタブにいるときはプライベートタブで開きます）。入力中に表示される内容は[候補](/guide/web#suggestions)をご覧ください。左端には鍵のアイコンがあります（プライベートタブでは、その前に紫色の**プライベート**チップが表示されます。[プライベートタブ](/guide/web#private-tabs)を参照）。右端には、ページがユーザーの言語と異なる場合にページを翻訳するボタン（[ページを翻訳する](/guide/web#translate-a-page)を参照）、ページに記事があるときに表示されるリーダービューの本のボタン（オンの間は横に**Aa**が表示されます。[リーダービュー](/guide/web#reader-view)を参照）、そして星のボタンがあります。
- ボックスの端にある星は、ページをブックマークバーにブックマークします。塗りつぶされているとブックマーク済みで、もう一度押すとブックマークが外れます。バーにあるサイトは、タブの列の上部にタイルとして表示されます。
- **保存**は、リーダービューと同じ形で、読みやすいページのコピーをプロジェクトに保存します。記事の本文と画像、動画が残り、サイトのメニュー、広告、コメント、スクリプトは含まれません。「（プロジェクト名）に保存しました」（例：「Thesisのファイルに保存しました」）というメッセージと**開く**が表示されます。コピーはプロジェクトのファイルの中にあるWebページで、**ファイル**タブにあります（[ファイル](/guide/projects#files)を参照）。**保存**の横の**▾**（**保存先のプロジェクトを選択**）には、保存先の候補として**プロジェクトなし**とすべてのプロジェクトが一覧表示されます。**保存**が使う保存先にはこのメニューで印が付きます。このコンピューターで最後に選んだ保存先です（最初は**プロジェクトなし**）。プロジェクトなしの場合は、「保存しました。コピーをプロジェクトのファイルに残すには、保存の横でプロジェクトを選んでください。」と表示されます。この場合、コピーはどのプロジェクトにも属さず、検索ボックス（Ctrl+K）で見つけられます。リスト類（ブックマーク、あとで読むページ、ダウンロード、履歴、ハイライト）は、**メニュー**（⋯）から開くこのページのパネルです（[ページの横の列](/guide/web#the-column-beside-the-page)を参照）。
- **質問**は、ページの横の列を開き、ページについてエージェントに質問できるようにします。**実行**を選ぶと、エージェントにそのページで作業させることもできます（[ページの横で質問する](/guide/web#ask-beside-the-page)を参照）。この列が表示されている間は、ボタンが点灯します。
- 続いて、ピン留めした拡張機能のボタンが並びます。その次が**拡張機能**（パズルのピース）で、オンになっているすべての拡張機能が一覧表示されます。開いているタブが拡張機能のChrome Web Storeページのときは、さらに**Hydorに追加**が表示されます（[Chrome拡張機能](/guide/web#chrome-extensions)を参照）。
- **メニュー**（⋯）には、**新しいプライベートタブ**（[プライベートタブ](/guide/web#private-tabs)を参照）があり、続いてページに対する操作として、**ページ内を検索**、**ページを翻訳…**（ページの翻訳中は**原文を表示**。[ページを翻訳する](/guide/web#translate-a-page)を参照）、**リーダービュー**と**ダークページ**（オンの間はチェックが付きます。[リーダービュー](/guide/web#reader-view)と[ダークページ](/guide/web#dark-pages)を参照）、そして**ズーム**（− と + の間にズームの割合が%で表示されます。[ズーム、印刷、全画面表示](/guide/web#zoom-print-and-full-screen)を参照）があります。続いて**印刷…**と**スクリーンショットまたはPDF**があり、後者を開くと、メニューの同じ場所に**表示範囲のスクリーンショット**、**ページ全体のスクリーンショット**、**PDFとして保存…**が表示されます（上の**スクリーンショットまたはPDF**を押すと戻ります。[スクリーンショットとPDF](/guide/web#screenshots-and-pdfs)を参照）。続いて、一覧として**履歴**、**ダウンロード**、**ブックマーク**、**あとで読む**（待っているページの数も表示されます。[あとで読む](/guide/web#read-later)を参照）、**ハイライト**（ページにある数も表示されます）が並びます。最後に、ブラウザそのものの**拡張機能**、**サイトの権限**、**設定**、**キーボードショートカット**があります。一覧とこれらの項目は、ページの右側の列に開きます（[ページの横の列](/guide/web#the-column-beside-the-page)を参照）。ズームの − と + を押している間も、メニューは開いたままです。プライベートタブでは、エージェントにプライベートタブが渡されることはないため、**質問**はグレーアウトされます。

`/browser?url=https://example.com` へのリンクは、そのアドレスを新しいタブで開いた状態でブラウザページを開きます。[/browser?private=1](/browser?private=1) は新しいプライベートタブを開きます（そのアドレスを開くには `&url=https://example.com` を付けます）。

### 候補

アドレスバーに入力すると、その下のリストに次のものが表示されます。入力した言葉は太字になります。

- 開いているタブ（「タブに切り替え」。選ぶと、ページを開き直さずにそのタブへ移動します。プライベートタブも開いている間は含まれ、閉じたあとは何も残りません）
- タイトルやアドレスが入力した言葉に一致するブックマークと履歴のページ。よく行くページや最近のページが先に表示されます（自分で入力したアドレスは最も重視され、ブックマークは20回の訪問として数えます）。入力した言葉に一致するブックマークがあるときは、履歴の最後のページの代わりに、必ず2件以上が候補に入ります。そのため、ほかのブラウザから読み込んだ大量の履歴があっても、ブックマークが埋もれることはありません。
- [意味で検索](/settings?s=memory&find=Search%20by%20meaning)がオンのとき、タイトルやアドレスに入力した言葉が含まれていなくても、入力した内容に関連するブックマークと履歴のページ。言葉が含まれるものの後に表示されます（太字の言葉は付きません）。これらを見つけるモデルはこのコンピューター上で動作し、各ページのタイトルとアドレス（クエリ文字列は除く）から作ったベクトルを使います。ベクトルはほかのデータとは別にアプリのデータベースに保存され、ページが消えると一緒に消えます。
- 入力した内容が検索ショートカットとスペースで始まるとき（`yt lofi`）、最初に、その後ろの言葉でそのサイトを検索する行（「YouTubeで「lofi」を検索」）。**Enter**で実行できます（[ブラウザの設定](/guide/web#browser-settings)を参照）。
- 入力した内容を検索する行（「Googleで検索」）。アドレスに見える場合は、そのアドレスを開く行になります。ショートカットを付けた場合も、この行はすべての言葉を検索エンジンで検索します。
- [検索候補](/guide/web#browser-settings)がオンのとき、検索エンジン自身の候補
- その下には、開いているタブがWebページのとき（エージェントには渡されないプライベートタブは除く）、**このページについて質問：「…」**が表示されます。入力した内容を質問として、ページの横の質問を開きます。質問で**実行**を選んでいる間は、代わりに**このページで実行：「…」**と表示され、入力した内容をエージェントに渡してそのページで実行させます（[ページ上で実行する](/guide/web#do-it-on-the-page)を参照）。
- 最後に、**エージェントに質問：「…」**があります。入力した内容を最初のメッセージとしてセッションを開始し、スタートページで最後に使ったエージェントとモデルを使って、そのセッションへ移動します。

リストには、画面に収まる数だけ表示されます。ページと検索エンジンの候補が2件以上ずつあるときは、それぞれ最低2件が含まれます。ウィンドウが低くてリストを切り詰める必要があるときは、履歴のページがブックマークや開いているタブより先に省かれます。矢印キーでリスト内を移動し、**Enter**で選択中の項目を開きます（何も選んでいないときは、入力した内容を開きます）。**Alt+Enter**または Ctrl+Enter（Macでは ⌘+Enter）を押すと、新しいタブで開きます（プライベートタブにいるときはプライベートタブで開きます）。アドレスバーはその場で補完もします。訪れたことのあるページのうち、入力した内容で始まるものがあると、残りがカーソルの後ろに選択状態で表示されます（入力した言葉で探すもので、意味では探しません）。**Tab**または**→**で確定します。入力した内容を削除すると、補完はオフになります。履歴の候補で**Shift+Delete**を押すと、そのページを履歴から消去します。**Esc**でリストを閉じます。

### タブ列

ページの左側にある列には、上から順に次の項目が並びます（**タブを隠す**、またはCtrl+Bで列を折りたためます）。

- **ピン留めしたサイト**：ブックマークバーの項目をタイルで表示します。1行に5つ、最大2行までで、残りは **…** タイルにまとめられます。クリックすると開いているタブで開き、Ctrl+クリック（Macでは⌘+クリック）または中クリックで新しいタブで開きます。フォルダを開くと、中身の一覧が表示されます。タイルを右クリックすると、**開く**、**新しいタブで開く**、**編集**（フォルダの場合は**名前を変更**）、**削除**が選べます。ブックマークバーに何もないときはタイルは表示されません。星印を押すと、そのページがバーに追加されます（[ブックマーク](/guide/web#bookmarks)を参照）。
- **作業中のエージェント**：エージェントがブラウザを開いている間に表示されます。エージェントごとに1行で、アイコンと点（作業中は青、ユーザーの操作待ちや手動操作中は琥珀色）、セッションのタイトル、実行中の内容が表示されます。クリックすると様子を見られます（[作業中のエージェント](/guide/web#agents-at-work)を参照）。矢印で一覧を折りたためます。
- **プライベート**：プライベートタブを開いている間に表示される紫色のセクションです。仮面のアイコンと開いている数、プライベートタブごとの行（色付きの行で、アイコンに小さな仮面が付きます）が並びます。ラベルをクリックするとセクションを折りたためます。**プライベートタブを閉じる**（ラベルにポインターを合わせると表示される×）ですべて閉じ、末尾の**新しいプライベートタブ**でもう1つ開けます（[プライベートタブ](/guide/web#private-tabs)を参照）。プライベートタブはどのグループにも属さず、グループにドラッグすることもできません。
- **タブ**：タブごとに1行で、アイコン、タイトル、**⋯**、**×**が表示されます（**⋯**と**×**は開いているタブと、ポインターを合わせたタブに表示されます）。列に収まらない長いタイトルは末尾が薄くなり、行にポインターを合わせると流れて続きが表示されます。開いているタブは印の付いた行です。行をクリックするとそのタブが表示され、中クリックで閉じます。行を右クリックするか**⋯**を押すと、タブのメニューが開きます（[タブグループとタブのメニュー](/guide/web#tab-groups-and-the-tab-menu)を参照）。グループに入れたタブはグループの見出しの下に並びます。**タブ**ラベルの末尾にあるキラキラのボタンで、AIがタブをグループ化します。音を出しているタブにはスピーカーが表示され、クリックでタブをミュートし、もう一度クリックすると音が出ます。ミュートしたタブにもスピーカーは残ります。末尾の**新しいタブ**でホームページが開きます。最後のタブを閉じると、空白のタブが残ります。
- **あとで読む**：タブの下にあり、取っておいたページ（[あとで読む](/guide/web#read-later)を参照）が新しい順に並び、それぞれアイコンとタイトル、待っている数が表示されます。待っているページがないときは折りたたまれていて、矢印で開けます。行をクリックすると、そのページが新しいタブで開きます。行にポインターを合わせると**既読にする**（一覧から消えます）と**外す**が表示されます。末尾の**既読を表示**で読み終えたページが一覧に戻り、**既読を隠す**でもう一度しまえます。

### タブグループとタブのメニュー

タブを右クリックするか（ポインターを合わせた行の**⋯**を押す、またはフォーカスした行でメニューキーを押す方法もあります）、メニューが開きます。

- **タブを閉じる**、**他のタブを閉じる**、**下のタブを閉じる**（列に並んでいる順で、そのタブより下のタブ）。ブラウザには常に1つタブが残ります。
- **複製**は、同じアドレスを同じグループ内のすぐ隣の新しいタブで開いて表示します（プライベートタブの複製もプライベートになります）。**再読み込み**は、開いているタブだけでなく、そのタブを再読み込みします。
- **アドレスをコピー**、**Markdownリンクとしてコピー**（ページへのリンクを、タイトルをテキストにしたMarkdown形式でコピーします。ドキュメントやメッセージ用で、「Markdownリンクをコピーしました」と通知が出ます）、**ブックマーク**（ブックマーク済みの場合は**ブックマークを外す**）。ページがブックマークバーに追加されます。
- **グループに追加**はグループの一覧を表示し（タブが入っているグループにはチェックが付きます）、**新しいグループ…**はそのタブでグループを作って名前の入力欄を開きます。**グループから外す**もあります。プライベートタブのメニューにはどちらもありません。プライベートタブはグループ化できません。

グループは、関連するタブをまとめておくものです。名前と7色（グレー、青、緑、琥珀色、オレンジ、赤、紫）のうちの1色があり、開いた状態か折りたたんだ状態になります。列ではグループは見出しとして表示され、色、名前（付けるまでは「名前のないグループ」）、タブの数が並びます。グループのタブは見出しの下に、グループの色の線を側面に付けて並び、どのグループにも入っていないタブはグループの後に続きます。見出しをクリックするとグループを折りたたみ、もう一度クリックすると開きます。折りたたんだグループでは、開いているタブを除いてタブが隠れます。名前をダブルクリックするか、F2を押すと名前を変更できます。タブをグループにドラッグすると追加され、グループに入っていないタブの上にドラッグすると外れます。見出しを右クリックするか**⋯**を押すと、グループのメニューが開きます。

- **名前を変更**と**色**。
- **グループに新しいタブ**は、ホームページを新しいタブでグループ内に開きます。
- **グループ解除**は、グループをばらして、タブはそのままの位置に残します。
- **グループを閉じる**は、グループとそのタブをすべて閉じます。

タブが1つもなくなったグループは消えます。グループはタブと一緒に保存されるので、ブラウザを再び開くと一緒に戻ります。スマートフォンでは、タブはバーの一覧で表示され、グループはありません。

### AIでタブをグループ化

タブをたくさん開いているときは、**タブ**ラベルの末尾にあるキラキラのボタン（**AIでタブをグループ化**。ラベルにポインターを合わせると表示されます）で、どのグループにも入っていないタブを用途別に整理できます。対象になるのは3つ以上のタブです。すでにグループに入っているタブはそのままで、プライベートタブは対象外です。カウントも、グループ化も、どこかに送信されることもありません。

**送信される内容と、使われるモデル。**ボタンを押したときだけ、対象の各タブ（最大60個）のタイトルとアドレスが、アプリの補助モデル（セッションのタイトルやメモリのメモを書くモデル。[設定 → エージェント → モデル → 補助モデル](/settings?s=models&find=Helper%20model)）に送られます。**自動**の場合は、Claude Code経由のClaude Haiku、なければCodexが使われ、どちらもオンラインです。このコンピューター上の独自のモデルなら、タブの情報はコンピューターの外に出ません。アドレスは **?** や **#** より後ろを除いて送られ、ファイルのアドレスは名前だけになります。ページの本文や画像は送られず、それ以外のときは何も送られません。タイトルが非公開の内容なら、ボタンを押さないでください（または、補助モデルにこのコンピューター上のモデルを設定してください）。

モデルは、短い名前と色を付けたタブのグループを返し、アプリはすぐにグループを作成します。作成したグループの数がメッセージで表示され、**元に戻す**を押すとグループ化する前の状態に戻ります。まとまるタブがない場合は、その旨が表示され、何も変更されません。エージェントがユーザーのタブを見ることはなく、アプリもエージェントにこの機能を使わせません。

### ページ横の列

ページの右側には、何かが入っているときだけ表示される列があり、次のいずれか1つが表示されます。ページについて**質問**する、またはページ上でエージェントに何かをしてもらう画面（[ページの横で質問](/guide/web#ask-beside-the-page)を参照）、タブの様子を見ているときのエージェントの会話（[作業中のエージェント](/guide/web#agents-at-work)を参照）、あるいは**履歴**、**ダウンロード**、**ブックマーク**、**あとで読む**、**ブックマークと履歴をインポート**、**ハイライト**、**拡張機能**、**サイトの権限**、**設定**、**キーボードショートカット**のパネルです。それぞれに閉じるための**×**があり、別のものを選ぶと置き換わります。ページの上に重なることはなく、ページは列の分だけ狭くなり、列を閉じると元の幅に戻ります。[履歴](/browser?panel=history)、[ダウンロード](/browser?panel=downloads)、[ブックマーク](/browser?panel=bookmarks)、[あとで読む](/browser?panel=later)、[ブックマークと履歴をインポート](/browser?panel=import)、[ハイライト](/browser?panel=highlights)、[拡張機能](/browser?panel=extensions)、[サイトの権限](/browser?panel=permissions)、[設定](/browser?panel=settings)、[キーボードショートカット](/browser?panel=shortcuts)のアドレスを開くと、そのパネルを表示した状態でブラウザページが開きます。

列の左端をドラッグすると幅を広げたり狭めたりできます（端にフォーカスして**←**または**→**を押す方法もあります）。ダブルクリックすると、標準の幅の400 pxに戻ります。幅は列に表示するすべての内容で共通で、このデバイスに保存され、340 px未満にはならず、ページには常に360 px以上が残されます。幅の狭いウィンドウでは、タブはバーの一覧になり、列はページの上に重なるシートになって、独自の幅になります。

### ページの横で質問

バーの**質問**（または入力ボックスの一覧の**このページについて質問：「…」**、右クリックメニューの**エージェントに質問**）で、表示中のタブ用の列が開きます。上部には**質問**と**実行**の切り替えがあり、選んだほうはこのデバイスに保存されます。

**質問**では、知りたいことを書くか、**要約**、**要点**、**やさしく説明**を押してから、**質問**を押します（**Ctrl+Enter**、Macでは⌘+Enter）。ボックスの下の行には、どのエージェントとモデルが答えるかが表示されます。スタートページで最後に使ったものです。新しいセッションは、現在のページのコピーから始まり（[このページについて質問](/guide/web#ask-about-this-page)を参照）、その会話が列いっぱいに表示されるので、そのまま質問を続けられます。メモの末尾には「**実行**を選ぶと、エージェントがページ上で作業します。」と表示されます。

**実行**では、このページでエージェントにしてほしいこと（「フォームに私の情報を入力して」など）を書いて、**実行する**を押します（**Ctrl+Enter**、Macでは⌘+Enter）。ボックスの下のエージェントの行はボタンになっていて、**Claude Code**または**Custom**を選べます（1つのタブに限定できるのはこの2つだけです。スタートページで最後に使ったほうが選ばれ、初期状態ではClaude Codeです）。モデルは、そのエージェントでスタートページが最後に使ったものです。メモには、エージェントが受け取るものが書かれています。専用のタブ、このサイトでのユーザーのサインイン状態、ブラウザだけです。また、送信、投稿、削除、支払いの前には確認を求めます（[ページ上で実行](/guide/web#do-it-on-the-page)を参照）。開始すると、エージェントのタブがページの代わりに表示され、会話が列いっぱいに表示されます。[作業中のエージェント](/guide/web#agents-at-work)と同じです。

どちらの場合も、ページ内で選択して**エージェントに質問**で送った言葉は、ボックスの上に表示され、リクエストと一緒に送られます（最大4,000文字）。**この画像について質問**で送った画像も同様にボックスの上に表示されます（[右クリックメニュー](/guide/web#right-click-menu)を参照）。質問では、**この画像を説明して**のようなクイック質問も表示されます。

タブごとに会話があり、タブを切り替えると、列にはそのタブの会話が表示されます。**セッションとして開く**を押すと、セッションの一覧にある該当のセッションに移動します。**新しい質問**（実行のあとは**新しいリクエスト**）を押すと、ここでのこのタブの会話が消去され（セッションは残ります）、改めて質問できます。実行のあとでタブに戻ってそのタブの質問を開くと、会話と**作業を見る**が表示され、押すとエージェントのタブがページの代わりにもう一度表示されます。ウェブサイトのページで使えます（質問はファイルでも使えます）。アドレスバーのページの行は、この切り替えに従います（[候補](/guide/web#suggestions)を参照）。

### キーボードショートカット

ブラウザページで、ページの中にいるときも使えます。WindowsとLinuxではCtrl、Macでは⌘を使います。

- **Ctrl+T**で新しいタブを開き、**Ctrl+W**で開いているタブを閉じます。
- **Ctrl+Shift+T**で最後に閉じたタブをもう一度開きます。続けて押すと、その前のタブが開きます（プライベートタブはこの一覧に含まれません）。
- **Ctrl+Shift+N**で新しいプライベートタブを開きます（Macでは**⇧⌘N**）。
- **Ctrl+Tab**で次のタブへ、**Ctrl+Shift+Tab**で前のタブへ移動します。**Ctrl+1**〜**Ctrl+8**でその番号のタブへ、**Ctrl+9**で最後のタブへ移動します。
- **Ctrl+L**でアドレスバーに移動します。
- **Ctrl+R**（**F5**も）で再読み込みします。
- **Alt+←**と**Alt+→**で戻る・進む操作をします（Macでは**⌘[**と**⌘]**も使えます）。
- **Ctrl+F**でページ内検索を開き、**Esc**で閉じます。
- **Ctrl+D**でページをブックマークします。
- **Ctrl+H**で履歴を、**Ctrl+J**でダウンロードを開きます。
- **Ctrl+B**でタブ列を折りたたみ、もう一度押すと元に戻します。端をドラッグすると幅を変えられます。幅は、アプリ内のすべての列で共通です。
- **Ctrl+P**でページを印刷します。
- **メニュー**（⋯）→**キーボードショートカット**で、これらのキーがページ右側の列にグループ別（タブ、ページ、アドレスバー、リスト、エージェント）に表示されます（[キーボードショートカット](/browser?panel=shortcuts)）。
- **Ctrl+Shift+Delete**で、設定の**閲覧データを消去**が開きます。
- **Ctrl**と**+**、**−**、**0**で、拡大、縮小、100 %に戻す操作ができます（[ズーム、印刷、全画面](/guide/web#zoom-print-and-full-screen)を参照）。

### ページ内を検索

**Ctrl+F**、またはメニューの**ページ内を検索**で、アドレスバーの下にバーが開きます。入力して少し止まると、最初の一致が見つかり、表示位置までスクロールされます。**Enter**で次の一致へ、**Shift+Enter**で前の一致へ移動します（矢印でも移動できます）。バーには、現在の一致位置（「3/12」、1000件を超えると「1000+」）、または「一致なし」と表示されます。**大文字と小文字を区別**を押さない限り、大文字と小文字は区別されず、最後まで行くと最初に戻ります。**Esc**または**×**でバーを閉じ、検索結果の強調表示を消します。

### ズーム、印刷、全画面

- **ズーム**：**Ctrl**と**+**で拡大、**−**で縮小します。段階はChromeと同じです（25 %〜500 %）。Ctrlとマウスホイールでもズームでき、**メニュー**（⋯）の**ズーム**行の**−**と**+**でも操作できます（押している間、メニューは開いたままです）。**Ctrl+0**、その行のパーセント表示、または下のチップで、[ブラウザ設定](/guide/web#browser-settings)の**ページのズーム**（初期状態は100 %）に戻ります。自分でズームしたサイトは、アプリの実行中はそのズームが保たれます。ページのズームと異なるズームのときは、アドレスバーの末尾に「125%」のようなチップが表示されます。クリックすると元に戻ります（タイトルは「100 %に戻す」、またはページのズームの値です）。
- **印刷**：**Ctrl+P**、またはメニューか右クリックメニューの**印刷…**で、ページの背景を含めて、コンピューターの印刷ダイアログが開きます。
- **全画面**：動画やページが画面全体への表示を求めると、アプリのウィンドウが全画面になり、ページが画面いっぱいに表示されます。ページ独自の終了方法（Esc）で、ウィンドウが元に戻ります。

### スクリーンショットとPDF

**メニュー**（⋯）→ **スクリーンショットまたはPDF**には、いま開いているウェブページやタブに表示しているファイルをファイルとして残す項目が3つあります。

- **表示範囲のスクリーンショット**：タブに表示されているページ部分の画像です。
- **ページ全体のスクリーンショット**：スクロールする長さにかかわらず、ページを上から下まで撮った画像です（高さは最大16,384ピクセルまで。撮影できない場合は、表示範囲の画像になります）。
- **PDFとして保存…**：印刷したときのように、背景も含めてページをPDFにします。

スクリーンショットはPNG形式です。ダウンロードフォルダに、ページのタイトルに日付と時刻を付けた名前（「Example 2026-11-18 at 14.30.05.png」）で保存され、クリップボードにもコピーされるので、メッセージやドキュメントにそのまま貼り付けられます。「Screenshot saved to Downloads and copied」というお知らせが表示され、**フォルダで表示**を選べます。PDFはダウンロードフォルダにページのタイトルの名前で保存され、「Saved as PDF in Downloads」というお知らせと**フォルダで表示**が表示されます。同じ名前のファイルがある場合は名前の後ろに番号が付き、上書きされることはありません。プライベートタブでも使えます。

### 右クリックメニュー

ページ上で右クリックすると、クリックした場所に応じたメニューが開きます。見た目も言語もアプリのほかのメニューと同じです（**Esc**を押すか、外側をクリックすると閉じます）。

- テキストフィールド：つづりの間違った単語には修正候補と**辞書に追加**が表示されます。続けて、**元に戻す**、**やり直す**、**切り取り**、**コピー**、**貼り付け**、**すべて選択**が表示されます。
- リンク：**リンクを新しいタブで開く**、**リンクをプライベートタブで開く**（[プライベートタブ](/guide/web#private-tabs)を参照）、**リンクを既定のブラウザで開く**、**リンクのアドレスをコピー**、**リンクをあとで読む**（[あとで読む](/guide/web#read-later)を参照）。
- 画像：**画像を新しいタブで開く**、**画像を別名で保存…**（ダウンロードフォルダに保存）、「**画像を保存**」の保存先として「*保存先に使うプロジェクト*」（プロジェクトを選んでいない間は**画像を保存**のみ）、**この画像について質問**、**画像をコピー**、**画像のアドレスをコピー**。
- 動画：**再生**または**一時停止**、**ミュート**または**ミュート解除**、**ループ**と**コントロールを表示**（オンの間はチェックが付きます）、**ピクチャインピクチャ**（表示中はチェックが付きます）、**動画を新しいタブで開く**、**動画を別名で保存…**（ダウンロードフォルダに保存）、**動画のアドレスをコピー**。音声にも同様の項目があり、**音声を新しいタブで開く**、**音声を別名で保存…**、**音声のアドレスをコピー**が表示されます（ピクチャインピクチャはありません）。その動画や音声でできる操作の項目だけが表示されます。
- テキストを選択しているとき：**コピー**、選択した語句を検索エンジンで調べる**検索**（新しいタブで開きます）、**エージェントに質問**（原文は「Ask an agent about」）があります。これを選ぶと、ページの横に**質問**が開き、選択した語句（最大4,000文字）とページのアドレスが質問用に用意されます（[ページの横で質問](/guide/web#ask-beside-the-page)を参照）。さらに、選択した語句をお使いの言語に翻訳して小さなボックスに表示する**「…」を翻訳**（[ページを翻訳する](/guide/web#translate-a-page)を参照）と、ページ上の語句にマークを付けて残す**ハイライト**（[ハイライト](/guide/web#highlights)を参照）があります。
- 自分のハイライト上：**ハイライトを削除**。
- フィールドや選択したテキストから離れたページ上：**戻る**、**進む**、**再読み込み**、そして**ドイツ語に翻訳**（翻訳先の言語。ページが翻訳されている間は**原文を表示**）。
- いつでも表示：**このページをブックマーク**、**このページをあとで読む**（ウェブページの場合）、**印刷…**、ページのデベロッパーツールを開く**検証**。

プライベートタブのメニューには**リンクをプライベートタブで開く**がなく、**リンクを新しいタブで開く**などの「新しいタブで開く」項目はプライベートタブで開きます。また、エージェントにはプライベートタブが渡されないため、**質問**に関する項目（**エージェントに質問**、**この画像について質問**）も表示されません。

「*プロジェクト*」への**画像を保存**は、そのタブ自身のサインイン情報で画像を読み込むため、ログインが必要なページの画像も保存できます。画像は**保存**の横で選んだプロジェクトの**ファイル**（元のページが取得元として記録されます）に、またはプロジェクトなしで保存されます。「Saved to Thesis’s files」（または「Picture saved」）というお知らせと**開く**が表示されます（以前に保存済みの場合は「That picture is saved already」）。保存できるのは、50MBまでのPNG、JPEG、WebP、GIF、AVIFの画像です。ビットマップやアイコンはPNGに変換され、SVGなどそれ以外の形式は保存できません。画像のアドレスはhttp、https、data、blobのいずれかが必要です。エージェントはプロジェクトに保存された内容を読めるので、保存するのは問題ない画像だけにしてください。**この画像について質問**も同じ方法で画像を読み込み、ページの横に**質問**を開いて、ページのコピーとともに質問用に画像を用意します。

拡張機能が追加した項目は表示されません（[動作しない可能性があるもの](/guide/web#what-may-not-work)を参照）。

### プライベートタブ

プライベートタブは、閲覧の記録を残さないタブです。**Ctrl+Shift+N**（Macでは**⇧⌘N**）、**メニュー**（⋯）→**新しいプライベートタブ**、タブ列の**プライベート**セクションの末尾にある**新しいプライベートタブ**、または[/browser?private=1](/browser?private=1)から開きます（`&url=https://example.com`を付けると、そのアドレスを開きます）。リンクを右クリックして**リンクをプライベートタブで開く**を選ぶ方法もあります。プライベートタブ自体にはこの項目はなく、**リンクを新しいタブで開く**でプライベートタブが開きます（ほかの「新しいタブで開く」項目、選択した語句の**検索**、アドレスバーでの**Alt+Enter**も同様です）。

プライベートタブは次のように表示されます。

- タブ列の紫色の**プライベート**セクションに表示され、タブの数も分かります。ラベル末尾の×（**プライベートタブを閉じる**）で、すべて閉じられます。
- アドレスバーの先頭に、紫色の**プライベート**チップが表示されます。押すと、プライベートタブとは何か、何を保持するかが表示され、**プライベートタブを閉じる**も選べます。

プライベートタブが分けて保持するものと、忘れるものは次のとおりです。

- **サインイン情報、Cookie、サイトデータ、キャッシュされたファイル**はメモリ上に保持され、ほかのタブとは分けられます。通常のタブでサインインしているサイトは、プライベートタブではあなたを認識せず、その逆も同様です。これらは、最後のプライベートタブを閉じたとき、またはアプリを終了したときにすべて忘れられます。
- **ページは記録されません**。[履歴](/guide/web#history)にも**最近閉じたタブ**の一覧にも残らず（**Ctrl+Shift+T**でも復元されません）、次にブラウザを起動したときに開き直されるタブにも含まれません。閉じたタブは完全に失われます。
- **拡張機能は動作しません**。広告ブロックとCookieバナーの非表示は、通常のタブと同じように働きます。
- サイトが求める**権限**（カメラ、位置情報など）は毎回確認され、回答はタブを閉じると忘れられます。通常のタブでブロックしたサイトは、ブロックされたままです。
- **ダウンロード**はダウンロードフォルダに保存されますが、検索ボックス（Ctrl+K）で見つかるダウンロード一覧には追加されません。
- 自分で操作して残すものは保持されます。**ブックマーク**、**あとで読む**、**ハイライト**、（プロジェクトへの）**保存**です。これらはプライベートタブを閉じたあとも残り、ページの内容が分かるので、問題ない場合にだけ使ってください。
- **翻訳中**のページも通常のタブと同様に翻訳でき、ページの語句は補助モデルに送られます（[ページを翻訳する](/guide/web#translate-a-page)を参照）。守りたい内容がある場合は、プライベートページを翻訳しないでください。
- プライベートタブはグループに入れられません。**AIでタブをグループ化**は、プライベートタブを数えることも送ることもありません。
- **エージェントにプライベートタブは渡されません**。**質問**はグレー表示になり、アドレスバーの**このページについて質問**（または**このページで実行**）の行、右クリックメニューの**エージェントに質問**と**この画像について質問**も表示されず、サーバーはエージェントのためにそのページをコピーすることを拒否します（[ページをエージェントに渡す](/guide/web#hand-a-page-to-an-agent)を参照）。

プライベートタブが開いている状態で最後の通常タブを閉じると、プライベートタブだけが残ります。それ以外の場合、ブラウザには常に1つのタブが開いたままになります。プライベートタブが対象とするのは、このコンピューター上の記録です。訪問先のサイト、インターネットプロバイダー、ネットワークからは行き先が見える可能性があり、サインインしたサイトにはユーザーが誰かが分かります。

### ページを翻訳する

読み慣れた言語とは別の言語のページでは、アドレスバーの右側に翻訳ボタン（小さな**言語**アイコン）が表示されます。ページを翻訳している間は点灯し、翻訳の処理中は点滅します。押すと次のようになります。

- ページの言語が表示されます（「Detected: German」）。これは、ページの語句と言語タグから、このコンピューター上で判定されます。
- **翻訳先**は翻訳する言語です。最初はアプリの言語になっています。別の言語を選ぶとその選択が保持され（[ブラウザ設定](/guide/web#browser-settings)の**翻訳先**にも反映されます）、すでに翻訳されているページはその言語で翻訳し直されます。
- **翻訳**で開始します。処理中は、その下の行に「Translating… 12 of 40 parts」と表示され、ボタンは**原文を表示**に変わります。これを押すと、ページのすべての語句が元に戻ります。完了すると、どの言語から、どのモデルで翻訳したかが表示されます。翻訳できなかった場合は理由が表示され、ボタンは**もう一度試す**になります。
- **常にドイツ語を翻訳**（判定された言語）を選ぶと、以降その言語のページは読み込み時にすぐ翻訳されます。**ドイツ語は翻訳しない**を選ぶと、その言語ではボタンが表示されなくなります。**example.comは翻訳しない**（ページのサイト）は、言語に関係なく、そのサイトで同様に動作します。
- **翻訳設定**を選ぶと、[ブラウザ設定](/guide/web#browser-settings)の**翻訳**が開きます。

最初に画面に表示されている部分が翻訳され、次にページの残りが、その後はスクロールやページ自体の変化によって新しく現れた部分が翻訳されるので、ずっとお使いの言語で読めます。ページのレイアウト、リンク、画像はそのままで、語句だけがその場で置き換わります。テキストフィールド、コード、サイトが翻訳対象外と指定した部分はそのままです。とても長いページは、画面に表示されている部分から約150,000文字先まで翻訳されます。

**メニュー**（⋯）→**ページを翻訳…**（翻訳中は**原文を表示**）も使えます。すでにお使いの言語のページなど、ボタンが表示されない場合は、メニューの下に同じボックスが開きます。リンク、画像、選択した語句から離れたページ上で右クリックし、**ドイツ語に翻訳**（翻訳先の言語）を選ぶこともできます。翻訳中は**原文を表示**を選びます。語句を選択して右クリックし、**「…」を翻訳**を選ぶと、その部分だけを翻訳できます（最大5,000文字）。**翻訳**ボックスに原文と訳文、別の言語を試すための**翻訳先**の選択、**コピー**が表示されます。

ボタンや一覧に表示される言語名は、アプリの言語で表示され、その横に各言語自身の名前も表示されます。

**送信される内容と使われるモデル。** 翻訳では、ページの語句が分割されて、アプリの補助モデルに送られます。これはセッションのタイトルやメモリのメモを書くモデルです（[設定→エージェント→モデル→補助モデル](/settings?s=models&find=Helper%20model)）。翻訳のために選択した語句も同じ補助モデルに送られます。**自動**の場合は、Claude Code経由のClaude Haiku、それができなければCodexで、どちらもオンラインです。このコンピューター上の独自モデルを使うと、語句はこのコンピューターの外に出ません。画像とサインイン情報は送られません。送信は、**翻訳**やメニュー項目を押したときに行われ、**常に翻訳**を設定した言語では、各ページの読み込み時に自動で行われます。非公開にしたい語句を含むページは翻訳しないでください（または、このコンピューター上のモデルを補助モデルにしてください）。エージェントにはその内容は一切見えず、翻訳用のルートへのアクセスも拒否されます。

翻訳したページは、[リーダービュー](/guide/web#reader-view)でも翻訳されたまま表示されます。

### リーダービュー

ニュース記事、ブログ記事、レシピなど、記事のあるページでは、アドレスバーの右側に本のボタン（**リーダービュー**）が表示されます。押すと、ページの上に記事だけがすっきりした1列で表示されます。サイト名、タイトル、著者、読むのにかかる時間（「5 min read」）、日付に続いて、画像を含む本文が表示され、サイトのメニュー、広告、コメントは表示されません。もう一度ボタン（**リーダービューを終了**）を押すとページに戻ります。**メニュー**（⋯）→**リーダービュー**でも切り替えられ、オンの間はチェックが付きます。リーダービュー内でリンクを開くと、ほかのページに移動したときと同じようにリーダービューを終了します。表示できる記事がないページにはボタンがありません（メニュー項目もグレー表示になります。実際には記事がなかった場合は、「This page has no article to show in reader view」というお知らせが表示されます）。

リーダービューがオンの間は、**Aa**（**リーダービューのスタイル**）で記事の見た目を設定できます。

- **文字サイズ**：**文字を小さく**と**文字を大きく**で調整します。14から28までで、最初は19です。
- **カラー**：**自動**（アプリのライトまたはダークの外観に合わせます）、**ダーク**、**ライト**、**セピア**。
- **フォント**：**明朝体**または**ゴシック体**。

変更はすぐに反映され、すべての記事で保持されます。矢印キー、**Page Down**、**Space**で記事をスクロールできます。リーダービューの作成中、タブの外には何も送られません。ページはその場で読み取られ、エージェントやモデルは使われません。

### ダークページ

**メニュー**（⋯）→**ダークページ**（オンの間はチェックが付きます）、または[ブラウザ設定](/guide/web#browser-settings)の**ダークページ**で、ウェブページをダークで表示します。独自のダークの外観があるサイトはそれを使い、コンピューターがダークに設定されているときと同じ表示になります。ない場合は、ブラウザ自体の自動ダークモードで暗くされ、明るい背景は暗く、文字は明るくなります。最初はオフで、すべてのタブに一度に適用され、エージェントのブラウザには影響しません。

ページによっては、暗くすると不自然に見えることがあります（画像、グラフ、意味のある色など）。特定のサイトだけそのまま表示するには、鍵のアイコンをクリックして**このサイトのダークページ**をオフにします（このスイッチは、ダークページがオンの間だけ表示されます）。そうしたサイトは、ブラウザ設定の**そのまま表示するサイト**に一覧表示され、横の×を押すと、そのサイトがまたダークで表示されます。

### あとで読む

時間があるときのためにページを取っておけます。**メニュー**（⋯）→**あとで読む**を開き、パネルの上部にある**このページを追加**を押すか、ページを右クリックして**このページをあとで読む**を選ぶか、リンクを右クリックして**リンクをあとで読む**を選びます。「あとで読むに追加しました」というメッセージが表示されます。すでにリストにあるページは、先頭に戻って読まれるのを待つ状態になります。今開いているページがリストで待っている間は、パネルのボタンに**リストに追加済み**と表示されます。取っておけるのはWebページ（httpとhttps）だけです。

リストは2か所に表示されます。1つはタブ列の**あとで読む**です（[タブ列](/guide/web#the-tab-column)を参照）。もう1つはページの横の列にある専用のパネルで、**メニュー**（⋯）→**あとで読む**（メニューには待っているページの数が表示されます）、または[あとで読む](/browser?panel=later)から開けます。パネルのタイトルの下には**「あとで読む」リストを検索**というボックスがあり、タイトルまたはアドレスに入力した語句を含むページだけに絞り込めます。新しいものから順に並び、各行にはサイトのアイコン、ページのタイトル、その下にサイト名と追加した日時（「今日追加」）または既読にした日時が表示されます。行をクリックするか**開く**を押すと、ページが新しいタブで開きます。**既読にする**を押すとリストから外れます。**既読を表示**（既読のページができると表示されます）を押すと既読のページが再び表示され、**未読にする**で読まれるのを待つ状態に戻せます。**既読を隠す**を押すと、既読のページはまた隠れます。**外す**を押すと、リストから取り除かれます。何も取っておいていないときは、パネルに「あとで読むために取っておいたものはありません」と表示されます。

ブックマークと同じく、このリストは自分専用です。エージェントには見えず、リストを提供する経路もエージェントには拒否されます。

### 履歴

**Ctrl+H**を押すか、**メニュー**（⋯）→**履歴**、または[履歴](/browser?panel=history)を開きます。パネルには、自分のブラウザで訪れたページが新しいものから順に、日ごと（「今日」「昨日」、それ以前は日付）に並びます。各行には時刻、サイトのアイコン、タイトル、アドレスが表示されます。

- 検索ボックス**履歴を検索**では、タイトルとアドレスに含まれる語句でページを探せます。
- ページをクリックすると今のタブで開きます。Ctrl+クリック（Macでは⌘+クリック）なら新しいタブで開きます。各ページの横の**×**を押すと、そのページが履歴から外れます。**古いものを表示**を押すと、さらに読み込まれます。
- **最近閉じたタブ**（検索していないときに表示）には、最近閉じたタブが並びます。クリックすると再び開きます。**Ctrl+Shift+T**で最も新しいタブが開きます。
- **閲覧データを消去…**を押すと、設定のその項目が開きます。

履歴はこのコンピューター内のアプリ専用データベースに保存され、自分の閲覧だけが記録されます。記録されるのは、Webページとファイル、各タブが最終的に表示したページ、落ち着いたときのタイトルです。[プライベートタブ](/guide/web#private-tabs)のページは記録されず、閉じたプライベートタブは**最近閉じたタブ**にも表示されません。保存されるのは直近の20,000ページで、古いものから順に消えます。エージェントには見えません。アドレスバーの[候補](/guide/web#suggestions)は、この履歴をもとに表示されます。

ほかのブラウザの履歴を取り込むには、パネルの下部にある**インポート**を使います（検索していないときに表示されます）。ブックマークのパネルと同じ操作です。履歴のあるこのコンピューター上のブラウザが一覧に表示されます。[ブックマーク](/guide/web#bring-in-bookmarks)のときと同じブラウザで、プロファイルが複数あるブラウザはプロファイルごとに1行になり、取り込めるページ数（「8,931ページ」）も表示されます。**インポート**を押すと、最新の20,000ページが取り込まれます。各ページのタイトル、最後に訪れた日時、訪問回数、アドレスを直接入力した回数が保持されるため、アドレスバーの[候補](/guide/web#suggestions)は元のブラウザと同じ基準で並びます。すでにあるページは、新しいほうの訪問日時と大きいほうの回数が残るので、もう一度インポートしても二重には追加されません。履歴に保存されるのは引き続き直近の20,000ページで、古いものから順に消えます。すべてこのコンピューター内に保存され、エージェントには見えません。完了すると「8,931ページを取り込みました」（すでにすべてある場合は「履歴にはすでにすべて含まれています」）と表示されます。取り込める元がないときは、パネルに「履歴のある他のブラウザはこのコンピューターに見つかりませんでした。」と表示されます。

履歴を開いている間はロックするブラウザでは、「Google Chromeを閉じてからもう一度お試しください。開いている間は履歴をロックします」と表示されます。閉じてから**インポート**をもう一度押してください。Firefoxは開いたままで大丈夫です。Safariは、ブックマークと同様に、macOSが保護する場所に履歴を保存しています。許可するまでは、その行に「HydorはSafariの履歴を読み取れません。システム設定→プライバシーとセキュリティ→フルディスクアクセスで許可してください」と表示されます。その行には**インポート**の代わりに**システム設定を開く**が表示されます。押すとシステム設定→プライバシーとセキュリティ→フルディスクアクセスが開くので、Hydorをオンにします（一覧にない場合は**+**で追加します）。Hydorに戻ると再確認され、Safariのページ数と**インポート**が表示されます。それでもSafariを読み取れない場合は、「許可しましたか？ macOSがHydorの再起動を求めることがあります。Hydorを終了してもう一度開いてください。」と行に追記されます。

ブラウザでダウンロードしたファイルも一覧に保存されます。各ファイルの名前、保存先、ダウンロード元のアドレスが記録され、保存されるのは直近の5,000件です。**閲覧データを消去**で**閲覧履歴**にチェックを入れると、この一覧も同じ期間分が消去されます（ファイルは保存先に残ります）。消えたページ、ブックマーク、ダウンロードは、意味で検索の対象からも外れます。検索ボックス（Ctrl+K）では、履歴、ブックマーク、ダウンロードを、語句と内容の両方から探せます。**検索範囲**の**ブラウザ**で指定します（[Ctrl+Kですべてを検索](/guide/start#search-everything-with-ctrlk)を参照）。これらはいずれも、エージェントには見えません。

### ハイライト

ページ上の語句にマークを付けると、そのまま残ります。語句を選択して右クリックし、**ハイライト**を選ぶと、すぐに淡い黄色でマークされ、保存されます。ダークなページでも見やすい色です。そのページを開くたびに語句が見つかってマークされ、読み込み後にコンテンツを組み立てるページでは、少し遅れてもう一度マークされます。ハイライトの中を右クリックして**ハイライトを削除**を選ぶと、マークが外れます。ページ自体の文字は変更されず、囲まれるだけなので、ページからテキストをコピーしても同じ語句になります。

- アドレスのあとに何が続いても、同じページとして扱われます。`#fragment`や追跡用パラメーター（`utm_…`、`fbclid`など）は無視され、`http`、`https`、`www.`は同じものとみなされます。各ハイライトには、語句、その前後の少しのテキスト（同じ語句が複数あるときに正しい位置を見つけるためのもの）、ページのタイトル、作成した日時、そしてメモを追加した場合はそのメモが保存されます。
- ハイライトのあるページでは、**メニュー**（⋯）に小さな黄色いマークが付き、**メニュー**（⋯）→**ハイライト**に件数が表示されます。これを開くと、ページの横の列にそのページのハイライトが表示されます。[ハイライト](/browser?panel=highlights)からも開けます。**ページ上に表示**を押すとその位置までスクロールし、**コピー**で語句をコピーできます。**メモを追加**（または**メモを編集**）では、ページ上でハイライトにポインターを合わせたときに表示されるメモを書けます。**削除**を押すと、ハイライトが削除されます。**これらについてエージェントに質問**を押すと、ページのアドレスとハイライト（メモ付き）が引用された状態でセッションが始まります。
- ページが変わるなどして見つからなくなった語句は、リストには残りますが、マークは付きません。1つのハイライトは5,000文字まで、1ページあたり500件までです。テキストフィールド内の語句や、ページの非表示部分の語句はマークされません。ページ内のフレーム（その中に表示された別のページ）にある語句もマークされず、そこではメニューに**ハイライト**が表示されません。ページ独自のコンポーネント内の語句は、ほかの語句と同じようにマークされます。

ハイライトはこのコンピューター内のアプリ専用データベースに保存され、エージェントには見えません。ハイライトに関する経路も、エージェントには拒否されます。エージェントに渡るのは**これらについてエージェントに質問**を押したときだけで、そのときもそのページのアドレスとハイライトだけが渡されます。

### ブラウザ設定

**メニュー**（⋯）→**設定**、[設定→ブラウザ→自分の閲覧→ブラウザ設定](/settings?s=browser&find=Browser%20settings)、または[ブラウザ設定](/browser?panel=settings)を開くと、次の項目のあるパネルが表示されます。

- **ホームページ**：ホームボタンと新しいタブで開くWebアドレスです（初期設定はhttps://www.google.com/）。**現在のページを使う**を押すと、今開いているページが設定されます。
- **検索エンジン**：アドレスバーでの検索に使うエンジンです。Google（初期設定）、DuckDuckGo、Bing、Brave、Ecosia、Startpageから選べます。**Custom**では、入力した語句が入る部分に%sを入れた独自のアドレスを指定できます（例：`https://example.com/search?q=%s`）。
- **検索ショートカット**：アドレスバーにショートカット、スペース、語句の順に入力すると、そのサイトを検索できます。標準のショートカットは`yt`（YouTube）、`wiki`（Wikipedia）、`gh`（GitHub）、`scholar`（Google Scholar）、`arxiv`（arXiv）、`hf`（Hugging Face）です。各ショートカットの×で削除できます。**ショートカットを追加**では、**ショートカット**（1語）、**名前**、**アドレス（入力した語句が入る部分に%s）**を入力して**追加**を押します（**キャンセル**もできます）。登録できるのは50件までです。**標準のものに戻す**は、リストを変更すると表示されます。アドレスバーで`yt lofi`と入力すると、先頭に「YouTubeで「lofi」を検索」が表示され、**Enter**で実行されます。入力した内容の行（「Googleで検索」）は、これまでどおり、すべての語句を検索エンジンで検索します。
- **検索候補**（初期設定はオン）：アドレスバーに入力した内容は、ほかのブラウザと同じように、入力中に検索エンジンへ送られ、検索候補が表示されます。Startpageとカスタムのアドレスでは候補は表示されません。オフにすると、入力内容はこのコンピューターの外に出ません。開いているタブ、ブックマーク、履歴は引き続き表示されます。
- **広告とトラッカーをブロック**（初期設定はオン）：詳しくは下記を参照してください。
- **Cookieバナーを非表示**（初期設定はオン。**広告とトラッカーをブロック**がオンのときのみ有効で、オフの間はグレーアウトされます）：詳しくは下記を参照してください。
- **翻訳**：[ページの翻訳](/guide/web#translate-a-page)に関する設定です。
  - **翻訳先**：ページの翻訳先の言語です。選ぶまではアプリの言語になります。
  - **他の言語のページで翻訳を提案**（初期設定はオン）：他の言語のページで、アドレスバーに翻訳ボタンを表示します。オフにすると、すでに翻訳されたページにだけボタンが表示されます。**メニュー**（⋯）→**ページを翻訳…**は引き続き使えます。
  - **常に翻訳**：読み込まれると同時にページが翻訳される言語です。**言語を追加**で選びます。言語の×で外せます。
  - **翻訳しない**：翻訳ボタンを表示しない言語です。1つの言語が入るのは、この2つのリストのどちらか一方だけです。
  - **これらのサイトを翻訳しない**：翻訳ボタンを表示せず、自動でも翻訳しないサイトです（翻訳ボックスの**翻訳しない**で追加するまでは「サイトなし」）。サイトの×で外せます。
  - 翻訳で何がどのモデルに送られるかが、メッセージで表示されます。
- **ページ**：
  - **ページのズーム**（初期設定は100%、50%～200%）：ページの大きさです。サイトを個別にズームした場合は除きます。個別にズームしたサイトは、アプリの実行中はそのズームが保たれます（Ctrlと+または−、Ctrlとホイール、メニューの**ズーム**）。**リセット**（Ctrl+0、メニューのパーセント表示、アドレスバーのチップ）を押すと、ページのズームに戻ります（[ズーム、印刷、全画面表示](/guide/web#zoom-print-and-full-screen)を参照）。
  - **スペルチェック**（初期設定はオン）：入力中のスペルミスの単語に下線を引き、右クリックメニューに修正候補を表示します。
  - **ダークページ**（初期設定はオフ）：独自のダーク表示がないページをダークの配色で表示します（[ダークページ](/guide/web#dark-pages)を参照）。
  - **そのまま表示するサイト**：**このサイトのダークページ**をオフにしたサイトです。×を押すと、そのサイトを再びダークで表示します。
  - **サイトが自動で音を再生することを許可**（初期設定はオフ）：オフの間は、クリックまたは入力するまでページの音が待機します。音のない動画は再生されます。オンにすると、従来のブラウザと同じように、ページがすぐに音を鳴らせます。変更後に開いたタブに適用されます。
- **閲覧データを消去**：**閲覧履歴**、**Cookieとサイトデータ**（サイトからサインアウトされます）、**キャッシュされたファイル**にチェックを入れ、期間（**過去1時間**、**過去24時間**、**過去7日間**、**全期間**）を選んで**データを消去**を押します。期間の指定は履歴（および一緒に保存されているダウンロードの一覧）にのみ適用されます。Cookie、サイトデータ、キャッシュされたファイルは、常に全期間分が消去されます。

### 広告とトラッカーをブロック

自分のブラウザでは、広告ブロッカーと同じように広告とトラッカーをブロックします。既知の広告サーバーやトラッキングサーバーへのリクエストが送られないようにし、空いた場所を非表示にします。Ghosteryの広告・トラッカーのリスト（EasyList、EasyPrivacyなど）を使います。このリストは、ブラウザの初回起動時にGitHubからダウンロードされ、毎週更新されます（更新できないときは、手元のリストをそのまま使います）。その際、ユーザーに関する情報は送信されません。エージェントのブラウザではブロックされません。プライベートタブでは動作します。[ブラウザ設定](/guide/web#browser-settings)の**広告とトラッカーをブロック**でオフにできます。

オンの間も、Chrome拡張機能はページのリクエストを見られます。ただし、リクエストをブロックまたは変更する拡張機能（自分で入れた広告ブロッカーなど）は、リクエストをブロックできません。ページをその拡張機能に任せたいときは、ブロックをオフにしてください。

特定のサイトで広告を表示するには、アドレスバーの鍵アイコンをクリックして**このサイトで広告を許可**を押します（サブドメインも対象です）。ページが再読み込みされます。**このサイトで広告をブロック**を押すと、元に戻ります。

**Cookieバナーを非表示**（初期設定はオン。ブラウザ設定にあり、ブロッカーがオンのときのみ有効）は、多くのサイトが表示するCookieの通知も非表示にします。上記のリストに、EasyListのCookie通知リストが追加されます。通知を非表示にするだけで、代わりに回答するわけではないため、回答を待つサイトでは、一部のコンテンツが表示されないことがあります。その場合は、そのサイトの鍵アイコンから広告を許可すると、通知が再び表示されます。

### 鍵アイコン

アドレスバーの先頭にある鍵アイコンは、サイトとの接続が安全かどうかを示します（httpのページでは、開いた鍵アイコンとともに「保護されていません」と表示されます）。クリックすると、サイトの情報、接続が安全かどうか、サイトに対して許可またはブロックした内容（それぞれに**削除**があり、押すと次回から再び確認されます）が表示されます。ブロッカーがオンのときは、このページでブロックした広告とトラッカーの数と、**このサイトで広告を許可**または**このサイトで広告をブロック**も表示されます。Webページでは、次の項目も表示されます。

- **このサイトのダークページ**：[ダークページ](/guide/web#dark-pages)がオンのときに表示されるスイッチです。オフにすると、このサイトがそのまま表示されます。
- **Cookieとサイトデータ**と**削除**：押すとまず確認が表示されます（「example.com のCookieとサイトデータを削除しますか？ サインアウトされます。」）。**削除**を押すと、そのサイトのCookieと保存されたサイトデータが、サブドメインも含めて削除されます（`mail.example.com`の場合は、example.comのものが対象）。対象は、このタブ専用のサインイン情報です（プライベートタブのものはそのタブ専用です）。その後、ページが再読み込みされます。何が削除されたかはメッセージで表示されます。キャッシュされたファイルは残ります。キャッシュされたファイルと、すべてのサイトのすべてのデータは、ブラウザ設定の**閲覧データを消去**で消去できます。

### ダウンロード

ページがダウンロードしたファイルは、アプリが動作しているコンピューターのダウンロードフォルダに保存され、**メニュー**（⋯）→ **ダウンロード**に「ダウンロード中…」「完了」「失敗」のいずれかの状態とパスが一覧表示されます。プライベートタブからのダウンロードも同じように保存され、ここに表示されますが、検索ボックス（Ctrl+K）で見つかる一覧には追加されません。完了したものをクリックすると、そのフォルダで確認できます。デスクトップアプリでは、システムのファイルマネージャーが開き、ファイルが選択された状態になります（**Finderで表示**、**エクスプローラーで表示**、または**フォルダで表示**。[ファイルとフォルダを操作する](/guide/files-git#work-with-files-and-folders)を参照）。

### サイトが権限を求めてきたとき

自分のブラウザでページがカメラ、マイク、位置情報、通知、クリップボードなどの使用を求めると、ページの上にバーが表示され（「example.com がカメラの使用を求めています」）、**許可しない**と**許可**を選べます。回答はそのサイトについて記憶されるため、確認されるのは一度だけです。許可またはブロックした内容を確認したい場合や、もう一度確認されるようにしたい場合は、鍵のアイコン、または**メニュー**（⋯）→ **サイトの権限**を開き、該当する回答の横にある**削除**を押します。エージェントのブラウザでは、画面全体表示とクリップボードへのコピーを除き、こうしたリクエストはすべて自動的に拒否されます。プライベートタブでは、バーが毎回表示されます。回答はタブを閉じると忘れられ、通常のタブで行った許可は引き継がれません（ブロックしたサイトはブロックされたままです）。ページのポップアップの質問（アラート、はい・いいえの確認、テキスト入力）は、エージェントのブラウザと同様にページの上に表示されます（[ページのポップアップの質問に答える](/guide/web#answer-a-pages-pop-up-questions)を参照）。

## ブックマーク

ブックマークバーにブックマークが1つでもあると、そのサイトがタブ列の上部にピン留めされます（スマートフォンにはタブ列がなく、ブックマークはメニューにあります）。クリックすると開いているタブで開き、Ctrl+クリック（Macでは⌘+クリック）または中クリックすると新しいタブで開きます。フォルダをクリックすると中身の一覧が開き、表示されるタイルは最大10個です（残りは**…**タイルに一覧表示されます）。タイルを右クリックすると、**開く**、**新しいタブで開く**、**編集**（フォルダは**名前を変更**）、**削除**が選べます。

すべてのブックマークを見るには、**メニュー**（⋯）→ **ブックマーク**を押すか、[ブックマーク](/browser?panel=bookmarks)を開きます。パネルには**ブックマークバー**と**その他のブックマーク**の2つの場所があり、その中のフォルダは開閉できます。

- **ブックマークを検索**（上部のボックス）では、言葉でブックマークを探せます（[ブックマークを検索](/guide/web#search-your-bookmarks)を参照）。
- **新しいフォルダ**（上部）は、バーにフォルダを追加し、名前を入力する画面を表示します。
- **AIで整理**（上部の**新しいフォルダ**の横にあるキラキラのボタン）は、ブックマークをトピックごとにフォルダへ整理します（[AIで整理](/guide/web#organize-with-ai)を参照）。
- 行にポインタを合わせると、**上へ移動**、**下へ移動**、**編集**（フォルダは**名前を変更**）、**削除**が表示されます。行をドラッグすることもできます。フォルダの中央にドロップするとその中に入り、行と行の間にドロップするとその位置に置かれます。フォルダを自分自身の中に入れることはできません。フォルダを削除するときは先に確認が表示され、中身も一緒に削除されます。
- ブックマークのアドレスは http://、https://、file://、chrome-extension:// のいずれかで始まります。最大20,000件まで保存できます。

### ブックマークを検索

パネルの上部にある**ブックマークを検索**ボックスは、入力したすべての言葉を含むブックマークを、名前とアドレスから探します（大文字小文字やアクセントは区別されません）。フォルダは名前から探します。ボックスに言葉が入っている間、パネルにはフォルダの代わりに**フォルダ**（最大20件）と**ブックマーク**（最大200件）が表示されます。各ブックマークには、サイトと場所（「ブックマークバー › Imported from Chrome › Research」など）が表示されます。

- フォルダをクリックすると、フォルダの一覧の中でそのフォルダが表示されます。検索が解除され、フォルダが開きます。
- ブックマークをクリックすると開きます。Ctrl+クリック（Macでは⌘+クリック）すると新しいタブで開きます。
- ブックマークにポインタを合わせると、**フォルダで表示**、**編集**、**削除**が表示されます。
- **Enter**で最初に見つかったブックマークが開き、**Esc**で検索が解除されます。

### AIで整理

ブックマークが多いときは、パネル上部の**新しいフォルダ**の横にあるキラキラのボタン**AIで整理**で、トピックごとにフォルダへ整理できます。検索ボックス（Ctrl+K）で「AIでブックマークを整理」と検索するか、[AIで整理](/browser?panel=bookmarks&organize=1)を開く方法もあります。**AIでブックマークを整理**が開くので、整理の方法を選びます。

- **自分のフォルダを残す**（最初に選ばれています）：自分のフォルダとその中のブックマークは、そのまま残ります。フォルダに入っていないブックマークは、合うフォルダ（自分のフォルダまたは新しいフォルダ）に入ります。フォルダに入っていないとは、**その他のブックマーク**の直下にある場合、またはブックマークを集めるだけのフォルダにある場合です。たとえば、インポートで作られた「Imported from Chrome」と、その中の「Other bookmarks」や「Mobile bookmarks」のフォルダです（補助モデルが、これらと自分のフォルダを言語を問わず見分けます）。整理の結果、空になった集約用フォルダは削除されます（最初から空だったものは残ります）。それ以外のフォルダが削除、名前変更、移動されることはありません。新しいフォルダは、**その他のブックマーク**の末尾か、自分のフォルダの中に作られます。
- **最初からやり直す**：すべてのブックマークがトピックごとの新しいフォルダに入り、**その他のブックマーク**に置かれ、元のフォルダは削除されます。新しいフォルダは**その他のブックマーク**の先頭に名前順で並び、サブフォルダは1階層までです。モデルが振り分けられなかったブックマークが残ったフォルダは、そのまま残ります。

どちらの場合も、ブックマークバーにピン留めされたサイト（バー自体のリンク）はそのままです。

**送信される内容と送信先のモデル。** **整理**を押したときだけ、ブックマークのタイトルとアドレス（**?**や**#**以降は除きます）、およびフォルダの名前が、アプリの補助モデルに送信されます。これはセッションのタイトルやメモリのメモを書くモデルです（[設定 → エージェント → モデル → 補助モデル](/settings?s=models&find=Helper%20model)）。自動の場合は、Claude Code経由のClaude Haikuです。このコンピューター上の自分のモデルを使うと、データはこのコンピューターの外に出ません。それ以外のときは何も送信されません。ブックマークのタイトルが非公開の内容である場合は、押さないでください（または、このコンピューター上のモデルを補助モデルに設定してください）。

処理は2段階で進みます。まずフォルダを決め、次にブックマークを150件ずつ振り分けます。数百件のブックマークなら1～2分ほどかかります。処理中は、パネルの上部に「フォルダを検討しています…」、続いてバーとともに「ブックマークを振り分けています… 412件中150件」と表示され、**停止**も表示されます。**停止**を押しても何も変更されません。完了すると、「412件のブックマークを14個の新しいフォルダに振り分けました。空のフォルダを3個削除しました。」のように結果が表示され、新しいフォルダが見分けやすいよう、フォルダはすべて閉じた状態で表示されます。**元に戻す**を押すと、その後ブックマークを変更していない限り、すべてのブックマークが元の状態に戻ります。Xを押すとメモが閉じます。失敗した場合は何も変更されず、**もう一度試す**を押すと再び開きます。

エージェントがブックマークを整理することはできません。自分の閲覧は自分だけのものだからです。エージェントに頼むと、ボタンの場所を教えてくれます。

### ブックマークを取り込む

パネルの**インポート**の下に、このコンピューター上でブックマークのあるブラウザが、それぞれの件数とともに一覧表示されます。対象は、Chrome（およびChrome Beta）、Chromium、Edge、Brave、Vivaldi、Opera、Firefox、そしてMacのみArcとSafariです。複数のプロファイルがあるブラウザは、プロファイル名ごとに1行ずつ表示されます。いずれかの**インポート**を押すと、そのブラウザのブックマークが、ブックマークバーの末尾に作られる新しいフォルダ「Imported from Chrome」（複数のプロファイルがある場合は「Imported from Chrome (Work)」）に入ります。ブラウザ自体のフォルダ構成は保たれます。最初にブックマークバーにあったもの、続いてその他のブックマーク、モバイルのブックマーク、Firefoxのメニューが、そのブラウザでの呼び名のフォルダとして入ります。javascript: など、Webページではないリンクと、空のフォルダは取り込まれません。Firefoxは開いたままで構いません。デスクトップアプリでは、Hydorがこのコンピューター上に他のブラウザを見つけた場合、ウェルカムツアーでも、専用のページ**ブックマークと履歴を取り込みますか？**で案内されます（[ツアーを見る](/guide/app#take-the-tour)を参照）。

ブラウザのページを初めて開いたとき、Hydorがこのコンピューター上に他のブラウザを見つけ、まだインポートが案内されていない場合（ツアーのページも案内に含まれます）、ページの上にバーが表示され、見つかったブラウザの名前とともに「Google ChromeとFirefoxからブックマークと履歴を取り込みますか？」と尋ねられます。**いいえ**を押すと閉じ、**読み込む…**を押すと**ブックマークと履歴をインポート**パネルが開きます（[ブックマークと履歴をインポート](/browser?panel=import)）。このバーが表示されるのはその1回だけですが、パネルはそのアドレスでいつでも開けますし、検索ボックス（Ctrl+K）でも見つかります。**ブックマーク**と**履歴**のパネルの下部にも**インポート**があります。パネルには、「ブックマークは、ブックマークバーの末尾に作られる新しいフォルダに入り、履歴は今ある履歴に追加されます。すべてこのコンピューター上に保存されます。」という説明があり、その下に**ブックマーク**と**履歴**のスイッチ（どちらもオン）と、ブラウザ（およびプロファイル）ごとの行があります。各行には、ブックマークと履歴のページの件数と**インポート**が表示され、**インポート**を押すと、オンになっているものがツアーのページと同様に取り込まれます。取り込まれたものの横には、どちらの場所でも**取り込み済み**と表示されます。何も見つからない場合は、「このコンピューター上に他のブラウザは見つかりませんでした。」と表示されます。

Safariは、macOSが保護している場所にブックマークを保存しています。許可するまで、その行には「HydorはSafariのブックマークを読み取れない可能性があります。システム設定 → プライバシーとセキュリティ → フルディスクアクセスで許可してください」と表示されます。その行には**インポート**の代わりに**システム設定を開く**が表示され、押すとシステム設定 → プライバシーとセキュリティ → フルディスクアクセスが開くので、そこでHydorをオンにします（一覧にない場合は**+**で追加します）。Hydorに戻ると再確認が行われ、Safariの件数と**インポート**が表示されます。それでもSafariを読み取れない場合、その行に「許可しましたか？ macOSがHydorの再起動を必要としている場合があります。Hydorを終了して、もう一度開いてください。」と追加されます。

ファイルから取り込むには、**ファイルから**を押し、任意のブラウザからエクスポートしたブックマークファイル（.htmlファイル、20 MBまで）を選びます。「Imported bookmarks」というフォルダに入ります。

### ブックマークを書き出す

**インポート**の下にある**エクスポート**を押すと、すべてのブックマークが `bookmarks.html` として保存されます。このファイルは、Chrome、Firefox、Safariでインポートできます。

## Chromeの拡張機能

専用のブラウザでは、パスワードマネージャー、ダークモード、翻訳などのChrome拡張機能を使えます。**メニュー**（⋯）→ **拡張機能**を押すか、[拡張機能](/browser?panel=extensions)を開きます。拡張機能が動くのはデスクトップアプリ専用のブラウザです。それ以外では、パネルが拡張機能を保管し、その旨を表示します（「拡張機能はデスクトップアプリ専用のブラウザで動作します。ここに保管され、そこで実行されます。」）。拡張機能はサインインした状態で動作し、必要とするサイトの内容を読み取れます。信頼できるものだけを追加してください。

### 拡張機能を追加する

- **Chromeウェブストアから**：拡張機能のリンク（chromewebstore.google.comまたはchrome.google.com/webstoreのアドレス）かID（aからpまでの32文字）を**Chromeウェブストアから**の下に貼り付けて、**追加**を押します。または、専用のブラウザで拡張機能のページを開き、上部のバーで**Hydorに追加**を押します。アプリがChromeウェブストアからダウンロードし（Googleへのリクエストになります）、ウェブストアのIDを保持します。
- **フォルダから**：manifest.jsonを含む展開済みの拡張機能は、**フォルダを選択**を押す（デスクトップアプリ）か、フォルダのパスを入力します（それ以外：アプリが動いているコンピューター上のフォルダ）。コピーはされず、その場所のまま使うので、開発者による変更が反映されます。
- **他のブラウザから**：このコンピューターのChrome、Edge、Braveなど、Chromiumベースのブラウザにインストールされている拡張機能がチェックボックス付きで一覧表示されます。読み込みたいものにチェックを入れて**読み込む**を押します。すでにここにあるものには「追加済み」、元のブラウザでオフになっているものには「そちらでオフ」と表示されます。

拡張機能は自動では更新されません。最新バージョンにするには、Chromeウェブストアからもう一度追加してください。古いバージョンは置き換えられます。

### オフにする、取り除く

パネルの各拡張機能には、アイコン、名前、バージョンと、オン・オフを切り替えるスイッチが表示されます。**外す**を押すと削除されます（フォルダ内のファイルは残ります）。**オプション**を押すと、オプションページがタブで開きます。

拡張機能にツールバーのボタンがある場合、オンでピン留めされている間はアドレスバーの右に表示されます。クリックするとボタンの下にポップアップが開き、ボタン上のバッジ（数字や数文字）で拡張機能からの通知がわかります。ピン留めしていない拡張機能には専用のボタンがなく、ほかのボタンの後ろにある**拡張機能**ボタン（パズルのピース）にまとめられます。このボタンは、オンの拡張機能が1つ以上ある間だけ表示されます。

- **メニューから拡張機能を使う**：**拡張機能**を押し、拡張機能の名前をクリックします。ボタンをクリックしたときと同じように使えます。ツールバーに専用ボタンがない拡張機能も一覧に載り、オプションページがあれば、名前をクリックするとそのページが開きます。
- **ピン留めする、外す**：メニュー内の拡張機能の横にあるピン（**ツールバーにピン留め**、ピン留め中は**ツールバーのピン留めを外す**）で、ツールバーのボタンの表示と非表示を切り替えます。ピン留め中はピンが点灯します。変わるのはツールバーだけで、拡張機能はどちらの場合も動き続けます。
- **拡張機能のその他の操作**：横の**⋮**には、**オプション**（オプションページがある場合）、**オフにする**、**外す**があります。**外す**は確認が表示されます。
- メニューの下部にある**拡張機能を管理**を押すと、パネルが開きます。
- ツールバーのボタンを**右クリック**すると、名前が付いた小さなメニューが表示され、**オプション**（オプションページがある場合）、**ピン留めを外す**、**外す**、**拡張機能を管理**を選べます。
- **ツールバーにピン留め**は、オンでボタンのある各拡張機能の下にあるパネル内のスイッチでもあります。

新しい拡張機能は、最初はピン留めされています。Chromeから読み込んだ拡張機能は、Chromeでのピン留めの状態を引き継ぎます。Chromeでピン留めしていたものはここでもピン留めされ、それ以外は**拡張機能**メニューに入ります。このブラウザで動いていない拡張機能をクリックすると、その旨が表示されます（「…はこのブラウザでは動作していません」）。

**エージェントのブラウザでも使う**は、最初はオフです。オンにすると、その拡張機能は、サインインを保持するエージェントのブラウザ、つまりプロファイルを使うブラウザでも動作します（[プロファイルでサインインを保持する](/guide/web#keep-sign-ins-with-profiles)を参照）。対象はそれだけです。毎回新しく起動するブラウザには拡張機能は入りません。（サーバーでは、ChromiumまたはChrome for Testingが読み込みます。Google Chromeはもう読み込みません。）

### 動作しない場合があるもの

デスクトップアプリのブラウザは、Chromeが拡張機能に提供する機能の大半に対応しています。拡張機能がページに追加するコンテンツ、ポップアップ、オプションページ、保存された設定、メッセージ、バッジ、通知（システムの通知として表示）、アラームは動作します。タブに対する操作も同様です。拡張機能は、いま開いているタブや、読み取りを許可されたページのアドレスとタイトルを確認でき、タブを開き（Chromeと同じく前面に）、切り替え、閉じ、読み込みや変更を検知します。ダウンロードはユーザー自身のダウンロードと同じように保存され、許可されたサイトのCookieの読み取りと設定ができ、拡張機能が自分用に作るバックグラウンドページ（オフスクリーン）も動作し、サイドパネルもポップアップと同じようにボタンの下に開きます。動作しない場合があるのは、リクエストのブロックや変更（多くの広告ブロッカーが利用しています）、アカウントでのサインイン、ブラウザの履歴とブックマーク、タブグループ、拡張機能のキーボードショートカット、拡張機能が右クリックメニューに追加する項目（受け付けられますが、表示されません）です。どれを要求しているかは、拡張機能の行に「一部の機能はここでは動作しない場合があります：リクエストのブロックや変更、アカウントでのサインイン」のように表示されます。この表示は拡張機能が要求する内容に基づくため、実際には問題なく動作することもあります。

## ページをエージェントに渡す

エージェントが専用のブラウザそのものを使うことはありません。渡せるのは1ページだけで、方法は2つあります（[プライベートタブ](/guide/web#private-tabs)は渡せません。そこでは**質問**がグレーアウトされ、ページのコピーもアプリが拒否します）。**質問**は読むためのコピーを渡し、**実行**は作業用のタブを渡します。どちらもバーの**質問**から使います。ページの横の列が開き、**質問**と**実行**の切り替えがあります（[ページの横で質問する](/guide/web#ask-beside-the-page)を参照）。対象はウェブサイトのページです。バーのボックスは、切り替えに応じて、入力した内容でどちらも行えます。**このページについて質問：「…」**の行は、**実行**を選ぶと**このページで実行：「…」**に変わります。

### このページについて質問する

エージェントには、ページのコピーが渡されます。これはタイトル、アドレス、ページ上で選択していた内容、読み取れるテキスト（最大200,000文字）を含むファイルです。そして、スタートページで最後に使ったエージェントとモデルで、質問を含む新しいセッションが始まります。回答はページの横の列に表示され、**セッションとして開く**を押すとそのセッションに移動します。エージェントはページに触れず、サインイン情報も見られません。読むのはコピーだけです。コピーは現在タブに表示されている内容なので、先にページの読み込みが終わるのを待ってください。

### ページで実行する

質問で**実行**を選ぶと、列に「エージェントにこのページで何をさせますか？」と表示され、エージェントに渡される内容が示されます。エージェントボタンで**Claude Code**または**Custom**を選び（ブラウザだけに限定できるのはこの2つだけで、ほかはアプリが拒否します）、**実行する**を押します。ページ内で**エージェントに質問**で選んだ言葉や、**この画像について質問**で選んだ画像は、リクエストに添えられます。エージェントに渡されるのは次のものです。

- **専用のタブ**：サインインを保持するブラウザで、ページのアドレスで開かれます。そのサイトにはユーザーとしてサインインした状態です。自分のタブはそのまま残ります。
- **そのサイトだけ**：ほかのサイトのページは開けません。このコンピューター上のページの場合は、そのアドレスだけです。
- **ブラウザだけ**：コマンド、ファイル、ウェブ検索、ほかのアプリ、メモリ、サブエージェントは使えません。このようなセッションはほかのエージェントでは続けられず、フォークしてもブラウザだけに限定されたままです。
- **送信前の停止**：前述のとおり、送信、投稿、削除、送金などを行うボタンを押す前に確認を求め、判断に迷うときはユーザーに尋ねるよう指示されています（[送信、投稿、削除を行うボタン](/guide/web#buttons-that-send-post-or-delete)を参照）。支払いは、これまでどおりユーザーが行います。

エージェントへの最初のメッセージには、ページがエージェントのブラウザで開かれていることと、そこで1人で作業することが伝えられます。設定の**エージェント用のブラウザ**がオンになっている必要があります。**実行する**を押すと、ページの場所にエージェントのタブが表示され、横に会話が表示されます（[作業中のエージェント](/guide/web#agents-at-work)を参照）。自分のタブに戻ってそのタブの質問を開くと、会話が表示され、**作業を見る**（エージェントのタブが再び表示されます）、**セッションとして開く**、**新しいリクエスト**があります。

### ページを取り戻す

ページを受け取ったエージェントのブラウザでは、メッセージボックスの上のパネルに「example.comからのタブ」と**引き継ぐ**が表示され、見ている間はバーにも表示されます。押すとエージェントのタブが閉じ、そのページが自分の新しいタブとして前面に開きます。エージェントには「ページを引き継ぎました。もう自分のものです」と伝えられます。エージェントのブラウザは、最後のタブとともに閉じるほか、セッションが終わったときにほかのセッションと同じように閉じます（[ブラウザが閉じるとき](/guide/web#when-the-browser-closes)を参照）。

## 作業中のエージェント

エージェントがブラウザを開いている間、タブの列の**作業中のエージェント**に、1つにつき1行で一覧表示されます。セッションのタイトルと、いま行っていることが表示されます（「「サインイン」をクリック中」「待機中」「操作中：エージェントは待機しています」）。一覧は常に最新で、ブラウザを開いているエージェントがいない場合、この項目は表示されません。行をクリックすると、そのブラウザがページの場所に表示されます。

- ページは、エージェントからの質問が上に表示され、周りに輪が付いた状態で表示されます（[ログイン、確認、支払いのために操作を代わる](/guide/web#take-over-to-log-in-solve-a-check-or-pay)を参照）。輪は、ユーザーの対応を待っている間は黄色、操作している間は青です。ボックスには、エージェントとセッションのタイトルのチップ（その**×**、**自分のタブに戻る**で戻ります）と、エージェントのタブのアドレスが表示されます。
- バーには、エージェントの作業中は**停止**、**操作を代わる**（操作しているときは**戻す**）、渡したページには**引き継ぐ**、そして**セッションを開く**があります。デスクトップアプリでは、ページ内をクリックすると自分で操作でき、その間エージェントは待機します。
- 右の列には、セッションの会話がリアルタイムで、メッセージボックスとともに表示されます。作業を見たり、返答したり、メッセージを送ったりできます。上部には**セッションを開く**と**×**があります。

**Esc**、チップの**×**、**自分のタブに戻る**、または自分のタブのクリックで、自分のタブに戻ります。右の列は、以前表示していた内容に戻るか、閉じます。

## ブラウザの設定

[設定 → 機能 → ブラウザ](/settings?s=browser)（「エージェントが使うウェブブラウザ。操作の様子を見ることも、引き継ぐこともできます」）を開きます。

### エージェント用のブラウザ

[エージェント用のブラウザ](/settings?s=browser&find=A%20browser%20for%20agents)は、セクションのタイトルの横にあるスイッチです。すべてのエージェントのブラウザをオンまたはオフにします。Chromiumが見つかると自動でオンになり、見つかるまではオンにできません。オフの間、エージェントはブラウザのツールを使えません。各エージェントにも専用の**ブラウザを使う**スイッチが[使えるもの](/guide/agents#what-it-may-use)にあります。このスイッチがオフのエージェントは、ここでの設定にかかわらずブラウザのツールを使えません。

### Chromium

[Chromium](/settings?s=browser&find=Chromium)には、使用中のChromiumがバージョンとともに表示され、その場所は（i）で確認できます。アプリは次の順に選びます。デスクトップアプリでは**デスクトップアプリ専用のブラウザ**、このコンピューターにインストールされているChromeまたはChromium、アプリがダウンロードしたもの、Playwright（ブラウザのテスト用ツール）がインストールしたもの、の順です。複数見つかった場合は、選択肢から**見つかった中で最適なもの**か、特定の1つを選べます。

デスクトップアプリ専用のブラウザはダウンロードが不要で、表示するパスもありません。これを使用中は、行に「ページはアプリのウィンドウに表示されます。」と表示され、**Chromeをダウンロード**と**ウィンドウを表示**は意味を持たないため表示されません。別のChromiumを選ぶと、再び表示されます。ブラウザページ（自分用のブラウザ）も同じエンジンを使います。

Chromiumが1つも見つからない場合は、その旨が行に表示され、Chrome for Testing（約170MB）をアプリのデータフォルダにダウンロードするよう案内されます。**Chromeをダウンロード**を押すと、進行状況がバーで表示されます。失敗した場合は、その理由が行に表示されます。ダウンロード済みのコピーがない間は、ほかのChromiumが見つかっていても、このボタンは表示されたままです。

ChromeのサンドボックスA（ページとコンピューターのそのほかの部分を隔てる壁）がこのコンピューターで動作しない場合は、その旨の注意が表示されます。ページがこのマシンのネットワークに届かない状態は変わりませんが、プロファイルは必要なサイトだけに絞ってください。

### ウィンドウを表示

[ウィンドウを表示](/settings?s=browser&find=Show%20a%20window)は、初期状態ではオフです。ブラウザは画面に出ない状態で動作し、アプリ内で様子を見られます。オンにすると、このコンピューターの画面にもウィンドウが開きます。Playwrightのヘッドレスシェル（ウィンドウのないChromium）はウィンドウを表示できないため、これを使う間はスイッチがオフのままです。変更は、次にブラウザが起動したときに反映されます。デスクトップアプリ専用のブラウザを使用中は、このスイッチは表示されません。

### ページをこのマシンとそのネットワークから隔離

[ページをこのマシンとそのネットワークから隔離](/settings?s=browser&find=Keep%20pages%20off%20this%20machine%20and%20its%20network)は、初期状態ではオンです。ページは、このコンピューターや、ネットワーク上のプライベートアドレス（ルーター、プリンター、このアプリなど）に、直接の接続でも、後でそうしたアドレスにつながるサイト名を経由しても、アクセスできません。すべての接続がアプリのチェックポイントを通ります。セッションは、許可すれば自身の開発サーバーを開けます（[セッションにこのコンピューターやネットワーク上のサイトを開かせる](/guide/web#let-a-session-open-a-site-on-this-computer-or-your-network)を参照）。オフにすると、ページはネットワークにアクセスできますが、Hydor自体は引き続きアクセスできません。

### 画像を扱えるモデル向けのスクリーンショット

[画像を扱えるモデル向けのスクリーンショット](/settings?s=browser&find=Screenshots%20for%20models%20that%20see%20images)は、初期状態ではオンです。画像を扱えるモデルのエージェントは、番号付きの枠が描かれたページを見ることができます。テキストしか読めないモデルは、常にページをテキストとして受け取ります。オフにすると、すべてのモデルがそうなります。

### サインイン済みのサイトで送信前に確認

[サインイン済みのサイトで送信前に確認](/settings?s=browser&find=Ask%20before%20sending%20on%20signed-in%20sites)は、初期状態ではオンです。エージェントがサインイン済みのサイトで何かを送信、投稿、削除、送金しようとする前に、確認が表示されます（[送信、投稿、削除を行うボタン](/guide/web#buttons-that-send-post-or-delete)を参照）。オフにすると、プロファイルがサインイン済みのサイトや、渡されたページでは、確認なしでそうしたボタンを押します。支払いは、どちらの設定でも止まります。

### サイト：これらのサイトのみ、これらのサイトは常に除外

[サイト](/settings?s=browser&find=Sites)の下にある2つのリストは、すべてのセッションのブラウザに適用されます。1行に1サイトを、example.comのように入力します（サブドメインも含まれます）。

- **これらのサイトのみ**：1件でも入力があると、ブラウザはこれらのサイトのページだけを開きます。空の場合は、どのサイトも開けます。
- **これらのサイトは常に除外**：これらのサイトからは何も読み込まれません。

変更すると、グループのタイトルの横に**サイトを保存**が表示されるので、押してください。アドレス全体を貼り付けることもできます。アプリはサイト部分だけを保存します（「https://www.example.com/page」はexample.comになります）。各セッションは、ブラウザのメニューから独自に追加することもできます（**このセッションのサイト**）。

### プロファイルでサインイン状態を保つ

**プロファイル**とは、セッションをまたいでログイン状態を保つ、専用のブラウザフォルダです。パスワードがエージェントに渡ることなく、サインイン済みのサイトで作業できます。自分のChromeのプロファイルは使われません。[プロファイル](/settings?s=browser&find=Profiles)で次のようにします。

1. **新しいプロファイル**を押し、名前（仕事、買い物など）を付けて、**追加**を押します。
2. 「サイトにログイン · 仕事」というウィンドウが開きます。ログインするサイト（github.com/loginなど）を入力して、**開く**を押します。
3. 通常のブラウザと同じように、ページ内でクリックや入力をしてログインします（スマートフォンでは、**キーボード**でキーボードを開けます）。ほかのサイトも同じ手順で開けます。
4. 終わったらウィンドウを閉じます。ログイン情報はプロファイルに残ります。

使うには、セッションのブラウザを開き、**ブラウザのオプション**（⋯）→ **プロフィール**でプロファイルを選びます。選ぶとブラウザが閉じ、次にエージェントまたは自分が開いたときにログイン済みの状態で開き、パネルにプロファイル名が表示されます。同じプロファイルを使うセッションは、ログイン情報を共有します。

一覧の各プロファイルには、**サイトにログイン**（ほかのサイトにログインする場合）と、**名前を変更**と**削除**がある**⋯**メニューがあります。**削除**すると、そのログイン情報とブラウザが保持していたすべてのデータも削除され、そのプロファイルを使っているブラウザは閉じられます。プロファイルがまだない場合、一覧には、各セッションのブラウザは新しい状態で始まり、どこにもログインしていないと表示されます。

### 自分のブラウジング

デスクトップアプリでは、[設定 → ブラウザ](/settings?s=browser)に**自分のブラウジング**グループ（「ブラウザページ：自分で使うページ。エージェントは使えません」）もあり、ブラウザページのパネルを開く3つの行があります。[ブックマーク](/settings?s=browser&find=Bookmarks)（「自分のもの。このコンピューター上のほかのブラウザのものも含みます」）、[拡張機能](/settings?s=browser&find=Extensions)（「Chrome拡張機能（デスクトップアプリ）」）、[ブラウザ設定](/settings?s=browser&find=Browser%20settings)（「ホームページ、検索エンジン、翻訳、ダークページ、広告ブロック、履歴、保存されたデータの消去」）です。ほかの環境では、このグループは表示されません。[ブックマーク](/guide/web#bookmarks)、[Chrome拡張機能](/guide/web#chrome-extensions)、[ブラウザ設定](/guide/web#browser-settings)を参照してください。

## エージェントにコンピューターを使わせる

デスクトップアプリでは、Mac、Windows、Linuxのいずれでも、エージェントがコンピューター自体を人と同じように使えます。画面を見て、マウスとキーボードを操作します。対象はどのアプリでも構いません（Macのメモやカレンダー、Windowsのメモ帳やExcel、Linuxのファイル、ブラウザでは扱えないアプリなど）。ウェブサイトについては、より速く安全なブラウザを使います。コンピューターの操作は、初期状態ではオフです。各エージェントにも専用の**コンピューターを使う**スイッチが[使えるもの](/guide/agents#what-it-may-use)にあります。このスイッチがオフのエージェントは、コンピューターの操作がオンでもコンピューターを使えません。

### コンピューターの操作をオンにする

[設定 → 機能 → コンピューターの操作](/settings?s=computer)（「エージェントが画面を見て、マウスとキーボードを操作します（デスクトップアプリ）」）を開き、セクションのタイトルの横にある[**コンピューターの操作**](/settings?s=computer&find=Computer%20use)スイッチをオンにします。続いて、使用しているシステムに応じて次の操作をします。

- **Mac**では、HydorにmacOSの2つの権限を与えます。[**アクセシビリティ**](/settings?s=computer&find=Accessibility)（マウスとキーボードを使うためのmacOSの権限）の横で**許可…**を押します。HydorがこのコンピューターをコントロールしてよいかmacOSに尋ねられ、システム設定の**プライバシーとセキュリティ → アクセシビリティ**が開くので、そこで**Hydor**をオンにします。次に[**画面収録**](/settings?s=computer&find=Screen%20Recording)（画面を見るためのmacOSの権限）の横で**許可…**を押し、**画面収録**（macOS 15では**画面とシステムオーディオの収録**）で**Hydor**をオンにします。macOSからHydorの終了と再起動を求められたら、そのとおりにしてください。実行中のエージェントは作業を続けます。macOSが許可した権限には**許可済み**と表示され、アプリを更新しても保たれます。システム設定では**Hydor**がオンなのに設定では**許可…**のままの場合、そのスイッチは以前のバージョンのものです（0.28.1より前は、更新のたびに権限を付与し直す必要がありました）。**許可…**を押すとスイッチが解除されるので、もう一度**Hydor**をオンにします。
- **Windows**では、許可する操作はありません。管理者として実行中のプログラムと、ロック中の画面は、エージェントの操作対象外です。
- **Linux**では、Python 3があるX11（Xorg）デスクトップで動作します。Python 3はほとんどのシステムに入っています。現在多くのシステムでGNOMEやKDEが使っているWaylandのデスクトップでは、アプリが互いの画面を見ることも、マウスやキーボードを操作することもできません。その場合は、セクションにその旨と、代わりにX11セッションでログインする方法が表示されます（Ubuntuでは、ログイン画面の歯車 → **Ubuntu on Xorg**）。

このコンピューターでコンピューターの操作が動作しない原因がある場合は、セクションの上部の黄色いボックスに内容が表示されます（スイッチがオフのときは、エージェントがこのコンピューターを使えないという注意が表示されます）。このセクションはどの環境でも設定に表示されますが、実際に操作できるのはデスクトップアプリだけです。ほかの環境ではその旨が表示されます。

### エージェントがコンピューターでできること

セッションのエージェントが初めてコンピューターを使おうとすると、会話内のカードに「エージェントにMacを使わせますか？」と表示されます（Windowsでは「PC」、Linuxでは「コンピューター」）。選択肢は**このセッションで許可**と**今はしない**です。セッションは返答を待ち、通知が届きます。許可すると、エージェントは次のことができます。

- 画面を見る（メインディスプレイを縮小したもの。ほかのディスプレイは表示されません）
- クリック、ダブルクリック、右クリック、ドラッグ、スクロール、ポインターの移動
- 任意の言語のテキスト入力、およびMacの⌘C、WindowsとLinuxのCtrl+Cなどのキーやショートカットの操作
- 「スタート」メニューやアプリケーションメニューに表示される名前を指定してアプリを開く

エージェントの作業中は、すべてのディスプレイで画面の縁が光り、下部に「エージェントがMacを使用中です」（PC、コンピューター）と「Escで停止」というメモが表示されます。クリックはこの表示を通り抜け、キーボードは奪われません。この表示は自分に見せるためのもので、エージェントのスクリーンショットには写りません（スクリーンショットを撮る間だけ非表示になり、その後戻ります）。Linuxでは、GNOME、KDE、Xfce、Cinnamon、MATEのように、ウィンドウを合成するデスクトップが必要です。そうでないデスクトップでは光りませんが、トレイアイコンにはエージェントが作業中であることが表示されます。

### エージェントが画面上で指している場所を見る

エージェントは自分のマウスポインターを動かしますが、ポインターは小さく、見失いやすいものです。そのため、作業中は光と同じ色で柔らかなハローを持つ大きなリングがポインターを囲み、横に**エージェント**のタグが表示されます。

- ポインターは各地点へ飛ぶのではなく、4分の1秒で滑らかに移動し、リングもそれに付いていくので、目で追えます。
- クリックした場所には波紋が広がります（右クリックは破線の波紋、ダブルクリックは2つの波紋）。ボタンを押し続けている間（ドラッグ）は、リングが小さく締まり、ドラッグに付いていきます。
- 入力した言葉や押したキー（Ctrl+S、Enterなど）は、タグの横にしばらく表示され、スクロールの向きは矢印で示されます。

リングは光の一部です。クリックはリングを通り抜け、キーボードは奪われず、エージェントのスクリーンショットにも写りません。Linuxでは、ウィンドウを合成するデスクトップが必要です。

各ステップは、会話内に1行で表示され、その後の画面の小さな画像が付きます。画像をクリックすると大きく表示され、エージェントの回答全文の行も見られます。開いた画像には、そのステップで操作した場所が示されます。クリックした場所にはリング（ダブルクリックは2つ、右クリックは破線）、ドラッグには線、スクロールには矢印が表示され、1つのステップで複数の操作をした場合は番号が付きます。アプリは、各セッションの直近200ステップ分の画像を保存します。1か月操作のないセッションの画像は削除されます。

エージェントには、操作の前に画面を確認すること、ウェブサイトにはブラウザを使うこと、パスワード、カード番号、コードの入力、支払い、購入、送金は決して行わないことが指示されています。これらが必要な場合、エージェントは手を止め、自分で行うよう求めます。コンピューターを使えるセッションは、同時に1つだけです。

### エージェントによるコンピューターの操作を止める

エージェントがコンピューターを使っている間は、光とメモが表示され、アプリのアイコンにもその状態が示されます（Macでは、メニューバーのアイコンの横に「エージェントがMacを使用中」と表示されます）。また、そのセッションのメッセージボックスの上に「エージェントがMacを使用中です」（PC、コンピューター）と表示されます。すぐに止めるには、次のいずれかを行います。

- どのアプリでも**Esc**を押します（Macでは**⌘⇧Esc**も使えます）。Escが止めるのは、エージェントが作業中のときだけです。ダイアログを閉じるためなどにエージェント自身がEscapeを押しても、停止しません。
- アプリのアイコンのメニューで**停止**を選びます。Macではメニューバー、Windowsでは通知領域、Linuxではシステムトレイにあります。
- またはセッションのメッセージボックスの上か、設定 → コンピューターの操作で**停止**を押します。

停止すると、エージェントの作業は終了し、すべてのセッションの許可が取り消されます。エージェントが再びコンピューターを使いたい場合は、カードでもう一度確認します（「エージェントによるMacの使用を停止しました。続けますか？」）。**コンピューターの操作**をオフにした場合も同じです。

## エージェントに頼む

- 「https://searx.example.org のSearXNGをオンにして、検索プロバイダの先頭にし、テストしてください。」
- 「ウェブ検索でDuckDuckGoをオフにしてください。」
- 「エージェントが既定で50件の検索結果を取得するようにしてください。」
- 「ブラウザでfacebook.comとtiktok.comを絶対に開かないようにしてください。」
- 「ブラウザをこのコンピューター上のウィンドウで表示して、スクリーンショットをオフにしてください。」
- 「Shoppingという名前のブラウザプロファイルを作ってください。」（サイトへのログインは、設定 → ブラウザで自分で行います。）
- 「サインイン済みのサイトで、エージェントが送信や削除を押す前に確認しないようにしてください。」（設定 → ブラウザ → サインイン済みのサイトで送信する前に確認、で変更できます。元に戻すときも同じ場所です。）
- 「エージェントのブラウザは、デスクトップアプリ独自のものですか？ それともChromiumですか？」
- 「ブラウザページで見ているページをエージェントに渡すにはどうすればいいですか？」（**このページについて質問**ではコピーを渡し、質問の中の**実行**ではそのページを開いた専用のタブを渡します）
- 「このページのフォームを代わりに入力してください。」（バーで**質問**を選び、続けて**実行**を押します。エージェントは専用のタブを使い、そのサイトに自分としてサインインした状態で作業し、送信する前に確認します）
- 「アドレスバーからYouTubeやWikipediaを直接検索するにはどうすればいいですか？」（検索ショートカットを使います。`yt`や`wiki`に続けてスペースと検索したい言葉を入力します。**ブラウザの設定** → **検索ショートカット**で自分用のショートカットを追加できます）
- 「ウェブページを既定で大きく表示して、スペルチェックをオフにしてください。」（**ブラウザの設定** → **ページ** → **ページのズーム**と**スペルチェック**）
- 「ページの横にある列を広くしてください。」（左端をドラッグします。ダブルクリックすると元の幅に戻ります）
- 「ブラウザで使えるキーは何ですか？」（**メニュー** → **キーボードショートカット**）
- 「example.org/reportsを、ブックマークバーの「Work」というフォルダに追加してください。」
- 「ブラウザの検索エンジンやホームページを変更するにはどうすればいいですか？」（ブラウザページの**メニュー** → **設定**で変更できます。変更できるのは本人だけで、エージェントにはできません）
- 「ブラウザで特定のサイトだけ広告を許可するにはどうすればいいですか？」（鍵アイコンの**このサイトで広告を許可**）
- 「閲覧履歴とCookieを消去するにはどうすればいいですか？」（**ブラウザの設定** → **閲覧データを消去**。期間は履歴に適用され、履歴と一緒に保持されるダウンロードの一覧にも適用されます）
- 「アドレスバーに、入力した言葉が1つも含まれていない、以前見たページが候補に出るのはなぜですか？」（意味で検索がオンのときは、入力した内容に関するページも候補に表示されます）
- 「タブをグループに分けるにはどうすればいいですか？ また、「AIでタブをグループ化」では何が送信されますか？」（タブを右クリックして**グループに追加**を選びます。AIボタンを押したときだけ、タブのタイトルとアドレス（?や#以降は除きます）が補助モデルに送信されます）
- 「閉じたタブをもう一度開くにはどうすればいいですか？」（**Ctrl+Shift+T**、または履歴の**最近閉じたタブ**）
- 「ページ上の言葉をハイライトして、あとでまた見つけるにはどうすればいいですか？」（言葉を選択して右クリックし、**ハイライト**を選びます。**メニュー** → **ハイライト**で一覧を確認できます）
- 「ブラウザは広告をブロックしますか？ そのリストはどこから取得されますか？」
- 「プライベートタブでは何が保存され、何が消えますか？」（サインイン情報、Cookie、サイトデータは別に管理され、最後のプライベートタブを閉じると消えます。ページは履歴に残りません。ダウンロード、ブックマーク、保存したものは残ります）
- 「このページを英語に翻訳して、日本語のページは常に翻訳してください。」（アドレスバーの翻訳ボタンを使います。**常に翻訳**は**ブラウザの設定** → **翻訳**にあります。ページの文章は補助モデルに送信されます）
- 「余計な要素なしで、記事を大きな文字で読むにはどうすればいいですか？」（アドレスバーの本のボタンを押し、続けて**Aa**を選びます）
- 「ウェブページをダークで表示して、1つのサイトだけ除外してください。」（**メニュー** → **ダークページ**を選び、そのサイトの鍵アイコン → **このサイトのダークページ**で設定します）
- 「ウェブページ全体を画像やPDFとして保存するにはどうすればいいですか？」（**メニュー** → **スクリーンショットまたはPDF** → **ページ全体のスクリーンショット**または**PDFとして保存…**。どちらもダウンロードに保存されます）
- 「AIでブックマークをフォルダに整理するにはどうすればいいですか？ また、何が送信されますか？」（ブックマークパネルの**AIで整理**を使います。**整理**を押したときだけ、ブックマークのタイトルとアドレス（?や#以降は除きます）およびフォルダ名が補助モデルに送信されます。**元に戻す**で元の状態に戻せます）
- 「ブックマークを探すにはどうすればいいですか？」（ブックマークパネルの上部にある**ブックマークを検索**）
- 「ページをあとで読むために取っておくにはどうすればいいですか？ また、その一覧はどこにありますか？」（**メニュー** → **あとで読む** → **このページを追加**、または右クリック → **このページをあとで読む**。一覧はそのパネルと、タブの下にあるあとで読むリストにあります）
- 「このページを「Thesis」プロジェクトに保存してください。」（隣の**▾**で**学位論文**を選んでから**保存**を押します。コピーはプロジェクトの**ファイル**に入ります）
- 「ChromeとFirefoxのブックマークをブラウザページに取り込んでください。」（または「Safariのブックマークを取り込めないのはなぜですか？」）
- 「Chromeの履歴をブラウザページに取り込んでください。」（または「Safariの履歴を取り込めないのはなぜですか？」）
- 「ブラウザに入っているChromeの拡張機能はどれですか？ そのうち、エージェントのブラウザでも動くのはどれですか？」
- 「https://chromewebstore.google.com/detail/… の拡張機能をブラウザに追加してください。」（アプリが毎回先に確認します）
- 「ツールバーにはパスワードマネージャーだけを表示して、ほかの拡張機能は**拡張機能**メニューに入れてください。」（**拡張機能**ボタンのメニューで、各拡張機能の横にあるピンを使います）
- 「riverside.example.orgの図書館カードのフォームを代わりに入力してください。見守っています。」（クリックや入力の位置は、ライブビューにポインターで表示されます）
- 「MacのメモアプリでNotesを開いて、今日の買い物リストでメモを始めてください。」
- 「メモ帳を開いて、今日の買い物リストを書き留めてください。」（Windowsの場合です。作業中は画面の周りが光り、指している位置がリングで示され、Escで止められます）
