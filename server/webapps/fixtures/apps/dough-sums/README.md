# Dough Sums

Put in how many loaves and how much each should weigh; it says how much flour, water, salt and starter to weigh out.

To run it (needs Node.js 18.2 or newer, nothing to install):

    npm start

Then open http://localhost:3000. On a phone on the same Wi-Fi, use this computer's address instead of "localhost".
To use another port: `PORT=8080 npm start`. Nothing is saved and there is no login.
