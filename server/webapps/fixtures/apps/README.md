# Apps the web app tests run

Four small web apps that agents built from scratch, as they came out, kept so that the tests and proofs of launching and of
the page checks have real apps to run. Each has the `hydor.json` Hydor runs it by and the `judge.json` its builder wrote for
the benchmark. Their people and addresses are made up. Nothing here is part of Hydor, and the apps are not to be tidied:
what the checks find in them is part of what the tests look at.

| Folder | What it is | Dependencies |
| --- | --- | --- |
| `food-bank` | A food bank's stock and deliveries, with accounts and photos | none |
| `crews` | Customers, jobs and notes, seen by one crew | Express (`npm ci`) |
| `dough-sums` | A baker's calculator | none |
| `market-takings` | A card reader's weekend file added up | none |
