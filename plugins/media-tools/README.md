# Audio and video

Teaches agents to work with audio and video files using **ffmpeg** (which must be installed on this
computer) and gives them **yt-dlp** in an environment of its own, for downloading media you have the
right to download.

The skill `media-tools` covers converting, trimming, joining, compressing, extracting audio,
normalising loudness, GIFs, thumbnails and contact sheets, subtitles, and checking every result with
ffprobe. Other plugins build on this one (Speech to text).
